# x86/x64指令集基础

### 3.1 寄存器体系

**x86通用寄存器（按大小分层）：**

```
64位:  RAX  RBX  RCX  RDX  RSI  RDI  RBP  RSP  R8  R9  R10  R11  R12  R13  R14  R15
32位:  EAX  EBX  ECX  EDX  ESI  EDI  EBP  ESP                         R8D-R15D
16位:  AX   BX   CX   DX   SI   DI   BP   SP
低8位: AL   BL   CL   DL   SIL  DIL  BPL  SPL   R8B-R15B
高8位: AH   BH   CH   DH (仅在32位模式可用)
```

**特殊寄存器：**
- RIP/EIP：指令指针寄存器（程序计数器）
- RFLAGS/EFLAGS：标志寄存器

**EFLAGS关键标志位：**

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | CF | 进位标志 |
| 2 | PF | 奇偶标志 |
| 4 | AF | 辅助进位标志 |
| 6 | ZF | 零标志 |
| 7 | SF | 符号标志 |
| 8 | TF | 陷阱标志（单步调试） |
| 9 | IF | 中断允许标志 |
| 10 | DF | 方向标志 |
| 11 | OF | 溢出标志 |

### 3.2 寻址方式

**x86寻址模式通用公式：**

```
[Base + Index*Scale + Displacement]
```

- Base：基址寄存器（EAX/RAX等，可为空）
- Index：变址寄存器（可为空）
- Scale：比例因子（1, 2, 4, 8）
- Displacement：位移量（8位/16位/32位立即数）

**寻址方式示例：**

```asm
mov eax, 0x42            ; 立即数寻址
mov eax, ebx             ; 寄存器寻址
mov eax, [0x403000]      ; 直接寻址（内存地址）
mov eax, [ebx]           ; 寄存器间接寻址
mov eax, [ebx+0x10]     ; 基址+位移
mov eax, [ebx+esi]      ; 基址+变址
mov eax, [ebx+esi*4]    ; 基址+变址*比例
mov eax, [ebx+esi*4+8]  ; 完整寻址公式
lea eax, [ebx+0x10]     ; LEA用于计算地址（不访问内存）
```

### 3.3 核心指令详解

**数据传送指令：**

```asm
MOV dest, src     ; 基本数据传送
MOVZX dest, src   ; 零扩展传送（小→大）
MOVSX dest, src   ; 符号扩展传送（小→大）
LEA dest, [addr]  ; 计算有效地址（不访问内存）
PUSH src          ; 压栈
POP dest          ; 出栈
XCHG op1, op2     ; 交换
```

**算术运算指令：**

```asm
ADD dest, src     ; 加法
SUB dest, src     ; 减法
MUL src           ; 无符号乘法（结果在RDX:RAX）
IMUL dest, src    ; 有符号乘法
DIV src           ; 无符号除法（RDX:RAX / src）
IDIV src          ; 有符号除法
INC op            ; 加1
DEC op            ; 减1
NEG op            ; 取负
```

**逻辑运算与位操作：**

```asm
AND dest, src     ; 按位与
OR dest, src      ; 按位或
XOR dest, src     ; 按位异或（XOR reg,reg 常用于清零）
NOT op            ; 按位取反
SHL op, count     ; 逻辑左移
SHR op, count     ; 逻辑右移
SAR op, count     ; 算术右移（保留符号）
ROL op, count     ; 循环左移
ROR op, count     ; 循环右移
```

**比较与条件跳转：**

```asm
CMP op1, op2      ; 比较（计算op1-op2，设置标志位）
TEST op1, op2     ; 测试（计算op1&op2，设置标志位）

; 条件跳转（基于CMP/TEST结果）
JE  / JZ  target  ; 等于/零 → 跳转
JNE / JNZ target  ; 不等于/非零 → 跳转
JG  / JNLE target ; 大于 → 跳转（有符号）
JL  / JNGE target ; 小于 → 跳转（有符号）
JGE / JNL target  ; 大于等于 → 跳转（有符号）
JLE / JNG target  ; 小于等于 → 跳转（有符号）
JA  / JNBE target ; 大于 → 跳转（无符号）
JB  / JNAE target ; 小于 → 跳转（无符号）
JS  target        ; 符号标志为1 → 跳转
JNS target        ; 符号标志为0 → 跳转
```

**函数调用相关：**

```asm
CALL target       ; 调用函数（push返回地址, jmp target）
RET               ; 返回（pop返回地址到EIP, jmp EIP）
RET n             ; 返回并清理n字节参数
ENTER level, nest  ; 建立栈帧
LEAVE             ; 拆除栈帧（mov esp,ebp; pop ebp）
```

### 3.4 函数调用与栈帧

**函数调用过程中栈的变化：**

```asm
; 调用者代码
push arg3          ; 参数3入栈（右到左）
push arg2          ; 参数2入栈
push arg1          ; 参数1入栈
call function      ; 返回地址入栈，跳转到function

; 被调用函数
function:
    push ebp           ; 保存调用者的EBP
    mov ebp, esp       ; 建立新栈帧（EBP指向栈帧基址）
    sub esp, 0x20      ; 分配局部变量空间
    
    ; 函数体...
    ; [ebp+8]  = arg1   访问参数
    ; [ebp+12] = arg2
    ; [ebp-4]  = 局部变量1
    ; [ebp-8]  = 局部变量2
    
    mov esp, ebp       ; 释放局部变量（等同于leave的mov部分）
    pop ebp            ; 恢复调用者的EBP
    ret 12             ; 返回并清理3个参数（cdecl则用ret，调用者清栈）
```

**栈帧布局图：**

```
高地址
+--------------------+
|   参数3            |  [ebp+16]
+--------------------+
|   参数2            |  [ebp+12]
+--------------------+
|   参数1            |  [ebp+8]
+--------------------+
|   返回地址(RET)    |  [ebp+4]
+--------------------+
|   保存的EBP        |  [ebp+0]  ← EBP指向这里
+--------------------+
|   局部变量1        |  [ebp-4]
+--------------------+
|   局部变量2        |  [ebp-8]
+--------------------+
|   ...              |
+--------------------+  ← ESP指向栈顶
低地址
```

**x64调用约定的变化：**

Linux x64 (System V ABI)：
- 参数1-6：RDI, RSI, RDX, RCX, R8, R9
- 参数7+：通过栈传递
- 返回值：RAX
- 栈必须16字节对齐（call前）

Windows x64 (Microsoft ABI)：
- 参数1-4：RCX, RDX, R8, R9
- 参数5+：通过栈传递
- 返回值：RAX
- 调用者必须在栈上为4个寄存器参数预留空间（shadow space）
