# 附录：常见代码模式识别速查表

| 代码模式 | 汇编特征 | 含义 |
|---------|---------|------|
| 循环 | CMP+Jcc回跳 | for/while循环 |
| 条件分支 | CMP+Jcc前跳 | if-else |
| 函数调用 | CALL+RET | 函数调用 |
| 字符串比较 | REP CMPSB | strcmp |
| 内存复制 | REP MOVSD | memcpy |
| 数组访问 | MOV [reg+index*4] | 数组元素访问 |
| 结构体访问 | MOV [reg+offset] | 结构体成员访问 |
| 栈分配 | SUB ESP, n | 局部变量空间 |
| 栈释放 | ADD ESP, n 或 LEAVE | 释放局部变量 |
| 虚函数调用 | MOV reg,[obj]; CALL [reg+off] | C++虚函数 |

```python
# Ghidra Python 脚本模板
# 保存为 .py 文件，放入 Ghidra 脚本目录

# 获取当前程序
current_program = getCurrentProgram()
listing = current_program.getListing()

# 遍历所有函数
func = getFirstFunction()
while func is not None:
    print(f"Function: {func.getName()} @ {func.getEntryPoint()}")
    func = getFunctionAfter(func)

# 搜索特定字节模式
from ghidra.program.model.address import AddressSet
pattern = bytes([0x55, 0x48, 0x89, 0xE5])  # push rbp; mov rbp, rsp
addr_set = current_program.getMemory().findBytes(
    current_program.getMinAddress(),
    pattern,
    None,
    True,
    None
)

# 重命名所有以 FUN_ 开头的函数（根据字符串引用推测）
def rename_functions_by_strings():
    from ghidra.program.util import FunctionDef
    func_iter = listing.getFunctions(True)
    for func in func_iter:
        # 获取函数内的字符串引用
        refs = getReferencesTo(func.getEntryPoint())
        print(f"  {func.getName()}: {len(list(refs))} references")

# 修改内存数据
addr = toAddr(0x401000)
setBytes(addr, b'\x90\x90\x90')  # 写入3个NOP

# 创建数据类型
from ghidra.program.model.data import StructureDataType
struct = StructureDataType("MyStruct", 0)
struct.addByteField("field1", "第一个字段")
struct.addWordField("field2", "第二个字段")
```

**IDC / IDAPython 常用脚本：**

```python
# IDAPython 基础操作
import idautils
import idc
import idaapi

# 获取所有函数
for func_ea in idautils.Functions():
    func_name = idc.get_func_name(func_ea)
    print(f"0x{func_ea:016x}: {func_name}")

# 搜索字节模式 (IDA 7.x+)
pattern = "55 48 89 E5"  # push rbp; mov rbp, rsp
addr = idaapi.find_binary(
    idaapi.get_imagebase(),
    idaapi.get_imagebase() + idaapi.get_segm_by_name('.text').size(),
    pattern,
    16,
    idaapi.SEARCH_DOWN
)
print(f"Found pattern at: 0x{addr:x}")

# 批量重命名函数（按特征字符串）
def rename_func_by_string(target_str, new_name):
    for ref in idautils.XrefsTo(idc.get_name_ea_simple(target_str)):
        func = idaapi.get_func(ref.frm)
        if func:
            idc.set_name(func.start_ea, new_name, idc.SN_NOWARN)
            print(f"Renamed 0x{func.start_ea:x} -> {new_name}")

# Patch 字节
def patch_bytes(addr, data):
    for i, b in enumerate(data):
        idc.patch_byte(addr + i, b)

patch_bytes(0x401000, [0x90, 0x90, 0x90])  # 写入3个NOP

# 读取字符串
s = idc.get_strlit_contents(0x402000, -1, idc.STRTYPE_C)
print(f"String at 0x402000: {s}")

# 获取导入函数
for func_ea, func_name in idautils.Entries():
    print(f"Export: {func_name} @ 0x{func_ea:x}")

# 交叉引用枚举
addr = idc.get_name_ea_simple("main")
for xref in idautils.XrefsTo(addr):
    print(f"  referenced from 0x{xref.frm:x} (type: {xref.type})")

# 枚举段
for seg in idautils.Segments():
    name = idc.get_segm_name(seg)
    start = idc.get_segm_start(seg)
    end = idc.get_segm_end(seg)
    print(f"{name}: 0x{start:x} - 0x{end:x}")
```

**radare2 脚本示例（r2pipe Python）：**

```python
import r2pipe

# 连接到已打开的 r2 进程
r2 = r2pipe.open("./binary")

# 分析
r2.cmd("aaa")

# 获取函数列表
funcs = r2.cmdj("aflj")  # JSON格式输出
for f in funcs:
    print(f"0x{f['offset']:016x} {f['name']} ({f.get('nbbs', 0)} blocks)")

# 反汇编函数
disasm = r2.cmdj("pdfj @ main")
for op in disasm['ops']:
    print(f"0x{op['offset']:x}: {op.get('disasm', '???')}")

# 搜索字符串
strings = r2.cmdj("izzj")
for s in strings:
    if 'flag' in s.get('string', '').lower():
        print(f"0x{s['vaddr']:x}: {s['string']}")

# 查找 gadget
r2.cmd("/R pop rdi; ret")  # 搜索ROP gadget

r2.quit()
```

### 五、其他常用逆向工具命令

**1. checksec / file / readelf**

```bash
# 查看二进制保护机制
checksec --file=./binary
# 或 pwntools 中: pwn checksec ./binary

readelf -S ./binary     # 节区表
readelf -s ./binary     # 符号表

readelf -d ./binary     # 动态段信息
readelf -l ./binary     # 程序头

# PE文件信息 (Linux下)
objdump -f ./binary     # 文件头
objdump -d ./binary     # 反汇编
objdump -t ./binary     # 符号表
objdump -R ./binary     # 动态重定位
```

**2. strings / xxd / hexdump**

```bash
# 提取字符串
strings ./binary               # 提取可打印字符串
strings -n 8 ./binary          # 至少8字符的字符串
strings -tx ./binary           # 显示偏移（十六进制）
strings -e l ./binary          # 宽字符（UTF-16 LE）

# 十六进制查看
xxd ./binary | head -50        # 前50行十六进制
xxd -g 1 ./binary              # 1字节一组
xxd -r -p hex.txt out.bin      # 将十六进制文本转回二进制
hexdump -C ./binary | head     # 标准十六进制+ASCII显示
```

**3. objdump / nm / ldd**

```bash

nm -D ./binary                 # 动态符号

ldd ./binary                   # 查看依赖的共享库
ldd -u ./binary                # 未使用的依赖
ldd -v ./binary                # 详细版本信息
```

### 六、逆向分析工作流速查

```
静态分析工作流：
1. 文件识别 → file / readelf -h / Detect It Easy
2. 查壳 → upx -l / DIE / PEiD
3. 字符串分析 → strings / Shift+F12 (IDA)
4. 导入/导出函数分析 → ida/ghidra 的 imports/exports
5. 主函数定位 → 找 main / WinMain / entry point
6. 函数分析 → 按调用图逐层分析
7. 关键逻辑定位 → 字符串引用跳转 + 交叉引用
8. 算法识别 → 特征常量/指令序列比对

动态调试工作流：
1. 加载程序 → F3 (x64dbg) / r2 -d (radare2)
2. 设入口断点 → bp EntryPoint / 在入口点下断
3. 关键函数下断 → 字符串引用 → 定位函数 → 下断点
4. 运行到断点 → F9
5. 观察参数 → 栈/寄存器窗口
6. 单步跟踪 → F7/F8
7. 修改变量 → 内存编辑 / 寄存器修改
8. 验证逻辑 → 多次运行对比结果
```
