# 附录：常见代码模式识别速查表

| 代码模式 | 汇编特征 | 含义 |
|---------|---------|------|
| 循环 | CMP+Jcc回跳 | for/while循环 |
| 条件分支 | CMP+Jcc前跳 | if-else |
| 函数调用 | CALL+RET | 函数调用 |
| 字符串比较 | REP CMPSB | strcmp |
| 内存复制 | REP MOVSD | memcpy |
| 数组访问 | MOV [reg+index*4] | 数组元素访问 |
| 结构体访问 | MOV [reg+offset] | 结构体成员访问 |
| 栈分配 | SUB ESP, n | 局部变量空间 |
| 栈释放 | ADD ESP, n 或 LEAVE | 释放局部变量 |
| 虚函数调用 | MOV reg,[obj]; CALL [reg+off] | C++虚函数 |
