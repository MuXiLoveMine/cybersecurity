# 漏洞缓解机制概述

```
漏洞缓解机制演进:

  1990s: 无保护
    -> 栈溢出直接执行shellcode

  2000s: DEP/NX
    -> 禁止在数据段执行代码
    -> ret2libc/ROP绕过

  2001: Stack Canary
    -> 检测栈溢出
    -> 信息泄露绕过

  2005: ASLR
    -> 随机化地址空间
    -> 信息泄露绕过

  2010: RELRO
    -> 保护GOT表
    -> 部分RELRO仍可绕过

  2013: PIE
    -> 可执行文件位置随机化
    -> 信息泄露绕过

  2015+: CFI/CFG
    -> 控制流完整性
    -> COOP/数据导向攻击绕过

当前缓解机制栈:
  +--------------------------------------------------+
  |              应用层                               |
  |  +-------+ +-------+ +-------+ +-------+ +-----+ |
  |  | ASLR  | | DEP   | |Canary | |RELRO  | | PIE ||
  |  +-------+ +-------+ +-------+ +-------+ +-----+ |
  |  +-------------------------------------------+   |
  |  |              CFI / CFG                    |   |
  |  +-------------------------------------------+   |
  +--------------------------------------------------+
  |              内核层                               |
  |  +-------+ +-------+ +-------+ +-------+        |
  |  |KASLR  | |SMEP   | |SMAP   | |KPTI   |        |
  |  +-------+ +-------+ +-------+ +-------+        |
  +--------------------------------------------------+
```
