# ASLR地址空间布局随机化

### 2.1 ASLR原理

ASLR通过随机化进程地址空间中各模块的加载基址来防止攻击者预测关键地址。

```
无ASLR (固定地址):
  +------------------+
  | 0x08048000       |  <- ELF加载地址(固定)
  | .text (代码段)    |
  | 0x08049000       |  <- .plt
  | 0x0804a000       |  <- .got
  | ...              |
  | 0xbffff000       |  <- 栈(固定位置)
  +------------------+

有ASLR (随机地址):
  +------------------+
  | 0x56555000       |  <- ELF加载地址(每次不同)
  | .text (代码段)    |
  | 0x56556000       |  <- .plt
  | 0x56557000       |  <- .got
  | ...              |
  | 0x7ffd1234000    |  <- 栈(每次不同)
  +------------------+

随机化范围:
  - 栈基址: 随机偏移 0-0xFFFF (低12位固定)
  - 堆基址: 随机偏移
  - mmap基址: 随机偏移 (共享库加载位置)
  - 主可执行文件: 需要PIE才随机化
```

### 2.2 ASLR类型

| 类型 | 说明 | 随机化对象 |
|------|------|-----------|
| 用户态ASLR | 进程级地址随机化 | 栈/堆/mmap/PIE |
| KASLR | 内核地址随机化 | 内核代码/模块 |
| 独立库ASLR | 每个库独立随机化 | 共享库加载地址 |
| 全局ASLR | 整体地址空间随机化 | 所有段 |

### 2.3 绕过技术

**信息泄露绕过**

```
攻击链:
  1. 信息泄露漏洞 -> 泄露某个地址
  2. 计算基地址偏移
  3. 利用已知偏移找到目标地址
  4. 执行后续攻击

示例:
  泄露printf地址: 0x7f123456a000
  printf在libc中的偏移: 0x6a000
  libc基址 = 0x7f123456a000 - 0x6a000 = 0x7f1234500000
  system地址 = libc基址 + system偏移
```

**暴力破解绕过**

```
对于32位系统:
  ASLR随机化位数有限(约8-16位)
  可以通过暴力尝试绕过

  示例: fork服务器
  - 每次fork子进程地址空间相同
  - 可以多次尝试不同地址
  - 子进程崩溃不影响父进程

  32位Linux ASLR:
  - 栈: 19位随机化(8MB范围)
  - 暴力约524288次尝试
  - 在fork场景下可行

  64位系统暴力破解不可行
```

**非随机化模块绕过**

```
当程序加载了未编译为PIE的库时:
  - 非PIE库的地址固定
  - 可以利用固定地址的gadget

检查:
  # 查看进程映射
  cat /proc/<pid>/maps
  # 非PIE模块地址固定:
  # 00400000-00401000 r-xp 00000000 fd:00 1234 /path/to/nonpie_binary
```

**部分覆盖绕过**

```
当只能覆盖返回地址的低位时:
  原返回地址: 0x08048456
  覆盖低位为: 0x08048XYZ
  只修改最后1-2字节
  在同一模块内跳转

  适用场景:
  - 有限长度溢出(只能覆盖1-2字节)
  - 同一模块内跳转
```
