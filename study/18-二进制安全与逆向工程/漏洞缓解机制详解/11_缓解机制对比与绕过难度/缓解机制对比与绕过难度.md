# 缓解机制对比与绕过难度

### 11.1 各机制绕过技术汇总表

```
缓解机制绕过技术对比:

| 机制 | 主要绕过方法 | 前提条件 | 难度 | 常见场景 |
|------|-------------|----------|------|----------|
| ASLR | 信息泄露 | 格式化字符串/越界读 | 中 | 有信息泄露漏洞 |
| ASLR | 暴力破解 | fork服务器/32位 | 中低 | fork-based服务 |
| ASLR | 非PIE模块 | 加载了非PIE库 | 低 | 旧系统/旧库 |
| DEP | ROP | 已知gadget地址 | 中 | 有足够gadget |
| DEP | ret2libc | 已知libc地址 | 中低 | 有libc地址 |
| DEP | ret2syscall | 可控寄存器 | 中 | 有pop寄存器gadget |
| Canary | 信息泄露 | 格式化字符串/越界读 | 中 | 有信息泄露 |
| Canary | 逐字节爆破 | fork服务器 | 中高 | fork-based |
| Canary | TLS覆写 | 任意写 | 高 | 有任意写原语 |
| RELRO(P) | GOT覆写 | 任意写.got.plt | 低 | Partial RELRO |
| RELRO(F) | .fini_array | 任意写.fini_array | 中高 | Full RELRO |
| PIE | 信息泄露 | 格式化字符串泄露代码地址 | 中 | 有信息泄露 |
| PIE | Partial overwrite | 有限覆盖 | 中高 | 1-2字节覆盖 |
| CFI | 数据导向攻击 | 数据溢出 | 高 | 可覆盖关键变量 |
| CFI | COOP | C++虚表可覆盖 | 高 | 有虚表覆盖 |
| CFI | 合法目标滥用 | system在合法集 | 中 | 目标在CFG允许集 |
```

### 11.2 历史CVE案例

```
缓解机制绕过的历史CVE案例:

1. CVE-2014-0160 (Heartbleed)
   - 漏洞: OpenSSL越界读
   - 绕过机制: 信息泄露 -> 绕过ASLR
   - 影响: 泄露内存中的密钥、cookie、Canary
   - 利用链: Heartbleed泄露 -> ASLR绕过 -> ROP

2. CVE-2014-6271 (Shellshock)
   - 漏洞: Bash环境变量注入
   - 绕过机制: 不需要绕过内存保护(逻辑漏洞)
   - 影响: 直接RCE
   - 启示: 不是所有攻击都需要绕过内存保护

3. CVE-2015-0235 (Ghost)
   - 漏洞: glibc getaddrinfo栈溢出
   - 绕过机制: ASLR + DEP + Canary
   - 利用: 需要信息泄露 + ROP
   - 难度: 高(但在DHCP场景可远程触发)

4. CVE-2016-5195 (Dirty COW)
   - 漏洞: Linux内核竞态条件
   - 绕过机制: 绕过所有用户态保护
   - 影响: 只读文件可写
   - 利用: 修改setuid程序 -> 提权

5. CVE-2017-0199 (Office RCE)
   - 漏洞: OLE对象处理
   - 绕过机制: 不涉及内存保护(逻辑漏洞)
   - 利用: 通过恶意文档直接执行代码

6. CVE-2018-17182 (Linux KASLR)
   - 漏洞: 内核信息泄露
   - 绕过机制: KASLR绕过
   - 利用: 泄露内核地址 -> 内核ROP

7. CVE-2019-2215 (bad binder)
   - 漏洞: Android Binder UAF
   - 绕过机制: 绕过SELinux + ASLR
   - 利用: UAF -> 任意读写 -> 提权

8. CVE-2020-8835 (Linux eBPF)
   - 漏洞: eBPF验证器绕过
   - 绕过机制: SMEP/SMAP/KASLR
   - 利用: 验证器绕过 -> 内核读写 -> 提权
```

### 11.3 内核层缓解机制

```
内核层缓解机制(与用户态配合):

| 机制 | 保护对象 | 绕过方法 | 难度 |
|------|----------|----------|------|
| KASLR | 内核地址 | 内核信息泄露 | 高 |
| SMEP | 内核执行用户代码 | ROP/JOP | 高 |
| SMAP | 内核访问用户数据 | copy_to_user利用 | 高 |
| KPTI | 内核页表隔离 | 侧信道/Meltdown | 极高 |
| KCFI | 内核控制流 | 数据导向 | 极高 |
| STACKPROTECTOR | 内核栈溢出 | 内核信息泄露 | 高 |
| HARDENED_USERCOPY | copy_to/from_user | 合法路径利用 | 高 |
| RANDOMIZE_BASE | 内核模块地址 | 模块泄露 | 高 |

KASLR绕过示例(CVE-2018-17182):
  1. 触发内核信息泄露(如dmesg泄露)
  2. 泄露内核函数地址
  3. 计算内核基址
  4. 构造内核ROP链
  5. 提权到root

SMEP绕过:
  1. 使用内核ROP代替用户态shellcode
  2. 利用native_write_cr4关闭SMEP位
  3. 然后在用户态执行代码
  4. 需要知道内核ROP gadget地址

SMAP绕过:
  1. 使用copy_from_user/copy_to_user
  2. 利用内核中已有的数据拷贝原语
  3. 不直接访问用户态内存
  4. 通过合法内核函数间接操作

KPTI绕过:
  1. 利用侧信道(Meltdown/Spectre)
  2. 通过缓存时序泄露内核数据
  3. 不需要直接访问内核内存
  4. 但速度慢且不稳定
```
