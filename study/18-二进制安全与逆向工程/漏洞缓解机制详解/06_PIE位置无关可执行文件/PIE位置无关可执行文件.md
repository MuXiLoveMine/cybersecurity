# PIE位置无关可执行文件

### 6.1 PIE原理

```
无PIE:
  程序加载到固定地址
  代码段地址固定
  可以使用固定地址的gadget

  $ readelf -h ./binary
  Entry point address: 0x400000  (固定)

有PIE:
  程序加载到随机地址
  需要信息泄露才能确定基址
  增加攻击难度

  $ readelf -h ./binary_pie
  Entry point address: 0x1060  (偏移，实际地址随机)
```

### 6.2 绕过技术

```
PIE绕过需要信息泄露:

  1. 泄露代码段地址
     - 格式化字符串泄露栈上保存的返回地址
     - 返回地址指向代码段
     - 计算基址

  2. 泄露代码指针
     - 已初始化的函数指针
     - 虚函数表地址
     - 计算基址

  3. Partial overwrite
     - 只覆盖地址低位
     - 在同一模块内跳转
     - 不需要知道完整基址

  示例:
  泄露返回地址: 0x55a1b2c3d456
  PIE基址 = 0x55a1b2c3d000 (对齐到页)
  目标函数 = 基址 + offset
```
