# 附录：重要术语对照表

| 英文术语 | 中文 | 简要说明 |
|---------|------|---------|
| Buffer Overflow | 缓冲区溢出 | 向缓冲区写入超过其容量的数据 |
| Shellcode | Shell代码 | 用于获取shell的机器码 |
| ROP | 返回导向编程 | 利用代码片段构建攻击逻辑 |
| Gadget | 代码片段 | 以ret结尾的小指令序列 |
| Payload | 攻击载荷 | 漏洞利用的有效载荷 |
| GOT | 全局偏移表 | 动态链接函数地址表 |
| PLT | 过程链接表 | 动态函数调用的跳转表 |
| Canary | 栈金丝雀 | 栈溢出检测机制 |
| ASLR | 地址随机化 | 随机化内存布局 |
| DEP/NX | 数据执行保护 | 禁止数据段执行 |
| PIE | 位置无关代码 | 代码段地址随机化 |
| RELRO | 重定位只读 | 保护GOT表 |
| CFG | 控制流防护 | 验证间接调用目标 |
| CFI | 控制流完整性 | 控制流验证机制 |
| tcache | 线程缓存 | glibc线程级堆缓存 |
| fastbin | 快速bin | 小块内存的快速分配链表 |
| UAF | 释放后使用 | 使用已释放的内存 |
| Double Free | 双重释放 | 同一块内存被释放两次 |
| Fuzzing | 模糊测试 | 自动化漏洞挖掘 |
| Coverage | 覆盖率 | 代码执行路径覆盖 |
| Seed Corpus | 种子语料库 | 模糊测试的初始输入 |
