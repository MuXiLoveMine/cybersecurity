# 学习资源

### 5.1 书籍推荐

**入门级：**
1. 《汇编语言》- 王爽（x86汇编入门经典）
2. 《逆向工程核心原理》- 李承远（逆向入门必读）
3. 《C++反汇编与逆向分析技术揭秘》- 钱林松
4. 《程序员的自我修养—链接、装载与库》- 俞甲子

**进阶级：**
5. 《0day安全：软件漏洞分析技术》- 王清（漏洞利用圣经）
6. 《IDA Pro权威指南》- Chris Eagle
7. 《Practical Binary Analysis》- Dennis Andriesse
8. 《 Practical Malware Analysis》- Michael Sikorski
9. 《模糊测试：强制发现漏洞》- Michael Sutton

**高级/专业级：**
10. 《深入理解Linux内核》- Daniel Bovet
11. 《Windows内核安全与驱动开发》- 谭文
12. 《内核漏洞的利用与防范》- Enrico Perla
13. 《The Art of Software Security Testing》- Chris Wysopal

### 5.2 视频课程

1. **"LiveOverflow"** YouTube频道 - 二进制安全实战教学
2. **"OpenSecurityTraining2"** - 系统的安全培训视频
3. **"MalwareTechBlog"** - 恶意代码分析
4. **"OALabs"** YouTube频道 - 逆向分析教学
5. **"pwn.college"** - 亚利桑那州立大学的pwn课程
6. **"RPISEC MBE"** - RPI的安全课程材料

### 5.3 在线平台

1. **pwnable.kr** - 按难度分级的pwn练习平台
2. **pwnable.tw** - 更高难度的pwn挑战
3. **pwn.college** - 系统化的pwn学习平台
4. **crackmes.one** - 逆向工程挑战平台
5. **exploit-exercises.com** - 各种级别的安全练习
6. **RingZer0 Team** - 多方向CTF练习

### 5.4 CTF平台

1. **CTFtime.org** - 全球CTF赛事汇总
2. **攻防世界 (adworld)** - 国内优质CTF练习平台
3. **BUUCTF** - 国内综合CTF平台
4. **CTFHub** - CTF技能树学习
5. **HackTheBox** - 渗透测试与安全学习平台

### 5.5 开源项目与文档

1. **CTF Wiki** (ctf-wiki.org) - 最全面的CTF知识库
2. **pwntools文档** (docs.pwntools.com)
3. **AFL++文档** (github.com/AFLplusplus/AFLplusplus)
4. **angr文档** (docs.angr.io)
5. **shell-storm** -exploit数据库
6. **exploit-db.com** - 漏洞利用数据库

### 5.6 安全会议与论文

**重要会议：**
- Black Hat（黑帽）- 全球最知名的安全会议
- DEF CON - 世界最大的黑客大会
- RECon - 逆向工程专题会议
- OffensiveCon - 进阶安全研究会议
- CanSecWest - 加拿大安全会议
- MoSec - 移动安全会议

**重要论文方向：**
- 模糊测试效率优化
- 自动化漏洞利用生成
- 符号执行与约束求解
- 控制流完整性
- 防御机制设计
