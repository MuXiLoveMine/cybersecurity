# 花指令技术

### 花指令原理

花指令通过插入跳转指令和数据，干扰线性扫描式反汇编器（如线性扫描算法），使其将代码后的数据误判为指令，导致后续反汇编错位。

```
反汇编算法分类：
- 线性扫描（Linear Sweep）：从起始地址逐字节解析，不跟踪跳转 → 易受花指令干扰
- 递归下降（Recursive Descent）：跟踪跳转确定代码路径 → 对部分花指令有效

IDA Pro使用递归下降算法，但仍可能被特定花指令模式欺骗。
```

### 常见花指令模式

**模式1：跳转+数据干扰**
```asm
start:
    jmp over
    db 0xE8           ; 被线性扫描误认为CALL指令的开始
over:
    mov eax, 1        ; 真实代码
```

**模式2：条件跳转永真**
```asm
    pushfd
    xor eax, eax
    jz real           ; ZF总为1（xor后必跳），但反汇编器不确定
    db 0xFF, 0x25     ; 虚假数据
real:
    popfd
    mov eax, 1
```

**模式3：利用x86/x64变长指令特性**
```asm
    call label1
    db 0xE8           ; 干扰数据
label1:
    pop eax           ; 获取返回地址
    sub eax, 5        ; 修正
    jmp eax           ; 跳回call之后（跳过干扰字节）
```

**模式4：多层嵌套跳转**
```asm
    jmp a1
a1: jmp a2
a2: jmp a3
a3: jmp a4
    db 0xFF           ; 干扰
a4: mov eax, 1        ; 真实代码
```

### x64dbg/IDA反汇编影响

```
IDA Pro中花指令的表现：
  - Graph View中出现不连通的块
  - 函数被截断（IDA认为函数提前结束）
  - 数据被错误识别为指令
  - 交叉引用不完整

x64dbg中花指令的表现：
  - 单步时可能跳到数据区域
  - 反汇编窗口显示混乱
  - 断点设置在花指令区域可能失败
```

### 花指令去除方法

**手动去除**：在 IDA 中使用 `U`（Undefine）取消数据定义，然后 `C`（Code）重新分析为代码，再 `P`（Function）重建函数。

**脚本批量去除**（IDA Python）：

```python
import idautils
import idaapi
import idc

def remove_junk_patterns():
    """识别并去除常见花指令模式"""
    pattern1 = bytes([0xEB, 0x03])  # jmp +3 (短跳转跳过3字节)
    pattern2 = bytes([0xE9, 0x00, 0x00, 0x00, 0x00])  # jmp +0

    for seg in idautils.Segments():
        seg_start = idc.get_segm_start(seg)
        seg_end = idc.get_segm_end(seg)
        ea = seg_start
        while ea < seg_end:
            idaapi.get_bytes(ea, 2)
            data = idaapi.get_bytes(ea, 5)
            if data and data[:2] == pattern1:
                # NOP掉花指令
                idaapi.patch_bytes(ea, b'\x90' * 2, 2)
            ea += 1
    print("花指令清理完成")
```
