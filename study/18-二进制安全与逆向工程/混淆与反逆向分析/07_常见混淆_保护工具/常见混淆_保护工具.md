# 常见混淆/保护工具

### OLLVM（Obfuscator-LLVM）

OLLVM 是基于 LLVM 编译框架的开源代码混淆器，提供三种混淆 pass：

```bash
# 编译时启用混淆
# 控制流平坦化
clang -mllvm -fla -c target.c -o target.o

# 虚假控制流
clang -mllvm -sub -c target.c -o target.o

# 指令替换
clang -mllvm -sub -c target.c -o target.o

# 组合使用
clang -mllvm -fla -mllvm -sub -mllvm -bcf -c target.c -o target.o

# 控制不透明谓词来源
clang -mllvm -fla -mllvm -split_num=5  # 每个块分裂为5个子块
```

OLLVM 配置选项：
```
-fla              启用控制流平坦化
-bcf              启用虚假控制流
-bcf_loop=2       虚假控制流嵌套次数
-bcf_prob=40      虚假控制流概率
-sub              启用指令替换
-split            启用基本块分裂
-split_num=5      每个块分裂次数
```

### VMP / Themida / Enigma

| 工具 | 特点 | 保护级别 |
|------|------|----------|
| VMP (VMProtect) | 代码虚拟化+变异+反调试 | 极高 |
| Themida | 虚拟化+反调试+反Dump+加密 | 极高 |
| Enigma Protector | 虚拟化+加密+许可管理 | 高 |
| ASProtect | 代码加密+反调试 | 中高 |

```
VMP保护选项：
  - Mutation（变异）：指令替换+垃圾代码
  - Virtualization（虚拟化）：转为虚拟字节码
  - Ultra（混合）：变异+虚拟化
  - 可选择保护范围：整个程序/指定函数

Themida保护流程：
  1. PE文件加密压缩
  2. 添加保护壳代码
  3. 选择性虚拟化关键函数
  4. 嵌入反调试/反Dump/完整性校验
  5. 生成受保护的PE文件
```

### .NET混淆（dotfuscator / ConfuserEx）

.NET 程序编译为 MSIL 中间语言，混淆工作在 IL 层面进行：

```
dotfuscator（商业）：
  - 重命名混淆（符号重命名）
  - 控制流混淆（IL层面平坦化）
  - 字符串加密
  - 剥离调试信息

ConfuserEx（开源）：
  - anti_tamper：完整性校验（运行时检测修改）
  - anti_debug：反调试
  - control_flow：控制流混淆
  - constants：常量加密
  - renaming：符号重命名
  - anti_dump：反Dump（PE头修改）
```

**ConfuserEx 配置示例（.crproj）：**
```xml
<Project baseDir="...">
  <Module path="target.exe">
    <Rule pattern="true" preset="maximum">
      <protection id="anti tamper" />
      <protection id="anti debug" />
      <protection id="control flow" />
      <protection id="constants" />
      <protection id="renaming" />
    </Rule>
  </Module>
</Project>
```

### Android混淆（加固 / DEX混淆）

```
Android应用保护层次：
1. ProGuard/R8（编译时混淆）：
   - 符号重命名（类名/方法名/字段名）
   - 代码优化（删除无用代码）
   - gradle: minifyEnabled true

2. DEX加固（运行时保护）：
   - 壳程序替换原始DEX
   - 运行时从内存中动态加载原始DEX
   - 典型工具：360加固、腾讯乐固、爱加密

3. SO层虚拟化：
   - 对native .so文件使用VMP保护
   - 关键算法在native层实现并虚拟化
```

```gradle
// build.gradle - ProGuard配置
android {
    buildTypes {
        release {
            minifyEnabled true
            proguardFiles getDefaultProguardFile('proguard-optimize.txt'),
                          'proguard-rules.pro'
        }
    }
}

// proguard-rules.pro
-optimizationpasses 5
-repackageclasses ''
-allowaccessmodification
-optimizations !code/simplification/*
```
