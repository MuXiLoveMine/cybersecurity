### 二、安全运营指标体系详解

#### 2.1 五级安全运营指标体系

```
战略层（董事会/CIO）
├── 安全投资回报率（Security ROI）
├── 风险敞口（Risk Exposure）
├── 合规达标率（Compliance Rate）
└── 重大安全事件数量

管理层（CISO/安全总监）
├── MTTD 平均检测时间
├── MTTR 平均响应时间
├── MTTC 平均遏制时间
├── 漏洞修复SLA达成率
├── 安全事件分级数量
└── 安全意识培训覆盖率

运营层（安全运营经理）
├── 告警准确率（True Positive Rate）
├── 告警响应及时率
├── 工单闭环率
├── 威胁狩猎成功率
├── 漏洞修复平均时间
├── 安全设备健康度
└── 日志采集完整度

执行层（安全分析师）
├── 每日告警处理量
├── 误报率/漏报率
├── IOC匹配数量
├── 事件调查数量
└── 分析报告输出量

技术层（技术指标）
├── 日志采集EPS（每秒事件数）
├── 规则命中次数
├── 威胁情报命中数
├── 扫描发现漏洞数
└── 端点覆盖率
```

#### 2.2 核心安全运营KPI定义与计算公式

| KPI名称 | 计算公式 | 目标值参考 | 数据来源 | 统计周期 |
|---------|----------|-----------|----------|----------|
| **MTTD（平均检测时间）** | 从攻击发生到首次检测到的总时间 / 事件数 | < 4小时（行业优秀 < 1小时） | SIEM、EDR告警 | 月度 |
| **MTTR（平均响应时间）** | 从告警产生到开始响应的总时间 / 告警数 | < 15分钟（高危） | SOAR工单系统 | 月度 |
| **MTTC（平均遏制时间）** | 从确认事件到完成遏制的总时间 / 事件数 | < 1小时（高危） | 事件管理系统 | 月度 |
| **MTTR修复** | 从漏洞发现到修复完成的总时间 / 漏洞数 | 高危<48h，中危<7天，低危<30天 | 漏洞管理系统 | 月度 |
| **告警准确率** | 真实安全事件告警数 / 总告警数 × 100% | > 10%（持续优化目标） | SIEM统计 | 月度 |
| **误报率** | 误报告警数 / 总告警数 × 100% | < 80%（逐步降低） | SIEM统计 | 月度 |
| **漏洞修复SLA达标率** | 按期修复的漏洞数 / 应修复漏洞总数 × 100% | > 90% | 漏洞管理平台 | 月度 |
| **事件闭环率** | 已关闭事件数 / 总事件数 × 100% | > 95% | 事件管理系统 | 月度 |
| **端点覆盖率** | 已部署EDR的终端数 / 终端总数 × 100% | > 99% | EDR管理平台 | 周度 |
| **日志采集完整度** | 实际采集日志源数 / 应采集日志源数 × 100% | > 95% | 日志平台 | 周度 |
| **安全培训完成率** | 完成培训员工数 / 应培训员工数 × 100% | 100% | 培训平台 | 季度 |
| **钓鱼演练成功率** | 成功钓鱼人数 / 参与人数 × 100% | < 5%（持续降低） | 钓鱼平台 | 季度 |

#### 2.3 安全度量计算脚本示例

```python
#!/usr/bin/env python3
"""
安全运营KPI计算器
支持MTTD/MTTR/告警准确率等核心指标计算
"""
import pandas as pd
from datetime import datetime, timedelta
import json

class SecurityMetricsCalculator:
    def __init__(self):
        self.sla_config = {
            "critical": {"response_minutes": 15, "containment_hours": 1, "vuln_days": 2},
            "high": {"response_minutes": 30, "containment_hours": 4, "vuln_days": 7},
            "medium": {"response_minutes": 60, "containment_hours": 24, "vuln_days": 30},
            "low": {"response_minutes": 240, "containment_hours": 72, "vuln_days": 90}
        }
    
    def calculate_mttd(self, incidents_data):
        """
        计算平均检测时间MTTD
        incidents_data: [{"attack_start": datetime, "detection_time": datetime, "severity": str}]
        """
        total_det = timedelta()
        valid_incidents = 0
        
        for inc in incidents_data:
            if inc.get("attack_start") and inc.get("detection_time"):
                det_time = inc["detection_time"] - inc["attack_start"]
                if det_time.total_seconds() > 0:
                    total_det += det_time
                    valid_incidents += 1
        
        if valid_incidents == 0:
            return {"mttd_hours": 0, "incident_count": 0}
        
        avg_det = total_det / valid_incidents
        return {
            "mttd_hours": avg_det.total_seconds() / 3600,
            "mttd_minutes": avg_det.total_seconds() / 60,
            "incident_count": valid_incidents
        }
    
    def calculate_mttr(self, incidents_data, metric_type="response"):
        """
        计算平均响应/遏制/修复时间
        metric_type: response/containment/recovery
        """
        time_mappings = {
            "response": ("alert_time", "response_time"),
            "containment": ("detection_time", "containment_time"),
            "recovery": ("containment_time", "recovery_time")
        }
        
        start_field, end_field = time_mappings[metric_type]
        total_time = timedelta()
        valid_count = 0
        
        for inc in incidents_data:
            if inc.get(start_field) and inc.get(end_field):
                delta = inc[end_field] - inc[start_field]
                if delta.total_seconds() > 0:
                    total_time += delta
                    valid_count += 1
        
        if valid_count == 0:
            return {f"mtt{metric_type[0]}_hours": 0, "incident_count": 0}
        
        avg_time = total_time / valid_count
        return {
            f"avg_{metric_type}_hours": avg_time.total_seconds() / 3600,
            f"avg_{metric_type}_minutes": avg_time.total_seconds() / 60,
            "incident_count": valid_count
        }
    
    def calculate_alert_quality(self, alerts_data):
        """
        计算告警质量指标（准确率、误报率）
        alerts_data: [{"severity": str, "is_true_positive": bool, "is_false_positive": bool}]
        """
        total_alerts = len(alerts_data)
        true_positives = sum(1 for a in alerts_data if a.get("is_true_positive"))
        false_positives = sum(1 for a in alerts_data if a.get("is_false_positive"))
        
        return {
            "total_alerts": total_alerts,
            "true_positives": true_positives,
            "false_positives": false_positives,
            "true_positive_rate": (true_positives / total_alerts * 100) if total_alerts > 0 else 0,
            "false_positive_rate": (false_positives / total_alerts * 100) if total_alerts > 0 else 0,
            "noise_rate": ((total_alerts - true_positives) / total_alerts * 100) if total_alerts > 0 else 0
        }
    
    def calculate_vuln_sla_compliance(self, vulns_data):
        """
        计算漏洞修复SLA达标率
        vulns_data: [{"severity": str, "discovery_date": datetime, "fix_date": datetime}]
        """
        results = {
            "total": 0,
            "compliant": 0,
            "by_severity": {}
        }
        
        for vuln in vulns_data:
            severity = vuln.get("severity", "low").lower()
            if severity not in self.sla_config:
                continue
            
            results["total"] += 1
            
            if severity not in results["by_severity"]:
                results["by_severity"][severity] = {"total": 0, "compliant": 0}
            results["by_severity"][severity]["total"] += 1
            
            if vuln.get("discovery_date") and vuln.get("fix_date"):
                fix_days = (vuln["fix_date"] - vuln["discovery_date"]).days
                sla_days = self.sla_config[severity]["vuln_days"]
                
                if fix_days <= sla_days:
                    results["compliant"] += 1
                    results["by_severity"][severity]["compliant"] += 1
        
        results["sla_compliance_rate"] = (
            results["compliant"] / results["total"] * 100 if results["total"] > 0 else 0
        )
        
        for sev in results["by_severity"]:
            sev_data = results["by_severity"][sev]
            sev_data["compliance_rate"] = (
                sev_data["compliant"] / sev_data["total"] * 100 if sev_data["total"] > 0 else 0
            )
        
        return results
    
    def generate_monthly_report(self, metrics_data):
        """生成月度安全运营报告数据"""
        report = {
            "report_period": f"{datetime.now().strftime('%Y年%m月')}",
            "generated_at": datetime.now().isoformat(),
            "executive_summary": {
                "overall_risk_level": "",  # 高/中/低
                "key_highlights": [],
                "major_concerns": []
            },
            "incident_metrics": {},
            "vulnerability_metrics": {},
            "alert_metrics": {},
            "compliance_metrics": {}
        }
        return report


# 使用示例
if __name__ == "__main__":
    calc = SecurityMetricsCalculator()
    
    # 示例：告警质量分析
    print("=== 告警质量分析 ===")
    alerts_sample = [
        {"severity": "high", "is_true_positive": True, "is_false_positive": False},
        {"severity": "medium", "is_true_positive": False, "is_false_positive": True},
        {"severity": "high", "is_true_positive": True, "is_false_positive": False},
        {"severity": "low", "is_true_positive": False, "is_false_positive": True},
        {"severity": "critical", "is_true_positive": True, "is_false_positive": False},
        # ... 更多数据
    ]
    # 生成100条模拟告警
    import random
    for i in range(100):
        sev = random.choice(["low", "medium", "high", "critical"])
        is_tp = random.random() < 0.15  # 15%真实告警
        alerts_sample.append({
            "severity": sev,
            "is_true_positive": is_tp,
            "is_false_positive": not is_tp
        })
    
    quality = calc.calculate_alert_quality(alerts_sample)
    print(f"总告警数: {quality['total_alerts']}")
    print(f"真实告警数: {quality['true_positives']}")
    print(f"误报数: {quality['false_positives']}")
    print(f"准确率: {quality['true_positive_rate']:.1f}%")
    print(f"误报率: {quality['false_positive_rate']:.1f}%")
    print(f"噪音率: {quality['noise_rate']:.1f}%")
    
    # 示例：漏洞SLA达标率
    print("\n=== 漏洞修复SLA分析 ===")
    base_date = datetime(2024, 1, 1)
    vulns_sample = []
    for i in range(50):
        sev = random.choice(["critical", "high", "medium", "low"])
        discover = base_date + timedelta(days=random.randint(0, 60))
        fix_days = random.randint(1, 60)
        vulns_sample.append({
            "severity": sev,
            "discovery_date": discover,
            "fix_date": discover + timedelta(days=fix_days)
        })
    
    vuln_metrics = calc.calculate_vuln_sla_compliance(vulns_sample)
    print(f"总漏洞数: {vuln_metrics['total']}")
    print(f"SLA达标数: {vuln_metrics['compliant']}")
    print(f"总体SLA达标率: {vuln_metrics['sla_compliance_rate']:.1f}%")
    for sev, data in vuln_metrics['by_severity'].items():
        print(f"  {sev}: {data['compliance_rate']:.1f}% ({data['compliant']}/{data['total']})")
```

### 三、安全运营成熟度评估工具

#### 3.1 安全运营成熟度模型（SOMM）

| 等级 | 名称 | 特征描述 | 关键能力 |
|------|------|----------|----------|
| **Level 1** | 初始级（Ad-hoc） | 被动响应，无固定流程，依赖个人能力 | 基础防火墙、防病毒、零散日志 |
| **Level 2** | 可重复级（Managed） | 建立基本流程，有专人负责，工具零散 | SIEM、漏洞扫描、基础事件响应流程 |
| **Level 3** | 已定义级（Defined） | 流程标准化，有文档体系，团队分工明确 | SOAR、威胁情报、7x24监控、SOC团队 |
| **Level 4** | 量化管理级（Quantitatively） | 数据驱动，可量化度量，持续优化 | 自动化编排、数据湖、ML检测、全面KPI |
| **Level 5** | 持续优化级（Optimizing） | 自适应、自进化，威胁狩猎、预测性防御 | AI驱动、红蓝对抗、威胁狩猎、安全度量体系完善 |
