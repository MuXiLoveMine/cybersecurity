# 安全成熟度评估

### 5.1 CMM模型

```
安全能力成熟度模型（CMM）：

Level 1 - 初始级（Initial）
  特征：
  ├── 安全活动无序、被动
  ├── 依赖个人英雄主义
  ├── 无标准化流程
  └── 无度量体系

  评估标准：
  ├── 无安全策略文档
  ├── 无定期风险评估
  ├── 无事件响应流程
  ├── 无安全培训
  └── 无安全度量

Level 2 - 可重复级（Repeatable）
  特征：
  ├── 建立基本安全流程
  ├── 可以重复执行
  ├── 有基本文档
  └── 依赖个人能力

  评估标准：
  ├── 有安全策略（但未完全执行）
  ├── 有基础SIEM
  ├── 有事件响应流程（基础版）
  ├── 有年度安全培训
  └── 有基础度量（事件计数）

Level 3 - 定义级（Defined）
  特征：
  ├── 安全流程标准化
  ├── 有组织级安全策略
  ├── 流程文档化
  └── 有专职团队

  评估标准：
  ├── 完整的安全策略和标准
  ├── SOC 24/7运营
  ├── SIEM+EDR+SOAR
  ├── 标准化Playbook
  ├── 定期渗透测试
  ├── 完整度量体系
  └── 有威胁情报

Level 4 - 量化级（Quantitatively Managed）
  特征：
  ├── 安全运营可量化
  ├── 数据驱动决策
  ├── 持续优化
  └── 高度自动化

  评估标准：
  ├── 全面的安全KPI体系
  ├── 安全度量Dashboard
  ├── SOAR自动化率>40%
  ├── 红蓝对抗常态化
  ├── 威胁狩猎常规化
  └── 安全ROI可计算

Level 5 - 优化级（Optimizing）
  特征：
  ├── 持续创新和改进
  ├── 预测性安全
  ├── 自适应架构
  └── 安全文化深入

  评估标准：
  ├── AI/ML辅助安全运营
  ├── 零信任架构
  ├── 安全即代码
  ├── DevSecOps
  ├── 行业标杆实践
  └── 持续威胁暴露管理
```

### 5.2 自评估方法

```python
class SecurityMaturityAssessment:
    """安全成熟度自评估"""

    def __init__(self):
        self.categories = {
            '治理与风险管理': self._governance_questions(),
            '安全运营': self._operations_questions(),
            '威胁管理': self._threat_questions(),
            '漏洞管理': self._vulnerability_questions(),
            '身份与访问': self_iam_questions(),
            '数据安全': self._data_questions(),
            '基础设施安全': self._infrastructure_questions(),
            '应用安全': self._appsec_questions(),
            '事件响应': self._incident_questions(),
            '安全意识': self._awareness_questions()
        }

    def _governance_questions(self):
        return [
            ("是否有书面的信息安全策略？", 1),
            ("策略是否每年更新和审批？", 1),
            ("是否有CISO或等效角色？", 1),
            ("是否有安全委员会？", 1),
            ("是否定期进行风险评估？", 2),
            ("是否有风险登记簿？", 2),
            ("风险是否有量化评分？", 3),
            ("安全指标是否报告给董事会？", 4),
            ("是否有安全投资ROI分析？", 4),
            ("是否有持续的安全战略规划？", 5),
        ]

    def _operations_questions(self):
        return [
            ("是否有SIEM？", 2),
            ("是否有24/7 SOC？", 3),
            ("是否有EDR？", 3),
            ("是否有SOAR？", 4),
            ("SOC是否有标准SOP？", 3),
            ("是否有自动化响应？", 4),
            ("是否有威胁狩猎？", 4),
            ("是否使用MITRE ATT&CK框架？", 4),
            ("是否有安全度量Dashboard？", 4),
            ("是否使用AI/ML辅助检测？", 5),
        ]

    def _vulnerability_questions(self):
        return [
            ("是否有漏洞扫描工具？", 2),
            ("是否每周扫描？", 3),
            ("是否有漏洞SLA？", 3),
            ("高危漏洞MTTR<14天？", 4),
            ("是否有漏洞度量？", 4),
            ("是否与资产CMDB关联？", 4),
            ("是否有攻击面管理？", 5),
            ("是否有自动修复流程？", 5),
        ]

    def assess(self, answers):
        """执行评估"""
        results = {}
        total_score = 0
        max_score = 0

        for category, questions in self.categories.items():
            cat_score = 0
            cat_max = 0

            for i, (question, level) in enumerate(questions):
                answer = answers.get(f"{category}_{i}", False)
                weight = level  # 问题对应成熟度级别作为权重
                cat_max += weight
                if answer:
                    cat_score += weight

            cat_percentage = (cat_score / cat_max * 100) if cat_max > 0 else 0
            cat_maturity = self._determine_maturity(cat_percentage)

            results[category] = {
                'score': cat_score,
                'max': cat_max,
                'percentage': round(cat_percentage, 1),
                'maturity_level': cat_maturity
            }

            total_score += cat_score
            max_score += cat_max

        overall_percentage = (total_score / max_score * 100) if max_score > 0 else 0
        overall_maturity = self._determine_maturity(overall_percentage)

        return {
            'categories': results,
            'overall': {
                'score': total_score,
                'max': max_score,
                'percentage': round(overall_percentage, 1),
                'maturity_level': overall_maturity
            }
        }

    def _determine_maturity(self, percentage):
        """根据百分比确定成熟度等级"""
        if percentage >= 90:
            return 5  # 优化级
        elif percentage >= 70:
            return 4  # 量化级
        elif percentage >= 50:
            return 3  # 定义级
        elif percentage >= 30:
            return 2  # 可重复级
        else:
            return 1  # 初始级

    def generate_report(self, results):
        """生成评估报告"""
        print("=" * 60)
        print("Security Maturity Assessment Report")
        print("=" * 60)

        print(f"\nOverall Maturity: Level {results['overall']['maturity_level']}")
        print(f"Overall Score: {results['overall']['percentage']}%")

        print("\nCategory Breakdown:")
        for cat, data in results['categories'].items():
            level = data['maturity_level']
            pct = data['percentage']
            bar = '█' * int(pct / 5) + '░' * (20 - int(pct / 5))
            print(f"  {cat:20s} L{level} [{bar}] {pct:.1f}%")

        # 改进建议
        print("\nImprovement Priorities:")
        sorted_cats = sorted(
            results['categories'].items(),
            key=lambda x: x[1]['percentage']
        )
        for cat, data in sorted_cats[:3]:
            print(f"  [!] {cat}: {data['percentage']}% (Level {data['maturity_level']})")
```
