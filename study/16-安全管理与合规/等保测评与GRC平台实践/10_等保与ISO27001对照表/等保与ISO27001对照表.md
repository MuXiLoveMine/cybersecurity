# 等保与ISO27001对照表

| 等保2.0要求域 | ISO 27001:2022控制措施 | 对应关系 |
|-------------|----------------------|---------|
| 安全物理环境 | 7.1-7.14 物理控制 | 高度对应 |
| 安全通信网络-网络架构 | 8.19 网络安全 / 8.21 网络隔离 | 高度对应 |
| 安全通信网络-通信传输 | 8.24 密码学 | 部分对应 |
| 安全区域边界-边界防护 | 8.19 网络安全 / 8.20 网络服务安全 | 高度对应 |
| 安全区域边界-访问控制 | 8.2 访问权限 / 8.3 信息访问限制 | 高度对应 |
| 安全区域边界-入侵防范 | 8.7 防恶意软件 / 8.16 监视活动 | 部分对应 |
| 安全计算环境-身份鉴别 | 8.5 安全认证 | 高度对应 |
| 安全计算环境-访问控制 | 8.2-8.4 访问控制系列 | 高度对应 |
| 安全计算环境-安全审计 | 8.15 日志记录 / 8.16 监视活动 | 高度对应 |
| 安全计算环境-数据完整性 | 8.12 数据泄露防护 | 部分对应 |
| 安全计算环境-数据保密性 | 8.24 密码学 / 8.11 数据屏蔽 | 高度对应 |
| 安全计算环境-数据备份恢复 | 8.13 数据备份 / 8.14 IT冗余 | 高度对应 |
| 安全管理制度 | 5.1 信息安全策略 | 高度对应 |
| 安全管理机构 | 5.2 角色和职责 / 5.4 管理层责任 | 高度对应 |
| 安全管理人员 | 6.1-6.8 人员控制系列 | 高度对应 |
| 安全建设管理 | 8.25 安全开发生命周期 / 8.28 安全编码 | 部分对应 |
| 安全运维管理 | 8.9 配置管理 / 8.31 技术变更管理 | 高度对应 |

**对照分析结论**
- 等保2.0与ISO 27001在管理层面上高度对应，约70%控制项可直接映射
- 等保2.0更强调技术要求的明确性和可测评性
- ISO 27001更强调管理体系的有效性和持续改进
- 两套标准可融合实施，形成统一控制矩阵，降低合规成本
