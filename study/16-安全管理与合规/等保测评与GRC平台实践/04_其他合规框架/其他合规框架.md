# 其他合规框架

### 4.1 NIST CSF（网络安全框架）

**核心功能**
1. 识别（Identify）
2. 保护（Protect）
3. 检测（Detect）
4. 响应（Respond）
5. 恢复（Recover）

**NIST CSF 2.0新增**
- 治理（Govern）作为第六大功能

### 4.2 SOC 2

**SOC 2信任服务标准**
- 安全（Security）
- 可用性（Availability）
- 处理完整性（Processing Integrity）
- 保密性（Confidentiality）
- 隐私（Privacy）

**SOC 2报告类型**
- Type I：特定时间点控制设计有效性
- Type II：一段时间内控制运行有效性

### 4.3 COBIT

**COBIT 2019核心**
- 治理目标和管理目标
- 40个治理和管理目标
- 设计因素和目标层级

### 4.4 GDPR合规

**GDPR核心要求**
- 数据处理的合法性基础
- 数据主体权利（访问、更正、删除、限制处理、数据可携带性、反对）
- 数据保护影响评估（DPIA）
- 数据泄露通知（72小时内）
- 数据保护官（DPO）
- 跨境数据传输

### 4.5 个人信息保护法（PIPL）

**PIPL核心要求**
- 处理个人信息的原则（合法、正当、必要）
- 告知-同意机制
- 敏感个人信息处理规则
- 个人信息跨境提供
- 个人信息主体权利
- 个人信息处理者义务
