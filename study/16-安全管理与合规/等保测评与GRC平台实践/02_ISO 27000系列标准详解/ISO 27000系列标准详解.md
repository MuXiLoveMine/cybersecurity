# ISO 27000系列标准详解

### 2.1 ISO 27001:2022

**核心变化（2022版 vs 2013版）**
- 控制措施数量从114个精简到93个
- 结构重组为4大类：组织、人员、物理、技术
- 新增11个控制措施

**ISO 27001框架**
```
1. 范围
2. 规范性引用文件
3. 术语和定义
4. 组织环境
   ├── 4.1 理解组织及其环境
   ├── 4.2 理解相关方需求
   ├── 4.3 确定ISMS范围
   └── 4.4 信息安全管理体系
5. 领导力
   ├── 5.1 领导力与承诺
   └── 5.2 方针
6. 策划
   ├── 6.1 应对风险和机会
   ├── 6.2 信息安全目标
   └── 6.3 变更策划
7. 支持
   ├── 7.1 资源
   ├── 7.2 能力
   ├── 7.3 意识
   ├── 7.4 沟通
   └── 7.5 文件化信息
8. 运行
   └── 8.1 运行策划与控制
9. 绩效评价
   ├── 9.1 监视、测量、分析和评价
   ├── 9.2 内部审核
   └── 9.3 管理评审
10. 改进
    ├── 10.1 不符合与纠正措施
    └── 10.2 持续改进
```

### 2.3 ISO 27005:2022 风险管理

**风险管理流程**
```
1. 风险管理范围与准则确定
2. 风险评估
   ├── 风险识别
   │   ├── 资产识别
   │   ├── 威胁识别
   │   ├── 现有控制识别
   │   └── 脆弱性识别
   ├── 风险分析
   │   ├── 资产价值评估
   │   ├── 威胁可能性评估
   │   └── 脆弱性严重程度评估
   └── 风险评价
       └── 风险等级判定

3. 风险处置
   ├── 风险修改（降低）
   ├── 风险保留（接受）
   ├── 风险规避（避免）
   └── 风险分担（转移）

4. 风险接受

5. 风险沟通

6. 风险监视与评审
```
