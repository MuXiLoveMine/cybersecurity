# 合规自动化工具

### 11.1 开源合规工具链

| 工具 | 类型 | 用途 |
|------|------|------|
| Prowler | AWS合规扫描 | AWS安全基线检查，对标CIS |
| Checkov | IaC扫描 | Terraform/CloudFormation安全扫描 |
| OPA/Conftest | 策略引擎 | 策略即代码，跨平台合规检查 |
| Trivy | 镜像扫描 | 容器镜像和IaC漏洞+配置扫描 |
| Cloud Custodian | 云管理 | 多云策略执行和资源管理 |
| Auditree | 合规审计 | 自动化合规证据收集 |
| InSpec | 合规测试 | 基础设施合规测试框架 |

### 11.2 合规自动化流水线

```yaml
# CI/CD 合规检查流水线示例
stages:
  - iac_scan        # IaC安全扫描
  - policy_check     # 策略合规检查
  - deploy          # 部署
  - post_audit      # 部署后审计

iac_scan:
  stage: iac_scan
  script:
    # Checkov扫描Terraform
    - checkov -d terraform/ --framework terraform
    # Trivy扫描
    - trivy config terraform/
    # 输出合规报告
    - checkov -d terraform/ --output json --report

policy_check:
  stage: policy_check
  script:
    # OPA策略检查
    - opa eval -d policies/ -i terraform/plan.json "data.terraform.deny"
    # 等保基线检查
    - inspec exec compliance/ --input-file attributes.yml

post_audit:
  stage: post_audit
  script:
    # Prowler合规扫描
    - prowler aws --compliance cis_2.0_aws
    # 生成等保对照报告
    - python3 generate_compliance_report.py
    # 推送至GRC平台
    - curl -X POST https://grc.internal/api/v1/evidence -H "Authorization: Bearer $TOKEN" -d @report.json
```
