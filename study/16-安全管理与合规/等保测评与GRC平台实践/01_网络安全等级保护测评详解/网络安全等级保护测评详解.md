# 网络安全等级保护测评详解

### 1.1 等保2.0测评流程

**测评标准体系**
- GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》
- GB/T 28448-2019《信息安全技术 网络安全等级保护测评要求》
- GB/T 28449-2018《信息安全技术 网络安全等级保护测评过程指南》
- GB/T 22240-2020《信息安全技术 网络安全等级保护定级指南》

**测评流程**
```
1. 测评准备阶段
   ├── 收集被测系统资料
   ├── 编制测评方案
   ├── 准备测评工具
   └── 确定测评人员

2. 方案编制阶段
   ├── 确定测评边界
   ├── 确定测评对象
   ├── 编制测评指标
   └── 制定测评实施计划

3. 测评实施阶段
   ├── 现场测评（访谈、核查、测试）
   ├── 记录测评结果
   ├── 发现问题确认
   └── 问题风险分析

4. 分析与报告编制阶段
   ├── 单项测评结果判定
   ├── 单元测评结果判定
   ├── 整体测评结果判定
   ├── 风险分析
   └── 编制测评报告
```

### 1.2 等保2.0技术要求详解

#### 1.2.1 安全物理环境

**物理位置选择**
- 机房应选择在具有防震、防风、防雨能力的建筑内
- 机房场地应避免设在地下室的最底层

**物理访问控制**
- 机房入口配置电子门禁系统
- 访客需登记并陪同
- 门禁记录保存至少6个月

**防盗窃和防破坏**
- 设备标识、主要设备固定、通信线缆隐蔽

**防雷击**
- 机房应设置雷电压保护器
- 应设置交流电源地线

**防火**
- 机房应设置火灾自动消防系统
- 应配置温感/烟感探测器

**防水和防潮**
- 安装防雨水渗漏和防结露装置
- 地面应有防水措施

**防静电**
- 采用防静电地板
- 配置静电消除器

**温湿度控制**
- 配置精密空调
- 温度18-28°C，湿度35-75%

**电力供应**
- 配置UPS不间断电源
- 备用发电机

**电磁防护**
- 电源线和通信线缆隔离敷设
- 电磁屏蔽

#### 1.2.2 安全通信网络

**网络架构**
- 划分不同网络区域
- 避免将重要网络区域部署在边界处
- 重要区域与其他区域隔离
- 通信传输应采用校验技术或加密技术

**通信传输**
- 通信过程中数据完整性校验
- 通信过程中数据加密传输

**可信接入**
- 设备接入网络前进行身份鉴别
- 接入后进行安全验证

#### 1.2.3 安全区域边界

**边界防护**
- 跨边界访问和数据流通过边界防护设备
- 非授权设备不能接入网络
- 内部设备不能私自连接外部网络

**访问控制**
- 边界设备配置访问控制策略
- 精确到端口和会话级别

**入侵防范**
- 检测和阻挡网络攻击
- 分析攻击行为并告警

**恶意代码防范**
- 边界处检测和清除恶意代码
- 防范策略和恶意代码库更新

**安全审计**
- 对边界访问行为进行审计
- 审计记录保存至少6个月

#### 1.2.4 安全计算环境

**身份鉴别**
- 身份唯一性
- 身份鉴别信息复杂度
- 鉴别信息传输加密
- 登录失败处理
- 会话超时
- 远程管理加密

**访问控制**
- 访问主体和客体权限控制
- 权限分离
- 最小权限
- 默认拒绝

**安全审计**
- 审计覆盖范围
- 审计内容（用户创建/删除、权限变更等）
- 审计记录保护
- 审计记录保存6个月以上
- 防止审计中断

**入侵防范**
- 检测入侵行为
- 检测系统完整性
- 重要节点部署入侵检测

**恶意代码防范**
- 安装防病毒软件
- 策略统一管理

**可信验证**
- 基于可信根对系统进行可信验证

**数据完整性**
- 数据传输和存储的完整性校验

**数据保密性**
- 数据传输和存储的加密保护

**数据备份恢复**
- 数据本地备份与恢复
- 数据异地备份与恢复
- 数据处理系统热冗余

**剩余信息保护**
- 鉴别信息存储空间释放前清除
- 存储空间分配前清除

**个人信息保护**
- 个人信息收集最小化
- 个人信息访问控制
- 个人信息脱敏与匿名化

### 1.4 测评报告模板

**单项测评结果判定**
```
判定标准:
- 符合：完全满足要求
- 部分符合：部分满足要求
- 不符合：不满足要求
- 不适用：该要求不适用于被测系统

风险分析:
- 高风险：系统面临严重安全威胁
- 中风险：系统面临中等安全威胁
- 低风险：系统面临轻微安全威胁

整体结论:
- 优：无高风险项，符合率≥90%
- 良：无高风险项，符合率≥80%
- 中：无高风险项，符合率≥70%
- 差：有高风险项或符合率<70%
```
