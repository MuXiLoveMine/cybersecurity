# 符合性

### 15.1 符合性概述

**符合性定义**：
组织的信息安全管理活动符合法律法规、标准规范、合同要求和内部制度的程度。

**符合性的重要性**：
- 满足法律法规要求，避免法律风险
- 满足客户要求，增强竞争力
- 满足标准要求，提升管理水平
- 满足内部制度要求，确保执行到位

### 15.2 符合性要求来源

#### 15.2.1 法律法规要求

**国内主要法律法规**：
- 《网络安全法》
- 《数据安全法》
- 《个人信息保护法》
- 《密码法》
- 《关键信息基础设施安全保护条例》
- 《网络安全等级保护条例》
- 各行业监管规定

**国际法规**：
- GDPR（欧盟通用数据保护条例）
- PCI DSS（支付卡行业数据安全标准）
- HIPAA（美国健康保险流通与责任法案）
- SOX（萨班斯法案）

#### 15.2.2 标准规范要求

- ISO 27001 信息安全管理体系
- 网络安全等级保护 2.0
- ISO 27701 隐私信息管理体系
- ISO 22301 业务连续性管理体系

#### 15.2.3 合同要求

- 客户合同中的安全条款
- 供应商合同中的安全要求
- 合作伙伴安全协议

#### 15.2.4 内部制度要求

- 信息安全方针
- 安全管理制度
- 操作规范和流程

### 15.3 符合性管理流程

```
识别合规要求 → 差距分析 → 整改实施 → 合规评估 → 持续改进
    │              │          │          │          │
    ▼              ▼          ▼          ▼          ▼
  收集法规     评估现状     制定计划     内部审计     定期评审
  梳理要求     识别差距     整改实施     外部审计     更新改进
  建立清单     风险评估     验证效果     合规证明     监测变化
```

### 15.4 合规性评估

#### 15.4.1 评估方法

- 文件审查：检查制度文件
- 人员访谈：了解执行情况
- 现场检查：查看实际情况
- 技术检测：检测技术措施
- 记录抽查：检查执行记录

#### 15.4.2 评估内容

| 评估领域 | 评估内容 |
|----------|----------|
| 管理合规 | 制度、组织、人员、培训 |
| 技术合规 | 网络、主机、应用、数据安全 |
| 物理合规 | 机房、门禁、监控、环境 |
| 运营合规 | 变更、备份、事件、漏洞 |
| 法律合规 | 法律法规符合性 |

### 15.5 常见合规问题

**管理类问题**：
- 制度不完善
- 职责不明确
- 培训不到位
- 记录不完整
- 执行不到位

**技术类问题**：
- 安全设备缺失
- 配置不加固
- 漏洞未修复
- 日志不完整
- 备份不规范

**常见原因**：
- 安全意识不足
- 资源投入不够
- 制度执行不力
- 技术能力不足
- 缺乏监督检查

### 15.6 符合性审计

#### 15.6.1 内部审计

**目的**：自我检查，发现问题，持续改进
**频次**：每年至少一次
**执行者**：内部审计人员或安全部门

#### 15.6.2 外部审计

**类型**：
- 认证审计（ISO 27001、等保测评等）
- 客户审计
- 监管检查

**准备工作**：
- 内部预审
- 问题整改
- 文件准备
- 人员准备

### 15.7 持续合规

**保持合规的措施**：

1. **建立法规跟踪机制**
   - 专人负责跟踪法规变化
   - 定期更新合规要求清单
   - 及时调整安全措施

2. **定期合规评估**
   - 季度自查
   - 半年评估
   - 年度审计

3. **持续改进机制**
   - 内审发现问题整改
   - 外审发现问题整改
   - 事件驱动改进
   - 定期管理评审

4. **全员合规意识**
   - 合规培训
   - 合规考核
   - 合规文化

### 15.8 符合性案例

**案例：某公司等保2.0三级合规建设**

**项目背景**：
某公司业务系统需通过等保2.0三级测评，但现有安全措施与等保要求有较大差距。

**项目过程**：

**阶段1：差距分析（2周）**
- 对照等保2.0三级要求逐项检查
- 识别差距项：共发现 45 项不符合
- 高风险项 12 项，中风险项 20 项，低风险项 13 项

**差距示例**：
- 缺少安全管理中心
- 网络未按区域划分
- 缺少入侵检测系统
- 数据未加密传输
- 日志保存时间不足
- 缺少灾备方案
- 制度文件不完善

**阶段2：整改方案设计（2周）**
- 制定技术整改方案
- 制定管理整改方案
- 编制项目计划
- 预算申请

**阶段3：整改实施（3个月）**
- 技术整改：
  - 部署防火墙、IDS、日志审计等设备
  - 网络重新规划和分段
  - 服务器安全加固
  - 部署数据加密
  - 建设灾备系统
- 管理整改：
  - 完善安全制度体系
  - 建立安全组织
  - 开展安全培训
  - 完善各项记录

**阶段4：内部测评（2周）**
- 组织内部测评
- 发现剩余问题 8 项
- 进行补充整改

**阶段5：正式测评（2周）**
- 第三方测评机构现场测评
- 顺利通过，得分 85 分

**项目成果**：
- 顺利通过等保2.0三级测评
- 安全防护能力大幅提升
- 安全管理制度化规范化
- 员工安全意识提高
