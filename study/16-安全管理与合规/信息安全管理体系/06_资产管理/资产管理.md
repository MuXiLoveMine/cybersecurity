# 资产管理

### 6.1 资产管理概述

**资产定义**：对组织有价值的任何东西，包括信息、设备、软件、服务、人员、无形资产等。

**资产管理的目的**：
- 识别和登记所有信息资产
- 明确资产责任
- 评估资产价值和重要性
- 实施与资产价值相匹配的保护措施
- 确保资产得到适当保护

### 6.2 资产分类

#### 按资产形态分类

| 资产类别 | 示例 |
|----------|------|
| 信息资产 | 数据、文档、源代码、设计文档、客户信息 |
| 软件资产 | 操作系统、应用软件、数据库、中间件 |
| 物理资产 | 服务器、网络设备、计算机、存储设备 |
| 服务资产 | 网络服务、云服务、运维服务、安全服务 |
| 人员资产 | 员工、管理员、技术专家 |
| 无形资产 | 品牌、声誉、知识产权、商业秘密 |

#### 按重要性分类（资产分级）

| 级别 | 定义 | 影响范围 | 保护要求 |
|------|------|----------|----------|
| 核心资产 | 一旦泄露/损坏会造成灾难性影响 | 公司生存 | 最高级别保护 |
| 重要资产 | 一旦泄露/损坏会造成严重影响 | 核心业务 | 高级别保护 |
| 一般资产 | 一旦泄露/损坏会造成一定影响 | 局部业务 | 常规保护 |
| 次要资产 | 影响较小或无影响 | 个人/小范围 | 基础保护 |

### 6.3 资产清单管理

**资产清单应包含的信息**：
- 资产编号
- 资产名称
- 资产类型
- 资产描述
- 资产位置
- 资产价值/重要性等级
- 责任部门/责任人
- 购置日期
- 状态（在用、停用、报废）
- 安全级别
- 备注

**资产清单模板示例**：

### 6.4 资产责任管理

**原则**：每项资产都应有明确的责任人。

**责任人职责**：
- 确保资产得到适当保护
- 定期检查资产安全状况
- 及时报告资产安全问题
- 配合安全审计和检查
- 参与资产风险评估

### 6.5 资产全生命周期管理

```
资产规划 → 资产采购 → 资产登记 → 资产使用 → 资产维护 → 资产报废
    │          │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼          ▼
  安全需求   安全评估   资产入库   安全监控   安全加固   安全销毁
  评估       与验收     与分类     与保护     与更新     与清理
```

**各阶段安全要点**：

| 阶段 | 安全管理要点 |
|------|-------------|
| 规划阶段 | 识别安全需求、进行风险评估 |
| 采购阶段 | 供应商安全评估、安全功能验收 |
| 登记阶段 | 资产登记、分类分级、责任分配 |
| 使用阶段 | 访问控制、安全监控、定期检查 |
| 维护阶段 | 补丁更新、漏洞修复、配置审计 |
| 报废阶段 | 数据清除、介质销毁、资产注销 |

### 6.6 信息分类分级

#### 分类分级原则

1. **合法合规**：符合法律法规要求
2. **业务影响**：考虑对业务的影响程度
3. **敏感程度**：考虑信息的敏感程度
4. **价值评估**：考虑信息的经济价值
5. **生命周期**：考虑信息的时效性

#### 常见分级方案（四级）

| 级别 | 名称 | 定义 | 示例 |
|------|------|------|------|
| 1级 | 公开 | 可对外公开的信息 | 公司介绍、产品宣传 |
| 2级 | 内部 | 仅限内部使用的信息 | 内部通知、普通文档 |
| 3级 | 秘密 | 敏感信息，泄露会造成损害 | 财务数据、客户名单 |
| 4级 | 机密 | 核心秘密，泄露会造成严重损害 | 核心技术、商业秘密 |

#### 标识要求

- 文档应有明确的密级标识
- 电子文档应有水印
- 存储介质应有标签
- 不同密级信息应区别存储和传输

**案例**：某科技公司实施了数据分类分级管理，将数据分为公开、内部、秘密、机密四级，每级数据有不同的访问权限、加密要求和传输限制。实施后，数据泄露事件减少了 70%。
