# 通信与操作安全

### 9.1 通信安全

#### 9.1.1 网络安全架构

**网络分段原则**：
- 按业务类型分段
- 按安全等级分段
- 按功能区域分段
- 最小权限访问

**典型网络架构**：
```
互联网
   │
  防火墙（边界）
   │
┌──┴──────────────┐
│   DMZ区         │
│  WEB服务器      │
│  邮件服务器     │
│  DNS服务器      │
└──┬──────────────┘
   │
  防火墙（内部边界）
   │
┌──┴──────────────┐
│  业务服务区     │
│  应用服务器      │
│  数据库服务器    │
│  文件服务器      │
└──┬──────────────┘
   │
┌──┴──────────────┐
│  管理区         │
│  运维堡垒机      │
│  安全设备        │
│  监控系统        │
└──┬──────────────┘
   │
┌──┴──────────────┐
│  办公区         │
│  员工终端        │
│  办公设备        │
└─────────────────┘
```

#### 9.1.2 安全通信协议

| 协议 | 用途 | 安全说明 |
|------|------|----------|
| HTTPS | Web通信 | 加密HTTP，使用TLS/SSL |
| SSH | 远程管理 | 加密远程登录 |
| VPN | 远程访问 | 加密隧道 |
| IPsec | 网络层加密 | 站点间加密通信 |
| SFTP | 文件传输 | 安全文件传输 |
| TLS/SSL | 传输层加密 | 通用传输加密 |

#### 9.1.3 网络安全设备

**边界防护**：
- 防火墙：访问控制、NAT、VPN
- 入侵检测系统（IDS）：攻击检测
- 入侵防御系统（IPS）：攻击防御
- 抗DDoS：拒绝服务攻击防护
- Web应用防火墙（WAF）：Web攻击防护

**内网安全**：
- 内网防火墙
- 网络访问控制（NAC）
- 流量监控与分析
- 网络隔离

### 9.2 操作安全

#### 9.2.1 操作安全管理

**操作安全目标**：
- 确保系统操作的安全可控
- 防止误操作和恶意操作
- 确保操作可追溯
- 保障系统稳定运行

**操作安全原则**：
- 职责分离
- 最小权限
- 操作审批
- 操作记录
- 双人操作（重要操作）

#### 9.2.2 变更管理

**变更管理流程**：
```
变更申请 → 变更评估 → 变更审批 → 变更实施 → 变更验证 → 变更关闭
    │          │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼          ▼
  提交变更   风险评估   分级审批   实施方案   验证结果   记录归档
  申请单     影响分析   紧急变更   回退方案   确认成功   事后回顾
```

**变更分类**：

| 变更类型 | 定义 | 审批级别 | 实施时间 |
|----------|------|----------|----------|
| 标准变更 | 低风险、有成熟方案 | 部门负责人 | 工作时间 |
| 普通变更 | 中等风险 | 变更委员会 | 非工作时间 |
| 重大变更 | 高风险、影响大 | CIO/CTO | 维护窗口 |
| 紧急变更 | 紧急故障修复 | 紧急审批 | 立即实施 |

**变更管理要点**：
- 所有变更必须有记录
- 变更前必须进行风险评估
- 重要变更必须有回退方案
- 变更后必须验证
- 定期评审变更效果

#### 9.2.3 备份管理

**备份策略**：
- 全量备份：完整备份所有数据
- 增量备份：只备份变化的数据
- 差异备份：备份上次全量备份以来的变化

**常见备份方案**：

| 备份方式 | 描述 | 恢复速度 | 存储空间 |
|----------|------|----------|----------|
| 全量+增量 | 每周全量+每日增量 | 慢 | 小 |
| 全量+差异 | 每周全量+每日差异 | 中 | 中 |
| 全量备份 | 每日全量 | 快 | 大 |

**备份三原则（3-2-1原则）**：
- 至少 3 份数据副本
- 使用 2 种不同介质
- 至少 1 份异地存储

**备份验证**：
- 定期进行备份恢复测试
- 验证备份数据完整性
- 验证备份可用性
- 记录测试结果

#### 9.2.4 日志管理

**日志类型**：
- 系统日志：操作系统日志
- 安全日志：安全设备日志
- 应用日志：应用系统日志
- 操作日志：用户操作记录
- 网络日志：网络设备日志

**日志管理要求**：
1. 日志收集：集中收集各类日志
2. 日志存储：安全存储、定期备份
3. 日志分析：安全分析、异常检测
4. 日志审计：定期审计、事件追溯
5. 日志保护：防止篡改和删除
6. 保存期限：不少于6个月（重要系统1年以上）

**日志内容要求**：
- 时间戳
- 用户标识
- 操作类型
- 操作对象
- 操作结果
- 源IP地址

#### 9.2.5 恶意代码防护

**防护层次**：
1. 网络层：防火墙、IPS、网关杀毒
2. 主机层：防病毒软件、主机加固
3. 应用层：WAF、应用安全检测
4. 邮件层：邮件安全网关
5. 终端层：终端安全管理

**防病毒管理要求**：
- 统一部署防病毒软件
- 病毒库及时更新
- 定期全盘扫描
- 实时防护开启
- 病毒事件及时处理

#### 9.2.6 漏洞管理

**漏洞管理流程**：
```
漏洞发现 → 漏洞评估 → 漏洞修复 → 漏洞验证 → 持续监控
    │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼
  漏洞扫描   风险分级   制定计划   验证修复   持续监测
  情报收集   影响分析   修复实施   关闭漏洞   定期扫描
```

**漏洞分级标准**：

| 级别 | CVSS评分 | 修复时限 | 示例 |
|------|----------|----------|------|
| 严重 | 9.0-10.0 | 立即/24小时内 | 远程代码执行、SQL注入 |
| 高危 | 7.0-8.9 | 7天内 | 权限绕过、文件泄露 |
| 中危 | 4.0-6.9 | 30天内 | 信息泄露、弱加密 |
| 低危 | 0.1-3.9 | 90天内 | 版本信息泄露 |

### 9.3 操作安全案例

**案例1：误删除数据事故**
某运维人员在执行清理操作时，误将生产数据库删除，导致业务中断4小时。
**原因分析**：
- 操作前未确认环境
- 没有操作审批
- 没有双人复核
- 备份恢复不及时

**改进措施**：
- 重要操作双人复核
- 操作前审批
- 生产环境操作窗口限制
- 加强备份恢复演练

**案例2：勒索病毒攻击**
某公司因员工点击钓鱼邮件，导致勒索病毒在内网传播，大量文件被加密。
**原因分析**：
- 员工安全意识薄弱
- 防病毒软件病毒库未及时更新
- 网络未有效隔离
- 备份数据也被加密

**改进措施**：
- 加强安全意识培训
- 及时更新病毒库和补丁
- 网络分段隔离
- 离线备份
