# 《关键信息基础设施安全保护条例》

### 5.1 条例概述

**全称**：《关键信息基础设施安全保护条例》
**通过时间**：2021年7月30日
**实施时间**：2021年9月1日
**地位**：关键信息基础设施安全保护的专门行政法规

**立法目的**：
- 保障关键信息基础设施安全
- 维护网络空间主权和国家安全
- 维护经济社会稳定运行
- 保护人民群众生命财产安全

### 5.2 关键信息基础设施定义

**定义**：公共通信和信息服务、能源、交通、水利、金融、公共服务、电子政务、国防科技工业等重要行业和领域的，以及其他一旦遭到破坏、丧失功能或者数据泄露，可能严重危害国家安全、国计民生、公共利益的重要网络设施、信息系统等。

**关键信息基础设施的特征**：
- 重要性：涉及重要行业和领域
- 影响大：一旦出问题严重危害国家安全、国计民生、公共利益
- 范围广：网络设施、信息系统等

### 5.3 保护部门和职责

**保护工作部门**：
- 国务院公安部门负责指导监督关键信息基础设施安全保护工作
- 国务院电信主管部门和其他有关部门依照本条例和有关法律、行政法规的规定，在各自职责范围内负责关键信息基础设施安全保护和监督管理工作

**行业监管职责**：
- 制定本行业、本领域关键信息基础设施安全规划
- 组织认定关键信息基础设施
- 指导监督运营者安全保护
- 组织开展安全检测和风险评估
- 应急处置

### 5.4 关键信息基础设施认定

**认定因素**：
1. 网络设施、信息系统等对于本行业、本领域关键核心业务的重要程度
2. 网络设施、信息系统等一旦遭到破坏、丧失功能或者数据泄露可能带来的危害程度
3. 对其他行业和领域的关联性影响
4. 法律、行政法规规定的其他事项

**认定程序**：
1. 运营者申报
2. 保护工作部门认定
3. 通知运营者
4. 报国务院公安部门备案

### 5.5 运营者的安全保护义务

#### 5.5.1 专门安全管理机构

**要求**：设置专门安全管理机构。

**专门安全管理机构职责**：
1. 建立健全本单位网络安全责任制
2. 组织制定并实施网络安全管理制度和操作规程
3. 组织开展网络安全教育和培训
4. 组织开展网络安全检测、风险评估和安全演练
5. 组织制定并实施网络安全事件应急预案
6. 定期向保护工作部门报告网络安全状况

#### 5.5.2 安全管理负责人

**要求**：专门安全管理机构负责人和关键岗位人员应当具备相应的安全管理能力和从业经历。

**背景审查**：运营者应当对专门安全管理机构负责人和关键岗位人员进行安全背景审查。

#### 5.5.3 安全投入

**要求**：运营者应当保障专门安全管理机构的运行经费、配备相应的人员，开展与网络安全和信息化有关的活动。

#### 5.5.4 安全检测评估

**要求**：运营者应当自行或者委托网络安全服务机构对关键信息基础设施每年至少进行一次网络安全检测和风险评估，对发现的安全问题及时整改。

#### 5.5.5 产品和服务采购安全

**要求**：
- 采购网络产品和服务，应当按照国家有关规定和标准进行安全检测
- 可能影响国家安全的，应当通过网络安全审查
- 应当与提供者签订安全保密协议

#### 5.5.6 数据安全保护

**要求**：
- 关键信息基础设施运营者在中华人民共和国境内运营中收集和产生的重要数据和个人信息应当在境内存储
- 因业务需要，确需向境外提供的，应当进行安全评估

#### 5.5.7 应急处置

**要求**：
- 制定网络安全事件应急预案
- 定期进行演练
- 发生网络安全事件时，立即启动应急预案
- 及时向保护工作部门报告

### 5.6 保障和促进措施

1. 国家对关键信息基础设施安全防护体系建设给予政策支持
2. 省级以上人民政府应当将关键信息基础设施安全保护工作纳入国民经济和社会发展规划
3. 国家鼓励关键信息基础设施安全技术创新和应用
4. 国家建立网络安全信息共享机制
5. 国家鼓励网络安全服务机构提供专业化服务

### 5.7 法律责任

| 违法情形 | 处罚措施 |
|----------|----------|
| 不履行安全保护义务 | 责令改正，给予警告 |
| 拒不改正或危害网络安全 | 10-100万元罚款，对直接责任人1-10万元 |
| 采购未经安全审查的产品服务 | 采购金额1-10倍罚款，最高1000万元 |
| 发生重大网络安全事件 | 按上一年度营业额的1%至5%罚款 |
