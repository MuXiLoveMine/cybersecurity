# 《数据安全法》要点解读

### 3.1 法律概述

**全称**：《中华人民共和国数据安全法》
**通过时间**：2021年6月10日
**实施时间**：2021年9月1日
**地位**：我国数据安全领域的基础性法律

**立法目的**：
- 规范数据处理活动
- 保障数据安全
- 促进数据开发利用
- 保护个人、组织的合法权益
- 维护国家主权、安全和发展利益

### 3.3 核心制度

#### 3.3.1 数据分类分级保护制度

**第二十一条**：国家建立数据分类分级保护制度，根据数据在经济社会发展中的重要程度，以及一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护。

**数据分类分级**：
- **一般数据**：对国家安全、公共利益或个人、组织合法权益影响较小
- **重要数据**：一旦遭到篡改、破坏、泄露等，可能对国家安全、公共利益造成危害
- **核心数据**：关系国家安全、国民经济命脉、重要民生、重大公共利益等数据

**保护要求**：
- 一般数据：常规保护
- 重要数据：重点保护，需风险评估、境内存储、出境评估
- 核心数据：实行更严格的管理制度

#### 3.3.2 数据安全风险评估制度

**第三十条**：重要数据的处理者应当按照规定对其数据处理活动定期开展风险评估，并向有关主管部门报送风险评估报告。

**风险评估内容**：
- 数据处理活动的安全状况
- 面临的安全威胁
- 存在的安全隐患
- 可能造成的危害
- 安全防护措施的有效性

#### 3.3.3 数据安全审查制度

**第二十四条**：国家建立数据安全审查制度，对影响或者可能影响国家安全的数据处理活动进行国家安全审查。

**审查对象**：
- 影响或可能影响国家安全的数据处理活动
- 关键信息基础设施运营者采购的数据产品和服务

**审查决定**：依法作出的安全审查决定为最终决定。

#### 3.3.4 数据出口管制制度

**第二十五条**：国家对与维护国家安全和利益、履行国际义务相关的属于管制物项的数据依法实施出口管制。

**管制方式**：
- 禁止出口
- 限制出口
- 许可出口

#### 3.3.5 数据交易管理制度

**第三十三条**：从事数据交易中介服务的机构提供服务，应当要求数据提供方说明数据来源，审核交易双方的身份，并留存审核、交易记录。

### 3.4 数据处理者的安全保护义务

#### 一般义务（所有数据处理者）

1. 建立健全全流程数据安全管理制度
2. 组织开展数据安全教育培训
3. 采取相应的技术措施和其他必要措施，保障数据安全
4. 加强风险监测，发现数据安全缺陷、漏洞等风险时，立即采取补救措施
5. 发生数据安全事件时，立即采取处置措施，按规定告知用户并向有关主管部门报告

#### 重要数据处理者的额外义务

1. 明确数据安全负责人和管理机构
2. 定期开展风险评估
3. 向主管部门报送风险评估报告
4. 重要数据境内存储
5. 数据出境需经过安全评估

### 3.5 与《网络安全法》的关系

| 对比项 | 网络安全法 | 数据安全法 |
|--------|-----------|-----------|
| 定位 | 网络安全领域基本法 | 数据安全领域基本法 |
| 调整范围 | 网络运行安全、网络信息安全 | 数据处理活动安全 |
| 重点 | 网络系统安全、网络信息安全 | 数据全生命周期安全 |
| 核心制度 | 等级保护、关基保护 | 分类分级、数据安全审查 |

**关系**：
- 两部法律相互衔接、互为补充
- 《网络安全法》侧重网络运行安全和网络信息安全
- 《数据安全法》侧重数据本身的安全和数据要素的治理
- 共同构成我国网络空间法治体系的重要组成部分

### 3.6 法律责任

| 违法情形 | 处罚措施 |
|----------|----------|
| 不履行数据安全保护义务 | 5-50万元罚款，对直接责任人1-10万元 |
| 违反重要数据保护规定 | 50-200万元罚款，对直接责任人5-20万元 |
| 拒不配合数据调取 | 5-50万元罚款 |
| 数据交易中介违规 | 没收违法所得，1-10倍罚款，无违法所得处10-100万元 |
| 违反国家核心数据管理制度 | 200-1000万元罚款，依法追究刑事责任 |
