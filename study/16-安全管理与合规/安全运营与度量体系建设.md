## 1. 安全运营概述

### 1.1 安全运营体系设计

安全运营（Security Operations）是企业为保护信息资产安全而建立的持续运营体系，涵盖预防、检测、响应和恢复全生命周期的安全活动。

**安全运营体系架构：**


**安全运营核心流程（OODA循环）：**

```
OODA循环在安全运营中的应用：

Observe（观察）→ Orient（定位）→ Decide（决策）→ Act（行动）
    ↑                                                    │
    └────────────────────────────────────────────────────┘

Observe: 收集安全数据
├── SIEM日志聚合
├── EDR告警
├── NDR流量分析
├── 威胁情报
└── 外部态势感知

Orient: 分析与判断
├── 告警分类与优先级排序
├── 事件关联分析
├── 威胁建模
├── 影响评估
└── 误报过滤

Decide: 决策与选择
├── 响应策略选择
├── 资源调度
├── 风险权衡
├── 升级判断
└── 合规考量

Act: 执行响应
├── 遏制（隔离、封禁）
├── 根除（清除、修复）
├── 恢复（系统恢复）
├── 通知与报告
└── 经验教训
```

```
├── 完整的安全运营流程

├── 24/7 SOC运营
├── 定期威胁狩猎

├── 红蓝对抗演练

├── AI/ML辅助检测
├── 预测性安全运营
├── 零信任架构
├── 自适应安全
├── 安全即代码
├── 持续集成安全
└── 响应时间：实时
```

## 2. 安全度量体系设计原则

### 2.1 SMART原则

安全度量指标应遵循SMART原则：

```
SMART原则在安全度量中的应用：

S - Specific（具体）
  ✗ 差：提高安全水平
  ✓ 好：将高危漏洞平均修复时间从30天降低到14天

M - Measurable（可度量）
  ✗ 差：减少安全风险
  ✓ 好：将外部攻击面暴露率降低20%

A - Achievable（可实现）
  ✗ 差：零安全事故（不现实）
  ✓ 好：年度重大安全事故不超过2起

R - Relevant（相关）
  ✗ 差：记录防火墙日志条数
  ✓ 好：防火墙规则合规率

T - Time-bound（有时限）
  ✗ 差：改善漏洞管理
  ✓ 好：2025年Q1内实现90%的高危漏洞24小时内修复
```

## 3. 安全KPI指标体系

### 3.1 防御度量

防御度量衡量组织预防安全事件的能力，是安全运营的基础。

**漏洞修复率（Vulnerability Remediation Rate）**

```
指标定义：
  漏洞修复率 = （已修复漏洞数 / 发现漏洞总数）× 100%

细分指标：
  ├── 高危漏洞修复率 = （已修复高危漏洞 / 发现高危漏洞总数）× 100%
  ├── 严重漏洞修复率 = （已修复严重漏洞 / 发现严重漏洞总数）× 100%
  ├── 平均修复时间（MTTR-Vuln）= 所有漏洞修复总时间 / 修复数量
  └── SLA达标率 = 在SLA时间内修复的漏洞数 / 应在SLA内修复的漏洞总数 × 100%

SLA目标示例：
  ├── 严重（Critical）：7天内修复，达标率>95%
  ├── 高危（High）：14天内修复，达标率>90%
  ├── 中危（Medium）：30天内修复，达标率>85%
  └── 低危（Low）：90天内修复，达标率>80%

计算示例：
  本月扫描发现漏洞：
    严重：10个（已修复9个）
    高危：50个（已修复45个）
    中危：200个（已修复160个）
    低危：500个（已修复350个）

  高危修复率 = 45/50 = 90%
  总体修复率 = (9+45+160+350)/(10+50+200+500) = 564/760 = 74.2%
```

```python
# 漏洞度量自动化脚本
import json
from datetime import datetime, timedelta
from collections import defaultdict

class VulnerabilityMetrics:
    def __init__(self):
        self.vulnerabilities = []

    def add_vuln(self, vuln_id, severity, discovered_date,
                 remediated_date=None, asset_id=None):
        self.vulnerabilities.append({
            'id': vuln_id,
            'severity': severity,
            'discovered': discovered_date,
            'remediated': remediated_date,
            'asset_id': asset_id
        })

    def calculate_remediation_rate(self, severity=None, period=None):
        """计算修复率"""
        vulns = self.vulnerabilities
        if severity:
            vulns = [v for v in vulns if v['severity'] == severity]
        if period:
            start, end = period
            vulns = [v for v in vulns
                     if start <= v['discovered'] <= end]

        total = len(vulns)
        remediated = sum(1 for v in vulns if v['remediated'])
        rate = (remediated / total * 100) if total > 0 else 0

        return {
            'total': total,
            'remediated': remediated,
            'rate': round(rate, 2)
        }

    def calculate_mttr(self, severity=None):
        """计算平均修复时间（天）"""
        vulns = [v for v in self.vulnerabilities
                 if v['remediated'] and
                 (severity is None or v['severity'] == severity)]

        if not vulns:
            return 0

        total_days = sum(
            (v['remediated'] - v['discovered']).days
            for v in vulns
        )
        return round(total_days / len(vulns), 1)

    def calculate_sla_compliance(self, sla_days):
        """计算SLA达标率"""
        sla_map = {'Critical': 7, 'High': 14,
                   'Medium': 30, 'Low': 90}

        results = {}
        for severity, sla in sla_map.items():
            vulns = [v for v in self.vulnerabilities
                     if v['severity'] == severity]

            total = len(vulns)
            if total == 0:
                results[severity] = {'rate': 100, 'total': 0}
                continue

            compliant = sum(
                1 for v in vulns
                if v['remediated'] and
                (v['remediated'] - v['discovered']).days <= sla
            )
            results[severity] = {
                'rate': round(compliant / total * 100, 2),
                'total': total,
                'compliant': compliant,
                'sla_days': sla
            }

        return results

    def generate_report(self, period=None):
        """生成度量报告"""
        print("=" * 60)
        print("Vulnerability Metrics Report")
        if period:
            print(f"Period: {period[0].date()} to {period[1].date()}")
        print("=" * 60)

        # 按严重级别统计
        for sev in ['Critical', 'High', 'Medium', 'Low']:
            rate = self.calculate_remediation_rate(severity=sev)
            mttr = self.calculate_mttr(severity=sev)
            print(f"\n{sev}:")
            print(f"  Total: {rate['total']}")
            print(f"  Remediated: {rate['remediated']}")
            print(f"  Remediation Rate: {rate['rate']}%")
            print(f"  MTTR: {mttr} days")

        # SLA达标率
        print("\nSLA Compliance:")
        sla_results = self.calculate_sla_compliance(None)
        for sev, data in sla_results.items():
            print(f"  {sev}: {data['rate']}% ({data.get('compliant', 0)}/"
                  f"{data['total']}, SLA: {data.get('sla_days', 'N/A')} days)")

        return {
            'remediation_rates': {
                sev: self.calculate_remediation_rate(severity=sev)
                for sev in ['Critical', 'High', 'Medium', 'Low']
            },
            'sla_compliance': sla_results
        }
```

```

  ├── 关键补丁覆盖率：关键安全补丁的部署率
```

### 3.2 检测度量

**平均检测时间（MTTD - Mean Time to Detect）**

```
指标定义：
  MTTD = 从威胁发生到被检测到的平均时间

计算公式：
  MTTD = Σ(检测时间 - 威胁发生时间) / 检测事件数

时间线：
  威胁发生 → ──── MTTD ──── → 检测到 → ──── MTTR ──── → 解决

目标值：
  ├── 自动化检测（EDR/NDR）：< 5分钟
  ├── SIEM关联检测：< 30分钟
  ├── 人工分析检测：< 4小时
  └── 综合MTTD：< 1小时（高危事件）

改进方向：
  ├── 扩大检测覆盖面
  ├── 优化检测规则（减少盲区）
  ├── 引入威胁狩猎（主动检测）
  ├── 部署EDR/XDR（实时检测）
  └── 引入UEBA（行为异常检测）
```

**告警准确率（Alert Accuracy / Precision）**

```
指标定义：
  告警准确率 = 真实安全事件告警数 / 总告警数 × 100%

相关指标：
  ├── 误报率（False Positive Rate）
  │   误报率 = 误报数 / 总告警数 × 100%
  │   目标：< 10%
  │
  ├── 漏报率（False Negative Rate）
  │   漏报率 = 未检测到的真实事件 / 真实事件总数 × 100%
  │   目标：< 5%
  │
  └── 告警信噪比（Signal-to-Noise Ratio）
      SNR = 真实告警 / 虚假告警

告警分级准确率：
  ┌──────────────┬──────────┬──────────┐
  │ 告警级别      │ 准确率目标│ 实际值   │
  ├──────────────┼──────────┼──────────┤
  │ 紧急(Critical)│ >95%     │ 待采集   │
  │ 高危(High)   │ >85%     │ 待采集   │
  │ 中危(Medium)  │ >70%     │ 待采集   │
```

### 3.3 响应度量

**平均响应时间（MTTR - Mean Time to Respond/Recover）**

```
指标定义：
  MTTR = 从检测到威胁到完全解决的平均时间

MTTR细分：
  ├── MTTR-Contain：检测到遏制的时间
  │   目标：紧急<30分钟，高危<2小时
  │
  ├── MTTR-Eradicate：遏制到根除的时间
  │   目标：紧急<4小时，高危<8小时
  │
  ├── MTTR-Recover：根除到恢复的时间
  │   目标：紧急<24小时，高危<48小时
  │
  └── MTTR-Total：检测到完全解决的时间
      目标：紧急<24小时，高危<72小时

MTTR计算示例：
  事件1: 检测14:00 → 遏制14:20 → 根除15:00 → 恢复16:00
         MTTR-Contain=20min, MTTR-Total=120min

  事件2: 检测09:00 → 遏制09:15 → 根除10:30 → 恢复12:00
         MTTR-Contain=15min, MTTR-Total=180min

  平均MTTR-Contain = (20+15)/2 = 17.5min
  平均MTTR-Total = (120+180)/2 = 150min
```

```python
class IncidentMetrics:
    """安全事件度量"""

    def __init__(self):
        self.incidents = []

    def add_incident(self, incident_id, detected_time, contained_time,
                     eradicated_time=None, recovered_time=None,
                     severity='medium', auto_detected=False):
        self.incidents.append({
            'id': incident_id,
            'detected': detected_time,
            'contained': contained_time,
            'eradicated': eradicated_time,
            'recovered': recovered_time,
            'severity': severity,
            'auto_detected': auto_detected
        })

    def calculate_mttd(self, occurred_time_key='occurred'):
        """计算MTTD"""
        # 需要知道威胁实际发生时间
        # 通常来自事后分析
        detection_times = []
        for inc in self.incidents:
            if inc.get(occurred_time_key):
                mttd = (inc['detected'] - inc[occurred_time_key]).total_seconds() / 60
                detection_times.append(mttd)
        return sum(detection_times) / len(detection_times) if detection_times else 0

    def calculate_mttr(self, phase='total', severity=None):
        """计算MTTR"""
        incidents = self.incidents
        if severity:
            incidents = [i for i in incidents if i['severity'] == severity]

        times = []
        for inc in incidents:
            if phase == 'contain':
                t = (inc['contained'] - inc['detected']).total_seconds() / 60
            elif phase == 'eradicate' and inc.get('eradicated'):
                t = (inc['eradicated'] - inc['contained']).total_seconds() / 60
            elif phase == 'recover' and inc.get('recovered'):
                t = (inc['recovered'] - inc.get('eradicated', inc['contained'])).total_seconds() / 60
            elif phase == 'total' and inc.get('recovered'):
                t = (inc['recovered'] - inc['detected']).total_seconds() / 60
            else:
                continue
            times.append(t)

        return round(sum(times) / len(times), 1) if times else 0

    def calculate_closure_rate(self, period=None):
        """计算事件闭环率"""
        incidents = self.incidents
        if period:
            start, end = period
            incidents = [i for i in incidents
                        if start <= i['detected'] <= end]

        total = len(incidents)
        closed = sum(1 for i in incidents if i.get('recovered'))

        return {
            'total': total,
            'closed': closed,
            'rate': round(closed / total * 100, 2) if total > 0 else 0
        }

    def calculate_false_positive_rate(self):
        """计算误报率"""
        total = len(self.incidents)
        false_pos = sum(1 for i in self.incidents if i.get('false_positive'))

        return round(false_pos / total * 100, 2) if total > 0 else 0

    def generate_dashboard(self):
        """生成度量仪表板数据"""
        return {
            'mttr_contain': self.calculate_mttr('contain'),
            'mttr_eradicate': self.calculate_mttr('eradicate'),
            'mttr_recover': self.calculate_mttr('recover'),
            'mttr_total': self.calculate_mttr('total'),
            'closure_rate': self.calculate_closure_rate(),
            'false_positive_rate': self.calculate_false_positive_rate(),
            'auto_detection_rate': self.calculate_auto_detection_rate(),
            'incidents_by_severity': self.count_by_severity()
        }

    def calculate_auto_detection_rate(self):
        """计算自动化检测率"""
        total = len(self.incidents)
        auto = sum(1 for i in self.incidents if i.get('auto_detected'))
        return round(auto / total * 100, 2) if total > 0 else 0

    def count_by_severity(self):
        """按严重级别统计"""
        counts = defaultdict(int)
        for inc in self.incidents:
            counts[inc['severity']] += 1
        return dict(counts)
```

### 4.1 投资回报率计算方法

```
安全ROI计算模型：

基本公式：
  ROI = （收益 - 投资） / 投资 × 100%

安全投资的收益维度：
├── 避免损失（Loss Avoidance）
│   ├── 避免的潜在数据泄露损失
│   ├── 避免的业务中断损失
│   ├── 避免的合规罚款
│   └── 避免的声誉损失
│
├── 运营效率（Operational Efficiency）
│   ├── 减少的人工分析时间
│   ├── 自动化节省的人力成本
│   ├── 减少的误报处理时间
│   └── 加速的响应时间
│
└── 风险降低（Risk Reduction）
    ├── 风险评分降低
    ├── 攻击面缩小
    └── 保险费降低
```

```python
class SecurityROI:
    """安全投资回报率计算"""

    def __init__(self):
        self.investments = {}
        self.benefits = {}
        self.baseline_metrics = {}

    def add_investment(self, category, amount, description=""):
        """添加投资项"""
        self.investments[category] = {
            'amount': amount,
            'description': description
        }

    def add_benefit(self, category, amount, description=""):
        """添加收益项"""
        self.benefits[category] = {
            'amount': amount,
            'description': description
        }

    def calculate_loss_avoidance(self, annual_loss_expectancy_before,
                                 annual_loss_expectancy_after):
        """
        计算避免的损失
        ALE = SLE × ARO
        SLE = Single Loss Expectancy（单次损失期望）
        ARO = Annualized Rate of Occurrence（年发生率）
        """
        return annual_loss_expectancy_before - annual_loss_expectancy_after

    def calculate_operational_savings(self, hours_saved, hourly_rate,
                                       automation_investment):
        """计算运营节省"""
        annual_savings = hours_saved * hourly_rate * 52  # 52周
        return annual_savings

    def calculate_roi(self):
        """计算总ROI"""
        total_investment = sum(
            v['amount'] for v in self.investments.values()
        )
        total_benefit = sum(
            v['amount'] for v in self.benefits.values()
        )

        roi = ((total_benefit - total_investment) /
               total_investment * 100) if total_investment > 0 else 0

        # 计算投资回收期
        payback_months = (total_investment /
                          (total_benefit / 12)) if total_benefit > 0 else 0

        return {
            'total_investment': total_investment,
            'total_benefit': total_benefit,
            'net_benefit': total_benefit - total_investment,
            'roi_percentage': round(roi, 2),
            'payback_months': round(payback_months, 1),
            'investments': self.investments,
            'benefits': self.benefits
        }

    def generate_roi_report(self):
        """生成ROI报告"""
        result = self.calculate_roi()

        print("=" * 60)
        print("Security Investment ROI Report")
        print("=" * 60)

        print("\nInvestments:")
        for cat, data in result['investments'].items():
            print(f"  {cat}: ${data['amount']:,.0f}")
            if data['description']:
                print(f"    ({data['description']})")

        print(f"\nTotal Investment: ${result['total_investment']:,.0f}")

        print("\nBenefits:")
        for cat, data in result['benefits'].items():
            print(f"  {cat}: ${data['amount']:,.0f}")
            if data['description']:
                print(f"    ({data['description']})")

        print(f"\nTotal Benefit: ${result['total_benefit']:,.0f}")
        print(f"Net Benefit: ${result['net_benefit']:,.0f}")
        print(f"ROI: {result['roi_percentage']}%")
        print(f"Payback Period: {result['payback_months']} months")

        return result
```

```python
            total_score += cat_score
            max_score += cat_max

        overall_percentage = (total_score / max_score * 100) if max_score > 0 else 0
        overall_maturity = self._determine_maturity(overall_percentage)

        return {
            'categories': results,
            'overall': {
                'score': total_score,
                'max': max_score,
                'percentage': round(overall_percentage, 1),
                'maturity_level': overall_maturity
            }
        }

    def _determine_maturity(self, percentage):
        """根据百分比确定成熟度等级"""
        if percentage >= 90:
            return 5  # 优化级
        elif percentage >= 70:
            return 4  # 量化级
        elif percentage >= 50:
            return 3  # 定义级
        elif percentage >= 30:
            return 2  # 可重复级
        else:
            return 1  # 初始级

    def generate_report(self, results):
        """生成评估报告"""
        print("=" * 60)
        print("Security Maturity Assessment Report")
        print("=" * 60)

        print(f"\nOverall Maturity: Level {results['overall']['maturity_level']}")
        print(f"Overall Score: {results['overall']['percentage']}%")

        print("\nCategory Breakdown:")
        for cat, data in results['categories'].items():
            level = data['maturity_level']
            pct = data['percentage']
            bar = '█' * int(pct / 5) + '░' * (20 - int(pct / 5))
            print(f"  {cat:20s} L{level} [{bar}] {pct:.1f}%")

        # 改进建议
        print("\nImprovement Priorities:")
        sorted_cats = sorted(
            results['categories'].items(),
            key=lambda x: x[1]['percentage']
        )
        for cat, data in sorted_cats[:3]:
            print(f"  [!] {cat}: {data['percentage']}% (Level {data['maturity_level']})")
```

```python
class PeerBenchmark:
    """同行基准分析"""

    # 行业基准数据（示例）
    BENCHMARKS = {
        'financial': {
            'mttd': 2.5,       # 小时
            'mttr': 6.0,
            'false_positive_rate': 12,
            'automation_rate': 35,
            'patch_coverage_30d': 92,
            'vuln_remediation_high': 12,  # 天
        },
        'healthcare': {
            'mttd': 5.0,
            'mttr': 12.0,
            'false_positive_rate': 18,
            'automation_rate': 20,
            'patch_coverage_30d': 78,
            'vuln_remediation_high': 25,
        },
        'technology': {
            'mttd': 1.5,
            'mttr': 4.0,
            'false_positive_rate': 8,
            'automation_rate': 45,
            'patch_coverage_30d': 95,
            'vuln_remediation_high': 8,
        },
        'manufacturing': {
            'mttd': 6.0,
            'mttr': 16.0,
            'false_positive_rate': 20,
            'automation_rate': 15,
            'patch_coverage_30d': 72,
            'vuln_remediation_high': 30,
        }
    }

    def __init__(self, industry, organization_metrics):
        self.industry = industry
        self.metrics = organization_metrics

    def compare(self):
        """与行业基准对比"""
        benchmark = self.BENCHMARKS.get(self.industry, {})
        results = {}

        for metric, org_value in self.metrics.items():
            bench_value = benchmark.get(metric)

            if bench_value is None:
                continue

            # 计算差异
            if metric in ['mttd', 'mttr', 'false_positive_rate',
                         'vuln_remediation_high']:
                # 越低越好的指标
                status = 'better' if org_value < bench_value else 'worse'
                diff_pct = ((bench_value - org_value) / bench_value) * 100
            else:
                # 越高越好的指标
                status = 'better' if org_value > bench_value else 'worse'
                diff_pct = ((org_value - bench_value) / bench_value) * 100

            results[metric] = {
                'organization': org_value,
                'benchmark': bench_value,
                'status': status,
                'diff_percentage': round(diff_pct, 1)
            }

        return results

    def generate_report(self):
        """生成对比报告"""
        comparison = self.compare()

        print("=" * 60)
        print(f"Peer Benchmark Report - {self.industry.title()}")
        print("=" * 60)

        print("\nMetric Comparison:")
        print(f"{'Metric':<30} {'Org':>10} {'Bench':>10} {'Status':>10} {'Diff':>10}")
        print("-" * 70)

        for metric, data in comparison.items():
            status = 'Better' if data['status'] == 'better' else 'Worse'
            diff = f"{data['diff_percentage']:+.1f}%"
            print(f"{metric:<30} {data['organization']:>10.1f} "
                  f"{data['benchmark']:>10.1f} {status:>10} {diff:>10}")

        # 识别需要改进的领域
        print("\nImprovement Priorities:")
        worse_metrics = [(m, d) for m, d in comparison.items()
                         if d['status'] == 'worse']
        worse_metrics.sort(key=lambda x: x[1]['diff_percentage'])

        for metric, data in worse_metrics:
            print(f"  [!] {metric}: {data['diff_percentage']:.1f}% "
                  f"vs benchmark")
```
