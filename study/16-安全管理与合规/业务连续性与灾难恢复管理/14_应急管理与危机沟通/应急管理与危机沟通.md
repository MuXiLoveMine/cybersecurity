# 应急管理与危机沟通

### 7.1 应急管理生命周期

```
预防与缓解 → 准备 → 响应 → 恢复 → 改进
   ↑                                        │
   └────────────────────────────────────────┘
                持续循环
```

**各阶段要点：**

- **预防与缓解**：识别风险，实施控制措施，降低灾难发生可能性和影响。
- **准备**：制定预案，培训人员，储备物资，建立通信渠道。
- **响应**：启动预案，保护人员安全，控制损害范围，维持核心运作。
- **恢复**：恢复业务运营，修复受损设施，恢复正常秩序。
- **改进**：事后总结经验，更新预案，改进措施。

### 7.2 危机沟通策略

**危机沟通原则（3C原则）：**
- **Clarity（清晰）**：信息简洁明确，避免专业术语。
- **Consistency（一致）**：所有渠道信息口径一致。
- **Candor（坦诚）**：诚实面对问题，不隐瞒不误导。

**危机沟通时间线：**

| 时间段 | 行动 | 目标 |
|--------|------|------|
| 0-1小时 | 确认事实，指定发言人 | 控制信息源 |
| 1-4小时 | 发布初步声明 | 占据信息主动权 |
| 4-24小时 | 详细说明与措施 | 展现应对能力 |
| 24-72小时 | 持续更新进展 | 维持公众信任 |
| 72小时+ | 总结与改进计划 | 修复声誉 |

### 7.3 媒体应对

**媒体应对Checklist：**

- [ ] 指定唯一新闻发言人
- [ ] 准备Q&A清单（预判媒体问题）
- [ ] 准备声明稿模板
- [ ] 建立媒体监测机制
- [ ] 社交媒体实时监控与回应
- [ ] 准备新闻发布会的后勤保障

**媒体应对"五不"原则：**
1. 不说"无可奉告"
2. 不推卸责任
3. 不编造信息
4. 不做超出权限的承诺
5. 不与记者争论

### 7.4 利益相关方通知

**通知优先级与时限：**

| 利益相关方 | 通知时限 | 通知内容 | 通知方式 |
|-----------|----------|----------|----------|
| 监管机构 | 1-24小时（法规要求） | 事件概述、影响评估、应对措施 | 正式书面报告 |
| 客户 | 1-4小时 | 服务影响、预计恢复时间 | 官网公告+邮件 |
| 员工 | 立即 | 安全指示、工作安排 | 内部通信+短信 |
| 供应商 | 1-2小时 | 协助需求、影响范围 | 电话+邮件 |
| 媒体 | 2-4小时 | 事实声明、应对措施 | 新闻发布 |
| 投资者 | 4-24小时 | 财务影响评估 | 公告+电话会议 |

**通知内容模板（黄金小时通知）：**

```
[事件级别：X级]
[发生时间：YYYY-MM-DD HH:MM]
[影响范围：简述]
[当前状态：正在评估/已控制/恢复中]
[预计恢复时间：___]
[下次更新时间：___]
[联系方式：___]
```
