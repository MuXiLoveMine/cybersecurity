# 等保建设实施指南

### 8.1 等保建设总体流程

```
定级备案 → 差距分析 → 方案设计 → 整改实施 → 等级测评 → 持续运维
    │          │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼          ▼
  确定等级   对照标准   技术方案   技术整改   第三方测评  定期检查
  专家评审   识别差距   管理方案   制度建设   问题整改    持续改进
  公安备案   风险评估   项目计划   培训宣贯   复测通过    年度测评
```

### 8.2 阶段一：定级备案

**工作内容**：
1. 确定定级对象
2. 进行等级评定
3. 组织专家评审
4. 主管部门审批
5. 公安机关备案

**输出文档**：
- 定级报告
- 备案证明

**时间**：2-4周

### 8.3 阶段二：差距分析

**工作内容**：
1. 收集现有资料
2. 现状调研（技术+管理）
3. 对照等保标准逐项检查
4. 识别差距项
5. 风险评估
6. 编制差距分析报告

**差距分析方法**：
- 文档审查
- 人员访谈
- 现场检查
- 技术检测

**输出文档**：
- 差距分析报告
- 风险评估报告

**时间**：2-4周

### 8.4 阶段三：方案设计

**工作内容**：
1. 制定技术整改方案
2. 制定管理整改方案
3. 设计安全架构
4. 产品选型
5. 编制项目计划
6. 预算编制

**技术整改主要内容**：
- 网络架构调整
- 安全设备部署
- 系统安全加固
- 数据安全保护
- 安全管理中心建设

**管理整改主要内容**：
- 制度体系建设
- 安全组织建设
- 人员培训
- 运维流程规范

**输出文档**：
- 安全建设方案
- 项目实施计划
- 预算方案

**时间**：2-4周

### 8.5 阶段四：整改实施

**工作内容**：
1. 安全设备采购
2. 设备部署调试
3. 系统安全加固
4. 安全策略配置
5. 制度文件编写
6. 安全培训
7. 试运行

**实施要点**：
- 分阶段实施，先急后缓
- 最小化对业务的影响
- 做好变更管理
- 保留详细实施记录

**输出文档**：
- 实施记录
- 配置文档
- 制度文件
- 培训记录

**时间**：2-6个月（根据系统规模和差距大小）

### 8.6 阶段五：等级测评

**工作内容**：
1. 选择测评机构
2. 测评准备
3. 现场测评
4. 问题整改
5. 复测（如需要）
6. 获取测评报告

**如何选择测评机构**：
- 具有等保测评资质
- 有相关行业经验
- 技术实力强
- 服务质量好
- 当地有办事处

**输出文档**：
- 等级测评报告
- 整改记录

**时间**：2-4周

### 8.7 阶段六：持续运维

**工作内容**：
1. 日常安全运维
2. 定期安全检查
3. 漏洞管理
4. 安全事件处理
5. 年度等级测评
6. 持续改进

**定期工作清单**：

| 工作项 | 频次 | 责任部门 |
|--------|------|----------|
| 漏洞扫描 | 每月 | 安全部 |
| 安全检查 | 每季度 | 安全部 |
| 备份恢复测试 | 每季度 | 运维部 |
| 应急演练 | 每年 | 安全部 |
| 安全培训 | 每年 | 人力资源部 |
| 内部审计 | 每年 | 审计部 |
| 等级测评 | 每年 | 安全部 |
| 风险评估 | 每年 | 安全部 |

### 8.8 等保建设常见问题

#### 问题1：等保就是买设备？

**答案**：不是。等保包括技术和管理两方面，设备只是技术的一部分，还需要制度、人员、流程等管理方面的建设。

#### 问题2：等保测评通过就一劳永逸了？

**答案**：不是。等保是持续的过程，需要每年进行测评，日常持续运维，持续改进。

#### 问题3：二级系统比三级简单很多？

**答案**：二级和三级的要求框架基本一致，但三级要求更高，特别是安全管理中心、异地备份、入侵防御等方面。

#### 问题4：等保只是安全部门的事？

**答案**：不是。等保涉及技术、管理、人员等各方面，需要各部门共同参与，是全员的责任。

### 8.9 等保建设案例

**案例：某企业三级等保建设项目**

**项目背景**：
某中型互联网企业，主要业务是在线教育，注册用户300万。根据业务特点和规模，系统定为第三级。企业之前没有系统的安全建设，需要从零开始进行等保建设。

**项目周期**：6个月

**项目过程**：

**第1个月：定级备案+差距分析**
- 完成系统定级（三级）
- 向当地公安局备案
- 进行全面差距分析
- 发现差距项：技术类35项，管理类25项

**主要差距**：
- 缺少安全管理中心
- 未部署IDS/IPS
- 网络未有效分段
- 数据传输未加密
- 日志保存时间不足
- 没有异地备份
- 安全制度不完善
- 缺少专职安全人员

**第2个月：方案设计**
- 设计安全架构
- 确定产品选型
- 制定实施计划
- 预算：约150万（设备100万+服务50万）

**第3-4个月：技术整改**
- 网络重新规划和分段
- 部署防火墙、IPS、WAF
- 部署日志审计系统
- 部署堡垒机
- 服务器安全加固
- 部署SSL证书，实现HTTPS
- 建设异地备份
- 建设安全管理中心

**第5个月：管理整改+试运行**
- 编写安全制度文件（20+份）
- 建立安全组织
- 开展安全培训
- 完善运维流程
- 系统试运行

**第6个月：等级测评**
- 选择测评机构
- 现场测评
- 发现问题8项（主要是细节问题）
- 整改后复测通过
- 最终得分：82分

**项目成果**：
- 顺利通过等保三级测评
- 安全防护能力大幅提升
- 建立了完善的安全管理体系
- 员工安全意识显著提高
- 满足了监管和客户要求

**经验总结**：
1. 领导重视是关键
2. 提前规划，分步实施
3. 技术和管理并重
4. 选择专业的服务商
5. 全员参与，持续改进
