# 等保 2.0 标准体系详解

### 4.1 基本要求的总体结构

等保2.0基本要求分为两大类：安全技术要求和安全管理要求。

```
等保2.0基本要求
├── 安全技术要求
│   ├── 安全物理环境
│   ├── 安全通信网络
│   ├── 安全区域边界
│   ├── 安全计算环境
│   └── 安全管理中心
└── 安全管理要求
    ├── 安全管理制度
    ├── 安全管理机构
    ├── 安全管理人员
    ├── 安全建设管理
    └── 安全运维管理
```

### 4.2 不同等级的要求强度

| 要求类别 | 一级 | 二级 | 三级 | 四级 |
|----------|------|------|------|------|
| 安全物理环境 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全通信网络 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全区域边界 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全计算环境 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全管理中心 | - | - | 要求 | 更高要求 |
| 安全管理制度 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全管理机构 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全管理人员 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全建设管理 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |
| 安全运维管理 | 基本要求 | + 增强要求 | + 更多增强 | + 最高要求 |

> 注：安全管理中心是三级及以上系统的要求，一、二级不做要求。

### 4.3 等保 2.0 与新技术扩展

#### 4.3.1 云计算安全扩展

**适用场景**：使用云计算服务的系统

**核心扩展要求**：
- 云平台和云上系统分别定级
- 云服务商的安全责任
- 虚拟化安全
- 云平台管理安全
- 数据隔离
- 云租户安全

#### 4.3.2 移动互联安全扩展

**适用场景**：有移动应用的系统

**核心扩展要求**：
- 移动终端安全
- 移动应用安全
- 无线接入安全
- 移动应用分发
- 移动端数据保护

#### 4.3.3 物联网安全扩展

**适用场景**：物联网系统

**核心扩展要求**：
- 感知节点安全
- 感知网络安全
- 数据采集安全
- 设备身份认证
- 边缘计算安全

#### 4.3.4 工业控制安全扩展

**适用场景**：工业控制系统

**核心扩展要求**：
- 工控系统分区隔离
- 工控设备安全
- 工控协议安全
- 工控数据安全
- 工控应急响应
