# 等保 2.0 变化与特点

### 2.1 等保 1.0 与 2.0 的主要区别

| 对比项 | 等保 1.0 | 等保 2.0 |
|--------|----------|----------|
| 法律地位 | 部门规章 | 上升为法律制度 |
| 覆盖范围 | 传统信息系统 | 传统系统+云+物联网+工控+移动互联 |
| 体系架构 | 以技术为主 | 一个中心、三重防护 |
| 管理要求 | 五项管理要求 | 安全管理中心+五项管理 |
| 安全理念 | 被动防御 | 主动防御、动态防御、整体防御 |
| 测评方法 | 符合性测评 | 验证+量化评估 |
| 标准数量 | 5个标准 | 10+个标准 |

### 2.2 等保 2.0 的主要变化

#### 变化1：名称变化
- 从"信息系统安全等级保护"变为"网络安全等级保护"
- 范围从信息系统扩展到整个网络空间

#### 变化2：体系架构变化
- 引入"一个中心、三重防护"理念
- 增加安全管理中心要求
- 从技术+管理二维变为中心+三重防护+管理

#### 变化3：扩展保护对象
- **云计算安全扩展要求**：针对云计算平台
- **移动互联安全扩展要求**：针对移动应用
- **物联网安全扩展要求**：针对物联网系统
- **工业控制安全扩展要求**：针对工业控制系统

#### 变化4：强化主动防御
- 增加入侵防范、恶意代码防范
- 增加安全审计、集中管控
- 增加态势感知、威胁情报
- 从被动防护变为主动防御

#### 变化5：强化可信验证
- 增加可信计算要求
- 增加可信验证要求
- 从设备可信到应用可信

#### 变化6：强化个人信息保护
- 增加个人信息保护要求
- 增加数据分类分级要求
- 增加数据脱敏、加密要求

### 2.3 等保 2.0 的特点

1. **主动防御**：从被动防护到主动发现、主动响应
2. **动态防御**：从静态防护到动态感知、动态调整
3. **纵深防御**：从单点防护到多层次、全方位防护
4. **精准防护**：从一刀切到基于风险的精准防护
5. **整体防护**：从分散防护到统一管理、整体协同

### 2.4 等保 2.0 标准体系

等保2.0形成了完整的标准体系，包括基础标准、应用标准和产品标准。
