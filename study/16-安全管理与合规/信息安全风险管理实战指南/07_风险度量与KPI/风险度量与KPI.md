# 风险度量与KPI

### 7.1 风险度量指标设计

有效的风险度量指标应具备SMART特性（具体、可度量、可实现、相关、时限）。

**核心风险度量指标**：

| 指标 | 定义 | 计算方法 | 目标 |
|------|------|---------|------|
| 风险敞口总额 | 组织全部风险ALE之和 | Σ(各风险ALE) | 逐年下降 |
| 高风险数量 | 极高+高风险等级数量 | 统计风险登记表 | 持续减少 |
| 风险处置率 | 已处置风险/总风险数 | 处置数/总数 | >80% |
| 平均处置时间 | 风险从识别到关闭的平均时间 | Σ(关闭时间-识别时间)/关闭数 | <90天 |
| 风险复发率 | 已关闭风险再次出现的比例 | 复发数/关闭数 | <10% |
| 控制有效率 | 有效控制/总控制措施 | 有效数/总数 | >85% |
| 风险接受率 | 接受风险/总风险数 | 接受数/总数 | <20% |

### 7.2 风险趋势分析

风险趋势分析通过时间序列对比揭示风险管理成效：
- 季度对比：本季度vs上季度的风险数量、风险敞口变化
- 年度对比：年度风险评估结果对比
- 分类趋势：按风险类型（技术/管理/操作）分布变化
- 处置趋势：处置率和处置时间趋势

趋势分析可用于：
- 向管理层展示风险管理成效
- 识别风险增长热点领域（如新业务引入新风险类型）
- 评估风险策略调整效果
- 支持下年度预算和安全投入决策

### 7.3 风险管理ROI

风险管理ROI（Return on Investment）量化安全投入的经济效益：

> **ROI = (风险降低收益 - 安全投入成本) / 安全投入成本 × 100%**

计算示例：
- 安全投入：部署SIEM系统，3年TCO = 150万元（采购100万+运维30万+培训20万）
- 风险降低前ALE总和 = 300万元/年
- 风险降低后ALE总和 = 120万元/年
- 年均风险降低收益 = 300 - 120 = 180万元/年
- 3年总收益 = 180 × 3 = 540万元
- ROI = (540 - 150) / 150 × 100% = 260%

ROI计算的挑战：
- 风险降低收益是"如果没有安全投入会损失多少"的估算值，具有不确定性
- 应使用蒙特卡洛模拟输出ROI的置信区间而非点值
- 需考虑间接收益（合规达标避免罚款、安全事件避免声誉损失等）

### 7.4 风险管理成熟度评估

| 级别 | 特征 | 典型表现 |
|------|------|---------|
| 1-初始级 | 事件驱动、无系统性方法 | 出了事才关注，无风险登记表 |
| 2-可重复级 | 有基本流程和模板 | 有年度评估但执行不一致 |
| 3-已定义级 | 标准化流程、制度完善 | 有风险管理政策和流程，定期执行 |
| 4-已管理级 | 度量驱动、持续改进 | KPI体系健全、量化分析、趋势跟踪 |
| 5-优化级 | 预测性管理、自适应 | AI辅助风险预测、与业务实时联动 |
