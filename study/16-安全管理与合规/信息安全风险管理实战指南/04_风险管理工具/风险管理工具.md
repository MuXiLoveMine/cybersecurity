# 风险管理工具

### 4.1 商业工具

**RSA Archer**：
- Gartner GRC魔力象限领导者
- 全功能GRC平台，覆盖风险、合规、审计、策略管理
- 优势：功能全面、可定制性强、大型企业首选
- 劣势：实施复杂、成本高、需要专业团队运维
- 适用：大型集团、金融行业

**ServiceNow GRC**：
- 基于ServiceNow ITSM平台构建
- 优势：与ITSM工单/变更/资产管理无缝集成
- 劣势：安全风险管理深度不如专业GRC
- 适用：已有ServiceNow ITSM基础的组织

**MetricStream**：
- 独立GRC平台
- 优势：合规管理功能强、支持多框架映射
- 劣势：技术风险管理不如RSA Archer深入
- 适用：合规要求密集的行业

**RiskLens**：
- 专门基于FAIR方法的定量风险分析平台
- 优势：FAIR方法论原生支持、量化输出精确
- 劣势：功能单一、需FAIR专业知识
- 适用：追求定量风险管理成熟度的组织

### 4.2 开源工具

**SimpleRisk**：
- 开源GRC平台，功能精简但实用
- 包含风险登记、风险评估、合规管理、缓解计划
- 优势：免费开源、部署简单、界面清晰
- 适用：中小企业风险管理起步

**CyberRisk（OpenFAIR）**：
- 开源的FAIR风险计算工具
- 输入威胁事件频率和损失幅度参数，输出蒙特卡洛模拟结果
- 适用：FAIR定量分析辅助计算

**EZ-GRC**：
- 轻量级开源GRC工具
- 功能简单但支持基本的资产登记和风险跟踪

### 4.3 Excel风险登记表模板设计

对于刚起步或预算有限的团队，Excel风险登记表是最实用的起步工具。推荐模板字段：

| 列名 | 说明 | 示例 |
|------|------|------|
| 风险编号 | 唯一标识 | R-2026-001 |
| 风险描述 | 简要描述风险 | 数据库遭受未授权访问 |
| 资产编号 | 关联资产 | A-001 |
| 威胁来源 | 威胁类型 | 外部攻击者 |
| 脆弱性 | 漏洞/弱点 | SQL注入漏洞 |
| 可能性(1-5) | 发生概率 | 4 |
| 影响(1-5) | 影响程度 | 5 |
| 资产价值(1-5) | 资产重要性 | 5 |
| 风险值 | 计算公式 | =可能性*影响*资产价值(=100) |
| 风险等级 | 映射 | 极高 |
| 现有控制 | 已部署措施 | WAF |
| 残余风险值 | 控制后 | 40 |
| 处置策略 | 规避/转移/降低/接受 | 降低 |
| 控制措施 | 计划措施 | 修复漏洞+加强WAF规则+数据库审计 |
| 责任人 | 负责人 | 张三 |
| 计划完成日 | 截止日期 | 2026-12-31 |
| 状态 | 进行中/已完成 | 进行中 |
| 复核日期 | 定期回顾 | 2027-01-15 |

Excel模板可使用条件格式实现风险值自动着色（红/橙/黄/绿），并使用数据透视表生成风险分布统计。

### 4.4 工具选型建议

| 组织规模 | 预算 | 推荐方案 | 理由 |
|---------|------|---------|------|
| 小型(<100人) | 低 | Excel风险登记表 | 零成本、易上手、足够覆盖基本需求 |
| 中型(100-500人) | 中 | SimpleRisk + Excel | 开源工具+灵活补充 |
| 大型(500-5000人) | 高 | RSA Archer或ServiceNow GRC | 需要体系化GRC支撑 |
| 集团(>5000人) | 高 | RSA Archer + RiskLens | GRC全流程+FAIR定量分析 |

选型核心考量：
- 与现有ITSM/安全工具的集成能力
- 工作流灵活度和自定义能力
- 报表和可视化能力
- 总持有成本（许可+实施+运维+培训）
- 供应商的持续支持能力
