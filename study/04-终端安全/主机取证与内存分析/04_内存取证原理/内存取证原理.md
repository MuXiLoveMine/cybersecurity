# 内存取证原理

### 4.1 内存获取方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 硬件采集 | DMA/PCI 设备读取内存 | 最可靠 | 需专用硬件 |
| 虚拟机快照 | 导出 VM 内存 | 方便 | 仅虚拟机 |
| 崩溃转储 | BlueScreen 后转储 | 完整 | 需触发蓝屏 |
| 工具采集 | 内存采集软件 | 便捷 | 可能被 Rootkit 干扰 |

**常用内存采集工具**：

```
Windows:
├── WinPmem      - 开源，支持 Windows 7-11
├── Magnet RAM Capture - 商业，免费使用
└── FTW Imager   - 转储工具

Linux:
├── LiME         - 内核模块，最可靠
└── AVML         - 微软开源

跨平台:
├── VirtualBox/VMware 快照
└── Live CD (Helix, CAIN)
```

```bash
# Windows 内存采集 (WinPmem)
winpmem_mini_x64.exe memory.dmp

# Linux 内存采集 (LiME)
# 编译 LiME 内核模块
make
insmod lime.ko "path=/tmp/memory.lime format=lime"

# VM 内存导出
# VMware: .vmem 文件即为内存镜像
# VirtualBox: VBoxManage exportvm --output memory.raw
```

### 4.2 内存结构

```
Windows 内存结构:

物理内存:
├── 物理页 (4KB/2MB)
└── 物理地址 (PA)

虚拟内存:
├── 虚拟地址 (VA) 空间
├── 页目录 (Page Directory)
├── 页表 (Page Table)
└── 页帧号 (PFN)

进程虚拟地址空间 (x64):
├── 0x000000000000 - 0x00007FFFFFFFFFFF  用户空间
├── 0xFFFF800000000000 - 0xFFFFFFFFFFFFFFFF  内核空间
│   ├── 进程 EPROCESS 结构
│   ├── PEB (进程环境块)
│   ├── VAD (虚拟地址描述符) - 记录进程内存分配
│   └── 句柄表
└── EPROCESS 中的关键字段:
    ├── UniqueProcessId (PID)
    ├── ActiveProcessLinks (进程链表 - 遍历所有进程)
    ├── ImageFileName (进程名)
    ├── PEB (进程环境块)
    └── VadRoot (VAD 树根)
```
