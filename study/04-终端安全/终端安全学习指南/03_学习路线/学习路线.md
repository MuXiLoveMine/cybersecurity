# 学习路线

### 阶段 1：系统基础（1-2 个月）
**学习目标**：掌握 Windows 和 Linux 系统基础知识

**学习内容**
- Windows 系统基础
- Linux 系统基础
- 常用命令
- 系统管理
- 网络配置
- 服务管理
- 脚本编程（Batch、PowerShell、Bash）

**实践任务**
- 安装 Windows 和 Linux 虚拟机
- 熟悉系统操作
- 学习常用命令
- 编写简单脚本
- 配置系统服务

### 阶段 2：系统安全（2-3 个月）
**学习目标**：掌握系统安全配置和加固方法

**学习内容**
- Windows 安全机制
- Linux 安全机制
- 安全基线配置
- 系统加固
- 防火墙配置
- 日志审计
- 漏洞管理
- 补丁管理

**实践任务**
- 配置 Windows 安全基线
- 配置 Linux 安全基线
- 配置防火墙规则
- 配置日志审计
- 进行系统加固
- 打系统漏洞靶场

### 阶段 3：恶意代码分析（3-4 个月）
**学习目标**：掌握恶意代码分析技术

**学习内容**
- 静态分析
- 动态分析
- 反汇编
- 调试技术
- 脱壳技术
- 常见恶意代码类型
- 分析工具使用
- 沙箱使用

**实践任务**
- 分析简单的恶意代码样本
- 使用各种分析工具
- 练习静态分析
- 练习动态分析
- 打逆向 CTF 题目
- 写分析报告

### 阶段 4：终端攻防（2-3 个月）
**学习目标**：掌握终端攻击和防御技术

**学习内容**
- 权限提升
- 进程注入
- 权限维持
- 绕过防护
- EDR 原理
- EDR 绕过
- 红队终端对抗
- 蓝队检测与响应

**实践任务**
- 练习各种提权方法
- 练习进程注入
- 练习权限维持技术
- 学习 EDR 检测原理
- 练习 EDR 绕过
- 打红队靶场

### 阶段 5：深入研究（持续）
**研究方向**
- 高级恶意代码分析
- Rootkit 分析
- 内核漏洞
- EDR 对抗
- 内存取证
- 威胁狩猎
- 安全研究
