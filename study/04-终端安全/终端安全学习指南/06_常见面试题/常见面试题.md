# 常见面试题

### 基础概念
1. **Windows 的安全机制有哪些？**
   - 用户账户控制（UAC）
   - 地址空间随机化（ASLR）
   - 数据执行保护（DEP/NX）
   - 结构化异常处理覆盖保护（SEHOP）
   - 强制完整性控制（MIC）
   - Windows Defender
   - 防火墙
   - BitLocker 加密

2. **Linux 的安全机制有哪些？**
   - 用户权限模型
   - 文件权限（UGO、ACL）
   - 进程隔离
   - 命名空间（Namespace）
   - 控制组（cgroups）
   - SELinux / AppArmor（强制访问控制）
   - seccomp（系统调用过滤）
   - Capabilities（能力机制）

3. **什么是 EDR？和传统杀毒软件有什么区别？**
   - EDR 是终端检测与响应
   - 传统杀毒主要靠特征码检测，EDR 更侧重行为检测和响应
   - EDR 有威胁狩猎、调查分析、远程响应等能力
   - EDR 可以发现更高级的威胁

4. **常见的恶意代码类型有哪些？**
   - 病毒、木马、蠕虫、勒索软件、间谍软件、广告软件、挖矿程序、僵尸网络、后门、Rootkit

### 漏洞原理
5. **常见的 Windows 提权方法有哪些？**
   - 内核漏洞提权
   - 服务权限配置错误
   - 注册表权限配置错误
   - 计划任务提权
   - 令牌窃取
   - 进程注入
   - 永远信任 SYSTEM

6. **常见的 Linux 提权方法有哪些？**
   - 内核漏洞提权
   - SUID/SGID 程序
   - 可写的服务配置
   - 计划任务
   - sudo 配置错误
   - 环境变量劫持
   - 共享库注入

7. **进程注入的方式有哪些？**
   - 远程线程注入
   - 反射式 DLL 注入
   - APC 注入
   - 进程空洞
   - 线程劫持
   - 映射注入

8. **Windows 持久化的方式有哪些？**
   - 注册表启动项
   - 计划任务
   - 服务
   - 驱动
   - WMI 事件订阅
   - 映像劫持
   - 启动文件夹
   - BITS Jobs
   - COM 劫持

### 实战相关
9. **如何进行恶意代码分析？**
   - 静态分析：文件类型、字符串、导入表、反汇编
   - 动态分析：进程行为、文件操作、注册表、网络
   - 高级分析：脱壳、反调试绕过、加密算法识别
   - 报告编写：整理分析结果和 Indicators of Compromise (IOC)

10. **勒索软件的防护措施有哪些？**
    - 数据备份（3-2-1 原则）
    - 补丁管理
    - 端点防护（EDR/杀毒）
    - 邮件安全
    - 网络分段
    - 最小权限
    - 应用白名单
    - 行为监控
    - 威胁狩猎
    - 应急响应预案

11. **什么是内存取证？有什么用？**
    - 内存取证是分析计算机内存中的数据
    - 可以发现运行中的恶意代码
    - 可以提取敏感信息（密码、密钥等）
    - 可以分析网络连接和进程行为
    - 可以发现无文件恶意代码和 Rootkit

12. **EDR 绕过的常见方法有哪些？**
    - 免杀技术（混淆、加密、加壳）
    - 反调试、反虚拟机、反沙箱
    - 无文件攻击
    - 白名单利用（LOLBins）
    - 用户态钩子绕过
    - 直接系统调用
    - 内存中解密执行
    - 代码混淆
    - 睡眠混淆
