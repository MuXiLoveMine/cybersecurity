# 分析工具介绍

### 6.1 静态分析工具

**IDA Pro**

```
IDA Pro 是业界最强大的反汇编和反编译工具，被广泛用于恶意代码分析、漏洞研究和软件逆向工程。

主要功能：
- 交互式反汇编器
- 强大的反编译器（Hex-Rays Decompiler）
- 跨平台分析（x86、x64、ARM、MIPS 等）
- 支持多种文件格式（PE、ELF、Mach-O 等）
- 丰富的插件生态系统
- 脚本支持（IDC、Python）

常用功能：
1. 反汇编视图（图形视图和文本视图）
2. 反编译视图（F5 伪代码）
3. 字符串搜索（Shift+F12）
4. 导入/导出函数分析
5. 交叉引用（Xrefs）
6. 结构体定义和识别
7. 类型分析和重建
8. 动态调试（配合调试器）

常用快捷键：
- F5：反编译
- Space：切换图形/文本视图
- G：跳转到地址
- X：查看交叉引用
- N：重命名
- ;：添加注释
- Shift+F12：字符串窗口
- Ctrl+S：查看段列表
```

**Ghidra**

```
Ghidra 是美国国家安全局（NSA）开源的逆向工程工具，
功能接近 IDA Pro，且完全免费。

主要功能：
- 反汇编和反编译
- 支持多种架构和文件格式
- 内置 Python 脚本支持
- 协作分析功能
- 丰富的插件系统
- 完全免费开源

与 IDA Pro 比较：
- 优点：免费、开源、持续更新
- 缺点：界面较复杂、学习曲线陡、插件生态不如 IDA 丰富

适用场景：
```

**Process Monitor**

```
Process Monitor 是 Sysinternals 工具集中的核心工具，
实时监控进程的文件系统、注册表、网络和进程操作。

主要功能：
- 实时监控文件系统操作
- 实时监控注册表操作
- 实时监控网络操作
- 实时监控进程/线程操作
- 强大的过滤和搜索功能
- 启动时监控（Boot Logging）
- 保存和加载日志

常用过滤技巧：
1. 按进程名过滤：只关注特定进程
2. 按操作类型过滤：只看文件写入或注册表修改
3. 按路径过滤：只关注特定目录或注册表键
4. 排除系统进程：减少噪音
5. 突出显示（Highlight）：标记重要操作

分析流程：
1. 启动 ProcMon，开始捕获
2. 运行恶意程序
3. 等待恶意程序执行关键操作
4. 停止捕获
5. 设置过滤，逐步分析
```

**Process Explorer**

```
Process Explorer 是增强版的任务管理器。

主要功能：
- 进程树视图
- 查看进程加载的 DLL
- 查看进程打开的句柄

- 替换任务管理器
- 查看进程网络连接
- 查看 CPU/内存/IO 使用情况
- 挂起/恢复/终止进程

分析用途：
1. 发现可疑进程（路径、签名、父进程）
2. 检测 DLL 注入（异常 DLL 路径）
3. 检查进程打开的文件和注册表键
4. 验证进程签名
5. 查看进程的 TCP/UDP 连接
```

**Wireshark**

```
Wireshark 是最流行的网络协议分析器。

主要功能：
- 实时抓包和离线分析
- 支持 2000+ 种网络协议
- 强大的过滤功能
- 流重组（TCP Stream、HTTP Stream）
- 多种统计功能
- 支持多种平台

常用显示过滤规则：
- ip.addr == 192.168.1.1  → 特定 IP
- tcp.port == 4444         → 特定端口
- http                      → HTTP 协议
- dns                       → DNS 协议
- http.request.method == "POST" → HTTP POST
- http contains "User-Agent"   → 包含特定字符串
- tcp.flags.reset == 1      → RST 标志

分析恶意软件流量的步骤：
1. 确定恶意进程的 PID 和端口
2. 过滤相关流量
3. 分析 HTTP 请求（URL、方法、头部、内容）
4. 分析 DNS 查询（域名、频率）
5. 分析加密流量（证书、JA3 指纹）
6. 提取 C2 通信特征
```

**Regshot**

```
Regshot 是一款注册表和文件系统对比工具。

主要功能：
- 拍摄注册表快照
- 拍摄文件系统快照
- 对比两个快照的差异
- 生成差异报告

使用方法：
1. 运行 Regshot，点击 "1st Shot" 拍摄第一张快照
2. 运行恶意软件，等待其执行完成
3. 点击 "2nd Shot" 拍摄第二张快照
4. 点击 "Compare" 对比差异
5. 查看报告（注册表变化、文件变化）

分析重点：
1. 新增的注册表启动项
2. 新增的服务和驱动
3. 新增的文件（特别是系统目录、启动目录）
4. 修改的系统配置
5. 删除的文件（如卷影副本）
```

## 🛠️ 补充：实战拓展

### 一、静态分析命令速查表

#### 文件类型与基本信息

```bash
# ===== 文件类型识别 =====
file sample.exe                    # 识别文件类型（PE/ELF/Mach-O等）
file sample.bin
# 详细输出
file -k sample.exe                 # 保持匹配，不停止在第一个结果

# ===== PE 文件信息（Windows）=====
# 查看PE头信息
dumpbin /headers sample.exe        # VS自带工具
# 或使用 peview 图形化工具

# 使用 Python pefile 库
# pip install pefile
python3 -c "import pefile; pe = pefile.PE('sample.exe'); print(pe.FILE_HEADER.Machine); print(pe.OPTIONAL_HEADER.AddressOfEntryPoint)"

# ===== 计算文件哈希 =====
md5sum sample.exe
sha256sum sample.exe
sha1sum sample.exe
# 或
openssl dgst -sha256 sample.exe

# ===== 查看文件大小与时间戳 =====
ls -la sample.exe
stat sample.exe
# Windows
dir sample.exe
Get-Item sample.exe | Format-List *

# ===== 字符串提取 =====
# Linux/Unix
strings sample.exe                 # 提取可打印字符串
strings -n 8 sample.exe            # 至少8个字符（减少噪音）
strings -a sample.exe              # 扫描整个文件（默认只扫描数据段）
strings -t x sample.exe            # 显示偏移（十六进制）

# Windows (Sysinternals Strings)
strings64.exe -a -n 8 sample.exe
strings64.exe -o sample.exe        # 显示偏移

# ===== 提取特定类型字符串 =====
# 只看URL
strings sample.exe | grep -i "http\|https\|ftp\|www\."
# 只看IP地址
strings sample.exe | grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}"
# 只看注册表路径
strings sample.exe | grep -i "HKLM\|HKCU\|HKEY_"
# 只看文件名
strings sample.exe | grep -i "\.exe\|\.dll\|\.sys\|\.bat"

# ===== 熵值分析（判断是否加壳/加密）=====
# 使用 ent 工具
ent sample.exe
# 高熵值（接近8.0）通常表示加壳或加密

# 使用 Python 计算
python3 -c "
import math
with open('sample.exe', 'rb') as f:
    data = f.read()
freq = [0]*256
for b in data:
    freq[b] += 1
entropy = 0
for count in freq:
    if count > 0:
        p = count / len(data)
        entropy -= p * math.log2(p)
print(f'熵值: {entropy:.4f}')
print(f'文件大小: {len(data)} 字节')
"
```

#### 加壳识别与脱壳

```bash
# ===== 查壳工具 =====
# Detect It Easy (DIE) - 图形化/命令行
diec sample.exe                    # 命令行版本
die sample.exe                     # 打开图形界面

# PEiD - 经典查壳工具（Windows）
# 有大量签名库，但更新较慢

# Exeinfo PE - 另一个查壳工具

# ===== 使用 PEiD 签名手动判断 =====
# 查看入口点附近的代码特征
# UPX 壳特征:
#   - 节区名: UPX0, UPX1
#   - 入口点在最后一个节
#   - 第一个节区RAW大小为0

# ===== 查看节区信息 =====
# Linux
objdump -h sample.exe 2>/dev/null  # 需要支持PE的objdump
readelf -S sample.elf              # ELF文件

# Python pefile
python3 -c "
import pefile
pe = pefile.PE('sample.exe')
for section in pe.sections:
    name = section.Name.decode().rstrip('\x00')
    print(f'{name:10} VA: 0x{section.VirtualAddress:08x} RawSize: {section.SizeOfRawData:8d} Char: 0x{section.Characteristics:08x}')
"

# ===== UPX 脱壳 =====
# 标准UPX壳
upx -d sample.exe -o unpacked.exe  # 脱壳
upx -l sample.exe                  # 检查是否是UPX压缩

# 手动脱壳（通用方法）:
# 1. 用x64dbg加载程序
# 2. 在入口点下断点
# 3. 运行到OEP（原始入口点）
# 4. 使用Scylla插件转储并修复IAT
```

#### 导入表与导出表分析

```bash
# ===== 查看导入表 =====
# Windows dumpbin
dumpbin /imports sample.exe

# Dependency Walker (depends.exe) - 经典图形化工具

# Python pefile
python3 -c "
import pefile
pe = pefile.PE('sample.exe')
pe.parse_data_directories()
for entry in pe.DIRECTORY_ENTRY_IMPORT:
    print(f'[DLL] {entry.dll.decode()}')
    for imp in entry.imports:
        if imp.name:
            print(f'  {imp.name.decode()}')
        else:
            print(f'  Ordinal: {imp.ordinal}')
"

# ===== 查看导出表 =====
dumpbin /exports sample.dll

python3 -c "
import pefile
pe = pefile.PE('sample.dll')
pe.parse_data_directories()
if hasattr(pe, 'DIRECTORY_ENTRY_EXPORT'):
    for exp in pe.DIRECTORY_ENTRY_EXPORT.symbols:
        print(f'  {exp.ordinal:4d}  0x{exp.address:08x}  {exp.name.decode() if exp.name else \"N/A\"}')
"

# ===== 可疑导入函数快速判断 =====
# 文件操作: CreateFile, WriteFile, ReadFile, DeleteFile
# 进程操作: CreateProcess, OpenProcess, WriteProcessMemory, VirtualAllocEx
# 注册表操作: RegOpenKey, RegSetValue, RegCreateKey
# 网络操作: socket, connect, send, recv, InternetOpen
# 服务操作: CreateService, OpenSCManager
# 钩子操作: SetWindowsHookEx, SetWinEventHook
# 注入操作: CreateRemoteThread, QueueUserAPC
# 反调试: IsDebuggerPresent, CheckRemoteDebuggerPresent
```

### 二、动态分析命令速查表

#### 进程与系统监控

```bash
# ===== 进程监控 =====
# Windows 任务管理器 - 基础查看
tasklist /v                         # 命令行进程列表
tasklist /m                         # 进程加载的DLL
Get-Process -IncludeUserName        # PowerShell含用户名

# Process Explorer (Sysinternals) - 增强任务管理器
procexp.exe
# 常用功能:
# - Ctrl+D: 查看进程DLL
# - Ctrl+H: 查看进程句柄
# - 右键 -> Verify Signatures: 验证签名
# - 右键 -> Kill Process Tree: 杀进程树

# ===== 系统行为监控 =====
# Process Monitor (Sysinternals) - 最核心工具
procmon.exe
# 常用过滤:
# - Process Name is sample.exe → 只看目标进程
# - Operation is WriteFile → 只看文件写入
# - Path contains HKCU → 只看注册表操作
# - Result is NAME NOT FOUND → 查找缺失文件/DLL

# 常用技巧:
# - Ctrl+L: 打开过滤对话框
# - Ctrl+X: 清除显示
# - File -> Capture Events (Ctrl+E): 暂停/开始捕获
# - Tools -> Process Tree: 查看进程树
# - File -> Save: 保存日志(PML格式)

# ===== 注册表对比 =====
# Regshot
regshot.exe
```

```python
#!/usr/bin/env python3
# PE 文件快速分析脚本
# pip install pefile

import pefile
import hashlib
import os
import sys
import math

def get_file_hashes(filepath):
    """计算文件MD5/SHA1/SHA256"""
    md5 = hashlib.md5()
    sha1 = hashlib.sha1()
    sha256 = hashlib.sha256()
    
    with open(filepath, 'rb') as f:
        while chunk := f.read(8192):
            md5.update(chunk)
            sha1.update(chunk)
            sha256.update(chunk)
    
    return {
        'md5': md5.hexdigest(),
        'sha1': sha1.hexdigest(),
        'sha256': sha256.hexdigest()
    }

def calculate_entropy(data):
    """计算数据熵值"""
    if not data:
        return 0.0
    freq = [0] * 256
    for b in data:
        freq[b] += 1
    entropy = 0.0
    length = len(data)
    for count in freq:
        if count > 0:
            p = count / length
            entropy -= p * math.log2(p)
    return entropy

def analyze_pe(filepath):
    """分析PE文件"""
    print("=" * 60)
    print(f"PE 文件分析: {os.path.basename(filepath)}")
    print("=" * 60)
    
    # 基本信息
    file_size = os.path.getsize(filepath)
    print(f"\n[文件信息]")
    print(f"  文件大小: {file_size} 字节 ({file_size/1024:.2f} KB)")
    
    hashes = get_file_hashes(filepath)
    print(f"  MD5:      {hashes['md5']}")
    print(f"  SHA-1:    {hashes['sha1']}")
    print(f"  SHA-256:  {hashes['sha256']}")
    
    # 计算整体熵值
    with open(filepath, 'rb') as f:
        data = f.read()
    entropy = calculate_entropy(data)
    print(f"  文件熵值: {entropy:.4f} {'(可能加壳)' if entropy > 7.0 else ''}")
    
    try:
        pe = pefile.PE(filepath)
    except Exception as e:
        print(f"\n[错误] 不是有效的PE文件: {e}")
        return
    
    # PE头信息
    print(f"\n[PE头信息]")
    machine = pe.FILE_HEADER.Machine
    machine_str = "x86" if machine == 0x14c else "x64" if machine == 0x8664 else f"0x{machine:04x}"
    print(f"  架构: {machine_str}")
    print(f"  节区数: {pe.FILE_HEADER.NumberOfSections}")
    print(f"  时间戳: {pe.FILE_HEADER.TimeDateStamp}")
    
    # 入口点
    oep = pe.OPTIONAL_HEADER.AddressOfEntryPoint
    image_base = pe.OPTIONAL_HEADER.ImageBase
    print(f"  入口点(VA): 0x{oep:08x}")
    print(f"  镜像基址: 0x{image_base:08x}")
    
    # 节区分析
    print(f"\n[节区信息]")
    print(f"  {'名称':10} {'虚拟地址':>10} {'虚拟大小':>10} {'原始大小':>10} {'熵值':>7} {'特征':>10}")
    print("  " + "-" * 65)
    
    for section in pe.sections:
        name = section.Name.decode().rstrip('\x00')
        va = f"0x{section.VirtualAddress:08x}"
        vsize = section.Misc_VirtualSize
        rsize = section.SizeOfRawData
        
        # 计算节区熵值
        section_data = section.get_data()
        sec_entropy = calculate_entropy(section_data)
        
        # 特征标记
        chars = []
        if section.Characteristics & 0x20: chars.append("代码")
        if section.Characteristics & 0x40: chars.append("数据")
        if section.Characteristics & 0x80000000: chars.append("可写")
        if section.Name.startswith(b"UPX"): chars.append("UPX壳")
        if sec_entropy > 7.5: chars.append("高熵")
        
        print(f"  {name:10} {va:>10} {vsize:>10d} {rsize:>10d} {sec_entropy:>7.3f} {','.join(chars):>10}")
    
    # 导入表分析
    print(f"\n[导入表]")
    pe.parse_data_directories()
    
    if hasattr(pe, 'DIRECTORY_ENTRY_IMPORT'):
        suspicious_imports = []
        total_imports = 0
        
        for entry in pe.DIRECTORY_ENTRY_IMPORT:
            dll_name = entry.dll.decode()
            func_count = len(entry.imports)
            total_imports += func_count
            print(f"\n  DLL: {dll_name} ({func_count}个函数)")
            
            for imp in entry.imports[:10]:  # 只显示前10个
                if imp.name:
                    func_name = imp.name.decode()
                    print(f"    - {func_name}")
                    
                    # 标记可疑函数
                    suspicious_keywords = [
                        'VirtualAlloc', 'WriteProcessMemory', 'CreateRemoteThread',
                        'SetWindowsHook', 'IsDebuggerPresent', 'CheckRemoteDebugger',
                        'InternetOpen', 'HttpSendRequest', 'socket', 'connect',
                        'RegSetValue', 'CreateService', 'StartService',
                        'WinExec', 'ShellExecute', 'CreateProcess',
                        'GetAsyncKeyState', 'SetWindowsHookEx'
                    ]
                    for kw in suspicious_keywords:
                        if kw.lower() in func_name.lower():
                            suspicious_imports.append(f"{dll_name}!{func_name}")
                            break
            
            if func_count > 10:
                print(f"    ... 还有 {func_count - 10} 个函数")
        
        print(f"\n  导入函数总数: {total_imports}")
        if suspicious_imports:
            print(f"  [警告] 发现 {len(suspicious_imports)} 个可疑导入函数:")
            for s in suspicious_imports[:10]:
                print(f"    - {s}")
    else:
        print("  无导入表（可能是纯资源DLL或加壳）")
    
    # 导出表分析
    if hasattr(pe, 'DIRECTORY_ENTRY_EXPORT'):
        print(f"\n[导出表]")
        exports = pe.DIRECTORY_ENTRY_EXPORT.symbols
        print(f"  导出函数数量: {len(exports)}")
        for exp in exports[:15]:  # 只显示前15个
            name = exp.name.decode() if exp.name else f"Ordinal_{exp.ordinal}"
            print(f"    #{exp.ordinal}  0x{exp.address:08x}  {name}")
        if len(exports) > 15:
            print(f"    ... 还有 {len(exports) - 15} 个导出函数")
    
    # 资源分析
    if hasattr(pe, 'DIRECTORY_ENTRY_RESOURCE'):
        print(f"\n[资源]")
        resource_types = {}
        for entry in pe.DIRECTORY_ENTRY_RESOURCE.entries:
            type_id = entry.id
            type_name = pefile.RESOURCE_TYPE.get(type_id, f"Type_{type_id}")
            count = len(entry.directory.entries) if hasattr(entry.directory, 'entries') else 1
            resource_types[type_name] = resource_types.get(type_name, 0) + count
        
        for rtype, count in resource_types.items():
            print(f"  {rtype}: {count}个")
    
    pe.close()
    print("\n[分析完成]")

if __name__ == "__main__":
    if len(sys.argv) != 2:
        print(f"用法: {sys.argv[0]} <pe_file>")
        sys.exit(1)
    
    analyze_pe(sys.argv[1])
```

#### 字符串与IOC提取脚本

```python
#!/usr/bin/env python3
# 恶意样本IOC提取脚本
# 提取URL、IP、域名、注册表路径、文件名等IOC

import re
import sys
import hashlib

def extract_urls(text):
    """提取URL"""
    url_pattern = re.compile(
        r'https?://[^\s<>"\']+|ftp://[^\s<>"\']+|www\.[^\s<>"\']+',
        re.IGNORECASE
    )
    return list(set(url_pattern.findall(text)))

def extract_ips(text):
    """提取IPv4地址"""
    ip_pattern = re.compile(r'\b(?:\d{1,3}\.){3}\d{1,3}\b')
    ips = ip_pattern.findall(text)
    # 过滤掉明显不是IP的（如版本号）
    valid_ips = []
    for ip in ips:
        parts = ip.split('.')
        if all(0 <= int(p) <= 255 for p in parts):
            # 排除私有IP和广播地址（可选）
            valid_ips.append(ip)
    return list(set(valid_ips))

def extract_domains(text):
    """提取域名（简单匹配）"""
    domain_pattern = re.compile(
        r'\b(?:[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?\.)+[a-zA-Z]{2,}\b',
        re.IGNORECASE
    )
    domains = domain_pattern.findall(text)
    # 排除一些常见的误报
    exclude = ['microsoft.com', 'windows.com', 'google.com']
    return list(set(d for d in domains if d.lower() not in exclude))

def extract_registry_paths(text):
    """提取注册表路径"""
    reg_pattern = re.compile(
        r'(?:HKLM|HKCU|HKCR|HKU|HKCC|HKEY_LOCAL_MACHINE|HKEY_CURRENT_USER|HKEY_CLASSES_ROOT)[\\][^\s<>"\'{}|]+',
        re.IGNORECASE
    )
    return list(set(reg_pattern.findall(text)))

def extract_file_paths(text):
    """提取文件路径（Windows风格）"""
    path_pattern = re.compile(
        r'[A-Za-z]:\\[^\s<>"\'|?*[\]]+(?:\.[A-Za-z0-9]+)?',
        re.IGNORECASE
    )
    return list(set(path_pattern.findall(text)))

def extract_mutexes(text):
    """提取可能的互斥体名"""
    # 常见互斥体命名模式（启发式）
    mutex_patterns = [
        r'Mutex_\w+',
        r'Global\\[\w{}]+',
        r'Local\\[\w{}]+',
    ]
    mutexes = []
    for pattern in mutex_patterns:
        mutexes.extend(re.findall(pattern, text))
    return list(set(mutexes))

def analyze_sample(filepath):
    """分析样本文件，提取IOC"""
    print("=" * 60)
    print("恶意样本 IOC 提取工具")
    print("=" * 60)
    
    # 读取文件（作为文本和二进制）
    with open(filepath, 'rb') as f:
        binary_data = f.read()
    
    # 提取可打印字符串（模拟 strings 命令）
    strings_list = []
    current = []
    for byte in binary_data:
        if 32 <= byte <= 126:  # 可打印ASCII
            current.append(chr(byte))
        else:
            if len(current) >= 5:  # 至少5个字符
                strings_list.append(''.join(current))
            current = []
    if len(current) >= 5:
        strings_list.append(''.join(current))
    
    text = '\n'.join(strings_list)
    
    # 文件哈希
    print(f"\n[文件哈希]")
    print(f"  MD5:    {hashlib.md5(binary_data).hexdigest()}")
    print(f"  SHA-1:  {hashlib.sha1(binary_data).hexdigest()}")
    print(f"  SHA-256:{hashlib.sha256(binary_data).hexdigest()}")
    
    # 提取各类IOC
    urls = extract_urls(text)
    ips = extract_ips(text)
    domains = extract_domains(text)
    registry_paths = extract_registry_paths(text)
    file_paths = extract_file_paths(text)
    mutexes = extract_mutexes(text)
    
    print(f"\n[提取结果]")
    print(f"  URL数量:              {len(urls)}")
    print(f"  IP地址数量:           {len(ips)}")
    print(f"  域名数量:             {len(domains)}")
    print(f"  注册表路径数量:       {len(registry_paths)}")
    print(f"  文件路径数量:         {len(file_paths)}")
    print(f"  可能的互斥体数量:     {len(mutexes)}")
    
    # 输出URL
    if urls:
        print(f"\n[URL列表]")
        for url in sorted(urls)[:20]:
            print(f"  {url}")
        if len(urls) > 20:
            print(f"  ... 还有 {len(urls) - 20} 个")
    
    # 输出IP
    if ips:
        print(f"\n[IP地址列表]")
        for ip in sorted(ips)[:20]:
            print(f"  {ip}")
        if len(ips) > 20:
            print(f"  ... 还有 {len(ips) - 20} 个")
    
    # 输出可疑域名
    if domains:
        print(f"\n[域名列表]")
        for domain in sorted(domains)[:20]:
            print(f"  {domain}")
        if len(domains) > 20:
            print(f"  ... 还有 {len(domains) - 20} 个")
    
    # 输出注册表路径
    if registry_paths:
        print(f"\n[注册表路径列表]")
        for reg in sorted(registry_paths)[:20]:
            print(f"  {reg}")
        if len(registry_paths) > 20:
            print(f"  ... 还有 {len(registry_paths) - 20} 个")
    
    # 输出互斥体
    if mutexes:
        print(f"\n[互斥体列表]")
        for m in sorted(mutexes)[:15]:
            print(f"  {m}")
        if len(mutexes) > 15:
            print(f"  ... 还有 {len(mutexes) - 15} 个")
    
    print(f"\n[提取完成]")
    print(f"  共提取 {len(strings_list)} 个字符串")

if __name__ == "__main__":
    if len(sys.argv) != 2:
        print(f"用法: {sys.argv[0]} <sample_file>")
        sys.exit(1)
    
    analyze_sample(sys.argv[1])
```
