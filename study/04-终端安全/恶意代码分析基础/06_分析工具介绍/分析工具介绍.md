# 分析工具介绍

### 6.1 静态分析工具

**IDA Pro**

```
IDA Pro 是业界最强大的反汇编和反编译工具，被广泛用于恶意代码分析、漏洞研究和软件逆向工程。

主要功能：
- 交互式反汇编器
- 强大的反编译器（Hex-Rays Decompiler）
- 跨平台分析（x86、x64、ARM、MIPS 等）
- 支持多种文件格式（PE、ELF、Mach-O 等）
- 丰富的插件生态系统
- 脚本支持（IDC、Python）

常用功能：
1. 反汇编视图（图形视图和文本视图）
2. 反编译视图（F5 伪代码）
3. 字符串搜索（Shift+F12）
4. 导入/导出函数分析
5. 交叉引用（Xrefs）
6. 结构体定义和识别
7. 类型分析和重建
8. 动态调试（配合调试器）

常用快捷键：
- F5：反编译
- Space：切换图形/文本视图
- G：跳转到地址
- X：查看交叉引用
- N：重命名
- ;：添加注释
- Shift+F12：字符串窗口
- Ctrl+S：查看段列表
```

**Ghidra**

```
Ghidra 是美国国家安全局（NSA）开源的逆向工程工具，
功能接近 IDA Pro，且完全免费。

主要功能：
- 反汇编和反编译
- 支持多种架构和文件格式
- 内置 Python 脚本支持
- 协作分析功能
- 丰富的插件系统
- 完全免费开源

与 IDA Pro 比较：
- 优点：免费、开源、持续更新
- 缺点：界面较复杂、学习曲线陡、插件生态不如 IDA 丰富

适用场景：
- 预算有限的个人和团队
- 需要大规模自动化分析
- 需要定制化逆向工具
```

**Detect It Easy (DIE)**

```
Detect It Easy 是一款功能强大的查壳工具，
用于识别文件类型、加壳器、编译器等。

主要功能：
- 识别 PE、ELF、Mach-O 等文件格式
- 识别 500+ 种加壳器和编译器
- 熵值分析
- 入口点签名识别
- 节区分析
- 资源分析
- 支持 x86/x64/ARM 等多种架构
- 内置签名编辑器

使用场景：
1. 快速判断文件类型和是否加壳
2. 识别加壳器类型，选择脱壳方法
3. 识别编译器类型，辅助分析
4. 批量分析文件
```

**PE Studio**

```
PE Studio 是一款 PE 文件静态分析工具，
专注于恶意代码初步分析。

主要功能：
- PE 文件头分析
- 节区分析
- 导入表分析（标记可疑函数）
- 字符串分析
- 资源分析
- 数字签名验证
- VirusTotal 集成
- 恶意软件指标检测

特点：
- 自动标记可疑的导入函数和字符串
- 提供"恶意软件指标"评分
- 快速生成分析报告
- 适合批量快速分析
```

**CFF Explorer**

```
CFF Explorer 是一款功能全面的 PE 文件编辑器和分析工具。

主要功能：
- PE 文件结构查看和编辑
- 资源查看和编辑
- 导入/导出表查看和编辑
- 地址转换器
- 反汇编器
- 签名计算和验证
- 扫描 PE 文件中的 UPX 壳
- PE 重建和修复

使用场景：
1. PE 文件结构分析
2. 修改 PE 文件（节区、导入表等）
3. 修复损坏的 PE 文件
4. 资源提取和编辑
```

### 6.2 动态分析工具

**x64dbg**

```
x64dbg 是一款开源的 Windows 调试器，支持 x32 和 x64。

主要功能：
- 动态调试（步过、步入、执行到光标等）
- 断点（软件断点、硬件断点、内存断点）
- 内存查看和编辑
- 寄存器查看和编辑
- 堆栈查看
- 反汇编视图
- 反编译（Snowman 插件）
- 脚本支持
- 丰富的插件系统

常用插件：
1. Scylla：转储和 IAT 修复（脱壳必备）
2. xAnalyzer：高级分析插件
3. Snowman：反编译器
4. x64dbgpy：Python 脚本支持
5. OllyDumpEx：转储进程内存

常用快捷键：
- F9：运行
- F8：步过
- F7：步入
- F2：切换断点
- Ctrl+G：跳转到表达式
- Ctrl+F9：执行到返回
- Alt+F9：执行到用户代码
```

**Process Monitor**

```
Process Monitor 是 Sysinternals 工具集中的核心工具，
实时监控进程的文件系统、注册表、网络和进程操作。

主要功能：
- 实时监控文件系统操作
- 实时监控注册表操作
- 实时监控网络操作
- 实时监控进程/线程操作
- 强大的过滤和搜索功能
- 启动时监控（Boot Logging）
- 保存和加载日志

常用过滤技巧：
1. 按进程名过滤：只关注特定进程
2. 按操作类型过滤：只看文件写入或注册表修改
3. 按路径过滤：只关注特定目录或注册表键
4. 排除系统进程：减少噪音
5. 突出显示（Highlight）：标记重要操作

分析流程：
1. 启动 ProcMon，开始捕获
2. 运行恶意程序
3. 等待恶意程序执行关键操作
4. 停止捕获
5. 设置过滤，逐步分析
```

**Process Explorer**

```
Process Explorer 是增强版的任务管理器。

主要功能：
- 进程树视图
- 查看进程加载的 DLL
- 查看进程打开的句柄
- 验证数字签名
- 替换任务管理器
- 查看进程网络连接
- 查看 CPU/内存/IO 使用情况
- 挂起/恢复/终止进程

分析用途：
1. 发现可疑进程（路径、签名、父进程）
2. 检测 DLL 注入（异常 DLL 路径）
3. 检查进程打开的文件和注册表键
4. 验证进程签名
5. 查看进程的 TCP/UDP 连接
```

**Wireshark**

```
Wireshark 是最流行的网络协议分析器。

主要功能：
- 实时抓包和离线分析
- 支持 2000+ 种网络协议
- 强大的过滤功能
- 流重组（TCP Stream、HTTP Stream）
- 多种统计功能
- 支持多种平台

常用显示过滤规则：
- ip.addr == 192.168.1.1  → 特定 IP
- tcp.port == 4444         → 特定端口
- http                      → HTTP 协议
- dns                       → DNS 协议
- http.request.method == "POST" → HTTP POST
- http contains "User-Agent"   → 包含特定字符串
- tcp.flags.reset == 1      → RST 标志

分析恶意软件流量的步骤：
1. 确定恶意进程的 PID 和端口
2. 过滤相关流量
3. 分析 HTTP 请求（URL、方法、头部、内容）
4. 分析 DNS 查询（域名、频率）
5. 分析加密流量（证书、JA3 指纹）
6. 提取 C2 通信特征
```

**Regshot**

```
Regshot 是一款注册表和文件系统对比工具。

主要功能：
- 拍摄注册表快照
- 拍摄文件系统快照
- 对比两个快照的差异
- 生成差异报告

使用方法：
1. 运行 Regshot，点击 "1st Shot" 拍摄第一张快照
2. 运行恶意软件，等待其执行完成
3. 点击 "2nd Shot" 拍摄第二张快照
4. 点击 "Compare" 对比差异
5. 查看报告（注册表变化、文件变化）

分析重点：
1. 新增的注册表启动项
2. 新增的服务和驱动
3. 新增的文件（特别是系统目录、启动目录）
4. 修改的系统配置
5. 删除的文件（如卷影副本）
```

### 6.3 沙箱和自动化分析

**Cuckoo Sandbox**

```
Cuckoo Sandbox 是最流行的开源自动化恶意软件分析系统。

主要功能：
- 支持多种文件类型（EXE、DLL、PDF、Office、脚本等）
- 自动行为分析
- 生成详细的 HTML 报告
- 网络流量捕获和分析
- 截图和内存转储
- 支持自定义分析模块
- REST API 接口
- 分布式部署支持

分析报告内容：
1. 文件信息（哈希、类型、大小）
2. 静态分析结果
3. 进程行为（创建、终止、注入）
4. 文件操作（创建、修改、删除）
5. 注册表操作
6. 网络行为（DNS、HTTP、TCP/UDP）
7. 互斥体
8. 行为签名匹配
9. 截图
10. 导出的 IOC
```

**ANY.RUN**

```
ANY.RUN 是一款交互式在线沙箱服务。

主要特点：
- 交互式操作：可以像远程桌面一样操作虚拟机
- 实时监控：实时查看进程、网络、文件操作
- 支持多种文件类型
- 自动生成分析报告
- 威胁情报集成
- 团队协作功能

优势：
1. 可以手动触发恶意代码的各种行为
2. 实时查看分析过程
3. 操作简单，不需要自己搭建环境
4. 大量公开样本可以参考

劣势：
1. 付费服务（有免费额度）
2. 样本会被公开（私有实例除外）
3. 定制化程度有限
```

**VirusTotal**

```
VirusTotal 是一个在线的多引擎病毒扫描服务。

主要功能：
- 70+ 款杀毒引擎扫描
- 文件元数据分析
- 动态分析（沙箱）
- URL 扫描
- IP 地址和域名分析
- 威胁情报
- API 接口（公开/私有）

分析文件时可查看：
1. 多引擎检测结果（检测率、检测名称）
2. 文件详情（哈希、大小、类型、版本信息）
3. 关系图（文件、IP、域名关联）
4. 社区评论
5. 行为分析（沙箱结果）
6. 详细报告

注意事项：
- 上传的文件会被共享给安全社区
- 敏感或机密文件不要上传
- 免费 API 有速率限制
```

### 6.4 其他实用工具

**Sysinternals 工具集**

```
Sysinternals 是微软提供的一套 Windows 系统工具，
对于恶意代码分析和应急响应非常有用。

核心工具：
1. Process Explorer - 增强型任务管理器
2. Process Monitor - 进程监控
3. Autoruns - 启动项管理
4. PsTools - 远程管理工具集
   - PsExec：远程执行命令
   - PsList：远程进程列表
   - PsService：远程服务管理
5. TCPView - 网络连接查看
6. Tcpvcon - 命令行版 TCPView
7. Handle - 查看进程打开的句柄
8. ListDLLs - 查看进程加载的 DLL
9. Strings - 提取字符串
10. Sigcheck - 签名验证
11. VMMap - 虚拟内存分析
12. RamMap - 物理内存分析
13. Autoruns - 启动项全面检查
```

**Autoruns**

```
Autoruns 是最全面的启动项检查工具。

可检查的启动位置：
1. 启动文件夹（当前用户和所有用户）
2. 注册表 Run / RunOnce / RunOnceEx
3. 计划任务
4. 服务
5. 驱动
6. Winlogon 通知
7. AppInit_DLLs
8. 映像劫持（IFEO）
9. 已知 DLL
10. WinSock 提供商
11. 打印监视器
12. LSA 安全提供程序
13. 网络提供程序
14. WMI 事件订阅
15. 浏览器扩展和 BHO
16. Office 插件
17. 编解码器
18. Sidebar 小工具

使用技巧：
- 勾选 "Hide Microsoft Entries" 隐藏微软签名的项
- 黄色 = 条目存在但文件找不到
- 红色 = 无发布者/无签名的启动项
- 绿色 = 最近新增的项
```
