# Linux 安全加固脚本说明

> 详细的加固脚本请参考 `linux_hardening.sh` 文件。以下是脚本的主要功能说明。

### 脚本功能概述

**1. 系统更新**
- 更新系统软件包
- 配置自动安全更新

**2. 账户安全**
- 配置密码策略（长度、复杂度、有效期）
- 配置账户锁定策略
- 禁用不必要的系统账户
- 禁用 root SSH 登录

**3. SSH 安全**
- 禁用 root 远程登录
- 禁用密码认证（建议启用密钥后）
- 修改默认 SSH 端口（可选）
- 配置空闲超时
- 限制最大认证尝试次数

**4. 防火墙配置**
- 配置 iptables/ufw 防火墙
- 默认入站拒绝
- 允许必要的服务端口
- 防止常见攻击（SYN Flood 等）

**5. 文件权限加固**
- 设置关键配置文件权限
- 查找并修复危险的 SUID/SGID 文件
- 设置 umask

**6. 审计配置**
- 安装和配置 auditd
- 配置关键文件和操作的审计规则
- 配置日志轮转

**7. 内核参数加固**
- 网络安全参数（防止 IP 欺骗、SYN Flood）
- 内存安全参数
- 禁用不必要的内核模块
- 启用 ASLR

**8. 服务加固**
- 禁用不必要的服务
- 配置服务最小权限

**9. 安全工具安装**
- 安装 fail2ban（防止暴力破解）
- 安装 rkhunter/chkrootkit（Rootkit 检测）
- 安装 AIDE（文件完整性检查）

---

> 💡 **Linux 安全是一个持续的过程。定期审计、持续监控、及时更新补丁，才能有效保障系统安全。**
