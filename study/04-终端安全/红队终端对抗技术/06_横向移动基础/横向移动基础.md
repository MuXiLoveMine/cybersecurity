# 横向移动基础

### 6.1 Pass-the-Hash（PTH）

PTH 利用 NTLM 认证协议的设计特性：认证过程中使用 NTLM Hash 而非明文密码。攻击者获取用户 NTLM Hash 后，可直接构造 NTLM 认证请求访问该用户有权限的资源，无需破解密码。典型工具思路为 `psexec -hashes <LM:NT>` 或 `crackmapexec smb --hashes`。

### 6.2 Pass-the-Ticket（PTT）

PTT 利用 Kerberos 票据机制：Kerberos 认证依赖 TGT（票据授予票据）和 ST（服务票据），票据本身即为访问凭据。攻击者注入窃取的 TGT/ST 到当前会话票据缓存中，随后以票据所有者身份访问对应服务。典型操作为 `klist` 管理票据缓存、Rubeus `ptt` 注入。

### 6.3 Overpass-the-Hash

Overpass-the-Hash（Pass-the-Key）使用 NTLM Hash 向 KDC 请求 TGT，然后使用 TGT 进行 Kerberos 认证。场景：在无法直接 PTH 但可获取 TGT 的情况下，将 NTLM Hash 转换为 Kerberos TGT 以获得更强的认证能力。

### 6.4 远程执行技术

| 协议/工具 | 端口 | 说明 |
|-----------|------|------|
| WMI | 135（DCE/RPC） | 通过 `Win32_Process.Create` 远程创建进程 |
| WinRM | 5985（HTTP）/5986（HTTPS） | PowerShell Remoting 底层协议 |
| SMB | 445 | 通过 `IPC$` 共享执行远程命令 |
| DCOM | 135 | 通过 `MMC20.Application` 等 DCOM 对象远程执行 |

### 6.5 PsExec/WMIC/DCOM 利用

- **PsExec**：通过 SMB 在远程主机创建临时服务执行命令，完成后删除服务。特征为 SYSTEM 临时服务创建和服务删除行为
- **WMIC**：`wmic /node:target process call create "cmd"` 远程创建进程，依赖于 WMI 服务和 135 端口
- **DCOM**：利用 `DCOM` 分布式组件对象模型远程激活 COM 对象，如通过 `MMC20.Application` 的 `ExecuteShellCommand` 方法远程执行命令
