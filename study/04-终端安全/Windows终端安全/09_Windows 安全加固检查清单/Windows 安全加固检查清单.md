# Windows 安全加固检查清单

### 9.1 系统更新

- [ ] 启用 Windows Update 自动更新
- [ ] 安装所有关键和安全更新
- [ ] 定期检查补丁状态
- [ ] 建立补丁管理流程
- [ ] 测试补丁后再部署到生产环境

### 9.2 账户安全

- [ ] 启用密码复杂性要求
- [ ] 设置密码最小长度（至少 14 位）
- [ ] 配置密码历史记录（至少 24 个）
- [ ] 设置密码最长使用期限（90 天）
- [ ] 启用账户锁定策略（5 次失败锁定 30 分钟）
- [ ] 禁用 Guest 账户
- [ ] 重命名 Administrator 账户
- [ ] 限制本地管理员组成员
- [ ] 禁用不需要的用户账户

### 9.3 审核与日志

- [ ] 启用安全审核策略
- [ ] 启用进程创建审核（含命令行）
- [ ] 启用登录/注销审核
- [ ] 启用账户管理审核
- [ ] 启用对象访问审核（关键文件/注册表）
- [ ] 启用特权使用审核
- [ ] 配置日志大小（至少 1GB 安全日志）
- [ ] 配置日志保留策略
- [ ] 配置集中日志收集（SIEM）
- [ ] 启用 PowerShell 模块日志和脚本块日志

### 9.4 网络安全

- [ ] 启用 Windows Defender 防火墙
- [ ] 默认入站策略设为阻止
- [ ] 关闭不必要的端口和服务
- [ ] 限制 RDP/SSH/WinRM 的源地址
- [ ] 启用 SMB 签名
- [ ] 禁用 SMBv1
- [ ] 配置网络分段
- [ ] 启用 Windows Defender 应用控制

### 9.5 服务加固

- [ ] 禁用不必要的服务
- [ ] 服务以最小权限运行
- [ ] 定期审查服务配置
- [ ] 验证服务文件完整性
- [ ] 限制服务权限

### 9.6 注册表加固

- [ ] 限制注册表关键键的权限
- [ ] 禁用自动运行（Autorun）
- [ ] 禁用默认共享（ADMIN$、C$）
- [ ] 限制对 SAM 的访问
- [ ] 增强 LSASS 保护（RunAsPPL）
- [ ] 禁用 LM 哈希
- [ ] 限制 NTLM 使用

### 9.7 UAC 配置

- [ ] 启用 UAC
- [ ] 设置 UAC 为最高级别
- [ ] 禁用内置管理员账户的管理员批准模式（视情况）
- [ ] 标准用户提升提示行为：自动拒绝

### 9.8 RDP 安全

- [ ] 启用网络级别身份验证（NLA）
- [ ] 限制具有 RDP 权限的用户
- [ ] 配置防火墙限制 RDP 源地址
- [ ] 使用 RD Gateway 或 VPN 进行远程访问
- [ ] 考虑更改默认端口（次要措施）
- [ ] 启用 RDP 登录审核
- [ ] 配置 RDP TLS 证书

### 9.9 恶意软件防护

- [ ] 启用 Windows Defender
- [ ] 更新病毒定义
- [ ] 启用实时保护
- [ ] 启用云提供的保护
- [ ] 配置定期扫描
- [ ] 启用勒索软件防护（受控文件夹访问）
- [ ] 启用网络保护
- [ ] 启用攻击面减少（ASR）规则

### 9.10 数据保护

- [ ] 启用 BitLocker 加密
- [ ] 配置安全启动
- [ ] 启用基于虚拟化的安全（VBS）
- [ ] 配置关键文件权限
- [ ] 配置共享文件夹权限
- [ ] 实施数据备份策略（3-2-1 原则）

### 9.11 应用安全

- [ ] 卸载不必要的软件
- [ ] 及时更新应用程序
- [ ] 配置 AppLocker 应用控制
- [ ] 禁用 Office 宏（默认禁用）
- [ ] 启用浏览器安全设置
- [ ] 配置 Flash/Java 限制

---

> 💡 **安全加固是一个持续的过程，不是一次性的任务。定期审计、持续监控、及时更新，才能有效保障终端安全。**
