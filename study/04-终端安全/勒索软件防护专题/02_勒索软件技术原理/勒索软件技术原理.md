# 勒索软件技术原理

### 2.1 加密机制分析

**混合加密方案**

```
现代勒索软件采用对称+非对称混合加密：

加密流程详解：

1. 密钥生成阶段
   - 生成随机AES密钥（每文件独立或全局共享）
   - 部分家族使用ChaCha20/Salsa20替代AES
   - 密钥长度：AES-256 / AES-128

2. 文件加密阶段
   - 使用对称密钥（AES/ChaCha20）加密文件内容
   - 对称加密速度快，适合大文件
   - 部分勒索软件只加密文件头部（加速）
   - 部分勒索软件加密全文件

3. 密钥保护阶段
   - 使用攻击者的RSA/ECDH公钥加密对称密钥
   - 加密后的密钥写入文件尾部或单独文件
   - RSA公钥可能硬编码在样本中或从C2获取

4. 不可逆性
   - 只有攻击者拥有RSA私钥
   - 对称密钥被RSA公钥加密后无法恢复
   - 即使分析出加密算法也无法解密

密钥管理方案对比：

方案A（每文件独立密钥）：
  生成AES Key → 加密文件 → RSA公钥加密AES Key → 写入文件
  优点：单个文件解密不影响其他文件
  缺点：性能开销大

方案B（会话密钥+文件密钥）：
  生成会话AES Key → 每文件生成随机IV/Nonce
  会话Key用RSA加密一次 → 每文件用会话Key+IV加密
  优点：性能好
  缺点：会话Key泄露则全部文件可解密

方案C（ECDH密钥协商）：
  生成临时密钥对 → 与硬编码公钥做ECDH协商 → 共享密钥
  优点：前向安全性更强
  使用者：REvil、BlackCat
```

**文件加密流程**

```
典型勒索软件加密执行流程：

1. 发现阶段
   - 遍历磁盘分区和目录
   - 枚举目标文件（文档/图片/数据库/备份）
   - 排除系统关键文件（保证系统可运行以显示勒索信）
   - 排除特定目录（Windows/system32等）

2. 加密阶段
   - 读取文件内容
   - 使用对称密钥加密文件
   - 写入加密后的内容（覆盖原文件或创建新文件）
   - 修改文件扩展名（添加家族特征后缀）
   - 将加密的密钥信息写入文件元数据

3. 勒索信放置
   - 在每个加密的目录放置勒索信
   - 修改桌面背景为勒索说明
   - 部分家族弹出勒索窗口

4. 清理阶段（防御规避）
   - 删除卷影副本（Shadow Copy）
   - 清理事件日志
   - 删除备份软件的备份
   - 终止可能干扰加密的进程（数据库/Office/安全软件）
   - 删除自身样本

常见加密文件后缀示例：
  .lockbit / .conti / .blackcat / .clop / .akira
  .encrypted / .locked / .crypto / .ransom
  家族特定后缀是快速识别家族的重要线索
```

**影子副本删除**

```
勒索软件删除卷影副本以阻止文件恢复：

常用命令：
  vssadmin delete shadows /all /quiet
  wmic shadowcopy delete
  wbadmin delete catalog -quiet
  bcdedit /set {default} recoveryenabled no
  bcdedit /set {default} bootstatuspolicy ignoreallfailures

防御/检测：
  - 监控vssadmin.exe的异常调用（Sysmon Event ID 1）
  - 监控wmic.exe的shadowcopy delete命令
  - 使用Windows事件转发（WEF）集中收集日志
  - 部署honeypot卷影副本（检测删除行为）

Sysmon检测规则示例（Event ID 1）：
  进程名: vssadmin.exe
  命令行包含: "delete shadows"
  → 高危告警
```

**安全模式重启**

```
部分勒索软件强制系统进入安全模式以绕过安全软件：

技术：
- 修改BCD（启动配置数据）进入安全模式
- 安全模式下安全软件通常不启动
- 安全模式下加密效率更高

相关命令：
  bcdedit /set safeboot network
  → 重启后进入安全模式
  → 安全软件不加载
  → 执行加密

案例：Snatch勒索软件使用此技术
```

### 2.2 常见IOC特征

```
勒索软件IOC（妥协指标）分类：

文件扩展名（加密后缀）：
  .lockbit     → LockBit
  .conti      → Conti
  .blackcat    → BlackCat/ALPHV
  .clop        → Cl0p
  .akira      → Akira
  .revil/.sodinokibi → REvil
  .ryuk       → Ryuk
  .encrypted  → 多种家族

勒索信文件名：
  Restore-My-Files.txt → LockBit
  READ_INSTRUCTIONS.txt → Conti
  ransom.txt / HOW_TO_RECOVER.txt → 多种家族
  readme.txt / READ_ME.txt → 多种家族
  HELP_DECRYPT_YOUR_FILES.txt → 多种家族

注册表键：
  HKCU\SOFTWARE\<家族名> → 配置/密钥存储
  HKLM\SYSTEM\CurrentSet\Services\<随机名> → 服务持久化
  修改 HKLM\SOFTWARE\...\Windows Defender → 禁用安全软件

网络通信：
  C2 IP/域名（部分家族从C2获取公钥）
  Tor隐藏服务地址（.onion）
  泄露网站域名（数据发布站点）
  加密货币钱包地址

进程行为：
  vssadmin delete shadows → 删除卷影副本
  bcdedit /set safeboot → 安全模式
  大量文件写入操作（加密）
  大量文件扩展名修改
  短时间内大量文件被修改（加密爆发期）

文件系统变化：
  每个目录出现勒索信文件
  文件扩展名批量变更
  文件内容被加密（高熵值）
  桌面背景被修改
```
