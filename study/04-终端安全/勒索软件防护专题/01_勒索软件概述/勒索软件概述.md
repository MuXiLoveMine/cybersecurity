# 勒索软件概述

### 1.1 勒索软件演进史

```
第一代（1989-2009）：萌芽期
- 1989年AIDS Trojan：首个勒索软件，通过软盘分发，要求邮寄赎金
- 使用简单加密或文件锁定，技术不成熟
- 易于破解，影响有限

第二代（2010-2015）：加密勒索期
- 2009年融合比特币支付通道，解决匿名收款问题
- CryptoLocker（2013）：首次大规模使用RSA+AES加密
- CryptoWall系列：继承和改进CryptoLocker
- 强加密使得无备份情况下几乎无法解密
- 攻击范围从个人扩大到中小企业

第三代（2016-2019）：双重勒索期
- RaaS（勒索软件即服务）模式兴起
- 2019年Maze率先引入"双重勒索"：先窃取数据再加密
  不付赎金则公开泄露数据
- 攻击目标转向企业（更高赎金、更多数据）
- Ryuk、GandCrab、REvil等活跃

第四代（2020-至今）：三重勒索+供应链期
- 三重勒索：加密+数据泄露+DDoS攻击
- 供应链攻击：利用MOVEit、Kaseya等漏洞
- 针对关键基础设施（Colonial Pipeline事件）
- BlackCat/ALPHV用Rust编写，跨平台
- LockBit成为最活跃的RaaS家族

演进趋势总结：
1. 加密算法越来越强（AES+RSA/ECDH混合）
2. 勒索手段从单一加密→数据泄露→DDoS叠加
3. 商业模式从个人开发→RaaS专业化分工
4. 攻击目标从个人→中小企业→大型企业→关键设施
5. 攻击路径从钓鱼邮件→漏洞利用→供应链→RDP暴力破解
```

### 1.2 常见勒索软件家族

| 家族 | 首次出现 | 加密算法 | 特点 |
|------|----------|----------|------|
| CryptoLocker | 2013 | RSA-2048+AES | 首个大规模加密勒索软件 |
| CryptoWall | 2014 | RSA-2048+AES | CryptoLocker继承者 |
| Locky | 2016 | RSA-2048+AES-128 | 钓鱼邮件大规模传播 |
| WannaCry | 2017 | RSA-2048+AES-128 | 利用永恒之蓝（MS17-010）蠕虫式传播 |
| Petya/NotPetya | 2017 | XOR+RSA | 加密MBR，破坏性极强（非Petya实为破坏性wiper） |
| Ryuk | 2018 | RSA-2048+AES-256 | 针对高价值目标，赎金高 |
| GandCrab | 2018 | Salsa20+RSA-2048 | RaaS模式，传播迅速 |
| REvil/Sodinokibi | 2019 | Salsa20+RSA/ECDH | 知名RaaS团伙，双重勒索 |
| Conti | 2020 | ChaCha20+RSA-4096 | 针对医疗/政府，源码泄露 |
| LockBit | 2022 | AES-128-CBC+RSA-2048 | 当前最活跃RaaS，自动化程度高 |
| BlackCat/ALPHV | 2022 | AES-256+RSA-2048 | Rust编写，跨平台，命令行控制 |
| Cl0p | 2023 | 不详 | 利用MOVEit漏洞供应链攻击 |
| Akira | 2023 | ChaCha20+RSA-4096 | 针对VPN漏洞，复古风格 |

### 1.3 勒索软件即服务（RaaS）商业模式

```
RaaS（Ransomware-as-a-Service）将勒索软件运营拆分为两个角色：

开发者（RaaS运营者）：
- 开发和维护勒索软件
- 提供构建器（Builder）生成定制化勒索软件
- 运营泄露网站（Data Leak Site）
- 处理赎金支付和分配
- 提供技术支持和运营手册

附属者（Affiliates）：
- 负责入侵目标企业（初始访问+横向移动）
- 部署勒索软件执行加密
- 谈判和收款
- 不需要开发能力

利益分配：
- 赎金通常按比例分成（常见80%附属者/20%开发者）
- 高价值目标可能调整比例
- 部分RaaS按订阅收费

RaaS提供的工具和服务：
1. 勒索软件构建器（定制加密后缀/勒索信/C2）
2. 管理面板（受害者管理/谈判/状态跟踪）
3. 泄露网站（数据发布/倒计时）
4. 加密货币洗钱通道
5. 解密工具（支付后提供）
6. 运营手册（攻击指南/谈判技巧）

当前活跃的RaaS平台：
- LockBit（最活跃， affiliates众多）
- BlackCat/ALPHV
- Cl0p
- Akira
- Play
- 8Base
```

### 1.4 攻击路径分析

```
勒索软件常见初始入侵路径：

1. 钓鱼邮件（最常见）
   - 恶意附件（Office宏文档/ISO/IMG/ZIP/JS）
   - 恶意链接（仿冒登录页/恶意下载）
   - 鱼叉式定向钓鱼
   - 载荷：→ PowerShell → 下载器 → 勒索软件

2. RDP暴力破解
   - 暴力破解暴露的RDP端口（3389）
   - 凭据泄露后直接RDP登录
   - RDP会话劫持
   - 一旦获得RDP访问→部署勒索软件

3. VPN漏洞利用
   - Fortinet/Pulse/SonicWall等VPN设备漏洞
   - 凭据窃取后VPN接入
   - 未启用MFA的VPN

4. 供应链攻击
   - 利用MSP（托管服务提供商）作为跳板
   - 软件更新通道植入（Kaseya VSA）
   - 第三方软件漏洞（MOVEit Transfer）

5. 公开服务漏洞
   - Web应用漏洞（RCE/SQL注入/SSRF）
   - 邮件服务器漏洞（Exchange ProxyShell/ProxyLogon）
   - 文件服务器漏洞（SMB/FTP）

6. 双重勒索的数据泄露路径
   - ExWare（数据外泄工具）
   - 压缩+加密数据上传到云存储
   - 通过C2隧道传输

攻击链典型路径：
钓鱼邮件 → 宏文档执行 → PowerShell下载器 → Cobalt Strike Beacon
→ 横向移动 + 凭据窃取(Mimikatz) → 域控沦陷 → 部署勒索软件
→ 批量加密 + 数据外泄
```
