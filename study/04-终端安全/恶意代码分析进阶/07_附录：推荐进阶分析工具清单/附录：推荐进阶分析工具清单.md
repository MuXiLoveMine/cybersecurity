# 附录：推荐进阶分析工具清单

| 工具 | 类别 | 说明 |
|------|------|------|
| IDA Pro | 反汇编 | 业界标准反汇编器，支持多架构 |
| Ghidra | 反编译 | NSA开源，支持反编译，免费 |
| x64dbg | 动态调试 | 开源Windows调试器，反反调试插件丰富 |
| Binary Ninja | 反汇编 | 现代化反汇编器，API友好 |
| radare2/rizin | 逆向框架 | 开源命令行逆向框架 |
| Frida | 动态插桩 | 跨平台动态Hook，绕过反调试 |
| Cuckoo Sandbox | 沙箱 | 开源自动化恶意软件分析系统 |
| Volatility | 内存取证 | 内存分析框架，分析无文件恶意代码 |
| YARA | 特征匹配 | 基于规则的恶意代码特征匹配 |
| Capa | 行为分析 | 自动从二进制中识别能力 |
| Scylla | 脱壳 | PE dump + IAT修复 |
| Detect It Easy | 查壳 | 特征+熵值分析，识别壳和编译器 |
| angr | 符号执行 | 符号执行框架，反混淆/CFG还原 |
| Triton | 动态分析 | 动态二进制分析+符号执行 |
