# 高级恶意代码家族分析

### 5.1 勒索软件分析

```
LockBit：
- 当前最活跃的勒索软件家族之一
- RaaS模式运营
- 支持AES-128-CBC + RSA-2048混合加密
- 自动化加密+横向移动
- 具有反虚拟机/反调试功能
- 支持"Stealth Mode"静默加密

Conti：
- 曾针对医疗机构和政府
- 使用ChaCha20流加密 + RSA-4096
- 高度自动化的加密流程
- 内置网络传播模块
- 源码泄露后衍生大量变种

BlackCat/ALPHV：
- 用Rust编写（跨平台、内存安全）
- 支持Windows和Linux
- 使用AES-256-CBC + RSA-2048
- 可通过命令行参数控制加密范围
- 支持指定排除目录/文件

共性分析要点：
1. 加密算法识别（导入函数+常量）
2. 文件遍历逻辑（FindFirstFile/FindNextFile）
3. 影子副本删除命令
4. 勒索信生成与放置逻辑
5. 密钥生成与公钥使用方式
6. 横向移动模块分析
```

### 5.2 银行木马分析

```
Zeus（Zbot）：
- 勒索软件和银行木马的"鼻祖"之一
- 窃取银行凭据，Web注入攻击
- 配置文件中定义目标银行和注入规则
- Web注入：在银行页面注入额外表单字段
- 基于配置文件的模块化设计

Emotet：
- 最初是银行木马，后演变为恶意软件分发平台
- 模块化架构：通信模块/传播模块/下载模块
- 通过垃圾邮件中的恶意附件传播
- 宏文档→PowerShell→Emotet DLL
- 被FBI/欧洲刑警组织联合打击后仍有变种

TrickBot：
- 银行木马 + 模块化恶意软件
- 通过模块化架构不断扩展功能
- 后演变为Conti勒索软件的前身
- 支持多种传播方式（邮件/漏洞/凭据）
- 内置Mimikatz功能（凭据窃取）

分析要点：
1. Web注入配置文件解析（目标银行列表）
2. C2通信协议与加密方式
3. 模块加载机制
4. 传播机制分析
5. 凭据窃取方式（表单抓取/HTTP注入/浏览器中间人）
```

### 5.3 APT工具集分析

```
PlugX：
- 常用于APT攻击的远控木马
- 模块化架构，支持插件扩展
- 常通过DLL侧加载（合法程序+恶意DLL）
- 加密配置存储（RC4/XOR加密）
- 多种C2通信方式

Cobalt Strike（被滥用）：
- 商业渗透测试工具
- 攻击者大量使用其Beacon组件
- 特征：beaconing通信+模块化payload
- 常通过PowerShell/宏文档投递
- Beacon支持多种通信协议

APT工具集分析要点：
1. 投递方式分析（鱼叉邮件/水坑/供应链/0day）
2. 初始载荷执行链（文档→脚本→Shellcode→DLL）
3. 持久化机制
4. C2协议特征与基础设施
5. 与已知APT组织TTP关联（MITRE ATT&CK映射）
```

### 5.4 无文件恶意代码分析

```
无文件（Fileless）恶意代码不落地磁盘文件，运行在内存中：

常见技术：

1. PowerShell内存执行
   - 通过-enc参数传递Base64编码命令
   - 使用反射式DLL加载（PE注入内存）
   - Invoke-Mimikatz / PowerSploit框架

2. WMI持久化
   - 通过WMI事件订阅实现持久化
   - __EventFilter + __EventConsumer + __EventFilterToConsumerBinding
   - 不落地文件/不写入注册表

3. 注册表存储 + PowerShell加载
   - 将Shellcode编码后存入注册表
   - 通过PowerShell读取并执行
   - 典型案例：POSHSPY

4. 进程注入
   - 注入到合法进程（explorer.exe/svchost.exe）
   - 不创建新文件
   - 反射式DLL注入

5. .NET反射式加载
   - 通过Assembly.Load在内存中执行.NET程序集
   - 不落地DLL文件

分析挑战：
- 磁盘上无文件 → 静态分析困难
- 需要内存取证（Volatility/Rekall）
- PowerShell日志分析（ScriptBlock日志 Event ID 4104）
- AMSI（反恶意软件扫描接口）可捕获内存中执行的脚本
- Sysmon Event ID 1/7/8/10/11/22/255覆盖进程/网络/文件/注册表
```

### 5.5 LOLBins攻击分析

```
LOLBins（Living off the Land Binaries）：
利用系统自带的合法程序执行恶意操作，绕过应用白名单：

常见LOLBins：

| 合法程序 | 恶意用途 |
|----------|----------|
| certutil.exe | 下载文件（-urlcache -split） |
| bitsadmin.exe | 后台下载文件 |
| mshta.exe | 执行HTA文件（内含VBScript） |
| wscript.exe/cscript.exe | 执行脚本 |
| powershell.exe | 内存执行payload |
| rundll32.exe | 加载DLL/执行Shellcode |
| regsvr32.exe | 加载COM对象（squiblydoo） |
| msbuild.exe | 编译并执行内嵌C#代码 |
| installutil.exe | 执行内嵌代码 |
| regsvcs.exe/regasm.exe | 执行.NET代码 |
| mavinject.exe | 进程注入 |
| wmic.exe | 远程执行命令 |

分析要点：
1. 进程命令行分析（异常参数组合）
2. 父子进程关系异常（如excel→cmd→powershell）
3. 网络连接来源进程（如certutil发起HTTP请求）
4. Sysmon Event ID 1 记录完整命令行
5. 可通过Sysmon配置专门监控LOLBins
```
