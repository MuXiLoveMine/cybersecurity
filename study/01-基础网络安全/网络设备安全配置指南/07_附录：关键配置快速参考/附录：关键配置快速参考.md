# 附录：关键配置快速参考

| 安全功能 | Cisco 关键命令 | 华为 关键命令 |
|---------|---------------|-------------|
| 密码加密 | `service password-encryption` | 默认加密存储 |
| SSH登录 | `ip ssh version 2` | `stelnet server enable` |
| 关闭Telnet | `no transport input telnet` | `protocol inbound ssh` |
| 端口安全 | `switchport port-security` | `port-security enable` |
| DHCP Snooping | `ip dhcp snooping` | `dhcp snooping enable` |
| DAI | `ip arp inspection vlan X` | `arp anti-attack` |
| STP根保护 | `spanning-tree guard root` | `stp root-protection` |
| OSPF认证 | `area 0 authentication message-digest` | `ospf authentication-mode md5` |
| SNMPv3 | `snmp-server user ... v3` | `snmp-agent ... v3` |

---

> **免责声明**：本指南中的配置命令仅用于学习和实验环境。在生产环境中部署前，请务必在测试环境验证，并根据实际网络架构和安全需求进行调整。所有命令均参考 Cisco IOS 15.x+ 和华为 VRP V8 平台。
