# 交换机安全配置

交换机工作在数据链路层，二层攻击（如 ARP 欺骗、DHCP 攫取、VLAN 跳跃）往往更隐蔽。以下涵盖核心的二层安全防护技术。

### 2.1 端口安全（Port Security）

端口安全限制每个端口可学习的 MAC 地址数量，防止 MAC 泛洪攻击和非法设备接入。

```cisco
! 进入接入端口配置
Switch(config)# interface FastEthernet0/1

! 开启端口安全
Switch(config-if)# switchport port-security

! 设置最大MAC地址数量（接入端口通常为1-2）
Switch(config-if)# switchport port-security maximum 2

! 配置静态绑定MAC地址（可选，更安全）
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security mac-address aaaa.bbbb.cccc

! 配置违规动作
Switch(config-if)# switchport port-security violation restrict
! restrict: 丢弃违规帧并记录日志（不关闭端口）
! protect : 静默丢弃违规帧（无日志）
! shutdown: 关闭端口（需管理员恢复，最严格）
Switch(config-if)# exit

! 配置端口恢复（err-disable自动恢复）
Switch(config)# errdisable recovery cause psecure-violation
Switch(config)# errdisable recovery interval 300    ! 300秒后自动恢复
```

**最佳实践**：接入端口建议使用 `sticky` + `shutdown` 模式，兼顾安全性和可维护性。

### 2.2 DHCP Snooping

DHCP Snooping 防止非法 DHCP 服务器响应，避免客户端获取错误网关和DNS。

```cisco
! 全局开启DHCP Snooping
Switch(config)# ip dhcp snooping

! 指定VLAN开启DHCP Snooping
Switch(config)# ip dhcp snooping vlan 10,20,30

! 配置信任端口（上联端口/合法DHCP服务器所在端口）
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip dhcp snooping trust
Switch(config-if)# exit

! 非信任端口（接入端口）限制DHCP报文速率（防DHCP泛洪）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# ip dhcp snooping limit rate 15    ! 每秒15个DHCP报文
Switch(config-if-range)# exit

! 开启DHCP Snooping MAC地址验证（Option 82）
Switch(config)# ip dhcp snooping information option
```

**原理**：信任端口可以转发 DHCP Offer/Ack；非信任端口丢弃这些报文。只有连接合法 DHCP 服务器或 DHCP 中继的端口才应设为信任端口。

### 2.3 动态ARP检测（DAI）

DAI 依赖 DHCP Snooping 绑定表，检查 ARP 报文的合法性，防止 ARP 欺骗。

```cisco
! 前提：已配置DHCP Snooping（DAI依赖其绑定表）

! 全局开启DAI（按VLAN）
Switch(config)# ip arp inspection vlan 10,20,30

! 配置信任端口（上连路由器的端口）
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip arp inspection trust
Switch(config-if)# exit

! 非信任端口配置ARP速率限制
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# ip arp inspection limit rate 15 burst-compatible
Switch(config-if-range)# exit

! 可选：配置静态ARP绑定（用于无DHCP环境）
Switch(config)# arp access-list STATIC-ARP
Switch(config-arclst)# permit ip host 10.10.10.50 mac host aaaa.bbbb.cccc
Switch(config-arclst)# exit
Switch(config)# ip arp inspection filter STATIC-ARP vlan 10
```

### 2.4 生成树协议安全（STP Security）

STP 用于防止二层环路，但攻击者可伪造根桥优先级来改变网络拓扑。

```cisco
! 配置根保护（防止下游交换机成为根桥）
Switch(config)# interface GigabitEthernet0/2
Switch(config-if)# spanning-tree guard root
Switch(config-if)# exit

! 配置BPDU保护（接入端口不应收到BPDU）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# spanning-tree portfast              ! 接入端口快速进入转发
Switch(config-if-range)# spanning-tree bpduguard enable      ! 收到BPDU则关闭端口
Switch(config-if-range)# exit

! 配置BPDU过滤（可选，完全忽略BPDU，需谨慎使用）
Switch(config)# spanning-tree portfast bpduguard default

! 配置环路保护（防止单向链路导致的环路）
Switch(config)# spanning-tree loopguard default

! 设置根桥优先级（确保核心交换机为根桥）
Switch(config)# spanning-tree vlan 10-30 root primary
```

### 2.5 VLAN安全与隔离

#### 2.5.1 VLAN跳跃攻击防护

VLAN跳跃攻击利用 DTP（动态中继协议）和双标签封装突破 VLAN 隔离。

```cisco
! 接入端口关闭中继协商（防止DTP协商攻击）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport nonegotiate          ! 关闭DTP协商
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

! Trunk端口配置
Switch(config)# interface GigabitEthernet0/24
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30    ! 明确允许的VLAN
Switch(config-if)# switchport trunk native vlan 999           ! 将Native VLAN设为未使用VLAN
Switch(config-if)# switchport nonegotiate
Switch(config-if)# exit

! 将VLAN 1作为Unused VLAN（VLAN 1默认承载管理流量，易被攻击）
Switch(config)# vlan 999
Switch(config-vlan)# name UNUSED-NATIVE
Switch(config-vlan)# state suspend
Switch(config-vlan)# exit
```

#### 2.5.2 Private VLAN（PVLAN）实现端口级隔离

```cisco
! 配置Primary VLAN
Switch(config)# vlan 100
Switch(config-vlan)# private-vlan primary
Switch(config-vlan)# exit

! 配置Isolated VLAN（隔离VLAN，端口间不可通信）
Switch(config)# vlan 201
Switch(config-vlan)# private-vlan isolated
Switch(config-vlan)# exit

! 配置Community VLAN（社区VLAN，组内可通信）
Switch(config)# vlan 202
Switch(config-vlan)# private-vlan community
Switch(config-vlan)# exit

! 关联Primary与Secondary VLAN
Switch(config)# vlan 100
Switch(config-vlan)# private-vlan association 201,202
Switch(config-vlan)# exit

! 将端口划入PVLAN
Switch(config)# interface FastEthernet0/5
Switch(config-if)# switchport mode private-vlan host
Switch(config-if)# switchport private-vlan host-association 100 201
Switch(config-if)# exit
```
