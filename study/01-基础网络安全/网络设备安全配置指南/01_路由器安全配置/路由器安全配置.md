# 路由器安全配置

路由器是网络的核心枢纽，一旦被攻破，攻击者即可控制路由流向、截获流量甚至作为跳板攻击内部网络。以下从基本加固、访问控制、路由协议安全和日志审计四个维度展开。

### 1.1 基本加固

#### 1.1.1 修改默认密码与账户管理

出厂默认凭证是网络设备最常见的安全风险之一。设备上线前必须修改所有默认密码，并启用密码加密。

**Cisco IOS 示例：**

```cisco
! 启用密码加密，防止配置文件中明文存储密码
Router(config)# service password-encryption

! 设置特权模式秘密密码（使用 SHA-256 加密）
Router(config)# enable secret 0 YourStrongP@ssw0rd

! 创建本地管理员账户，使用最高加密级别
Router(config)# username netadmin privilege 15 secret 0 AdminStr0ng!Pass

! 配置登录认证使用本地数据库
Router(config)# aaa new-model
Router(config)# aaa authentication login default local
Router(config)# aaa authorization exec default local
```

**华为 VRP 示例：**

```huawei
# 启用密码加密
[Huawei] password-policy min-length 12
[Huawei] aaa
[Huawei-aaa] local-user netadmin password cipher AdminStr0ng!Pass
[Huawei-aaa] local-user netadmin privilege level 15
[Huawei-aaa] local-user netadmin service-type ssh
[Huawei-aaa] quit
```

**加固要点：**
- 密码长度不少于 12 位，包含大小写字母、数字和特殊字符
- 设置密码过期策略，定期轮换
- 遵循最小权限原则，为不同管理员分配不同权限级别

#### 1.1.2 关闭不必要服务

默认情况下，路由器开启了多种服务以方便管理，但这些服务在正式环境中往往成为攻击面。

**Cisco IOS 关闭不必要服务：**

```cisco
! 关闭未使用的服务
Router(config)# no service tcp-small-servers
Router(config)# no service udp-small-servers
Router(config)# no service finger
Router(config)# no ip http server          ! 关闭明文 HTTP 管理
Router(config)# no ip http secure-server   ! 如不需要 Web 管理则关闭
Router(config)# no ip domain-lookup        ! 关闭 DNS 解析（防DNS反射攻击）
Router(config)# no cdp run                 ! 关闭CDP发现协议（内网可按需开启）
Router(config)# no ip source-route         ! 禁用源路由
Router(config)# no service dhcp            ! 如非DHCP服务器则关闭
Router(config)# no bootp server            ! 关闭BOOTP服务
```

**关闭 SNMPv1/v2c（不安全版本）：**

```cisco
Router(config)# no snmp-server community public RO   ! 删除默认社区字符串
Router(config)# no snmp-server community private RW
```

#### 1.1.3 SSH 替代 Telnet

Telnet 以明文传输所有数据（包括密码），必须用 SSH 替代。

**Cisco IOS 配置 SSH：**

```cisco
! 第一步：配置主机名和域名（SSH密钥生成的前提）
Router(config)# hostname CoreRouter01
CoreRouter01(config)# ip domain-name sec.lab.local

! 第二步：生成RSA密钥对（建议至少2048位）
CoreRouter01(config)# crypto key generate rsa modulus 2048

! 第三步：配置SSH参数
CoreRouter01(config)# ip ssh version 2              ! 仅允许SSHv2
CoreRouter01(config)# ip ssh time-out 60            ! 超时60秒
CoreRouter01(config)# ip ssh authentication-retries 3  ! 最大重试3次

! 第四步：限制VTY线路只允许SSH
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# transport input ssh     ! 仅允许SSH登录
CoreRouter01(config-line)# login local
CoreRouter01(config-line)# exec-timeout 5 0         ! 5分钟空闲超时
CoreRouter01(config-line)# exit

! 第五步：关闭Telnet
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# no transport input telnet
```

**华为 VRP 配置 SSH：**

```huawei
[Huawei] rsa local-key-pair create    # 生成RSA密钥
[Huawei] stelnet server enable         # 启用SSH服务器
[Huawei] ssh user netadmin
[Huawei] ssh user netadmin authentication-type password
[Huawei] ssh user netadmin service-type stelnet
[Huawei] ssh server port 22
# 关闭Telnet
[Huawei] user-interface vty 0 4
[Huawei-ui-vty0-4] protocol inbound ssh
```

### 1.2 访问控制列表（ACL）配置

ACL 是路由器的基本流量过滤机制，用于控制哪些流量可以到达或经过设备。

**示例：仅允许管理网段访问设备管理端口**

```cisco
! 定义管理网段ACL
CoreRouter01(config)# ip access-list extended MGMT-ACCESS
CoreRouter01(config-ext-nacl)# permit tcp 10.10.10.0 0.0.0.255 any eq 22
CoreRouter01(config-ext-nacl)# permit tcp 10.10.10.0 0.0.0.255 any eq 443
CoreRouter01(config-ext-nacl)# deny   ip any any log
CoreRouter01(config-ext-nacl)# exit

! 应用到VTY线路
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# access-class MGMT-ACCESS in
CoreRouter01(config-line)# exit
```

**示例：Anti-Spoofing ACL（防IP欺骗）**

```cisco
! 在面向互联网的接口入方向应用
CoreRouter01(config)# ip access-list extended ANTI-SPOOFING
CoreRouter01(config-ext-nacl)# deny   ip 10.0.0.0 0.255.255.255 any    ! 内网地址不应来自外网
CoreRouter01(config-ext-nacl)# deny   ip 172.16.0.0 0.15.255.255 any
CoreRouter01(config-ext-nacl)# deny   ip 192.168.0.0 0.0.255.255 any
CoreRouter01(config-ext-nacl)# deny   ip 127.0.0.0 0.255.255.255 any    ! 环回地址
CoreRouter01(config-ext-nacl)# deny   ip 169.254.0.0 0.0.255.255 any    ! 链路本地地址
CoreRouter01(config-ext-nacl)# permit ip any any
CoreRouter01(config-ext-nacl)# exit

CoreRouter01(config)# interface GigabitEthernet0/0/1
CoreRouter01(config-if)# ip access-group ANTI-SPOOFING in
```

### 1.3 路由协议安全

未认证的路由协议可被攻击者利用注入恶意路由，实现流量劫持。

#### 1.3.1 OSPF 认证配置

**Cisco OSPF MD5 认证：**

```cisco
! 配置OSPF区域认证
CoreRouter01(config)# router ospf 1
CoreRouter01(config-router)# area 0 authentication message-digest
CoreRouter01(config-router)# exit

! 接口级别配置密钥
CoreRouter01(config)# interface GigabitEthernet0/0/0
CoreRouter01(config-if)# ip ospf message-digest-key 1 md5 OSPFsecKey123!
CoreRouter01(config-if)# ip ospf hello-interval 10
CoreRouter01(config-if)# exit
```

**华为 OSPF 认证：**

```huawei
[Huawei] interface GigabitEthernet0/0/0
[Huawei-GigabitEthernet0/0/0] ospf authentication-mode md5 1 cipher OSPFsecKey123!
```

#### 1.3.2 BGP 认证配置

BGP 是互联网核心路由协议，认证尤为关键。

**Cisco BGP TCP MD5 认证：**

```cisco
CoreRouter01(config)# router bgp 65001
CoreRouter01(config-router)# neighbor 203.0.113.2 remote-as 65002
CoreRouter01(config-router)# neighbor 203.0.113.2 password BGPsecKey456!
CoreRouter01(config-router)# neighbor 203.0.113.2 fall-over bfd    ! 快速故障检测
CoreRouter01(config-router)# exit

! 配置前缀列表限制路由更新（防路由劫持）
CoreRouter01(config)# ip prefix-list BGP-IN seq 5 permit 192.0.2.0/24
CoreRouter01(config)# ip prefix-list BGP-IN seq 10 deny 0.0.0.0/0 le 32

CoreRouter01(config)# router bgp 65001
CoreRouter01(config-router)# neighbor 203.0.113.2 prefix-list BGP-IN in
```

### 1.4 日志与审计配置

日志记录是安全事件追踪和取证的关键。

```cisco
! 配置日志时间戳（精确到毫秒）
CoreRouter01(config)# service timestamps log datetime msec localtime show-timezone

! 配置日志缓冲区
CoreRouter01(config)# logging buffered 65536 informational    ! 64KB缓冲区，记录informational及以上级别

! 配置远程Syslog服务器
CoreRouter01(config)# logging 10.10.20.100
CoreRouter01(config)# logging trap informational               ! 发送informational及以上级别
CoreRouter01(config)# logging source-interface Loopback0        ! 指定日志源接口
CoreRouter01(config)# logging facility local6                   ! 定义facility标识

! 配置日志序列号（防篡改）
CoreRouter01(config)# service sequence-numbers

! 开启登录日志
CoreRouter01(config)# login on-success log
CoreRouter01(config)# login on-failure log
```
