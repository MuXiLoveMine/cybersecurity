# 常见网络设备漏洞

### 6.1 默认凭证风险

**风险描述**：许多网络设备出厂时带有默认管理员账户和密码（如 `admin/admin`、`cisco/cisco`），攻击者可通过搜索引擎或漏洞数据库（如 Shodan、Exploit-DB）快速发现暴露在互联网上的设备。

**防护措施**：
- 设备上线前强制修改所有默认密码
- 使用强密码策略（12位以上，混合字符）
- 禁用不必要的默认账户
- 定期审计凭据使用情况

### 6.2 管理接口暴露

**风险描述**：网络设备的管理接口（HTTP/HTTPS/Telnet/SSH）暴露在公网，攻击者可进行暴力破解或利用已知漏洞直接攻击。

**防护措施**：
- 管理接口仅允许内网管理网段访问
- 通过 ACL 限制源地址
- 使用堡垒机（Jump Server）集中管理
- 定期检查暴露面（使用 Shodan/Censys 自查）

```cisco
! 管理接口仅允许管理网段访问
Router(config)# ip access-list standard MGMT-ACL
Router(config-std-nacl)# permit 10.10.10.0 0.0.0.255
Router(config-std-nacl)# deny any log
Router(config-std-nacl)# exit

Router(config)# line vty 0 4
Router(config-line)# access-class MGMT-ACL in
```

### 6.3 SNMP社区字符串泄露

**风险描述**：SNMPv1/v2c 使用明文社区字符串认证，默认值 `public`（只读）和 `private`（读写）广为人知。攻击者获取读写权限后可修改设备配置。

**防护措施**：
- 升级至 SNMPv3（支持加密和认证）
- 删除默认社区字符串
- 使用复杂社区字符串（20位以上随机字符）
- 限制 SNMP 访问源地址

```cisco
! 配置SNMPv3
Router(config)# no snmp-server community public RO
Router(config)# no snmp-server community private RW

Router(config)# snmp-server group ADMINGROUP v3 priv read VIEW-ALL write VIEW-ALL
Router(config)# snmp-server user netadmin ADMINGROUP v3 auth sha AuthP@ss123! priv aes 128 EncrKey456!
Router(config)# snmp-server view VIEW-ALL iso included

! 限制SNMP访问源
Router(config)# snmp-server community restrict
Router(config)# ip access-list standard SNMP-ACL
Router(config-std-nacl)# permit 10.10.10.0 0.0.0.255
Router(config-std-nacl)# deny any log
Router(config-std-nacl)# exit
Router(config)# snmp-server group ADMINGROUP v3 priv access SNMP-ACL
```

### 6.4 配置文件泄露

**风险描述**：配置文件包含所有密码、密钥和策略信息。通过 TFTP 明文备份、HTTP 目录遍历或物理访问，攻击者可获取完整配置。

**防护措施**：
- 启用密码加密（`service password-encryption`）
- 使用 SCP 替代 TFTP 进行配置传输
- 限制配置文件访问权限
- 定期检查异常配置导出操作

```cisco
! 使用SCP替代TFTP传输配置
Router(config)# ip scp server enable
Router(config)# aaa authentication scp default local

! 禁用TFTP服务器
Router(config)# no tftp-server flash:

! 配置文件加密备份
Router(config)# archive
Router(config-archive)# path scp://10.10.20.50/backup/router-config
Router(config-archive)# write-memory
Router(config-archive)# time-period 86400    ! 每天自动备份
```
