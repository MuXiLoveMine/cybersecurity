# 防火墙安全配置

防火墙是网络安全的第一道防线，策略设计的合理性直接决定整体安全水平。

### 3.1 防火墙策略设计原则

1. **默认拒绝原则**：未经明确允许的流量一律拒绝
2. **最小权限原则**：只开放业务必需的端口和协议
3. **纵深防御原则**：多层过滤，不依赖单一规则
4. **规则精简原则**：定期清理冗余和过期规则，避免规则膨胀
5. **从严格到宽松**：高优先级规则放在最前，提高匹配效率

### 3.2 区域划分与安全域

将网络划分为不同安全等级的区域，区域间流量受策略控制。

```
互联网 (Untrust, 安全等级 5)
    │
    ├── 外部防火墙
    │
DMZ区 (安全等级 50)
  └── Web服务器、邮件服务器、DNS服务器
    │
    ├── 内部防火墙
    │
内部网络 (Trust, 安全等级 100)
  └── 办公网、生产网、管理网
    │
    ├── 隔离防火墙
    │
核心数据区 (安全等级 85)
  └── 数据库、文件服务器
```

**Cisco ASA 区域与策略配置示例：**

```cisco
! 定义安全区域
ciscoasa(config)# interface GigabitEthernet0/0
ciscoasa(config-if)# nameif outside
ciscoasa(config-if)# security-level 0
ciscoasa(config-if)# ip address 203.0.113.1 255.255.255.240

ciscoasa(config)# interface GigabitEthernet0/1
ciscoasa(config-if)# nameif inside
ciscoasa(config-if)# security-level 100
ciscoasa(config-if)# ip address 10.10.10.1 255.255.255.0

ciscoasa(config)# interface GigabitEthernet0/2
ciscoasa(config-if)# nameif dmz
ciscoasa(config-if)# security-level 50
ciscoasa(config-if)# ip address 192.0.2.1 255.255.255.0

! 配置安全策略：仅允许外部访问DMZ的Web服务
ciscoasa(config)# object network WEB-SERVER
ciscoasa(config-network-object)# host 192.0.2.10
ciscoasa(config-network-object)# exit

ciscoasa(config)# object network WEB-SERVICE
ciscoasa(config-network-object)# service tcp 80 443
ciscoasa(config-network-object)# exit

ciscoasa(config)# access-list OUTSIDE_IN extended permit tcp any object WEB-SERVER eq www
ciscoasa(config)# access-list OUTSIDE_IN extended permit tcp any object WEB-SERVER eq https
ciscoasa(config)# access-list OUTSIDE_IN extended deny ip any any log

ciscoasa(config)# access-group OUTSIDE_IN in interface outside
```

### 3.3 NAT配置安全

NAT 可隐藏内部网络结构，但也需注意安全配置。

```cisco
! 配置动态PAT（内部用户上网）
ciscoasa(config)# object network INSIDE-NET
ciscoasa(config-network-object)# subnet 10.10.10.0 255.255.255.0
ciscoasa(config-network-object)# exit

ciscoasa(config)# nat (inside,outside) dynamic interface

! 配置静态NAT（DMZ服务器发布，端口级精确映射）
ciscoasa(config)# object network WEB-SERVER
ciscoasa(config-network-object)# host 192.0.2.10
ciscoasa(config-network-object)# exit

ciscoasa(config)# nat (dmz,outside) static 203.0.113.10 service tcp www www
ciscoasa(config)# nat (dmz,outside) static 203.0.113.10 service tcp https https

! 注意：DNS重写（DNS Doctoring）防止内部用户使用外部地址访问内部服务器
ciscoasa(config)# nat (inside,dmz) static 192.0.2.10 dns
```

### 3.4 VPN网关配置

VPN 提供加密的远程接入通道，以下是 Site-to-Site IPSec VPN 配置示例。

**Cisco ASA Site-to-Site IPSec VPN：**

```cisco
! 第一阶段：ISAKMP策略配置
ciscoasa(config)# crypto ikev1 policy 10
ciscoasa(config-ikev1-policy)# authentication pre-share
ciscoasa(config-ikev1-policy)# encryption aes-256
ciscoasa(config-ikev1-policy)# hash sha
ciscoasa(config-ikev1-policy)# group 2
ciscoasa(config-ikev1-policy)# lifetime 86400
ciscoasa(config-ikev1-policy)# exit

! 配置隧道组（预共享密钥）
ciscoasa(config)# tunnel-group 198.51.100.2 type ipsec-l2l
ciscoasa(config)# tunnel-group 198.51.100.2 ipsec-attributes
ciscoasa(config-tunnel-ipsec)# ikev1 pre-shared-key VPNStr0ngKey789!
ciscoasa(config-tunnel-ipsec)# exit

! 第二阶段：IPSec变换集
ciscoasa(config)# crypto ipsec ikev1 transform-set TS-SET esp-aes-256 esp-sha-hmac

! 配置感兴趣流量
ciscoasa(config)# access-list VPN-TRAFFIC extended permit ip 10.10.10.0 255.255.255.0 172.16.20.0 255.255.255.0

! 配置Crypto Map
ciscoasa(config)# crypto map VPN-MAP 10 match address VPN-TRAFFIC
ciscoasa(config)# crypto map VPN-MAP 10 set peer 198.51.100.2
ciscoasa(config)# crypto map VPN-MAP 10 set ikev1 transform-set TS-SET

! 应用到外部接口
ciscoasa(config)# crypto map VPN-MAP interface outside
ciscoasa(config)# crypto ikev1 enable outside
```
