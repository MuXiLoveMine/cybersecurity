# 网络设备安全审计

### 4.1 配置审计检查清单

以下是一份可直接使用的网络设备安全检查清单：

| 检查项 | 检查内容 | 通过标准 |
|--------|---------|---------|
| 密码安全 | 默认密码是否修改 | 无默认凭证；密码加密存储 |
| 管理访问 | Telnet是否禁用 | 仅允许SSH v2访问 |
| 管理访问 | 管理ACL是否配置 | 仅管理网段可访问管理接口 |
| 不必要服务 | 小服务/CDP/HTTP是否关闭 | 非必要服务全部关闭 |
| 日志 | Syslog是否配置 | 远程日志服务器已配置且正常接收 |
| NTP | 时间同步是否正常 | NTP已配置且时钟同步 |
| SNMP | 是否使用SNMPv3 | SNMPv1/v2c已禁用 |
| ACL | 入方向过滤是否配置 | 反欺骗ACL已部署 |
| 路由认证 | OSPF/BGP是否认证 | 路由协议已开启MD5认证 |
| 端口安全 | 接入端口是否配置 | Port Security已启用 |
| 二层安全 | DHCP Snooping/DAI | 已部署并运行正常 |
| 固件版本 | 当前版本是否有已知漏洞 | 已升级至安全版本 |
| 配置备份 | 是否定期备份 | 配置自动备份至安全位置 |
| 物理安全 | Console口是否加锁 | Console口密码已设置 |

### 4.3 固件升级与补丁管理

```cisco
! Cisco IOS 升级流程
! 1. 备份当前配置和镜像
Router# copy running-config tftp://10.10.20.50/router-backup-config.cfg
Router# copy flash: tftp://10.10.20.50/router-backup-image.bin

! 2. 上传新镜像到Flash
Router# copy tftp://10.10.20.50/new-image.bin flash:
Router# verify /md5 flash:new-image.bin  ! 验证镜像完整性

! 3. 修改启动配置
Router(config)# boot system flash:new-image.bin

! 4. 保存配置并重启
Router# write memory
Router# reload
```

**补丁管理流程：**
1. 订阅厂商安全公告（Cisco PSIRT、华为安全公告）
2. 评估漏洞影响范围和严重程度
3. 在测试环境验证补丁兼容性
4. 制定升级窗口和回退方案
5. 执行升级并验证功能
6. 更新配置基线文档
