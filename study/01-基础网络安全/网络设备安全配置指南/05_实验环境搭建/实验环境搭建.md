# 实验环境搭建

### 5.1 模拟器选择与对比

| 模拟器 | 适用场景 | 优势 | 不足 |
|--------|---------|------|------|
| **Packet Tracer** | 初学者入门 | 免费、安装简单、界面友好 | 功能有限、非真实IOS |
| **GNS3** | 中级进阶 | 支持真实IOS镜像、功能强大 | 资源消耗大、需自行获取镜像 |
| **EVE-NG** | 高级实验 | 支持多厂商、Web界面、集群 | 部署复杂、需Linux基础 |

### 5.2 实验拓扑设计建议

以下拓扑覆盖本指南所有实验场景：

```
                    ┌──────────────┐
                    │  Internet模拟  │
                    │  (Loopback)   │
                    └──────┬───────┘
                           │
                    ┌──────┴───────┐
                    │   R1 (ISP)   │  ← OSPF/BGP认证实验
                    │  Cisco 7200  │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
       ┌──────┴────┐ ┌────┴────┐ ┌────┴────┐
       │ FW1 (ASA) │ │ SW1核心 │ │ SW2核心 │ ← STP/堆叠实验
       │  防火墙    │ │  STP根桥 │ │  STP备根 │
       └──────┬────┘ └────┬────┘ └────┬────┘
              │           │           │
              │     ┌──────┴───────┐   │
              │     │  SW3接入层    │   │
              │     │ PortSecurity │   │ ← 端口安全/DHCP Snooping/DAI实验
              │     │  DHCP Snooping│   │
              │     └──┬──┬──┬──┬──┘   │
              │        │  │  │  │      │
         ┌────┴──┐  ┌─┴┐┌┴─┐┌┴─┐┌┴─┐
         │ DMZ区  │  │PC1││PC2││PC3││PC4│  ← VLAN隔离/PVLAN实验
         │Web/DNS│  │V10││V10││V20││V20│
         └───────┘  └──┘└──┘└──┘└──┘
```

**实验建议：**
1. **路由器安全实验**：在 R1 上完成基本加固、ACL、OSPF/BGP认证配置
2. **交换机安全实验**：在 SW3 上完成端口安全、DHCP Snooping、DAI配置
3. **防火墙实验**：在 FW1 上完成区域划分、安全策略、NAT、VPN配置
4. **攻击模拟实验**：用 Kali Linux 虚拟机模拟攻击（ARP欺骗、MAC泛洪、VLAN跳跃）
5. **审计实验**：使用 Nmap/Nessus 对实验环境中的设备进行安全扫描
