# 全流量分析平台

### 7.1 Zeek（Bro）日志分析框架

Zeek 不是签名 IDS，而是"流量日志生成器"。它把流量解析成结构化日志，让你用 SQL/Python 分析。

**核心日志：**

| 日志 | 内容 |
|------|------|
| conn.log | 所有连接的五元组、字节数、持续时间 |
| dns.log | DNS查询/响应 |
| http.log | HTTP请求/响应摘要 |
| ssl.log | TLS连接、SNI、证书 |
| files.log | 文件提取记录 |
| weird.log | 协议异常 |
| notice.log | Zeek脚本产生的告警 |

```bash
# 安装Zeek
apt install zeek
# 或源码安装(更灵活)
./configure --with-libpcap && make && make install

# 配置监听 /opt/zeek/etc/zeek.conf
[zeek]
host=localhost
interface=eth1

# 启动
zeekctl deploy
zeekctl start

# 查看日志
ls /opt/zeek/logs/current/
# conn.log dns.log http.log ssl.log ...

# 简单分析: 找外联TOP10
cat conn.log | zeek-cut id.orig_h id.resp_h bytes | \
  sort | uniq -c | sort -rn | head
```

**Zeek 脚本示例（检测 DNS 隧道）：**

```zeek
# detect_dns_tunnel.zeek
module DNS_TUNNEL;

export {
    redef enum Notice::Type += { DNS_Tunnel_Suspect };
    global threshold: double = 50 &redef;
}

event dns_request(c: connection, msg: dns_msg, query: string, qtype: count)
{
    if (|query| > threshold)
        NOTICE([$note=DNS_Tunnel_Suspect,
                $msg=fmt("Long DNS query %s from %s", query, c$id$orig_h),
                $conn=c]);
}
```

### 7.2 Moloch / Arkime 全流量捕获与索引

Arkime（原 Moloch）是大规模全流量捕获与搜索系统。它把 pcap 存储到磁盘，同时把元数据索引到 Elasticsearch，支持 PB 级流量的秒级搜索。

```bash
# 安装 Arkime
# 需先装 Elasticsearch
# 下载并安装
./configure
make
make install

# 配置 /opt/arkime/etc/config.ini
[default]
elasticsearch=http://localhost:9200
pcapDir=/data/arkime/pcap
interface=eth1
bpf=not port 22
maxStreams=1000000

# 初始化ES
/opt/arkime/db/db.pl localhost:9200 init

# 启动捕获节点
/opt/arkime/bin/capture
# 启动Viewer
/opt/arkime/bin/viewer
```

访问 Web UI，可按 IP/端口/SNI/协议/时间多维度检索会话，一键下载 pcap 用 Wireshark 深挖。这是"先索引定位，再全流量深挖"的高效工作流。

### 7.3 Elasticsearch + Kibana 流量可视化

把 Suricata 的 eve.json、Zeek 的日志、NetFlow 都汇入 ELK，做统一可视化与告警。

```
数据流:
  Suricata eve.json ─┐
  Zeek logs ──────────┼─→ Logstash/Filebeat ─→ Elasticsearch ─→ Kibana
  NetFlow(GoFlow) ────┘                                          │
                                                                 ↓
                                                          告警(ElastAlert/Kibana Alerting)
```

Kibana 仪表盘示例：
- DDoS 监控：目的 IP 包速率时序图 + TOP 源 IP 表
- 外联异常：新出现的目的 IP 列表 + 上行字节数柱状图
- DNS 异常：高熵域名表 + NXDOMAIN 率趋势

```json
// Kibana 告警示例: 检测某IP外联峰值
{
  "trigger": {"source.event.bytes > 500MB AND destination.geo.country_name != \"China\""},
  "action": {"notify": "soc-team"}
}
```
