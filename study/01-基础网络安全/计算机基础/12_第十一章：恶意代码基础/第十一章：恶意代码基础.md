# 第十一章：恶意代码基础

### 11.1 恶意代码分类

```
按行为分类：
  病毒（Virus）：感染其他文件
  蠕虫（Worm）：自我传播
  木马（Trojan）：伪装成合法程序
  后门（Backdoor）：远程控制
  Rootkit：隐藏自身
  勒索软件（Ransomware）：加密文件勒索
  间谍软件（Spyware）：窃取信息
  广告软件（Adware）：强制广告

按技术特征：
  多态（Polymorphic）：每次感染改变自身代码
  变形（Metamorphic）：重写自身代码
  无文件（Fileless）：仅存在于内存中
  Living-off-the-Land：利用系统工具（PowerShell、WMI）
```

### 11.2 PE 文件分析基础

```bash
# 文件类型识别
file malware.exe
# 输出：PE32 executable for MS Windows

# 查看导入表（了解程序行为）
objdump -p malware.exe | grep -A 50 "Import"

# 提取字符串（查找 URL、IP、密钥）
strings -n 8 malware.exe | grep -i "http"
strings -n 8 malware.exe | grep -iE "([0-9]{1,3}\.){3}[0-9]{1,3}"
strings -n 8 malware.exe | grep -iE "(password|key|secret|admin)"

# 查看 PE 节区
objdump -h malware.exe

# 查看入口点
readpe -i malware.exe 2>/dev/null || objdump -f malware.exe

# 计算 Hash（查证情报库）
md5sum malware.exe
sha256sum malware.exe
```

### 11.3 ELF 文件分析

```bash
# Linux 恶意软件分析
file malware.elf
readelf -h malware.elf        # ELF 头
readelf -l malware.elf        # 程序头
readelf -S malware.elf        # 节头
objdump -d malware.elf        # 反汇编
nm -D malware.elf             # 动态符号
ldd malware.elf               # 依赖库
strings -n 8 malware.elf     # 字符串提取

# 动态分析
strace -f -o trace.log ./malware.elf
ltrace -f -o library.log ./malware.elf
```
