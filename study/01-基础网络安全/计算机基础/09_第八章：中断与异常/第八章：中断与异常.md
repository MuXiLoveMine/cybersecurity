# 第八章：中断与异常

### 8.1 中断处理机制

```
中断类型：
  1. 硬件中断（异步）
     - 键盘、网卡、定时器
     - 不可预测时间

  2. 软件中断（同步）
     - 系统调用（int 0x80 / syscall）
     - 除零错误、缺页异常
     - 可预测时间

  3. 异常（同步）
     - 故障（Fault）：缺页、GPF
     - 陷阱（Trap）：int3 断点、syscall
     - 终止（Abort）：硬件错误

中断处理流程：
  1. CPU 保存当前状态（寄存器、PC）到栈
  2. 查找中断描述符表（IDT）
  3. 跳转到中断处理程序
  4. 执行处理逻辑
  5. 恢复状态，iret 返回

安全相关：
  - IDT 劫持：Rootkit 修改 IDT 表项
  - 缺页异常处理：COW（Copy-on-Write）
  - int3 断点：调试器 hook
```
