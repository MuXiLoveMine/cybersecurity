# 第十章：网络协议基础补充

### 10.1 TCP/IP 协议栈

```
应用层：   HTTP/HTTPS, DNS, SSH, FTP, SMTP
传输层：   TCP（可靠）, UDP（快速）
网络层：   IP（IPv4/IPv6）, ICMP, ARP
链路层：   Ethernet, Wi-Fi, PPP

数据封装：
  应用数据
  → TCP 头 + 数据（段）
  → IP 头 + TCP 段（包）
  → Ethernet 头 + IP 包（帧）

TCP 三次握手安全性：
  Client → SYN → Server      （SYN 洪泛攻击点）
  Client ← SYN+ACK ← Server
  Client → ACK → Server      （连接建立）

TCP 序列号预测攻击：
  - 旧系统使用可预测的初始序列号
  - 攻击者伪造源 IP 进行会话劫持
  - 现代系统使用随机初始序列号防御

ARP 协议安全：
  - ARP 无认证机制
  - ARP 欺骗：伪造 ARP 响应
  - 防御：静态 ARP 绑定、DAI
```
