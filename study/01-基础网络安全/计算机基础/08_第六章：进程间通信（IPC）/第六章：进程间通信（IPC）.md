# 第六章：进程间通信（IPC）

### 6.1 IPC 机制概览

| 机制 | 说明 | 安全风险 |
|------|------|---------|
| **管道（Pipe）** | 父子进程间通信 | 数据可被嗅探 |
| **命名管道（FIFO）** | 任意进程间通信 | 权限控制不当 |
| **消息队列** | 内核维护的消息链表 | 竞态条件 |
| **共享内存** | 多进程映射同一物理内存 | 内存竞争、数据篡改 |
| **信号（Signal）** | 异步通知 | 信号处理函数漏洞 |
| **套接字（Socket）** | 网络通信 | 网络攻击面 |
| **信号量** | 同步访问共享资源 | 死锁 |

### 6.2 进程间通信安全

```bash
# 查看共享内存
ipcs -m

# 查看消息队列
ipcs -q

# 查看信号量
ipcs -s

# 删除共享内存段
ipcrm -m <shmid>

# 查看进程间通信
lsof -U    # 查看使用 UNIX 套接字的进程
```
