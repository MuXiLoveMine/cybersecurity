# 第五章：文件系统详解

### 5.1 Linux 文件系统结构

```
/                    根目录
├── bin/             基本命令（ls, cp, cat）
├── sbin/            系统管理命令（ifconfig, iptables）
├── etc/             配置文件
│   ├── passwd       用户信息
│   ├── shadow       密码哈希
│   ├── hosts        主机名映射
│   └── ssh/         SSH 配置
├── home/            用户主目录
│   └── user/        用户文件
├── var/             可变数据
│   ├── log/         系统日志
│   ├── www/         Web 根目录
│   └── lib/         应用数据
├── tmp/             临时文件（可执行权限）
├── dev/             设备文件
│   └── sda          磁盘设备
├── proc/            进程信息（虚拟文件系统）
│   ├── cpuinfo      CPU 信息
│   ├── meminfo      内存信息
│   └── [pid]/       各进程信息
└── sys/             内核参数（虚拟文件系统）
```

### 5.2 文件权限详解

```bash
# 查看文件权限
ls -la
# -rwxr-xr-- 1 user group 4096 Jan 1 file.txt

# 权限分解：
# 位置1：文件类型（- 普通文件, d 目录, l 符号链接）
# 位置2-4：所有者权限（rwx = 读/写/执行）
# 位置5-7：组权限（r-x = 读/执行）
# 位置8-10：其他用户权限（r-- = 只读）

# 数字表示法
# r=4, w=2, x=1
# rwxr-xr-- = 754

# 特殊权限位
chmod 4755 program    # SUID：以文件所有者身份执行
chmod 2755 directory   # SGID：以目录所属组身份创建文件
chmod 1755 tmpfile     # Sticky：只有所有者能删除

# 安全相关权限
find / -perm -4000 2>/dev/null   # 查找 SUID 文件
find / -perm -2000 2>/dev/null   # 查找 SGID 文件
find / -writable 2>/dev/null     # 查找可写文件

# SUID 提权示例
# nmap（旧版本支持交互模式）
nmap --interactive
nmap> !sh
# Perl
perl -e 'exec "/bin/sh"'
# Python
python -c 'import os; os.system("/bin/sh")'
```

### 5.3 文件系统类型对比

| 文件系统 | 最大文件 | 最大分区 | 日志 | 特点 |
|---------|---------|---------|------|------|
| **ext4** | 16TB | 1EB | 有 | Linux 默认，稳定可靠 |
| **XFS** | 8EB | 8EB | 有 | 高性能，适合大文件 |
| **Btrfs** | 16EB | 16EB | 有（CoW） | 快照、压缩、校验 |
| **ZFS** | 16EB | 256ZB | 有（CoW） | 企业级，数据完整性 |
| **NTFS** | 16EB | 256TB | 有 | Windows 默认 |
| **FAT32** | 4GB | 2TB | 无 | 兼容性最好 |
| **exFAT** | 16EB | 128PB | 无 | U盘/移动设备 |

### 5.4 ELF 与 PE 文件格式

**ELF 文件结构（Linux 可执行文件）**：

```
ELF Header
  ├── Magic: \x7fELF
  ├── Class: 32/64-bit
  ├── Data: Little/Big Endian
  ├── Type: EXEC(2)/DYN(3)
  ├── Entry Point: 程序入口地址
  └── ...

Program Headers（程序头表）
  ├── LOAD: 可加载段
  │   ├── Text Segment（R-X）：代码段
  │   └── Data Segment（RW-）：数据段
  ├── INTERP: 动态链接器路径
  └── ...

Section Headers（节头表）
  ├── .text：编译后的代码
  ├── .rodata：只读数据
  ├── .data：已初始化的全局变量
  ├── .bss：未初始化的全局变量
  ├── .got：全局偏移表
  ├── .got.plt：PLT 偏移表
  ├── .plt：过程链接表
  ├── .symtab：符号表
  └── .strtab：字符串表

安全分析：
  readelf -h binary    # 查看 ELF 头
  readelf -l binary    # 查看程序头
  readelf -S binary    # 查看节头
  objdump -d binary    # 反汇编
  objdump -R binary    # 查看重定位条目
```

**PE 文件结构（Windows 可执行文件）**：

```
DOS Header
  └── e_lfanew → PE 头偏移

PE Header
  ├── Signature: "PE\0\0"
  ├── COFF Header
  │   ├── Machine: 0x14c(x86) / 0x8664(x64)
  │   ├── NumberOfSections
  │   └── Characteristics（EXE/DLL标志）
  ├── Optional Header
  │   ├── AddressOfEntryPoint（入口点）
  │   ├── ImageBase（默认基地址 0x400000）
  │   ├── DataDirectory（导入/导出表等）
  │   └── ...
  └── Section Table

Sections:
  ├── .text：代码段
  ├── .data：数据段
  ├── .rdata：只读数据
  ├── .rsrc：资源段
  ├── .idata/.idata：导入表
  └── .reloc：重定位表

安全分析：
  PEiD / Detect It Easy → 检测编译器/打包器
  CFF Explorer → PE 结构查看器
  dumpbin /headers binary.exe → MSVC 工具
```
