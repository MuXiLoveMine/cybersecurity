# 第七章：系统调用

### 7.1 常见系统调用

```c
// 文件操作
open(path, flags, mode)     // 打开文件
read(fd, buf, count)       // 读文件
write(fd, buf, count)      // 写文件
close(fd)                  // 关闭文件
unlink(path)               // 删除文件
execve(path, argv, envp)   // 执行程序

// 进程管理
fork()                     // 创建子进程
exit(status)               // 退出进程
waitpid(pid, &status, opt) // 等待子进程
kill(pid, signal)          // 发送信号
getpid()                   // 获取当前 PID

// 内存管理
brk(addr)                  // 修改堆大小
mmap(...)                  // 内存映射
munmap(addr, length)      // 取消映射
mprotect(addr, len, prot)  // 修改内存权限

// 网络操作
socket(domain, type, proto)// 创建套接字
bind(fd, addr, len)        // 绑定地址
listen(fd, backlog)        // 监听
accept(fd, addr, len)      // 接受连接
connect(fd, addr, len)     // 发起连接
send(fd, buf, len, flags)  // 发送数据
recv(fd, buf, len, flags)  // 接收数据
```

### 7.2 Linux 系统调用号

```bash
# 查看系统调用号
cat /usr/include/asm/unistd_64.h

# 常见系统调用号（x86-64）
# 0  - read
# 1  - write
# 2  - open
# 3  - close
# 9  - mmap
# 10 - mprotect
# 11 - munmap
# 57 - fork
# 59 - execve
# 60 - exit
# 101 - ptrace  ← 调试/反调试关键
```

### 7.3 strace 追踪系统调用

```bash
# 追踪程序的系统调用
strace ./program

# 追踪特定系统调用
strace -e trace=read,write,open ./program

# 追踪网络相关
strace -e trace=network ./program

# 追踪子进程
strace -f ./program

# 统计系统调用
strace -c ./program

# 安全应用：
# 1. 分析恶意软件行为（文件读写、网络连接）
# 2. 逆向分析程序逻辑
# 3. 检测后门行为
# 4. 调试程序崩溃
```
