# 第四章：内存管理详解

### 4.1 虚拟内存

虚拟内存是操作系统提供的内存抽象，每个进程都有独立的虚拟地址空间。

```
Linux 进程虚拟地址空间（64 位）：

高地址
┌─────────────────────┐ 0x7fffffffffff
│     内核空间        │ （用户态不可访问）
├─────────────────────┤ 0x800000000000（256TB）
│     栈区 ↓          │ 函数局部变量、调用帧
│                     │
│     （空闲区域）     │
│                     │
│     mmap 区         │ 动态链接库、内存映射文件
│                     │
│     （空闲区域）     │
│                     │
│     堆区 ↑          │ malloc/new 分配
├─────────────────────┤
│     BSS 段          │ 未初始化的全局/静态变量
├─────────────────────┤
│     数据段（Data）  │ 已初始化的全局/静态变量
├─────────────────────┤
│     代码段（Text）  │ 程序指令（只读、可执行）
└─────────────────────┘ 0x0000000000000000
低地址
```

### 4.2 分页机制

```
虚拟地址 → 页表 → 物理地址

x86-64 四级页表：
  虚拟地址（64位）
  ├── PML4 索引（9位）→ PML4 表
  ├── PDPT 索引（9位）→ PDPT 表
  ├── PD 索引（9位）→ PD 表
  ├── PT 索引（9位）→ PT 表
  └── 页内偏移（12位）→ 物理页帧

页大小：
  - 标准页：4KB
  - 大页：2MB（减少 TLB miss）
  - 巨页：1GB（大型数据库）

安全意义：
  - ASLR 随机化页的虚拟地址映射
  - NX 位（不可执行位）在页表项中设置
  - 写保护页可检测缓冲区溢出
```

### 4.3 内存保护机制

| 保护机制 | 原理 | 绕过方法 | 安全等级 |
|---------|------|---------|---------|
| **DEP/NX** | 页表设置不可执行位 | ROP 链跳转到可执行段 | 中 |
| **ASLR** | 随机化基地址 | 信息泄露获取基地址 | 中 |
| **Stack Canary** | 栈中插入随机值 | 泄露 Canary 值 | 中高 |
| **PIE** | 可执行文件基地址随机化 | 信息泄露 | 高 |
| **RELRO** | GOT 只读 | Partial RELRO 仍可写 GOT | 中高 |
| **Fortify** | 编译时检查缓冲区大小 | 使用未检查函数 | 低 |
| **CFI** | 控制流完整性 | 间接跳转绕过 | 高 |

**Stack Canary（栈金丝雀）原理**：

```c
// 编译器在函数序言插入 Canary
void vulnerable_function(char *input) {
    // 栈布局（高地址在上）：
    // ┌──────────────┐
    // │ 返回地址      │ ← 被覆盖时执行流被劫持
    // ├──────────────┤
    // │ Canary 值    │ ← 如果被覆盖，__stack_chk_fail 检测到
    // ├──────────────┤
    // │ 保存的 EBP   │
    // ├──────────────┤
    // │ 局部变量 buf │ ← 溢出起始点
    // └──────────────┘
    
    char buf[64];
    strcpy(buf, input);  // 如果 input 超过 64 字节，覆盖 Canary
}
```

### 4.4 堆内存管理

```
堆分配器演进：

dlmalloc（传统分配器）：
  - 使用 unlink 宏合并空闲块
  - 经典漏洞：unlink 攻击（修改链表指针）

ptmalloc2（glibc 默认）：
  - fastbins：小内存快速分配（单链表 LIFO）
  - unsorted bin：回收的空闲块
  - small bins/large bins：按大小分类

tcmalloc（Google）：
  - 线程缓存减少锁竞争
  - 按大小类分桶

jemalloc（FreeBSD/Firefox）：
  - arena 分配减少碎片
  - 适用于多线程

安全相关：
  - 堆溢出：覆盖相邻堆块的元数据
  - Use-After-Free：利用已释放内存中的残留指针
  - Double Free：重复释放导致链表损坏
  - tcache poisoning：glibc 2.26+ 的 tcache 攻击
```
