# 第一章：操作系统基础

### 1.1 什么是操作系统

操作系统（Operating System，简称 OS）是管理计算机硬件与软件资源的计算机程序，是计算机系统的核心与基石。它位于硬件和应用软件之间，负责资源管理、进程调度、内存管理、文件管理和设备管理等。

```
┌─────────────────────────────────┐
│     应用层（浏览器、办公软件等）   │
├─────────────────────────────────┤
│     操作系统（OS）               │
├─────────────────────────────────┤
│     硬件层（CPU、内存、磁盘等）   │
└─────────────────────────────────┘
```

**操作系统的主要功能**：

| 功能 | 说明 |
|------|------|
| **进程管理** | 进程的创建、调度、终止，CPU 资源分配 |
| **内存管理** | 内存分配、回收、虚拟内存、地址映射 |
| **文件管理** | 文件的创建、读写、删除，目录管理 |
| **设备管理** | 硬件设备驱动、I/O 控制、中断处理 |
| **用户接口** | 提供命令行、图形界面、系统调用等接口 |
| **安全管理** | 用户认证、权限控制、访问控制 |

### 1.2 常见操作系统分类

| 类型 | 代表系统 | 特点 | 适用场景 |
|------|---------|------|---------|
| **桌面 OS** | Windows、macOS、Linux 桌面版 | 图形界面友好，软件生态丰富 | 个人电脑 |
| **服务器 OS** | Linux 服务器版、Windows Server | 稳定可靠，性能优化，支持高并发 | 服务器、云主机 |
| **移动 OS** | Android、iOS | 触控操作，功耗优化，应用商店 | 智能手机、平板 |
| **嵌入式 OS** | 嵌入式 Linux、RTOS、VxWorks | 体积小，实时性强，资源受限 | 路由器、物联网设备 |
| **实时 OS** | FreeRTOS、QNX | 严格的实时响应，确定性调度 | 工业控制、航空航天 |

### 1.3 进程与线程

#### 1.3.1 进程

进程（Process）是程序的一次执行过程，是系统资源分配的基本单位。

- 每个进程有独立的地址空间、文件描述符、内存等资源
- 进程之间相互隔离，一个进程崩溃不影响其他进程
- 进程由操作系统内核管理和调度

**进程的状态**：

| 状态 | 说明 |
|------|------|
| **就绪** | 等待 CPU 调度执行 |
| **运行** | 正在 CPU 上执行 |
| **阻塞** | 等待某个事件（如 I/O 完成）而暂停执行 |
| **终止** | 执行完毕或被终止 |

#### 1.3.2 线程

线程（Thread）是进程内的执行单元，是 CPU 调度的基本单位。

- 一个进程可以包含多个线程，共享进程的地址空间和资源
- 线程之间通信更方便，但需要同步机制防止竞态条件
- 线程切换开销比进程小得多

#### 1.3.3 进程 vs 线程

| 对比项 | 进程 | 线程 |
|--------|------|------|
| 资源 | 拥有独立资源 | 共享进程资源 |
| 切换开销 | 大 | 小 |
| 通信 | 复杂（IPC） | 简单（共享内存） |
| 稳定性 | 高（互不影响） | 低（一个线程崩溃影响整个进程） |
| 并发性 | 低 | 高 |

### 1.4 内存管理

#### 1.4.1 内存层次结构

```
寄存器 → 高速缓存(Cache) → 主存(RAM) → 磁盘 → 磁带/光盘
  小 ←———— 容量 ————————→ 大
  快 ←———— 速度 ————————→ 慢
  贵 ←———— 成本 ————————→ 便宜
```

#### 1.4.2 虚拟内存

虚拟内存是操作系统提供的一种内存管理技术，它使得应用程序认为自己拥有连续可用的内存，而实际上通常被分隔成多个物理内存碎片，还有部分暂时存储在磁盘上。

- **作用**：扩大可用内存空间、隔离进程地址空间、提高内存利用率
- **实现方式**：分页（Paging）、分段（Segmentation）
- **页面置换算法**：FIFO、LRU（最近最少使用）、Clock 算法等

**缺页中断（Page Fault）**：当程序访问的页面不在物理内存中时，触发缺页中断，操作系统将所需页面从磁盘加载到内存。

### 1.5 文件系统

文件系统是操作系统用于明确存储设备（如磁盘）上的文件的方法和数据结构，即文件在存储设备上的组织方式。

#### 常见文件系统

| 文件系统 | 支持系统 | 特点 |
|---------|---------|------|
| **NTFS** | Windows | 支持大文件、权限管理、加密、压缩 |
| **FAT32** | 跨平台 | 兼容性好，单文件最大 4GB |
| **exFAT** | 跨平台 | 支持大文件，U盘常用 |
| **ext4** | Linux | 日志文件系统，稳定可靠，Linux 主流 |
| **xfs** | Linux | 高性能，适合大文件，RHEL 默认 |
| **APFS** | macOS | Apple 文件系统，支持快照、加密 |
| **HFS+** | macOS | 旧版 Mac 文件系统 |

#### 文件系统重要概念

- **inode（索引节点）**：存储文件元数据（权限、所有者、时间戳、数据块指针等），每个文件对应一个 inode
- **硬链接**：指向同一个 inode 的文件名，删除一个不影响其他
- **软链接（符号链接）**：指向另一个文件的路径，类似 Windows 的快捷方式
- **挂载（Mount）**：将文件系统附加到目录树的某个位置

### 1.6 系统调用

系统调用（System Call）是应用程序与操作系统内核之间的接口。应用程序通过系统调用请求内核提供服务（如读写文件、创建进程、分配内存等）。

**常见系统调用类别**：

| 类别 | 示例 |
|------|------|
| **进程控制** | fork（创建进程）、exec（执行程序）、exit（退出）、wait（等待子进程） |
| **文件操作** | open、read、write、close、lseek |
| **设备管理** | ioctl、read、write |
| **信息维护** | getpid、gettimeofday、alarm |
| **通信** | pipe、shmget、semop |

### 1.7 中断与异常

| 类型 | 说明 | 示例 |
|------|------|------|
| **中断（Interrupt）** | 外部设备发起的，异步 | 键盘输入、磁盘 I/O 完成 |
| **异常（Exception）** | CPU 执行指令时产生的，同步 | 除零错误、缺页、非法指令 |
| **陷入（Trap）** | 有意触发的，用于系统调用 | int 0x80 / syscall 指令 |

### 1.8 权限与用户管理

#### Windows 权限体系

- **用户账户**：管理员账户、标准用户账户、来宾账户
- **UAC（用户账户控制）**：防止未经授权的更改，需要管理员权限时弹出确认
- **NTFS 权限**：文件和文件夹的访问控制列表（ACL）
- **组策略**：统一管理计算机和用户配置

#### Linux 权限体系

- **用户（User）与组（Group）**：每个用户有唯一 UID，每个用户可以属于多个组
- **文件权限**：r（读）、w（写）、x（执行），分为所有者、组、其他三组
- **root 用户**：超级管理员，拥有所有权限
- **sudo**：临时获取管理员权限执行命令
- **SUID/SGID**：执行文件时临时获得文件所有者/组的权限
