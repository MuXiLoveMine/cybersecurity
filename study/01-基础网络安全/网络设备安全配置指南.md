## 1. 路由器安全配置

路由器是网络的核心枢纽，一旦被攻破，攻击者即可控制路由流向、截获流量甚至作为跳板攻击内部网络。以下从基本加固、访问控制、路由协议安全和日志审计四个维度展开。

### 1.1 基本加固

#### 1.1.1 修改默认密码与账户管理

出厂默认凭证是网络设备最常见的安全风险之一。设备上线前必须修改所有默认密码，并启用密码加密。

**Cisco IOS 示例：**

```cisco
! 启用密码加密，防止配置文件中明文存储密码
Router(config)# service password-encryption

! 设置特权模式秘密密码（使用 SHA-256 加密）
Router(config)# enable secret 0 YourStrongP@ssw0rd

! 创建本地管理员账户，使用最高加密级别
Router(config)# username netadmin privilege 15 secret 0 AdminStr0ng!Pass

! 配置登录认证使用本地数据库
Router(config)# aaa new-model
Router(config)# aaa authentication login default local
Router(config)# aaa authorization exec default local
```

**华为 VRP 示例：**

```huawei
# 启用密码加密
[Huawei] password-policy min-length 12
[Huawei] aaa
[Huawei-aaa] local-user netadmin password cipher AdminStr0ng!Pass
[Huawei-aaa] local-user netadmin privilege level 15
[Huawei-aaa] local-user netadmin service-type ssh
[Huawei-aaa] quit
```

**加固要点：**
- 密码长度不少于 12 位，包含大小写字母、数字和特殊字符
- 设置密码过期策略，定期轮换
- 遵循最小权限原则，为不同管理员分配不同权限级别

#### 1.1.2 关闭不必要服务

默认情况下，路由器开启了多种服务以方便管理，但这些服务在正式环境中往往成为攻击面。

**Cisco IOS 关闭不必要服务：**

```cisco
! 关闭未使用的服务
Router(config)# no service tcp-small-servers
Router(config)# no service udp-small-servers
Router(config)# no service finger
Router(config)# no ip http server          ! 关闭明文 HTTP 管理
Router(config)# no ip http secure-server   ! 如不需要 Web 管理则关闭
Router(config)# no ip domain-lookup        ! 关闭 DNS 解析（防DNS反射攻击）
Router(config)# no cdp run                 ! 关闭CDP发现协议（内网可按需开启）
Router(config)# no ip source-route         ! 禁用源路由
Router(config)# no service dhcp            ! 如非DHCP服务器则关闭
Router(config)# no bootp server            ! 关闭BOOTP服务
```

**关闭 SNMPv1/v2c（不安全版本）：**

```cisco
Router(config)# no snmp-server community public RO   ! 删除默认社区字符串
Router(config)# no snmp-server community private RW
```

#### 1.1.3 SSH 替代 Telnet

Telnet 以明文传输所有数据（包括密码），必须用 SSH 替代。

**Cisco IOS 配置 SSH：**

```cisco
! 第一步：配置主机名和域名（SSH密钥生成的前提）
Router(config)# hostname CoreRouter01
CoreRouter01(config)# ip domain-name sec.lab.local

! 第二步：生成RSA密钥对（建议至少2048位）
CoreRouter01(config)# crypto key generate rsa modulus 2048

! 第三步：配置SSH参数
CoreRouter01(config)# ip ssh version 2              ! 仅允许SSHv2
CoreRouter01(config)# ip ssh time-out 60            ! 超时60秒
CoreRouter01(config)# ip ssh authentication-retries 3  ! 最大重试3次

! 第四步：限制VTY线路只允许SSH
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# transport input ssh     ! 仅允许SSH登录
CoreRouter01(config-line)# login local
CoreRouter01(config-line)# exec-timeout 5 0         ! 5分钟空闲超时
CoreRouter01(config-line)# exit

! 第五步：关闭Telnet
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# no transport input telnet
```

**华为 VRP 配置 SSH：**

```huawei
[Huawei] rsa local-key-pair create    # 生成RSA密钥
[Huawei] stelnet server enable         # 启用SSH服务器
[Huawei] ssh user netadmin
[Huawei] ssh user netadmin authentication-type password
[Huawei] ssh user netadmin service-type stelnet
[Huawei] ssh server port 22
# 关闭Telnet
[Huawei] user-interface vty 0 4
[Huawei-ui-vty0-4] protocol inbound ssh
```

### 1.2 访问控制列表（ACL）配置

ACL 是路由器的基本流量过滤机制，用于控制哪些流量可以到达或经过设备。

**示例：仅允许管理网段访问设备管理端口**

```cisco
! 定义管理网段ACL
CoreRouter01(config)# ip access-list extended MGMT-ACCESS
CoreRouter01(config-ext-nacl)# permit tcp 10.10.10.0 0.0.0.255 any eq 22
CoreRouter01(config-ext-nacl)# permit tcp 10.10.10.0 0.0.0.255 any eq 443
CoreRouter01(config-ext-nacl)# deny   ip any any log
CoreRouter01(config-ext-nacl)# exit

! 应用到VTY线路
CoreRouter01(config)# line vty 0 4
CoreRouter01(config-line)# access-class MGMT-ACCESS in
CoreRouter01(config-line)# exit
```

**示例：Anti-Spoofing ACL（防IP欺骗）**

```cisco
! 在面向互联网的接口入方向应用
CoreRouter01(config)# ip access-list extended ANTI-SPOOFING
CoreRouter01(config-ext-nacl)# deny   ip 10.0.0.0 0.255.255.255 any    ! 内网地址不应来自外网
CoreRouter01(config-ext-nacl)# deny   ip 172.16.0.0 0.15.255.255 any
CoreRouter01(config-ext-nacl)# deny   ip 192.168.0.0 0.0.255.255 any
CoreRouter01(config-ext-nacl)# deny   ip 127.0.0.0 0.255.255.255 any    ! 环回地址
CoreRouter01(config-ext-nacl)# deny   ip 169.254.0.0 0.0.255.255 any    ! 链路本地地址
CoreRouter01(config-ext-nacl)# permit ip any any
CoreRouter01(config-ext-nacl)# exit

CoreRouter01(config)# interface GigabitEthernet0/0/1
CoreRouter01(config-if)# ip access-group ANTI-SPOOFING in
```

### 1.3 路由协议安全

未认证的路由协议可被攻击者利用注入恶意路由，实现流量劫持。

#### 1.3.1 OSPF 认证配置

**Cisco OSPF MD5 认证：**

```cisco
! 配置OSPF区域认证
CoreRouter01(config)# router ospf 1
CoreRouter01(config-router)# area 0 authentication message-digest
CoreRouter01(config-router)# exit

! 接口级别配置密钥
CoreRouter01(config)# interface GigabitEthernet0/0/0
CoreRouter01(config-if)# ip ospf message-digest-key 1 md5 OSPFsecKey123!
CoreRouter01(config-if)# ip ospf hello-interval 10
CoreRouter01(config-if)# exit
```

**华为 OSPF 认证：**

```huawei
[Huawei] interface GigabitEthernet0/0/0
[Huawei-GigabitEthernet0/0/0] ospf authentication-mode md5 1 cipher OSPFsecKey123!
```

#### 1.3.2 BGP 认证配置

BGP 是互联网核心路由协议，认证尤为关键。

**Cisco BGP TCP MD5 认证：**

```cisco
CoreRouter01(config)# router bgp 65001
CoreRouter01(config-router)# neighbor 203.0.113.2 remote-as 65002
CoreRouter01(config-router)# neighbor 203.0.113.2 password BGPsecKey456!
CoreRouter01(config-router)# neighbor 203.0.113.2 fall-over bfd    ! 快速故障检测
CoreRouter01(config-router)# exit

! 配置前缀列表限制路由更新（防路由劫持）
CoreRouter01(config)# ip prefix-list BGP-IN seq 5 permit 192.0.2.0/24
CoreRouter01(config)# ip prefix-list BGP-IN seq 10 deny 0.0.0.0/0 le 32

CoreRouter01(config)# router bgp 65001
CoreRouter01(config-router)# neighbor 203.0.113.2 prefix-list BGP-IN in
```

### 1.4 日志与审计配置

日志记录是安全事件追踪和取证的关键。

```cisco
! 配置日志时间戳（精确到毫秒）
CoreRouter01(config)# service timestamps log datetime msec localtime show-timezone

! 配置日志缓冲区
CoreRouter01(config)# logging buffered 65536 informational    ! 64KB缓冲区，记录informational及以上级别

! 配置远程Syslog服务器
CoreRouter01(config)# logging 10.10.20.100
CoreRouter01(config)# logging trap informational               ! 发送informational及以上级别
CoreRouter01(config)# logging source-interface Loopback0        ! 指定日志源接口
CoreRouter01(config)# logging facility local6                   ! 定义facility标识

! 配置日志序列号（防篡改）
CoreRouter01(config)# service sequence-numbers

! 开启登录日志
CoreRouter01(config)# login on-success log
CoreRouter01(config)# login on-failure log
```

## 2. 交换机安全配置

交换机工作在数据链路层，二层攻击（如 ARP 欺骗、DHCP 攫取、VLAN 跳跃）往往更隐蔽。以下涵盖核心的二层安全防护技术。

### 2.1 端口安全（Port Security）

端口安全限制每个端口可学习的 MAC 地址数量，防止 MAC 泛洪攻击和非法设备接入。

```cisco
! 进入接入端口配置
Switch(config)# interface FastEthernet0/1

! 开启端口安全
Switch(config-if)# switchport port-security

! 设置最大MAC地址数量（接入端口通常为1-2）
Switch(config-if)# switchport port-security maximum 2

! 配置静态绑定MAC地址（可选，更安全）
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security mac-address aaaa.bbbb.cccc

! 配置违规动作
Switch(config-if)# switchport port-security violation restrict
! restrict: 丢弃违规帧并记录日志（不关闭端口）
! protect : 静默丢弃违规帧（无日志）
! shutdown: 关闭端口（需管理员恢复，最严格）
Switch(config-if)# exit

! 配置端口恢复（err-disable自动恢复）
Switch(config)# errdisable recovery cause psecure-violation
Switch(config)# errdisable recovery interval 300    ! 300秒后自动恢复
```

**最佳实践**：接入端口建议使用 `sticky` + `shutdown` 模式，兼顾安全性和可维护性。

### 2.2 DHCP Snooping

DHCP Snooping 防止非法 DHCP 服务器响应，避免客户端获取错误网关和DNS。

```cisco
! 全局开启DHCP Snooping
Switch(config)# ip dhcp snooping

! 指定VLAN开启DHCP Snooping
Switch(config)# ip dhcp snooping vlan 10,20,30

! 配置信任端口（上联端口/合法DHCP服务器所在端口）
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip dhcp snooping trust
Switch(config-if)# exit

! 非信任端口（接入端口）限制DHCP报文速率（防DHCP泛洪）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# ip dhcp snooping limit rate 15    ! 每秒15个DHCP报文
Switch(config-if-range)# exit

! 开启DHCP Snooping MAC地址验证（Option 82）
Switch(config)# ip dhcp snooping information option
```

**原理**：信任端口可以转发 DHCP Offer/Ack；非信任端口丢弃这些报文。只有连接合法 DHCP 服务器或 DHCP 中继的端口才应设为信任端口。

### 2.3 动态ARP检测（DAI）

DAI 依赖 DHCP Snooping 绑定表，检查 ARP 报文的合法性，防止 ARP 欺骗。

```cisco
! 前提：已配置DHCP Snooping（DAI依赖其绑定表）

! 全局开启DAI（按VLAN）
Switch(config)# ip arp inspection vlan 10,20,30

! 配置信任端口（上连路由器的端口）
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# ip arp inspection trust
Switch(config-if)# exit

! 非信任端口配置ARP速率限制
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# ip arp inspection limit rate 15 burst-compatible
Switch(config-if-range)# exit

! 可选：配置静态ARP绑定（用于无DHCP环境）
Switch(config)# arp access-list STATIC-ARP
Switch(config-arclst)# permit ip host 10.10.10.50 mac host aaaa.bbbb.cccc
Switch(config-arclst)# exit
Switch(config)# ip arp inspection filter STATIC-ARP vlan 10
```

### 2.4 生成树协议安全（STP Security）

STP 用于防止二层环路，但攻击者可伪造根桥优先级来改变网络拓扑。

```cisco
! 配置根保护（防止下游交换机成为根桥）
Switch(config)# interface GigabitEthernet0/2
Switch(config-if)# spanning-tree guard root
Switch(config-if)# exit

! 配置BPDU保护（接入端口不应收到BPDU）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# spanning-tree portfast              ! 接入端口快速进入转发
Switch(config-if-range)# spanning-tree bpduguard enable      ! 收到BPDU则关闭端口
Switch(config-if-range)# exit

! 配置BPDU过滤（可选，完全忽略BPDU，需谨慎使用）
Switch(config)# spanning-tree portfast bpduguard default

! 配置环路保护（防止单向链路导致的环路）
Switch(config)# spanning-tree loopguard default

! 设置根桥优先级（确保核心交换机为根桥）
Switch(config)# spanning-tree vlan 10-30 root primary
```

### 2.5 VLAN安全与隔离

#### 2.5.1 VLAN跳跃攻击防护

VLAN跳跃攻击利用 DTP（动态中继协议）和双标签封装突破 VLAN 隔离。

```cisco
! 接入端口关闭中继协商（防止DTP协商攻击）
Switch(config)# interface range FastEthernet0/1 - 24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport nonegotiate          ! 关闭DTP协商
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# exit

! Trunk端口配置
Switch(config)# interface GigabitEthernet0/24
Switch(config-if)# switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30    ! 明确允许的VLAN
Switch(config-if)# switchport trunk native vlan 999           ! 将Native VLAN设为未使用VLAN
Switch(config-if)# switchport nonegotiate
Switch(config-if)# exit

! 将VLAN 1作为Unused VLAN（VLAN 1默认承载管理流量，易被攻击）
Switch(config)# vlan 999
Switch(config-vlan)# name UNUSED-NATIVE
Switch(config-vlan)# state suspend
Switch(config-vlan)# exit
```

#### 2.5.2 Private VLAN（PVLAN）实现端口级隔离

```cisco
! 配置Primary VLAN
Switch(config)# vlan 100
Switch(config-vlan)# private-vlan primary
Switch(config-vlan)# exit

! 配置Isolated VLAN（隔离VLAN，端口间不可通信）
Switch(config)# vlan 201
Switch(config-vlan)# private-vlan isolated
Switch(config-vlan)# exit

! 配置Community VLAN（社区VLAN，组内可通信）
Switch(config)# vlan 202
Switch(config-vlan)# private-vlan community
Switch(config-vlan)# exit

! 关联Primary与Secondary VLAN
Switch(config)# vlan 100
Switch(config-vlan)# private-vlan association 201,202
Switch(config-vlan)# exit

! 将端口划入PVLAN
Switch(config)# interface FastEthernet0/5
Switch(config-if)# switchport mode private-vlan host
Switch(config-if)# switchport private-vlan host-association 100 201
Switch(config-if)# exit
```

## 3. 防火墙安全配置

防火墙是网络安全的第一道防线，策略设计的合理性直接决定整体安全水平。

### 3.1 防火墙策略设计原则

1. **默认拒绝原则**：未经明确允许的流量一律拒绝
2. **最小权限原则**：只开放业务必需的端口和协议
3. **纵深防御原则**：多层过滤，不依赖单一规则
4. **规则精简原则**：定期清理冗余和过期规则，避免规则膨胀
5. **从严格到宽松**：高优先级规则放在最前，提高匹配效率

### 3.2 区域划分与安全域

将网络划分为不同安全等级的区域，区域间流量受策略控制。

```
互联网 (Untrust, 安全等级 5)
    │
    ├── 外部防火墙
    │
DMZ区 (安全等级 50)
  └── Web服务器、邮件服务器、DNS服务器
    │
    ├── 内部防火墙
    │
内部网络 (Trust, 安全等级 100)
  └── 办公网、生产网、管理网
    │
    ├── 隔离防火墙
    │
核心数据区 (安全等级 85)
  └── 数据库、文件服务器
```

**Cisco ASA 区域与策略配置示例：**

```cisco
! 定义安全区域
ciscoasa(config)# interface GigabitEthernet0/0
ciscoasa(config-if)# nameif outside
ciscoasa(config-if)# security-level 0
ciscoasa(config-if)# ip address 203.0.113.1 255.255.255.240

ciscoasa(config)# interface GigabitEthernet0/1
ciscoasa(config-if)# nameif inside
ciscoasa(config-if)# security-level 100
ciscoasa(config-if)# ip address 10.10.10.1 255.255.255.0

ciscoasa(config)# interface GigabitEthernet0/2
ciscoasa(config-if)# nameif dmz
ciscoasa(config-if)# security-level 50
ciscoasa(config-if)# ip address 192.0.2.1 255.255.255.0

! 配置安全策略：仅允许外部访问DMZ的Web服务
ciscoasa(config)# object network WEB-SERVER
ciscoasa(config-network-object)# host 192.0.2.10
ciscoasa(config-network-object)# exit

ciscoasa(config)# object network WEB-SERVICE
ciscoasa(config-network-object)# service tcp 80 443
ciscoasa(config-network-object)# exit

ciscoasa(config)# access-list OUTSIDE_IN extended permit tcp any object WEB-SERVER eq www
ciscoasa(config)# access-list OUTSIDE_IN extended permit tcp any object WEB-SERVER eq https
ciscoasa(config)# access-list OUTSIDE_IN extended deny ip any any log

ciscoasa(config)# access-group OUTSIDE_IN in interface outside
```

### 3.3 NAT配置安全

NAT 可隐藏内部网络结构，但也需注意安全配置。

```cisco
! 配置动态PAT（内部用户上网）
ciscoasa(config)# object network INSIDE-NET
ciscoasa(config-network-object)# subnet 10.10.10.0 255.255.255.0
ciscoasa(config-network-object)# exit

ciscoasa(config)# nat (inside,outside) dynamic interface

! 配置静态NAT（DMZ服务器发布，端口级精确映射）
ciscoasa(config)# object network WEB-SERVER
ciscoasa(config-network-object)# host 192.0.2.10
ciscoasa(config-network-object)# exit

ciscoasa(config)# nat (dmz,outside) static 203.0.113.10 service tcp www www
ciscoasa(config)# nat (dmz,outside) static 203.0.113.10 service tcp https https

! 注意：DNS重写（DNS Doctoring）防止内部用户使用外部地址访问内部服务器
ciscoasa(config)# nat (inside,dmz) static 192.0.2.10 dns
```

### 3.4 VPN网关配置

VPN 提供加密的远程接入通道，以下是 Site-to-Site IPSec VPN 配置示例。

**Cisco ASA Site-to-Site IPSec VPN：**

```cisco
! 第一阶段：ISAKMP策略配置
ciscoasa(config)# crypto ikev1 policy 10
ciscoasa(config-ikev1-policy)# authentication pre-share
ciscoasa(config-ikev1-policy)# encryption aes-256
ciscoasa(config-ikev1-policy)# hash sha
ciscoasa(config-ikev1-policy)# group 2
ciscoasa(config-ikev1-policy)# lifetime 86400
ciscoasa(config-ikev1-policy)# exit

! 配置隧道组（预共享密钥）
ciscoasa(config)# tunnel-group 198.51.100.2 type ipsec-l2l
ciscoasa(config)# tunnel-group 198.51.100.2 ipsec-attributes
ciscoasa(config-tunnel-ipsec)# ikev1 pre-shared-key VPNStr0ngKey789!
ciscoasa(config-tunnel-ipsec)# exit

! 第二阶段：IPSec变换集
ciscoasa(config)# crypto ipsec ikev1 transform-set TS-SET esp-aes-256 esp-sha-hmac

! 配置感兴趣流量
ciscoasa(config)# access-list VPN-TRAFFIC extended permit ip 10.10.10.0 255.255.255.0 172.16.20.0 255.255.255.0

! 配置Crypto Map
ciscoasa(config)# crypto map VPN-MAP 10 match address VPN-TRAFFIC
ciscoasa(config)# crypto map VPN-MAP 10 set peer 198.51.100.2
ciscoasa(config)# crypto map VPN-MAP 10 set ikev1 transform-set TS-SET
```

## 6. 常见网络设备漏洞

### 6.1 默认凭证风险

**风险描述**：许多网络设备出厂时带有默认管理员账户和密码（如 `admin/admin`、`cisco/cisco`），攻击者可通过搜索引擎或漏洞数据库（如 Shodan、Exploit-DB）快速发现暴露在互联网上的设备。

**防护措施**：
- 设备上线前强制修改所有默认密码
- 使用强密码策略（12位以上，混合字符）
- 禁用不必要的默认账户
- 定期审计凭据使用情况

### 6.2 管理接口暴露

**风险描述**：网络设备的管理接口（HTTP/HTTPS/Telnet/SSH）暴露在公网，攻击者可进行暴力破解或利用已知漏洞直接攻击。

**防护措施**：
- 管理接口仅允许内网管理网段访问
- 通过 ACL 限制源地址
- 使用堡垒机（Jump Server）集中管理
- 定期检查暴露面（使用 Shodan/Censys 自查）

```cisco
! 管理接口仅允许管理网段访问
Router(config)# ip access-list standard MGMT-ACL
Router(config-std-nacl)# permit 10.10.10.0 0.0.0.255
Router(config-std-nacl)# deny any log
Router(config-std-nacl)# exit

Router(config)# line vty 0 4
Router(config-line)# access-class MGMT-ACL in
```

### 6.3 SNMP社区字符串泄露

**风险描述**：SNMPv1/v2c 使用明文社区字符串认证，默认值 `public`（只读）和 `private`（读写）广为人知。攻击者获取读写权限后可修改设备配置。

**防护措施**：
- 升级至 SNMPv3（支持加密和认证）
- 删除默认社区字符串
- 使用复杂社区字符串（20位以上随机字符）
- 限制 SNMP 访问源地址

```cisco
! 配置SNMPv3
Router(config)# no snmp-server community public RO
Router(config)# no snmp-server community private RW

Router(config)# snmp-server group ADMINGROUP v3 priv read VIEW-ALL write VIEW-ALL
Router(config)# snmp-server user netadmin ADMINGROUP v3 auth sha AuthP@ss123! priv aes 128 EncrKey456!
Router(config)# snmp-server view VIEW-ALL iso included

! 限制SNMP访问源
Router(config)# snmp-server community restrict
Router(config)# ip access-list standard SNMP-ACL
Router(config-std-nacl)# permit 10.10.10.0 0.0.0.255
Router(config-std-nacl)# deny any log
Router(config-std-nacl)# exit
Router(config)# snmp-server group ADMINGROUP v3 priv access SNMP-ACL
```

### 6.4 配置文件泄露

**风险描述**：配置文件包含所有密码、密钥和策略信息。通过 TFTP 明文备份、HTTP 目录遍历或物理访问，攻击者可获取完整配置。

**防护措施**：
- 启用密码加密（`service password-encryption`）
- 使用 SCP 替代 TFTP 进行配置传输
- 限制配置文件访问权限
- 定期检查异常配置导出操作

```cisco
! 使用SCP替代TFTP传输配置
Router(config)# ip scp server enable
Router(config)# aaa authentication scp default local

! 禁用TFTP服务器
Router(config)# no tftp-server flash:

! 配置文件加密备份
Router(config)# archive
Router(config-archive)# path scp://10.10.20.50/backup/router-config
Router(config-archive)# write-memory
Router(config-archive)# time-period 86400    ! 每天自动备份
```
