### 一、iptables 常用命令速查表

#### 1. 基础管理命令

| 命令 | 说明 |
|------|------|
| `iptables -L -n -v` | 查看所有规则（数字显示，带计数） |
| `iptables -L INPUT -n -v --line-numbers` | 查看INPUT链规则，带行号 |
| `iptables -S` | 以保存格式输出所有规则（便于备份） |
| `iptables -F` | 清空所有规则（**慎用！远程操作可能断连**） |
| `iptables -F INPUT` | 清空指定链的规则 |
| `iptables -Z` | 清零所有计数器 |
| `iptables -Z INPUT` | 清零指定链计数器 |
| `iptables -P INPUT DROP` | 设置链默认策略（DROP/ACCEPT） |
| `iptables-save > /etc/iptables/rules.v4` | 保存规则到文件 |
| `iptables-restore < /etc/iptables/rules.v4` | 从文件恢复规则 |
| `iptables -D INPUT 3` | 删除第3条规则（用--line-numbers查行号） |
| `iptables -I INPUT 2 -p tcp --dport 80 -j ACCEPT` | 在第2行前插入规则 |
| `iptables -R INPUT 2 -p tcp --dport 8080 -j ACCEPT` | 替换第2条规则 |

> **安全提醒：** 远程操作 iptables 时，建议先用 `sleep 30 && iptables -F` 放在后台，防止规则配置错误导致无法远程连接。

#### 2. 常用规则参数速查

| 参数 | 说明 | 示例 |
|------|------|------|
| `-A chain` | 追加规则到链末尾 | `iptables -A INPUT ...` |
| `-I chain [n]` | 插入规则到第n条前 | `iptables -I INPUT 1 ...` |
| `-p protocol` | 指定协议（tcp/udp/icmp/all） | `-p tcp` |
| `-s address` | 源IP/网段 | `-s 192.168.1.0/24` |
| `-d address` | 目的IP/网段 | `-d 10.0.0.1` |
| `-i interface` | 入站网卡 | `-i eth0` |
| `-o interface` | 出站网卡 | `-o eth0` |
| `--sport port` | 源端口（TCP/UDP） | `--sport 1024:65535` |
| `--dport port` | 目的端口（TCP/UDP） | `--dport 22` |
| `-m state --state STATE` | 连接状态匹配 | `-m state --state ESTABLISHED,RELATED` |
| `-m limit --limit n/s` | 速率限制 | `-m limit --limit 10/min` |
| `-m mac --mac-source` | MAC地址匹配 | `-m mac --mac-source 00:11:22:33:44:55` |
| `-m multiport --dports` | 多端口匹配 | `-m multiport --dports 80,443,8080` |
| `-m string --string "keyword"` | 字符串匹配 | `-m string --string "cmd.exe" --algo bm` |
| `-j TARGET` | 目标动作 | `-j ACCEPT / DROP / REJECT / LOG / DNAT / SNAT / MASQUERADE` |
| `--log-prefix "prefix"` | LOG目标的前缀 | `-j LOG --log-prefix "IPTABLES-DROP: "` |

#### 3. 实战场景规则集

**场景1：基础服务器防火墙（白名单策略）**

```bash
# ===== 基础策略 =====
# 默认全部拒绝
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 允许回环接口
iptables -A INPUT -i lo -j ACCEPT
iptables -A OUTPUT -o lo -j ACCEPT

# 允许已建立和相关连接（关键！否则响应包被挡）
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# ===== 开放服务端口 =====
# 允许 SSH（建议限制IP）
iptables -A INPUT -p tcp --dport 22 -s 192.168.1.0/24 -m state --state NEW -j ACCEPT

# 允许 HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -m state --state NEW -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -m state --state NEW -j ACCEPT

# 允许内网 ping
iptables -A INPUT -p icmp --icmp-type echo-request -s 192.168.1.0/24 -j ACCEPT

# 记录被拒绝的包（便于排查）
iptables -A INPUT -j LOG --log-prefix "IPTABLES-INPUT-DROP: " --log-level 4
```

**场景2：防止端口扫描**

```bash
# SYN扫描检测：短时间内大量SYN包则拒绝
iptables -N PORT_SCAN
iptables -A PORT_SCAN -m recent --set --name portscan --rsource
iptables -A PORT_SCAN -m recent --update --seconds 60 --hitcount 20 --name portscan --rsource -j DROP
iptables -A PORT_SCAN -j RETURN

# 在INPUT链引用（放在开放端口规则之前）
iptables -I INPUT 1 -p tcp --syn -j PORT_SCAN
```

**场景3：NAT/共享上网**

```bash
# 开启IP转发（临时）
echo 1 > /proc/sys/net/ipv4/ip_forward

# MASQUERADE：内网通过公网网卡上网
iptables -t nat -A POSTROUTING -o eth0 -s 192.168.1.0/24 -j MASQUERADE

# 端口转发：外网访问内网服务器
# 将公网IP的8080端口转发到内网192.168.1.100:80
iptables -t nat -A PREROUTING -i eth0 -p tcp --dport 8080 -j DNAT --to-destination 192.168.1.100:80
# FORWARD链也要放行
iptables -A FORWARD -d 192.168.1.100 -p tcp --dport 80 -j ACCEPT
```

**场景4：防DDoS基础配置**

```bash
# 限制单个IP的并发连接数（如HTTP）
iptables -A INPUT -p tcp --dport 80 -m connlimit --connlimit-above 50 -j DROP

# 限制SYN包速率（防止SYN Flood）
iptables -A INPUT -p tcp --syn -m limit --limit 10/s --limit-burst 20 -j ACCEPT
iptables -A INPUT -p tcp --syn -j DROP

# 限制ICMP请求速率
iptables -A INPUT -p icmp --icmp-type echo-request -m limit --limit 1/s --limit-burst 5 -j ACCEPT
```

#### 4. iptables 规则持久化

| 系统 | 保存命令 | 恢复/加载方式 |
|------|----------|--------------|
| CentOS/RHEL | `service iptables save` | `service iptables restart` |
| Debian/Ubuntu | `iptables-save > /etc/iptables/rules.v4` | `iptables-persistent` 包自动加载 |

### 二、SSH 配置加固脚本示例

#### 1. 一键加固脚本（ssh_hardening.sh）

```bash
#!/bin/bash
# ============================================================
# SSH 安全加固脚本
# 适用：CentOS 7+/Ubuntu 18.04+/Debian 10+
# 注意：执行前请确保有其他访问方式（如控制台），防止被锁在外面
# ============================================================

set -e

SSH_CONFIG="/etc/ssh/sshd_config"
BACKUP_DIR="/etc/ssh/backup-$(date +%Y%m%d%H%M%S)"

# ===== 0. 前置检查 =====
if [ "$(id -u)" -ne 0 ]; then
    echo "[!] 请以 root 身份运行此脚本"
    exit 1
fi

echo "[*] 开始 SSH 安全加固..."

# ===== 1. 备份原始配置 =====
mkdir -p "$BACKUP_DIR"
cp "$SSH_CONFIG" "$BACKUP_DIR/sshd_config.bak"
echo "[+] 原始配置已备份至: $BACKUP_DIR/sshd_config.bak"

# ===== 2. 基础安全配置 =====
echo "[*] 配置基础安全项..."

# 修改默认端口（建议改为非22端口，此处示例为2222）
# 注意：执行前请确保防火墙已放行新端口！
sed -i 's/^#\?Port .*/Port 2222/' "$SSH_CONFIG"

# 禁用root直接登录（关键！）
sed -i 's/^#\?PermitRootLogin .*/PermitRootLogin no/' "$SSH_CONFIG"

# 禁用空密码
sed -i 's/^#\?PermitEmptyPasswords .*/PermitEmptyPasswords no/' "$SSH_CONFIG"

# 禁用密码认证（建议配合密钥登录使用）
# 注意：确保密钥登录正常后再启用！
# sed -i 's/^#\?PasswordAuthentication .*/PasswordAuthentication no/' "$SSH_CONFIG"

# 启用公钥认证
sed -i 's/^#\?PubkeyAuthentication .*/PubkeyAuthentication yes/' "$SSH_CONFIG"

# 禁用X11转发
sed -i 's/^#\?X11Forwarding .*/X11Forwarding no/' "$SSH_CONFIG"

# 设置最大认证尝试次数（暴力破解防护）
sed -i 's/^#\?MaxAuthTries .*/MaxAuthTries 3/' "$SSH_CONFIG"

# 设置登录超时时间（无操作自动断开）
sed -i 's/^#\?ClientAliveInterval .*/ClientAliveInterval 300/' "$SSH_CONFIG"
sed -i 's/^#\?ClientAliveCountMax .*/ClientAliveCountMax 2/' "$SSH_CONFIG"
# 解释：每300秒发一次探测，2次无响应则断开，即10分钟超时

# 禁用TCP转发（如不需要可禁用，减少攻击面）
sed -i 's/^#\?AllowTcpForwarding .*/AllowTcpForwarding no/' "$SSH_CONFIG"

# 禁用代理转发
sed -i 's/^#\?AllowAgentForwarding .*/AllowAgentForwarding no/' "$SSH_CONFIG"

# 禁用SFTP（如不需要）
# sed -i 's/^Subsystem sftp/#Subsystem sftp/' "$SSH_CONFIG"

# 登录后显示Banner
echo "Authorized access only. All activities are monitored." > /etc/ssh/banner
sed -i 's/^#\?Banner .*/Banner \/etc\/ssh\/banner/' "$SSH_CONFIG"

# 只允许指定用户登录（白名单，按需启用）
# echo "AllowUsers admin deploy" >> "$SSH_CONFIG"

# 只允许指定用户组
# echo "AllowGroups sshusers" >> "$SSH_CONFIG"

# 使用更安全的KEX算法和加密算法（兼容现代SSH客户端）
cat >> "$SSH_CONFIG" << 'EOF'

# ===== 加密算法加固 =====
KexAlgorithms curve25519-sha256@libssh.org,diffie-hellman-group-exchange-sha256
Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com,aes128-gcm@openssh.com,aes256-ctr,aes192-ctr,aes128-ctr
MACs hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com,umac-128-etm@openssh.com
EOF

# ===== 3. 配置 fail2ban 防暴力破解 =====
echo "[*] 配置 fail2ban 防暴力破解..."

if command -v apt-get &> /dev/null; then
    apt-get update -qq && apt-get install -y -qq fail2ban
elif command -v yum &> /dev/null; then
    yum install -y -q epel-release && yum install -y -q fail2ban
fi

if [ -d /etc/fail2ban ]; then
    cat > /etc/fail2ban/jail.local << 'EOF'
[DEFAULT]
bantime = 3600    # 封禁1小时
findtime = 600    # 10分钟内
maxretry = 3      # 失败3次即封禁
ignoreip = 127.0.0.1/8 192.168.1.0/24  # 白名单IP

[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 86400   # SSH封禁24小时
EOF
    systemctl enable fail2ban --now
    echo "[+] fail2ban 已配置并启动"
else
    echo "[-] fail2ban 安装失败，请手动安装"
fi

# ===== 4. SSH 密钥登录配置 =====
echo "[*] 配置密钥登录..."

# 创建普通管理员用户（如不存在）
if ! id -u admin &> /dev/null; then
    useradd -m -s /bin/bash admin
    echo "[+] 创建 admin 用户"
    echo "[!] 请设置 admin 用户密码: passwd admin"
fi

# 创建.ssh目录（admin用户）
mkdir -p /home/admin/.ssh
chmod 700 /home/admin/.ssh
touch /home/admin/.ssh/authorized_keys
chmod 600 /home/admin/.ssh/authorized_keys
chown -R admin:admin /home/admin/.ssh

echo "[!] 请将公钥添加到 /home/admin/.ssh/authorized_keys"
echo "    示例：echo '你的公钥内容' >> /home/admin/.ssh/authorized_keys"

# ===== 5. 验证配置语法 =====
echo "[*] 验证 sshd 配置语法..."
if sshd -t; then
    echo "[+] 配置语法检查通过"
else
    echo "[!] 配置语法错误！正在恢复备份..."
    cp "$BACKUP_DIR/sshd_config.bak" "$SSH_CONFIG"
    exit 1
fi

# ===== 6. 重启 SSH 服务 =====
echo "[*] 重启 SSH 服务..."
if systemctl restart sshd; then
    echo "[+] SSH 服务重启成功"
else
    echo "[!] SSH 服务重启失败！正在恢复备份..."
    cp "$BACKUP_DIR/sshd_config.bak" "$SSH_CONFIG"
    systemctl restart sshd
    exit 1
fi

echo ""
echo "=============================================="
echo " SSH 加固完成！"
echo "=============================================="
echo " 备份目录: $BACKUP_DIR"
echo " SSH 端口: 2222（请确保防火墙已放行）"
echo " root登录: 已禁用"
echo " 密钥登录: 已启用（请先添加公钥再禁用密码）"
echo " fail2ban: 已配置（3次失败封禁24小时）"
echo ""
echo " 下一步操作："
echo "  1. 在新终端测试用 admin 用户密钥登录"
echo "  2. 确认正常后，将 PasswordAuthentication 设为 no"
echo "  3. 如需root权限，配置 sudoers 让 admin 可 sudo"
echo "=============================================="
```

**使用方法：**

```bash
# 1. 上传脚本到服务器
# 2. 添加执行权限
chmod +x ssh_hardening.sh

# 3. 执行前先确保有备用访问方式！
#    建议先在测试环境验证

# 4. 执行
./ssh_hardening.sh
```

#### 3. SSH 安全检查清单脚本

```bash
#!/bin/bash
# SSH 安全配置检查脚本
# 快速检查常见安全配置项是否正确设置

echo "===== SSH 安全配置检查 ====="
echo ""

CONFIG="/etc/ssh/sshd_config"

check_config() {
    local key=$1
    local expected=$2
    local actual=$(grep -E "^${key}" "$CONFIG" | awk '{print $2}' | head -1)
    if [ "$actual" = "$expected" ]; then
        echo "[PASS] $key = $actual"
    else
        echo "[FAIL] $key = ${actual:-未设置} (期望: $expected)"
    fi
}

echo "--- 基础安全 ---"
check_config "PermitRootLogin" "no"
check_config "PermitEmptyPasswords" "no"
check_config "PubkeyAuthentication" "yes"
# check_config "PasswordAuthentication" "no"  # 可选检查

echo ""
echo "--- 协议与加密 ---"
check_config "Protocol" "2"  # SSHv2
check_config "X11Forwarding" "no"
check_config "AllowTcpForwarding" "no"

echo ""
echo "--- 会话安全 ---"
check_config "MaxAuthTries" "3"
check_config "ClientAliveInterval" "300"

echo ""
echo "--- fail2ban 状态 ---"
if systemctl is-active --quiet fail2ban; then
    echo "[PASS] fail2ban 正在运行"
    fail2ban-client status sshd 2>/dev/null | grep -E "Currently banned|Total banned"
else
    echo "[FAIL] fail2ban 未运行或未安装"
fi

echo ""
echo "===== 检查完成 ====="
```
