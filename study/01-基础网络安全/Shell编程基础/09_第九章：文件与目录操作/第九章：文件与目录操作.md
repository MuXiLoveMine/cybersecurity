# 第九章：文件与目录操作

### 9.1 文件读写

```bash
# 读取文件内容
content=$(cat filename)

# 逐行读取文件
while read line; do
    echo "行内容：$line"
done < filename

# 写入文件（覆盖）
echo "hello" > output.txt

# 追加写入
echo "world" >> output.txt

# 多行写入（Here Document）
cat > output.txt << EOF
第一行内容
第二行内容
第三行内容
EOF

# Here String（从字符串读取）
read a b <<< "hello world"
echo "a=$a, b=$b"
```

### 9.2 文件属性判断

| 测试符 | 含义 |
|--------|------|
| `-e` | 存在 |
| `-f` | 普通文件 |
| `-d` | 目录 |
| `-r` | 可读 |
| `-w` | 可写 |
| `-x` | 可执行 |
| `-s` | 非空（大小 > 0） |
| `-L` | 符号链接 |
| `-b` | 块设备文件 |
| `-c` | 字符设备文件 |
| `-p` | 管道文件 |
| `-S` | 套接字文件 |
| `-nt` | 比...新（file1 -nt file2） |
| `-ot` | 比...旧（file1 -ot file2） |

```bash
file="/etc/passwd"

if [ -f "$file" ]; then
    echo "$file 存在且是普通文件"
    if [ -r "$file" ]; then
        echo "文件可读"
    fi
    if [ -s "$file" ]; then
        echo "文件非空"
    fi
fi
```

### 9.3 目录遍历

```bash
# 遍历目录下的文件
for file in /etc/*; do
    if [ -f "$file" ]; then
        echo "文件：$file"
    fi
done

# 递归遍历目录
find /etc -name "*.conf" -type f | while read file; do
    echo "配置文件：$file"
done

# 遍历目录树
for dir in $(find /path -type d); do
    echo "目录：$dir"
done
```

### 9.4 文件描述符与重定向

| 文件描述符 | 名称 | 说明 |
|-----------|------|------|
| 0 | stdin | 标准输入 |
| 1 | stdout | 标准输出 |
| 2 | stderr | 标准错误 |

```bash
# 重定向标准输出
echo "hello" > output.txt     # 覆盖
echo "hello" >> output.txt    # 追加

# 重定向标准错误
ls /nonexist 2> error.log     # 错误输出到文件
ls /nonexist 2>> error.log    # 追加错误

# 同时重定向 stdout 和 stderr
command > output.txt 2>&1
# 或简写（Bash 4+）
command &> output.txt

# 丢弃输出（黑洞）
command > /dev/null 2>&1

# 从文件读取输入
read line < input.txt

# 同时重定向输入和输出
command < input.txt > output.txt 2>&1
```

### 9.5 文件权限操作

```bash
# 修改权限
chmod 755 script.sh
chmod +x script.sh       # 添加执行权限
chmod -R 644 /path/dir   # 递归修改

# 修改所有者
chown user:group file.txt
chown -R user:group /path

# 修改所属组
chgrp group file.txt
```
