# 第三章：变量与数据类型

### 3.1 变量定义

```bash
# 定义变量（等号两边不能有空格！）
name="张三"
age=25
pi=3.14

# 使用变量（在变量名前加 $）
echo "姓名：$name"
echo "年龄：$age"

# 推荐使用 ${变量名} 形式，避免歧义
echo "我叫${name}，今年${age}岁"

# 只读变量（不可修改）
readonly PI=3.14159
PI=3.14   # 报错：PI: readonly variable

# 删除变量（不能删除只读变量）
unset age
echo $age   # 空值
```

### 3.2 变量命名规则

- 变量名由字母、数字、下划线组成
- 不能以数字开头
- 区分大小写
- 不能使用 Shell 关键字（if、for、while 等）

```bash
# 正确
my_var="hello"
Var1=123
_user="admin"

# 错误
1var=123        # 数字开头
my-var="hello"  # 包含连字符
var name="hi"   # 有空格
```

### 3.3 变量类型

Bash 是弱类型语言，变量默认都是字符串，根据上下文自动转换。

```bash
# 字符串
str="hello world"

# 整数
num=100
result=$((num + 50))

# 数组
arr=("apple" "banana" "cherry")
```

### 3.4 特殊变量

| 变量 | 说明 |
|------|------|
| `$0` | 当前脚本的文件名 |
| `$n` | 第 n 个命令行参数（n=1~9，n>9 用 ${n}） |
| `$#` | 命令行参数的个数 |
| `$*` | 所有参数作为一个字符串 |
| `$@` | 所有参数，每个参数都是独立的（引号保留） |
| `$?` | 上一个命令的退出状态码 |
| `$$` | 当前 Shell 进程的 PID |
| `$!` | 后台运行的最后一个进程的 PID |
| `$_` | 上一个命令的最后一个参数 |

**示例**：

```bash
#!/bin/bash
echo "脚本名：$0"
echo "第一个参数：$1"
echo "第二个参数：$2"
echo "参数个数：$#"
echo "所有参数（\$*）：$*"
echo "所有参数（\$@）：$@"
echo "当前 PID：$$"
```

运行：`./script.sh hello world`

### 3.5 环境变量

环境变量是全局变量，对所有子进程可见：

```bash
# 查看所有环境变量
env
printenv

# 查看某个环境变量
echo $PATH
echo $HOME
echo $USER
echo $SHELL
echo $PWD
echo $LANG

# 设置环境变量（当前 Shell 有效）
export MY_VAR="hello"

# 永久设置环境变量
# 在 ~/.bashrc 或 ~/.bash_profile 中添加：
# export MY_VAR="hello"
```

**常见环境变量**：

| 变量 | 说明 |
|------|------|
| `PATH` | 命令搜索路径，目录间用冒号分隔 |
| `HOME` | 当前用户的主目录 |
| `USER` | 当前用户名 |
| `SHELL` | 当前使用的 Shell |
| `PWD` | 当前工作目录 |
| `OLDPWD` | 上一个工作目录 |
| `LANG` | 系统语言和字符编码 |
| `PS1` | 命令提示符格式 |
| `HOSTNAME` | 主机名 |

### 3.6 变量的高级用法

```bash
# 变量默认值
# ${var:-default}  var 不存在或为空时返回 default
echo ${name:-"匿名"}

# ${var:=default}  var 不存在或为空时赋值 default 并返回
echo ${name:="匿名"}

# ${var:?message}  var 不存在或为空时报错并退出
echo ${name:?"变量 name 未定义"}

# 变量长度
str="hello world"
echo ${#str}    # 输出 11

# 字符串截取
echo ${str:0:5}   # 从第 0 位开始取 5 个字符 → hello
echo ${str:6}     # 从第 6 位开始取到结尾 → world
echo ${str: -5}   # 从倒数第 5 位开始取 → world（注意冒号后空格）

# 删除匹配
str="hello world hello"
echo ${str#hello}    # 删除最短匹配（从左）→  world hello
echo ${str##hello}   # 删除最长匹配（从左）→  world hello
echo ${str%hello}    # 删除最短匹配（从右）→ hello world 
echo ${str%%hello}   # 删除最长匹配（从右）→ hello world 

# 替换
echo ${str/hello/hi}    # 替换第一个 → hi world hello
echo ${str//hello/hi}   # 替换所有 → hi world hi
```
