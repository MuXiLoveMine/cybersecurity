# 第十二章：Shell 调试与最佳实践

### 12.1 Shell 调试

```bash
# 方式一：使用 bash -x 运行脚本
bash -x script.sh

# 方式二：在脚本中添加 set -x
set -x     # 开启调试（显示执行的命令和变量）
# ... 调试的代码段 ...
set +x     # 关闭调试

# 其他调试选项
set -e     # 遇到错误立即退出
set -u     # 使用未定义的变量时报错
set -o pipefail   # 管道中任一命令失败则整体失败
```

**常用 set 选项**：

| 选项 | 说明 |
|------|------|
| `-e` | 命令失败（非 0 退出码）时立即退出脚本 |
| `-u` | 使用未定义变量时报错 |
| `-x` | 调试模式，打印执行的命令和参数 |
| `-v` | 详细模式，打印读取的每一行输入 |
| `-n` | 语法检查，不实际执行 |
| `-o pipefail` | 管道中任一命令失败，整体返回失败 |

> **推荐脚本开头**：`set -euo pipefail`

### 12.2 错误处理

```bash
# 检查命令是否成功
if command; then
    echo "成功"
else
    echo "失败"
    exit 1
fi

# 失败时退出
command || exit 1

# 失败时输出错误信息并退出
command || { echo "命令失败"; exit 1; }

# 自定义错误函数
error_exit() {
    echo "错误：$1" >&2
    exit 1
}

command || error_exit "执行 command 失败"
```

### 12.3 最佳实践

1. **脚本开头加上 Shebang 和基本设置**
   ```bash
   #!/bin/bash
   set -euo pipefail
   ```

2. **使用有意义的变量名**，避免 a、b、c 这种无意义的命名

3. **变量用双引号括起来**，防止单词拆分和空变量问题
   ```bash
   if [ "$name" = "admin" ]; then ...
   ```

4. **函数内使用 local 变量**，避免污染全局命名空间

5. **添加注释**，说明脚本的用途、参数、返回值等

6. **使用函数封装重复代码**，提高复用性和可维护性

7. **使用 `$()` 代替反引号**，更易读且支持嵌套

8. **脚本加执行权限**，使用 `./script.sh` 方式运行

9. **输入验证**，检查用户输入和参数是否合法

10. **错误处理**，对可能失败的命令进行错误检查

11. **使用 [[ ]] 代替 [ ]**，更强大更安全

12. **脚本文件命名规范**，使用 `.sh` 后缀，小写字母和下划线

### 12.4 常用脚本模板

```bash
#!/bin/bash
set -euo pipefail

# ============================================================
# 脚本名称：script_name.sh
# 功能描述：脚本的功能说明
# 作者：Your Name
# 创建日期：2026-01-01
# 用法：./script_name.sh [参数]
# ============================================================

# 常量定义
readonly SCRIPT_NAME=$(basename "$0")
readonly SCRIPT_DIR=$(cd "$(dirname "$0")" && pwd)

# 用法说明
usage() {
    echo "用法：$SCRIPT_NAME [选项] <参数>"
    echo "选项："
    echo "  -h, --help    显示帮助信息"
    echo "  -v, --version 显示版本信息"
    exit 0
}

# 主函数
main() {
    # 解析参数
    while [[ $# -gt 0 ]]; do
        case "$1" in
            -h|--help)
                usage
                ;;
            -v|--version)
                echo "v1.0.0"
                exit 0
                ;;
            *)
                echo "未知选项：$1"
                usage
                ;;
        esac
        shift
    done

    echo "脚本开始执行..."
    # 主逻辑
    echo "脚本执行完成"
}

main "$@"
```
