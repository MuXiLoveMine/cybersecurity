# 第十一章：信号与陷阱

### 11.1 常见信号

| 信号 | 编号 | 说明 |
|------|------|------|
| HUP | 1 | 挂起（终端断开时发送） |
| INT | 2 | 中断（Ctrl+C） |
| QUIT | 3 | 退出（Ctrl+\） |
| KILL | 9 | 强制终止（不能被捕获） |
| TERM | 15 | 终止（默认信号） |
| STOP | 19 | 暂停（不能被捕获） |
| TSTP | 20 | 终端暂停（Ctrl+Z） |
| ALRM | 14 | 闹钟信号 |
| CHLD | 17 | 子进程结束 |

### 11.2 trap 命令

`trap` 用于捕获信号并执行指定命令：

```bash
# 捕获 Ctrl+C 信号
trap "echo '收到中断信号，正在退出...'; exit" SIGINT

# 捕获多个信号
trap "cleanup; exit" SIGINT SIGTERM SIGHUP

# 忽略信号
trap '' SIGINT

# 恢复默认行为
trap - SIGINT
```

**完整示例**：

```bash
#!/bin/bash

# 清理函数
cleanup() {
    echo "正在清理临时文件..."
    rm -f /tmp/temp_file_$$
    echo "清理完成"
}

# 注册信号处理
trap cleanup EXIT    # 脚本退出时执行
trap 'echo "收到中断信号"; exit 1' SIGINT SIGTERM

# 主逻辑
echo "脚本运行中，PID: $$"
echo "按 Ctrl+C 中断"
sleep 10
echo "脚本正常结束"
```
