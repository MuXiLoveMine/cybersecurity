# 第四章：条件判断与分支

### 4.1 if 语句

```bash
# 基本语法
if [ 条件 ]; then
    # 条件为真时执行
fi

# if-else
if [ 条件 ]; then
    # 条件为真
else
    # 条件为假
fi

# if-elif-else
if [ 条件1 ]; then
    # 条件1 为真
elif [ 条件2 ]; then
    # 条件2 为真
else
    # 都不满足
fi
```

### 4.2 条件测试

#### 4.2.1 test 命令与 []

`[ 条件 ]` 等价于 `test 条件`，注意括号内前后必须有空格。

#### 4.2.2 数值比较

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `-eq` | 等于（equal） | `[ $a -eq $b ]` |
| `-ne` | 不等于（not equal） | `[ $a -ne $b ]` |
| `-gt` | 大于（greater than） | `[ $a -gt $b ]` |
| `-ge` | 大于等于（greater or equal） | `[ $a -ge $b ]` |
| `-lt` | 小于（less than） | `[ $a -lt $b ]` |
| `-le` | 小于等于（less or equal） | `[ $a -le $b ]` |

```bash
age=18
if [ $age -ge 18 ]; then
    echo "已成年"
else
    echo "未成年"
fi
```

#### 4.2.3 字符串比较

| 运算符 | 说明 |
|--------|------|
| `=`, `==` | 字符串相等 |
| `!=` | 字符串不相等 |
| `<` | 字符串小于（字典序） |
| `>` | 字符串大于（字典序） |
| `-z` | 字符串长度为 0（空串） |
| `-n` | 字符串长度不为 0 |

```bash
str1="hello"
str2="world"

if [ "$str1" = "$str2" ]; then
    echo "相等"
else
    echo "不相等"
fi

if [ -z "$str1" ]; then
    echo "字符串为空"
fi

if [ -n "$str1" ]; then
    echo "字符串不为空"
fi
```

> **注意**：字符串比较时变量最好用双引号括起来，防止变量为空导致语法错误。

#### 4.2.4 文件测试

| 运算符 | 说明 |
|--------|------|
| `-e file` | 文件或目录是否存在 |
| `-f file` | 是否为普通文件 |
| `-d file` | 是否为目录 |
| `-r file` | 是否可读 |
| `-w file` | 是否可写 |
| `-x file` | 是否可执行 |
| `-s file` | 文件大小不为 0 |
| `-L file` | 是否为符号链接 |
| `-f file -a -r file` | 逻辑与（两个条件都满足） |
| `-f file -o -d file` | 逻辑或（满足一个即可） |

```bash
file="/etc/passwd"

if [ -f "$file" ]; then
    echo "$file 是普通文件"
fi

if [ -r "$file" -a -w "$file" ]; then
    echo "文件可读可写"
fi
```

### 4.3 逻辑运算

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `!` | 逻辑非 | `[ ! -f file ]` |
| `-a` | 逻辑与（test 内） | `[ $a -gt 0 -a $a -lt 10 ]` |
| `-o` | 逻辑或（test 内） | `[ $a -lt 0 -o $a -gt 10 ]` |
| `&&` | 逻辑与（连接命令） | `[ -f file ] && echo "存在"` |
| `\|\|` | 逻辑或（连接命令） | `[ -f file ] \|\| echo "不存在"` |

```bash
# && 和 || 的巧妙用法
# 如果前一个命令成功，则执行后一个
[ -f /etc/passwd ] && echo "文件存在"

# 如果前一个命令失败，则执行后一个
[ -f /etc/nonexist ] || echo "文件不存在"

# 组合使用
[ -d /tmp ] && echo "目录存在" || echo "目录不存在"
```

### 4.4 (( )) 双括号语法

双括号支持 C 语言风格的比较和运算，更直观：

```bash
a=10
b=20

if (( a > b )); then
    echo "a > b"
elif (( a == b )); then
    echo "a == b"
else
    echo "a < b"
fi

# 支持 && 和 ||
if (( a > 0 && b > 0 )); then
    echo "都大于 0"
fi
```

### 4.5 [[ ]] 双方括号语法

双方括号是 Bash 的增强版 test，支持字符串模式匹配和正则：

```bash
str="hello world"

# 模式匹配（右侧是通配符模式）
if [[ "$str" == h* ]]; then
    echo "以 h 开头"
fi

# 正则匹配（=~ 运算符，右侧是正则表达式）
if [[ "$str" =~ ^h.*d$ ]]; then
    echo "匹配正则"
fi

# 逻辑运算更自然
if [[ -f /etc/passwd && -r /etc/passwd ]]; then
    echo "文件存在且可读"
fi
```

### 4.6 case 语句

适用于多分支判断，相当于其他语言的 switch：

```bash
read -p "请输入一个数字（1-3）：" num

case $num in
    1)
        echo "你输入了 1"
        ;;
    2)
        echo "你输入了 2"
        ;;
    3)
        echo "你输入了 3"
        ;;
    *)
        echo "输入无效"
        ;;
esac
```

**case 的模式匹配**：

```bash
read -p "请输入文件名：" filename

case $filename in
    *.txt)
        echo "文本文件"
        ;;
    *.sh)
        echo "Shell 脚本"
        ;;
    *.jpg|*.png|*.gif)
        echo "图片文件"
        ;;
    [a-z]*)
        echo "以小写字母开头"
        ;;
    *)
        echo "其他类型"
        ;;
esac
```
