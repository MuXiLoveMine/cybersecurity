# 第五章：循环结构

### 5.1 for 循环

#### 5.1.1 遍历列表

```bash
# 遍历字符串列表
for fruit in apple banana cherry; do
    echo "水果：$fruit"
done

# 遍历数组
fruits=("apple" "banana" "cherry")
for fruit in "${fruits[@]}"; do
    echo "水果：$fruit"
done

# 遍历命令输出
for file in $(ls /etc); do
    echo "文件：$file"
done

# 数字范围
for i in {1..5}; do
    echo "数字：$i"
done

# 带步长的范围
for i in {0..10..2}; do
    echo "偶数：$i"
done
```

#### 5.1.2 C 语言风格 for 循环

```bash
for ((i=1; i<=5; i++)); do
    echo "第 $i 次循环"
done

# 倒序
for ((i=5; i>=1; i--)); do
    echo "倒计时：$i"
done
```

### 5.2 while 循环

条件为真时循环执行：

```bash
i=1
while [ $i -le 5 ]; do
    echo "第 $i 次循环"
    i=$((i + 1))
done

# 读取文件逐行处理
while read line; do
    echo "内容：$line"
done < /etc/passwd

# 无限循环
while true; do
    echo "死循环，按 Ctrl+C 退出"
    sleep 1
done
```

### 5.3 until 循环

条件为假时循环执行（与 while 相反）：

```bash
i=1
until [ $i -gt 5 ]; do
    echo "第 $i 次循环"
    i=$((i + 1))
done
```

### 5.4 循环控制

```bash
# break：跳出循环
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        break    # i=5 时跳出循环
    fi
    echo "i = $i"
done

# continue：跳过本次循环
for i in {1..10}; do
    if [ $((i % 2)) -eq 0 ]; then
        continue   # 偶数跳过
    fi
    echo "奇数：$i"
done

# break N / continue N：跳出/跳过 N 层循环
for i in {1..3}; do
    for j in {1..3}; do
        if [ $j -eq 2 ]; then
            break 2   # 跳出两层循环
        fi
        echo "i=$i, j=$j"
    done
done
```

### 5.5 select 循环

用于创建简单的交互式菜单：

```bash
PS3="请选择一个选项："

select choice in "选项一" "选项二" "选项三" "退出"; do
    case $choice in
        "选项一")
            echo "你选择了选项一"
            ;;
        "选项二")
            echo "你选择了选项二"
            ;;
        "选项三")
            echo "你选择了选项三"
            ;;
        "退出")
            echo "再见！"
            break
            ;;
        *)
            echo "无效选项"
            ;;
    esac
done
```
