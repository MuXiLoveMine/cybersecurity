# 第六章：函数

### 6.1 函数定义

```bash
# 方式一
function func_name {
    # 函数体
}

# 方式二（推荐，更可移植）
func_name() {
    # 函数体
}
```

### 6.2 函数调用与参数

```bash
greet() {
    echo "Hello, $1!"
    echo "你今年 $2 岁"
}

# 调用函数并传参
greet "张三" 25
```

### 6.3 函数返回值

Shell 函数的返回值是退出状态码（0~255），与命令一样：

```bash
add() {
    local sum=$(( $1 + $2 ))
    return $sum    # return 只能返回 0~255 的整数
}

add 3 5
echo "结果：$?"    # 通过 $? 获取返回值
```

如果需要返回字符串或大数值，使用 echo 输出并捕获：

```bash
greet() {
    echo "Hello, $1!"
}

result=$(greet "World")
echo $result
```

### 6.4 局部变量

使用 `local` 关键字定义局部变量，仅在函数内部有效：

```bash
global_var="我是全局的"

test_func() {
    local local_var="我是局部的"
    echo "函数内：$global_var"
    echo "函数内：$local_var"
}

test_func
echo "函数外：$global_var"
echo "函数外：$local_var"   # 空，因为是局部变量
```

### 6.5 递归函数

函数可以调用自身：

```bash
# 计算阶乘
factorial() {
    local n=$1
    if [ $n -le 1 ]; then
        echo 1
    else
        echo $(( n * $(factorial $((n - 1))) ))
    fi
}

result=$(factorial 5)
echo "5! = $result"    # 120
```

### 6.6 函数库

将常用函数放到单独的文件中，通过 `source` 引入：

```bash
# 函数库文件：mylib.sh
add() { echo $(( $1 + $2 )); }
sub() { echo $(( $1 - $2 )); }
mul() { echo $(( $1 * $2 )); }

# 在主脚本中引入
source mylib.sh
# 或
. mylib.sh

add 1 2
```
