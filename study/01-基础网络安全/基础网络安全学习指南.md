# 基础网络安全学习指南

> 基础网络安全是网络安全的基石，聚焦网络基础设施及数据传输过程的安全保障。所有上层安全（Web、移动、云、工控等）都建立在基础网络安全之上。

---

## 一、方向概述

基础网络安全（网络层安全）是所有安全领域的底层基石，研究的技术范畴主要围绕网络设备、网络协议、网络架构的安全防护。它保障网络连通性与传输完整性，是所有上层安全的基础。

**核心防护对象**：TCP/IP 协议栈、路由器、交换机、防火墙、VPN、局域网（LAN）、广域网（WAN）、互联网出口

**关键威胁**：DDoS 攻击、ARP 欺骗、端口扫描、路由劫持、中间人攻击（MITM）、DNS 劫持、嗅探攻击、VLAN 穿透

**职业方向**：网络安全工程师、网络运维工程师、安全架构师、渗透测试工程师（基础能力）

## 二、详细子方向

### 2.1 网络协议安全

#### 2.1.1 TCP/IP 协议栈安全
**核心知识点**
- OSI 七层模型与 TCP/IP 四层模型的对应关系
- 各层的安全风险与防护要点
- 协议设计缺陷导致的安全问题

**常见攻击**
- TCP 协议：SYN Flood、TCP 会话劫持、RST 攻击、端口扫描
- UDP 协议：UDP Flood、UDP 反射放大攻击
- IP 协议：IP 欺骗、IP 分片攻击、Smurf 攻击
- ICMP 协议：ICMP Flood、Ping of Death、Smurf、Traceroute 探测

**防御方法**
- 防火墙规则配置
- 流量清洗
- 协议异常检测
- SYN Cookie / SYN Proxy

#### 2.1.2 HTTP/HTTPS 协议安全
**核心知识点**
- HTTP 请求方法（GET/POST/PUT/DELETE/OPTIONS 等）
- HTTP 状态码含义
- HTTP 头字段（Cookie、Referer、User-Agent、X-Forwarded-For 等）
- HTTPS 握手过程
- TLS/SSL 协议原理
- 证书验证机制

**常见攻击**
- HTTP 走私（HTTP Smuggling）
- HTTPS 降级攻击
- SSL/TLS 漏洞（Heartbleed、POODLE、BEAST 等）
- 证书伪造
- 中间人攻击

**防御方法**
- 使用最新的 TLS 版本（TLS 1.3）
- 禁用弱加密套件
- 证书固定（Certificate Pinning）
- HSTS（HTTP Strict Transport Security）
- 安全的 HTTP 头配置

#### 2.1.3 DNS 协议安全
**核心知识点**
- DNS 解析过程（递归查询、迭代查询）
- DNS 记录类型（A、AAAA、CNAME、MX、TXT、NS、SOA 等）
- DNS 缓存机制
- DNSSEC 原理

**常见攻击**
- DNS 劫持
- DNS 缓存投毒
- DNS 放大攻击
- DNS 隧道
- 子域名劫持
- DNS 重绑定

**防御方法**
- DNSSEC 部署
- 安全的 DNS 服务器配置
- DNS 监控与异常检测
- 域名注册商安全
- 双因素认证保护域名管理账号

#### 2.1.4 ARP 协议安全
**核心知识点**
- ARP 协议工作原理
- ARP 缓存机制
- 免费 ARP（Gratuitous ARP）
- 代理 ARP

**常见攻击**
- ARP 欺骗（ARP Spoofing）
- ARP 缓存投毒
- 中间人攻击（基于 ARP 欺骗）
- 网络嗅探

**防御方法**
- 静态 ARP 绑定
- DAI（Dynamic ARP Inspection）
- 端口安全
- ARP 监控工具
- 网络分段

#### 2.1.5 DHCP 协议安全
**核心知识点**
- DHCP 工作原理（DORA 过程）
- DHCP 地址分配机制
- DHCP 选项

**常见攻击**
- DHCP 耗尽攻击
- 恶意 DHCP 服务器
- DHCP 欺骗

**防御方法**
- DHCP Snooping
- IP Source Guard
- 端口安全
- DHCP 服务器认证

#### 2.1.6 IPv6 安全
**核心知识点**
- IPv6 地址格式与类型
- IPv6 邻居发现协议（NDP）
- IPv6 自动配置
- IPv6 过渡技术

**常见攻击**
- NDP 欺骗（类似 ARP 欺骗）
- IPv6 隧道攻击
- 地址扫描
- 扩展头攻击

**防御方法**
- SEND（Secure Neighbor Discovery）
- RA Guard
- IPv6 防火墙规则
- IPv6 监控

### 2.2 网络设备安全

#### 2.2.1 路由器安全配置
**核心知识点**
- 路由器工作原理
- 路由协议（静态路由、RIP、OSPF、BGP）
- 访问控制列表（ACL）
- NAT 技术
- 路由器管理安全

**安全基线**
- 修改默认密码
- 禁用不必要的服务
- 启用 SSH，禁用 Telnet
- 配置 ACL 限制管理访问
- 启用日志记录
- 定期更新固件
- 物理安全防护

**常见攻击**
- 路由劫持
- BGP 前缀劫持
- 路由器弱口令
- 管理接口暴露
- 固件漏洞利用

#### 2.2.2 交换机安全配置
**核心知识点**
- 交换机工作原理
- VLAN 技术
- 生成树协议（STP）
- 端口安全
- 链路聚合

**安全基线**
- 配置 VLAN 隔离
- 启用端口安全
- 禁用未使用端口
- 配置 STP 安全（BPDU Guard、Root Guard）
- 启用 DHCP Snooping
- 启用 DAI
- 管理安全

**常见攻击**
- VLAN 穿透（VLAN Hopping）
- MAC 地址泛洪

- CAM 表溢出
- 端口安全绕过

#### 2.2.3 防火墙技术
**核心知识点**
- 防火墙类型：包过滤、状态检测、应用层网关、下一代防火墙（NGFW）
- 防火墙工作模式：路由模式、透明模式、混合模式
- 防火墙策略配置
- NAT 策略
- VPN 配置

**核心功能**
- 访问控制
- 网络地址转换（NAT）
- VPN 支持
- 入侵防御（IPS）
- 应用识别与控制
- 用户身份认证
- 日志与审计

**最佳实践**
- 最小权限原则
- 默认拒绝策略
- 定期审计防火墙规则
- 清理过期规则
- 规则优化与性能调优

#### 2.2.4 IDS/IPS（入侵检测/防御系统）
**核心知识点**
- IDS 与 IPS 的区别
- 检测技术：特征匹配、异常检测、协议分析
- 部署方式：旁路、串接
- 误报与漏报的平衡

**常见类型**
- NIDS（网络入侵检测系统）
- HIDS（主机入侵检测系统）
- NIPS（网络入侵防御系统）
- HIPS（主机入侵防御系统）

**知名产品**

- Bro / Zeek（开源）
- 天融信、启明星辰、深信服（国内厂商）
- Palo Alto、Fortinet（国外厂商）

#### 2.2.5 负载均衡安全
**核心知识点**
- 负载均衡原理
- 负载均衡算法（轮询、加权轮询、最少连接、IP Hash 等）

**安全功能**

**分析要点**
- 协议解析
- 流量统计
- 异常检测
- 会话重组
- 文件提取

**常用过滤语法**
```
# 按协议过滤
tcp
udp
http
dns

# 按 IP 过滤
ip.addr == 192.168.1.1
ip.src == 192.168.1.1
ip.dst == 192.168.1.1

# 按端口过滤
tcp.port == 80
tcp.dstport == 80
tcp.srcport == 80

# 组合过滤
ip.addr == 192.168.1.1 && tcp.port == 80
http.request.method == "POST"
```

## 三、学习路线

### 阶段 1：网络基础（1-2 个月）
**学习目标**：掌握计算机网络基础知识，理解网络工作原理

**学习内容**
- OSI 七层模型与 TCP/IP 四层模型
- IP 地址与子网划分
- 路由原理与路由协议
- 核心协议：TCP、UDP、HTTP、DNS、ARP、ICMP
- Wireshark 抓包分析

**实践任务**
- 用 Wireshark 抓取并分析各种协议数据包
- 配置静态路由
- 搭建简单的网络环境
- 完成子网划分练习

### 阶段 2：网络设备与安全技术（2-3 个月）
**学习目标**：掌握网络设备配置和基础安全技术

**学习内容**
- 路由器、交换机基础配置
- VLAN 配置与 trunk
- 防火墙原理与基础配置
- IDS/IPS 原理与部署
- VPN 技术与配置
- 网络访问控制

**实践任务**
- 用 Cisco Packet Tracer / GNS3 / EVE-NG 搭建实验环境
- 配置 VLAN 间路由
- 配置防火墙 ACL 规则
- 配置 IPsec VPN
- 部署 Snort IDS

### 阶段 3：攻击与防御（2-3 个月）
**学习目标**：理解常见网络攻击原理，掌握防御方法

**学习内容**
- DDoS 攻击原理与防御
- ARP 欺骗与防御
- DNS 劫持与防御
- 中间人攻击与防御
- 端口扫描技术
- 无线网络攻击与防御
- 网络嗅探与防护

**实践任务**
- 模拟 DDoS 攻击（实验环境）
- ARP 欺骗实验
- DNS 劫持实验
- 中间人攻击实验
- 无线密码破解实验
- 配置各种防御措施

### 阶段 4：进阶与实战（持续）
**学习目标**：深入理解高级网络安全技术，具备架构设计能力

**学习内容**
- 零信任架构
- SDN 安全
- 网络流量分析
- 安全架构设计
- 安全运营
- 应急响应

**实践任务**
- 参与 CTF 网络方向题目
- 搭建完整的企业网络安全架构
- 进行网络安全评估
- 编写安全配置基线

## 六、常见面试题

### 基础概念
1. **OSI 七层模型和 TCP/IP 四层模型的区别？**
   - OSI 是理论模型，TCP/IP 是实际使用的模型
   - OSI 七层：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层
   - TCP/IP 四层：网络接口层、网络层、传输层、应用层

2. **TCP 和 UDP 的区别？**
   - TCP 是面向连接的、可靠的、基于字节流的
   - UDP 是无连接的、不可靠的、面向报文的
   - TCP 有三次握手、四次挥手、流量控制、拥塞控制
   - UDP 速度快，适合实时应用

3. **TCP 三次握手的过程？为什么需要三次？**
   - 第一次：客户端发送 SYN
   - 第二次：服务端回复 SYN+ACK
   - 第三次：客户端回复 ACK
   - 三次握手是为了确认双方的收发能力都正常

4. **ARP 协议的作用？ARP 欺骗的原理？**
   - ARP 用于将 IP 地址解析为 MAC 地址
   - ARP 欺骗是通过发送伪造的 ARP 报文，修改目标的 ARP 缓存
   - 可以实现中间人攻击、流量劫持等

### 安全技术
5. **DDoS 攻击有哪些类型？如何防御？**
   - 网络层：SYN Flood、UDP Flood、ICMP Flood
   - 应用层：HTTP Flood、CC 攻击
   - 反射放大：DNS 放大、NTP 放大
   - 防御：流量清洗、高防 IP、CDN、限速、黑名单

6. **防火墙的类型和工作原理？**
   - 包过滤防火墙：基于 IP、端口、协议
   - 状态检测防火墙：跟踪连接状态
   - 应用层网关：代理应用层数据
   - 下一代防火墙：集成 IPS、应用识别等

7. **IDS 和 IPS 的区别？**
   - IDS 是入侵检测系统，旁路部署，只检测不阻断
   - IPS 是入侵防御系统，串接部署，可以主动阻断
   - IDS 误报影响小，IPS 误报影响大

8. **什么是零信任？核心原则是什么？**
   - 零信任：从不信任，始终验证
   - 核心原则：身份验证、最小权限、持续验证、假设 breach
   - 不是产品，是一种安全理念和架构

### 实战相关
9. **如何用 Wireshark 分析异常流量？**
   - 看统计信息：会话、端点、协议分层
   - 用过滤语法筛选可疑流量
   - 跟踪 TCP 流查看内容
   - 对比正常基线找异常

10. **VLAN 穿透的原理和防御？**
    - VLAN Hopping 两种方式：交换机欺骗、双标签
    - 交换机欺骗：伪装成 trunk 端口
    - 双标签：利用双层 VLAN 标签绕过
    - 防御：禁用 DTP、设置本征 VLAN、端口安全

## 七、学习建议

### 7.1 学习方法
1. **先基础后安全**：先掌握计算机网络基础知识，再学习安全技术。不懂网络就学安全，如同空中楼阁。

2. **多动手实践**：网络安全是实践性很强的学科，多做实验、多抓包分析。理论结合实践才能真正掌握。

3. **理解原理**：不要只记攻击方法，要深入理解协议原理和漏洞成因。理解了原理，才能举一反三。

4. **搭建实验环境**：用 GNS3、EVE-NG、Packet Tracer 等工具搭建自己的网络实验环境。

5. **抓包分析**：学习 Wireshark 的使用，养成遇到问题就抓包分析的习惯。

### 7.2 学习重点
- **协议理解**：深入理解 TCP/IP 协议栈，这是所有网络安全的基础
- **设备配置**：掌握常见网络设备的配置和安全加固
- **攻击原理**：理解各种攻击的原理，才能更好地防御
- **防御技术**：掌握各种防御技术的原理和部署
- **流量分析**：具备网络流量分析能力，能发现异常

### 7.3 常见误区
- ❌ 只学攻击不学防御：攻击和防御是一体两面，都要了解
- ❌ 只记工具不理解原理：工具只是手段，原理才是根本
- ❌ 忽视基础：网络基础不牢，后面越学越吃力
- ❌ 不做实验：光学不练假把式，一定要动手实践
- ❌ 急于求成：网络安全需要长期积累，不要想着速成
