# 第一章：Python 概述

### 1.1 什么是 Python

Python 是一种高级、解释型、通用的编程语言，由 Guido van Rossum 于 1991 年首次发布。Python 以简洁清晰的语法和丰富的标准库著称，被广泛用于 Web 开发、数据科学、人工智能、自动化运维和网络安全等领域。

**Python 的特点**：

| 特点 | 说明 |
|------|------|
| **语法简洁** | 缩进代替花括号，代码可读性高 |
| **解释执行** | 不需要编译，逐行解释运行 |
| **跨平台** | 支持 Windows、Linux、macOS 等 |
| **丰富的库** | 标准库 + PyPI 海量第三方库 |
| **面向对象** | 支持面向对象编程 |
| **动态类型** | 变量类型运行时确定 |

### 1.2 Python 版本

- **Python 2**：已于 2020 年停止维护，不再推荐使用
- **Python 3**：当前主流版本，最新版本为 3.12+

本教程基于 **Python 3**。

### 1.3 安装与运行

```bash
# 检查 Python 版本
python3 --version
python --version    # Windows

# 交互式运行（REPL）
python3
>>> print("Hello")

# 运行脚本
python3 script.py
```

### 1.4 第一个 Python 程序

```python
# hello.py
print("Hello, World!")
```
