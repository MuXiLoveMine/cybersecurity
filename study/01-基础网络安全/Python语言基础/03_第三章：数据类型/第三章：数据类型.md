# 第三章：数据类型

### 3.1 基本数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `int` | 整数 | `10`, `-5`, `0x1A` |
| `float` | 浮点数 | `3.14`, `1.5e2` |
| `bool` | 布尔值 | `True`, `False` |
| `str` | 字符串 | `"hello"`, `'world'` |
| `list` | 列表 | `[1, 2, 3]` |
| `tuple` | 元组 | `(1, 2, 3)` |
| `dict` | 字典 | `{"name": "张三"}` |
| `set` | 集合 | `{1, 2, 3}` |
| `NoneType` | 空值 | `None` |

### 3.2 类型转换

```python
# 转整数
int("123")       # 123
int(3.14)        # 3

# 转浮点数
float("3.14")    # 3.14
float(10)        # 10.0

# 转字符串
str(123)         # "123"
str(3.14)        # "3.14"

# 转布尔
bool(0)          # False
bool(1)          # True
bool("")         # False
bool("hello")    # True
bool([])         # False
```

### 3.3 类型判断

```python
x = 10
print(type(x))           # <class 'int'>
print(isinstance(x, int))    # True
print(isinstance(x, (int, float)))  # True（判断是否为多种类型之一）
```
