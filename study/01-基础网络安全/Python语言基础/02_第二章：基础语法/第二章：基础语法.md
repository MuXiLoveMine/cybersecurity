# 第二章：基础语法

### 2.1 变量与命名

```python
# 变量定义（不需要声明类型）
name = "张三"
age = 25
height = 1.75
is_student = True

# 变量命名规则
# - 由字母、数字、下划线组成
# - 不能以数字开头
# - 区分大小写
# - 不能使用关键字

# 多变量赋值
a = b = c = 10
x, y, z = 1, 2, 3

# 查看变量类型
print(type(name))    # <class 'str'>
print(type(age))     # <class 'int'>
```

### 2.2 注释

```python
# 这是单行注释

"""
这是多行注释

"""
```

### 2.3 输入输出

```python
# 输出
print("Hello")
print("姓名:", name, "年龄:", age)
print(f"姓名: {name}, 年龄: {age}")    # f-string（推荐）
print("姓名: %s, 年龄: %d" % (name, age))  # 格式化（旧风格）
print("姓名: {}, 年龄: {}".format(name, age))  # format 方法

# 输入
name = input("请输入你的名字：")    # 返回字符串
age = int(input("请输入年龄："))     # 需要手动转类型
```

### 2.4 缩进

Python 使用缩进来表示代码块（代替其他语言的花括号），通常用 4 个空格：

```python
if age >= 18:
    print("成年")      # 缩进 4 空格
    print("可以投票")
else:
    print("未成年")
```

### 2.5 运算符

#### 算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加 | `3 + 2 = 5` |
| `-` | 减 | `3 - 2 = 1` |
| `*` | 乘 | `3 * 2 = 6` |
| `/` | 除（浮点） | `7 / 2 = 3.5` |
| `//` | 整除 | `7 // 2 = 3` |
| `%` | 取余 | `7 % 2 = 1` |
| `**` | 幂 | `3 ** 2 = 9` |

#### 比较运算符

| 运算符 | 说明 |
|--------|------|
| `==` | 等于 |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

#### 逻辑运算符

| 运算符 | 说明 |
|--------|------|
| `and` | 与（两边都为真才为真） |
| `or` | 或（一边为真就为真） |
| `not` | 非（取反） |

#### 位运算符

| 运算符 | 说明 |
|--------|------|
| `&` | 按位与 |
| `\|` | 按位或 |
| `^` | 按位异或 |
| `~` | 按位取反 |
| `<<` | 左移 |
| `>>` | 右移 |

#### 赋值运算符

| 运算符 | 示例 | 等价于 |
|--------|------|--------|
| `=` | `a = 5` | - |
| `+=` | `a += 3` | `a = a + 3` |
| `-=` | `a -= 3` | `a = a - 3` |
| `*=` | `a *= 3` | `a = a * 3` |
| `/=` | `a /= 3` | `a = a / 3` |
