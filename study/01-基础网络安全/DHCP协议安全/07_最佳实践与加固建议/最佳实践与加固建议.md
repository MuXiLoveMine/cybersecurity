# 最佳实践与加固建议

### 综合安全架构

```
                    +-------------------+
                    | 网络准入控制(NAC) |
                    | 802.1X认证        |
                    +--------+----------+
                             |
                    +--------v----------+
                    | 接入层交换机       |
                    | - DHCP Snooping   |
                    | - 端口安全        |
                    | - 动态ARP检测     |
                    | - IP源守护        |
                    | - 报文限速        |
                    +--------+----------+
                             |
                    +--------v----------+
                    | 汇聚层交换机       |
                    | - DHCP中继代理     |
                    | - Option 82      |
                    | - ACL过滤        |
                    +--------+----------+
                             |
                    +--------v----------+
                    | DHCP服务器        |
                    | - 地址池规划      |
                    | - MAC绑定       |
                    | - 日志审计       |
                    | - 冗余部署       |
                    +-------------------+
```

### 检查清单

| 检查项 | 状态 | 说明 |
|--------|------|------|
| DHCP Snooping已启用 | [ ] | 在所有接入VLAN上启用 |
| 信任端口正确配置 | [ ] | 只连接DHCP服务器和上联链路 |
| 非信任端口限速 | [ ] | 限制DHCP报文速率 |
| 端口安全已启用 | [ ] | 限制MAC地址数量 |
| DAI已启用 | [ ] | 在所有接入VLAN上启用 |
| IPSG已启用 | [ ] | 防止IP地址欺骗 |
| 802.1X认证部署 | [ ] | 确保只有授权设备接入 |
| DHCP服务器加固 | [ ] | 配置MAC绑定、日志 |
| 冗余DHCP部署 | [ ] | 主备DHCP服务器 |
| 日志监控告警 | [ ] | 实时监控DHCP异常 |
| 定期安全审计 | [ ] | 定期检查配置和绑定表 |

### 事件响应流程

```
1. 发现异常（告警/用户报告无法上网）
2. 确认攻击类型（饥饿/伪造服务器/DoS）
3. 定位攻击源（通过Snooping绑定表/端口流量）
4. 紧急处置（关闭攻击端口/隔离攻击者）
5. 影响评估（检查是否有中间人攻击痕迹）
6. 恢复服务（清除恶意租约/重启DHCP服务）
7. 事后分析（完善检测规则/加固配置）
8. 编写报告
```
