### 4.2 端口查看与监听

#### 4.2.1 netstat命令

```cmd
:: 查看所有连接和监听端口
netstat -ano

:: 仅查看TCP连接
netstat -an -p tcp

:: 仅查看UDP连接
netstat -an -p udp

:: 查看监听端口
netstat -ano | findstr "LISTENING"

:: 查看建立的连接
netstat -ano | findstr "ESTABLISHED"

:: 查看特定端口
netstat -ano | findstr ":3389"

:: 查看端口对应的进程名
netstat -ano -b    :: 需管理员权限

:: 按协议统计
netstat -s

:: 持续刷新（每秒）
netstat -ano 1
```

#### 4.2.2 PowerShell端口查看

```powershell
# 查看所有TCP连接
Get-NetTCPConnection

# 查看监听端口
Get-NetTCPConnection -State Listen

# 查看建立的连接
Get-NetTCPConnection -State Established

# 查看特定端口
Get-NetTCPConnection -LocalPort 3389

# 查看UDP端点
Get-NetUDPEndpoint

# 查看端口对应的进程
Get-NetTCPConnection -State Listen | ForEach-Object {
    $proc = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
    [PSCustomObject]@{
        本地地址 = $_.LocalAddress
        本地端口 = $_.LocalPort
        状态 = $_.State
        PID = $_.OwningProcess
        进程名 = if ($proc) { $proc.ProcessName } else { "未知" }
    }
} | Format-Table -AutoSize
```

#### 4.2.3 其他端口查看工具

```cmd
:: 查看被系统保留的端口
netsh int ipv4 show excludedportrange protocol=tcp

:: 查看端口代理
netsh interface portproxy show all
```

### 4.3 服务管理

#### 4.3.1 图形界面管理

```
运行 → services.msc
或
计算机管理 → 服务和应用程序 → 服务
```

服务管理控制台可以：
- 查看所有服务的状态、启动类型、登录身份
- 启动/停止/暂停/恢复服务
- 配置服务属性（启动类型、恢复选项、依赖关系）
- 导出服务列表

#### 4.3.2 sc命令

```cmd
:: 查看所有服务
sc query
sc query state= all        :: 所有状态（包括已停止）
sc query type= service     :: 仅Win32服务
sc query type= driver      :: 仅驱动服务

:: 查看指定服务
sc query TermService
sc qc TermService          :: 查看服务配置

:: 启动/停止服务
sc start TermService
sc stop TermService
sc pause TermService       :: 暂停
sc continue TermService    :: 继续

:: 配置服务启动类型
sc config Telnet start= disabled
sc config Telnet start= demand      :: 手动
sc config Telnet start= auto        :: 自动
sc config Telnet start= delayed-auto :: 自动（延迟启动）

:: 创建/删除服务
sc create MyService binPath= "C:\service.exe" start= auto
sc delete MyService

:: 配置服务登录账户
sc config MyService obj= "NT AUTHORITY\NetworkService" password= ""
```

#### 4.3.3 PowerShell服务管理

```powershell
# 查看所有服务
Get-Service
Get-Service | Where-Object { $_.Status -eq "Running" }
Get-Service | Where-Object { $_.StartType -eq "Automatic" }

# 查看指定服务
Get-Service -Name TermService
Get-Service -DisplayName "*远程*"

# 启动/停止/重启服务
Start-Service -Name TermService
Stop-Service -Name TermService -Force
Restart-Service -Name TermService

# 设置启动类型
Set-Service -Name Telnet -StartupType Disabled
Set-Service -Name Telnet -StartupType Manual
Set-Service -Name Telnet -StartupType Automatic

# 查看服务依赖关系
Get-Service -Name TermService -DependentServices     # 依赖此服务的服务
Get-Service -Name TermService -RequiredServices      # 此服务依赖的服务

# 查看服务详细信息
Get-CimInstance Win32_Service -Filter "Name='TermService'" | Select-Object *
```

### 4.4 危险服务与禁用建议

#### 4.4.1 高风险服务

| 服务名 | 显示名 | 风险说明 | 建议 |
|--------|--------|----------|------|
| Telnet | Telnet | 明文传输，极易被窃听 | 禁用 |
| FTP Publishing Service | FTP发布服务 | 明文传输，弱口令风险 | 禁用，改用SFTP |
| Simple TCP/IP Services | 简单TCP/IP服务 | 包含echo、daytime等，可被滥用 | 禁用 |
| Remote Registry | 远程注册表 | 允许远程修改注册表 | 禁用（按需启用） |
| Server | Server | 提供SMB文件共享（445端口） | 非文件服务器禁用 |
| Workstation | Workstation | 客户端SMB服务 | 必要服务，谨慎配置 |
| SSDP Discovery | SSDP发现 | UPnP发现服务 | 禁用 |
| UPnP Device Host | UPnP设备主机 | UPnP设备支持 | 禁用 |
| Remote Desktop Services | 远程桌面服务 | RDP服务 | 非必要禁用，使用则加固 |
| WinRM | Windows远程管理(WS-Management) | PowerShell远程管理 | 非必要禁用，使用则加固 |
| WMI Performance Adapter | WMI性能适配器 | WMI远程性能监控 | 禁用 |
| SNMP Service | SNMP服务 | 简单网络管理协议 | 非必要禁用，使用则修改community |

#### 4.4.2 批量禁用不必要服务

```powershell
# 建议禁用的服务列表
$disableServices = @(
    "Telnet",
    "RemoteRegistry",
    "SSDPSRV",      # SSDP Discovery
    "upnphost",     # UPnP Device Host
    "FtpSvc",       # FTP服务
    "Simptcp",      # Simple TCP/IP Services
    "lmhosts",      # TCP/IP NetBIOS Helper（如不需要NetBIOS）
    "WinRM"         # 非管理服务器禁用
)

foreach ($svc in $disableServices) {
    $service = Get-Service -Name $svc -ErrorAction SilentlyContinue
    if ($service) {
        Stop-Service -Name $svc -Force -ErrorAction SilentlyContinue
        Set-Service -Name $svc -StartupType Disabled
        Write-Host "已禁用服务: $svc" -ForegroundColor Green
    }
}
```

### 4.5 服务权限配置与加固

#### 4.5.1 服务运行账户

服务的登录身份直接影响安全风险：

| 账户 | 权限 | 适用场景 |
|------|------|----------|
| Local System | 最高系统权限 | 核心系统服务 |
| Local Service | 标准用户权限，网络访问以匿名身份 | 本地服务 |
| Network Service | 标准用户权限，网络访问以计算机账户 | 需要网络访问的服务 |
| 自定义账户 | 按分配的权限 | 第三方服务，遵循最小权限 |

**安全建议**：
- 第三方服务尽量使用低权限账户运行
- 避免使用管理员账户运行服务
- 定期审计服务账户权限

#### 4.5.2 服务权限加固

```powershell
# 查看服务安全描述符
sc sdshow TermService

# 修改服务权限（示例：禁止普通用户停止服务）
# 注意：修改服务SD需要谨慎操作，建议先备份
# sc sdset <service> <security descriptor>
```

#### 4.5.3 服务路径检查

服务路径中如果包含空格且未加引号，可能存在**路径劫持（Unquoted Service Path）**漏洞：

```powershell
# 检查未加引号的服务路径
Get-CimInstance Win32_Service | Where-Object {
    $_.PathName -match '^[^"]*\s[^"]*\.exe' -and $_.PathName -notmatch '^"'
} | Select-Object Name, PathName, StartMode
```

### 4.6 启动项管理

#### 4.6.1 系统配置实用程序（msconfig）

```
运行 → msconfig
```

系统配置工具可管理：
- 常规启动选项（正常/诊断/有选择启动）
- 启动项（Windows 10/11已移至任务管理器）
- 服务管理
- 工具列表

#### 4.6.2 启动项位置

**启动文件夹**：
- 当前用户：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- 所有用户：`C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup`

**注册表启动项**：
```
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnceEx
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Userinit
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell
```

#### 4.6.3 任务计划程序

```
运行 → taskschd.msc
```

任务计划是恶意程序常用的持久化方式，需要重点关注：
- 定期检查任务计划中的未知任务
- 关注以高权限运行的任务
- 检查触发器和操作内容

```powershell
# 查看所有计划任务
Get-ScheduledTask

# 查看任务详细信息
Get-ScheduledTaskInfo -TaskName "TaskName"

# 查看以最高权限运行的任务
Get-ScheduledTask | Where-Object { $_.Principal.RunLevel -eq "Highest" } | Select-Object TaskName, State

# 查看触发器
Get-ScheduledTask | ForEach-Object {
    foreach ($trigger in $_.Triggers) {
        [PSCustomObject]@{
            任务名 = $_.TaskName
            触发器类型 = $trigger.CimClass.CimClassName
            启用 = $_.State
        }
    }
}
```

#### 4.6.4 其他启动持久化位置

- **驱动程序**：`HKLM\SYSTEM\CurrentControlSet\Services`（Type=1/2内核驱动）
- **WMI事件订阅**：攻击者通过WMI永久事件订阅实现持久化
- **映像劫持**：`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options`
- **COM对象劫持**：`HKCR\CLSID` 下的COM对象替换
- **登录脚本**：组策略登录/注销脚本
- **服务**：以服务形式运行的恶意程序

## 🛠️ 补充：实战拓展

### 命令速查表

```powershell
# 快速端口与服务安全检查脚本
function Invoke-PortServiceAudit {
    Write-Host "=== 监听端口列表 ===" -ForegroundColor Cyan
    Get-NetTCPConnection -State Listen | ForEach-Object {
        $proc = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
        [PSCustomObject]@{
            本地端口 = $_.LocalPort
            本地地址 = $_.LocalAddress
            PID = $_.OwningProcess
            进程名 = if ($proc) { $proc.ProcessName } else { "未知" }
            进程路径 = if ($proc) { $proc.Path } else { "未知" }
        }
    } | Sort-Object 本地端口 | Format-Table -AutoSize

    Write-Host "=== 自动启动服务 ===" -ForegroundColor Cyan
    Get-Service | Where-Object { $_.StartType -eq "Automatic" -or $_.StartType -eq "AutomaticDelayedStart" } |
        Select-Object Name, DisplayName, Status | Sort-Object Name | Format-Table -AutoSize

    Write-Host "=== 注册表启动项 ===" -ForegroundColor Cyan
    $runPaths = @(
        "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run",
        "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
    )
    foreach ($path in $runPaths) {
        Write-Host "路径: $path" -ForegroundColor Yellow
        Get-ItemProperty -Path $path -ErrorAction SilentlyContinue |
            Select-Object -ExcludeProperty PSPath, PSParentPath, PSChildName, PSDrive, PSProvider |
            Format-List
    }

    Write-Host "=== 高权限计划任务 ===" -ForegroundColor Cyan
    Get-ScheduledTask | Where-Object { $_.Principal.RunLevel -eq "Highest" -and $_.State -eq "Ready" } |
        Select-Object TaskName, @{n="运行身份";e={$_.Principal.UserId}} | Format-Table -AutoSize
}
```

### 端口安全检查清单

```
1. 列出所有监听端口，确认每个端口对应的服务
2. 关闭不需要的服务和端口
3. 对必须开放的端口，通过防火墙限制访问来源
4. 检查服务运行账户，遵循最小权限原则
5. 检查是否存在未加引号的服务路径漏洞
6. 审查所有启动项和计划任务
7. 定期进行端口扫描，验证开放端口
```
