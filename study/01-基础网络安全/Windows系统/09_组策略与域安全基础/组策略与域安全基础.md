# 组策略与域安全基础

### 9.1 活动目录基础概念

#### 9.1.1 活动目录概述

活动目录（Active Directory，AD）是微软提供的目录服务，是Windows域环境的核心：
- 存储网络中所有对象的信息（用户、计算机、组、打印机等）
- 提供统一的身份认证和授权管理
- 支持组策略集中配置管理
- 是企业Windows环境的基础架构

#### 9.1.2 核心概念

**域（Domain）**：
- 活动目录的基本管理单元
- 共享同一目录数据库的计算机和用户的集合
- 每个域有唯一的DNS名称（如corp.example.com）
- 域之间可以建立信任关系

**域控制器（Domain Controller，DC）**：
- 运行活动目录域服务（AD DS）的Windows Server
- 存储目录数据库的完整副本
- 处理用户身份验证请求
- 域内可以有多台域控制器，通过多主机复制同步数据
- 承担FSMO（灵活单主机操作）角色

**组织单元（Organizational Unit，OU）**：
- 域内的逻辑容器，用于组织和管理对象
- 可以嵌套，形成层级结构
- 组策略可以链接到OU，实现精细化管理
- 是权限委派和组策略应用的基本单位

**组策略（Group Policy）**：
- 集中式配置管理技术
- 可配置用户和计算机的上千种设置
- 通过组策略对象（GPO）实现
- 支持站点、域、OU多级应用

#### 9.1.3 AD逻辑结构 vs 物理结构

**逻辑结构**：
- 林（Forest）：一个或多个域树的集合，共享同一架构和配置
- 域树（Domain Tree）：共享连续命名空间的域的集合
- 域（Domain）：基本管理单元
- OU：域内的组织单元

**物理结构**：
- 站点（Site）：一个或多个IP子网的集合，代表物理位置
- 域控制器：承载AD DS的服务器
- 复制连接：域控制器之间的数据同步链路

#### 9.1.4 活动目录数据库

- **数据库文件**：NTDS.dit，存储在 `C:\Windows\NTDS\` 目录
- **SYSVOL文件夹**：存储组策略模板、脚本等，`C:\Windows\SYSVOL\`
- **复制机制**：
  - AD数据库：多主机复制（FRS → DFSR）
  - SYSVOL：Windows Server 2008起使用DFSR复制

### 9.2 组策略对象（GPO）基础

#### 9.2.1 组策略概述

组策略（Group Policy）是Windows的集中配置管理技术：
- 可管理计算机配置和用户配置
- 支持软件部署、安全设置、脚本、首选项等
- 通过GPO（组策略对象）存储配置信息
- 应用顺序：站点 → 域 → OU（从上到下）

#### 9.2.2 GPO组成

每个GPO由两部分组成：

**GPC（Group Policy Container）**：
- 存储在活动目录中
- 包含GPO的属性和版本信息
- 路径：`CN=Policies,CN=System,DC=域,DC=com`

**GPT（Group Policy Template）**：
- 存储在SYSVOL共享中
- 包含实际的策略设置文件
- 路径：`\\域\SYSVOL\域\Policies\{GPO GUID}\`
- 包含：Registry.pol（注册表设置）、Scripts（脚本）、Adm/Admx（管理模板）等

#### 9.2.3 组策略处理顺序

组策略应用遵循"LSDOU"顺序：
1. **L**ocal（本地）：本地组策略
2. **S**ite（站点）：链接到站点的GPO
3. **D**omain（域）：链接到域的GPO
4. **O**U（组织单元）：从父OU到子OU依次应用

默认情况下，后应用的策略会覆盖先应用的策略（除非启用了"强制"）。

#### 9.2.4 组策略筛选

- **安全筛选**：基于安全组控制GPO的应用范围
  - 默认：Authenticated Users（所有经过身份验证的用户和计算机）
  - 可修改为特定安全组
- **WMI筛选**：基于WMI查询动态决定是否应用GPO
  - 如：只对Windows 10应用、只对笔记本电脑应用

#### 9.2.5 常用组策略管理命令

```cmd
:: 刷新组策略
gpupdate
gpupdate /force              :: 强制刷新所有设置
gpupdate /target:computer    :: 仅刷新计算机配置
gpupdate /target:user        :: 仅刷新用户配置
gpupdate /boot               :: 刷新后重启
gpupdate /logoff             :: 刷新后注销

:: 查看组策略结果
gpresult
gpresult /r                  :: 摘要信息
gpresult /v                  :: 详细信息
gpresult /z                  :: 超级详细
gpresult /h report.html      :: 生成HTML报告
gpresult /scope computer     :: 仅计算机策略
gpresult /scope user         :: 仅用户策略
```

```powershell
# 获取组策略
Get-GPO -All
Get-GPO -Name "默认域策略"
Get-GPO -Guid "GPO-GUID"

# 创建GPO
New-GPO -Name "安全基线策略"

# 链接GPO
New-GPLink -Name "安全基线策略" -Target "OU=服务器,DC=corp,DC=com"

# 备份/恢复GPO
Backup-GPO -All -Path "C:\GPO_Backup"
Restore-GPO -Name "安全基线策略" -Path "C:\GPO_Backup"
```

### 9.3 常用安全组策略配置

#### 9.3.1 密码与账户策略

```
计算机配置 → 策略 → Windows设置 → 安全设置 → 账户策略
```

- 密码必须符合复杂性要求：已启用
- 密码长度最小值：12个字符
- 密码最长使用期限：90天
- 强制密码历史：24个记住的密码
- 账户锁定阈值：5次无效登录
- 账户锁定时间：30分钟
- 重置账户锁定计数器：30分钟后

#### 9.3.2 安全选项

```
计算机配置 → 策略 → Windows设置 → 安全设置 → 本地策略 → 安全选项
```

**账户安全**：
- 账户：管理员账户状态：已禁用
- 账户：来宾账户状态：已禁用
- 账户：重命名系统管理员账户：自定义名称

**交互式登录**：
- 交互式登录：不显示最后的用户名：已启用
- 交互式登录：不需要CTRL+ALT+DEL：已禁用
- 交互式登录：提示用户在密码到期前更改密码：14天

**网络安全**：
- 网络安全：LAN管理器身份验证级别：仅发送NTLMv2响应。拒绝LM和NTLM
- 网络安全：不允许存储LAN管理器哈希值：已启用

**网络访问**：
- 网络访问：不允许SAM账户的匿名枚举：已启用
- 网络访问：不允许SAM账户和共享的匿名枚举：已启用
- 网络访问：限制匿名访问命名管道和共享：已启用

#### 9.3.3 审核策略

```
计算机配置 → 策略 → Windows设置 → 安全设置 → 高级审核策略配置
```

- 账户登录/安全审核：成功，失败
- 账户管理：成功，失败
- 登录/注销：成功，失败
- 对象访问：失败（关键对象启用成功审核）
- 策略更改：成功，失败
- 特权使用：失败
- 系统：成功，失败
- 详细跟踪/进程创建：成功

#### 9.3.4 用户权限分配

```
计算机配置 → 策略 → Windows设置 → 安全设置 → 本地策略 → 用户权限分配
```

关键权限控制：
- 允许在本地登录：Administrators
- 允许通过远程桌面服务登录：Remote Desktop Users
- 从网络访问此计算机：Administrators, Authenticated Users
- 拒绝本地登录：Guest, 高危服务账户
- 调试程序：Administrators（必要时移除普通用户）
- 备份文件和目录：Administrators, Backup Operators
- 管理审核和安全日志：Administrators

#### 9.3.5 Windows Defender防火墙

```
计算机配置 → 策略 → Windows设置 → 安全设置 → Windows Defender防火墙
```

- 所有配置文件：启用防火墙
- 默认入站行为：阻止
- 默认出站行为：允许
- 配置入站/出站规则（按业务需要）

#### 9.3.6 软件限制

```
计算机配置 → 策略 → Windows设置 → 安全设置 → 应用程序控制策略
```

- AppLocker：配置允许运行的应用程序
- WDAC：更高级的应用程序控制（需Windows 10企业版）

### 9.4 组策略结果与建模

#### 9.4.1 组策略结果（GPResult）

组策略结果用于查看已应用的组策略：

```cmd
:: 命令行查看
gpresult /r
gpresult /h report.html /f
```

```powershell
# PowerShell获取组策略结果
Get-GPResultantSetOfPolicy -ReportType Html -Path "C:\gpresult.html" -Computer DC01
```

**图形界面工具**：
```
运行 → gpmc.msc → 组策略结果
```

#### 9.4.2 组策略建模（Group Policy Modeling）

组策略建模用于模拟策略应用结果，测试配置是否符合预期：

```
GPMC → 组策略建模 → 组策略建模向导
```

可模拟的条件：
- 目标容器（站点/域/OU）
- 安全组成员身份
- WMI筛选器
- 慢速网络连接
- 环回处理模式

#### 9.4.3 常见策略应用问题排查

- **策略未应用**：检查GPO链接、安全筛选、WMI筛选、权限
- **策略顺序问题**：确认LSDOU顺序，检查是否有"强制"设置
- **用户配置未应用**：检查用户是否在正确的OU中
- **计算机配置未应用**：检查计算机账户位置和网络连通性
- **策略冲突**：使用gpresult查看最终生效的设置

### 9.5 域环境安全最佳实践

#### 9.5.1 域控制器安全

- **物理安全**：域控制器应放置在安全的物理环境中
- **最小化角色**：域控制器不运行其他服务（如不做文件服务器、Web服务器）
- **补丁管理**：及时安装安全补丁，域控制器是高价值目标
- **备份策略**：定期备份系统状态和AD数据库
- **限制登录**：只有域管理员才能登录域控制器
- **监控审计**：启用完整的安全审计，监控域控制器异常活动

#### 9.5.2 权限管理

- **遵循最小权限原则**：用户只拥有完成工作所需的最小权限
- **限制管理员组**：Domain Admins、Enterprise Admins组成员应严格控制
- **使用服务账户**：服务使用专用低权限账户运行
- **定期权限审计**：定期审查高权限组的成员
- **权限委派**：将部分管理权限委派给普通用户，避免使用域管理员

#### 9.5.3 认证安全

- **禁用NTLM**：尽量使用Kerberos认证，减少NTLM使用
- **启用LDAP签名**：要求LDAP查询签名，防止中间人攻击
- **启用LDAPS**：敏感操作使用LDAP over SSL
- **Kerberos策略**：合理配置票据生命周期
- **保护KRBTGT账户**：定期重置KRBTGT密码（防御黄金票据攻击）

#### 9.5.4 组策略安全

- **GPO权限控制**：限制谁可以编辑和链接GPO
- **GPO备份**：定期备份所有GPO
- **变更管理**：GPO修改应有审批和测试流程
- **SYSVOL安全**：保护SYSVOL文件夹，防止未授权修改
- **检查GPO中的密码**：GPO中不应存储明文密码（如组策略首选项密码）

#### 9.5.5 攻击面减少

- **禁用LLMNR和NBT-NS**：防止中继攻击
- **启用SMB签名**：防止SMB中继攻击
- **禁用WPAD**：防止代理自动发现被滥用
- **限制本地管理员权限**：用户不应拥有本地管理员权限
- **部署LAPS**：本地管理员密码解决方案，随机化本地管理员密码

### 9.6 本地组策略编辑器

#### 9.6.1 打开本地组策略编辑器

```
运行 → gpedit.msc
```

适用于未加入域的独立计算机，配置本地策略。

#### 9.6.2 本地组策略 vs 域组策略

| 特性 | 本地组策略 | 域组策略 |
|------|-----------|----------|
| 管理范围 | 单台计算机 | 域内多台计算机 |
| 配置位置 | 本地 | 域控制器 |
| 优先级 | 最低（LSDOU中的L） | 高于本地策略 |
| 管理工具 | gpedit.msc | GPMC（gpmc.msc） |
| 适用场景 | 独立计算机、工作组 | 域环境 |

#### 9.6.3 本地安全策略

```
运行 → secpol.msc
```

本地安全策略是本地组策略的子集，专注于安全设置：
- 账户策略（密码策略、账户锁定策略）
- 本地策略（审核策略、用户权限分配、安全选项）
- 高级审核策略配置
- Windows Defender防火墙
- 网络列表管理器策略
- 公钥策略
- 软件限制策略

### 命令速查表

```powershell
# 域环境信息收集脚本
function Get-DomainInfo {
    Write-Host "=== 域信息 ===" -ForegroundColor Cyan
    $domain = [System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain()
    Write-Host "域名: $($domain.Name)"
    Write-Host "林: $($domain.Forest)"
    Write-Host "域控制器:"
    $domain.DomainControllers | ForEach-Object { Write-Host "  - $($_.Name)" }

    Write-Host "`n=== 当前用户信息 ===" -ForegroundColor Cyan
    whoami /user
    whoami /groups

    Write-Host "`n=== 组策略应用情况 ===" -ForegroundColor Cyan
    gpresult /r | Select-String -Pattern "已应用的组策略对象" -Context 0,10
}
```

### 本地安全策略配置脚本

```powershell
# 本地安全策略快速加固（非域环境）
function Invoke-LocalSecHardening {
    Write-Host "正在配置本地安全策略..." -ForegroundColor Yellow

    # 导出当前安全策略
    $tempFile = "C:\temp\secpol_temp.cfg"
    secedit /export /cfg $tempFile /areas SECURITYPOLICY | Out-Null

    # 读取并修改
    $secpol = Get-Content $tempFile
    $secpol = $secpol -replace 'PasswordComplexity.*', 'PasswordComplexity = 1'
    $secpol = $secpol -replace 'MinimumPasswordLength.*', 'MinimumPasswordLength = 12'
    $secpol = $secpol -replace 'MaximumPasswordAge.*', 'MaximumPasswordAge = 90'
    $secpol = $secpol -replace 'PasswordHistorySize.*', 'PasswordHistorySize = 24'
    $secpol = $secpol -replace 'LockoutBadCount.*', 'LockoutBadCount = 5'
    $secpol = $secpol -replace 'LockoutDuration.*', 'LockoutDuration = 30'
    $secpol = $secpol -replace 'ResetLockoutCount.*', 'ResetLockoutCount = 30'

    $secpol | Set-Content $tempFile

    # 导入安全策略
    secedit /configure /db "C:\Windows\security\local.sdb" /cfg $tempFile /areas SECURITYPOLICY | Out-Null

    Remove-Item $tempFile -Force
    Write-Host "本地安全策略配置完成" -ForegroundColor Green
}
```
