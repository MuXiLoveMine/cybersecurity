# 实战加固检查清单

### 10.1 系统信息收集清单

#### 10.1.1 基本信息

```powershell
# 系统基本信息
systeminfo

# PowerShell方式
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber, OSArchitecture, InstallDate, LastBootUpTime

# 计算机名和域名
$env:COMPUTERNAME
(Get-CimInstance Win32_ComputerSystem).Domain
(Get-CimInstance Win32_ComputerSystem).Workgroup

# 硬件信息
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, NumberOfLogicalProcessors
Get-CimInstance Win32_PhysicalMemory | Measure-Object -Property Capacity -Sum
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" | Select-Object DeviceID, Size, FreeSpace
```

#### 10.1.2 补丁与更新信息

```powershell
# 已安装的补丁
Get-HotFix | Sort-Object InstalledOn -Descending
Get-HotFix | Measure-Object

# 最后更新时间
(Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 1).InstalledOn

# Windows更新服务状态
Get-Service -Name wuauserv
```

#### 10.1.3 用户与组信息

```powershell
# 本地用户列表
Get-LocalUser
net user

# 本地组列表
Get-LocalGroup
net localgroup

# 管理员组成员
Get-LocalGroupMember -Group "Administrators"
net localgroup administrators

# 查看用户详细信息
Get-LocalUser -Name "用户名" | Select-Object *
```

#### 10.1.4 网络信息

```powershell
# IP地址配置
Get-NetIPAddress -AddressFamily IPv4 | Select-Object InterfaceAlias, IPAddress, PrefixLength

# 默认网关
Get-NetRoute -DestinationPrefix "0.0.0.0/0" | Select-Object InterfaceAlias, NextHop

# DNS服务器
Get-DnsClientServerAddress -AddressFamily IPv4 | Select-Object InterfaceAlias, ServerAddresses

# 网络配置文件
Get-NetConnectionProfile | Select-Object InterfaceAlias, NetworkCategory
```

### 10.2 账户安全检查

#### 10.2.1 密码策略检查

```
检查项：
□ 密码是否启用复杂性要求
□ 密码最小长度是否≥12位
□ 密码最长使用期限是否≤90天
□ 是否启用密码历史（≥24个）
□ 是否禁用可还原的加密存储密码
```

```cmd
:: 查看密码策略
net accounts
```

#### 10.2.2 账户锁定策略检查

```
检查项：
□ 账户锁定阈值是否≤5次
□ 账户锁定时间是否≥30分钟
□ 重置锁定计数器是否≤30分钟
```

#### 10.2.3 账户安全检查

```
检查项：
□ 内置Administrator账户是否已禁用/重命名
□ Guest账户是否已禁用
□ 是否存在多余的用户账户
□ 管理员组成员是否合理
□ 是否存在空密码账户
□ 所有账户是否都有强密码
□ 服务账户权限是否符合最小权限原则
```

```powershell
# 检查禁用的账户
Get-LocalUser | Where-Object { $_.Enabled -eq $false } | Select-Object Name

# 检查启用的账户
Get-LocalUser | Where-Object { $_.Enabled -eq $true } | Select-Object Name

# 检查密码永不过期的账户
Get-LocalUser | Where-Object { $_.PasswordNeverExpires -eq $true } | Select-Object Name, PasswordNeverExpires
```

### 10.3 网络与防火墙检查

#### 10.3.1 防火墙状态检查

```
检查项：
□ 所有配置文件防火墙是否已启用
□ 默认入站策略是否为"阻止"
□ 默认出站策略是否合理
□ 入站规则是否最小化
□ 是否有多余的防火墙规则
□ 管理端口（RDP、WinRM）是否限制来源IP
```

```powershell
# 防火墙状态
Get-NetFirewallProfile | Select-Object Name, Enabled, DefaultInboundAction, DefaultOutboundAction

# 启用的入站规则数量
(Get-NetFirewallRule -Direction Inbound -Enabled True).Count

# 查看所有入站允许规则
Get-NetFirewallRule -Direction Inbound -Enabled True -Action Allow | Select-Object DisplayName, Action, Direction | Format-Table -AutoSize
```

#### 10.3.2 开放端口检查

```
检查项：
□ 监听端口是否都是必要服务
□ 是否有不必要的服务在监听
□ 高危端口（135、139、445等）是否对外开放
□ RDP端口是否修改并限制来源
□ 是否使用了不必要的网络协议
```

```powershell
# 所有监听端口
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess | Sort-Object LocalPort

# 检查常见高危端口
$highRiskPorts = @(135, 139, 445, 3389, 5985, 5986)
foreach ($port in $highRiskPorts) {
    $conn = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue
    if ($conn) {
        $proc = Get-Process -Id $conn.OwningProcess -ErrorAction SilentlyContinue
        Write-Host "端口 $port 监听中 - 进程: $($proc.ProcessName)"
    }
}
```

#### 10.3.3 网络协议安全

```
检查项：
□ 是否已禁用SMBv1
□ 是否禁用了LLMNR和NBT-NS（如不需要）
□ 是否启用了SMB签名
□ NetBIOS是否按需禁用
```

```powershell
# 检查SMBv1状态
Get-WindowsOptionalFeature -Online -FeatureName SMB1Protocol

# 检查SMB配置
Get-SmbServerConfiguration | Select-Object EnableSMB1Protocol, EnableSMB2Protocol, RequireSecuritySignature, AutoDisconnectTimeout
```

### 10.4 服务与端口检查

#### 10.4.1 服务状态检查

```
检查项：
□ 自动启动服务是否都是必要的
□ 危险服务是否已禁用（Telnet、FTP等）
□ 服务运行账户是否遵循最小权限
□ 是否存在未加引号的服务路径
□ 服务权限配置是否合理
```

```powershell
# 自动启动的服务
Get-Service | Where-Object { $_.StartType -eq "Automatic" -or $_.StartType -eq "AutomaticDelayedStart" } | Select-Object Name, DisplayName, Status | Sort-Object Name

# 检查未加引号的服务路径
Get-CimInstance Win32_Service | Where-Object {
    $_.PathName -match '^[^"]*\s[^"]*\.exe' -and $_.PathName -notmatch '^"' -and $_.PathName -notmatch 'System32'
} | Select-Object Name, PathName, StartMode
```

#### 10.4.2 启动项检查

```
检查项：
□ Run注册表项是否有可疑程序
□ 启动文件夹是否有可疑程序
□ 计划任务是否有可疑任务
□ 服务中是否有可疑服务
□ 驱动程序是否有可疑项
```

```powershell
# 注册表Run项
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run"
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# 启动文件夹
Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup"
Get-ChildItem "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"

# 计划任务
Get-ScheduledTask | Where-Object { $_.State -eq "Ready" } | Select-Object TaskName, @{n="运行身份";e={$_.Principal.UserId}}
```

```powershell
# 检查PowerShell日志配置
$sbLog = Get-ItemProperty "HKLM:\SOFTWARE\Wow6432Node\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -ErrorAction SilentlyContinue
$modLog = Get-ItemProperty "HKLM:\SOFTWARE\Wow6432Node\Policies\Microsoft\Windows\PowerShell\ModuleLogging" -ErrorAction SilentlyContinue

Write-Host "脚本块日志: $(if($sbLog){$sbLog.EnableScriptBlockLogging -eq 1}else{'未配置'})"
Write-Host "模块日志: $(if($modLog){$modLog.EnableModuleLogging -eq 1}else{'未配置'})"
Write-Host "转录日志: $(if($trans){$trans.EnableTranscripting -eq 1}else{'未配置'})"
```

### 10.8 加固操作步骤汇总

#### 10.8.1 初始加固步骤

```
步骤1：系统信息收集
  - 记录系统版本、补丁级别、硬件配置
  - 记录当前用户、服务、网络配置
  - 建立基线，便于后续对比

步骤2：账户安全加固
  - 禁用/重命名Administrator账户
  - 禁用Guest账户
  - 设置强密码策略
  - 配置账户锁定策略
  - 清理多余用户账户
  - 限制管理员组成员

步骤3：网络与防火墙加固
  - 启用所有配置文件的防火墙
  - 清理不必要的入站规则
  - 限制管理端口的来源IP
  - 禁用不必要的网络协议
  - 修改RDP默认端口（如需要）

步骤4：服务加固
  - 禁用不必要的服务
  - 检查服务运行账户
  - 修复服务路径漏洞
  - 清理可疑启动项
  - 审查计划任务

步骤5：日志与审计加固
  - 启用完整的安全审计策略
  - 增大安全日志大小
  - 启用PowerShell日志
  - 配置日志转发/集中收集
```

#### 10.8.2 进阶加固步骤

```
步骤6：PowerShell安全加固
  - 设置合理的执行策略
  - 启用脚本块日志、模块日志、转录日志
  - 禁用PowerShell 2.0
  - 部署WDAC/AppLocker启用约束语言模式

步骤7：安全基线配置
  - 配置安全选项（LSA、匿名枚举等）
  - 配置用户权限分配
  - 启用Windows Defender相关功能
  - 配置UAC级别

步骤8：数据保护
  - 启用BitLocker磁盘加密
  - 配置EFS（如需要）
  - 配置备份策略

步骤9：补丁与更新
  - 配置自动更新
  - 建立补丁测试和部署流程
  - 定期扫描缺失补丁

步骤10：持续监控
  - 部署监控告警
  - 定期安全审计
  - 日志分析与异常检测
  - 定期渗透测试
```

## 🛠️ 补充：实战拓展

### 综合安全检查脚本

```powershell
# Windows安全加固检查清单自动化脚本
function Invoke-SecurityChecklist {
    Write-Host "========================================" -ForegroundColor Cyan
    Write-Host "  Windows系统安全检查清单" -ForegroundColor Cyan
    Write-Host "========================================" -ForegroundColor Cyan
    Write-Host ""

    $results = @()

    # 1. 账户安全
    Write-Host "[1/7] 账户安全检查" -ForegroundColor Yellow
    $adminCount = (Get-LocalGroupMember -Group "Administrators").Count
    $guestStatus = (Get-LocalUser -Name "Guest" -ErrorAction SilentlyContinue).Enabled
    $results += [PSCustomObject]@{类别="账户安全"; 检查项="管理员组成员数量"; 结果=$adminCount; 状态=if($adminCount -le 3){"通过"}else{"警告"}}
    $results += [PSCustomObject]@{类别="账户安全"; 检查项="Guest账户状态"; 结果="禁用: $(-not $guestStatus)"; 状态=if(-not $guestStatus){"通过"}else{"不通过"}}

    # 2. 防火墙
    Write-Host "[2/7] 防火墙检查" -ForegroundColor Yellow
    $firewall = Get-NetFirewallProfile
    $allEnabled = ($firewall | Where-Object { $_.Enabled -eq $false }).Count -eq 0
    $results += [PSCustomObject]@{类别="防火墙"; 检查项="所有配置文件启用"; 结果=$allEnabled; 状态=if($allEnabled){"通过"}else{"不通过"}}

    # 3. 服务与端口
    Write-Host "[3/7] 服务与端口检查" -ForegroundColor Yellow
    $listenPorts = (Get-NetTCPConnection -State Listen).Count
    $results += [PSCustomObject]@{类别="端口"; 检查项="监听端口数量"; 结果=$listenPorts; 状态="待评估"}

    # 4. 补丁更新
    Write-Host "[4/7] 补丁更新检查" -ForegroundColor Yellow
    $hotfixCount = (Get-HotFix).Count
    $lastPatch = (Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 1).InstalledOn
    $daysSince = (Get-Date) - $lastPatch
    $results += [PSCustomObject]@{类别="补丁"; 检查项="已安装补丁数"; 结果=$hotfixCount; 状态="待评估"}
    $results += [PSCustomObject]@{类别="补丁"; 检查项="最近补丁时间"; 结果=$lastPatch; 状态=if($daysSince.TotalDays -lt 90){"通过"}else{"警告"}}

    # 5. Windows Defender
    Write-Host "[5/7] Defender检查" -ForegroundColor Yellow
    $defender = Get-MpComputerStatus -ErrorAction SilentlyContinue
    if ($defender) {
        $results += [PSCustomObject]@{类别="Defender"; 检查项="实时保护"; 结果=$defender.RealTimeProtectionEnabled; 状态=if($defender.RealTimeProtectionEnabled){"通过"}else{"不通过"}}
    }

    # 6. UAC
    Write-Host "[6/7] UAC检查" -ForegroundColor Yellow
    $uac = Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name "EnableLUA" -ErrorAction SilentlyContinue
    $results += [PSCustomObject]@{类别="UAC"; 检查项="UAC启用"; 结果=$($uac.EnableLUA -eq 1); 状态=if($uac.EnableLUA -eq 1){"通过"}else{"不通过"}}

    # 7. 日志审计
    Write-Host "[7/7] 日志审计检查" -ForegroundColor Yellow
    $sbLog = Get-ItemProperty "HKLM:\SOFTWARE\Wow6432Node\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" -ErrorAction SilentlyContinue
    $results += [PSCustomObject]@{类别="日志"; 检查项="PS脚本块日志"; 结果=$(if($sbLog){$sbLog.EnableScriptBlockLogging -eq 1}else{"未配置"}); 状态=if($sbLog -and $sbLog.EnableScriptBlockLogging -eq 1){"通过"}else{"不通过"}}

    Write-Host ""
    Write-Host "========================================" -ForegroundColor Cyan
    Write-Host "  检查结果汇总" -ForegroundColor Cyan
    Write-Host "========================================" -ForegroundColor Cyan
    $results | Format-Table -AutoSize
}
```

### 加固优先级建议

```
高优先级（立即执行）：
1. 启用Windows防火墙

中优先级（本周内完成）：

低优先级（逐步完善）：
1. 部署AppLocker/WDAC
2. 启用BitLocker加密

```
