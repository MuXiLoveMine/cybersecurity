# 详细子方向

### 2.1 网络协议安全

#### 2.1.1 TCP/IP 协议栈安全
**核心知识点**
- OSI 七层模型与 TCP/IP 四层模型的对应关系
- 各层的安全风险与防护要点
- 协议设计缺陷导致的安全问题

**常见攻击**
- TCP 协议：SYN Flood、TCP 会话劫持、RST 攻击、端口扫描
- UDP 协议：UDP Flood、UDP 反射放大攻击
- IP 协议：IP 欺骗、IP 分片攻击、Smurf 攻击
- ICMP 协议：ICMP Flood、Ping of Death、Smurf、Traceroute 探测

**防御方法**
- 防火墙规则配置
- 流量清洗
- 协议异常检测
- SYN Cookie / SYN Proxy

#### 2.1.2 HTTP/HTTPS 协议安全
**核心知识点**
- HTTP 请求方法（GET/POST/PUT/DELETE/OPTIONS 等）
- HTTP 状态码含义
- HTTP 头字段（Cookie、Referer、User-Agent、X-Forwarded-For 等）
- HTTPS 握手过程
- TLS/SSL 协议原理
- 证书验证机制

**常见攻击**
- HTTP 走私（HTTP Smuggling）
- HTTPS 降级攻击
- SSL/TLS 漏洞（Heartbleed、POODLE、BEAST 等）
- 证书伪造
- 中间人攻击

**防御方法**
- 使用最新的 TLS 版本（TLS 1.3）
- 禁用弱加密套件
- 证书固定（Certificate Pinning）
- HSTS（HTTP Strict Transport Security）
- 安全的 HTTP 头配置

#### 2.1.3 DNS 协议安全
**核心知识点**
- DNS 解析过程（递归查询、迭代查询）
- DNS 记录类型（A、AAAA、CNAME、MX、TXT、NS、SOA 等）
- DNS 缓存机制
- DNSSEC 原理

**常见攻击**
- DNS 劫持
- DNS 缓存投毒
- DNS 放大攻击
- DNS 隧道
- 子域名劫持
- DNS 重绑定

**防御方法**
- DNSSEC 部署
- 安全的 DNS 服务器配置
- DNS 监控与异常检测
- 域名注册商安全
- 双因素认证保护域名管理账号

#### 2.1.4 ARP 协议安全
**核心知识点**
- ARP 协议工作原理
- ARP 缓存机制
- 免费 ARP（Gratuitous ARP）
- 代理 ARP

**常见攻击**
- ARP 欺骗（ARP Spoofing）
- ARP 缓存投毒
- 中间人攻击（基于 ARP 欺骗）
- 网络嗅探

**防御方法**
- 静态 ARP 绑定
- DAI（Dynamic ARP Inspection）
- 端口安全
- ARP 监控工具
- 网络分段

#### 2.1.5 DHCP 协议安全
**核心知识点**
- DHCP 工作原理（DORA 过程）
- DHCP 地址分配机制
- DHCP 选项

**常见攻击**
- DHCP 耗尽攻击
- 恶意 DHCP 服务器
- DHCP 欺骗

**防御方法**
- DHCP Snooping
- IP Source Guard
- 端口安全
- DHCP 服务器认证

#### 2.1.6 IPv6 安全
**核心知识点**
- IPv6 地址格式与类型
- IPv6 邻居发现协议（NDP）
- IPv6 自动配置
- IPv6 过渡技术

**常见攻击**
- NDP 欺骗（类似 ARP 欺骗）
- IPv6 隧道攻击
- 地址扫描
- 扩展头攻击

**防御方法**
- SEND（Secure Neighbor Discovery）
- RA Guard
- IPv6 防火墙规则
- IPv6 监控

### 2.2 网络设备安全

#### 2.2.1 路由器安全配置
**核心知识点**
- 路由器工作原理
- 路由协议（静态路由、RIP、OSPF、BGP）
- 访问控制列表（ACL）
- NAT 技术
- 路由器管理安全

**安全基线**
- 修改默认密码
- 禁用不必要的服务
- 启用 SSH，禁用 Telnet
- 配置 ACL 限制管理访问
- 启用日志记录
- 定期更新固件
- 物理安全防护

**常见攻击**
- 路由劫持
- BGP 前缀劫持
- 路由器弱口令
- 管理接口暴露
- 固件漏洞利用

#### 2.2.2 交换机安全配置
**核心知识点**
- 交换机工作原理
- VLAN 技术
- 生成树协议（STP）
- 端口安全
- 链路聚合

**安全基线**
- 配置 VLAN 隔离
- 启用端口安全
- 禁用未使用端口
- 配置 STP 安全（BPDU Guard、Root Guard）
- 启用 DHCP Snooping
- 启用 DAI
- 管理安全

**常见攻击**
- VLAN 穿透（VLAN Hopping）
- MAC 地址泛洪
- STP 攻击
- CAM 表溢出
- 端口安全绕过

#### 2.2.3 防火墙技术
**核心知识点**
- 防火墙类型：包过滤、状态检测、应用层网关、下一代防火墙（NGFW）
- 防火墙工作模式：路由模式、透明模式、混合模式
- 防火墙策略配置
- NAT 策略
- VPN 配置

**核心功能**
- 访问控制
- 网络地址转换（NAT）
- VPN 支持
- 入侵防御（IPS）
- 应用识别与控制
- 用户身份认证
- 日志与审计

**最佳实践**
- 最小权限原则
- 默认拒绝策略
- 定期审计防火墙规则
- 清理过期规则
- 规则优化与性能调优

#### 2.2.4 IDS/IPS（入侵检测/防御系统）
**核心知识点**
- IDS 与 IPS 的区别
- 检测技术：特征匹配、异常检测、协议分析
- 部署方式：旁路、串接
- 误报与漏报的平衡

**常见类型**
- NIDS（网络入侵检测系统）
- HIDS（主机入侵检测系统）
- NIPS（网络入侵防御系统）
- HIPS（主机入侵防御系统）

**知名产品**
- Snort / Suricata（开源）
- Bro / Zeek（开源）
- 天融信、启明星辰、深信服（国内厂商）
- Palo Alto、Fortinet（国外厂商）

#### 2.2.5 负载均衡安全
**核心知识点**
- 负载均衡原理
- 负载均衡算法（轮询、加权轮询、最少连接、IP Hash 等）
- 四层 vs 七层负载均衡
- 负载均衡安全配置

**安全功能**
- DDoS 防护
- SSL 卸载
- WAF 集成
- 健康检查
- 连接限制

### 2.6 网络流量分析

#### 2.6.1 流量抓包与分析
**核心工具**
- Wireshark（图形化）
- tcpdump（命令行）
- tshark（Wireshark 命令行版本）

**分析要点**
- 协议解析
- 流量统计
- 异常检测
- 会话重组
- 文件提取

**常用过滤语法**
```
# 按协议过滤
tcp
udp
http
dns

# 按 IP 过滤
ip.addr == 192.168.1.1
ip.src == 192.168.1.1
ip.dst == 192.168.1.1

# 按端口过滤
tcp.port == 80
tcp.dstport == 80
tcp.srcport == 80

# 组合过滤
ip.addr == 192.168.1.1 && tcp.port == 80
http.request.method == "POST"
```

#### 2.6.2 异常流量检测
**常见异常**
- 流量突增

**检测方法**
