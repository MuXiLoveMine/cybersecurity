# 常见面试题

### 基础概念
1. **OSI 七层模型和 TCP/IP 四层模型的区别？**
   - OSI 是理论模型，TCP/IP 是实际使用的模型
   - OSI 七层：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层
   - TCP/IP 四层：网络接口层、网络层、传输层、应用层

2. **TCP 和 UDP 的区别？**
   - TCP 是面向连接的、可靠的、基于字节流的
   - UDP 是无连接的、不可靠的、面向报文的
   - TCP 有三次握手、四次挥手、流量控制、拥塞控制
   - UDP 速度快，适合实时应用

3. **TCP 三次握手的过程？为什么需要三次？**
   - 第一次：客户端发送 SYN
   - 第二次：服务端回复 SYN+ACK
   - 第三次：客户端回复 ACK
   - 三次握手是为了确认双方的收发能力都正常

4. **ARP 协议的作用？ARP 欺骗的原理？**
   - ARP 用于将 IP 地址解析为 MAC 地址
   - ARP 欺骗是通过发送伪造的 ARP 报文，修改目标的 ARP 缓存
   - 可以实现中间人攻击、流量劫持等

### 安全技术
5. **DDoS 攻击有哪些类型？如何防御？**
   - 网络层：SYN Flood、UDP Flood、ICMP Flood
   - 应用层：HTTP Flood、CC 攻击
   - 反射放大：DNS 放大、NTP 放大
   - 防御：流量清洗、高防 IP、CDN、限速、黑名单

6. **防火墙的类型和工作原理？**
   - 包过滤防火墙：基于 IP、端口、协议
   - 状态检测防火墙：跟踪连接状态
   - 应用层网关：代理应用层数据
   - 下一代防火墙：集成 IPS、应用识别等

7. **IDS 和 IPS 的区别？**
   - IDS 是入侵检测系统，旁路部署，只检测不阻断
   - IPS 是入侵防御系统，串接部署，可以主动阻断
   - IDS 误报影响小，IPS 误报影响大

8. **什么是零信任？核心原则是什么？**
   - 零信任：从不信任，始终验证
   - 核心原则：身份验证、最小权限、持续验证、假设 breach
   - 不是产品，是一种安全理念和架构

### 实战相关
9. **如何用 Wireshark 分析异常流量？**
   - 看统计信息：会话、端点、协议分层
   - 用过滤语法筛选可疑流量
   - 跟踪 TCP 流查看内容
   - 对比正常基线找异常

10. **VLAN 穿透的原理和防御？**
    - VLAN Hopping 两种方式：交换机欺骗、双标签
    - 交换机欺骗：伪装成 trunk 端口
    - 双标签：利用双层 VLAN 标签绕过
    - 防御：禁用 DTP、设置本征 VLAN、端口安全
