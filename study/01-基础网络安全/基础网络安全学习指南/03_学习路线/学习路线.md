# 学习路线

### 阶段 1：网络基础（1-2 个月）
**学习目标**：掌握计算机网络基础知识，理解网络工作原理

**学习内容**
- OSI 七层模型与 TCP/IP 四层模型
- IP 地址与子网划分
- 路由原理与路由协议
- 核心协议：TCP、UDP、HTTP、DNS、ARP、ICMP
- Wireshark 抓包分析

**实践任务**
- 用 Wireshark 抓取并分析各种协议数据包
- 配置静态路由
- 搭建简单的网络环境
- 完成子网划分练习

### 阶段 2：网络设备与安全技术（2-3 个月）
**学习目标**：掌握网络设备配置和基础安全技术

**学习内容**
- 路由器、交换机基础配置
- VLAN 配置与 trunk
- 防火墙原理与基础配置
- IDS/IPS 原理与部署
- VPN 技术与配置
- 网络访问控制

**实践任务**
- 用 Cisco Packet Tracer / GNS3 / EVE-NG 搭建实验环境
- 配置 VLAN 间路由
- 配置防火墙 ACL 规则
- 配置 IPsec VPN
- 部署 Snort IDS

### 阶段 3：攻击与防御（2-3 个月）
**学习目标**：理解常见网络攻击原理，掌握防御方法

**学习内容**
- DDoS 攻击原理与防御
- ARP 欺骗与防御
- DNS 劫持与防御
- 中间人攻击与防御
- 端口扫描技术
- 无线网络攻击与防御
- 网络嗅探与防护

**实践任务**
- 模拟 DDoS 攻击（实验环境）
- ARP 欺骗实验
- DNS 劫持实验
- 中间人攻击实验
- 无线密码破解实验
- 配置各种防御措施

### 阶段 4：进阶与实战（持续）
**学习目标**：深入理解高级网络安全技术，具备架构设计能力

**学习内容**
- 零信任架构
- SDN 安全
- 网络流量分析
- 安全架构设计
- 安全运营
- 应急响应

**实践任务**
- 参与 CTF 网络方向题目
- 搭建完整的企业网络安全架构
- 进行网络安全评估
- 编写安全配置基线
