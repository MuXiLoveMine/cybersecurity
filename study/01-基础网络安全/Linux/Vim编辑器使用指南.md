# Vim 编辑器使用指南

> Vim 是 Linux/Unix 下最强大的文本编辑器之一，是安全从业者、程序员、运维人员的必备技能。掌握 Vim 能极大提升工作效率。

---

## 一、Vim 简介

### 1.1 什么是 Vim

Vim（Vi IMproved）是从 vi 发展而来的高度可配置的文本编辑器，由 Bram Moolenaar 于 1991 年发布。它以高效的键盘操作、强大的插件生态和陡峭的学习曲线闻名。

**特点**：
- 纯键盘操作，脱离鼠标
- 模式化编辑（多种工作模式）
- 高度可配置
- 丰富的插件生态
- 跨平台（Linux、macOS、Windows）
- 轻量快速
- 几乎所有 Linux 发行版默认安装

### 1.2 为什么要学 Vim

- **服务器必备**：几乎所有 Linux 服务器都预装了 vi/vim，SSH 远程操作必须会
- **效率极高**：熟练后编辑速度远超普通编辑器
- **无处不在**：Git、SSH、Docker 等很多工具默认调用 vi
- **安全从业者必备**：修改配置、写脚本、分析文件都离不开
- **可定制性强**：可以打造成专属 IDE

### 1.3 Vim vs Vi vs Neovim

| 编辑器 | 说明 |
|--------|------|
| vi | 最原始的版本，Unix 标配 |
| Vim | Vi IMproved，功能增强，最常用 |
| Neovim | Vim 的现代分支，性能更好，Lua 配置 |

> 本文档以 Vim 为主，大部分命令同样适用于 vi 和 Neovim。

## 二、Vim 的三种基本模式

Vim 最核心的概念是**模式**，不同模式下按键的含义完全不同。

### 2.1 普通模式（Normal Mode）

- **默认模式**，启动 Vim 后进入的模式
- 按键作为**命令**执行，不是输入文字
- 用于移动光标、复制粘贴、删除、查找等
- 按 `Esc` 键从其他模式回到普通模式

### 2.2 插入模式（Insert Mode）

- 用于**输入文字**，和普通编辑器一样
- 左下角显示 `-- INSERT --`
- 从普通模式按 `i`、`a`、`o` 等进入
- 按 `Esc` 回到普通模式

### 2.3 命令行模式（Command-Line Mode）

- 也叫底行模式、Ex 模式
- 用于执行复杂命令：保存、退出、查找替换、设置等
- 从普通模式按 `:` 进入
- 命令输入完按回车执行，按 `Esc` 取消

### 2.4 其他模式

- **可视模式（Visual Mode）**：选择文本，按 `v`、`V`、`Ctrl+v` 进入
- **替换模式（Replace Mode）**：覆盖输入，按 `R` 进入
- **选择模式（Select Mode）**：类似可视模式，较少用

### 2.5 模式切换图

```
启动 Vim
   ↓
普通模式 ←──Esc── 插入模式
   │                    ↑
   │ :                  │ i a o
   ↓                    │
命令行模式              │
   │                    │
   └─────Esc────────────┘
   
普通模式 ←──Esc── 可视模式
   │                    ↑
   │ v V Ctrl+v         │
   └────────────────────┘
```

> 💡 **记住**：不确定在什么模式时，按几下 `Esc` 就回到普通模式了。

## 三、打开与退出 Vim

### 3.1 打开 Vim

```bash
# 直接打开
vim

# 打开文件
vim 文件名

# 打开多个文件
vim 文件1 文件2 文件3

# 只读方式打开
vim -R 文件名
# 或
view 文件名

# 打开到指定行
vim +行号 文件名
vim +100 test.txt  # 打开到第 100 行

# 打开到最后一行
vim + 文件名

# 打开并搜索
vim +/关键词 文件名
```

### 3.2 保存与退出

在**普通模式**下按 `:` 进入命令行模式：

| 命令 | 作用 |
|------|------|
| `:w` | 保存（write） |
| `:w 文件名` | 另存为 |
| `:q` | 退出（quit），未保存会提示 |
| `:q!` | 强制退出，不保存 |
| `:wq` | 保存并退出 |
| `:x` | 保存并退出（和 :wq 类似，无修改时不更新时间戳） |
| `:wq!` | 强制保存退出（只读文件也能保存，前提是有权限） |
| `:qa` | 退出所有文件 |
| `:wqa` | 保存所有并退出 |
| `ZZ` | 普通模式下，保存并退出（大写 Z 连按两次） |
| `ZQ` | 普通模式下，不保存退出 |

> 💡 **新手最常遇到的问题**：不知道怎么退出 Vim。记住 `:q!` 可以强制退出不保存，`ZZ` 快速保存退出。

### 3.3 新建文件

```bash
vim 新文件名
# 进入后输入内容，:w 保存即可
```

## 四、光标移动（普通模式）

光标移动是 Vim 最基础也最重要的操作，熟练后可以脱离方向键。

### 4.1 基本移动

| 按键 | 作用 | 助记 |
|------|------|------|
| `h` | 左移 | 左手最左 |
| `j` | 下移 | j 像向下的箭头 |
| `k` | 上移 | k 像向上的箭头 |
| `l` | 右移 | 右手最右 |

> 💡 建议从一开始就练习用 `hjkl` 移动，不要用方向键，这样手不用离开主键盘区。

|------|------|

| `^` | 行首第一个非空字符 |
| `$` | 行尾 |
| `g_` | 行尾最后一个非空字符 |
| `+` | 下一行行首 |
| `-` | 上一行行首 |
| `Enter` | 下一行行首 |

### 4.4 屏幕移动

| 按键 | 作用 |
|------|------|
| `H` | 屏幕顶部（High） |
| `M` | 屏幕中间（Middle） |
| `L` | 屏幕底部（Low） |
| `Ctrl + f` | 向下翻一页（forward） |
| `Ctrl + b` | 向上翻一页（backward） |
| `Ctrl + d` | 向下翻半页（down） |
| `Ctrl + u` | 向上翻半页（up） |
| `Ctrl + e` | 屏幕向下滚动一行 |
| `Ctrl + y` | 屏幕向上滚动一行 |

### 4.5 文件移动

| 按键 | 作用 |
|------|------|
| `gg` | 文件开头 |
| `G` | 文件末尾 |
| `行号G` | 跳转到指定行，如 `100G` |

### 4.6 搜索移动

| 按键 | 作用 |
|------|------|
| `f字符` | 向右跳转到指定字符（find） |
| `F字符` | 向左跳转到指定字符 |
| `t字符` | 向右跳转到指定字符前一个（till） |
| `T字符` | 向左跳转到指定字符后一个 |
| `;` | 重复上次 f/F/t/T 搜索 |
| `,` | 反向重复上次 f/F/t/T 搜索 |

### 4.7 其他移动

| 按键 | 作用 |
|------|------|
| `(` | 上一句 |
| `)` | 下一句 |
| `{` | 上一段 |
| `}` | 下一段 |
| `[[` | 上一节 |
| `]]` | 下一节 |

### 4.8 数字前缀

Vim 中大部分命令前可以加数字，表示重复执行：

```
10j      # 向下移动 10 行
5w       # 向后移动 5 个单词
3dd      # 删除 3 行
100G     # 跳转到第 100 行
2y$      # 复制 2 行（从当前到下一行行尾）
```

## 五、进入插入模式

从普通模式进入插入模式的方式有很多，根据需要选择：

### 5.1 在光标位置插入

| 按键 | 作用 |
|------|------|
| `i` | 在光标前插入（insert） |
| `I` | 在行首插入（大写 i） |
| `a` | 在光标后插入（append） |
| `A` | 在行尾插入（大写 a） |

### 5.2 新开一行插入

| 按键 | 作用 |
|------|------|
| `o` | 在下方新开一行插入（open） |
| `O` | 在上方新开一行插入（大写 o） |

### 5.3 替换后插入

| 按键 | 作用 |
|------|------|
| `s` | 删除光标字符并进入插入模式（substitute） |
| `S` | 删除整行并进入插入模式（同 `cc`） |
| `C` | 删除光标到行尾并进入插入模式（同 `c$`） |
| `r字符` | 替换光标处单个字符，不进入插入模式 |
| `R` | 进入替换模式，逐字符覆盖 |

### 5.4 插入模式下的操作

在插入模式中也可以用一些快捷键：

| 按键 | 作用 |
|------|------|
| `Ctrl + h` | 删除前一个字符（同 Backspace） |
| `Ctrl + w` | 删除前一个单词 |
| `Ctrl + u` | 删除到行首 |
| `Ctrl + t` | 缩进一行 |
| `Ctrl + d` | 反缩进一行 |
| `Ctrl + n` | 向下补全 |
| `Ctrl + p` | 向上补全 |
| `Ctrl + o` | 临时回到普通模式执行一个命令 |
| `Ctrl + [` | 同 Esc，回到普通模式 |

> 💡 `Ctrl + o` 很实用，比如插入模式下按 `Ctrl + o dd` 可以删除当前行然后自动回到插入模式。

## 六、删除、复制、粘贴

### 6.1 删除（剪切）

Vim 中删除的内容会被保存到寄存器，可以粘贴，相当于剪切。

| 按键 | 作用 |
|------|------|
| `x` | 删除光标处字符 |
| `X` | 删除光标前一个字符 |
| `dd` | 删除整行 |
| `D` | 删除光标到行尾（同 `d$`） |
| `dw` | 删除一个单词 |
| `d$` | 删除光标到行尾 |
| `d0` | 删除光标到行首 |
| `dG` | 删除光标到文件末尾 |
| `dgg` | 删除光标到文件开头 |
| `d}` | 删除到段落末尾 |
| `d)` | 删除到句子末尾 |
| `diw` | 删除光标所在单词（不包括空格） |
| `daw` | 删除光标所在单词（包括空格） |
| `di"` | 删除双引号内的内容 |
| `da"` | 删除双引号及内容 |
| `di(` | 删除括号内的内容 |
| `da(` | 删除括号及内容 |
| `J` | 合并下一行到当前行 |

### 6.2 复制（yank）

| 按键 | 作用 |
|------|------|
| `yy` | 复制整行 |
| `Y` | 复制整行（同 yy） |
| `yw` | 复制一个单词 |
| `y$` | 复制光标到行尾 |
| `y0` | 复制光标到行首 |
| `yG` | 复制光标到文件末尾 |
| `ygg` | 复制光标到文件开头 |
| `yiw` | 复制光标所在单词 |
| `yaw` | 复制光标所在单词（含空格） |
| `yi"` | 复制双引号内的内容 |

### 6.3 粘贴（put）

| 按键 | 作用 |
|------|------|
| `p` | 在光标后粘贴（小写 p） |
| `P` | 在光标前粘贴（大写 P） |
| `"np` | 粘贴第 n 号寄存器内容，如 `"1p` |
| `"+p` | 粘贴系统剪贴板内容 |
| `gp` | 粘贴并移动光标到粘贴内容后 |

### 6.4 文本对象（Text Objects）

文本对象是 Vim 的强大功能，可以精确选择/删除/复制一块内容。

格式：`操作符 + 范围 + 对象`

**操作符**：`d`（删除）、`y`（复制）、`c`（修改）、`v`（可视选择）、`>`（缩进）等

**范围**：
- `i`：inner，内部（不包括边界）
- `a`：around，周围（包括边界）

**对象**：
- `w`：单词（word）
- `s`：句子（sentence）
- `p`：段落（paragraph）
- `"`、`'`、`` ` ``：引号
- `(`、`)`、`b`：括号
- `[`、`]`：方括号
- `{`、`}`、`B`：花括号
- `<`、`>`：尖括号
- `t`：标签（HTML/XML tag）

**示例**：
```
diw    # 删除光标所在单词
ci"    # 修改双引号内的内容（删除并进入插入模式）
ya(    # 复制括号及内容
vi{    # 可视选择花括号内的内容
dat    # 删除整个 HTML 标签（含标签）
cit    # 修改 HTML 标签内的内容
```

> 💡 文本对象是 Vim 效率的核心，熟练掌握后编辑速度会有质的飞跃。

## 七、修改与替换

### 7.1 修改（change）

修改 = 删除 + 进入插入模式

| 按键 | 作用 |
|------|------|
| `c` | 修改操作符，配合移动命令 |
| `cc` | 修改整行（删除整行并插入） |
| `C` | 修改光标到行尾 |
| `cw` | 修改一个单词 |
| `c$` | 修改光标到行尾 |
| `ciw` | 修改光标所在单词 |
| `ci"` | 修改双引号内内容 |
| `r` | 替换单个字符 |
| `R` | 进入替换模式 |
| `~` | 切换光标处字符大小写 |
| `g~w` | 切换单词大小写 |
| `guw` | 单词转小写 |
| `gUw` | 单词转大写 |

### 7.2 撤销与重做

| 按键 | 作用 |
|------|------|
| `u` | 撤销（undo） |
| `U` | 撤销整行的所有修改 |
| `Ctrl + r` | 重做（redo） |
| `.` | 重复上次修改命令（非常实用！） |

> 💡 `.` 命令是 Vim 最强大的命令之一，可以重复上次的修改操作。比如 `dd` 删除一行后，按 `.` 可以继续删除下一行。

### 7.3 缩进

| 按键 | 作用 |
|------|------|
| `>>` | 当前行向右缩进 |
| `<<` | 当前行向左缩进 |
| `>G` | 当前行到文件末尾向右缩进 |
| `>}` | 到段落末尾向右缩进 |
| `==` | 自动缩进当前行 |
| `=G` | 自动缩进当前行到文件末尾 |
| `gg=G` | 自动缩进整个文件 |

### 7.4 查找替换（命令行模式）

#### 基本查找

| 命令 | 作用 |
|------|------|
| `/关键词` | 向下查找 |
| `?关键词` | 向上查找 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `*` | 向下查找光标所在单词 |
| `#` | 向上查找光标所在单词 |
| `g*` | 向下查找光标所在单词（部分匹配） |

#### 查找替换语法

```
:[范围]s/查找内容/替换内容/[标志]
```

**范围**：
- 不写：当前行
- `%`：整个文件
- `1,10`：第 1 到 10 行
- `.,$`：当前行到文件末尾
- `'<,'>`：可视选择的范围（在可视模式按 : 自动填入）

**标志**：
- `g`：全局替换（一行中所有匹配）
- `c`：替换前确认
- `i`：忽略大小写
- `I`：区分大小写
- `n`：只统计不替换

#### 常用示例

```bash
# 当前行替换第一个
:s/old/new/

# 当前行全部替换
:s/old/new/g

# 整个文件替换
:%s/old/new/g

# 整个文件替换，每次确认
:%s/old/new/gc

# 第 1 到 10 行替换
:1,10s/old/new/g

# 替换并忽略大小写
:%s/old/new/gi

# 只统计匹配数量
:%s/old//gn

# 查找特殊字符需要转义
:%s/\./。/g    # 把英文句号替换为中文句号

# 使用其他分隔符（避免转义 /）
:%s#/usr/local#/opt#g
```

#### 正则表达式

Vim 查找替换支持正则表达式：

```
:%s/^#//g        # 删除行首的 #
:%s/\s*$//g      # 删除行尾空格
:%s/^\n//        # 删除空行
:%s/^/    /g     # 每行前加 4 个空格
:%s/\(.*\)/"\1"/g  # 每行加双引号
```

## 八、可视模式

可视模式用于选择文本，然后对选中的内容执行操作。

### 8.1 进入可视模式

| 按键 | 模式 | 作用 |
|------|------|------|
| `v` | 字符可视模式 | 按字符选择 |
| `V` | 行可视模式 | 按行选择 |
| `Ctrl + v` | 块可视模式 | 按矩形块选择 |

### 8.2 可视模式操作

进入可视模式后，移动光标选择文本，然后执行操作：

| 按键 | 作用 |
|------|------|
| `d` | 删除选中内容 |
| `y` | 复制选中内容 |
| `c` | 修改选中内容 |
| `>` | 向右缩进 |
| `<` | 向左缩进 |
| `=` | 自动缩进 |
| `U` | 转大写 |
| `u` | 转小写 |
| `~` | 切换大小写 |
| `J` | 合并行 |
| `gq` | 格式化文本 |
| `:` | 对选中内容执行命令 |

### 8.3 块可视模式（Ctrl + v）

块可视模式是 Vim 的特色功能，可以选择矩形区域，非常适合批量编辑。

**常见用途**：
- 批量在多行前添加内容
- 批量删除多行前的字符
- 批量对齐

**示例：批量注释多行**
1. `Ctrl + v` 进入块可视模式
2. 移动光标选择要注释的行（按 j 向下选）
3. 按 `I`（大写 i）进入块插入模式
4. 输入 `//` 或 `#`
5. 按 `Esc`，所有选中行前都会添加注释

**示例：批量删除行首字符**
1. `Ctrl + v` 进入块可视模式
2. 选择要删除的矩形区域
3. 按 `d` 删除

### 8.4 扩展选择

在可视模式中可以用文本对象扩展选择：

```
viw    # 选择光标所在单词
vi"    # 选择双引号内内容
vi(    # 选择括号内内容
vip    # 选择整个段落
vat    # 选择整个 HTML 标签
```

## 九、多文件编辑

### 9.1 打开多个文件

```bash
vim 文件1 文件2 文件3
```

### 9.2 Buffer（缓冲区）操作

每个打开的文件对应一个 buffer。

| 命令 | 作用 |
|------|------|
| `:ls` | 列出所有 buffer |
| `:buffers` | 同 :ls |
| `:b 编号` | 跳转到指定 buffer |
| `:b 文件名` | 跳转到指定文件（支持 Tab 补全） |
| `:bn` | 下一个 buffer（next） |

## 十二、寄存器（Registers）

寄存器是 Vim 存储复制/删除内容的地方，有多个独立的寄存器。

### 12.1 寄存器类型

| 寄存器 | 名称 | 作用 |
|--------|------|------|
| `""` | 无名寄存器 | 默认寄存器，最近一次删除/复制 |
| `"0` | 复制寄存器 | 最近一次 yank 内容 |
| `"1-9` | 编号寄存器 | 最近 9 次删除（行级） |
| `"-` | 小删除寄存器 | 小于一行的删除 |
| `".` | 上次插入寄存器 | 上次插入模式输入的内容 |
| `"%` | 当前文件名 | 当前文件路径 |
| `"#` | 轮换文件名 | 上一个文件 |
| `":` | 上次命令 | 上次执行的命令行 |
| `"/` | 上次搜索 | 上次搜索的内容 |
| `"a-z` | 命名寄存器 | 用户自定义，共 26 个 |
| `"+` | 系统剪贴板 | 操作系统剪贴板 |
| `"*` | 选择寄存器 | X11 选择（Linux） |

### 12.2 使用寄存器

```
"ayy    # 复制当前行到寄存器 a
"ap     # 粘贴寄存器 a 的内容
"Ayy    # 大写 A 表示追加到寄存器 a
"+y     # 复制到系统剪贴板
"+p     # 从系统剪贴板粘贴
:reg    # 查看所有寄存器内容
:reg a  # 查看寄存器 a
```

### 12.3 命名寄存器技巧

命名寄存器（a-z）非常适合临时存储多段内容：

```
"ayy    # 第一段存到 a
"byy    # 第二段存到 b
"cyy    # 第三段存到 c
"ap     # 需要时粘贴 a
"bp     # 需要时粘贴 b
```

## 十三、宏（Macro）

宏可以录制一系列操作，然后重复执行，是批量处理的利器。

### 13.1 录制宏

1. 按 `q` + 寄存器名（如 `qa`）开始录制
2. 左下角显示 `recording @a`
3. 执行要录制的操作
4. 按 `q` 结束录制

### 13.2 执行宏

```
@a      # 执行寄存器 a 的宏
@@      # 重复上次执行的宏
10@a    # 执行宏 10 次
```

### 13.3 宏示例

**示例：给每行加序号**
1. 第一行手动输入 `1. `
2. `qa` 开始录制
3. `yyp` 复制一行
4. `Ctrl + a` 数字加 1
5. `q` 结束录制
6. `10@a` 执行 10 次，生成 11 行带序号的内容

**示例：批量格式化**
```
qa        # 开始录制到 a
0         # 到行首
i"        # 行首加引号
A",       # 行尾加引号和逗号
j         # 下一行
q         # 结束录制
10@a      # 对 10 行执行
```

### 13.4 编辑宏

```
:let @a=' '   # 清空寄存器 a
"ap           # 粘贴宏内容到文件
# 编辑内容
"ay$          # 重新复制回寄存器 a
```

## 十六、Vim 配置文件 .vimrc

Vim 的配置文件是 `~/.vimrc`（Linux/macOS）或 `_vimrc`（Windows），所有配置写在这里。

### 16.1 基础配置

```vim
" ===== 基础设置 =====
set nocompatible              " 不兼容 vi 模式
filetype plugin indent on     " 启用文件类型检测、插件、缩进
syntax on                     " 语法高亮

set number                    " 显示行号
set relativenumber            " 相对行号
set cursorline                " 高亮当前行
set cursorcolumn              " 高亮当前列

set tabstop=4                 " Tab 显示为 4 个空格
set shiftwidth=4              " 自动缩进宽度
set softtabstop=4             " 编辑时 Tab 宽度
set expandtab                 " Tab 转换为空格
set autoindent                " 自动缩进
set smartindent               " 智能缩进

set incsearch                 " 输入时即时搜索
set hlsearch                  " 高亮搜索结果
set ignorecase                " 搜索忽略大小写
set smartcase                 " 有大写时区分大小写

set wrap                      " 自动换行
set linebreak                 # 整词换行
set scrolloff=5               " 光标上下保留 5 行
set sidescrolloff=5           " 光标左右保留 5 列

set wildmenu                  " 命令行补全增强
set wildmode=longest:full,full
set laststatus=2              " 总是显示状态栏
set ruler                     " 显示光标位置
set showcmd                   " 显示未完成的命令
set showmode                  " 显示当前模式

set undofile                  " 持久化撤销
set undodir=~/.vim/undodir    " 撤销文件目录
set backup                    " 备份文件
set backupdir=~/.vim/backup   " 备份目录

set encoding=utf-8            " 默认编码
set fileencodings=utf-8,gbk   " 文件编码检测顺序
set termencoding=utf-8        " 终端编码

set mouse=a                   " 启用鼠标支持
set clipboard=unnamedplus     " 与系统剪贴板共享
```

### 16.2 常用快捷键映射

```vim
" ===== 快捷键映射 =====
" 让空格作为 leader 键
let mapleader = " "

" 保存
nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
nnoremap <leader>x :x<CR>

" 分屏移动（Ctrl + hjkl）
nnoremap <C-h> <C-w>h
nnoremap <C-j> <C-w>j
nnoremap <C-k> <C-w>k
nnoremap <C-l> <C-w>l

" 调整分屏大小
nnoremap <C-Left> :vertical resize -3<CR>
nnoremap <C-Right> :vertical resize +3<CR>
nnoremap <C-Up> :resize -3<CR>
nnoremap <C-Down> :resize +3<CR>

" 快速打开/重新加载 vimrc
nnoremap <leader>ev :e $MYVIMRC<CR>
nnoremap <leader>sv :source $MYVIMRC<CR>

" 清除搜索高亮
nnoremap <leader><space> :nohlsearch<CR>

" 快速切换 buffer
nnoremap <leader>n :bn<CR>
nnoremap <leader>p :bp<CR>

" 插入模式下 jj 快速退出
inoremap jj <Esc>
```

### 16.3 状态行配置

```vim
" ===== 状态行 =====
set statusline=%F%m%r%h%w\ [FORMAT=%{&ff}]\ [TYPE=%Y]\ [POS=%l,%v][%p%%]\ %{strftime(\"%d/%m/%y\ -\ %H:%M\")}
```

### 16.4 自动命令

```vim
" ===== 自动命令 =====
augroup vimrc
    autocmd!
    " 打开文件时回到上次编辑位置
    autocmd BufReadPost * if line("'\"") > 1 && line("'\"") <= line("$") | exe "normal! g'\"" | endif
    " Python 文件设置

    " Shell 脚本设置
    autocmd FileType sh setlocal tabstop=4 shiftwidth=4 expandtab
    " Markdown 设置
    autocmd FileType markdown setlocal wrap linebreak spell
    " 保存时去除行尾空格
    autocmd BufWritePre * :%s/\s\+$//e
augroup END
```

| 全文替换 | `:%s/old/new/g` |
| 全文替换确认 | `:%s/old/new/gc` |

### 19.5 文件操作

| 操作 | 命令 |
|------|------|
| 保存 | `:w` |
| 退出 | `:q` |
| 保存退出 | `:wq` / `:x` / `ZZ` |
| 强制退出 | `:q!` / `ZQ` |
| 打开文件 | `:e 文件名` |
| 另存为 | `:w 文件名` |

## 二十、学习建议

### 20.1 学习路径

1. **第一周**：掌握基本模式、光标移动、保存退出、简单编辑
2. **第二周**：练习删除复制粘贴、文本对象、查找替换
3. **第三周**：学习可视模式、分屏、多文件
4. **第四周**：学习寄存器、宏、标记、折叠
5. **持续**：配置 .vimrc、安装插件、形成自己的工作流

### 20.2 练习方法

- **vimtutor**：终端输入 `vimtutor`，Vim 自带的交互式教程，必做！
- **日常使用**：把 Vim 作为默认编辑器，强迫自己使用
- **不要用方向键**：坚持用 `hjkl`，一周后就习惯了
- **不要用鼠标**：纯键盘操作才是 Vim 的精髓
- **看别人的配置**：参考别人的 .vimrc，学习好的配置
- **逐步添加配置**：不要一开始就用别人的完整配置，自己慢慢加

### 20.3 常见误区

- ❌ 只学不用：Vim 是练出来的，不是看出来的
- ❌ 一开始就装一堆插件：先学好原生功能
- ❌ 用方向键和鼠标：效率大打折扣
- ❌ 不配置 .vimrc：默认配置体验不好
- ❌ 急于求成：Vim 学习曲线陡，需要时间积累

### 20.4 进阶方向

- 学习 VimScript，写自己的插件
- 学习 Neovim + Lua 配置
- 用 Vim 作为 IDE（coc.nvim + LSP）
- 学习 tmux + Vim 组合
- 学习 Git 集成（vim-fugitive）
