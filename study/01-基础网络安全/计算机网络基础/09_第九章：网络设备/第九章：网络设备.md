# 第九章：网络设备

### 9.1 网络设备总览

| 设备 | 工作层次 | 主要功能 | 冲突域 | 广播域 |
|------|---------|---------|--------|--------|
| 中继器/集线器 | 物理层 | 信号放大/广播 | 1 个（共享） | 1 个（共享） |
| 网桥/交换机（二层） | 数据链路层 | MAC 地址转发 | 每个端口 1 个 | 1 个（共享） |
| 路由器/三层交换机 | 网络层 | IP 路由转发 | 每个端口 1 个 | 每个端口 1 个 |
| 防火墙 | 网络层/应用层 | 访问控制、安全防护 | - | - |

### 9.2 物理层设备

#### 9.2.1 中继器（Repeater）

- 功能：对衰减的信号进行放大和再生，扩展传输距离
- 特点：不识别 MAC 地址和 IP 地址，只是简单地转发比特流
- 限制：中继器不能无限级联（以太网 5-4-3 规则：5 个网段、4 个中继器、3 个可连接主机）

#### 9.2.2 集线器（Hub）

- 功能：多端口中继器，将一个端口收到的信号从其他所有端口转发出去
- 特点：
  - 共享带宽：所有端口共享总带宽
  - 半双工：同一时间只能有一个设备发送数据
  - 所有端口在同一冲突域和同一广播域
- 现状：已基本被交换机取代

### 9.3 数据链路层设备

#### 9.3.1 网桥（Bridge）

- 功能：连接两个局域网，根据 MAC 地址决定是否转发帧
- 特点：
  - 分割冲突域：每个端口是一个独立的冲突域
  - 不分割广播域：广播帧会转发到所有端口
  - 透明网桥：自动学习 MAC 地址表

#### 9.3.2 二层交换机（Layer 2 Switch）

交换机是现代局域网的核心设备，相当于多端口的网桥。

**主要功能**：
- MAC 地址学习：自动建立 MAC 地址与端口的映射表
- 帧转发/过滤：根据目的 MAC 地址精准转发
- 消除冲突：每个端口是独立的冲突域，支持全双工
- VLAN 支持：将交换机逻辑划分为多个虚拟局域网

**工作原理**：
1. 收到帧后，将源 MAC 地址和接收端口记录到 MAC 地址表（CAM 表）
2. 查询目的 MAC 地址：
   - 已知单播：向对应端口转发
   - 未知单播：向所有其他端口泛洪（广播）
   - 广播/组播：向所有其他端口泛洪
3. MAC 地址表有老化时间（默认 300 秒），过期自动删除

**VLAN（Virtual LAN，虚拟局域网）**：
- 将一台交换机逻辑上划分为多个独立的广播域
- 同一 VLAN 内的设备可以直接通信，不同 VLAN 之间需要三层设备（路由器/三层交换机）才能通信
- 优点：隔离广播域、提高安全性、灵活的网络组织
- VLAN 范围：1 ~ 4094（VLAN 1 为默认 VLAN）

### 9.4 网络层设备

#### 路由器（Router）

路由器是互联网的核心节点设备，负责在不同网络之间转发数据包。

**主要功能**：
- 路由选择：根据路由协议和路由表选择最佳路径
- 数据包转发：根据 IP 地址转发数据包
- 网络隔离：每个接口是一个独立的广播域
- 地址转换（NAT）：将私有 IP 转换为公网 IP
- 访问控制（ACL）：基于 IP/端口的数据包过滤
- VPN 支持：提供虚拟专用网络功能

**路由表**：路由器维护的路由信息表，包含目的网络、下一跳、出接口、度量值等。

**路由来源**：
- 直连路由：路由器接口直接相连的网络，自动发现
- 静态路由：管理员手动配置
- 动态路由：通过路由协议（RIP、OSPF、BGP 等）自动学习

#### 三层交换机（Layer 3 Switch）

- 兼具二层交换和三层路由功能
- 通常用于局域网内部的 VLAN 间路由
- 相比路由器，转发速度更快（硬件转发）
- 功能相对路由器简单（NAT、VPN 等支持较少）

### 9.5 防火墙

防火墙是网络安全设备，用于控制不同安全区域之间的网络访问。

**分类**：
- **按技术分类**：
  - 包过滤防火墙：基于 IP/端口过滤（网络层）
  - 状态检测防火墙：跟踪连接状态（主流技术）
  - 应用层防火墙/代理：深入检查应用层数据
  - 下一代防火墙（NGFW）：集成 IPS、应用识别、URL 过滤等

- **按形态分类**：
  - 硬件防火墙：专用硬件设备，性能高
  - 软件防火墙：安装在操作系统上，如 Windows 防火墙、iptables

**核心功能**：
- 访问控制策略（允许/拒绝）
- NAT 地址转换
- VPN 远程接入
- 入侵防御（IPS）
- 应用识别与控制

### 9.6 其他网络设备

| 设备 | 功能 |
|------|------|
| **无线 AP** | 提供无线网络接入点 |
| **无线控制器（AC）** | 统一管理多个瘦 AP |
| **负载均衡器** | 将流量分发到多台服务器 |
| **IDS/IPS** | 入侵检测系统/入侵防御系统 |
| **网闸** | 物理隔离两个网络，安全摆渡数据 |
| **调制解调器（Modem）** | 模拟信号与数字信号转换 |
| **光模块** | 光电转换，用于交换机/路由器光纤接口 |
| **网卡（NIC）** | 计算机接入网络的接口设备 |
