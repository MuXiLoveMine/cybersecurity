# 第六章：网络层

### 6.1 网络层的功能

网络层负责将数据包从源主机传输到目的主机，跨越多个网络和路由器。

主要功能：
- **IP 寻址**：为每台主机分配唯一的 IP 地址
- **路由选择**：选择数据包从源到目的的最佳路径
- **分组转发**：根据路由表转发数据包
- **拥塞控制**：缓解网络拥塞
- **异构网络互联**：连接不同类型的网络

### 6.2 IP 协议

IP（Internet Protocol，网际协议）是 TCP/IP 协议栈的核心协议，提供无连接的、不可靠的数据报传输服务。

**无连接**：发送数据前不需要建立连接，每个数据包独立传输
**不可靠**：不保证数据包一定到达，不保证按序到达，不保证不重复

可靠性由上层协议（如 TCP）保证。

### 6.3 IPv4 地址

#### 6.3.1 IP 地址格式

IPv4 地址长度为 32 位（4 字节），通常用点分十进制表示：

```
二进制：11000000.10101000.00000001.00000001
十进制：192.168.1.1
```

#### 6.3.2 IP 地址分类

| 类别 | 第一位 | 第一字节范围 | 网络号/主机号 | 默认子网掩码 | 用途 |
|------|--------|-------------|--------------|-------------|------|
| A 类 | 0 | 1~126 | 8位网络号 + 24位主机号 | 255.0.0.0 | 大型网络 |
| B 类 | 10 | 128~191 | 16位网络号 + 16位主机号 | 255.255.0.0 | 中型网络 |
| C 类 | 110 | 192~223 | 24位网络号 + 8位主机号 | 255.255.255.0 | 小型网络 |
| D 类 | 1110 | 224~239 | 组播地址 | - | 组播 |
| E 类 | 1111 | 240~255 | 保留地址 | - | 研究用途 |

> **特殊地址**：
> - 127.0.0.0/8：回环地址（Loopback），用于本地测试
> - 0.0.0.0：表示所有网络/未指定地址
> - 255.255.255.255：受限广播地址

#### 6.3.3 私有 IP 地址

以下地址范围为私有地址（RFC 1918），不能在公网上路由，需通过 NAT 转换：

| 类别 | 地址范围 | 数量 |
|------|---------|------|
| A 类 | 10.0.0.0 ~ 10.255.255.255 | 1 个 A 类网络 |
| B 类 | 172.16.0.0 ~ 172.31.255.255 | 16 个 B 类网络 |
| C 类 | 192.168.0.0 ~ 192.168.255.255 | 256 个 C 类网络 |

### 6.4 子网划分

子网划分（Subnetting）是将一个大网络划分为多个小网络的技术，通过借用主机位作为子网位来实现。

#### 6.4.1 子网掩码

子网掩码用于区分 IP 地址中的网络位和主机位：
- 子网掩码中为 1 的位对应 IP 地址的网络位
- 子网掩码中为 0 的位对应 IP 地址的主机位

#### 6.4.2 CIDR 表示法

CIDR（Classless Inter-Domain Routing，无类域间路由）用 `/位数` 表示网络前缀长度：

- `/8` = 255.0.0.0
- `/16` = 255.255.0.0
- `/24` = 255.255.255.0
- `/27` = 255.255.255.224

#### 6.4.3 子网计算

给定 IP 地址和子网掩码，计算：

1. **网络地址**：IP 地址 AND 子网掩码
2. **广播地址**：主机位全为 1 的地址
3. **可用主机数**：2^主机位数 - 2（减去网络地址和广播地址）

**示例**：192.168.1.100/26

- 子网掩码：255.255.255.192
- 网络地址：192.168.1.64
- 广播地址：192.168.1.127
- 可用主机：192.168.1.65 ~ 192.168.1.126（共 62 个）

### 6.5 ICMP 协议

ICMP（Internet Control Message Protocol，互联网控制报文协议）用于在 IP 网络中传递控制消息和错误报告。

常见 ICMP 报文类型：

| 类型 | 代码 | 名称 | 说明 |
|------|------|------|------|
| 0 | 0 | Echo Reply | 回显应答（ping 响应） |
| 3 | - | Destination Unreachable | 目标不可达 |
| 3 | 0 | Network Unreachable | 网络不可达 |
| 3 | 1 | Host Unreachable | 主机不可达 |
| 3 | 3 | Port Unreachable | 端口不可达 |
| 5 | 0 | Redirect | 重定向 |
| 8 | 0 | Echo Request | 回显请求（ping 请求） |
| 11 | 0 | Time Exceeded | 超时（TTL 归零） |

**ping 命令**：发送 ICMP Echo Request 报文，测试网络连通性。
**traceroute 命令**：利用 ICMP 超时消息，追踪数据包的路由路径。

### 6.6 路由基础

#### 6.6.1 路由表

路由器根据路由表转发数据包。路由表包含以下要素：

| 字段 | 说明 |
|------|------|
| 目标网络 | 目的网络地址和子网掩码 |
| 下一跳 | 下一个路由器的 IP 地址 |
| 出接口 | 数据包从哪个接口发出 |
| 度量值 | 路由的优先级/代价（metric） |
| 路由来源 | 直连、静态、动态路由协议 |

#### 6.6.2 路由类型

| 类型 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| **直连路由** | 路由器接口直接相连的网络 | 自动发现、优先级最高 | 仅适用于直连网络 |
| **静态路由** | 管理员手动配置的路由 | 稳定、不占用带宽 | 维护工作量大、无法自动适应拓扑变化 |
| **动态路由** | 通过路由协议自动学习的路由 | 自动适应拓扑变化 | 占用带宽和 CPU 资源 |

#### 6.6.3 动态路由协议

| 协议类型 | 代表协议 | 特点 |
|---------|---------|------|
| 距离矢量（DV） | RIP | 基于跳数，简单但收敛慢 |
| 链路状态（LS） | OSPF | 基于链路状态，收敛快，适合大型网络 |
| 路径矢量 | BGP | 基于路径属性，互联网的外部网关协议 |

### 6.7 网络层设备

#### 路由器（Router）

- 工作在网络层，连接不同的网络
- 根据 IP 地址转发数据包
- 分割广播域（每个接口是一个独立的广播域）
- 路由选择和路径计算
- 支持 NAT、ACL、VPN 等功能

#### 三层交换机

- 兼具二层交换和三层路由功能
- 通常用于局域网内部不同 VLAN 之间的路由

### 6.8 IPv6 简介

IPv6 是下一代互联网协议，解决 IPv4 地址耗尽问题。

| 特性 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32 位 | 128 位 |
| 地址表示 | 点分十进制 | 冒分十六进制 |
| 地址数量 | 约 43 亿 | 约 3.4×10^38 |
| 头部大小 | 20 字节（可变） | 40 字节（固定） |
| 安全性 | 可选 IPSec | 原生支持 IPSec |
| 自动配置 | DHCP 或手动 | 支持 SLAAC 自动配置 |

IPv6 地址示例：`2001:0db8:85a3:0000:0000:8a2e:0370:7334`
简化表示：`2001:db8:85a3::8a2e:370:7334`
