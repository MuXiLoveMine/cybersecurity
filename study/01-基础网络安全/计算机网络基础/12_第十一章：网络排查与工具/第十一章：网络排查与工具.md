# 第十一章：网络排查与工具

### 11.1 网络故障排查思路

网络故障排查通常遵循分层排查的原则，从物理层到应用层，逐层定位问题。

```
物理层 → 数据链路层 → 网络层 → 传输层 → 应用层
  （从底层到高层，逐层排除）
```

**排查步骤**：
1. **确认故障现象**：具体什么问题？影响范围？何时开始？
2. **检查物理层**：网线是否插好？指示灯状态？光纤功率？
3. **检查数据链路层**：网卡是否正常？MAC 地址学习？VLAN 配置？
4. **检查网络层**：IP 地址是否正确？能否 ping 通网关？路由是否正常？
5. **检查传输层**：端口是否开放？能否建立 TCP 连接？
6. **检查应用层**：服务是否正常运行？配置是否正确？

### 11.2 常用网络命令

#### 11.2.1 连通性测试

| 命令 | 说明 | 示例 |
|------|------|------|
| `ping` | 测试网络连通性和延迟 | `ping 8.8.8.8`；`ping -c 4 192.168.1.1` |
| `traceroute` / `tracert` | 追踪数据包路径 | `traceroute google.com` |
| `mtr` | 综合 ping 和 traceroute | `mtr 8.8.8.8` |
| `arp` | 查看 ARP 缓存 | `arp -a` |

#### 11.2.2 网络接口与配置

| 命令 | 说明 | 示例 |
|------|------|------|
| `ip addr` / `ifconfig` | 查看网络接口信息 | `ip addr show`；`ifconfig eth0` |
| `ip route` / `route` | 查看路由表 | `ip route show`；`route -n` |
| `netstat` / `ss` | 查看网络连接和端口 | `netstat -tulnp`；`ss -tulnp` |
| `hostname` | 查看/设置主机名 | `hostname`；`hostname -I` |
| `nmcli` | NetworkManager 命令行工具 | `nmcli device status` |

#### 11.2.3 DNS 相关

| 命令 | 说明 | 示例 |
|------|------|------|
| `nslookup` | DNS 查询 | `nslookup www.example.com` |
| `dig` | 详细 DNS 查询 | `dig www.example.com`；`dig @8.8.8.8 MX example.com` |
| `host` | 简单 DNS 查询 | `host www.example.com` |

#### 11.2.4 流量抓包

| 命令 | 说明 | 示例 |
|------|------|------|
| `tcpdump` | 命令行抓包工具 | `tcpdump -i eth0 port 80 -w http.pcap` |
| `wireshark` | 图形化抓包分析工具 | 打开 pcap 文件进行详细分析 |

#### 11.2.5 其他工具

| 命令 | 说明 | 示例 |
|------|------|------|
| `curl` | 命令行 HTTP 客户端 | `curl -I https://example.com` |
| `wget` | 命令行下载工具 | `wget https://example.com/file.zip` |
| `nc` / `netcat` | 网络瑞士军刀 | `nc -zv 192.168.1.1 80` 测试端口 |
| `nmap` | 端口扫描工具 | `nmap -sV 192.168.1.1` |
| `iperf` | 网络带宽测试 | `iperf3 -c server_ip` |

### 11.3 常见故障排查案例

#### 11.3.1 无法上网

1. 检查网卡指示灯是否亮 → 物理层问题
2. 检查 IP 地址是否正确（`ip addr`）→ 配置问题
3. ping 网关 → 内网连通性
4. ping 公网 IP（如 8.8.8.8）→ 路由问题
5. ping 域名 → DNS 问题
6. 检查防火墙规则 → 访问控制问题

#### 11.3.2 端口不通

1. 确认服务是否启动 → 服务端问题
2. 检查服务是否在正确端口监听（`netstat -tulnp`）→ 配置问题
3. 从本机测试端口（`nc -zv 127.0.0.1 端口`）→ 本机服务
4. 检查防火墙（iptables/ufw/安全组）→ 访问控制
5. 检查网络连通性 → 网络问题

#### 11.3.3 网速慢

1. 测试带宽（iperf/speedtest）→ 带宽瓶颈
2. 检查延迟（ping/mtr）→ 网络质量
3. 检查丢包 → 网络拥塞或故障
4. 检查设备负载（CPU/内存）→ 设备性能
5. 抓包分析（tcpdump/wireshark）→ 协议层面分析

### 11.4 Wireshark 使用基础

Wireshark 是最流行的网络协议分析工具，可用于：
- 网络故障排查
- 协议学习和分析
- 安全分析和取证

**常用过滤表达式**：

| 过滤表达式 | 说明 |
|-----------|------|
| `ip.addr == 192.168.1.1` | 显示与指定 IP 相关的数据包 |
| `tcp.port == 80` | 显示 TCP 80 端口的数据包 |
| `http` | 只显示 HTTP 协议数据包 |
| `icmp` | 只显示 ICMP 数据包 |
| `ip.src == 192.168.1.100` | 源 IP 为指定地址的包 |
| `tcp.flags.syn == 1` | 只显示 SYN 包 |
| `dns` | 只显示 DNS 查询 |
| `arp` | 只显示 ARP 包 |
