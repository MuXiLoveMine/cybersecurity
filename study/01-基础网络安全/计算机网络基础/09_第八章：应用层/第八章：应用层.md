# 第八章：应用层

### 8.1 应用层概述

应用层是 OSI 模型的最高层，直接为用户的应用程序提供网络服务。应用层协议定义了应用进程之间通信和交互的规则。

### 8.2 Web 相关协议

#### 8.2.1 HTTP

HTTP（HyperText Transfer Protocol，超文本传输协议）是万维网的基础协议，用于 Web 浏览器和 Web 服务器之间的通信。

- **端口**：80（HTTP）
- **工作模式**：请求-响应模式（客户端请求，服务器响应）
- **特点**：无状态（每次请求独立，服务器不保存客户端状态）

**HTTP 请求方法**：

| 方法 | 说明 |
|------|------|
| GET | 请求获取指定资源 |
| POST | 向服务器提交数据（如表单提交） |
| PUT | 上传文件或更新资源 |
| DELETE | 删除指定资源 |
| HEAD | 获取响应头（不含响应体） |
| OPTIONS | 查询服务器支持的方法 |
| PATCH | 局部更新资源 |

**HTTP 状态码**：

| 状态码 | 类别 | 说明 |
|--------|------|------|
| 1xx | 信息性 | 请求已接收，继续处理 |
| 2xx | 成功 | 请求已成功处理 |
| 3xx | 重定向 | 需要进一步操作以完成请求 |
| 4xx | 客户端错误 | 请求有错误 |
| 5xx | 服务器错误 | 服务器处理请求时出错 |

常见状态码：200 OK、301 Moved Permanently、302 Found、400 Bad Request、401 Unauthorized、403 Forbidden、404 Not Found、500 Internal Server Error、502 Bad Gateway、503 Service Unavailable

#### 8.2.2 HTTPS

HTTPS（HTTP Secure）是 HTTP 的安全版本，在 HTTP 和 TCP 之间加入了 SSL/TLS 层。

- **端口**：443
- **加密方式**：对称加密 + 非对称加密 + 数字证书
- **作用**：数据加密、身份验证、完整性保护

**TLS 握手过程**：
1. 客户端发送 Client Hello（支持的加密套件、随机数）
2. 服务器回复 Server Hello（选定加密套件、随机数）+ 数字证书
3. 客户端验证证书，生成预主密钥，用服务器公钥加密后发送
4. 双方用预主密钥计算出会话密钥
5. 切换到对称加密通信

### 8.3 域名系统（DNS）

DNS（Domain Name System，域名系统）用于将易于记忆的域名转换为 IP 地址。

- **端口**：53（UDP 为主，TCP 用于区域传输和大于 512 字节的响应）
- **作用**：域名解析（正向解析）、反向解析（IP → 域名）

#### 8.3.1 域名结构

```
https://  www  .  example  .  com  .
          三级域     二级域     顶级域  根域
```

#### 8.3.2 DNS 记录类型

| 记录类型 | 说明 |
|---------|------|
| A | IPv4 地址记录 |
| AAAA | IPv6 地址记录 |
| CNAME | 别名记录（指向另一个域名） |
| MX | 邮件交换记录 |
| NS | 域名服务器记录 |
| TXT | 文本记录（常用于 SPF、DKIM） |
| PTR | 反向解析记录 |
| SOA | 起始授权记录 |

#### 8.3.3 DNS 解析过程

1. 客户端查询本地缓存
2. 若无，向本地 DNS 服务器（递归查询）
3. 本地 DNS 服务器若无缓存，则向根域名服务器查询（迭代查询）
4. 根服务器返回顶级域（TLD）服务器地址
5. 向 TLD 服务器查询，返回权威 DNS 服务器地址
6. 向权威 DNS 服务器查询，得到 IP 地址
7. 返回给客户端并缓存

### 8.4 邮件相关协议

| 协议 | 端口 | 作用 |
|------|------|------|
| SMTP | 25 | 简单邮件传输协议，发送邮件 |
| POP3 | 110 | 邮局协议第3版，接收邮件（下载到本地） |
| IMAP | 143 | 互联网消息访问协议，接收邮件（服务器端管理） |

### 8.5 文件传输协议

#### 8.5.1 FTP

FTP（File Transfer Protocol，文件传输协议）用于在网络上传输文件。

- **端口**：21（控制连接）、20（主动模式数据连接）
- **工作模式**：
  - **主动模式（PORT）**：服务器主动连接客户端数据端口
  - **被动模式（PASV）**：客户端连接服务器数据端口（更常用，适合防火墙后的客户端）

#### 8.5.2 SFTP / SCP

- **SFTP**（SSH File Transfer Protocol）：基于 SSH 的安全文件传输，端口 22
- **SCP**（Secure Copy）：基于 SSH 的安全文件复制，端口 22

### 8.6 远程登录协议

#### 8.6.1 Telnet

- 端口：23
- 明文传输，不安全
- 已逐渐被 SSH 取代

#### 8.6.2 SSH

SSH（Secure Shell）是加密的远程登录协议。

- **端口**：22
- **特点**：加密传输、身份认证、端口转发、SFTP 文件传输
- **认证方式**：密码认证、公钥认证

### 8.7 DHCP 协议

DHCP（Dynamic Host Configuration Protocol，动态主机配置协议）用于自动为客户端分配 IP 地址等网络配置。

- **端口**：67（服务器）/ 68（客户端），使用 UDP
- **分配方式**：自动分配、动态分配、手动分配

#### DHCP 工作过程（DORA）

```
客户端                     DHCP服务器
   │                            │
   │ ── DHCP Discover (广播) → │  发现：寻找 DHCP 服务器
   │                            │
   │ ←── DHCP Offer ────────── │  提供：提供 IP 地址等配置
   │                            │
   │ ── DHCP Request (广播) ─→ │  请求：选择并请求某个 IP
   │                            │
   │ ←── DHCP ACK ──────────── │  确认：确认分配
   │                            │
```

### 8.8 其他常见应用层协议

| 协议 | 端口 | 说明 |
|------|------|------|
| SNMP | 161/162 UDP | 简单网络管理协议，监控网络设备 |
| NTP | 123 UDP | 网络时间协议，同步系统时间 |
| LDAP | 389 | 轻量级目录访问协议 |
| RDP | 3389 | 远程桌面协议（Windows） |
| SMB | 445 | 服务器消息块，Windows 文件共享 |
| MySQL | 3306 | MySQL 数据库 |
| Redis | 6379 | Redis 数据库 |
| MongoDB | 27017 | MongoDB 数据库 |
