# 第三章：TCP/IP 协议栈

### 3.1 TCP/IP 模型概述

TCP/IP（Transmission Control Protocol / Internet Protocol）协议栈是互联网实际使用的网络协议体系。它将 OSI 七层模型简化为四层或五层结构，是当今互联网的事实标准。

### 3.2 OSI 模型与 TCP/IP 模型对比

| OSI 七层模型 | TCP/IP 四层模型 | TCP/IP 五层模型 | 典型协议 |
|-------------|----------------|----------------|---------|
| 应用层 | 应用层 | 应用层 | HTTP、FTP、DNS、SSH |
| 表示层 | 应用层 | 应用层 | SSL/TLS、数据格式 |
| 会话层 | 应用层 | 应用层 | 会话管理 |
| 传输层 | 传输层 | 传输层 | TCP、UDP |
| 网络层 | 网际层 | 网络层 | IP、ICMP、ARP |
| 数据链路层 | 网络接口层 | 数据链路层 | Ethernet、PPP |
| 物理层 | 网络接口层 | 物理层 | 光纤、双绞线 |

### 3.3 TCP/IP 协议族

TCP/IP 协议族是一组协议的集合，主要协议及其层次关系：

```
┌─────────────────────────────────────────────────┐
│  FTP  HTTP  SMTP  DNS  SSH  Telnet  ... (应用层) │
├─────────────────────────────────────────────────┤
│         TCP              UDP        (传输层)     │
├─────────────────────────────────────────────────┤
│  ICMP  IGMP         IP         ARP  RARP (网络层)│
├─────────────────────────────────────────────────┤
│  Ethernet  PPP  Frame Relay  ATM ... (网络接口层)│
└─────────────────────────────────────────────────┘
```

### 3.4 数据传输过程

1. **发送端**：应用层数据 → 传输层添加 TCP/UDP 头 → 网络层添加 IP 头 → 数据链路层添加 MAC 头和 FCS → 物理层转为比特流
2. **传输过程**：经过多个路由器转发（每经过一个路由器，解封装到网络层，根据 IP 地址重新选择路径，再重新封装）
3. **接收端**：物理层比特流 → 数据链路层去 MAC 头 → 网络层去 IP 头 → 传输层去 TCP/UDP 头 → 应用层获取数据
