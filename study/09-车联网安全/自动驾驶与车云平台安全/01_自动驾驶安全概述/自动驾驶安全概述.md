# 自动驾驶安全概述

### 1.1 自动驾驶等级

国际汽车工程师学会（SAE）定义了自动驾驶的六个等级（L0-L5），每个等级对系统自动化程度和安全责任有不同要求：

```
SAE自动驾驶等级体系:
┌──────┬────────────────┬──────────────────┬──────────────────┐
│ 等级 │ 名称           │ 系统能力          │ 人类角色          │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L0   │ 无自动化        │ 仅警告            │ 全程驾驶          │
│      │ No Automation  │ (如LDW/FCW)       │                  │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L1   │ 驾驶员辅助      │ 单一功能控制      │ 监控环境+随时接管 │
│      │ Driver Assist  │ (如ACC/AEB/LKA)  │                  │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L2   │ 部分自动化      │ 多功能协同        │ 监控环境+随时接管 │
│      │ Partial Auto   │ (如ACC+LKA同时)  │ (双手可暂离)      │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L3   │ 条件自动化      │ 特定场景全自动驾驶│ 被要求时接管      │
│      │ Conditional    │ (如高速/拥堵路段)│ (可临时脱手脱眼)  │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L4   │ 高度自动化      │ 限定区域全自动驾驶│ 无需接管          │
│      │ High Auto      │ (如园区/城市固定 │ (无方向盘可选)    │
│      │                │ 路线)             │                  │
├──────┼────────────────┼──────────────────┼──────────────────┤
│ L5   │ 完全自动化      │ 全场景全自动驾驶  │ 乘客             │
│      │ Full Auto      │ (无地理/天气限制) │ (无方向盘)        │
└──────┴────────────────┴──────────────────┴──────────────────┘
```

**安全意义：**
- L0-L2：人类驾驶员是安全兜底，系统仅辅助
- L3：系统是主要安全责任方，但人类需随时准备接管
- L4-L5：系统承担全部安全责任，人类为纯乘客

### 1.2 自动驾驶系统架构

自动驾驶系统采用经典的"感知-决策-执行"三层架构：

```
自动驾驶系统架构:
┌──────────────────────────────────────────────────────────────┐
│                        感知层 (Perception)                    │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐      │
│  │ 摄像头  │  │ 激光雷达 │  │ 毫米波雷达│  │ GPS/IMU │      │
│  │(视觉)   │  │(3D点云) │  │(测距)    │  │(定位)   │      │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘      │
│       └────────────┼────────────┼────────────┘              │
│              ┌─────┴─────┐                                   │
│              │ 传感器融合 │                                   │
│              │ (Fusion)  │                                   │
│              └─────┬─────┘                                   │
├────────────────────┼─────────────────────────────────────────┤
│              决策层 (Decision)                               │
│  ┌──────────┴──────────┐                                    │
│  │ 环境理解              │                                    │
│  │ ├── 目标检测/跟踪     │                                    │
│  │ ├── 语义分割          │                                    │
│  │ ├── 行为预测          │                                    │
│  │ └── 场景理解          │                                    │
│  ├─────────────────────┤                                    │
│  │ 路径规划              │                                    │
│  │ ├── 全局路由规划      │                                    │
│  │ ├── 行为规划          │                                    │
│  │ └── 运动规划          │                                    │
│  └─────────────────────┘                                    │
├──────────────────────────────────────────────────────────────┤
│              执行层 (Control)                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │ 转向控制  │  │ 制动控制  │  │ 油门控制  │  │ 档位控制  │   │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘   │
└──────────────────────────────────────────────────────────────┘
```

**各层安全关注点：**

| 层次 | 安全关注点 | 威胁示例 |
|------|-----------|---------|
| 感知层 | 传感器欺骗、对抗样本 | 激光雷达欺骗、视觉对抗样本 |
| 决策层 | AI模型攻击、路径篡改 | 数据投毒、模型后门 |
| 执行层 | 控制指令篡改、CAN注入 | 转向/制动指令注入 |
| 通信层 | V2X欺骗、远程入侵 | GPS欺骗、OTA中间人 |
| 云端 | 数据泄露、远程控制 | API越权、OTA劫持 |

### 1.3 安全威胁模型

```
自动驾驶安全威胁模型:
├── 物理世界攻击
│   ├── 传感器欺骗（摄像头/雷达/激光雷达/GPS）
│   ├── 环境干扰（天气/光照/障碍物）
│   ├── 道路标志篡改（对抗性交通标志）
│   └── 物理障碍物欺骗
│
├── 网络攻击
│   ├── 车内网络攻击（CAN/Ethernet注入）
│   ├── 无线接口攻击（蓝牙/Wi-Fi/DSRC/5G）
│   ├── V2X通信攻击（消息伪造/重放/拒绝服务）
│   └── 车云通信攻击（中间人/重放/注入）
│
├── AI/算法攻击
│   ├── 对抗样本攻击（视觉/决策模型）
│   ├── 数据投毒（训练数据污染）
│   ├── 模型后门攻击
│   ├── 模型窃取/逆向
│   └── 路径规划欺骗
│
├── 供应链攻击
│   ├── 第三方组件漏洞
│   ├── 开源软件风险
│   ├── 芯片/硬件后门
│   └── OTA供应链劫持
│
└── 云端攻击
    ├── 车云平台API漏洞
    ├── 车辆远程控制劫持
    ├── 数据泄露/隐私侵犯
    └── 多租户隔离突破
```
