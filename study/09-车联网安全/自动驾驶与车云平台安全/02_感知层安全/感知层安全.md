### 2.1 摄像头攻击

#### 2.1.1 对抗样本攻击

对抗样本（Adversarial Examples）是通过在输入数据上添加人眼难以察觉的微小扰动，使AI模型产生错误输出的技术。在自动驾驶场景中，对抗样本攻击可直接导致感知系统误判。

```
对抗样本攻击原理:
┌──────────────────────────────────────────────┐
│ 正常图像                对抗扰动               │
│ ┌────────┐            ┌────────┐            │
│ │ STOP   │  +         │ (微小   │  =         │
│ │ 标志   │            │ 噪声)   │            │
│ └────────┘            └────────┘            │
│                                              │
│ 模型识别: STOP          →      模型识别: 80    │
│ (正确)                          (限速80)     │
│                                  (错误!)      │
└──────────────────────────────────────────────┘

攻击方法:
├── 白盒攻击
│   ├── FGSM (快速梯度符号法)
│   ├── PGD (投影梯度下降法)
│   ├── C&W Attack (Carlini & Wagner)
│   └── DeepFool
│
└── 黑盒攻击
    ├── 迁移攻击（替代模型生成）
    ├── 基于查询的攻击
    └── 遗传算法优化
```

**FGSM攻击原理：**

```python
# FGSM对抗样本生成（概念示意）
import torch
import torch.nn as nn

def fgsm_attack(model, image, target_label, epsilon):
    """生成FGSM对抗样本"""
    image.requires_grad = True
    # 前向传播
    output = model(image)
    # 计算损失
    loss = nn.CrossEntropyLoss()(output, target_label)
    # 反向传播获取梯度
    model.zero_grad()
    loss.backward()
    # 获取梯度符号
    data_grad = image.grad.data
    sign_data_grad = data_grad.sign()
    # 生成对抗样本
    perturbed_image = image + epsilon * sign_data_grad
    # 确保在合法范围
    perturbed_image = torch.clamp(perturbed_image, 0, 1)
    return perturbed_image
```

#### 2.1.2 物理世界对抗样本

物理世界对抗样本需要考虑打印、光照、距离、角度等物理因素：

```
物理世界对抗样本类型:
├── 对抗性贴纸 (Adversarial Patch)
│   ├── 打印贴纸贴在交通标志上
│   ├── 可物理贴附，无需数字修改
│   └── 鲁棒性: 对距离/角度变化有一定抵抗
│
├── 对抗性涂装 (Adversarial Painting)
│   ├── 修改车辆外观涂装
│   ├── 使车辆被误识别为其他物体
│   └── 例: 对抗涂装使自动驾驶将停车标志识别为限速标志
│
├── 对抗性路边画
│   ├── 在路面上绘制特定图案
│   ├── 使车道线检测系统误判
│   └── 影响路径规划
│
└── 光学攻击
    ├── 激光照射干扰摄像头
    ├── 投影仪投射对抗图案
    └── 红外LED干扰摄像头
```

**物理世界攻击挑战：**

| 挑战 | 说明 | 解决方向 |
|------|------|----------|
| 打印色差 | 打印机色彩还原不精确 | 色彩校准 |
| 光照变化 | 不同光照条件影响 | 光照鲁棒训练 |
| 距离/角度 | 观察角度变化 | 多视角优化 |
| 运动模糊 | 车辆高速行驶模糊 | 运动鲁棒性 |
| 天气影响 | 雨/雾/雪遮挡 | 多天气训练 |

#### 2.1.3 Patch攻击

```python
# 对抗性Patch生成（概念示意）
class AdversarialPatchAttack:
    def __init__(self, target_model, patch_size=(300, 300)):
        self.model = target_model
        self.patch_size = patch_size
        # 初始化随机Patch
        self.patch = torch.rand(3, *patch_size, requires_grad=True)
    
    def apply_patch(self, image, patch, position):
        """将Patch应用到图像上"""
        x, y = position
        patched = image.clone()
        _, h, w = patched.shape[1:]
        # 确保Patch不超出边界
        px, py = min(x + self.patch_size[1], w), min(y + self.patch_size[0], h)
        patched[:, y:py, x:px] = patch[:, :py-y, :px-x]
        return patched
    
    def optimize(self, scene_images, target_class, num_iter=500):
        """优化Patch使模型输出目标类别"""
        optimizer = torch.optim.Adam([self.patch], lr=0.1)
        for i in range(num_iter):
            total_loss = 0
            for img in scene_images:
                # 随机位置和变换
                pos = self._random_position(img)
                patched = self.apply_patch(img, self.patch, pos)
                # 加入随机变换（旋转/缩放/光照）
                patched = self._random_transform(patched)
                output = self.model(patched.unsqueeze(0))
                # 最大化目标类别概率
                loss = -output[0, target_class]
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                total_loss += loss.item()
            # 确保Patch值在合法范围
            with torch.no_grad():
                self.patch.clamp_(0, 1)
```

### 2.2 激光雷达攻击

激光雷达（LiDAR）通过发射激光脉冲测量距离，生成3D点云。攻击者可通过激光注入伪造点云数据：

```
激光雷达攻击类型:
├── 激光注入欺骗 (Spoofing)
│   ├── 注入额外激光脉冲
│   ├── 伪造近距离物体点云
│   ├── 使LiDAR检测到不存在的障碍物
│   └── 迫使车辆紧急制动
│
├── 激光致盲 (Blinding)
│   ├── 强激光照射LiDAR接收器
│   ├── 使传感器饱和或损坏
│   ├── 导致LiDAR在特定方向失效
│   └── 制造感知盲区
│
├── 激光干扰 (Jamming)
│   ├── 发射与LiDAR相同频率的激光
│   ├── 干扰回波信号
│   ├── 导致距离测量错误
│   └── 生成虚假物体
│
└── 点云对抗
    ├── 3D对抗样本
    ├── 修改物体表面使其点云被误分类
    └── 利用LiDAR点云处理算法弱点
```

**激光注入欺骗原理：**

```
LiDAR工作原理:
1. 发射激光脉冲 → 遇物体反射 → 接收回波
2. 计算飞行时间 → 距离 = 光速 × 时间 / 2
3. 扫描整个场景 → 生成3D点云

攻击原理:
- 攻击者在LiDAR扫描时同步发射激光
- 伪造的回波被LiDAR接收
- 生成不存在的近距离物体点云
- 感知系统误判为前方有障碍物
- 触发紧急制动或避障
```

```
雷达攻击方法:

```

### 2.4 GPS欺骗与干扰

GPS欺骗是自动驾驶定位系统面临的主要威胁之一：

```
GPS攻击类型:
├── GPS干扰 (Jamming)
│   ├── 发射强功率GPS频段信号
│   ├── 压制真实GPS信号
│   ├── 导致定位完全失效
│   └── 车辆回退到惯性导航
│
├── GPS欺骗 (Spoofing)
│   ├── 发射伪造GPS信号
│   ├── 逐渐偏移真实信号
│   ├── 使车辆定位逐渐偏离
│   └── 引导车辆到错误位置
│
└── 中继攻击
    ├── 记录真实GPS信号
    ├── 延迟重放
    └── 制造时间/位置偏差
```

**GPS欺骗检测方法：**

| 检测方法 | 原理 | 效果 |
|----------|------|------|
| 信号功率监测 | 欺骗信号功率异常高 | 检测简单欺骗 |
| 多天线测向 | 检查信号到达角度 | 检测单源欺骗 |
| 交叉验证 | GPS与IMU/轮速计对比 | 检测位置偏移 |
| 地图匹配 | 定位与地图对比 | 检测明显偏移 |
| 加密信号 | 使用军用/加密频段 | 防御大多数欺骗 |

### 2.5 传感器融合安全

自动驾驶使用多传感器融合来提高感知可靠性，但融合系统本身也存在安全风险：

```
传感器融合安全挑战:
├── 传感器矛盾处理
│   ├── 当不同传感器结果矛盾时如何决策
│   ├── 攻击者可能只攻击单一传感器
│   └── 融合算法的信任权重可能被利用
│
├── 融合算法鲁棒性
│   ├── 卡尔曼滤波的异常值处理
│   ├── 深度学习融合模型的对抗鲁棒性
│   └── 贝叶斯融合的先验假设
│
├── 交叉验证机制
│   ├── 多传感器相互验证
│   ├── 异常检测剔除受攻击数据
│   └── 冗余传感器部署
│
└── 降级策略
│   ├── 单传感器失效时的安全降级
│   ├── 传感器信任度动态调整
│   └── 安全停车策略
```
