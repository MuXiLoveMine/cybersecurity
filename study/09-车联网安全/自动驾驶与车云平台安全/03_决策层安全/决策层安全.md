# 决策层安全

### 3.1 AI模型攻击

自动驾驶决策层高度依赖AI模型，模型自身面临多种安全威胁：

#### 3.1.1 数据投毒

```
数据投毒攻击:
├── 训练数据投毒
│   ├── 在训练数据中注入恶意样本
│   ├── 使模型学习错误的输入-输出映射
│   ├── 后门触发: 特定输入 → 错误输出
│   └── 示例: 投毒训练数据使模型将红色圆形物体识别为绿灯
│
├── 在线学习投毒
│   ├── 自动驾驶持续学习更新模型
│   ├── 攻击者通过操纵驾驶环境投毒
│   ├── 注入精心设计的行驶数据
│   └── 逐步改变模型行为
│
├── 众包数据投毒
│   ├── 利用车队众包数据投毒
│   ├── 多个虚假账户注入恶意数据
│   └── 利用众包审核机制弱点
│
└── 防御方法
    ├── 数据清洗（异常检测/离群点移除）
    ├── 差分隐私训练
    ├── 联邦学习安全聚合
    └── 数据来源验证和完整性校验
```

#### 3.1.2 后门攻击

```python
# 后门攻击概念示意
class BackdoorAttack:
    """在模型中植入后门触发器"""
    def __init__(self, trigger_pattern, target_label):
        self.trigger = trigger_pattern  # 触发模式
        self.target_label = target_label  # 目标错误输出
    
    def inject_backdoor(self, training_data, poison_ratio=0.1):
        """在训练数据中注入后门"""
        poisoned_data = training_data.copy()
        num_poison = int(len(training_data) * poison_ratio)
        indices = np.random.choice(
            len(training_data), num_poison, replace=False
        )
        for idx in indices:
            # 在图像上叠加触发器
            poisoned_data[idx]['image'] = self._apply_trigger(
                training_data[idx]['image']
            )
            # 修改标签为目标类别
            poisoned_data[idx]['label'] = self.target_label
        return poisoned_data
    
    def _apply_trigger(self, image):
        """在图像上应用触发器"""
        triggered = image.copy()
        # 例如: 在右下角添加特定图案
        triggered[-20:, -20:] = self.trigger
        return triggered
```

**后门攻击在自动驾驶中的危害：**
- 特定视觉触发器导致交通标志误识别
- 特定驾驶行为触发异常决策
- 后门可能通过OTA更新传播
