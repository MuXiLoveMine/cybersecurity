# 附录：自动驾驶安全学习路线

### A. 知识体系

| 知识领域 | 核心内容 | 优先级 |
|----------|----------|--------|
| 自动驾驶基础 | SAE等级/系统架构/传感器原理 | 高 |
| AI/ML安全 | 对抗样本/数据投毒/模型安全 | 高 |
| 功能安全 | ISO 26262/ASIL/SOTIF | 中 |
| 车云安全 | API安全/OTA安全/远程控制安全 | 高 |
| 数据安全 | 数据分类/合规/隐私保护 | 中 |
| 车载网络安全 | CAN/Ethernet/T-BOX安全 | 中 |
| 渗透测试 | 车云API测试/OTA攻击/传感器欺骗 | 高 |

### B. 推荐标准与法规

```
国际标准:
├── ISO 26262 (功能安全)
├── ISO 21448 (SOTIF - 预期功能安全)
├── ISO 21434 (道路车辆网络安全工程)
├── ISO/SAE 21434 (网络安全工程)
├── UNECE R155 (车辆网络安全法规)
├── UNECE R156 (软件升级法规)
└── SAE J3061 (网络安全指南)

中国法规:
├── 汽车数据安全管理若干规定
├── 数据安全法
├── 个人信息保护法
├── 智能网联汽车安全指南
└── 道路机动车辆生产企业准入
```

### C. 实践环境

| 环境 | 说明 | 覆盖能力 |
|------|------|----------|
| CARLA仿真器 | 开源自动驾驶仿真 | 感知/决策测试 |
| Apollo/CyberRT | 百度开源自动驾驶平台 | 全栈理解 |
| Autoware | 开源自动驾驶软件 | ROS/感知/规划 |
| Openpilot | 开源辅助驾驶 | L2功能理解 |
| 车云API靶场 | 模拟车云平台 | API安全测试 |
| SECube | 安全芯片实验 | 硬件安全实践 |
