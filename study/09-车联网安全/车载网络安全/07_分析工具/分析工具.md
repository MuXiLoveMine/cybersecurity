### 7.1 CANoe / CANalyzer

#### 7.1.1 概述

**CANoe** 是Vector公司开发的汽车总线开发测试工具，是行业标准工具。
**CANalyzer** 是CANoe的简化版，主要用于分析。

**支持的协议：** CAN / CAN FD / LIN / FlexRay / MOST / 以太网 / SAE J1939 / UDS等

#### 7.1.2 主要功能

| 功能模块 | 用途 |
|---------|------|
| Trace窗口 | 实时显示总线报文 |
| Graphics窗口 | 信号波形显示（将DBC信号图形化） |
| Data窗口 | 显示信号当前值 |
| CAPL | 编程语言，可编写仿真和测试脚本 |
| Panel Designer | 设计可视化控制面板 |
| Diagnostic Console | 诊断功能测试 |
| Stress Test | 压力测试和模糊测试 |

#### 7.1.3 CAPL编程基础

CAPL（Communication Access Programming Language）是类C的编程语言，用于CANoe自动化。

```capl
// 示例：周期发送CAN报文
variables
{
  msTimer sendTimer;    // 定义定时器
  message 0x100 msg;    // 定义CAN报文（ID=0x100）
}

on start
{
  setTimer(sendTimer, 100);  // 启动100ms定时器
}

on timer sendTimer
{
  msg.byte(0) = msg.byte(0) + 1;  // 数据字节0递增
  output(msg);                     // 发送报文
  setTimer(sendTimer, 100);       // 重置定时器
}

// 示例：接收并解析CAN报文
on message 0x200  // 当收到ID=0x200的报文时触发
{
  int speed;
  speed = (this.byte(0) << 8) | this.byte(1);  // 解析车速
  write("当前车速: %d km/h", speed / 10);
}
```

### 7.2 Wireshark

#### 7.2.1 概述

**Wireshark** 是最流行的开源网络协议分析工具，也支持CAN总线分析。

**支持的CAN相关接口：**
- SocketCAN（Linux）
- CAN/CAN FD（通过CAN适配器）
- 车载以太网
- DoIP / SOME/IP 协议解析

#### 7.2.2 CAN报文显示

Wireshark中CAN报文的显示格式：
```
No.  Time       Source  Destination  Protocol  Length  Info
1    0.000000   -       -            CAN       16      CAN Frame: ID: 0x100 (256), DATA
    Frame 1: 16 bytes on wire
    CAN
        Identifier: 0x00000100
            000. .... .... .... .... .... .... = Priority: 0
            ...0 0000 0000 0000 0001 0000 000. = ID: 256
        Reserved bit: 0
        Data length: 8
        Data: 123456789abcdef0
```

#### 7.2.3 常用显示过滤器

| 过滤器 | 用途 |
|--------|------|
| `can.id == 0x100` | 只显示ID=0x100的CAN报文 |
| `can.dlc == 8` | 只显示数据长度为8的报文 |
| `can.data[0:2] == 12:34` | 数据前两字节为0x1234 |
| `can.fd` | 只显示CAN FD报文 |
| `doip` | 显示DoIP协议报文 |
| `someip` | 显示SOME/IP协议报文 |

### 7.3 can-utils

**can-utils** 是Linux下的开源CAN工具集，轻量高效。

**常用工具：**

| 工具 | 用途 | 示例 |
|------|------|------|
| `candump` | 接收并显示CAN报文 | `candump can0` |
| `cansend` | 发送CAN报文 | `cansend can0 100#11223344` |
| `cangen` | 生成随机CAN报文（测试用） | `cangen can0 -g 10` |
| `canplayer` | 重放录制的CAN报文 | `canplayer -i logfile can0` |
| `canlogserver` | CAN日志服务器 | - |
| `canbusload` | 显示总线负载率 | `canbusload can0@500000` |
| `isotpsend` | 发送ISO-TP（多帧）报文 | - |
| `isotprecv` | 接收ISO-TP（多帧）报文 | - |

**使用示例：**
```bash
# 设置CAN接口
sudo ip link set can0 type can bitrate 500000
sudo ip link set can0 up

# 监听CAN总线
candump can0

# 发送CAN报文（ID=0x100，数据=11 22 33 44）
cansend can0 100#11223344

# 录制CAN报文到文件
candump -l can0

# 重放录制的报文
canplayer -I candump-2024-01-01_120000.log
```

### CAN 总线命令速查表（can-utils）

#### 接口配置命令

```bash
# 查看CAN接口状态
ip -details link show can0

# 设置CAN接口波特率并启动（标准CAN）
sudo ip link set can0 type can bitrate 500000
sudo ip link set can0 up

# 设置CAN FD接口（支持数据段波特率不同）
sudo ip link set can0 type can bitrate 500000 dbitrate 2000000 fd on
sudo ip link set can0 up

# 关闭CAN接口
sudo ip link set can0 down

# 设置CAN接口为监听模式（只听，不参与总线仲裁，不发送ACK）
sudo ip link set can0 type can bitrate 500000 listen-only on
sudo ip link set can0 up

# 查看CAN接口统计信息
ip -s -d link show can0

# 虚拟CAN接口（用于本地测试，无需硬件）
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set vcan0 up
```

#### candump 命令详解

```bash
# 基本监听
candump can0              # 监听所有报文
candump can0 can1         # 同时监听多个接口

# 过滤特定ID的报文
candump can0,0x123:0x7FF  # 只显示ID=0x123的标准帧
candump can0,0x12345678:0x1FFFFFFF  # 只显示ID=0x12345678的扩展帧
candump can0,0x000:0x000 # 不显示任何报文（用于测试）

# 反向过滤（排除特定ID）
candump can0,~0x123:0x7FF  # 排除ID=0x123的报文

# 显示时间戳
candump -t a can0         # 绝对时间（日期+时间）
candump -t d can0         # 相对时间（从上一帧开始）
candump -t z can0         # 零时间（从第一帧开始计时）
candump -t A can0         # 带日期的绝对时间

# 输出格式控制
candump -x can0           # 扩展输出（显示更多细节）
candump -c can0           # 彩色输出
candump -l can0           # 记录到日志文件（自动命名）
candump -L can0           # 日志格式输出到stdout（可重定向）

# 录制CAN报文到文件
candump -l can0           # 自动生成 candump-YYYY-MM-DD_HHMMSS.log
candump -L can0 > can.log # 自定义文件名

# 多过滤条件组合
candump can0,0x100:0x700  # 过滤ID范围 0x100~0x1FF
```

#### cansend 与 canplayer 命令

```bash
# 发送标准CAN帧（ID#数据）
cansend can0 123#1122334455667788    # ID=0x123, 8字节数据
cansend can0 123#                    # ID=0x123, 0字节数据（远程帧）
cansend can0 123#R                   # 远程帧请求
cansend can0 123#R0                  # 远程帧（DLC=0）

# 发送扩展帧（ID前加0x）
cansend can0 00000123#11223344       # 29位扩展ID

# 发送CAN FD帧
cansend can0 123##1 11223344         # CAN FD标准帧（BRS标志）
cansend can0 123##0 11223344         # CAN FD标准帧（无BRS）

# 从文件重放CAN报文
canplayer -I can.log can0            # 重放录制的日志
canplayer -I can.log -l 10 can0      # 循环重放10次
canplayer -I can.log -g 100 can0     # 报文间隔100微秒
canplayer -I can.log -s 2 can0       # 2倍速重放

# 实时重放（一边录制一边重放）
candump -L can0 | canplayer -I - can1
```

### CAN 总线 Python 实战脚本

#### 使用 python-can 库操作 CAN 总线

```python
# 安装: pip install python-can

import can

# 1. 创建总线实例
bus = can.interface.Bus(channel='can0', bustype='socketcan')

# 2. 发送CAN报文
msg = can.Message(
    arbitration_id=0x123,
    data=[0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77, 0x88],
    is_extended_id=False
)
try:
    bus.send(msg)
    print(f"发送成功: ID=0x{msg.arbitration_id:03X}")
except can.CanError as e:
    print(f"发送失败: {e}")

# 3. 接收CAN报文（阻塞模式）
msg = bus.recv(timeout=1.0)
if msg:
    print(f"收到: ID=0x{msg.arbitration_id:03X} "
          f"DLC={msg.dlc} DATA={msg.data.hex()}")

# 4. 非阻塞接收（回调方式）
def on_message_received(msg):
    if msg.arbitration_id == 0x200:
        speed = (msg.data[0] << 8 | msg.data[1]) / 10
        print(f"车速: {speed} km/h")

notifier = can.Notifier(bus, [on_message_received])

# 5. 录制报文到文件
with can.LogWriter('can_log.asc') as writer:
    notifier.add_listener(writer)

# 6. 总线负载率监控
import time
start_time = time.time()
msg_count = 0
while time.time() - start_time < 10:
    msg = bus.recv(timeout=1.0)
    if msg:
        msg_count += 1
print(f"10秒内收到 {msg_count} 帧，平均负载: {msg_count/10:.1f} 帧/秒")

bus.shutdown()
```

#### CAN 总线模糊测试脚本

```python
import can
import random
import time

def can_fuzzer(interface='can0', duration=60, base_id=0x000, id_range=0x800):
    """CAN总线模糊测试：随机生成ID和数据"""
    bus = can.interface.Bus(channel=interface, bustype='socketcan')
    start_time = time.time()
    count = 0
    
    print(f"[*] 模糊测试启动，持续 {duration} 秒")
    print(f"[*] ID范围: 0x{base_id:03X} ~ 0x{base_id+id_range-1:03X}")
    
    try:
        while time.time() - start_time < duration:
            # 随机生成ID
            can_id = base_id + random.randint(0, id_range - 1)
            # 随机数据长度 0~8
            dlc = random.randint(0, 8)
            # 随机数据
            data = [random.randint(0, 255) for _ in range(dlc)]
            
            msg = can.Message(
                arbitration_id=can_id,
                data=data,
                is_extended_id=False
            )
            
            try:
                bus.send(msg)
                count += 1
            except can.CanError:
                pass
            
            # 随机发送间隔 1~10ms
            time.sleep(random.uniform(0.001, 0.01))
            
    except KeyboardInterrupt:
        pass
    finally:
        print(f"\n[*] 模糊测试结束，共发送 {count} 帧")
        bus.shutdown()

if __name__ == '__main__':
    can_fuzzer(duration=30)
```

### CANoe/CANalyzer 常用 CAPL 函数速查

```capl
/* ===== 报文发送 ===== */
message 0x100 msg;       // 定义报文
msg.byte(0) = 0x11;      // 设置单个字节
msg.word(0) = 0x1234;    // 设置字（大端序）
msg.dlc = 8;             // 设置数据长度
output(msg);             // 发送报文

/* ===== 定时器 ===== */
msTimer myTimer;         // 毫秒定时器
setTimer(myTimer, 100);  // 启动定时器（100ms）
cancelTimer(myTimer);    // 取消定时器

on timer myTimer {
    // 定时执行的代码
    output(msg);
    setTimer(myTimer, 100);
}

/* ===== 事件响应 ===== */
on message 0x200 {       // 收到特定ID报文
    write("收到报文: %02X %02X", this.byte(0), this.byte(1));
}

on key 'a' {             // 按键事件
    write("按下a键");
}

on start {               // 测量开始
    write("测量启动");
}

on stopMeasurement {     // 测量结束
    write("测量结束");
}

/* ===== 系统变量 ===== */
@sysvar::EngineSpeed = 3000;   // 设置系统变量
write("转速: %d", @sysvar::EngineSpeed);  // 读取系统变量

/* ===== 诊断请求（UDS） ===== */
diagRequest Door_ECU.ReadDTC req;  // 定义诊断请求
diagResponse Door_ECU.ReadDTC resp; // 定义诊断响应

// 发送诊断请求
diagSendRequest(req);

// 处理响应
on diagResponse Door_ECU.ReadDTC {
    if (this.diagResult == 0) {
        write("诊断成功");
    } else {
        write("诊断失败: NRC=0x%02X", this.NRC);
    }
}
```
