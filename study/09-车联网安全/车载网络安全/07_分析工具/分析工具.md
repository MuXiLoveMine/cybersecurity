# 分析工具

### 7.1 CANoe / CANalyzer

#### 7.1.1 概述

**CANoe** 是Vector公司开发的汽车总线开发测试工具，是行业标准工具。
**CANalyzer** 是CANoe的简化版，主要用于分析。

**支持的协议：** CAN / CAN FD / LIN / FlexRay / MOST / 以太网 / SAE J1939 / UDS等

#### 7.1.2 主要功能

| 功能模块 | 用途 |
|---------|------|
| Trace窗口 | 实时显示总线报文 |
| Graphics窗口 | 信号波形显示（将DBC信号图形化） |
| Data窗口 | 显示信号当前值 |
| CAPL | 编程语言，可编写仿真和测试脚本 |
| Panel Designer | 设计可视化控制面板 |
| Diagnostic Console | 诊断功能测试 |
| Stress Test | 压力测试和模糊测试 |

#### 7.1.3 CAPL编程基础

CAPL（Communication Access Programming Language）是类C的编程语言，用于CANoe自动化。

```capl
// 示例：周期发送CAN报文
variables
{
  msTimer sendTimer;    // 定义定时器
  message 0x100 msg;    // 定义CAN报文（ID=0x100）
}

on start
{
  setTimer(sendTimer, 100);  // 启动100ms定时器
}

on timer sendTimer
{
  msg.byte(0) = msg.byte(0) + 1;  // 数据字节0递增
  output(msg);                     // 发送报文
  setTimer(sendTimer, 100);       // 重置定时器
}

// 示例：接收并解析CAN报文
on message 0x200  // 当收到ID=0x200的报文时触发
{
  int speed;
  speed = (this.byte(0) << 8) | this.byte(1);  // 解析车速
  write("当前车速: %d km/h", speed / 10);
}
```

### 7.2 Wireshark

#### 7.2.1 概述

**Wireshark** 是最流行的开源网络协议分析工具，也支持CAN总线分析。

**支持的CAN相关接口：**
- SocketCAN（Linux）
- CAN/CAN FD（通过CAN适配器）
- 车载以太网
- DoIP / SOME/IP 协议解析

#### 7.2.2 CAN报文显示

Wireshark中CAN报文的显示格式：
```
No.  Time       Source  Destination  Protocol  Length  Info
1    0.000000   -       -            CAN       16      CAN Frame: ID: 0x100 (256), DATA
    Frame 1: 16 bytes on wire
    CAN
        Identifier: 0x00000100
            000. .... .... .... .... .... .... = Priority: 0
            ...0 0000 0000 0000 0001 0000 000. = ID: 256
        Reserved bit: 0
        Data length: 8
        Data: 123456789abcdef0
```

#### 7.2.3 常用显示过滤器

| 过滤器 | 用途 |
|--------|------|
| `can.id == 0x100` | 只显示ID=0x100的CAN报文 |
| `can.dlc == 8` | 只显示数据长度为8的报文 |
| `can.data[0:2] == 12:34` | 数据前两字节为0x1234 |
| `can.fd` | 只显示CAN FD报文 |
| `doip` | 显示DoIP协议报文 |
| `someip` | 显示SOME/IP协议报文 |

### 7.3 can-utils

**can-utils** 是Linux下的开源CAN工具集，轻量高效。

**常用工具：**

| 工具 | 用途 | 示例 |
|------|------|------|
| `candump` | 接收并显示CAN报文 | `candump can0` |
| `cansend` | 发送CAN报文 | `cansend can0 100#11223344` |
| `cangen` | 生成随机CAN报文（测试用） | `cangen can0 -g 10` |
| `canplayer` | 重放录制的CAN报文 | `canplayer -i logfile can0` |
| `canlogserver` | CAN日志服务器 | - |
| `canbusload` | 显示总线负载率 | `canbusload can0@500000` |
| `isotpsend` | 发送ISO-TP（多帧）报文 | - |
| `isotprecv` | 接收ISO-TP（多帧）报文 | - |

**使用示例：**
```bash
# 设置CAN接口
sudo ip link set can0 type can bitrate 500000
sudo ip link set can0 up

# 监听CAN总线
candump can0

# 发送CAN报文（ID=0x100，数据=11 22 33 44）
cansend can0 100#11223344

# 录制CAN报文到文件
candump -l can0

# 重放录制的报文
canplayer -I candump-2024-01-01_120000.log
```
