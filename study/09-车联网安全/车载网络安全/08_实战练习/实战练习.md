# 实战练习

### 8.1 实验环境搭建

**方案一：虚拟CAN接口（推荐入门）**
- Linux系统（虚拟机即可）
- 安装can-utils
- 使用vcan（虚拟CAN）进行实验

```bash
# 加载vcan模块
sudo modprobe vcan
# 创建虚拟CAN接口
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
```

**方案二：真实硬件**
- USB-CAN适配器（PCAN USB、USB2CAN等）
- 汽车ECU或开发板
- CAN总线线缆

**方案三：开发板**
- 树莓派 + MCP2515 CAN模块
- Arduino + CAN shield
- STM32开发板 + CAN收发器

### 8.2 练习任务

1. **基础操作**：使用candump监听、cansend发送CAN报文
2. **报文分析**：录制CAN报文，分析ID和数据规律
3. **重放攻击**：录制一段报文（如车门控制），然后重放
4. **频率检测**：编写简单脚本检测CAN报文频率异常
5. **UDS诊断**：模拟UDS安全访问流程
