# CAN总线入侵检测

### 5.1 入侵检测系统（IDS）概述

**CAN IDS（Intrusion Detection System）** 用于监控CAN总线通信，检测异常或恶意行为。

**部署位置：**
- 网关节点
- 关键ECU中
- 独立的安全模块

**检测类型：**
- **基于签名的检测**：匹配已知攻击特征
- **基于异常的检测**：识别偏离正常行为的模式
- **混合检测**：结合多种方法

### 5.2 常见检测方法

#### 5.2.1 基于频率/周期的检测

**原理：** 正常CAN报文的发送周期相对固定，如果某个ID的发送频率异常升高，可能是攻击。

```
正常: ID=0x100 每10ms发送一次
攻击: ID=0x100 每0.1ms发送一次（洪泛攻击）
     → 检测到频率异常 → 触发告警
```

**优点：** 简单高效，易实现
**缺点：** 只能检测频率异常，无法检测内容伪造

#### 5.2.2 基于ID序列的检测

**原理：** 正常情况下CAN ID的出现顺序有一定规律，如果出现异常序列，可能是攻击。

```
正常序列: 0x100 → 0x200 → 0x300 → 0x100 → 0x200 → ...
异常序列: 0x100 → 0x999 → 0x300 → ... （0x999是未知ID）
         → 检测到未知ID → 触发告警
```

#### 5.2.3 基于数据内容的检测

**原理：** 正常报文中的数据变化有规律（如车速不会跳变），异常的数据变化可能是攻击。

```
正常车速变化: 50km/h → 52km/h → 55km/h → 53km/h （渐变）
攻击数据:     50km/h → 120km/h → 0km/h （跳变）
             → 检测到数据异常 → 触发告警
```

#### 5.2.4 基于时钟偏移的检测（指纹识别）

**原理：** 每个ECU的时钟有微小差异（时钟偏移指纹），可用于识别发送者身份。伪造的报文会有不同的时钟偏移特征。

```
ECU-A的时钟偏移: +50ppm
ECU-B的时钟偏移: -30ppm
攻击者的时钟偏移: +200ppm  ← 明显不同 → 检测到伪造
```

**优点：** 可检测报文伪造，无需修改现有协议
**缺点：** 实现复杂，需要高精度时间测量

#### 5.2.5 基于机器学习的检测

**方法：**
- 使用正常CAN数据训练模型
- 监督学习（标注攻击样本）
- 无监督学习（检测异常）
- 深度学习（LSTM、CNN处理时间序列）

**常用算法：**
- LSTM / GRU（时序分析）
- 孤立森林（异常检测）
- 自编码器（特征学习）
- SVM（分类）

### 5.3 入侵响应

检测到攻击后，IDS可以采取以下响应措施：

| 响应级别 | 措施 | 适用场景 |
|---------|------|---------|
| 告警 | 记录日志、上报云端 | 低风险异常 |
| 过滤 | 丢弃恶意报文 | 已知攻击类型 |
| 隔离 | 断开相关节点/总线 | 严重攻击 |
| 降级 | 进入安全运行模式 | 影响安全功能时 |
| 停车 | 安全停车 | 危及驾驶安全时 |
