# 供应链安全

### 6.1 供应链攻击面

```text
车云平台供应链攻击面

┌──────────────────────────────────────────────────────────┐
│                  供应链攻击向量                             │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  1. 开源依赖                                              │
│     → npm/pip/maven包中的恶意代码                          │
│     → 后门依赖（Typosquatting）                           │
│     → 防御: 依赖扫描、SBOM、私有镜像仓库                   │
│                                                          │
│  2. 容器镜像                                              │
│     → 基础镜像漏洞                                        │
│     → 恶意镜像层                                         │
│     → 防御: 镜像扫描、签名验证、只读根文件系统              │
│                                                          │
│  3. CI/CD管道                                             │
│     → 构建环境被入侵                                      │
│     → 部署凭证泄露                                        │
│     → 防御: 管道隔离、最小权限、审计日志                   │
│                                                          │
│  4. 第三方API                                             │
│     → 地图API、天气API等的供应链攻击                      │
│     → 防御: API监控、数据验证、降级方案                    │
│                                                          │
│  5. 基础设施供应商                                         │
│     → 云服务商被入侵                                      │
│     → 防御: 多云部署、加密控制、审计                      │
│                                                          │
│  6. 第三方SDK                                             │
│     → 车载App中的第三方SDK漏洞                            │
│     → 防御: SDK安全评估、沙箱隔离                         │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 6.2 第三方组件安全

```text
第三方组件安全管理

1. 组件引入评估
   ├── 安全评估（漏洞历史、维护活跃度）
   ├── 许可证合规检查
   ├── 代码质量评估
   └── 供应链风险评级

2. 持续监控
   ├── 漏洞监控（CVE/NVD）
   ├── 版本更新追踪
   ├── 行为监控（异常网络连接）
   └── 依赖树分析

3. 应急响应
   ├── 漏洞响应SOP
   ├── 快速替换方案
   ├── 热补丁机制
   └── 回滚方案

SBOM (Software Bill of Materials):
├── 记录所有依赖组件
├── 版本号和来源
├── 许可证信息
├── 已知漏洞映射
└── 定期更新和审计
```

### 6.3 DevSecOps实践

```text
DevSecOps安全管道

代码提交 → 静态分析(SAST) → 依赖扫描(SCA) → 容器扫描 → 
动态分析(DAST) → 安全测试 → 审批 → 部署 → 运行时监控

具体工具:
├── SAST: SonarQube, Semgrep, CodeQL
├── SCA: Dependency-Track, Snyk, Trivy
├── 容器扫描: Trivy, Clair, Anchore
├── DAST: OWASP ZAP, Burp Suite
├── IaC扫描: Checkov, tfsec
├── 密钥扫描: Git-secrets, TruffleHog
└── 运行时: Falco, Aqua, Sysdig
```
