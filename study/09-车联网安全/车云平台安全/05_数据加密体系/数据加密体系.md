# 数据加密体系

### 5.1 传输加密

```text
数据传输加密体系

车辆 → 云平台:
├── 控制面: mTLS (双向证书认证)
├── 数据面: MQTT over TLS 或 HTTPS
├── 密钥交换: TLS 1.3 ECDHE
└── 加密算法: AES-256-GCM

用户 → 云平台:
├── Web界面: HTTPS (TLS 1.3)
├── API调用: HTTPS + Bearer Token
├── 移动App: HTTPS + Certificate Pinning
└── WebSocket: WSS (WebSocket Secure)

云平台内部:
├── 服务间通信: mTLS (Service Mesh)
├── 消息队列: TLS加密传输
├── 数据库连接: TLS
└── 对象存储: TLS + KMS加密

配置要求:
├── TLS版本: 最低1.2，推荐1.3
├── 密码套件: 仅使用前向安全算法
├── 证书: ECDSA P-256 或 RSA-2048+
├── HSTS: 启用HTTP严格传输安全
└── 证书轮换: 每90天
```

### 5.2 静态数据加密

```text
静态数据加密策略

数据分类:
├── 公开数据: 车辆型号、软件版本 → 不加密
├── 内部数据: 聚合统计、运营数据 → 透明加密
├── 敏感数据: 车辆位置、驾驶行为 → 应用层加密
└── 高敏感数据: 用户身份、密钥 → KMS加密 + 访问控制

加密方案:
┌──────────────────────────────────────────────────┐
│ 数据类型          │ 存储加密方式    │ 密钥管理    │
├──────────────────────────────────────────────────┤
│ 车辆位置历史       │ AES-256-GCM   │ KMS轮转密钥 │
│ 用户个人信息       │ AES-256-GCM   │ 租户级密钥  │
│ 驾驶行为数据       │ AES-256-GCM   │ 租户级密钥  │
│ 车辆证书私钥       │ HSM保护       │ 不可导出    │
│ OTA固件           │ AES-256 +签名 │ 批次密钥    │
│ 审计日志          │ 不可变存储     │ 哈希链      │
└──────────────────────────────────────────────────┘

数据库透明加密(TDE):
├── MySQL: InnoDB表空间加密
├── PostgreSQL: 透明数据加密
├── MongoDB: WiredTiger加密
└── 对象存储: 服务器端加密(SSE)
```

### 5.3 密钥管理体系

```python
class CloudKeyManagement:
    """云平台密钥管理系统"""

    def __init__(self):
        # 密钥层级
        # Root Key (HSM) → KEK → DEK → Data
        self.key_store = {}

    def create_key_hierarchy(self, tenant_id):
        """为租户创建密钥层次"""
        # 1. 根密钥（在HSM中，不可导出）
        root_key_id = f"root-{tenant_id}"

        # 2. KEK (Key Encryption Key) - 数据加密密钥的加密密钥
        kek = self._generate_key(256)  # 256位
        kek_id = f"kek-{tenant_id}"
        kek_wrapped = self._wrap_key(kek, root_key_id)
        self.key_store[kek_id] = kek_wrapped

        # 3. DEK (Data Encryption Key) - 实际加密数据的密钥
        dek = self._generate_key(256)
        dek_id = f"dek-{tenant_id}-001"
        dek_wrapped = self._wrap_key(dek, kek_id)
        self.key_store[dek_id] = dek_wrapped

        return {
            'root_key_id': root_key_id,
            'kek_id': kek_id,
            'dek_id': dek_id
        }

    def encrypt_data(self, data, tenant_id):
        """加密数据"""
        dek_id = f"dek-{tenant_id}-001"

        # 获取DEK（解密后）
        dek = self._unwrap_key(self.key_store[dek_id])

        # AES-256-GCM加密
        import os
        from Crypto.Cipher import AES

        nonce = os.urandom(12)
        cipher = AES.new(dek, AES.MODE_GCM, nonce=nonce)
        ciphertext, tag = cipher.encrypt_and_digest(data)

        # 安全清除DEK
        del dek

        return {
            'ciphertext': ciphertext,
            'nonce': nonce,
            'tag': tag,
            'key_id': dek_id
        }

    def decrypt_data(self, encrypted_data, tenant_id):
        """解密数据"""
        from Crypto.Cipher import AES

        dek_id = encrypted_data['key_id']
        dek = self._unwrap_key(self.key_store[dek_id])

        cipher = AES.new(dek, AES.MODE_GCM, nonce=encrypted_data['nonce'])
        plaintext = cipher.decrypt_and_verify(
            encrypted_data['ciphertext'],
            encrypted_data['tag']
        )

        del dek
        return plaintext

    def rotate_dek(self, tenant_id):
        """轮换DEK"""
        old_dek_id = f"dek-{tenant_id}-001"
        new_dek = self._generate_key(256)
        new_dek_id = f"dek-{tenant_id}-002"
        new_dek_wrapped = self._wrap_key(new_dek, f"kek-{tenant_id}")
        self.key_store[new_dek_id] = new_dek_wrapped

        # 标记旧密钥为待轮换
        # 旧数据用旧密钥解密，用新密钥重新加密

        return new_dek_id

    @staticmethod
    def _generate_key(bits):
        import os
        return os.urandom(bits // 8)

    def _wrap_key(self, key, wrapper_key_id):
        """密钥封装"""
        # 实际使用AES Key Wrap (RFC 3394)
        return key  # 简化

    def _unwrap_key(self, wrapped_key):
        """密钥解封装"""
        return wrapped_key  # 简化


# 使用示例
def demo_key_management():
    kms = CloudKeyManagement()

    # 创建租户密钥
    key_hierarchy = kms.create_key_hierarchy('tenant_001')
    print(f"密钥层次: {key_hierarchy}")

    # 加密数据
    data = b'{"vehicle_id": "VIN123", "location": {"lat": 31.23, "lon": 121.47}}'
    encrypted = kms.encrypt_data(data, 'tenant_001')
    print(f"加密数据大小: {len(encrypted['ciphertext'])} 字节")

    # 解密数据
    decrypted = kms.decrypt_data(encrypted, 'tenant_001')
    print(f"解密数据: {decrypted.decode()}")


if __name__ == '__main__':
    demo_key_management()
```
