### 10.2 学习路线建议

```
推荐学习路线（由浅入深）：

阶段 1：协议基础
  ├── 学习 CAN/CAN FD 总线协议
  ├── 学习 UDS (ISO 14229) 诊断服务
  ├── 学习 DoIP (ISO 13400) 以太网诊断
  └── 实践：使用 CAN 分析工具（如 CANoe, PCAN）进行诊断通信

阶段 2：安全分析
  ├── 理解 SecurityAccess 种子-密钥机制
  ├── 分析 UDS 安全漏洞（种子固定、密钥弱算法）
  ├── 学习 SOME/IP 服务发现与 Payload 安全
  └── 实践：UDS 协议模糊测试、SecurityAccess 绕过实验

阶段 3：防护体系
  ├── 学习车载网关架构与防火墙规则
  ├── 理解 IDS/IPS 部署策略与检测规则
  ├── 学习 ISO 21434 TARA 方法论
  └── 实践：编写 IDS 规则、TARA 分析报告

阶段 4：合规实践
  ├── 深入学习 ISO 21434 全文
  ├── 理解 ISO 26262 与 ISO 21434 融合
  ├── 参与安全需求到实现的完整流程
  └── 实践：模拟车型项目完成 TARA → CSG → CSR → 验证

推荐工具：
  - CANoe / CANalyzer (Vector)         - CAN 总线分析与仿真
  - Wireshark + SOME/IP Dissector       - 以太网诊断抓包
  - Scapy + CAN 构造                    - 自定义协议帧构造
  - PROVEtech:OTA / SecurityGuard      - 诊断安全测试
  - UDS Fuzzer / DoIP Fuzzer            - 协议模糊测试
```

### 10.3 关键要点速查

| 安全主题        | 核心要点                                       | 标准参考       |
|---------------|---------------------------------------------|---------------|
| UDS 认证      | 种子-密钥挑战响应，AES-CMAC，尝试锁定           | ISO 14229     |
| DoIP 安全     | TLS 加密，路由激活认证，证书验证                 | ISO 13400     |
| SOME/IP 安全  | VLAN 隔离，服务实例认证，Payload 加密             | AUTOSAR       |
| 网关安全      | 默认拒绝路由，防火墙规则，域间隔离                | OEM Spec      |
| IDS/IPS      | 多层级部署，规则+异常检测，云端关联               | ISO 21434 §8  |
| 固件刷写安全  | 数字签名验证，防降级，完整性校验                 | ISO 14229 §34 |
| TARA          | 资产→损害→威胁→可行性→风险五步法                 | ISO 21434 §9  |
| CSMS          | 组织级安全管理，供应链协同，持续改进              | ISO 21434 §5  |
| 安全验证      | SAST+SCA+渗透测试+模糊测试+整车测试             | ISO 21434 §11 |
| 事件响应      | 检测→分析→遏制→消除→恢复→总结                    | ISO 21434 §13 |
