# 车载网络安全防护

### 5.1 车载入侵检测系统（IDS）

**车载IDS架构：**

```
┌──────────────────────────────────────────────────────┐
│                  车载IDS 架构                         │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐             │
│  │ CAN IDS │  │以太网IDS │  │ 无线IDS  │  ← 传感器层 │
│  │(报文频率 │  │(端口扫描│  │(异常连接│             │
│  │/ID异常)  │  │/流量异常)│  │/伪AP)   │             │
│  └────┬────┘  └────┬────┘  └────┬────┘             │
│       └────────────┼┴────────────┘                   │
│                    ▼                                  │
│              ┌─────────────┐                         │
│              │  关联分析引擎 │  ← 检测引擎           │
│              │  (规则+ML)   │                         │
│              └──────┬──────┘                         │
│                     ▼                                │
│  ┌─────────┐  ┌──────────┐  ┌─────────┐            │
│  │ 本地告警 │  │ 云端上报  │  │ 自动响应 │  ← 响应层 │
│  │(仪表/HUD)│  │(SOC/态势)│  │(限流/断网)│            │
│  └─────────┘  └──────────┘  └─────────┘            │
└──────────────────────────────────────────────────────┘
```

**CAN IDS检测方法：**

| 检测方法 | 原理 | 适用场景 |
|---------|------|---------|
| ID白名单 | 只允许预定义的CAN ID | 报文注入检测 |
| 周期频率检测 | 基线频率 + 容差窗口 | DoS/泛洪检测 |
| 信号值范围 | 信号值超出物理合理范围 | 传感器欺骗 |
| 跨报文关联 | 多报文逻辑一致性校验 | 复杂注入攻击 |
| ML异常检测 | 正常行为模型 + 偏离检测 | 未知攻击 |

### 5.2 车载防火墙

**车载防火墙部署位置：**

```
外部网络 ──→ [T-BOX防火墙] ──→ 车内网络
                                   │
                        [安全网关防火墙]
                    ┌────────┼────────┐
                    ▼        ▼        ▼
                 动力域    底盘域    座舱域
```

**车载防火墙规则示例：**

| 源域 | 目标域 | 允许报文ID | 动作 |
|------|--------|-----------|------|
| T-BOX | 车身域 | 0x3E0（远程解锁响应） | 允许+日志 |
| T-BOX | 动力域 | ALL | 拒绝 |
| 座舱域 | 底盘域 | 0x1xx（查询类） | 允许 |
| 座舱域 | 底盘域 | 0x2xx（控制类） | 拒绝 |
| 任意 | 任意 | 未注册ID | 拒绝+告警 |

### 5.3 安全网关与域控制器

**中央计算+区域控制架构（新一代电子电气架构）：**

```
┌────────────────────────────────────────────┐
│              中央计算平台                    │
│  ┌──────────┬──────────┬──────────────┐   │
│  │ 自动驾驶 │  智能座舱  │ 车身/网关管理 │   │
│  │  SoC    │   SoC    │   安全 MCU    │   │
│  └──────────┴──────────┴──────────────┘   │
└─────────────┬──────────────┬───────────────┘
              │              │
     ┌────────┴───┐   ┌─────┴────┐
     │ 前区域控制器│   │后区域控制器│
     │(防火墙+IDS)│   │(防火墙+IDS)│
     └──────┬─────┘   └────┬─────┘
            │               │
        前灯/雷达/    后灯/雷达/
        转向/制动      驱动/制动
```

**安全网关核心能力：**
- 域间隔离 + 报文过滤
- 协议转换（CAN ↔ Ethernet/TSN）
- 安全启动 + 固件签名验证
- 内置IDS + 流量审计
- OTA分发与验证

### 5.4 OTA安全监控

- **版本一致性监控**：确保所有ECU固件版本兼容
- **更新失败率监控**：异常失败率可能指示攻击
- **回滚告警**：非预期的版本回退触发告警
- **固件来源审计**：记录每个固件的来源、签名链、安装时间
