# APP关联分析

### 8.1 移动APP安全测试

#### 8.1.1 测试范围

- **车主APP**：远程控制、车辆状态、服务预约
- **经销商APP**：车辆管理、售后服务
- **共享汽车APP**：租车、还车、支付
- **车载APP**：车机端应用

#### 8.1.2 常见安全问题

| 问题 | 说明 |
|------|------|
| 反编译风险 | 代码未混淆，容易逆向 |
| 敏感信息泄露 | 密码、密钥硬编码在APK中 |
| 调试信息残留 | 开发调试代码未移除 |
| 数据存储不安全 | 敏感数据明文存储 |
| 通信安全问题 | 不验证证书、明文传输 |
| 组件导出风险 | Activity/Service/Broadcast导出 |
| WebView漏洞 | JavaScript接口漏洞 |
| Root检测绕过 | 可绕过Root检测 |

#### 8.1.3 APK分析流程

```
APK文件
    ↓
① 反编译
    ├── apktool → 资源文件、Smali代码
    ├── jadx → Java源代码
    └── dex2jar → jar文件
    ↓
② 静态分析
    ├── AndroidManifest.xml分析（组件、权限）
    ├── 敏感信息搜索（密钥、URL、密码）
    ├── 代码审计（业务逻辑漏洞）
    ├── 加密算法分析
    └── 第三方SDK分析
    ↓
③ 动态分析
    ├── Frida Hook（关键函数）
    ├── 网络抓包（API接口分析）
    ├── 数据存储检查
    └── 运行时行为分析
```

### 8.2 APP与车辆关联安全

#### 8.2.1 账号与车辆绑定

**测试要点：**
- 绑定流程是否需要验证车主身份
- 是否可绑定他人车辆
- 解绑是否需要验证
- 多用户控制同一辆车的权限隔离

#### 8.2.2 远程控制安全

**测试要点：**
- 控制指令是否需要二次验证（PIN、指纹）
- 是否有操作频率限制
- 是否有地理围栏限制
- 控制指令是否可重放
- 控制日志是否完整

### 8.3 第三方SDK安全

车联网APP常集成以下SDK：
- 地图SDK（高德、百度、腾讯）
- 支付SDK（支付宝、微信支付）
- 推送SDK（极光、个推）
- 统计SDK（友盟、TalkingData）
- 语音SDK（科大讯飞、百度语音）

**安全风险：**
- SDK自身存在漏洞
- SDK过度申请权限
- SDK收集过多用户数据
- SDK更新不及时
