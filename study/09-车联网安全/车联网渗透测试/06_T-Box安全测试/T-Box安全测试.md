# T-Box安全测试

### 6.1 T-Box硬件分析

#### 6.1.1 拆解分析

```
① 拆除外壳
   ↓
② 识别主要芯片
   ├── 主控芯片（MCU/SoC）
   ├── 4G/5G通信模组
   ├── GPS/北斗模组
   ├── Wi-Fi/蓝牙芯片
   ├── Flash存储芯片
   └── CAN收发器
   ↓
③ 查找调试接口
   ├── UART串口（最常见）
   ├── JTAG/SWD调试接口
   └── USB测试点
   ↓
④ 提取固件
   ├── 编程器读取Flash
   ├── 调试接口读取
   └── UART启动模式
```

#### 6.1.2 常见T-Box芯片方案

| 厂商 | 芯片 | 特点 |
|------|------|------|
| 高通 | MDM9x07 / MDM9628 | 4G通信+MCU |
| 联发科 | MTK系列 | 高集成度 |
| 华为 | Balong系列 | 4G/5G |
| 移远 | AG35 / AG550Q | 车规模组 |
| 广和通 | L610 / FM650 | 车规模组 |

### 6.2 T-Box固件分析

#### 6.2.1 固件获取方法

1. **OTA抓包**：拦截OTA更新包
2. **芯片读取**：编程器直接读取Flash
3. **调试接口**：通过JTAG/SWD读取
4. **U-Boot**：利用Bootloader功能读取
5. **厂商泄露**：从维修渠道、论坛获取

#### 6.2.2 固件分析流程

```
固件文件
    ↓
① 文件类型识别
    ├── file命令
    ├── binwalk分析
    └── 字符串搜索
    ↓
② 提取文件系统
    ├── squashfs / ubifs / jffs2
    ├── ext4 / FAT
    └── 自定义格式
    ↓
③ 静态分析
    ├── 配置文件分析
    ├── 敏感信息搜索（密钥、密码）
    ├── 二进制逆向（IDA/Ghidra）
    ├── 通信协议分析
    └── 加密算法分析
    ↓
④ 漏洞挖掘
    ├── 命令注入
    ├── 缓冲区溢出
    ├── 权限绕过
    └── 认证缺陷
```

#### 6.2.3 敏感信息搜索

```bash
# 搜索硬编码密码
grep -r "password" extracted_fs/
grep -r "passwd" extracted_fs/

# 搜索密钥
grep -r "key" extracted_fs/etc/
grep -r "secret" extracted_fs/

# 搜索IP和域名
grep -rE "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}" extracted_fs/

# 搜索证书和私钥
find extracted_fs/ -name "*.pem" -o -name "*.key" -o -name "*.crt"

# 搜索调试开关
grep -r "debug" extracted_fs/etc/
grep -r "DEBUG" extracted_fs/etc/
```

### 6.3 T-Box通信安全测试

#### 6.3.1 通信协议分析

**常见通信协议：**
- MQTT（消息队列遥测传输）
- HTTP/HTTPS（REST API）
- TCP私有协议
- UDP私有协议
- CoAP（受限应用协议）

**分析方法：**
1. **中间人攻击**：安装自签名证书，拦截HTTPS通信
2. **端口扫描**：扫描T-Box开放的端口
3. **流量分析**：Wireshark抓包分析
4. **逆向分析**：从固件中分析协议实现

#### 6.3.2 中间人攻击测试

```
T-Box ←──→ 攻击者（中间人） ←──→ 云平台
         拦截/篡改/注入
```

**测试步骤：**
1. 将T-Box连接到可控的网络环境
2. 配置代理或中间人工具
3. 检查T-Box是否验证服务器证书
4. 尝试篡改通信数据
5. 检查是否可伪造服务器身份

#### 6.3.3 常见通信安全问题

| 问题 | 风险 |
|------|------|
| 未使用加密（明文HTTP/TCP） | 数据泄露、篡改 |
| 不验证服务器证书 | 中间人攻击 |
| 硬编码证书/密钥 | 证书泄露、伪造 |
| 弱加密算法 | 加密被破解 |
| 无身份认证 | 伪造设备身份 |
| 无消息完整性校验 | 消息篡改 |

### 6.4 T-Box远程控制测试

#### 6.4.1 常见远程控制功能

- 车门解锁/上锁
- 远程启动/熄火
- 空调控制
- 车窗控制
- 灯光控制
- 喇叭控制
- 车辆定位
- 车辆状态查询

#### 6.4.2 测试要点

1. **身份认证**：控制指令是否有强身份认证
2. **权限控制**：是否存在越权控制漏洞
3. **重放防护**：控制指令是否可重放
4. **完整性校验**：指令是否可被篡改
5. **速率限制**：是否有操作频率限制
