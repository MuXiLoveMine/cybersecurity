# 无线攻击

### 4.1 蓝牙攻击

#### 4.1.1 攻击面

- **蓝牙电话**：HFP（免提协议）
- **音乐播放**：A2DP（高级音频分发）
- **手机互联**：蓝牙MAP、PBAP（通讯录同步）
- **蓝牙钥匙**：PKE（被动无钥匙进入）
- **BLE设备**：车载BLE传感器、胎压监测

#### 4.1.2 常见攻击方式

**1. 蓝牙扫描与信息收集**
```bash
# 扫描周围蓝牙设备
hcitool scan
hcitool lescan  # BLE设备扫描

# 获取设备详细信息
sdptool browse <MAC地址>
```

**2. 配对攻击**
- **PIN码暴力破解**：早期蓝牙使用4位PIN，容易破解
- **中间人攻击**：在配对过程中拦截通信
- **BlueBorne**：蓝牙协议级漏洞，可远程代码执行

**3. 蓝牙欺骗**
- 伪造车载蓝牙设备，诱骗手机连接
- 窃取通讯录、通话记录等信息

#### 4.1.3 汽车蓝牙攻击案例

- **2017年**：研究人员发现多款车型的蓝牙系统存在漏洞，可通过蓝牙远程控制车机功能
- **2020年**：特斯拉Model 3蓝牙钥匙被破解，可通过中继攻击解锁车辆
- **BlueBorne漏洞**：影响多款车载蓝牙系统，可远程执行代码

### 4.2 Wi-Fi攻击

#### 4.2.1 攻击面

- **车内Wi-Fi热点**：T-Box提供的Wi-Fi
- **车机Wi-Fi**：IVI系统连接外部Wi-Fi
- **Wi-Fi车钥匙**：基于Wi-Fi的数字钥匙
- **Wi-Fi OTA**：通过Wi-Fi进行固件更新

#### 4.2.2 常见攻击方式

**1. Evil Twin（邪恶双胞胎）**
- 搭建与车载Wi-Fi同名的虚假AP
- 诱骗车机连接，进行中间人攻击

**2. WPA/WPA2破解**
- 抓取握手包
- 暴力破解密码
- 连接车内网络

**3. Wi-Fi协议漏洞**
- KRACK攻击（WPA2密钥重装攻击）
- 车载Wi-Fi芯片固件漏洞

### 4.3 车钥匙攻击

#### 4.3.1 钥匙系统类型

| 类型 | 原理 | 安全性 |
|------|------|--------|
| 传统机械钥匙 | 物理匹配 | 低 |
| 遥控钥匙（RKE） | 315/433MHz射频 | 中 |
| 智能钥匙（PKE） | 低频+射频，被动进入 | 中高 |
| 数字钥匙 | 蓝牙/NFC/UWB | 高 |

#### 4.3.2 中继攻击（Relay Attack）

**原理：** 使用两个中继设备，将车钥匙的信号转发到车辆附近，欺骗车辆认为钥匙就在附近。

```
车主（钥匙在口袋里）           中继设备A          中继设备B           车辆
     │                           │                   │                │
     │<── 钥匙低频信号 ──────────│                   │                │
     │                           │                   │                │
     │  ─── 信号转发 ──────────→ │ ─── 转发 ──────→ │ ── 信号 ──→   │
     │                           │                   │                │
     │  ←── 钥匙响应 ──────────  │ ←── 转发 ─────── │ ←── 响应 ──   │
     │                           │                   │                │
```

**防御措施：**
- 运动检测（钥匙静止时降低发射功率）
- UWB精确定位（测量距离，防止中继）
- 时间戳校验（信号飞行时间）

#### 4.3.3 重放攻击（Rolling Code绕过）

**原理：** 遥控钥匙使用滚动码（Rolling Code），每次发送的代码都不同。攻击者可以在信号覆盖范围外干扰车辆接收，同时录制钥匙信号，下次使用。

**攻击步骤（Jamming + Replay）：**
```
① 攻击者在车辆附近放置干扰器
② 车主按钥匙解锁
③ 干扰器阻止车辆接收，但攻击者录制了遥控信号
④ 车主再次按钥匙（车辆仍未收到），攻击者录制第二帧
⑤ 攻击者使用第一帧解锁车辆（第二帧留着下次用）
```

### 4.4 4G/5G攻击

#### 4.4.1 攻击面

- **T-Box蜂窝通信**：车云通信
- **eSIM安全**：嵌入式SIM卡安全
- **基站攻击**：伪基站（Stingray）
- **协议漏洞**：SS7协议漏洞、 Diameter协议漏洞

#### 4.4.2 攻击方式

**1. 伪基站攻击**
- 建立伪基站，诱骗T-Box连接
- 中间人攻击，窃取通信数据
- 发送伪造的控制指令

**2. SS7/Diameter攻击**
- 利用电信网协议漏洞
- 获取车辆位置信息
- 拦截短信和数据

### 4.5 V2X攻击

#### 4.5.1 攻击面

- **V2V（车车通信）**：车辆间安全消息
- **V2I（车路通信）**：路侧单元消息
- **消息伪造**：伪造紧急制动、事故预警等消息
- **位置欺骗**：发送虚假位置信息

#### 4.5.2 攻击方式

**1. 消息伪造攻击**
- 伪造BSM（基本安全消息）
- 发送虚假的紧急制动消息
- 导致后车误判，紧急刹车

**2. Sybil攻击（女巫攻击）**
- 一个攻击者伪造多个车辆身份
- 造成交通拥堵假象
- 干扰交通管理系统

**3. 重放攻击**
- 录制合法的V2X消息
- 在其他时间/地点重放
- 欺骗其他车辆
