# 车机系统攻击

### 5.1 IVI系统攻击

#### 5.1.1 系统识别

**常见IVI系统：**
- Android Automotive（原生安卓车机）
- Android系统定制（各厂商深度定制）
- QNX
- Linux（AGL等）
- 自研RTOS

**识别方法：**
- 查看系统设置-关于本机
- 查看启动画面
- 分析固件
- USB连接后查看设备信息

#### 5.1.2 Android车机攻击

**攻击路径：**

```
USB接口攻击
    ├── ADB调试开启 → 获取Shell → 提权 → 完全控制
    ├── MTP漏洞 → 数据窃取
    └── USB配件模式 → Android Auto攻击

应用层攻击
    ├── 第三方应用漏洞 → 应用内攻击
    ├── 应用商店恶意应用 → 安装恶意软件
    ├── WebView漏洞 → 远程代码执行
    └── 深度链接攻击 → 唤起应用、传递恶意参数

系统层攻击
    ├── 系统服务漏洞 → 权限提升
    ├── 内核漏洞 → Root权限
    ├── 供应商漏洞 → 硬件相关漏洞
    └── 启动漏洞 → 刷入自定义系统
```

**ADB攻击示例：**
```bash
# 连接设备
adb devices

# 获取系统信息
adb shell getprop ro.build.version.release
adb shell getprop ro.product.model

# 查看已安装应用
adb shell pm list packages

# 安装恶意应用
adb install malicious_app.apk

# 复制敏感数据
adb pull /data/data/com.tencent.navi/databases/
```

#### 5.1.3 QNX系统攻击

QNX是实时操作系统，常见于高端车型的仪表盘和IVI系统。

**攻击面：**
- QNX Neutrino RTOS内核漏洞
- 系统服务漏洞
- 应用程序漏洞
- 文件系统分析

**特点：**
- 微内核架构，安全性较高
- 通过ISO 26262 ASIL D认证
- 市场占有率高（宝马、奔驰、奥迪等）

### 5.2 Android Auto / CarPlay攻击

#### 5.2.1 Android Auto

**攻击面：**
- 手机端Android Auto应用漏洞
- 车机端Android Auto接收器漏洞
- 投影协议安全
- USB连接安全

**攻击方式：**
- 通过恶意手机应用攻击车机
- 通过恶意车机攻击连接的手机
- 中间人攻击（USB通信）

#### 5.2.2 Apple CarPlay

**攻击面：**
- CarPlay协议安全
- 应用漏洞（支持CarPlay的iOS应用）
- USB连接安全

**攻击方式：**
- 恶意iOS应用通过CarPlay攻击车机
- 车机漏洞反攻手机

### 5.3 IVI提权技术

#### 5.3.1 常见提权路径

1. **ADB + 系统漏洞**：通过ADB进入Shell，利用本地提权漏洞获取Root
2. **调试接口**：通过UART调试口获取Shell
3. **固件修改**：提取固件 → 修改 → 刷回
4. **应用漏洞**：利用第三方应用漏洞，再进行提权
5. **恢复模式**：进入Recovery模式进行修改

#### 5.3.2 Root检测与绕过

很多车机系统有Root检测机制：
- 检测su二进制文件
- 检测系统分区挂载状态
- 检测调试属性

绕过方法：
- Magisk Hide（系统less root）
- 修改系统属性
- Frida Hook检测函数
