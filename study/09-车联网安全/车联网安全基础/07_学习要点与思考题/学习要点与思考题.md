# 学习要点与思考题

### 7.1 核心知识点总结

1. **三层架构**：端（终端）、管（网络）、云（平台）各有不同的安全挑战
2. **核心组件**：ECU、CAN总线、网关、IVI、T-Box是车联网的核心
3. **主要协议**：CAN是基础，车载以太网是发展方向
4. **最大威胁**：远程控制、数据泄露、固件篡改、供应链攻击
5. **核心标准**：ISO 21434是网络安全的核心标准，UNECE R155是强制法规
6. **标志性事件**：Jeep Cherokee事件是车联网安全的转折点

### 7.2 思考题

1. 为什么CAN总线设计之初没有考虑安全机制？这反映了什么设计理念的变化？
2. 为什么说网关是车载网络安全的关键节点？网关被攻破会有什么后果？
3. 车联网安全与传统IT安全最大的区别是什么？为什么不能直接照搬IT安全方案？
4. ISO 21434中的TARA方法与传统的风险评估方法有什么不同？
5. Jeep Cherokee事件为什么对行业影响这么大？它改变了什么？
