# 车辆系统架构

### 2.1 ECU（电子控制单元）

#### 2.1.1 ECU概述

**ECU（Electronic Control Unit，电子控制单元）** 是汽车的"大脑"，负责控制车辆的各个系统。现代汽车通常包含 50~150 个 ECU。

**ECU 硬件组成：**
- **MCU（微控制器）**：核心计算单元（常见：Infineon AURIX、NXP S32、Renesas RH850）
- **存储器**：Flash（程序存储）、RAM（运行内存）、EEPROM（数据存储）
- **通信接口**：CAN / LIN / FlexRay / 以太网 收发器
- **模拟/数字接口**：传感器输入、执行器输出
- **电源管理**：稳压、休眠/唤醒控制

**ECU 软件组成：**
- **Bootloader**：启动引导程序，负责固件更新
- **RTOS（实时操作系统）**：AUTOSAR OS、FreeRTOS、μC/OS等
- **应用层软件**：具体控制逻辑
- **通信协议栈**：CAN/LIN协议栈、诊断协议栈

#### 2.1.2 典型ECU分类

| ECU类型 | 功能 | 所属域 | 安全等级 |
|---------|------|--------|---------|
| ECM（发动机控制模块） | 控制燃油喷射、点火等 | 动力域 | ASIL D |
| BCM（车身控制模块） | 控制车灯、门锁、车窗等 | 车身域 | ASIL B |
| ABS/ESC | 防抱死制动、车身稳定控制 | 底盘域 | ASIL D |
| EPS（电动助力转向） | 转向助力控制 | 底盘域 | ASIL D |
| SRS（安全气囊） | 碰撞检测与气囊触发 | 车身域 | ASIL D |
| TCM（变速箱控制） | 自动变速箱控制 | 动力域 | ASIL C |
| IC（仪表盘） | 仪表显示、报警提示 | 座舱域 | ASIL B |
| ADAS ECU | 高级驾驶辅助 | 自动驾驶域 | ASIL B/D |

#### 2.1.3 ECU安全风险

**常见安全漏洞：**
1. **固件漏洞**：缓冲区溢出、整数溢出、命令注入
2. **调试接口未关闭**：JTAG、SWD、UART等调试接口暴露
3. **固件未加密**：可直接读取Flash提取固件
4. **缺乏安全启动**：可刷入恶意固件
5. **认证机制薄弱**：诊断服务缺少身份认证
6. **硬编码密钥**：密钥、密码硬编码在固件中

**案例：** 2015年，研究人员发现特斯拉Model S的车载网关存在漏洞，攻击者可通过CAN总线注入恶意报文控制车辆。

### 2.2 CAN总线

#### 2.2.1 CAN总线概述

**CAN（Controller Area Network，控制器局域网）** 是由博世公司于1986年开发的串行通信协议，是目前汽车中最主要的车载网络。

**CAN总线特点：**
- **多主架构**：任何节点都可主动发送消息
- **广播通信**：所有节点都能收到总线上的消息
- **基于优先级的仲裁**：通过ID优先级解决总线冲突
- **差分信号传输**：抗干扰能力强
- **错误检测与处理**：CRC校验、错误帧机制
- **缺乏安全机制**：无认证、无加密

#### 2.2.2 CAN在汽车中的应用

现代汽车通常有多条CAN总线，按功能和速率划分：

```
                    ┌─────────────┐
                    │   网关 ECU  │
                    └──┬───┬───┬──┘
                       │   │   │
          ┌────────────┘   │   └────────────┐
          ▼                ▼                ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ 动力CAN  │    │ 车身CAN  │    │ 信息CAN  │
    │ 500kbps  │    │ 125kbps  │    │ 250kbps  │
    └────┬─────┘    └────┬─────┘    └────┬─────┘
         │                │                │
    ┌────┴────┐      ┌────┴────┐      ┌───┴────┐
    │  ECM    │      │  BCM    │      │  IVI   │
    │  TCM    │      │  门锁   │      │  导航   │
    │  ABS    │      │  车灯   │      │  娱乐   │
    └─────────┘      └─────────┘      └────────┘
```

### 2.3 车载网关

#### 2.3.1 网关的作用

**车载网关（Gateway）** 是连接不同车载网络的核心设备，负责协议转换和数据转发。

**核心功能：**
- **协议转换**：CAN ↔ LIN ↔ FlexRay ↔ 以太网
- **报文路由**：根据ID和内容转发报文
- **信号聚合**：汇总各总线数据供上层使用
- **诊断路由**：统一诊断入口，转发诊断请求
- **安全防护**：防火墙、入侵检测（新一代网关）

#### 2.3.2 网关安全意义

网关是车载网络的"交通枢纽"，也是安全防护的关键节点：
- **攻击跳板**：攻破信息域后，可通过网关渗透到动力域
- **防护核心**：在网关部署防火墙/IDS可有效隔离攻击
- **安全瓶颈**：网关一旦被控制，全车网络沦陷

**案例：** Jeep Cherokee 事件中，攻击者通过Uconnect娱乐系统进入信息CAN，再通过网关转发恶意报文到动力CAN，实现远程控制。

### 2.4 IVI（车载信息娱乐系统）

#### 2.4.1 IVI系统架构

**IVI（In-Vehicle Infotainment）** 是车载信息娱乐系统，是用户接触最多的车载系统。

```
┌─────────────────────────────────────────┐
│              应用层                      │
│  导航 | 音乐 | 视频 | 蓝牙电话 | 应用商店 │
├─────────────────────────────────────────┤
│              系统层                      │
│  Android Automotive / QNX / Linux / 自研 │
├─────────────────────────────────────────┤
│              服务层                      │
│  蓝牙协议栈 | Wi-Fi | 4G模块 | CAN接口   │
├─────────────────────────────────────────┤
│              硬件层                      │
│  SoC | 显示屏 | 触控 | 麦克风 | 摄像头   │
└─────────────────────────────────────────┘
```

#### 2.4.2 常见IVI系统

| 系统 | 厂商 | 特点 | 代表车型 |
|------|------|------|---------|
| Android Automotive | Google | 开源、生态丰富、安全机制完善 | 沃尔沃、雷诺、极星 |
| QNX | 黑莓 | 安全可靠、通过ISO 26262认证 | 宝马、奔驰、奥迪 |
| Linux（AGL） | 汽车级Linux联盟 | 开源、可定制 | 丰田、马自达 |
| 自研系统 | 各车企 | 深度定制、差异化 | 特斯拉、比亚迪、蔚来 |

#### 2.4.3 IVI安全风险

1. **系统漏洞**：操作系统本身的漏洞（如Linux内核漏洞）
2. **应用漏洞**：第三方应用存在安全问题
3. **恶意应用**：应用商店审核不严导致恶意APP进入
4. **供应链攻击**：第三方SDK、组件存在后门
5. **蓝牙/Wi-Fi攻击**：通过无线接口远程入侵
6. **数据泄露**：通讯录、行驶轨迹、语音数据泄露
7. **提权漏洞**：从普通应用提权到系统权限

### 2.5 T-Box（远程通信终端）

#### 2.5.1 T-Box概述

**T-Box（Telematics Box）** 是车辆与云端通信的核心设备，是车联网的"通信枢纽"。

**主要功能：**
- **远程控制**：远程启动、开闭锁、空调控制
- **数据采集**：车辆状态、行驶数据、位置信息
- **OTA升级**：接收云端推送的固件更新
- **紧急救援**：碰撞自动求助、道路救援
- **WiFi热点**：为车内提供无线网络
- **定位服务**：GPS/北斗定位

#### 2.5.2 T-Box硬件架构

```
┌─────────────────────────────────┐
│         通信模块                 │
│  4G/5G模组 | GPS/北斗 | WiFi/BT │
├─────────────────────────────────┤
│         主控单元                 │
│  MCU/SoC | Flash | RAM | SIM卡  │
├─────────────────────────────────┤
│         车辆接口                 │
│  CAN总线 | OBD | 电源管理        │
└─────────────────────────────────┘
```

#### 2.5.3 T-Box安全重要性

T-Box是车辆的"远程入口"，安全至关重要：
- **直接联网**：暴露在公网，面临远程攻击
- **权限高**：可直接向CAN总线发送报文
- **数据多**：掌握大量车辆和用户数据
- **OTA入口**：被攻破可下发恶意固件

**案例：** 2020年，某品牌T-Box被发现存在未授权访问漏洞，攻击者可远程控制车辆的门锁、启动等功能，涉及数十万辆汽车。
