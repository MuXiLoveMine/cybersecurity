# 车联网安全标准

### 5.1 国际标准

#### 5.1.1 ISO/SAE 21434

**全称：** ISO/SAE 21434:2021 Road vehicles — Cybersecurity engineering

**定位：** 汽车网络安全工程的核心标准，规定了汽车全生命周期的网络安全要求。

**核心内容：**

| 章节 | 内容 | 说明 |
|------|------|------|
| 第5章 | 组织层面网络安全管理 | 建立CSMS（网络安全管理体系） |
| 第6章 | 项目层面网络安全管理 | 项目中的网络安全活动 |
| 第7章 | 持续网络安全活动 | 漏洞管理、事件响应等 |
| 第8章 | 风险评估方法 | 威胁分析与风险评估（TARA） |
| 第9章 | 概念阶段 | 网络安全概念、目标定义 |
| 第10章 | 产品开发 | 系统/硬件/软件层面的安全要求 |
| 第11章 | 生产与运营 | 生产安全、运维安全 |
| 第12章 | 报废阶段 | 报废时的安全处理 |

**TARA（威胁分析与风险评估）方法：**
1. **资产识别**：识别需要保护的资产
2. **威胁场景**：识别潜在的威胁场景
3. **影响评级**：评估安全事件的影响（安全、财产、运营、隐私）
4. **攻击路径分析**：分析攻击可行性
5. **风险确定**：综合影响和可行性确定风险等级
6. **风险处置**：制定风险缓解措施

#### 5.1.2 ISO 26262

**全称：** ISO 26262 Road vehicles — Functional safety

**定位：** 汽车功能安全标准，确保电子系统在故障情况下仍能安全运行。

**ASIL（汽车安全完整性等级）：**

| 等级 | 风险程度 | 典型应用 |
|------|---------|---------|
| ASIL D | 最严重 | 制动系统、转向系统、安全气囊 |
| ASIL C | 严重 | 变速箱控制、灯光控制 |
| ASIL B | 中等 | 仪表盘、车灯 |
| ASIL A | 轻微 | 后视镜调节 |
| QM | 无特殊要求 | 娱乐系统、导航 |

**与网络安全的关系：**
- 功能安全关注随机故障，网络安全关注人为攻击
- 两者相辅相成，共同保障车辆安全
- ISO 21434与ISO 26262在开发流程上有对应关系

#### 5.1.3 ISO 21448 (SOTIF)

**全称：** ISO 21448 Road vehicles — Safety of the Intended Functionality

**定位：** 预期功能安全，关注系统在没有故障情况下的安全问题（如感知局限、误用等）。

**主要应用：** ADAS和自动驾驶系统。

#### 5.1.4 UNECE R155 & R156

**UN R155 — 网络安全管理体系（CSMS）：**
- 要求车企建立网络安全管理体系
- 覆盖车辆全生命周期
- 需通过型式认证
- 2022年7月起在欧盟强制实施

**UN R156 — 软件更新管理体系（SUMS）：**
- 要求车企建立软件更新管理体系
- 确保OTA更新的安全性
- 需记录更新过程和版本信息
- 防止降级攻击

**实施意义：** 是汽车网络安全合规的强制性要求，未通过认证的车型无法在欧盟销售。

#### 5.1.5 SAE J3061

**全称：** SAE J3061 Cybersecurity Guidebook for Cyber-Physical Vehicle Systems

**定位：** 汽车网络安全指南，提供汽车网络安全的最佳实践。

**核心内容：**
- 网络安全生命周期
- 威胁分析方法
- 安全设计原则
- 验证与确认方法

#### 5.2.2 重要法规

**《汽车数据安全管理若干规定》**（2021年10月施行）
- 明确汽车数据处理者的安全责任
- 规定重要数据和敏感个人信息的处理要求
- 要求数据出境安全评估
- 明确车内处理、默认不收集、精度范围适用等原则

**《智能网联汽车道路测试与示范应用管理规范》**
- 规范智能网联汽车道路测试
- 要求网络安全和数据安全保障措施
- 规定事故报告和应急处理要求

**《网络安全等级保护2.0》**
- 车联网平台需按等保要求进行安全建设
- 重要系统需达到三级及以上保护等级
