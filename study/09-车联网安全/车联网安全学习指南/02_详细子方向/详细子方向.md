# 详细子方向

### 2.1 车联网基础

#### 2.1.1 车联网概述
**核心知识点**
- 车联网定义与概念
- 车联网发展历程
- 车联网架构
- 车联网特点
- 车联网应用场景
- 车联网安全的重要性

**车联网特点**
- 安全性要求高（人身安全）
- 实时性要求高
- 生命周期长
- 更新困难
- 异构系统多
- 供应链复杂
- 法规要求严

#### 2.1.2 车联网架构
**三层架构**
- 感知层：车载系统、传感器、ECU
- 网络层：车载网络、V2X 通信、移动通信
- 平台层：车云平台、大数据平台、应用平台

**端-管-云架构**
- 端：车载终端、智能座舱、自动驾驶系统
- 管：车载网络、V2X、4G/5G
- 云：车云平台、服务平台、数据平台

#### 2.1.3 智能网联汽车分级
**自动驾驶分级（SAE）**
- L0：无自动化
- L1：驾驶辅助
- L2：部分自动化
- L3：有条件自动化
- L4：高度自动化
- L5：完全自动化

**网联化分级**
- 网联辅助信息交互
- 网联协同感知
- 网联协同决策与控制
- 网联自动驾驶

**常见系统**

#### 2.2.2 智能座舱
**智能座舱组成**
- 中控屏
- 仪表盘
- 抬头显示（HUD）
- 语音交互
- 人脸识别
- 手势控制
- 多屏互动

**安全风险**
- 系统漏洞
- 数据泄露
- 隐私问题
- 生物识别安全
- 应用安全
- 供应链安全

#### 2.2.3 车载操作系统
**常见车载 OS**
- QNX（黑莓，安全可靠，用于关键系统）
- Linux（开源，用于 IVI 和自动驾驶）
- Android Automotive（谷歌，生态丰富）
- AUTOSAR（汽车开放系统架构）

**安全挑战**

### 2.3 车载网络安全

#### 2.3.1 车载网络协议
**常见车载网络**
- CAN / CAN FD（控制器局域网，最常用）
- LIN（本地互联网络，低成本）
- FlexRay（高速、实时、确定性）
- MOST（媒体导向系统传输，多媒体）
- 车载以太网（高速、大带宽）

#### 2.3.2 CAN 总线安全
**CAN 协议基础**
- CAN 协议原理
- CAN 报文格式
- CAN 标识符
- CAN 仲裁机制
- CAN 错误处理

**CAN 安全风险**
- 缺乏认证
- 缺乏加密
- 广播通信
- 报文可伪造
- 拒绝服务
- 总线监听
- 重放攻击

**CAN 攻击方式**
- 报文注入
- 报文篡改
- 重放攻击
- 拒绝服务
- 总线监听
- 模糊测试

**CAN 安全防护**
- 报文认证
- 加密通信
- 入侵检测
- 防火墙
- 总线监控
- 安全网关

#### 2.3.3 车载以太网
**车载以太网特点**
- 高速率（100Mbps/1Gbps/10Gbps）
- 大带宽
- IP 化
- 与 IT 网络融合
- 用于智能座舱、自动驾驶

**安全挑战**
- 传统网络安全问题
- 实时性要求
- 可靠性要求
- 与 CAN 等传统网络的安全网关

### 2.4 V2X 通信安全

#### 2.4.1 V2X 概述
**V2X 概念**
- Vehicle to Everything
- 车与万物互联
- V2V（车与车）
- V2I（车与基础设施）
- V2P（车与人）
- V2N（车与网络）

**V2X 技术路线**
- DSRC（专用短程通信，基于 WiFi）
- C-V2X（蜂窝车联网，基于 4G/5G）
- 中国主推 C-V2X

#### 2.4.2 V2X 安全风险
**安全威胁**
- 消息伪造
- 消息篡改
- 重放攻击
- 拒绝服务
- 位置隐私泄露
- 身份冒充
- 中间人攻击
- Sybil 攻击（女巫攻击）

#### 2.4.3 V2X 安全机制
**安全技术**
- 数字签名
- 公钥基础设施（PKI）
- 证书管理
- 匿名认证
- 隐私保护
- 消息认证
- 加密通信

**安全标准**
- IEEE 1609.2
- ETSI TS 103 097
- 中国 C-V2X 安全标准
- GB/T 车联网安全标准
