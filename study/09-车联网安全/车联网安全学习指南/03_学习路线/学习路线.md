# 学习路线

### 阶段 1：车联网基础（1-2 个月）
**学习目标**：掌握车联网基础知识和架构

**学习内容**
- 车联网概念与架构
- 智能网联汽车基础
- 车载系统介绍
- 车载网络基础
- V2X 基础
- 自动驾驶基础
- 车联网安全概述

**实践任务**
- 学习车联网基础知识
- 了解汽车电子架构
- 学习 CAN 协议基础
- 了解车载系统
- 关注车联网安全事件

### 阶段 2：车载系统与网络安全（2-3 个月）
**学习目标**：掌握车载系统和车载网络安全

**学习内容**
- 车载操作系统安全
- IVI 系统安全
- 智能座舱安全
- CAN 总线安全
- 车载以太网安全
- 车载网络攻击与防御
- T-BOX 安全

**实践任务**
- 学习 CAN 协议分析
- 使用 CAN 工具
- 分析车载系统
- 搭建车载网络实验环境
- 学习车载漏洞分析

### 阶段 3：车联网安全技术（3-4 个月）
**学习目标**：掌握车联网核心安全技术

**学习内容**
- OTA 安全
- V2X 安全
- 自动驾驶安全
- 车云平台安全
- 移动 App 安全
- 数据安全与隐私保护
- 车联网安全标准

**实践任务**
- 分析 OTA 安全机制
- 学习 V2X 安全协议
- 研究自动驾驶安全
- 测试车云平台
- 分析车联网漏洞

### 阶段 4：车联网渗透测试（2-3 个月）
**学习目标**：掌握车联网渗透测试方法

**学习内容**
- 车联网渗透测试方法论
- 硬件测试技术
- 固件分析与逆向
- 网络协议测试
- 应用安全测试
- 云平台测试
- 报告编写

**实践任务**
- 学习硬件测试技术
- 练习固件分析
- 练习协议分析
- 做渗透测试练习
- 写测试报告

### 阶段 5：深入研究（持续）
**研究方向**
- 车载系统漏洞挖掘
- CAN 总线安全
- V2X 安全
- 自动驾驶安全
- 车联网攻防技术
- 车联网安全标准
- 车联网安全产品
