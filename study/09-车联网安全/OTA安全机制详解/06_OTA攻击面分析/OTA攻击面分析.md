### 6.2 传输通道攻击

```text
传输通道攻击

攻击1: 中间人攻击
车辆 ←─攻击者─→ OTA服务器
→ 攻击者替换升级包
→ 防御: mTLS双向认证 + 固件签名

攻击2: 固件窃取
→ 攻击者截获固件，逆向分析漏洞
→ 防御: 端到端加密固件

攻击3: 重放攻击
→ 攻击者重放旧升级包
→ 防御: 时间戳 + nonce + 版本检查

攻击4: 降级攻击
→ 攻击者替换为旧版本固件
→ 防御: 防回滚计数器

攻击5: 信道阻塞
→ 干扰4G/5G信号导致升级失败
→ 防御: 断点续传 + 升级完整性检查
```
