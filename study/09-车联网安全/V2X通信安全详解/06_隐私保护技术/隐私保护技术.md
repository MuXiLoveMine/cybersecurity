# 隐私保护技术

### 6.1 假名证书机制

**假名证书（Pseudonym Certificate）** 是V2X隐私保护的核心机制。

**假名证书管理流程：**

```text
假名证书生命周期：

1. 申请阶段
   车辆 → RA: "我需要一批假名证书"
   RA验证车辆身份后 → PCA签发证书批次

2. 使用阶段
   车辆持有: [假名1, 假名2, ..., 假名20]
   T=0-5min: 使用假名1
   T=5-10min: 使用假名2
   ...
   T=95-100min: 使用假名20

3. 切换策略
   - 固定间隔切换（每5分钟）
   - 事件触发切换（如停车、转弯）
   - 混合策略（基础间隔+随机扰动）

4. 更新阶段
   剩余假名<5张时 → 申请新批次
   旧假名过期 → 安全删除
```

**隐私保护量化分析：**

```python
class PrivacyAnalysis:
    """隐私保护量化分析"""

    @staticmethod
    def calculate_linkability(num_pseudonyms, rotation_interval_min,
                              observation_duration_min):
        """
        计算假名切换下的位置链接成功率
        :param num_pseudonyms: 假名数量
        :param rotation_interval_min: 切换间隔（分钟）
        :param observation_duration_min: 观察时长（分钟）
        :return: 链接成功率
        """
        # 理论上的最大切换次数
        max_rotations = observation_duration_min / rotation_interval_min

        # 如果观察时间小于切换间隔，可以100%链接
        if observation_duration_min <= rotation_interval_min:
            return 1.0

        # 随着切换次数增加，链接成功率降低
        # 但仍可通过位置连续性等手段部分链接
        base_linkability = rotation_interval_min / observation_duration_min

        # 混入因素：周围有多少其他车辆
        # 车辆越多，越容易在切换时混入其他车辆
        mixing_factor = 0.3  # 假设30%概率混入成功

        linkability = base_linkability * (1 - mixing_factor) + \
                       mixing_factor * 0.1  # 混入后链接成功率约10%

        return max(0, min(1, linkability))

    @staticmethod
    def privacy_requirements():
        """V2X隐私保护要求"""
        return {
            "假名数量": "至少20张/批次",
            "切换间隔": "5分钟（推荐）",
            "切换随机性": "±30秒随机扰动",
            "证书有效期": "与切换间隔一致",
            "过期证书": "立即删除，不可恢复",
            "跨批次隔离": "不同批次的假名不可关联",
            "位置混淆": "切换时避免可追踪的连续轨迹",
            "链接成功率目标": "<10%（10分钟观察窗口）"
        }


analysis = PrivacyAnalysis()
print("隐私保护要求:")
for k, v in analysis.privacy_requirements().items():
    print(f"  {k}: {v}")

print("\n链接成功率分析:")
for duration in [5, 10, 30, 60]:
    rate = analysis.calculate_linkability(20, 5, duration)
    print(f"  观察{duration}分钟: 链接成功率={rate:.1%}")
```

### 6.2 位置隐私保护

除了假名证书外，V2X还需要考虑消息中的位置信息对隐私的影响。

```text
位置隐私泄露路径：

1. BSM消息包含精确GPS坐标
   → 即使使用假名，位置轨迹也暴露

2. 轨迹分析推断身份
   → 轨迹起点=家庭住址
   → 轨迹终点=工作单位
   → 推断车辆主人身份

3. 假名切换时的位置连续性
   → 假名1最后位置 ≈ 假名2第一个位置
   → 攻击者可以关联两个假名

防御措施：
├── 位置模糊化
│   ├── 降低GPS精度（10米→50米）
│   └── 随机化坐标低位
├── 切换时机优化
│   ├── 在群体中切换（如等红灯时有多车）
│   ├── 在非关键时刻切换（如停车时）
│   └── 添加位置跳跃（切换时位置有间隙）
├── 混合区域（Mix Zone）
│   ├── 设定混合区域（如停车场、路口）
│   ├── 进入混合区域后停止发送BSM
│   └── 离开时使用新假名
└── 虚假消息注入
    ├── 发送少量虚拟轨迹
    └── 增加攻击者追踪难度
```

### 6.3 隐私保护分析

```text
隐私 vs 安全的平衡

隐私保护太强：
  → 无法追溯犯罪行为
  → 执法困难
  → 安全性降低

隐私保护太弱：
  → 位置追踪
  → 身份泄露
  → 用户不信任V2X

平衡方案：
  ┌──────────────────────────────────┐
  │  正常情况: 强隐私保护             │
  │  → 假名证书 → 无法追踪             │
  │  → 位置隐私 → 不可关联             │
  │                                  │
  │  犯罪情况: 有条件去匿名           │
  │  → 法院授权 → LA去匿名             │
  │  → 恢复真实身份 → 执法追溯         │
  │  → 去匿名需多人审批 → 防滥用       │
  └──────────────────────────────────┘
```
