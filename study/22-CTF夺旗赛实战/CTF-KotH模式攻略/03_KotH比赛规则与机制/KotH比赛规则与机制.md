# KotH比赛规则与机制

### 2.1 得分机制

#### 2.1.1 占领时间计分

这是KotH最核心的计分方式。

**基本规则：**
- 选手在靶机的指定位置（通常是`/root/king.txt`或类似文件）写入自己的标识
- 系统以固定频率（通常是每分钟或每30秒）检查当前占领者
- 每次检查时，如果占领者是你，则获得一定分数
- 最终分数 = 占领次数 × 每次检查分值

**分数计算示例：**
- 比赛时长：60分钟
- 检查频率：每分钟一次
- 每次检查得分：1分
- 选手A占领了35分钟 → 35分
- 选手B占领了20分钟 → 20分
- 无人占领：5分钟 → 无人得分

**变种规则：**
- **阶梯式计分**：连续占领时间越长，单次得分越高
- **末段加倍**：比赛最后10分钟得分翻倍
- **首次占领奖励**：第一个占领靶机的选手获得额外奖励分

#### 2.1.2 Flag数量计分

部分KotH赛事还结合了传统CTF的flag机制。

**常见形式：**
- **用户flag + root flag**：靶机中设置user和root两个flag，获取flag可获得额外分数
- **隐藏flag**：在靶机各处隐藏多个flag，寻找flag可获得积分
- **攻击得分**：成功攻击其他选手（如获取其他选手的shell）可获得额外分数

#### 2.1.3 扣分机制

- **违规操作扣分**：使用禁止的攻击手段（如DDoS）会被扣分
- **防御失败扣分**：部分赛制中被攻破会扣分
- **超时扣分**：长时间未占领可能有惩罚

### 2.2 攻防平衡机制

为了保证比赛的公平性和可玩性，KotH赛制通常会设置一些攻防平衡机制。

#### 2.2.1 占领冷却机制

- **描述**：刚占领靶机后有一段保护期，在此期间其他选手无法夺走
- **目的**：防止选手反复快速切换占领，保证比赛稳定性
- **常见设置**：30秒到2分钟不等的保护期

#### 2.2.2 难度递增机制

- **描述**：随着比赛进行，靶机可能会自动加固或增加防御
- **目的**：防止某一选手过早建立绝对优势
- **实现方式**：自动更新安全补丁、增加防火墙规则等

#### 2.2.3 资源限制

- **描述**：对选手的操作进行一定限制
- **常见限制**：
  - SSH连接数限制
  - 进程数限制
  - CPU/内存使用限制
  - 网络带宽限制

### 2.3 常见比赛模式

#### 2.3.1 个人赛（Solo）

**特点：**
- 每个选手独立作战
- 依靠个人技术能力
- 更考验个人综合素质

**适合场景：**
- 日常练习
- 个人能力评估
- 小型比赛

#### 2.3.2 团队赛

**特点：**
- 多名队员协同作战
- 可以进行攻防分工
- 策略性更强

**团队分工模式：**

1. **攻击手**：专注于攻破靶机，快速获取控制权
2. **防御手**：专注于加固系统，防止被其他队伍夺走
3. **监控员**：监控比赛状态，提供情报支持
4. **指挥官**：制定战术策略，协调队员行动

**团队规模：**
- 小型团队：2-3人
- 中型团队：4-6人
- 大型团队：7人以上（较少见）

#### 2.3.3 混合模式

部分比赛同时包含KotH和解题模式：
- **攻防+解题混合**：既要解题获取flag，也要进行KotH对抗
- **多靶机模式**：同时有多台靶机，各队分配不同目标
