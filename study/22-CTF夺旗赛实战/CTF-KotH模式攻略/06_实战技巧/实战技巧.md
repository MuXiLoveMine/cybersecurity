# 实战技巧

### 6.1 开局策略

#### 6.1.1 前5分钟：信息收集阶段

**目标：快速掌握靶机的基本情况**

1. **第1分钟：全端口扫描启动**
   - 启动masscan或nmap快速扫描
   - 同时手动访问Web服务（如果有）
   - 查看网页源代码、robots.txt

2. **第2-3分钟：初步漏洞评估**
   - 根据端口和服务信息，判断可能的攻击路径
   - 在Exploit-DB中搜索已知漏洞
   - 启动目录爆破

3. **第4-5分钟：选择最优攻击路径**
   - 确定最有可能成功的攻击方式
   - 准备好对应的EXP或工具
   - 开始第一次攻击尝试

#### 6.1.2 前15分钟：首次占领

**目标：尽快拿下靶机控制权**

1. **优先尝试高成功率漏洞**
   - 默认凭证登录
   - 已知RCE漏洞
   - 未授权访问

2. **并行操作**
   - 一边尝试Web漏洞，一边跑密码爆破
   - 多个攻击向量同时进行
   - 使用tmux分屏管理多个会话

3. **获取Shell后的操作顺序**
   ```
   1. 升级为交互式Shell
   2. 查看当前权限
   3. 尝试权限提升
   4. 获取root后写入flag
   5. 建立持久化后门
   6. 加固系统防御
   ```

### 6.2 中期攻防转换

#### 6.2.1 进攻转防御

当你成功占领靶机后，需要迅速切换到防御模式：

**黄金30秒：**
- 第0-10秒：写入flag，确认占领
- 第10-20秒：修改root密码
- 第20-30秒：清除其他用户的会话

**前5分钟防御：**
1. 检查并清除所有后门
2. 配置防火墙规则
3. 加固SSH配置
4. 建立多个备用后门
5. 启动监控脚本

#### 6.2.2 防御转进攻

当你的占领被夺走时，需要快速反击：

**反击流程：**
1. 使用备用后门重新进入系统
2. 清除对手的访问权限
3. 重新写入flag
4. 加强防御措施
5. 分析对手的攻击方式，针对性加固

**如果后门全部失效：**
1. 重新进行信息收集（对手可能改变了配置）
2. 寻找新的攻击路径
3. 尝试不同的攻击向量
4. 利用对手可能留下的漏洞

### 6.3 末期冲刺技巧

#### 6.3.1 最后10分钟策略

比赛末期是最激烈的阶段，策略非常重要。

**防守方策略：**
- 加强监控频率
- 确保所有后门都正常工作
- 准备好应急响应脚本
- 考虑使用更激进的防御手段

**进攻方策略：**
- 集中所有资源进行最后冲刺
- 尝试之前未使用过的攻击向量
- 利用对手可能的疏忽
- 准备好占领后立即加固

#### 6.3.2 最后1分钟技巧

**最后一分钟的操作：**
1. 确认当前占领状态
2. 如果是你占领：
   - 断开不必要的连接
   - 确保flag文件正确
   - 监控是否有攻击
3. 如果不是你占领：
   - 发起最后的猛攻
   - 使用所有可用的后门
   - 尝试DoS攻击（如果规则允许）

### 6.4 团队配合技巧

#### 6.4.1 角色分工

**典型3人团队分工：**

| 角色 | 职责 | 技能要求 |
|------|------|---------|
| 主攻手 | 攻破靶机、权限提升 | 漏洞利用、Web安全、系统内核 |
| 防御手 | 系统加固、后门清除、监控 | 系统管理、安全加固、日志分析 |
| 支援手 | 信息收集、工具开发、情报分析 | 脚本编写、侦察技术、情报分析 |

#### 6.4.2 通信与协作

**通信工具：**
- 语音通信：Discord、TeamSpeak、腾讯会议
- 文字协作：共享笔记、实时文档
- 终端共享：tmate、tmux协作

**协作规范：**
1. **统一命名约定**：对靶机、漏洞、后门等使用统一的命名
2. **状态同步**：定期同步当前状态（占领/失守/进攻中）
3. **操作确认**：重要操作前与队友确认，避免冲突
4. **日志记录**：记录关键操作和发现，便于复盘

#### 6.4.3 战术配合

**接力攻击战术：**
- 主攻手A尝试一种方法，主攻手B准备另一种方法
- 一种方法失败后立即切换，无缝衔接
- 共享发现的信息，避免重复劳动

**多门同开战术：**
- 同时从多个入口攻击
- 一个入口被封，还有其他入口可用
- 分散对手的防御注意力

**声东击西战术：**
- 一方进行明显的攻击，吸引对手注意力
- 另一方从隐蔽路径悄悄入侵
- 时机成熟时同时发力
