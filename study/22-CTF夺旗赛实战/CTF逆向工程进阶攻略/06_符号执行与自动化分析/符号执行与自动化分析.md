# 符号执行与自动化分析

### 5.1 angr进阶使用

angr是一个强大的二进制分析框架，支持符号执行、约束求解、静态分析等功能。

#### 5.1.1 angr核心概念

**1. 符号执行（Symbolic Execution）**

用符号值代替具体数值执行程序，收集路径约束，用约束求解器求解满足条件的输入。

```
具体执行: input = "AAAA" → 程序执行 → output = ?
符号执行: input = α (符号) → 程序执行 → 路径约束 + 符号化输出
```

**2. 路径爆炸（Path Explosion）**

符号执行的主要挑战：程序分支太多，路径数量指数级增长。

**应对方法：**
- 状态合并（State Merging）
- 路径剪枝（Path Pruning）
- 循环摘要（Loop Summarization）
- 针对性探索（Targeted Exploration）

#### 5.1.2 angr实战脚本

**基础使用：**
```python
import angr
import sys

# 加载二进制文件
proj = angr.Project('./challenge', auto_load_libs=False)

# 获取入口状态
state = proj.factory.entry_state()

# 创建仿真管理器
simgr = proj.factory.simulation_manager(state)

# 探索到目标地址
target_addr = 0x401234  # 成功分支地址
simgr.explore(find=target_addr)

# 检查是否找到
if simgr.found:
    found_state = simgr.found[0]
    # 获取标准输入
    solution = found_state.posix.dumps(sys.stdin.fileno())
    print(f"Solution: {solution}")
else:
    print("No solution found")
```

**处理复杂条件：**
```python
import angr
import claripy

proj = angr.Project('./challenge', auto_load_libs=False)

# 创建符号输入
flag = claripy.BVS('flag', 8 * 32)  # 32字节的符号值

# 创建入口状态，设置标准输入为符号
state = proj.factory.entry_state(stdin=flag)

# 添加约束：flag以"flag{"开头
for i, c in enumerate(b"flag{"):
    state.add_constraints(flag.get_byte(i) == c)

# 添加约束：所有字符都是可打印的
for i in range(32):
    byte = flag.get_byte(i)
    state.add_constraints(byte >= 0x20)  # 空格
    state.add_constraints(byte <= 0x7e)  # ~

# 创建仿真管理器
simgr = proj.factory.simulation_manager(state)

# 定义成功和失败的条件
def is_successful(state):
    stdout_output = state.posix.dumps(sys.stdout.fileno())
    return b'Correct' in stdout_output

def should_abort(state):
    stdout_output = state.posix.dumps(sys.stdout.fileno())
    return b'Wrong' in stdout_output

# 探索
simgr.explore(find=is_successful, avoid=should_abort)

if simgr.found:
    found_state = simgr.found[0]
    solution = found_state.solver.eval(flag, cast_to=bytes)
    print(f"Flag: {solution}")
```

**优化探索策略：**
```python
import angr

proj = angr.Project('./challenge', auto_load_libs=False)
state = proj.factory.entry_state()
simgr = proj.factory.simulation_manager(state)

# 使用不同的探索策略
# 1. DFS（深度优先）
simgr.use_technique(angr.exploration_techniques.DFS())

# 2. 长度优先（探索最短路径）
simgr.use_technique(angr.exploration_techniques.LengthLimiter(max_length=100))

# 3. 循环限制
simgr.use_technique(angr.exploration_techniques.LoopSeer())

# 4. 手动指导探索
while len(simgr.active) > 0:
    simgr.step()
    # 可以在这里添加自定义的状态过滤逻辑
    # 比如优先探索接近目标地址的状态
    print(f"Active: {len(simgr.active)}, Found: {len(simgr.found)}")
```

#### 5.1.3 angr高级技巧

**1. Hook函数**

用Python函数替换原有的函数调用，加速分析：

```python
import angr

proj = angr.Project('./challenge', auto_load_libs=False)

# Hook strlen函数
@proj.hook(0x401000, length=5)  # 假设strlen在0x401000
def my_strlen(state):
    # 获取字符串地址
    str_addr = state.regs.rdi
    # 读取字符串（符号化）
    s = state.mem[str_addr].string.concrete  # 注意：只适用于具体字符串
    # 设置返回值
    state.regs.rax = len(s)

# 或者使用SimProcedure
class StrLen(angr.SimProcedure):
    def run(self, s):
        # 更复杂的实现...
        pass

proj.hook_symbol('strlen', StrLen())
```

### 5.2 Z3约束求解实战

Z3是微软开发的约束求解器，是符号执行的核心引擎，也可以独立使用。

#### 5.2.1 Z3基础

```python
from z3 import *

# 创建变量
x = Int('x')
y = Int('y')

# 创建求解器
s = Solver()

# 添加约束
s.add(x + y == 10)
s.add(x - y == 4)
s.add(x > 0)
s.add(y > 0)

# 求解
if s.check() == sat:
    model = s.model()
    print(f"x = {model[x]}")
    print(f"y = {model[y]}")
else:
    print("No solution")
```

#### 5.2.2 CTF中的Z3应用

**1. 解方程类题目**
```python
from z3 import *

# 多变量方程求解
x, y, z = Ints('x y z')
s = Solver()
s.add(2*x + 3*y - z == 10)

s.add(3*x + 2*y + z == 15)
```

**2. 自定义编码/加密逆向**
```python
from z3 import *

# 假设加密算法：每个字符与密钥异或，然后交换位置
# 已知密文，求明文
encrypted = [0x5f, 0x73, 0x6b, 0x72, 0x7e, 0x3c, 0x7e, 0x60, 0x72, 0x73]
key = 0x42

# 创建符号变量
flag = [BitVec(f'flag_{i}', 8) for i in range(10)]

# 模拟加密过程
result = []
for i in range(10):
    # 异或
    xored = flag[i] ^ key
    # 位置交换（简单的置换）
    new_pos = (i + 3) % 10
    result.insert(new_pos, xored)

# 添加约束：加密结果等于已知密文
s = Solver()
for i in range(10):
    s.add(result[i] == encrypted[i])

# 添加约束：可打印字符
for c in flag:
    s.add(c >= 0x20)
    s.add(c <= 0x7e)

if s.check() == sat:
    m = s.model()
    flag_str = ''.join(chr(m[c].as_long()) for c in flag)
    print(f"Flag: {flag_str}")
```

**3. 逻辑约束类题目**
```python
from z3 import *

# 数独求解示例
# 9x9的数独，0表示空格
puzzle = [
    [5, 3, 0, 0, 7, 0, 0, 0, 0],
    [6, 0, 0, 1, 9, 5, 0, 0, 0],
    [0, 9, 8, 0, 0, 0, 0, 6, 0],
    [8, 0, 0, 0, 6, 0, 0, 0, 3],
    [4, 0, 0, 8, 0, 3, 0, 0, 1],
    [7, 0, 0, 0, 2, 0, 0, 0, 6],
    [0, 6, 0, 0, 0, 0, 2, 8, 0],
    [0, 0, 0, 4, 1, 9, 0, 0, 5],
    [0, 0, 0, 0, 8, 0, 0, 7, 9]
]

# 创建变量
cells = [[Int(f'cell_{i}_{j}') for j in range(9)] for i in range(9)]

s = Solver()

# 约束1：值在1-9之间
for i in range(9):
    for j in range(9):
        s.add(cells[i][j] >= 1)
        s.add(cells[i][j] <= 9)

# 约束2：每行数字不重复
for i in range(9):
    s.add(Distinct(cells[i]))

# 约束3：每列数字不重复
for j in range(9):
    s.add(Distinct([cells[i][j] for i in range(9)]))

# 约束4：每个3x3宫格数字不重复
for block_i in range(3):
    for block_j in range(3):
        block_cells = []
        for i in range(3):
            for j in range(3):
                block_cells.append(cells[block_i*3 + i][block_j*3 + j])
        s.add(Distinct(block_cells))

# 约束5：已知数字
for i in range(9):
    for j in range(9):
        if puzzle[i][j] != 0:
            s.add(cells[i][j] == puzzle[i][j])

if s.check() == sat:
    m = s.model()
    for i in range(9):
        row = [m[cells[i][j]].as_long() for j in range(9)]
        print(row)
```

### 5.3 自动化漏洞挖掘

#### 5.3.1 Fuzzing基础

Fuzzing是一种自动化漏洞挖掘技术，通过生成大量随机输入来触发程序异常。

**常用Fuzzing工具：**
- **AFL++**：覆盖率引导的模糊测试
- **libFuzzer**：LLVM内置的模糊测试引擎
- **Honggfuzz**：谷歌开发的模糊测试工具
- **Wfuzz**：Web应用模糊测试

**AFL++使用示例：**
```bash
# 编译插桩的程序
afl-gcc -o target target.c

# 创建输入目录，放入种子文件
mkdir in
echo "test_input" > in/seed1

# 启动Fuzzing
afl-fuzz -i in -o out ./target @@
```

#### 5.3.2 符号执行 + Fuzzing

结合符号执行和Fuzzing的优点：
- Fuzzing速度快，但难以覆盖深层路径
- 符号执行能覆盖深层路径，但速度慢

**混合策略：**
1. 先用Fuzzing快速覆盖浅层路径
2. 用符号执行处理Fuzzing难以到达的深层分支
3. 互相补充，提高覆盖率

### 5.4 脚本化解题技巧

#### 5.4.1 自动化分析框架

**1. 自动化字符串解密**
```python
# 自动识别并解密异或加密的字符串
import re

def auto_decrypt_strings(binary_data):
    """自动尝试解密二进制中的字符串"""
    results = []
    
    # 尝试单字节异或
    for key in range(1, 256):
        decrypted = bytes([b ^ key for b in binary_data])
        # 检查是否包含可打印字符串
        strings = re.findall(b'[ -~]{6,}', decrypted)
        if len(strings) > 3:  # 找到多个字符串
            results.append((key, strings))
    
    return results
```

**2. 加密算法识别**
```python
# 识别常见加密算法的常量
import re

# 常见加密算法的常量特征
CRYPTO_CONSTANTS = {
    'AES': [
        # AES S-box 特征值
        bytes([0x63, 0x7c, 0x77, 0x7b, 0xf2, 0x6b, 0x6f, 0xc5]),
    ],
    'SHA256': [
        # SHA-256 初始哈希值
        bytes([0x6a, 0x09, 0xe6, 0x67]),
    ],
    'MD5': [
        # MD5 初始值
        bytes([0x01, 0x23, 0x45, 0x67]),
    ],
    'RC4': [
        # RC4 初始化模式
    ],
}

def identify_crypto(data):
    """识别二进制数据中的加密算法"""
    results = []
    for algo, patterns in CRYPTO_CONSTANTS.items():
        for pattern in patterns:
            if pattern in data:
                results.append(algo)
                break
    return results
```
