# 特殊平台逆向

### 6.1 ARM/Android逆向进阶

#### 6.1.1 ARM汇编进阶

**ARM指令集特点：**
- 固定长度指令（ARM状态32位，Thumb状态16位）
- Load-Store架构（只有Load/Store指令访问内存）
- 条件执行（大多数指令可以条件执行）
-  barrel shifter（桶形移位器）

**常见ARM指令：**
```arm
; 数据处理
MOV R0, R1          ; 寄存器移动
ADD R0, R1, R2      ; 加法
SUB R0, R1, R2      ; 减法
MUL R0, R1, R2      ; 乘法
AND R0, R1, R2      ; 与
ORR R0, R1, R2      ; 或
EOR R0, R1, R2      ; 异或
LSL R0, R1, #2      ; 逻辑左移
LSR R0, R1, #2      ; 逻辑右移

; 内存访问
LDR R0, [R1]        ; 加载字
STR R0, [R1]        ; 存储字
LDRB R0, [R1]       ; 加载字节
STRB R0, [R1]       ; 存储字节
LDMIA R1!, {R2-R5}  ; 多加载
STMIA R1!, {R2-R5}  ; 多存储

; 分支
B label             ; 无条件跳转
BL label            ; 带链接跳转（函数调用）
BEQ label           ; 相等时跳转
BNE label           ; 不等时跳转

; 条件执行（示例）
ADDEQ R0, R1, R2    ; 如果相等，则执行加法
MOVNE R0, #0        ; 如果不等，则R0=0
```

**ARM调用约定（AAPCS）：**
- 参数：R0-R3（前4个），其余压栈
- 返回值：R0（64位用R0:R1）
- 被调用者保存：R4-R11, SP, LR
- 调用者保存：R0-R3

#### 6.1.2 Android Native层逆向

**Android应用结构：**
- Java层：大部分应用逻辑
- Native层（.so文件）：核心算法、性能关键代码
- JNI：Java和Native之间的桥梁

**Native层逆向要点：**

1. **定位JNI函数**
   - 静态注册：函数名有固定格式`Java_包名_类名_方法名`
   - 动态注册：通过`RegisterNatives`注册

2. **分析JNI接口**
   ```c
   // JNI函数示例
   JNIEXPORT jstring JNICALL
   Java_com_example_app_MainActivity_getFlag(JNIEnv *env, jobject thiz) {
       // Native代码
       return (*env)->NewStringUTF(env, "flag{...}");
   }
   ```

3. **常用工具**
   - IDA Pro：支持ARM反汇编和反编译
   - Ghidra：支持ARM，免费
   - JEB：专门的Android逆向工具
   - Frida：动态插桩，可Hook Native函数

#### 6.1.3 Frida Native Hook

```javascript
// Frida脚本：Hook Native函数
// 查找导出函数
const nativeLib = Module.load('libnative-lib.so');
console.log('Library base:', nativeLib.base);

// Hook导出函数
const targetFunc = Module.findExportByName('libnative-lib.so', 'Java_com_example_app_MainActivity_check');
Interceptor.attach(targetFunc, {
    onEnter: function(args) {
        // 打印参数
        console.log('check() called');
        console.log('  env:', args[0]);
        console.log('  thiz:', args[1]);
        console.log('  input:', args[2].readCString());
        
        // 保存参数供onLeave使用
        this.input = args[2].readCString();
    },
    onLeave: function(retval) {
        console.log('check() returned:', retval.toInt32());
        // 可以修改返回值
        // retval.replace(1);
    }
});

// Hook基于偏移的函数（未导出）
const funcOffset = 0x1234;
const funcAddr = nativeLib.base.add(funcOffset);
Interceptor.attach(funcAddr, {
    onEnter: function(args) {
        console.log('Secret function called');
        // 打印参数...
    }
});
```

### 6.2 MIPS/IoT逆向

#### 6.2.1 MIPS架构特点

**MIPS指令集特点：**
- 32个通用寄存器
- 固定长度32位指令
- 延迟槽（Delay Slot）：分支指令后面的一条指令总是执行
- 寄存器$0恒为0

**常用寄存器：**
- $v0-$v1：返回值
- $a0-$a3：参数
- $t0-$t9：临时寄存器（调用者保存）
- $s0-$s7：保存寄存器（被调用者保存）
- $sp：栈指针
- $ra：返回地址
- $gp：全局指针

**MIPS调用约定：**
- 参数：$a0-$a3（前4个），其余压栈
- 返回值：$v0（64位用$v0:$v1）
- 返回地址：$ra寄存器

#### 6.2.2 IoT固件逆向流程

**1. 获取固件**
- 从官网下载
- 从设备中Dump（UART/SPI Flash）
- 流量抓取

**2. 解包固件**
```bash
# 使用binwalk分析固件
binwalk firmware.bin

# 提取文件系统
binwalk -e firmware.bin

# 使用firmadyne模拟
# https://github.com/firmadyne/firmadyne
```

**3. 分析文件系统**
- 查找Web管理界面源码
- 查找配置文件
- 查找硬编码的凭证
- 查找可执行文件

**4. 逆向关键二进制**
- 使用QEMU运行MIPS程序
- 使用IDA/Ghidra分析
- 动态调试（QEMU + GDB）

#### 6.2.3 QEMU用户模式模拟

```bash
# 安装QEMU
sudo apt install qemu-user qemu-user-static

# 直接运行MIPS程序
qemu-mips ./mips_program

# 使用库文件运行
qemu-mips -L ./firmware_rootfs/ ./mips_program

```

### 6.3 .NET逆向进阶

#### 6.3.1 .NET基础

**.NET程序结构：**
- CIL（Common Intermediate Language）：公共中间语言
- CLR（Common Language Runtime）：公共语言运行时
- 程序集（Assembly）：.NET编译的基本单元

**元数据：**
- .NET程序包含丰富的元数据
- 类型、方法、字段、属性等信息都保留
- 反编译可以得到几乎完整的源代码

#### 6.3.2 .NET反编译工具

**1. dnSpy**
- 功能最强大的.NET反编译调试工具
- 支持编辑和调试
- 开源免费
- 下载地址：https://github.com/dnSpy/dnSpy

**2. ILSpy**
- 开源.NET反编译器
- 轻量级
- 支持插件

**3. de4dot**
- .NET脱混淆工具
- 支持多种混淆器
- 命令行工具

```bash
# 使用de4dot脱混淆
de4dot.exe obfuscated.exe -o cleaned.exe
```

#### 6.3.3 常见.NET混淆与对抗

**常见混淆手段：**
1. **名称混淆**：类名、方法名、变量名替换为无意义字符
2. **控制流混淆**：修改控制流，增加分析难度
3. **字符串加密**：加密字符串常量
4. **代理调用**：通过代理方法间接调用
5. **代码虚拟化**：将IL转为自定义虚拟机指令

**对抗方法：**
1. **de4dot**：自动处理大部分混淆
2. **手动还原**：对于特殊混淆，需要手动分析
3. **动态调试**：使用dnSpy调试，观察运行时行为

### 6.4 Java逆向进阶

#### 6.4.1 Java字节码基础

**JVM内存结构：**
- 方法区：类信息、常量、静态变量
- 堆：对象实例
- 栈：方法调用栈帧
- 本地方法栈：Native方法

**JVM指令特点：**
- 基于栈的虚拟机
- 指令长度可变
- 类型指令（不同类型有不同指令）

**常见指令：**
```
; 常量加载
iconst_0    ; int常量0入栈
bipush 10   ; byte值入栈
ldc "str"   ; 常量池项入栈

; 加载存储
iload_0     ; 第0个int局部变量入栈
istore_1    ; 栈顶int存入第1个局部变量
aload_0     ; 第0个引用局部变量入栈（this）

; 运算
iadd        ; int加法
isub        ; int减法
imul        ; int乘法

; 对象操作
new ClassName       ; 创建对象
invokespecial       ; 调用构造方法/私有方法
invokevirtual       ; 调用虚方法
invokestatic        ; 调用静态方法
invokeinterface     ; 调用接口方法

; 控制流
goto label          ; 无条件跳转
ifeq label          ; 等于0时跳转
if_icmp_eq label    ; int相等时跳转
```

#### 6.4.3 Java混淆与脱壳

**常见混淆器：**
- **ProGuard**：最常见的混淆器，Android默认使用
- **DashO**：商业混淆器
- **Zelix KlassMaster**：商业混淆器
- **Allatori**：商业混淆器

**对抗方法：**
1. **反混淆工具**：针对特定混淆器的脱混淆工具
2. **动态分析**：使用调试器跟踪执行
3. **Agent技术**：使用Java Agent在运行时Hook

```java
// Java Agent示例：Hook方法调用
import java.lang.instrument.Instrumentation;
import java.lang.instrument.ClassFileTransformer;
import java.security.ProtectionDomain;

public class MyAgent {
    public static void premain(String agentArgs, Instrumentation inst) {
        inst.addTransformer(new ClassFileTransformer() {
            @Override
            public byte[] transform(ClassLoader loader, String className,
                    Class<?> classBeingRedefined, ProtectionDomain protectionDomain,
                    byte[] classfileBuffer) {
                // 可以在这里修改字节码
                System.out.println("Loading class: " + className);
                return null; // 返回null表示不修改
            }
        });
    }
}
```
