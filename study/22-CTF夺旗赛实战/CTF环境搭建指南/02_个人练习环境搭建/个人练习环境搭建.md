# 个人练习环境搭建

### 2.1 虚拟化平台选择

虚拟化是搭建CTF练习环境的基础。选择合适的虚拟化平台非常重要。

#### 2.1.1 VMware Workstation / Fusion

**优点：**
- 性能优秀，资源占用合理
- 功能丰富，支持快照、克隆、共享等
- 网络配置灵活
- 兼容性好，支持各种操作系统
- 稳定性高

**缺点：**
- 商业软件，需要付费
- 体积较大

**适用场景：**
- Windows/Mac用户
- 需要稳定可靠的虚拟化环境
- 对性能要求较高

**下载地址：**
- Windows: https://www.vmware.com/products/workstation-pro.html
- Mac: https://www.vmware.com/products/fusion.html

#### 2.1.2 VirtualBox

**优点：**
- 完全免费开源
- 跨平台支持（Windows/Linux/Mac）
- 轻量级，安装简单
- 基本功能齐全

**缺点：**
- 性能略逊于VMware
- 高级功能较少
- 偶尔有兼容性问题

**适用场景：**
- 预算有限的用户
- Linux用户
- 简单的虚拟化需求

**下载地址：**
https://www.virtualbox.org/

#### 2.1.3 KVM/QEMU

**优点：**
- Linux原生，性能最佳
- 完全免费开源
- 高度可定制化
- 支持命令行管理

**缺点：**
- 只支持Linux
- 配置相对复杂
- 学习曲线较陡

**适用场景：**
- Linux高级用户
- 需要高性能虚拟化
- 服务器环境部署

**安装命令：**
```bash
# Ubuntu/Debian
sudo apt install qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virt-manager

# CentOS/RHEL
sudo yum install qemu-kvm libvirt virt-install bridge-utils
```

#### 2.1.4 选择建议

| 用户类型 | 推荐平台 | 理由 |
|---------|---------|------|
| Windows用户 | VMware Workstation | 性能好，功能全，易用 |
| Mac用户 | VMware Fusion / Parallels | 兼容性好，性能优 |
| Linux用户 | KVM | 原生支持，性能最佳 |
| 预算有限 | VirtualBox | 免费开源，功能够用 |
| 服务器部署 | KVM / ESXi | 稳定可靠，管理方便 |

### 2.2 攻击机配置

攻击机是CTF选手的主要工作环境，需要精心配置。

#### 2.2.1 Kali Linux

Kali Linux是最流行的渗透测试发行版，预装了大量安全工具。

**下载地址：**
https://www.kali.org/get-kali/

**安装步骤：**

1. **下载镜像**：选择合适的版本（推荐64位完整版）
2. **创建虚拟机**：
   - 内存：建议4GB以上（推荐8GB）
   - 硬盘：建议60GB以上（推荐100GB）
   - CPU：建议2核以上（推荐4核）
   - 网络：NAT或桥接模式
3. **安装系统**：按照向导完成安装
4. **初始配置**：
   ```bash
   # 更新系统
   sudo apt update && sudo apt full-upgrade -y
   
   # 安装Open-VM-Tools（虚拟机增强工具）
   sudo apt install -y open-vm-tools-desktop
   
   # 设置中文环境
   sudo dpkg-reconfigure locales
   # 选择 zh_CN.UTF-8
   ```

**Kali Linux的优势：**
- 预装600+安全工具
- 活跃的社区和文档
- 定期更新
- 支持多种架构
- 有专门的CTF工具集

#### 2.2.2 Parrot Security OS

Parrot是另一个流行的安全发行版，基于Debian。

**特点：**
- 界面更美观
- 工具分类更清晰
- 对隐私保护更重视
- 资源占用略低于Kali
- 包含一些Kali没有的工具

**下载地址：**
https://www.parrotsec.org/

#### 2.2.3 自定义攻击机

高级用户可以基于自己喜欢的发行版定制攻击机环境。

**推荐基础系统：**
- Ubuntu Desktop
- Debian
- Arch Linux

**核心工具安装脚本：**
```bash
#!/bin/bash
# 自定义攻击机安装脚本（基于Ubuntu）

# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y \
    git vim tmux zsh curl wget net-tools \
    build-essential python3 python3-pip python3-venv \
    default-jdk golang rustc ruby perl \
    nmap masscan wireshark tcpdump \
    gdb gdb-multiarch radare2 \
    sqlmap hydra hashcat john \
    metasploit-framework \
    docker.io docker-compose

# Python工具
pip3 install --upgrade pip
pip3 install \
    requests beautifulsoup4 lxml \
    pwntools ropper capstone keystone unicorn \
    z3-solver angr \
    pycryptodome gmpy2 \
    flask django

# 安装常用工具
# Gobuster
go install github.com/OJ/gobuster/v3@latest

# ffuf
go install github.com/ffuf/ffuf/v2@latest

# 创建工作目录
mkdir -p ~/ctf/{web,pwn,re,crypto,misc,tools,wordlists}

# 下载字典
cd ~/ctf/wordlists
git clone https://github.com/danielmiessler/SecLists.git

# 配置zsh（可选）
chsh -s /bin/zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

echo "[*] Setup complete! Please reboot."
```

#### 2.2.4 攻击机配置最佳实践

1. **使用虚拟机快照**：
   - 安装完成后创建基础快照
   - 安装工具后创建工具快照
   - 每次重大更新前创建快照
   - 出现问题可快速回滚

2. **配置共享文件夹**：
   - 方便在宿主机和虚拟机间传输文件
   - VMware: 虚拟机设置 → 选项 → 共享文件夹
   - VirtualBox: 设备 → 共享文件夹

3. **网络配置**：
   - NAT模式：用于日常使用，访问互联网
   - 桥接模式：用于连接真实网络
   - 仅主机模式：用于靶机练习，隔离环境

4. **工具管理**：
   - 系统工具用apt管理
   - Python工具有pip和venv管理
   - 自定义工具放在~/tools目录
   - 定期更新所有工具

### 2.3 靶机部署

#### 2.3.1 VulnHub靶机

VulnHub提供了大量可下载的漏洞虚拟机，是CTF练习的重要资源。

**使用方法：**

1. **访问网站**：https://www.vulnhub.com/
2. **选择靶机**：根据难度和类型选择合适的靶机
3. **下载镜像**：通常是OVA格式或压缩包
4. **导入虚拟机**：
   - VMware: 文件 → 打开 → 选择OVA文件
   - VirtualBox: 管理 → 导入虚拟电脑
5. **配置网络**：建议使用仅主机模式（Host-Only）
6. **启动靶机**：开始练习

**推荐入门靶机：**
- Mr-Robot：入门级，适合新手
- Stapler：初级，涉及多种漏洞
- DC系列：循序渐进的系列靶机
- Hack The Box OSCP Prep：OSCP备考专用

**推荐中级靶机：**
- Blue：MS17-010经典漏洞
- Traverxec：Web漏洞+提权
- Brainfuck：多步攻击链
- Jeeves：Windows靶机

**推荐高级靶机：**
- CVE系列：真实CVE漏洞复现
- 红队相关靶机：模拟真实APT场景

#### 2.3.2 Hack The Box（HTB）

HTB是在线的渗透测试平台，不需要本地部署靶机。

**使用方式：**

1. **注册账号**：访问https://www.hackthebox.com/注册
2. **下载VPN配置**：接入HTB网络需要使用VPN
3. **连接VPN**：
   ```bash
   sudo openvpn your_username.ovpn
   ```
4. **选择靶机**：在平台上选择要挑战的靶机
5. **开始练习**：直接通过VPN访问靶机IP

**HTB的优势：**
- 靶机质量高，更新频繁
- 有活跃的社区和Writeup
- 有排名系统，可对比水平
- 有开始盒（Starting Point）适合新手

#### 2.3.3 本地靶场软件

除了单个靶机，还可以搭建综合性的本地靶场平台。

**1. OWASP Juice Shop**

OWASP Juice Shop是一个有意设计成不安全的Web应用，包含OWASP Top 10等各种漏洞。

```bash
# Docker快速部署
docker run --rm -p 3000:3000 bkimminich/juice-shop
```

**2. DVWA（Damn Vulnerable Web Application）**

经典的Web漏洞练习平台。

```bash
# Docker部署
docker run --rm -it -p 80:80 vulnerables/web-dvwa
```

**3. WebGoat**

OWASP出品的Web安全教学应用。

```bash
# Docker部署
docker run --rm -p 8080:8080 -p 9090:9090 webgoat/webgoat-8.0
```

**4. bWAPP**

一个包含100多种漏洞的Web应用。

```bash
# Docker部署
docker run --rm -p 80:80 raesene/bwapp
```

### 2.4 网络配置与隔离

#### 2.4.1 网络模式选择

| 网络模式 | 说明 | 安全性 | 适用场景 |
|---------|------|--------|---------|
| NAT | 虚拟机通过宿主机上网 | 较高 | 日常使用，工具更新 |
| 桥接 | 虚拟机直接连接物理网络 | 较低 | 需要真实IP时 |
| 仅主机 | 虚拟机只能和宿主机通信 | 最高 | 靶机练习，安全隔离 |
| 内部网络 | 虚拟机之间互通，与宿主机隔离 | 最高 | 多台靶机互访 |

#### 2.4.2 推荐网络架构

```
宿主机（物理机）
  │
  ├── VM-1: Kali Linux（攻击机）
  │   ├── 网卡1: NAT（访问互联网）
  │   └── 网卡2: 仅主机（连接靶机）
  │
  ├── VM-2: 靶机1
  │   └── 网卡1: 仅主机
  │
  ├── VM-3: 靶机2
  │   └── 网卡1: 仅主机
  │
  └── VM-4: 靶机3
      └── 网卡1: 仅主机
```

**配置步骤（VirtualBox）：**

1. 创建仅主机网络：
   - 管理 → 主机网络管理器 → 创建
   - 记下网段（如192.168.56.0/24）

2. 配置攻击机双网卡：
   - 网卡1：NAT
   - 网卡2：仅主机（选择刚才创建的网络）

3. 配置靶机单网卡：
   - 网卡1：仅主机（同一个网络）

4. 验证连接：
   - 攻击机可以访问互联网
   - 攻击机可以ping通靶机
   - 靶机无法访问互联网（安全隔离）

#### 2.4.3 网络安全注意事项

1. **永远不要把有漏洞的靶机直接暴露在公网上**
2. **练习时使用仅主机或内部网络模式**
3. **定期检查靶机网络配置**
4. **不要在生产环境中运行CTF靶机**
5. **使用完靶机后及时关闭**
