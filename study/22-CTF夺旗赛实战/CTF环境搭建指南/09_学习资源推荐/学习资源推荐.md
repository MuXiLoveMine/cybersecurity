# 学习资源推荐

### 8.1 书籍推荐

- 《Web安全深度剖析》
- 《白帽子讲Web安全》
- 《Metasploit渗透测试指南》
- 《Kali Linux渗透测试技术详解》

#### 8.1.2 进阶书籍

- 《0day安全：软件漏洞分析技术》

- 《漏洞战争》
- 《Python灰帽子》
- 《Linux内核设计与实现》

### 8.2 在线课程

- **Hack The Box Academy**：系统化的渗透测试课程

- **PortSwigger Web Security Academy**：Web安全免费课程
- **pwn.college**：Pwn学习平台
- **Cryptopals**：密码学挑战
