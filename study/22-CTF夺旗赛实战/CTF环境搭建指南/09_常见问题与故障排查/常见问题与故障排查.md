# 常见问题与故障排查

### 7.1 虚拟机常见问题

#### 7.1.1 虚拟机无法启动

**可能原因：**
1. 虚拟化未开启
2. 内存不足
3. 磁盘空间不足
4. 虚拟机文件损坏

**解决方法：**
```
1. 检查BIOS/UEFI中VT-x/AMD-V是否开启
2. 关闭其他占用内存的程序
3. 清理磁盘空间
4. 从备份/快照恢复
```

#### 7.1.2 网络连接问题

**NAT模式无法上网：**
- 检查宿主机网络是否正常
- 检查虚拟机网卡是否启用
- 检查虚拟机IP配置：`ip addr`
- 检查DNS配置：`cat /etc/resolv.conf`
- 尝试重启网络：`sudo systemctl restart networking`

**仅主机模式无法互通：**
- 确认虚拟机在同一个仅主机网络
- 检查IP地址是否在同一网段
- 检查防火墙是否阻止通信
- 使用`ping`测试连通性

#### 7.1.3 虚拟机性能优化

**提高性能的方法：**
1. 分配更多内存和CPU
2. 安装虚拟机增强工具（VMware Tools / Guest Additions）
3. 使用SSD存储
4. 关闭不必要的服务
5. 使用轻量级桌面环境或纯命令行

### 7.2 Docker常见问题

#### 7.2.1 端口冲突

**问题：**启动容器时报端口已被占用
```
Error starting userland proxy: listen tcp 0.0.0.0:80: bind: address already in use.
```

**解决：**
```bash
# 查找占用端口的进程
sudo lsof -i :80
sudo netstat -tulnp | grep 80

# 停止占用端口的进程，或更换映射端口
docker run -p 8080:80 <image>
```

#### 7.2.2 容器启动失败

**排查步骤：**
```bash
# 查看容器日志
docker logs <container_name>

# 查看所有容器状态
docker ps -a

# 以交互模式启动调试
docker run -it --entrypoint /bin/bash <image>
```

#### 7.2.3 镜像下载慢

**解决方法：**
```bash
# 配置国内镜像源
# 创建或编辑 /etc/docker/daemon.json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ]
}

# 重启Docker
sudo systemctl restart docker
```

### 7.3 靶机常见问题

#### 7.3.1 找不到靶机IP

**解决方法：**
```bash
# 使用arp-scan扫描
sudo arp-scan -l

# 使用nmap扫描
nmap -sn 192.168.56.0/24

# 使用netdiscover
sudo netdiscover -r 192.168.56.0/24
```

#### 7.3.2 靶机无法启动

**常见原因：**
- 虚拟机文件不完整
- 虚拟硬件配置不兼容
- 磁盘空间不足

**解决方法：**
- 重新下载靶机文件
- 调整虚拟机配置（降低内存等）
- 检查磁盘空间
- 查看虚拟机日志

### 7.4 工具安装常见问题

#### 7.4.1 依赖缺失

**解决方法：**
```bash
# 更新包列表
sudo apt update

# 修复损坏的依赖
sudo apt --fix-broken install

# 安装build-essential（编译依赖）
sudo apt install build-essential

# Python依赖
pip install --upgrade pip
pip install setuptools wheel
```

#### 7.4.2 编译失败

**常见原因：**
- 缺少编译工具
- 缺少开发库
- 版本不兼容

**解决方法：**
```bash
# 安装基础编译工具
sudo apt install build-essential cmake

# 根据错误信息安装对应的开发库
# 例如：缺少ssl库
sudo apt install libssl-dev
```
