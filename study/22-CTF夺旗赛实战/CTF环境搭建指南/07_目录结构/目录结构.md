### 6.2 协作平台配置

#### 6.2.1 即时通信

**推荐方案：**
- **Discord**：功能强大，支持语音、文字、文件共享
- **飞书/钉钉**：国内常用，功能全面
- **腾讯会议**：语音沟通方便
- **Mattermost**：自建开源团队通信平台

**自建Mattermost：**
```bash
# 使用Docker部署
docker run --name mattermost -d \
  --publish 8065:8065 \
  --add-host dockerhost:127.0.0.1 \
  mattermost/mattermost-preview
```

#### 6.2.2 文档协作

**推荐方案：**
- **Notion**：功能强大的笔记和知识库
- **语雀**：国内优质文档平台
- **飞书文档**：实时协作，国内访问快

**自建Wiki.js：**
```bash
# 使用Docker部署
docker run -d \
  -p 8080:3000 \
  -e "DB_TYPE=sqlite" \
  -v /path/to/data:/wiki/data \
  ghcr.io/requarks/wiki:2
```

### 6.3 远程调试环境

#### 6.3.1 SSH跳板机

团队共用的SSH跳板机，方便远程访问和协作。

```bash
# 配置跳板机
sudo apt install openssh-server

# 创建团队账号
sudo useradd -m teamuser
sudo passwd teamuser

# 配置SSH密钥登录
mkdir -p /home/teamuser/.ssh
cat id_rsa.pub >> /home/teamuser/.ssh/authorized_keys
chmod 700 /home/teamuser/.ssh
chmod 600 /home/teamuser/.ssh/authorized_keys
chown -R teamuser:teamuser /home/teamuser/.ssh

# 安全配置（/etc/ssh/sshd_config）
PermitRootLogin no
PasswordAuthentication no
AllowUsers teamuser
```

#### 6.3.2 终端共享

**tmate：**
```bash
# 安装
sudo apt install tmate

# 启动共享终端
tmate

# 分享SSH会话链接给队友
```

**tmux协作：**
```bash
# 安装tmux
sudo apt install tmux

# 创建共享会话
tmux new -s shared

# 其他人加入
tmux attach -t shared
```

#### 6.3.3 远程桌面

**VNC：**
```bash
# 安装
sudo apt install tightvncserver

# 设置密码
vncpasswd

# 启动
vncserver :1 -geometry 1920x1080 -depth 24
```

**Guacamole（Web远程桌面）：**
```bash
# 使用Docker部署
docker run --name guacd -d guacamole/guacd
docker run --name guacamole \
  --link guacd:guacd \
  -e MYSQL_HOSTNAME=mysql \
  -e MYSQL_DATABASE=guacamole_db \
  -e MYSQL_USER=guacamole_user \
  -e MYSQL_PASSWORD=password \
  -p 8080:8080 \
  -d guacamole/guacamole
```
