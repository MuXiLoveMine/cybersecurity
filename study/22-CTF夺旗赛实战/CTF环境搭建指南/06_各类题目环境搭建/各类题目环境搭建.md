# 各类题目环境搭建

### 5.1 Web题环境搭建

#### 5.1.1 PHP环境

**使用XAMPP（Windows/Mac/Linux）：**
- 下载地址：https://www.apachefriends.org/
- 包含Apache + MySQL + PHP + Perl
- 一键安装，适合新手

**手动搭建（Linux）：**
```bash
# 安装Apache + PHP + MySQL
sudo apt install apache2 php mysql-server php-mysql libapache2-mod-php

# 启动服务
sudo systemctl start apache2
sudo systemctl start mysql

# 测试
echo "<?php phpinfo(); ?>" | sudo tee /var/www/html/info.php
# 访问 http://localhost/info.php
```

#### 5.1.2 Java环境

**Tomcat部署：**
```bash
# 安装Tomcat
sudo apt install tomcat9 tomcat9-admin

# 配置管理用户
sudo nano /etc/tomcat9/tomcat-users.xml
# 添加：
# <user username="admin" password="password" roles="manager-gui,admin-gui"/>

# 启动
sudo systemctl start tomcat9

# 访问 http://localhost:8080
```

**Spring Boot应用：**
```bash
# 使用Maven构建
mvn clean package

# 运行
java -jar target/app.jar
```

#### 5.1.3 Python环境

**Flask应用：**
```bash
# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装Flask
pip install flask

# 简单示例
cat > app.py << 'EOF'
from flask import Flask
app = Flask(__name__)

@app.route('/')

    return 'Hello, CTF!'

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
EOF

# 运行
python app.py
```

**Django应用：**
```bash
pip install django
django-admin startproject myproject
cd myproject
python manage.py runserver 0.0.0.0:8000
```

#### 5.2.3 远程Pwn题部署

使用socat部署远程Pwn题：

```bash
# 安装socat
sudo apt install socat

# 启动服务
socat TCP-LISTEN:10000,reuseaddr,fork EXEC:./challenge,pty,ctty,echo=0 &

# 使用xinetd（更稳定）
sudo apt install xinetd

# 配置文件 /etc/xinetd.d/pwn
cat > /etc/xinetd.d/pwn << 'EOF'
service pwn
{
    disable = no
    socket_type = stream
    protocol = tcp
    wait = no
    user = ctf
    server = /home/ctf/challenge
    port = 10000
    type = UNLISTED
    per_source = 10
    cps = 100 30
}
EOF

# 重启xinetd
sudo systemctl restart xinetd
```

### 5.3 逆向题环境

#### 5.3.1 静态分析工具

**IDA Pro：**
- 业界标准反汇编工具
- 商业软件，价格较高
- 有免费版（Freeware）和教育版
- 下载地址：https://hex-rays.com/ida-pro/

**Ghidra：**
- NSA开源的逆向工程工具
- 功能强大，完全免费
- 支持多平台
- 下载地址：https://ghidra-sre.org/

**Radare2：**
- 开源逆向工程框架
- 命令行为主，学习曲线较陡
- 功能丰富，高度可定制
- 安装：`sudo apt install radare2`

**Binary Ninja：**
- 现代化逆向平台
- 界面友好，API强大
- 商业软件，有个人免费版
- 下载地址：https://binary.ninja/

#### 5.3.2 动态调试环境

**Linux调试：**
- GDB + Pwndbg（推荐）
- GDB + GEZ
- LLDB

**Windows调试：**
- x64dbg（免费，推荐）
- OllyDbg（经典，但只支持32位）
- WinDbg（微软官方）
- IDA调试器

**安装x64dbg：**
- 下载地址：https://x64dbg.com/
- 解压即可使用
- 推荐安装插件：Scylla（脱壳）、xAnalyzer（分析）

#### 5.3.3 .NET/Java逆向环境

**.NET逆向：**
- dnSpy：.NET反编译调试工具（免费）
- ILSpy：开源.NET反编译器
- .NET Reflector：商业工具

**Java逆向：**
