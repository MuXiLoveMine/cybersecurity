# 学习总结

### 12.1 Crypto方向学习路线

```
密码学学习路线:
1. 理解对称/非对称加密原理
2. 掌握古典密码（凯撒、维吉尼亚、栅栏等）
3. 深入学习RSA原理和攻击
4. 学习AES各模式及攻击
5. 掌握哈希算法及长度扩展攻击
6. 学习椭圆曲线密码
7. 了解格密码和后量子密码
```

### 12.2 Misc方向学习路线

```
Misc学习路线:
1. 掌握各种编码解码（Base、URL、Morse等）
2. 学习隐写术（图片、音频、文档）
3. 熟练使用Wireshark进行流量分析
4. 学习取证技术（磁盘、内存、日志）
5. 了解硬件安全和侧信道分析
6. 培养综合分析能力和直觉
```

### 12.3 常用工具速查

```
Crypto工具:
├── SageMath (数学计算)
├── PyCryptodome (Python密码学库)
├── RsaCtfTool (RSA自动攻击)
├── HashPumpy (哈希长度扩展)
├── yafu (大数分解)
└── hashcat (哈希破解)

Misc工具:
├── CyberChef (编码解码)
├── StegSolve (图片隐写)
├── zsteg (PNG/BMP隐写)
├── Wireshark (流量分析)
├── Audacity (音频分析)
├── Volatility (内存取证)
├── foremost (文件恢复)
├── binwalk (固件分析)
└── 010 Editor (十六进制编辑)
```

---

> **安全提示**：密码学和隐写技术仅用于CTF竞赛和安全研究。破解他人系统的加密数据属于违法行为。请始终在授权环境中学习，遵守相关法律法规。
