# 已知p、q、e、c，解密
p = 1234567891
q = 9876543211

# === 维纳攻击 (Wiener's Attack) ===
# 当d很小时（e很大）
def wiener_attack(e, n):
    # 使用连分数展开找d
    cf = continued_fraction(e / n)
    convergents = cf.convergents()
    for conv in convergents:
        k = conv.numerator()
        d = conv.denominator()
        if k == 0:
            continue
        phi = (e * d - 1) // k
        # 检查phi是否合理
        # 解二次方程: x^2 - (n-phi+1)x + n = 0
        b = n - phi + 1
        disc = b^2 - 4 * n
        if disc >= 0 and is_square(disc):
            return d
    return None

# === 共模攻击 (Common Modulus) ===
# 同一n，两个不同e加密同一明文
def common_modulus(c1, c2, e1, e2, n):
    g, s1, s2 = xgcd(e1, e2)
    if g != 1:
        return None
    # m = c1^s1 * c2^s2 mod n
    m = (pow(c1, s1, n) * pow(c2, s2, n)) % n
    return m

**4. PNG 隐写检测**

```python
# 检查PNG文件结构
# 常见隐写手法: 末尾追加数据、IDAT块后追加、tEXt块

import struct

def analyze_png(filepath):
    with open(filepath, 'rb') as f:
        data = f.read()
    
    # PNG签名
    print(f"PNG signature: {data[:8].hex()}")
    
    # 解析chunk
    pos = 8
    while pos < len(data):
        length = struct.unpack('>I', data[pos:pos+4])[0]
        chunk_type = data[pos+4:pos+8].decode('latin1')
        chunk_data = data[pos+8:pos+8+length]
        crc = struct.unpack('>I', data[pos+8+length:pos+12+length])[0]
        
        print(f"Chunk: {chunk_type}, size: {length}")
        
        # 检查文本块
        if chunk_type == 'tEXt' or chunk_type == 'zTXt':
            print(f"  Text data: {chunk_data[:100]}")
        
        pos += 12 + length
    
    # 检查文件末尾是否有多余数据
    print(f"File size: {len(data)}")
    print(f"Last 50 bytes: {data[-50:].hex()}")

# 常用检测点:
# 1. IEND块后是否有多余数据
# 2. 是否有未知chunk类型
# 3. IDAT数据大小是否异常
# 4. PLTE调色板是否有异常
```

| URL编码 | %xx 格式 | CyberChef / urllib |
| HTML实体 | &name; 或 &#数字; | CyberChef |
| Unicode | \uXXXX 或 U+XXXX | CyberChef |
| 摩尔斯码 | . 和 -，用空格分隔 | CyberChef |
| 培根密码 | A/B 或 0/1 两种字符 | CyberChef |
| 栅栏密码 | 按列重新排列 | CyberChef / 手动 |
| 凯撒密码 | 字母移位 | CyberChef / ROT |
| 维吉尼亚 | 多表替换，有密钥 | CyberChef |

**2. 编码组合检测思路**

```
1. 看长度和字符集
   - 只有0和1 → 二进制 → 转ASCII
   - 只有A-Z和2-7 → Base32
   - 有+/和结尾= → Base64
   - 有% → URL编码
   - 有&# → HTML实体

2. 多层编码嵌套
   - Base64 解完还是Base64 → 多层
   - URL编码的Base64 → 先URL解码
   - 双重Hex → hex解码两次

3. 特殊编码
   - Brainfuck: +-<>[].,
   - Ook!: Ook. Ook? Ook!
   - JSFuck: []()!+
   - Whitespace: 空格/制表符/换行
   - 八卦/阴阳/盲文/猪圈密码等

4. 图片中的编码
   - 二维码 → 扫描
   - 条形码 → 扫描
   - 像素颜色编码 → 每像素存数据
   - 字符画/ASCII Art
```

### 六、Crypto/Misc 解题工作流

```
密码学解题流程:
1. 识别加密方式
   ├── 看题目提示 / 文件名
   ├── 分析密文特征（长度、字符集、格式）
   └── 搜索特征常量/字符串
2. 确定攻击面
   ├── 密钥太小 → 暴力破解
   ├── 算法实现缺陷 → 利用漏洞
   ├── 有已知明文 → 已知明文攻击
   └── 有两个相关密文 → 选择密文等
3. 选择工具
   ├── 简单密码 → CyberChef
   ├── RSA → RsaCtfTool / SageMath
   ├── 格/LLL → SageMath
   └── 哈希 → hashcat
4. 编写脚本 / 使用工具
5. 验证结果

Misc解题流程:
1. 文件分析
   ├── file 查看类型
   ├── binwalk / foremost 扫描隐藏文件
   ├── strings 查看可打印字符串
   └── 十六进制查看文件头尾
2. 分类处理
   ├── 图片 → StegSolve / zsteg / binwalk
   ├── 音频 → Audacity / 频谱分析
   ├── 流量 → Wireshark / tshark
   ├── 内存 → Volatility
   ├── 磁盘 → FTK / Autopsy
   └── 编码 → CyberChef
3. 找线索
   ├── 搜索 "flag" / "ctf" / "key"
   ├── 检查文件末尾 / 注释 / 元数据
   ├── 对比正常文件的差异
   └── 关注异常大小/格式
4. 组合分析
   ├── 多文件关联
   ├── 时间线分析
   └── 逻辑推理
```
