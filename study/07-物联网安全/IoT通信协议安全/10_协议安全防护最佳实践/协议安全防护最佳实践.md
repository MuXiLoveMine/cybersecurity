# 协议安全防护最佳实践

### 10.1 通用防护原则

1. **使用加密传输**：所有通信必须加密，禁止明文传输敏感数据
2. **强身份认证**：使用强认证机制，避免弱口令和默认凭证
3. **最小权限原则**：只授予必要的访问权限
4. **输入验证**：所有输入数据必须验证，防止注入攻击
5. **安全更新**：协议实现需及时更新修复漏洞
6. **安全审计**：记录关键操作，便于安全审计

### 10.2 各协议安全配置对比

| 协议 | 默认端口 | 加密方式 | 认证方式 | 安全等级 |
|------|---------|---------|---------|---------|
| MQTT | 1883 / 8883 (TLS) | TLS | 用户名密码/证书 | 中~高（取决于配置） |
| CoAP | 5683 / 5684 (DTLS) | DTLS / OSCORE | PSK/证书 | 中~高（取决于配置） |
| HTTP/HTTPS | 80 / 443 | TLS | 多种方式 | 中~高（取决于配置） |
| LoRaWAN | 无线 | AES-128 | 设备密钥认证 | 中~高 |
| NB-IoT | 蜂窝 | 蜂窝加密 | SIM 卡认证 | 高（空口） |
| ZigBee | 2.4GHz 无线 | AES-128 | 网络密钥/链路密钥 | 低~中（取决于配置） |
| BLE | 2.4GHz 无线 | AES-CCM | 配对认证 | 低~高（取决于配对方式） |

#### 2. Mosquitto 客户端常用命令

```bash
# ===== 安装 Mosquitto 客户端 =====
# Ubuntu/Debian
sudo apt install mosquitto-clients

# CentOS/RHEL
sudo yum install mosquitto

# macOS
brew install mosquitto

# ===== 基本连接测试 =====
# 匿名连接测试（检查是否允许匿名访问）
mosquitto_sub -h 192.168.1.100 -t '#' -v --connection-message 1

# 指定端口连接（MQTT 默认 1883，MQTTS 8883）
mosquitto_sub -h 192.168.1.100 -p 1883 -t 'test' -v

# 用户名密码认证连接
mosquitto_sub -h 192.168.1.100 -u admin -P password -t '#' -v

# MQTT over TLS 连接
mosquitto_sub -h mqtt.example.com -p 8883 --cafile ca.crt -t '#' -v

# 客户端 ID 伪装
mosquitto_sub -h 192.168.1.100 -i "client-sensor-001" -t '#' -v

# ===== 订阅主题 =====
# 订阅所有主题（# 通配符）
mosquitto_sub -h 192.168.1.100 -t '#' -v

# 订阅多层通配符
mosquitto_sub -h 192.168.1.100 -t 'sensors/+/temperature' -v
mosquitto_sub -h 192.168.1.100 -t 'devices/#/status' -v

# 订阅并保存到文件
mosquitto_sub -h 192.168.1.100 -t '#' -v | tee mqtt_messages.log

# ===== 发布消息 =====
# 发布简单消息
mosquitto_pub -h 192.168.1.100 -t 'test/topic' -m 'Hello MQTT'

# 发布 JSON 消息
mosquitto_pub -h 192.168.1.100 -t 'device/command' \
  -m '{"action":"reboot", "device":"sensor-001"}'

# 发布保留消息（新订阅者会立即收到）
mosquitto_pub -h 192.168.1.100 -t 'config/device' \
  -m 'default_config' -r

# 发布 QoS 1/2 消息
mosquitto_pub -h 192.168.1.100 -t 'critical/alarm' -m 'ALERT' -q 2

# 从文件发布消息
mosquitto_pub -h 192.168.1.100 -t 'firmware/update' -f update.bin

# ===== 安全测试命令 =====
# 测试匿名发布权限
mosquitto_pub -h 192.168.1.100 -t 'admin/command' -m 'test' -d 2>&1

# 暴力破解密码（使用 patator 或 hydra）
patator mqtt_login host=192.168.1.100 port=1883 \
  user=FILE0 password=FILE1 0=users.txt 1=passwords.txt -x ignore:code=0

# 测试 MQTT 暴力认证
# 使用 mqtt-brute 脚本
for pass in $(cat passwords.txt); do
  mosquitto_sub -h 192.168.1.100 -u admin -P "$pass" \
    -t 'test' -C 1 -W 1 2>/dev/null && echo "Found: $pass" && break
done

# ===== MQTT 5.0 新特性测试 =====
# 测试用户属性
mosquitto_pub -h 192.168.1.100 -t 'test' -m 'hello' \
  -D PUBLISH user-property key1=value1

# 测试共享订阅
mosquitto_sub -h 192.168.1.100 -t '$share/group1/sensors/#' -v
```

#### 4. MQTT Broker 安全加固命令

```bash
# ===== Mosquitto 安全配置 =====
# 配置文件 /etc/mosquitto/mosquitto.conf

# 1. 禁止匿名访问
cat >> /etc/mosquitto/mosquitto.conf << 'EOF'
# 禁止匿名访问
allow_anonymous false

# 启用密码文件认证
password_file /etc/mosquitto/passwd
EOF

# 创建密码文件并添加用户
mosquitto_passwd -c /etc/mosquitto/passwd admin
mosquitto_passwd /etc/mosquitto/passwd user1

# 2. 启用 ACL（访问控制列表）
cat >> /etc/mosquitto/mosquitto.conf << 'EOF'
# ACL 文件
acl_file /etc/mosquitto/acl
EOF

# 创建 ACL 配置文件
cat > /etc/mosquitto/acl << 'EOF'
# 管理员所有权限
user admin
topic readwrite #

# 普通用户只能读写自己的主题
pattern readwrite devices/%u/#

# 所有用户可读取公告主题
topic read announcement/#
EOF

# 3. 启用 TLS 加密
cat >> /etc/mosquitto/mosquitto.conf << 'EOF'
# TLS 监听器
listener 8883
cafile /etc/mosquitto/ca.crt
certfile /etc/mosquitto/server.crt
keyfile /etc/mosquitto/server.key

# 要求客户端证书认证（双向认证）
require_certificate true
use_identity_as_username true
EOF

# 生成自签名证书
openssl req -new -x509 -days 365 -extensions v3_ca \
  -keyout ca.key -out ca.crt

openssl genrsa -out server.key 2048
openssl req -new -out server.csr -key server.key
openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key \
  -CAcreateserial -out server.crt -days 360

# 重启服务
systemctl restart mosquitto
```

#### 2. libcoap 客户端常用命令

```bash
# ===== 安装 libcoap =====
# Ubuntu/Debian
sudo apt install libcoap2 libcoap2-dev coap-client

# 源码编译
git clone https://github.com/obgm/libcoap.git
cd libcoap
./autogen.sh
./configure --enable-documentation=no --with-gnutls
make
sudo make install

# ===== 基本请求 =====
# GET 请求（获取资源）
coap-client -m get coap://192.168.1.100/.well-known/core
coap-client -m get coap://192.168.1.100/sensors/temperature

# 详细输出（包含请求响应详情）
coap-client -m get -v 9 coap://192.168.1.100/status

# POST 请求（创建/更新资源）
coap-client -m post -e "value=25.5" coap://192.168.1.100/sensors/temperature

# PUT 请求（更新资源）
coap-client -m put -e "new_config" coap://192.168.1.100/config

# DELETE 请求（删除资源）
coap-client -m delete coap://192.168.1.100/temp/sensor1

# ===== 资源发现 =====
# 发现设备所有资源
coap-client -m get coap://192.168.1.100/.well-known/core

# 使用 Uri-Query 过滤
coap-client -m get 'coap://192.168.1.100/.well-known/core?rt=sensor'

# ===== 观察模式 (Observe) =====
# 订阅资源变化（观察模式）
coap-client -m get -s 10 coap://192.168.1.100/sensors/temperature
# -s 10 表示观察 10 秒，-s 0 无限观察

# ===== 块传输 =====
# 块传输（大资源）
coap-client -m get -b 64 coap://192.168.1.100/firmware

# ===== DTLS 加密 =====
# DTLS 预共享密钥连接
coap-client -m get -u client_identity -k secret_key \
  coaps://192.168.1.100/sensors/temperature

# DTLS 证书认证
coap-client -m get -c client.crt -j client.key -r ca.crt \
  coaps://192.168.1.100/status

# ===== 安全测试命令 =====
# 测试匿名访问
coap-client -m get coap://192.168.1.100/admin/config 2>&1

# 测试不安全的方法（PUT/DELETE）
coap-client -m put -e "test" coap://192.168.1.100/config
coap-client -m delete coap://192.168.1.100/sensor001

# 测试资源路径遍历
coap-client -m get coap://192.168.1.100/../etc/passwd 2>&1

# 测试缓冲区溢出（长 URI）
LONG_URI=$(python3 -c 'print("A"*2000)')
coap-client -m get "coap://192.168.1.100/$LONG_URI" 2>&1
```

```bash

# ===== 测试脚本示例 =====
cat > coap_scanner.py << 'EOF'
from coapthon.client.helperclient import HelperClient
import sys

target = sys.argv[1]
client = HelperClient(server=(target, 5683))

# 常见 CoAP 资源路径字典
common_paths = [
    '.well-known/core',
    'sensors',
    'actuators',
    'status',
    'config',
    'admin',
    'api',
    'v1',
    'device',
    'info',
    'firmware',
    'time',
    'test',
    'auth',
    'login'
]

print(f"Scanning CoAP resources on {target}...")
for path in common_paths:
    try:
        response = client.get(path)
        if response:
            print(f"[+] /{path} - Code: {response.code}")
            if response.payload:
                print(f"    Payload: {response.payload[:100]}")
    except Exception as e:
        pass

client.stop()
EOF

python3 coap_scanner.py 192.168.1.100
```

#### 4. CoAP 安全测试方法

```bash
# ===== Nmap CoAP 发现 =====
# CoAP 服务发现（UDP 5683）
nmap -sU -p 5683 --script coap-resources 192.168.1.100

# ===== Wireshark CoAP 过滤 =====
# 过滤 CoAP 流量
# coap

# 过滤 GET 请求
# coap.code == 1

# 过滤 2.05 Content 响应
# coap.code == 69

# 过滤 Token
# coap.token

# ===== DTLS 安全测试 =====
# 测试 DTLS 支持
openssl s_client -dtls1_2 -connect 192.168.1.100:5684 -quiet

# 测试 DTLS 密码套件
sslyze --dtls 192.168.1.100:5684

# 使用 coap-client 测试 DTLS PSK
coap-client -m get -u test -k test coaps://192.168.1.100/

# ===== Fuzzing 测试 =====
# 使用 boofuzz 进行 CoAP 模糊测试
pip install boofuzz

cat > coap_fuzzer.py << 'EOF'
from boofuzz import *
import socket

def main():
    session = Session(
        target=Target(
            connection=UDPSocketConnection("192.168.1.100", 5683)
        )
    )
    
    s_initialize("coap-get")
    # CoAP Header: Ver(2) Type(0) TKL TokenLength Code(1=GET) MsgID
    s_raw(name="header", default_value=b'\x41\x01\x00\x01')
    s_raw(name="token", default_value=b'\x01')
    # URI-Path option (delta=11, length=...)
    s_raw(name="uri_path", default_value=b'\xb4test')
    s_raw(name="payload_marker", default_value=b'\xff')
    s_string(name="payload", default_value="test")
    
    session.connect(s_get("coap-get"))
    session.fuzz()

if __name__ == "__main__":
    main()
EOF

python3 coap_fuzzer.py
```
