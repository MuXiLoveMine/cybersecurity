# ZigBee 安全

### 7.1 ZigBee 基础

ZigBee 是基于 IEEE 802.15.4 标准的短距离、低功耗无线通信协议。

**特点**：
- 低功耗：电池可使用数月到数年
- 自组网：Mesh 网络拓扑
- 低速率：250 kbps（2.4 GHz）
- 节点容量：理论上最多 65535 个节点
- 应用场景：智能家居、工业控制、传感器网络

### 7.2 ZigBee 安全架构

#### 7.2.1 安全层次

```
┌─────────────────────────────────────┐
│         应用层 (APS) 安全           │
│  应用链路密钥、信任中心            │
├─────────────────────────────────────┤
│         网络层 (NWK) 安全           │
│  网络密钥、设备认证、帧加密         │
├─────────────────────────────────────┤
│         MAC 层安全                  │
│  访问控制列表、帧计数器             │
└─────────────────────────────────────┘
```

#### 7.2.2 密钥类型

| 密钥类型 | 用途 | 共享范围 |
|---------|------|---------|
| **网络密钥 (Network Key)** | 加密网络层数据 | 网络内所有设备共享 |
| **链路密钥 (Link Key)** | 加密应用层数据 | 两个设备之间共享 |
| **主密钥 (Master Key)** | 派生链路密钥 | 信任中心和设备共享 |

#### 7.2.3 安全模式

| 安全模式 | 说明 | 安全性 |
|---------|------|--------|
| **住宅模式 (Residential Mode)** | 使用网络密钥，无信任中心 | 低 |
| **标准模式 (Standard Mode)** | 有信任中心，使用网络密钥 | 中 |
| **高安全模式 (High Security Mode)** | 有信任中心，使用链路密钥和网络密钥 | 高 |

### 7.3 ZigBee 安全风险

#### 7.3.1 常见安全问题

| 风险类型 | 描述 |
|---------|------|
| **默认网络密钥** | 很多设备使用默认密钥（如 "ZigBeeAlliance09"） |
| **密钥传输不安全** | 入网时密钥可能以明文或弱加密传输 |
| **重放攻击** | 帧计数器空间有限，可能发生重放 |
| **未授权入网** | 安全配置不当时，恶意设备可加入网络 |
| **设备被物理捕获** | 设备被拆解后可提取密钥 |

#### 7.3.2 著名漏洞：ZigBee 密钥提取

**攻击场景**：
1. 攻击者在设备入网时嗅探通信
2. 如果密钥以明文传输，可直接获取网络密钥
3. 获得网络密钥后，可解密所有网络通信
4. 可进一步加入网络，控制其他设备

**防护措施**：
- 使用预配置密钥，不通过空中传输
- 使用高安全模式
- 定期更换网络密钥
- 物理保护设备

### 7.4 ZigBee 安全测试工具

| 工具 | 用途 |
|------|------|
| **KillerBee** | ZigBee 安全测试框架 |
| **ApiMote** | ZigBee 渗透测试硬件 |
| **Atmel RZUSBstick** | ZigBee USB 适配器 |
| **Wireshark** | 配合抓包硬件分析 ZigBee 协议 |

**KillerBee 常用命令**：
```bash
# 扫描信道
zbscapy -c 11,15,20,25

# 嗅探 ZigBee 流量（需要网络密钥）
zbdump -c 15 -w capture.pcap

# 注入数据包
zbinject -c 15 -p "00000000..."
```
