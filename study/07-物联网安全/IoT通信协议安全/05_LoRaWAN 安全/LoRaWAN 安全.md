# LoRaWAN 安全

### 5.1 LoRaWAN 基础

#### 5.1.1 技术概述

LoRaWAN 是一种基于 LoRa 调制技术的低功耗广域网（LPWAN）协议。

**特点**：
- 传输距离远：市区 2~5 公里，郊区可达 15 公里
- 低功耗：电池可使用数年
- 低速率：0.3 kbps ~ 50 kbps
- 大容量：一个网关可连接数万个设备
- 工作频段：ISM 频段（中国 470~510 MHz）

#### 5.1.2 网络架构

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 终端设备 │     │  网关   │     │ 网络服务器│     │ 应用服务器│
│ (End    │     │(Gateway)│     │(Network │     │(App     │
│  Device)│     │         │     │ Server) │     │ Server) │
└────┬────┘     └────┬────┘     └────┬────┘     └────┬────┘
     │   LoRa 无线    │                │                │
     │───────────────>│   IP 网络      │                │
     │                │───────────────>│   应用数据     │
     │                │                │───────────────>│
     │                │                │                │
```

### 5.2 LoRaWAN 安全机制

#### 5.2.1 密钥体系

LoRaWAN 使用三层密钥体系：

| 密钥 | 长度 | 用途 |
|------|------|------|
| **AppKey** | 128 位 | 应用根密钥，用于派生 AppSKey |
| **NwkKey** | 128 位 | 网络根密钥，用于派生 NwkSKey |
| **AppSKey** | 128 位 | 应用会话密钥，加密应用数据 |
| **NwkSKey** | 128 位 | 网络会话密钥，加密网络指令和 MIC |

**注**：LoRaWAN 1.0.x 中 AppKey 和 NwkKey 合并为一个 AppKey。

#### 5.2.2 设备激活方式

**方式一：OTAA (Over-The-Air Activation)**

通过空中激活，安全性较高：
```
终端设备                         网络服务器
    │                               │
    │------ Join Request ---------->│  (DevEUI, AppEUI, DevNonce)
    │                               │  验证设备合法性
    │<------ Join Accept -----------│  (AppNonce, NetID, DevAddr)
    │                               │
    │  双方使用 AppKey 派生会话密钥   │
    │  NwkSKey = aes128_encrypt(AppKey, 0x01 | AppNonce | NetID | DevNonce)
    │  AppSKey = aes128_encrypt(AppKey, 0x02 | AppNonce | NetID | DevNonce)
    │                               │
```

**方式二：ABP (Activation By Personalization)**

通过个性化激活，直接预配置会话密钥：
- 安全性较低（密钥长期不变）
- 适用于无法执行 OTAA 的场景

#### 5.2.3 安全特性

| 特性 | 说明 |
|------|------|
| **端到端加密** | 应用数据只有终端和应用服务器可解密 |
| **消息完整性** | 使用 MIC (Message Integrity Code) 验证消息完整性 |
| **重放保护** | 使用帧计数器 (FCnt) 防止重放攻击 |
| **设备唯一标识** | DevEUI 全球唯一标识设备 |

### 5.3 LoRaWAN 安全风险

| 风险类型 | 描述 | 防护措施 |
|---------|------|---------|
| **重放攻击** | 截获并重放 LoRaWAN 消息 | 帧计数器 (FCnt) 机制 |
| **中间人攻击** | 劫持设备通信 | OTAA 激活机制、密钥保护 |
| **物理攻击** | 拆解设备提取密钥 | 硬件安全模块、密钥保护 |
| **网关攻击** | 恶意网关注入消息 | MIC 验证、网络服务器过滤 |
| **频谱攻击** | 干扰 LoRa 信号 | 跳频、信道检测 |
| **A/B 类设备下行安全** | 下行消息可能被嗅探 | 加密保护、应用层加密 |
