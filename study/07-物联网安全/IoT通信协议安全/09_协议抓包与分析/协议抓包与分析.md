# 协议抓包与分析

### 9.1 Wireshark 抓包分析

#### 9.1.1 MQTT 抓包分析

**过滤 MQTT 报文**：
```
mqtt                      # 显示所有 MQTT 报文
mqtt.msgtype == 1         # 只显示 CONNECT 报文
mqtt.msgtype == 3         # 只显示 PUBLISH 报文
mqtt.topic == "sensors/#" # 按主题过滤（支持部分匹配）
mqtt.username             # 包含用户名的报文
```

**常见 MQTT 报文类型**：
| 值 | 报文类型 | 说明 |
|----|---------|------|
| 1 | CONNECT | 客户端连接请求 |
| 2 | CONNACK | 连接确认 |
| 3 | PUBLISH | 发布消息 |
| 4 | PUBACK | 发布确认 (QoS 1) |
| 8 | SUBSCRIBE | 订阅请求 |
| 9 | SUBACK | 订阅确认 |
| 12 | PINGREQ | 心跳请求 |
| 13 | PINGRESP | 心跳响应 |
| 14 | DISCONNECT | 断开连接 |

**安全分析要点**：
1. 检查 CONNECT 报文中是否有用户名密码（明文传输！）
2. 检查 PUBLISH 消息内容是否敏感
3. 检查是否使用 TLS 加密（端口 8883）
4. 检查主题命名规则，尝试枚举

#### 9.1.2 CoAP 抓包分析

**过滤 CoAP 报文**：
```
coap                      # 显示所有 CoAP 报文
coap.code == 1            # GET 请求
coap.code == 2            # POST 请求
coap.opt.uri_path == "sensor"  # 按 URI 路径过滤
```

**安全分析要点**：
1. 检查是否使用 DTLS 加密（端口 5684）
2. 检查请求中是否包含敏感信息
3. 分析资源发现 (`/.well-known/core`) 返回的资源

#### 9.1.3 BLE 抓包分析

使用 Wireshark + Ubertooth/nRF Sniffer：

**过滤 BLE 报文**：
```
btle                      # 显示所有 BLE 报文
btle.advertising_header   # 广播报文
btle.data_header          # 数据通道报文
btatt.opcode == 0x0a      # Write Request
btatt.opcode == 0x0b      # Write Response
btatt.opcode == 0x02      # Read Request
```

**安全分析要点**：
1. 检查广播数据中是否包含敏感信息
2. 检查配对过程是否安全
3. 检查 GATT 读写是否需要认证
4. 检查数据是否加密

### 9.2 Scapy 协议分析与测试

Scapy 是一个强大的 Python 数据包处理库，可用于构造和分析网络报文。

#### 9.2.1 MQTT 报文构造

```python
from scapy.all import *

# 构造 MQTT CONNECT 报文
# MQTT 头：类型(4位) + 标志(4位) + 剩余长度
connect_packet = bytes([
    0x10,  # 报文类型：CONNECT (0001) + 标志 (0000)
    0x13,  # 剩余长度：19 字节
    # 可变报头
    0x00, 0x04,  # 协议名长度 (4)
    0x4d, 0x51, 0x54, 0x54,  # "MQTT"
    0x04,  # 协议级别 (4 = MQTT 3.1.1)
    0x02,  # 连接标志：清理会话
    0x00, 0x3c,  # 保持连接时间：60 秒
    # 有效载荷
    0x00, 0x07,  # Client ID 长度 (7)
    0x74, 0x65, 0x73, 0x74, 0x5f, 0x69, 0x64  # "test_id"
])

# 发送报文
send(IP(dst="192.168.1.100")/TCP(dport=1883)/Raw(load=connect_packet))
```

#### 9.2.2 CoAP 报文构造

```python
from scapy.all import *
from scapy.contrib.coap import CoAP

# 构造 CoAP GET 请求
coap_get = CoAP(
    ver=1,
    type=0,  # Confirmable
    code=1,  # GET
    msg_id=1234,
    token=b"\x01\x02\x03\x04",
    options=[
        ("Uri-Path", "sensor"),
        ("Uri-Path", "temperature"),
    ],
)

# 发送 CoAP 请求
send(IP(dst="192.168.1.100")/UDP(dport=5683)/coap_get)
```

### 9.3 协议模糊测试

模糊测试 (Fuzzing) 是发现协议漏洞的有效方法。

#### 9.3.1 常用模糊测试工具

| 工具 | 适用协议 | 说明 |
|------|---------|------|
| **Boofuzz** | 通用协议 | Python 编写，基于 Sulley |
| **AFL** | 文件/标准输入 | 覆盖率引导的模糊测试 |
| **Peach** | 通用协议 | 商业模糊测试框架 |
| **MQTT Fuzzer** | MQTT | MQTT 专用模糊测试工具 |
| **CoAP Fuzzer** | CoAP | CoAP 专用模糊测试工具 |

#### 9.3.2 Boofuzz MQTT 模糊测试示例

```python
from boofuzz import *

# 定义 MQTT CONNECT 报文的模糊测试模板
def mqtt_fuzz():
    session = Session(
        target=Target(connection=TCPSocketConnection("192.168.1.100", 1883)),
        sleep_time=0.1,
    )

    s_initialize("mqtt_connect")

    # MQTT 固定报头
    s_byte(0x10, name="fixed_header_type")  # CONNECT

    # 剩余长度（使用块计算）
    s_size("mqtt_payload", length=1, name="remaining_length")

    s_block_start("mqtt_payload")
    # 可变报头：协议名
    s_size("protocol_name", length=2, name="protocol_name_len")
    s_block_start("protocol_name")
    s_string("MQTT", name="protocol_name_str")
    s_block_end()

    s_byte(0x04, name="protocol_level")  # MQTT 3.1.1
    s_byte(0x02, name="connect_flags")   # 连接标志
    s_word(0x003c, name="keep_alive")    # 保持连接

    # 有效载荷：Client ID
    s_size("client_id", length=2, name="client_id_len")
    s_block_start("client_id")
    s_string("test_client", name="client_id_str")
    s_block_end()

    s_block_end("mqtt_payload")

    session.connect(s_get("mqtt_connect"))
    session.fuzz()
```
