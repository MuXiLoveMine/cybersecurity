# 边缘计算安全概述

### 7.1 边缘计算架构

```
┌──────────────────────────────────────────────────────────┐
│                    云中心 (Cloud)                          │
│   全局分析 / 模型训练 / 长期存储 / 跨域协同               │
└──────────────────────────┬───────────────────────────────┘
                           │ 边云协同
┌──────────────────────────┴───────────────────────────────┐
│                   边缘节点 (Edge Node)                    │
│   网关 / 边缘服务器 / 边缘 AI 推理                        │
│   本地实时处理 / 数据过滤 / 协议转换                      │
└──────────────────────────┬───────────────────────────────┘
                           │
┌──────────────────────────┴───────────────────────────────┐
│                   边缘设备 (Edge Device)                  │
│   摄像头 / 传感器 / 工业控制器 / 智能终端                 │
└──────────────────────────────────────────────────────────┘
```

### 7.2 边缘安全的三大层面

| 层面 | 关注点 |
|------|--------|
| 边缘架构安全 | 边云协同通道、边缘节点准入、信任根传递 |
| 边缘节点安全 | 边缘网关/服务器加固、容器安全、运行时防护 |
| 边缘数据安全 | 数据采集、传输、存储、脱敏、生命周期 |
| 边缘 AI 安全 | 模型保护、推理安全、对抗样本防御 |

### 7.3 边缘计算安全特点（与云对比）

```
云安全                          边缘安全
集中式防护                      分布式防护
可信机房                        开放/物理暴露
算力充足                        资源受限
补丁集中                        补丁碎片化
攻击面相对集中                  攻击面广泛
```

> 边缘设备物理暴露是边缘安全的核心挑战：攻击者可直接接触设备，绕过网络层防护。因此边缘安全必须从"信任根"做起，硬件信任根 + 安全启动是基础。
