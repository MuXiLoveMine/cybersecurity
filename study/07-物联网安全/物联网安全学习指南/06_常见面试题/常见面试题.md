# 常见面试题

### 基础概念
1. **什么是物联网？物联网的架构是什么？**
   - 物联网是物物相连的互联网
   - 三层架构：感知层、网络层、应用层
   - 四层架构：感知层、网络层、平台层、应用层

2. **物联网安全的挑战是什么？**
   - 设备资源受限，难以部署复杂安全机制
   - 设备数量庞大，管理困难
   - 设备生命周期长，更新困难
   - 协议多样，缺乏统一安全标准
   - 物理暴露，容易被物理攻击
   - 供应链安全问题
   - 隐私泄露风险

3. **常见的物联网协议有哪些？**
   - 应用层：MQTT、CoAP、HTTP、XMPP、AMQP
   - 网络层：IPv6、6LoWPAN
   - 无线协议：WiFi、BLE、Zigbee、Z-Wave、LoRa、NB-IoT
   - 工业协议：Modbus、Profinet 等（见工控安全）

4. **什么是固件？固件安全为什么重要？**
   - 固件是设备的底层软件，控制设备运行
   - 固件安全是物联网设备安全的基础
   - 固件漏洞影响范围广、修复困难
   - 固件是攻击者的重要目标

### 技术原理
5. **固件分析的流程是什么？**
   - 固件获取：下载、拆设备读取、调试接口读取
   - 格式识别：识别固件格式和文件系统
   - 解包/解密：解压、解密固件
   - 静态分析：文件系统分析、代码分析、字符串分析
   - 动态分析：模拟运行、调试
   - 漏洞发现：查找安全漏洞
   - 漏洞验证：验证发现的漏洞

6. **常见的固件漏洞有哪些？**
   - 硬编码密码/密钥
   - 后门账户
   - 命令注入
   - 缓冲区溢出
   - 身份认证绕过
   - 权限提升
   - 信息泄露
   - 未授权访问
   - 加密算法缺陷
   - 固件签名验证绕过

7. **什么是 Mirai 僵尸网络？有什么影响？**
   - Mirai 是一个感染物联网设备的僵尸网络
   - 主要利用弱口令进行传播
   - 用于发起 DDoS 攻击
   - 2016 年导致 Dyn DNS 服务中断，影响大量网站
   - 源代码已公开，衍生出大量变种
   - 让物联网安全问题引起广泛关注

8. **MQTT 协议的安全风险有哪些？**
   - 缺乏认证或弱认证
   - 未加密传输
   - 未授权访问
   - Topic 枚举
   - 恶意发布/订阅
   - 中间人攻击
   - 拒绝服务攻击
   - Broker 配置不当

### 实战相关
9. **如何进行物联网设备的渗透测试？**
   - 信息收集：设备识别、端口扫描、服务识别
   - 硬件测试：调试接口、串口、JTAG
   - 固件分析：提取、解包、逆向、漏洞挖掘
   - 协议测试：无线协议、网络协议、应用协议
   - Web/API 测试：管理界面、云 API
   - 移动 App 测试：配套 App 安全
   - 云平台测试：云平台安全
   - 报告编写：漏洞详情、风险评估、修复建议

10. **硬件攻击的方式有哪些？**
    - 侧信道攻击：功耗分析、电磁分析、时间分析
    - 故障注入：电压毛刺、时钟毛刺、激光故障注入
    - 物理拆解：芯片解密、总线监听
    - 调试接口：JTAG、SWD、UART 利用
    - 内存读取：直接读取内存芯片
    - 固件提取：从芯片读取固件

11. **物联网安全防护措施有哪些？**
    - 设备安全：安全启动、固件签名、硬件安全模块、安全更新
    - 网络安全：加密传输、身份认证、访问控制、网络隔离
    - 数据安全：数据加密、隐私保护、访问控制
    - 平台安全：身份认证、访问控制、API 安全、租户隔离
    - 管理安全：安全管理制度、漏洞管理、应急响应

12. **OWASP IoT Top 10 有哪些？**
    - I1: 弱口令、可猜测的密码
    - I2: 不安全的网络服务
    - I3: 不安全的生态系统接口
    - I4: 缺乏安全的更新机制
    - I5: 使用不安全或过时的组件
    - I6: 隐私保护不足
    - I7: 数据传输和保护不足
    - I8: 缺乏安全的设备管理
    - I9: 不安全的默认设置
    - I10: 缺乏物理加固
