# 学习路线

### 阶段 1：物联网基础（1-2 个月）
**学习目标**：掌握物联网基础知识和架构

**学习内容**
- 物联网概念与架构
- 嵌入式系统基础
- 常见物联网设备
- 物联网协议基础
- 物联网平台介绍
- 嵌入式 Linux 基础

**实践任务**
- 了解常见物联网设备
- 学习物联网架构
- 学习嵌入式基础
- 搭建简单的物联网实验环境
- 接触一些物联网硬件

### 阶段 2：固件安全（2-3 个月）
**学习目标**：掌握固件分析和漏洞挖掘技术

**学习内容**
- 固件提取技术
- 固件分析工具
- 固件解包与解包
- 静态分析
- 动态分析
- 固件逆向
- 常见固件漏洞
- 漏洞验证

**实践任务**
- 下载分析各种固件
- 使用 binwalk 等工具
- 练习固件解包
- 分析固件文件系统
- 查找简单漏洞
- 搭建 QEMU 模拟环境

### 阶段 3：物联网协议安全（2-3 个月）
**学习目标**：掌握常见物联网协议的安全分析

**学习内容**
- MQTT 协议安全
- CoAP 协议安全
- BLE 协议安全
- Zigbee 协议安全
- 其他无线协议安全
- 协议分析工具
- 协议攻击技术

**实践任务**
- 分析各种物联网协议
- 使用 Wireshark 抓包分析
- 搭建协议测试环境
- 测试协议安全问题
- 学习协议攻击技术

### 阶段 4：物联网渗透测试（3-4 个月）
**学习目标**：掌握物联网渗透测试方法和工具

**学习内容**
- 物联网渗透测试方法论
- 硬件安全测试
- 固件安全测试
- 协议安全测试
- Web/API 安全测试
- 移动 App 安全测试
- 云平台安全测试
- 报告编写

**实践任务**
- 对物联网设备进行完整的渗透测试
- 练习硬件攻击
- 练习固件分析
- 练习协议攻击
- 写渗透测试报告

### 阶段 5：深入研究（持续）
**研究方向**
- 固件漏洞挖掘
- 硬件安全
- 协议安全
- 物联网僵尸网络
- 物联网安全防护
- 物联网安全标准
