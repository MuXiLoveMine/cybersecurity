# 详细子方向

### 2.1 物联网架构安全

#### 2.1.1 物联网架构
**三层架构**
- 感知层：传感器、执行器、RFID、智能设备
- 网络层：互联网、移动通信网、无线传感网
- 应用层：各种物联网应用和平台

**四层架构**
- 感知层
- 网络层
- 平台层
- 应用层

#### 2.1.2 各层安全挑战
**感知层安全**
- 设备资源受限
- 计算能力弱
- 存储能力有限
- 电池供电
- 物理暴露
- 数量庞大

**网络层安全**
- 协议多样性
- 异构网络融合
- 传输安全
- 身份认证
- 访问控制

**平台层安全**
- 数据安全
- 身份认证
- 访问控制
- API 安全
- 云安全

**应用层安全**
- 业务逻辑安全
- 用户隐私
- 数据安全
- 应用漏洞

### 2.2 嵌入式系统安全

#### 2.2.1 嵌入式系统基础
**嵌入式系统特点**
- 资源受限（CPU、内存、存储）
- 实时性要求
- 低功耗
- 专用功能
- 生命周期长
- 更新困难

**常见嵌入式平台**
- ARM（最常见）
- MIPS
- x86
- AVR
- PIC
- RISC-V（新兴）

#### 2.2.2 嵌入式操作系统
**常见 RTOS**
- FreeRTOS
- VxWorks
- uC/OS
- RT-Thread
- Zephyr
- ThreadX

**嵌入式 Linux**
- OpenWrt
- DD-WRT
- Tomato
- Buildroot
- Yocto

#### 2.2.3 嵌入式安全挑战
**安全挑战**
- 资源受限，难以部署复杂安全机制
- 缺乏安全更新机制
- 硬编码密码和密钥
- 调试接口暴露
- 不安全的默认配置
- 缺乏认证和加密
- 供应链安全

### 2.3 固件安全

#### 2.3.1 固件分析
**固件格式**
- 原始二进制
- 压缩固件
- 加密固件
- 分块固件
- 固件包格式（uImage、FitImage 等）

**固件分析流程**
1. 固件获取
2. 格式识别
3. 解包/解密
4. 文件系统分析
5. 代码分析
6. 漏洞发现
7. 漏洞验证

#### 2.3.2 固件提取
**提取方法**
- 官方固件下载
- 设备更新流量抓取
- 串口读取
- 编程器读取（拆芯片）
- JTAG/SWD 调试接口
- 内存 dump

**提取工具**
- binwalk
- firmware-mod-kit
- FMK
- jefferson
- sasquatch
- unsquashfs

#### 2.3.3 固件逆向
**逆向分析**
- 静态分析：反汇编、反编译
- 动态分析：调试、运行
- 字符串分析
- 漏洞挖掘
- 密码分析

**逆向工具**
- IDA Pro
- Ghidra
- Radare2
- Binary Ninja
- GDB + pwndbg
- QEMU（模拟运行）

#### 2.3.4 常见固件漏洞
**常见漏洞类型**
- 硬编码密码
- 后门账户
- 命令注入
- 缓冲区溢出
- 身份认证绕过
- 权限提升
- 信息泄露
- 未授权访问
- 加密算法缺陷
- 固件签名验证绕过

### 2.4 物联网协议安全

#### 2.4.1 无线通信协议
**短距离无线协议**
- WiFi（802.11）
- Bluetooth / BLE
- Zigbee
- Z-Wave
- Thread
- NFC
- RFID
- LoRa

**低功耗广域网协议**
- LoRaWAN
- NB-IoT
- eMTC
- Sigfox

#### 2.4.2 应用层协议
**常见协议**
- MQTT
- CoAP
- HTTP / HTTPS
- XMPP
- AMQP
- DDS
- Modbus（工业物联网）

**协议安全问题**
- 缺乏认证
- 缺乏加密
- 弱认证机制
- 协议设计缺陷
- 实现漏洞
- 拒绝服务

#### 2.4.3 MQTT 安全
**MQTT 基础**
- 发布/订阅模式
- Broker（代理服务器）
- Topic（主题）
- QoS（服务质量）
- 遗嘱消息
- 保留消息

**安全风险**
- 弱认证/无认证
- 未授权访问
- 数据泄露
- 中间人攻击
- 拒绝服务
- Topic 枚举
- 恶意发布

**安全措施**
- 用户名密码认证
- TLS 加密传输
- 访问控制列表（ACL）
- 证书认证
- 安全的 Broker 配置

#### 2.4.4 BLE 安全
**BLE 基础**
- 低功耗蓝牙
- GAP（通用访问配置文件）
- GATT（通用属性配置文件）
- Service / Characteristic
- 广播 / 连接

**安全风险**
- 配对安全问题
- 窃听
- 中间人攻击
- 重放攻击
- 未授权访问
- 数据泄露

### 2.10 物联网僵尸网络

#### 2.10.1 Mirai 僵尸网络
**Mirai 概述**
- 2016 年爆发
- 主要感染物联网设备
- 利用弱口令
- 用于 DDoS 攻击
- 源代码已公开
- 大量变种

**感染方式**
- Telnet 弱口令扫描
- 暴力破解
- 多种默认口令组合

**影响**
- 大规模 DDoS 攻击
- 导致 Dyn DNS 服务中断
- 影响大量网站
- 物联网安全问题引起重视

#### 2.10.2 其他僵尸网络
**其他著名僵尸网络**
- Hajime：Mirai 的对手，更隐蔽
- BrickerBot：破坏设备而非利用
- Reaper：利用漏洞传播，更强大
- Mozi：基于 DHT 网络的僵尸网络
- 各种 Mirai 变种
