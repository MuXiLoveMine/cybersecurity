## 2. 侧信道攻击

### 2.1 功耗分析攻击

```
功耗分析攻击原理:

芯片在处理不同数据时, 晶体管开关数量不同, 导致功耗变化。
通过测量和分析功耗变化, 可以推断出芯片内部处理的数据。

功耗模型:
  P = P_static + P_dynamic
  P_static: 静态功耗 (漏电流)
  P_dynamic: 动态功耗 = C * V^2 * f * α

  其中:
    C: 电容
    V: 电压
    f: 频率
    α: 活动因子

功耗与数据的关系:
  当数据从0变1或1变0时, 晶体管翻转, 功耗增加
  汉明重量(Hamming Weight): 数据中1的个数
  汉明距离(Hamming Distance): 前后数据不同的位数

  功耗 ∝ 汉明重量 (绝对功耗模型)
  功耗 ∝ 汉明距离 (差分功耗模型)
```

#### 2.1.1 简单功耗分析 (SPA)

```
SPA (Simple Power Analysis):

直接观察功耗轨迹, 通过肉眼识别操作阶段和密钥相关模式。

攻击步骤:
1. 用示波器测量设备功耗
2. 触发加密操作
3. 录制功耗波形
4. 肉眼分析波形特征

示例: RSA中平方和乘法操作的功耗差异
  - 平方操作: 功耗模式A
  - 乘法操作: 功耗模式B (更高)
  
  通过观察功耗模式序列, 可以推断RSA密钥:
  模式A, A, B, A, B, A, A, B...
  对应密钥位:  0, 0, 1, 0, 1, 0, 0, 1...
```

#### 2.1.2 差分功耗分析 (DPA)

```
DPA (Differential Power Analysis):

统计分析大量功耗轨迹, 提取密钥相关信息。

攻击流程:
1. 收集大量(1000-100000)功耗轨迹
2. 对每条轨迹, 已知明文/密文
3. 对每个可能的密钥猜测:
   a. 计算中间值 (如S盒输出)
   b. 根据中间值的某一位(如LSB)分组
   c. 计算两组功耗轨迹的差分均值
4. 差分峰值对应的密钥猜测即为正确密钥

DPA攻击伪代码:
```

```python
#!/usr/bin/env python3
"""DPA (差分功耗分析) 攻击框架"""
import numpy as np
from collections import defaultdict

class DPAAttack:
    """DPA攻击框架"""
    
    def __init__(self, traces, plaintexts, ciphertexts):
        """
        参数:
            traces: 功耗轨迹数组 (N x T, N=轨迹数, T=采样点数)
            plaintexts: 明文数组 (N,)
            ciphertexts: 密文数组 (N,)
        """
        self.traces = np.array(traces)
        self.plaintexts = np.array(plaintexts)
        self.ciphertexts = np.array(ciphertexts)
        self.num_traces = len(traces)
        self.num_samples = len(traces[0]) if self.num_traces > 0 else 0
    
    def attack_sbox_last_round(self, sbox, key_range=256):
        """
        攻击AES最后一轮S盒
        
        参数:
            sbox: AES S盒查找表
            key_range: 密钥搜索范围
        """
        best_key = 0
        best_correlation = 0
        results = {}
        
        for key_guess in range(key_range):
            # 计算中间值
            intermediate_values = []
            for i in range(self.num_traces):
                ct = self.ciphertexts[i]
                # AES最后一轮: S盒逆变换
                intermediate = sbox[ct ^ key_guess]
                intermediate_values.append(intermediate)
            
            # 选择函数: 中间值的LSB
            selection_values = [v & 1 for v in intermediate_values]
            
            # 分组
            group_0 = []
            group_1 = []
            for i in range(self.num_traces):
                if selection_values[i] == 0:
                    group_0.append(self.traces[i])
                else:
                    group_1.append(self.traces[i])
            
            if len(group_0) == 0 or len(group_1) == 0:
                continue
            
            # 计算差分均值
            mean_0 = np.mean(group_0, axis=0)
            mean_1 = np.mean(group_1, axis=0)
            differential = mean_1 - mean_0
            
            # 找到最大差分
            max_diff = np.max(np.abs(differential))
            results[key_guess] = max_diff
            
            if max_diff > best_correlation:
                best_correlation = max_diff
                best_key = key_guess
        
        print(f"[+] 最佳密钥猜测: 0x{best_key:02X}")
        print(f"[+] 最大差分值: {best_correlation:.6f}")
        
        # 显示前10个候选
        sorted_results = sorted(results.items(), key=lambda x: x[1], reverse=True)
        print(f"[+] 前10候选:")
        for key, corr in sorted_results[:10]:
            print(f"    Key=0x{key:02X}, Correlation={corr:.6f}")
        
        return best_key
    
    def attack_correlation(self, leakage_model='hamming_weight'):
        """
        相关性功耗分析 (CPA)
        
        使用汉明重量模型进行相关性分析
        """
        # AES S盒
        sbox = [
            0x63, 0x7c, 0x77, 0x7b, 0xf2, 0x6b, 0x6f, 0xc5,
            0x30, 0x01, 0x67, 0x2b, 0xfe, 0xd7, 0xab, 0x76,
            # ... 完整AES S盒
        ]
        
        best_key = 0
        best_correlation = 0
        
        for key_guess in range(256):
            # 计算假设功耗值
            hypotheses = []
            for i in range(self.num_traces):
                pt = self.plaintexts[i]
                intermediate = sbox[pt ^ key_guess]
                
                if leakage_model == 'hamming_weight':
                    hw = bin(intermediate).count('1')
                    hypotheses.append(hw)
                else:
                    hypotheses.append(intermediate)
            
            # 计算相关性
            for t in range(self.num_samples):
                trace_samples = self.traces[:, t]
                correlation = np.corrcoef(hypotheses, trace_samples)[0, 1]
                
                if abs(correlation) > best_correlation:
                    best_correlation = abs(correlation)
                    best_key = key_guess
        
        return best_key
```

### 2.2 时间分析攻击

```
时间分析 (Timing Analysis):

通过测量操作执行时间来推断密钥信息。

攻击原理:
  某些密码算法的执行时间依赖于密钥或数据
  时间差异 -> 密钥信息泄露

示例: RSA平方乘法
  - 指数位为0: 只平方
  - 指数位为1: 平方+乘法 (额外时间)
  通过测量时间差推断指数(密钥)

防护:
  - 恒定时间实现
  - 增加随机延迟
  - 掩除时间依赖
```

### 2.3 电磁分析攻击

```
EMA (Electromagnetic Analysis):

通过测量芯片电磁辐射来获取信息。

原理:
  晶体管开关产生电磁辐射
  不同操作产生不同电磁特征
  近场探头可以捕获局部辐射

优势(相比功耗分析):
  - 空间分辨率高 (可以定位到特定电路)
  - 可以绕过功耗保护
  - 不需要直接接触电源

设备:
  - 近场电磁探头
  - 低噪声放大器
  - 示波器/采集卡
  - XYZ定位平台

攻击流程:
1. 打开设备外壳
2. 定位芯片
3. 用探头扫描芯片表面
4. 触发加密操作
5. 录制电磁信号
6. SPA/DPA分析
```

## 3. 故障注入攻击

### 3.1 电压毛刺注入

```
电压毛刺 (Voltage Glitching):

通过在芯片电源中注入短暂的电压变化(毛刺), 导致电路异常工作。

原理:
  电压骤降 -> 晶体管不满足开关条件 -> 跳过指令/错误计算
  电压骤升 -> 晶体管异常导通 -> 数据损坏

攻击目标:
  - 跳过安全检查 (如密码验证)
  - 跳过循环计数
  - 破坏条件分支
  - 修改寄存器值

电压毛刺参数:
  - 毛刺类型: 负压/正压
  - 毛刺幅度: -3V ~ +3V (相对于Vcc)
  - 毛刺宽度: 1ns ~ 100ns
  - 毛刺时机: 精确到时钟周期
```

```python
#!/usr/bin/env python3
"""电压毛刺注入控制工具"""
import serial
import time
import struct

class VoltageGlitcher:
    """电压毛刺注入控制器"""
    
    def __init__(self, port='/dev/ttyUSB0', baud=115200):
        self.ser = serial.Serial(port, baud, timeout=1)
        self.target_voltage = 3.3
        self.glitch_type = 'negative'  # negative/positive
        self.glitch_voltage = 0.0      # 毛刺电压
        self.glitch_width_ns = 10       # 毛刺宽度(纳秒)
        self.glitch_delay_us = 0       # 触发后延迟(微秒)
    
    def set_glitch_params(self, voltage, width_ns, delay_us=0):
        """设置毛刺参数"""
        self.glitch_voltage = voltage
        self.glitch_width_ns = width_ns
        self.glitch_delay_us = delay_us
    
    def arm_glitch(self):
        """装载毛刺参数"""
        # 构建命令包
        # 格式: [CMD] [Voltage] [Width] [Delay]
        cmd = b'\x01'  # ARM命令
        cmd += struct.pack('>f', self.glitch_voltage)
        cmd += struct.pack('>I', self.glitch_width_ns)
        cmd += struct.pack('>I', self.glitch_delay_us)
        
        self.ser.write(cmd)
        response = self.ser.read(4)
        
        if response == b'OKAY':
            return True
        return False
    
    def trigger_glitch(self):
        """触发毛刺"""
        self.ser.write(b'\x02')  # TRIGGER命令
        response = self.ser.read(4)
        return response == b'OKAY'
    
    def sweep_parameters(self, target_command):
        """参数扫描 - 自动寻找最佳毛刺参数"""
        results = []
        
        # 电压范围扫描
        voltages = [-0.5, -1.0, -1.5, -2.0, -2.5, -3.0, 0.5, 1.0, 1.5, 2.0]
        # 宽度范围扫描
        widths = [5, 10, 20, 50, 100, 200]
        # 延迟范围扫描
        delays = [0, 1, 5, 10, 50, 100, 500, 1000]
        
        for voltage in voltages:
            for width in widths:
                for delay in delays:
                    self.set_glitch_params(voltage, width, delay)
                    
                    if self.arm_glitch():
                        # 发送目标命令
                        # 触发毛刺
                        self.trigger_glitch()
                        
                        # 检查结果
                        result = self.check_result()
                        
                        results.append({
                            'voltage': voltage,
                            'width': width,
                            'delay': delay,
                            'result': result,
                        })
                        
                        if result == 'success':
                            print(f"[!] 找到有效参数!")
                            print(f"    电压: {voltage}V")
                            print(f"    宽度: {width}ns")
                            print(f"    延迟: {delay}us")
                            return results
                    
                    time.sleep(0.1)
        
        return results
    
    def check_result(self):
        """检查毛刺效果"""
        # 读取目标设备响应
        response = self.ser.read(1024)
        
        if b'access granted' in response.lower():
            return 'success'
        elif b'error' in response.lower():
            return 'error'
        elif b'crash' in response.lower() or len(response) == 0:
            return 'crash'
        else:
            return 'normal'
```

### 3.2 时钟毛刺注入

```
时钟毛刺 (Clock Glitching):

通过在时钟信号中注入毛刺, 导致芯片时序异常。

原理:
  正常时钟: ────┐┌────┐┌────┐┌────
                ││    ││    ││
                └┘    └┘    └┘
  
  时钟毛刺: ────┐┌──┐┌────┐┌────
                ││  ││    ││
                └┘  └┘    └┘
                    ↑
              额外的时钟边沿

  额外的时钟脉冲 -> 指令计数器跳变 -> 跳过指令

攻击效果:
  - 跳过安全检查
  - 跳过循环迭代
  - 破坏条件跳转
  - 导致指令对齐错误

设备:
  - 信号发生器
  - 时钟注入探头
  - 精确时序控制
  - 示波器监控
```

### 3.3 电磁脉冲注入

```
EMFI (Electromagnetic Fault Injection):

通过电磁脉冲在芯片特定位置注入故障。

原理:
  强电磁脉冲 -> 感应电流 -> 晶体管异常

优势:
  - 不需要直接电气接触
  - 空间定位精确
  - 可绕过某些硬件保护
  - 毛刺参数可调

设备:
  - 电磁脉冲探头
  - 脉冲发生器
  - XYZ精密定位平台
  - 示波器

参数:
  - 脉冲电压: 50V - 500V
  - 脉冲宽度: 1ns - 100ns
  - 脉冲位置: 芯片表面精确坐标
  - 触发时机: 精确到时钟周期
```

### 3.4 激光故障注入

```
LFI (Laser Fault Injection):

使用激光在芯片特定位置注入故障。

原理:
  激光照射 -> 半导体中产生电子-空穴对 -> 晶体管异常导通

优势:
  - 极高的空间分辨率 (亚微米级)
  - 可以精确定位到单个晶体管
  - 可以从芯片背面注入
  - 非接触式

设备:
  - 激光器 (红光/红外)
  - 光学显微镜
  - XYZ精密定位平台
  - 光学系统

成本: $10000-$100000+
```

## 4. 芯片逆向工程

### 4.1 芯片去封装

```
芯片去封装 (Decapsulation):

去除芯片封装材料, 暴露内部裸晶。

方法1: 化学腐蚀
  试剂: 发烟硝酸 (HNO3) / 硫酸 (H2SO4)
  步骤:
  1. 将芯片固定在耐酸支架上
  2. 滴加酸液腐蚀封装树脂
  3. 用丙酮清洗
  4. 在显微镜下检查
  5. 重复直到暴露裸晶

方法2: 机械研磨
  工具: 砂纸/研磨机
  步骤:
  1. 从芯片背面研磨
  2. 逐步使用更细的砂纸
  3. 直到看到硅裸晶

方法3: 等离子体刻蚀
  设备: 等离子体刻蚀机
  优点: 精确控制, 不损坏裸晶

安全注意事项:
  - 化学操作需在通风橱中进行
  - 佩戴防护装备
  - 废液需妥善处理
```

### 4.2 电路提取

```
芯片层次逆向:

1. 去金属层:
   - 逐层去除金属互连
   - 化学机械抛光 (CMP)
   - 或选择性腐蚀

2. 图像采集:
   - 光学显微镜 (用于较大工艺)
   - 扫描电子显微镜 (SEM)
   - 适用于90nm以上工艺

3. 图像处理:
   - 图像拼接 (多张拼接成完整芯片)
   - 图像分割 (区分金属/通孔/晶体管)
   - 矢量化 (转换为电路图)

4. 电路分析:
   - 识别标准单元 (逻辑门)
   - 提取网表 (逻辑连接)
   - 功能分析
   - 密钥/安全逻辑识别

工具:
  - Delayer (层次去除)
  - GDSII查看器
```

### 5.1 UART串口利用

```
UART (Universal Asynchronous Receiver/Transmitter):

引脚:
  TX (发送)
  RX (接收)
  GND (地)
  VCC (电源, 可选)

发现UART引脚:

  设备TX -> 适配器RX
  设备RX -> 适配器TX
  设备GND -> 适配器GND
```

### 5.2 JTAG利用

```
JTAG (Joint Test Action Group):

引脚:
  TCK (Test Clock)    - 时钟

   - TDO通常直接连接或弱下拉
   - GND对地电阻0

JTAG利用工具:
  - OpenOCD (开源)

  - Bus Pirate (开源)
```

## 6. 侵入式与非侵入式攻击

### 6.1 非侵入式攻击

```
非侵入式攻击特征:

定义:
  不破坏芯片封装, 不修改硬件
  仅通过外部接口或物理测量进行攻击

方法:
  - 侧信道分析 (功耗/电磁/时间)
  - 故障注入 (电压/时钟/电磁)
  - 调试接口利用 (JTAG/SWD/UART)
  - 固件提取 (从外部Flash读取)
  - 总线嗅探

特点:
  - 设备保持完好
  - 可重复使用
  - 难以检测
  - 成本相对较低
  - 不需要昂贵的实验室设备
```

### 6.2 侵入式攻击

```
侵入式攻击特征:

定义:
  破坏芯片封装, 直接访问内部电路
  可能修改硬件结构

方法:
  - 芯片去封装
  - 电路逆向工程
  - 探针直接读取总线
  - FIB电路修改
  - 存储器直接读取
  - eFuse修改

特点:
  - 设备被破坏
  - 需要专业实验室设备
  - 成本极高
  - 信息获取最完整
  - 通常由专业实验室进行
```

### 6.3 半侵入式攻击

```
半侵入式攻击:

定义:
  去除封装但不去除钝化层
  不直接接触内部电路

方法:
  - UV光擦除保护位
  - 红外激光故障注入
  - 从背面接近芯片

特点:
  - 介于侵入和非侵入之间
  - 设备可能损坏也可能不损坏
  - 成本中等
  - 效果较好
```

```c
// 1. 调试器检测
bool is_debugger_present(void) {
    // 检查调试状态寄存器
    if (CoreDebug->DHCSR & CoreDebug_DHCSR_C_DEBUGEN_Msk) {
        return true;
    }
    
    // 检查时间异常 (调试暂停)
    uint32_t start = DWT->CYCCNT;
    __NOP(); __NOP(); __NOP(); __NOP();
    uint32_t elapsed = DWT->CYCCNT - start;
    
    if (elapsed > 50) {
        return true;  // 可能在调试
    }
    
    return false;
}

// 2. 故障检测 (冗余计算)
uint32_t secure_calculate(uint32_t a, uint32_t b) {
    uint32_t result1 = a + b;
    uint32_t result2 = a + b;  // 冗余计算
    
    if (result1 != result2) {
        // 检测到故障注入
        security_handler(FAULT_DETECTED);
        return 0;  // 安全失败
    }
    
    return result1;
}

// 3. 控制流完整性
void critical_function(void) {
    uint32_t token = 0xDEADBEEF;
    
    // 进入关键区域
    if (token != 0xDEADBEEF) {
        security_handler(CORRUPTION_DETECTED);
    }
    
    // 关键操作
    secure_operation();
    
    // 验证token (防止跳过)
    if (token != 0xDEADBEEF) {
        security_handler(SKIP_DETECTED);
    }
    
    token = 0xCAFEBABE;  // 改变token
}

// 4. 电压/时钟监测
void monitor_power(void) {
    // STM32 PVD (电源电压监测器)
    PWR->CR |= PWR_CR_PVDE;        // 启用PVD

}
```

```python
#!/usr/bin/env python3
"""ChipWhisperer功耗分析实验"""
# 需要安装: pip install chipwhisperer

try:
    import chipwhisperer as cw
except ImportError:
    print("请安装ChipWhisperer: pip install chipwhisperer")
    exit(1)

class ChipWhispererExperiment:
    """ChipWhisperer功耗分析实验"""
    
    def __init__(self):
        self.scope = None
        self.target = None
    
    def setup(self, scope_type='cw-lite'):
        """初始化设备"""
        # 连接示波器
        self.scope = cw.scope(type=scope_type)
        
        # 连接目标
        self.target = cw.target(self.scope)
        
        # 配置示波器
        self.scope.gain.gain = 45
        self.scope.gain.mode = 'low'
        self.scope.adc.samples = 5000
        self.scope.adc.triggers = 1
        self.scope.adc.offset = 0
        self.scope.clock.src = 'target'
        
        print("[+] ChipWhisperer已初始化")
    
    def capture_trace(self, plaintext):
        """捕获单条功耗轨迹"""
        # 设置明文
        self.target.simpleserial_write('p', plaintext)
        
        # 触发并采集
        ret = self.scope.capture()
        
        if ret:
            print("[-] 采集超时")
            return None
        
        # 获取轨迹数据
        trace = self.scope.get_last_trace()
        
        # 获取密文
        response = self.target.simpleserial_read('r', 16)
        
        return trace, response
    
    def capture_traces(self, num_traces=5000):
        """采集多条轨迹"""
        traces = []
        plaintexts = []
        ciphertexts = []
        
        from Crypto.Cipher import AES
        key = bytes([0x2b, 0x7e, 0x15, 0x16, 0x28, 0xae, 0xd2, 0xa6,
                      0xab, 0xf7, 0x15, 0x88, 0x09, 0xcf, 0x4f, 0x3c])
        
        import os
        for i in range(num_traces):
            # 生成随机明文
            plaintext = os.urandom(16)
            
            # 捕获轨迹
            result = self.capture_trace(plaintext)
            if result:
                trace, ciphertext = result
                traces.append(trace)
                plaintexts.append(plaintext)
                ciphertexts.append(ciphertext)
            
            if (i + 1) % 100 == 0:
                print(f"  采集进度: {i+1}/{num_traces}")
        
        print(f"[+] 共采集 {len(traces)} 条轨迹")
        return traces, plaintexts, ciphertexts
    
    def run_dpa(self, traces, plaintexts, ciphertexts):
        """运行DPA攻击"""
        import numpy as np
        
        traces = np.array(traces)
        
        # AES S盒
        sbox = [
            0x63, 0x7c, 0x77, 0x7b, 0xf2, 0x6b, 0x6f, 0xc5,
            0x30, 0x01, 0x67, 0x2b, 0xfe, 0xd7, 0xab, 0x76,
            # ... 完整S盒
        ]
        
        best_key = 0
        best_corr = 0
        
        for key_guess in range(256):
            # 计算假设中间值
            hypotheses = []
            for pt in plaintexts:
                intermediate = sbox[pt[0] ^ key_guess]
                hw = bin(intermediate).count('1')
                hypotheses.append(hw)
            
            # 计算相关性
            for t in range(len(traces[0])):
                trace_samples = traces[:, t]
                if np.std(trace_samples) > 0 and np.std(hypotheses) > 0:
                    corr = np.corrcoef(hypotheses, trace_samples)[0, 1]
                    if abs(corr) > best_corr:
                        best_corr = abs(corr)
                        best_key = key_guess
        
        print(f"[+] CPA结果: Key=0x{best_key:02X}, Corr={best_corr:.4f}")
        return best_key

    experiment.setup()
```
