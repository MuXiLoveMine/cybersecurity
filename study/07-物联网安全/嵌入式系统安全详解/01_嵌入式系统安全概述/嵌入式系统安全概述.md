# 嵌入式系统安全概述

### 1.1 嵌入式系统的安全挑战

```
嵌入式系统安全挑战:

┌──────────────────────────────────────────────────────────┐
│ 1. 资源受限                                                │
│    - 内存有限 (KB-MB级)                                  │
│    - 计算能力受限                                         │
│    - 电池供电 (低功耗要求)                                │
│    - 无法运行复杂安全算法                                 │
├──────────────────────────────────────────────────────────┤
│ 2. 物理暴露                                                │
│    - 设备在物理上可被攻击者接触                            │
│    - 调试接口可被利用                                     │
│    - 存储芯片可被读取                                     │
│    - 总线可被嗅探                                         │
├──────────────────────────────────────────────────────────┤
│ 3. 长生命周期                                              │
│    - 部署后运行10-20年                                   │
│    - 难以更新补丁                                        │
│    - 安全机制可能过时                                     │
│    - 密码算法可能被破解                                   │
├──────────────────────────────────────────────────────────┤
│ 4. 供应链复杂                                              │
│    - 多个供应商组件                                       │
│    - 第三方库和固件                                       │
│    - 开源组件漏洞                                        │
│    - 供应链攻击风险                                       │
├──────────────────────────────────────────────────────────┤
│ 5. 网络连接性                                              │
│    - IoT设备直接连接互联网                                 │
│    - 缺乏网络隔离                                        │
│    - 攻击面增大                                         │
│    - 大规模僵尸网络风险                                   │
└──────────────────────────────────────────────────────────┘
```

### 1.2 嵌入式系统安全层次模型

```
嵌入式系统安全层次:

┌─────────────────────────────────────────────┐
│ 应用层安全                                    │
│  - 应用认证与授权                            │
│  - 数据加密与保护                            │
│  - 安全UI                                   │
├─────────────────────────────────────────────┤
│ 操作系统安全                                  │
│  - 进程隔离                                  │
│  - 内存保护 (MPU/MMU)                       │
│  - 权限管理                                  │
│  - 安全更新机制                              │
├─────────────────────────────────────────────┤
│ 硬件抽象层安全                                │
│  - 驱动安全                                  │
│  - DMA保护                                   │
│  - 中断安全                                  │
├─────────────────────────────────────────────┤
│ 硬件安全                                      │
│  - 安全启动 (Secure Boot)                    │
│  - 硬件加密引擎                              │
│  - 真随机数发生器 (TRNG)                     │
│  - 防篡改检测                                │
│  - 安全存储 (eFuse/OTP)                      │
│  - 调试接口保护                              │
├─────────────────────────────────────────────┤
│ 物理安全                                      │
│  - 芯片封装保护                              │
│  - 侧信道防护                                │
│  - 故障注入防护                              │
└─────────────────────────────────────────────┘
```
