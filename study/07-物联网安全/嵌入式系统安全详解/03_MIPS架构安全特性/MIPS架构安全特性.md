# MIPS架构安全特性

### 3.1 MIPS安全概述

```
MIPS安全特性:

1. 虚拟内存:
   - 32位地址空间 (MIPS32) / 64位 (MIPS64)
   - TLB (Translation Lookaside Buffer)
   - 固定映射段 (kseg0, kseg1, kuseg)

2. 特权级别:
   - User Mode
   - Kernel Mode
   - Debug Mode (EJTAG)

3. 安全扩展:
   - Virtualization (MIPS VZ)
   - 多线程 (MIPS MT)
   - DSP ASE (数字信号处理)

4. MIPS Warrior系列:
   - P5600: 多发射, 乱序执行
   - I6400: 64位多线程
   - M6250: 嵌入式多线程
```

### 3.2 MIPS内存段保护

```
MIPS内存段布局 (32位):

┌──────────────────┬──────────┬───────────────────────┐
│ 段                │ 地址范围  │ 特性                  │
├──────────────────┼──────────┼───────────────────────┤
│ kuseg            │ 0x00000000-│ 用户空间              │
│                  │ 0x7FFFFFFF │ 需TLB映射             │
├──────────────────┼──────────┼───────────────────────┤
│ kseg0            │ 0x80000000-│ 内核直接映射          │
│                  │ 0x9FFFFFFF │ 缓存, 无TLB          │
├──────────────────┼──────────┼───────────────────────┤
│ kseg1            │ 0xA0000000-│ 内核直接映射          │
│                  │ 0xBFFFFFFF │ 不缓存, 无TLB         │
├──────────────────┼──────────┼───────────────────────┤
│ kseg2            │ 0xC0000000-│ 内核可映射            │
│                  │ 0xDFFFFFFF │ 需TLB映射             │
├──────────────────┼──────────┼───────────────────────┤
│ kseg3            │ 0xE0000000-│ 内核可映射            │
│                  │ 0xFFFFFFFF │ 需TLB映射             │
└──────────────────┴──────────┴───────────────────────┘

安全风险:
- kseg0/kseg1在内核模式下可直接访问
- 无内存随机化 (ASLR)
- 固定地址布局便于攻击
```
