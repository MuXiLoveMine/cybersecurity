# 概述

物联网僵尸网络（IoT Botnet）是指利用物联网设备（如路由器、摄像头、DVR、智能家电等）的安全漏洞，将其感染并控制，形成可远程指挥的僵尸网络。与传统PC僵尸网络相比，IoT僵尸网络具有以下显著特征：

### 1.1 IoT僵尸网络特征

| 特征 | 传统PC僵尸网络 | IoT僵尸网络 |
|------|---------------|-------------|
| 设备数量 | 数千至数万 | 数十万至数百万 |
| 设备生命周期 | 3-5年 | 5-15年（难以修补漏洞） |
| 安全防护 | 杀毒软件/防火墙 | 几乎无防护 |
| 默认凭证 | 少见 | 大量使用默认密码 |
| 补丁能力 | 自动更新 | 多数无法更新 |
| 攻击带宽 | 平均1-10Mbps | 平均1-50Mbps每设备 |
| 持久性 | 重装可清除 | 重启后仍可感染 |

### 1.2 威胁影响

IoT僵尸网络造成的威胁包括但不限于：

- **超大规模DDoS攻击**：2016年Mirai攻击Dyn公司，导致美国东海岸大面积断网
- **数据窃取**：通过受控设备窃取网络流量中的敏感信息
- **代理跳板**：利用IoT设备作为攻击跳板，隐藏真实攻击来源
- **加密货币挖矿**：劫持设备算力进行挖矿
- **物理世界破坏**：通过控制智能家居设备造成物理伤害
