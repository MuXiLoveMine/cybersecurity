### 10.1 网络层检测

```python
# IoT僵尸网络检测系统
class BotnetDetector:
    """IoT僵尸网络检测引擎"""
    
    def __init__(self):
        self.flow_table = {}
        self.suspicious_ips = set()
        self.alert_rules = self._load_rules()
        
    def analyze_flow(self, flow: dict) -> bool:
        """分析网络流量"""
        suspicious = False
        
        # 规则1: 异常出站连接（Telnet/SSH）
        if flow['dst_port'] in [23, 2323, 22]:
            if flow['packets'] > 100 and flow['duration'] < 60:
                self._alert('SCAN_TELNET', flow)
                suspicious = True
        
        # 规则2: C2通信模式
        if self._check_c2_pattern(flow):
            self._alert('C2_COMMUNICATION', flow)
            suspicious = True
        
        # 规则3: DDoS出站流量
        if flow['bytes_out'] > 1000000 and flow['duration'] < 300:
            if flow['dst_port'] in [80, 443, 53, 123]:
                self._alert('DDOS_PARTICIPATION', flow)
                suspicious = True
        
        # 规则4: 异常DNS查询
        if flow['dst_port'] == 53:
            if self._check_dns_anomaly(flow):
                self._alert('DNS_TUNNELING', flow)
                suspicious = True
        
        # 规则5: P2P通信模式
        if self._check_p2p_pattern(flow):
            self._alert('P2P_BOTNET', flow)
            suspicious = True
        
        return suspicious
    
    def _check_c2_pattern(self, flow: dict) -> bool:
        """检测C2通信模式"""
        # Mirai C2特征: 固定间隔心跳包
        if flow['src_port'] in [23, 2323, 8443, 457]:
            if self._check_heartbeat_pattern(flow):
                return True
        
        # 定期连接同一外部IP
        if flow['dst_ip'] in self.flow_table:
            connections = self.flow_table[flow['dst_ip']]
            if len(connections) > 10 and all(
                c['interval'] < 300 for c in connections
            ):
                return True
        
        return False
    
    def _check_p2p_pattern(self, flow: dict) -> bool:
        """检测P2P僵尸网络通信"""
        # Mozi P2P特征:
        # - 大量不同目的IP的小数据包
        # - 固定大小的数据包
        # - DHT查询模式
        
        if flow['bytes_out'] < 500 and flow['bytes_in'] < 500:
            # 检查是否有大量不同目标
            peers = self._get_recent_peers(flow['src_ip'])
            if len(peers) > 50:  # 50+不同目标
                return True
        
        return False
```

### 10.2 设备层防御

#### 10.2.1 设备加固清单

```
IoT设备安全加固检查表:

[ ] 修改默认密码（强密码：12+字符，字母数字特殊字符）
[ ] 禁用Telnet，使用SSH
[ ] 关闭不必要的服务（UPnP, TR-069等）
[ ] 更新固件到最新版本
[ ] 禁用远程管理（如需远程，使用VPN）
[ ] 配置防火墙规则（仅允许必要端口）
[ ] 启用日志审计
[ ] 网络隔离（IoT设备在独立VLAN/网段）
[ ] 禁用UPnP
[ ] 修改默认管理端口
[ ] 启用设备认证（证书认证优于密码）
[ ] 配置SNMP v3（禁用v1/v2c）
```

### 10.3 ISP级防御

```
ISP层面的僵尸网络防御:

1. 源地址验证(uRPF)
   - 丢弃源IP地址不合法的数据包
   - 防止IP欺骗

2. 流量清洗
   - 检测异常流量模式
   - 对DDoS流量进行限速/丢弃
   - 黑洞路由

3. CGNAT日志
   - 记录NAT映射关系
   - 追踪恶意流量来源

4. Botnet C2封锁
   - 维护C2 IP黑名单
   - DNS Sinkhole
   - 与安全厂商共享威胁情报

5. 客户通知
   - 检测到C2通信时通知客户
   - 临时隔离受感染设备
   - 提供修复指导
```
