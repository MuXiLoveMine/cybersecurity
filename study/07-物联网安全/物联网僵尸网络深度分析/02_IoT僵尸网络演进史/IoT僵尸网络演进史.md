# IoT僵尸网络演进史

### 2.1 第一代：简单扫描感染（2013-2015）

最早的IoT僵尸网络主要利用Telnet弱密码进行传播：

```
感染流程:
1. 随机生成IP地址
2. 尝试Telnet连接（端口23）
3. 使用默认凭证字典爆破密码
4. 成功后植入ELF可执行文件
5. 连接C2服务器接收指令
```

典型代表：Bashlite（又称Gafgyt/Lizamoon）、Qbot（又称Baidu）

### 2.2 第二代：高效传播（2016）

Mirai的出现标志着IoT僵尸网络进入新阶段：

- 引入高效SYN扫描机制
- 预置60+默认凭证组合
- 自适应架构（x86/ARM/MIPS等）
- 单日感染峰值可达40万台设备

### 2.3 第三代：漏洞利用蠕虫（2017-2018）

从依赖弱密码转向利用N-day漏洞传播：

| 僵尸网络 | 利用漏洞 | CVE编号 |
|----------|---------|---------|
| Reaper | D-Link路由器RCE | CVE-2017-8225 |
| IoTroop | 多厂商设备漏洞 | 多个CVE |
| VPNFilter | VPN路由器漏洞 | 多个CVE |
| Omni | 多种路由器漏洞 | 多个CVE |

### 2.4 第四代：P2P去中心化（2019-至今）

以Mozi为代表的P2P僵尸网络：

- 无中心C2服务器
- 通过DHT（分布式哈希表）进行节点发现
- 使用ECC椭圆曲线加密通信
- 极难通过关闭C2服务器来消灭

### 2.5 第五代：智能自动化（2020-至今）

最新趋势包括：

- 自动化漏洞挖掘与利用
- 利用AI进行目标选择优化
- 跨平台感染能力（IoT+云+边缘）
- 自适应防御规避机制
