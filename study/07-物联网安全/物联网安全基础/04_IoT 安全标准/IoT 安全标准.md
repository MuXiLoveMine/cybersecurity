# IoT 安全标准

### 4.1 国际标准

#### 4.1.1 ITU-T X.1035

**标准名称**：《物联网安全指南》（Security guidelines for the Internet of Things）

**发布机构**：国际电信联盟电信标准化部门（ITU-T）

**主要内容**：
- 物联网安全威胁识别
- 物联网安全需求
- 物联网安全架构
- 各层安全指南（感知层、网络层、应用层）
- 身份管理和隐私保护
- 安全管理和运维

**核心安全需求**：
1. **可用性**：确保 IoT 服务和数据可用
2. **完整性**：确保数据和设备状态的完整性
3. **保密性**：保护敏感数据不被未授权访问
4. **真实性**：确保设备和数据的真实性
5. **可追溯性**：确保操作可审计和追溯
6. **隐私保护**：保护个人隐私信息

#### 4.1.2 ISO/IEC 27030

**标准名称**：《信息技术 安全技术 物联网安全与隐私指南》（Information technology — Security techniques — Guidelines for security and privacy in the Internet of Things (IoT)）

**发布机构**：国际标准化组织/国际电工委员会（ISO/IEC）

**主要内容**：
- IoT 安全概念和模型
- IoT 安全风险
- IoT 安全控制
- IoT 隐私保护
- 实施指南

**适用范围**：
- IoT 系统设计者和开发者
- IoT 服务提供商
- IoT 安全评估人员
- IoT 设备制造商

#### 4.1.3 ISO/IEC 27001 / 27002

**ISO/IEC 27001**：信息安全管理体系（ISMS）要求标准
- 提供信息安全管理体系的建立、实施、维护和持续改进的要求
- 可用于物联网企业的信息安全管理

**ISO/IEC 27002**：信息安全控制实践指南
- 提供详细的信息安全控制措施
- 可作为物联网安全控制的参考

#### 4.1.4 NIST 物联网安全标准

**NIST SP 800-160**：系统安全工程
- 系统安全工程的框架和方法
- 可应用于物联网系统的安全设计

**NIST SP 800-183**：物联网网络安全
- 物联网设备网络安全基线
- 设备安全能力分类

**NIST IR 8259**：物联网设备网络安全基线
- 定义物联网设备的最低安全要求
- 包括：设备标识、配置管理、数据保护、接口安全、软件更新、网络安全、状态感知

#### 4.1.5 IETF 相关标准

IETF（互联网工程任务组）制定了多项与物联网安全相关的 RFC：

| 标准编号 | 名称 | 说明 |
|---------|------|------|
| RFC 7228 | 受限节点网络术语定义 | 定义了受限设备的分类和术语 |
| RFC 7252 | CoAP 协议 | 受限应用协议 |
| RFC 7925 | TLS/DTLS 1.3 剖析 | 针对 IoT 设备的 TLS 配置 |
| RFC 8128 | CoAP 通用安全 | CoAP 的安全框架 |
| RFC 8240 | OSCAR | 受限环境下的对象安全 |

### 4.2 国内标准

#### 4.2.1 网络安全等级保护制度（等保 2.0）

**标准体系**：
- **GB/T 22239-2019**：《信息安全技术 网络安全等级保护基本要求》
- **GB/T 25070-2019**：《信息安全技术 网络安全等级保护安全设计技术要求》
- **GB/T 28448-2019**：《信息安全技术 网络安全等级保护测评要求》

**物联网扩展要求**：
等保 2.0 针对物联网安全提出了专门的扩展要求，主要包括：

**感知节点安全**：
- 感知节点应具有唯一标识，确保节点身份可识别
- 感知节点应具备防篡改能力
- 感知节点应支持身份认证，防止非法节点接入
- 关键感知节点应支持通信数据加密

**感知网关安全**：
- 应支持感知节点的接入认证
- 应支持感知节点数据的汇聚和转发安全
- 应具备协议转换的安全保障
- 应支持感知节点的管理和控制

**物联网安全管理**：
- 应建立物联网设备台账
- 应实施物联网设备全生命周期管理
- 应建立物联网安全监控和应急响应机制

#### 4.2.2 GB/T 36958-2018

**标准名称**：《信息安全技术 网络安全等级保护测评要求》

**内容概述**：规定了不同安全保护等级下，等级保护对象的安全测评要求，包括安全物理环境、安全通信网络、安全区域边界、安全计算环境、安全管理中心五个层面，以及针对物联网的扩展测评要求。

#### 4.2.3 GB/T 35273-2020

**标准名称**：《信息安全技术 个人信息安全规范》

**与物联网的关系**：
- 物联网设备收集大量个人信息
- 规范个人信息的收集、存储、使用、共享等
- 对智能设备的权限申请、数据最小化等提出要求

### 4.3 行业安全标准

#### 4.3.1 医疗物联网安全

- **IEC 80001-1**：医疗设备网络安全风险管理
- **IEC 62443**：工业自动化和控制系统安全（可应用于医疗设备）
- **FDA 上市前指南**：医疗设备网络安全指南

#### 4.3.2 车联网安全

- **ISO 21434**：道路车辆网络安全工程
- **UNECE R155**：车辆网络安全管理体系
- **GB 汽车数据安全管理若干规定**：中国汽车数据安全法规
