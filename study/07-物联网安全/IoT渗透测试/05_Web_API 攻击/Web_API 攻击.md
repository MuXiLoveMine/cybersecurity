# Web/API 攻击

### 5.1 IoT 设备 Web 界面

很多 IoT 设备提供 Web 管理界面，是重要的攻击面。

#### 5.1.1 常见 Web 漏洞

| 漏洞类型 | IoT 场景示例 |
|---------|-------------|
| **弱口令** | 管理后台使用默认密码（admin/admin） |
| **命令注入** | Ping/Traceoute 功能将用户输入拼接到系统命令 |
| **身份认证绕过** | 直接访问管理页面，无需登录 |
| **CSRF** | 没有 CSRF 防护，可诱导管理员执行操作 |
| **XSS** | 设备名称等字段未过滤，可注入脚本 |
| **信息泄露** | 错误页面泄露敏感信息 |
| **未授权 API 访问** | API 接口不需要认证即可调用 |
| **固件上传漏洞** | 固件上传功能可上传恶意固件 |

#### 5.1.2 命令注入测试

IoT 设备的 Web 界面经常有命令注入漏洞，因为很多功能通过调用系统命令实现。

**常见注入点**：
- Ping / Traceroute 功能（IP 地址参数）
- 系统诊断功能
- 文件上传（文件名注入）
- 设备名称/位置等配置项
- NTP 服务器配置
- DDNS 配置

**测试方法**：
```
# 测试命令分隔符
127.0.0.1; id
127.0.0.1| id
127.0.0.1&& id
127.0.0.1 || id

# 测试反引号
`id`
$(id)

# 测试重定向（验证命令执行）
127.0.0.1; cat /etc/passwd > /www/passwd.txt
# 然后访问 http://device/passwd.txt
```

**真实案例**：某品牌路由器的 ping 功能存在命令注入漏洞，通过在 IP 地址中注入 `;命令` 可以执行任意系统命令，获取 root 权限。

### 5.2 云 API 攻击

IoT 设备通常连接到云平台，云 API 是重要的攻击面。

#### 5.2.1 API 发现

**发现 API 的方法**：
1. 抓包分析：在设备和 APP 通信时抓包
2. APP 逆向：反编译移动 APP，查找 API 地址和密钥
3. 固件分析：从固件中提取 API 相关信息
4. 文档泄露：查找公开的 API 文档

#### 5.2.2 常见 API 安全问题

| 问题类型 | 说明 | 风险 |
|---------|------|------|
| **硬编码 API Key** | API 密钥硬编码在 APP/固件中 | 密钥泄露，可冒充设备 |
| **弱认证** | API 认证机制不完善 | 未授权访问 |
| **越权访问** | 可访问其他用户的设备和数据 | 数据泄露、设备控制 |
| **注入攻击** | API 参数存在注入漏洞 | 数据泄露、代码执行 |
| **无速率限制** | API 没有调用频率限制 | 暴力破解、枚举 |
| **敏感数据泄露** | API 返回过多敏感信息 | 信息泄露 |

#### 5.2.3 越权访问测试

**水平越权**：访问同级别其他用户的资源
```
正常：/api/device?device_id=12345（自己的设备）
测试：/api/device?device_id=12346（别人的设备）
```

**垂直越权**：访问高级别权限的功能
```
普通用户：/api/user/info
测试：/api/admin/users
```

**IDOR（不安全的直接对象引用）**：
- 修改请求中的设备 ID
- 修改用户 ID
- 修改资源 ID

### 5.3 移动 APP 关联分析

IoT 设备通常配有移动 APP，通过分析 APP 可以发现大量安全问题。

#### 5.3.1 APP 分析内容

1. **API 接口发现**：反编译 APP，提取 API 地址和参数
2. **硬编码凭证**：查找硬编码的 API Key、密钥、密码
3. **认证机制分析**：分析 APP 的认证流程
4. **本地数据存储**：检查本地存储的敏感数据
5. **通信安全**：检查是否使用 HTTPS、证书验证
6. **组件安全**：检查 Activity、Service 等组件是否可导出

#### 5.3.2 分析工具

| 工具 | 用途 |
|------|------|
| apktool | APK 反编译 |
| jadx | DEX 反编译为 Java |
| Frida | 动态插桩、Hook |
| MobSF | 移动 APP 安全分析框架 |
| Burp Suite | 抓包分析 API 通信 |
| drozer | Android 安全测试框架 |

#### 5.3.3 分析步骤

```
1. APK 反编译
   ├─> 提取资源文件
   ├─> 反编译 smali/dex
   └─> 查找硬编码字符串

2. API 分析
   ├─> 配置 Burp 抓包
   ├─> 分析 API 接口
   ├─> 测试认证和授权
   └─> 测试越权访问

3. 动态分析
   ├─> Frida Hook 关键函数
   ├─> 绕过证书固定
   └─> 分析运行时行为
```

### 5.4 云平台攻击面

#### 5.4.1 云平台架构

```
┌─────────────────────────────────────────┐
│              移动 APP                   │
└───────────────┬─────────────────────────┘
                │ HTTPS/API
┌───────────────▼─────────────────────────┐
│              云平台                     │
│  ┌─────────┐  ┌─────────┐  ┌────────┐ │
│  │ API 网关 │  │ 设备管理 │  │ 数据分析│ │
│  └─────────┘  └─────────┘  └────────┘ │
│  ┌─────────┐  ┌─────────┐  ┌────────┐ │
│  │ 用户管理 │  │ 消息队列 │  │ 存储服务│ │
│  └─────────┘  └─────────┘  └────────┘ │
└───────────────┬─────────────────────────┘
                │ MQTT/CoAP/HTTPS
┌───────────────▼─────────────────────────┐
│              IoT 设备                   │
└─────────────────────────────────────────┘
```

#### 5.4.2 常见云平台安全问题

1. **设备身份伪造**：冒充合法设备连接云平台
2. **API 越权**：通过 API 访问其他用户的设备
3. **租户隔离问题**：多租户环境下的数据泄露
4. **消息队列安全**：MQTT/AMQP 配置不当
5. **对象存储泄露**：云存储桶配置错误导致数据泄露
6. **固件更新安全**：固件分发和更新的安全问题
7. **日志和监控不足**：缺乏安全监控和告警
