| | TL866II+ | 通用编程器 |

| | 逻辑分析仪 | 数字信号分析 |
| | 示波器 | 模拟信号分析 |
| | 直流稳压电源 | 设备供电 |
| **焊接工具** | 电烙铁 | 焊接 |
| | 热风枪 | 拆焊芯片 |

| **无线工具** | Ubertooth One | BLE 抓包和注入 |
| | nRF52840 Dongle | BLE 开发和抓包 |
| | KillerBee + ApiMote | ZigBee 安全测试 |

| **其他** | 树莓派 | 测试平台 |
