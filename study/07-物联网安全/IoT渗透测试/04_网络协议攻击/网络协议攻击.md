# 网络协议攻击

### 4.1 网络服务发现

#### 4.1.1 端口扫描

使用 Nmap 扫描设备开放的端口和服务。

```bash
# 全端口扫描
nmap -p- 192.168.1.100

# 服务识别和版本探测
nmap -sV -p- 192.168.1.100

# 脚本扫描（安全相关）
nmap -sV --script=safe 192.168.1.100

# 常见 IoT 端口扫描
nmap -p 21,22,23,80,443,1883,5683,8080,8443,9090 192.168.1.100
```

#### 4.1.2 常见 IoT 端口和服务

| 端口 | 协议/服务 | 说明 |
|------|----------|------|
| 21 | FTP | 文件传输 |
| 22 | SSH | 安全登录 |
| 23 | Telnet | 远程登录（不安全，常见弱口令） |
| 80 | HTTP | Web 管理界面 |
| 443 | HTTPS | 加密 Web 管理 |
| 1883 | MQTT | 消息队列遥测传输 |
| 5683 | CoAP | 受限应用协议 |
| 502 | Modbus | 工业控制协议 |
| 2404 | IEC 60870-5-104 | 电力系统协议 |
| 8080 | HTTP 代理/备用 | Web 服务备用端口 |
| 8443 | HTTPS 备用 | 加密 Web 备用端口 |
| 9090 | HTTP 备用 | Web 服务备用端口 |
| 8883 | MQTT/TLS | 加密 MQTT |

### 4.2 MQTT 协议攻击

详见《IoT通信协议安全.md》和 `iot_mqtt_security.py` 工具。

**常见攻击方式**：
1. 匿名访问检测
2. 弱口令暴力破解
3. 主题嗅探和信息收集
4. 越权发布消息
5. 中间人攻击（未启用 TLS 时）
6. 拒绝服务攻击

### 4.3 CoAP 协议攻击

**常见攻击方式**：
1. 资源发现（`/.well-known/core`）
2. 未授权访问资源
3. CoAP 放大攻击（DDoS）
4. 重放攻击
5. 协议模糊测试

### 4.4 无线协议攻击

#### 4.4.1 WiFi 攻击

如果设备通过 WiFi 连接：
- WiFi 密码破解（WPA/WPA2）
- Evil Twin 攻击
- 中间人攻击
- 端口扫描和服务发现

#### 4.4.2 BLE 攻击

详见《IoT通信协议安全.md》。

**常见攻击方式**：
1. BLE 设备扫描
2. 服务和特征发现
3. 未授权读写
4. 配对攻击（中间人）
5. 重放攻击
6. 嗅探通信

#### 4.4.3 ZigBee 攻击

**常见攻击方式**：
1. 信道扫描和设备发现
2. 网络密钥获取
3. 加入网络
4. 设备欺骗
5. 重放攻击

### 4.5 协议模糊测试

对设备的网络服务进行模糊测试，发现内存破坏类漏洞。

**常用工具**：
- Boofuzz：Python 协议模糊测试框架
- AFL：覆盖率引导的模糊测试
- Peach：商业模糊测试平台
