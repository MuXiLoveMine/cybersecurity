# 固件分析

固件分析是 IoT 渗透测试的核心环节，详细内容请参考《IoT固件安全.md》。

### 3.1 固件获取（渗透测试视角）

在渗透测试中，获取固件的优先级顺序：

1. **官方下载**：最简单，优先尝试
2. **OTA 抓包**：通过监听设备更新获取
3. **UART 读取**：通过串口从 bootloader 读取
4. **JTAG/SWD 读取**：通过调试接口读取
5. **拆芯片读取**：最可靠但有破坏性

### 3.2 固件分析流程（渗透测试）

```
固件获取
    │
    ▼
固件解包（binwalk / FMK）
    │
    ▼
信息收集 ────────────────────────┐
    │                            │
    ├─> 用户/密码/密钥           │
    ├─> 服务和端口               │
    ├─> Web 界面源码             │
    └─> 配置文件                 │
                                 │
    ▼                            │
二进制分析  <────────────────────┘
    │
    ├─> 危险函数查找
    ├─> 认证逻辑分析
    ├─> 命令注入查找
    └─> 缓冲区溢出查找
    │
    ▼
漏洞验证（QEMU / 真实设备）
    │
    ▼
漏洞利用
```

### 3.3 重点关注的漏洞类型

1. **硬编码凭证**：最快的突破口
2. **命令注入**：Web 接口和管理功能中常见
3. **认证绕过**：直接获取设备控制权
4. **缓冲区溢出**：可能实现代码执行
5. **后门账户**：厂商预留的调试账户
