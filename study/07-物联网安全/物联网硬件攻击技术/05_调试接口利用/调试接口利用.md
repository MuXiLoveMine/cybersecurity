# 调试接口利用

### 5.1 UART串口利用

```
UART (Universal Asynchronous Receiver/Transmitter):

引脚:
  TX (发送)
  RX (接收)
  GND (地)
  VCC (电源, 可选)

发现UART引脚:
1. 视觉检查:
   - 查看PCB上4个连排的焊盘
   - 标注: TX, RX, GND, VCC
   - 或无标注的测试点

2. 万用表测量:
   - GND: 对地电阻为0
   - VCC: 对地电压3.3V或5V
   - TX: 空闲时为高电平
   - RX: 空闲时为高电平

3. 逻辑分析仪:
   - 连接可能的TX引脚
   - 观察是否有数据波形
   - 确定波特率

常用波特率:
  9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600

连接方法:
  设备TX -> 适配器RX
  设备RX -> 适配器TX
  设备GND -> 适配器GND
  (不连接VCC, 除非需要供电)
```

```bash
# UART交互示例

# 1. 连接USB-TTL适配器
# 设备: USB转串口模块 (CP2102/CH340/FT232)

# 2. 使用minicom/picocom连接
picocom -b 115200 /dev/ttyUSB0
# 或
minicom -D /dev/ttyUSB0 -b 115200

# 3. 波特率自动检测
# 使用python脚本扫描波特率
python3 -c "
import serial
import time

for baud in [9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600]:
    try:
        s = serial.Serial('/dev/ttyUSB0', baud, timeout=1)
        s.write(b'\n')
        time.sleep(0.5)
        data = s.read(1024)
        if data:
            print(f'波特率 {baud}: 收到 {len(data)} bytes: {data[:50]}')
        s.close()
    except:
        pass
"

# 4. 获取Shell
# 很多设备在启动时输出调试信息
# 可能需要按键中断启动流程
# 尝试的按键: Enter, Space, Ctrl+C, Esc, 任意键

# 5. Bootloader Shell
# U-Boot常见命令
=> help              # 帮助
=> printenv          # 环境变量
=> bdinfo           # 板级信息
=> bootm            # 启动内核
=> tftpboot         # TFTP下载
=> md 0x80000000    # 显示内存
=> mw 0x80000000 0x12345678 1  # 写内存
=> cp 0x80000000 0x90000000 0x1000  # 复制内存

# 6. Linux Shell
# 获取Shell后:
# 检查root权限
id
# 查看文件系统
ls -la /
cat /etc/passwd
# 查看网络配置
ifconfig -a
# 查看进程
ps aux
# 查看固件版本
cat /etc/version
cat /proc/version
```

### 5.2 JTAG利用

```
JTAG (Joint Test Action Group):

引脚:
  TCK (Test Clock)    - 时钟
  TMS (Test Mode Select) - 模式选择
  TDI (Test Data In)  - 数据输入
  TDO (Test Data Out) - 数据输出
  TRST (Test Reset)   - 复位 (可选)
  GND (地)

发现JTAG引脚:
1. 视觉检查:
   - 5-6个连排焊盘/测试点
   - 有时标注JTAG/TCK/TMS等

2. JTAGulator工具:
   - 自动识别JTAG引脚排列
   - 通过暴力测试确定TCK/TMS/TDI/TDO

3. 电阻测量:
   - TCK/TMS通常有上拉电阻 (4.7k-10k)
   - TDO通常直接连接或弱下拉
   - GND对地电阻0

JTAG利用工具:
  - OpenOCD (开源)
  - J-Link (商业)
  - ST-Link (ST免费)
  - Bus Pirate (开源)
```

```bash
# OpenOCD JTAG操作示例

# 1. 安装OpenOCD
apt-get install openocd

# 2. 配置文件
# openocd.cfg
source [find interface/jtagkey.cfg]    # 适配器
source [find target/stm32f4x.cfg]      # 目标芯片

# 3. 连接目标
openocd -f openocd.cfg

# 4. 在另一个终端使用telnet连接
telnet localhost 4444

# 5. JTAG操作
> reset halt                  # 复位并暂停CPU
> jtag arp_init              # 初始化JTAG链
> scan_chain                 # 查看扫描链
> dap info 0                 # 调试访问端口信息
> mdw 0x08000000 0x100       # 读取Flash内存
> mww 0x20000000 0xDEADBEEF  # 写入内存
> reg                        # 查看寄存器
> reg pc 0x08001000         # 设置PC
> step                       # 单步执行
> bp 0x08001000 2 hw        # 设置硬件断点
> resume                     # 继续执行

# 6. 读取Flash
> flash probe 0              # 探测Flash
> flash info 0               # Flash信息
> flash read_bank 0 firmware.bin 0 0x400000  # 读取Flash到文件

# 7. 注入代码
# 加载并执行任意代码
> load_image code.bin 0x20000000
> resume 0x20000000
```

### 5.3 SWD利用

```
SWD (Serial Wire Debug):

引脚:
  SWCLK (时钟)
  SWDIO (数据)
  GND (地)
  VCC (电源, 可选)

优势(相比JTAG):
  - 仅需2个数据线
  - 同样功能强大
  - 适用于引脚有限的设备

工具:
  - ST-Link (STM32)
  - J-Link (通用)
  - Bus Pirate (开源)
  - Black Magic Probe
```

```bash
# SWD操作示例 (使用OpenOCD)

# 配置文件
# openocd_swd.cfg
source [find interface/stlink.cfg]      # ST-Link适配器
transport select swd                    # 选择SWD模式
source [find target/stm32f4x.cfg]

# 连接
openocd -f openocd_swd.cfg

# Telnet操作
> reset halt
> swj_scan                   # SWD扫描
> mdw 0x1FFF0000 0x10        # 读取选项字节
> flash read_bank 0 dump.bin 0 0x80000  # 读取Flash
> ftfm device 0 info         # Flash信息
```
