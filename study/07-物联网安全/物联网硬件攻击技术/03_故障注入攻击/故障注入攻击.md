# 故障注入攻击

### 3.1 电压毛刺注入

```
电压毛刺 (Voltage Glitching):

通过在芯片电源中注入短暂的电压变化(毛刺), 导致电路异常工作。

原理:
  电压骤降 -> 晶体管不满足开关条件 -> 跳过指令/错误计算
  电压骤升 -> 晶体管异常导通 -> 数据损坏

攻击目标:
  - 跳过安全检查 (如密码验证)
  - 跳过循环计数
  - 破坏条件分支
  - 修改寄存器值

电压毛刺参数:
  - 毛刺类型: 负压/正压
  - 毛刺幅度: -3V ~ +3V (相对于Vcc)
  - 毛刺宽度: 1ns ~ 100ns
  - 毛刺时机: 精确到时钟周期
```

```python
#!/usr/bin/env python3
"""电压毛刺注入控制工具"""
import serial
import time
import struct

class VoltageGlitcher:
    """电压毛刺注入控制器"""
    
    def __init__(self, port='/dev/ttyUSB0', baud=115200):
        self.ser = serial.Serial(port, baud, timeout=1)
        self.target_voltage = 3.3
        self.glitch_type = 'negative'  # negative/positive
        self.glitch_voltage = 0.0      # 毛刺电压
        self.glitch_width_ns = 10       # 毛刺宽度(纳秒)
        self.glitch_delay_us = 0       # 触发后延迟(微秒)
    
    def set_glitch_params(self, voltage, width_ns, delay_us=0):
        """设置毛刺参数"""
        self.glitch_voltage = voltage
        self.glitch_width_ns = width_ns
        self.glitch_delay_us = delay_us
    
    def arm_glitch(self):
        """装载毛刺参数"""
        # 构建命令包
        # 格式: [CMD] [Voltage] [Width] [Delay]
        cmd = b'\x01'  # ARM命令
        cmd += struct.pack('>f', self.glitch_voltage)
        cmd += struct.pack('>I', self.glitch_width_ns)
        cmd += struct.pack('>I', self.glitch_delay_us)
        
        self.ser.write(cmd)
        response = self.ser.read(4)
        
        if response == b'OKAY':
            return True
        return False
    
    def trigger_glitch(self):
        """触发毛刺"""
        self.ser.write(b'\x02')  # TRIGGER命令
        response = self.ser.read(4)
        return response == b'OKAY'
    
    def sweep_parameters(self, target_command):
        """参数扫描 - 自动寻找最佳毛刺参数"""
        results = []
        
        # 电压范围扫描
        voltages = [-0.5, -1.0, -1.5, -2.0, -2.5, -3.0, 0.5, 1.0, 1.5, 2.0]
        # 宽度范围扫描
        widths = [5, 10, 20, 50, 100, 200]
        # 延迟范围扫描
        delays = [0, 1, 5, 10, 50, 100, 500, 1000]
        
        for voltage in voltages:
            for width in widths:
                for delay in delays:
                    self.set_glitch_params(voltage, width, delay)
                    
                    if self.arm_glitch():
                        # 发送目标命令
                        # 触发毛刺
                        self.trigger_glitch()
                        
                        # 检查结果
                        result = self.check_result()
                        
                        results.append({
                            'voltage': voltage,
                            'width': width,
                            'delay': delay,
                            'result': result,
                        })
                        
                        if result == 'success':
                            print(f"[!] 找到有效参数!")
                            print(f"    电压: {voltage}V")
                            print(f"    宽度: {width}ns")
                            print(f"    延迟: {delay}us")
                            return results
                    
                    time.sleep(0.1)
        
        return results
    
    def check_result(self):
        """检查毛刺效果"""
        # 读取目标设备响应
        response = self.ser.read(1024)
        
        if b'access granted' in response.lower():
            return 'success'
        elif b'error' in response.lower():
            return 'error'
        elif b'crash' in response.lower() or len(response) == 0:
            return 'crash'
        else:
            return 'normal'
```

### 3.2 时钟毛刺注入

```
时钟毛刺 (Clock Glitching):

通过在时钟信号中注入毛刺, 导致芯片时序异常。

原理:
  正常时钟: ────┐┌────┐┌────┐┌────
                ││    ││    ││
                └┘    └┘    └┘
  
  时钟毛刺: ────┐┌──┐┌────┐┌────
                ││  ││    ││
                └┘  └┘    └┘
                    ↑
              额外的时钟边沿

  额外的时钟脉冲 -> 指令计数器跳变 -> 跳过指令

攻击效果:
  - 跳过安全检查
  - 跳过循环迭代
  - 破坏条件跳转
  - 导致指令对齐错误

设备:
  - 信号发生器
  - 时钟注入探头
  - 精确时序控制
  - 示波器监控
```

### 3.3 电磁脉冲注入

```
EMFI (Electromagnetic Fault Injection):

通过电磁脉冲在芯片特定位置注入故障。

原理:
  强电磁脉冲 -> 感应电流 -> 晶体管异常

优势:
  - 不需要直接电气接触
  - 空间定位精确
  - 可绕过某些硬件保护
  - 毛刺参数可调

设备:
  - 电磁脉冲探头
  - 脉冲发生器
  - XYZ精密定位平台
  - 示波器

参数:
  - 脉冲电压: 50V - 500V
  - 脉冲宽度: 1ns - 100ns
  - 脉冲位置: 芯片表面精确坐标
  - 触发时机: 精确到时钟周期
```

### 3.4 激光故障注入

```
LFI (Laser Fault Injection):

使用激光在芯片特定位置注入故障。

原理:
  激光照射 -> 半导体中产生电子-空穴对 -> 晶体管异常导通

优势:
  - 极高的空间分辨率 (亚微米级)
  - 可以精确定位到单个晶体管
  - 可以从芯片背面注入
  - 非接触式

设备:
  - 激光器 (红光/红外)
  - 光学显微镜
  - XYZ精密定位平台
  - 光学系统

成本: $10000-$100000+
```
