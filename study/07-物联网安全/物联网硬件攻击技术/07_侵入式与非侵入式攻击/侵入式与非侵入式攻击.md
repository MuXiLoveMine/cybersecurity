# 侵入式与非侵入式攻击

### 6.1 非侵入式攻击

```
非侵入式攻击特征:

定义:
  不破坏芯片封装, 不修改硬件
  仅通过外部接口或物理测量进行攻击

方法:
  - 侧信道分析 (功耗/电磁/时间)
  - 故障注入 (电压/时钟/电磁)
  - 调试接口利用 (JTAG/SWD/UART)
  - 固件提取 (从外部Flash读取)
  - 总线嗅探

特点:
  - 设备保持完好
  - 可重复使用
  - 难以检测
  - 成本相对较低
  - 不需要昂贵的实验室设备
```

### 6.2 侵入式攻击

```
侵入式攻击特征:

定义:
  破坏芯片封装, 直接访问内部电路
  可能修改硬件结构

方法:
  - 芯片去封装
  - 电路逆向工程
  - 探针直接读取总线
  - FIB电路修改
  - 存储器直接读取
  - eFuse修改

特点:
  - 设备被破坏
  - 需要专业实验室设备
  - 成本极高
  - 信息获取最完整
  - 通常由专业实验室进行
```

### 6.3 半侵入式攻击

```
半侵入式攻击:

定义:
  去除封装但不去除钝化层
  不直接接触内部电路

方法:
  - UV光擦除保护位
  - 红外激光故障注入
  - 从背面接近芯片

特点:
  - 介于侵入和非侵入之间
  - 设备可能损坏也可能不损坏
  - 成本中等
  - 效果较好
```
