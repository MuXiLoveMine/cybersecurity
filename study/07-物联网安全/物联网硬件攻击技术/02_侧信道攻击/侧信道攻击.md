# 侧信道攻击

### 2.1 功耗分析攻击

```
功耗分析攻击原理:

芯片在处理不同数据时, 晶体管开关数量不同, 导致功耗变化。
通过测量和分析功耗变化, 可以推断出芯片内部处理的数据。

功耗模型:
  P = P_static + P_dynamic
  P_static: 静态功耗 (漏电流)
  P_dynamic: 动态功耗 = C * V^2 * f * α

  其中:
    C: 电容
    V: 电压
    f: 频率
    α: 活动因子

功耗与数据的关系:
  当数据从0变1或1变0时, 晶体管翻转, 功耗增加
  汉明重量(Hamming Weight): 数据中1的个数
  汉明距离(Hamming Distance): 前后数据不同的位数

  功耗 ∝ 汉明重量 (绝对功耗模型)
  功耗 ∝ 汉明距离 (差分功耗模型)
```

#### 2.1.1 简单功耗分析 (SPA)

```
SPA (Simple Power Analysis):

直接观察功耗轨迹, 通过肉眼识别操作阶段和密钥相关模式。

攻击步骤:
1. 用示波器测量设备功耗
2. 触发加密操作
3. 录制功耗波形
4. 肉眼分析波形特征

示例: RSA中平方和乘法操作的功耗差异
  - 平方操作: 功耗模式A
  - 乘法操作: 功耗模式B (更高)
  
  通过观察功耗模式序列, 可以推断RSA密钥:
  模式A, A, B, A, B, A, A, B...
  对应密钥位:  0, 0, 1, 0, 1, 0, 0, 1...
```

#### 2.1.2 差分功耗分析 (DPA)

```
DPA (Differential Power Analysis):

统计分析大量功耗轨迹, 提取密钥相关信息。

攻击流程:
1. 收集大量(1000-100000)功耗轨迹
2. 对每条轨迹, 已知明文/密文
3. 对每个可能的密钥猜测:
   a. 计算中间值 (如S盒输出)
   b. 根据中间值的某一位(如LSB)分组
   c. 计算两组功耗轨迹的差分均值
4. 差分峰值对应的密钥猜测即为正确密钥

DPA攻击伪代码:
```

```python
#!/usr/bin/env python3
"""DPA (差分功耗分析) 攻击框架"""
import numpy as np
from collections import defaultdict

class DPAAttack:
    """DPA攻击框架"""
    
    def __init__(self, traces, plaintexts, ciphertexts):
        """
        参数:
            traces: 功耗轨迹数组 (N x T, N=轨迹数, T=采样点数)
            plaintexts: 明文数组 (N,)
            ciphertexts: 密文数组 (N,)
        """
        self.traces = np.array(traces)
        self.plaintexts = np.array(plaintexts)
        self.ciphertexts = np.array(ciphertexts)
        self.num_traces = len(traces)
        self.num_samples = len(traces[0]) if self.num_traces > 0 else 0
    
    def attack_sbox_last_round(self, sbox, key_range=256):
        """
        攻击AES最后一轮S盒
        
        参数:
            sbox: AES S盒查找表
            key_range: 密钥搜索范围
        """
        best_key = 0
        best_correlation = 0
        results = {}
        
        for key_guess in range(key_range):
            # 计算中间值
            intermediate_values = []
            for i in range(self.num_traces):
                ct = self.ciphertexts[i]
                # AES最后一轮: S盒逆变换
                intermediate = sbox[ct ^ key_guess]
                intermediate_values.append(intermediate)
            
            # 选择函数: 中间值的LSB
            selection_values = [v & 1 for v in intermediate_values]
            
            # 分组
            group_0 = []
            group_1 = []
            for i in range(self.num_traces):
                if selection_values[i] == 0:
                    group_0.append(self.traces[i])
                else:
                    group_1.append(self.traces[i])
            
            if len(group_0) == 0 or len(group_1) == 0:
                continue
            
            # 计算差分均值
            mean_0 = np.mean(group_0, axis=0)
            mean_1 = np.mean(group_1, axis=0)
            differential = mean_1 - mean_0
            
            # 找到最大差分
            max_diff = np.max(np.abs(differential))
            results[key_guess] = max_diff
            
            if max_diff > best_correlation:
                best_correlation = max_diff
                best_key = key_guess
        
        print(f"[+] 最佳密钥猜测: 0x{best_key:02X}")
        print(f"[+] 最大差分值: {best_correlation:.6f}")
        
        # 显示前10个候选
        sorted_results = sorted(results.items(), key=lambda x: x[1], reverse=True)
        print(f"[+] 前10候选:")
        for key, corr in sorted_results[:10]:
            print(f"    Key=0x{key:02X}, Correlation={corr:.6f}")
        
        return best_key
    
    def attack_correlation(self, leakage_model='hamming_weight'):
        """
        相关性功耗分析 (CPA)
        
        使用汉明重量模型进行相关性分析
        """
        # AES S盒
        sbox = [
            0x63, 0x7c, 0x77, 0x7b, 0xf2, 0x6b, 0x6f, 0xc5,
            0x30, 0x01, 0x67, 0x2b, 0xfe, 0xd7, 0xab, 0x76,
            # ... 完整AES S盒
        ]
        
        best_key = 0
        best_correlation = 0
        
        for key_guess in range(256):
            # 计算假设功耗值
            hypotheses = []
            for i in range(self.num_traces):
                pt = self.plaintexts[i]
                intermediate = sbox[pt ^ key_guess]
                
                if leakage_model == 'hamming_weight':
                    hw = bin(intermediate).count('1')
                    hypotheses.append(hw)
                else:
                    hypotheses.append(intermediate)
            
            # 计算相关性
            for t in range(self.num_samples):
                trace_samples = self.traces[:, t]
                correlation = np.corrcoef(hypotheses, trace_samples)[0, 1]
                
                if abs(correlation) > best_correlation:
                    best_correlation = abs(correlation)
                    best_key = key_guess
        
        return best_key
```

### 2.2 时间分析攻击

```
时间分析 (Timing Analysis):

通过测量操作执行时间来推断密钥信息。

攻击原理:
  某些密码算法的执行时间依赖于密钥或数据
  时间差异 -> 密钥信息泄露

示例: RSA平方乘法
  - 指数位为0: 只平方
  - 指数位为1: 平方+乘法 (额外时间)
  通过测量时间差推断指数(密钥)

防护:
  - 恒定时间实现
  - 增加随机延迟
  - 掩除时间依赖
```

### 2.3 电磁分析攻击

```
EMA (Electromagnetic Analysis):

通过测量芯片电磁辐射来获取信息。

原理:
  晶体管开关产生电磁辐射
  不同操作产生不同电磁特征
  近场探头可以捕获局部辐射

优势(相比功耗分析):
  - 空间分辨率高 (可以定位到特定电路)
  - 可以绕过功耗保护
  - 不需要直接接触电源

设备:
  - 近场电磁探头
  - 低噪声放大器
  - 示波器/采集卡
  - XYZ定位平台

攻击流程:
1. 打开设备外壳
2. 定位芯片
3. 用探头扫描芯片表面
4. 触发加密操作
5. 录制电磁信号
6. SPA/DPA分析
```
