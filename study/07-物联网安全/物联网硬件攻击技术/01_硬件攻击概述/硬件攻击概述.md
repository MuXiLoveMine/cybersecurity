# 硬件攻击概述

### 1.1 硬件攻击分类

```
物联网硬件攻击分类:

┌─────────────────────────────────────────────────────────────┐
│                      硬件攻击                                │
├───────────────────────┬─────────────────────────────────────┤
│   非侵入式攻击          │   侵入式攻击                        │
│  (Non-invasive)       │  (Invasive)                       │
├───────────────────────┼─────────────────────────────────────┤
│ - 侧信道分析(SCA)     │ - 芯片去封装                        │
│   - 功耗分析           │ - 芯片层次剥离                      │
│   - 时间分析           │ - 电子显微镜检查                    │
│   - 电磁分析           │ - FIB(聚焦离子束)修改                │
│   - 声学分析           │ - 逻辑电路逆向                      │
│ - 故障注入(FI)        │ - 探针直接读取总线                  │
│   - 电压毛刺          │ - 存储器直接读取                    │
│   - 时钟毛刺          │ - 电路修改                          │
│   - 电磁脉冲          │ - eFuse修改                        │
│   - 激光故障          │                                   │
│   - 温度故障          │                                   │
│ - 调试接口利用         │                                   │
│ - 固件提取             │                                   │
└───────────────────────┴─────────────────────────────────────┘
```
