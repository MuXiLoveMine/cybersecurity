# 芯片逆向工程

### 4.1 芯片去封装

```
芯片去封装 (Decapsulation):

去除芯片封装材料, 暴露内部裸晶。

方法1: 化学腐蚀
  试剂: 发烟硝酸 (HNO3) / 硫酸 (H2SO4)
  步骤:
  1. 将芯片固定在耐酸支架上
  2. 滴加酸液腐蚀封装树脂
  3. 用丙酮清洗
  4. 在显微镜下检查
  5. 重复直到暴露裸晶

方法2: 机械研磨
  工具: 砂纸/研磨机
  步骤:
  1. 从芯片背面研磨
  2. 逐步使用更细的砂纸
  3. 直到看到硅裸晶

方法3: 等离子体刻蚀
  设备: 等离子体刻蚀机
  优点: 精确控制, 不损坏裸晶

安全注意事项:
  - 化学操作需在通风橱中进行
  - 佩戴防护装备
  - 废液需妥善处理
```

### 4.2 电路提取

```
芯片层次逆向:

1. 去金属层:
   - 逐层去除金属互连
   - 化学机械抛光 (CMP)
   - 或选择性腐蚀

2. 图像采集:
   - 光学显微镜 (用于较大工艺)
   - 扫描电子显微镜 (SEM)
   - 适用于90nm以上工艺

3. 图像处理:
   - 图像拼接 (多张拼接成完整芯片)
   - 图像分割 (区分金属/通孔/晶体管)
   - 矢量化 (转换为电路图)

4. 电路分析:
   - 识别标准单元 (逻辑门)
   - 提取网表 (逻辑连接)
   - 功能分析
   - 密钥/安全逻辑识别

工具:
  - Delayer (层次去除)
  - GDSII查看器
  - 逆向工程软件 (如NetZy, ChipGuys)
```
