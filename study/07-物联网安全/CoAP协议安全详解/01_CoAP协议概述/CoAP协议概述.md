# CoAP协议概述

### 1.1 协议背景

CoAP（Constrained Application Protocol，受限应用协议）是IETF专为资源受限的IoT设备设计的应用层协议。它于2014年6月正式发布为RFC 7252，主要运行在UDP之上，具有以下设计目标：

```
设计目标:
1. 轻量级：专为内存<100KB、CPU<10MHz的设备设计
2. REST架构：支持GET/POST/PUT/DELETE方法
3. 异步通信：支持设备休眠后的延迟响应
4. 多播支持：支持一对多通信
5. 简单代理：支持资源发现和代理缓存
6. 低开销：头部仅4字节（HTTP头部通常数百字节）
```

### 1.2 CoAP vs HTTP对比

| 特性 | HTTP | CoAP |
|------|------|------|
| 传输层 | TCP | UDP |
| 头部大小 | 数百字节 | 4-8字节 |
| 方法 | GET/POST/PUT/DELETE等 | GET/POST/PUT/DELETE |
| 可靠性 | TCP保证 | 消息层确认机制 |
| 状态 | 无状态 | 无状态 |
| 资源发现 | 无标准 | /.well-known/core |
| 观察模式 | WebSocket/Polling | 原生Observe支持 |
| 多播 | 不支持 | 支持 |
| 安全 | TLS | DTLS |
| 典型场景 | Web应用 | IoT设备通信 |

### 1.3 CoAP应用场景

```
典型应用场景:

1. 智能家居
   ┌─────────┐     CoAP      ┌─────────┐
   │  手机APP │ ←─────────→  │ 智能灯泡 │
   └─────────┘               └─────────┘
   - 设备控制（开/关/调光）
   - 状态查询
   - 事件订阅

2. 工业物联网
   ┌─────────┐     CoAP      ┌─────────┐
   │  网关    │ ←─────────→  │ 传感器   │
   └─────────┘               └─────────┘
   - 传感器数据上报
   - 设备远程配置
   - 告警推送

3. 智慧城市
   ┌──────────┐  CoAP多播  ┌──────────┐
   │ 路灯控制 │ ────────→  │ 多个路灯 │
   └──────────┘            └──────────┘
   - 一对多控制
   - 节能管理
   - 环境监测

4. 医疗IoT
   - 患者生命体征监测
   - 远程诊断设备
   - 药品追踪
```
