## 1. 安全启动概述

### 1.1 什么是安全启动

安全启动（Secure Boot）是一种确保设备仅运行经过授权的固件/软件的机制。它通过密码学签名验证，构建从硬件信任根到操作系统的完整信任链：

```
安全启动的核心目标:

1. 完整性验证: 确保固件未被篡改
2. 来源认证: 确认固件来自可信发布者
3. 防回滚: 阻止降级到有漏洞的旧版本
4. 信任链: 从硬件到应用的逐级验证
5. 密钥保护: 防止签名密钥泄露

信任链模型:
┌────────────────────────────────────────────┐
│                                            │
│  ROM代码 (不可变)                          │
│    ↓ 验证                                   │
│  引导加载器 (Bootloader)                   │
│    ↓ 验证                                   │
│  内核 (Kernel)                             │
│    ↓ 验证                                   │
│  根文件系统 (Rootfs)                       │
│    ↓ 验证                                   │
│  应用程序 (Applications)                   │
│                                            │
└────────────────────────────────────────────┘

每一级验证下一级的数字签名
任一环节验证失败 → 启动中止
```

### 1.2 安全启动的必要性

```
无安全启动的风险:

1. 固件植入攻击
   - 攻击者替换固件植入后门
   - 恶意固件持久化存在
   - 即使重置系统也无法清除

2. Bootkit/Rootkit
   - 恶意代码在OS之前加载
   - 对OS不可见
   - 可禁用安全软件

3. 固件降级攻击
   - 将固件降级到有漏洞的版本
   - 利用已知漏洞进行攻击
   - 绕过新版安全补丁

4. 供应链攻击
   - 在固件分发环节篡改
   - 中间人攻击固件更新
   - 第三方组件注入恶意代码

历史案例:
- 2014年: Lenovo预装广告软件Superfish (SSL中间人)
- 2018年: LoJax UEFI rootkit (APT28)
- 2020年: 多款路由器固件后门暴露
- 2021年: iLOBot恶意固件 (HPE iLO)
```

### 1.3 安全启动标准与规范

| 标准 | 适用领域 | 关键要求 |
|------|---------|---------|
| UEFI Secure Boot | PC/服务器 | 签名验证, 密钥管理, 启动策略 |
| Android Verified Boot | 移动设备 | 分区验证, 防回滚, 恢复模式 |
| TPM 2.0 | 通用 | 度量启动, 密封存储, 远程证明 |
| ARM Trusted Board | ARM设备 | 信任根, 信任链, 调试控制 |
| NIST SP 800-147 | 通用固件 | 固件完整性保护指导 |
| NIST SP 800-147B | 服务器 | 服务器固件安全指南 |
| TCG PC Client | PC | TPM规范, 度量启动 |
| GlobalPlatform TEE | 移动/IoT | 可信执行环境 |

## 2. 固件签名技术

### 2.1 数字签名基础

```
数字签名流程:

签名方（固件开发者）:
┌─────────────────────────────────────────┐
│                                         │
│  固件文件 ──→ Hash(SHA-256)             │
│                   │                     │
│                   ↓                     │
│              私钥加密(签名)              │
│                   │                     │
│                   ↓                     │
│         固件 + 签名 → 分发              │
│                                         │
└─────────────────────────────────────────┘

验证方（设备启动时）:
┌─────────────────────────────────────────┐
│                                         │
│  接收的固件 ──→ Hash(SHA-256)           │
│                   │                     │
│                   ↓                     │
│              计算的哈希值                │
│                   │                     │
│  签名 ──→ 公钥解密 ──→ 原始哈希值       │
│                   │                     │
│                   ↓                     │
│         比较两个哈希值                  │
│                                         │
│      匹配 = 固件可信                    │
│      不匹配 = 固件被篡改                │
│                                         │
└─────────────────────────────────────────┘
```

### 2.3 固件签名实现

```python
#!/usr/bin/env python3
"""
固件签名与验证工具
==================

功能:
1. 生成签名密钥对
2. 对固件文件进行签名
3. 验证固件签名
4. 固件包封装(含签名、元数据)
"""

import os
import json
import struct
import hashlib
import argparse
import logging
from datetime import datetime
from typing import Optional, Tuple

# 密码学库
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa, ec, padding, ed25519
from cryptography.hazmat.primitives.asymmetric.utils import (
    decode_dss_signature, encode_dss_signature
)
from cryptography.exceptions import InvalidSignature

logging.basicConfig(level=logging.INFO, 
                    format='%(asctime)s [%(levelname)s] %(message)s')
logger = logging.getLogger('FirmwareSigner')

# ============================================================
# 固件包格式定义
# ============================================================

FIRMWARE_MAGIC = b'FWSIG'  # 固件签名魔数
FIRMWARE_HEADER_VERSION = 1
FIRMWARE_HEADER_SIZE = 256  # 固定头部大小

class FirmwareHeader:
    """固件包头部"""
    
    def __init__(self):
        self.magic = FIRMWARE_MAGIC
        self.version = FIRMWARE_HEADER_VERSION
        self.firmware_size = 0
        self.firmware_hash = b''
        self.sign_algorithm = ''  # RSA-2048, ECDSA-P256, Ed25519
        self.sign_time = ''
        self.firmware_version = ''
        self.firmware_description = ''
        self.signature = b''
        
    def pack(self) -> bytes:
        """序列化头部"""
        # 魔数 + 版本
        header = self.magic + struct.pack('>I', self.version)
        # 固件大小
        header += struct.pack('>I', self.firmware_size)
        # 固件哈希
        header += self.firmware_hash.ljust(32, b'\x00')
        # 签名算法
        header += self.sign_algorithm.encode().ljust(20, b'\x00')
        # 签名时间
        header += self.sign_time.encode().ljust(20, b'\x00')
        # 固件版本
        header += self.firmware_version.encode().ljust(32, b'\x00')
        # 描述
        header += self.firmware_description.encode().ljust(64, b'\x00')
        # 签名
        header += self.signature.ljust(96, b'\x00')
        # 填充到固定大小
        header = header.ljust(FIRMWARE_HEADER_SIZE, b'\x00')
        return header
    
    @classmethod
    def unpack(cls, data: bytes) -> 'FirmwareHeader':
        """反序列化头部"""
        header = cls()
        offset = 0
        
        header.magic = data[offset:offset+5]
        offset += 5
        if header.magic != FIRMWARE_MAGIC:
            raise ValueError(f"无效的固件魔数: {header.magic}")
        
        header.version = struct.unpack('>I', data[offset:offset+4])[0]
        offset += 4
        
        header.firmware_size = struct.unpack('>I', data[offset:offset+4])[0]
        offset += 4
        
        header.firmware_hash = data[offset:offset+32].rstrip(b'\x00')
        offset += 32
        
        header.sign_algorithm = data[offset:offset+20].rstrip(b'\x00').decode()
        offset += 20
        
        header.sign_time = data[offset:offset+20].rstrip(b'\x00').decode()
        offset += 20
        
        header.firmware_version = data[offset:offset+32].rstrip(b'\x00').decode()
        offset += 32
        
        header.firmware_description = data[offset:offset+64].rstrip(b'\x00').decode()
        offset += 64
        
        header.signature = data[offset:offset+96].rstrip(b'\x00')
        offset += 96
        
        return header

# ============================================================
# 固件签名器
# ============================================================

class FirmwareSigner:
    """固件签名工具"""
    
    def __init__(self, algorithm: str = 'ECDSA-P256'):
        self.algorithm = algorithm
        self.private_key = None
        self.public_key = None
        
    def generate_keypair(self, output_dir: str = '.'):
        """生成签名密钥对"""
        logger.info(f"生成密钥对: {self.algorithm}")
        
        if self.algorithm.startswith('RSA'):
            key_size = int(self.algorithm.split('-')[1])
            self.private_key = rsa.generate_private_key(
                public_exponent=65537,
                key_size=key_size,
            )
        elif self.algorithm == 'ECDSA-P256':
            self.private_key = ec.generate_private_key(ec.SECP256R1())
        elif self.algorithm == 'ECDSA-P384':
            self.private_key = ec.generate_private_key(ec.SECP384R1())
        elif self.algorithm == 'Ed25519':
            self.private_key = ed25519.Ed25519PrivateKey.generate()
        else:
            raise ValueError(f"不支持的算法: {self.algorithm}")
        
        self.public_key = self.private_key.public_key()
        
        # 保存密钥
        priv_path = os.path.join(output_dir, 'firmware_signing_key.pem')
        pub_path = os.path.join(output_dir, 'firmware_signing_pubkey.pem')
        
        # 私钥（加密存储）
        with open(priv_path, 'wb') as f:
            f.write(self.private_key.private_bytes(
                encoding=serialization.Encoding.PEM,
                format=serialization.PrivateFormat.PKCS8,
                encryption_algorithm=serialization.BestAvailableEncryption(
                    os.urandom(32)  # 实际应用中使用HSM保护
                )
            ))
        os.chmod(priv_path, 0o600)
        
        # 公钥
        with open(pub_path, 'wb') as f:
            f.write(self.public_key.public_bytes(
                encoding=serialization.Encoding.PEM,
                format=serialization.PublicFormat.SubjectPublicKeyInfo
            ))
        
        logger.info(f"私钥保存: {priv_path}")
        logger.info(f"公钥保存: {pub_path}")
        
    def sign_firmware(self, firmware_path: str, 
                      version: str = '',
                      description: str = '') -> str:
        """对固件进行签名"""
        logger.info(f"签名固件: {firmware_path}")
        
        # 读取固件
        with open(firmware_path, 'rb') as f:
            firmware_data = f.read()
        
        # 计算哈希
        firmware_hash = hashlib.sha256(firmware_data).digest()
        logger.info(f"固件SHA-256: {firmware_hash.hex()}")
        
        # 签名
        signature = self._sign(firmware_hash)
        
        # 构造头部
        header = FirmwareHeader()
        header.firmware_size = len(firmware_data)
        header.firmware_hash = firmware_hash
        header.sign_algorithm = self.algorithm
        header.sign_time = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        header.firmware_version = version
        header.firmware_description = description
        header.signature = signature
        
        # 写入签名固件包
        output_path = firmware_path + '.signed'
        with open(output_path, 'wb') as f:
            f.write(header.pack())
            f.write(firmware_data)
        
        logger.info(f"签名固件保存: {output_path}")
        return output_path
    
    def _sign(self, data: bytes) -> bytes:
        """执行签名"""
        if self.algorithm.startswith('RSA'):
            return self.private_key.sign(
                data,
                padding.PSS(
                    mgf=padding.MGF1(hashes.SHA256()),
                    salt_length=padding.PSS.MAX_LENGTH
                ),
                hashes.SHA256()
            )
        elif self.algorithm.startswith('ECDSA'):
            der_sig = self.private_key.sign(data, hashes.SHA256())
            # 转换为原始格式（r || s）
            r, s = decode_dss_signature(der_sig)
            return r.to_bytes(32, 'big') + s.to_bytes(32, 'big')
        elif self.algorithm == 'Ed25519':
            return self.private_key.sign(data)
    
    @staticmethod
    def verify_firmware(signed_path: str, 
                       public_key_path: str) -> Tuple[bool, dict]:
        """验证固件签名"""
        logger.info(f"验证固件: {signed_path}")
        
        # 读取公钥
        with open(public_key_path, 'rb') as f:
            public_key = serialization.load_pem_public_key(f.read())
        
        # 读取签名固件
        with open(signed_path, 'rb') as f:
            header_data = f.read(FIRMWARE_HEADER_SIZE)
            firmware_data = f.read()
        
        # 解析头部
        header = FirmwareHeader.unpack(header_data)
        
        # 验证固件大小
        if header.firmware_size != len(firmware_data):
            logger.error("固件大小不匹配")
            return False, {'error': '固件大小不匹配'}
        
        # 重新计算哈希
        calc_hash = hashlib.sha256(firmware_data).digest()
        
        # 验证哈希
        if calc_hash != header.firmware_hash:
            logger.error("固件哈希不匹配")
            return False, {'error': '固件被篡改'}
        
        # 验证签名
        try:
            algorithm = header.sign_algorithm
            if algorithm.startswith('RSA'):
                public_key.verify(
                    header.signature,
                    header.firmware_hash,
                    padding.PSS(
                        mgf=padding.MGF1(hashes.SHA256()),
                        salt_length=padding.PSS.MAX_LENGTH
                    ),
                    hashes.SHA256()
                )
            elif algorithm.startswith('ECDSA'):
                # 原始格式转DER
                r = int.from_bytes(header.signature[:32], 'big')
                s = int.from_bytes(header.signature[32:], 'big')
                der_sig = encode_dss_signature(r, s)
                public_key.verify(der_sig, header.firmware_hash, hashes.SHA256())
            elif algorithm == 'Ed25519':
                public_key.verify(header.signature, header.firmware_hash)
            
            logger.info("签名验证成功")
            return True, {
                'algorithm': algorithm,
                'firmware_size': header.firmware_size,
                'firmware_hash': header.firmware_hash.hex(),
                'version': header.firmware_version,
                'sign_time': header.sign_time,
                'description': header.firmware_description,
            }
            
        except InvalidSignature:
            logger.error("签名验证失败")
            return False, {'error': '签名无效'}
        except Exception as e:
            logger.error(f"验证异常: {e}")
            return False, {'error': str(e)}

def main():
    parser = argparse.ArgumentParser(description='固件签名与验证工具')
    subparsers = parser.add_subparsers(dest='command', help='命令')
    
    # 生成密钥
    gen_parser = subparsers.add_parser('gen-key', help='生成签名密钥对')
    gen_parser.add_argument('-a', '--algorithm', default='ECDSA-P256',
                           choices=['RSA-2048', 'RSA-3072', 'ECDSA-P256',
                                   'ECDSA-P384', 'Ed25519'],
                           help='签名算法')
    gen_parser.add_argument('-o', '--output', default='.', help='输出目录')
    
    # 签名固件
    sign_parser = subparsers.add_parser('sign', help='签名固件')
    sign_parser.add_argument('firmware', help='固件文件路径')
    sign_parser.add_argument('-k', '--key', help='私钥文件路径')
    sign_parser.add_argument('-v', '--version', default='', help='固件版本')
    sign_parser.add_argument('-d', '--description', default='', help='固件描述')
    
    # 验证固件
    verify_parser = subparsers.add_parser('verify', help='验证固件签名')
    verify_parser.add_argument('firmware', help='签名固件文件路径')
    verify_parser.add_argument('-p', '--pubkey', required=True, 
                               help='公钥文件路径')
    
    args = parser.parse_args()
    
    if args.command == 'gen-key':
        signer = FirmwareSigner(args.algorithm)
        signer.generate_keypair(args.output)
        
    elif args.command == 'sign':
        # 加载私钥（简化版，实际需要密码解密）
        # ...
        signer = FirmwareSigner('ECDSA-P256')
        signer.generate_keypair()  # 实际应加载已有密钥
        signer.sign_firmware(args.firmware, args.version, args.description)
        
    elif args.command == 'verify':
        valid, info = FirmwareSigner.verify_firmware(
            args.firmware, args.pubkey
        )
        if valid:
            print("固件验证通过")
            print(json.dumps(info, indent=2, ensure_ascii=False))
        else:
            print("固件验证失败")
            print(json.dumps(info, indent=2, ensure_ascii=False))
            exit(1)

if __name__ == '__main__':
    main()
```

## 3. 安全启动信任链

### 3.1 信任链架构

```
完整信任链 (从硬件到应用):

┌─────────────────────────────────────────────────────┐
│                    硬件信任根 (RoT)                  │
│            (Boot ROM / eFuse / OTP)                  │
│   ┌─────────────────────────────────────────────┐   │
│   │  • 厂商公钥哈希 (写入eFuse/OTP)              │   │
│   │  • 根密钥 (不可读出)                        │   │
│   │  • 调试禁用标志                              │   │
│   │  • 防回滚计数器                              │   │
│   └──────────────────────┬──────────────────────┘   │
└──────────────────────────┼──────────────────────────┘
                           │ 验证
                           ↓
┌─────────────────────────────────────────────────────┐
│               第一级: Bootloader (SPL)               │
│   ┌─────────────────────────────────────────────┐   │
│   │  • 从Flash读取Bootloader                    │   │
│   │  • 使用RoT公钥验证签名                      │   │
│   │  • 验证通过 → 执行Bootloader                │   │
│   │  • 验证失败 → 进入恢复模式/停止              │   │
│   └──────────────────────┬──────────────────────┘   │
└──────────────────────────┼──────────────────────────┘
                           │ 验证
                           ↓
┌─────────────────────────────────────────────────────┐
│              第二级: U-Boot / Main Bootloader        │
│   ┌─────────────────────────────────────────────┐   │
│   │  • 初始化更多硬件                            │   │
│   │  • 验证内核镜像签名                         │   │
│   │  • 验证设备树(DTB)签名                      │   │
│   │  • 加载内核到内存                           │   │
│   └──────────────────────┬──────────────────────┘   │
└──────────────────────────┼──────────────────────────┘
                           │ 验证
                           ↓
┌─────────────────────────────────────────────────────┐
│              第三级: 操作系统内核                     │
│   ┌─────────────────────────────────────────────┐   │
│   │  • 验证initramfs签名                        │   │
│   │  • 验证内核模块签名 (IMA)                    │   │
│   │  • 挂载验证过的根文件系统                    │   │
│   │  • 启动验证过的服务                          │   │
│   └──────────────────────┬──────────────────────┘   │
└──────────────────────────┼──────────────────────────┘
                           │ 验证
                           ↓
```

### 3.2 信任链验证流程

```c
// 安全启动验证流程（伪代码）

// Boot ROM中的验证函数（不可修改）
int boot_rom_verify() {
    // 1. 从eFuse读取厂商公钥哈希
    uint8_t *vendor_pubkey_hash = read_efuse(EFUSE_PUBKEY_HASH);
    
    // 2. 从Flash读取Bootloader
    uint8_t *bootloader = read_flash(BOOTLOADER_ADDR, BOOTLOADER_SIZE);
    
    // 3. 读取Bootloader签名
    uint8_t *signature = read_flash(BOOTLOADER_SIG_ADDR, SIG_SIZE);
    
    // 4. 读取附带的公钥
    uint8_t *pubkey = read_flash(BOOTLOADER_PUBKEY_ADDR, PUBKEY_SIZE);
    
    // 5. 验证公钥是否匹配eFuse中的哈希
    uint8_t calc_hash[32];
    sha256(pubkey, PUBKEY_SIZE, calc_hash);
    
    if (memcmp(calc_hash, vendor_pubkey_hash, 32) != 0) {
        // 公钥不匹配，拒绝启动
        return BOOT_FAIL_KEY_MISMATCH;
    }
    
    // 6. 验证Bootloader签名
    uint8_t calc_firmware_hash[32];
    sha256(bootloader, BOOTLOADER_SIZE, calc_firmware_hash);
    
    int result = ecdsa_verify(
        pubkey,           // 公钥
        calc_firmware_hash, // 固件哈希
        signature          // 签名
    );
    
    if (result != 0) {
        return BOOT_FAIL_SIG_INVALID;
    }
    
    // 7. 检查防回滚计数器
    uint32_t fw_version = read_flash_version(bootloader);
    uint32_t min_version = read_efuse(EFUSE_MIN_VERSION);
    
    if (fw_version < min_version) {
        return BOOT_FAIL_VERSION_ROLLBACK;
    }
    
    // 8. 验证通过，跳转到Bootloader
    ((void(*)(void))bootloader)();
    
    return BOOT_SUCCESS;
}
```

### 3.3 防回滚机制

```
防回滚保护原理:

版本管理方式:
1. eFuse/OTP方案 (硬件一次性写入)
   - 每个固件版本对应一个eFuse位
   - 版本N的固件要求eFuse位N必须为0
   - 安装版本N后，烧断eFuse位N
   - 旧版本固件因eFuse位已断，无法启动

2. 安全计数器方案 (可更新但有保护)
   - 使用TPM/安全存储中的单调计数器
   - 每次更新递增计数器
   - 固件包含最小允许计数器值
   - 计数器值小于要求的固件被拒绝

eFuse防回滚示例:
┌───────────────────────────────────────┐
│  eFuse区域 (32 bits)                  │
│  Bit 31 30 29 28 27 26 25 24 ...      │
│  [ 0   0   0   1  1  1  0  0 ...]    │
│         ↑              ↑               │
│   V5以下已禁用     V3以下已禁用         │
│                                       │
│  当前最低允许版本: V4                  │
│  (eFuse位3已烧断)                     │
└───────────────────────────────────────┘

固件版本检查:
- V5固件: eFuse位4=0 → 允许
- V4固件: eFuse位3=1 → 允许
- V3固件: eFuse位2=0 → 拒绝(版本太低)
```

### 5.2 UEFI镜像验证

```python
# UEFI镜像签名验证
class UEFISecureBoot:
    """UEFI安全启动验证"""
    
    def __init__(self, db: list, dbx: list):
        """
        db: 授权签名证书列表
        dbx: 撤销签名证书列表
        """
        self.db = db  # 授权数据库
        self.dbx = dbx  # 撤销数据库
    
    def verify_efi_image(self, image_path: str) -> bool:
        """验证EFI镜像签名"""
        # 1. 解析PE/COFF格式
        pe_data = self._read_pe_image(image_path)
        
        # 2. 检查是否存在签名
        signature = self._extract_signature(pe_data)
        if not signature:
            print("镜像未签名，拒绝启动")
            return False
        
        # 3. 提取签名证书
        cert = self._extract_certificate(signature)
        
        # 4. 检查证书是否在撤销列表中
        if self._is_in_dbx(cert):
            print(f"证书在撤销列表中，拒绝启动")
            return False
        
        # 5. 检查证书是否在授权列表中
        if not self._is_in_db(cert):
            print(f"证书不在授权列表中，拒绝启动")
            return False
        
        # 6. 验证签名
        image_hash = self._calculate_image_hash(pe_data)
        if not self._verify_signature(image_hash, signature, cert):
            print("签名验证失败")
            return False
        
        print("UEFI镜像验证通过")
        return True
    
    def _read_pe_image(self, path: str) -> bytes:
        """读取PE格式镜像"""
        with open(path, 'rb') as f:
            return f.read()
    
    def _extract_signature(self, pe_data: bytes) -> dict:
        """从PE镜像提取签名"""
        # PE签名的证书目录在可选头中
        # 简化实现
        signature = {
            'algorithm': 'RSA-SHA256',
            'data': b'',  # 实际签名数据
            'cert': b'',  # 签名证书
        }
        # ... 实际PE解析逻辑
        return signature
    
    def _is_in_dbx(self, cert: bytes) -> bool:
        """检查证书是否在撤销列表"""
        cert_hash = hashlib.sha256(cert).hexdigest()
        for entry in self.dbx:
            if cert_hash == entry['hash']:
                return True
        return False
    
    def _is_in_db(self, cert: bytes) -> bool:
        """检查证书是否在授权列表"""
        cert_hash = hashlib.sha256(cert).hexdigest()
        for entry in self.db:
            if cert_hash == entry['hash']:
                return True
        return False
```

## 7. IoT设备安全启动实现

### 7.1 基于MCU的轻量级安全启动

```c
// 基于Cortex-M的轻量级安全启动

#include "sha256.h"
#include "ecc256.h"  // ECC P-256验证
#include "flash.h"
#include "efuse.h"

// 固件头格式
typedef struct {
    uint32_t magic;          // 魔数 0x46575331 ("FWS1")
    uint32_t version;       // 固件版本
    uint32_t size;          // 固件大小
    uint8_t  hash[32];      // 固件SHA-256哈希
    uint8_t  signature[64]; // ECDSA-P256签名
} __attribute__((packed)) firmware_header_t;

// 安全启动验证
int secure_boot_verify(void) {
    firmware_header_t header;
    uint8_t *firmware_data;
    uint8_t calc_hash[32];
    
    // 1. 读取固件头
    flash_read(FIRMWARE_BASE, &header, sizeof(header));
    
    // 2. 验证魔数
    if (header.magic != 0x46575331) {
        log_error("固件魔数无效");
        return BOOT_FAIL_MAGIC;
    }
    
    // 3. 读取固件数据
    firmware_data = (uint8_t *)malloc(header.size);
    flash_read(FIRMWARE_BASE + sizeof(header), firmware_data, header.size);
    
    // 4. 计算哈希
    sha256_context ctx;
    sha256_init(&ctx);
    sha256_update(&ctx, firmware_data, header.size);
    sha256_final(&ctx, calc_hash);
    
    // 5. 比较哈希
    if (memcmp(calc_hash, header.hash, 32) != 0) {
        log_error("固件哈希不匹配");
        free(firmware_data);
        return BOOT_FAIL_HASH;
    }
    
    // 6. 从eFuse读取公钥
    uint8_t pubkey[64];
    efuse_read_pulickey(pubkey);
    
    // 7. 验证签名
    if (ecdsa_verify(pubkey, calc_hash, header.signature) != 0) {
        log_error("固件签名无效");
        free(firmware_data);
        return BOOT_FAIL_SIGNATURE;
    }
    
    // 8. 检查防回滚
    uint32_t min_version = efuse_read(EFUSE_MIN_VERSION);
    if (header.version < min_version) {
        log_error("固件版本过低(回滚)");
        free(firmware_data);
        return BOOT_FAIL_ROLLBACK;
    }
    
    // 9. 验证通过
    log_info("固件验证通过");
    
    // 10. 跳转到固件
    void (*firmware_entry)(void) = 
        (void (*)(void))(FIRMWARE_BASE + sizeof(header));
    
    free(firmware_data);
    firmware_entry();
    
    return BOOT_SUCCESS;
}
```

## 8. 固件签名验证流程

### 8.1 完整验证流程

```python
# 固件签名验证完整流程
class FirmwareVerification:
    """固件签名验证器"""
    
    def __init__(self, trust_root: dict):
        """
        trust_root: 信任根配置
        {
            'public_key': bytes,    # 厂商公钥
            'min_version': int,     # 最低固件版本
            'trusted_subjects': list,  # 可信发布者
        }
        """
        self.trust_root = trust_root
    
    def verify(self, firmware_package: bytes) -> dict:
        """完整验证流程"""
        result = {
            'valid': False,
            'stage': '',
            'errors': [],
        }
        
        # 阶段1: 解析固件包
        try:
            header, firmware = self._parse_package(firmware_package)
            result['stage'] = 'parse'
        except Exception as e:
            result['errors'].append(f"解析失败: {e}")
            return result
        
        # 阶段2: 验证格式
        if not self._validate_header(header):
            result['errors'].append("固件头格式无效")
            return result
        result['stage'] = 'format'
        
        # 阶段3: 完整性验证
        calc_hash = hashlib.sha256(firmware).digest()
        if calc_hash != header['hash']:
            result['errors'].append("固件哈希不匹配 - 固件被篡改")
            return result
        result['stage'] = 'integrity'
        
        # 阶段4: 签名验证
        if not self._verify_signature(header, firmware):
            result['errors'].append("签名验证失败")
            return result
        result['stage'] = 'signature'
        
        # 阶段5: 防回滚检查
        if header['version'] < self.trust_root['min_version']:
            result['errors'].append(
                f"固件版本 {header['version']} 低于最低要求 "
                f"{self.trust_root['min_version']}"
            )
            return result
        result['stage'] = 'rollback'
        
        # 阶段6: 发布者验证
        if not self._verify_publisher(header):
            result['errors'].append("发布者不在信任列表中")
            return result
        result['stage'] = 'publisher'
        
        # 阶段7: 时间戳验证（防止重放旧签名）
        if not self._verify_timestamp(header):
            result['errors'].append("签名时间戳无效")
            return result
        
        result['valid'] = True
        result['stage'] = 'complete'
        result['version'] = header['version']
        result['hash'] = header['hash'].hex()
        
        return result
    
    def _verify_signature(self, header: dict, firmware: bytes) -> bool:
        """验证数字签名"""
        from cryptography.hazmat.primitives.asymmetric import ec
        from cryptography.hazmat.primitives.asymmetric.utils import (
            decode_dss_signature, encode_dss_signature
        )
        
        public_key = self.trust_root['public_key']
        signature = header['signature']
        hash_value = header['hash']
        
        try:
            if header['algorithm'] == 'ECDSA-P256':
                r = int.from_bytes(signature[:32], 'big')
                s = int.from_bytes(signature[32:], 'big')
                der_sig = encode_dss_signature(r, s)
                public_key.verify(der_sig, hash_value, ec.ECDSA(
                    hashes.SHA256()
                ))
                return True
            elif header['algorithm'] == 'Ed25519':
                public_key.verify(signature, hash_value)
                return True
            elif header['algorithm'].startswith('RSA'):
                from cryptography.hazmat.primitives.asymmetric import padding
                public_key.verify(
                    signature, hash_value,
                    padding.PSS(
                        mgf=padding.MGF1(hashes.SHA256()),
                        salt_length=padding.PSS.MAX_LENGTH
                    ),
                    hashes.SHA256()
                )
                return True
        except Exception:
            return False
        
        return False
```

```python
# A/B分区管理器
class ABPartitionManager:
    """A/B分区管理器"""
    
    def __init__(self):
        self.partitions = {
            'A': {'active': True, 'boot_attempts': 0, 'version': ''},
            'B': {'active': False, 'boot_attempts': 0, 'version': ''},
        }
        self.max_boot_attempts = 3
    
    def get_active_partition(self) -> str:
        """获取当前活动分区"""
        for name, info in self.partitions.items():
            if info['active']:
                return name
        return 'A'
    
    def get_inactive_partition(self) -> str:
        """获取非活动分区"""
        active = self.get_active_partition()
        return 'B' if active == 'A' else 'A'
    
    def prepare_update(self, firmware_data: bytes) -> bool:
        """准备更新"""
        inactive = self.get_inactive_partition()
        
        # 写入固件到非活动分区
        self._write_partition(inactive, firmware_data)
        
        # 设置启动尝试计数
        self.partitions[inactive]['boot_attempts'] = 0
        
        # 标记下次启动该分区
        self._set_next_boot(inactive)
        
        return True
    
    def on_boot_success(self):
        """启动成功后调用"""
        active = self.get_active_partition()
        
        # 提交当前分区为活动
        self.partitions[active]['boot_attempts'] = 0
        inactive = self.get_inactive_partition()
        self.partitions[active]['active'] = True
        self.partitions[inactive]['active'] = False
        
        # 更新防回滚计数器
        self._update_rollback_counter(
            self.partitions[active]['version']
        )
        
        logger.info(f"分区 {active} 启动成功并提交")
    
    def on_boot_failure(self):
        """启动失败后调用"""
        # 此函数由Bootloader在多次失败后调用
        active = self.get_active_partition()
        inactive = self.get_inactive_partition()
        
        logger.error(f"分区 {active} 启动失败, 回退到 {inactive}")
        
        # 切换回旧分区
        self.partitions[active]['active'] = False
        self.partitions[inactive]['active'] = True
        self._set_next_boot(inactive)
```

### 10.2 故障注入攻击

```python
# 故障注入攻击安全启动的原理
class FaultInjectionAttack:
    """
    故障注入攻击通过在签名验证过程中引入硬件故障,
    使验证错误地返回成功结果
    
    攻击目标: 
    - 在ECDSA/RSA验证的关键步骤中引入时钟毛刺
    - 使比较指令跳过或返回错误结果
    - 绕过签名验证
    """
    
    """
    典型攻击场景:
    
    正常验证流程:
    1. 计算固件哈希 H
    2. 从固件头读取签名 S
    3. 从公钥计算预期值 E = Verify(PK, H, S)
    4. 比较: if E == EXPECTED → 通过
    
    故障注入:
    - 在步骤4的时钟注入毛刺
    - 使CMP指令的Zero标志位被错误设置
    - 验证错误地返回"通过"
    
    防御:
    1. 双重验证: 执行两次验证, 比较结果
    2. 反向验证: 验证失败标志也被验证
    3. 时间冗余: 在不同时间执行验证
    4. 空间冗余: 使用不同代码验证
    5. 随机延迟: 增加攻击者时序预测难度
    """
    
    # 安全验证实现(抗故障注入)
    @staticmethod
    def secure_verify(hash_value: bytes, signature: bytes, 
                      pubkey: bytes) -> bool:
        """抗故障注入的验证实现"""
        
        # 第一次验证
        result1 = verify_signature(hash_value, signature, pubkey)
        
        # 第二次验证(冗余)
        result2 = verify_signature(hash_value, signature, pubkey)
        
        # 结果一致性检查
        if result1 != result2:
            # 可能遭受故障注入
            secure_log("验证结果不一致，可能遭受攻击")
            return False
        
        # 反向检查(验证失败标志)
        # 如果签名是无效的，verify_invalid应该返回True
        if verify_invalid_signature(hash_value, signature, pubkey):
            secure_log("检测到无效签名标记")
            return False
        
        return result1
```

## 总结

安全启动是IoT和嵌入式设备安全的基石。通过从硬件信任根到应用程序的完整信任链，可以有效防止固件篡改、恶意固件植入和回滚攻击。

实施安全启动需要注意以下关键点：

1. **硬件信任根是不可妥协的** - 必须基于不可变的Boot ROM或eFuse
2. **签名密钥管理至关重要** - 使用HSM保护密钥，实施严格的访问控制
3. **防回滚机制必须配置** - 否则攻击者可以降级到有漏洞的版本
4. **抗物理攻击设计** - 双重验证、随机延迟、故障检测
5. **OTA更新必须安全** - A/B分区、原子更新、自动回滚
6. **完整的信任链** - 不能有任何环节跳过验证

建议结合本文中的代码示例，在实际设备上实现和测试安全启动流程，深入理解从硬件到应用的完整安全验证机制。
