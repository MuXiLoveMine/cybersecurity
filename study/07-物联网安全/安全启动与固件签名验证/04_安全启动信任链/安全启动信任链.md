# 安全启动信任链

### 3.1 信任链架构

### 3.2 信任链验证流程

```c
// 安全启动验证流程（伪代码）

// Boot ROM中的验证函数（不可修改）
int boot_rom_verify() {
    // 1. 从eFuse读取厂商公钥哈希
    uint8_t *vendor_pubkey_hash = read_efuse(EFUSE_PUBKEY_HASH);
    
    // 2. 从Flash读取Bootloader
    uint8_t *bootloader = read_flash(BOOTLOADER_ADDR, BOOTLOADER_SIZE);
    
    // 3. 读取Bootloader签名
    uint8_t *signature = read_flash(BOOTLOADER_SIG_ADDR, SIG_SIZE);
    
    // 4. 读取附带的公钥
    uint8_t *pubkey = read_flash(BOOTLOADER_PUBKEY_ADDR, PUBKEY_SIZE);
    
    // 5. 验证公钥是否匹配eFuse中的哈希
    uint8_t calc_hash[32];
    sha256(pubkey, PUBKEY_SIZE, calc_hash);
    
    if (memcmp(calc_hash, vendor_pubkey_hash, 32) != 0) {
        // 公钥不匹配，拒绝启动
        return BOOT_FAIL_KEY_MISMATCH;
    }
    
    // 6. 验证Bootloader签名
    uint8_t calc_firmware_hash[32];
    sha256(bootloader, BOOTLOADER_SIZE, calc_firmware_hash);
    
    int result = ecdsa_verify(
        pubkey,           // 公钥
        calc_firmware_hash, // 固件哈希
        signature          // 签名
    );
    
    if (result != 0) {
        return BOOT_FAIL_SIG_INVALID;
    }
    
    // 7. 检查防回滚计数器
    uint32_t fw_version = read_flash_version(bootloader);
    uint32_t min_version = read_efuse(EFUSE_MIN_VERSION);
    
    if (fw_version < min_version) {
        return BOOT_FAIL_VERSION_ROLLBACK;
    }
    
    // 8. 验证通过，跳转到Bootloader
    ((void(*)(void))bootloader)();
    
    return BOOT_SUCCESS;
}
```

### 3.3 防回滚机制

```
防回滚保护原理:

版本管理方式:
1. eFuse/OTP方案 (硬件一次性写入)
   - 每个固件版本对应一个eFuse位
   - 版本N的固件要求eFuse位N必须为0
   - 安装版本N后，烧断eFuse位N
   - 旧版本固件因eFuse位已断，无法启动

2. 安全计数器方案 (可更新但有保护)
   - 使用TPM/安全存储中的单调计数器
   - 每次更新递增计数器
   - 固件包含最小允许计数器值
   - 计数器值小于要求的固件被拒绝

eFuse防回滚示例:
┌───────────────────────────────────────┐
│  eFuse区域 (32 bits)                  │
│  Bit 31 30 29 28 27 26 25 24 ...      │
│  [ 0   0   0   1  1  1  0  0 ...]    │
│         ↑              ↑               │
│   V5以下已禁用     V3以下已禁用         │
│                                       │
│  当前最低允许版本: V4                  │
│  (eFuse位3已烧断)                     │
└───────────────────────────────────────┘

固件版本检查:
- V5固件: eFuse位4=0 → 允许
- V4固件: eFuse位3=1 → 允许
- V3固件: eFuse位2=0 → 拒绝(版本太低)
```
