# 硬件信任根

### 4.1 信任根类型

```
硬件信任根分类:

1. 不可变信任根 (Immutable RoT)
   ┌─────────────────────────────────────┐
   │  Boot ROM                          │
   │  • 在芯片制造时写入                  │
   │  • 物理上不可修改                    │
   │  • 包含厂商公钥哈希                  │
   │  • 执行第一级验证                    │
   └─────────────────────────────────────┘
   
   优点: 最高安全性，不可篡改
   缺点: 密钥不可更新（如果泄露则芯片作废）

2. 可更新信任根 (Updatable RoT)
   ┌─────────────────────────────────────┐
   │  eFuse/OTP + Flash                  │
   │  • 公钥哈希在eFuse中                 │
   │  • 实际公钥在Flash中                 │
   │  • 可通过密钥轮换更新                │
   └─────────────────────────────────────┘
   
   优点: 密钥可更新
   缺点: 安全性略低于不可变方案

3. TPM信任根 (TPM-based RoT)
   ┌─────────────────────────────────────┐
   │  TPM 2.0芯片                        │
   │  • 独立的安全处理器                  │
   │  • 度量启动(PCR)                     │
   │  • 密封存储                         │
   │  • 远程证明                         │
   └─────────────────────────────────────┘
   
   优点: 标准化，功能强大
   缺点: 成本高，需要TPM芯片

4. 软件信任根 (Software RoT - 仅限高安全设备)
   ┌─────────────────────────────────────┐
   │  TEE / Secure Element               │
   │  • ARM TrustZone                    │
   │  • 外部安全芯片                      │
   │  • 提供密钥存储和签名验证             │
   └─────────────────────────────────────┘
```

### 4.2 eFuse/OTP配置

```
eFuse配置示例 (ARM SoC):

eFuse区域分布:
┌──────────────────────────────────────────┐
│  Region         Size    Description       │
├──────────────────────────────────────────┤
│  PUBLIC_KEY    256 bits  厂商公钥哈希     │
│  SECURE_BOOT    1 bit    安全启动使能     │
│  JTAG_DISABLE   1 bit    JTAG禁用        │
│  DEBUG_DISABLE  1 bit    调试禁用         │
│  USB_DISABLE    1 bit    USB禁用         │
│  ROLLBACK_BITS  32 bits  防回滚版本位    │
│  CUSTOMER_DATA  128 bits 客户自定义数据   │
│  RESERVED      64 bits  保留             │
└──────────────────────────────────────────┘

安全启动配置流程:
1. 芯片出厂时eFuse全为0
2. 制造商写入公钥哈希
3. 烧录SECURE_BOOT=1 (启用安全启动)
4. 烧录JTAG_DISABLE=1 (禁用调试)
5. 每次固件更新后更新ROLLBACK_BITS

一旦写入，eFuse位不可逆（类似保险丝烧断）
```

### 4.3 TPM 2.0度量启动

```python
# TPM 2.0 度量启动
class TPMMeasuredBoot:
    """TPM度量启动实现"""
    
    # PCR (Platform Configuration Register) 用途
    PCR_USAGE = {
        0:  'BIOS固件度量',
        1:  'BIOS配置度量',
        2:  'Option ROM度量',
        3:  'Option ROM配置度量',
        4:  'MBR/GPT度量',
        5:  'Bootloader配置',
        6:  '内核启动参数',
        7:  '安全启动策略',
        8:  'GRUB度量',
        9:  '内核度量',
        10: 'initramfs度量',
        11: '内核命令行',
        12: '内核模块度量',
        13: '固件文件度量',
        14: 'UEFI变量度量',
        15: '保留',
    }
    
    def __init__(self):
        self.pcr_values = {}  # PCR当前值
        
    def extend_pcr(self, pcr_num: int, data: bytes):
        """扩展PCR寄存器"""
        # PCR使用SHA-256
        old_value = self.pcr_values.get(pcr_num, b'\x00' * 32)
        new_value = hashlib.sha256(old_value + data).digest()
        self.pcr_values[pcr_num] = new_value
        logger.info(f"PCR{pcr_num} 扩展: {new_value.hex()}")
    
    def measure_boot_stage(self, stage: str, data: bytes):
        """度量启动阶段"""
        pcr_map = {
            'bios': 0,
            'bootloader': 4,
            'kernel': 4,
            'initramfs': 9,
            'modules': 11,
        }
        
        pcr_num = pcr_map.get(stage)
        if pcr_num is not None:
            self.extend_pcr(pcr_num, hashlib.sha256(data).digest())
    
    def get_quote(self, nonce: bytes) -> dict:
        """生成远程证明报告"""
        return {
            'pcr_values': {k: v.hex() for k, v in self.pcr_values.items()},
            'nonce': nonce.hex(),
            'timestamp': datetime.now().isoformat(),
        }
    
    def verify_quote(self, quote: dict, nonce: bytes) -> bool:
        """验证远程证明报告"""
        # 在实际实现中，这里使用TPM签名的引用结构
        if quote['nonce'] != nonce.hex():
            return False
        # 验证TPM签名...
        return True
```
