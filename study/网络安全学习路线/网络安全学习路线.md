# 网络安全完整学习路线（2026版）

> 适用于零基础小白、转行从业者，学习周期建议 **6-18个月**（根据每日学习时长调整）
> 核心原则：**先打基础，再选方向，实战贯穿全程**

---

## 一、网络安全领域全景

网络空间安全是一个覆盖"物理层-网络层-应用层-数据层-业务层"的全域防护体系，主要分为 **16大核心方向**：

| 序号 | 方向 | 核心防护对象 | 典型威胁 |
|------|------|-------------|---------|
| 01 | 基础网络安全 | 路由器、交换机、防火墙、VPN | DDoS攻击、ARP欺骗、路由劫持 |
| 02 | Web应用安全 | Web服务器、动态脚本、数据库接口 | SQL注入、XSS、文件上传、CSRF |
| 03 | 移动应用安全 | APK/IPA安装包、本地存储、权限 | 应用逆向、恶意SDK、钓鱼APP |
| 04 | 终端安全 | Windows/Linux/macOS系统、进程 | 勒索软件、病毒木马、系统漏洞 |
| 05 | 数据安全 | 用户隐私数据、业务核心数据 | 数据泄露、数据篡改、数据丢失 |
| 06 | 工控安全 | PLC、SCADA、DCS、工业协议 | 工控病毒、非法修改生产参数 |
| 07 | 物联网安全 | 智能摄像头、智能门锁、传感器 | 设备劫持、隐私泄露、默认密码 |
| 08 | 云安全 | 云服务器、云存储、容器、Serverless | 云配置错误、容器逃逸、账号泄露 |
| 09 | 车联网安全 | 车载系统、CAN总线、V2X协议 | 远程控制车辆、伪造交通信号 |
| 10 | 区块链安全 | 智能合约、共识节点、钱包私钥 | 51%攻击、智能合约漏洞、私钥泄露 |
| 11 | 人工智能安全 | 训练数据集、深度学习模型、推理API | 对抗样本、模型投毒、模型窃取 |
| 12 | 卫星网络安全 | 卫星转发器、地面控制中心、调制解调器 | 信号劫持、地面站入侵、通信截获 |
| 13 | 身份与访问安全 | 用户账号、管理员权限、API密钥 | 账号泄露、水平越权、垂直越权 |
| 14 | 密码学与密钥安全 | 加密算法、密钥生成/存储/销毁 | 算法破解、密钥泄露、中间人攻击 |
| 15 | 应急响应与威胁情报 | 安全事件检测、处置、溯源 | APT攻击、勒索软件、数据泄露 |
| 16 | 安全管理与合规 | 安全制度、合规认证、风险评估 | 等保不合规、人员意识薄弱 |

## 二、核心学习原则

1. **实战为王**：每学一个知识点，必须配套靶场实战验证
2. **循序渐进**：从基础到进阶，先打牢底层知识，再攻安全技术
3. **聚焦方向**：新手先主攻1-2个方向，再横向拓展
4. **持续跟进**：安全技术迭代快，养成关注行业动态的习惯
5. **合法合规**：所有测试必须在合法授权范围内进行

## 三、五阶段学习路线

### 阶段1：零基础入门（1-2个月）—— 建立核心认知

**核心目标**：了解行业全貌，掌握计算机基础、网络基础、Linux系统基础

#### 1.1 行业认知
- 网络安全核心岗位（渗透测试工程师、安全运维、安全开发、漏洞挖掘）
- 岗位职责与技能要求
- 行业发展趋势与薪资水平

#### 1.2 计算机基础
- 操作系统基础（进程/线程、内存管理、文件系统）
- 二进制基础（十六进制、ASCII编码）

#### 1.3 网络基础（重中之重）
- TCP/IP协议栈（IP、TCP、UDP、HTTP/HTTPS）
- 子网划分、网关与路由
- 端口与服务的对应关系（80=HTTP、443=HTTPS、3389=RDP）
- OSI七层模型与TCP/IP四层模型

#### 1.4 Linux系统基础
- Linux系统安装（推荐Kali Linux）
- 常用命令：`cd/ls/cat/grep/find/chmod/netstat/ps/top`
- 文件权限管理
- 远程登录（SSH）
- Shell脚本基础

#### 1.5 编程语言入门（Python）
- 基础语法（变量、循环、条件判断、函数）
- 列表/字典/字符串操作
- 网络请求（requests库）
- 正则表达式
- 简单脚本编写

#### 🎯 实战任务
- [ ] 安装Kali Linux虚拟机，熟练使用20+常用Linux命令
- [ ] 用Wireshark抓包分析HTTP请求、TCP三次握手/四次挥手
- [ ] 编写简单Shell脚本（批量创建用户、批量查看端口状态）
- [ ] 编写Python脚本批量扫描指定网段的80端口

#### 📚 推荐资源
- 书籍：《计算机网络：自顶向下方法》《Linux鸟哥的私房菜》《Python编程：从入门到实践》
- 视频：韩顺平Linux教程、B站网络安全干货TCP/IP讲解
- 工具：VMware Workstation、Kali Linux、Wireshark

---

### 阶段2：基础夯实（2-3个月）—— 掌握核心漏洞原理

**核心目标**：聚焦Web安全，掌握常见Web漏洞原理与利用方法，熟练使用核心工具

#### 2.1 Web基础
- HTML/CSS/JavaScript基础（能看懂前端页面结构）
- Web架构（前端→后端→数据库）
- 动态语言基础（PHP/Java任选其一，推荐PHP）

#### 2.2 数据库基础
- MySQL基础（库/表/字段、增删改查语句）
- 联合查询、子查询
- 数据库权限管理

#### 2.3 核心Web漏洞（原理+利用）
| 漏洞类型 | 核心知识点 |
|---------|-----------|
| SQL注入 | 手工注入（错误/布尔/时间盲注）、SQLMap使用、WAF绕过 |
| XSS跨站脚本 | 存储型/反射型/DOM型、Payload构造、CSP防御 |
| 文件上传 | 后缀绕过、内容验证绕过、一句话木马植入 |
| 文件包含 | 本地包含(LFI)、远程包含(RFI)、包含漏洞利用 |
| CSRF | 攻击原理、防御方案（Token、SameSite Cookie） |
| 越权漏洞 | 水平越权、垂直越权、逻辑漏洞 |
| 弱口令 | 暴力破解、字典生成、验证码绕过 |

#### 2.4 核心工具使用
- **Burp Suite**：抓包、改包、重放、爆破、插件使用
- **SQLMap**：自动化SQL注入利用
- **Nmap**：端口扫描、服务识别、操作系统探测
- **Dirsearch**：目录扫描
- **Wireshark**：流量分析

#### 🎯 实战任务
- [ ] 完成SQLi-Labs靶场全关卡
- [ ] 完成DVWA靶场全关卡（所有难度）
- [ ] 完成皮卡丘靶场Web漏洞专项
- [ ] 用Burp Suite爆破简单密码、修改POST请求参数
- [ ] 用Dirsearch扫描测试站点，发现备份文件

#### 📚 推荐资源
- 书籍：《Web安全深度剖析》《白帽子讲Web安全》
- 视频：B站"小迪安全"Web渗透基础教程
- 靶场：SQLi-Labs、DVWA、皮卡丘靶场、CTFHub Web入门区
- 工具：Burp Suite Community、SQLMap、Dirsearch、Nmap

## 七、新手避坑指南

### ❌ 常见错误
1. **只学工具不学原理**：只会用SQLmap跑注入，不懂SQL语法，遇到WAF就傻眼
2. **盲目追新技术**：还没搞懂基础漏洞，就去学内存马、APT攻击
3. **不复盘总结**：刷完题、挖完漏洞不记录，下次遇到同类问题还是不会
4. **忽视法律风险**：未授权攻击真实网站，哪怕是小网站也可能违法
5. **孤军奋战**：不加入学习社群、不参与比赛，信息闭塞

### ✅ 正确做法
1. **先原理后工具**：理解漏洞本质，工具只是辅助
2. **循序渐进**：基础打牢再进阶，不要跳级学习
3. **勤做笔记**：每学一个漏洞、做一个项目都记录下来
4. **合法合规**：只在授权靶场或SRC平台练习
5. **加入社群**：和同行交流，获取最新资讯和学习资源

## 九、推荐学习路径（零基础版）

```
   ↓

   ↓
第7-9个月：内网渗透 + 域渗透 + 红队工具
   ↓
第10-12个月：SRC挖洞 + CTF比赛 + 项目作品集
   ↓
第12个月+：求职/专项深耕
```
