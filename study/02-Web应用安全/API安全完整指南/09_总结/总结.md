# 总结

| 安全维度 | 关键要点 | 核心防御 |
|----------|----------|----------|
| 认证 | JWT安全、OAuth2标准 | 强密钥、短过期、算法白名单 |
| 授权 | BOLA/BFLA防护 | 归属校验、RBAC/ABAC |
| 输入 | 注入防护 | 参数化查询、Schema验证 |
| 资源 | DoS防护 | 速率限制、分页限制 |
| 配置 | 最小暴露面 | 关闭调试、CORS白名单 |
| 资产 | 完整清单 | OpenAPI注册、版本废弃 |
| 第三方 | 响应验证 | 输出编码、域名白名单 |
| 监控 | 异常检测 | 行为基线、实时告警 |
