# len

> **分类**：内置函数
> **说明**：返回对象的长度或元素个数

---

## 语法

```c
len(s)
```

## 参数说明

- s: 序列（字符串、列表、元组等）或集合（字典、集合等）

## 示例代码

```python
# 字符串长度
print(len("hello"))  # 5

# 列表长度
print(len([1, 2, 3]))  # 3

# 字典长度
print(len({"a": 1, "b": 2}))  # 2

# 集合长度
print(len({1, 2, 3}))  # 3

# 字节长度
print(len(b"hello"))  # 5
```
