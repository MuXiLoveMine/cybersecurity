## 1. 汇编语言概述

### 1.1 什么是汇编语言

汇编语言（Assembly Language）是一种低级编程语言，它使用助记符（Mnemonic）来表示机器指令。每一条汇编指令对应一条 CPU 机器指令，是对机器码的第一层抽象。

**机器码（Machine Code）**：CPU 直接执行的二进制指令，如 `B8 01 00 00 00`。

**汇编语言**：用助记符表示机器码，如 `mov eax, 1`。

**高级语言**：如 C/C++、Python 等，经过编译/解释转换为机器码执行。

### 1.2 为什么学习汇编

在网络安全领域，汇编语言是必备的基础知识：

| 应用领域 | 说明 |
|---------|------|
| **逆向工程** | 分析二进制程序、恶意软件、闭源软件 |
| **漏洞挖掘** | 理解内存破坏漏洞的原理和利用方式 |
| **Exploit 开发** | Shellcode 编写、ROP 链构造、绕过保护机制 |
| **反调试与反逆向** | 理解并实现反调试、加壳、代码混淆 |
| **底层开发** | 操作系统内核、Bootloader、嵌入式系统 |
| **代码优化** | 理解编译器优化原理，进行性能优化 |

### 1.3 汇编语言的种类

| 类型 | 说明 | 示例 |
|-----|------|------|
| **x86 汇编** | Intel/AMD 32位处理器 | `mov eax, ebx` |
| **x86_64 汇编** | Intel/AMD 64位处理器 | `mov rax, rbx` |
| **ARM 汇编** | ARM 架构处理器（手机、嵌入式） | `mov r0, r1` |
| **MIPS 汇编** | MIPS 架构（路由器、IoT） | `add $t0, $t1, $t2` |

本教程主要聚焦于 **x86 / x86_64 架构**，使用 NASM 语法。

### 1.4 汇编语法格式

主要有两种语法格式：

#### Intel 语法（NASM、MASM 使用）
```nasm
mov eax, 123        ; 目的操作数在前，源在后
add ebx, ecx
```

#### AT&T 语法（GAS、GDB 默认使用）
```asm
movl $123, %eax     ; 源在前，目的在后
addl %ecx, %ebx
```

**主要区别：**
- Intel：`mov dst, src`；AT&T：`mov src, dst`
- AT&T 寄存器前加 `%`，立即数前加 `$`
- AT&T 指令后缀表示操作数大小：`b`(字节)、`w`(字)、`l`(双字)、`q`(四字)

本教程统一使用 **Intel 语法（NASM）**。

### 1.5 开发环境配置

#### Linux 平台

```bash
# Ubuntu/Debian
sudo apt install nasm gcc gdb

# CentOS/RHEL
sudo yum install nasm gcc gdb
```

#### 验证安装

```bash
nasm --version      # NASM 汇编器
gcc --version       # C 编译器（用于链接和混合编程）
gdb --version       # GNU 调试器
```

#### 第一个汇编程序

```nasm
; hello.asm - Hello World (Linux x86_64)
section .data
    msg db  'Hello, Assembly!', 0xA
    len equ $ - msg

section .text
    global _start

_start:
    mov rax, 1          ; sys_write
    mov rdi, 1          ; stdout
    mov rsi, msg        ; 字符串地址
    mov rdx, len        ; 字符串长度
    syscall             ; 执行系统调用

    mov rax, 60         ; sys_exit
    mov rdi, 0          ; 退出码
    syscall
```

编译运行：
```bash
nasm -f elf64 hello.asm -o hello.o   # 汇编
ld hello.o -o hello                   # 链接
./hello                                # 运行
```

## 2. CPU架构与寄存器

### 2.1 x86 / x86_64 架构简介

x86 架构源于 Intel 8086 处理器，经过多年发展，已成为最主流的 CPU 架构之一。

| 阶段 | 数据宽度 | 地址空间 | 代表型号 |
|-----|---------|---------|---------|
| 8086 | 16位 | 1MB | Intel 8086/8088 |
| 80386 | 32位 | 4GB | Intel 80386 |
| x86_64 | 64位 | 256TB | AMD Opteron, Intel Core 2 及以后 |

x86_64（又称 AMD64、Intel 64、x64）是 x86 的 64 位扩展，由 AMD 首先提出。

### 2.2 通用寄存器

#### x86（32位）通用寄存器

```
EAX —— 累加器 (Accumulator)
EBX —— 基址寄存器 (Base)
ECX —— 计数寄存器 (Counter)
EDX —— 数据寄存器 (Data)
ESI —— 源索引 (Source Index)
EDI —— 目的索引 (Destination Index)
EBP —— 基址指针 (Base Pointer)
ESP —— 栈指针 (Stack Pointer)
EIP —— 指令指针 (Instruction Pointer)
```

#### x86_64（64位）通用寄存器

在 32 位基础上扩展为 64 位，并新增 8 个寄存器：

```
RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP  —— 原 8 个扩展为 64 位
R8, R9, R10, R11, R12, R13, R14, R15    —— 新增 8 个通用寄存器
RIP —— 64位指令指针
```

#### 寄存器子部分

以 RAX 为例，其不同位宽的访问方式：

```
63                            31           15    7   0
+-----------------------------+------------+-----+---+
|                             |            |     |   |
|            RAX (64位)       |   EAX (32位)| AX  | AL|
|                             |            |     |   |
+-----------------------------+------------+-----+---+
                                                   |
                                             AH (高8位)
```

| 64位 | 32位 | 16位 | 高8位 | 低8位 |
|------|------|------|-------|-------|
| RAX | EAX | AX | AH | AL |
| RBX | EBX | BX | BH | BL |
| RCX | ECX | CX | CH | CL |
| RDX | EDX | DX | DH | DL |
| RSI | ESI | SI | - | SIL |
| RDI | EDI | DI | - | DIL |
| RBP | EBP | BP | - | BPL |
| RSP | ESP | SP | - | SPL |
| R8 | R8D | R8W | - | R8B |
| R9 | R9D | R9W | - | R9B |
| R10-R15 | R10D-R15D | R10W-R15W | - | R10B-R15B |

**注意**：
- 写入 32 位寄存器（如 EAX）会将高 32 位清零
- 写入 8 位或 16 位寄存器不会影响高位

### 2.3 标志寄存器（RFLAGS / EFLAGS）

标志寄存器用于反映运算结果的状态和控制处理器操作。

| 标志位 | 位 | 名称 | 说明 |
|-------|----|------|------|
| CF | 0 | 进位标志 (Carry Flag) | 无符号数运算溢出时置1 |
| PF | 2 | 奇偶标志 (Parity Flag) | 结果低8位1的个数为偶数时置1 |
| AF | 4 | 辅助进位 (Auxiliary) | BCD运算时低4位进位置1 |
| ZF | 6 | 零标志 (Zero Flag) | 结果为0时置1 |
| SF | 7 | 符号标志 (Sign Flag) | 结果为负时置1（最高位为1） |
| TF | 8 | 陷阱标志 (Trap Flag) | 置1时单步执行（调试用） |
| IF | 9 | 中断标志 (Interrupt) | 置1时允许可屏蔽中断 |
| DF | 10 | 方向标志 (Direction) | 字符串操作方向（0递增，1递减） |
| OF | 11 | 溢出标志 (Overflow) | 有符号数运算溢出时置1 |

标志位在安全领域的应用：
- **TF 标志**：反调试检测（单步执行时 TF=1）
- **DF 标志**：字符串操作方向控制
- **CF/OF/ZF**：条件跳转的判断依据

### 2.4 段寄存器

| 寄存器 | 名称 | 作用 |
|-------|------|------|
| CS | 代码段 (Code Segment) | 存放程序代码 |
| DS | 数据段 (Data Segment) | 存放全局/静态数据 |
| SS | 栈段 (Stack Segment) | 存放栈 |
| ES | 附加段 (Extra Segment) | 附加数据段（字符串操作目的） |
| FS | F 段 | 通常用于 TLS（线程局部存储） |
| GS | G 段 | 其他用途（SEH 等） |

在 32 位保护模式下，段寄存器存放段选择子（Segment Selector），指向 GDT/LDT 中的段描述符。

在 64 位模式下，段寄存器的作用大大弱化，CS/DS/ES/SS 的基址通常为 0，采用平坦内存模型。

### 2.5 控制寄存器（CR0-CR4）

控制寄存器用于控制处理器的工作模式。

| 寄存器 | 主要标志 | 作用 |
|-------|---------|------|
| CR0 | PE (bit 0) | 保护模式使能 |
| | PG (bit 31) | 分页使能 |
| | WP (bit 16) | 写保护 |
| CR2 | - | 页错误线性地址 |
| CR3 | - | 页目录基址（PDBR） |
| CR4 | PAE (bit 5) | 物理地址扩展 |
| | PSE (bit 4) | 页大小扩展 |

这些寄存器只能在特权级 0（内核模式）下访问。

### 2.6 调试寄存器（DR0-DR7）

| 寄存器 | 作用 |
|-------|------|
| DR0-DR3 | 硬件断点地址（最多4个） |
| DR4-DR5 | 保留 |
| DR6 | 调试状态 |
| DR7 | 调试控制（启用/禁用断点、类型设置） |

反调试中常检测这些寄存器的值。

## 3. 指令集基础

### 3.1 指令格式

一条典型的汇编指令格式：

```
[label:]  mnemonic  [operands]  [; comment]
```

- **label**：标签，表示当前地址（可选）
- **mnemonic**：指令助记符，如 `mov`、`add`、`jmp`
- **operands**：操作数，0~3个
- **comment**：注释，从 `;` 开始到行尾

示例：
```nasm
start:
    mov rax, 1      ; rax = 1
    add rax, rbx    ; rax += rbx
    ret             ; 返回
```

### 3.2 操作数类型

1. **立即数（Immediate）**：常量值
   ```nasm
   mov rax, 100        ; 十进制
   mov rax, 0x64       ; 十六进制
   mov rax, 0b1100100  ; 二进制
   mov rax, 'A'        ; 字符
   ```

2. **寄存器操作数**：CPU 内部寄存器
   ```nasm
   mov rax, rbx
   add ecx, edx
   ```

3. **内存操作数**：内存中的数据
   ```nasm
   mov rax, [0x12345678]    ; 直接地址
   mov rax, [rbx]            ; 寄存器间接
   mov rax, [rbx + rcx*4 + 8] ; 基址+变址+偏移
   ```

### 3.3 数据大小说明符

在 NASM 中，当操作数大小不明确时，需要指定大小：

| 关键字 | 大小 | 示例 |
|-------|------|------|
| `byte` | 1字节 (8位) | `mov byte [rax], 1` |
| `word` | 2字节 (16位) | `mov word [rax], 1` |
| `dword` | 4字节 (32位) | `mov dword [rax], 1` |
| `qword` | 8字节 (64位) | `mov qword [rax], 1` |
| `tword` | 10字节 (80位) | `fld tword [rax]` |

示例：
```nasm
mov byte  [buf], 'A'    ; 写入1字节
mov word  [buf], 0x1234 ; 写入2字节
mov dword [buf], 0x12345678  ; 写入4字节
mov qword [buf], 0x123456789ABCDEF0  ; 写入8字节
```

### 3.4 NASM 段定义

| 段名 | 说明 | 权限 |
|-----|------|------|
| `.text` / `.code` | 代码段 | 读/执行 |
| `.data` | 已初始化数据段 | 读/写 |
| `.bss` | 未初始化数据段 | 读/写 |
| `.rodata` | 只读数据段 | 只读 |

```nasm
section .data
    msg db 'Hello', 0   ; 已初始化数据

section .bss
    buf resb 256        ; 未初始化缓冲区（256字节）

section .text
    global _start
_start:
    ; 代码在这里
```

### 3.5 常用伪指令

| 伪指令 | 作用 | 示例 |
|-------|------|------|
| `db` | 定义字节 | `db 0x41, 'A', 0` |
| `dw` | 定义字 (2字节) | `dw 0x1234` |
| `dd` | 定义双字 (4字节) | `dd 0x12345678` |
| `dq` | 定义四字 (8字节) | `dq 0xDEADBEEFCAFEBABE` |
| `resb` | 预留字节 | `resb 100` |
| `resw` | 预留字 | `resw 50` |
| `resd` | 预留双字 | `resd 25` |
| `resq` | 预留四字 | `resq 12` |
| `equ` | 定义常量 | `len equ $ - msg` |
| `global` | 导出符号 | `global _start` |
| `extern` | 引用外部符号 | `extern printf` |
| `%define` | 宏定义 | `%define MAX 100` |

### 3.6 小端序与大端序

x86/x86_64 使用**小端序（Little Endian）**：低字节存放在低地址。

```
数值：0x12345678

小端序（x86）：
地址:  低  →  →  →  高
       78  56  34  12

大端序（网络字节序、ARM可选）：
地址:  低  →  →  →  高
       12  34  56  78
```

安全研究中的重要性：
- Shellcode 中构造数据时需要考虑小端序
- 网络编程中需要字节序转换（htonl/ntohl）
- 漏洞利用中构造数据时的字节排列

## 4. 寻址方式

寻址方式指的是如何确定操作数的内存地址。

### 4.1 立即寻址

操作数是立即数，直接包含在指令中。

```nasm
mov rax, 12345        ; rax = 12345
add ebx, 0x100        ; ebx += 0x100
```

### 4.2 寄存器寻址

操作数在寄存器中。

```nasm
mov rax, rbx          ; rax = rbx
add ecx, edx          ; ecx += edx
```

### 4.3 直接寻址

操作数的地址直接给出。

```nasm
mov rax, [0x12345678]  ; 从地址 0x12345678 读取8字节到 rax
mov [var], eax          ; 将 eax 写入变量 var
```

### 4.4 寄存器间接寻址

操作数的地址在寄存器中。

```nasm
mov rax, [rbx]         ; rax = 内存[rbx]
mov [rcx], rdx         ; 内存[rcx] = rdx
```

### 4.5 基址寻址

基址寄存器 + 偏移量。

```nasm
mov rax, [rbx + 8]     ; rax = 内存[rbx + 8]
mov [rbp - 16], eax    ; 内存[rbp - 16] = eax（局部变量）
```

### 4.6 变址寻址

变址寄存器 * 比例因子 + 偏移量。

比例因子只能是 1、2、4、8。

```nasm
mov rax, [array + rcx*4]   ; rax = array[rcx] (int数组)
mov rax, [table + rdx*8]   ; rax = table[rdx] (指针数组)
```

### 4.7 基址变址寻址

基址寄存器 + 变址寄存器 * 比例因子 + 偏移量。

```nasm
mov rax, [rbx + rcx*4 + 8]    ; 最完整的寻址方式
mov rax, [rbp + rdx*8 - 16]   ; 访问结构体中的数组元素
```

### 4.8 RIP 相对寻址（x86_64 特有）

以当前指令指针（RIP）为基址的相对寻址。

```nasm
lea rax, [rel msg]     ; rax = msg 的地址（RIP相对）
mov rax, [rel var]     ; 读取 var 的值
```

这是 64 位模式下访问全局变量的默认方式，用于生成位置无关代码（PIC）。

### 4.9 寻址方式总结表

| 寻址方式 | 格式 | 示例 |
|---------|------|------|
| 立即寻址 | 立即数 | `mov rax, 100` |
| 寄存器寻址 | 寄存器 | `mov rax, rbx` |
| 直接寻址 | [地址] | `mov rax, [0x1234]` |
| 寄存器间接 | [寄存器] | `mov rax, [rbx]` |
| 基址寻址 | [基址+偏移] | `mov rax, [rbx+8]` |
| 变址寻址 | [基址+变址*比例] | `mov rax, [arr+rcx*4]` |
| 基址变址 | [基址+变址*比例+偏移] | `mov rax, [rbx+rcx*4+8]` |
| RIP相对 | [rel 符号] | `mov rax, [rel var]` |

## 5. 数据传送指令

### 5.1 MOV 指令

最基本的数据传送指令。

```
MOV dst, src    ; dst = src
```

**示例：**
```nasm
; 寄存器间传送
mov rax, rbx          ; rax = rbx
mov eax, ebx          ; eax = ebx（高32位清零）
mov al, bl            ; al = bl

; 立即数到寄存器
mov rax, 100          ; rax = 100
mov ecx, 0xFFFFFFFF   ; ecx = -1

; 寄存器到内存
mov [buf], rax
mov byte [buf], 'A'

; 内存到寄存器
mov rax, [buf]
mov ecx, [buf + 4]
```

**注意事项：**
- 不能直接 `mov mem, mem`（内存到内存），需通过寄存器中转
- 操作数大小必须匹配
- 不能 `mov cs, ...`（代码段寄存器不能直接修改）

### 5.2 XCHG 指令

交换两个操作数的值。

```
XCHG a, b    ; 交换 a 和 b
```

```nasm
xchg rax, rbx        ; 交换 rax 和 rbx
xchg [buf], al       ; 交换内存和寄存器
```

### 5.3 LEA 指令

加载有效地址（Load Effective Address）。

```
LEA dst, [addr]    ; dst = addr 的地址（不访问内存）
```

LEA 不访问内存，只计算地址。常用于：
- 计算地址
- 进行简单的算术运算

```nasm
lea rax, [rbx + rcx*4 + 8]    ; rax = rbx + rcx*4 + 8
lea rax, [rax + rax*2]        ; rax = rax * 3
lea rdi, [rel msg]             ; 获取 msg 的地址（RIP相对）
```

**LEA 与 MOV 的区别：**
```nasm
mov rax, [rbx + 8]   ; rax = 内存[rbx+8] 的值
lea rax, [rbx + 8]   ; rax = rbx + 8（地址值）
```

### 5.4 堆栈操作指令

#### PUSH / POP

```
PUSH src    ; 压入栈：rsp -= size; [rsp] = src
POP dst     ; 弹出栈：dst = [rsp]; rsp += size
```

```nasm
push rax               ; 压入 rax (8字节)
push 123               ; 压入立即数
pop rbx                ; 弹出到 rbx
```

#### PUSHF / POPF

标志寄存器压栈和出栈：
```nasm
pushf                  ; 压入 RFLAGS (64位)
popf                   ; 弹出到 RFLAGS
```

#### PUSHA / POPA（32位）

压入/弹出所有通用寄存器（64位模式不支持）。

### 5.5 类型转换指令

用于符号扩展（有符号数扩展位宽）。

| 指令 | 作用 | 从 → 到 |
|-----|------|---------|
| `CBW` | 字节转字 | AL → AX |
| `CWDE` | 字转双字 | AX → EAX |
| `CDQE` | 双字转四字 | EAX → RAX |
| `CWD` | 字转双字（DX:AX） | AX → DX:AX |
| `CDQ` | 双字转四字（EDX:EAX） | EAX → EDX:EAX |
| `CQO` | 四字转八字（RDX:RAX） | RAX → RDX:RAX |

```nasm
; 有符号除法前需要符号扩展
mov rax, -10
cqo                      ; 符号扩展到 rdx:rax
mov rbx, 3
idiv rbx                 ; rax = 商, rdx = 余数
```

### 5.6 标志传送指令

| 指令 | 作用 |
|-----|------|
| `LAHF` | 将 EFLAGS 低8位加载到 AH |
| `SAHF` | 将 AH 存储到 EFLAGS 低8位 |
| `CLC` | 清除 CF（CF = 0） |
| `STC` | 设置 CF（CF = 1） |
| `CMC` | 取反 CF |
| `CLD` | 清除 DF（字符串递增） |
| `STD` | 设置 DF（字符串递减） |
| `CLI` | 清除 IF（关中断） |
| `STI` | 设置 IF（开中断） |

```nasm
cld                      ; 字符串操作方向：递增
std                      ; 字符串操作方向：递减
clc                      ; 清除进位标志
```

## 6. 算术逻辑指令

### 6.1 加法指令

#### ADD —— 加法
```
ADD dst, src    ; dst = dst + src
```
```nasm
add rax, rbx            ; rax += rbx
add ecx, 100            ; ecx += 100
add byte [buf], 5       ; 内存字节 +5
```

#### ADC —— 带进位加法
```
ADC dst, src    ; dst = dst + src + CF
```
用于大整数运算：
```nasm
; 128位加法：rdx:rax += rcx:rbx
add rax, rbx            ; 低64位相加
adc rdx, rcx            ; 高64位 + 进位
```

#### INC —— 自增
```
INC dst    ; dst = dst + 1
```
```nasm
inc rax                 ; rax++
inc byte [counter]      ; 计数器+1
```
**注意**：INC 不影响 CF 标志。

### 6.2 减法指令

#### SUB —— 减法
```
SUB dst, src    ; dst = dst - src
```

#### SBB —— 带借位减法
```
SBB dst, src    ; dst = dst - src - CF
```

#### DEC —— 自减
```
DEC dst    ; dst = dst - 1
```
DEC 不影响 CF 标志。

#### NEG —— 取负（补码）
```
NEG dst    ; dst = -dst  (0 - dst)
```
```nasm
mov rax, 5
neg rax                 ; rax = -5
```

#### CMP —— 比较
```
CMP a, b    ; a - b（只设置标志位，不修改操作数）
```
比较指令本质是减法，但只影响标志位，不改变操作数。常用于条件跳转之前。

```nasm
cmp rax, 10
jg  greater_than_10     ; 如果 rax > 10 则跳转
```

### 6.3 乘法指令

#### MUL —— 无符号乘法
```
MUL src
; 8位:  AX = AL * src
; 16位: DX:AX = AX * src
; 32位: EDX:EAX = EAX * src
; 64位: RDX:RAX = RAX * src
```

```nasm
mov rax, 100
mov rbx, 200
mul rbx                 ; rdx:rax = 100 * 200
```

#### IMUL —— 有符号乘法

形式1（单操作数，同 MUL）：
```nasm
imul rbx                ; rdx:rax = rax * rbx (有符号)
```

形式2（双操作数）：
```
IMUL dst, src    ; dst = dst * src
```
```nasm
imul rax, rbx           ; rax *= rbx
```

形式3（三操作数）：
```
IMUL dst, src, imm    ; dst = src * imm
```
```nasm
imul rax, rbx, 10       ; rax = rbx * 10
```

### 6.4 除法指令

#### DIV —— 无符号除法
```
DIV src
; 8位:  AL = AX / src, AH = 余数
; 16位: AX = DX:AX / src, DX = 余数
; 32位: EAX = EDX:EAX / src, EDX = 余数
; 64位: RAX = RDX:RAX / src, RDX = 余数
```

```nasm
mov rax, 100
xor rdx, rdx            ; rdx = 0 (被除数高位置0)
mov rbx, 7
div rbx                 ; rax = 14 (商), rdx = 2 (余数)
```

#### IDIV —— 有符号除法

使用前需要符号扩展：
```nasm
mov rax, -100
cqo                     ; 符号扩展 rax → rdx:rax
mov rbx, 7
idiv rbx                ; rax = -14, rdx = -2
```

**除零错误**：除数为 0 或商溢出时触发 #DE 异常。

### 6.5 逻辑运算指令

#### AND —— 按位与
```
AND dst, src    ; dst = dst & src
```
```nasm
and rax, 0xFF           ; 保留低8位
and eax, eax            ; 清高位，同时设置标志位
```

#### OR —— 按位或
```
OR dst, src    ; dst = dst | src
```

#### XOR —— 按位异或
```
XOR dst, src    ; dst = dst ^ src
```
```nasm
xor rax, rax            ; rax = 0（清零技巧，比 mov 短）
xor rax, 0xFF           ; 翻转低8位
```

#### NOT —— 按位取反
```
NOT dst    ; dst = ~dst
```
NOT 不影响标志位。

#### TEST —— 按位测试
```
TEST a, b    ; a & b（只设置标志位）
```
```nasm
test rax, rax           ; 检查 rax 是否为 0
jz   is_zero

test eax, 0x80          ; 检查最高位是否为1
js   is_negative
```

### 6.6 移位指令

#### SHL / SHR —— 逻辑移位
```
SHL dst, count    ; 逻辑左移（低位补0）
SHR dst, count    ; 逻辑右移（高位补0）
```
```nasm
shl rax, 3                ; rax <<= 3 (相当于 * 8)
shr rax, cl               ; rax >>= cl (逻辑右移)
```

#### SAL / SAR —— 算术移位
```
SAL dst, count    ; 算术左移（同 SHL）
SAR dst, count    ; 算术右移（高位补符号位）
```
```nasm
mov rax, -8
sar rax, 2                ; rax = -2 (算术右移，保持符号)
```

#### ROL / ROR —— 循环移位
```
ROL dst, count    ; 循环左移
ROR dst, count    ; 循环右移
```

#### RCL / RCR —— 带进位循环移位
```
RCL dst, count    ; 带进位循环左移
RCR dst, count    ; 带进位循环右移
```

移位指令的 count 可以是立即数或 CL 寄存器。

### 6.7 标志位影响汇总

| 指令 | CF | OF | ZF | SF | PF | AF |
|-----|----|----|----|----|----|----|
| ADD/ADC | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| SUB/SBB/CMP/NEG | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| MUL/IMUL | ✓ | ✓ | ? | ? | ? | ? |
| DIV/IDIV | ? | ? | ? | ? | ? | ? |
| INC/DEC | - | ✓ | ✓ | ✓ | ✓ | ✓ |
| AND/OR/XOR | 0 | 0 | ✓ | ✓ | ✓ | ? |
| TEST | 0 | 0 | ✓ | ✓ | ✓ | ? |
| NOT | - | - | - | - | - | - |
| SHL/SHR | ✓ | ✓ | ✓ | ✓ | ✓ | ? |
| SAR | ✓ | ? | ✓ | ✓ | ✓ | ? |

✓ = 受影响, 0 = 清零, - = 不影响, ? = 未定义

## 7. 控制转移指令

### 7.1 无条件跳转

#### JMP —— 无条件跳转
```
JMP target    ; 跳转到 target
```

跳转类型：
```nasm
jmp short label         ; 短跳转（-128 ~ +127 字节）
jmp near label          ; 近跳转（同一段内）
jmp far 0x10:0x1234     ; 远跳转（跨段）
jmp rbx                 ; 间接跳转（寄存器）
jmp [addr]              ; 间接跳转（内存）
```

### 7.2 条件跳转

条件跳转根据标志位决定是否跳转。

#### 基于零标志（ZF）
| 指令 | 条件 | 说明 |
|-----|------|------|
| `JZ` / `JE` | ZF = 1 | 为零 / 相等 |
| `JNZ` / `JNE` | ZF = 0 | 不为零 / 不相等 |

```nasm
cmp rax, rbx
je  equal               ; 如果 rax == rbx 则跳转
```

#### 基于进位标志（CF）
| 指令 | 条件 | 说明 |
|-----|------|------|
| `JC` / `JB` / `JNAE` | CF = 1 | 进位 / 低于 |
| `JNC` / `JAE` / `JNB` | CF = 0 | 无进位 / 高于等于 |

#### 基于溢出标志（OF）
| 指令 | 条件 | 说明 |
|-----|------|------|
| `JO` | OF = 1 | 溢出 |
| `JNO` | OF = 0 | 无溢出 |

#### 基于符号标志（SF）
| 指令 | 条件 | 说明 |
|-----|------|------|
| `JS` | SF = 1 | 负数 |
| `JNS` | SF = 0 | 非负数 |

#### 基于奇偶标志（PF）
| 指令 | 条件 | 说明 |
|-----|------|------|
| `JP` / `JPE` | PF = 1 | 偶数个1 |
| `JNP` / `JPO` | PF = 0 | 奇数个1 |

#### 无符号数比较（CMP a, b）
| 指令 | 含义 | 条件 |
|-----|------|------|
| `JA` / `JNBE` | a > b | CF=0 且 ZF=0 |
| `JAE` / `JNB` | a >= b | CF=0 |
| `JB` / `JNAE` | a < b | CF=1 |
| `JBE` / `JNA` | a <= b | CF=1 或 ZF=1 |

#### 有符号数比较（CMP a, b）
| 指令 | 含义 | 条件 |
|-----|------|------|
| `JG` / `JNLE` | a > b | ZF=0 且 SF=OF |
| `JGE` / `JNL` | a >= b | SF=OF |
| `JL` / `JNGE` | a < b | SF≠OF |
| `JLE` / `JNG` | a <= b | ZF=1 或 SF≠OF |

**记忆方法：**
- 无符号：A = Above（高于），B = Below（低于）
- 有符号：G = Greater（大于），L = Less（小于）
- E = Equal（等于），N = Not（不）

### 7.3 循环指令

#### LOOP
```
LOOP label    ; rcx--; if (rcx != 0) goto label
```
```nasm
mov rcx, 10
loop_start:
    ; 循环体
    loop loop_start     ; 循环10次
```

#### LOOPE / LOOPZ
```
LOOPE label   ; rcx--; if (rcx != 0 && ZF == 1) goto label
```

#### LOOPNE / LOOPNZ
```
LOOPNE label  ; rcx--; if (rcx != 0 && ZF == 0) goto label
```

### 7.4 调用与返回

#### CALL —— 调用函数
```
CALL target   ; 压入返回地址，跳转到 target
```

执行过程：
1. 将返回地址（CALL 下一条指令的地址）压入栈
2. 跳转到 target

```nasm
call my_function
; 返回到这里继续执行
```

#### RET —— 返回
```
RET           ; 弹出栈顶到 RIP
RET n         ; 弹出栈顶到 RIP，再释放 n 字节栈空间
```

执行过程：
1. 从栈顶弹出返回地址到 RIP
2. 继续执行

### 7.5 中断指令

| 指令 | 说明 |
|-----|------|
| `INT n` | 软中断（n 为中断号） |
| `INT3` | 断点中断（INT 3，0xCC） |
| `INTO` | 溢出中断（OF=1 时触发） |
| `IRET` | 中断返回 |

```nasm
; 32位 Linux 系统调用使用 int 0x80
mov eax, 1          ; sys_exit
mov ebx, 0
int 0x80
```

在安全研究中，INT3（0xCC）是软件断点的标志，反调试常检测它。

### 7.6 条件设置指令（SETcc）

根据条件设置字节为 0 或 1。

```
SETcc dst    ; 如果条件 cc 成立，dst = 1；否则 dst = 0
```

```nasm
cmp rax, rbx
sete al                 ; al = (rax == rbx) ? 1 : 0

test eax, eax
setz bl                 ; bl = (eax == 0) ? 1 : 0

setg cl                 ; cl = 大于 ? 1 : 0
```

### 7.7 条件传送指令（CMOVcc）

根据条件传送数据（Pentium Pro 及以后支持）。

```
CMOVcc dst, src   ; 如果条件 cc 成立，dst = src
```

```nasm
cmp rax, 0
cmovz rbx, rcx          ; 如果 rax == 0，则 rbx = rcx
```

常用于避免分支预测失败。

## 8. 函数调用约定

### 8.1 什么是调用约定

调用约定规定了：
1. 参数如何传递（寄存器、栈）
2. 返回值放在哪里
3. 哪些寄存器由调用者保存，哪些由被调用者保存
4. 栈的清理方式

不同的架构和操作系统有不同的调用约定。

### 8.2 x86_64 System V ABI（Linux/macOS）

这是 Linux 和 macOS 使用的调用约定。

#### 参数传递

前 6 个整数/指针参数通过寄存器传递：

| 参数序号 | 寄存器 |
|---------|--------|
| 第1个 | RDI |
| 第2个 | RSI |
| 第3个 | RDX |
| 第4个 | RCX |
| 第5个 | R8 |
| 第6个 | R9 |

超过 6 个参数：从右往左压入栈中。

浮点参数通过 XMM0-XMM7 传递。

#### 返回值

- 整数/指针返回值：RAX（64位）或 RDX:RAX（128位）
- 浮点返回值：XMM0 或 XMM1:XMM0

#### 寄存器保存规则

| 类型 | 寄存器 | 说明 |
|-----|--------|------|
| **调用者保存** (Caller-saved) | RAX, RDI, RSI, RDX, RCX, R8, R9, R10, R11 | 调用后可能被修改，调用者需自行保存 |
| **被调用者保存** (Callee-saved) | RBX, RBP, R12, R13, R14, R15 | 函数返回后值不变，被调用者需保存/恢复 |

#### 栈对齐

- 栈必须 16 字节对齐
- CALL 指令压入 8 字节返回地址，所以进入函数时栈是 8 字节对齐的
- 函数需要再压入 8 字节（如 push rbp）来恢复 16 字节对齐

### 8.3 调用约定示例

#### 示例1：两个参数

```c
// C 代码
int add(int a, int b) {
    return a + b;
}
```

```nasm
; 汇编实现
add:
    push rbp
    mov  rbp, rsp
    ; rdi = a, rsi = b
    mov  eax, edi
    add  eax, esi        ; 返回值在 eax
    pop  rbp
    ret
```

#### 示例2：六个以上参数

```c
// C 代码
int many_args(int a, int b, int c, int d, int e, int f, int g) {
    return a + b + c + d + e + f + g;
}
```

```nasm
; 汇编视角
; rdi = a, rsi = b, rdx = c, rcx = d, r8 = e, r9 = f
; [rsp + 8] = g (第7个参数在栈上)
many_args:
    mov  eax, edi
    add  eax, esi
    add  eax, edx
    add  eax, ecx
    add  eax, r8d
    add  eax, r9d
    add  eax, [rsp + 8]  ; 第7个参数
    ret
```

### 8.4 x86（32位）调用约定

#### cdecl（C 调用约定）
- 参数从右往左压栈
- 调用者清理栈
- 返回值在 EAX

```c
// cdecl
int func(int a, int b);
```
```nasm
push b
push a
call func
add  esp, 8            ; 调用者清理栈
```

#### stdcall
- 参数从右往左压栈
- 被调用者清理栈（RET n）
- Windows API 使用

```nasm
push b
push a
call func              ; 函数内部用 ret 8 清理
```

#### fastcall
- 前两个参数在 ECX 和 EDX
- 其余参数从右往左压栈
- 被调用者清理栈

### 8.5 x64 Windows 调用约定

与 System V ABI 不同，Windows x64 有自己的约定：

| 参数序号 | 寄存器 |
|---------|--------|
| 第1个 | RCX |
| 第2个 | RDX |
| 第3个 | R8 |
| 第4个 | R9 |
| 更多 | 栈（从右往左） |

- 调用者必须分配 32 字节的"影子空间"（shadow space）
- 被调用者保存：RBX, RBP, RDI, RSI, R12-R15, XMM6-XMM15
- 返回值在 RAX

## 9. 栈与栈帧

### 9.1 栈的基本概念

栈（Stack）是一块特殊的内存区域，具有 **后进先出（LIFO）** 的特性。

- **栈顶**：低地址方向，由 ESP/RSP 指向
- **栈底**：高地址方向，由 EBP/RBP 指向
- **增长方向**：从高地址向低地址增长

```
高地址
    ...
    [ 参数 N ]
    [ 参数 N-1 ]
    ...
    [ 返回地址 ]
RBP -> [ 旧 RBP ]
    [ 局部变量1 ]
    [ 局部变量2 ]
    ...
RSP -> [ 栈顶 ]
低地址
```

### 9.2 栈帧结构

一个典型的函数栈帧（Stack Frame）：

```
; 进入函数时
push rbp           ; 保存旧的 rbp
mov  rbp, rsp      ; 设置新的栈帧基址
sub  rsp, N        ; 分配 N 字节局部变量空间

; 函数体...

; 离开函数时
mov  rsp, rbp      ; 恢复栈指针
pop  rbp           ; 恢复基址指针
ret                ; 返回
```

可以简化为：
```nasm
enter N, 0         ; 等价于 push rbp; mov rbp, rsp; sub rsp, N
; ...
leave              ; 等价于 mov rsp, rbp; pop rbp
ret
```

### 9.3 栈帧中的数据访问

```
高地址
+------------------+ <-- rbp + 16  (第2个参数)
|   参数2          |
+------------------+ <-- rbp + 8   (第1个参数)
|   参数1          |
+------------------+ <-- rbp + 0   (返回地址，64位)
|   返回地址       |
+------------------+ <-- rbp (旧rbp的地址)
|   旧 rbp         |
+------------------+ <-- rbp - 8   (局部变量1)
|   局部变量1      |
+------------------+ <-- rbp - 16  (局部变量2)
|   局部变量2      |
+------------------+
|   ...            |
+------------------+ <-- rsp
低地址
```

```nasm
; 访问参数（x86 32位示例）
mov eax, [ebp + 8]     ; 第1个参数
mov ebx, [ebp + 12]    ; 第2个参数

; 访问局部变量
mov [ebp - 4], eax     ; 局部变量1
mov [ebp - 8], ebx     ; 局部变量2
```

**注意**：x86_64 前6个参数在寄存器中，通常不需要从栈上访问。

### 9.4 栈的用途

1. **保存返回地址**：CALL 指令自动压入
2. **保存寄存器**：保存被调用者保存寄存器
3. **局部变量**：函数内部的临时变量
4. **传递参数**：寄存器不够用时通过栈传递
5. **临时存储**：寄存器不够用时的中转

### 9.5 栈溢出原理

栈溢出是最经典的内存安全漏洞：

```c
void vulnerable(char *input) {
    char buffer[64];          // 局部变量（64字节）
    strcpy(buffer, input);    // 无边界检查的拷贝
}
```

当输入超过 64 字节时，多余的数据会覆盖：
1. 旧的 EBP/RBP
2. 返回地址
3. 函数参数
4. ...

**利用方式**：覆盖返回地址为 Shellcode 地址，从而控制程序执行流。

**保护机制**：
- 栈保护（Canary / GS Cookie）
- DEP / NX（栈不可执行）
- ASLR（地址空间随机化）

### 9.6 叶子函数与栈帧优化

不调用其他函数的函数称为**叶子函数（Leaf Function）**，编译器可能会优化掉栈帧：

```nasm
; 优化后的叶子函数（无栈帧）
add_numbers:
    mov rax, rdi
    add rax, rsi
    ret
```

这种函数不使用 RBP，也不分配栈空间，执行效率更高。

## 10. 系统调用

### 10.1 什么是系统调用

系统调用（System Call）是用户程序与操作系统内核之间的接口。用户程序通过系统调用请求内核提供服务，如文件操作、网络通信、内存分配等。

### 10.2 x86_64 Linux 系统调用约定

| 项目 | 说明 |
|-----|------|
| 调用号 | RAX |
| 参数1 | RDI |
| 参数2 | RSI |
| 参数3 | RDX |
| 参数4 | R10 |
| 参数5 | R8 |
| 参数6 | R9 |
| 指令 | SYSCALL |
| 返回值 | RAX（负数表示错误） |
| 被破坏的寄存器 | RCX, R11 |

**注意**：第4个参数是 R10（不是 RCX），因为 SYSCALL 指令会用 RCX 保存 RIP。

### 10.3 常用系统调用

| 编号 | 名称 | 作用 | 参数 |
|-----|------|------|------|
| 0 | sys_read | 读取文件 | fd, buf, count |
| 1 | sys_write | 写入文件 | fd, buf, count |
| 2 | sys_open | 打开文件 | name, flags, mode |
| 3 | sys_close | 关闭文件 | fd |
| 8 | sys_lseek | 文件定位 | fd, offset, whence |
| 9 | sys_mmap | 内存映射 | addr, len, prot, flags, fd, off |
| 10 | sys_mprotect | 内存保护 | addr, len, prot |
| 11 | sys_munmap | 解除映射 | addr, len |
| 12 | sys_brk | 设置堆大小 | brk |
| 39 | sys_getpid | 获取PID | - |
| 41 | sys_socket | 创建套接字 | family, type, protocol |
| 42 | sys_connect | 连接套接字 | fd, addr, len |
| 57 | sys_fork | 创建子进程 | - |
| 59 | sys_execve | 执行程序 | path, argv, envp |
| 60 | sys_exit | 退出进程 | code |
| 101 | sys_ptrace | 进程跟踪 | request, pid, addr, data |
| 102 | sys_getuid | 获取UID | - |
| 231 | sys_exit_group | 退出线程组 | code |

### 10.4 sys_write 示例

```nasm
; write(1, "Hello\n", 6)
mov rax, 1          ; sys_write
mov rdi, 1          ; fd = 1 (stdout)
mov rsi, msg        ; buf = 字符串地址
mov rdx, 6          ; count = 6
syscall             ; 执行系统调用
```

### 10.5 sys_execve 示例

```nasm
; execve("/bin/sh", NULL, NULL)
xor rax, rax
push rax                       ; 字符串结尾 0
mov  rbx, 0x68732F6E69622F2F  ; "//bin/sh"
push rbx
mov  rdi, rsp                  ; path
xor  rsi, rsi                  ; argv = NULL
xor  rdx, rdx                  ; envp = NULL
mov  al, 59                    ; sys_execve
syscall
```

这是经典的 execve shellcode 实现。

### 10.6 x86（32位）系统调用

32 位 Linux 使用 `int 0x80` 触发系统调用：

| 项目 | 说明 |
|-----|------|
| 调用号 | EAX |
| 参数1 | EBX |
| 参数2 | ECX |
| 参数3 | EDX |
| 参数4 | ESI |
| 参数5 | EDI |
| 参数6 | EBP |
| 指令 | int 0x80 |
| 返回值 | EAX |

```nasm
; 32位 write 示例
mov eax, 4          ; sys_write (32位编号 = 4)
mov ebx, 1          ; stdout
mov ecx, msg
mov edx, len
int 0x80
```

### 10.8 安全意义

- **Shellcode 核心**：Shellcode 的本质就是通过系统调用完成特定功能
- **系统调用钩子**：Rootkit 常通过 Hook 系统调用来隐藏自身
- **系统调用过滤**：seccomp 等安全机制限制可用的系统调用
- **syscall/sysret**：理解系统调用机制有助于内核漏洞利用

## 11. 汇编与C混合编程

### 11.1 C 调用汇编函数

#### 方法1：单独的汇编文件

```nasm
; add.asm
section .text
global add_numbers       ; 导出函数

add_numbers:
    ; rdi = a, rsi = b
    mov rax, rdi
    add rax, rsi
    ret
```

```c
// main.c
#include <stdio.h>

extern int add_numbers(int a, int b);

int main() {
    int result = add_numbers(10, 20);
    printf("Result: %d\n", result);
    return 0;
}
```

编译链接：
```bash
nasm -f elf64 add.asm -o add.o
gcc main.c add.o -o main
./main
```

#### 方法2：内联汇编（GCC extended asm）

```c
#include <stdio.h>

int add_numbers(int a, int b) {
    int result;
    __asm__ __volatile__ (
        "add %1, %0\n\t"      // result += a
        "add %2, %0\n\t"      // result += b
        : "=r"(result)        // 输出操作数
        : "0"(0), "r"(a), "r"(b)  // 输入操作数
        :                     // 破坏列表
    );
    return result;
}

int main() {
    printf("%d\n", add_numbers(10, 20));
    return 0;
}
```

### 11.2 GCC 内联汇编语法

```c
__asm__ __volatile__ (
    "汇编指令模板"
    : 输出操作数列表
    : 输入操作数列表
    : 破坏的寄存器列表
);
```

#### 操作数约束符

| 约束 | 含义 |
|-----|------|
| `r` | 任意通用寄存器 |
| `a` | eax/rax |
| `b` | ebx/rbx |
| `c` | ecx/rcx |
| `d` | edx/rdx |
| `S` | esi/rsi |
| `D` | edi/rdi |
| `m` | 内存操作数 |
| `i` | 立即数 |
| `g` | 寄存器/内存/立即数 |
| `=r` | 输出操作数（只写） |
| `+r` | 输入输出操作数（读写） |
| `0` | 与第0个操作数使用同一寄存器 |

#### 示例：读取时间戳计数器

```c
uint64_t rdtsc() {
    uint32_t lo, hi;
    __asm__ __volatile__ (
        "rdtsc"
        : "=a"(lo), "=d"(hi)
    );
    return (uint64_t)hi << 32 | lo;
}
```

### 11.3 C 函数对应的汇编

以下面的 C 代码为例：

```c
int add(int a, int b) {
    int sum = a + b;
    return sum;
}
```

对应的汇编（未优化）：
```nasm
add:
    push    rbp
    mov     rbp, rsp
    mov     [rbp-4], edi      ; 保存参数 a
    mov     [rbp-8], esi      ; 保存参数 b
    mov     edx, [rbp-4]
    mov     eax, [rbp-8]
    add     eax, edx
    mov     [rbp-12], eax     ; sum = a + b
    mov     eax, [rbp-12]     ; 返回值
    pop     rbp
    ret
```

优化后的汇编（-O2）：
```nasm
add:
    lea eax, [rdi + rsi]
    ret
```

### 11.4 查看 C 代码的汇编输出

```bash
# 生成汇编代码
gcc -S test.c -o test.s          # AT&T 语法
gcc -S -masm=intel test.c        # Intel 语法

# 反编译目标文件
objdump -d test.o                # 反汇编
objdump -d -M intel test.o       # Intel 语法

# 编译+反编译（不生成中间文件）
gcc -c test.c -o test.o && objdump -d test.o
```

### 11.5 汇编调用 C 函数

```nasm
; call_c.asm
extern printf
extern exit

section .data
    fmt db 'Result: %d', 0xA, 0

section .text
global main

main:
    ; 调用 printf(fmt, 42)
    mov rdi, fmt          ; 第1个参数：格式字符串
    mov rsi, 42           ; 第2个参数：数值
    xor rax, rax          ; 浮点参数数量 = 0
    call printf

    ; 调用 exit(0)
    mov rdi, 0
    call exit
```

```bash
nasm -f elf64 call_c.asm -o call_c.o
gcc call_c.o -o call_c
./call_c
```

- **Shellcode 测试**：用 C 写测试框架，调用汇编 Shellcode
- **性能优化**：关键路径用汇编优化
- **Inline Hook**：用汇编实现函数钩子
- **Shellcode 注入**：汇编代码注入到目标进程

### 12.1 NASM 汇编器

| `bin` | 纯二进制（无格式） |


### 12.3 GDB 调试器

GDB（GNU Debugger）是 Linux 下最常用的调试器。

#### 基本命令

| 命令 | 缩写 | 作用 |
|-----|------|------|
| `file <程序>` | | 加载程序 |
| `run [参数]` | `r` | 运行程序 |
| `break <位置>` | `b` | 设置断点 |

格式说明：
- `x` = 十六进制, `d` = 十进制, `i` = 指令, `s` = 字符串

- 栈帧结构与栈溢出原理
