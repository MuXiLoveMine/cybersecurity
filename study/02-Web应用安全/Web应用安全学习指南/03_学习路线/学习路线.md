# 学习路线

### 阶段 1：Web 基础（1-2 个月）
**学习目标**：掌握 Web 基础知识，理解 Web 工作原理

**学习内容**
- HTTP/HTTPS 协议
- HTML/CSS/JavaScript 基础
- 前端开发基础
- 后端开发基础（PHP 或 Python）
- 数据库基础（MySQL）
- Web 服务器配置（Apache/Nginx）

**实践任务**
- 搭建 LAMP/LNMP 环境
- 开发简单的 Web 应用
- 用 Burp Suite 抓包分析
- 学习 HTTP 请求和响应

### 阶段 2：Web 安全入门（2-3 个月）
**学习目标**：掌握常见 Web 漏洞原理和基本利用

**学习内容**
- SQL 注入（联合查询、报错、盲注）
- XSS 跨站脚本（反射型、存储型、DOM 型）
- CSRF 跨站请求伪造
- 文件上传漏洞
- 文件包含漏洞
- 命令执行漏洞
- 代码执行漏洞
- SSRF 漏洞
- XXE 漏洞
- 信息泄露

**实践任务**
- 打 DVWA 全部关卡
- 打 SQLi-Labs 全部关卡
- 打 Upload-labs 全部关卡
- 打皮卡丘靶场
- 用 Burp Suite 进行渗透测试

### 阶段 3：Web 安全进阶（3-4 个月）
**学习目标**：深入理解高级漏洞，掌握绕过技巧

**学习内容**
- SQL 注入进阶（绕过、WAF 绕过、各种数据库）
- XSS 进阶（绕过、CSP 绕过、利用技巧）
- 反序列化漏洞（PHP、Java、Python）
- 模板注入（SSTI）
- 业务逻辑漏洞
- 越权漏洞
- 支付漏洞
- 验证码漏洞
- 中间件漏洞
- CMS 漏洞
- WAF 绕过

**实践任务**
- 打 CTF Web 题目
- 打 Vulhub 漏洞环境
- 打 PortSwigger Web Security Academy
- 代码审计练习
- 挖 SRC（合法授权）

### 阶段 4：渗透测试实战（2-3 个月）
**学习目标**：掌握完整的渗透测试流程，具备实战能力

**学习内容**
- 渗透测试方法论
- 信息收集技巧
- 漏洞扫描与验证
- Web Shell 使用
- 权限维持
- 内网渗透基础
- 渗透测试报告编写

**实践任务**
- 完成完整的渗透测试项目
- 打综合靶场（如 VulnHub 的靶机）
- 参与 CTF 比赛
- 挖 SRC 漏洞
- 写渗透测试报告

### 阶段 5：深入研究（持续）
**学习目标**：深入研究某个方向，成为专家

**研究方向**
- 代码审计
- 漏洞挖掘
- WAF 绕过
- 浏览器安全
- API 安全
- 云原生安全
- 安全开发
- 安全研究
