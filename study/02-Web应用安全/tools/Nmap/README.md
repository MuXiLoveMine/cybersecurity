## 快速开始

```bash
# 最简单的扫描
nmap 192.168.1.1

# 主机发现
nmap -sn 192.168.1.0/24

# 全面扫描
nmap -A 192.168.1.1

# 全端口扫描
nmap -p- -T4 192.168.1.1
```

更多内容请查看各分文档。
