# Nmap 常用命令速查表

> 本速查表整理了 Nmap 最常用的命令和参数，方便快速查阅。

---

## 一、基础扫描

| 命令 | 说明 |
|------|------|
| `nmap 192.168.1.1` | 扫描单个 IP（默认 SYN 扫描，1000 个常用端口） |
| `nmap example.com` | 扫描域名 |
| `nmap 192.168.1.1 192.168.1.2` | 扫描多个 IP |
| `nmap 192.168.1.0/24` | 扫描 C 段 |
| `nmap 192.168.1.1-100` | 扫描 IP 范围 |
| `nmap -iL targets.txt` | 从文件读取目标 |
| `nmap 192.168.1.0/24 --exclude 192.168.1.1` | 排除指定 IP |
| `nmap -sn 192.168.1.0/24` | 仅主机发现（不扫端口） |
| `nmap -Pn 192.168.1.1` | 跳过主机发现，直接扫描端口 |

---

## 二、端口扫描

### 2.1 扫描类型

| 参数 | 类型 | 说明 |
|------|------|------|
| `-sS` | TCP SYN | 半开放扫描（默认，需 root），快且隐蔽 |
| `-sT` | TCP Connect | 完整 TCP 连接，不需 root，易被记录 |
| `-sU` | UDP | UDP 端口扫描，慢 |
| `-sA` | TCP ACK | ACK 扫描，探测防火墙规则 |
| `-sW` | TCP Window | 窗口扫描，判断端口开放/关闭 |
| `-sN` | Null | 无标志位，绕过某些防火墙 |
| `-sF` | FIN | FIN 标志位，绕过无状态防火墙 |
| `-sX` | Xmas | FIN+PSH+URG，圣诞包扫描 |

### 2.2 端口指定

| 命令 | 说明 |
|------|------|
| `nmap -p 22 192.168.1.1` | 扫描单个端口 |
| `nmap -p 22,80,443 192.168.1.1` | 扫描多个端口 |
| `nmap -p 1-1000 192.168.1.1` | 扫描端口范围 |
| `nmap -p- 192.168.1.1` | 扫描全端口（1-65535） |
| `nmap -F 192.168.1.1` | 快速扫描（100 个常用端口） |
| `nmap --top-ports 100 192.168.1.1` | 扫描前 N 个常用端口 |
| `nmap -p T:80,443,U:53 192.168.1.1` | 指定协议和端口 |
| `nmap -p http,https,ssh 192.168.1.1` | 按服务名指定端口 |

---

## 三、主机发现

| 参数 | 说明 |
|------|------|
| `-sn` | Ping 扫描（仅主机发现） |
| `-Pn` | 跳过主机发现（假设所有主机存活） |
| `-PS22,80,443` | TCP SYN Ping（指定端口） |
| `-PA80,443` | TCP ACK Ping |
| `-PU53,161` | UDP Ping |
| `-PE` | ICMP Echo Ping |
| `-PP` | ICMP Timestamp Ping |
| `-PM` | ICMP Netmask Ping |
| `-PR` | ARP Ping（局域网最快最准） |
| `-n` | 不做 DNS 解析（更快） |
| `-R` | 总是做 DNS 反向解析 |

**常用组合：**
```bash
# 快速存活主机扫描（ARP + 不解析DNS）
nmap -sn -PR -n 192.168.1.0/24

# 目标禁 Ping 时使用
nmap -sn -PS22,80,443 -PU53,161 192.168.1.0/24
```

## 四、服务与版本探测

| 参数 | 说明 |
|------|------|
| `-sV` | 服务版本探测 |
| `-sV --version-intensity 5` | 版本探测强度（0-9，默认 7） |
| `-sV --version-light` | 轻量级探测（强度 2） |
| `-sV --version-all` | 最高强度探测（强度 9） |
| `-O` | 操作系统探测 |
| `-O --osscan-guess` | 激进猜测 OS |
| `-A` | 全面扫描（-sV -O -sC --traceroute） |

## 五、脚本扫描（NSE）

### 5.1 脚本分类

| 分类 | 说明 |
|------|------|
| `default` | 默认脚本（安全且信息丰富） |
| `safe` | 安全无害脚本 |
| `discovery` | 服务/主机发现 |
| `vuln` | 漏洞检测 |
| `auth` | 认证绕过相关 |
| `brute` | 暴力破解 |
| `exploit` | 漏洞利用 |
| `dos` | 拒绝服务攻击 |
| `fuzzer` | Fuzz 测试 |
| `intrusive` | 可能触发报警/破坏 |

### 5.2 常用命令

```bash
# 默认安全脚本扫描
nmap -sC 192.168.1.1

# 漏洞脚本扫描
nmap --script=vuln 192.168.1.1

# 指定脚本
nmap --script=http-title,ssh-auth-methods -p 80,22 192.168.1.1

# 多个分类组合
nmap --script=vuln,auth,brute -sV 192.168.1.1

# 脚本传参
nmap --script=http-enum --script-args http-enum.url-path=/admin 192.168.1.1

# 暴力破解
nmap --script=ssh-brute --script-args userdb=users.txt,passdb=pass.txt -p 22 192.168.1.1
```

### 5.3 常用脚本速查

| 脚本名 | 端口 | 说明 |
|--------|------|------|
| `http-title` | 80/443 | 获取网页标题 |
| `http-methods` | 80/443 | 支持的 HTTP 方法 |
| `http-enum` | 80/443 | 目录枚举 |
| `http-waf-detect` | 80/443 | WAF 检测 |
| `http-wordpress*` | 80/443 | Wordpress 扫描 |
| `ssh-auth-methods` | 22 | SSH 认证方式 |
| `ftp-anon` | 21 | FTP 匿名登录检测 |
| `mysql-empty-password` | 3306 | MySQL 空密码检测 |
| `smb-vuln-ms17-010` | 445 | 永恒之蓝检测 |
| `ssl-heartbleed` | 443 | 心脏出血检测 |
| `ssl-poodle` | 443 | Poodle 漏洞检测 |
| `dns-zone-transfer` | 53 | DNS 区域传输 |
| `smb-os-discovery` | 445 | SMB 系统发现 |
| `snmp-info` | 161 | SNMP 信息收集 |

## 六、防火墙/IDS 绕过

| 参数 | 说明 |
|------|------|
| `-f` | 分片扫描（将探测包分片） |
| `--mtu 24` | 指定分片 MTU（必须是 8 的倍数） |
| `-D RND:5` | 诱饵扫描（随机 5 个诱饵 IP） |
| `-D 10.0.0.1,10.0.0.2,ME` | 指定诱饵 IP |
| `-sI zombie_ip` | 空闲扫描（僵尸扫描，最隐蔽） |
| `-S 10.0.0.100` | 伪造源 IP |
| `-g 53` / `--source-port 53` | 伪造源端口 |
| `--spoof-mac 0` | 随机 MAC 地址 |
| `--spoof-mac Apple` | 指定厂商 MAC 前缀 |
| `--data-length 25` | 附加随机数据（改变包长度） |
| `--randomize-hosts` | 随机化目标顺序 |
| `--scanflags SYN,FIN,URG` | 自定义 TCP Flag |
| `--scan-delay 2s` | 发送延迟 |
| `--max-rate 10` | 最大速率（包/秒） |
| `-T0` ~ `-T5` | 时序模板（T0 最慢，T5 最快） |

**常用绕过组合：**
```bash
# 分片 + 慢速 + 随机数据
nmap -sS -f -T2 --data-length 50 192.168.1.1

# 诱饵 + 源端口欺骗
nmap -sS -D RND:5 -g 53 -T3 192.168.1.1

# 最隐蔽组合（慢速 + 分片 + 诱饵 + 源端口）
nmap -sS -f -D RND:5 -g 53 --scan-delay 1s -T2 --data-length 25 192.168.1.1
```

## 七、输出格式

| 参数 | 格式 | 说明 |
|------|------|------|
| `-oN file` | Normal | 普通文本格式 |
| `-oX file` | XML | XML 格式（程序解析用） |
| `-oG file` | Grepable | Grep 友好格式（一行一条） |
| `-oA prefix` | All | 同时输出三种格式 |
| `-v` / `-vv` | - | 详细输出 |
| `-d` / `-dd` | - | 调试输出 |

**常用输出处理：**
```bash
# 提取开放 22 端口的主机
grep "22/open" scan.gnmap | awk '{print $2}'

# 提取所有开放端口统计
grep -oP '\d+/open' scan.gnmap | sort -t/ -n | uniq -c | sort -rn

# 提取 Web 服务主机
grep "80/open\|443/open" scan.gnmap | awk '{print $2}'
```

## 九、常用扫描组合速查

### 9.1 信息收集阶段

```bash
# 1. 存活主机发现（最快）
nmap -sn -PR -n 192.168.1.0/24 -oA discovery

# 2. 快速端口扫描
nmap -sS -F -T4 -iL discovery.gnmap -oA quick_scan

# 3. 全端口扫描
nmap -sS -p- -T4 --min-rate 1000 192.168.1.1 -oA full_port
```

### 9.2 深度扫描阶段

```bash
# 1. 服务版本 + 脚本 + OS
nmap -sV -sC -O -p 22,80,443,3306 192.168.1.1 -oA deep_scan

# 2. 全面扫描（-A）
nmap -A -p- -T4 192.168.1.1 -oA full_scan

# 3. 漏洞扫描
nmap --script=vuln,auth,brute -sV -T4 192.168.1.1 -oA vuln_scan
```

### 9.3 隐蔽扫描阶段

```bash
# 1. 慢速 SYN + 分片
nmap -sS -f -T2 --scan-delay 5s -n -Pn -p 22,80,443 192.168.1.1

# 2. 空闲扫描（最隐蔽）
nmap -sI zombie_ip -Pn -n -p 1-1000 192.168.1.1

# 3. 诱饵 + 源端口
nmap -sS -D RND:10 -g 53 -T2 -n -Pn -p 22,80,443 192.168.1.1
```

## 十、命令速查卡片

```
基础扫描:
  nmap <目标>                    # 默认扫描
  nmap -sn <目标>                # 仅主机发现
  nmap -Pn <目标>                # 跳过主机发现
  nmap -p <端口> <目标>          # 指定端口
  nmap -p- <目标>                # 全端口
  nmap -F <目标>                 # 快速扫描（100端口）

信息收集:
  nmap -sV <目标>                # 服务版本
  nmap -O <目标>                 # 操作系统
  nmap -A <目标>                 # 全面扫描
  nmap -sC <目标>                # 默认脚本

脚本扫描:
  nmap --script=vuln <目标>      # 漏洞扫描
  nmap --script=brute <目标>     # 暴力破解
  nmap --script=<脚本名> <目标>  # 指定脚本

绕过技术:
  nmap -f <目标>                 # 分片
  nmap -D RND:5 <目标>           # 诱饵
  nmap -sI <僵尸IP> <目标>       # 空闲扫描
  nmap -g 53 <目标>              # 源端口欺骗
  nmap -T2 <目标>                # 慢速

输出:
  nmap -oN/-oX/-oG <文件> <目标> # 输出格式
  nmap -oA <前缀> <目标>         # 全部格式
```
