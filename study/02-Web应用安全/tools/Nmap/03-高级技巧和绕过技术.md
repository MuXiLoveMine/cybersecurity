# Nmap 高级技巧和绕过技术

> 本文整理了 Nmap 的高级使用技巧和各种防火墙/IDS 绕过技术，适合在有防护设备的环境中进行渗透测试。

---

## 一、高级扫描技术

### 1.1 空闲扫描（Idle Scan / Zombie Scan）

空闲扫描是 Nmap 中最隐蔽的扫描方式，扫描过程中不会从攻击机 IP 发送任何数据包到目标。

**原理：**
1. 利用"僵尸主机"的 IP ID 序列来推断目标端口状态
2. 攻击机伪造源 IP 为僵尸主机，向目标发送 SYN 包
3. 目标回复 SYN/ACK 或 RST 给僵尸主机
4. 僵尸主机的 IP ID 会因此递增
5. 攻击机探测僵尸主机的 IP ID 变化来判断目标端口状态

**操作步骤：**

```bash
# 第一步：寻找合适的僵尸主机
# 条件：
#   1. IP ID 是递增的（Incremental）
#   2. 主机空闲，网络流量少
#   3. 攻击机能访问僵尸主机和目标

# 检测主机是否适合做僵尸
nmap -p 80 --script=ipidseq 192.168.1.50

# 可能的结果：
# - Incremental: 适合做僵尸
# - Random: 不适合
# - Zero: 不适合
# - Broken: 不适合

# 第二步：执行空闲扫描
# 格式：nmap -sI <僵尸IP>:<端口> <目标>
nmap -sI 192.168.1.50:80 -Pn -n -p 1-1000 192.168.1.100

# 常用选项：
nmap -sI zombie_ip -p- -Pn -n --scan-delay 1s target_ip
```

**寻找僵尸主机的方法：**
- 网络打印机（很多打印机 IP ID 递增且流量少）
- 网络设备（路由器、交换机）
- 一些老旧的嵌入式系统
- 某些 IoT 设备

### 1.2 自定义 TCP Flag 扫描

通过设置不同的 TCP Flag 组合来绕过防火墙检测。

```bash
# 查看所有可用 Flag
nmap -h | grep scanflags

# 自定义 Flag 组合
nmap -sS --scanflags SYN 192.168.1.1      # 同 -sS
nmap -sF --scanflags FIN 192.168.1.1      # 同 -sF
nmap -sX --scanflags FIN,PSH,URG 192.168.1.1  # 同 -sX

# 组合多个 Flag 绕过检测
nmap --scanflags SYN,FIN 192.168.1.1       # SYN+FIN
nmap --scanflags SYN,RST 192.168.1.1       # SYN+RST
nmap --scanflags PSH,URG 192.168.1.1       # PSH+URG
nmap --scanflags SYN,FIN,PSH,URG 192.168.1.1  # 多种组合

# 可用 Flag: URG, ACK, PSH, RST, SYN, FIN, ECE, CWR
```

### 1.3 协议扫描

```bash
# 探测目标支持哪些 IP 协议
nmap -sO 192.168.1.1

# 常用协议号：
# 1 - ICMP
# 2 - IGMP
# 6 - TCP
# 17 - UDP
# 47 - GRE
# 50 - ESP
# 51 - AH
# 89 - OSPF
```

### 1.4 FTP Bounce 扫描

利用 FTP 服务器的 PORT 命令来间接扫描其他主机。

```bash
# FTP Bounce 扫描
nmap -b user:pass@ftp_server target_ip

# 匿名 FTP Bounce
nmap -b anonymous@ftp_server target_ip

# 说明：
# - 利用 FTP 服务器的 PORT 命令
# - 让 FTP 服务器去连接目标端口
# - 根据响应判断端口状态
# - 现在大多数 FTP 服务器已禁用此功能
```

## 二、防火墙绕过技术

### 2.1 分片绕过

将 TCP 包分割成多个小的 IP 分片，绕过某些简单的防火墙/IDS 规则。

```bash
# 基本分片
nmap -sS -f 192.168.1.1

# 指定 MTU（必须是 8 的倍数）
nmap -sS --mtu 16 192.168.1.1    # 最小分片
nmap -sS --mtu 24 192.168.1.1
nmap -sS --mtu 32 192.168.1.1
nmap -sS --mtu 48 192.168.1.1

# 分片 + 其他绕过组合
nmap -sS -f --data-length 50 -T2 192.168.1.1
```

**原理说明：**
- 某些防火墙只检查第一个分片的 TCP 头
- 将 TCP 头拆分到多个分片中可以绕过检测
- 现代防火墙通常会重组分片，效果有限

### 2.2 源地址欺骗

```bash
# 指定源 IP
nmap -sS -S 10.0.0.100 192.168.1.1

# 注意：
# - 需要攻击机能收到响应包（需要路由配置）
# - 否则无法收到响应，无法判断结果
# - 配合 -e 指定网卡接口
nmap -sS -S 10.0.0.100 -e eth0 192.168.1.1
```

### 2.3 源端口欺骗

利用防火墙对常用服务端口的白名单规则，使用这些端口作为源端口。

```bash
# 常用源端口：
nmap -sS -g 53 192.168.1.1       # DNS 端口
nmap -sS -g 80 192.168.1.1       # HTTP 端口
nmap -sS -g 443 192.168.1.1      # HTTPS 端口
nmap -sS -g 88 192.168.1.1       # Kerberos
nmap -sS -g 25 192.168.1.1       # SMTP
nmap -sS --source-port 123 192.168.1.1  # NTP

# 原理：
# 很多防火墙允许来自 53 端口的数据包通过（DNS 响应）
# 使用这些端口作为源端口可能绕过过滤规则
```

### 2.4 MAC 地址欺骗

```bash
# 随机 MAC 地址
nmap -sS --spoof-mac 0 192.168.1.1

# 指定 MAC 地址
nmap -sS --spoof-mac 00:11:22:33:44:55 192.168.1.1

# 指定厂商前缀
nmap -sS --spoof-mac Apple 192.168.1.1
nmap -sS --spoof-mac Dell 192.168.1.1
nmap -sS --spoof-mac Cisco 192.168.1.1
nmap -sS --spoof-mac Huawei 192.168.1.1

# 查看支持的厂商列表
nmap --spoof-mac help 2>&1 | head -20
```

### 2.5 数据长度混淆

```bash
# 附加随机数据，改变数据包长度
nmap -sS --data-length 25 192.168.1.1
nmap -sS --data-length 50 192.168.1.1
nmap -sS --data-length 100 192.168.1.1

# 原理：
# 某些 IDS 基于固定长度的 payload 进行特征匹配
# 改变包长度可以绕过这些规则
```

### 2.6 随机化目标顺序

```bash
# 随机化扫描目标顺序，避免规律性行为
nmap --randomize-hosts 192.168.1.0/24

# 组合使用
nmap -sS -p- --randomize-hosts --scan-delay 1s 192.168.1.0/24
```

## 三、IDS 规避策略

### 3.1 时序模板详解

| 模板 | 名称 | 扫描延迟 | 并行数 | 适用场景 |
|------|------|---------|--------|---------|
| `-T0` | Paranoid | 5分钟/包 | 1 | 极致隐蔽 |
| `-T1` | Sneaky | 15秒/包 | 1 | 高度隐蔽 |
| `-T2` | Polite | 400ms/包 | 1 | 低噪声 |
| `-T3` | Normal | 动态 | 动态 | 默认 |
| `-T4` | Aggressive | 动态 | 高 | 快速扫描 |
| `-T5` | Insane | 动态 | 极高 | 最快但可能漏报 |

```bash
# 实际使用建议：
# 内网扫描：-T4（快速且准确）
# 外网扫描：-T3（避免被封）
# 隐蔽扫描：-T1 或 -T2（慢速）
# 生产环境：-T2 或 -T3（安全第一）
```

### 3.2 精细速率控制

```bash
# 最小速率（包/秒）
nmap --min-rate 100 192.168.1.0/24
nmap --min-rate 500 192.168.1.0/24
nmap --min-rate 1000 192.168.1.0/24

# 最大速率（包/秒）
nmap --max-rate 10 192.168.1.1    # 每秒 10 个包
nmap --max-rate 50 192.168.1.1
nmap --max-rate 100 192.168.1.1

# 最小并行数
nmap --min-parallelism 50 192.168.1.0/24

# 最大并行数
nmap --max-parallelism 10 192.168.1.1

# 扫描延迟
nmap --scan-delay 1s 192.168.1.1   # 每个包间隔 1 秒
nmap --scan-delay 5s 192.168.1.1
nmap --scan-delay 30s 192.168.1.1

# 最大重试次数
nmap --max-retries 2 192.168.1.1    # 降低重试减少特征
nmap --max-retries 0 192.168.1.1    # 不重试（最隐蔽）

# 主机超时
nmap --host-timeout 5m 192.168.1.0/24
```

### 3.3 规避策略对比

| 技术 | 隐蔽性 | 速度 | 可靠性 | 复杂度 |
|------|--------|------|--------|--------|
| SYN 扫描 | 中 | 快 | 高 | 低 |
| 分片扫描 | 中高 | 中 | 中 | 低 |
| 诱饵扫描 | 高 | 中 | 高 | 中 |
| 空闲扫描 | 极高 | 慢 | 中 | 高 |
| 慢速扫描 | 高 | 极慢 | 高 | 低 |
| 源端口欺骗 | 中 | 快 | 中 | 低 |
| Flag 组合 | 中 | 中 | 低 | 中 |
| 组合策略 | 极高 | 慢 | 中 | 高 |

## 四、NSE 高级用法

### 4.1 脚本并行执行

```bash
# 设置脚本线程数
nmap --script=http-brute --script-args userdb=users.txt,passdb=pass.txt \
     --script-args brute.threads=10 -p 80 192.168.1.1
```

### 4.2 脚本参数高级用法

```bash
# HTTP 认证脚本
nmap --script=http-brute \
     --script-args http-brute.path=/admin/login,http-brute.method=POST \
     -p 80 192.168.1.1

# 暴力破解脚本高级参数
nmap --script=ssh-brute \
     --script-args userdb=users.txt,passdb=passwords.txt,brute.threads=5,brute.delay=1 \
     -p 22 192.168.1.1

# 脚本超时设置
nmap --script=http-enum \
     --script-args http-enum.timeout=10 \
     -p 80 192.168.1.1
```

### 4.3 自定义脚本目录

```bash
# 使用自定义脚本目录
nmap --script ./my_scripts/ -p 80 192.168.1.1

# 更新脚本数据库（添加新脚本后）
nmap --script-updatedb
```

## 五、性能优化技巧

### 5.1 大规模扫描优化

```bash
# 大网段快速存活扫描
nmap -sn -n -PR -T4 --min-rate 5000 10.0.0.0/8

# 分阶段扫描
# 阶段1：快速存活发现
nmap -sn -n -T4 192.168.0.0/16 -oG alive.gnmap
grep "Status: Up" alive.gnmap | awk '{print $2}' > alive.txt

# 阶段2：端口扫描（只扫存活主机）
nmap -sS -F -T4 -iL alive.txt -oG ports.gnmap

# 阶段3：服务识别（只扫开放端口）
# 提取开放端口的主机再深入扫描
```

### 5.2 加速 filtered 端口判定

```bash
# --defeat-rst-ratelimit
# 绕过某些系统的 RST 速率限制
nmap -sS -p- --defeat-rst-ratelimit -T4 192.168.1.1

# 原理：
# 某些系统对 RST 包有限速
# 这会导致 filtered 端口判断变慢
# 使用此选项可以加速判定
```

### 5.3 UDP 扫描优化

```bash
# UDP 扫描通常很慢，优化策略：

# 1. 只扫描常用 UDP 端口
nmap -sU --top-ports 50 -T4 192.168.1.1

# 2. 常用 UDP 端口
nmap -sU -p 53,67,69,111,123,137,138,161,162,500,1900,5353 192.168.1.1

# 3. 加速 UDP 扫描
nmap -sU -T4 --min-rate 100 192.168.1.1

# 4. 配合版本探测
nmap -sU -sV --version-intensity 0 192.168.1.1
```

## 六、高级输出与自动化

### 6.1 自定义输出格式

```bash
# 使用 Nmap 的 --stylesheet 指定自定义 XSL 样式表
nmap -oX scan.xml --stylesheet custom.xsl 192.168.1.1

# 生成 HTML 报告
# 使用 xsltproc 将 XML 转为 HTML
xsltproc scan.xml -o scan_report.html
```

### 6.2 Nmap 与其他工具联动

```bash
# 与 Metasploit 联动
msfconsole -q -x "db_import scan.xml; hosts; services; exit"

# 与 Nessus 联动
# 导入 Nmap 结果到 Nessus 进行漏洞扫描

# 与 Hydra 联动（暴力破解）
# 先用 Nmap 发现开放服务，再用 Hydra 爆破
nmap -sV -p 22 -oG ssh.gnmap 192.168.1.0/24
grep "22/open" ssh.gnmap | awk '{print $2}' > ssh_targets.txt
hydra -L users.txt -P pass.txt -M ssh_targets.txt ssh
```

### 6.3 批量扫描脚本示例

```bash
#!/bin/bash
# 批量扫描脚本示例

NETWORKS=("192.168.1.0/24" "192.168.2.0/24" "10.0.0.0/24")
OUTPUT_DIR="./scan_results"
mkdir -p $OUTPUT_DIR

for net in "${NETWORKS[@]}"; do
    name=$(echo $net | tr '/' '_')
    echo "Scanning $net ..."
    
    # 存活发现
    nmap -sn -PR -n -T4 $net -oG $OUTPUT_DIR/${name}_discovery.gnmap
    
    # 提取存活 IP
    grep "Status: Up" $OUTPUT_DIR/${name}_discovery.gnmap | \
        awk '{print $2}' > $OUTPUT_DIR/${name}_alive.txt
    
    # 端口扫描
    if [ -s $OUTPUT_DIR/${name}_alive.txt ]; then
        nmap -sS -F -T4 -iL $OUTPUT_DIR/${name}_alive.txt \
             -oA $OUTPUT_DIR/${name}_ports
    fi
    
    echo "Done: $net"
done
```

## 七、绕过技术组合拳

### 7.1 针对基础防火墙

```bash
# 分片 + 源端口欺骗 + 慢速
nmap -sS -f -g 53 -T2 --scan-delay 2s \
     -n -Pn -p 22,80,443 192.168.1.1
```

### 7.2 针对 IDS/IPS

```bash
# 诱饵 + 分片 + 随机数据 + 慢速
nmap -sS -f -D RND:5 --data-length 25 \
     -T2 --scan-delay 1s \
     -n -Pn --randomize-hosts \
     -p 22,80,443,3306 192.168.1.0/24
```

### 7.3 深度隐蔽扫描

```bash
# 空闲扫描 + 慢速 + 分片（如果支持）
nmap -sI zombie_ip -f -T2 -Pn -n \
     -p 1-1000 192.168.1.1

# 或者分段慢速扫描
nmap -sS -f -T1 --scan-delay 30s \
     --max-retries 0 \
     -n -Pn -p 22,80,443 192.168.1.1
```

## 八、反检测技术

### 8.1 指纹修改

```bash
# 修改 User-Agent（HTTP 相关脚本）
nmap --script http-title --script-args http.useragent="Mozilla/5.0 ..." -p 80 target.com

# 随机 User-Agent
# 配合 --random-agent 参数（部分脚本支持）
```

### 8.2 扫描特征规避

```bash
# 避免连续端口扫描（跳跃式扫描）
nmap -sS -p 1,10,25,53,80,110,143,443,3306,8080 -T2 target.com

# 使用 --top-ports 代替连续端口
nmap -sS --top-ports 100 target.com
```

### 8.3 DNS 反检测

```bash
# 使用 -n 不做 DNS 解析，避免 DNS 查询特征
nmap -sn -n 192.168.1.0/24

# 使用自定义 DNS 服务器
nmap --dns-servers 8.8.8.8,1.1.1.1 192.168.1.1
```
