## 二、Proxy 模块速查

### 2.1 Intercept 面板操作

| 操作 | 说明 |
|------|------|
| `Intercept is on/off` | 开启/关闭请求拦截 |
| `Forward` | 放行当前请求（或响应） |
| `Drop` | 丢弃当前请求/响应 |
| `Action` | 操作菜单（发送到其他模块等） |
| `Raw` 视图 | 原始 HTTP 数据 |
| `Headers` 视图 | 结构化 Headers 显示 |
| `Hex` 视图 | 十六进制数据 |
| `Params` 视图 | 参数列表视图 |

### 2.2 常用操作流程

```
1. 开启 Intercept (Intercept is on)
2. 浏览器发送请求
3. Burp 拦截请求
4. 修改请求内容
5. 点击 Forward 放行
6. （可选）拦截响应并修改
7. 点击 Forward 放行响应
```

### 2.3 代理设置速查

| 设置项 | 路径 | 说明 |
|--------|------|------|
| 监听端口 | Proxy settings → Proxy Listeners | 默认 127.0.0.1:8080 |
| SSL Pass Through | Proxy settings → TLS Pass Through | 跳过指定 HTTPS 站点拦截 |
| Match and Replace | Proxy settings → Match and Replace | 自动替换请求/响应内容 |
| Response Modification | Proxy settings → Response Modification | 自动修改响应 |

### 3.3 Inspector 面板

Inspector 面板位于 Repeater 底部，提供结构化编辑：

```
Request 部分：
  ├── Request Attributes  (方法、URL、协议版本)
  ├── Request Query Parameters (查询参数)
  ├── Request Body Parameters (请求体参数)
  ├── Request Headers     (请求头)
  └── Request Cookies     (Cookie)

Response 部分：
  ├── Response Attributes (状态码、协议)
  ├── Response Headers    (响应头)
  ├── Response Cookies    (Set-Cookie)
  └── Response Body       (响应体)
```

## 四、Intruder 模块速查

### 4.1 攻击类型对比

| 类型 | Payload 集 | 位置数 | 说明 | 适用场景 |
|------|-----------|--------|------|---------|
| **Sniper** | 1 个 | 多个 | 逐个替换每个位置 | 单个参数爆破 |
| **Battering ram** | 1 个 | 多个 | 同时替换所有位置 | 多个相同参数值 |
| **Pitchfork** | 多个 | 多个 | 一一对应替换 | 用户名+密码配对 |
| **Cluster bomb** | 多个 | 多个 | 笛卡尔积组合 | 用户名+密码全组合 |

**数量关系：**
- Sniper: payload数 × 位置数 = 请求数
- Battering ram: payload数 = 请求数
- Pitchfork: min(payload集行数) = 请求数
- Cluster bomb: payload1数 × payload2数 × ... = 请求数

### 4.2 使用步骤

```
1. 发送请求到 Intruder (Ctrl+I)
2. Positions 标签：
   ├── 点击 "Clear §" 清除所有标记
   └── 选中参数值，点击 "Add §" 标记
3. Payloads 标签：
   ├── 选择 Payload type
   ├── 加载/输入 Payload 列表
   └── （可选）添加 Payload Processing 规则
4. Options 标签：
   ├── 设置线程数
   ├── 设置超时/重试
   ├── （可选）配置 Grep-Match / Grep-Extract
   └── （可选）配置重定向处理
5. 点击 "Start attack" 开始攻击
6. 结果窗口：
   ├── 按 Status/Length/Time 排序
   ├── 找出异常值
   └── 保存结果
```

### 4.3 Payload 类型速查

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| Simple list | 简单列表 | 字典文件、手动输入 |
| Runtime file | 运行时文件 | 大字典文件 |
| Numbers | 数字序列 | 验证码、ID 遍历 |
| Brute forcer | 暴力字符组合 | 短字符串爆破 |
| Character substitution | 字符替换 | 密码变形 |
| Recursive grep | 递归抓取 | 需要从响应提取 |
| Username generator | 用户名生成 | 用户名枚举 |
| Illegal Unicode | 非法 Unicode | 绕过检测 |
| Null payloads | 空 payload | 并发测试、重放 |
| Custom iterator | 自定义迭代器 | 多字段组合 |

### 4.4 Payload Processing 常用规则

| 规则 | 说明 |
|------|------|
| Add prefix / Add suffix | 添加前缀/后缀 |
| Match / replace | 正则匹配替换 |
| Encode / Decode | 编码解码（URL/Base64/HTML等） |
| Hash | 哈希计算（MD5/SHA等） |
| Skip if regex matches | 条件跳过 |
| Invoke Burp extension | 调用扩展处理 |
| Case modification | 大小写转换 |

### 4.5 结果判断要点

```
判断依据：
  ├── Status（状态码）：200 vs 302 vs 403 等
  ├── Length（响应长度）：长度不同通常意味着结果不同
  ├── Time（响应时间）：时间盲注、延迟判断
  └── Grep-Match：匹配特定关键词

快速找异常：
  ├── 点击列标题排序
  ├── 找出长度/状态/时间异常的行
  └── 双击查看完整请求响应
```

## 六、Scanner 模块速查（专业版）

### 6.1 扫描类型

| 类型 | 说明 | 特点 |
|------|------|------|
| Passive Scan | 被动扫描 | 分析已有流量，不发额外请求 |
| Active Scan | 主动扫描 | 发送 payload 探测漏洞 |

### 6.2 扫描方式

```
1. 全站扫描：
   Target → 站点地图 → 右键 → Scan

2. 单 URL 扫描：
   Dashboard → New scan → 输入 URL

3. 选中请求扫描：
   右键请求 → Do an active scan
```

### 6.3 扫描配置

| 配置项 | 选项 | 说明 |
|--------|------|------|
| Crawl strategy | Simple / Normal / Comprehensive | 爬取深度 |
| Audit strategy | Light / Normal / Deep | 审计强度 |
| Scan speed | Fast / Normal / Throttled | 扫描速度 |
| Audit checks | 可勾选具体漏洞类型 | 检查项配置 |

### 6.4 漏洞严重等级

| 等级 | 说明 |
|------|------|
| High | 高危，可直接获取权限或数据 |
| Medium | 中危，需要进一步利用 |
| Low | 低危，信息泄露等 |
| Information | 信息，提示性内容 |

## 七、Target 模块速查

### 7.1 站点地图（Site map）

```
功能：
  ├── 显示所有访问过的 URL 结构
  ├── 按域名/目录层级组织
  ├── 显示每个页面的请求响应
  └── 可右键发送到其他模块

常用操作：
  ├── 右键 → Send to Repeater/Intruder/Scanner
  ├── 右键 → Do an active scan
  ├── 右键 → Add to scope
  └── Filer：过滤显示内容
```

### 7.2 Scope 设置

```
设置目标范围：
  Target → Scope settings
  ├── Include in scope（包含范围）
  └── Exclude from scope（排除范围）

作用：
  ├── 只拦截范围内的请求
  ├── 只对范围内 URL 进行扫描
  └── 过滤站点地图显示
```

## 九、常用操作流程速查

### 9.1 SQL 注入测试流程

```
1. 拦截包含参数的请求
2. 发送到 Repeater (Ctrl+R)
3. 在参数后加单引号 '
4. 发送请求，观察响应变化
5. 判断注入类型（报错/盲注/联合）
6. 构造 Payload 进一步测试
7. （可选）发送到 Intruder 自动化
8. （可选）使用 SQLiPy 插件调用 sqlmap
```

### 9.2 XSS 测试流程

```
1. 找到输入点（参数/表单/URL）
2. 发送到 Repeater
3. 注入测试 Payload：<script>alert(1)</script>
4. 查看响应中是否原样输出
5. 测试各种绕过（编码、过滤）
6. 检查 CSP 等防护机制
7. 构造可利用的 Payload
```

### 9.3 越权测试流程

```
1. 使用低权限账号（普通用户）浏览功能
2. 记录所有 API 请求
3. 发送到 Repeater
4. 替换 Cookie/Token 为高权限账号
5. 观察是否返回高权限数据
6. 或者使用 Autorize 插件自动化测试
```

### 9.4 密码爆破流程

```
1. 拦截登录请求
2. 发送到 Intruder (Ctrl+I)
3. Positions：标记 password 参数
4. Attack type：Sniper
5. Payloads：加载密码字典
6. Options：设置线程数
7. Start attack
8. 按 Length/Status 排序找异常
```

## 十、实用技巧卡片

### 10.1 提高效率

```
1. 设置 Scope：只关注目标范围
2. 使用过滤：HTTP history 中快速筛选
3. 注释标记：重要请求加注释和颜色
4. 保存项目：保存项目文件 (.burp)
5. 搜索功能：全站搜索请求/响应内容
6. 消息编辑器：支持多选、列选择等
```

### 10.2 常用 Match & Replace 规则

```
1. 修改 User-Agent
2. 添加/删除 Cookie
3. 修改 Referer
4. 替换响应内容（调试用）
5. 添加测试 Header
```

### 10.3 响应修改常用选项

```
☑ Unhide hidden form fields      显示隐藏表单字段
☑ Enable disabled form fields    启用禁用的表单字段
☑ Remove JavaScript validation   移除 JS 验证
☑ Remove all JavaScript          移除所有 JS
☑ Remove object tags             移除 object 标签
```
