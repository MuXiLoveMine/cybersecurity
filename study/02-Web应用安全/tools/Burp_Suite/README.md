## 快速开始

```
1. 配置代理：127.0.0.1:8080
2. 安装 CA 证书（访问 http://burp）
3. 开启 Intercept 拦截请求
4. 浏览器访问目标网站
5. 将请求发送到 Repeater/Intruder 进行测试
```

更多内容请查看各分文档。
