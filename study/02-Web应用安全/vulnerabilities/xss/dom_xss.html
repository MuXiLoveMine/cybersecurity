DOM 型 XSS 示例

请在 URL 中添加 # 后面的内容：

dom_xss.html#<img src=x onerror=alert(1)>

1. innerHTML 注入

2. document.write 注入

3. eval 执行 URL 参数

测试：在 URL 后加 ?exp=alert(1)

测试 Payload：

  • dom_xss.html#<img src=x onerror=alert(1)>
  • dom_xss.html#<svg onload=alert(1)>
  • dom_xss.html?exp=alert(document.cookie)

修复方法：

  • 使用 textContent 代替 innerHTML
  • 避免使用 eval、setTimeout(string)、setInterval(string)
  • 对插入 DOM 的内容进行转义
  • 使用安全的模板引擎（默认转义）
