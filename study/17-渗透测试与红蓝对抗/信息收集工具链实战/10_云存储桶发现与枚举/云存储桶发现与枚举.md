# 云存储桶发现与枚举

### 10.1 AWS S3存储桶发现

```bash
# 方法1: 基于域名猜测存储桶名称
# 常见命名模式: company-backup, company-assets, company-uploads等
# 工具: bucket_finder
python3 bucket_finder.py -k company_name

# 方法2: 使用AWS CLI检查存储桶权限
aws s3 ls s3://company-backup --no-sign-request
aws s3 ls s3://company-assets --no-sign-request

# 方法3: 扫描公开存储桶
# 使用Slurp工具
go install github.com/spstafford/slurp@latest
slurp -t company.com
slurp -k company
slurp -c amazonaws.com

# 方法4: 使用AWS S3 Scanner
python3 s3scanner.py -f domains.txt

# 存储桶权限检查脚本
#!/bin/bash
BUCKET=$1
echo "[*] 检查存储桶: $BUCKET"
aws s3 ls s3://$BUCKET --no-sign-request 2>/dev/null
if [ $? -eq 0 ]; then
    echo "[!] 存储桶可公开访问: $BUCKET"
    aws s3 ls s3://$BUCKET --recursive --no-sign-request 2>/dev/null
fi

# 枚举存储桶内容
aws s3 ls s3://company-backup --recursive --no-sign-request > bucket_contents.txt
```

### 10.2 其他云存储枚举

```bash
# Azure Blob Storage
# 格式: https://<account>.blob.core.windows.net/<container>
# 常见容器名: backup, public, images, files, data
curl -s https://company.blob.core.windows.net/public?restype=container&comp=list

# Google Cloud Storage
# 格式: https://storage.googleapis.com/<bucket>
curl -s https://storage.googleapis.com/company-backup
gsutil ls gs://company-backup

# 阿里云OSS
# 格式: https://<bucket>.oss-cn-<region>.aliyuncs.com
curl -s https://company.oss-cn-hangzhou.aliyuncs.com/?list-type=2

# 腾讯云COS
# 格式: https://<bucket>.cos.<region>.myqcloud.com
curl -s https://company-1250000000.cos.ap-guangzhou.myqcloud.com/
```
