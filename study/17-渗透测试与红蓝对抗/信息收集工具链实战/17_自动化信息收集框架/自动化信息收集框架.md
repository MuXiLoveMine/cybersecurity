# 自动化信息收集框架

### 16.1 Recon-ng

```bash
# Recon-ng - 全功能OSINT框架
# 安装
pip install recon-ng

# 初始化
recon-ng

# 查看模块
recon-ng > marketplace search

# 安装模块
recon-ng > marketplace install all

# 创建工作空间
recon-ng > workspaces create target_company

# 添加目标
recon-ng > db insert domains example.com

# 使用模块
recon-ng > modules search
recon-ng > modules load recon/domains-hosts/hackertarget
recon-ng > run

# 查看结果
recon-ng > show hosts

# 导出结果
recon-ng > marketplace install reporting/html
recon-ng > modules load reporting/html
recon-ng > set FILENAME report.html
recon-ng > set CREATOR analyst
recon-ng > run

# 常用模块链
# 1. 子域名发现
modules load recon/domains-hosts/hackertarget
modules load recon/domains-hosts/threatcrowd
modules load recon/domains-hosts/certificate_transparency
# 2. 端口扫描
modules load discovery/ports/tcp_scan
# 3. Web指纹
modules load recon/hosts/ports/ssl_scan
```

### 16.2 AutoRecon

```bash
# AutoRecon - 自动化端口扫描和服务枚举
# 安装
pip install autorecon

# 基本使用
autorecon 10.10.10.10

# 扫描多个目标
autorecon 10.10.10.10 10.10.10.20 10.10.10.30

# 从文件读取目标
autorecon -f targets.txt

# 指定输出目录
autorecon -o /path/to/results 10.10.10.10

# 自定义扫描速度
autorecon --slower 10.10.10.10
autorecon --faster 10.10.10.10

# 限制并发
autorecon --concurrency 10 10.10.10.10

# 自定义Nmap参数
autorecon --nmap-append "-A -sC" 10.10.10.10

# 只运行特定扫描
autorecon --only-scans-dir 10.10.10.10
autorecon --ports 80,443,22,8080 10.10.10.10

# 输出目录结构
# results/
# ├── 10.10.10.10/
# │   ├── exploit/
# │   ├── loot/
# │   ├── report/
# │   │   ├── _full_tcp_scan.txt
# │   │   ├── _quick_tcp_scan.txt
# │   │   └── manual_commands.txt
# │   └── scans/
# │       ├── _quick_nmap.txt
# │       ├── _full_nmap.txt
# │       ├── http_80_nmap.txt
# │       ├── http_80_gobuster.txt
# │       └── ssh_22_nmap.txt
```

### 16.3 综合自动化框架对比

```text
信息收集框架对比:

| 框架 | 类型 | 优势 | 适用场景 |
|------|------|------|----------|
| Recon-ng | OSINT | 模块化设计,类似Metasploit | 社工/OSINT收集 |
| AutoRecon | 主动扫描 | 快速全面,输出规范 | CTF/渗透测试 |
| Spiderfoot | 综合 | 自动化程度高,200+模块 | 企业级资产发现 |
| Maltego | 图形化 | 可视化关联分析 | 复杂关系挖掘 |
| OSINTFramework | Web | 集成300+工具链接 | 快速查找工具 |
| Amass | 子域名 | 全面准确,多种技术 | 子域名深度枚举 |
| ProjectDiscovery | 工具链 | subfinder+httpx+nuclei | 大规模资产扫描 |
```

### 16.4 SpiderFoot

```bash
# SpiderFoot - 自动化OSINT框架
# 安装(Docker)
docker run -p 8080:8080 spiderfoot/spiderfoot

# 命令行模式
docker run -it spiderfoot/spiderfoot -t example.com -o results.json -f

# 使用API
# 启动后访问 http://localhost:8080

# 常用扫描模块:
# - sfp_dnsbrute: DNS暴力破解
# - sfp_subdomains: 子域名发现
# - sfp_whois: Whois查询
# - sfp_shodan: Shodan查询
# - sfp_censys: Censys查询
# - sfp_hunter: 邮箱搜索
# - sfp_github: GitHub搜索
# - sfp_bing: Bing搜索
# - sfp_google: Google搜索

# 筛选模块
spiderfoot -t example.com -m sfp_dnsbrute,sfp_subdomains,sfp_whois
```
