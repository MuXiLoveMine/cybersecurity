# 目录爆破

### 6.1 ffuf

```bash
# ffuf - 快速Web Fuzzer
# 安装
go install github.com/ffuf/ffuf/v2@latest

# 目录爆破
ffuf -u https://example.com/FUZZ -w wordlist.txt

# 使用常用字典
ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/dirb/common.txt

# 扩展名爆破
ffuf -u https://example.com/FUZZ -w wordlist.txt -e .php,.html,.txt,.bak

# 过滤状态码
ffuf -u https://example.com/FUZZ -w wordlist.txt -fc 404

# 过滤响应大小
ffuf -u https://example.com/FUZZ -w wordlist.txt -fs 1234

# 并发控制
ffuf -u https://example.com/FUZZ -w wordlist.txt -t 50

# 递归爆破
ffuf -u https://example.com/FUZZ -w wordlist.txt -recursion -recursion-depth 2

# vHost爆破
ffuf -u https://example.com -H "Host: FUZZ.example.com" -w vhosts.txt -fs 1234

# POST参数Fuzzing
ffuf -u https://example.com/api -X POST -d "user=admin&password=FUZZ" -w passwords.txt

# 使用多个字典
ffuf -u https://example.com/FUZZ1/FUZZ2 -w wordlist1.txt:FUZZ1 -w wordlist2.txt:FUZZ2
```

### 6.2 dirsearch

```bash
# dirsearch - 目录扫描工具
# 安装
pip install dirsearch

# 基本使用
dirsearch -u https://example.com

# 指定扩展名
dirsearch -u https://example.com -e php,asp,jsp,html,txt

# 指定字典
dirsearch -u https://example.com -w /path/to/wordlist.txt

# 递归扫描
dirsearch -u https://example.com -r -R 3

# 过滤
dirsearch -u https://example.com --exclude-status 404,403

# 线程数
dirsearch -u https://example.com -t 50

# 代理
dirsearch -u https://example.com --proxy http://127.0.0.1:8080

# 输出
dirsearch -u https://example.com -o results.json
```
