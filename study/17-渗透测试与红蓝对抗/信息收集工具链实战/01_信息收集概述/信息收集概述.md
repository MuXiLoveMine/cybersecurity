# 信息收集概述

### 1.1 信息收集分类

```
信息收集类型:

被动侦察 (不直接接触目标):
  ├── Whois查询
  ├── DNS历史记录
  ├── 证书透明日志
  ├── 搜索引擎(Google Dorking)
  ├── Shodan/Censys
  ├── GitHub代码搜索
  ├── 社交媒体OSINT
  └── 网页存档(Wayback Machine)

主动侦察 (直接接触目标):
  ├── 端口扫描(Nmap/Masscan)
  ├── 子域名枚举
  ├── 目录/文件爆破
  ├── Web指纹识别
  ├── 服务版本探测
  └── 漏洞验证扫描
```

### 1.2 信息收集方法论

```
信息收集流程:

  1. 域名信息
     ├── Whois → 注册信息
     ├── 子域名 → 攻击面扩展
     └── DNS记录 → IP/邮件服务器

  2. IP信息
     ├── IP段 → 网络范围
     ├── 反向DNS → 关联域名
     └── Shodan → 开放服务

  3. Web信息
     ├── 技术栈识别
     ├── 目录结构发现
     └── 页面内容分析

  4. 人员信息
     ├── 邮箱收集
     ├── 员工信息
     └── 组织架构

  5. 整合分析
     ├── 攻击面映射
     ├── 优先级排序
     └── 后续利用方向
```
