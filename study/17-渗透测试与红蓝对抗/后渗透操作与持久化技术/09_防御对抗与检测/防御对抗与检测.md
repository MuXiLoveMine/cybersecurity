# 防御对抗与检测

### 9.1 常见防御机制

```
企业安全防御体系：

1. 终端检测与响应 (EDR)
   ├── 进程行为监控
   ├── API调用监控
   ├── 内存扫描
   ├── 文件系统监控
   └── 网络行为监控

2. 安全信息与事件管理 (SIEM)
   ├── 日志集中收集
   ├── 关联分析
   ├── 异常检测
   ├── UEBA (用户行为分析)
   └── 告警响应

3. 身份与访问管理 (IAM)
   ├── 多因素认证
   ├── 特权访问管理
   ├── 条件访问
   └── 零信任架构

4. 网络安全
   ├── 防火墙
   ├── 入侵检测/防御
   ├── 网络分段
   ├── 微隔离
   └── 流量分析

5. 数据安全
   ├── 数据加密
   ├── 数据防泄漏 (DLP)
   ├── 数据分类
   └── 权限管控
```

### 9.2 检测与对抗技术

```
后渗透操作检测点与对抗方法：

1. 进程注入检测
   检测:
     - CreateRemoteThread API监控
     - VirtualAllocEx + WriteProcessMemory序列
     - 进程内存中的MZ头
   对抗:
     - 使用APC注入代替RemoteThread
     - 使用Process Hollowing
     - 使用Reflective DLL Injection
     - 使用Thread Hijacking

2. 凭证提取检测
   检测:
     - LSASS进程访问监控
     - Mimikatz特征码
     - SAM文件访问
   对抗:
     - 使用合法凭证提取方式
     - 内存中操作不落盘
     - 修改工具特征码

3. 横向移动检测
   检测:
     - 异常认证事件
     - 远程执行监控
     - 服务创建事件
   对抗:
     - 使用合法协议和端口
     - 模拟正常用户行为
     - 避免高频操作

4. 持久化检测
   检测:
     - 注册表Run键监控
     - 服务变更监控
     - 计划任务审计
     - WMI事件订阅
   对抗:
     - 使用隐蔽持久化方法
     - COM劫持
     - WMI永久订阅
     - 减少修改痕迹

5. 数据外传检测
   检测:
     - 大数据量传输
     - 异常协议使用
     - 加密流量分析
     - DLP规则
   对抗:
     - 小数据量分段外传
     - 使用合法云服务
     - DNS隧道
     - 数据隐写
```

### 9.3 蓝队检测策略

```
蓝队后渗透检测策略：

1. 黄金镜像策略
   - 维护系统黄金镜像
   - 定期对比系统状态
   - 检测未授权变更

2. 蜜标策略
   - 部署蜜罐文件
   - 监控虚假账户
   - 追踪攻击者路径

3. 防御策略建议
   - 启用PowerShell日志 (脚本块日志)
   - 启用进程审计 (命令行记录)
   - 启用Sysmon监控
   - 配置LSASS保护
   - 启用Windows Defender ATP
   - 实施网络分段
   - 部署EDR解决方案
   - 配置SIEM关联规则

4. 关键监控规则
   - Event ID 4624/4625 (登录成功/失败)
   - Event ID 4688 (进程创建，含命令行)
   - Event ID 4672 (特权登录)
   - Event ID 4720 (用户创建)
   - Event ID 7045 (服务安装)
   - Sysmon Event ID 1 (进程创建)
   - Sysmon Event ID 3 (网络连接)
   - Sysmon Event ID 8 (远程线程创建)
   - Sysmon Event ID 10 (进程访问)
   - Sysmon Event ID 11 (文件创建)
   - Sysmon Event ID 12/13/14 (注册表操作)
   - Sysmon Event ID 22 (DNS查询)
```
