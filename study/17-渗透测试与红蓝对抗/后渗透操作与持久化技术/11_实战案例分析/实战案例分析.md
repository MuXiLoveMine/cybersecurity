# 实战案例分析

### 10.1 内网渗透实战流程

```
红队内网渗透标准流程：

阶段1: 外部突破
  ├── 钓鱼邮件投递
  ├── 漏洞利用获取Shell
  └── 建立初始Beacon

阶段2: 信息收集
  ├── 域信息收集 (nltest, net命令)
  ├── 网络拓扑发现
  ├── 活动目录枚举
  └── 关键目标识别

阶段3: 权限提升
  ├── 本地提权分析
  ├── 漏洞利用提权
  └── 获取SYSTEM权限

阶段4: 凭证收集
  ├── Mimikatz提取凭证
  ├── 密码文件搜索
  ├── 浏览器密码提取
  └── SSH密钥收集

阶段5: 横向移动
  ├── 利用凭证访问其他主机
  ├── Pass-the-Hash攻击
  ├── PsExec远程执行
  └── RDP横向移动

阶段6: 域控获取
  ├── Kerberoasting
  ├── DCSync攻击
  ├── ZeroLogon (CVE-2020-1472)
  └── Golden Ticket

阶段7: 持久化
  ├── 多点持久化部署
  ├── 隐蔽后门植入
  └── C2通道多样化

阶段8: 数据收集与外传
  ├── 敏感数据定位
  ├── 数据打包加密
  └── 数据外传

阶段9: 痕迹清理
  ├── 日志清理
  ├── 文件删除
  └── 持久化隐蔽

阶段10: 报告
  ├── 攻击路径记录
  ├── 影响评估
  └── 修复建议
```

### 10.2 典型攻击场景

```
场景1: 从Web应用到域控

1. 外部Web应用SQL注入
   → 获取数据库凭证
   → 获取应用服务器Shell

2. 内网信息收集
   → 发现域环境
   → 定位域控

3. 本地提权
   → 发现未修补漏洞
   → SYSTEM权限

4. 凭证收集
   → Mimikatz获取域用户凭证
   → 发现管理员会话

5. 横向移动
   → PsExec访问其他服务器
   → 发现开发环境

6. 获取域管凭证
   → 发现配置文件中域管密码
   → 或Kerberoasting破解

7. 攻击域控
   → DCSync获取所有哈希
   → Golden Ticket

8. 持久化
   → WMI事件订阅
   → 多台主机后门


场景2: 钓鱼到数据外传

1. 钓鱼邮件
   → Office宏执行
   → PowerShell下载器

2. 内存执行
   → 反射加载ShellCode
   → 无文件Beacon

3. 信息收集
   → 发现文件服务器
   → 发现数据库服务器

4. 凭证窃取
   → 浏览器密码
   → 配置文件密码

5. 横向移动
   → WinRM远程执行
   → 访问文件服务器

6. 数据收集
   → 发现敏感文档
   → 压缩打包

7. 数据外传
   → HTTPS外传
   → 或云存储外传

8. 持久化
   → 计划任务后门
   → 注册表后门
```

### 10.3 防御建议总结

```
后渗透防御重点：

1. 减少攻击面
   - 及时修补漏洞
   - 最小权限原则
   - 关闭不必要服务
   - 网络分段

2. 加强凭证管理
   - 密码策略强化
   - 特权账户管控
   - 定期更换密码
   - 禁止密码复用
   - 启用LAPS

3. 加强监控
   - 启用Sysmon
   - 配置EDR
   - SIEM关联分析
   - 异常行为告警

4. 快速响应
   - 应急响应流程
   - 取证能力建设
   - 自动化响应
   - 威胁情报集成

5. 安全意识
   - 安全培训
   - 钓鱼模拟
   - 报告机制
   - 红蓝对抗演练
```
