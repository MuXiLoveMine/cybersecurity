# 检测与防御

### 7.1 Meterpreter特征与检测

```
Meterpreter 内存特征:
├── 注入到合法进程（explorer.exe / svchost.exe）
├── 反射 DLL 加载（无文件落地）
├── 加密通信（TLV 协议）
├── 心跳连接模式（定期回连）
└── 特定 API 调用模式

检测方法:
├── 内存扫描（搜索 Meterpreter 签名）
├── 网络流量分析（检测 TLV 协议特征）
├── 行为分析（异常进程注入、网络外连）
├── 注册表监控（持久化特征）
└── 端点检测响应（EDR）告警
```

### 7.2 MSF通信加密分析

```
Meterpreter 通信特征:
├── 默认使用 TLV（Type-Length-Value）协议
├── 通信可配置为明文或加密
├── 默认监听端口 4444（可修改）
├── HTTP/S 传输模式模拟正常 Web 流量
└── 常见特征: 固定 User-Agent / 特定 Cookie 格式

检测策略:
├── 异常外连端口检测（非标准端口）
├── TLS 证书分析（自签名/异常 CN）
├── 流量频率分析（固定间隔心跳）
├── User-Agent 指纹匹配
└── JA3/JA3S TLS 指纹
```

### 7.3 蓝队检测规则

**Sigma规则示例（Meterpreter检测）**

```yaml
title: Metasploit Meterpreter Activity
status: experimental
description: Detects Meterpreter process injection patterns
logsource:
    product: windows
    category: process_creation
detection:
    selection_migrate:
        CommandLine|contains:
            - 'migrate'
            - 'stager'
    selection_reflective_dll:
        CommandLine|contains|all:
            - 'rundll32'
            - '.dll'
    condition: selection_migrate or selection_reflective_dll
level: high
tags:
    - attack.execution
    - attack.t1055
```
