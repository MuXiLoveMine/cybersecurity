# 学习建议

### 7.1 学习方法
- 以靶场为核心，理论与实践并行
- 从简单靶场到复杂靶场，循序渐进
- 复现 CVE 漏洞，理解漏洞原理和利用过程
- 关注安全社区新漏洞、新技术的披露
- 参加 CTF 竞赛积累实战经验

### 7.2 学习重点
- 信息收集是渗透测试最重要的一步，投入最多时间
- 内网渗透是渗透测试的核心竞争力
- 域环境攻击是红队必备技能
- 防御绕过是高级红队工程师的分水岭
- 蓝队检测能力是红蓝对抗的关键

### 7.3 常见误区
- 重利用轻信息收集：信息收集不充分导致遗漏攻击面
- 重 Web 轻内网：内网渗透能力不足限制职业发展
- 重工具轻原理：不理解原理遇到新场景无法应对
- 攻防不对立：优秀的安全工程师需要同时理解攻与防
- 忽视法律边界：未经授权的渗透测试是违法行为

### 7.4 职业发展
- 渗透测试工程师 → 高级渗透测试工程师 → 红队工程师 → 安全架构师
- 红蓝双修是安全行业的高级方向
- 建议同时学习蓝队技能，成为紫队人才
- 持有 OSCP/OSEP/OSED/CISP-PTE 等认证提升竞争力
- 红队工程师应深入理解 ATT&CK 框架和 TTPs

### 7.5 关注趋势
- 云环境渗透测试成为新热点
- 容器/Kubernetes 渗透需求增长
- AI 辅助攻击与防御工具兴起
- 零信任架构对红队提出了新挑战
- 供应链攻击成为红队重点研究方向
- 紫队自动化工具持续演进
