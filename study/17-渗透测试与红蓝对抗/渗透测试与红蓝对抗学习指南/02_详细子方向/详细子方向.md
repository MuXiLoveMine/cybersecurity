# 详细子方向

### 2.1 渗透测试基础

#### 2.1.1 渗透测试概述
**渗透测试概念**
- 渗透测试定义：授权的、系统的安全评估
- 渗透测试 vs 漏洞扫描
- 渗透测试分类：黑盒、白盒、灰盒
- 渗透测试分类：外部测试、内部测试、盲测、双盲测

**渗透测试标准**
- PTES（Penetration Testing Execution Standard）
- OWASP Testing Guide
- NIST SP 800-115
- 渗透测试行业规范与法律边界

#### 2.1.2 渗透测试流程
**PTES 七阶段模型**
1. 前交互阶段（Pre-engagement Interactions）
2. 信息收集阶段（Intelligence Gathering）
3. 威胁建模阶段（Threat Modeling）
4. 漏洞分析阶段（Vulnerability Analysis）
5. 漏洞利用阶段（Exploitation）
6. 后渗透阶段（Post Exploitation）
7. 报告阶段（Reporting）

**各阶段关键活动**
- 前交互：确定范围、授权书、规则约束、时间窗口
- 信息收集：被动信息收集、主动信息收集
- 威胁建模：攻击树、角色定义、攻击向量
- 漏洞分析：扫描、验证、分类
- 漏洞利用：漏洞验证、Payload定制、绕过防护
- 后渗透：权限提升、横向移动、数据获取、痕迹清理
- 报告：执行摘要、技术细节、修复建议

### 2.2 信息收集

#### 2.2.1 被动信息收集
**OSINT 概述**
- 开源情报（Open Source Intelligence）
- 信息收集目标：域名、IP、人员、技术栈、架构

**域名与子域名收集**
- DNS 枚举：dig、fierce、sublist3r、amass
- 证书透明日志：crt.sh、Censys
- 搜索引擎语法：Google Dork、Shodan、Fofa、ZoomEye
- 代码仓库泄露：GitHub、GitLab、Gitee 搜索
- 子域名爆破：字典优化、泛解析处理、递归爆破

**IP 与网络信息**
- IP 段发现：BGP 查询、ASN 查询
- 端口扫描：Nmasscan、RustScan、Nmap
- 服务指纹识别：Banner 抓取、Wappalyzer、httpx
- CDN 识别与真实 IP 获取
- WAF 识别：wafw00f

#### 2.2.2 主动信息收集
**主机发现与端口扫描**
- Nmap 主机发现技术（-sn、-PS、-PA、-PU）
- 端口扫描技术（全连接扫描、SYN 扫描、UDP 扫描）
- 服务版本探测（-sV）
- 操作系统指纹识别（-O）
- NSE 脚本引擎（脚本分类与使用）
- Masscan 大规模端口扫描

**Web 应用信息收集**
- 目录扫描：dirsearch、feroxbuster、gobuster
- 文件扫描：备份文件、配置文件、源码泄露
- 指纹识别：CMS 识别、框架识别、WAF 识别
- 技术栈分析：JavaScript 框架、后端语言、数据库类型
- API 接口发现：Swagger 文档、GraphQL 接口

#### 2.2.3 人员与社会工程学信息
**人员信息收集**
- LinkedIn / 脉脉员工信息
- 组织架构推断
- 邮箱格式发现：theHarvester、Hunter.io
- 社交媒体信息
- 公开资料泄露检查：HIBP、Dehashed

### 2.3 漏洞利用

#### 2.3.1 Web 漏洞利用
**OWASP Top 10 深入利用**
- SQL 注入：sqlmap 自动化、手工注入、WAF 绕过
- XSS：存储型 XSS 利用、CSP 绕过、XSS 平台使用
- SSRF：内网探测、Redis 利用、云元数据获取
- SSTI：模板引擎注入利用
- 文件上传：绕过技巧汇总
- 反序列化：PHP/Java/Python 反序列化利用链
- 命令注入：各种注入场景与绕过
- XXE：外部实体注入、参数实体注入、无回显利用

#### 2.3.2 网络服务漏洞利用
**常见服务漏洞**
- SMB/NetBIOS：永恒之蓝（MS17-010）、SMBGhost
- RDP：BlueKeep、RDP 劫持
- SSH：弱密码爆破、密钥泄露利用
- 数据库服务：MySQL/MSQL/Oracle/Redis 未授权或弱密码
- 邮件服务：Exchange RCE、邮件协议枚举
- FTP/HTTP/TFTP/DNS 服务漏洞

#### 2.3.3 Metasploit 框架
**Metasploit 基础**
- 架构：模块（Exploit/Payload/Auxiliary/Post/Encoder）
- Payload 类型：Single/Staged/Stageless
- Meterpreter 高级 Payload
- 简介与模块搜索
- exploit/multi/handler 监听
- db_nmap 与工作区管理
- 后渗透模块（post/）
- 资源脚本（resource）与自动化

### 2.4 后渗透

#### 2.4.1 权限提升
**Windows 权限提升**
- 内核漏洞提权：MS16-032/MS16-135/MS17-017/CVE-2021-1675/CVE-2022-26923
- 服务配置错误：不安全的服务权限、服务路径未引用
- 注册表凭据：注册表存储的密码
- 自动化提权工具：WinPEAS、PrivescCheck、PowerUp
- UAC 绕过技术
- 令牌窃取与 impersonation

**Linux 权限提升**
- 内核漏洞提权：Dirty COW/Dirty Pipe/Dirty Pipe 等
- SUID 提权：SUID 二进制文件利用
- sudo 配置错误：sudo 权限滥用
- Cron 任务利用
- PATH 变量劫持
- 自动化提权工具：LinPEAS、LinEnum、linux-exploit-suggester

#### 2.4.2 横向移动
**Windows 域内横向移动**
- PSEXEC / WMI / WinRM / RDP
- Pass the Hash（PtH）
- Pass the Ticket（PtT）
- Overpass the Hash
- Kerberoasting
- AS-REP Roasting
- Golden Ticket / Silver Ticket
- DCSync 攻击
- 使用工具：Impacket 套件、CrackMapExec、BloodHound

**非域环境横向移动**
- SSH 密钥代理与转发利用
- 密码复用检查
- 内部服务漏洞利用
- 代理穿透与隧道

#### 2.4.3 持久化与痕迹清理
**Windows 持久化**
- 注册表自启动
- 计划任务
- 服务
- WMI 事件订阅
- DLL 劫持
- Logon Script

**Linux 持久化**
- Crontab
- Bash Profile / RC
- SSH 公钥
- PAM 后门
- Rootkit

**痕迹清理**
- Windows 日志清理
- Linux 日志清理
- Meterpreter 的 timestomp
- 日志搬运与告警规避

### 2.5 内网渗透

#### 2.5.1 内网信息收集
**Windows 内网信息收集**
- 域信息：域控制器、域用户、域管组
- 网络拓扑：ARP 表、路由表、网络连接
- 服务发现：端口扫描、服务枚举
- 凭据收集：注册表、LSASS、浏览器密码
- 使用工具：AdFind、BloodHound、PowerView、SharpHound

**Linux 内网信息收集**
- 网络信息：ifconfig、netstat、route
- 用户信息：/etc/passwd、/etc/shadow
- SSH 配置与密钥
- 历史命令：.bash_history
- 计划任务与定时任务

#### 2.5.2 代理与隧道
**代理技术**
- 正向代理
- 反向代理
- SOCKS 代理：proxychains + SSH 动态端口转发
- 内网穿透：frp、nps、chisel
- 端口转发：PortForward、rinetd
- DNS 隧道：dnscat2
- ICMP 隧道：icmpsh
- WebSocket 隧道

**多级代理场景**
- 多级 SOCKS 代理链
- proxychains-ng 配置多级代理
- 跳板机利用

### 2.6 红蓝对抗

#### 2.6.1 红蓝对抗概述
**红蓝对抗概念**
- 红蓝对抗 vs 渗透测试
- 红队：模拟攻击方
- 蓝队：防御检测方
- 紫队（Purple Team）：红蓝协作提升
- 对抗演练目标与范围

**红蓝对抗类型**
- 桌面推演
- 技术对抗
- 全场景实战对抗
- TTPs 驱动的对抗

#### 2.6.2 红队攻击链
**攻击链框架**
- Cyber Kill Chain（Lockheed Martin）
- MITRE ATT&CK 框架
- TTPs（Tactics, Techniques, Procedures）

**红队攻击流程**
1. 目标侦察与 OSINT
2. 初始 foothold 获取（钓鱼、外部漏洞利用、供应链攻击）
3. 持久化与立足
4. 内网渗透与横向移动
5. 目标达成与数据获取
6. 痕迹清理与撤离
7. 报告与复盘

**红队 TTPs**
- 初始访问：钓鱼邮件、水坑攻击、外部服务漏洞
- 执行：PowerShell、CMD、WMI、计划任务
- 持久化：注册表、服务、WMI 事件订阅
- 权限提升：内核漏洞、配置错误
- 防御绕过：AMSI 绕过、ETW 绕过、EDR 绕过、进程注入
- 凭据访问：LSASS dump、注册表凭据、Kerberoasting
- 发现：BloodHound、域信息枚举
- 横向移动：PtH/PtT/DCSync
- 收集与外传：数据压缩、分块传输、加密通道

#### 2.6.3 蓝队防御与检测
**蓝队能力体系**
- 日志采集：Windows 事件日志、Sysmon、Linux auditd
- SIEM/SOAR 平台：Splunk、ELK、QRadar
- EDR/XDR：端点检测与响应
- NDR/NTA：网络流量分析
- 威胁狩猎：基于 ATT&CK 的主动威胁狩猎
- 蜜罐与欺骗防御

**检测能力**
- 规则检测：Sigma 规则、YARA 规则
- 行为检测：异常进程树、异常网络连接
- 关联分析：多源日志关联、ATT&CK 映射
- UEBA：用户与实体行为分析

**响应能力**
- 遏制：隔离主机、阻断 IP、封禁账户
- 根除：清除后门、修复漏洞、重置凭据
- 恢复：系统重建、服务恢复
- 总结：攻击链还原、防御改进

#### 2.6.4 紫队与持续改进
**紫队概念**
- 紫队 = 红队 + 蓝队协作
- 攻击模拟与检测验证同步进行
- 每次攻击 TTP 同时验证检测覆盖

**紫队工作流**
1. 选取 ATT&CK 技术点
2. 红队执行模拟攻击
3. 蓝队实时验证检测
4. 评估检测覆盖率
5. 补齐检测缺口
6. 更新规则与配置

**自动化紫队工具**
- Atomic Red Team
- CALDERA
- VectorSphere
- Stratus Red Team
