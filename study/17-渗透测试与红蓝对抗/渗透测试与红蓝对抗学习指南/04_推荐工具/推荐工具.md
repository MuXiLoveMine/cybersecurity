# 推荐工具

### 4.1 信息收集工具
- Nmap / Masscan / RustScan：端口扫描
- Sublist3r / Amass / OneForAll：子域名收集
- Shodan / Fofa / ZoomEye：网络空间搜索
- theHarvester / Hunter.io：邮箱收集
- Wappalyzer / httpx：指纹识别
- wafw00f：WAF 识别
- dirsearch / feroxbuster / gobuster：目录扫描
- Gobuster / wfuzz：目录与文件爆破

### 4.2 漏洞利用工具
- Metasploit Framework：综合利用框架
- Burp Suite Professional：Web 渗透测试
- sqlmap：SQL 注入自动化
- Cobalt Strike：红队仿真平台
- Sliver / Mythic：开源 C2 框架
- Empire / Starkiller：PowerShell 后渗透
- Impacket 套件：内网协议利用

### 4.3 内网渗透工具
- BloodHound / SharpHound：域内关系分析
- CrackMapExec / NetExec：内网批量利用
- Mimikatz：凭据提取
- Rubeus：Kerberos 攻击套件
- PowerSploit / PowerView：PowerShell 渗透
- Proxifier / proxychains：代理工具
- frp / chisel / nps：内网穿透

### 4.4 后渗透工具
- Meterpreter：后渗透 Payload
- Cobalt Strike Beacon：C2 通信
- WinPEAS / LinPEAS：提权信息收集
- PowerUp / PrivescCheck：权限提升辅助
- Mimikatz / lsassy：凭据提取
- LaZagne：密码恢复

### 4.5 红蓝对抗工具
- Atomic Red Team：ATT&CK 技术模拟
- CALDERA：自动化对手仿真
- Sigma：日志检测规则
- Sysmon：系统监控
- Velociraptor / TheHive：事件响应平台
- Velociraptor / OpenEDR：EDR 工具
