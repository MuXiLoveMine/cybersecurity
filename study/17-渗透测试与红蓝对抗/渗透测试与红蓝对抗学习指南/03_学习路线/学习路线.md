# 学习路线

### 阶段 1：渗透测试基础（1-2 个月）
- 渗透测试概念与标准
- 网络协议基础
- Linux/Windows 系统基础
- 基本工具：Nmap、Burp Suite、Wireshark
- 基本漏洞类型与利用

### 阶段 2：Web 渗透测试（2-3 个月）
- OWASP Top 10 深入学习
- SQL 注入、XSS、SSRF 等漏洞利用
- Burp Suite 高级用法
- 目录扫描与信息收集
- Web 靶场实践

### 阶段 3：内网渗透（3-4 个月）
- Windows 域环境安全机制
- 内网信息收集
- 横向移动技术
- 权限提升
- 代理与隧道技术
- Impacket/BloodHound/CrackMapExec 使用
- 内网靶场实践

### 阶段 4：后渗透与高级利用（2-3 个月）
- 持久化技术
- 痕迹清理
- 绕过防御（AMSI/EDR）
- Metasploit 高级用法
- 社会工程学攻击模拟

### 阶段 5：红蓝对抗（持续）
- ATT&CK 框架深入
- 红队攻击链设计
- 蓝队检测规则编写
- 紫队协作演练
- 红蓝对抗靶场实战
- 持续关注新漏洞与新技术
