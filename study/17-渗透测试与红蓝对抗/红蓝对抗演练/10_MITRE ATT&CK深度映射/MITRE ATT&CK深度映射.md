# MITRE ATT&CK深度映射

### 10.1 ATT&CK Navigator使用

```
ATT&CK Navigator 使用流程:

1. 创建图层
   - 选择ATT&CK矩阵版本（Enterprise/Mobile/ICS）
   - 选择平台（Windows/Linux/macOS/Network）

2. 技术标注
   - 绿色: 已有检测覆盖
   - 黄色: 部分检测覆盖
   - 红色: 无检测覆盖
   - 灰色: 不适用

3. 层级分析
   - 基于战术分组查看覆盖率
   - 基于数据源查看检测能力
   - 导出覆盖热力图

4. 报告生成
   - 覆盖率统计（按战术/平台）
   - 检测缺口清单
   - 改进优先级排序
```
