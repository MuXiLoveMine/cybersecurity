# 紫队协作

### 5.1 紫队工作流

**紫队标准流程**
```
1. 计划阶段
   - 选择 ATT&CK 技术
   - 确定评估目标
   - 准备测试环境

2. 执行阶段
   - 红队执行攻击模拟
   - 蓝队实时监控检测
   - 记录检测结果

3. 评估阶段
   - 评估检测覆盖率
   - 识别检测缺口
   - 分析误报率

4. 改进阶段
   - 补充检测规则
   - 优化日志采集
   - 更新响应流程

5. 验证阶段
   - 重新执行攻击
   - 验证改进效果
   - 文档化结果
```

### 5.3 CALDERA

**CALDERA 自动化对手仿真**
```bash
# 启动 CALDERA
docker run -p 8888:8888 caldera

# 创建对抗计划
1. 选择 adversary profile
2. 选择 fact source
3. 配置 agents
4. 运行 operation
5. 实时监控蓝队检测情况
```
