# 红队攻击链

### 3.1 攻击链设计

#### 3.1.1 Cyber Kill Chain

**Lockheed Martin 七阶段模型**
```
1. 侦察 (Recon)
   - OSINT 信息收集
   - 目标画像
   - 攻击面发现

2. 武器化 (Weaponize)
   - Payload 开发
   - 漏洞利用集成
   - 投递方式选择

3. 投递 (Deliver)
   - 钓鱼邮件
   - 水坑攻击
   - 物理接触
   - 供应链攻击

4. 利用 (Exploit)
   - 漏洞触发
   - 执行 Payload
   - 获取 foothold

5. 安装 (Install)
   - 持久化后门
   - 植入 C2 通信

6. 命令与控制 (C2)
   - 建立通信信道
   - 隐蔽数据传输

7. 行动 (Actions)
   - 横向移动
   - 数据收集
   - 数据外传
```

#### 3.2.2 C2 隐蔽配置

**域名策略**
- 选择与目标行业相关的域名
- 域名年龄大于 1 年
- 分类为新闻/教育/金融等正常分类
- SSL 证书配置
- CDN 代理

**Malleable C2 配置**
```
# Cobalt Strike Malleable C2 示例
http-get {
    set uri "/api/v1/data";

    client {
        metadata {
            base64url
            prepend "session="
            header "Cookie"
        }
    }

    server {
        header "Content-Type" "application/json";
        output {
            base64url
            prepend "{\"data\":\""
            append "\"}"
        }
    }
}

http-post {
    set uri "/api/v1/report";
    set verb "POST";

    client {
        body {
            base64url
            prepend "report="
            append "&format=json"
        }
    }
}
```

**流量伪装策略**
- 使用合法域名作为 C2 域名
- 模拟正常 HTTP 流量特征
- 使用 HTTPS + 合法证书
- CDN 代理隐藏真实 IP
- 域前置（Domain Fronting）
- 多级 C2 信道

### 3.3 红队投递技术

#### 3.3.1 钓鱼邮件投递

**钓鱼邮件设计**
```
投递方案：
├── 载荷类型
│   ├── 宏文档（.doc/.xls）
│   ├── 可执行文件（.exe/.scr）
│   ├── 快捷方式（.lnk）
│   ├── 压缩包（.zip/.rar）
│   ├── ISO/IMG 镜像文件
│   └── HTML 文件（.html/.htm）
│
├── 投递技巧
│   ├── 发件人欺骗（相似域名）
│   ├── 主题定制（业务相关）
│   ├── 内容个性化（鱼叉定制）
│   ├── 绕过邮件网关（密码保护压缩包）
│   └── 多阶段投递（链接→下载→执行）
│
└── 执行链
    ├── 宏文档: 打开→启用宏→执行 ShellCode→连接 C2
    ├── ISO 文件: 挂载→执行→绕过 MOTW→连接 C2
    └── LNK 文件: 点击→执行 PowerShell→下载→执行
```

**初始 Payload 设计**

#### 3.3.2 水坑攻击

**水坑攻击流程**
1. 识别目标常访问的网站
2. 发现网站漏洞或第三方组件漏洞
3. 注入恶意 JavaScript
4. 访问者浏览器执行恶意代码
5. 利用浏览器漏洞或社工获取 foothold
