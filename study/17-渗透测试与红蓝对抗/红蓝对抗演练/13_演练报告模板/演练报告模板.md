# 演练报告模板

### 13.1 演练报告结构

```
红蓝对抗演练报告

一、演练概述
   1. 演练目的
   2. 演练范围与边界
   3. 演练时间
   4. 参与人员
   5. 演练规则

二、红队攻击报告
   1. 攻击链概述
   2. 各阶段攻击详情
      ├── 初始访问
      │   ├── 攻击技术
      │   ├── ATT&CK映射
      │   ├── 执行过程
      │   └── 结果与证据
      ├── 执行与持久化
      ├── 凭据访问
      ├── 横向移动
      └── 目标达成
   3. 攻击时间线
   4. 使用的工具和技术
   5. 攻击成功率

三、蓝队防御报告
   1. 检测情况概述
   2. 各阶段检测详情
      ├── 检测到的攻击
      ├── 未检测到的攻击
      └── 误报情况
   3. 响应情况
      ├── 响应动作
      ├── 响应时间
      └── 响应效果
   4. 威胁狩猎结果

四、ATT&CK覆盖矩阵
   1. 覆盖热力图
   2. 覆盖率统计
   3. 检测缺口分析

五、度量指标
   1. 红队指标
      ├── 攻击链完成度
      ├── 目标达成时间
      └── 被发现时间
   2. 蓝队指标
      ├── MTTD（平均检测时间）
      ├── MTTR（平均响应时间）
      ├── 检测覆盖率
      ├── 遏制时间
      └── 误报率
   3. 整体指标
      ├── 攻击链阻断率
      └── 安全成熟度评分

六、改进建议
   1. 检测改进（补充检测规则）
   2. 响应改进（优化响应流程）
   3. 架构改进（安全架构优化）
   4. 管理改进（流程与制度完善）

七、附录
   1. 完整ATT&CK映射表
   2. 检测规则清单
   3. 攻击证据截图
   4. 日志样本
```
