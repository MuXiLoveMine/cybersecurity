# 紫队评估方法

### 11.1 紫队评估流程

```
紫队评估标准流程:

1. 准备阶段（1-2天）
   ├── 选择评估目标（ATT&CK技术子集）
   ├── 确认数据源和日志覆盖
   ├── 准备攻击工具和payload
   └── 配置检测规则基线

2. 执行阶段（3-5天）
   ├── 红队执行攻击技术（逐项）
   ├── 蓝队实时监控检测
   ├── 记录每项技术的检测结果
   │   ├── 检测延迟（从执行到告警）
   │   ├── 告警准确度（是否正确识别）
   │   ├── 响应动作（是否自动/手动响应）
   │   └── 响应效果（是否有效阻断）
   └── 同步讨论和即时改进

3. 评估阶段（1-2天）
   ├── 汇总检测结果
   ├── 计算覆盖率指标
   ├── 识别检测缺口
   └── 生成改进优先级列表

4. 改进阶段（1-2周）
   ├── 补充检测规则
   ├── 优化日志采集
   ├── 建立自动化响应剧本
   └── 更新应急响应流程

5. 验证阶段（1-2天）
   ├── 重新执行攻击技术
   ├── 验证改进效果
   └── 更新覆盖矩阵
```

### 11.2 紫队评估指标体系

| 指标类别 | 具体指标 | 计算方式 |
|---------|---------|---------|
| 检测覆盖率 | ATT&CK技术检测比例 | 已检测技术数/测试技术总数 |
| 检测时效 | 平均检测时间(MTTD) | 所有检测到的攻击的平均延迟 |
| 响应时效 | 平均响应时间(MTTR) | 所有响应的平均时间 |
| 告警质量 | 精确率 | TP/(TP+FP) |
| 告警质量 | 召回率 | TP/(TP+FN) |
| 自动化率 | 自动响应比例 | 自动响应次数/总响应次数 |
| 阻断率 | 攻击阻断比例 | 被阻断攻击数/总攻击数 |
| 误报率 | 误报比例 | FP/(FP+TP) |
