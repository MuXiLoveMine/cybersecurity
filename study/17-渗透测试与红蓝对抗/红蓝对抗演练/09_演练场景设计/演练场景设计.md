# 演练场景设计

### 9.1 场景设计原则

| 原则 | 说明 |
|------|------|
| 真实性 | 基于真实威胁组织TTPs设计攻击链 |
| 全面性 | 覆盖完整攻击生命周期 |
| 针对性 | 针对组织特有业务和安全弱点 |
| 可控性 | 设置安全止损机制防止业务中断 |
| 可度量 | 每个阶段有明确的检测和响应度量标准 |

### 9.2 典型演练场景

**场景1：勒索软件模拟**
```
攻击链设计:
1. 鱼叉钓鱼 → 初始访问
2. PowerShell载荷执行 → 建立C2
3. Mimikatz凭据获取 → 横向移动
4. PsExec/WMI内网传播 → 多机感染
5. 域控攻击 → 全域沦陷
6. 文件加密模拟 → 影响

蓝队检测点:
- 邮件网关拦截钓鱼邮件
- EDR检测PowerShell恶意执行
- SIEM关联横向移动行为
- NDR发现异常内网连接
- 备份系统完整性验证
```

**场景2：数据外泄模拟**
```
攻击链设计:
1. Web应用漏洞利用 → 初始访问
2. 数据库注入 → 数据获取
3. C2隧道建立 → 数据传输通道
4. DNS隧道/HTTPS外传 → 数据外泄
5. 云存储桶上传 → 数据持久化

蓝队检测点:
- WAF拦截SQL注入
- 数据库审计异常查询告警
- NDR异常流量检测（DNS隧道）
- DLP数据泄露防护
- 云安全态势管理告警
```

**场景3：供应链攻击模拟**
```
攻击链设计:
1. 第三方供应商VPN接入 → 初始访问
2. 供应商凭据复用 → 内网渗透
3. CI/CD管道篡改 → 软件供应链投毒
4. 恶意更新推送 → 大规模感染

蓝队检测点:
- 零信任接入验证
- 供应商访问审计
- 代码仓库变更监控
- 软件签名验证
- SBOM对比异常检测
```
