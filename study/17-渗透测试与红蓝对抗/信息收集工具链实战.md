## 一、信息收集概述

### 1.1 信息收集分类

```
信息收集类型:

被动侦察 (不直接接触目标):
  ├── Whois查询
  ├── DNS历史记录
  ├── 证书透明日志
  ├── 搜索引擎(Google Dorking)
  ├── Shodan/Censys
  ├── GitHub代码搜索
  ├── 社交媒体OSINT
  └── 网页存档(Wayback Machine)

主动侦察 (直接接触目标):
  ├── 端口扫描(Nmap/Masscan)
  ├── 子域名枚举
  ├── 目录/文件爆破
  ├── Web指纹识别
  ├── 服务版本探测
  └── 漏洞验证扫描
```

### 1.2 信息收集方法论

```
信息收集流程:

  1. 域名信息
     ├── Whois → 注册信息
     ├── 子域名 → 攻击面扩展
     └── DNS记录 → IP/邮件服务器

  2. IP信息
     ├── IP段 → 网络范围
     ├── 反向DNS → 关联域名
     └── Shodan → 开放服务

  3. Web信息
     ├── 技术栈识别
     ├── 目录结构发现
     └── 页面内容分析

  4. 人员信息
     ├── 邮箱收集
     ├── 员工信息
     └── 组织架构

  5. 整合分析
     ├── 攻击面映射
     ├── 优先级排序
     └── 后续利用方向
```

## 二、被动侦察

### 2.1 Whois查询

```bash
# 基本Whois查询
whois example.com

# 使用在线API
curl -s "https://api.hackertarget.com/whois/?q=example.com"

# 查询IP的Whois
whois 93.184.216.34

# 查询DNS记录
dig example.com ANY
dig +short example.com A
dig +short example.com MX
dig +short example.com NS
dig +short example.com TXT
dig +short example.com CNAME

# 反向DNS
dig -x 93.184.216.34 +short

# DNS区域传输尝试(通常被拒绝)
dig axfr @ns1.example.com example.com

# 使用nslookup
nslookup example.com
nslookup -type=mx example.com
nslookup -type=txt example.com
```

### 2.2 Shodan搜索

```bash
# Shodan CLI安装
pip install shodan

# 设置API Key
shodan init YOUR_API_KEY

# 搜索特定IP
shodan host 93.184.216.34

# 搜索关键词
shodan search "apache"
shodan search "nginx" country:CN
shodan search "tomcat" port:8080
shodan search "redis" port:6379 -auth
shodan search "mongodb" port:27017

# 常用搜索语法
shodan search "http.title:\"Dashboard\""          # 页面标题
shodan search "http.component:\"wordpress\""      # 技术组件
shodan search "ssl.cert.subject.CN:example.com"  # SSL证书
shodan search "product:\"Apache httpd\""          # 产品名
shodan search "version:\"2.4.49\""                # 版本号
shodan search "hostname:example.com"              # 主机名

# 导出结果

shodan parse --fields ip_str,port,org results.json.gz
```

### 2.4 证书透明日志(crt.sh)

```bash
# 查询域名的SSL证书历史
# 这可以发现子域名(因为每个证书需要记录)

# Web查询
# https://crt.sh/?q=example.com

# API查询(JSON格式)
curl -s "https://crt.sh/?q=example.com&output=json" | \
    jq -r '.[].name_value' | \
    sort -u

# 提取所有子域名
curl -s "https://crt.sh/?q=%.example.com&output=json" | \
    jq -r '.[].name_value' | \
    sed 's/\*\.//g' | \
    sort -u | \
    grep -v " "

# 自动化脚本
#!/bin/bash
domain=$1
curl -s "https://crt.sh/?q=%.${domain}&output=json" | \
    jq -r '.[].name_value' | \
    sed 's/\*\.//g' | \
    sort -u
```

## 三、主动侦察

### 3.1 Nmap

```bash
# 基本扫描
nmap 192.168.1.0/24           # 扫描网段
nmap -sL 192.168.1.0/24       # 列表扫描(不做ping)
nmap -sn 192.168.1.0/24       # Ping扫描(发现存活主机)

# 端口扫描技术
nmap -sS 192.168.1.10         # SYN半开扫描(默认)
nmap -sT 192.168.1.10         # TCP全连接扫描
nmap -sU 192.168.1.10         # UDP扫描
nmap -sA 192.168.1.10         # ACK扫描(防火墙检测)
nmap -sF 192.168.1.10         # FIN扫描
nmap -sX 192.168.1.10         # Xmas扫描
nmap -sN 192.168.1.10         # Null扫描

# 端口范围
nmap -p 80 192.168.1.10       # 指定端口
nmap -p 1-1000 192.168.1.10   # 端口范围
nmap -p- 192.168.1.10         # 全端口
nmap --top-ports 100 192.168.1.10  # 最常见的100个端口
nmap -p 80,443,8080,8443 192.168.1.10  # 指定多个端口

# 服务版本探测
nmap -sV 192.168.1.10         # 版本探测
nmap -sV --version-intensity 5 192.168.1.10  # 高强度版本探测
nmap -sV --version-all 192.168.1.10          # 最高强度

# 操作系统探测
nmap -O 192.168.1.10          # OS检测
nmap -O --osscan-guess 192.168.1.10  # 猜测OS

# 综合扫描
nmap -A 192.168.1.10          # 全功能扫描(OS+版本+脚本+traceroute)
nmap -A -T4 192.168.1.10      # 快速全功能扫描

# NSE脚本
nmap --script vuln 192.168.1.10              # 漏洞检测脚本
nmap --script default 192.168.1.10           # 默认脚本
nmap --script "http-*" 192.168.1.10          # HTTP相关脚本
nmap --script "smb-*" 192.168.1.10           # SMB相关脚本
nmap --script "ssl-*" 192.168.1.10           # SSL相关脚本
nmap --script "nfs-*" 192.168.1.10           # NFS相关脚本

# 常用NSE脚本
nmap --script http-title 192.168.1.10 -p 80  # 获取HTTP标题
nmap --script http-headers 192.168.1.10 -p 80  # HTTP头
nmap --script http-enum 192.168.1.10 -p 80   # 目录枚举
nmap --script http-methods 192.168.1.10 -p 80 # HTTP方法
nmap --script ssl-cert 192.168.1.10 -p 443   # SSL证书
nmap --script smb-enum-shares 192.168.1.10   # SMB共享枚举
nmap --script smb-os-discovery 192.168.1.10   # SMB系统信息
nmap --script ssh-auth-methods 192.168.1.10 -p 22  # SSH认证方法
nmap --script dns-brute 192.168.1.10          # DNS子域爆破

# 时序和性能
nmap -T0 192.168.1.10   # 极慢(躲避IDS)
nmap -T1 192.168.1.10   # 很慢
nmap -T2 192.168.1.10   # 慢
nmap -T3 192.168.1.10   # 正常(默认)
nmap -T4 192.168.1.10   # 快
nmap -T5 192.168.1.10   # 极快(可能丢包)

# 防火墙绕过
nmap -f 192.168.1.10              # 分片数据包
nmap --mtu 16 192.168.1.10        # 自定义MTU
nmap -D RND:10 192.168.1.10       # 随机诱饵
nmap -D 10.0.0.1,10.0.0.2 192.168.1.10  # 指定诱饵
nmap --source-port 53 192.168.1.10  # 源端口欺骗
nmap --spoof-mac 0 192.168.1.10   # 随机MAC
nmap --data-length 30 192.168.1.10  # 附加随机数据

# 输出格式
nmap -oN scan.txt 192.168.1.10    # 正常输出
nmap -oX scan.xml 192.168.1.10    # XML输出
nmap -oG scan.gnmap 192.168.1.10  # Grepable输出
nmap -oA scan 192.168.1.10        # 所有格式

# 实用组合
nmap -sS -sV -O --top-ports 1000 -T4 -oA full_scan 192.168.1.0/24
```

### 3.2 Masscan

```bash
# Masscan - 极速端口扫描器
# 安装
apt install masscan

# 基本扫描(全端口)
masscan 192.168.1.0/24 -p1-65535 --rate=10000

# 常用端口
masscan 192.168.1.0/24 -p80,443,8080,8443,3306,5432 --rate=10000

# 高速扫描(需要足够带宽)
masscan 10.0.0.0/8 -p80 --rate=100000

# 输出格式
masscan 192.168.1.0/24 -p80 --rate=10000 -oJ results.json
masscan 192.168.1.0/24 -p80 --rate=10000 -oG results.grep

# 结合Nmap使用
# 1. Masscan快速发现开放端口
masscan 192.168.1.0/24 -p1-65535 --rate=10000 -oJ ports.json

# 2. Nmap深入扫描发现的端口
# 提取开放端口和IP
cat ports.json | jq -r '.[].ip + " " + (.[].ports[].port|tostring)' | \
    while read ip port; do
        nmap -sV -sC -p $port $ip
    done
```

### 4.2 Amass

```bash

# 安装
go install -v github.com/owasp-amass/amass/v4/...@master

# 被动枚举(不接触目标)
amass enum -passive -d example.com

# 主动枚举(包括区域传送等)
amass enum -active -d example.com

# 暴力枚举
amass enum -brute -d example.com

# 综合枚举
amass enum -d example.com -src

amass enum -d example.com -o subdomains.txt
amass enum -d example.com -json subdomains.json

# 可视化
amass viz -d3 -d example.com -o amass_d3.html

# IP范围发现
amass intel -d example.com -ip

# 配置(~/.config/amass/config.yaml)
# data_sources:
#   - virustotal
#   - crtsh
#   - securitytrails
```

## 八、信息收集自动化

```bash
#!/bin/bash
# 综合信息收集脚本

TARGET_DOMAIN=$1
OUTPUT_DIR="recon_${TARGET_DOMAIN}_$(date +%Y%m%d)"
mkdir -p "$OUTPUT_DIR"

echo "[*] 开始信息收集: $TARGET_DOMAIN"
echo "[*] 输出目录: $OUTPUT_DIR"

# 1. Whois信息
echo "[1/8] Whois查询..."
```

## 九、子域名接管检测

### 9.1 子域名接管原理

子域名接管（Subdomain Takeover）是指当子域名指向的外部服务已被删除，但DNS的CNAME记录未清理时，攻击者可以在该外部服务上注册自己的账户并接管该子域名。

```text
子域名接管风险等级:

  高危: 云服务CNAME失效 (AWS S3 / GitHub Pages / Heroku)
  中危: 自定义服务CNAME失效
  低危: A记录指向失效IP

常见可被接管的云服务:
  ├── AWS S3 Bucket        -> s3.amazonaws.com
  ├── GitHub Pages         -> github.io
  ├── Heroku               -> herokuapp.com
  ├── Azure                -> azurewebsites.net
  ├── Tumblr               -> tumblr.com
  ├── Shopify              -> myshopify.com
  ├── Tumblr              -> tumblr.com
  └── WordPress.com        -> wordpress.com
```

```python
#!/usr/bin/env python3
"""GitHub信息泄露自动化搜索工具"""

import requests
import re
import json
from datetime import datetime, timedelta

class GitHubDorker:
    def __init__(self, token):
        self.headers = {"Authorization": f"token {token}"}
        self.base_url = "https://api.github.com/search/code"

    def search_code(self, query, per_page=100):
        """搜索GitHub代码"""
        params = {"q": query, "per_page": per_page, "sort": "indexed"}
        response = requests.get(self.base_url, headers=self.headers, params=params)
        if response.status_code == 200:
            return response.json()
        return None

    def search_leaks(self, target_domain):
        """搜索目标域名相关的泄露"""
        dorks = [
            f'"{target_domain}" filename:.env',
            f'"{target_domain}" filename:config',
            f'"{target_domain}" filename:settings',
            f'"{target_domain}" filename:docker-compose',
            f'"{target_domain}" filename:.git-config',
            f'"{target_domain}" API_KEY',
            f'"{target_domain}" API_SECRET',
            f'"{target_domain}" password',
            f'"{target_domain}" AWS_SECRET_ACCESS_KEY',
            f'"{target_domain}" private_key',
            f'"{target_domain}" BEGIN RSA PRIVATE',
        ]
        results = []
        for dork in dorks:
            print(f"[*] 搜索: {dork}")
            data = self.search_code(dork)
            if data and data.get("total_count", 0) > 0:
                for item in data["items"]:
                    results.append({
                        "dork": dork,
                        "repository": item["repository"]["full_name"],
                        "file_path": item["path"],
                        "html_url": item["html_url"],
                    })
        return results

# 使用示例
if __name__ == "__main__":
    dorker = GitHubDorker("ghp_your_token_here")
    leaks = dorker.search_leaks("example.com")
    for leak in leaks:
        print(f"[!] 发现: {leak['repository']} - {leak['file_path']}")
        print(f"    URL: {leak['html_url']}")
```

```python
#!/usr/bin/env python3
"""综合人员信息收集工具"""

import requests
import json
from collections import defaultdict

class PeopleOSINT:
    def __init__(self):
        self.results = defaultdict(list)

    def linkedin_search(self, company_name):
        """LinkedIn公司员工搜索"""
        # 使用Google Dork搜索LinkedIn
        dorks = [
            f'site:linkedin.com/in "{company_name}"',
            f'site:linkedin.com/in "{company_name}" "engineer"',
            f'site:linkedin.com/in "{company_name}" "developer"',
            f'site:linkedin.com/in "{company_name}" "manager"',
            f'site:linkedin.com/in "{company_name}" "CTO"',
            f'site:linkedin.com/in "{company_name}" "security"',
        ]
        # 实际使用时需要配合搜索引擎API
        return dorks

    def email_pattern_detect(self, domain, known_emails):
        """检测邮箱命名模式"""
        patterns = []
        for email in known_emails:
            prefix = email.split("@")[0]
            # 分析模式
            if "." in prefix:
                patterns.append("first.last")
            if "_" in prefix:
                patterns.append("first_last")
            if len(prefix) == 1:
                patterns.append("first_initial")
            # ...更多模式分析
        return patterns

    def generate_emails(self, domain, names, pattern):
        """根据模式和姓名列表生成邮箱"""
        emails = []
        for name in names:
            parts = name.lower().split()
            first = parts[0] if parts else ""
            last = parts[-1] if len(parts) > 1 else ""
            if pattern == "first.last":
                emails.append(f"{first}.{last}@{domain}")
            elif pattern == "flast":
                emails.append(f"{first[0]}{last}@{domain}")
            elif pattern == "firstl":
                emails.append(f"{first}{last[0]}@{domain}")
            elif pattern == "first":
                emails.append(f"{first}@{domain}")
        return emails
```
