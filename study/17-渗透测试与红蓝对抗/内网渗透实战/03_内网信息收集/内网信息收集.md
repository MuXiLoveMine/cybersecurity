# 内网信息收集

### 3.1 域环境信息收集

#### 3.1.1 域基础信息

**PowerShell 命令**
```powershell
# 获取域信息
Get-NetDomain                    # 域信息
Get-NetDomainController          # 域控制器
Get-NetUser                      # 域用户列表
Get-NetGroup                     # 域组列表
Get-NetGroupMember -GroupName "Domain Admins"  # 域管组成员
Get-NetComputer                  # 域内机器
Get-NetOU                        # 组织单元
Get-NetGPO                       # 组策略
Get-ObjectAcl -SamAccountName "user1"  # ACL 信息
```

**AdFind 工具**
```bash
# 域信息
adfind -f objectcategory=domain

# 域管组
adfind -b "CN=Domain Admins,CN=Users,DC=domain,DC=com"

# 域控制器
adfind -f "(objectcategory=computer)(primarygroupid=516)"

# 所有用户
adfind -f objectcategory=person

# 计算机列表
adfind -f objectcategory=computer -dn
```

#### 3.1.2 BloodHound 域分析

**BloodHound 使用流程**
```
1. 信息收集
   - SharpHound.exe -c All
   - 或: python3 bloodhound.py -u user -p pass -d domain -ns DC_IP

2. 数据导入
   - 启动 BloodHound 界面
   - 导入 JSON 文件

3. 路径分析
   - 查询最短路径到达 Domain Admin
   - 查询 Kerberoastable 用户
   - 查询 DCSync 权限用户
   - 查询 AS-REP Roastable 用户

4. 自定义查询
   - Cypher 查询语言编写自定义分析
```

**常用 Cypher 查询**
```cypher
// 查找所有到达 Domain Admin 的最短路径
MATCH (n:User),(m:Group {name:"DOMAIN ADMINS@DOMAIN.COM"}),p=shortestPath((n)-[:MemberOf|HasSession|AdminTo|AllExtendedRights|GenericAll|GenericWrite|Owns|WriteDacl|WriteOwner|(Controls|AllowedToDelegate)*1..]->(m)) RETURN p

// 查找所有 Kerberoastable 用户
MATCH (n:User) WHERE n.kerberoastable=true RETURN n

// 查找所有可以 DCSync 的用户
MATCH (n:User)-[:GetChanges|GetChangesAll]->(m:Domain) RETURN n
```

### 3.2 主机信息收集

#### 3.2.1 Windows 主机信息收集

```powershell
# 系统信息
systeminfo
hostname
whoami /all
whoami /priv
whoami /groups

# 网络信息
ipconfig /all
route print
arp -a
netstat -ano
netsh interface portproxy show all

# 进程与服务
tasklist /svc
net start
sc query state= all
wmic process list full

# 用户与会话
net user
net localgroup
net localgroup administrators
query user
query session

# 共享
net share
net session
net use

# 计划任务
schtasks /query /fo LIST /v
```

#### 3.2.2 凭据收集

**凭据收集位置**
```
1. 内存中的凭据
   - Mimikatz: sekurlsa::logonpasswords
   - lsassy: 远程 LSASS dump

2. 注册表凭据
   - HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Winlogon
   - HKLM\SYSTEM\CurrentControlSet\Services\
   - 自动化: reg query 命令

3. 文件系统凭据
   - unattend.xml / sysprep.xml
   - web.config / app.config
   - SSH 密钥: C:\Users\*\.ssh\id_rsa
   - RDP 文件: C:\Users\*\Documents\Default.rdp
   - 浏览器密码: Chrome/Firefox/Edge

4. 凭据管理器
   - cmdkey /list
   - [System.Net.WebClient]::new()

5. Vault
   - Vault::list
   - Vault::cred

6. DPAPI
   - dpapi::masterkey
   - dpapi::cred
```

### 3.3 Linux 内网信息收集

```bash
# 系统信息
uname -a
cat /etc/os-release
cat /etc/issue
id
whoami
hostname

# 网络信息
ifconfig -a
ip addr
ip route
arp -a
netstat -tulpn
ss -tulpn

# 用户信息
cat /etc/passwd
cat /etc/shadow  # 需要 root
cat /etc/group
w
last

# 进程与服务
ps aux
ps -ef
systemctl list-units --type=service
chkconfig --list

# 文件与权限
find / -perm -4000 2>/dev/null    # SUID 文件
find / -perm -2000 2>/dev/null    # SGID 文件
cat /etc/crontab
ls -la /etc/cron.*
cat ~/.bash_history
cat ~/.ssh/id_rsa

# Docker 信息
docker ps
docker images
cat /etc/docker/daemon.json
```
