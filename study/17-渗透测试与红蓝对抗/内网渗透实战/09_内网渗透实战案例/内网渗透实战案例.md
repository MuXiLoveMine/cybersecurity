# 内网渗透实战案例

### 9.1 场景：从 Web Shell 到域管

```
1. 获取 Web Shell
   - 通过文件上传漏洞获取 Web Shell
   - 执行命令获取当前权限（IIS 用户 / www-data）

2. 权限提升
   - 运行 WinPEAS 发现内核漏洞
   - 利用 PrintNightmare 提权到 SYSTEM

3. 凭据收集
   - Mimikatz dump LSASS
   - 获取本地管理员凭据

4. 域信息收集
   - BloodHound 分析域内路径
   - 发现可 Kerberoast 的服务账户

5. 横向移动
   - Kerberoasting 获取服务账户密码
   - CrackMapExec 密码复用检查
   - 发现多台机器使用相同密码

6. 获取域管凭据
   - 通过 BloodHound 发现某服务账户有 DCSync 权限
   - 执行 DCSync 获取 krbtgt Hash

7. 生成黄金票据
   - 使用 krbtgt Hash 伪造域管 TGT
   - 通过 PtT 访问域控制器

8. 持久化
   - 在域控制器上部署黄金票据
   - WMI 事件订阅
   - 创建域管账户
```

### 9.2 场景：限制出网环境下的内网渗透

```
1. 初始 foothold（钓鱼邮件获取初始 Shell）
2. 内网信息收集（内网代理通过 Web Shell 执行）
3. 发现内网横向目标
4. 使用正向代理建立 SOCKS（SSH 动态端口转发）
5. 通过 proxychains 执行 Impacket 工具
6. 横向移动到域内机器
7. 域内信息收集与攻击
8. 通过 DNS 隧道外传数据
```
