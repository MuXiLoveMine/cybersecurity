# 物理渗透

### 13.1 物理渗透方法论

```
物理渗透测试流程：

1. 侦察阶段
   - 物理环境观察
   - 出入口分析
   - 安保措施评估
   - 员工行为模式

2. 进入策略
   - 尾随（Tailgating）
   - 伪造身份（工牌）
   - 快递/外卖伪装
   - 维修人员伪装

3. 设备部署
   - 无线接入设备（WiFi Pineapple）
   - 网络嗅探设备
   - 键盘记录器
   - 恶意 USB

4. 信息获取
   - 查看屏幕内容
   - 翻找敏感文档
   - 访问未锁屏终端
   - 拍摄敏感信息

5. 撤离
   - 清理痕迹
   - 恢复设备
   - 记录发现
```
