# 钓鱼/社工结合

### 12.1 钓鱼攻击方法论

```
钓鱼攻击流程：

1. 目标信息收集
   - 目标员工邮箱列表
   - 组织架构
   - 常用系统/应用
   - 内部文档格式

2. 钓鱼场景设计
   - IT 通知（密码到期、VPN 升级）
   - 人事通知（薪资调整、福利）
   - 安全通知（安全检查、漏洞修复）
   - 外部合作（供应商、合作伙伴）

3. 基础设施准备
   - 注册相似域名
   - 配置邮件服务器
   - 搭建钓鱼页面
   - SSL 证书

4. 投递与执行
   - 发送钓鱼邮件
   - 等待用户交互
   - 收集凭据/获取 Shell

5. 后渗透
   - 利用收集的凭据
   - VPN/远程接入内网
   - 横向移动

常用工具：
- Gophish：钓鱼模拟框架
- Evilginx2：中间人钓鱼框架
- SET（Social Engineering Toolkit）
- King Phisher
```
