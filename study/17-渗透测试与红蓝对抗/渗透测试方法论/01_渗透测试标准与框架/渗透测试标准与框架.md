# 渗透测试标准与框架

### 1.1 PTES（渗透测试执行标准）

PTES 是渗透测试领域最完整的标准框架，包含七个阶段：

#### 阶段一：前交互（Pre-engagement Interactions）
**核心活动**
- 确定测试目标：系统范围、网络范围、应用范围
- 确定测试类型：黑盒/白盒/灰盒
- 确定测试窗口：时间限制、频率限制
- 授权文件：书面授权书、测试范围确认书
- 法律边界：禁止行为清单、紧急联系人
- 交付物约定：报告格式、交付时间

**关键文档模板**
```
渗透测试授权书
├── 委托方信息
├── 测试范围（IP/域名/应用列表）
├── 测试类型（黑盒/白盒/灰盒）
├── 测试时间（起止时间）
├── 禁止行为（DoS攻击、数据修改等）
├── 紧急联系人
├── 授权签字
└── 法律责任声明
```

#### 阶段二：信息收集（Intelligence Gathering）

**被动信息收集**
- DNS 信息：域名注册信息、子域名、DNS 记录
- 网络信息：IP 段、ASN、CDN
- 人员信息：员工名单、邮箱格式、社交媒体
- 技术信息：技术栈、第三方服务、开源项目

**主动信息收集**
- 主机存活探测
- 端口扫描与服务识别
- Web 应用目录与文件扫描
- 指纹识别

#### 阶段三：威胁建模（Threat Modeling）
- 资产识别
- 攻击者画像
- 攻击向量分析
- 攻击树构建
- 风险评级

#### 阶段四：漏洞分析（Vulnerability Analysis）
- 自动化扫描：Nessus、OpenVAS
- 手动验证
- 漏洞分类与优先级排序
- 漏洞链分析

#### 阶段五：漏洞利用（Exploitation）
- 漏洞利用验证
- Payload 定制
- 绕过防御
- 获取初始 foothold

#### 阶段六：后渗透（Post Exploitation）
- 权限提升
- 横向移动
- 数据获取
- 持久化
- 痕迹清理

#### 阶段七：报告（Reporting）
- 执行摘要（管理层视角）
- 技术报告（技术团队视角）
- 修复建议
- 复测计划

### 1.2 OWASP 测试指南

**OWASP WSTG（Web Security Testing Guide）**

OWASP WSTG 提供了 Web 应用渗透测试的系统化方法论：

**测试分类**
- 信息收集与侦察
- 配置与部署管理测试
- 身份认证测试
- 会话管理测试
- 授权测试
- 输入验证测试
- 业务逻辑测试
- 客户端测试
- API 测试

### 1.3 NIST SP 800-115

**NIST 技术指南核心流程**
1. 规划阶段：确定范围、规则、授权
2. 发现阶段：信息收集、漏洞扫描
3. 攻击阶段：漏洞利用、后渗透
4. 报告阶段：结果分析、报告编写
