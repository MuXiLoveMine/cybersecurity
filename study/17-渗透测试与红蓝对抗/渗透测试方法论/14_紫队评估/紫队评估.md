# 紫队评估

### 14.1 紫队概念

```
紫队（Purple Teaming）是红队（攻击）和蓝队（防御）的协作模式：

红队（攻击方）：
  - 模拟真实攻击者
  - 执行攻击链
  - 发现安全漏洞

蓝队（防御方）：
  - 监控和检测
  - 事件响应
  - 安全加固

紫队（协作）：
  - 红蓝协同测试
  - 攻击→检测→改进→再攻击
  - 闭环持续改进

紫队评估流程：
1. 确定测试场景（如：钓鱼→初始访问→横向移动→数据外泄）
2. 红队执行攻击
3. 蓝队尝试检测和响应
4. 评估检测结果
5. 识别检测盲区
6. 优化检测规则
7. 重复测试验证改进效果

紫队评估输出：
- 攻击路径映射
- 检测覆盖率评估
- 检测规则优化建议
- 安全加固建议
```
