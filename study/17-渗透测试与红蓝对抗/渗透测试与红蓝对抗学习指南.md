# 渗透测试与红蓝对抗学习指南

> 渗透测试是模拟真实攻击者视角评估系统安全性的实战技术，红蓝对抗是检验整体安全防御体系有效性的高级演练形式。

---

## 一、方向概述

渗透测试（Penetration Testing）是通过模拟黑客攻击手段，对目标系统进行授权的安全评估，发现可被利用的安全漏洞并评估其风险。红蓝对抗（Red Team / Blue Team Exercise）是更高级的实战演练，红队模拟真实攻击者进行多维度的攻击链，蓝队进行检测、响应和防御，全面检验组织的安全防御能力。

**核心防护对象**：网络基础设施、应用系统、终端设备、身份认证体系、安全防护设备（IDS/IPS/EDR/SIEM）、应急响应能力

**关键威胁**：外部攻击者入侵、内部威胁、APT攻击链、供应链攻击、社会工程学攻击、零日漏洞利用、横向移动、权限提升、数据窃取、持久化后门

**职业方向**：渗透测试工程师、红队工程师、蓝队/安全运营工程师、攻防实验室研究员、安全架构师、漏洞研究员

## 二、详细子方向

### 2.1 渗透测试基础

#### 2.1.1 渗透测试概述
**渗透测试概念**
- 渗透测试定义：授权的、系统的安全评估
- 渗透测试 vs 漏洞扫描
- 渗透测试分类：黑盒、白盒、灰盒
- 渗透测试分类：外部测试、内部测试、盲测、双盲测

**渗透测试标准**
- PTES（Penetration Testing Execution Standard）
- OWASP Testing Guide
- NIST SP 800-115
- 渗透测试行业规范与法律边界

#### 2.1.2 渗透测试流程
**PTES 七阶段模型**
1. 前交互阶段（Pre-engagement Interactions）
2. 信息收集阶段（Intelligence Gathering）
3. 威胁建模阶段（Threat Modeling）
4. 漏洞分析阶段（Vulnerability Analysis）
5. 漏洞利用阶段（Exploitation）
6. 后渗透阶段（Post Exploitation）
7. 报告阶段（Reporting）

**各阶段关键活动**
- 前交互：确定范围、授权书、规则约束、时间窗口
- 信息收集：被动信息收集、主动信息收集
- 威胁建模：攻击树、角色定义、攻击向量
- 漏洞分析：扫描、验证、分类
- 漏洞利用：漏洞验证、Payload定制、绕过防护
- 后渗透：权限提升、横向移动、数据获取、痕迹清理
- 报告：执行摘要、技术细节、修复建议

### 2.2 信息收集

#### 2.2.1 被动信息收集
**OSINT 概述**
- 开源情报（Open Source Intelligence）
- 信息收集目标：域名、IP、人员、技术栈、架构

**域名与子域名收集**
- DNS 枚举：dig、fierce、sublist3r、amass
- 证书透明日志：crt.sh、Censys
- 搜索引擎语法：Google Dork、Shodan、Fofa、ZoomEye
- 代码仓库泄露：GitHub、GitLab、Gitee 搜索
- 子域名爆破：字典优化、泛解析处理、递归爆破

**IP 与网络信息**
- IP 段发现：BGP 查询、ASN 查询
- 端口扫描：Nmasscan、RustScan、Nmap
- 服务指纹识别：Banner 抓取、Wappalyzer、httpx
- CDN 识别与真实 IP 获取
- WAF 识别：wafw00f

#### 2.2.2 主动信息收集
**主机发现与端口扫描**
- Nmap 主机发现技术（-sn、-PS、-PA、-PU）
- 端口扫描技术（全连接扫描、SYN 扫描、UDP 扫描）
- 服务版本探测（-sV）
- 操作系统指纹识别（-O）
- NSE 脚本引擎（脚本分类与使用）
- Masscan 大规模端口扫描

**Web 应用信息收集**
- 目录扫描：dirsearch、feroxbuster、gobuster
- 文件扫描：备份文件、配置文件、源码泄露
- 指纹识别：CMS 识别、框架识别、WAF 识别
- 技术栈分析：JavaScript 框架、后端语言、数据库类型
- API 接口发现：Swagger 文档、GraphQL 接口

#### 2.2.3 人员与社会工程学信息
**人员信息收集**
- LinkedIn / 脉脉员工信息
- 组织架构推断
- 邮箱格式发现：theHarvester、Hunter.io
- 社交媒体信息
- 公开资料泄露检查：HIBP、Dehashed

### 2.3 漏洞利用

#### 2.3.1 Web 漏洞利用
**OWASP Top 10 深入利用**
- SQL 注入：sqlmap 自动化、手工注入、WAF 绕过
- XSS：存储型 XSS 利用、CSP 绕过、XSS 平台使用
- SSRF：内网探测、Redis 利用、云元数据获取
- SSTI：模板引擎注入利用
- 文件上传：绕过技巧汇总
- 反序列化：PHP/Java/Python 反序列化利用链
- 命令注入：各种注入场景与绕过
- XXE：外部实体注入、参数实体注入、无回显利用

#### 2.3.2 网络服务漏洞利用
**常见服务漏洞**
- SMB/NetBIOS：永恒之蓝（MS17-010）、SMBGhost
- RDP：BlueKeep、RDP 劫持
- SSH：弱密码爆破、密钥泄露利用
- 数据库服务：MySQL/MSQL/Oracle/Redis 未授权或弱密码
- 邮件服务：Exchange RCE、邮件协议枚举
- FTP/HTTP/TFTP/DNS 服务漏洞

#### 2.3.3 Metasploit 框架
**Metasploit 基础**
- 架构：模块（Exploit/Payload/Auxiliary/Post/Encoder）
- Payload 类型：Single/Staged/Stageless
- Meterpreter 高级 Payload
- 简介与模块搜索
- exploit/multi/handler 监听
- db_nmap 与工作区管理
- 后渗透模块（post/）
- 资源脚本（resource）与自动化

### 2.4 后渗透

#### 2.4.1 权限提升
**Windows 权限提升**
- 内核漏洞提权：MS16-032/MS16-135/MS17-017/CVE-2021-1675/CVE-2022-26923

- UAC 绕过技术

**Linux 权限提升**

#### 2.4.3 持久化与痕迹清理

### 2.6 红蓝对抗

#### 2.6.1 红蓝对抗概述
**红蓝对抗概念**
- 红蓝对抗 vs 渗透测试
- 红队：模拟攻击方
- 蓝队：防御检测方
- 紫队（Purple Team）：红蓝协作提升
- 对抗演练目标与范围

**红蓝对抗类型**
- 桌面推演
- 技术对抗
- 全场景实战对抗
- TTPs 驱动的对抗

#### 2.6.2 红队攻击链
**攻击链框架**
- Cyber Kill Chain（Lockheed Martin）
- MITRE ATT&CK 框架
- TTPs（Tactics, Techniques, Procedures）

**红队攻击流程**
1. 目标侦察与 OSINT
2. 初始 foothold 获取（钓鱼、外部漏洞利用、供应链攻击）
3. 持久化与立足
4. 内网渗透与横向移动
5. 目标达成与数据获取
6. 痕迹清理与撤离
7. 报告与复盘

**红队 TTPs**
- 初始访问：钓鱼邮件、水坑攻击、外部服务漏洞
- 执行：PowerShell、CMD、WMI、计划任务
- 持久化：注册表、服务、WMI 事件订阅
- 权限提升：内核漏洞、配置错误
- 防御绕过：AMSI 绕过、ETW 绕过、EDR 绕过、进程注入
- 凭据访问：LSASS dump、注册表凭据、Kerberoasting
- 发现：BloodHound、域信息枚举
- 横向移动：PtH/PtT/DCSync
- 收集与外传：数据压缩、分块传输、加密通道

#### 2.6.3 蓝队防御与检测
**蓝队能力体系**
- 日志采集：Windows 事件日志、Sysmon、Linux auditd
- SIEM/SOAR 平台：Splunk、ELK、QRadar
- EDR/XDR：端点检测与响应
- NDR/NTA：网络流量分析
- 威胁狩猎：基于 ATT&CK 的主动威胁狩猎
- 蜜罐与欺骗防御

**检测能力**
- 规则检测：Sigma 规则、YARA 规则
- 行为检测：异常进程树、异常网络连接
- 关联分析：多源日志关联、ATT&CK 映射
- UEBA：用户与实体行为分析

**响应能力**
- 遏制：隔离主机、阻断 IP、封禁账户
- 根除：清除后门、修复漏洞、重置凭据
- 恢复：系统重建、服务恢复
- 总结：攻击链还原、防御改进

#### 2.6.4 紫队与持续改进
**紫队概念**
- 紫队 = 红队 + 蓝队协作
- 攻击模拟与检测验证同步进行
- 每次攻击 TTP 同时验证检测覆盖

**紫队工作流**
1. 选取 ATT&CK 技术点
2. 红队执行模拟攻击
3. 蓝队实时验证检测
4. 评估检测覆盖率
5. 补齐检测缺口
6. 更新规则与配置

**自动化紫队工具**
- Atomic Red Team
- CALDERA
- VectorSphere
- Stratus Red Team

## 七、学习建议

### 7.1 学习方法
- 以靶场为核心，理论与实践并行
- 从简单靶场到复杂靶场，循序渐进
- 复现 CVE 漏洞，理解漏洞原理和利用过程
- 关注安全社区新漏洞、新技术的披露
- 参加 CTF 竞赛积累实战经验

### 7.2 学习重点
- 信息收集是渗透测试最重要的一步，投入最多时间
- 内网渗透是渗透测试的核心竞争力
- 域环境攻击是红队必备技能
- 防御绕过是高级红队工程师的分水岭
- 蓝队检测能力是红蓝对抗的关键

### 7.3 常见误区
- 重利用轻信息收集：信息收集不充分导致遗漏攻击面
- 重 Web 轻内网：内网渗透能力不足限制职业发展
- 重工具轻原理：不理解原理遇到新场景无法应对
- 攻防不对立：优秀的安全工程师需要同时理解攻与防
- 忽视法律边界：未经授权的渗透测试是违法行为

### 7.4 职业发展
- 渗透测试工程师 → 高级渗透测试工程师 → 红队工程师 → 安全架构师
- 红蓝双修是安全行业的高级方向
- 建议同时学习蓝队技能，成为紫队人才
- 持有 OSCP/OSEP/OSED/CISP-PTE 等认证提升竞争力
- 红队工程师应深入理解 ATT&CK 框架和 TTPs
