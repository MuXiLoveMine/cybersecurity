# 威胁建模方法

### 3.1 威胁建模概述

威胁建模是在设计阶段系统性地识别、评估和缓解安全威胁的方法。

**威胁建模流程**
```
1. 系统理解 → 2. 组件分解 → 3. 信任边界识别
                                    ↓
4. 绘制数据流图 → 5. 威胁识别 → 6. 风险评估 → 7. 缓解措施
```

### 3.2 STRIDE 方法

STRIDE 是 Microsoft 提出的威胁分类框架，从六个维度分析威胁：

| 威胁类型 | 安全属性 | 攻击示例 | 缓解措施 |
|---------|---------|---------|---------|
| Spoofing（身份欺骗） | 认证 | 伪造用户身份、会话劫持 | MFA、强认证、会话绑定 |
| Tampering（数据篡改） | 完整性 | 修改传输数据、篡改文件 | 数字签名、MAC、输入验证 |
| Repudiation（否认） | 不可抵赖性 | 否认操作行为 | 审计日志、数字签名 |
| Information Disclosure（信息泄露） | 机密性 | 数据泄露、错误信息暴露 | 加密、访问控制、最小信息暴露 |
| Denial of Service（拒绝服务） | 可用性 | 资源耗尽、流量攻击 | 限流、冗余、验证码 |
| Elevation of Privilege（提权） | 授权 | 水平/垂直越权 | 最小权限、RBAC、输入验证 |
