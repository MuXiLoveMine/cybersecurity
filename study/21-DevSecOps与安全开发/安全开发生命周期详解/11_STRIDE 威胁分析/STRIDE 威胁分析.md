# STRIDE 威胁分析

### Spoofing（身份欺骗）
- 威胁：攻击者伪造用户身份登录
- 风险：高
- 缓解：MFA + 会话 Token 绑定 IP + 设备指纹

### Tampering（数据篡改）
- 威胁：攻击者修改传输中的数据
- 风险：高
- 缓解：HTTPS + HSTS + 输入完整性验证

### Repudiation（否认）
- 威胁：用户否认关键操作
- 风险：中
- 缓解：关键操作审计日志 + 用户确认

### Information Disclosure（信息泄露）
- 威胁：错误信息泄露技术栈
- 风险：中
- 缓解：自定义错误页面 + 最小信息暴露

### Denial of Service（拒绝服务）
- 威胁：暴力请求导致服务不可用
- 风险：高
- 缓解：限流 + WAF + CDN 缓存

### Elevation of Privilege（提权）
- 威胁：普通用户获取管理员权限
- 风险：高
- 缓解：RBAC + 最小权限 + 二次授权

### 3.3 DREAD 风险评估

DREAD 用于评估威胁的风险等级，每个维度 1-10 分：

| 维度 | 说明 | 评分标准 |
|------|------|---------|
| Damage（损害程度） | 威胁造成的损害 | 1=轻微 10=灾难性 |
| Reproducibility（可复现性） | 攻击复现难度 | 1=困难 10=容易 |
| Exploitability（可利用性） | 攻击实施难度 | 1=需高级技能 10=任何人 |
| Affected Users（影响范围） | 受影响用户数量 | 1=极少数 10=所有用户 |
| Discoverability（可发现性） | 威胁被发现难度 | 1=难以发现 10=显而易见 |

**DREAD 评分示例**
```python
# DREAD 风险评分计算
def calculate_dread_score(d, r, e, a, di):
    """计算 DREAD 风险评分（1-10分，总分 5-50）"""
    score = (d + r + e + a + di) / 5
    if score >= 8:
        return "Critical", score
    elif score >= 6:
        return "High", score
    elif score >= 4:
        return "Medium", score
    else:
        return "Low", score

# SQL 注入威胁评分
severity, score = calculate_dread_score(
    d=9,   # 损害：可获取所有数据
    r=8,   # 可复现：容易复现
    e=7,   # 可利用：有自动化工具
    a=10,  # 影响范围：所有用户
    di=8   # 可发现性：容易发现
)
print(f"SQL注入风险: {severity}, 评分: {score}")
# 输出: SQL注入风险: Critical, 评分: 8.4
```

### 3.4 PASTA 威胁建模

PASTA（Process for Attack Simulation and Threat Analysis）是一种以风险为中心的七步威胁建模方法：

**PASTA 七步流程**
1. 定义业务和技术范围
2. 定义技术架构组件
3. 分解应用：数据流和信任边界
4. 威胁分析：基于攻击者视角
5. 漏洞分析：技术漏洞和弱点
6. 攻击建模：攻击树和场景
7. 风险评估与缓解

**PASTA 攻击树示例**
```
获取管理员权限
├── 获取管理员凭证
│   ├── 暴力破解管理员密码
│   ├── 钓鱼攻击管理员
│   └── 从配置文件中提取硬编码密码
├── 利用认证漏洞
│   ├── Session Fixation
│   ├── JWT 签名绕过
│   └── Cookie 篡改提权
└── 利用授权漏洞
    ├── IDOR 水平越权
    ├── 参数篡改垂直越权
    └── 路径遍历访问管理页面
```

### 3.5 数据流图（DFD）

数据流图用于可视化系统中的数据流动和信任边界。

**DFD 符号**
```
──→  数据流      [实体]      (处理)
  ○  数据存储    ═══ 信任边界
```
