# 错误处理与日志

### 6.1 安全的错误处理

**漏洞代码：**
```python
# Python - 泄露堆栈信息
@app.route('/api/data')
def get_data():
    try:
        data = query_database()
        return jsonify(data)
    except Exception as e:
        return jsonify({'error': str(e), 'traceback': traceback.format_exc()}), 500
        # 泄露数据库结构、SQL语句、文件路径！
```

**安全代码：**
```python
import logging
import uuid

logger = logging.getLogger(__name__)

@app.route('/api/data')
def get_data():
    try:
        data = query_database()
        return jsonify(data)
    except Exception as e:
        error_id = uuid.uuid4().hex
        # 详细错误记录到日志（不返回给用户）
        logger.error(f"[{error_id}] Database error: {e}", exc_info=True)
        # 用户看到的是友好错误+追踪ID
        return jsonify({'error': '服务器内部错误', 'request_id': error_id}), 500
```

```java
// Java - 全局异常处理
@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public ResponseEntity<Map<String, String>> handleException(Exception e) {
        String errorId = UUID.randomUUID().toString();
        log.error("[{}] Unexpected error: {}", errorId, e.getMessage(), e);
        return ResponseEntity.status(500)
            .body(Map.of("error", "服务器内部错误", "request_id", errorId));
    }
}
```

### 6.2 安全日志记录

**漏洞代码：**
```python
# 泄露敏感信息到日志
logger.info(f"用户登录: username={username}, password={password}")  # 密码入日志！
logger.info(f"信用卡支付: card={card_number}, cvv={cvv}")  # 卡号+CVV！
```

**安全代码：**
```python
# 敏感数据脱敏
def mask_sensitive(key, value):
    SENSITIVE_KEYS = {'password', 'token', 'secret', 'card_number', 'cvv', 'ssn'}
    if key.lower() in SENSITIVE_KEYS:
        return '***REDACTED***'
    if key.lower() == 'email':
        return value[:2] + '***' + value[value.index('@'):]
    return value

logger.info(f"用户登录: username={username}, password=***REDACTED***")
logger.info(f"支付: card=****-****-****-{card_number[-4:]}, amount={amount}")
```

### 6.3 日志注入防护

**漏洞代码：**
```python
# 用户输入直接写入日志，可注入伪造日志行
logger.info(f"用户操作: {user_input}")
# 输入: "正常操作\n[ERROR] 管理员删除了所有数据"
# 结果: 日志中伪造了一条 ERROR 日志
```

**安全代码：**
```python
import re

def sanitize_log_input(text):
    """移除换行符和控制字符，防止日志注入"""
    text = re.sub(r'[\r\n\t]', '_', text)
    text = re.sub(r'[^\x20-\x7E]', '', text)  # 仅保留可打印ASCII
    return text

logger.info(f"用户操作: {sanitize_log_input(user_input)}")
```
