# 文件操作安全

### 5.1 文件上传安全编码

**漏洞代码：**
```python
# Python - 不安全文件上传
@app.route('/upload', methods=['POST'])
def upload():
    file = request.files['file']
    file.save(f'/var/www/uploads/{file.filename}')  # 原始文件名，可路径遍历+任意类型
```

**安全代码：**
```python
import uuid
import os

ALLOWED_EXTENSIONS = {'png', 'jpg', 'jpeg', 'gif', 'pdf'}
MAX_FILE_SIZE = 10 * 1024 * 1024  # 10MB

@app.route('/upload', methods=['POST'])
def upload():
    file = request.files['file']

    # 1. 验证文件大小
    file.seek(0, 2)
    if file.tell() > MAX_FILE_SIZE:
        abort(413)
    file.seek(0)

    # 2. 验证扩展名（白名单）
    ext = file.filename.rsplit('.', 1)[-1].lower() if '.' in file.filename else ''
    if ext not in ALLOWED_EXTENSIONS:
        abort(415)

    # 3. 验证文件内容（Magic Number）
    magic = file.read(8)
    file.seek(0)
    if not is_valid_magic(magic, ext):
        abort(415)

    # 4. 生成随机文件名，避免遍历和覆盖
    safe_name = f"{uuid.uuid4().hex}.{ext}"
    upload_dir = '/var/www/uploads'
    full_path = os.path.join(upload_dir, safe_name)

    # 5. 确保路径安全
    if not os.path.abspath(full_path).startswith(upload_dir):
        abort(403)

    file.save(full_path)
```

### 5.2 文件下载安全编码

**漏洞代码：**
```python
@app.route('/download')
def download():
    filename = request.args.get('file')
    return send_file(f'/var/www/files/{filename}')  # 路径遍历！
```

**安全代码：**
```python
import os
from flask import send_from_directory

FILE_DIR = '/var/www/files'

@app.route('/download')
def download():
    filename = request.args.get('file', '')
    # 白名单验证文件名（只允许字母数字和._-）
    if not re.match(r'^[a-zA-Z0-9._-]+$', filename):
        abort(403)
    return send_from_directory(FILE_DIR, filename, as_attachment=True)
```

### 5.3 临时文件处理

**漏洞代码：**
```python
import tempfile
# 创建可预测名称的临时文件（竞态条件）
f = open(f'/tmp/process_{os.getpid()}.tmp', 'w')
```

**安全代码：**
```python
import tempfile
import os

# 使用 mkstemp 创建安全的临时文件
fd, tmp_path = tempfile.mkstemp(prefix='process_', suffix='.tmp')
os.chmod(tmp_path, 0o600)  # 仅属主可读写
try:
    with os.fdopen(fd, 'w') as f:
        f.write(data)
    # 处理文件...
finally:
    os.unlink(tmp_path)  # 使用后立即删除
```

```java
// Java - 安全临时文件
File tmp = File.createTempFile("process_", ".tmp");
tmp.setReadable(true, true);   // 仅属主可读
tmp.setWritable(true, true);
tmp.deleteOnExit();            // JVM退出时删除
```

### 5.4 文件权限管理

```python
# Python - 文件权限设置
import os

# 创建目录时设置最小权限
os.makedirs('/var/app/data', mode=0o750)  # 属主rwx，组r-x，其他无

# 创建文件时设置权限
with open('config.json', 'w', opener=lambda path, flags: os.open(path, flags, 0o640)):
    json.dump(config, f)
```

```
文件权限参考：
├── 配置文件(含密钥)   600  rw-------  仅属主
├── 日志文件           640  rw-r-----  属主+组
├── Web静态资源        644  rw-r--r--  所有人可读
├── 上传目录           750  rwxr-x---  禁止其他用户
├── 可执行脚本         750  rwxr-x---  禁止其他用户
└── 密钥文件           400  r--------  只读
```
