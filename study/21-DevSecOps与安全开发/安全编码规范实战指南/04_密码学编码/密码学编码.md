# 密码学编码

### 4.1 随机数生成规范

**漏洞代码：**
```python
import random
token = ''.join(random.choices('0123456789', k=6))  # 不安全！可预测
```

**安全代码：**
```python
import secrets
token = secrets.token_urlsafe(32)  # CSPRNG，安全随机
# 或
import os
token = os.urandom(32).hex()
```

```java
// Java
import java.security.SecureRandom;
SecureRandom random = new SecureRandom();
byte[] token = new byte[32];
random.nextBytes(token);
```

```go
// Go
import "crypto/rand"
b := make([]byte, 32)
rand.Read(b)
```

### 4.2 对称加密使用规范（AES-GCM）

**漏洞代码：**
```python
# Python - 使用 ECB 模式（最不安全）
from Crypto.Cipher import AES
cipher = AES.new(key, AES.MODE_ECB)  # ECB模式！相同明文产生相同密文
```

**安全代码：**
```python
# Python - AES-GCM（提供加密+认证）
from Crypto.Cipher import AES
import os

key = os.urandom(32)  # AES-256
nonce = os.urandom(12)  # 96位 nonce
cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
ciphertext, tag = cipher.encrypt_and_digest(plaintext)

# 传输：nonce + ciphertext + tag
# 解密时验证 tag 防篡改
cipher_dec = AES.new(key, AES.MODE_GCM, nonce=nonce)
plaintext = cipher_dec.decrypt_and_verify(ciphertext, tag)
```

```go
// Go - AES-GCM
import (
    "crypto/aes"
    "crypto/cipher"
    "crypto/rand"
)

block, _ := aes.NewCipher(key)
gcm, _ := cipher.NewGCM(block)
nonce := make([]byte, gcm.NonceSize())
rand.Read(nonce)
ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)
```

```java
// Java - AES-GCM
import javax.crypto.Cipher;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;

Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
GCMParameterSpec spec = new GCMParameterSpec(128, nonce);  // 128位 tag
cipher.init(Cipher.ENCRYPT_MODE, new SecretKeySpec(key, "AES"), spec);
byte[] ciphertext = cipher.doFinal(plaintext);
```

### 4.3 哈希使用规范

```
┌──────────────────────────────────────────────┐
│              哈希算法安全对照表               │
├──────────┬────────────┬───────────────────────┤
│ 算法      │ 安全性      │ 用途                  │
├──────────┼────────────┼───────────────────────┤
│ MD5      │ 已不安全    │ 仅校验完整性，不安全   │
│ SHA-1    │ 已不安全    │ 弃用                  │
│ SHA-256  │ 安全        │ 数据完整性、数字签名   │
│ SHA-3    │ 安全        │ 新一代标准             │
│ bcrypt   │ 安全        │ 密码存储（含盐值）     │
│ argon2   │ 最安全      │ 密码存储（抗GPU攻击）  │
│ HMAC     │ 安全        │ 消息认证码             │
└──────────┴────────────┴───────────────────────┘
```

```python
# Python - HMAC 消息认证
import hmac, hashlib

secret_key = get_secret_key()
message = b"transfer:100:account_A"
signature = hmac.new(secret_key, message, hashlib.sha256).hexdigest()

# 接收方验证
expected = hmac.new(secret_key, received_message, hashlib.sha256).hexdigest()
if hmac.compare_digest(signature, expected):  # 常量时间比较
    print("验证通过")
```

```
HSM 硬件安全模块    ████████████████████ 最安全

环境变量+密文存储   ████████████         .env + 加密
环境变量明文        ████████             开发环境可用
```


### 4.5 常见密码学错误

```
┌──────────────────────────────────────────────────────┐
│                  密码学常见错误清单                    │
├──────────────────┬───────────────────────────────────┤
│ 错误              │ 后果                              │
├──────────────────┼───────────────────────────────────┤
│ 使用 ECB 模式     │ 相同明文→相同密文，泄露模式       │
│ 使用 MD5/SHA1     │ 碰撞攻击，数字签名伪造            │
│ 硬编码密钥        │ 源码泄露即密钥泄露                │
│ 复用 nonce/IV     │ 流密码密钥重用，明文可恢复         │
│ 自实现加密算法    │ 不要自己实现密码学！              │
│ 随机数用 random  │ 伪随机可预测，token 可伪造         │
└──────────────────┴───────────────────────────────────┘
```
