# 附录：安全编码快速参考卡片

```
┌─────────────────────────────────────────────────────────────────┐
│                    安全编码黄金法则                              │
├─────────────────────────────────────────────────────────────────┤
│ 1. 永远不要信任用户输入 → 白名单验证                             │
│ 2. 永远不要拼接 SQL    → 参数化查询                              │
│ 3. 永远不要拼接命令    → 参数列表调用                            │
│ 4. 永远不要明文存密码  → bcrypt/argon2                           │
│ 5. 永远不要硬编码密钥  → 密钥管理服务                            │
│ 6. 永远不要用弱随机数  → CSPRNG                                 │
│ 7. 永远不要用 ECB 模式 → AES-GCM                                │
│ 8. 永远不要泄露错误    → 友好错误+追踪ID                         │
│ 9. 永远不要忘记编码    → 按上下文输出编码                        │
│ 10. 永远不要默认开放   → 最小权限+默认安全                       │
└─────────────────────────────────────────────────────────────────┘
```

### 二、安全编码规则集速查

#### 2.1 OWASP Top 10 2021 安全编码要点
```
A01: Broken Access Control - 访问控制失效
├── 实施最小权限原则
├── 禁用默认账户和默认密码
├── 验证每个请求的权限
├── 防止水平越权（IDOR）
├── 防止垂直越权
├── CORS配置安全
└── 文件访问控制

A02: Cryptographic Failures - 加密失败
├── 使用强加密算法（AES-256-GCM, ChaCha20-Poly1305）
├── 使用安全的哈希算法（SHA-256, SHA-3, bcrypt, Argon2）
├── 密码使用bcrypt/Argon2id存储
├── TLS 1.2+（推荐1.3）
├── 密钥管理（不硬编码、定期轮换）
├── 随机数使用CSPRNG
└── 敏感数据传输加密

A03: Injection - 注入攻击
├── SQL注入：使用参数化查询/ORM
├── 命令注入：避免system()/exec()
├── XSS注入：输出编码/上下文转义
├── LDAP注入：参数化查询
├── XXE注入：禁用外部实体
├── SSTI注入：避免模板中使用用户输入
└── 表达式注入：禁用危险表达式

A04: Insecure Design - 不安全的设计
├── 威胁建模（STRIDE, PASTA）
├── 安全设计原则（最小权限、纵深防御）
├── 业务逻辑安全
├── 限频与限流
├── 输入验证（白名单）
└── 状态管理安全

A05: Security Misconfiguration - 安全配置错误
├── 移除默认配置和账户
├── 关闭不必要的功能和端口
├── 错误信息不泄露细节
├── 安全响应头配置
├── 目录列表禁用
├── CSP/CORS安全配置
└── 安全的HTTP方法限制

A06: Vulnerable and Outdated Components - 过时组件
├── 依赖清单管理（SBOM）
├── 定期漏洞扫描
├── 组件版本锁定
├── 最小化依赖
├── 定期更新
└── 供应链安全验证

A07: Identification and Authentication Failures - 认证失效
├── 强密码策略
├── 多因素认证(MFA)
├── 安全的会话管理
├── 防暴力破解（锁定/限流）
├── 密码安全存储（bcrypt/Argon2）
├── 安全的密码重置流程
└── 防会话固定攻击

A08: Software and Data Integrity Failures - 软件和数据完整性失效
├── 代码签名验证
├── 依赖完整性校验（checksum）
├── CI/CD流水线安全
├── 反序列化防护
├── 数据完整性校验
└── 不可信数据验证

A09: Security Logging and Monitoring Failures - 日志和监控失效
├── 安全事件日志记录
├── 敏感数据不入日志
├── 日志完整性保护
├── 实时监控与告警
├── 审计日志留存
└── 日志分析与检测

A10: Server-Side Request Forgery - SSRF
├── 禁止内网地址访问
├── URL白名单验证
├── 禁用重定向跟随
├── DNS重绑定防护
├── 出站流量限制
└── 云环境元数据服务防护
```

### 四、安全编码检查 CI/CD 集成实践

#### 4.1 Pre-commit 钩子配置
```yaml
# .pre-commit-config.yaml
repos:
  # 密钥检测
  - repo: https://github.com/gitleaks/gitleaks
    rev: v8.18.2
    hooks:
      - id: gitleaks
        args: ["--staged", "--redact"]

  # Python 安全检查
  - repo: https://github.com/PyCQA/bandit
    rev: 1.7.5
    hooks:
      - id: bandit
        args: ["-c", "bandit.yaml", "-lll"]
        files: \.py$

  # JavaScript/TypeScript 安全
  - repo: local
    hooks:
      - id: eslint-security
        name: ESLint Security Check
        entry: npx eslint
        args: ["--ext", ".js,.ts", "--no-eslintrc", "--plugin", "security", "--rule", "security/detect-eval-with-expression:error"]
        files: \.[jt]sx?$
        pass_filenames: true
        language: node

  # 通用SAST
  - repo: local
    hooks:
      - id: semgrep
        name: Semgrep Security Scan
        entry: semgrep
        args: ["--config", "p/owasp-top-ten", "--config", "p/secrets", "--error", "--severity", "ERROR"]
        language: python
        pass_filenames: false

  # IaC 安全检查
  - repo: https://github.com/antonbabenko/pre-commit-terraform
    rev: v1.83.2
    hooks:
      - id: terraform_tfsec
      - id: terraform_checkov
```

#### 4.2 安全编码门禁策略
```
安全编码门禁（Security Gate）策略建议：

1. 代码提交前（Pre-commit）
   ├── 密钥泄露检测（Gitleaks）- 阻断
   ├── 代码格式检查 - 提示
   ├── Lint基本检查 - 警告
   └── 简单SAST扫描 - 警告

2. PR/MR 阶段
   ├── SAST全量扫描（SonarQube/Semgrep）
   │   ├── 新增高危漏洞 - 阻断
   │   ├── 新增中危漏洞 - 需审核
   │   └── 低危漏洞 - 记录
   ├── 依赖漏洞扫描（Snyk/Dependency-Check）
   │   ├── Critical漏洞 - 阻断
   │   ├── High漏洞 - 需审核
   │   └── Medium及以下 - 记录
   ├── 代码覆盖率门槛
   │   └── 新增代码覆盖率 > 80%
   └── 安全代码审查
       └── 安全团队必须审查高风险变更

3. 合并后/发布前
   ├── 完整SAST + DAST 扫描
   ├── 容器镜像扫描
   ├── IaC全量扫描
   ├── SBOM生成与校验
   └── 渗透测试（关键版本）

4. 生产环境
   ├── 运行时安全监控（RASP）
   ├── 依赖漏洞监控（持续）
   ├── 攻击检测与响应
   └── 定期安全审计
```

工具配置最佳实践：

   ├── 左移：尽早发现（pre-commit → IDE）
   ├── 分层：不同阶段不同扫描深度
