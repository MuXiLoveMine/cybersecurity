# 最佳实践总结

### 9.1 SAST 最佳实践
1. **分层扫描策略**：预提交快速扫描 + CI/CD 全量扫描 + 定期深度扫描
2. **多工具组合**：不同工具覆盖不同漏洞类型，交叉验证减少遗漏
3. **误报管理**：建立基线机制，标记和抑制已知误报，定期审查
4. **自定义规则**：根据项目特点编写针对性的安全规则
5. **覆盖率追踪**：监控安全扫描覆盖率，确保代码被充分覆盖

### 9.2 DAST 最佳实践
1. **分层扫描**：测试环境主动扫描 + 生产环境被动监控
2. **认证支持**：配置认证信息扫描需要登录的功能
3. **限速控制**：避免扫描影响目标系统稳定性
4. **持续扫描**：每次部署后自动执行 DAST 扫描
5. **结果关联**：将 DAST 发现与代码关联，定位问题代码位置

### 9.3 SCA 最佳实践
1. **持续监控**：每次代码提交和每日定期扫描
2. **SBOM 生成**：为每个制品生成软件物料清单
3. **修复优先级**：根据可利用性和影响范围评估修复优先级
4. **自动修复**：使用工具自动升级安全版本
5. **供应链验证**：验证第三方组件来源和完整性

---

> **总结**：SAST 和 DAST 是互补的安全测试方法，SAST 在早期发现源代码层面的漏洞，DAST 在运行时验证实际可利用的漏洞。最佳实践是将两者与 IAST、SCA 结合使用，通过 CI/CD 流水线自动化集成，配合安全门禁策略，实现持续的安全质量保障。关键是根据项目实际情况选择合适的工具组合，建立可持续的安全扫描流程。

#### 2.3 ZAP 自动化脚本（Python）
```python
#!/usr/bin/env python3
# ZAP 自动化扫描脚本

import time
from zapv2 import ZAPv2

# 配置
target = 'https://example.com'
api_key = 'your-api-key'
zap = ZAPv2(apikey=api_key, proxies={'http': 'http://127.0.0.1:8080', 'https': 'http://127.0.0.1:8080'})

print(f'开始扫描目标: {target}')

# 1. 开启新会话
zap.core.new_session(name='scan_session', overwrite=True)

# 2. Spider 爬取
print('启动 Spider...')
scan_id = zap.spider.scan(target)
while int(zap.spider.status(scan_id)) < 100:
    print(f'Spider 进度: {zap.spider.status(scan_id)}%')
    time.sleep(10)
print('Spider 完成')

# 3. 被动扫描等待
print('等待被动扫描完成...')
time.sleep(30)

# 4. 主动扫描
print('启动主动扫描...')
scan_id = zap.ascan.scan(target)
while int(zap.ascan.status(scan_id)) < 100:
    print(f'主动扫描进度: {zap.ascan.status(scan_id)}%')
    time.sleep(30)
print('主动扫描完成')

# 5. 生成报告
print('生成报告...')
with open('zap_report.html', 'w', encoding='utf-8') as f:
    f.write(zap.core.htmlreport())

# 6. 输出告警摘要
alerts = zap.core.alerts(baseurl=target)
print(f'\n发现 {len(alerts)} 个告警:')
risk_counts = {}
for alert in alerts:
    risk = alert['risk']
    risk_counts[risk] = risk_counts.get(risk, 0) + 1

for risk in ['High', 'Medium', 'Low', 'Informational']:
    print(f'  {risk}: {risk_counts.get(risk, 0)}')

print('\n报告已保存到 zap_report.html')
```
