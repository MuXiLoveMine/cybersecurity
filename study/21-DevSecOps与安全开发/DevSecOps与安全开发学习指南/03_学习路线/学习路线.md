# 学习路线

### 阶段 1：基础入门（1-2 个月）
**学习目标**：理解 DevSecOps 理念，掌握安全编码基础

**学习内容**
- DevOps 基础理念
- DevSecOps 核心概念
- OWASP Top 10 漏洞
- 安全编码规范
- Git 版本控制与安全
- CI/CD 基础概念

**实践任务**
- 安装使用 SonarQube 社区版
- 在 IDE 安装安全检查插件
- 配置 Git 预提交钩子
- 学习安全编码规范
- 编写安全的代码示例

### 阶段 2：安全测试工具（2-3 个月）
**学习目标**：掌握 SAST/DAST/SCA 工具使用

**学习内容**
- SAST 工具使用（SonarQube/Semgrep/Bandit）
- DAST 工具使用（OWASP ZAP/Nuclei）
- SCA 工具使用（Snyk/Trivy/Dependency-Check）
- IAST 概念和工具
- 误报管理与规则调优

**实践任务**
- 用 Semgrep 编写自定义规则
- 用 OWASP ZAP 做自动化扫描
- 用 Trivy 扫描项目依赖
- 搭建漏洞管理平台 DefectDojo
- 集成多种安全工具到流水线

### 阶段 3：容器与云原生安全（2-3 个月）
**学习目标**：掌握容器和 Kubernetes 安全

**学习内容**
- 容器安全原理
- 镜像扫描与签名
- 容器运行时安全
- Kubernetes 安全（RBAC/PSP/Network Policy）
- IaC 安全扫描

**实践任务**
- 编写安全的 Dockerfile
- 配置 Kubernetes Pod 安全策略
- 用 Trivy 扫描容器镜像
- 用 Checkov 扫描 Terraform
- 搭建容器运行时安全监控

### 阶段 4：流水线集成（2-3 个月）
**学习目标**：构建完整的 DevSecOps 流水线

**学习内容**
- GitLab CI / Jenkins 安全集成
- 安全门禁策略设计
- SBOM 生成与管理
- 漏洞管理流程
- 安全度量指标

**实践任务**
- 搭建完整 DevSecOps 流水线
- 实现安全门禁自动化
- 构建漏洞管理流程
- 编写安全度量报告
- 实现安全发现聚合

### 阶段 5：深入进阶（持续）
**学习目标**：DevSecOps 架师级能力

**学习内容**
- 安全架构设计
- 威胁建模实战
- 供应链安全
- 安全自动化高级实践
- 安全成熟度评估

**实践任务**
- 进行完整的威胁建模
- 设计企业 DevSecOps 架构
- 实现安全自动化平台
- 评估安全成熟度
- 研究供应链安全前沿
