# 软件成分分析（SCA）概述

### 1.1 开源组件安全风险

```
现代软件构成：

┌─────────────────────────────────────────┐
│            应用程序                      │
│  ┌─────────────────────────────────┐    │
│  │     自研代码（约 10-30%）        │    │
│  ├─────────────────────────────────┤    │
│  │  第三方库（约 40-60%）           │    │
│  │  ├── 直接依赖                    │    │
│  │  │   ├── requests==2.28.0       │    │
│  │  │   ├── django==4.2.0          │    │
│  │  │   └── ...                    │    │
│  │  └── 间接依赖（传递依赖）        │    │
│  │      ├── urllib3               │    │
│  │      ├── certifi               │    │
│  │      └── ...（可达数百个）      │    │
│  ├─────────────────────────────────┤    │
│  │  基础镜像层（约 20-30%）         │    │
│  │  ├── OS 包（apt/yum）           │    │
│  │  └── 系统库                     │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘

风险点：
├── 已知漏洞（CVE）        → 组件含已公开漏洞
├── 许可证合规              → GPL 等传染性许可证风险
├── 废弃/未维护组件         → 无人修复漏洞
├── 供应链投毒              → 恶意代码注入上游包
├── 依赖混淆                → 名称相似包伪装
└── 版本漂移                → 间接依赖版本不一致
```

**典型案例：**
- **Log4Shell（CVE-2021-44228）**：Log4j2 JNDI 注入，CVSS 10.0，影响全球数百万系统
- **LeftPad 事件**：一个 11 行代码的 npm 包删除导致数千个项目构建失败
- **XZ Utils 后门**：攻击者两年渗透开源项目，在压缩库中植入后门

### 1.2 SCA 在 DevSecOps 中的角色

```
DevSecOps 流水线中的安全测试层次：

代码提交 → 编译构建 → 测试 → 打包 → 部署 → 运行
   │          │        │       │       │       │
  SAST      SCA      DAST    SCA     镜像    RASP
  静态分析  组件分析   动态    SBOM   漏洞   运行时
           依赖扫描   测试    生成   扫描   保护
```

SCA 在 DevSecOps 中负责：
- **开发阶段**：IDE 插件实时告警依赖漏洞
- **构建阶段**：CI 流水线扫描依赖 + 生成 SBOM
- **部署阶段**：镜像/容器漏洞扫描
- **运行阶段**：持续监控新漏洞（零日漏洞响应）

### 1.3 SCA vs SAST vs DAST

```
┌──────────┬────────────┬─────────────┬──────────────┐
│ 维度     │ SAST       │ SCA         │ DAST         │
├──────────┼────────────┼─────────────┼──────────────┤
│ 分析对象  │ 源代码     │ 依赖清单     │ 运行中应用    │
│ 检测内容  │ 自研代码   │ 第三方组件   │ 运行时行为    │
│ 漏洞类型  │ 注入/XSS   │ CVE已知漏洞  │ 业务逻辑漏洞  │
│ 时机      │ 编码阶段   │ 构建/部署    │ 测试/生产     │
│ 误报率    │ 较高       │ 低          │ 中等         │
│ 发现速度  │ 分钟级     │ 秒级        │ 分钟~小时     │
│ 许可证    │ 不覆盖     │ 覆盖        │ 不覆盖       │
└──────────┴────────────┴─────────────┴──────────────┘

三者互补：SAST 管自研代码 → SCA 管第三方依赖 → DAST 管运行时
```
