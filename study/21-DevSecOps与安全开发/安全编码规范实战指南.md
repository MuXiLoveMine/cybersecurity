## 一、安全编码概述

### 1.1 安全编码的重要性

```
漏洞修复成本随生命周期指数级增长：

需求阶段修复     ●           成本 1x
设计阶段修复     ●●          成本 5x
编码阶段修复     ●●●         成本 10x
测试阶段修复     ●●●●●       成本 50x
生产阶段修复     ●●●●●●●●●   成本 200x
```

安全编码在编码阶段消除 70% 以上的常见漏洞，是成本最低、效果最好的安全投入。

### 1.2 OWASP Secure Coding Practices 核心原则

- **输入验证**：所有外部输入均不可信，必须验证
- **输出编码**：数据输出到不同上下文时需相应编码
- **最小权限**：代码以最小权限运行
- **默认安全**：默认配置应为最安全状态
- **纵深防御**：多层防护，不依赖单一控制
- **失败安全**：异常时进入安全状态而非开放状态

### 1.3 安全编码与业务目标的平衡

安全编码不是追求绝对安全，而是在风险、成本、体验之间取得平衡：

```
安全 ←──────────────────────→ 敏捷
高管控                          低延迟
严格验证  ←── 平衡点 ──→  体验优先
深度防御                       快速迭代
```

**实践原则**：高危路径（支付、认证、权限）严格安全编码，低危路径适度安全投入。

### 2.1 输入验证原则

```
白名单验证 > 黑名单过滤

验证维度：
├── 类型验证   → 期望 int 就拒绝 string
```


### 2.6 SSRF 防护

**漏洞代码：**
```python
# Python - 用户控制 URL 直接请求
import requests
url = request.args.get('url')
resp = requests.get(url)  # SSRF！可请求内网 http://169.254.169.254/
```

**安全代码：**
```python
import ipaddress
import socket
from urllib.parse import urlparse

ALLOWED_SCHEMES = ['http', 'https']

def is_safe_url(url):
    parsed = urlparse(url)
    if parsed.scheme not in ALLOWED_SCHEMES:
        return False
    # 解析 IP，拒绝内网地址
    try:
        ip = ipaddress.ip_address(socket.gethostbyname(parsed.hostname))
        if ip.is_private or ip.is_loopback or ip.is_link_local:
            return False
    except ValueError:
        return False
    return True

if not is_safe_url(url):
    abort(403)
resp = requests.get(url, timeout=5)
```

## 三、认证与授权编码

### 3.1 密码存储安全

**漏洞代码：**
```python
# Python - 明文或弱哈希存储密码
import hashlib
password_hash = hashlib.md5(password.encode()).hexdigest()  # MD5不安全！
```

**安全代码：**
```python
# Python - 使用 bcrypt
import bcrypt

# 注册时哈希
salt = bcrypt.gensalt(rounds=12)
password_hash = bcrypt.hashpw(password.encode('utf-8'), salt)

# 登录时验证
if bcrypt.checkpw(input_password.encode('utf-8'), password_hash):
    print("密码正确")
```

```java
// Java - 使用 Argon2（推荐）
import de.mkammerer.argon2.Argon2;
import de.mkammerer.argon2.Argon2Factory;

Argon2 argon2 = Argon2Factory.create();
// 哈希密码（自动生成盐值）
String hash = argon2.hash(10, 65536, 1, password.toCharArray());
// 验证密码
if (argon2.verify(hash, inputPassword.toCharArray())) {
    System.out.println("密码正确");
}
```

```go
// Go - 使用 scrypt
import "golang.org/x/crypto/scrypt"

func hashPassword(password string) ([]byte, error) {
    salt := generateRandomBytes(32)
    hash, err := scrypt.Key([]byte(password), salt, 32768, 8, 1, 32)
    return append(salt, hash...), err
}
```

```php
// PHP - 使用 password_hash（默认 bcrypt）
$hash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);
if (password_verify($input, $hash)) {
    // 认证成功
}
```

### 3.4 JWT 安全使用规范

**漏洞代码：**
```python

from cryptography.hazmat.primitives.asymmetric import rsa

private_key = load_private_key_from_vault()  # 从密钥管理服务获取

# 验证时强制指定算法
try:
```

### 3.5 OAuth 安全集成

```python
# Python - OAuth2 安全集成要点
# 1. 使用 state 参数防 CSRF
# 2. 验证 redirect_uri 白名单
# 3. 使用 PKCE（Proof Key for Code Exchange）

import secrets

# 生成 state 和 PKCE
state = secrets.token_urlsafe(32)
code_verifier = secrets.token_urlsafe(64)
import hashlib, base64
code_challenge = base64.urlsafe_b64encode(
    hashlib.sha256(code_verifier.encode()).digest()
).rstrip(b'=').decode()

# 构造授权 URL
auth_url = f"{auth_server}/authorize?response_type=code&client_id={client_id}" \
           f"&redirect_uri={redirect_uri}&state={state}" \
           f"&code_challenge={code_challenge}&code_challenge_method=S256"
```

### 4.2 对称加密使用规范（AES-GCM）

**漏洞代码：**
```python
# Python - 使用 ECB 模式（最不安全）
from Crypto.Cipher import AES
cipher = AES.new(key, AES.MODE_ECB)  # ECB模式！相同明文产生相同密文
```

**安全代码：**
```python
# Python - AES-GCM（提供加密+认证）
from Crypto.Cipher import AES
import os

key = os.urandom(32)  # AES-256
nonce = os.urandom(12)  # 96位 nonce
cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
ciphertext, tag = cipher.encrypt_and_digest(plaintext)

# 传输：nonce + ciphertext + tag
# 解密时验证 tag 防篡改
cipher_dec = AES.new(key, AES.MODE_GCM, nonce=nonce)
plaintext = cipher_dec.decrypt_and_verify(ciphertext, tag)
```

```go
// Go - AES-GCM
import (
    "crypto/aes"
    "crypto/cipher"
    "crypto/rand"
)

block, _ := aes.NewCipher(key)
gcm, _ := cipher.NewGCM(block)
nonce := make([]byte, gcm.NonceSize())
rand.Read(nonce)
ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)
```

```java
// Java - AES-GCM
import javax.crypto.Cipher;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;

Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
GCMParameterSpec spec = new GCMParameterSpec(128, nonce);  // 128位 tag
cipher.init(Cipher.ENCRYPT_MODE, new SecretKeySpec(key, "AES"), spec);
byte[] ciphertext = cipher.doFinal(plaintext);
```

## 五、文件操作安全

### 5.1 文件上传安全编码

**漏洞代码：**
```python
# Python - 不安全文件上传
@app.route('/upload', methods=['POST'])
def upload():
    file = request.files['file']
    file.save(f'/var/www/uploads/{file.filename}')  # 原始文件名，可路径遍历+任意类型
```

**安全代码：**
```python
import uuid
import os

ALLOWED_EXTENSIONS = {'png', 'jpg', 'jpeg', 'gif', 'pdf'}
MAX_FILE_SIZE = 10 * 1024 * 1024  # 10MB

@app.route('/upload', methods=['POST'])
def upload():
    file = request.files['file']

    # 1. 验证文件大小
    file.seek(0, 2)
    if file.tell() > MAX_FILE_SIZE:
        abort(413)
    file.seek(0)

    # 2. 验证扩展名（白名单）
    ext = file.filename.rsplit('.', 1)[-1].lower() if '.' in file.filename else ''
    if ext not in ALLOWED_EXTENSIONS:
        abort(415)

    # 3. 验证文件内容（Magic Number）
    magic = file.read(8)
    file.seek(0)
    if not is_valid_magic(magic, ext):
        abort(415)

    # 4. 生成随机文件名，避免遍历和覆盖
    safe_name = f"{uuid.uuid4().hex}.{ext}"
    upload_dir = '/var/www/uploads'
    full_path = os.path.join(upload_dir, safe_name)

    # 5. 确保路径安全
    if not os.path.abspath(full_path).startswith(upload_dir):
        abort(403)

    file.save(full_path)
```

```python
# Python Flask - 白名单 CORS
ALLOWED_ORIGINS = {'https://app.example.com', 'https://admin.example.com'}

@app.after_request
def cors(response):
    origin = request.headers.get('Origin')
    if origin in ALLOWED_ORIGINS:

        response.headers['Access-Control-Allow-Credentials'] = 'true'
        response.headers['Access-Control-Allow-Methods'] = 'GET, POST, PUT, DELETE'
```
