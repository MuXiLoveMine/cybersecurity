# 容器与 IaC 安全最佳实践总结

### 8.1 容器安全清单

| 类别 | 检查项 | 优先级 |
|------|-------|-------|
| 镜像安全 | 使用官方精简基础镜像 | 高 |
| 镜像安全 | 固定镜像版本标签 | 高 |
| 镜像安全 | 定期扫描镜像漏洞 | 高 |
| 镜像安全 | 镜像签名验证 | 中 |
| 镜像安全 | 不在镜像中存储密钥 | 高 |
| 运行时安全 | 非 root 用户运行 | 高 |
| 运行时安全 | 只读根文件系统 | 高 |
| 运行时安全 | 丢弃所有 capabilities | 高 |
| 运行时安全 | 启用 Seccomp | 中 |
| 运行时安全 | 资源限制 | 高 |
| 运行时安全 | 运行时安全监控 | 中 |

### 8.2 Kubernetes 安全清单

| 类别 | 检查项 | 优先级 |
|------|-------|-------|
| RBAC | 最小权限配置 | 高 |
| RBAC | 禁止 cluster-admin 过度授权 | 高 |
| Pod Security | Restricted 安全级别 | 高 |
| Pod Security | 禁止特权容器 | 高 |
| 网络安全 | 默认拒绝 Network Policy | 高 |
| 网络安全 | 最小允许网络策略 | 高 |
| 网络安全 | mTLS 服务网格 | 中 |
| 准入控制 | OPA Gatekeeper 策略 | 高 |
| 准入控制 | 镜像签名验证 | 中 |
| 密钥管理 | Vault 动态密钥 | 高 |
| 密钥管理 | 禁止 Secret 明文存储 | 高 |
| 审计 | 启用审计日志 | 高 |
| 监控 | 运行时安全监控(Falco) | 中 |
| 监控 | 安全基准检查(kube-bench) | 中 |

### 8.3 IaC 安全清单

| 类别 | 检查项 | 优先级 |
|------|-------|-------|
| 网络安全 | 安全组最小化规则 | 高 |
| 网络安全 | 禁止 0.0.0.0/0 入站 | 高 |
| 网络安全 | 数据库禁止公网访问 | 高 |
| IAM | 最小权限策略 | 高 |
| IAM | 禁止通配符权限 | 高 |
| 数据保护 | 存储加密 | 高 |
| 数据保护 | 数据库加密 | 高 |
| 数据保护 | 传输加密(TLS) | 高 |
| 密钥管理 | 禁止硬编码密钥 | 高 |
| 密钥管理 | 使用 Vault/KMS | 高 |
| 日志审计 | 启用操作日志 | 中 |
| 资源保护 | 启用删除保护 | 中 |
| IaC扫描 | tfsec/Checkov 扫描 | 高 |

---

> **总结**：容器与 IaC 安全是云原生安全的基石。容器安全需要从镜像构建到运行时全链路防护，Kubernetes 安全需要从集群到工作负载多层防御，IaC 安全需要将安全检查嵌入代码管理流程。关键是通过自动化工具链实现持续安全验证，确保基础设施配置始终符合安全标准。通过"安全即代码"的方式，将安全策略版本化管理、自动化验证、持续监控，才能真正构建安全的云原生生产环境。
