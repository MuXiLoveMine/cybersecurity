# 容器安全概述

### 1.1 容器与虚拟机安全差异

| 特性 | 虚拟机 | 容器 |
|------|-------|------|
| 隔离机制 | 硬件级隔离（Hypervisor） | 进程级隔离（Namespace + Cgroup） |
| 内核共享 | 独立内核 | 共享宿主机内核 |
| 攻击面 | 较小 | 较大（共享内核） |
| 逃逸难度 | 高 | 相对较低 |
| 安全边界 | Hypervisor | 容器运行时 |
| 资源限制 | 硬件隔离 | Cgroup 限制 |
| 网络隔离 | 虚拟网络 | 网络命名空间 |

**容器安全的核心挑战**
- 共享内核：容器共享宿主机内核，内核漏洞可导致逃逸
- 权限提升：容器可能以 root 运行，具有危险 capabilities
- 镜像供应链：第三方镜像可能包含恶意代码或漏洞
- 网络隔离弱：默认情况下容器间网络可互通
- 密钥管理：容器环境中的密钥管理更复杂

### 1.2 容器攻击面分析

```
┌─────────────────────────────────────────────────────────┐
│                   容器攻击面分析                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 容器镜像层                                          │
│     ├─ 基础镜像漏洞（OS 包、基础软件）                   │
│     ├─ 应用依赖漏洞（npm、pip 包）                      │
│     ├─ 恶意镜像（镜像投毒）                             │
│     ├─ 敏感信息泄露（镜像中的硬编码密钥）                 │
│     └─ 镜像篡改（未签名验证）                           │
│                                                         │
│  2. 容器运行时层                                        │
│     ├─ 容器逃逸（privileged 模式）                      │
│     ├─ Capabilities 滥用                               │
│     ├─ 文件系统挂载（敏感目录挂载）                      │
│     ├─ 容器间攻击（网络可达性）                         │
│     └─ 资源耗尽（DoS）                                 │
│                                                         │
│  3. 编排平台层（Kubernetes）                            │
│     ├─ RBAC 配置错误                                   │
│     ├─ API Server 暴露                                 │
│     ├─ etcd 未授权访问                                  │
│     ├─ Dashboard 暴露                                  │
│     ├─ Pod 间网络互通                                  │
│     └─ 准入控制缺失                                    │
│                                                         │
│  4. 供应链层                                            │
│     ├─ CI/CD 流水线安全                                │
│     ├─ 制品仓库安全                                    │
│     ├─ IaC 配置错误                                    │
│     └─ 密钥管理不当                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
