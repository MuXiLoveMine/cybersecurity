# 学习路线

### 阶段 1：工控基础（1-2 个月）
**学习目标**：掌握工业控制系统基础知识

**学习内容**
- 工控系统概述
- 常见工控系统类型（SCADA、DCS、PLC）
- 工控系统架构（Purdue 模型）
- 工业协议基础
- 工业互联网概念
- IT 与 OT 的区别

**实践任务**
- 学习工控系统基础知识
- 了解常见工控设备
- 学习工业协议基础
- 搭建简单的实验环境
- 学习 Wireshark 分析工业协议

### 阶段 2：工控安全基础（2-3 个月）
**学习目标**：掌握工控安全基础知识和防护技术

**学习内容**
- 工控安全风险与挑战
- 工控安全防护体系
- 网络隔离与分区
- 工控防火墙
- 主机安全加固
- 安全监测与审计
- 安全管理体系

**实践任务**
- 学习工控安全标准
- 配置工控防火墙
- 进行主机加固
- 部署工控监测系统
- 学习工控安全评估方法

### 阶段 3：工控漏洞与渗透（3-4 个月）
**学习目标**：掌握工控漏洞挖掘和渗透测试技术

**学习内容**
- 工控漏洞分析
- 工业协议安全
- 协议逆向分析
- 模糊测试
- 工控渗透测试方法
- 工控渗透工具使用
- 著名工控漏洞分析

**实践任务**
- 分析工控漏洞
- 学习协议分析
- 练习模糊测试
- 做工控渗透实验（实验环境）
- 分析著名工控恶意代码

### 阶段 4：工控安全实战（2-3 个月）
**学习目标**：具备工控安全实战能力

**学习内容**
- 工控安全评估
- 工控安全加固
- 工控应急响应
- 工业互联网安全
- 工控安全运营
- 安全态势感知

**实践任务**
- 做完整的工控安全评估
- 制定安全加固方案
- 编写应急预案
- 搭建工控安全实验环境
- 参与工控安全项目

### 阶段 5：深入研究（持续）
**研究方向**
- 工控漏洞挖掘
- 工业协议安全
- 工控恶意代码分析
- 工业互联网安全
- 工控安全产品
- 工控安全标准
