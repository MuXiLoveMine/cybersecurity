# 工控网络分段与微隔离

### 8.1 宏观分段（Zone 级）

宏观分段遵循 IEC 62443 Zones/Conduits 模型，按 Purdue 层级划分：
- L4-L3.5：IT/OT 边界防火墙
- L3.5-L3：工业防火墙 + DMZ
- L3-L2：工业防火墙，启用工控协议 DPI
- L2-L1：二层隔离 + 端口级 ACL
- L1-L0：现场总线级隔离

### 8.2 微隔离（Micro-segmentation）

微隔离将策略细化到单台设备/工作负载级，在工控场景中需特别考虑实时性与协议特殊性：

- 基于 MAC + IP + 端口绑定，禁止任何未注册设备接入
- 白名单化 PLC 通信：仅允许 HMI 到指定 PLC 的指定功能码
- 工程师站默认仅能访问维护网段，访问生产网需审批放行

**Modbus 功能码白名单示例（工业防火墙策略）：**
```
# 工业防火墙 Modbus 功能码白名单策略
# 仅允许 HMI (10.10.20.5) 向 PLC (10.10.30.10) 发起指定功能码

rule name "HMI_to_PLC_ReadOnly"
    source 10.10.20.5
    destination 10.10.30.10
    protocol modbus-tcp
    modbus-function-code 3,4        # 读保持/输入寄存器
    action permit
    log enable

rule name "HMI_to_PLC_WriteCmd"
    source 10.10.20.5
    destination 10.10.30.10
    protocol modbus-tcp
    modbus-function-code 6,16       # 写单/多寄存器
    action permit
    log enable
    time-range maintenance-window   # 仅维护窗口允许写操作

rule name "Block_Dangerous_FC"
    protocol modbus-tcp
    modbus-function-code 5,8,22     # 写线圈/诊断/屏蔽控制
    action deny
    log enable
    alert critical
```

### 8.3 工控协议 DPI 配置示例

以 Suricata 检测 Modbus 异常为例：
```yaml
# Suricata modbus 规则示例
- modbus:
    enabled: yes
    detection-rules:
      - msg: "非法写线圈功能码来自非授权主机"
        function-code: 5
        source-address: [!10.10.20.0/24]
        action: alert
      - msg: "Modbus 诊断功能码（可能用于探测）"
        function-code: 8
        action: alert
      - msg: "写多寄存器触发越界地址"
        function-code: 16
        register-address-range: "<0x0000 or >0x7FFF"
        action: alert
```
