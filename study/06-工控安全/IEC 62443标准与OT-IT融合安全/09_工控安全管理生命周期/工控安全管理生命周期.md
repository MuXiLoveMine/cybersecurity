# 工控安全管理生命周期

### 9.1 生命周期阶段

IEC 62443 强调安全是全生命周期活动，分为以下阶段：

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ 1.规划   │→│ 2.设计   │→│ 3.集成   │→│ 4.运维   │→│ 5.退役   │
│ 风险评估 │  │ 架构设计 │  │ 测试验证 │  │ 监测响应 │  │ 安全擦除 │
│ SL-T设定 │  │ 区域划分 │  │ 安全验收 │  │ 变更管理 │  │ 资产注销 │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
```

### 9.2 关键阶段要求

**规划阶段（Plan）：**
- 完成资产清单与数据流梳理
- 进行威胁建模（参考 ATT&CK for ICS）
- 确定 SL-T，并作为设计输入

**设计阶段（Design）：**
- 区域/管道划分方案
- 选型对照 62443-4-2 的 SL-C 声明
- 编制安全设计基线文档

**集成阶段（Integrate）：**
- 安全功能测试：认证、加密、审计
- 渗透测试与红队演练
- 安全验收报告归档

**运维阶段（Operate）：**
- 持续监测：IDS/日志/SOC
- 变更管理：所有变更经风险评估与审批
- 补丁管理：离线验证 → 维护窗口部署 → 回退预案
- 应急响应：演练、剧本、取证

**退役阶段（Decommission）：**
- 敏感数据擦除（密钥、配方、工艺参数）
- 设备注销与清单更新
- 历史日志归档

### 9.3 变更管理流程示例

```
变更申请 → 风险评估 → 测试验证 → 审批（多级）
   ↓                                        ↓
   ←─────────── 回退预案 ──────────────────┘
                       ↓
             维护窗口内执行 → 监控观察 → 验收关闭
```

> 工控变更管理强调"不测试不上线、不审批不执行、无回退不部署"三大铁律。
