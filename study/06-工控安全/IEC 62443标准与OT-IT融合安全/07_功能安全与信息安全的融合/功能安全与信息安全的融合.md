# 功能安全与信息安全的融合

### 7.1 IEC 61508 与 SIL 等级

功能安全（Functional Safety）关注系统在故障下仍能正确执行安全功能的能力，其核心标准为 IEC 61508，对应工控领域的 IEC 61511（过程工业）。

- **SIL（安全完整性等级）**：衡量安全功能可靠性的等级，SIL1-SIL4
- **PFD（平均危险故障概率）**：低要求模式下的失效概率
- **PFH（每小时危险故障频率）**：高要求/连续模式下的失效率

| SIL | PFD (低要求) | PFH (高要求) | 风险降低因子 |
|-----|--------------|--------------|--------------|
| SIL1 | 10⁻² ~ 10⁻¹ | 10⁻⁶ ~ 10⁻⁵ | ≥10 |
| SIL2 | 10⁻³ ~ 10⁻² | 10⁻⁷ ~ 10⁻⁶ | ≥100 |
| SIL3 | 10⁻⁴ ~ 10⁻³ | 10⁻⁸ ~ 10⁻⁷ | ≥1000 |
| SIL4 | 10⁻⁵ ~ 10⁻⁴ | 10⁻⁹ ~ 10⁻⁸ | ≥10000 |

### 7.2 SIL 与 SL 的关系

两者容易混淆，务必区分：

- **SIL** 衡量"随机硬件故障"下的安全功能可靠性
- **SL** 衡量"网络安全威胁"下的系统防护能力

**融合风险：** 网络攻击可能触发安全功能（如紧急停车 ESD），导致：
1. 攻击者利用网络漏洞触发误停车 → 影响生产连续性
2. 攻击者禁用安全仪表系统（SIS）→ 在真实危险时安全功能失效 → 人身事故

### 7.3 安全功能与网络安全的隔离原则

依据 IEC 61511 和 IEC 62443 的协同实践：

- SIS 应与 BPCS（基本过程控制系统）逻辑、物理分离
- SIS 不应接入互联网或办公网，避免远程攻击面
- SIS 与 BPCS 通信应通过专用安全网关，禁止共用控制器
- 安全功能网络的安全等级 SL-T 应不低于 BPCS

### 7.4 协同安全分析示例

某化工厂反应釜超压保护场景：

```
压力传感器 ──→ SIS PLC ──→ 切断进料阀 (SIL3 安全功能)
     │
     └──→ BPCS DCS ──→ 常规调节阀 (SL2 网络防护)

威胁建模：
  T1: 网络攻击篡改 BPCS 设定值 → 导致压力升高
  T2: 网络攻击禁用 SIS 触发条件 → 安全功能失效
  T3: 物理攻击篡改压力传感器标定 → SIS 与 BPCS 都误判

缓解措施：
  M1: BPCS 网络 SL3 防护，降低 T1 概率
  M2: SIS 网络物理隔离 + SIL3 硬件冗余，降低 T2
  M3: 传感器多样性 + 定期校准，降低 T3
```
