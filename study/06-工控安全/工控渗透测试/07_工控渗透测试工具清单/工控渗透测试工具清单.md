# 工控渗透测试工具清单

### 7.1 信息收集工具

| 工具 | 用途 | 说明 |
|------|------|------|
| Nmap | 端口扫描、服务识别 | 必备，配合 NSE 脚本 |
| Masscan | 高速端口扫描 | 大范围扫描，谨慎使用 |
| Shodan/FOFA/ZoomEye | 网络空间搜索 | OSINT 收集 |
| Wireshark | 抓包分析 | 协议分析必备 |
| tcpdump | 命令行抓包 | 轻量级抓包 |
| Zmap | 互联网扫描 | 大规模资产测绘 |

### 7.2 协议分析工具

| 工具 | 用途 | 说明 |
|------|------|------|
| Wireshark | 协议解析 | 支持多数工控协议 |
| Scapy | 报文构造 | Python 数据包库 |
| Modbus Poll/Slave | Modbus 模拟 | Modbus 测试工具 |
| UA Expert | OPC UA 客户端 | OPC UA 测试 |
| S7 Client | S7 通信测试 | 西门子 PLC 测试 |

### 7.3 漏洞扫描工具

| 工具 | 用途 | 类型 |
|------|------|------|
| Nessus | 综合漏洞扫描 | 商业 |
| OpenVAS/GVM | 开源漏洞扫描 | 开源 |
| 工控专用漏洞扫描器 | 工控漏洞扫描 | 商业（360/启明/绿盟等） |
| 协议 Fuzz 工具 | 协议漏洞挖掘 | Boofuzz 等 |

### 7.4 漏洞利用工具

| 工具 | 用途 | 说明 |
|------|------|------|
| Metasploit | 渗透测试框架 | 有部分工控模块 |
| ISF | 工控渗透框架 | 专门针对工控系统 |
| 自定义 Python 脚本 | 定制化利用 | 根据目标编写 |
| 厂商组态软件 | 官方工具利用 | 工程师站权限后使用 |

### 7.5 逆向分析工具

| 工具 | 用途 | 说明 |
|------|------|------|
| IDA Pro | 反汇编/反编译 | 商业，功能最强 |
| Ghidra | 逆向工程 | 开源，NSA 出品 |
| Binwalk | 固件分析 | 提取固件文件系统 |
| FirmAE | 固件模拟 | 固件仿真运行 |
