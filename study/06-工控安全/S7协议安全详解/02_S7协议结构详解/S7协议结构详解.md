# S7协议结构详解

### 2.1 完整帧结构

S7协议通信的完整帧结构由多层协议封装：

```
完整S7帧结构:

┌─────────────────────────────────────────────────────────────────┐
│ TPKT层 (4字节)                                                  │
├─────────┬───────┬───────────────────────────────────────────────┤
│ Version │ Reserve│ Length (总长度)                               │
│ (1byte) │ (1byte)│ (2bytes)                                      │
│ =0x03   │ =0x00  │                                               │
├─────────┴───────┴───────────────────────────────────────────────┤
│ COTP层 (变长, 通常3-18字节)                                     │
├─────────────────────────────────────────────────────────────────┤
│ S7协议层 (10字节头 + 变长数据)                                  │
├─────────┬─────────┬─────────┬─────────┬──────────┬──────────────┤
│ ProtID  │ ROSCTR  │ Reserve │ PDU Ref │ ParamLen │ DataLen      │
│ (1byte) │ (1byte) │ (2bytes)│ (2bytes)│ (2bytes) │ (2bytes)     │
│ =0x32   │         │         │         │          │              │
├─────────┴─────────┴─────────┴─────────┴──────────┴──────────────┤
│ 参数区 (变长)                                                   │
├─────────────────────────────────────────────────────────────────┤
│ 数据区 (变长)                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 TPKT层

TPKT (Transport Service on top of the TCP) 用于在TCP上封装OSI传输协议：

```
TPKT帧格式:
┌──────────┬──────────┬────────────────────────────┐
│ Version  │ Reserved │ Length                      │
│ (1 byte) │ (1 byte) │ (2 bytes, Big Endian)       │
└──────────┴──────────┴────────────────────────────┘

字段说明:
- Version: 固定为 0x03
- Reserved: 固定为 0x00
- Length: 整个TPKT帧的长度 (包括TPKT头自身)
  最小值: 7 (TPKT=4 + COTP最小=3)
  最大值: 65535

示例: 0x03 0x00 0x00 0x1F -> 长度=31字节
```

### 2.3 COTP层

COTP (ISO 8073) 提供传输层服务，分为多种PDU类型：

```
COTP PDU类型:

1. 连接请求 (Connect Request, CR):
   ┌──────────┬──────────┬───────────┬───────────┬────────┐
   │ Length   │ PDU Type │ Dest Ref  │ Src Ref   │ Class  │
   │ (1byte)  │ (1byte)  │ (2bytes)  │ (2bytes)  │ (1byte)│
   │          │ =0xE0    │           │           │ =0x00  │
   └──────────┴──────────┴───────────┴───────────┴────────┘
   ┌──────────────────────────────────────────────────────────┐
   │ 可变参数区                                                │
   ├────────┬────────┬─────────────────────────────────────────┤
   │ TPDU   │ Param  │ 参数值                                  │
   │ Size   │ Code   │                                          │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC0   │ 0x02   │ Called TSAP (2bytes)                    │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC1   │ 0x02   │ Calling TSAP (2bytes)                   │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC2   │ 0x01   │ TPDU Size (1byte)                       │
   └────────┴────────┴─────────────────────────────────────────┘

   TSAP格式: 0x01 0x00 -> 设备类型/机架/槽号
   TPDU Size: 0x0A=1024, 0x0B=2048, 0x0C=4096, 0x0D=8192

2. 连接确认 (Connect Confirm, CC):
   PDU Type = 0xD0
   格式与CR相同，Dest/Src引用互换

3. 数据传输 (Data Transfer, DT):
   ┌──────────┬──────────┐
   │ Length   │ PDU Type │
   │ =0x02    │ =0xF0    │
   └──────────┴──────────┘
   后接S7协议数据

4. 断开请求 (Disconnect Request, DR):
   PDU Type = 0x80

5. 拒绝 (Reject):
   PDU Type = 0x50
```

### 2.4 S7协议层

```
S7协议头格式 (10字节):

┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ Protocol │ PDU Type │ Reserved │ PDU Ref  │ Param    │ Data     │
│ ID       │ (ROSCTR) │          │          │ Length   │ Length   │
│ (1byte)  │ (1byte)  │ (2bytes) │ (2bytes) │ (2bytes) │ (2bytes) │
│ =0x32    │          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

PDU Type (ROSCTR) 取值:
  0x01 - 请求 (Request)
  0x02 - 确认 (Ack)
  0x03 - 响应数据 (Ack-Data)
  0x04 - 用户数据 (User Data)
  0x05 - 丢弃 (Discard)
  0x06 - 未定义
  0x07 - 未定义
  0x08 - 保留
  0x09 - 保留
  0x0A - 保留
  0x0B - 保留
  0x0C - 保留
  0x0D - 保留
  0x0E - 保留
  0x0F - 保留
  0x10 - 保留
  0x28 - 密码验证 (Password Check)
  0x29 - 密码验证确认

Reserved: 固定为 0x0000

PDU Reference: 递增的序号，用于请求-响应匹配
  范围: 0x0000 - 0xFFFF

Param Length: 参数区长度
Data Length: 数据区长度
```

### 2.5 参数区详解

参数区定义了S7协议的操作类型和参数：

```
参数区结构:

┌──────────┬──────────┬──────────────────────────────────────────┐
│ Func     │ SubFunc/ │ 参数数据                                 │
│ Group    │ ItemSpec │                                          │
│ (1byte)  │ (1byte)  │ (变长)                                   │
└──────────┴──────────┴──────────────────────────────────────────┘

功能组 (Func Group):
  0x00 - 取消
  0x01 - CPU服务
  0x02 - 模块信息
  0x03 - 诊断
  0x04 - 读/写变量
  0x05 - 控制CPU (启停等)
  0x06 - 程序处理
  0x07 - 安全功能
  0x08 - 安全参数设置
  0x09 - 组态/编程
  0x0A - 循环读
  0x0B - 安全通信设置
  0x0C - 接口/模块信息
  0x0D - 文件传输
  0x0E - 组态上传
  0x0F - 安全文件传输
  0x10 - 时间设置
  0x11 - 安全功能

子功能码 (常见):
  读变量: 0x04, 0x01 -> 子功能=0x12 (变量规格)
  写变量: 0x05, 0x01 -> 子功能=0x12 (变量规格)
  CPU启停: 0x28, 0x00 -> 启动 / 0x28, 0x01 -> 停止
  密码验证: 0x28, 0x02 -> 子功能=0x26
```

### 2.6 变量规格 (Variable Specification)

S7协议使用变量规格来寻址PLC内存区域：

```
变量规格格式 (Item结构):

┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ Item     │ Length   │ Syntax   │ Area     │ DB Number│ Address  │
│ Type     │ of Read  │ ID       │ Type     │          │          │
│ (1byte)  │ (1byte)  │ (1byte)  │ (1byte)  │ (2bytes) │ (3bytes) │
│ =0x12    │ =0x0A    │ =0x10    │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

Item Type: 0x12 = 变量
Length of Read: 0x0A = 10字节
Syntax ID: 0x10 = 地址/类型语法

区域类型 (Area Type):
  0x81 - I (过程映像输入区)
  0x82 - Q (过程映像输出区)
  0x83 - M (标志位区)
  0x84 - DB (数据块)
  0x85 - DI (背景数据块)
  0x86 - C (计数器)
  0x87 - T (定时器)
  0x88 - P (外设输入)
  0x89 - P (外设输出)
  0x8A - V (变量存储器, S7-200)

DB Number:
  对于DB/DI区域: 数据块编号 (1-65535)
  对于其他区域: 0

Address:
  字节地址编码为3字节, 实际为字地址*8+位地址
  例如: M10.2 -> 地址 = 10*8 + 2 = 82 -> 0x000052
  例如: DB1.DBW10 -> 地址 = 10*8 = 80 -> 0x000050
```

### 2.7 完整报文示例

```
读取S7-300标志位MW10的完整报文:

TPKT:
03 00 00 1F     版本=3, 长度=31

COTP (数据传输):
02 F0 80        长度=2, 类型=Data(0xF0), EOT=0x80

S7协议头:
32              协议ID=0x32
01              PDU类型=Request(0x01)
00 00           保留
00 01           PDU引用=1
00 0E           参数长度=14
00 00           数据长度=0

参数区:
04              功能组=读变量
01              子功能=1个Item
12 0A 10 01    Item类型=变量, 长度=10, 语法=地址/类型, 传输大小=BYTE
00 08           DB号=8 (假设)
01              区域类型=M(0x83)
00 0A 00        地址=10*8=80=0x000050 -> 这里是按字节编码
00 01           读取长度=1

完整报文 (十六进制):
03 00 00 1F 02 F0 80 32 01 00 00 00 01 00 0E 00 00
04 01 12 0A 10 01 00 08 83 00 0A 00 00 01
```
