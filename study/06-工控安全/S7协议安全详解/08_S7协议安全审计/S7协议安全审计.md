# S7协议安全审计

### 8.1 审计检查清单

```
S7协议安全审计检查清单:

1. 认证安全:
   [ ] PLC是否设置了密码保护?
   [ ] 保护级别是否设置为最高?
   [ ] 密码是否符合复杂度要求?
   [ ] 密码是否定期更换?
   [ ] 是否有密码管理流程?
   [ ] S7-1500是否启用了证书认证?

2. 通信安全:
   [ ] PLC网络是否隔离?
   [ ] 是否使用防火墙限制102端口?
   [ ] 是否部署了IDS/IPS?
   [ ] S7CommPlus加密是否启用?
   [ ] 是否使用VPN进行远程访问?
   [ ] 网络流量是否被监控?

3. 访问控制:
   [ ] 是否限制了可访问PLC的IP?
   [ ] 工程站是否部署了安全措施?
   [ ] 是否有USB管控?
   [ ] 远程访问是否有审计?
   [ ] 是否启用了操作日志?

4. 固件安全:
   [ ] 固件版本是否最新?
   [ ] 是否应用了安全补丁?
   [ ] 固件更新是否有流程?
   [ ] 是否检查固件完整性?

5. 日志审计:
   [ ] 是否启用了诊断缓冲区?
   [ ] 是否配置了远程Syslog?
   [ ] 是否有日志分析流程?
   [ ] 是否检测异常访问模式?

6. 物理安全:
   [ ] PLC机柜是否上锁?
   [ ] 是否限制物理访问?
   [ ] 网络端口是否有标记?
   [ ] 未使用的端口是否禁用?
```
