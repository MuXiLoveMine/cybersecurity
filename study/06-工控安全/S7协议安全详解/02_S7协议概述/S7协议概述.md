# S7协议概述

### 1.1 S7协议简介

S7协议是西门子公司开发的专有通信协议，用于SIMATIC S7系列PLC与编程设备、HMI和SCADA系统之间的通信。S7协议运行在ISO-on-TCP（RFC 1006）之上，使用TCP端口102进行通信。

```
S7协议在协议栈中的位置:

┌─────────────────────────────────────────────┐
│              应用层 (S7 Protocol)            │
├─────────────────────────────────────────────┤
│           ISO-on-TCP (RFC 1006)              │
├─────────────────────────────────────────────┤
│              TCP (端口102)                   │
├─────────────────────────────────────────────┤
│                IP                            │
├─────────────────────────────────────────────┤
│          以太网 / 串行 / PROFIBUS            │
└─────────────────────────────────────────────┘
```

### 1.2 S7协议版本

```
S7协议版本发展:

S7Comm (经典S7协议)
├── 用于 S7-200/300/400 系列
├── 无加密
├── 无认证 (可选密码)
├── 明文传输
└── 端口: 102

S7CommPlus (增强S7协议)
├── 用于 S7-1200/1500 系列
├── 加密通信
├── 强认证
├── 完整性校验
├── 防重放保护
└── 端口: 102

S7CommPlus Drake (进一步增强)
├── S7-1500 V2.5+ 固件
├── 更强的加密算法
├── 证书认证
└── 增强的防重放机制
```

### 1.3 支持的设备

| 设备系列 | 支持协议 | 默认端口 | 认证方式 |
|---------|---------|---------|---------|
| S7-200 | S7Comm | 102 | 无/可选密码 |
| S7-300 | S7Comm | 102 | 无/可选密码 |
| S7-400 | S7Comm | 102 | 无/可选密码 |
| S7-1200 | S7CommPlus | 102 | 密码+保护级别 |
| S7-1500 | S7CommPlus | 102 | 密码+证书 |
| ET 200 | S7Comm | 102 | 无/可选密码 |
| WinCC | S7Comm/Plus | 102 | 应用层认证 |
