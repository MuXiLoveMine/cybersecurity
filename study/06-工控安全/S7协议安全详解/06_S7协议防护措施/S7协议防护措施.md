# S7协议防护措施

### 6.1 访问保护级别

```
Siemens PLC访问保护级别:

保护级别1 (无保护):
- 默认级别
- 任何人都可访问
- 无密码要求

保护级别2 (写保护):
- 需要密码才能写入
- 读取不需要密码
- 密码通过S7协议验证 (弱保护)

保护级别3 (读写保护):
- 需要密码才能读写
- 需要密码才能上传程序
- 需要密码才能停止CPU
- 密码通过S7协议验证

保护级别4 (完整保护) (仅S7-1500):
- 需要密码进行任何操作
- 包括诊断和通信设置
- 使用S7CommPlus强认证

配置方法 (TIA Portal):
1. PLC属性 -> 保护与安全
2. 设置访问级别
3. 设置密码
4. 启用"防止未经授权的访问"

配置方法 (STEP 7 Classic):
1. PLC属性 -> 保护
2. 设置保护级别
3. 设置密码
```

### 6.2 网络安全配置

```
S7协议网络安全防护:

1. 网络分段:
   - 使用防火墙隔离PLC网络
   - 仅允许授权IP访问102端口
   - 使用VLAN进一步隔离
   - 禁止PLC直连互联网

2. 防火墙规则示例 (iptables):
   # 允许工程站访问PLC
   iptables -A INPUT -s 192.168.1.10 -p tcp --dport 102 -j ACCEPT
   
   # 允许SCADA服务器访问
   iptables -A INPUT -s 192.168.1.20 -p tcp --dport 102 -j ACCEPT
   
   # 拒绝其他所有访问
   iptables -A INPUT -p tcp --dport 102 -j DROP
   
   # 记录被拒绝的连接
   iptables -A INPUT -p tcp --dport 102 -j LOG --log-prefix "S7_ACCESS:"

3. Siemens S7-1500 通信负载:
   - 启用"通信负载"限制
   - 限制每秒接受的连接数
   - 防止DoS攻击

4. 网络入侵检测:
   # Suricata规则: 检测未授权S7访问
   alert tcp $EXTERNAL_NET any -> $PLC_NET 102 (
       msg:"Unauthorized S7 Protocol Access";
       content:"|03 00|";
       depth:2;
       content:"|32|";
       depth:8;
       offset:7;
       sid:2000001;
   )
```

### 6.3 S7-1500安全增强

```
S7-1500安全增强功能:

1. 安全通信 (Secure Communication):
   - 启用S7CommPlus加密
   - 使用TLS/SSL封装
   - 证书认证

2. 安全评估工具 (Security Assessment Tool):
   - 检测安全配置缺陷
   - 评估暴露的攻击面
   - 提供修复建议

3. 访问保护:
   - 4级保护级别
   - 基于角色的访问控制
   - 密码策略强制

4. 通信安全:
   - 限制连接速率
   - 防御DoS攻击
   - 连接超时设置

5. 日志审计:
   - 记录所有访问尝试
   - 记录配置变更
   - 记录CPU启停操作
   - 远程Syslog发送

6. 固件安全:
   - 定期固件更新
   - 安全补丁管理
   - 固件完整性校验
```
