# 工控安全管理

### 5.1 安全管理体系

工控安全三分技术、七分管理。完善的管理体系是工控安全的重要保障。

#### 5.1.1 管理制度体系

```
第一层：安全策略（总纲）
  工控安全管理办法、总体方针

第二层：管理制度
  ├── 人员安全管理制度
  ├── 资产安全管理制度
  ├── 网络安全管理制度
  ├── 主机安全管理制度
  ├── 数据安全管理制度
  ├── 运维安全管理制度
  ├── 供应链安全管理制度
  ├── 应急响应管理制度
  └── 培训教育制度

第三层：操作规程
  ├── 日常运维操作规程
  ├── 补丁管理操作规程
  ├── 备份恢复操作规程
  ├── 变更管理操作规程
  ├── 应急处置操作规程
  └── 远程维护操作规程

第四层：记录表单
  ├── 巡检记录表
  ├── 变更申请单
  ├── 备份记录表
  ├── 应急演练记录
  └── 培训记录表
```

#### 5.1.2 组织机构与职责

**组织架构：**
- **信息安全领导小组**：最高决策机构，通常由厂级领导牵头
- **信息安全管理部门**：日常管理工作
- **工控安全专职人员**：负责工控安全具体工作
- **各业务部门**：配合落实安全要求
- **运维团队**：执行安全运维工作

**关键岗位：**
- 工控安全主管
- 工控安全工程师
- 工控系统管理员
- 工控运维工程师
- 安全审计人员

### 5.2 人员管理

#### 5.2.1 人员安全要求

**入职审查：**
- 背景调查
- 安全保密协议
- 岗位安全培训
- 权限最小化分配

**在岗管理：**
- 定期安全教育
- 安全考核
- 权限定期复核
- 离岗审计

**离岗管理：**
- 权限立即回收
- 资产归还
- 工作交接
- 保密承诺延续

#### 5.2.2 第三方人员管理

**风险：**
- 运维服务人员
- 设备厂商工程师
- 集成商人员
- 参观来访人员

**管理措施：**
```
1. 访问审批
   · 第三方人员访问需审批
   · 明确访问范围和时间
   
2. 陪同制度
   · 现场操作需甲方人员陪同
   · 禁止单独操作关键设备
   
3. 设备管理
   · 外来设备需检查登记
   · 优先使用甲方提供的设备
   · 禁止直接接入生产网络
   
4. 操作审计
   · 所有操作全程审计
   · 重要操作需审批
   · 操作记录存档
   
5. 保密协议
   · 签订保密协议
   · 明确保密责任
```

### 5.3 资产管理

#### 5.3.1 资产分类

| 资产类别 | 示例 | 安全等级 |
|----------|------|---------|
| **核心控制设备** | 关键 PLC、DCS 控制器、SIS | 极高 |
| **监控系统** | SCADA 服务器、HMI、工程师站 | 高 |
| **生产管理系统** | MES、历史数据库 | 中高 |
| **网络设备** | 工业交换机、工业防火墙 | 高 |
| **安全设备** | 工控 IDS、审计系统、防火墙 | 高 |
| **现场设备** | 传感器、执行器、仪表 | 中 |
| **数据资产** | 生产数据、配置数据、程序 | 高 |

#### 5.3.2 资产管理要求

- 建立完整的资产台账
- 资产标识唯一可追溯
- 定期资产盘点
- 资产变更记录
- 资产分类分级管理
- 报废资产安全处理

### 5.4 变更管理

工控系统的任何变更都可能影响安全，必须严格管理。

#### 5.4.1 变更类型

| 变更类型 | 示例 | 风险等级 |
|----------|------|---------|
| **硬件变更** | 更换设备、增加设备 | 高 |
| **软件变更** | 安装软件、升级版本 | 高 |
| **配置变更** | 修改参数、调整策略 | 中 |
| **网络变更** | 调整拓扑、修改路由 | 高 |
| **策略变更** | 安全策略调整 | 中 |
| **程序变更** | PLC 程序修改 | 极高 |

#### 5.4.2 变更管理流程

```
变更申请 → 变更评估 → 变更审批 → 变更实施 → 变更验证 → 变更关闭
    ↑          ↑          ↑          ↑          ↑
    │          │          │          │          │
  提交申请   风险评估   分级审批   按方案实施   确认效果
  说明原因   影响分析   签字确认   全程记录   资料归档
```

**关键控制点：**
- 变更前必须评估风险
- 重要变更需有回滚方案
- 变更应在生产低谷期进行
- 变更后需验证功能正常
- 所有变更都要记录归档

### 5.6 备份管理

#### 5.6.1 备份内容

| 备份对象 | 说明 | 备份频率 |
|----------|------|---------|
| PLC 程序 | 控制逻辑程序 | 每次变更后 |
| 组态配置 | HMI/SCADA 组态 | 每次变更后 |
| 系统备份 | 操作系统镜像 | 定期（月/季） |
| 生产数据 | 历史数据、实时数据 | 实时/日备份 |
| 配置文件 | 网络设备、安全设备配置 | 每次变更后 |
| 数据库 | 应用数据库 | 日/周备份 |

#### 5.6.2 备份策略

- **3-2-1 原则**：3 份备份、2 种介质、1 份异地
- 定期备份 + 增量备份
- 备份数据加密存储
- 定期恢复演练
- 备份介质安全管理

### 5.7 远程访问管理

#### 5.7.1 远程访问风险

- 扩大攻击面
- 认证强度不足
- 操作不可控
- 审计困难
- 成为攻击入口

#### 5.7.2 远程访问安全要求

```
1. 专用通道
   · 禁止直接暴露工控端口到互联网
   · 使用 VPN 或专用远程访问网关
   · 双因素认证（必须）
   
2. 严格审批
   · 远程访问必须申请审批
   · 限定访问时间和范围
   · 到期自动关闭
   
3. 全程审计
   · 所有操作录屏/记录
   · 操作日志留存
   · 定期审计检查
   
4. 过程可控
   · 甲方人员全程监督
   · 重要操作需实时确认
   · 可随时中断连接
   
5. 环境隔离
   · 远程访问区与生产区隔离
   · 通过跳板机访问
   · 禁止直接访问控制设备
```

### 5.8 安全培训

#### 5.8.1 培训对象与内容

| 对象 | 培训内容 | 培训频率 |
|------|---------|---------|
| **全员** | 工控安全意识、基本规范 | 每年至少 1 次 |
| **运维人员** | 安全操作规范、应急处置 | 每半年至少 1 次 |
| **安全人员** | 专业技术、最新威胁 | 持续学习 |
| **管理人员** | 安全管理、法规要求 | 每年至少 1 次 |
| **新员工** | 入职安全培训 | 入职时 |
| **第三方人员** | 安全须知 | 每次进场前 |

#### 5.8.2 培训方式

- 课堂培训
- 在线学习
- 应急演练
- 案例分享
- 安全宣传
