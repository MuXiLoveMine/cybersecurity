# 边界防护（工业防火墙/网闸）

### 2.1 边界防护的重要性

网络边界是攻击进入工控系统的第一道防线，也是最重要的防线之一。

**主要边界：**
1. **IT-OT 边界**：企业网与生产网之间的边界
2. **区域边界**：生产管理区与过程监控区之间的边界
3. **单元边界**：不同生产单元之间的边界
4. **对外接口**：远程维护、数据上报等对外连接

### 2.2 工业防火墙

#### 2.2.1 工业防火墙与传统防火墙的区别

| 对比项 | 传统 IT 防火墙 | 工业防火墙 |
|--------|---------------|-----------|
| **设计目标** | 通用网络防护 | 工业环境专用 |
| **协议支持** | TCP/IP、HTTP 等 | 支持 Modbus/S7/Profinet 等工业协议深度解析 |
| **环境适应** | 机房环境 | 工业级（宽温、抗干扰、防尘） |
| **部署方式** | 路由/透明模式 | 支持在线部署、旁路部署 |
| **可靠性** | 一般 | 高可靠（Bypass、冗余） |
| **性能特点** | 吞吐量优先 | 低延迟优先（不影响实时性） |
| **管理方式** | Web/CLI | 支持工业协议管理、图形化策略配置 |

#### 2.2.2 工业防火墙核心功能

**1. 工业协议深度解析（DPI）**
- 支持 Modbus TCP、S7、Profinet、EtherNet/IP、DNP3、IEC 104 等
- 基于协议功能码的访问控制
- 基于寄存器地址/标签的访问控制
- 协议异常检测

**2. 白名单访问控制**
- 基于 IP/MAC 的白名单
- 基于工业协议的白名单
- 基于功能码的白名单
- 默认拒绝，仅允许已知通信

**3. 实时性保障**
- 低延迟转发（微秒级）
- 硬件加速
- 不影响工业控制实时性

**4. 高可靠性**
- 硬件 Bypass（断电直通）
- 双机热备
- 链路冗余

#### 2.2.3 工业防火墙部署位置

```
位置 1：IT-OT 边界（最重要）
  企业网 ─── 工业防火墙 ─── 生产管理网

位置 2：生产管理与监控区边界
  MES区 ─── 工业防火墙 ─── SCADA区

位置 3：关键设备前
  工业网络 ─── 工业防火墙 ─── 关键PLC/控制器

位置 4：远程访问入口
  外部 ─── VPN网关 + 工业防火墙 ─── 工控网络
```

### 2.3 工业网闸（物理隔离装置）

#### 2.3.1 网闸的工作原理

网闸（又称物理隔离装置、正向/反向隔离装置）通过物理断开的方式实现两个网络之间的数据交换，确保不会有直接的网络连接。

```
外网处理单元 ─── 私有协议摆渡 ─── 内网处理单元
            (物理断开，仅数据摆渡)
```

**核心特点：**
- 内外网物理断开
- 仅允许特定格式的数据通过
- 不支持 TCP 连接转发
- 安全性最高，但灵活性低

#### 2.3.2 网闸的类型

**正向隔离装置：**
- 数据只能从内网（生产侧）向外网（管理侧）单向传输
- 用于生产数据上报
- 安全性最高

**反向隔离装置：**
- 数据只能从外网向内网单向传输
- 用于程序下载、参数下发等
- 需要严格的认证和审批

**双向隔离装置：**
- 两个方向各有独立的摆渡通道
- 仍保持物理断开
- 适用于需要双向数据交换的场景

#### 2.3.3 网闸与防火墙的区别

| 对比项 | 工业防火墙 | 网闸（物理隔离） |
|--------|-----------|-----------------|
| 隔离方式 | 逻辑隔离 | 物理隔离 |
| 安全性 | 高 | 极高 |
| 灵活性 | 高 | 低 |
| 协议支持 | 丰富的工业协议 | 仅支持特定数据格式 |
| 实时性 | 好 | 有延迟（摆渡时间） |
| 适用场景 | 区域边界防护 | 高安全等级的跨网数据交换 |

### 2.4 边界防护最佳实践

1. **分层防护**：不要只依赖一道边界防线
2. **默认拒绝**：白名单机制，只允许必要的通信
3. **最小化暴露面**：只开放必要的端口和协议
4. **定期审计**：定期检查边界策略的合理性
5. **冗余设计**：关键边界部署冗余设备
6. **集中管理**：统一管理所有边界设备
