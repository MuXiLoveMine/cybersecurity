# 工控安全建设路线图

### 7.1 分阶段建设建议

#### 阶段一：基础防护（0-6 个月）

**目标：** 建立基本的安全防护能力，堵住明显的安全漏洞。

**重点工作：**
- 资产梳理，摸清家底
- 网络分区，边界隔离
- 工业防火墙部署
- 主机基础加固
- 禁用不必要的服务和端口
- 修改默认/弱口令
- 制定基本管理制度
- 全员安全意识培训

#### 阶段二：体系建设（6-12 个月）

**目标：** 建立较完善的安全防护体系，具备基本的监测和响应能力。

**重点工作：**
- 部署工控安全监测系统
- 部署工控主机防护（白名单）
- 建立安全审计体系
- 完善安全管理制度
- 建立应急响应机制
- 开展定期风险评估
- 建设安全运营团队

#### 阶段三：深度防御（12-24 个月）

**目标：** 纵深防御体系成熟，具备主动防御和态势感知能力。

**重点工作：**
- 建设工控态势感知平台
- 建立威胁情报体系
- 实现安全运营自动化
- 完善纵深防御体系
- 建立供应链安全管理
- 定期开展攻防演练
- 安全与生产深度融合

### 7.2 投资优先级建议

按 ROI（投入产出比）排序：

| 优先级 | 措施 | 说明 |
|--------|------|------|
| 1 | 网络分区与边界隔离 | 最有效、投资相对不高 |
| 2 | 修改弱口令/默认口令 | 零成本，效果明显 |
| 3 | 主机基础加固 | 投入小，收益大 |
| 4 | 工业防火墙 | 重要防线，必要投资 |
| 5 | 安全监测/审计 | 发现威胁，不可缺少 |
| 6 | 应用白名单 | 有效防病毒，工控场景推荐 |
| 7 | 管理制度建设 | 管理提升，长期价值 |
| 8 | 态势感知平台 | 高级阶段，投资较大 |

---

> ⚠️ **结语**：工控安全是一项持续的系统工程，没有一劳永逸的解决方案。需要技术、管理、人员多方面协同，持续改进，才能有效保障工业控制系统的安全。安全的最终目标是保障生产的安全稳定运行，所有安全措施都不能脱离这个根本目标。

  source-address 10.0.0.10/32  # SCADA服务器
  destination-address 192.168.0.100/32  # PLC

  action allow

**Windows 工控主机加固配置（PowerShell）：**
```powershell
# 1. 启用AppLocker白名单（需Windows企业版）
# 创建默认规则
Set-AppLockerPolicy -Default -XmlPolicy "C:\AppLocker\DefaultPolicy.xml"

# 导出当前策略
Get-AppLockerPolicy -Effective -Xml > "C:\AppLocker\CurrentPolicy.xml"

# 导入并强制执行
Set-AppLockerPolicy -XmlPath "C:\AppLocker\ProductionPolicy.xml" -Force

# 2. 禁用不必要的服务
$services = @(
    "RemoteRegistry",      # 远程注册表
    "Telnet",              # Telnet服务
    "FTPSVC",              # FTP服务
    "W3SVC",               # IIS Web服务（如不需要）
    "RemoteDesktopServices", # 远程桌面（如不需要）
    "SSDPSRV",             # SSDP发现
    "upnphost",            # UPnP设备主机
    "lmhosts",             # NetBIOS支持
    "Browser"              # 计算机浏览器
)
foreach ($svc in $services) {
    Stop-Service -Name $svc -Force -ErrorAction SilentlyContinue
    Set-Service -Name $svc -StartupType Disabled -ErrorAction SilentlyContinue
}

# 3. 配置Windows防火墙（入站默认拒绝）
Set-NetFirewallProfile -Profile Domain,Public,Private -DefaultInboundAction Block
Set-NetFirewallProfile -Profile Domain,Public,Private -DefaultOutboundAction Allow

# 允许工控协议入站（按需）
New-NetFirewallRule -DisplayName "Allow Modbus TCP" `
    -Direction Inbound -Protocol TCP -LocalPort 502 -Action Allow

New-NetFirewallRule -DisplayName "Allow S7comm" `
    -Direction Inbound -Protocol TCP -LocalPort 102 -Action Allow

# 4. 禁用不必要的Windows功能
Disable-WindowsOptionalFeature -Online -FeatureName "TelnetClient"
Disable-WindowsOptionalFeature -Online -FeatureName "TFTP"
Disable-WindowsOptionalFeature -Online -FeatureName "MicrosoftWindowsPowerShellV2"

# 5. 账户安全策略
# 设置密码策略
secedit /export /cfg "C:\temp\secpol.cfg"
# 修改密码策略后导入
secedit /configure /db "C:\windows\security\local.sdb" /cfg "C:\temp\secpol.cfg" /areas SECURITYPOLICY
```

**Linux 工控主机加固：**
```bash
# 1. 关闭不必要的服务
systemctl stop telnet.socket
systemctl disable telnet.socket
systemctl stop vsftpd
systemctl disable vsftpd
systemctl stop rpcbind
systemctl disable rpcbind

# 2. 配置iptables防火墙
# 默认策略
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许工控协议端口
iptables -A INPUT -p tcp --dport 502 -s 192.168.0.0/24 -j ACCEPT  # Modbus
iptables -A INPUT -p tcp --dport 102 -s 192.168.0.0/24 -j ACCEPT  # S7

# 允许SSH管理（仅管理网段）
iptables -A INPUT -p tcp --dport 22 -s 10.0.0.0/24 -j ACCEPT

# 3. 禁用root远程登录
sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
systemctl restart sshd

# 4. 文件权限加固
chmod 700 /root
chmod 600 /etc/shadow
chmod 644 /etc/passwd

# 5. 启用审计
auditctl -w /etc/passwd -p wa -k passwd_change
auditctl -w /etc/shadow -p wa -k shadow_change
auditctl -w /sbin/modprobe -p x -k module_load
```

### 二、工控安全配置指南

#### 2.1 网络分段配置最佳实践

**Purdue模型网络分段方案：**
```
Level 5: 企业网 / 云
    │  ↓ 工业防火墙 / DMZ
Level 4: 企业管理区 (ERP, MES)
    │  ↓ 工业防火墙
Level 3.5: DMZ区 (补丁服务器、数据交换)
    │  ↓ 工业防火墙
Level 3: 生产管理区 (SCADA, HMI, 历史数据库)
    │  ↓ 工业防火墙 / 交换机ACL
Level 2: 监控区 (操作员站、工程师站)
    │  ↓ 工业交换机
Level 1: 基础控制区 (PLC, DCS控制器)
    │  ↓ 现场总线
Level 0: 现场设备 (传感器、执行器、驱动器)
```
