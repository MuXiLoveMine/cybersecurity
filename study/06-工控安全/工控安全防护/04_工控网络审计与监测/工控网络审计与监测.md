# 工控网络审计与监测

### 4.1 工控安全监测概述

工控安全监测是指通过技术手段对工控网络的流量、行为、状态进行持续监控，及时发现安全威胁和异常行为。

**与 IT 监测的区别：**
- 工控网络流量相对固定，规律性强
- 重点监测工业协议和控制行为
- 不能影响生产系统的正常运行
- 以旁路监测为主，避免在线风险

### 4.2 工控入侵检测系统（IDS）

#### 4.2.1 工控 IDS 的特点

| 特点 | 说明 |
|------|------|
| **旁路部署** | 不串联在网络中，通过镜像流量监测 |
| **协议识别** | 支持多种工业协议深度解析 |
| **行为基线** | 自学习建立正常行为基线 |
| **异常检测** | 检测偏离基线的异常行为 |
| **实时告警** | 发现威胁实时告警 |
| **低误报率** | 针对工业场景优化，减少误报 |

#### 4.2.2 工控 IDS 检测能力

**1. 协议异常检测**
- 畸形报文检测
- 协议规范违反检测
- 未知功能码检测
- 报文异常检测

**2. 行为异常检测**
- 新设备接入检测
- 异常通信关系检测
- 异常通信频率检测
- 异常数据量检测
- 非常规功能码使用检测

**3. 攻击检测**
- 端口扫描检测
- 漏洞利用检测
- 暴力破解检测
- 已知攻击特征匹配

**4. 操作审计**
- 控制操作记录（写操作、启停操作）
- 参数修改记录
- 程序下载/上传记录
- 配置变更记录

#### 4.2.3 部署方式

```
方式一：端口镜像（最常用）
  交换机镜像端口 ─── 工控 IDS
  优点：不影响网络，部署灵活
  缺点：需要交换机支持镜像功能

方式二：网络分流器（TAP）
  链路 ─── TAP 设备 ─── 工控 IDS
  优点：不依赖交换机，更可靠
  缺点：需要额外硬件，需断网部署

方式三：混合部署
  核心交换机用镜像，关键链路用 TAP
  兼顾成本和可靠性
```

### 4.3 工控安全审计系统

#### 4.3.1 审计对象

| 审计对象 | 审计内容 |
|----------|---------|
| **网络通信审计** | 所有网络访问记录、协议使用、通信关系 |
| **操作行为审计** | 控制操作、参数修改、程序变更 |
| **设备状态审计** | 设备在线状态、配置变更、固件更新 |
| **系统日志审计** | 操作系统日志、应用日志、安全日志 |
| **人员操作审计** | 登录登出、操作记录、权限变更 |

#### 4.3.2 审计日志要求

**日志内容要求：**
- 操作时间（精确到毫秒）
- 操作人员（账号、IP、终端）
- 操作类型（读/写/配置/管理）
- 操作对象（设备、寄存器、参数）
- 操作结果（成功/失败/异常）
- 原始数据（请求和响应报文）

**日志存储要求：**
- 日志存储时间不少于 6 个月
- 重要系统不少于 1 年
- 日志防篡改（只读存储、哈希校验）
- 日志备份策略

### 4.4 工控态势感知

#### 4.4.1 什么是态势感知

工控安全态势感知是指在一定时空条件下，对工控系统安全状态的感知、理解和预测。

**三个层次：**
1. **感知**：知道当前发生了什么（数据采集和展示）
2. **理解**：理解发生的事情意味着什么（关联分析和研判）
3. **预测**：预测接下来会发生什么（趋势分析和预警）

#### 4.4.2 态势感知平台功能

```
┌─────────────────────────────────────────────────────────┐
│                    态势感知与展示层                       │
│  总览大屏 / 安全态势 / 威胁地图 / 趋势分析 / 报表         │
├─────────────────────────────────────────────────────────┤
│                    分析与研判层                           │
│  关联分析 / 威胁建模 / 风险评估 / 事件研判 / 溯源分析     │
├─────────────────────────────────────────────────────────┤
│                    数据采集与处理层                       │
│  流量采集 / 日志采集 / 资产采集 / 漏洞采集 / 威胁情报     │
└─────────────────────────────────────────────────────────┘
```

**核心能力：**
- 全网资产可视化
- 安全威胁实时监测
- 安全事件智能分析
- 攻击路径溯源
- 风险量化评估
- 安全趋势预测

### 4.5 监测技术发展趋势

1. **AI/ML 赋能**：机器学习用于异常检测和威胁识别
2. **威胁情报驱动**：基于工控威胁情报提升检测能力
3. **资产指纹化**：建立设备指纹库，精准识别资产
4. **行为建模**：建立正常行为模型，检测异常
5. **协同联动**：监测与防护设备联动响应
