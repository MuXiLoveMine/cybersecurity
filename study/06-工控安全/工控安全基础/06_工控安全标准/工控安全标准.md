# 工控安全标准

### 6.1 国际标准

#### 6.1.1 IEC 62443 系列标准

IEC 62443 是国际电工委员会制定的工业控制系统安全标准，是目前最权威、最系统的工控安全标准体系。

**标准结构：**

| 部分 | 编号 | 名称 | 内容 |
|------|------|------|------|
| 第1部分 | IEC 62443-1-1 | 术语、概念和模型 | 定义工控安全的基本概念 |
| | IEC 62443-1-2 | 术语和缩略语 | 术语表 |
| | IEC 62443-1-3 | 系统安全合规性度量 | 安全合规性评估方法 |
| 第2部分 | IEC 62443-2-1 | 资产所有者的安全管理体系 | 企业级安全管理要求 |
| | IEC 62443-2-3 | 补丁管理 | 工控系统补丁管理指南 |
| | IEC 62443-2-4 | 服务提供商的安全管理 | 服务提供商安全要求 |
| 第3部分 | IEC 62443-3-1 | 安全技术和系统要求 | 安全技术要求 |
| | IEC 62443-3-2 | 安全等级和目标 | 安全等级划分（SL1-SL4） |
| | IEC 62443-3-3 | 系统安全要求和安全等级 | 系统级安全要求 |
| 第4部分 | IEC 62443-4-1 | 产品开发生命周期 | 安全开发生命周期要求 |
| | IEC 62443-4-2 | 组件的技术安全要求 | 产品级安全要求 |

**安全等级（Security Level, SL）：**
- **SL0**：无特殊安全要求
- **SL1**：防止偶然或无意的违规访问
- **SL2**：防止使用简单手段的故意攻击
- **SL3**：防止使用复杂手段的故意攻击
- **SL4**：防止使用高级持续威胁（APT）的攻击

#### 6.1.2 NIST SP 800-82

美国国家标准技术研究院（NIST）发布的《工业控制系统安全指南》。

**主要内容：**
- 工控系统概述和特点
- 工控系统威胁和漏洞
- 工控安全控制措施
- 工控安全架构
- 与 IT 安全的区别
- 推荐的安全实践

#### 6.1.3 ISA-99 / IEC 62443 关系

ISA-99 是国际自动化学会制定的工控安全标准，后来与 IEC 合作，演变为 IEC 62443 系列。两者内容基本一致。

### 6.2 国内标准

#### 6.2.1 等保 2.0（GB/T 22239-2019）

**工控扩展要求**是等保 2.0 的重要组成部分，在基本要求基础上增加了工控系统特有的安全要求。

**工控扩展要求主要内容：**

| 层面 | 主要要求 |
|------|----------|
| **安全物理环境** | 电子门禁、视频监控、防盗窃防破坏、电磁防护 |
| **安全通信网络** | 安全分区、网络专用、横向隔离、纵向认证 |
| **安全区域边界** | 边界防护、访问控制、入侵防范、可信验证 |
| **安全计算环境** | 身份鉴别、访问控制、安全审计、入侵防范、恶意代码防范、数据完整性/保密性 |
| **安全建设管理** | 方案设计、产品采购、工程实施、测试验收、服务供应商 |
| **安全运维管理** | 环境管理、资产管理、介质管理、设备管理、漏洞和风险管理、应急处置 |

**核心要求：**
1. **安全分区**：根据业务特点和安全需求划分安全区域
2. **网络专用**：工业控制网络独立建设，与其他网络隔离
3. **横向隔离**：不同安全区域之间采用隔离技术
4. **纵向认证**：上下级控制中心之间采用认证加密技术

#### 6.2.2 GB/T 32919-2016

《信息安全技术 工业控制系统安全控制应用指南》

**主要内容：**
- 工控系统安全控制框架
- 8 大类 35 项安全控制措施
- 覆盖管理、技术、工程等方面
- 提供了控制措施的选择和应用指南

#### 6.2.3 GB/T 30976-2014

《工业控制系统信息安全防护指南》

**防护要点：**
- 安全配置
- 边界防护
- 入侵检测
- 恶意代码防范
- 安全审计
- 备份与恢复
- 应急响应
