# 工控系统架构（Purdue 模型）

### 2.1 Purdue 模型层级详解

Purdue 模型（普渡模型）是工业控制系统的经典参考架构，将工业企业网络划分为不同层级，每层具有不同的功能和安全要求。

```
Level 5 ─────────────────────────────────────────────────
         │                 互联网
Level 4 ─────────────────────────────────────────────────
         │              企业层（ERP / 办公网）
         │           ┌─────────────────────┐
         │           │ 企业资源计划(ERP)   │
         │           │ 办公自动化系统      │
         │           │ 邮件 / 文件服务     │
         │           └─────────────────────┘
Level 3.5 ──────────── DMZ 区 ───────────────────────────
         │         （工业隔离区 / 非军事区）
         │           ┌─────────────────────┐
         │           │ 工业防火墙          │
         │           │ 数据交换服务器      │
         │           │ 远程访问网关        │
         │           └─────────────────────┘
Level 3 ─────────────────────────────────────────────────
         │            生产管理层（MES / 历史库）
         │           ┌─────────────────────┐
         │           │ 制造执行系统(MES)   │
         │           │ 实时历史数据库      │
         │           │ 生产调度系统        │
         │           └─────────────────────┘
Level 2 ─────────────────────────────────────────────────
         │             监控层（SCADA / HMI）
         │           ┌─────────────────────┐
         │           │ SCADA 服务器        │
         │           │ HMI 操作站          │
         │           │ 工程师站            │
         │           │ OPC 服务器          │
         │           └─────────────────────┘
Level 1 ─────────────────────────────────────────────────
         │             控制层（PLC / DCS 控制器）
         │           ┌─────────────────────┐
         │           │ PLC / DCS 控制器    │
         │           │ 安全控制器(SIS)     │
         │           │ 运动控制器          │
         │           └─────────────────────┘
Level 0 ─────────────────────────────────────────────────
         │            现场设备层（传感器 / 执行器）
         │           ┌─────────────────────┐
         │           │ 传感器              │
         │           │ 执行器              │
         │           │ 智能仪表            │
         │           │ 变频器 / 电机       │
         │           └─────────────────────┘
```

### 2.2 各层级详细说明

#### Level 0 - 物理层 / 现场设备层

**功能：** 直接与生产过程交互，感知物理量并执行控制指令

**设备类型：**
- 传感器：温度、压力、流量、液位、位移等
- 执行器：阀门、电机、继电器、变频器
- 智能仪表：具有通信功能的测量仪表
- 现场总线设备：连接到现场总线的各类设备

**安全特点：**
- 设备资源极其有限，计算能力弱
- 通常无法安装安全软件
- 物理接触可能导致安全问题
- 协议简单，几乎没有安全机制

#### Level 1 - 控制层

**功能：** 直接控制工业过程，运行控制逻辑

**设备类型：**
- PLC（可编程逻辑控制器）
- DCS 控制站 / 控制器
- RTU（远程终端单元）
- 安全控制器 / SIS 控制器
- 运动控制器、数控系统（CNC）

**安全特点：**
- 实时性要求极高（毫秒级响应）
- 运行专用实时操作系统
- 使用专用工业协议通信
- 固件更新困难，漏洞长期存在

#### Level 2 - 监控层

**功能：** 监视和控制生产过程，提供人机交互界面

**设备类型：**
- SCADA 服务器 / DCS 操作站
- HMI（人机界面）工作站
- 工程师站（编程组态）
- OPC 服务器
- 报警服务器

**安全特点：**
- 运行 Windows 操作系统居多
- 常年不更新补丁
- 使用工业专用软件
- 是攻击的重点目标（跳板）

#### Level 3 - 生产管理层

**功能：** 生产调度、质量管理、过程优化

**设备类型：**
- MES（制造执行系统）
- 实时历史数据库（如 PI、InfoPlus）
- 生产调度系统
- 实验室信息管理系统（LIMS）
- 工业云平台边缘节点

**安全特点：**
- 连接控制层和企业层
- 存储大量敏感生产数据
- 是横向移动的关键区域

#### Level 3.5 - DMZ 区（工业隔离区）

**功能：** 生产网与企业网之间的隔离缓冲区

**设备类型：**
- 工业防火墙
- 网闸 / 正向反向隔离装置
- 数据交换服务器
- 远程访问 VPN 网关
- 补丁服务器 / 更新服务器

**安全特点：**
- 是 IT 与 OT 的边界
- 安全防护最严格的区域
- 通常实施严格的访问控制

#### Level 4 - 企业层

**功能：** 企业级资源管理和办公

**设备类型：**
- ERP 系统（SAP、Oracle 等）
- 办公自动化系统
- 邮件服务器、文件服务器
- 企业办公终端

**安全特点：**
- 典型的 IT 环境
- 与互联网连接
- 是攻击进入工控系统的跳板

### 2.3 网络分区与防护原则

根据等保 2.0 工控扩展要求和行业实践，工控网络防护遵循以下原则：

```
┌─────────────────────────────────────────────────────────┐
│                    企业网络（IT 区）                     │
└────────────────────────┬────────────────────────────────┘
                         │ 工业防火墙 / 网闸
┌────────────────────────┴────────────────────────────────┐
│                    生产管理区（Level 3）                 │
│  MES / 历史数据库 / 生产调度                             │
└────────────────────────┬────────────────────────────────┘
                         │ 工业防火墙
┌────────────────────────┴────────────────────────────────┐
│                    过程监控区（Level 2）                 │
│  SCADA / HMI / 工程师站 / OPC 服务器                    │
└────────────────────────┬────────────────────────────────┘
                         │ 工业交换机
┌────────────────────────┴────────────────────────────────┐
│                    现场控制区（Level 1/0）               │
│  PLC / 控制器 / 传感器 / 执行器                          │
└─────────────────────────────────────────────────────────┘
```

**防护原则（十六字方针）：**
- **安全分区**：按功能和安全等级划分区域
- **网络专用**：工控网络独立建设，不与办公网混用
- **横向隔离**：不同区域之间实施隔离措施
- **纵向认证**：上下层之间通信需要认证
