# DNP3 协议

### 3.1 DNP3 协议概述

DNP3（Distributed Network Protocol 3）是电力系统中广泛使用的通信协议，主要用于 SCADA 系统与远程终端单元（RTU）之间的通信。

**特点：**
- 设计用于恶劣通信环境（高误码率、低带宽）
- 支持主站-从站模式（Master-Outstation）
- 支持多种传输介质（串行、TCP、UDP）
- 具有时间同步和事件数据传输机制
- 支持安全认证（可选）

**应用行业：**
- 电力系统（配电自动化、变电站）
- 水务系统（泵站、管网）
- 石油天然气（管线监控）
- 交通信号控制

### 3.2 DNP3 帧结构

**数据链路层帧：**

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 起始字节 │ 长度     │ 控制字段 │ 目的地址 │ 源地址   │
│ 0x05 0x64│ (1 字节) │ (1 字节) │ (2 字节) │ (2 字节) │
├──────────┴──────────┴──────────┴──────────┴──────────┤
│ 数据区 (可变)                                         │
├───────────────────────────────────────────────────────┤
│ CRC 校验 (每 16 字节数据一个 CRC)                     │
└───────────────────────────────────────────────────────┘
```

**起始字节：** 固定为 `0x05 0x64`

**控制字段（FCV/FCB/功能码）：**
```
bit 7: 保留
bit 6: FCB (Frame Count Bit) - 帧计数位
bit 5: FCV (Frame Count Valid) - 帧计数有效位
bit 4-0: 功能码
```

### 3.3 DNP3 功能码

| 功能码 | 主站→从站 | 从站→主站 | 名称 |
|--------|----------|----------|------|
| 0 | 是 | - | 确认（ACK） |
| 1 | 是 | - | 读（Read） |
| 2 | 是 | - | 写（Write） |
| 3 | 是 | - | 选择（Select） |
| 4 | 是 | - | 操作（Operate） |
| 5 | 是 | - | 直接操作（Direct Operate） |
| 6 | 是 | - | 直接操作（无应答） |
| 7 | 是 | - | 冻结命令 |
| 8 | 是 | - | 冻结并清除 |
| 9 | 是 | - | 冻结带时间 |
| 10 | 是 | - | 冷重启 |
| 11 | 是 | - | 热重启 |
| 12 | 是 | - | 停止应用 |
| 13 | 是 | - | 保存配置 |
| 14 | 是 | - | 启用/禁用自发报告 |
| 15 | 是 | - | 延迟测量 |
| - | - | 129 | 响应（Response） |
| - | - | 130 | 自发响应（Unsolicited Response） |

### 3.4 DNP3 数据对象

DNP3 定义了丰富的数据对象类型：

| 组号 | 对象类型 | 说明 |
|------|---------|------|
| 组 1 | 二进制输入 | 开关量输入状态 |
| 组 2 | 二进制输入事件 | 开关量变化事件 |
| 组 3 | 双位二进制输入 | 两位开关量 |
| 组 10 | 二进制输出 | 控制继电器输出块 |
| 组 11 | 二进制输出命令 | 控制输出命令 |
| 组 20 | 模拟输入 | 模拟量测量值 |
| 组 21 | 模拟输入事件 | 模拟量变化事件 |
| 组 30 | 模拟输入（浮点） | 浮点型模拟量 |
| 组 40 | 模拟输出 | 模拟输出（设定值） |
| 组 41 | 模拟输出命令 | 模拟输出命令 |
| 组 50 | 时间和日期 | 时间同步 |
| 组 70 | 文件传输 | 文件操作 |
| 组 80 | 内部指示位 | 设备状态指示 |
| 组 120-127 | 安全认证 | 安全相关功能 |

### 3.5 DNP3 安全机制

DNP3 v5 增加了安全认证机制（Secure Authentication）：

**功能：**
- 基于挑战-应答的认证机制
- 使用 HMAC-SHA1/SHA256
- 支持密钥管理
- 支持用户权限管理

**安全对象组：**
- 组 120：认证查询
- 组 121：认证挑战
- 组 122：认证回复
- 组 123：密钥状态
- 组 124：密钥配置
- 组 125：用户统计
- 组 126：认证命令

**实际情况：**
- 很多现场设备不启用安全认证
- 安全认证增加了配置复杂度
- 老旧设备不支持 DNP3 v5

### 3.6 DNP3 安全风险

**1. 安全认证可选**
- 很多部署未启用安全认证
- 默认配置不安全
- 攻击者可直接发送控制命令

**2. 明文传输**
- 数据和命令明文传输
- 可被窃听和篡改
- 无加密机制

**3. 控制命令风险**
- 写操作可直接控制输出
- 可操作断路器、阀门等设备
- 可能造成严重后果

**4. 已知漏洞**
- DNP3 实现栈的各种漏洞
- 畸形报文导致拒绝服务
- 缓冲区溢出漏洞
