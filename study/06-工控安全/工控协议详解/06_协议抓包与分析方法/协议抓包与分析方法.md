# 协议抓包与分析方法

### 6.1 Wireshark 抓包分析

Wireshark 是最常用的网络协议分析工具，支持大多数工业协议的解析。

#### 6.1.1 常用工控协议过滤器

| 协议 | 显示过滤器 | 说明 |
|------|-----------|------|
| Modbus TCP | `modbus` | 显示所有 Modbus TCP 报文 |
| Modbus TCP | `modbus.func_code == 3` | 过滤功能码 03（读保持寄存器） |
| Modbus TCP | `tcp.port == 502` | 按端口过滤 |
| S7comm | `s7comm` | 显示 S7 协议报文 |
| S7comm | `s7comm.param.func == 0x04` | 过滤 S7 读操作 |
| S7comm-plus | `s7comm_plus` | 显示 S7+ 协议 |
| Profinet | `pn_io` | 显示 Profinet IO |
| DNP3 | `dnp3` | 显示 DNP3 报文 |
| IEC 104 | `iec104` | 显示 IEC 104 报文 |
| IEC 104 | `iec104.typeid == 45` | 过滤单点命令 |
| OPC UA | `opcua` | 显示 OPC UA 报文 |
| EtherNet/IP | `enip` | 显示 EtherNet/IP |
| FINS | `fins` | 显示欧姆龙 FINS 协议 |
| MELSEC | `melsec` | 显示三菱 MC 协议 |

#### 6.1.2 抓包分析步骤

**步骤 1：准备工作**
- 安装 Wireshark
- 确保网卡支持混杂模式
- 获取镜像端口（交换机端口镜像）或使用 TAP 设备
- 工控网络中注意不要影响生产

**步骤 2：开始抓包**
```
1. 选择正确的网卡
2. 开始抓包
3. 可以先设置捕获过滤器减少数据量
   - 示例：host 192.168.1.100 and tcp port 502
```

**步骤 3：协议分析**
```
1. 使用显示过滤器过滤目标协议
2. 查看报文结构和内容
3. 分析通信流程（请求/响应模式）
4. 提取关键数据（寄存器值、控制命令等）
5. 识别异常通信行为
```

**步骤 4：数据分析**
- 统计通信模式（周期/事件）
- 识别设备地址和功能
- 分析数据变化规律
- 检测异常和攻击行为

#### 6.1.3 Wireshark 工控协议分析技巧

**1. 跟踪 TCP 流**
- 右键报文 → Follow → TCP Stream
- 查看完整的通信交互过程
- 分析会话内容

**2. I/O Graph 统计**
- Statistics → I/O Graph
- 查看流量变化趋势
- 发现异常流量峰值

**3. 对话统计**
- Statistics → Conversations
- 查看设备间通信关系
- 识别异常通信对

**4. 导出数据**
- File → Export Packet Dissections
- 导出为 CSV/JSON 进行进一步分析

### 6.2 Scapy 协议分析

Scapy 是 Python 的数据包操作库，可以用于构造和解析工业协议报文。

**安装：**
```bash
pip install scapy
```

**Modbus TCP 报文构造示例：**
```python
from scapy.all import *
from scapy.contrib.modbus import *

# 构造 Modbus TCP 读保持寄存器请求
# 功能码 0x03，读取 40001 开始的 10 个寄存器
pkt = IP(dst="192.168.1.100")/TCP(dport=502)/ModbusADU()/ModbusPDU03ReadHoldingRegisters(
    startAddr=0x0000,  # 起始地址 0 (对应 40001)
    quantity=10        # 读取 10 个寄存器
)

# 发送并接收响应
resp = sr1(pkt, timeout=2)
if resp and resp.haslayer(ModbusPDU03ReadHoldingRegisters):
    print(f"寄存器值: {resp[ModbusPDU03ReadHoldingRegisters].registerVal}")
```

### 6.3 协议逆向分析方法

对于未知或专有协议，可以通过以下方法进行逆向分析：

#### 6.3.1 流量分析

**方法：**
1. 抓包收集正常通信数据
2. 对比不同操作的报文差异
3. 识别报文头部和数据字段
4. 推断字段含义和边界

**技巧：**
- 修改一个变量，观察报文变化
- 发送相同请求，对比响应
- 分析周期性数据的变化规律

#### 6.3.2 文档分析

**信息来源：**
- 厂商技术手册
- 协议规范文档
- SDK/API 文档
- 专利文件
- 学术论文

#### 6.3.3 固件分析

**方法：**
- 提取设备固件
- 逆向分析固件中的协议实现
- 查找协议字符串和常量
- 分析协议处理函数

**工具：**
- Binwalk：固件提取
- IDA Pro / Ghidra：反汇编反编译
- FirmAE：固件模拟

#### 6.3.4 模糊测试

**方法：**
- 构造各种变异的报文
- 发送给目标设备
- 观察设备响应和异常
- 发现协议处理漏洞

**工具：**
- Boofuzz：协议模糊测试框架
- AFL：通用模糊测试
- 自定义 Fuzz 脚本
