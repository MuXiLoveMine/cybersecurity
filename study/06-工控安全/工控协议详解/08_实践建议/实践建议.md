# 实践建议

### 8.1 学习路径

1. **从 Modbus 开始**：最简单、最通用，容易理解
2. **学习 S7 协议**：西门子设备应用广泛，资料较多
3. **深入电力协议**：DNP3、IEC 104 等电力行业协议
4. **学习 OPC UA**：新一代协议，安全机制完善
5. **协议逆向**：学习未知协议的分析方法

### 8.2 实践环境

- **Modbus 模拟器**：Modbus Poll / Modbus Slave
- **PLC 模拟器**：PLCSIM Advanced、各种开源模拟器
- **OPC UA 服务器/客户端**：UA Expert、open62541
- **抓包工具**：Wireshark（必须）
- **编程工具**：Python + Scapy

### 8.3 安全提示

- 协议分析务必在测试环境中进行
- 不要对真实生产设备进行模糊测试
- 工控协议攻击可能导致严重后果
- 学习协议安全是为了防护，不是攻击

### 一、Modbus 协议分析工具与命令速查表

#### 1.1 Modbus 扫描与探测工具

**nmap NSE 脚本扫描：**
```bash
# 扫描Modbus TCP设备（端口502）
nmap -p 502 --script modbus-discover <目标IP>

# 获取Modbus设备信息
nmap -p 502 --script modbus-discover,modbus-info <目标IP>

# 读取保持寄存器（功能码03）
nmap -p 502 --script modbus-holdings-registers <目标IP>

# 读取输入寄存器（功能码04）
nmap -p 502 --script modbus-input-registers <目标IP>

# 读取线圈状态（功能码01）
nmap -p 502 --script modbus-coils <目标IP>

# 读取离散输入（功能码02）
nmap -p 502 --script modbus-discrete-inputs <目标IP>
```

**Python pymodbus 库操作：**
```python
from pymodbus.client import ModbusTcpClient

# 连接Modbus TCP设备
client = ModbusTcpClient('192.168.1.100', port=502)
client.connect()

# 读取保持寄存器（功能码03）- 地址0开始，读取10个寄存器
result = client.read_holding_registers(address=0, count=10, slave=1)
print("保持寄存器值:", result.registers)

# 读取输入寄存器（功能码04）
result = client.read_input_registers(address=0, count=5, slave=1)
print("输入寄存器值:", result.registers)

# 写入单个寄存器（功能码06）
client.write_register(address=0, value=1234, slave=1)

# 写入多个寄存器（功能码16）
client.write_registers(address=0, values=[100, 200, 300], slave=1)

# 读取线圈（功能码01）
result = client.read_coils(address=0, count=8, slave=1)
print("线圈状态:", result.bits)

# 写入单个线圈（功能码05）
client.write_coil(address=0, value=True, slave=1)

client.close()
```

#### 1.2 Modbus RTU 串口通信

```bash
# 使用 modpoll 工具（Windows/Linux）进行RTU通信
# 读取保持寄存器，串口COM3，波特率9600，从站地址1
modpoll -m rtu -a 1 -r 0 -c 10 -b 9600 -p none COM3

# Modbus TCP 读取
modpoll -m tcp -a 1 -r 0 -c 10 192.168.1.100
```

### 二、S7 协议分析工具与命令速查表

#### 2.1 Snap7 工具集

**安装 Snap7：**
```bash
# Ubuntu/Debian
sudo apt install snap7

# Python 绑定
pip install python-snap7
```

**s7client 命令行工具：**
```bash
# 连接并读取S7 PLC数据
s7_client 192.168.0.1 -get DB1.DBD0  # 读取数据块1的双字
s7_client 192.168.0.1 -get DB1.DBW0  # 读取数据块1的字
s7_client 192.168.0.1 -get DB1.DBB0  # 读取数据块1的字节

# 写入数据
s7_client 192.168.0.1 -set DB1.DBW0=1234

# 读取输入/输出
s7_client 192.168.0.1 -get I0.0      # 读取输入
s7_client 192.168.0.1 -get Q0.0      # 读取输出
s7_client 192.168.0.1 -get M0.0      # 读取位存储
```

**Python Snap7 操作示例：**
```python
import snap7

# 连接PLC
client = snap7.client.Client()
client.connect('192.168.0.1', 0, 1)  # IP, rack, slot

# 检查连接状态
print("PLC状态:", client.get_cpu_state())
print("PLC信息:", client.get_cpu_info())

# 读取数据块DB1的前100字节
data = client.db_read(1, 0, 100)
print("DB1数据:", data.hex())

# 解析数据
from snap7.util import *
value = get_real(data, 0)      # 从偏移0读取REAL（浮点数）
int_val = get_int(data, 4)     # 从偏移4读取INT
dint_val = get_dint(data, 6)   # 从偏移6读取DINT
bool_val = get_bool(data, 10, 0)  # 从偏移10的第0位读取BOOL

# 写入数据块
client.db_write(1, 0, data)

# 读取输入（I区）
input_data = client.read_area(snap7.types.Areas.PE, 0, 0, 10)

# 读取输出（Q区）
output_data = client.read_area(snap7.types.Areas.PA, 0, 0, 10)

# 读取位存储区（M区）
merker_data = client.read_area(snap7.types.Areas.MK, 0, 0, 10)

client.disconnect()
```

### 三、DNP3 协议分析工具与命令速查表

#### 3.1 DNP3 工具与库

**安装 opendnp3：**
```bash
# 从源码编译
git clone https://github.com/dnp3/opendnp3.git
cd opendnp3 && mkdir build && cd build
cmake .. && make && sudo make install

# Python 绑定
pip install pydnp3
```

**dnp3-master 命令行工具：**
```bash
# 连接DNP3从站并读取数据
dnp3-master --tcp 192.168.1.100:20000 --outstation 1

# 读取类0数据（静态数据）
> scan class 0

# 读取类1/2/3事件数据
> scan class 1
> scan class 2
> scan class 3

# 发送控制命令
> control select 10
> control operate 10
```

#### 3.2 Python DNP3 操作示例

```python
from pydnp3 import opendnp3, openpal

class DNP3MasterApplication(opendnp3.IMasterApplication):
    def __init__(self):
        super().__init__()
    
    def OnReceiveIIN(self, iin):
        print(f"IIN字段: {iin}")
    
    def OnTaskComplete(self, info):
        print(f"任务完成: {info.result}")

# 创建DNP3管理器
manager = opendnp3.DNP3Manager(1)

# 创建TCP通道
channel = manager.AddTCPClient(
    "client",
    opendnp3.levels.NOTHING,
    opendnp3.ChannelRetry().Default(),
    ["192.168.1.100:20000"],
    "0.0.0.0"
)

# 配置主站
config = opendnp3.MasterStackConfig()
config.master.responseTimeout = openpal.TimeDuration().Seconds(5)
config.link.LocalAddr = 1
config.link.RemoteAddr = 10

# 创建主站
app = DNP3MasterApplication()
master = channel.AddMaster("master", app, opendnp3.PrintingSOEHandler(), config)
master.Enable()

# 执行扫描
scan = master.AddClassScan(
    opendnp3.ClassField.AllClasses(),
    openpal.TimeDuration().Minutes(5)
)
scan.Demand()
```

### 六、Python Scapy 工控协议构造

#### 6.1 Modbus TCP 数据包构造

```python
from scapy.all import *
from scapy.contrib.modbus import *

# 构造Modbus TCP读保持寄存器请求
pkt = IP(dst="192.168.1.100")/TCP(dport=502)/ModbusADU()/ModbusPDU03ReadHoldingRegisters(
    startAddr=0,
    quantity=10
)

# 发送并接收响应
resp = sr1(pkt, timeout=2)
if resp and resp.haslayer(ModbusPDU03ReadHoldingRegistersPayload):
    print("寄存器值:", resp[ModbusPDU03ReadHoldingRegistersPayload].registerVal)

# 构造写单个寄存器请求
pkt_write = IP(dst="192.168.1.100")/TCP(dport=502)/ModbusADU()/ModbusPDU06WriteSingleRegister(
    registerAddr=0,
    registerValue=1234
)
send(pkt_write)
```

#### 6.2 S7comm 数据包构造

```python
from scapy.all import *
from scapy.contrib.s7 import *

# 构造S7comm连接请求
pkt = IP(dst="192.168.0.1")/TCP(dport=102)/COTP()/S7()
send(pkt)

# 构造S7读数据请求
read_pkt = IP(dst="192.168.0.1")/TCP(dport=102)/COTP()/S7(
    pdu_type=1,  # 数据请求
    param=S7ParameterReadVar() / S7VarRequestParameterItem(
        address=S7AddressAny(
            area=0x84,  # DB区
            db_number=1,
            start=0,
            length=10
        )
    )
)
```
