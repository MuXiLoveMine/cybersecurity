# Siemens S7 协议分析

### 2.1 S7 协议概述

S7 协议是西门子（Siemens）S7 系列 PLC 的通信协议，广泛应用于工业自动化领域。

**协议家族：**

| 协议 | 全称 | 适用设备 | 传输层 |
|------|------|---------|--------|
| S7comm (S7 Basic) | S7 Communication | S7-200/300/400 | TCP 102 端口 |
| S7comm-plus | S7 Communication Plus | S7-1200/1500 | TCP 102 端口 |
| S7 Protocol (ISO-on-TCP) | - | 所有 S7 系列 | RFC1006 (ISO over TCP) |

**端口号：** TCP 102（ISO-on-TCP / RFC1006）

### 2.2 S7 协议栈结构

S7 协议采用多层封装结构：

```
┌─────────────────────────────────────────┐
│           S7 PDU (S7 协议数据单元)      │ ← 应用层
├─────────────────────────────────────────┤
│           COTP (ISO 8073)               │ ← 会话层
├─────────────────────────────────────────┤
│           ISO-on-TCP (RFC1006)          │ ← 表示层封装
├─────────────────────────────────────────┤
│           TCP (端口 102)                │ ← 传输层
├─────────────────────────────────────────┤
│           IP / Ethernet                 │ ← 网络层/链路层
└─────────────────────────────────────────┘
```

### 2.3 ISO-on-TCP (RFC1006) 头

```
┌──────────┬──────────┬─────────────────┐
│ 版本     │ 保留     │ 长度             │
│ (1 字节) │ (1 字节) │ (2 字节)         │
└──────────┴──────────┴─────────────────┘
```

- 版本：固定为 0x03
- 保留：固定为 0x00
- 长度：整个 TPKT 包的长度（包括头部）

### 2.4 COTP 头

```
┌──────────┬──────────┬──────────┐
│ 长度     │ PDU 类型 │ 字段     │
│ (1 字节) │ (1 字节) │ (可变)   │
└──────────┴──────────┴──────────┘
```

**常见 PDU 类型：**
- 0xE0：连接请求（CR - Connect Request）
- 0xD0：连接确认（CC - Connect Confirm）
- 0xF0：数据（DT - Data）
- 0x80：断开请求（DR - Disconnect Request）

### 2.5 S7 PDU 结构

S7 数据报文的头部结构：

```
┌──────────────┬──────────────┬──────────────┐
│ 协议标识     │ 消息类型     │ 保留         │
│ (1 字节)     │ (1 字节)     │ (2 字节)     │
├──────────────┼──────────────┼──────────────┤
│ PDU 参考     │ 参数长度     │ 数据长度     │
│ (2 字节)     │ (2 字节)     │ (2 字节)     │
├──────────────┴──────────────┴──────────────┤
│ 参数区 (Parameter)                         │
├────────────────────────────────────────────┤
│ 数据区 (Data)                              │
└────────────────────────────────────────────┘
```

**关键字段：**

| 字段 | 说明 |
|------|------|
| 协议标识 | 固定为 0x32 |
| 消息类型 | 0x01=请求, 0x02=响应, 0x03=用户数据 |
| PDU 参考 | 请求/响应匹配标识 |
| 参数长度 | 参数区长度 |
| 数据长度 | 数据区长度 |

### 2.6 常用 S7 功能（Function Code）

| 功能码 | 名称 | 说明 |
|--------|------|------|
| 0x04 | 读变量（Read Var） | 读取数据块/输入/输出/存储器 |
| 0x05 | 写变量（Write Var） | 写入数据块/输入/输出/存储器 |
| 0x00 | 设置通信（Setup） | 协商 PDU 大小 |
| 0x1A | 读 SZL（系统状态列表） | 读取系统信息 |
| 0x28 | 块功能 | 上传/下载程序块 |
| 0x29 | PLC 控制 | 启动/停止 PLC |
| 0xF0 | 编程器通信 | 编程、调试功能 |

### 2.7 S7 通信流程示例

**建立连接 → 读取数据的完整流程：**

```
客户端 (HMI/编程器)                    服务器 (PLC)
     │                                     │
     ├────── TCP 三次握手 ────────────────▶│
     │                                     │
     ├────── CR (连接请求) ───────────────▶│
     │  ISO-on-TCP + COTP CR               │
     │                                     │
     │◀───── CC (连接确认) ────────────────┤
     │  ISO-on-TCP + COTP CC               │
     │                                     │
     ├────── Setup Communication ─────────▶│
     │  S7 功能码 0x00                     │
     │  协商 PDU 大小                      │
     │                                     │
     │◀───── Setup 响应 ───────────────────┤
     │                                     │
     ├────── Read Var 请求 ───────────────▶│
     │  S7 功能码 0x04                     │
     │  读取 DB1.DBW0 (1个数据字)          │
     │                                     │
     │◀───── Read Var 响应 ────────────────┤
     │  返回数据值 0x1234                   │
     │                                     │
     ├────── TCP 关闭 ────────────────────▶│
```

### 2.8 读取数据块（Read Var）详解

**请求报文参数区：**
```
功能码: 0x04
条目数: 0x01 (读取 1 个变量)

地址说明 (每个变量 12 字节):
  规范类型: 0x12 (ANY 类型)
  语法类型: 0x10 (S7 基本类型)
  长度:     0x00 0x02 (2 字节 = 1 个字)
  地址类型: 0x84 (数据块 DB)
  DB号:    0x00 0x01 (DB1)
  起始地址: 0x00 0x00 0x00 (偏移 0 字节)
```

**地址类型码：**
- 0x81：输入区（I）
- 0x82：输出区（Q）
- 0x83：存储器区（M）
- 0x84：数据块（DB）
- 0x1D：计数器（C）
- 0x1C：定时器（T）

### 2.9 S7 协议安全风险

**1. 弱认证或无认证**
- S7-200/300/400 基本没有认证机制
- S7-1200/1500 虽有认证机制，但存在已知绕过漏洞
- 知道 IP 地址就可以读写 PLC 数据

**2. 明文传输**
- 所有数据和指令明文传输
- 抓包即可获取程序、数据、密码
- 可被中间人篡改

**3. 程序上传下载风险**
- 攻击者可以上传恶意程序到 PLC
- 可以下载 PLC 中的程序进行分析
- 可以修改控制逻辑

**4. PLC 启停控制**
- 可以远程将 PLC 切换到 STOP 模式
- 导致生产线停机
- 严重影响生产

**5. 已知漏洞**
- CVE-2019-13944：S7-1200/1500 认证绕过
- CVE-2020-15782：S7-1200/1500 内存损坏
- CVE-2022-38465：S7-1200/1500 拒绝服务
