# BlackEnergy分析

### 6.1 概述

BlackEnergy最初是一个通用的银行木马工具包，后来被改造用于攻击工控系统，特别是乌克兰电力设施。

```
BlackEnergy演变:
- 2007年: 最初版本作为银行木马
- 2014年: 被改造用于工控攻击 (BlackEnergy 2)
- 2015年: 攻击乌克兰电力 (BlackEnergy 3)
- 2016年: 继续针对乌克兰

攻击链:
1. 鱼鱼邮件 -> 感染办公网络
2. 横向移动 -> 进入工控网络
3. 窃取凭据 -> 获取SCADA访问权限
4. 远程操作 -> 断开断路器
5. 擦除数据 -> 破坏恢复能力
6. 电话轰炸 -> 阻止用户报修
```
