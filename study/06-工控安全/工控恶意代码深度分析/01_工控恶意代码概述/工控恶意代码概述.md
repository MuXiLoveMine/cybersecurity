# 工控恶意代码概述

### 1.1 工控恶意代码的发展历程

工控恶意代码的发展经历了从概念验证到实战部署、从单点到系统化的演进过程：

```
工控恶意代码时间线:
┌──────────┬─────────────────────────────────────────────────────┐
│ 2003     │ 性能最差 - 通用蠕虫首次影响SCADA系统                   │
│ 2007     │ 乌鲁木齐水厂攻击 - 首次针对ICS的网络攻击              │
│ 2010     │ Stuxnet - 首个针对PLC的恶意代码，里程碑事件            │
│ 2011     │ Duqu - 信息窃取工具，Stuxnet的"表亲"                  │
│ 2012     │ Flame - 复杂的信息窃取平台                            │
│ 2013     │ Havex - 针对工控系统的后门                            │
│ 2014     │ BlackEnergy - 针对能源行业的攻击                      │
│ 2015     │ 乌克兰电网攻击 - 首次成功攻击电网                      │
│ 2016     │ Industroyer - 专为破坏电网设计                       │
│ 2017     │ Triton - 首个针对SIS的恶意代码                        │
│ 2018     │ VPNFilter - 感染路由器，可用于工控网络                 │
│ 2020     │ EKANS - 首个工控针对性勒索软件                        │
│ 2022     │ Industroyer2 - 针对乌克兰电网的新变体                 │
│ 2024+    │ AI增强型工控攻击工具出现                              │
└──────────┴─────────────────────────────────────────────────────┘
```

| 特征 | 传统IT恶意代码 | 工控恶意代码 |

| 传播方式 | 大规模传播 | 精确定向传播 |
| 潜伏期 | 短 | 长期潜伏 |
| 技术复杂度 | 中等 | 极高 |

| 影响范围 | 数字资产 | 物理安全 |
