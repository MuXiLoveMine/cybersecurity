# Duqu分析

### 3.1 概述

Duqu发现于2011年9月，与Stuxnet共享大量代码，但攻击目的不同。Duqu以信息窃取为目标，收集工控系统设计图纸和配置信息，为后续攻击做准备。

```
Duqu基本信息:
- 发现时间: 2011年9月
- 首次释放: 约2009年
- 目标: 中东和欧洲的工控系统供应商
- 攻击目的: 信息窃取，为攻击者提供情报
- 与Stuxnet关系: 共享代码框架，同一开发组织
- C2通信: 使用独特的协议和加密
- 代码体积: 约100KB (不含配置)
```

### 3.2 技术特征

```
Duqu技术特征:

1. 模块化架构:
   - 核心: 轻量级后门
   - 插件: 按需加载功能模块
   - 配置: 动态C2配置更新

2. 信息收集:
   - 屏幕截图
   - 键盘记录
   - 文件搜索 (特定工控文件)
   - 网络拓扑映射
   - 凭据窃取

3. C2通信:
   - 使用HTTP/HTTPS伪装
   - 自定义加密协议
   - C2服务器伪装为图片服务器
   - 使用JPEG文件作为数据载体

4. 持久化:
   - 使用零日漏洞 (CVE-2011-3402)
   - 内核驱动rootkit
   - 通过计划任务保持持久

5. 目标筛选:
   - 仅在特定环境激活
   - 自动检测工控软件
   - 非目标环境自清除
```

### 3.3 Duqu与Stuxnet对比

| 维度 | Stuxnet | Duqu |
|------|---------|------|
| 目标 | 物理破坏 | 信息窃取 |
| 目标行业 | 核浓缩设施 | 多个行业 |
| 传播方式 | 激进传播 | 精确投放 |
| PLC交互 | 直接攻击PLC | 不直接攻击PLC |
| C2通信 | 有 | 有，更隐蔽 |
| 代码共享 | 是 | 是 |
| 零日漏洞 | 4+个 | 2+个 |
| 影响 | 物理破坏 | 数据泄露 |
