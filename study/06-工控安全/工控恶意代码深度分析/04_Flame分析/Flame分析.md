# Flame分析

### 4.1 概述

Flame (又名Flamer, sKyWIper) 是2012年5月发现的高级间谍软件，代码体积极大，功能极为复杂。它针对中东地区，特别是伊朗的能源设施和政府机构。

```
Flame基本信息:
- 发现时间: 2012年5月
- 首次释放: 约2010年
- 目标: 伊朗、以色列、巴勒斯坦、苏丹、叙利亚等
- 代码体积: 约20MB (极大)
- 开发语言: C++, C, Lua脚本
- 攻击目的: 全面的间谍活动
- 与Stuxnet关系: 共享部分代码 (同一方程式组织)
```

### 4.2 技术特征

```
Flame功能模块:

1. 信息收集模块:
   ├── 屏幕截图 (定时捕获)
   ├── 键盘记录
   ├── 麦克风录音
   ├── 蓝牙设备发现
   ├── 网络流量嗅探
   ├── 文件搜索和上传
   └── 剪贴板监控

2. 传播模块:
   ├── USB传播
   ├── 局域网传播
   ├── 打印机漏洞传播 (MS10-061)
   ├── 利用LNK漏洞 (与Stuxnet相同)
   └── Flame专有传播 (伪造Windows Update)

3. C2通信模块:
   ├── HTTP/HTTPS
   ├── SSH
   ├── 蓝牙
   └── 伪装为Windows Update (伪造MU)

4. 反检测模块:
   ├── 多种加密 (多次加密数据)
   ├── 反虚拟机
   ├── 反沙箱
   └── 代码混淆

5. 独特功能:
   ├── 蓝牙信标 (用于物理追踪)
   ├── 网络接口MAC修改
   ├── 自定义数据库 (SQLite)
   ├── Lua脚本引擎 (动态功能加载)
   └── 加密命名 (使用游戏术语)
```

### 4.3 独特的C2机制

Flame使用极其独特的C2通信机制：

```
Flame C2通信流程:

1. 信标阶段:
   客户端 -> C2服务器: HTTP请求 (伪装为浏览器)
   请求中包含加密的感染信息

2. 配置更新:
   C2服务器 -> 客户端: 加密的配置文件
   包含新的C2地址和攻击参数

3. 数据上传:
   客户端 -> C2服务器: 加密的数据包
   使用自研加密算法 (多轮XOR + 位移)

4. 命令执行:
   C2服务器 -> 客户端: Lua脚本
   客户端在内部Lua引擎中执行

5. 伪造Windows Update:
   客户端 -> 局域网: 广播伪造的MU消息
   其他机器看到"有更新"并连接到Flame的伪MU服务器
   通过仿冒数字签名验证传播
```
