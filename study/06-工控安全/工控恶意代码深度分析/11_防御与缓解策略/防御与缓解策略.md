### 11.3 加固检查清单

```
工控系统安全加固检查清单:

1. 网络安全:
   [ ] IT/OT网络物理或逻辑隔离
   [ ] 防火墙配置白名单规则
   [ ] 禁止工控网络直连互联网
   [ ] 网络分段 (VLAN)
   [ ] DMZ部署数据收集服务器
   [ ] 网络入侵检测系统部署
   [ ] 流量监控和异常告警

2. 主机安全:
   [ ] 工程站/HMI安全基线配置
   [ ] 禁用不必要的服务
   [ ] 安装安全补丁
   [ ] 防病毒/EDR部署
   [ ] USB设备管控
   [ ] 应用白名单
   [ ] 审计日志启用

3. PLC/控制器安全:
   [ ] 启用访问保护
   [ ] 设置通信密码
   [ ] 禁用调试接口
   [ ] 固件版本更新
   [ ] 安全配置备份
   [ ] PLC程序完整性校验

4. 访问控制:
   [ ] 强密码策略
   [ ] 账户锁定策略
   [ ] 双因素认证 (远程访问)
   [ ] 最小权限分配
   [ ] 定期权限审查
   [ ] 访问日志审计

5. 数据安全:
   [ ] SCADA数据备份
   [ ] PLC程序备份
   [ ] 配置文件备份
   [ ] 备份离线存储
   [ ] 备份完整性验证
   [ ] 恢复流程演练

6. 应急准备:
   [ ] 应急响应预案
   [ ] 联系人清单
   [ ] 手动操作流程
   [ ] 安全事件演练
   [ ] 取证工具准备
   [ ] 隔离方案准备
```
