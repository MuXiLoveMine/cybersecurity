# 漏洞挖掘工具详解

### 6.1 AFL (American Fuzzy Lop)

AFL是一款基于覆盖率的模糊测试工具，通过遗传算法优化输入变异策略。

```bash
# 安装AFL
apt-get install afl

# 编译目标程序 (启用插桩)
# 方法1: 直接使用afl-gcc
afl-gcc -o target target.c

# 方法2: 使用LLVM模式 (更快)
afl-clang-fast -o target target.c

# 运行模糊测试
# -i: 输入目录 (种子文件)
# -o: 输出目录 (发现的结果)
# -m: 内存限制 (MB)
# -t: 超时 (ms)
# -T: 指定主题名称

afl-fuzz -i input/ -o output/ -m 512 -t 1000 -T "Modbus-Parser" ./target @@

# 并行模糊测试 (多核)
afl-fuzz -i input/ -o output/ -m 512 -t 1000 -M master -- ./target @@
afl-fuzz -i input/ -o output/ -m 512 -t 1000 -S slave1 -- ./target @@
afl-fuzz -i input/ -o output/ -m 512 -t 1000 -S slave2 -- ./target @@

# AFL持久模式 (提高速度)
# 在目标代码中添加:
# __AFL_INIT();  // 延迟初始化
# while (__AFL_LOOP(1000)) {
#     // 解析输入
# }

# 结果分析
afl-whatsup output/          # 查看状态
afl-showmap -o trace.txt ./target input_file  # 查看覆盖路径
afl-tmin -i crash -o min_crash ./target       # 最小化crash

# 工控协议解析器的AFL集成
# 需要将协议解析器编译为接受stdin输入的独立程序
# 然后用AFL对解析器进行模糊测试
```

### 6.2 Peach Fuzzer

Peach是支持基于生成和基于变异的模糊测试框架，通过XML配置定义协议模型。

```xml
<!-- Peach Modbus协议模糊测试配置 -->
<?xml version="1.0" encoding="utf-8"?>
<Peach xmlns="http://peachfuzzer.com/2012/Peach"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://peachfuzzer.com/2012/Peach ../peach.xsd"
       author="ICS Security Researcher" version="1.0.0">

  <!-- 数据模型定义 -->
  <DataModel name="ModbusTCP">
    <!-- TPKT头 -->
    <Number name="Version" size="8" value="3" />
    <Number name="Reserved" size="8" value="0" />
    <Number name="Length" size="16" />
    
    <!-- MBAP头 -->
    <Number name="TransactionID" size="16" />
    <Number name="ProtocolID" size="16" value="0" />
    <Number name="Length" size="16" />
    <Number name="UnitID" size="8" value="1" />
    
    <!-- PDU -->
    <Number name="FunctionCode" size="8" />
    <Blob name="Data" />
  </DataModel>

  <!-- 状态模型定义 -->
  <StateModel name="ModbusState" initialState="Initial">
    <State name="Initial">
      <Action type="output">
        <DataModel ref="ModbusTCP" />
      </Action>
      <Action type="input">
        <DataModel ref="ModbusTCP" />
      </Action>
    </State>
  </StateModel>

  <!-- 测试代理 -->
  <Agent name="ModbusAgent" location="tcp://127.0.0.1:9001">
    <Monitor class="SocketAgent">
      <Param name="Host" value="192.168.1.100" />
      <Param name="Port" value="502" />
    </Monitor>
    <Monitor class="Process">
      <Param name="Command" value="./modbus_server" />
      <Param name="RestartOn" value="true" />
    </Monitor>
  </Agent>

  <!-- 测试用例 -->
  <Test name="ModbusFuzzTest">
    <Agent ref="ModbusAgent" />
    <StateModel ref="ModbusState" />
    <Publisher class="tcp.Tcp">
      <Param name="Host" value="192.168.1.100" />
      <Param name="Port" value="502" />
    </Publisher>
    <Strategy class="Sequential" />
    <Mutator class="Standard" />
  </Test>

</Peach>
```

```bash
# 运行Peach模糊测试
peach ModbusFuzz.xml

# 使用不同策略
peach -t ModbusFuzz.xml --strategy random
peach -t ModbusFuzz.xml --strategy sequential

# 并行运行
peach -t ModbusFuzz.xml --parallel 4 --job 1
```

### 6.3 ScadaBR

ScadaBR是开源的SCADA/HMI系统，可用于搭建测试环境。

```bash
# 安装ScadaBR (Docker方式)
docker run -d \
  --name scadabr \
  -p 8080:8080 \
  -v scadabr_data:/opt/scadabr/data \
  scadabr/scadabr:latest

# 配置Modbus数据源
# 1. 访问 http://localhost:8080/ScadaBR
# 2. 默认凭据: admin/admin
# 3. 数据源 -> 添加数据源
# 4. 选择类型: Modbus IP
# 5. 配置IP地址和端口
# 6. 添加数据点 (寄存器地址、功能码等)

# API接口用于自动化测试
# 获取数据源列表
curl -u admin:admin http://localhost:8080/ScadaBR/api/datasource/getAll
```
