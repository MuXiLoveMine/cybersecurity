# 工控安全事件概述

### 1.1 工控安全事件的特殊性

工控安全事件与传统IT安全事件在影响范围、响应优先级和处置方法上存在显著差异：

```
工控安全事件特殊性:

1. 物理影响:
   - IT事件: 数据丢失/泄露
   - OT事件: 可能导致人员伤亡、环境灾难、设备损坏
   
2. 响应优先级:
   - IT: 保护数据 > 恢复服务 > 取证调查
   - OT: 保障安全 > 稳定运行 > 恢复服务 > 取证调查
   
3. 恢复复杂度:
   - IT: 重装系统/恢复备份
   - OT: 需要验证PLC程序/校准传感器/测试联锁
   
4. 取证约束:
   - IT: 可以关机取证
   - OT: 不能随意关机, 可能导致危险工艺失控
   
5. 时间约束:
   - IT: 通常允许数小时到数天
   - OT: 必须在分钟到小时内控制影响
```

### 1.2 事件影响评估框架

```
工控安全事件影响评估矩阵:

┌──────────────┬──────────┬──────────┬──────────┬──────────┐
│ 影响维度      │ 轻微     │ 中等     │ 严重     │ 灾难性   │
├──────────────┼──────────┼──────────┼──────────┼──────────┤
│ 人员安全      │ 无影响   │ 轻伤可能 │ 重伤可能 │ 死亡可能 │
│ 环境影响      │ 无排放   │ 小量泄漏 │ 大量泄漏 │ 灾难性   │
│ 设备损坏      │ 无损坏   │ 可修复   │ 部分报废│ 大面积   │
│ 生产中断      │ <1小时   │ 1-4小时  │ 4-24小时│ >24小时  │
│ 经济损失      │ <10万    │ 10-100万 │ 100-千万│ >千万    │
│ 数据泄露      │ 内部     │ 有限外部 │ 大范围  │ 敏感工艺 │
│ 声誉影响      │ 无       │ 行业内   │ 媒体报道│ 公众关注│
└──────────────┴──────────┴──────────┴──────────┴──────────┘
```
