# 应急响应流程

### 4.1 ICS应急响应生命周期

```
工控安全应急响应六步法:

┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 1. 准备 │ --> │ 2. 识别 │ --> │ 3. 隔离 │ --> │ 4. 根除 │
│Prepare │      │Identify │      │ Contain│      │Eradicate│
└─────────┘     └─────────┘     └─────────┘     └─────────┘
                                                      │
┌─────────┐     ┌─────────┐                           │
│ 6. 经验 │ <-- │ 5. 恢复 │ <─────────────────────────┘
│ Lessons │     │ Recover │
└─────────┘     └─────────┘
```

```
事件识别流程:

┌─────────────────────────────────────────────────────────┐
│ 1. 告警/报告来源                                          │
│    ├── IDS/IPS告警                                       │

│    ├── 维护人员发现                                       │

│    └── 外部通报                                          │
├─────────────────────────────────────────────────────────┤
│ 2. 初始评估                                              │
│    ├── 确认事件真实性                                    │

│    ├── 确定事件类型                                      │

├─────────────────────────────────────────────────────────┤

│    ├── P1-紧急: 威胁人员/环境安全                       │

```

### 4.4 隔离阶段

```
OT环境隔离策略:

原则: 先保障物理安全, 再隔离网络, 最后根除威胁

隔离层次:
┌─────────────────────────────────────────────────────────┐
│ Level 1: 物理隔离 (最高优先级)                          │
│  - 如有物理危险: 立即启动紧急停机 (E-Stop)              │
│  - 切断危险源 (阀门/电源)                               │
│  - 疏散人员                                             │
│  - 通知应急服务 (119/120)                              │
├─────────────────────────────────────────────────────────┤
│ Level 2: 网络隔离                                       │
│  - 断开IT/OT连接                                       │
│  - 隔离受影响网段 (VLAN隔离)                           │
│  - 阻断恶意IP (防火墙规则)                             │
│  - 暂停远程访问 (VPN断开)                              │
│  注意: 评估断网对生产的影响                             │
├─────────────────────────────────────────────────────────┤
│ Level 3: 设备隔离                                       │
│  - 断开受感染工程站                                     │
│  - 禁用受影响PLC的通信                                  │
│  - 切换到手动操作模式                                   │
│  - 启用备用系统                                         │
├─────────────────────────────────────────────────────────┤
│ Level 4: 数据隔离                                       │
│  - 冻结数据库                                           │
│  - 停止数据采集                                         │
│  - 保存当前状态快照                                     │
│  - 防止数据进一步泄露                                   │
└─────────────────────────────────────────────────────────┘
```

```python
#!/usr/bin/env python3
"""工控安全事件隔离决策工具"""
import sys

class ICSContainmentAdvisor:
    """帮助决策隔离策略"""
    
    def __init__(self):
        self.questions = []
        self.answers = {}
    
    def assess_and_recommend(self, incident_type, physical_risk, 
                             network_isolated, production_status):
        """评估并推荐隔离策略"""
        recommendations = []
        
        # 1. 物理安全评估
        if physical_risk:
            recommendations.append({
                'priority': 'P1-紧急',
                'action': '立即启动紧急停机 (E-Stop)',
                'detail': '存在物理安全风险, 优先保障人员安全',
                'steps': [
                    '1. 按下紧急停止按钮',
                    '2. 疏散危险区域人员',
                    '3. 通知应急服务 (119)',
                    '4. 切断危险源',
                    '5. 等待安全确认后再进行其他操作',
                ]
            })
        
        # 2. 网络隔离
        if not network_isolated:
            if incident_type in ['malware', 'ransomware', 'apt']:
                recommendations.append({
                    'priority': 'P2-高',
                    'action': '立即隔离IT/OT网络连接',
                    'detail': '恶意代码可能跨网络传播',
                    'steps': [
                        '1. 在防火墙上阻断IT/OT之间的所有连接',
                        '2. 禁用远程访问VPN',
                        '3. 隔离受感染的工程站',
                        '4. 在IDS/IPS上启用紧急阻断规则',
                        '5. 记录隔离操作和时间',
                    ]
                })
            
            if incident_type == 'dos':
                recommendations.append({
                    'priority': 'P2-高',
                    'action': '阻断攻击源IP',
                    'detail': 'DoS攻击需要阻断来源',
                    'steps': [
                        '1. 识别攻击源IP (从IDS日志)',
                        '2. 在防火墙上阻断攻击IP',
                        '3. 在上游路由器实施速率限制',
                        '4. 联系ISP协助',
                    ]
                })
        
        # 3. PLC保护
        if incident_type in ['malware', 'unauthorized_access']:
            recommendations.append({
                'priority': 'P2-高',
                'action': '保护PLC和控制器',
                'detail': '防止PLC程序被篡改',
                'steps': [
                    '1. 断开非必要的PLC网络连接',
                    '2. 切换到手动操作模式 (如可行)',
                    '3. 锁定PLC编程接口',
                    '4. 增加PLC访问监控',
                    '5. 准备PLC程序备份用于验证',
                ]
            })
        
        # 4. 生产决策
        if production_status == 'affected':
            recommendations.append({
                'priority': 'P3-中',
                'action': '启动生产应急程序',
                'detail': '生产已受影响, 需要恢复或维持',
                'steps': [
                    '1. 评估是否可安全维持部分生产',
                    '2. 切换到手动操作或备用系统',
                    '3. 通知调度部门调整生产计划',
                    '4. 通知供应链和客户',
                ]
            })
        
        return recommendations

# 使用示例
if __name__ == '__main__':
    advisor = ICSContainmentAdvisor()
    
    # 模拟事件评估
    recommendations = advisor.assess_and_recommend(
        incident_type='malware',
        physical_risk=False,
        network_isolated=False,
        production_status='normal'
    )
    
    print("=" * 60)
    print("工控安全事件隔离建议")
    print("=" * 60)
    
    for rec in recommendations:
        print(f"\n[{rec['priority']}] {rec['action']}")
        print(f"  原因: {rec['detail']}")
        print(f"  步骤:")
        for step in rec['steps']:
            print(f"    {step}")
```

### 4.5 根除阶段

```
根除阶段任务:

1. 威胁清除:
   ├── 清除恶意代码
   │   ├── 隔离受感染设备
   │   ├── 使用AV/EDR扫描
   │   ├── 手动清除恶意文件/注册表
   │   └── 验证清除效果
   │
   ├── 修复漏洞
   │   ├── 应用安全补丁
   │   ├── 修复配置缺陷
   │   ├── 更新默认密码
   │   └── 加固网络规则
   │
   ├── 清除后门
   │   ├── 检查隐藏账户
   │   ├── 检查计划任务
   │   ├── 检查服务/驱动
   │   └── 检查启动项
   │
   └── 恢复配置
       ├── 恢复被修改的防火墙规则
       ├── 恢复被修改的PLC配置
       ├── 恢复被禁用的安全控制
       └── 恢复正常网络路由

2. 根除验证:
   ├── 确认恶意代码已清除
   ├── 确认后门已移除
   ├── 确认漏洞已修复
   ├── 确认配置已恢复
   └── 进行全面安全扫描

注意:
- 根除前确保证据已保全
- 根除操作需要记录
- 某些根除可能需要停机
- 根除后需要监控是否复发
```
