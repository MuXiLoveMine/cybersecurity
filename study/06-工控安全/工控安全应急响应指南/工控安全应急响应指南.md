## 1. 工控安全事件概述

### 1.1 工控安全事件的特殊性

工控安全事件与传统IT安全事件在影响范围、响应优先级和处置方法上存在显著差异：

```
工控安全事件特殊性:

1. 物理影响:
   - IT事件: 数据丢失/泄露
   - OT事件: 可能导致人员伤亡、环境灾难、设备损坏
   
2. 响应优先级:
   - IT: 保护数据 > 恢复服务 > 取证调查
   - OT: 保障安全 > 稳定运行 > 恢复服务 > 取证调查
   
3. 恢复复杂度:
   - IT: 重装系统/恢复备份
   - OT: 需要验证PLC程序/校准传感器/测试联锁
   
4. 取证约束:
   - IT: 可以关机取证
   - OT: 不能随意关机, 可能导致危险工艺失控
   
5. 时间约束:
   - IT: 通常允许数小时到数天
   - OT: 必须在分钟到小时内控制影响
```

### 1.2 事件影响评估框架

```
工控安全事件影响评估矩阵:

┌──────────────┬──────────┬──────────┬──────────┬──────────┐
│ 影响维度      │ 轻微     │ 中等     │ 严重     │ 灾难性   │
├──────────────┼──────────┼──────────┼──────────┼──────────┤
│ 人员安全      │ 无影响   │ 轻伤可能 │ 重伤可能 │ 死亡可能 │
│ 环境影响      │ 无排放   │ 小量泄漏 │ 大量泄漏 │ 灾难性   │
│ 设备损坏      │ 无损坏   │ 可修复   │ 部分报废│ 大面积   │
│ 生产中断      │ <1小时   │ 1-4小时  │ 4-24小时│ >24小时  │
│ 经济损失      │ <10万    │ 10-100万 │ 100-千万│ >千万    │
│ 数据泄露      │ 内部     │ 有限外部 │ 大范围  │ 敏感工艺 │
│ 声誉影响      │ 无       │ 行业内   │ 媒体报道│ 公众关注│
└──────────────┴──────────┴──────────┴──────────┴──────────┘
```

## 2. ICS事件类型分类

### 2.1 恶意代码事件

```
恶意代码事件类型:

1. 工控专用恶意代码:
   ├── Stuxnet类: 直接攻击PLC, 修改控制逻辑
   ├── BlackEnergy类: 攻击SCADA系统, 远程操作设备
   ├── Industroyer类: 通过工控协议直接操控设备
   └── Triton类: 攻击安全仪表系统(SIS)

2. 通用恶意代码波及:
   ├── 勒索软件: 加密工程站/HMI文件
   ├── 蠕虫: 通过网络传播感染OT网络
   ├── 木马: 远程控制工程站
   └── 矿机: 占用工程站计算资源

3. 恶意代码行为特征:
   ├── 网络扫描: 枚举工控设备
   ├── 协议操作: 发送控制命令
   ├── 数据窃取: 上传工艺参数
   ├── 代码注入: 修改PLC程序
   └── 数据擦除: 破坏恢复能力
```

### 2.2 勒索软件事件

```
工控勒索软件事件分析:

特征:
- 目标: 工程站、SCADA服务器、历史数据库
- 影响: 加密项目文件、配置文件、HMI画面
- 后果: 无法操作PLC, 无法查看工艺状态
- 间接影响: 可能导致生产中断
- 不直接攻击: PLC固件 (通常)

历史案例:
- 2021 Colonial Pipeline: DarkSide勒索软件
  影响: 燃油管道停运6天, 美国东海岸燃油短缺
  原因: IT网络被攻击, 主动关闭OT网络
  
- 2020 Molex: EKANS勒索软件
  影响: 生产线停机
  特征: 专门终止工控相关进程
  
- 2019 Norsk Hydro: LockerGoga
  影响: 铝业生产中断, 手动操作
  损失: 约7100万美元

响应策略:
1. 不要支付赎金 (鼓励未来攻击)
2. 立即隔离受感染系统
3. 使用离线备份恢复
4. 验证OT系统完整性
5. 加强IT/OT隔离
```

### 2.3 拒绝服务事件

```
ICS拒绝服务(DoS)攻击类型:

1. 网络层DoS:
   ├── SYN Flood: 耗尽PLC连接资源
   ├── UDP Flood: 耗尽网络带宽
   ├── ICMP Flood: Ping洪水
   └── 畸形包: 导致设备崩溃

2. 应用层DoS:
   ├── 连接耗尽: 大量S7/Modbus连接
   ├── 请求洪泛: 快速发送读写请求
   ├── 长连接: 占用连接不释放
   └── 超大PDU: 发送超大数据单元

3. 协议特定DoS:
   ├── Modbus: 大量写线圈操作
   ├── S7: 快速CPU启停命令
   ├── DNP3: 链路层洪泛
   └── OPC: DCOM连接耗尽

4. 资源耗尽DoS:
   ├── CPU过载: 复杂运算请求
   ├── 内存耗尽: 大量数据请求
   ├── 连接表耗尽: 大量连接
   └── 通信缓冲区: 超大报文
```

### 2.4 物理破坏事件

```
物理破坏攻击:

1. 直接物理破坏:
   ├── PLC代码修改: 改变控制参数导致超速/超压
   ├── 安全联锁禁用: 禁用SIS保护功能
   ├── 阀门控制: 关闭/打开错误阀门
   ├── 温度控制: 修改加热/冷却参数
   └── 电机控制: 修改频率/方向

2. 间接物理破坏:
   ├── 报警抑制: 隐藏异常状态
   ├── 数据伪造: 使操作员看到正常值
   ├── HMI劫持: 在HMI上显示虚假数据
   └── 传感器欺骗: 注入虚假传感器信号

3. 破坏后果:
   ├── 设备损坏: 泵/阀/电机损坏
   ├── 产品报废: 不合格产品
   ├── 环境污染: 有害物质泄漏
   ├── 火灾爆炸: 可燃物失控
   └── 人员伤亡: 机械/化学伤害
```

### 2.5 操作员误操作事件

```
操作员误操作分类:

1. 配置错误:
   ├── PLC参数修改: 错误设定值
   ├── 量程范围: 传感器量程配置错误
   ├── 联锁逻辑: 安全联锁被误禁用
   └── 通信配置: 错误的网络地址

2. 操作错误:
   ├── 错误操作: 按错按钮/选错设备
   ├── 时序错误: 操作顺序不当
   ├── 参数输入: 输入错误数值
   └── 维护错误: 维护后未恢复

3. 程序错误:
   ├── 下载错误: 下载了错误的程序版本
   ├── 在线修改: 运行中错误修改
   ├── 强制变量: 强制了错误的变量值
   └── 删除程序: 误删除功能块

4. 预防措施:
   ├── 变更管理: 严格的变更审批流程
   ├── 操作确认: 关键操作双人确认
   ├── 模拟验证: 先在模拟器测试
   └── 权限管理: 最小权限原则
```

### 4.4 隔离阶段

```

隔离层次:
┌─────────────────────────────────────────────────────────┐
│ Level 1: 物理隔离 (最高优先级)                          │
│  - 如有物理危险: 立即启动紧急停机 (E-Stop)              │
│  - 切断危险源 (阀门/电源)                               │
│  - 疏散人员                                             │
│  - 通知应急服务 (119/120)                              │
├─────────────────────────────────────────────────────────┤
│ Level 2: 网络隔离                                       │
│  - 断开IT/OT连接                                       │
│  - 隔离受影响网段 (VLAN隔离)                           │
│  - 阻断恶意IP (防火墙规则)                             │
│  - 暂停远程访问 (VPN断开)                              │
│  注意: 评估断网对生产的影响                             │
├─────────────────────────────────────────────────────────┤
│ Level 3: 设备隔离                                       │
│  - 断开受感染工程站                                     │
│  - 禁用受影响PLC的通信                                  │
│  - 切换到手动操作模式                                   │
│  - 启用备用系统                                         │
├─────────────────────────────────────────────────────────┤
│ Level 4: 数据隔离                                       │
│  - 冻结数据库                                           │
│  - 停止数据采集                                         │
│  - 保存当前状态快照                                     │
│  - 防止数据进一步泄露                                   │
└─────────────────────────────────────────────────────────┘
```

```python
#!/usr/bin/env python3
"""工控安全事件隔离决策工具"""
import sys

class ICSContainmentAdvisor:
    """帮助决策隔离策略"""
    
    def __init__(self):
        self.questions = []
        self.answers = {}
    
    def assess_and_recommend(self, incident_type, physical_risk, 
                             network_isolated, production_status):
        """评估并推荐隔离策略"""
        recommendations = []
        
        # 1. 物理安全评估
        if physical_risk:
            recommendations.append({
                'priority': 'P1-紧急',
                'action': '立即启动紧急停机 (E-Stop)',
                'detail': '存在物理安全风险, 优先保障人员安全',
                'steps': [
                    '1. 按下紧急停止按钮',
                    '2. 疏散危险区域人员',
                    '3. 通知应急服务 (119)',
                    '4. 切断危险源',
                    '5. 等待安全确认后再进行其他操作',
                ]
            })
        
        # 2. 网络隔离
        if not network_isolated:
            if incident_type in ['malware', 'ransomware', 'apt']:
                recommendations.append({
                    'priority': 'P2-高',
                    'action': '立即隔离IT/OT网络连接',
```

## 5. OT环境证据保全

### 5.1 取证原则

```
OT取证核心原则:

1. 不破坏原则:
   - 不改变PLC运行状态
   - 不修改系统配置
   - 不删除任何数据
   - 不重启设备 (除非必要)

2. 最小干预原则:
   - 仅采集必要的证据
   - 使用只读方式采集
   - 避免在生产设备上操作
   - 优先使用网络取证

3. 可重现原则:
   - 记录所有操作步骤
   - 采集时有多人见证
   - 证据链完整
   - 使用时间戳

4. 安全优先:
   - 物理安全 > 取证
   - 如果取证导致危险, 立即停止
   - 安全人员参与取证决策
```

### 5.2 证据采集顺序

```
OT环境证据采集顺序 (易失性排序):

1. 寄存器/缓存 (最易失):
   - PLC内存状态
   - 计时器/计数器值
   - 当前输出状态

2. 网络连接 (高易失):
   - 活动连接表
   - ARP表
   - 路由表

3. 内存 (中易失):
   - 进程内存转储
   - 网络缓冲区
   - 临时数据

4. 临时数据 (中低易失):
   - 临时文件
   - 页面文件
   - 日志缓冲区

5. 持久数据 (低易失):
   - PLC程序
   - 配置文件
   - 事件日志
   - 诊断缓冲区

6. 离线数据 (最持久):
   - 备份磁带
   - 离线备份
   - 归档日志
```

```python
#!/usr/bin/env python3
"""OT网络取证数据采集工具"""
import subprocess
import os
import hashlib
import json
from datetime import datetime

class OTNetworkForensics:
    """OT网络取证采集工具"""
    
    def __init__(self, case_id, evidence_dir='/tmp/ot_forensics'):
        self.case_id = case_id
        self.evidence_dir = os.path.join(evidence_dir, case_id)
        self.chain_of_custody = []
        self.timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        
        # 创建证据目录
        os.makedirs(self.evidence_dir, exist_ok=True)
    
    def _log_action(self, action, details):
        """记录证据链"""
        entry = {
            'timestamp': datetime.now().isoformat(),
            'action': action,
            'details': details,
            'operator': os.getenv('USER', 'unknown'),
        }
        self.chain_of_custody.append(entry)
        
        # 写入证据链文件
        coc_file = os.path.join(self.evidence_dir, 'chain_of_custody.json')
        with open(coc_file, 'a', encoding='utf-8') as f:
            f.write(json.dumps(entry, ensure_ascii=False) + '\n')
    
    def _calc_hash(self, filepath):
        """计算文件哈希"""
        sha256 = hashlib.sha256()
        with open(filepath, 'rb') as f:
            for chunk in iter(lambda: f.read(8192), b''):
                sha256.update(chunk)
        return sha256.hexdigest()
    
    def capture_network_traffic(self, interface, duration=60):
        """采集网络流量"""
        print(f"[*] 采集网络流量 (接口: {interface}, 时长: {duration}秒)")
        
        output_file = os.path.join(
            self.evidence_dir,
            f'capture_{interface}_{self.timestamp}.pcap'
        )
        
        try:
            # 使用tcpdump采集 (需要root)
            cmd = [
                'tcpdump', '-i', interface,
                '-w', output_file,
                '-s', '0',  # 捕获完整包
                '-c', '0',   # 不限制包数
                f'{duration}'  # 时长通过timeout控制
            ]
            
            # 使用timeout控制采集时长
            result = subprocess.run(
                ['timeout', str(duration)] + cmd,
                capture_output=True, text=True, timeout=duration + 10
            )
            
            if os.path.exists(output_file):
                file_hash = self._calc_hash(output_file)
                file_size = os.path.getsize(output_file)
                
                self._log_action('网络流量采集', {
                    'interface': interface,
                    'duration': duration,
                    'file': output_file,
                    'size': file_size,
                    'sha256': file_hash,
                })
                
                print(f"[+] 采集完成: {output_file}")
                print(f"    大小: {file_size} bytes")
                print(f"    SHA256: {file_hash}")
                
                return output_file
            else:
                print("[-] 采集失败")
                return None
                
        except Exception as e:
            print(f"[-] 错误: {e}")
            self._log_action('采集失败', {'error': str(e)})
            return None
    
    def capture_connection_state(self):
        """采集网络连接状态"""
        print("[*] 采集网络连接状态")
        
        # 采集活动连接
        connections_file = os.path.join(
            self.evidence_dir,
            f'connections_{self.timestamp}.txt'
        )
        
        try:
            result = subprocess.run(
                ['netstat', '-anp'],
                capture_output=True, text=True, timeout=30
            )
            
            with open(connections_file, 'w', encoding='utf-8') as f:
                f.write(f"# 网络连接状态 - {datetime.now().isoformat()()}\n")
                f.write(result.stdout)
            
            file_hash = self._calc_hash(connections_file)
            
            self._log_action('网络连接状态采集', {
                'file': connections_file,
                'sha256': file_hash,
                'connection_count': result.stdout.count('\n'),
            })
            
            print(f"[+] 连接状态已保存")
            return connections_file
            
        except Exception as e:
            print(f"[-] 错误: {e}")
            return None
    
    def capture_arp_table(self):
        """采集ARP表"""
        print("[*] 采集ARP表")
        
        arp_file = os.path.join(
            self.evidence_dir,
            f'arp_table_{self.timestamp}.txt'
        )
        
        try:
            result = subprocess.run(
                ['arp', '-a'],
                capture_output=True, text=True, timeout=10
            )
            
            with open(arp_file, 'w', encoding='utf-8') as f:
                f.write(f"# ARP表 - {datetime.now().isoformat()}\n")
                f.write(result.stdout)
            
            file_hash = self._calc_hash(arp_file)
            
            self._log_action('ARP表采集', {
                'file': arp_file,
                'sha256': file_hash,
            })
            
            print(f"[+] ARP表已保存")
            return arp_file
            
        except Exception as e:
            print(f"[-] 错误: {e}")
            return None
    
    def capture_routing_table(self):
        """采集路由表"""
        print("[*] 采集路由表")
        
        route_file = os.path.join(
            self.evidence_dir,
            f'routing_table_{self.timestamp}.txt'
        )
        
        try:
            result = subprocess.run(
                ['netstat', '-rn'],
                capture_output=True, text=True, timeout=10
            )
            
            with open(route_file, 'w', encoding='utf-8') as f:
                f.write(f"# 路由表 - {datetime.now().isoformat()}\n")
                f.write(result.stdout)
            
            self._log_action('路由表采集', {
                'file': route_file,
                'sha256': self._calc_hash(route_file),
            })
            
            print(f"[+] 路由表已保存")
            return route_file
            
        except Exception as e:
            print(f"[-] 错误: {e}")
            return None
    
    def capture_firewall_rules(self):
        """采集防火墙规则"""
        print("[*] 采集防火墙规则")
        
        fw_file = os.path.join(
            self.evidence_dir,
            f'firewall_rules_{self.timestamp}.txt'
        )
        
        try:
            # iptables (Linux)
            result = subprocess.run(
                ['iptables', '-L', '-n', '-v'],
                capture_output=True, text=True, timeout=10
            )
            
            with open(fw_file, 'w', encoding='utf-8') as f:
                f.write(f"# 防火墙规则 - {datetime.now().isoformat()}\n")
                f.write(result.stdout)
            
            self._log_action('防火墙规则采集', {
                'file': fw_file,
                'sha256': self._calc_hash(fw_file),
            })
            
            print(f"[+] 防火墙规则已保存")
            return fw_file
            
        except Exception as e:
            print(f"[-] 错误: {e}")
            return None
    
    def capture_system_logs(self):
        """采集系统日志"""
        print("[*] 采集系统日志")
        
        log_files = [
            '/var/log/syslog',
            '/var/log/messages',
            '/var/log/auth.log',
            '/var/log/audit/audit.log',
        ]
        
        collected = []
        
        for log_file in log_files:
            if os.path.exists(log_file):
                dest = os.path.join(
                    self.evidence_dir,
                    f'log_{os.path.basename(log_file)}_{self.timestamp}'
                )
                
                try:
                    # 使用cp而不是cat, 保留元数据
                    subprocess.run(['cp', '-p', log_file, dest], timeout=30)
                    
                    file_hash = self._calc_hash(dest)
                    
                    self._log_action('系统日志采集', {
                        'source': log_file,
                        'destination': dest,
                        'sha256': file_hash,
                    })
                    
                    collected.append(dest)
                    print(f"  [+] {log_file} -> {dest}")
                    
                except Exception as e:
                    print(f"  [-] {log_file}: {e}")
        
        return collected
    
    def capture_plc_diagnostic(self, plc_ip, port=102):
        """采集PLC诊断信息 (非侵入性)"""
        print(f"[*] 采集PLC诊断信息 ({plc_ip})")
        
        diag_file = os.path.join(
            self.evidence_dir,
            f'plc_diag_{plc_ip}_{self.timestamp}.txt'
        )
        
        try:
            import socket
            import struct
            
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(10)
            sock.connect((plc_ip, port))
            
            # 仅读取诊断信息, 不修改任何内容
            # COTP连接
            tpkt = struct.pack('>BBH', 3, 0, 22)
            cotp = bytes([
                0x11, 0xE0, 0x00, 0x01, 0x00, 0x01, 0x00,
                0xC0, 0x02, 0x01, 0x00,
                0xC1, 0x02, 0x01, 0x02,
                0xC2, 0x01, 0x0A
            ])
            sock.send(tpkt + cotp)
            response = sock.recv(1024)
            
            with open(diag_file, 'w', encoding='utf-8') as f:
                f.write(f"# PLC诊断信息 - {datetime.now().isoformat()}\n")
                f.write(f"# PLC地址: {plc_ip}:{port}\n")
                f.write(f"# COTP响应: {response.hex()}\n")
                f.write(f"# 响应长度: {len(response)}\n")
                
                # 检查连接是否成功
                if len(response) >= 7 and response[5] == 0xD0:
                    f.write("# COTP连接: 成功\n")
                else:
                    f.write("# COTP连接: 失败\n")
            
            sock.close()
            
            self._log_action('PLC诊断采集', {
                'plc_ip': plc_ip,
                'file': diag_file,
                'sha256': self._calc_hash(diag_file),
            })
            
            print(f"[+] PLC诊断信息已保存")
            return diag_file
            
        except Exception as e:
            print(f"[-] 错误: {e}")
            return None
    
    def generate_report(self):
        """生成取证报告"""
        report_file = os.path.join(
            self.evidence_dir,
            f'forensics_report_{self.timestamp}.txt'
        )
        
        with open(report_file, 'w', encoding='utf-8') as f:
            f.write("=" * 70 + "\n")
            f.write("工控安全事件取证报告\n")
            f.write(f"案件编号: {self.case_id}\n")
            f.write(f"采集时间: {datetime.now().isoformat()}\n")
            f.write(f"采集人员: {os.getenv('USER', 'unknown')}\n")
            f.write("=" * 70 + "\n\n")
            
            f.write("证据链:\n")
            f.write("-" * 70 + "\n")
            for entry in self.chain_of_custody:
                f.write(f"时间: {entry['timestamp']}\n")
                f.write(f"操作: {entry['action']}\n")
                f.write(f"详情: {json.dumps(entry['details'], ensure_ascii=False)}\n")
                f.write(f"操作人: {entry['operator']}\n")
                f.write("-" * 70 + "\n")
        
        print(f"\n[+] 取证报告已生成: {report_file}")
        return report_file
```

### 6.2 PLC恢复程序

```
PLC恢复标准流程:

阶段1: 准备
1. 获取已知良好的PLC程序备份
   - 从版本控制系统获取
   - 与之前的版本比对
   - 验证备份的完整性 (哈希校验)
   
2. 准备干净的工程站
   - 使用干净的笔记本电脑
   - 安装正版TIA Portal/STEP 7
   - 确保无恶意软件
   - 准备必要的项目文件

阶段2: PLC检查
1. 物理检查
   - 检查PLC外观 (有无物理损坏)
   - 检查连接线 (有无篡改)
   - 检查存储卡 (有无替换)
   
2. 固件检查
   - 读取当前固件版本
   - 比对已知正确版本
   - 如有差异: 刷新固件
```

```python
#!/usr/bin/env python3
"""PLC程序差异分析工具 - 比较当前程序与备份"""
import hashlib
import struct
from datetime import datetime

class PLCProgramComparator:
    """PLC程序比较器"""
    
    def __init__(self):
        self.differences = []
    
    def compare_blocks(self, backup_blocks, current_blocks):
        """比较程序块
        
        参数:
            backup_blocks: 备份中的块列表
            current_blocks: 当前PLC中的块列表
        """
        backup_names = set(b['name'] for b in backup_blocks)
        current_names = set(b['name'] for b in current_blocks)
        
        # 1. 检查被删除的块
        deleted = backup_names - current_names
        if deleted:
            self._add_diff('deleted', list(deleted), 
                          '以下块在当前PLC中不存在')
        
        # 2. 检查新增的块
        added = current_names - backup_names
        if added:
            self._add_diff('added', list(added),
                          '以下块是新增的 (可能是注入的恶意代码)')
        
        # 3. 检查被修改的块
        common = backup_names & current_names
        modified = []
        
        for name in common:
            backup_block = next(b for b in backup_blocks if b['name'] == name)
            current_block = next(b for b in current_blocks if b['name'] == name)
            
            if backup_block['hash'] != current_block['hash']:
                modified.append({
                    'name': name,
                    'backup_hash': backup_block['hash'],
                    'current_hash': current_block['hash'],
                    'backup_size': backup_block['size'],
                    'current_size': current_block['size'],
                })
        
        if modified:
            self._add_diff('modified', modified,
                          '以下块内容已修改')
        
        return self.differences
    
    def _add_diff(self, diff_type, items, description):
        """添加差异"""
        self.differences.append({
            'type': diff_type,
            'description': description,
            'items': items,
            'timestamp': datetime.now().isoformat(),
        })
    
    def analyze_code_changes(self, backup_code, current_code):
        """分析代码变化细节"""
        changes = {
            'new_networks': [],
            'deleted_networks': [],
            'modified_networks': [],
            'new_variables': [],
            'deleted_variables': [],
        }
        
        # 分析变量变化
        backup_vars = set(backup_code.get('variables', {}).keys())
        current_vars = set(current_code.get('variables', {}).keys())
        
        changes['new_variables'] = list(current_vars - backup_vars)
        changes['deleted_variables'] = list(backup_vars - current_vars)
        
        # 分析网络变化
        backup_networks = backup_code.get('networks', [])
        current_networks = current_code.get('networks', [])
        
        max_len = max(len(backup_networks), len(current_networks))
        for i in range(max_len):
            b_net = backup_networks[i] if i < len(backup_networks) else None
            c_net = current_networks[i] if i < len(current_networks) else None
            
            if b_net is None:
                changes['new_networks'].append({
                    'index': i,
                    'content': c_net,
                })
            elif c_net is None:
                changes['deleted_networks'].append({
                    'index': i,
                    'content': b_net,
                })
            elif b_net != c_net:
                changes['modified_networks'].append({
                    'index': i,
                    'backup': b_net,
                    'current': c_net,
                })
        
        return changes
    
    def generate_report(self):
        """生成差异报告"""
        print("=" * 60)
        print("PLC程序差异分析报告")
        print("=" * 60)
        
        if not self.differences:
            print("未发现差异")
            return
        
        for diff in self.differences:
            print(f"\n[{diff['type'].upper()}] {diff['description']}")
            for item in diff['items']:
                if isinstance(item, dict):
                    print(f"  {item}")
                else:
                    print(f"  - {item}")
        
        print("\n" + "=" * 60)
        print("安全建议:")
        
        for diff in self.differences:
            if diff['type'] == 'added':
                print("  [!] 检查新增的块是否为恶意注入")
            elif diff['type'] == 'modified':
                print("  [!] 仔细审查被修改的块")
            elif diff['type'] == 'deleted':
                print("  [!] 确认被删除的块是否影响安全功能")
        
        print("=" * 60)

# 使用示例
if __name__ == '__main__':
    # 模备份数据
    backup_blocks = [
        {'name': 'OB1', 'hash': 'abc123', 'size': 1024},
        {'name': 'OB35', 'hash': 'def456', 'size': 512},
```

```python
#!/usr/bin/env python3
"""工控网络流量取证分析工具"""
import struct
from collections import defaultdict, Counter
from datetime import datetime

class ICSNetworkForensics:
    """ICS网络流量取证分析"""
    
    def __init__(self):
        self.sessions = defaultdict(list)
        self.anomalies = []
    
    def analyze_pcap(self, pcap_file):
        """分析pcap文件"""
        try:
            from scapy.all import rdpcap, TCP, IP
            packets = rdpcap(pcap_file)
            
            print(f"[*] 加载 {len(packets)} 个数据包")
            
            for pkt in packets:
                if IP in pkt and TCP in pkt:
                    self._process_tcp_packet(pkt)
            
            self._generate_analysis_report()
            
        except ImportError:
            print("[-] 需要安装scapy: pip install scapy")
    
    def _process_tcp_packet(self, pkt):
        """处理TCP包"""
        src_ip = pkt[IP].src
        dst_ip = pkt[IP].dst
        src_port = pkt[TCP].sport
        dst_port = pkt[TCP].dport
        payload = bytes(pkt[TCP].payload)
        
        # 检测工控协议
        if dst_port == 102 and len(payload) > 0:
            self._analyze_s7_traffic(src_ip, dst_ip, payload)
        elif dst_port == 502 and len(payload) > 0:
            self._analyze_modbus_traffic(src_ip, dst_ip, payload)
        elif dst_port == 20000 and len(payload) > 0:
            self._analyze_dnp3_traffic(src_ip, dst_ip, payload)
        
        # 记录会话
        session_key = f"{src_ip}:{src_port} -> {dst_ip}:{dst_port}"
        self.sessions[session_key].append({
            'timestamp': float(pkt.time),
            'payload': payload,
            'payload_len': len(payload),
        })
    
    def _analyze_s7_traffic(self, src_ip, dst_ip, payload):
        """分析S7协议流量"""
        if len(payload) < 8:
            return
        
        # 检查是否为S7协议
        if payload[0] != 0x03:  # TPKT版本
            return
        
        if len(payload) > 7 and payload[7] == 0x32:  # S7协议ID
            if len(payload) > 16:
                func_group = payload[16]
                
                # 检测危险操作
                if func_group == 0x05:  # 写操作
                    self._add_anomaly(
                        's7_write',
                        src_ip, dst_ip,
                        'S7写操作',
                        payload.hex()
                    )
                
                elif func_group == 0x28:
                    if len(payload) > 17:
                        sub_func = payload[17]
                        if sub_func == 0x00:
                            self._add_anomaly(
                                's7_cpu_start',
                                src_ip, dst_ip,
                                'S7 CPU启动命令',
                                payload.hex()
                            )
                        elif sub_func == 0x01:
                            self._add_anomaly(
                                's7_cpu_stop',
                                src_ip, dst_ip,
                                'S7 CPU停止命令',
                                payload.hex()
                            )
                
                elif func_group == 0x28 and len(payload) > 17:
                    if payload[17] == 0x02:
                        self._add_anomaly(
                            's7_password',
                            src_ip, dst_ip,
                            'S7密码验证',
                            payload.hex()
                        )
    
    def _analyze_modbus_traffic(self, src_ip, dst_ip, payload):
        """分析Modbus协议流量"""
        if len(payload) < 8:
            return
        
        func_code = payload[7] if len(payload) > 7 else 0
        
        # 写操作
        if func_code in [0x05, 0x06, 0x0F, 0x10]:
            self._add_anomaly(
                'modbus_write',
                src_ip, dst_ip,
                f'Modbus写操作 (功能码: 0x{func_code:02X})',
                payload.hex()
            )
    
    def _analyze_dnp3_traffic(self, src_ip, dst_ip, payload):
        """分析DNP3协议流量"""
        if len(payload) < 2:
            return
        
        # DNP3起始字节
        if payload[0] == 0x05 and payload[1] == 0x64:
            if len(payload) > 10:
                func_code = payload[10]
                # 写操作
                if func_code in [0x01, 0x02, 0x03, 0x04]:
                    self._add_anomaly(
                        'dnp3_write',
                        src_ip, dst_ip,
                        f'DNP3控制操作 (功能码: {func_code})',
                        payload.hex()
                    )
    
    def _add_anomaly(self, anomaly_type, src_ip, dst_ip, description, data):
        """添加异常"""
        self.anomalies.append({
            'type': anomaly_type,
            'src_ip': src_ip,
            'dst_ip': dst_ip,
            'description': description,
            'data': data[:200],  # 截断
            'timestamp': datetime.now().isoformat(),
        })
    
    def _generate_analysis_report(self):
        """生成分析报告"""
        print("\n" + "=" * 60)
        print("工控网络流量取证分析报告")
        print("=" * 60)
        
        # 会话统计
        print(f"\n[1] 会话统计")
        print(f"    总会话数: {len(self.sessions)}")
        for session, packets in sorted(self.sessions.items(),
                                       key=lambda x: len(x[1]),
                                       reverse=True)[:10]:
            print(f"    {session}: {len(packets)} 个包")
        
        # 异常事件
        print(f"\n[2] 异常事件 ({len(self.anomalies)} 个)")
        
        type_counts = Counter(a['type'] for a in self.anomalies)
        for atype, count in type_counts.items():
            print(f"    {atype}: {count} 次")
        
        # 详细异常
        if self.anomalies:
            print(f"\n[3] 异常详情 (前20个)")
            for anomaly in self.anomalies[:20]:
                print(f"\n  类型: {anomaly['type']}")
                print(f"  来源: {anomaly['src_ip']} -> {anomaly['dst_ip']}")
                print(f"  描述: {anomaly['description']}")
                print(f"  数据: {anomaly['data']}")
        
        # 安全评估
        print(f"\n[4] 安全评估")
        
        cpu_stops = [a for a in self.anomalies if a['type'] == 's7_cpu_stop']
        if cpu_stops:
            print(f"  [!] 检测到 {len(cpu_stops)} 次CPU停止命令")
        
        writes = [a for a in self.anomalies if 'write' in a['type']]
        if writes:
            print(f"  [!] 检测到 {len(writes)} 次写操作")
        
        passwords = [a for a in self.anomalies if a['type'] == 's7_password']
        if passwords:
            print(f"  [!] 检测到 {len(passwords)} 次密码验证")
            print(f"      可能的密码暴力破解或窃取")
        
        print("\n" + "=" * 60)

if __name__ == '__main__':
    import sys
    
    if len(sys.argv) < 2:
        print("用法: python3 network_forensics.py <pcap文件>")
        sys.exit(1)
    
    forensics = ICSNetworkForensics()
    forensics.analyze_pcap(sys.argv[1])
```
