```
┌──────────────┬──────┬──────┬──────┬──────┬──────┐

│ 人员安全      │  A   │  C   │  R   │  C   │  R   │
│ 取证调查      │  A   │  R   │  C   │  I   │  I   │
│ 恢复决策      │  A   │  R   │  C   │  I   │  C   │
│ 系统恢复      │  I   │  R   │  C   │  I   │  I   │
│ 生产恢复      │  A   │  C   │  R   │  I   │  C   │

│ 事后分析      │  A   │  R   │  C   │  C   │  C   │

R=负责执行  A=批准  C=被咨询  I=被告知
```
