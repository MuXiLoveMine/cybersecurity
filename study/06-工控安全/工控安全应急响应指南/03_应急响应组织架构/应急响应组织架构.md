# 应急响应组织架构

### 3.1 ICS应急响应团队

```
工控安全应急响应团队 (ICS-CSIRT):

┌──────────────────────────────────────────────────────┐
│                  应急响应指挥官                        │
│  (运营总监/厂长)                                     │
│  职责: 决策授权、资源调配、对外协调                   │
└──────────────────────────┬───────────────────────────┘
                           │
        ┌──────────────────┼──────────────────────┐
        │                  │                      │
┌───────┴───────┐  ┌──────┴───────┐  ┌──────────┴──────────┐
│  技术响应组     │  │ 运营保障组    │  │  外部协调组           │
│                │  │              │  │                      │
│ - OT安全专家   │  │ - 工艺工程师  │  │ - 管理层             │
│ - IT安全专家   │  │ - 操作员      │  │ - 公关                │
│ - PLC编程师    │  │ - 维护人员    │  │ - 法务                │
│ - 网络工程师   │  │ - 安全员      │  │ - 监管机构联络        │
│ - 取证分析师   │  │ - 环境监测    │  │ - 厂商技术支持        │
│ - 恶意代码分析 │  │ - HSE         │  │ - CERT/CSP           │
└────────────────┘  └──────────────┘  └──────────────────────┘
```

### 3.2 角色与职责

```
角色职责矩阵 (RACI):

┌──────────────┬──────┬──────┬──────┬──────┬──────┐
│ 任务          │指挥官│技术组│运营组│协调组│安全员│
├──────────────┼──────┼──────┼──────┼──────┼──────┤
│ 事件报告      │  A   │  R   │  R   │  C   │  I   │
│ 事件分类      │  I   │  R   │  C   │  I   │  C   │
│ 隔离决策      │  A   │  R   │  C   │  I   │  C   │
│ 系统隔离      │  I   │  R   │  C   │  I   │  I   │
│ 生产安全      │  A   │  C   │  R   │  I   │  C   │
│ 人员安全      │  A   │  C   │  R   │  C   │  R   │
│ 取证调查      │  A   │  R   │  C   │  I   │  I   │
│ 恢复决策      │  A   │  R   │  C   │  I   │  C   │
│ 系统恢复      │  I   │  R   │  C   │  I   │  I   │
│ 生产恢复      │  A   │  C   │  R   │  I   │  C   │
│ 对外通报      │  A   │  C   │  I   │  R   │  I   │
│ 事后分析      │  A   │  R   │  C   │  C   │  C   │
└──────────────┴──────┴──────┴──────┴──────┴──────┘

R=负责执行  A=批准  C=被咨询  I=被告知
```
