## 2. Stuxnet深度分析

### 2.1 概述

Stuxnet是已知最早的针对工业控制系统的网络武器，于2010年被发现，但据信从2007年就开始部署。它专门针对伊朗纳坦兹铀浓缩工厂的西门子S7-300/400系列PLC，通过修改PLC控制逻辑使离心机超速运转，最终造成物理破坏。

```
Stuxnet基本信息:
- 发现时间: 2010年6月
- 首次释放: 约2007年
- 目标: 伊朗纳坦兹铀浓缩设施
- 攻击对象: 西门子S7-315和S7-415 PLC
- 使用零日漏洞: 4个 (最初发现)
- 后续发现: 共20+个零日漏洞
- 代码体积: 约500KB (极大)
- 开发成本: 估计数百万美元
- 疑似开发者: 美国/以色列联合开发 (方程式组织)
```

### 2.3 关键技术分析

#### 2.3.1 DLL劫持技术

Stuxnet使用DLL劫持来拦截Step 7与PLC的通信：

```
正常流程:
  Step 7 -> s7otbxdx.dll -> PLC通信 -> S7-300 PLC

被劫持后:
  Step 7 -> malicious s7otbxdx.dll -> 原始s7otbxdx.dll -> PLC通信
                    │
                    └── 拦截和修改数据 -> 注入恶意代码
```

```c
// Stuxnet DLL劫持伪代码
// 恶意DLL导出的函数
BOOL __stdcall s7_patch_export(... original_params ...)
{
    // 1. 记录Step 7对PLC的操作
    log_operation(original_params);
    
    // 2. 调用原始DLL函数
    HMODULE hOrigDll = LoadLibrary("s7otbxdx_orig.dll");
    BOOL result = original_s7_patch(hOrigDll, original_params);
    
    // 3. 如果是写入操作，注入恶意代码
    if (is_write_operation(original_params)) {
        inject_malicious_code(original_params);
    }
    
    // 4. 如果是读取操作，返回伪造数据
    if (is_read_operation(original_params)) {
        return fake_data(original_params);
    }
    
    return result;
}
```

#### 2.3.2 PLC Rootkit

Stuxnet创建了PLC级别的Rootkit，用于隐藏恶意代码：

```
PLC Rootkit工作原理:

1. 代码注入:
   - 在OB (Organization Block) 中注入恶意代码块
   - 恶意代码块伪装为正常的DB (Data Block)

2. 代码隐藏:
   - 拦截Step 7的读取请求
   - 返回原始代码而非恶意代码
   - 使操作员在Step 7中看到的代码是正常的

3. 数据伪造:
   - 拦截传感器数据读取
   - 返回伪造的正常值
   - 隐藏离心机的异常运行状态

4. 持久化:
   - 即使PLC断电重启，恶意代码仍然存在
   - 通过修改系统DB实现持久化
```

#### 2.3.3 目标识别机制

Stuxnet具有精确的目标识别功能，只在特定环境中激活：

```
目标识别条件 (所有条件必须同时满足):

1. 系统环境:
   - Windows 2000/XP/2003/Vista/7
   - 安装了WinCC或PCS 7
   - 存在西门子Step 7软件

2. PLC配置:
   - 连接了S7-315或S7-415 CPU
   - 特定的硬件配置 (CP 342-5等)

3. 工艺特征 (核心识别):
   - 检测特定数量 (164个) 的离心机
   - 检测级联排列配置 (15级)
   - 检测特定频率转换器 (Vacon系列)
   - 检测特定压力传感器 (Kroneck系列)

4. 攻击窗口:
   - 离心机运行时间 > 30天
   - 系统无报警状态
   - 操作员不在旁

如果任何条件不满足，Stuxnet进入休眠或自清除
```

## 3. Duqu分析

### 3.1 概述

Duqu发现于2011年9月，与Stuxnet共享大量代码，但攻击目的不同。Duqu以信息窃取为目标，收集工控系统设计图纸和配置信息，为后续攻击做准备。

```
Duqu基本信息:
- 发现时间: 2011年9月
- 首次释放: 约2009年
- 目标: 中东和欧洲的工控系统供应商
- 攻击目的: 信息窃取，为攻击者提供情报
- 与Stuxnet关系: 共享代码框架，同一开发组织
- C2通信: 使用独特的协议和加密
- 代码体积: 约100KB (不含配置)
```

### 3.2 技术特征

```
Duqu技术特征:

1. 模块化架构:
   - 核心: 轻量级后门
   - 插件: 按需加载功能模块
   - 配置: 动态C2配置更新

2. 信息收集:
   - 屏幕截图
   - 键盘记录
   - 文件搜索 (特定工控文件)
   - 网络拓扑映射
   - 凭据窃取

3. C2通信:
   - 使用HTTP/HTTPS伪装
   - 自定义加密协议
   - C2服务器伪装为图片服务器
   - 使用JPEG文件作为数据载体

4. 持久化:
   - 使用零日漏洞 (CVE-2011-3402)
   - 内核驱动rootkit
   - 通过计划任务保持持久

5. 目标筛选:
   - 仅在特定环境激活
   - 自动检测工控软件
   - 非目标环境自清除
```

### 3.3 Duqu与Stuxnet对比

| 维度 | Stuxnet | Duqu |
|------|---------|------|
| 目标 | 物理破坏 | 信息窃取 |
| 目标行业 | 核浓缩设施 | 多个行业 |

## 4. Flame分析

### 4.1 概述

Flame (又名Flamer, sKyWIper) 是2012年5月发现的高级间谍软件，代码体积极大，功能极为复杂。它针对中东地区，特别是伊朗的能源设施和政府机构。

```
Flame基本信息:
- 发现时间: 2012年5月
- 首次释放: 约2010年
- 目标: 伊朗、以色列、巴勒斯坦、苏丹、叙利亚等
- 代码体积: 约20MB (极大)
- 开发语言: C++, C, Lua脚本
- 攻击目的: 全面的间谍活动
- 与Stuxnet关系: 共享部分代码 (同一方程式组织)
```

### 4.2 技术特征

```
Flame功能模块:

1. 信息收集模块:
   ├── 屏幕截图 (定时捕获)
   ├── 键盘记录
   ├── 麦克风录音
   ├── 蓝牙设备发现
   ├── 网络流量嗅探
   ├── 文件搜索和上传
   └── 剪贴板监控

2. 传播模块:
   ├── USB传播
   ├── 局域网传播
   ├── 打印机漏洞传播 (MS10-061)
   ├── 利用LNK漏洞 (与Stuxnet相同)
   └── Flame专有传播 (伪造Windows Update)

3. C2通信模块:
   ├── HTTP/HTTPS
   ├── SSH
   ├── 蓝牙
   └── 伪装为Windows Update (伪造MU)

4. 反检测模块:
   ├── 多种加密 (多次加密数据)
   ├── 反虚拟机
   ├── 反沙箱
   └── 代码混淆

5. 独特功能:
   ├── 蓝牙信标 (用于物理追踪)
   ├── 网络接口MAC修改
   ├── 自定义数据库 (SQLite)
   ├── Lua脚本引擎 (动态功能加载)
   └── 加密命名 (使用游戏术语)
```

### 4.3 独特的C2机制

Flame使用极其独特的C2通信机制：

```
Flame C2通信流程:

1. 信标阶段:
   客户端 -> C2服务器: HTTP请求 (伪装为浏览器)
   请求中包含加密的感染信息

2. 配置更新:
   C2服务器 -> 客户端: 加密的配置文件
   包含新的C2地址和攻击参数

3. 数据上传:
   客户端 -> C2服务器: 加密的数据包
   使用自研加密算法 (多轮XOR + 位移)

4. 命令执行:
   C2服务器 -> 客户端: Lua脚本
   客户端在内部Lua引擎中执行

5. 伪造Windows Update:
   客户端 -> 局域网: 广播伪造的MU消息
   其他机器看到"有更新"并连接到Flame的伪MU服务器
   通过仿冒数字签名验证传播
```

## 5. Havex分析

### 5.1 概述

Havex发现于2013年，是一种针对工控系统的远程访问木马(RAT)。它通过感染工控软件供应商的网站，在用户下载合法工控软件时植入恶意代码。

```
Havex基本信息:
- 发现时间: 2013年
- 目标: 欧洲能源、水电、石油天然气行业
- 传播方式: 水坑攻击 (感染工控软件下载站点)
- 攻击目的: 信息收集和远程控制
- 特殊功能: OPC数据枚举
```

### 5.2 OPC数据枚举

Havex的独特之处在于能够枚举OPC服务器的标签信息：

```
Havex OPC枚举流程:

1. 发现OPC服务器:
   - 扫描本地和远程OPC服务器
   - 使用OPC枚举接口

2. 连接OPC服务器:
   - 使用DCOM连接
   - 调用IOPCServerList接口

3. 获取标签信息:
   - 枚举所有数据点 (Tag)
   - 获取标签名称、类型、地址

### 8.3 TriStation协议逆向

```
TriStation协议分析:

1. 物理层: RS-232串口
2. 链路层: 自定义帧格式
   ┌────────┬──────────┬─────────┬────────┬────────┐
   │ 起始符  │ 长度     │ 命令码  │ 数据    │ CRC    │
   │ 0x5A   │ 2 bytes │ 1 byte │ 变长   │ 2 bytes│
   └────────┴──────────┴─────────┴────────┴────────┘

3. 关键命令:
   - 0x01: 读控制器状态
   - 0x02: 写控制器配置
   - 0x03: 下载用户程序
   - 0x04: 读内存数据
   - 0x05: 写内存数据
   - 0x09: 切换控制器模式

4. 安全验证:
   - 协议本身无加密
   - 仅依赖网络隔离
   - 无认证机制
   - 无完整性校验

# Triton TriStation协议通信伪代码

class TriStationClient:
    """Triconex TriStation协议客户端"""
    
    def __init__(self, serial_port):
        self.port = serial_port
        self.seq_num = 0
    
    def build_frame(self, command, data=b''):
        """构建TriStation帧"""
        start = bytes([0x5A])
        length = struct.pack('<H', 4 + len(data) + 2)  # 命令+数据+CRC
        cmd = bytes([command])
        
        frame = start + length + cmd + data
        crc = self._calc_crc(frame[1:])  # CRC不包含起始符
        
        return frame + struct.pack('<H', crc)
    
    def read_controller_status(self):
        """读取控制器状态"""
        frame = self.build_frame(0x01)
        response = self._send_recv(frame)
        
        if response:
            status = self._parse_status(response)
            return status
        return None
    
    def switch_mode(self, mode):
        """切换控制器模式
        0x00: 运行模式
        0x01: 程序模式
        0x02: 远程模式
        """
        frame = self.build_frame(0x09, bytes([mode]))
        response = self._send_recv(frame)
        return response is not None
    
    def download_program(self, program_data):
        """下载用户程序"""
        # 分段发送
        chunk_size = 256
        for i in range(0, len(program_data), chunk_size):
            chunk = program_data[i:i+chunk_size]
            addr = struct.pack('<I', i)
            frame = self.build_frame(0x03, addr + chunk)
            self._send_recv(frame)
    
    def write_memory(self, address, data):
        """写内存"""
        addr = struct.pack('<I', address)
        frame = self.build_frame(0x05, addr + data)
        response = self._send_recv(frame)
        return response is not None

                asdu_type = data[9] if len(data) > 9 else 0
                # 0x2D = C_DC_NA (双点控制) - Industroyer使用的命令
                if asdu_type in [0x2D, 0x2E, 0x2F]:
                    return True
        return False
    
    def _check_modbus_write(self, data):
        """检查Modbus写操作"""
        if len(data) < 8:
            return False
        func_code = data[7] if len(data) > 7 else 0
        # 写线圈(0x05), 写多个线圈(0x0F), 写寄存器(0x06), 写多个寄存器(0x10)
        return func_code in [0x05, 0x06, 0x0F, 0x10]
    
    def generate_report(self):
        """生成检测报告"""
        print(f"\n{'='*60}")
        print("工控恶意代码检测报告")
        print(f"{'='*60}")
        
        if not self.alerts:
            print("未检测到恶意代码活动")
            return
        
        # 按恶意代码分组
        malware_groups = defaultdict(list)
        for alert in self.alerts:
            malware_groups[alert['malware']].append(alert)
        
        for malware, alerts in malware_groups.items():
            print(f"\n[{malware}] 检测到 {len(alerts)} 个告警:")
            for a in alerts:
                print(f"  - [{a['severity']}] {a['type']}: {a['detail']}")
                print(f"    时间: {a['timestamp']}")
        
        print(f"\n{'='*60}")

#!/usr/bin/env python3
"""工控恶意代码主机行为检测"""
import psutil
import os
import hashlib
from datetime import datetime

class ICSHostDetector:
    """检测工控工程站/HMI上的恶意代码行为"""
    
    def __init__(self):
        self.suspicious_processes = [
            'ccalc.exe',      # Stuxnet伪装的计算器
            'mrxcls.sys',     # Stuxnet内核驱动
            'mrxnet.sys',     # Stuxnet内核驱动
            's7otbxdx.dll',   # Stuxnet DLL劫持
            'lsass.exe.*',    # 凭据窃取
        ]
        
        self.suspicious_paths = [
            'C:\\Windows\\Temp\\',
            'C:\\ProgramData\\',
            'C:\\Users\\*\\AppData\\Local\\Temp\\',
        ]
        
        self.suspicious_network_connections = [
            ('www.todaysfutbol.com', 80),
            ('www.mypremierfutbol.com', 80),
            ('www.bestsoccerdeal.com', 80),
        ]
    
    def scan_processes(self):
        """扫描可疑进程"""
        findings = []
        
        for proc in psutil.process_iter(['pid', 'name', 'exe', 'cmdline', 'create_time']):
            try:
                proc_name = proc.info['name'].lower()
                
                # 检查可疑进程名
                for susp in self.suspicious_processes:
                    if susp.replace('*', '') in proc_name:
                        findings.append({
                            'type': '可疑进程',
                            'pid': proc.info['pid'],
                            'name': proc.info['name'],
                            'exe': proc.info.get('exe', ''),
                            'reason': f'匹配规则: {susp}',
                            'severity': 'high'
                        })
                
                # 检查伪装进程
                if proc_name == 'ccalc.exe':
                    # Stuxnet伪装为Windows计算器
                    findings.append({
                        'type': '伪装进程',
                        'pid': proc.info['pid'],
                        'name': proc.info['name'],
                        'reason': '可能是Stuxnet伪装的计算器',
                        'severity': 'critical'
                    })
                
                # 检查路径异常
                exe_path = proc.info.get('exe', '')
                if exe_path:
                    for susp_path in self.suspicious_paths:
                        if susp_path.replace('*', '') in exe_path:
                            findings.append({
                                'type': '可疑路径',
                                'pid': proc.info['pid'],
                                'name': proc.info['name'],
                                'exe': exe_path,
                                'reason': f'从可疑路径运行: {susp_path}',
                                'severity': 'medium'
                            })
                
            except (psutil.NoSuchProcess, psutil.AccessDenied):
                pass
        
        return findings
    
    def scan_network_connections(self):
        """扫描网络连接"""
        findings = []
        
        for conn in psutil.net_connections(kind='inet'):
            if conn.status == 'ESTABLISHED':
                # 检查到已知C2的连接
                for c2_host, c2_port in self.suspicious_network_connections:
                    if (conn.laddr and c2_port in conn.laddr or
                        conn.raddr and c2_port in conn.raddr):
                        findings.append({
                            'type': 'C2连接',
                            'local': f"{conn.laddr.ip}:{conn.laddr.port}" if conn.laddr else '',
                            'remote': f"{conn.raddr.ip}:{conn.raddr.port}" if conn.raddr else '',
                            'pid': conn.pid,
                            'reason': f'连接到已知C2: {c2_host}',
                            'severity': 'critical'
                        })
                
                # 检查非标准端口
                if conn.raddr:
                    rport = conn.raddr.port
                    standard_ports = [80, 443, 102, 502, 3389, 22]
                    if rport not in standard_ports and rport > 49152:
                        findings.append({
                            'type': '非标准端口',
                            'local': f"{conn.laddr.ip}:{conn.laddr.port}" if conn.laddr else '',
                            'remote': f"{conn.raddr.ip}:{conn.raddr.port}",
                            'pid': conn.pid,
                            'reason': f'连接到非标准高端口 {rport}',
                            'severity': 'low'
                        })
        
        return findings
    
    def scan_dll_injection(self):
        """扫描DLL注入"""
        findings = []
        
        # 检查Step 7是否被注入
        target_processes = ['s7tgtopx.exe', 'STEP7.exe', 'pcs7.exe']
        
        for proc in psutil.process_iter(['pid', 'name']):
            try:
                proc_name = proc.info['name'].lower()
                if any(t in proc_name for t in target_processes):
                    # 获取加载的DLL
                    p = psutil.Process(proc.info['pid'])
                    
                    # 检查是否有可疑DLL
                    suspicious_dlls = [
                        's7otbxdx.dll',   # Stuxnet DLL劫持
                        's7hklspx.dll',   # Stuxnet
                        'api_log.dll',    # 通用API hook
                    ]
                    
                    for dll_name in suspicious_dlls:
                        # 通过内存映射检查DLL
                        try:
                            for mapping in p.memory_maps():
                                if dll_name.lower() in mapping.path.lower():
                                    findings.append({
                                        'type': 'DLL注入',
                                        'pid': proc.info['pid'],
                                        'process': proc.info['name'],
                                        'dll': mapping.path,
                                        'reason': f'检测到可疑DLL: {dll_name}',
                                        'severity': 'critical'
                                    })
                        except:
                            pass
            except:
                pass
        
        return findings
    
    def scan_filesystem(self):
        """扫描文件系统"""
        findings = []
        
        # 检查关键目录
        scan_dirs = [
            'C:\\Windows\\System32\\drivers',
            'C:\\Windows\\SysWOW64',
            'C:\\Program Files\\Siemens\\',
            'C:\\Program Files (x86)\\Siemens\\',
        ]
        
        suspicious_files = {
            'mrxcls.sys': 'Stuxnet内核驱动',
            'mrxnet.sys': 'Stuxnet内核驱动',
            's7otbxdx.dll': 'Stuxnet DLL劫持',
            '~WTR4141.tmp': 'Stuxnet临时文件',
            '~WTR4142.tmp': 'Stuxnet临时文件',
        }
        
        for scan_dir in scan_dirs:
            if not os.path.exists(scan_dir):
                continue
            
            for root, dirs, files in os.walk(scan_dir):
                for filename in files:
                    if filename.lower() in [f.lower() for f in suspicious_files]:
                        filepath = os.path.join(root, filename)
                        
                        # 计算文件哈希
                        try:
                            with open(filepath, 'rb') as f:
                                md5 = hashlib.md5(f.read()).hexdigest()
                            
                            findings.append({
                                'type': '恶意文件',
                                'path': filepath,
                                'md5': md5,
                                'reason': suspicious_files.get(filename, '未知'),
                                'severity': 'critical'
                            })
                        except:
                            pass
        
        return findings
    
    def run_full_scan(self):
        """运行完整扫描"""
        print(f"{'='*60}")
        print("工控恶意代码主机检测扫描")
        print(f"扫描时间: {datetime.now()}")
        print(f"{'='*60}")
        
        all_findings = []
        
        print("\n[1] 扫描进程...")
        findings = self.scan_processes()
        all_findings.extend(findings)
        print(f"    发现 {len(findings)} 个可疑项")
        
        print("[2] 扫描网络连接...")
        findings = self.scan_network_connections()
        all_findings.extend(findings)
        print(f"    发现 {len(findings)} 个可疑项")
        
        print("[3] 扫描DLL注入...")
        findings = self.scan_dll_injection()
        all_findings.extend(findings)
        print(f"    发现 {len(findings)} 个可疑项")
        
        print("[4] 扫描文件系统...")
        findings = self.scan_filesystem()
        all_findings.extend(findings)
        print(f"    发现 {len(findings)} 个可疑项")
        
        print(f"\n{'='*60}")
        print("扫描结果:")
        
        if not all_findings:
            print("未发现可疑活动")
        else:
            # 按严重程度排序
            severity_order = {'critical': 0, 'high': 1, 'medium': 2, 'low': 3}
            all_findings.sort(key=lambda x: severity_order.get(x.get('severity', 'low'), 4))
            
            for f in all_findings:
                print(f"\n  [{f.get('severity', 'unknown').upper()}] {f['type']}")
                for key, val in f.items():
                    if key not in ['type', 'severity']:
                        print(f"    {key}: {val}")
        
        print(f"\n{'='*60}")

if __name__ == '__main__':
    detector = ICSHostDetector()
    detector.run_full_scan()
