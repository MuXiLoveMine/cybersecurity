## 1. 工控系统漏洞挖掘概述

### 1.1 工控系统与IT系统的差异

工控系统（Industrial Control System, ICS）与传统IT系统在架构、通信协议、安全需求方面存在显著差异，这些差异直接影响漏洞挖掘的策略和方法。

| 对比维度 | IT系统 | ICS系统 |
|---------|--------|---------|
| 可用性要求 | 中等（容忍短暂宕机） | 极高（24/7不间断运行） |
| 实时性要求 | 非实时 | 毫秒级实时响应 |
| 协议类型 | TCP/IP协议簇 | Modbus、DNP3、S7、Profinet等 |
| 补丁频率 | 定期（每月） | 极低（需停机验证） |
| 寿命周期 | 3-5年 | 15-25年 |
| 安全防护 | 成熟（防火墙、IDS等） | 薄弱（缺乏安全机制） |
| 网络隔离 | 相对开放 | 分层隔离（Purdue模型） |
| 操作系统 | Windows/Linux等 | VxWorks、RTOS、专有OS |

### 1.2 漏洞挖掘的核心挑战

工控漏洞挖掘面临以下独特挑战：

**1. 设备获取困难**

工控设备（如PLC、SCADA服务器、RTU）价格昂贵，且制造商通常不提供研究样机。研究者需要通过模拟器、二手设备或厂商合作项目获取测试设备。

```
常见设备获取途径：
- 厂商漏洞奖励计划（VDP）
- 二手市场采购（eBay、闲鱼等）
- 开源PLC模拟器（如OpenPLC、PlcSim）
- 实验室合作（高校/研究机构）
- 数字孪生仿真环境
```

**2. 协议多样性**

工控协议种类繁多且缺乏统一标准，每种协议都有独特的消息格式、功能码和状态机设计，研究者需要深入理解每种协议的规范和实现。

**3. 实时性约束**

许多工控设备对超时和异常输入极其敏感，在测试过程中可能导致设备停机、重启甚至物理损坏，限制了激进测试方法的应用。

**4. 缺乏调试接口**

多数PLC和RTU不提供JTAG、SWD或串口调试接口，使得动态分析和代码执行跟踪极为困难。

### 1.3 漏洞挖掘方法论

工控漏洞挖掘遵循系统化的方法论：

```
漏洞挖掘流程：
┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  信息收集    │ -> │  固件分析     │ -> │  协议分析     │ -> │  漏洞挖掘    │
│  资产识别    │    │  逆向工程     │    │  模糊测试     │    │  验证/利用   │
└─────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

#### 1.3.1 信息收集阶段

信息收集是漏洞挖掘的起点，包括设备型号识别、固件获取、协议规范收集等。

```python
# 工控设备信息收集脚本示例
import socket
import struct

def identify_siemens_plc(target_ip, port=102):
    """通过S7协议识别西门子PLC设备信息"""
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(5)
        sock.connect((target_ip, port))
        
        # 构建S7 COTP连接请求
        # TPKT头: version=3, length=22
        tpkt = struct.pack('>BBH', 3, 0, 22)
        # COTP连接请求
        cotp = bytes([
            0x11,  # Length
            0xE0,  # PDU type: Connect Request
            0x00, 0x01,  # Destination reference
            0x00, 0x01,  # Source reference
            0x00,        # Class
            0xC0, 0x01, 0x0A,  # Called/Calling TSAP
            0xC1, 0x02, 0x01, 0x00,  # TPDU size = 1024
            0xC2, 0x02, 0x01, 0x02   # Additional options
        ])
        
        packet = tpkt + cotp
        sock.send(packet)
        response = sock.recv(1024)
        
        if len(response) > 0:
            print(f"[+] 目标 {target_ip} 响应S7协议通信")
            print(f"[+] 响应长度: {len(response)} bytes")
            # 解析设备信息
            if len(response) >= 20:
                print(f"[+] 可能是西门子S7系列PLC")
            return True
        return False
    except Exception as e:
        print(f"[-] 连接失败: {e}")
        return False
    finally:
        sock.close()

# 扫描整个网段
def scan_network(base_ip="192.168.1"):
    """扫描网段内的工控设备"""
    for i in range(1, 255):
        target = f"{base_ip}.{i}"
        # 检查常见工控端口
        ports = [102, 502, 47808, 20000, 44818]
        for port in ports:
            try:
                sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                sock.settimeout(1)
                result = sock.connect_ex((target, port))
                if result == 0:
                    print(f"[+] {target}:{port} 端口开放")
                sock.close()
            except:
                pass
```

#### 1.3.2 Purdue模型与攻击面分析

Purdue企业参考模型将工业网络分为多个层级，漏洞挖掘需要针对每一层进行攻击面分析：

```
Purdue模型层级与攻击面：
┌─────────────────────────────────────────────────┐
│ Level 5: 企业网络      │ ERP系统、办公终端            │
├─────────────────────────────────────────────────┤
│ Level 4: IT/OT边界     │ 历史数据库、DMZ              │
├─────────────────────────────────────────────────┤
│ Level 3: 制造执行层    │ MES系统、SCADA服务器         │
├─────────────────────────────────────────────────┤
│ Level 2: 监督控制层    │ HMI、工程师站               │
├─────────────────────────────────────────────────┤
│ Level 1: 基本控制层    │ PLC、RTU、DCS控制器          │
├─────────────────────────────────────────────────┤
│ Level 0: 物理过程层    │ 传感器、执行器               │
└─────────────────────────────────────────────────┘
```

每个层级的攻击面不同：

- **Level 5-4**：Web应用漏洞、数据库注入、钓鱼攻击
- **Level 3**：SCADA服务器RCE、OPC DA漏洞、历史数据库攻击
- **Level 2**：HMI缓冲区溢出、工程师站恶意软件
- **Level 1**：PLC协议漏洞、固件篡改、逻辑注入
- **Level 0**：传感器欺骗、执行器劫持

#### 2.2.2 手动提取文件系统

当binwalk无法自动提取时，需要手动定位和提取文件系统：

```python
#!/usr/bin/env python3
"""手动固件文件系统提取工具"""
import struct
import os

# 常见文件系统魔数
FS_MAGIC = {
    'squashfs': b'\x68\x73\x71\x73',  # hsqs
    'jffs2':   b'\x19\x85',           # JFFS2
    'cramfs':  b'\x45\x3d\xcd\x28',   # cramfs
    'romfs':   b'\x2d\x72\x6f\x6d',   # -rom
    'ubifs':   b'\x31\x18\x53\x20',   # UBI
}

def find_filesystem(firmware_path):
    """在固件镜像中搜索文件系统"""
    with open(firmware_path, 'rb') as f:
        data = f.read()
    
    results = []
    for fs_name, magic in FS_MAGIC.items():
        offset = 0
        while True:
            pos = data.find(magic, offset)
            if pos == -1:
                break
            results.append({
                'type': fs_name,
                'offset': pos,
                'hex_offset': hex(pos)
            })
            offset = pos + len(magic)
    
    return results

def extract_squashfs(firmware_path, offset, output_path):
    """提取SquashFS文件系统"""
    with open(firmware_path, 'rb') as f:
        f.seek(offset)
        # 读取SquashFS头部信息
        header = f.read(96)
        
        magic = header[0:4]
        inode_count = struct.unpack('<I', header[4:8])[0]
        block_size = struct.unpack('<I', header[12:16])[0]
        frag_count = struct.unpack('<I', header[40:44])[0]
        
        print(f"SquashFS信息:")
        print(f"  魔数: {magic}")
        print(f"  Inode数量: {inode_count}")
        print(f"  块大小: {block_size}")
        print(f"  分片数量: {frag_count}")
        
        # 提取整个SquashFS
        f.seek(offset)
        # 估算文件系统大小（从头部读取）
        bytes_used = struct.unpack('<I', header[48:52])[0]
        fs_data = f.read(bytes_used)
        
        with open(output_path, 'wb') as out:
            out.write(fs_data)
        
        print(f"  已提取到: {output_path}")
        print(f"  使用以下命令解包: unsquashfs {output_path}")

def analyze_firmware(firmware_path):
    """分析固件整体结构"""
    with open(firmware_path, 'rb') as f:
        data = f.read()
    
    file_size = len(data)
    print(f"固件文件: {firmware_path}")
    print(f"文件大小: {file_size} bytes ({file_size/1024/1024:.2f} MB)")
    print(f"MD5: {__import__('hashlib').md5(data).hexdigest()}")
    print(f"SHA256: {__import__('hashlib').sha256(data).hexdigest()}")
    
    # 查找文件系统
    print(f"\n[+] 搜索文件系统签名...")
    results = find_filesystem(firmware_path)
    
    if results:
        print(f"[+] 发现 {len(results)} 个文件系统标记:")
        for r in results:
            print(f"    类型: {r['type']}, 偏移: {r['offset']} ({r['hex_offset']})")
        
        # 提取第一个SquashFS
        for r in results:
            if r['type'] == 'squashfs':
                output = os.path.splitext(firmware_path)[0] + '_squashfs.bin'
                extract_squashfs(firmware_path, r['offset'], output)
                break
    else:
        print("[-] 未发现已知文件系统标记")
    
    # 查找ELF文件
    print(f"\n[+] 搜索ELF可执行文件...")
    elf_magic = b'\x7fELF'
    offset = 0
    elf_count = 0
    while True:
        pos = data.find(elf_magic, offset)
        if pos == -1:
            break
        elf_count += 1
        # 判断位数
        ei_class = data[pos + 4] if pos + 4 < len(data) else 0
        arch_type = "32位" if ei_class == 1 else "64位" if ei_class == 2 else "未知"
        print(f"    ELF #{elf_count}: 偏移 {pos} ({hex(pos)}), {arch_type}")
        offset = pos + 4
    
    print(f"\n共发现 {elf_count} 个ELF文件")

if __name__ == '__main__':
    import sys
    if len(sys.argv) < 2:
        print("用法: python3 firmware_extractor.py <固件文件>")
        sys.exit(1)
    analyze_firmware(sys.argv[1])
```

```python
        r'private[_-]?key\s*[=:]\s*["\']?([^"\'\s]+)',

        r'api[_-]?key\s*[=:]\s*["\']?([^"\'\s]+)',
    ],
    '证书': [
        r'-----BEGIN (RSA |EC )?PRIVATE KEY-----',
        r'-----BEGIN CERTIFICATE-----',
    ],
    '凭据': [
        r'admin\s*[:=]\s*([^\s]+)',
        r'root\s*[:=]\s*([^\s]+)',
        r'user\s*[:=]\s*([^\s]+)',
    ],
    '数据库': [
        r'(?:mysql|postgres|mongodb)://[^\s]+',
        r'(?:redis|mssql)://[^\s]+',
    ],
    'Token': [
        r'token\s*[=:]\s*["\']?([^"\'\s]+)',
        r'authorization\s*[:=]\s*[Bb]earer\s+([^\s]+)',
    ],
}

# 可疑文件名
SUSPICIOUS_FILES = [
    'passwd', 'shadow', 'htpasswd', '.htpasswd',
    'config', 'configuration', 'cfg',
    'credentials', 'secrets', 'private',
    'ssl', 'cert', 'certificate',
    '.env', 'env', 'environment',
    'shadow-', 'pwd.db', 'spwd.db',
]

def scan_file(file_path):
    """扫描单个文件中的敏感信息"""
    findings = []
    
    try:
        # 跳过二进制文件
        with open(file_path, 'rb') as f:
            chunk = f.read(4096)
            if b'\x00' in chunk:
                # 可能是二进制文件，尝试strings提取
                return scan_binary_strings(file_path)
    
        with open(file_path, 'r', errors='ignore') as f:
            content = f.read()
            line_num = 0
            for line in content.split('\n'):
                line_num += 1
                for category, patterns in PATTERNS.items():
                    for pattern in patterns:
                        matches = re.findall(pattern, line, re.IGNORECASE)
                        for match in matches:
                            if match and len(match) > 2:
                                findings.append({
                                    'category': category,
                                    'file': file_path,
                                    'line': line_num,
                                    'value': match[:100],  # 截断长值
                                    'context': line.strip()[:200]
                                })
    except Exception as e:
        pass
    
    return findings

def scan_binary_strings(file_path, min_length=4):
    """从二进制文件中提取字符串并扫描"""
    findings = []
    try:
        with open(file_path, 'rb') as f:
            data = f.read()
        
        # 提取可打印字符串
        strings = re.findall(b'[\x20-\x7e]{%d,}' % min_length, data)
        
        for s in strings:
            try:
                s_str = s.decode('ascii')
                for category, patterns in PATTERNS.items():
                    for pattern in patterns:
                        matches = re.findall(pattern, s_str, re.IGNORECASE)
                        for match in matches:
                            if match and len(match) > 2:
                                findings.append({
                                    'category': category,
                                    'file': file_path,
                                    'line': 0,
                                    'value': match[:100],
                                    'context': s_str[:200]
                                })
            except:
                pass
    except:
        pass
    
    return findings

def scan_directory(root_dir):
    """递归扫描目录"""
    all_findings = []
    file_count = 0
    
    for dirpath, dirnames, filenames in os.walk(root_dir):
        for filename in filenames:
            file_path = os.path.join(dirpath, filename)
            
            # 检查是否为可疑文件名
            for suspicious in SUSPICIOUS_FILES:
                if suspicious in filename.lower():
                    print(f"[!] 发现可疑文件: {file_path}")
                    break
            
            # 扫描文件内容
            findings = scan_file(file_path)
            if findings:
                all_findings.extend(findings)
                for f in findings:
                    print(f"[{f['category']}] {f['file']}:{f['line']} -> {f['value']}")
            
            file_count += 1
            if file_count % 100 == 0:
                print(f"[*] 已扫描 {file_count} 个文件...")
    
    return all_findings

def generate_report(findings, output_file='credentials_report.txt'):
    """生成凭据扫描报告"""
    with open(output_file, 'w', encoding='utf-8') as f:
        f.write("=" * 70 + "\n")
        f.write("固件凭据扫描报告\n")
        f.write("=" * 70 + "\n\n")
        
        # 按类别分组
        categories = {}
        for finding in findings:
            cat = finding['category']
            if cat not in categories:
                categories[cat] = []
            categories[cat].append(finding)
        
        for cat, items in sorted(categories.items()):
            f.write(f"\n{'='*50}\n")
            f.write(f"类别: {cat} (共 {len(items)} 项)\n")
            f.write(f"{'='*50}\n\n")
            
            for item in items:
                f.write(f"文件: {item['file']}\n")
                f.write(f"行号: {item['line']}\n")
                f.write(f"值: {item['value']}\n")
                f.write(f"上下文: {item['context']}\n")
                f.write("-" * 40 + "\n")
    
    print(f"\n[+] 报告已生成: {output_file}")
    print(f"[+] 共发现 {len(findings)} 个敏感信息")

if __name__ == '__main__':
    import sys
    if len(sys.argv) < 2:
        print("用法: python3 cred_scanner.py <固件文件系统目录>")
        sys.exit(1)
    
    root = sys.argv[1]
    print(f"[*] 开始扫描: {root}")
    findings = scan_directory(root)
    generate_report(findings)
```

## 3. 协议模糊测试

### 3.1 模糊测试概述

模糊测试（Fuzzing）是一种自动化漏洞挖掘技术，通过向目标系统发送大量非预期或畸形输入数据来触发异常行为。在工控领域，协议模糊测试是发现通信协议实现漏洞的重要手段。

```
工控协议模糊测试分类：
┌─────────────────────────────────────────────────────────┐
│                    模糊测试方法                           │
├──────────────────┬──────────────────┬───────────────────┤
│   基于变异        │   基于生成        │   混合方法         │
│  (Mutation)      │  (Generation)    │  (Hybrid)         │
├──────────────────┼──────────────────┼───────────────────┤
│ 对正常报文进行    │ 根据协议规范      │ 结合变异与生成     │
│ 随机修改        │ 从零构造报文      │ 使用协议模型       │
├──────────────────┼──────────────────┼───────────────────┤
│ 优点:快速上手     │ 优点:高覆盖率    │ 优点:平衡效率     │
│ 缺点:覆盖率低    │ 缺点:需协议规范   │ 缺点:实现复杂     │
└──────────────────┴──────────────────┴───────────────────┘
```

### 3.2 Modbus协议模糊测试

#### 3.2.1 Modbus协议结构

```
Modbus TCP报文结构:
┌─────────────────────────────────────────────────────┐
│ TPKT头 (4 bytes)                                     │
├──────────┬──────────┬──────────────────────────────┤
│ 事务ID    │ 协议ID   │ 长度       │ 单元ID          │
│ (2 bytes)│(2 bytes) │ (2 bytes)  │ (1 byte)        │
├──────────┴──────────┴────────────┴──────────────────┤
│ PDU (功能码 + 数据)                                   │
├──────────┬─────────────────────────────────────────┤
│ 功能码    │ 数据区                                   │
│ (1 byte)│ (变长)                                   │
└──────────┴─────────────────────────────────────────┘

常见功能码:
  0x01 - 读线圈
  0x02 - 读离散输入
  0x03 - 读保持寄存器
  0x04 - 读输入寄存器
  0x05 - 写单个线圈
  0x06 - 写单个寄存器
  0x0F - 写多个线圈
  0x10 - 写多个寄存器
  0x17 - 读写多个寄存器
```

#### 3.2.2 Modbus模糊测试实现

```python
#!/usr/bin/env python3
"""Modbus协议模糊测试工具"""
import socket
import struct
import random
import time
import logging
from datetime import datetime
from enum import IntEnum

# 日志配置
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(message)s',
    handlers=[
        logging.FileHandler('modbus_fuzz.log'),
        logging.StreamHandler()
    ]
)
logger = logging.getLogger(__name__)

class ModbusFunctionCode(IntEnum):
    READ_COILS = 0x01
    READ_DISCRETE_INPUTS = 0x02
    READ_HOLDING_REGISTERS = 0x03
    READ_INPUT_REGISTERS = 0x04
    WRITE_SINGLE_COIL = 0x05
    WRITE_SINGLE_REGISTER = 0x06
    WRITE_MULTIPLE_COILS = 0x0F
    WRITE_MULTIPLE_REGISTERS = 0x10
    READ_WRITE_MULTIPLE = 0x17
    MASK_WRITE_REGISTER = 0x16

class ModbusFuzzer:
    def __init__(self, target_ip, target_port=502, unit_id=1):
        self.target_ip = target_ip
        self.target_port = target_port
        self.unit_id = unit_id
        self.transaction_id = 0
        self.crash_count = 0
        self.success_count = 0
        self.error_count = 0
        self.anomalies = []
    
    def build_modbus_request(self, func_code, data=b''):
        """构建Modbus TCP请求"""
        self.transaction_id += 1
        protocol_id = 0  # Modbus协议
        length = 2 + len(data)  # 单元ID + 功能码 + 数据
        
        # TPKT + MBAP头
        header = struct.pack('>HHHBB',
            self.transaction_id,
            protocol_id,
            length,
            self.unit_id,
            func_code
        )
        
        return header + data
    
    def send_request(self, packet, timeout=3):
        """发送请求并检测响应"""
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(timeout)
            sock.connect((self.target_ip, self.target_port))
            sock.send(packet)
            
            response = sock.recv(4096)
            sock.close()
            
            # 分析响应
            if len(response) < 8:
                self.anomalies.append({
                    'type': '短响应',
                    'packet': packet.hex(),
                    'response': response.hex(),
                    'timestamp': datetime.now().isoformat()
                })
                logger.warning(f"异常短响应: {len(response)} bytes")
                return None
            
            # 检查异常响应
            resp_func = response[7]
            if resp_func & 0x80:
                # 异常响应
                exception_code = response[8] if len(response) > 8 else -1
                return ('exception', exception_code)
            else:
                return ('normal', response)
                
        except socket.timeout:
            self.crash_count += 1
            logger.error(f"超时 - 目标可能崩溃! Packet: {packet.hex()}")
            self.anomalies.append({
                'type': '超时/崩溃',
                'packet': packet.hex(),
                'timestamp': datetime.now().isoformat()
            })
            return ('timeout', None)
        except ConnectionRefusedError:
            self.error_count += 1
            logger.error("连接被拒绝")
            return ('refused', None)
        except Exception as e:
            self.error_count += 1
            logger.error(f"异常: {e}")
            return ('error', str(e))
    
    def fuzz_function_code(self):
        """模糊测试功能码字段"""
        logger.info("=== 功能码模糊测试 ===")
        
        # 1. 测试所有可能的功能码 (0x00 - 0xFF)
        for func_code in range(256):
            data = struct.pack('>HH', 0, 10)  # 读10个寄存器
            packet = self.build_modbus_request(func_code, data)
            result = self.send_request(packet)
            
            if result and result[0] == 'timeout':
                logger.critical(f"功能码 0x{func_code:02X} 导致超时!")
                self.crash_count += 1
            elif result and result[0] == 'normal':
                self.success_count += 1
                logger.info(f"功能码 0x{func_code:02X} 正常响应")
            
            time.sleep(0.1)  # 避免过载
    
    def fuzz_unit_id(self):
        """模糊测试单元ID字段"""
        logger.info("=== 单元ID模糊测试 ===")
        
        for unit_id in range(256):
            original_unit = self.unit_id
            self.unit_id = unit_id
            
            packet = self.build_modbus_request(
                ModbusFunctionCode.READ_HOLDING_REGISTERS,
                struct.pack('>HH', 0, 1)
            )
            result = self.send_request(packet)
            
            if result and result[0] == 'normal':
                logger.info(f"单元ID {unit_id} 有效")
            elif result and result[0] == 'exception':
                logger.info(f"单元ID {unit_id} 返回异常码 {result[1]}")
            
            self.unit_id = original_unit
            time.sleep(0.05)
    
    def fuzz_data_field(self, func_code=0x03):
        """模糊测试数据字段"""
        logger.info("=== 数据字段模糊测试 ===")
        
        # 1. 超长数据
        for length in [10, 100, 500, 1000, 5000, 10000]:
            data = bytes(random.randint(0, 255) for _ in range(length))
            packet = self.build_modbus_request(func_code, data)
            result = self.send_request(packet)
            
            if result and result[0] == 'timeout':
                logger.critical(f"超长数据({length} bytes)导致超时!")
            
            time.sleep(0.1)
        
        # 2. 特殊值
        special_values = [
            b'\x00' * 100,       # 全零
            b'\xff' * 100,       # 全FF
            b'\x00\x01\x02\x03' * 25,  # 递增模式
            b'\xfe\xed\xfa\xce' * 25,  # 魔数模式
            b'A' * 1000,         # 字符填充
            b'\x00' * 0xFFFF,    # 最大长度
        ]
        
        for i, data in enumerate(special_values):
            packet = self.build_modbus_request(func_code, data)
            result = self.send_request(packet)
            
            if result and result[0] == 'timeout':
                logger.critical(f"特殊值 #{i} 导致超时!")
                self.crash_count += 1
            
            time.sleep(0.1)
    
    def fuzz_register_address(self):
        """模糊测试寄存器地址"""
        logger.info("=== 寄存器地址模糊测试 ===")
        
        # 测试边界值
        addresses = [0, 1, 0xFFFF, 0x7FFF, 0x8000, 0xFFFE, 0xFFFF]
        
        for addr in addresses:
            # 读操作
            data = struct.pack('>HH', addr, 1)
            packet = self.build_modbus_request(0x03, data)
            result = self.send_request(packet)
            
            if result and result[0] == 'normal':
                logger.info(f"寄存器地址 0x{addr:04X} 可读")
            elif result and result[0] == 'exception':
                logger.info(f"寄存器地址 0x{addr:04X} 异常码: {result[1]}")
            
            # 写操作
            data = struct.pack('>HH', addr, 0x1234)
            packet = self.build_modbus_request(0x06, data)
            result = self.send_request(packet)
            
            if result and result[0] == 'normal':
                logger.warning(f"寄存器地址 0x{addr:04X} 可写!")
            
            time.sleep(0.05)
    
    def fuzz_protocol_variants(self):
        """协议变体模糊测试"""
        logger.info("=== 协议变体模糊测试 ===")
        
        # 1. 修改协议ID
        for proto_id in [1, 2, 0xFFFF]:
            self.transaction_id += 1
            packet = struct.pack('>HHHB', 
                self.transaction_id,
                proto_id,  # 修改协议ID
                6,
                self.unit_id
            ) + bytes([0x03, 0x00, 0x00, 0x00, 0x01])
            
            result = self.send_request(packet)
            if result and result[0] == 'normal':
                logger.warning(f"非标准协议ID {proto_id} 被接受!")
        
        # 2. 长度字段不匹配
        for length_val in [0, 1, 255, 0xFFFF]:
            self.transaction_id += 1
            packet = struct.pack('>HHHB',
                self.transaction_id,
                0,
                length_val,  # 修改长度字段
                self.unit_id
            ) + bytes([0x03, 0x00, 0x00, 0x00, 0x01])
            
            result = self.send_request(packet)
            if result and result[0] == 'timeout':
                logger.critical(f"长度字段 {length_val} 导致崩溃!")
        
        # 3. 分片和重组测试
        # 发送半个包，看目标如何处理
        normal_packet = self.build_modbus_request(0x03, struct.pack('>HH', 0, 1))
        
        # 发送半个包
        half_packet = normal_packet[:len(normal_packet)//2]
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(3)
            sock.connect((self.target_ip, self.target_port))
            sock.send(half_packet)
            time.sleep(1)
            try:
                response = sock.recv(4096)
                if response:
                    logger.info(f"半包测试有响应: {response.hex()}")
            except:
                logger.info("半包测试无响应 (可能等待更多数据)")
            sock.close()
        except Exception as e:
            logger.error(f"半包测试异常: {e}")
    
    def run_full_fuzz(self):
        """运行完整模糊测试套件"""
        logger.info("=" * 60)
        logger.info(f"Modbus模糊测试开始 - 目标: {self.target_ip}:{self.target_port}")
        logger.info("=" * 60)
        
        start_time = time.time()
        
        try:
            self.fuzz_function_code()
            self.fuzz_unit_id()
            self.fuzz_register_address()
            self.fuzz_data_field()
            self.fuzz_protocol_variants()
        except KeyboardInterrupt:
            logger.warning("用户中断测试")
        
        elapsed = time.time() - start_time
        
        logger.info("=" * 60)
        logger.info("测试完成 - 统计信息:")
        logger.info(f"  总用时: {elapsed:.1f}秒")
        logger.info(f"  正常响应: {self.success_count}")
        logger.info(f"  异常响应: {self.error_count}")
        logger.info(f"  崩溃/超时: {self.crash_count}")
        logger.info(f"  异常事件: {len(self.anomalies)}")
        logger.info("=" * 60)
        
        # 保存异常报告
        if self.anomalies:
            with open('modbus_anomalies.txt', 'w') as f:
                for a in self.anomalies:
                    f.write(f"类型: {a['type']}\n")
                    f.write(f"时间: {a['timestamp']}\n")
                    if 'packet' in a:
                        f.write(f"数据包: {a['packet']}\n")
                    if 'response' in a:
                        f.write(f"响应: {a['response']}\n")
                    f.write("-" * 40 + "\n")
            logger.info("异常报告已保存: modbus_anomalies.txt")

if __name__ == '__main__':
    import argparse
    parser = argparse.ArgumentParser(description='Modbus协议模糊测试工具')
    parser.add_argument('target', help='目标IP地址')
    parser.add_argument('-p', '--port', type=int, default=502, help='目标端口')
    parser.add_argument('-u', '--unit', type=int, default=1, help='Modbus单元ID')
    args = parser.parse_args()
    
    fuzzer = ModbusFuzzer(args.target, args.port, args.unit)
    fuzzer.run_full_fuzz()
```

### 3.3 S7协议模糊测试

```python
#!/usr/bin/env python3
"""S7协议模糊测试工具"""
import socket
import struct
import random
import time
import logging

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(message)s',
    handlers=[logging.StreamHandler(), logging.FileHandler('s7_fuzz.log')]
)
logger = logging.getLogger(__name__)

class S7Fuzzer:
    def __init__(self, target_ip, target_port=102):
        self.target_ip = target_ip
        self.target_port = target_port
        self.local_tsap = 0x0100
        self.remote_tsap = 0x0100
        self.connection_id = 0
    
    def build_tpkt(self, payload):
        """构建TPKT头"""
        length = 4 + len(payload)
        return struct.pack('>BBH', 3, 0, length)
    
    def build_cotp_connect(self):
        """构建COTP连接请求"""
        cotp = bytes([
            0x11,       # 长度
            0xE0,       # PDU类型: Connect Request
            0x00, 0x01, # 目标引用
            0x00, 0x01, # 源引用
            0x00,       # 类
            # 参数: TSAP
            0xC0,       # 参数代码: Called TSAP
            0x02,       # 参数长度
            (self.remote_tsap >> 8) & 0xFF,
            self.remote_tsap & 0xFF,
            0xC1,       # 参数代码: Calling TSAP
            0x02,
            (self.local_tsap >> 8) & 0xFF,
            self.local_tsap & 0xFF,
            # 参数: TPDU大小
            0xC2,       # 参数代码
            0x01,       # 参数长度
            0x0A,       # TPDU大小: 1024
        ])
        return cotp
    
    def build_s7_request(self, pdu_type, func_group, sub_func, data=b''):
        """构建S7协议请求"""
        # S7头
        s7_header = struct.pack('>BBHHHH',
            0x32,           # 协议ID
            pdu_type,       # PDU类型 (0x01=请求)
            0x0000,         # 保留
            self._next_id(), # PDU引用
            len(data) + 4,  # 参数长度
            len(data)       # 数据长度
        )
        
        # 参数区
        param = struct.pack('>BBB',
            func_group,     # 功能组
            sub_func,       # 子功能
            0x12 if func_group == 0x04 else 0x00  # 子功能类型
        )
        
        return s7_header + param[:4] + data
    
    def _next_id(self):
        self.connection_id = (self.connection_id + 1) & 0xFFFF
        return self.connection_id
    
    def connect(self):
        """建立S7连接"""
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(5)
            sock.connect((self.target_ip, self.target_port))
            
            # 发送COTP连接请求
            cotp = self.build_cotp_connect()
            tpkt = self.build_tpkt(cotp)
            sock.send(tpkt + cotp)
            
            response = sock.recv(1024)
            if len(response) >= 7 and response[5] == 0xD0:
                logger.info("COTP连接建立成功")
                
                # 发送S7通信设置请求
                setup = struct.pack('>BBHHHH',
                    0x32,       # 协议ID
                    0x01,       # 请求
                    0x0000,     # 保留
                    self._next_id(),
                    0x0008,     # 参数长度
                    0x0000      # 数据长度
                )
                setup_param = struct.pack('>BBHBBH',
                    0xF0,       # 功能: 通信设置
                    0x00,       # 子功能
                    0x0001,     # 保留
                    0x00, 0x01, # PDU大小
                    0x04E2      # PDU大小: 1250
                )
                
                tpkt = self.build_tpkt(setup + setup_param)
                sock.send(tpkt + setup + setup_param)
                
                response = sock.recv(1024)
                if len(response) > 0:
                    logger.info("S7通信设置完成")
                    return sock
            
            logger.error("COTP连接失败")
            return None
        except Exception as e:
            logger.error(f"连接失败: {e}")
            return None
    
    def fuzz_s7_header(self, sock):
        """模糊测试S7协议头"""
        logger.info("=== S7协议头模糊测试 ===")
        
        # 修改协议ID
        for proto_id in [0x00, 0x31, 0x33, 0xFF]:
            packet = struct.pack('>BBHHHH',
                proto_id,  # 修改协议ID
                0x01, 0x0000, self._next_id(),
                0x0004, 0x0000
            )
            self._send_and_check(sock, packet, f"协议ID=0x{proto_id:02X}")
        
        # 修改PDU类型
        for pdu_type in range(256):
            packet = struct.pack('>BBHHHH',
                0x32,
                pdu_type,  # 修改PDU类型
                0x0000, self._next_id(),
                0x0004, 0x0000
            )
            result = self._send_and_check(sock, packet, f"PDU类型=0x{pdu_type:02X}")
            if result == 'timeout':
                logger.critical(f"PDU类型 0x{pdu_type:02X} 导致超时!")
            
            time.sleep(0.05)
    
    def fuzz_read_area(self, sock):

        for area_name, area_code in area_types.items():
            # 构建读请求
            read_data = struct.pack('>BBBBHH',
                0x12,       # 变量规格头
                0x0A,       # 长度规格
                0x10,       # 语法ID
                area_code,  # 区域类型
                1,          # DB号
                0,          # 地址
            ) + struct.pack('>HH', 1, 0)  # 长度和偏移

                0x32, 0x01, 0x0000,
                self._next_id(),
                len(read_data), 0
            ) + read_data

            elif result == 'timeout':

        for db_num in [0, 1, 2, 100, 255, 0xFFFF]:
            read_data = struct.pack('>BBBBHH',
                0x12, 0x0A, 0x10, 0x85,
                db_num,  # DB号
                0,       # 地址

            s7_pdu = struct.pack('>BBHHHH',
                0x32, 0x01, 0x0000,
                self._next_id(),

        logger.info("=== 写操作模糊测试 ===")

            if result == 'normal':

            # S7密码验证请求
            pwd_data = struct.pack('>BB',
                0x26, 0x02  # 密码子功能
            ) + password.encode('latin-1').ljust(8, b'\x00')
            
            s7_pdu = struct.pack('>BBHHHH',
                0x32, 0x28, 0x0000,
                self._next_id(),

        """发送数据并检查响应"""
        try:
            tpkt = self.build_tpkt(pdu)
            sock.send(tpkt + pdu)
            
            response = sock.recv(4096)
            
            if len(response) == 0:
                logger.warning(f"[{description}] 空响应")
                return 'empty'
            
            # 检查是否有异常
            if len(response) < 12:
                logger.warning(f"[{description}] 短响应: {response.hex()}")
                return 'short'
            
            return 'normal'
            
        except socket.timeout:
            logger.error(f"[{description}] 超时 - 可能崩溃!")
            return 'timeout'
        except Exception as e:
            logger.error(f"[{description}] 异常: {e}")
            return 'error'
    
    def run(self):
        """运行S7模糊测试"""
        logger.info("=" * 60)
        logger.info(f"S7模糊测试开始 - 目标: {self.target_ip}:{self.target_port}")
        logger.info("=" * 60)
        
        sock = self.connect()
        if not sock:
            logger.error("无法建立连接")
            return
        
        try:
            self.fuzz_s7_header(sock)
            self.fuzz_read_area(sock)
            self.fuzz_db_read(sock)
            self.fuzz_write_operations(sock)
            self.fuzz_password_operations(sock)
        except KeyboardInterrupt:
            logger.warning("用户中断")
        finally:
            sock.close()
            logger.info("测试完成")
```

```python
#!/usr/bin/env python3
"""DNP3协议模糊测试工具"""
import socket
import struct
import random
import time
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s [%(levelname)s] %(message)s')
logger = logging.getLogger(__name__)

class DNP3Fuzzer:
    def __init__(self, target_ip, target_port=20000, source_addr=1, dest_addr=1):
        self.target_ip = target_ip
        self.target_port = target_port
        self.source_addr = source_addr
        self.dest_addr = dest_addr
    
    def compute_crc(self, data):
        """计算DNP3 CRC-16"""
        crc_table = [
            0x0000, 0x3656, 0x6CAC, 0x5EFA, 0xD594, 0xE3C2, 0xB938, 0x8F6E,
            0x0E2D, 0x387B, 0x6281, 0x54D7, 0xDFB9, 0xE9EF, 0xB315, 0x8543,
            # ... 完整的CRC表 (256项)
        ]
        # 简化版CRC计算
        crc = 0x0000
        for byte in data:
            crc = ((crc << 8) ^ crc_table[((crc >> 8) ^ byte) & 0xFF]) & 0xFFFF
        return crc
    
    def build_link_header(self, frame_type='request'):
        """构建DNP3链路层头"""
        # 起始字节
        start = bytes([0x05, 0x64])
        
        # 长度 (占位，后面填充)
        length = 5  # 最小长度
        
        # 控制域
        if frame_type == 'request':
            control = 0x44  # DIR=1, PRM=1, FCB=0, FCV=0, FC=4
        else:
            control = 0x40  # DIR=0, PRM=0
        
        # 目的地址
        dest = struct.pack('<H', self.dest_addr)
        # 源地址
        source = struct.pack('<H', self.source_addr)
        
        # CRC
        header = start + bytes([length]) + bytes([control]) + dest + source
        crc = self.compute_crc(header[:8])
        
        return header + struct.pack('<H', crc)
    
    def build_application_request(self, func_code, data=b''):
        """构建DNP3应用层请求"""
        # 应用层控制
        app_ctl = 0x01  # FIR=1, FIN=1, SEQ=1
        
        # 功能码
        func = bytes([func_code])
        
        return bytes([app_ctl]) + func + data
    
    def fuzz_function_codes(self, sock):
        """模糊测试DNP3功能码"""
        logger.info("=== DNP3功能码模糊测试 ===")
        
        # DNP3功能码定义
        func_codes = {
            0x00: '读',
            0x01: '写',
            0x02: '选择',
            0x03: '操作',
            0x04: '直接操作',
            0x07: '延迟操作',
            0x09: '冻结',
            0x0A: '冻结清除',
            0x0D: '响应数据',
            0x0E: '写响应',
            0x12: '存储配置',
            0x13: '响应配置',
        }
        
        for func_code in range(256):
            app_data = self.build_application_request(func_code)
            link_header = self.build_link_header()
            
            # 构建完整帧
            frame = link_header + app_data
            
            try:
                sock.send(frame)
                response = sock.recv(4096)
                
                if len(response) > 0:
                    logger.info(f"功能码 0x{func_code:02X} ({func_codes.get(func_code, '未知')}) 响应: {len(response)} bytes")
                else:
                    logger.warning(f"功能码 0x{func_code:02X} 空响应")
                
            except socket.timeout:
                logger.critical(f"功能码 0x{func_code:02X} 导致超时!")
            except Exception as e:
                logger.error(f"功能码 0x{func_code:02X} 异常: {e}")
            
            time.sleep(0.1)
    
    def fuzz_addresses(self, sock):
        """模糊测试地址字段"""
        logger.info("=== 地址字段模糊测试 ===")
        
        # 测试不同的源/目标地址组合
        address_pairs = [
            (0, 0),
            (1, 1),
            (0xFFFF, 0xFFFF),
            (0x10000, 0),  # 溢出
            (0xFFFE, 0xFFFF),
            (0x3FFF, 0x3FFF),  # 最大有效地址
        ]
        
        for src, dst in address_pairs:
            self.source_addr = src
            self.dest_addr = dst
            
            link_header = self.build_link_header()
            app_data = self.build_application_request(0x00)  # 读请求
            
            frame = link_header + app_data
            
            try:
                sock.send(frame)
                response = sock.recv(4096)
                logger.info(f"地址(src={src}, dst={dst}) 响应: {len(response)} bytes")
            except socket.timeout:
                logger.critical(f"地址(src={src}, dst={dst}) 导致超时!")
            except Exception as e:
                logger.error(f"地址(src={src}, dst={dst}) 异常: {e}")
            
            time.sleep(0.1)
    
    def fuzz_data_sizes(self, sock):
        """模糊测试数据大小"""
        logger.info("=== 数据大小模糊测试 ===")
        
        for size in [0, 1, 100, 500, 1000, 2000, 5000, 10000]:
            data = bytes(random.randint(0, 255) for _ in range(size))
            app_data = self.build_application_request(0x01, data)  # 写请求
            link_header = self.build_link_header()

        logger.info("=" * 60)

        logger.info("=" * 60)

            sock.settimeout(5)
            sock.connect((self.target_ip, self.target_port))

            self.fuzz_addresses(sock)
            self.fuzz_data_sizes(sock)
            
            sock.close()
        except Exception as e:
            logger.error(f"连接失败: {e}")
```

## 4. 漏洞验证方法

### 4.1 漏洞验证原则

在工控系统中，漏洞验证需要遵循"最小影响"原则，确保验证过程不会对生产系统造成实际损害。

```
验证原则：
1. 隔离环境验证 - 在独立的实验室环境中验证
2. 非破坏性测试 - 使用只读方式验证漏洞存在性
3. 影响评估 - 评估漏洞被利用的实际风险
4. 可复现性 - 确保漏洞可稳定复现
5. 时间约束 - 限制测试持续时间
```

### 4.2 缓冲区溢出验证

```python
#!/usr/bin/env python3
"""缓冲区溢出漏洞验证工具"""
import socket
import struct
import time

class BufferOverflowVerifier:
    def __init__(self, target_ip, target_port):
        self.target_ip = target_ip
        self.target_port = target_port
        self.critical_length = None
    
    def find_crash_point(self, protocol='modbus'):
        """逐步增加数据长度，定位崩溃点"""
        print(f"[*] 开始定位崩溃点 - 协议: {protocol}")
        
        lengths = list(range(100, 5000, 100)) + [5000, 10000, 50000]
        
        for length in lengths:
            try:
                sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                sock.settimeout(5)
                sock.connect((self.target_ip, self.target_port))
                
                if protocol == 'modbus':
                    # Modbus TCP
                    tpkt = struct.pack('>BBH', 3, 0, 6 + length)
                    mbap = struct.pack('>HHBB', 1, 0, length + 1, 1)
                    payload = bytes([0x06]) + b'A' * length  # 写寄存器
                    
                    packet = tpkt + mbap[:6] + payload
                    
                elif protocol == 's7':
                    # S7协议
                    tpkt = struct.pack('>BBH', 3, 0, 10 + length)
                    cotp = bytes([0x02, 0xF0, 0x80])  # Data传输
                    s7 = struct.pack('>BBHHHH', 0x32, 0x01, 0, 1, length, 0)
                    payload = b'A' * length
                    
                    packet = tpkt + cotp + s7 + payload
                
                sock.send(packet)
                
                try:
                    response = sock.recv(4096)
                    print(f"  长度 {length}: 正常响应 ({len(response)} bytes)")
                except socket.timeout:
                    print(f"  长度 {length}: [!] 超时 - 可能崩溃!")
                    self.critical_length = length
                    
                    # 等待设备恢复
                    time.sleep(5)
                    
                    # 验证是否真的崩溃
                    if not self._check_alive():
                        print(f"  [!] 设备在长度 {length} 时崩溃!")
                        return length
                    else:
                        print(f"  设备已恢复")
                
                sock.close()
                
            except ConnectionRefusedError:
                print(f"  长度 {length}: 连接被拒绝 - 设备可能崩溃")
                self.critical_length = length
                return length
            except Exception as e:
                print(f"  长度 {length}: 异常 - {e}")
            
            time.sleep(0.5)
        
        print(f"[*] 未找到崩溃点")
        return None
    
    def _check_alive(self):
        """检查目标是否存活"""
        for _ in range(3):
            try:
                sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                sock.settimeout(3)
                sock.connect((self.target_ip, self.target_port))
                sock.close()
                return True
            except:
                time.sleep(2)
        return False
    
    def binary_search_crash_point(self, low, high):
        """二分查找精确崩溃点"""
        if low > high:
            return low
        
        mid = (low + high) // 2
        
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(5)
            sock.connect((self.target_ip, self.target_port))
            
            payload = b'A' * mid
            sock.send(payload)
            
            try:
                response = sock.recv(4096)
                sock.close()
                # 设备正常，向上搜索
                return self.binary_search_crash_point(mid + 1, high)
            except socket.timeout:
                sock.close()
                # 设备崩溃，向下搜索
                time.sleep(5)
                return self.binary_search_crash_point(low, mid - 1)
        
        except:
            return self.binary_search_crash_point(low, mid - 1)
    
    def verify_overflow(self, crash_length):
        """验证溢出是否可控"""
        print(f"\n[*] 验证溢出可控性 (崩溃长度: {crash_length})")
        
        # 使用模式字符串确定偏移
        pattern = self._generate_pattern(crash_length + 200)
        
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(5)
            sock.connect((self.target_ip, self.target_port))
            sock.send(pattern)
            
            try:
                response = sock.recv(4096)
            except:
                pass
            
            sock.close()
        except:
            pass
        
        # 如果能获取崩溃信息，分析EIP覆盖偏移
        print(f"[*] 需要通过调试器获取EIP值来确定精确偏移")
        print(f"[*] 使用 pattern_offset 工具计算偏移")
    
    def _generate_pattern(self, length):
        """生成唯一模式字符串"""
        pattern = b''
        upper = ord('A')
        lower = ord('a')
        digit = ord('0')
        
        while len(pattern) < length:
            for u in range(26):
                for l in range(26):
                    for d in range(10):
                        if len(pattern) >= length:
                            return pattern
                        pattern += bytes([upper + u, lower + l, digit + d])
        
        return pattern[:length]

if __name__ == '__main__':
    import argparse
    parser = argparse.ArgumentParser(description='缓冲区溢出漏洞验证工具')
    parser.add_argument('target', help='目标IP')
    parser.add_argument('-p', '--port', type=int, required=True, help='目标端口')
    parser.add_argument('--protocol', default='modbus', choices=['modbus', 's7', 'dnp3'])
    args = parser.parse_args()
    
    verifier = BufferOverflowVerifier(args.target, args.port)
    crash_point = verifier.find_crash_point(args.protocol)
    
    if crash_point:
        print(f"\n[+] 发现崩溃点: {crash_point} bytes")
        verifier.verify_overflow(crash_point)
```

```python
            sock.connect((self.target_ip, port))
            
            # 不发送任何认证，直接读取数据
            # 读保持寄存器 (功能码0x03, 地址0, 数量1)
            tpkt = struct.pack('>BBH', 3, 0, 6)
            mbap = struct.pack('>HHBB', 1, 0, 2, 1)
            pdu = bytes([0x03, 0x00, 0x00, 0x00, 0x01])
            
            sock.send(tpkt + mbap + pdu)
            response = sock.recv(4096)
            sock.close()
            
            if len(response) >= 9:
                func_code = response[7]
                if func_code == 0x03:
                    byte_count = response[8]
                    print(f"  [!] 未授权读取成功! 返回 {byte_count} 字节数据")
                    print(f"  [!] 响应: {response.hex()}")
                    return True
                elif func_code & 0x80:
                    print(f"  [-] 返回异常码: {response[8]}")
                    return False
            else:
                print(f"  [-] 响应异常")
                return False
                
        except Exception as e:
            print(f"  [-] 连接失败: {e}")
            return False
    
    def check_s7_unauthorized(self, port=102):
        """验证S7协议未授权访问"""
        print(f"\n[*] 检查S7协议未授权访问 ({self.target_ip}:{port})")
        
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(5)
            sock.connect((self.target_ip, port))
            
            # COTP连接请求 (无认证)
            tpkt = struct.pack('>BBH', 3, 0, 22)
            cotp = bytes([
                0x11, 0xE0, 0x00, 0x01, 0x00, 0x01, 0x00,
                0xC0, 0x02, 0x01, 0x00,
                0xC1, 0x02, 0x01, 0x02,
                0xC2, 0x01, 0x0A
            ])
            
            sock.send(tpkt + cotp)
            response = sock.recv(1024)
            
            if len(response) >= 7 and response[5] == 0xD0:
                print(f"  [!] COTP连接成功 (无认证)")
                
                # 尝试读取设备信息
                setup = struct.pack('>BBHHHH', 0x32, 0x01, 0, 1, 8, 0)
                setup_param = struct.pack('>BBHBBH', 0xF0, 0, 1, 0, 1, 0x04E2)
                
                tpkt = struct.pack('>BBH', 3, 0, len(setup + setup_param))
                sock.send(tpkt + setup + setup_param)
                response = sock.recv(1024)
                
                if len(response) > 0:
                    print(f"  [!] S7通信建立成功 (无认证)")
                    
                    # 尝试读取标志位区
                    read_data = struct.pack('>BBBBHH', 0x12, 0x0A, 0x10, 0x84, 0, 0)
                    read_data += struct.pack('>HH', 1, 0)
                    
                    s7_pdu = struct.pack('>BBHHHH', 0x32, 0x01, 0, 2, len(read_data), 0)
                    
                    tpkt = struct.pack('>BBH', 3, 0, len(s7_pdu + read_data))
                    sock.send(tpkt + s7_pdu + read_data)
                    response = sock.recv(1024)
                    
                    if len(response) > 12:
                        print(f"  [!] 成功读取PLC数据 (无认证)")
                        print(f"  [!] 响应: {response.hex()}")
                        return True
            
            sock.close()
            return False
            
        except Exception as e:
            print(f"  [-] 连接失败: {e}")
            return False

    def check_telnet_unauthorized(self, port=23):
```

```python
#!/usr/bin/env python3
"""Modbus从站模拟器 - 用于模糊测试目标"""
from pyModbusTCP.server import ModbusServer
import logging
import sys
import random

logging.basicConfig(level=logging.INFO, format='%(asctime)s [%(levelname)s] %(message)s')
logger = logging.getLogger(__name__)

class ModbusSlaveSimulator:
    """模拟Modbus从站设备"""
    
    def __init__(self, host='0.0.0.0', port=502):
        self.host = host
        self.port = port
        
        # 初始化数据区
        self.coils = [False] * 10000       # 线圈
        self.discrete_inputs = [False] * 10000  # 离散输入
        self.holding_registers = [0] * 10000   # 保持寄存器
        self.input_registers = [0] * 10000      # 输入寄存器
        
        # 设置一些初始值
        for i in range(100):
            self.coils[i] = random.choice([True, False])
            self.holding_registers[i] = random.randint(0, 65535)
            self.input_registers[i] = random.randint(0, 65535)
        
        logger.info(f"Modbus从站模拟器初始化完成 - {host}:{port}")
        logger.info(f"数据区大小: 线圈={len(self.coils)}, "
                    f"保持寄存器={len(self.holding_registers)}")
    
    def run(self):
        """启动Modbus服务器"""
        try:
            server = ModbusServer(
                host=self.host,
                port=self.port,
                no_block=True
            )
            
            server.start()
            logger.info("Modbus从站启动成功")
            logger.info("等待连接...")
            
            import time
            while True:
                time.sleep(1)
                
        except KeyboardInterrupt:
            logger.info("停止服务器")
            server.stop()
        except Exception as e:
            logger.error(f"启动失败: {e}")
            sys.exit(1)

if __name__ == '__main__':
    import argparse
    parser = argparse.ArgumentParser(description='Modbus从站模拟器')
    parser.add_argument('--host', default='0.0.0.0', help='监听地址')
    parser.add_argument('--port', type=int, default=502, help='监听端口')
    args = parser.parse_args()
    
    simulator = ModbusSlaveSimulator(args.host, args.port)
    simulator.run()
```

### 7.4 Wireshark自定义协议解析器

```lua
-- Wireshark Modbus协议解析器增强版
-- 文件: modbus_enhanced.lua

-- 协议定义
local modbus_proto = Proto("ModbusEnhanced", "Modbus TCP Enhanced")

-- 字段定义
local f_transaction_id = ProtoField.uint16("modbus.transaction_id", "Transaction ID", base.DEC)
local f_protocol_id = ProtoField.uint16("modbus.protocol_id", "Protocol ID", base.DEC)
local f_length = ProtoField.uint16("modbus.length", "Length", base.DEC)
local f_unit_id = ProtoField.uint8("modbus.unit_id", "Unit ID", base.DEC)
local f_func_code = ProtoField.uint8("modbus.func_code", "Function Code", base.HEX)
local f_exception_code = ProtoField.uint8("modbus.exception_code", "Exception Code", base.HEX)
local f_data = ProtoField.bytes("modbus.data", "Data")

modbus_proto.fields = {
    f_transaction_id, f_protocol_id, f_length,
    f_unit_id, f_func_code, f_exception_code, f_data
}

-- 功能码名称映射
local func_names = {
    [0x01] = "Read Coils",
    [0x02] = "Read Discrete Inputs",
    [0x03] = "Read Holding Registers",
    [0x04] = "Read Input Registers",
    [0x05] = "Write Single Coil",
    [0x06] = "Write Single Register",
    [0x07] = "Read Exception Status",
    [0x08] = "Diagnostic",
    [0x0F] = "Write Multiple Coils",
    [0x10] = "Write Multiple Registers",
    [0x11] = "Report Slave ID",
    [0x14] = "Read File Record",
    [0x15] = "Write File Record",
    [0x16] = "Mask Write Register",
    [0x17] = "Read Write Multiple Registers",
    [0x18] = "Read FIFO Queue",
    [0x2B] = "Encapsulated Interface Transport",
}

-- 异常码名称映射
local exception_names = {
    [0x01] = "Illegal Function",
    [0x02] = "Illegal Data Address",
    [0x03] = "Illegal Data Value",
    [0x04] = "Slave Device Failure",
    [0x05] = "Acknowledge",
    [0x06] = "Slave Device Busy",
    [0x08] = "Memory Parity Error",
    [0x0A] = "Gateway Path Unavailable",
    [0x0B] = "Gateway Target No Response",
}

-- 解析器
function modbus_proto.dissector(buffer, pinfo, tree)
    local min_len = 8  -- MBAP头最小长度
    if buffer:len() < min_len then return 0 end
    
    pinfo.cols.protocol = "Modbus Enhanced"
    
    local subtree = tree:add(modbus_proto, buffer(), "Modbus TCP")
    
    -- MBAP头
    local trans_id = buffer(0, 2):uint()
    local proto_id = buffer(2, 2):uint()
    local length = buffer(4, 2):uint()
    local unit_id = buffer(6, 1):uint()
    
    subtree:add(f_transaction_id, buffer(0, 2))
    subtree:add(f_protocol_id, buffer(2, 2))
    subtree:add(f_length, buffer(4, 2))
    subtree:add(f_unit_id, buffer(6, 1))
    
    -- PDU
    if buffer:len() > 7 then
        local func_code = buffer(7, 1):uint()
        
        local func_item = subtree:add(f_func_code, buffer(7, 1))
        local func_name = func_names[func_code & 0x7F] or "Unknown"
        func_item:append_text(" (" .. func_name .. ")")
        
        -- 检查是否为异常响应
        if func_code & 0x80 ~= 0 then
            pinfo.cols.info = "Modbus Exception Response: " .. func_name
            if buffer:len() > 8 then
                local exc_code = buffer(8, 1):uint()
                local exc_item = subtree:add(f_exception_code, buffer(8, 1))
                local exc_name = exception_names[exc_code] or "Unknown"
                exc_item:append_text(" (" .. exc_name .. ")")
            end
        else
            pinfo.cols.info = "Modbus " .. func_name
        end
        
        -- 数据区
        if buffer:len() > 8 then
            subtree:add(f_data, buffer(8))
        end
        
        -- 异常检测
        if length > 255 then
            pinfo.cols.info:append(" [WARNING: Abnormal Length]")
        end
        if proto_id ~= 0 then
            pinfo.cols.info:append(" [WARNING: Non-standard Protocol ID]")
        end
    end
    
    return buffer:len()
end

-- 注册解析器
register_tcp_table_dissector(tcp.port_table, 502, modbus_proto)
```

### 9.2 伦理准则

进行工控漏洞研究时必须遵守以下伦理准则：

1. **授权原则**：仅对授权范围内的设备和系统进行测试
2. **无害原则**：确保测试不会导致设备损坏或生产中断
3. **最小影响原则**：尽量减少测试对生产系统的影响
4. **负责任披露原则**：通过正当渠道向厂商报告漏洞
5. **不利用原则**：不利用发现的漏洞进行攻击或牟利
