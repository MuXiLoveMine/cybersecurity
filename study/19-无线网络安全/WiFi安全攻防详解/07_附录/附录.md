### 6.2 常用端口和协议

```
WiFi 相关端口和协议：

EAPoL (Extensible Authentication Protocol over LAN):
├── EtherType: 0x888E
├── 用于 802.1X 认证和密钥交换
└── 四次握手通过 EAPoL-Key 帧传输

RADIUS:
├── 认证端口: UDP 1812
├── 计费端口: UDP 1813
└── 旧标准: UDP 1645/1646

CAPWAP (Control and Provisioning of Wireless Access Points):
├── 数据端口: UDP 5247
├── 控制端口: UDP 5246
└── 用于 AP 与控制器通信

HTTP/HTTPS (Captive Portal):
├── HTTP: TCP 80
├── HTTPS: TCP 443
└── Portal 重定向页面
```

### 6.3 安全检查清单

```
WiFi 安全检查清单：

基础配置:
[ ] 使用 WPA3（或至少 WPA2-AES）
[ ] 禁用 WEP 和 WPA-TKIP
[ ] 禁用 WPS 功能
[ ] 修改默认管理员密码
[ ] 修改默认 SSID
[ ] 禁用远程管理
[ ] 更新最新固件

企业安全:
[ ] 部署 802.1X 认证
[ ] 使用 EAP-TLS 双向证书认证
[ ] 配置 RADIUS 服务器冗余
[ ] 部署 WIDS/WIPS
[ ] VLAN 隔离无线网络
[ ] 配置防火墙策略
[ ] 定期安全审计

客户端安全:
[ ] 配置证书验证
[ ] 禁用自动连接未知网络
[ ] 使用 VPN 加密无线流量
[ ] 定期更新驱动和固件
[ ] 启用 PMF（管理帧保护）

物理安全:
[ ] AP 部署在安全位置
[ ] 控制信号覆盖范围
[ ] 有线侧端口安全
[ ] 定期物理巡查
```
