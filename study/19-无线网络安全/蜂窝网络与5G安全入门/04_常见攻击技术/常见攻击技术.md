# 常见攻击技术

### 4.1 IMSI捕手（IMSI Catcher）

#### 4.1.1 攻击原理

IMSI捕手（IMSI Catcher）是一种能够获取用户IMSI（国际移动用户识别码）的设备。它本质上是一个伪基站（Fake BTS/Cell），通过伪装成合法基站，诱使终端向其发送IMSI。

**工作原理：**
1. 攻击者在目标区域设置伪基站，使用与目标运营商相同的频率
2. 伪基站发射较强的信号，使附近的终端认为这是一个更好的小区
3. 终端尝试接入伪基站，发起位置更新或业务请求
4. 在身份识别阶段，网络（伪基站）向终端请求身份信息
5. 终端以明文形式发送IMSI
6. 攻击者捕获IMSI后，通常释放连接或引导终端返回真实网络

#### 4.1.2 技术细节

**伪基站配置：**
- **广播信道配置**：伪基站需要广播正确的系统信息，包括MCC/MNC、LAC/CI等
- **功率设置**：通常设置比周围基站略高的功率，以吸引终端接入
- **频率选择**：选择目标运营商使用的频段和频点

**身份获取方式：**
- **位置更新触发**：伪基站设置不同的LAC，触发终端进行位置更新
- **寻呼响应**：伪基站发送寻呼消息，终端响应时提供身份
- **业务请求**：终端发起呼叫或数据业务时需要提供身份

**2G vs 3G/4G/5G差异：**
- **2G（GSM）**：最容易实施，因为没有网络侧认证。IMSI以明文传输，TMSI也容易关联。
- **3G（UMTS）**：由于有双向认证，纯3G伪基站较难实现。但可以通过降级到2G来获取IMSI。
- **4G（LTE）**：同样有双向认证，但初始附着时仍可能泄露IMSI。TMSI追踪仍然可行。
- **5G**：引入SUCI保护，IMSI获取难度大大增加。但仍存在降级攻击可能。

#### 4.1.3 攻击工具与实现

**硬件平台：**
- **USRP（Universal Software Radio Peripheral）**：高端SDR平台，性能稳定
- **HackRF One**：价格较低，半双工，覆盖1MHz-6GHz
- **BladeRF**：全双工SDR，性能较好
- **YateBTS + 射频板**：开源基站实现方案
- **商用IMSI捕手设备**：灰色市场上的专业设备

**软件实现：**
- **OpenBTS**：开源GSM基站实现
- **YateBTS**：基于Yate软交换的GSM基站
- **OsmocomBB + OsmoBTS**：完整的开源GSM网络栈
- **srsLTE/srsRAN**：开源LTE实现，可用于研究伪基站攻击
- **OpenAirInterface**：开源4G/5G实现

#### 4.1.4 防御措施

**网络侧：**
- 尽快淘汰2G网络，关闭GSM支持
- 部署基站指纹识别系统，检测伪基站
- 优化TMSI分配机制，频繁更换TMSI
- 部署5G网络，使用SUCI保护用户身份

**终端侧：**
- 禁用2G网络支持（如果运营商允许）
- 优先使用4G/5G网络
- 使用支持5G SUCI的终端和USIM卡
- 安装伪基站检测应用

**协议改进：**
- 5G SUCI机制
- 增强的身份隐私保护
- 基站认证机制

### 4.2 位置追踪攻击

#### 4.2.1 攻击方式

**基于IMSI的追踪：**
- 获取目标用户的IMSI
- 使用IMSI捕手在不同位置探测该IMSI是否在附近
- 多点采样后可确定用户的移动轨迹

**基于TMSI的追踪：**
- 即使无法获取IMSI，也可以通过TMSI追踪用户
- TMSI与IMSI一一对应，且在一定时间内保持不变
- 攻击者可以持续观察TMSI的出现和消失来追踪用户位置

**基于信令网的位置查询：**
- 通过SS7/Diameter信令查询用户位置
- 可以远程获取用户的VLR/MME位置信息
- 精度可达基站小区级别（几百米到几公里）

**被动监听定位：**
- 通过多个监听点测量信号到达时间差（TDOA）
- 利用三角定位原理确定用户位置
- 不需要与目标交互，完全被动

#### 4.2.2 定位精度

| 技术 | 典型精度 | 适用场景 |
|------|----------|----------|
| 小区级定位 | 100m - 5km | SS7/Diameter查询 |
| TA+小区 | 50m - 500m | 定时提前量 |
| 多基站TDOA | 10m - 100m | 信号时间差 |
| A-GPS | 5m - 50m | 辅助GPS |
| WiFi指纹 | 5m - 30m | 室内定位 |

### 4.3 短信嗅探与劫持

#### 4.3.1 短信嗅探

**GSM短信嗅探：**
- 2G网络中，短信在无线信道上以加密或明文形式传输
- 如果加密被破解或未启用，可以直接读取短信内容
- 使用SDR设备可以捕获空中接口的短信

**攻击工具：**
- **Airprobe**：GSM信号捕获和分析工具
- **Wireshark + GSMTAP**：GSM协议分析
- **OsmocomBB**：基于手机的GSM嗅探
- **Kraken**：A5/1破解工具

**攻击步骤：**
1. 锁定目标运营商的频率
2. 捕获BCCH广播信息，确定系统参数
3. 监听寻呼信道，找到目标用户
4. 跟随目标用户的业务信道
5. 解密（如果加密）并解析短信内容

#### 4.3.2 短信劫持

**SS7/Diameter劫持：**
- 通过SS7 MAP协议的 `sendRoutingInfoForSM` 获取短信中心地址
- 利用 `forwardSM` 或其他操作重定向短信
- 攻击者可以接收目标用户的所有短信

**伪基站劫持：**
- 在伪基站模式下，攻击者可以接收发给目标用户的短信
- 需要将目标用户"粘滞"在伪基站上
- 同时需要处理短信的转发或阻断

**影响与危害：**
- 窃取银行/支付验证码
- 窃取社交媒体登录验证码
- 窃取二次认证令牌
- 个人隐私泄露
- 商业机密泄露

### 4.4 拒绝服务攻击

#### 4.4.1 无线侧DoS

**干扰攻击（Jamming）：**
- 发射大功率射频信号淹没正常信号
- 可以针对特定频段或特定信道
- 设备简单，效果明显
- 属于物理层攻击

**RACH风暴攻击：**
- 大量伪造的随机接入请求
- 耗尽基站的随机接入资源
- 导致合法用户无法接入网络

**寻呼攻击：**
- 发送大量寻呼消息
- 使终端频繁响应寻呼，耗尽电池
- 也称为"电池耗尽攻击"

#### 4.4.2 信令DoS

**SS7/Diameter信令洪水：**
- 发送大量信令消息
- 耗尽目标网元的处理能力
- 可能导致整个网络服务中断

**位置更新风暴：**
- 伪造大量用户的位置更新请求
- 使HLR/HSS和VLR/MME过载
- 影响正常用户的位置更新和切换

#### 4.4.3 核心网DoS

**SBA架构下的DoS：**
- API调用洪水：大量API请求耗尽NF资源
- NRF攻击：攻击NRF导致服务发现失败
- UPF攻击：用户面功能攻击导致数据中断
