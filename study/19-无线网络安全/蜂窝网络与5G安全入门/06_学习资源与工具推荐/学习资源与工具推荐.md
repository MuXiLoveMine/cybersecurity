# 学习资源与工具推荐

### 6.1 标准规范

**3GPP安全规范：**
- **TS 33.501**：5G系统安全架构和过程（核心规范）
- **TS 33.401**：EPS（4G）安全架构
- **TS 33.102**：3G安全架构
- **TS 33.105**：加密算法需求
- **TS 33.200**：网络域安全
- **TS 33.210**：网络域安全架构
- **TS 33.220**：通用认证架构
- **TS 33.221**：基于EAP的AKA
- **TS 33.222**：通用认证架构的访问网络安全
- **TS 33.223**：通用认证架构的媒体面安全
- **TS 33.310**：网络域安全，基于Diameter的NDS/IP

**GSMA安全文档：**
- **FS.11**：SS7安全指南
- **FS.19**：信令安全架构和指南
- **FS.20**：5G安全指南
- **FS.36**：信令安全测试方法论

**IETF相关RFC：**
- **RFC 6733**：Diameter基础协议
- **RFC 5448**：EAP-AKA'
- **RFC 5246**：TLS 1.2
- **RFC 8446**：TLS 1.3
- **RFC 6749**：OAuth 2.0

### 6.2 开源工具

**SDR平台：**
- **GNU Radio**：开源SDR开发框架，支持多种信号处理
  - 官网：https://www.gnuradio.org/
  - 用途：学习和研究各种无线信号

- **HackRF / BladeRF / USRP**：SDR硬件平台
  - HackRF One：入门级，半双工，1MHz-6GHz
  - BladeRF x40：中端，全双工，300MHz-3.8GHz
  - USRP B200/B210：专业级，全双工，70MHz-6GHz

**蜂窝网络研究工具：**
- **Osmocom**：开源移动通信项目集合
  - **OsmoBTS**：开源BTS实现
  - **OsmoBSC**：开源BSC实现
  - **OsmoMSC**：开源MSC实现
  - **OsmoHLR**：开源HLR实现
  - **OsmoNITB**：一体式GSM网络
  - **OsmocomBB**：手机端GSM协议栈

- **srsRAN**（前身srsLTE）：开源4G/5G实现
  - 包含eNB/gNB、UE、EPC等完整组件
  - 支持多种SDR硬件
  - 适合研究LTE/5G安全

- **OpenAirInterface（OAI）**：开源4G/5G协议栈
  - 完整的LTE和5G NR实现
  - 支持x86和ARM平台
  - 适合协议级安全研究

- **YateBTS**：基于Yate的GSM基站
  - 易于部署和使用
  - 支持多种SDR硬件

- **OpenBTS**：开源GSM基站
  - 最早的开源GSM实现之一
  - 历史悠久，文档丰富

**安全分析工具：**
- **Airprobe**：GSM信号分析工具
- **Kraken / RainbowCrack**：A5/1破解工具
- **Wireshark**：网络协议分析器，支持GSM MAP、Diameter等协议
- **SS7Map**：SS7网络映射工具
- **SigPloit**：信令协议渗透测试框架

### 6.5 学习路径建议

**第一阶段：基础积累（1-2个月）**
1. 学习移动通信基础知识（调制、多址、蜂窝概念）
2. 学习GSM系统架构和基本信令流程
3. 学习TCP/IP网络基础
4. 熟悉Linux操作系统和命令行

**第二阶段：工具入门（2-3个月）**
1. 购买入门级SDR设备（如HackRF One）
2. 学习GNU Radio基本使用
3. 搭建Osmocom实验环境
4. 学习Wireshark协议分析

**第三阶段：协议深入（3-6个月）**
1. 深入学习LTE协议栈（RRC、NAS、S1AP等）
2. 阅读3GPP安全规范（TS 33系列）
3. 搭建srsLTE/OpenAirInterface实验环境
4. 研究AKA、加密算法等安全机制

**第四阶段：安全研究（6个月以上）**
1. 学习SS7/Diameter协议及其安全问题
2. 研究5G安全架构和新特性
3. 参与开源安全项目
4. 阅读最新安全研究论文
5. 尝试独立发现和验证安全漏洞
