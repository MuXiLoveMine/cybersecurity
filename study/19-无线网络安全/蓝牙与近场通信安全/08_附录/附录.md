## 🛠️ 补充：实战拓展

### 一、BlueZ 工具集命令速查

#### 1.1 hciconfig - 蓝牙适配器配置
```bash
# 查看蓝牙适配器状态
hciconfig -a                      # 显示所有适配器详细信息
hciconfig hci0 name               # 查看设备名称

# 启用/禁用适配器
hciconfig hci0 up                 # 启用适配器
hciconfig hci0 down               # 禁用适配器
hciconfig hci0 reset              # 重置适配器

# 修改适配器配置
hciconfig hci0 name "MyDevice"    # 修改设备名称
hciconfig hci0 class 0x000100     # 修改设备类别
hciconfig hci0 piscan             # 启用可发现+可连接
hciconfig hci0 noscan             # 禁用扫描
hciconfig hci0 iscan              # 仅启用可发现
hciconfig hci0 pscan              # 仅启用可连接

# 修改MAC地址（需适配器支持）
hciconfig hci0 bdaddr 11:22:33:44:55:66
```

#### 1.2 hcitool - 蓝牙设备交互
```bash
# 扫描发现
hcitool scan                      # 经典蓝牙扫描（可发现设备）
hcitool scan --class              # 扫描并显示设备类别
hcitool inq                       # 询问扫描（带信号强度）
hcitool lescan                    # BLE设备扫描
hcitool lescan --duplicates       # 显示重复广播包

# 设备信息查询
hcitool name AA:BB:CC:DD:EE:FF    # 获取设备名称
hcitool info AA:BB:CC:DD:EE:FF    # 获取设备详细信息
hcitool con                       # 查看当前连接

# 连接与断开
hcitool cc AA:BB:CC:DD:EE:FF      # 创建连接
hcitool dc AA:BB:CC:DD:EE:FF      # 断开连接

# L2CAP测试
hcitool l2ping AA:BB:CC:DD:EE:FF  # L2CAP ping
hcitool l2ping -s 100 AA:BB:CC:DD:EE:FF  # 指定包大小
```

#### 1.3 sdptool - SDP服务发现
```bash
# 浏览目标设备所有服务
sdptool browse AA:BB:CC:DD:EE:FF
sdptool browse --tree AA:BB:CC:DD:EE:FF   # 树形显示

# 查询特定服务
sdptool search SP AA:BB:CC:DD:EE:FF       # 搜索串口服务
sdptool search OPUSH AA:BB:CC:DD:EE:FF    # 搜索对象推送服务
sdptool search HF AA:BB:CC:DD:EE:FF       # 搜索免提服务
sdptool search A2DP AA:BB:CC:DD:EE:FF     # 搜索音频服务

# 本地SDP管理
sdptool add SP                    # 添加串口服务
sdptool del 0x10000               # 删除指定服务记录
sdptool records local             # 查看本地服务
```

#### 1.4 gatttool - BLE GATT操作
```bash
# 交互式模式
gatttool -b AA:BB:CC:DD:EE:FF -I

# 命令行模式
gatttool -b AA:BB:CC:DD:EE:FF --primary      # 列出主要服务
gatttool -b AA:BB:CC:DD:EE:FF --characteristics  # 列出特征值
gatttool -b AA:BB:CC:DD:EE:FF --char-read --handle=0x000a  # 读取特征值
gatttool -b AA:BB:CC:DD:EE:FF --char-write --handle=0x000a --value=0100  # 写入特征值

# 常用GATT UUID速查
# 0x1800 = Generic Access
# 0x1801 = Generic Attribute
# 0x1802 = Immediate Alert
# 0x1803 = Link Loss
# 0x1804 = Tx Power
# 0x180f = Battery Service
# 0x1810 = Blood Pressure
# 0x1811 = Alert Notification
# 0x1812 = Human Interface Device
# 0x1813 = Scan Parameters
```

### 二、Bettercap BLE 模块完整命令

```bash
# 启动bettercap
bettercap -iface wlan0             # WiFi接口
bettercap -iface eth0              # 有线接口（BLE通过USB适配器）

# BLE侦察
ble.recon on                       # 启用BLE扫描
ble.recon off                      # 禁用BLE扫描
ble.show                           # 显示发现的设备
ble.show.clear                     # 清空设备列表

# 目标操作
ble.enum AA:BB:CC:DD:EE:FF         # 枚举GATT服务和特征值
ble.enum.clear                     # 清空枚举结果
ble.connect AA:BB:CC:DD:EE:FF      # 连接BLE设备
ble.disconnect                     # 断开当前连接

# 特征值读写
ble.read <handle>                  # 读取特征值
ble.write <handle> <value>         # 写入特征值（write）
ble.write.cmd <handle> <value>     # 写入特征值（write without response）
ble.notify <handle> on             # 启用通知
ble.notify <handle> off            # 禁用通知

# BLE中间人攻击
ble.mitm on                        # 启用BLE MITM
ble.mitm off                       # 禁用BLE MITM
set ble.mitm.mac AA:BB:CC:DD:EE:FF # 设置目标设备MAC
set ble.mitm.name "FakeDevice"     # 设置伪造设备名称

# 其他BLE命令
ble.adv on                         # 启用BLE广播
ble.adv off                        # 禁用BLE广播
set ble.adv.name "EvilDevice"      # 设置广播名称
set ble.adv.company_id 0x004C      # 设置厂商ID（Apple）
```

### 三、Ubertooth 工具集使用指南

```bash
# 安装依赖（Kali Linux）
apt-get install libubertooth-dev ubertooth

# 基本扫描
ubertooth-util -v                  # 查看设备版本信息
ubertooth-util -r                  # 复位设备
ubertooth-util -a                  # 查看USB序列号

# BLE抓包
ubertooth-btle -f -c capture.pcap  # 抓包并保存为pcap格式
ubertooth-btle -n -c capture.pcap  # 不连接主设备，仅监听
ubertooth-btle -f -A AA:BB:CC:DD:EE:FF  # 跟踪指定地址
ubertooth-btle -p                  # 仅被动扫描（不发送任何包）

# 指定信道
ubertooth-btle -f -c capture.pcap -C 37  # 仅信道37
ubertooth-btle -f -c capture.pcap -C 38  # 仅信道38
ubertooth-btle -f -c capture.pcap -C 39  # 仅信道39

# 经典蓝牙抓包
ubertooth-rx                       # 接收蓝牙数据包
ubertooth-rx -l 39 -u 41           # 监听特定跳频范围

# 频谱分析
ubertooth-specan                   # 频谱分析（文本模式）
ubertooth-specan-ui                # 频谱分析（图形界面）
ubertooth-scan                     # 扫描经典蓝牙设备
ubertooth-scan -t 30               # 扫描30秒

# Wireshark实时分析
# 方法1：通过管道
mkfifo /tmp/pipe
ubertooth-btle -f -c /tmp/pipe &
wireshark -k -i /tmp/pipe

# 方法2：先抓包后分析
ubertooth-btle -f -c ble_capture.pcap
wireshark ble_capture.pcap
```

#### 4.2 spooftooph - 蓝牙设备伪装
```bash
# 扫描并记录设备信息
spooftooph -i hci0 -s              # 扫描并保存设备信息

# 伪装设备
spooftooph -i hci0 -n "TargetName" -a AA:BB:CC:DD:EE:FF -c 0x000100
# -n: 名称, -a: MAC地址, -c: 设备类别

# 自动克隆最近的设备
spooftooph -i hci0 -m 10           # 每10秒自动更换身份
```
