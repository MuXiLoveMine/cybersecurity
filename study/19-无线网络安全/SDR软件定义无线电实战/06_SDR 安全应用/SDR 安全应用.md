# SDR 安全应用

### 6.1 无线门铃/车库门信号分析

```
分析目标：自有无线门铃/车库门

分析步骤：
1. 频率扫描
   → RTL-SDR + GQRX 扫描 433.92MHz 附近
   → 按下门铃按钮观察频谱出现信号

2. 信号录制
   → rtl_sdr 录制原始 IQ 数据
   → 使用 URH 分析

3. 协议解码
   → rtl_433 自动识别已知协议
   → 输出：协议类型、设备ID、状态

# rtl_433 分析
rtl_433 -d 0 -f 433.92e6 -s 250000 -r capture.cu8

安全评估：
├── 固定码？→ 重放风险（建议升级）
├── 滚动码？→ 评估加密强度
├── 信号范围？→ 有效距离多大
└── 干扰容限？→ 抗干扰能力
```

### 6.2 RF 远程控制安全

```
RF 远程控制安全检查项：

┌────────────────┬──────────────────────┬──────────────┐
│ 检查项         │ 安全标准             │ 风险         │
├────────────────┼──────────────────────┼──────────────┤
│ 编码方式       │ 滚动码（Keeloq等）    │ 固定码=高危  │

│ 重放保护       │ 计数器+时间窗口       │ 无保护=高危  │
│ 信号范围       │ 合理覆盖范围          │ 过远=中危    │
│ 配对机制       │ 安全配对（非明文）    │ 明文=中危    │
│ 固件更新       │ 安全OTA              │ 无更新=中危  │
└────────────────┴──────────────────────┴──────────────┘
```

### 6.3 IMSI Catcher 原理与检测

```
IMSI Catcher（伪基站）原理：

正常移动通信：
手机 → 基站（运营商）→ 核心网
       ↑ 信号最强基站优先

IMSI Catcher：
手机 → 伪基站（IMSI Catcher）
       ↑ 模拟更强信号吸引手机
       ↓
       获取 IMSI（国际移动用户标识）
       可执行：身份追踪/中间人攻击/短信劫持

检测方法：
├── 信号特征检测
│   → 异常强信号（LAC/CID 不匹配）
│   → 非标准频段/信道
│   → 2G 降级攻击（从 4G 强制降级到 2G）
├── 工具
│   → SDR + srsRAN/OsmocomBB 分析
│   → 手机 App（SnoopSnitch / Cell Spy Catcher）
│   → 专用硬件检测器
└── 检测指标
    → 基站 ID 突变
    → LAC（位置区码）异常
    → 邻区列表异常
    → 信号强度异常波动

⚠️ 注意：搭建 IMSI Catcher 在绝大多数国家/地区属违法行为
        本内容仅用于理解威胁原理与检测方法
```

### 6.4 无线键盘窃听风险

```
无线键盘安全风险：

攻击场景：
├── 2.4GHz 无线键盘（非蓝牙）
│   → 多数使用简单协议 + 固定码或弱加密
│   → SDR 可捕获并解调键盘输入
│   → 按键记录 = 密码/敏感信息泄露
├── 蓝牙键盘
│   → 蓝牙加密提供一定保护
│   → 旧版蓝牙（4.0前）加密可被破解
│   └── 蓝牙 4.2+ LE Secure Connections 较安全

安全建议：
├── 使用有线键盘处理敏感输入
├── 选择蓝牙 4.2+ LE 的键盘
├── 关注键盘厂商安全更新
└── 在敏感场景使用键盘屏蔽器
```

### 6.5 RFID/NFC 分析

```
RFID/NFC 与 SDR 的关系：

RFID 频段：
├── 低频（LF）125kHz    → 门禁卡/宠物芯片
├── 高频（HF）13.56MHz  → NFC/MIFARE
└── 超高频（UHF）860-960MHz → 物流标签

SDR 可分析：
├── LF/HF RFID 信号（需合适天线）
├── NFC 通信（Proxmark3 更专业）
└── UHF 标签

专用工具（比 SDR 更高效）：
├── Proxmark3 → RFID/NFC 全频段分析
├── NFC Reader/Writer → 13.56MHz
└── Flipper Zero → 多功能（含 RFID）
```
