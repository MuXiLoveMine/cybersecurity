# 无线协议逆向

### 5.1 信号捕获与录制

```
信号捕获流程：

1. 频率定位
   → 使用 GQRX/SDR# 频谱扫描找到目标信号
   → 记录中心频率、带宽、信号类型

2. 录制 IQ 数据
   → 使用 rtl_sdr / Universal Radio Hacker 录制

# 录制 433MHz 信号 10秒
rtl_sdr -d 0 -f 433.92e6 -s 250000 -g 42 -n 2500000 capture_433.cu8
# -n: 采样点数（2500000/250000 = 10秒）

3. 文件格式
   ├── .cu8  → 复数无符号 8 位（RTL-SDR 默认）
   ├── .cs8  → 复数有符号 8 位
   ├── .cs16 → 复数有符号 16 位
   └── .wav  → 音频格式（已解调）
```

### 5.2 调制方式识别

```
调制识别方法：

频谱特征：
├── 窄带连续谱 → NBFM（对讲机）
├── 宽带连续谱 → WBFM（FM电台）
├── 离散谱线   → ASK/OOK（遥控器）
├── 多峰谱     → FSK（多频移键控）
└── 宽带平坦谱 → DSSS（扩频）

时域特征：
├── 幅度跳变   → OOK/ASK
├── 频率跳变   → FSK
├── 相位突变   → PSK
└── 恒定包络   → FM/FSK/PSK

星座图分析：
├── 2点（实轴）   → BPSK / OOK
├── 4点           → QPSK
├── 圆环分布     → FSK
└── 网格分布     → QAM
```

### 5.3 数据解调

```
Universal Radio Hacker (URH) 解调流程：

1. 导入信号文件
   → File → Open → 选择 .cu8/.cs8 文件

2. 频率分析
   → 自动检测中心频率偏移
   → 调整带宽

3. 调制识别
   → Analyze → 自动识别 ASK/FSK/PSK
   → 或手动选择

4. 解调设置
   ├── Bit Length → 每个比特的采样数
   ├── Error Tolerance → 容错范围
   ├── Center → 判决门限
   └── Data Lock → 锁定位同步

5. 数据解码
   → 输出二进制/十六进制位流
   → 协议字段标注
```

### 5.4 协议分析

```
典型 OOK 协议结构（433MHz 遥控器）：

┌──────┬──────────┬──────────┬──────────┬────────┐
│ 前导 │ 同步码    │ 设备ID    │ 命令码    │ 校验   │
│ 码   │          │          │          │        │
│ 12位 │ 8位      │ 20位     │ 4位      │ 4位    │
└──────┴──────────┴──────────┴──────────┴────────┘

分析步骤：
1. 录制多次信号（同一遥控不同按键）
2. 对比解调数据，找出固定部分和变化部分
3. 固定部分 → 前导码/同步码
4. 变化部分 → 按键对应的命令码
5. 每次变化的部分 → 滚动码（Keeloq等）
6. 校验字段 → CRC/校验和

滚动码分析（仅教育）：
├── 固定码部分不变 → 设备识别码
├── 变化部分每次不同 → 滚动计数器
├── 计数器每次+1 → 防重放
└── 加密算法 → 需逆向芯片固件
```

### 5.5 重放攻击原理（仅教育用途）

```
重放攻击原理（仅用于理解防御需求）：

固定码系统（老旧遥控器）：
├── 每次发送相同的固定码
├── 录制信号 → 重放即可触发
├── 防御：升级为滚动码

滚动码系统（Keeloq 等）：
├── 每次发送不同的加密序列
├── 接收器校验计数器单调递增
├── 简单重放 → 被拒绝（计数器过旧）
├── 滚动码攻击 → 需录制多组 + 密钥逆向
└── 防御：使用强加密 + 前向安全

⚠️ 法律提示：
├── 未经授权录制/重放他人设备信号属于违法行为
├── 本内容仅用于理解安全风险，促进防御设计
├── 实际操作必须在授权环境和自有设备上进行
└── 禁止对他人设备进行任何未授权操作
```
