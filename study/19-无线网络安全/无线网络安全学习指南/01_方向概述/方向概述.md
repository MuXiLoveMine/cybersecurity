# 方向概述

### 1.1 核心防护对象

无线网络安全致力于保护通过电磁波进行数据传输的通信系统，其核心防护对象包括：

- **无线接入网络**：WiFi（802.11 系列）、WiMAX、卫星通信等接入层网络
- **个人区域网络（PAN）**：蓝牙（BR/EDR/BLE）、Zigbee、Thread 等短距离通信
- **近场通信**：NFC、RFID 等非接触式通信
- **广域无线网络**：蜂窝网络（2G/3G/4G/5G）、LoRa、Sigfox 等 LPWAN
- **卫星导航系统**：GPS、北斗、GLONASS 等定位信号
- **物联网无线通信**：各类 IoT 协议及其组网安全

### 1.2 关键威胁

无线网络由于其传输介质的开放性，面临着比有线网络更多的安全威胁：

| 威胁类别 | 具体威胁 | 影响等级 |
|---------|---------|---------|
| 被动窃听 | 无线信号监听、流量分析 | 高 |
| 主动攻击 | 中间人攻击、会话劫持 | 严重 |
| 拒绝服务 | Deauth 攻击、信号干扰 | 高 |
| 身份伪造 | Evil Twin、KARMA、MAC 伪装 | 严重 |
| 加密破解 | WEP/WPA 离线破解、密钥恢复 | 严重 |
| 协议漏洞 | KRACK、BlueBorne、KNOB | 严重 |
| 侧信道攻击 | 信号分析、功耗分析 | 中 |
| 物理层攻击 | 信号干扰、重放攻击 | 中 |

### 1.3 职业方向

无线网络安全领域的职业发展方向主要包括：

- **无线安全工程师**：负责企业无线网络的安全架构设计、部署和运维
- **渗透测试工程师**：执行无线网络渗透测试，发现和验证安全漏洞
- **物联网安全研究员**：研究 IoT 设备的无线通信安全
- **安全顾问**：为客户提供无线安全评估和加固方案
- **红队成员**：在红蓝对抗中利用无线攻击向量
- **安全产品研发**：开发 WIDS/WIPS、无线安全审计工具
- **学术研究员**：研究新型无线攻击和防御技术
