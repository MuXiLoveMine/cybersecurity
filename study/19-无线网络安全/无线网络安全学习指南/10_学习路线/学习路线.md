# 学习路线

### 阶段1：基础理论（1-2 个月）

**目标**：建立无线通信和网络安全的基础知识

- 学习无线电传播原理、频段划分、调制解调基础
- 理解 OSI 模型，重点掌握数据链路层和物理层
- 学习 802.11 协议族基础，理解帧结构和状态机
- 掌握密码学基础：对称加密、非对称加密、哈希、MAC
- 熟悉 Linux 基本操作和网络配置

**推荐实践**：
```
# 使用 iw 查看无线接口
iw dev

# 扫描周围 WiFi
iw dev wlan0 scan

# 使用 nmcli 管理连接
nmcli device wifi list
```

### 阶段2：WiFi 安全攻防（2-3 个月）

**目标**：掌握 WiFi 安全的核心攻防技术

- 深入学习 WEP/WPA/WPA2/WPA3 加密体系
- 理解四次握手过程和密钥派生
- 熟练使用 Aircrack-ng 套件进行 WiFi 渗透
- 学习 PMKID、WPS、Evil Twin 等攻击技术
- 掌握 Wireshark 分析 802.11 帧的能力

**推荐实践**：
```
# Aircrack-ng 基本流程
airmon-ng start wlan0
airodump-ng wlan0mon
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon
aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon
aircrack-ng -w wordlist.txt capture-01.cap
```

### 阶段3：蓝牙与短距离通信安全（1-2 个月）

**目标**：掌握蓝牙、Zigbee、NFC 等短距离通信安全

- 学习蓝牙协议栈架构和配对机制
- 掌握 BLE 扫描、GATT 服务发现和攻击
- 了解 Zigbee 安全机制和攻击方法
- 学习 NFC 安全威胁和防护
- 使用 Bettercap、Ubertooth 等工具

**推荐实践**：
```
# 使用 bettercap 进行 BLE 扫描
sudo bettercap -interface wlan0
> ble.recon on
> ble.show

# 使用 hcitool 扫描蓝牙设备
hcitool scan
hcitool lescan
```

### 阶段4：软件定义无线电与高级技术（2-3 个月）

**目标**：掌握 SDR 技术和高级无线攻击

- 学习软件定义无线电（SDR）原理和操作
- 使用 HackRF/USRP 进行信号捕获和重放
- 掌握 GNU Radio 进行信号处理
- 学习 GPS 欺骗、RFID 克隆等高级技术
- 研究无线协议逆向工程

**推荐实践**：
```
# 使用 HackRF 捕获信号
hackrf_transfer -r capture.bin -f 433920000 -s 8000000 -l 32 -g 40

# 使用 GNU Radio 分析信号
gnuradio-companion

# 使用 rtl_433 解码无线传感器
rtl_433 -f 433920000
```

### 阶段5：企业级防护与职业发展（1-2 个月）

**目标**：掌握企业级无线安全防护和运维

- 学习企业 WiFi 安全架构（802.1X、RADIUS、WIDS/WIPS）
- 掌握无线安全审计和合规要求
- 了解无线安全产品选型和部署
- 学习无线安全事件响应流程
- 准备相关认证（OSWP、GPEN、CEH 等）
