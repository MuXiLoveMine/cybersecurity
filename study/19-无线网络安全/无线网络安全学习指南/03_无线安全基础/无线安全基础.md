# 无线安全基础

### 2.1 无线电原理

无线通信利用电磁波在空间中传播信息。理解无线电原理是无线安全的基础。

#### 2.1.1 电磁波基础

电磁波是由同相振荡且互相垂直的电场与磁场在空间中以波的形式移动的现象。关键参数包括：

- **频率（Frequency）**：单位时间内振荡的次数，单位为赫兹（Hz）
- **波长（Wavelength）**：波在一个周期内传播的距离，λ = c/f
- **振幅（Amplitude）**：波的强度，影响信号覆盖范围
- **相位（Phase）**：波的相对位置，用于相位调制

#### 2.1.2 信号传播特性

```
信号传播中的关键概念：

1. 自由空间路径损耗（FSPL）
   FSPL(dB) = 20*log10(d) + 20*log10(f) + 32.44
   其中 d 为距离（km），f 为频率（MHz）

2. 多径效应
   - 信号经反射、折射、散射后通过多条路径到达接收端
   - 导致信号衰落和码间干扰
   - MIMO 技术利用多径提升性能

3. 衰减与干扰
   - 障碍物吸收和反射信号
   - 同频干扰：相同频率的信号互相干扰
   - 邻频干扰：相邻频率的信号泄漏

4. 信噪比（SNR）
   SNR = 10 * log10(信号功率 / 噪声功率)
   SNR 越高，信号质量越好，传输速率越高
```

#### 2.1.3 天线类型

- **全向天线**：360 度水平覆盖，适用于 AP 覆盖
- **定向天线**：集中能量朝向特定方向，适用于点对点桥接
- **八木天线**：高增益定向天线，适用于远距离探测
- **贴片天线**：小型化，适用于移动设备
- **天线增益**：用 dBi 表示，每增加 3dBi，覆盖距离约增加 1.4 倍

### 2.2 频段划分

无线通信使用不同的频率波段，各频段有不同的传播特性和应用场景。

#### 2.2.1 主要频段

| 频段 | 频率范围 | 主要应用 | 安全关注点 |
|------|---------|---------|-----------|
| LF（低频） | 30-300 kHz | 导航、潜艇通信 | 信号截获 |
| MF（中频） | 300-3000 kHz | AM 广播、海事通信 | 信号干扰 |
| HF（高频） | 3-30 MHz | 短波通信、业余无线电 | 远距离窃听 |
| VHF（甚高频） | 30-300 MHz | FM 广播、VHF 电视 | 信号伪造 |
| UHF（特高频） | 300-3000 MHz | LTE、WiFi、蓝牙、GPS | 多协议共存干扰 |
| SHF（超高频） | 3-30 GHz | WiFi 5GHz/60GHz、卫星 | 定向窃听 |
| EHF（极高频） | 30-300 GHz | 毫米波 5G、雷达 | 物理层安全 |

#### 2.2.2 WiFi 频段

```
2.4 GHz 频段（802.11 b/g/n/ax）
├── 信道 1-14（中国支持 1-13）
├── 每个信道带宽 22 MHz，中心频率间隔 5 MHz
├── 信道 1、6、13 为不重叠信道
├── 优势：穿墙能力强、覆盖范围大
└── 劣势：设备密集、干扰严重

5 GHz 频段（802.11 a/n/ac/ax）
├── 信道 36-165（中国支持部分信道）
├── 更宽的信道带宽（20/40/80/160 MHz）
├── 优势：干扰少、速率高
└── 劣势：穿墙能力弱、覆盖范围小

6 GHz 频段（802.11 ax/be/WiFi 6E/7）
├── 信道 1-233（连续频谱）
├── 优势：超大带宽、极低干扰
└── 劣势：设备兼容性有限
```

### 2.3 调制解调

调制是将信息编码到载波信号上的过程，解调是逆向过程。

#### 2.3.1 常见调制方式

```
模拟调制：
├── AM（调幅）：信息编码在载波振幅中
├── FM（调频）：信息编码在载波频率中
└── PM（调相）：信息编码在载波相位中

数字调制：
├── ASK（振幅键控）：二进制控制载波振幅
├── FSK（频移键控）：二进制控制载波频率
├── PSK（相移键控）：BPSK/QPSK/8PSK
├── QAM（正交振幅调制）：16-QAM/64-QAM/256-QAM/1024-QAM
├── OFDM（正交频分复用）：WiFi/LTE 核心调制技术
└── DSSS/FHSS：扩频技术
```

#### 2.3.2 调制与安全的关系

- 调制方式影响信号的截获难度
- 跳频扩频（FHSS）提供一定的抗截获能力
- 直接序列扩频（DSSS）抗干扰能力强
- 认知无线电可实现频谱感知和动态接入
