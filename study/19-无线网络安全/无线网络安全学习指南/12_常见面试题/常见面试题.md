# 常见面试题

### 基础题

**Q1: WEP 加密的根本漏洞是什么？**

WEP 使用 RC4 流密码，其根本漏洞在于 IV（初始化向量）空间过小（24位）且以明文传输。当相同 IV 重用时，RC4 流密码的密钥流会重复，导致密钥流恢复和明文还原。此外，WEP 的 CRC-32 完整性校验是线性的，无法防止数据篡改。

**Q2: 简述 WPA2 的四次握手过程。**

四次握手用于在 Station 和 AP 之间协商出用于数据加密的会话密钥 PTK：

1. AP 发送 ANonce 给 Station
2. Station 用 ANonce + SNonce + 两个 MAC 地址 + PMK 计算 PTK，发送 SNonce 和 MIC 给 AP
3. AP 验证 MIC，发送 GTK 和 MIC 给 Station
4. Station 安装密钥，发送确认给 AP

**Q3: WPA3 相比 WPA2 有哪些安全改进？**

- 使用 SAE（Simultaneous Authentication of Equals）替代 PSK，抗离线字典攻击
- 提供前向保密（Forward Secrecy）
- 192 位安全套件（WPA3-Enterprise）
- OWE（Opportunistic Wireless Encryption）提供开放网络的加密
- 简化的设备配对（Easy Connect）

### 进阶题

**Q4: Evil Twin 攻击的原理和检测方法？**

原理：攻击者部署一个与合法 AP 相同 SSID（和相同 BSSID/MAC）的伪造 AP，通过更强的信号诱使客户端连接，从而实施中间人攻击。

检测方法：
- 对比 BSSID 与已知 AP 列表
- 检测同一 BSSID 出现在不同信道
- 检测信号强度异常变化
- 对比 BSSID 与 OUI（厂商标识）
- WIDS/WIPS 的 Rogue AP 检测功能
- 检测异常的 DHCP 响应

**Q5: KRACK 攻击的原理和影响？**

KRACK（Key Reinstallation Attack）利用了 WPA2 四次握手中的状态机缺陷。攻击者在第三次握手时阻断或延迟消息，导致 Station 重装已经使用的密钥，从而重置 nonce 和重放计数器。这使得攻击者可以：
- 解密数据帧
- 重放数据帧
- 在某些配置下伪造数据帧（TKIP 配置）
- 但不能解密所有流量，且需要物理接近

**Q6: 蓝牙 KNOB 攻击的原理？**

KNOB（Key Negotiation of Bluetooth）攻击利用了蓝牙密钥协商协议中的漏洞。攻击者在配对过程中间人介入，强制协商的加密密钥长度降低到最小值（1 字节），使得加密形同虚设，可在几分钟内暴力破解密钥。

### 实战题

**Q7: 如何检测企业网络中是否存在 Rogue AP？**

```
检测策略：
1. 部署 WIDS 传感器进行 24/7 无线监控
2. 维护授权 AP 白名单（SSID/BSSID/信道/厂商）
3. 扫描所有 802.11 频段（2.4G/5G/6G）
4. 对比发现 AP 与白名单：
   - 未知 SSID 的 AP
   - 已知 SSID 但未知 BSSID
   - 同 BSSID 不同信道
   - 异常信号强度/位置
5. 物理定位：三角定位或巡查
6. 有线侧检测：扫描交换机端口是否桥接无线
7. 配合 NAC 检测：未授权设备入网
```

**Q8: 在无线渗透测试中，如何获取 WPA2-Enterprise 的凭证？**

```
攻击方法：
1. 部署 Evil Twin AP，配置相同 SSID
2. 设置 Captive Portal 仿冒登录页
3. 等待客户端自动连接或诱导连接
4. 收集用户输入的凭证
5. 可结合 Deauth 攻击加速断连重连

防御措施：
- 部署服务器证书验证
- 配置客户端验证 CA 证书
- 使用 PEAP-EAP-TLS 双因素认证
- WIDS 检测伪造 AP
```
