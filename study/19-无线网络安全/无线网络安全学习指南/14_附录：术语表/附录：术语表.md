# 附录：术语表

| 术语 | 全称 | 说明 |
|------|------|------|
| AP | Access Point | 无线接入点 |
| STA | Station | 无线终端站 |
| SSID | Service Set Identifier | 网络名称 |
| BSSID | Basic Service Set Identifier | AP 的 MAC 地址 |
| ESSID | Extended Service Set Identifier | 扩展网络名称 |
| PSK | Pre-Shared Key | 预共享密钥 |
| PMK | Pairwise Master Key | 成对主密钥 |
| PTK | Pairwise Transient Key | 成对临时密钥 |
| GTK | Group Temporal Key | 组临时密钥 |
| SAE | Simultaneous Authentication of Equals | WPA3 认证协议 |
| OWE | Opportunistic Wireless Encryption | 机会性无线加密 |
| EAP | Extensible Authentication Protocol | 可扩展认证协议 |
| RADIUS | Remote Authentication Dial-In User Service | 远程认证服务 |
| WPS | WiFi Protected Setup | WiFi 保护设置 |
| WIDS | Wireless Intrusion Detection System | 无线入侵检测系统 |
| WIPS | Wireless Intrusion Prevention System | 无线入侵防御系统 |
| SDR | Software Defined Radio | 软件定义无线电 |
| BLE | Bluetooth Low Energy | 低功耗蓝牙 |
| GATT | Generic Attribute Profile | 通用属性协议 |
| NFC | Near Field Communication | 近场通信 |
| LPWAN | Low Power Wide Area Network | 低功耗广域网 |
