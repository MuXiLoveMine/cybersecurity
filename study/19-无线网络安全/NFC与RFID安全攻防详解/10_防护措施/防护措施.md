# 防护措施

```
RFID/NFC安全防护措施:

  1. 卡片层面:
     - 使用DESFire EV3替代Classic
     - 使用CPU卡实现PKI认证
     - 启用随机UID(防止追踪)
     - 定期轮换密钥

  2. 系统层面:
     - 双因素认证(卡+PIN/生物)
     - 基于时间的访问控制
     - 行为分析(异常使用检测)
     - 卡片黑名单
     - Magic卡检测

  3. 网络层面:
     - 端到端加密通信
     - 读卡器到服务器认证
     - 防重放机制
     - 时间戳验证

  4. 物理层面:
     - RFID屏蔽钱包/卡套
     - 防止远距离读取
     - 物理安全控制

  5. 支付层面:
     - Token化(不传输真实卡号)
     - 动态交易码
     - 设备绑定
     - 用户认证(指纹)
     - 交易限额

  6. 运营层面:
     - 卡片生命周期管理
     - 密钥管理制度
     - 安全审计
     - 应急响应预案
     - 员工安全意识

防御技术:

  距离限定协议:
  - 快速挑战-响应
  - 测量往返时间
  - 检测中继延迟
  - 精度可达厘米级

  多频段验证:
  - 同时使用HF和UHF
  - 中继两个频段极困难
  - 增加攻击复杂度

  环境验证:
  - 结合位置、时间、行为
  - 多维度验证
  - 异常检测
```
