# 中继攻击

### 5.1 攻击原理

```
中继攻击(Relay Attack):

  正常支付流程:
  用户手机 -> NFC终端 -> 验证 -> 完成

  中继攻击:
  攻击者A(接近受害者)        攻击者B(接近NFC终端)
     |                              |
     | 读取手机NFC信号              |
     | 通过无线传输给B              |
     +---------- 无线通道 ---------+
     |                              | 转发给NFC终端
     |                              | 终端认为是手机在场
     |                              | 完成支付

  攻击者不需要知道密钥
  只是中继通信
  利用协议的时序漏洞
```

### 5.2 NFC中继攻击

```
NFC支付中继攻击:

  前提:
  - 受害者手机开启了NFC支付
  - 手机放在包里/口袋中

  攻击步骤:
  1. 攻击者A靠近受害者
  2. A的设备模拟NFC终端
  3. 受害者手机开始NFC通信
  4. A将通信数据实时转发给B
  5. B靠近真实NFC终端
  6. B将数据转发给终端
  7. 终端与手机完成"支付"

  防御:
  - 超时检测(增加延迟会失败)
  - 距离限定协议
  - 多因素验证(指纹/面部)
  - 声音/震动提示
```
