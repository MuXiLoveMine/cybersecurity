# 最佳实践与防护清单

```
RFID/NFC安全最佳实践清单:

卡片选择:
  [ ] 新部署使用DESFire EV3/CPU卡
  [ ] 不再使用Mifare Classic(新项目)
  [ ] 不使用纯ID卡(EM410x)做安全门禁
  [ ] 使用随机UID(防止追踪)
  [ ] 考虑后量子密码迁移路径

密钥管理:
  [ ] 不使用出厂默认密钥
  [ ] 密钥长度足够(AES-128+)
  [ ] 不同扇区使用不同密钥
  [ ] 密钥定期轮换
  [ ] 密钥存储在HSM中
  [ ] 密钥分发使用安全通道

访问控制:
  [ ] 双因素认证(卡+PIN/生物)
  [ ] 最小权限原则
  [ ] 时间窗口限制
  [ ] 异常行为检测
  [ ] 卡片黑名单机制
  [ ] 丢失卡片即时注销

网络架构:
  [ ] 读卡器到服务器加密通信
  [ ] 读卡器双向认证
  [ ] 防重放(时间戳/nonce)
  [ ] 审计日志全量记录
  [ ] 网络分段隔离

物理防护:
  [ ] RFID屏蔽卡套/钱包
  [ ] 读卡器防拆开关
  [ ] 读卡器防物理篡改
  [ ] 监控读卡器状态

支付安全:
  [ ] Token化替代PAN
  [ ] 动态交易密码
  [ ] 设备绑定
  [ ] 用户认证(指纹/PIN)
  [ ] 交易限额
  [ ] 异常交易监控

中继防护:
  [ ] 距离绑定协议
  [ ] 交易超时设置
  [ ] 声音/震动提示
  [ ] 多频段验证(可选)

运营管理:
  [ ] 卡片生命周期管理
  [ ] 定期安全审计
  [ ] 渗透测试
  [ ] 应急响应预案
  [ ] 员工安全培训
  [ ] 供应链安全管理
```
