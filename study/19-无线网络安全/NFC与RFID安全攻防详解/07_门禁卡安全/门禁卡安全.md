# 门禁卡安全

```
门禁卡安全分析:

  常见门禁卡类型:
  1. ID卡 (125kHz, EM410x)
     - 只读, 只有UID
     - 无加密
     - 极易克隆

  2. Mifare Classic
     - 有扇区密钥
     - 但Crypto-1已被破解
     - 易克隆

  3. Mifare DESFire
     - AES加密
     - 双向认证
     - 难克隆

  4. CPU卡
     - 完整加密芯片
     - PKI认证
     - 最安全

门禁系统攻击:
  1. 克隆攻击(最常见)
     - 复制卡片UID
     - 或复制完整数据

  2. 暴力破解
     - 破解扇区密钥
     - 读取所有数据

  3. 中继攻击
     - 中继合法用户与读卡器

  4. 后门利用
     - Magic卡后门指令
     - 系统维护后门
```
