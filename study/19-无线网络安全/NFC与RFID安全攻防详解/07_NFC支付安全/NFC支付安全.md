# NFC支付安全

```
NFC支付安全架构:

  +-------------------+
  |     用户手机       |
  |  +-------------+  |
  |  | SE/eSE      |  |  安全芯片存储密钥
  |  |  或 HCE     |  |  Host Card Emulation
  |  +-------------+  |
  |  | 支付应用     |  |
  |  +-------------+  |
  +---------+---------+
            |
        NFC通信
            |
  +---------v---------+
  |   POS终端          |
  |  (商户收银机)      |
  +---------+---------+
            |
            v
  +-------------------+
  |   支付网络         |
  |  Visa/Mastercard  |
  +-------------------+

安全机制:
  1. 安全芯片(SE/eSE)
     - 防篡改硬件
     - 密钥不出芯片
     - 独立安全域

  2. Token化
     - 使用token替代真实卡号
     - 一次性动态码
     - 即使截获也不可重用

  3. 动态数据
     - 每次交易生成唯一密码
     - 密码与交易数据绑定
     - 防重放攻击

  4. HCE安全
     - 云端密钥管理
     - 限时token
     - 设备绑定

  5. 用户认证
     - 指纹/面部识别
     - 大额需在线验证
```
