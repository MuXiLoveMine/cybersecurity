### 9.4 CTF中的Zigbee题目

#### 9.4.1 常见题型

Zigbee在CTF中出现的频率不高，但逐渐增多。常见题型：

1. **流量分析题**
   - 给出pcap文件，分析Zigbee通信
   - 考点：协议解析、密钥解密、数据提取
   - 工具：Wireshark + KillerBee

2. **重放攻击题**
   - 捕获的Zigbee流量中有flag
   - 需要重放特定命令获取flag
   - 考点：重放攻击、命令识别

3. **密钥破解题**
   - 给出包含设备加入过程的pcap
   - 需要从pcap中提取网络密钥
   - 考点：密钥分发机制、默认密钥、AES解密

4. **固件逆向题**
   - 给出Zigbee设备固件
   - 分析固件中的密钥和协议实现
   - 考点：固件逆向、密钥提取

5. **现场实战题**
   - 现场有真实Zigbee设备
   - 需要物理攻击+无线攻击
   - 考点：综合能力

#### 9.4.2 CTF解题思路

**流量分析题通用解法**：

```bash
# 步骤1：打开pcap，确认协议
wireshark challenge.pcap

# 步骤2：查看是否有加密
# 检查NWK安全位是否为1

# 步骤3：尝试解密
# 如果有加密，尝试常见默认密钥
# 在Wireshark中配置密钥

# 步骤4：分析ZCL命令和属性
# 寻找包含flag的字段

# 步骤5：提取数据
# 使用tshark批量提取
tshark -r challenge.pcap -T fields -e zbee_zcl.payload
```

**密钥查找题**：

```bash
# 使用zbgoodfind自动查找
zbgoodfind -f challenge.pcap

# 如果失败，尝试常见厂商密钥
zbgoodfind -f challenge.pcap -k common_keys.txt

# 手动分析Transport Key帧
# 在Wireshark中查找NWK Command: Transport Key
```
