# GPS欺骗技术原理

### 3.1 民用GPS信号脆弱性

#### 3.1.1 信号设计缺陷

民用GPS信号（C/A码）存在根本性的安全设计缺陷：

**1. 公开的信号结构**
- C/A码的生成算法完全公开
- 导航电文格式完全公开
- 任何人都可以生成完全符合标准的GPS信号
- 没有信号认证机制，接收机无法区分信号真伪

**2. 到达功率极低**
- 到达地面的GPS信号功率约为-160 dBm
- 比热噪声还低约20-30 dB
- 一个简单的1瓦发射机，在几公里外就能超过真实信号功率
- 欺骗攻击的功率门槛极低

**3. 单向广播机制**
- GPS是单向广播系统，卫星只发不收
- 接收机不向卫星发送任何信息
- 卫星系统不知道谁在接收信号
- 无法检测或阻止欺骗攻击

**4. 缺乏加密和认证**
- 民用信号没有加密
- 没有数字签名或消息认证码
- 导航电文可被任意伪造
- 接收机完全信任接收到的信号

#### 3.1.2 接收机设计弱点

**1. 跟踪环设计**
- GPS接收机的码跟踪环和载波跟踪环设计目标是跟踪最强的信号
- 当有更强的"相似"信号出现时，跟踪环会被"劫持"
- 这是欺骗攻击能够成功的根本原因

**2. 捕获策略**
- 接收机捕获信号时，只要相关峰超过阈值就认为捕获成功
- 不区分信号来源
- 冷启动状态下特别容易被欺骗

**3. 缺少欺骗检测**
- 大多数消费级GPS接收机没有欺骗检测功能
- 即使是专业级接收机，欺骗检测能力也很有限
- 用户通常不知道自己正在被欺骗

### 3.2 欺骗攻击分类

#### 3.2.1 生成式欺骗（Generative Spoofing）

生成式欺骗是指攻击者实时生成伪造的GPS信号。

**实现方式：**
- 基于GPS信号模型生成信号
- 使用真实星历数据计算卫星位置
- 根据目标位置计算每颗卫星的伪距
- 生成对应的C/A码信号和导航电文
- 上变频到射频后发射

**优点：**
- 灵活性高，可以设置任意目标位置
- 可以精确控制每颗卫星的参数
- 可以模拟任意时刻的信号

**缺点：**
- 需要精确的星历数据
- 计算复杂度较高
- 实时生成需要较强的处理能力
- 信号细节可能与真实信号有差异（容易被高级检测方法发现）

**实现工具：**
- **gps-sdr-sim**：开源GPS信号生成工具
- **GNSS-SDR**：开源软件定义接收机，也可用于信号生成
- **自研软件**：基于GNU Radio等平台开发

#### 3.2.2 转发式欺骗（Meaconing / Repeater Spoofing）

转发式欺骗是指接收真实的GPS信号，经过处理（延迟、放大等）后再转发出去。

**基本原理：**
- 接收天线接收真实GPS信号
- 信号经过延迟线或数字延迟
- 经过功率放大后由发射天线发射
- 目标接收机接收到转发的信号

**分类：**

1. **模拟转发**
   - 纯模拟电路实现
   - 信号经过延迟线和放大器
   - 结构简单，延迟时间有限
   - 不能改变信号内容

2. **数字转发**
   - 数字化接收信号
   - 可以进行更复杂的处理
   - 延迟时间可以更长
   - 可以修改信号内容（结合生成式）

**优点：**
- 信号更"真实"，因为来自真实卫星
- 保留了真实信号的所有特征
- 难以通过信号特征分析检测
- 不需要星历数据和复杂计算

**缺点：**
- 灵活性较差，位置偏移量有限
- 需要接收真实信号（需要良好的视野）
- 转发会引入额外的噪声和失真
- 攻击距离受限

### 3.3 欺骗攻击实施条件

#### 3.3.1 技术条件

**硬件条件：**
- **SDR设备**：至少支持GPS L1频段（1575.42 MHz）
  - HackRF One：入门级，半双工，最大发射功率约10-15 dBm
  - BladeRF x40/x115：全双工，性能更好
  - USRP B200/B210：专业级，性能稳定
  - 专用GPS欺骗器：商用设备，功能更完善

- **天线**：
  - GPS接收天线（用于接收真实信号）
  - GPS发射天线（用于发射欺骗信号）
  - 根据需要选择定向或全向天线

- **放大器**（可选）：
  - 增加发射功率，扩大攻击范围
  - 需要注意不要超过法律限制

**软件条件：**
- **GPS信号生成软件**：gps-sdr-sim、GNSS-SDR等
- **星历数据获取**：需要最新的GPS星历数据
- **实时处理能力**：精细欺骗需要实时信号处理

**知识条件：**
- GPS信号结构和工作原理
- 扩频通信基础
- 软件定义无线电技术
- 信号处理基础

#### 3.3.2 环境条件

**目标状态：**
- 冷启动状态：最容易被欺骗，因为接收机没有先验信息
- 热启动状态：较难欺骗，因为接收机有时间和位置的先验信息
- 跟踪状态：最难欺骗，需要逐步接管跟踪环

**环境因素：**
- 开阔地带：GPS信号好，欺骗效果更好
- 室内/城市峡谷：真实信号弱，欺骗更容易成功
- 电磁环境：干扰会影响欺骗效果

**攻击距离：**
- 近距离（<100m）：低功率即可，控制精度高
- 中距离（100m-1km）：需要中等功率
- 远距离（>1km）：需要高功率和定向天线
