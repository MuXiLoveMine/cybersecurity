# GPS欺骗实战

### 4.1 软件定义无线电（SDR）实现GPS欺骗

#### 4.1.1 SDR基础

软件定义无线电（Software Defined Radio, SDR）是一种使用软件实现传统硬件无线电功能的技术。

**SDR的优势：**
- 灵活性：同一硬件可以实现多种无线协议
- 可编程性：可以通过软件修改信号参数
- 可重构性：可以动态调整工作模式
- 成本低：相比专用硬件设备更经济

**GPS欺骗中的SDR作用：**
- 生成GPS基带信号
- 数字上变频到L1频段
- 数模转换（DAC）输出射频信号
- 控制发射功率和频率

#### 4.1.2 欺骗系统架构

一个典型的SDR GPS欺骗系统包括以下部分：

```
┌─────────────────────────────────────────────────────┐
│                    计算机（主机）                      │
│  ┌─────────────┐    ┌─────────────────────────────┐ │
│  │ 星历数据     │    │  GPS信号生成软件             │ │
│  │ (RINEX等)   │    │  (gps-sdr-sim等)            │ │
│  └──────┬──────┘    └──────────────┬──────────────┘ │
│         │                          │                │
│         └──────────────┬───────────┘                │
│                        │ IQ数据                      │
└────────────────────────┼─────────────────────────────┘
                         │ USB/以太网
                         ▼
┌─────────────────────────────────────────────────────┐
│                    SDR设备                           │
│  ┌─────────────┐    ┌─────────────┐    ┌──────────┐ │
│  │ 数字上变频   │───▶│ DAC转换器   │───▶│ 射频前端 │ │
│  └─────────────┘    └─────────────┘    └────┬─────┘ │
└──────────────────────────────────────────────┼───────┘
                                               │
                                               ▼
                                        ┌──────────┐
                                        │ 发射天线  │
                                        └────┬─────┘
                                             │
                                             ▼
                                        目标GPS接收机
```

**工作流程：**
1. 获取最新的GPS星历数据
2. 设定目标位置（经纬度、高度）和时间
3. 信号生成软件根据星历和目标位置计算每颗卫星的信号参数
4. 生成GPS基带IQ信号
5. 将IQ数据传输到SDR设备
6. SDR设备进行上变频和数模转换
7. 通过天线发射伪造的GPS信号
8. 目标接收机接收到欺骗信号，计算出错误的位置

### 4.2 HackRF/BladeRF硬件配置

#### 4.2.1 HackRF One配置

**硬件规格：**
- 频率范围：1 MHz - 6 GHz
- 采样率：最高20 Msps
- 发射功率：约0-15 dBm（与频率有关）
- 半双工（同一时间只能收或发）
- 8位ADC/DAC
- USB 2.0接口

**GPS欺骗设置：**
- 中心频率：1575.42 MHz（GPS L1）
- 采样率：2.6 MHz（gps-sdr-sim默认）或更高
- 发射增益：根据需要调整，从低到高
- 天线：GPS有源天线（注意发射时不要使用有源天线，可能损坏设备）

**软件安装（以Ubuntu为例）：**
```bash
# 安装依赖
sudo apt-get install build-essential git cmake libusb-1.0-0-dev

# 安装HackRF工具
sudo apt-get install hackrf

# 验证设备连接
hackrf_info
```

#### 4.2.2 BladeRF配置

**硬件规格（BladeRF x40）：**
- 频率范围：300 MHz - 3.8 GHz
- 采样率：最高40 Msps
- 发射功率：约10-15 dBm
- 全双工（可同时收发）
- 12位ADC/DAC
- USB 3.0接口

**GPS欺骗优势：**
- 全双工特性可以同时接收真实信号和发射欺骗信号
- 更高的采样率和精度
- USB 3.0提供更高的数据吞吐量
- 更适合实现精细欺骗

**软件安装：**
```bash
# 安装bladerf工具
sudo apt-get install bladerf

# 验证设备
bladeRF-cli -p
```

### 4.3 gps-sdr-sim工具使用

#### 4.3.1 工具介绍

gps-sdr-sim是由Takuji Ebinuma开发的开源GPS信号生成工具，可以生成GPS L1 C/A码信号的IQ采样数据。

**功能特点：**
- 支持生成最多12颗卫星的GPS信号
- 可自定义位置（经纬度、高度）
- 可自定义运动轨迹
- 可自定义时间
- 支持多种输出格式（适合不同的SDR设备）
- 支持实时流输出（通过管道）

**获取方式：**
- GitHub仓库：https://github.com/osqzss/gps-sdr-sim
- 编译简单，依赖少

#### 4.3.2 星历数据获取

gps-sdr-sim需要GPS星历数据来生成准确的信号。

**RINEX星历数据：**
- RINEX（Receiver Independent Exchange Format）是GPS数据交换标准格式
- 星历数据文件包含所有卫星的轨道参数
- 可以从多个公开数据源下载

**数据来源：**
- **NASA CDDIS**：https://cddis.nasa.gov/
- **IGS（International GNSS Service）**：https://www.igs.org/
- **BKG（德国联邦制图与大地测量局）**：https://www.bkg.bund.de/
- **u-blox工具**：从u-blox接收机实时提取星历

**星历文件命名：**
- 广播星历文件通常命名为 `brdcDDD0.YYn.Z`
  - DDD：年积日
  - YY：年份
  - n：文件序号
- 例如：`brdc2750.23n.Z` 表示2023年第275天的广播星历

#### 4.3.3 基本使用方法

**编译：**
```bash
git clone https://github.com/osqzss/gps-sdr-sim.git
cd gps-sdr-sim
gcc gpssim.c -lm -O2 -o gps-sdr-sim
```

**生成静态位置欺骗信号：**
```bash
# 基本用法：生成北京天安门位置的GPS信号
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -d 300

# 参数说明：
# -e: 星历文件
# -l: 纬度,经度,高度（度，米）
# -d: 持续时间（秒）
```

**输出文件：**
- 默认输出 `gpssim.bin` 文件
- 文件格式：16位有符号整数，I/Q交替
- 采样率：2.6 Msps（默认）

**指定输出格式和采样率：**
```bash
# 输出为HackRF格式（8位无符号）
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -b 8

# 指定采样率为5 Msps
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -s 5000000
```

**生成运动轨迹：**
```bash
# 使用用户运动文件
./gps-sdr-sim -e brdc2750.23n -u user_motion.csv

# 运动文件格式（CSV）：
# 时间(秒), 纬度(度), 经度(度), 高度(米)
# 0, 39.9087, 116.3975, 50
# 10, 39.9088, 116.3976, 50
# 20, 39.9089, 116.3977, 50
```

#### 4.3.4 使用HackRF发射

**方法一：先生成文件再发射**
```bash
# 1. 生成GPS信号文件（8位格式）
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -b 8 -d 60

# 2. 使用HackRF发射
hackrf_transfer -t gpssim.bin -f 1575420000 -s 2600000 -a 1 -x 47

# 参数说明：
# -t: 发射文件
# -f: 中心频率（Hz）
# -s: 采样率（Hz）
# -a: 放大器使能（0或1）
# -x: 发射增益（0-47 dB）
```

**方法二：实时管道发射**
```bash
# 通过管道实时生成并发射
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -b 8 -d 300 - | \
  hackrf_transfer -t - -f 1575420000 -s 2600000 -a 1 -x 40
```

**方法三：使用BladeRF发射**
```bash
# 生成信号
./gps-sdr-sim -e brdc2750.23n -l 39.9087,116.3975,50 -d 60

# 使用BladeRF发射
bladeRF-cli -e "tx config frequency=1575420000 samplerate=2600000 bandwidth=2500000 gain=20" \
            -e "tx start" -e "tx cal lms"
bladeRF-cli -t gpssim.bin -s 2600000 -f 1575420000 -b 16
```

**增益调节注意事项：**
- 从低增益开始，逐步增加
- 增益过高可能导致信号失真
- 注意遵守当地无线电管理法规
- 实验应在屏蔽环境中进行，避免干扰真实信号

### 4.4 欺骗效果验证

#### 4.4.1 验证方法

**方法一：使用GPS接收机直接验证**
- 使用普通GPS接收机（如手机、导航仪）
- 观察定位结果是否为设定的欺骗位置
- 最简单直接的验证方法

**方法二：使用SDR接收分析**
- 使用另一台SDR设备接收欺骗信号
- 使用GNU Radio或其他工具分析信号
- 验证信号的频谱、相关峰等特征

**方法三：使用软件接收机分析**
- 使用GNSS-SDR等软件定义接收机
- 对接收到的信号进行处理和解码
- 验证导航电文、伪距等参数

#### 4.4.2 验证步骤

**步骤1：确认欺骗信号已发射**
- 使用SDR接收1575.42 MHz频段
- 观察频谱，确认有信号存在
- 信号应呈现噪声状（因为是扩频信号）

**步骤2：冷启动测试**
- 将目标GPS接收机置于冷启动状态
- 关闭其他信号源（或在屏蔽室中）
- 观察接收机是否能捕获信号并定位
- 定位结果应为设定的欺骗位置

**步骤3：热启动/跟踪状态测试（精细欺骗）**
- 让接收机先正常定位（使用真实信号）
- 然后打开欺骗信号，逐步增加功率
- 观察接收机是否被欺骗信号接管
- 定位结果是否缓慢偏移到欺骗位置

**步骤4：欺骗效果评估**
- 定位精度：欺骗位置的精度
- 捕获时间：接收机需要多长时间被欺骗
- 稳定性：定位结果是否稳定
- 可检测性：欺骗是否容易被发现
