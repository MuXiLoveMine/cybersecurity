# GPS攻击面与威胁模型

### 2.1 GPS干扰（Jamming）

#### 2.1.1 干扰原理

GPS干扰是指发射射频信号，使GPS接收机无法正常接收或处理卫星信号，导致定位性能下降或完全失效。

**干扰原理：**
- GPS到达地面的信号功率极低（约-160 dBm）
- 远低于背景噪声水平
- 干扰信号只需要足够的功率就能压制GPS信号
- 干扰功率越大，干扰范围越广

#### 2.1.2 干扰类型

**按干扰信号形式分类：**

1. **宽带噪声干扰（Wideband Noise Jamming）**
   - 在GPS频段内发射宽带高斯噪声
   - 提高噪声底，降低信噪比
   - 实现简单，效果明显
   - 干扰功率与带宽成正比

2. **窄带干扰（Narrowband Jamming）**
   - 在特定频率上发射单音或窄带信号
   - 功率集中，效率更高
   - 但容易被抗干扰技术（如自适应滤波）抑制

3. **脉冲干扰（Pulsed Jamming）**
   - 以脉冲形式发射干扰信号
   - 占空比低，平均功率小
   - 对某些类型的接收机特别有效

4. **扫频干扰（Swept Jamming）**
   - 干扰频率在GPS频段内快速扫描
   - 可以同时干扰多个频段
   - 难以被固定陷波滤波器抑制

**按干扰目的分类：**
- **压制式干扰**：完全阻止接收机工作
- **欺骗式干扰**：诱导接收机获得错误的位置/时间（即GPS欺骗，详见下节）
- **渐进式干扰**：逐步提高干扰功率，使定位缓慢偏移

#### 2.1.3 干扰设备

**商用干扰器：**
- 便携式GPS干扰器：功率1-10W，干扰范围几十米到几百米
- 车载GPS干扰器：用于躲避车辆跟踪
- 无人机反制设备：通常包含GPS干扰功能
- 注意：在大多数国家和地区，使用GPS干扰器是违法的

**军用干扰系统：**
- 机载/车载大功率干扰系统
- 可在几十公里范围内干扰GPS信号
- 通常与其他电子战系统配合使用

**SDR实现干扰：**
- 使用通用SDR设备（如HackRF、BladeRF、USRP）
- 通过软件生成干扰信号
- 灵活可变，可以模拟多种干扰类型
- 功率有限，通常用于近距离研究

#### 2.1.4 干扰效果评估

**干扰效果指标：**
- **捕获阈值**：使接收机无法捕获信号所需的干扰功率
- **跟踪失锁阈值**：使已跟踪信号失锁所需的干扰功率
- **定位精度下降**：干扰对定位精度的影响程度
- **干扰距离**：在特定功率下的有效干扰范围

**影响因素：**
- 干扰信号的功率和形式
- 接收机的灵敏度和抗干扰能力
- 天线增益和方向
- 环境因素（遮挡、多径等）
- 卫星信号的实际强度

### 2.2 GPS欺骗（Spoofing）

#### 2.2.1 欺骗原理

GPS欺骗是指发射伪造的GPS信号，使目标接收机计算出错误的位置和/或时间。与干扰不同，欺骗攻击更加隐蔽，受害者往往无法察觉。

**欺骗攻击的核心要素：**
1. **信号同步**：欺骗信号需要与真实信号在时间和频率上同步
2. **功率控制**：欺骗信号功率略高于真实信号，以"盖过"真实信号
3. **导航电文伪造**：生成虚假的导航电文数据
4. **位置计算控制**：通过控制各卫星信号的延迟来控制目标位置

**欺骗攻击的基本过程：**
1. 接收真实GPS信号，获取当前卫星状态和时间
2. 生成伪造的GPS信号，模拟特定位置的卫星信号
3. 调整欺骗信号功率，从略低于真实信号逐步增加
4. 目标接收机锁定欺骗信号后，逐步调整信号参数
5. 将目标接收机"牵引"到攻击者设定的虚假位置/时间

#### 2.2.2 欺骗攻击分类

**按欺骗程度分类：**

1. **粗欺骗（Coarse Spoofing）**
   - 简单生成虚假信号，不与真实信号同步
   - 只能欺骗处于冷启动状态的接收机
   - 容易被检测（信号不连续、跳变等）

2. **精细欺骗（Sophisticated/Subtle Spoofing）**
   - 欺骗信号与真实信号精确同步
   - 功率缓慢增加，逐步接管接收机跟踪环
   - 可以欺骗已经正常工作的接收机
   - 攻击过程平滑，难以检测

**按攻击距离分类：**

1. **近距欺骗（Proximate Spoofing）**
   - 欺骗设备距离目标很近（几米到几百米）
   - 容易实现，因为信号功率可以精确控制
   - 例如：对无人机的近距离欺骗

2. **远距欺骗（Remote Spoofing）**
   - 欺骗设备距离目标较远（几公里以上）
   - 需要更大的发射功率和高增益天线
   - 实现难度较大

**按攻击目的分类：**
- 位置欺骗：使目标获得错误的位置
- 时间欺骗：使目标获得错误的时间
- 速度欺骗：使目标获得错误的速度测量
- 位置+时间组合欺骗

#### 2.2.3 威胁模型

**攻击者能力模型：**

| 能力等级 | 描述 | 典型设备 |
|----------|------|----------|
| L1 | 简单干扰 | 商用干扰器 |
| L2 | 简单欺骗（冷启动） | 入门级SDR + gps-sdr-sim |
| L3 | 同步欺骗（跟踪中接收机） | 高端SDR + 实时处理 |
| L4 | 多目标欺骗 | 多通道SDR阵列 |
| L5 | 军用码欺骗 | 专用设备（仅理论上） |

**攻击场景：**
- **无人机劫持**：欺骗无人机GPS，使其偏离航线或降落到指定地点
- **船舶导航攻击**：欺骗船舶导航系统，使其偏离航道
- **自动驾驶攻击**：欺骗自动驾驶汽车的GPS导航
- **通信网络攻击**：利用GPS时间欺骗攻击依赖GPS授时的通信系统
- **金融系统攻击**：攻击依赖GPS时间的金融交易系统
- **电力系统攻击**：攻击电力系统的时间同步

### 2.3 GPS重放攻击

#### 2.3.1 攻击原理

GPS重放攻击是一种特殊的欺骗攻击，攻击者录制真实的GPS信号，然后在不同时间或地点重新播放。

**攻击特点：**
- 不需要生成信号，只需录制和重放
- 信号是"真实"的，包含正确的导航电文
- 但信号对应的是录制时刻和录制地点的位置
- 可以绕过一些基于信号特征的检测方法

**攻击分类：**
- **简单重放**：将录制的信号直接重放
- **延迟重放**：录制后延迟一段时间再播放
- **移位重放**：将录制的信号移频后重放
- **选择重放**：只重放部分卫星信号

#### 2.3.2 攻击局限性

- 重放信号对应的是录制时刻的卫星位置
- 接收机可能通过时间一致性检测发现异常
- 多频接收机可能检测到不一致
- 难以与真实信号同步（如果目标有真实信号）
- 重放信号的多普勒特性可能与本地不一致
