## 1. 方向概述

### 1.1 核心防护对象

无线网络安全致力于保护通过电磁波进行数据传输的通信系统，其核心防护对象包括：

- **无线接入网络**：WiFi（802.11 系列）、WiMAX、卫星通信等接入层网络
- **个人区域网络（PAN）**：蓝牙（BR/EDR/BLE）、Zigbee、Thread 等短距离通信
- **近场通信**：NFC、RFID 等非接触式通信
- **广域无线网络**：蜂窝网络（2G/3G/4G/5G）、LoRa、Sigfox 等 LPWAN
- **卫星导航系统**：GPS、北斗、GLONASS 等定位信号
- **物联网无线通信**：各类 IoT 协议及其组网安全

### 1.2 关键威胁

无线网络由于其传输介质的开放性，面临着比有线网络更多的安全威胁：

| 威胁类别 | 具体威胁 | 影响等级 |
|---------|---------|---------|
| 被动窃听 | 无线信号监听、流量分析 | 高 |
| 主动攻击 | 中间人攻击、会话劫持 | 严重 |
| 拒绝服务 | Deauth 攻击、信号干扰 | 高 |
| 身份伪造 | Evil Twin、KARMA、MAC 伪装 | 严重 |
| 加密破解 | WEP/WPA 离线破解、密钥恢复 | 严重 |
| 协议漏洞 | KRACK、BlueBorne、KNOB | 严重 |
| 侧信道攻击 | 信号分析、功耗分析 | 中 |
| 物理层攻击 | 信号干扰、重放攻击 | 中 |

### 1.3 职业方向

无线网络安全领域的职业发展方向主要包括：

- **无线安全工程师**：负责企业无线网络的安全架构设计、部署和运维
- **渗透测试工程师**：执行无线网络渗透测试，发现和验证安全漏洞
- **物联网安全研究员**：研究 IoT 设备的无线通信安全
- **安全顾问**：为客户提供无线安全评估和加固方案
- **红队成员**：在红蓝对抗中利用无线攻击向量
- **安全产品研发**：开发 WIDS/WIPS、无线安全审计工具
- **学术研究员**：研究新型无线攻击和防御技术

## 2. 无线安全基础

### 2.1 无线电原理

无线通信利用电磁波在空间中传播信息。理解无线电原理是无线安全的基础。

#### 2.1.1 电磁波基础

电磁波是由同相振荡且互相垂直的电场与磁场在空间中以波的形式移动的现象。关键参数包括：

- **频率（Frequency）**：单位时间内振荡的次数，单位为赫兹（Hz）
- **波长（Wavelength）**：波在一个周期内传播的距离，λ = c/f
- **振幅（Amplitude）**：波的强度，影响信号覆盖范围
- **相位（Phase）**：波的相对位置，用于相位调制

#### 2.1.2 信号传播特性

```
信号传播中的关键概念：

1. 自由空间路径损耗（FSPL）
   FSPL(dB) = 20*log10(d) + 20*log10(f) + 32.44
   其中 d 为距离（km），f 为频率（MHz）

2. 多径效应
   - 信号经反射、折射、散射后通过多条路径到达接收端
   - 导致信号衰落和码间干扰
   - MIMO 技术利用多径提升性能

3. 衰减与干扰
   - 障碍物吸收和反射信号
   - 同频干扰：相同频率的信号互相干扰
   - 邻频干扰：相邻频率的信号泄漏

4. 信噪比（SNR）
   SNR = 10 * log10(信号功率 / 噪声功率)
   SNR 越高，信号质量越好，传输速率越高
```

#### 2.1.3 天线类型

- **全向天线**：360 度水平覆盖，适用于 AP 覆盖
- **定向天线**：集中能量朝向特定方向，适用于点对点桥接
- **八木天线**：高增益定向天线，适用于远距离探测
- **贴片天线**：小型化，适用于移动设备
- **天线增益**：用 dBi 表示，每增加 3dBi，覆盖距离约增加 1.4 倍

### 2.2 频段划分

无线通信使用不同的频率波段，各频段有不同的传播特性和应用场景。

#### 2.2.1 主要频段

| 频段 | 频率范围 | 主要应用 | 安全关注点 |
|------|---------|---------|-----------|
| LF（低频） | 30-300 kHz | 导航、潜艇通信 | 信号截获 |
| MF（中频） | 300-3000 kHz | AM 广播、海事通信 | 信号干扰 |
| HF（高频） | 3-30 MHz | 短波通信、业余无线电 | 远距离窃听 |
| VHF（甚高频） | 30-300 MHz | FM 广播、VHF 电视 | 信号伪造 |
| UHF（特高频） | 300-3000 MHz | LTE、WiFi、蓝牙、GPS | 多协议共存干扰 |
| SHF（超高频） | 3-30 GHz | WiFi 5GHz/60GHz、卫星 | 定向窃听 |
| EHF（极高频） | 30-300 GHz | 毫米波 5G、雷达 | 物理层安全 |

#### 2.2.2 WiFi 频段

```
2.4 GHz 频段（802.11 b/g/n/ax）
├── 信道 1-14（中国支持 1-13）
├── 每个信道带宽 22 MHz，中心频率间隔 5 MHz
├── 信道 1、6、13 为不重叠信道
├── 优势：穿墙能力强、覆盖范围大
└── 劣势：设备密集、干扰严重

5 GHz 频段（802.11 a/n/ac/ax）
├── 信道 36-165（中国支持部分信道）
├── 更宽的信道带宽（20/40/80/160 MHz）
├── 优势：干扰少、速率高
└── 劣势：穿墙能力弱、覆盖范围小

6 GHz 频段（802.11 ax/be/WiFi 6E/7）
├── 信道 1-233（连续频谱）
├── 优势：超大带宽、极低干扰
└── 劣势：设备兼容性有限
```

### 2.3 调制解调

调制是将信息编码到载波信号上的过程，解调是逆向过程。

#### 2.3.1 常见调制方式

```
模拟调制：
├── AM（调幅）：信息编码在载波振幅中
├── FM（调频）：信息编码在载波频率中
└── PM（调相）：信息编码在载波相位中

数字调制：
├── ASK（振幅键控）：二进制控制载波振幅
├── FSK（频移键控）：二进制控制载波频率
├── PSK（相移键控）：BPSK/QPSK/8PSK
├── QAM（正交振幅调制）：16-QAM/64-QAM/256-QAM/1024-QAM
├── OFDM（正交频分复用）：WiFi/LTE 核心调制技术
└── DSSS/FHSS：扩频技术
```

#### 2.3.2 调制与安全的关系

- 调制方式影响信号的截获难度
- 跳频扩频（FHSS）提供一定的抗截获能力
- 直接序列扩频（DSSS）抗干扰能力强
- 认知无线电可实现频谱感知和动态接入

## 3. WiFi 安全

### 3.1 WiFi 加密体系

WiFi 安全经历了从 WEP 到 WPA3 的演进过程：

```
WiFi 安全协议演进：

WEP (1997)
├── 使用 RC4 流密码
├── 40/104 位密钥
├── 严重安全漏洞，几分钟内可破解
└── 已被废弃，但仍可见于老旧设备

WPA (2003)
├── 临时方案，兼容 WEP 硬件
├── 使用 TKIP 加密
├── 引入了 MIC 防篡改
└── 存在 TKIP 注入漏洞

WPA2 (2004)
├── 使用 AES-CCMP 加密
├── 四次握手认证
├── KRACK 攻击暴露协议缺陷
└── 当前最广泛部署的协议

WPA3 (2018)
├── 使用 SAE 替代 PSK
├── 前向保密
├── 抗离线字典攻击
└── 分为 Personal 和 Enterprise 版本
```

### 3.2 认证流程

WiFi 认证流程涉及多个阶段：

```
WiFi 连接完整流程：

1. 扫描阶段
   ├── 主动扫描：Station 发送 Probe Request
   └── 被动扫描：Station 监听 Beacon 帧

2. 认证阶段（Open System / Shared Key）
   ├── Station -> AP: Authentication Request
   └── AP -> Station: Authentication Response

3. 关联阶段
   ├── Station -> AP: Association Request
   └── AP -> Station: Association Response

4. 密钥协商阶段（WPA/WPA2/WPA3）
   ├── WPA2: 四次握手（4-Way Handshake）
   └── WPA3: SAE 握手

5. 数据传输阶段
   └── 使用协商的密钥加密数据帧
```

## 4. 蓝牙安全

### 4.1 蓝牙技术概览

蓝牙技术工作在 2.4 GHz ISM 频段，分为经典蓝牙（BR/EDR）和低功耗蓝牙（BLE）：

```
蓝牙版本演进：

Bluetooth 1.0 (2000) - 基本速率 1 Mbps
Bluetooth 2.0 (2004) - EDR 增强速率 3 Mbps
Bluetooth 3.0 (2009) - 高速模式（通过 802.11）
Bluetooth 4.0 (2010) - 引入 BLE（Bluetooth Low Energy）
Bluetooth 4.2 (2014) - BLE 安全增强
Bluetooth 5.0 (2016) - 速度/范围/广播增强
Bluetooth 5.1 (2019) - 方向查找
Bluetooth 5.2 (2020) - LE Audio / Auracast
Bluetooth 5.3 (2021) - 信道选择增强
Bluetooth 5.4 (2023) - PAwR 周期性广播响应

安全相关里程碑：
- 4.2: 引入 LE Secure Connections（ECDH）
- 5.2: 引入 LE Power Control
- KNOB 攻击（2019）暴露密钥协商漏洞
- BLURtooth（2020）暴露跨层安全边界漏洞
```

### 4.2 BLE 安全机制

BLE 安全模型基于配对（Pairing）和绑定（Bonding）：

- **配对模式**：Just Works、Passkey Entry、Numeric Comparison、Out of Band
- **加密密钥**：STK（短期密钥）、LTK（长期密钥）
- **隐私特性**：可解析私有地址（RPA）防止设备追踪

### 4.3 经典蓝牙安全

经典蓝牙面临多种已知攻击：

- **Bluejacking**：发送未授权的 vCard 消息
- **Bluesnarfing**：未授权访问设备数据
- **BlueBorne**：远程代码执行漏洞
- **KNOB Attack**：降级加密密钥长度到 1 字节
- **BIAS**：蓝牙模拟攻击绕过认证

## 5. Zigbee 安全

### 5.1 Zigbee 概述

Zigbee 是基于 IEEE 802.15.4 标准的低功耗、低速率无线通信协议，广泛用于智能家居和工业控制：

```
Zigbee 网络架构：

协调器（Coordinator）
├── 网络的创建者和管理者
├── 每个网络有且仅有一个协调器
└── 存储网络密钥和信任中心信息

路由器（Router）
├── 转发数据包
├── 扩展网络覆盖
└── 可作为父节点接受子节点加入

终端设备（End Device）
├── 低功耗，可休眠
├── 不转发数据
└── 通过父节点通信

安全层级：
├── 网络层安全：AES-128 对称加密
├── 应用层安全：APS 层密钥
├── 信任中心：密钥分发与管理
└── 密钥类型：网络密钥、链接密钥、应用密钥
```

### 5.2 Zigbee 安全机制

Zigbee 使用 AES-128-CCM* 加密，提供加密和完整性保护：

- **网络密钥（Network Key）**：所有设备共享，用于网络层加密
- **链接密钥（Link Key）**：设备与信任中心之间的预共享密钥
- **安装码（Install Code）**：用于设备入网时的密钥协商
- **密钥传输**：信任中心通过带外或带内方式分发密钥

## 6. NFC 安全

### 6.1 NFC 技术概览

NFC（Near Field Communication）工作在 13.56 MHz，通信距离通常在 4 cm 以内：

```
NFC 工作模式：

1. 读写模式（Reader/Writer）
   └── NFC 设备主动读写 NFC 标签

2. 点对点模式（Peer-to-Peer）
   └── 两个 NFC 设备之间交换数据

3. 卡模拟模式（Card Emulation）
   ├── HCE（主机卡模拟）：软件模拟
   └── eSE（嵌入式安全元件）：硬件安全

NFC 协议栈：
├── NFCIP-1（ISO 18092）
├── MIFARE（NXP 专有）
├── FeliCa（Sony 专有）
├── ISO 14443 A/B
└── ISO 15693
```

### 6.2 NFC 安全威胁

- **Relay Attack（中继攻击）**：通过中继设备转发 NFC 信号，远程欺骗读卡器
- **Eavesdropping（窃听）**：虽然通信距离短，但仍可通过高增益天线窃听
- **Data Corruption/Modification**：使用特定设备干扰或修改 NFC 信号
- **Card Emulation 攻击**：利用 HCE 模拟合法卡进行欺诈
- **克隆攻击**：复制 NFC 卡片数据到空白卡

## 7. 无线 IDS/IPS

### 7.1 WIDS/WIPS 概念

无线入侵检测系统（WIDS）和无线入侵防御系统（WIPS）是无线网络安全的监控和防御基础设施：

```
WIDS/WIPS 功能架构：

检测功能：
├── Rogue AP 检测：识别未授权接入点
├── Ad-hoc 网络检测：检测点对点网络
├── Soft AP 检测：检测软件 AP
├── MAC 欺骗检测：识别 MAC 地址伪造
├── 无线钓鱼 AP 检测：检测 Evil Twin
├── Deauth 攻击检测：检测去认证洪泛
├── 桥接攻击检测：检测无线桥接
└── 信道重叠检测：检测信道干扰

响应功能（WIPS）：
├── 主动抑制：发送去认证帧切断非法连接
├── 频谱干扰：对非法设备发射干扰信号
├── 自动定位：三角定位非法设备
├── 告警通知：邮件/短信/SIEM 集成
└── 自动隔离：配合交换机端口关闭
```

### 7.2 部署模式

- **覆盖式部署**：专用传感器覆盖整个区域
- **集成式部署**：AP 集成 WIDS 功能，分时扫描
- **混合部署**：专用传感器 + AP 集成扫描

## 8. 无线渗透测试方法论

### 8.1 渗透测试流程

```
无线渗透测试标准流程：

阶段1：信息收集（Reconnaissance）
├── 被动扫描：监听 Beacon/Probe 帧
├── 主动扫描：发送 Probe Request
├── 信号映射：绘制覆盖热力图
├── GPS 定位：记录 AP 物理位置
└── 客户端发现：识别关联的 Station

阶段2：漏洞分析（Vulnerability Analysis）
├── 加密协议识别：WEP/WPA/WPA2/WPA3
├── 认证方式识别：PSK/802.1X/Captive Portal
├── WPS 状态检查：是否开启 WPS
├── 默认配置检查：默认 SSID/密码
└── 已知漏洞扫描：KRACK/WPS PIN 等

阶段3：漏洞利用（Exploitation）
├── WEP 破解：ARP 重放 + 统计攻击
├── WPA/WPA2 破解：握手包抓取 + 离线破解
├── PMKID 攻击：无需客户端在线
├── WPS 攻击：Pixie Dust / 在线 PIN 爆破
├── Evil Twin：伪造 AP 钓鱼
├── KARMA：响应 Probe Request 诱骗
└── DoS 攻击：Deauth/Disassociate 洪泛

阶段4：后渗透（Post-Exploitation）
├── 内网渗透：通过无线进入内网
├── 凭证获取：抓取网络凭证
├── 横向移动：内网横向渗透
└── 权限维持：持久化后门

阶段5：报告编写（Reporting）
├── 漏洞描述：技术细节和影响
├── 风险评级：CVSS 评分
├── 修复建议：具体加固方案
└── 执行摘要：面向管理层
```

### 8.2 法律与合规

> **重要提示**：无线渗透测试必须在获得明确授权后进行。未经授权的无线网络监听和攻击在任何司法管辖区都可能构成违法行为。在中国，相关法律包括《网络安全法》《刑法》第285条、第286条等。

## 9. 学习路线

### 阶段1：基础理论（1-2 个月）

**目标**：建立无线通信和网络安全的基础知识

- 学习无线电传播原理、频段划分、调制解调基础
- 理解 OSI 模型，重点掌握数据链路层和物理层
- 学习 802.11 协议族基础，理解帧结构和状态机
- 掌握密码学基础：对称加密、非对称加密、哈希、MAC
- 熟悉 Linux 基本操作和网络配置

**推荐实践**：
```
# 使用 iw 查看无线接口
iw dev

# 扫描周围 WiFi
iw dev wlan0 scan

# 使用 nmcli 管理连接
nmcli device wifi list
```

### 阶段2：WiFi 安全攻防（2-3 个月）

**目标**：掌握 WiFi 安全的核心攻防技术

- 深入学习 WEP/WPA/WPA2/WPA3 加密体系
- 理解四次握手过程和密钥派生
- 熟练使用 Aircrack-ng 套件进行 WiFi 渗透
- 学习 PMKID、WPS、Evil Twin 等攻击技术
- 掌握 Wireshark 分析 802.11 帧的能力

**推荐实践**：

## 12. 常见面试题

### 基础题

**Q1: WEP 加密的根本漏洞是什么？**

WEP 使用 RC4 流密码，其根本漏洞在于 IV（初始化向量）空间过小（24位）且以明文传输。当相同 IV 重用时，RC4 流密码的密钥流会重复，导致密钥流恢复和明文还原。此外，WEP 的 CRC-32 完整性校验是线性的，无法防止数据篡改。

**Q2: 简述 WPA2 的四次握手过程。**

四次握手用于在 Station 和 AP 之间协商出用于数据加密的会话密钥 PTK：

1. AP 发送 ANonce 给 Station
2. Station 用 ANonce + SNonce + 两个 MAC 地址 + PMK 计算 PTK，发送 SNonce 和 MIC 给 AP
3. AP 验证 MIC，发送 GTK 和 MIC 给 Station
4. Station 安装密钥，发送确认给 AP

**Q3: WPA3 相比 WPA2 有哪些安全改进？**

- 使用 SAE（Simultaneous Authentication of Equals）替代 PSK，抗离线字典攻击
- 提供前向保密（Forward Secrecy）
- 192 位安全套件（WPA3-Enterprise）
- OWE（Opportunistic Wireless Encryption）提供开放网络的加密
- 简化的设备配对（Easy Connect）

### 进阶题

**Q4: Evil Twin 攻击的原理和检测方法？**

原理：攻击者部署一个与合法 AP 相同 SSID（和相同 BSSID/MAC）的伪造 AP，通过更强的信号诱使客户端连接，从而实施中间人攻击。

检测方法：
- 对比 BSSID 与已知 AP 列表
- 检测同一 BSSID 出现在不同信道
- 检测信号强度异常变化
- 对比 BSSID 与 OUI（厂商标识）
- WIDS/WIPS 的 Rogue AP 检测功能
- 检测异常的 DHCP 响应

**Q5: KRACK 攻击的原理和影响？**

KRACK（Key Reinstallation Attack）利用了 WPA2 四次握手中的状态机缺陷。攻击者在第三次握手时阻断或延迟消息，导致 Station 重装已经使用的密钥，从而重置 nonce 和重放计数器。这使得攻击者可以：
- 解密数据帧
- 重放数据帧
- 在某些配置下伪造数据帧（TKIP 配置）
- 但不能解密所有流量，且需要物理接近

**Q6: 蓝牙 KNOB 攻击的原理？**

KNOB（Key Negotiation of Bluetooth）攻击利用了蓝牙密钥协商协议中的漏洞。攻击者在配对过程中间人介入，强制协商的加密密钥长度降低到最小值（1 字节），使得加密形同虚设，可在几分钟内暴力破解密钥。

### 实战题

**Q7: 如何检测企业网络中是否存在 Rogue AP？**

```
检测策略：
1. 部署 WIDS 传感器进行 24/7 无线监控
2. 维护授权 AP 白名单（SSID/BSSID/信道/厂商）
3. 扫描所有 802.11 频段（2.4G/5G/6G）
4. 对比发现 AP 与白名单：
   - 未知 SSID 的 AP
   - 已知 SSID 但未知 BSSID
   - 同 BSSID 不同信道
   - 异常信号强度/位置
5. 物理定位：三角定位或巡查
6. 有线侧检测：扫描交换机端口是否桥接无线
7. 配合 NAC 检测：未授权设备入网
```

**Q8: 在无线渗透测试中，如何获取 WPA2-Enterprise 的凭证？**

```
攻击方法：
1. 部署 Evil Twin AP，配置相同 SSID
2. 设置 Captive Portal 仿冒登录页
3. 等待客户端自动连接或诱导连接
4. 收集用户输入的凭证
5. 可结合 Deauth 攻击加速断连重连

防御措施：
- 部署服务器证书验证
- 配置客户端验证 CA 证书
- 使用 PEAP-EAP-TLS 双因素认证
- WIDS 检测伪造 AP
```
