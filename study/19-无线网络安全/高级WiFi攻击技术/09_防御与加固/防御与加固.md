# 防御与加固

### 9.1 针对各类攻击的防御措施

#### 9.1.1 WPA3攻击防御

| 攻击类型 | 防御措施 |
|---------|---------|
| Dragonblood侧信道攻击 | 更新固件（hostapd/wpa_supplicant已修复） |
| 降级攻击 | 禁用WPA2过渡模式，纯WPA3环境 |
| SAE在线猜测 | 启用速率限制，限制认证尝试次数 |
| 密码暴力破解 | 使用强密码（至少12位，混合字符） |

**详细措施**：

1. **纯WPA3部署**：
   - 如果所有设备都支持WPA3，禁用WPA2
   - 消除降级攻击的可能性

2. **固件更新**：
   - 确保AP和客户端都安装了Dragonblood补丁
   - 定期检查并更新固件

3. **强密码策略**：
   - 即使SAE抗离线攻击，强密码仍能防御在线猜测
   - 建议12位以上，包含大小写、数字、符号

4. **速率限制**：
   - 配置AP限制同一客户端的认证尝试频率
   - 防止在线暴力破解

#### 9.1.2 Enterprise WiFi攻击防御

| 攻击类型 | 防御措施 |
|---------|---------|
| Evil Twin | 启用服务器证书验证，配置正确的CA |
| GTC降级 | 客户端仅允许指定EAP方法 |
| EAP中继 | 部署WIPS，启用通道绑定 |
| RADIUS攻击 | 使用强共享密钥，限制RADIUS访问 |

**详细措施**：

1. **证书验证强制化**：
   - 客户端必须验证服务器证书
   - 配置受信任的根CA
   - 验证证书域名/主题

2. **EAP方法限制**：
   - 仅启用需要的EAP方法
   - 禁用不安全的方法（如EAP-MD5、LEAP）
   - 优先使用EAP-TLS

3. **RADIUS安全加固**：
   - 使用强共享密钥（至少16位随机字符）
   - 限制RADIUS服务器的访问源IP
   - 启用RADIUS/TLS（RadSec）

4. **账号安全**：
   - 使用强密码策略
   - 启用账号锁定（多次失败后锁定）
   - 定期审计账号使用情况

#### 9.1.3 管理帧攻击防御

| 攻击类型 | 防御措施 |
|---------|---------|
| 取消认证攻击 | 启用MFP（802.11w）必需模式 |
| Beacon洪泛 | 部署WIPS，检测异常Beacon |
| Evil Twin | WIPS检测和定位，员工培训 |
| 半关联攻击 | 监控异常关联模式 |

**详细措施**：

1. **启用MFP**：
   - 配置为"Required"模式
   - 确保所有客户端支持MFP
   - 不支持MFP的设备应升级或隔离

2. **无线入侵检测**：
   - 部署WIDS/WIPS系统
   - 监控未授权AP
   - 检测异常管理帧流量

3. **物理安全**：
   - 限制物理接入范围
   - 定期进行无线场地勘测
   - 检测和定位未授权设备

#### 9.1.4 KRACK攻击防御

| 攻击类型 | 防御措施 |
|---------|---------|
| KRACK密钥重装 | 安装所有设备的安全补丁 |
| 流量解密 | 使用端到端加密（VPN、HTTPS） |
| 重放攻击 | 补丁修复 + 应用层防护 |

**详细措施**：

1. **补丁管理**：
   - 确保所有客户端安装KRACK补丁
   - 确保所有AP/控制器安装补丁
   - 建立固件更新机制

2. **端到端加密**：
   - 即使WiFi加密被破解，数据仍受保护
   - 强制使用HTTPS（HSTS）
   - 企业网络使用VPN

3. **网络分段**：
   - 无线网络与内部网络隔离
   - 通过防火墙控制访问
   - 限制无线用户的访问权限

#### 9.1.5 Captive Portal攻击防御

| 攻击类型 | 防御措施 |
|---------|---------|
| 虚假Portal | 验证Portal证书，使用官方APP认证 |
| 自动连接漏洞 | 禁用开放网络自动连接 |
| DNS劫持 | 使用加密DNS（DoH/DoT） |
| 流量劫持 | 使用VPN，验证HTTPS证书 |

**详细措施**：

1. **用户教育**：
   - 不随意连接公共WiFi
   - 不轻易信任Captive Portal
   - 公共WiFi下不进行敏感操作

2. **设备配置**：
   - 关闭自动连接开放网络
   - 定期清理已知网络列表
   - 启用VPN自动连接公共网络

3. **技术防护**：
   - 使用HTTPS Everywhere
   - 启用DNS over HTTPS/TLS
   - 使用VPN保护所有流量

### 9.2 企业无线安全最佳实践

#### 9.2.1 网络架构设计

**分层架构**：

```
互联网
   |
[防火墙]
   |
[核心交换机]
   |
   +-- [无线控制器] -- [AP] -- 无线网络
   |
   +-- 内部有线网络
   |
   +-- [DMZ区]
```

**网络分段原则**：
- 访客网络与内部网络完全隔离
- 不同部门使用不同SSID和VLAN
- IoT设备单独划分网络
- 无线访问受防火墙控制

**SSID规划**：
- 企业员工网络：WPA3-Enterprise，EAP-TLS
- 访客网络：Captive Portal，隔离VLAN
- IoT网络：WPA3-Personal，MAC白名单，网络隔离
- 不使用隐藏SSID（安全性提升有限，使用不便）

#### 9.2.2 认证与加密

**推荐认证方式**（按安全性排序）：

1. **WPA3-Enterprise + EAP-TLS**：最高安全性
   - 双向证书认证
   - 无密码泄露风险
   - 适合高安全要求环境

2. **WPA3-Enterprise + PEAP/EAP-TTLS**：
   - 服务器端证书认证
   - 内层密码认证
   - 部署成本较低

3. **WPA3-Personal (SAE)**：
   - 适用于小型办公室
   - 使用强密码
   - 比WPA2-PSK安全

**禁用的认证方式**：
- WEP（完全不安全）
- WPA（已过时）
- WPA2-TKIP（TKIP已被破解）
- LEAP（思科专有，已不安全）
- EAP-MD5（单向认证，易被破解）

#### 9.2.3 AP安全配置基线

**加密配置**：
- 加密协议：WPA3-Enterprise（首选），WPA2-Enterprise（过渡）
- 加密算法：AES-CCMP（必需），GCMP（可选）
- 禁用TKIP、WEP

**管理帧保护**：
- MFP模式：Required（如所有客户端支持）
- 不支持MFP的客户端应升级

**WPS配置**：
- 禁用WPS-PIN模式（易受暴力破解）
- 如需WPS，仅使用WPS-PBC（按钮配置）

**广播配置**：
- 禁用默认SSID（如"linksys"、"default"）
- SSID不包含公司敏感信息
- 禁用旧的802.11b速率（如1/2 Mbps）

**管理接口安全**：
- 禁用HTTP管理，仅用HTTPS/SSH
- 更改默认管理员密码
- 使用强密码或密钥认证
- 限制管理接口的访问源
- 启用审计日志

#### 9.2.4 客户端安全配置

**策略**：
- 统一部署无线配置（通过GPO、MDM等）
- 强制证书验证
- 禁止用户随意添加无线网络
- 禁用ad-hoc模式

**设备管理**：
- 仅允许受管设备连接企业网络
- NAC（网络访问控制）检查设备健康状态
- 设备注册和白名单机制
- 离职员工及时撤销访问权限

### 9.3 无线入侵检测与防御（WIDS/WIPS）

#### 9.3.1 WIDS与WIPS概述

**WIDS（Wireless Intrusion Detection System）**：
- 检测无线攻击和未授权设备
- 监控无线频谱和流量
- 产生告警和日志

**WIPS（Wireless Intrusion Prevention System）**：
- 在WIDS基础上增加防御功能
- 主动阻断攻击
- 压制未授权设备

#### 9.3.2 WIDS/WIPS的主要功能

**检测功能**：
- Rogue AP检测（未授权接入点）
- Evil Twin检测
- 取消认证/解除关联攻击检测
- KRACK攻击检测
- Beacon洪泛检测
- 异常流量检测
- 无线渗透测试工具检测

**防御功能**：
- 自动阻断未授权AP
- 取消认证攻击防御
- 干扰恶意AP信号
- 自动关闭受影响端口

**定位功能**：
- 定位未授权设备位置
- 追踪移动设备
- 可视化热点图

#### 9.3.3 部署架构

**分布式部署**：
- 专用传感器部署在各个区域
- 集中管理和分析
- 覆盖范围广，成本高

**集成式部署**：
- 利用现有AP兼任传感器
- 成本低，性能可能受影响
- 适合中小企业

**混合部署**：
- 关键区域专用传感器
- 其他区域使用AP兼任
- 平衡成本和性能

#### 9.3.4 常见WIDS/WIPS产品

**企业级**：
- Cisco DNA Center / Cisco Prime Infrastructure
- Aruba Central / AirWave
- Fortinet FortiWIPS
- Extreme Management Center

**开源/低成本**：
- Kismet（检测为主）
- 基于Python的定制方案

### 9.4 安全配置基线

#### 9.4.1 WLAN控制器安全基线

**管理安全**：
- [ ] 更改默认管理员密码
- [ ] 启用强密码策略
- [ ] 配置多因素认证（如支持）
- [ ] 禁用未使用的管理接口
- [ ] 启用HTTPS/SSH，禁用Telnet/HTTP
- [ ] 限制管理访问源IP
- [ ] 启用审计日志
- [ ] 配置日志服务器

**无线安全**：
- [ ] 禁用WEP和WPA
- [ ] 禁用TKIP加密
- [ ] 启用WPA3（如设备支持）
- [ ] 启用MFP（802.11w）
- [ ] 禁用WPS-PIN
- [ ] 配置RADIUS强共享密钥
- [ ] 启用RADIUS记账
- [ ] 配置客户端空闲超时
- [ ] 配置每个AP的最大客户端数

**网络安全**：
- [ ] 启用控制平面安全
- [ ] 配置CAPWAP DTLS加密
- [ ] 禁用未使用的VLAN
- [ ] 启用DHCP Snooping
- [ ] 启用动态ARP检测

#### 9.4.2 AP安全基线

**通用配置**：
- [ ] 更改默认凭证
- [ ] 更新最新固件
- [ ] 禁用未使用的服务
- [ ] 启用NTP时间同步
- [ ] 配置SNMPv3（如需要）
- [ ] 禁用SNMPv1/v2c

**无线射频配置**：
- [ ] 禁用低速率（1/2 Mbps）
- [ ] 合理设置发射功率
- [ ] 信道规划（避免干扰）
- [ ] 启用DFS（雷达检测，5GHz）
- [ ] 禁用40MHz信道宽度（2.4GHz，避免干扰）

#### 9.4.3 RADIUS服务器安全基线

**系统安全**：
- [ ] 操作系统加固
- [ ] 最小化安装
- [ ] 启用防火墙
- [ ] 定期更新补丁
- [ ] 启用审计日志

**RADIUS配置**：
- [ ] 使用强共享密钥（至少16位随机）
- [ ] 限制客户端IP白名单
- [ ] 禁用未使用的EAP方法
- [ ] 启用账户锁定策略
- [ ] 配置认证失败告警
- [ ] 使用证书验证（EAP-TLS）
- [ ] 定期轮换证书和密钥

#### 9.4.4 客户端安全基线

**Windows客户端**：
- [ ] 配置企业WiFi配置文件（通过GPO）
- [ ] 强制验证服务器证书
- [ ] 禁用自动连接开放网络
- [ ] 启用防火墙
- [ ] 保持系统更新
- [ ] 安装防病毒软件

**移动设备**：
- [ ] 通过MDM部署WiFi配置
- [ ] 禁用开放网络自动加入
- [ ] 启用随机MAC地址
- [ ] 强制设备加密
- [ ] 启用远程擦除功能
- [ ] 定期更新系统

#### 9.4.5 安全运维实践

**定期检查**：
- 每月：审查无线安全日志
- 每季度：无线场地勘测（检测未授权设备）
- 每半年：渗透测试
- 每年：全面安全审计

**应急响应**：
- 制定无线安全事件响应流程
- 定期演练应急响应
- 建立设备黑名单机制
- 准备应急工具包

**文档与培训**：
- 维护网络架构文档
- 记录所有无线设备清单
- 定期进行员工安全培训
- 更新安全策略和流程
