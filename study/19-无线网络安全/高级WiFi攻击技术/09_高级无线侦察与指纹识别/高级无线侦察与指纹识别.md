# 高级无线侦察与指纹识别

### 8.1 802.11指纹识别技术概述

#### 8.1.1 什么是无线指纹识别

无线指纹识别是指通过分析无线信号和帧的特征，来识别设备类型、厂商、型号甚至具体设备的技术。

**指纹识别的分类**：
- **主动指纹识别**：发送探测帧，分析响应特征
- **被动指纹识别**：仅监听，不发送任何帧
- **信号层指纹**：基于物理层信号特征
- **协议层指纹**：基于802.11协议实现特征

#### 8.1.2 指纹识别的应用场景

**安全领域**：
- 检测恶意设备（未授权AP、隐藏设备）
- 设备资产盘点
- 入侵检测（识别已知攻击工具的指纹）
- 网络边界监控

**商业领域**：
- 客流统计
- 用户行为分析
- 精准营销
- 位置服务

**研究领域**：
- 设备行为分析
- 网络测绘
- 漏洞研究

### 8.2 设备指纹与驱动指纹

#### 8.2.1 信息元素（IE）指纹

每个AP和客户端发送的802.11管理帧中包含各种信息元素（Information Element）。这些元素的顺序、内容和组合方式构成了独特的指纹。

**AP端指纹特征**：
- 支持的速率集（Supported Rates IE）
- RSN IE的具体内容（加密套件、AKM套件顺序）
- 供应商特定IE（Vendor Specific IE）
- HT能力IE（802.11n）
- VHT能力IE（802.11ac）
- HE能力IE（802.11ax）
- Beacon间隔的精确度
- DTIM周期

**客户端指纹特征**：
- Probe Request中的SSID列表
- 支持的速率集
- 支持的信道列表
- HT/VHT/HE能力
- 厂商特定IE（如WPS、Apple特定IE）
- Probe Request的时间间隔模式

#### 8.2.2 常见设备指纹库

**Wireshark的设备指纹**：
- Wireshark内置了一些厂商识别
- 基于OUI（MAC地址前24位）

**aircrack-ng的airodump-ng**：
- 显示AP的加密方式和厂商
- 基于OUI和能力信息

**Kismet**：
- 更详细的设备指纹
- 客户端行为分析
- 设备类型推断

**专业工具**：
- WiGLE：全球WiFi数据库
- Ekahau Site Survey：企业级无线勘测
- AirMagnet：企业级无线安全

#### 8.2.3 驱动指纹识别

不同的WiFi驱动程序有不同的实现细节，这些差异可以用来识别驱动甚至操作系统：

**驱动指纹特征**：
- 关联请求中的信息元素顺序
- 重试策略（重试次数、重试间隔）
- 信道扫描模式（扫描顺序、每个信道停留时间）
- 功率控制行为
- 漫游触发条件和行为

**操作系统级别的指纹**：

| 操作系统 | 典型特征 |
|---------|---------|
| Windows | 特定的IE顺序，NDIS驱动特征 |
| macOS/iOS | Apple特定的Vendor IE，AWDL（Apple Wireless Direct Link） |
| Android | 各种厂商定制，多样性高 |
| Linux | 通常基于mac80211，特征相对统一 |

#### 8.2.4 实战：使用scapy进行指纹分析

```python
from scapy.all import *
from scapy.layers.dot11 import Dot11, Dot11Beacon, Dot11Elt

def analyze_ap_fingerprint(packet):
    if packet.haslayer(Dot11Beacon):
        beacon = packet[Dot11Beacon]
        bssid = packet[Dot11].addr2
        
        ie_order = []
        layer = packet.getlayer(Dot11Elt)
        while layer:
            if hasattr(layer, 'ID'):
                ie_order.append(layer.ID)
            layer = layer.payload if hasattr(layer, 'payload') else None
            if layer and not isinstance(layer, Dot11Elt):
                break
        
        print(f"BSSID: {bssid}")
        print(f"IE顺序: {ie_order}")

sniff(iface="wlan0mon", prn=analyze_ap_fingerprint, count=100)
```

### 8.3 客户端设备被动识别

#### 8.3.1 被动识别的优势

- **完全静默**：不发送任何帧，不会被检测
- **可远程进行**：只要在信号范围内
- **不影响网络**：不会对网络造成任何干扰
- **可长期监控**：持续收集设备信息

#### 8.3.2 Probe Request分析

Probe Request是客户端指纹识别的主要信息来源：

**信息内容**：
- 客户端MAC地址（可能被随机化）
- 请求的SSID（已知网络列表）
- 支持的速率
- 支持的信道
- HT/VHT能力
- 厂商特定信息

**行为模式**：
- 发送间隔
- 信道扫描模式
- 发送功率
- 重传行为

#### 8.3.3 MAC地址随机化应对

现代操作系统普遍使用MAC地址随机化来保护隐私：
- iOS 8+：默认启用随机MAC
- Android 6.0+：支持随机MAC
- Windows 10+：支持随机硬件地址

**应对随机化的方法**：

1. **行为指纹**：
   - 扫描模式（信道顺序、停留时间）
   - Probe Request的内容和结构
   - 发送间隔模式

2. **关联后识别**：
   - 客户端关联后使用真实MAC
   - 通过数据帧中的特征识别

3. **信号特征**：
   - 信号强度模式
   - 定时特征（时钟偏移）

4. **设备关联分析**：
   - 同一设备的不同接口（WiFi+蓝牙）
   - 时间和空间关联

#### 8.3.4 客户端行为画像

通过长期监控，可以建立客户端的行为画像：

- **出现时间规律**：工作日/周末、早晚高峰
- **位置移动规律**：在不同AP之间的漫游
- **连接偏好**：常连接的网络类型
- **数据使用模式**：流量大小、协议分布
- **设备活跃度**：发送/接收数据的频率

### 8.4 接入点型号与固件版本识别

#### 8.4.1 AP指纹识别方法

**基于信息元素的识别**：
- 不同厂商的AP发送的Beacon帧有不同的IE组合
- 同一厂商不同型号的AP也有差异
- 固件版本也会影响IE内容

**基于响应时间的识别**：
- 不同AP对Probe Request的响应延迟不同
- 处理能力不同导致响应时间差异

**基于错误响应的识别**：
- 发送异常构造的帧
- 不同实现的错误响应不同
- 类似TCP/IP协议栈指纹识别

#### 8.4.2 常见厂商AP特征

**Cisco**：
- 特定的Cisco Vendor IE
- CCX支持信息
- 通常有较高的Beacon间隔稳定性

**Ubiquiti (UniFi)**：
- Ubiquiti特定的Vendor IE
- 支持的功能集特征

**TP-Link**：
- 常见的配置模式
- 特定的默认SSID模式

**MikroTik**：
- RouterOS特定的信息元素
- 独特的功能声明

#### 8.4.3 实战：AP指纹数据库

构建AP指纹数据库的步骤：

1. **数据收集**：
   - 在已知AP环境下收集Beacon帧
   - 记录AP型号、固件版本
   - 提取所有IE信息

2. **特征提取**：
   - IE的ID顺序
   - 每个IE的长度
   - IE内容的关键字节
   - Beacon间隔精度

3. **分类模型**：
   - 使用机器学习模型进行分类
   - 决策树、随机森林等
   - 根据特征识别型号和固件

### 8.5 无线流量分析与设备行为画像

#### 8.5.1 流量分析可以获取的信息

即使流量被加密，通过流量分析仍可获取大量信息：

**设备类型推断**：
- 流量模式（突发流量 vs 持续流量）
- 端口使用情况
- 协议分布
- DNS查询模式

**用户行为分析**：
- 上网时间规律
- 流量大小变化
- 漫游模式
- 连接的AP和时间

**应用识别**：
- 通过包大小和时间模式识别应用
- 例如：视频流（大包、持续）、VoIP（小包、固定间隔）
- TLS SNI（服务器名称指示）可暴露访问的网站

#### 8.5.2 加密流量分析技术

**流量特征提取**：
- 包大小分布
- 包间隔时间
- 流量突发模式
- 上行/下行流量比例

**网站指纹识别**：
- 即使使用HTTPS，通过包大小和顺序仍可识别访问的网页
- 每个网页有独特的资源加载模式
- 防御：流量填充、Tor等

**设备活动识别**：
- 视频观看：下行大包持续流量
- 语音通话：小包双向对称
- 文件下载：下行大流量
- 浏览网页：突发流量

#### 8.5.3 元数据泄露

**802.11帧头信息**：
- MAC地址（设备身份）
- BSSID（所属网络）
- 帧类型/子类型
- 序列号（行为模式）
- 持续时间（流量估算）

**数据量估算**：
- 通过帧的数量和大小估算总流量
- 即使无法解密内容，也能知道通信量
- 可推断用户活动

### 8.6 基于信号特征的定位与追踪

#### 8.6.1 RSSI定位原理

RSSI（Received Signal Strength Indicator）是最常用的定位依据：

**三角定位法**：
- 至少三个已知位置的接收器
- 测量目标设备的信号强度
- 根据信号衰减模型估算距离
- 用三角测量计算位置

**指纹定位法**：
- 预先建立信号指纹地图（每个位置的RSSI特征）
- 实时测量RSSI并与指纹库匹配
- 精度更高，但需要预先勘测

#### 8.6.2 定位精度与限制

**影响精度的因素**：
- 多径效应（信号反射）
- 障碍物（墙壁、人体）
- 环境变化（家具移动、人员走动）
- 天线方向和增益
- 发送功率变化

**典型精度**：
- 室外开阔地：5-20米
- 室内多房间：3-10米
- 高精度系统：1-3米

#### 8.6.3 设备追踪

**人员追踪**：
- 通过WiFi信号追踪人员位置
- 商场客流分析
- 人员路径追踪
- 即使不连接AP，只要WiFi开启就可被追踪

**防御追踪的方法**：
- 关闭WiFi（不使用时）
- 使用MAC地址随机化
- 信号混淆技术
- 法律和监管限制

#### 8.6.4 时钟偏移指纹

每个设备的时钟都有微小的偏移（Clock Skew），这种偏移是独特的，可以用来识别设备：

**原理**：
- 每个设备的晶振频率略有不同
- 导致时间戳有独特的漂移模式
- 这种漂移模式是设备的物理指纹
- 无法通过软件修改

**应用**：
- 绕过MAC地址随机化
- 识别特定设备
- 跨网络追踪设备
