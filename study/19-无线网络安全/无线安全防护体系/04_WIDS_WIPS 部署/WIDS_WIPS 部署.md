# WIDS/WIPS 部署

### 3.1 WIDS/WIPS 架构

```
企业级 WIDS/WIPS 架构：

┌──────────────────────────────────────────────────┐
│                  安全管理平台                     │
│  ┌─────────┐  ┌─────────┐  ┌─────────────────┐ │
│  │ 告警引擎 │  │ 分析引擎 │  │ 报表/可视化     │ │
│  └─────────┘  └─────────┘  └─────────────────┘ │
│  ┌─────────┐  ┌─────────┐  ┌─────────────────┐ │
│  │ SIEM集成 │  │ 响应引擎 │  │ 取证存储        │ │
│  └─────────┘  └─────────┘  └─────────────────┘ │
└──────────────────────┬───────────────────────────┘
                       │
           ┌───────────┼───────────┐
           │           │           │
    ┌──────┴──┐ ┌──────┴──┐ ┌──────┴──┐
    │传感器-1 │ │传感器-2 │ │传感器-N │
    │楼层1F  │ │楼层2F  │ │楼层NF  │
    └─────────┘ └─────────┘ └─────────┘

传感器部署模式：

1. 专用传感器（Overlay）
   ├── 独立硬件传感器
   ├── 7x24 全频段扫描
   ├── 不影响 AP 性能
   ├── 成本较高
   └── 适用于高安全需求

2. 集成传感器（Underlay）
   ├── AP 集成 WIDS 功能
   ├── 分时扫描（服务+扫描）
   ├── 成本较低
   ├── 扫描覆盖有限
   └── 适用于一般安全需求

3. 混合部署
   ├── 关键区域: 专用传感器
   ├── 一般区域: AP 集成扫描
   ├── 平衡成本和覆盖
   └── 推荐企业部署方案

传感器覆盖规划：
├── 每层楼至少 2 个传感器
├── 覆盖所有 2.4G/5G/6G 频段
├── 传感器间距 < 30 米
├── 重点区域加密部署
├── 停车场/外围区域覆盖
└── 信号重叠确保定位精度
```

### 3.2 Rogue AP 检测

```
Rogue AP 检测流程：

检测方法：

1. 无线侧检测
   ├── 扫描所有信道
   ├── 记录发现的 AP 信息:
   │   ├── BSSID (MAC 地址)
   │   ├── SSID
   │   ├── 信道
   │   ├── 信号强度
   │   ├── 厂商 OUI
   │   ├── 加密方式
   │   └── Beacon/Probe 响应
   ├── 与授权 AP 白名单对比
   └── 标记未授权 AP

2. 有线侧检测
   ├── 扫描交换机 MAC 地址表
   ├── 查找无线 AP 的 MAC
   ├── 追踪 AP 连接的交换机端口
   ├── 检测 DHCP 服务器
   └── 确认 AP 是否连接到企业网络

3. 分类判定
   ├── Rogue AP: 未授权连接到企业网
   ├── Friendly AP: 授权的企业 AP
   ├── External AP: 非企业的外部 AP
   └── Ad-hoc: 点对点网络

分类算法：
┌──────────────┐
│  发现新 AP    │
└──────┬───────┘
       │
       ▼
┌──────────────┐     是    ┌──────────────┐
│ 在白名单中？  │────────→│  Friendly AP │
└──────┬───────┘          └──────────────┘
       │ 否
       ▼
┌──────────────┐     是    ┌──────────────┐
│ 连接到企业网？│────────→│  Rogue AP    │
│ (有线侧检测) │          │  (严重威胁)  │
└──────┬───────┘          └──────────────┘
       │ 否
       ▼
┌──────────────┐     是    ┌──────────────┐
│ 使用企业SSID？│────────→│ 可能是伪造AP │
│ 但非授权MAC   │          │  (Evil Twin) │
└──────┬───────┘          └──────────────┘
       │ 否
       ▼
┌──────────────┐
│  External AP │
│  (外部AP)    │
└──────────────┘

自动响应：
├── Rogue AP: 切断交换机端口 + 无线抑制
├── Evil Twin: 告警 + 客户端抑制
├── Ad-hoc: 告警 + 无线抑制
└── External: 记录，持续监控
```

### 3.3 无线入侵防御

```
WIPS 主动防御机制：

1. 主动抑制（Containment）
   ├── 向非法设备发送 Deauth 帧
   ├── 切断非法 AP 与客户端连接
   ├── 持续抑制直到威胁消除
   └── 注意: 可能影响合法通信

2. 信道干扰
   ├── 对非法 AP 发射定向干扰
   ├── 信道级 DoS 抑制
   ├── 需要专用硬件支持
   └── 谨慎使用，避免副作用

3. 端口关闭
   ├── 联动交换机关闭 Rogue AP 端口
   ├── SNMP/SSH 自动配置
   ├── 快速切断有线连接
   └── 需要网络设备支持

4. 设备定位
   ├── 信号强度三角定位
   ├── 到达时间差（TDOA）
   ├── 到达角度（AOA）
   └── 精度: 2-5 米

5. 客户端保护
   ├── 向连接 Rogue AP 的客户端发送告警
   ├── 推送安全策略
   ├── 隔离受影响客户端
   └── NAC 联动策略执行

WIPS 响应策略矩阵：

威胁类型    │ 响应级别 │ 自动响应         │ 通知方式
Rogue AP   │ 严重    │ 端口关闭+抑制   │ 短信+邮件+SIEM
Evil Twin  │ 严重    │ 客户端抑制+告警 │ 短信+邮件+SIEM
Deauth洪水 │ 高      │ 源定位+告警     │ 邮件+SIEM
Ad-hoc网络 │ 中      │ 告警+可选抑制   │ 邮件
未授权设备  │ 中      │ 告警+定位       │ 邮件
信号干扰   │ 中      │ 告警+频谱分析   │ 邮件
弱加密配置  │ 低      │ 告警            │ 日报

开源 WIDS 方案（Kismet + 自定义脚本）：

#!/bin/bash
# Kismet WIDS 自动响应脚本
# 监控 Kismet 告警并自动响应

KISMET_ALERT_DIR="/var/log/kismet/alerts"
WHITELIST_FILE="/etc/kismet/ap_whitelist.txt"

# 加载授权 AP 白名单
declare -A WHITELIST
while read -r mac ssid; do
    WHITELIST["$mac"]="$ssid"
done < "$WHITELIST_FILE"

# 监控新 AP 出现
check_new_ap() {
    while read -r line; do
        bssid=$(echo "$line" | awk '{print $1}')
        ssid=$(echo "$line" | awk '{print $2}')
        
        if [[ -z "${WHITELIST[$bssid]}" ]]; then
            echo "[!] 未授权 AP 发现: $bssid ($ssid)"
            # 触发告警和响应
            send_alert "$bssid" "$ssid"
            locate_ap "$bssid"
            # 自动抑制（谨慎使用）
            # contain_ap "$bssid"
        fi
    done < <(kismet_client --dump-aps)
}

send_alert() {
    local bssid=$1
    local ssid=$2
    # 发送告警到 SIEM
    logger -t WIDS "ROGUE_AP_DETECTED: $bssid $ssid"
    # 发送邮件
    echo "发现未授权 AP: $ssid ($bssid)" | \
        mail -s "WIDS Alert: Rogue AP" security@company.com
}

locate_ap() {
    local bssid=$1
    # 使用多个传感器进行三角定位
    kismet_locate "$bssid"
}

check_new_ap
```
