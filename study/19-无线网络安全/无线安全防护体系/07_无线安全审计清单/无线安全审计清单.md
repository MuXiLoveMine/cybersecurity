# 无线安全审计清单

### 6.1 WiFi 安全审计清单

```
WiFi 安全审计清单（全面版）：

A. 架构安全
[ ] 无线网络与有线网络 VLAN 隔离
[ ] 不同安全级别网络分离（员工/访客/IoT）
[ ] 无线管理网络专用 VLAN
[ ] 客户端隔离（禁止 STA 间通信）
[ ] AP 管理接口不可从无线访问
[ ] CAPWAP 隧道加密
[ ] WLC 冗余部署

B. 认证安全
[ ] 使用 WPA3-Enterprise（或 WPA2）
[ ] 802.1X 认证（EAP-TLS 推荐）
[ ] 服务器证书验证
[ ] 客户端证书部署
[ ] CA 基础设施完善
[ ] RADIUS 高可用
[ ] 认证超时和重新认证
[ ] 禁用 WEP 和 WPA-TKIP
[ ] 访客使用 Portal 认证

C. 加密安全
[ ] 使用 AES-CCMP 或 GCMP
[ ] 密钥长度符合标准
[ ] 密钥定期轮换
[ ] PTK/GTK 重新生成
[ ] 管理帧保护（PMF）启用
[ ] WPA3 SAE 配置正确

D. AP 安全
[ ] 修改默认管理员密码
[ ] 修改默认 SSID
[ ] 禁用远程管理
[ ] 固件版本最新
[ ] WPS 功能禁用
[ ] 禁用 UPnP
[ ] 管理界面 HTTPS
[ ] 日志功能启用
[ ] 信号功率合理控制

E. 漫游安全
[ ] 802.11r 快速漫游
[ ] 802.11k 射频管理
[ ] 802.11v BSS 转换
[ ] 漫游密钥安全

F. 监控安全
[ ] WIDS/WIPS 部署
[ ] Rogue AP 检测
[ ] 告警策略配置
[ ] SIEM 集成
[ ] 日志保留合规
[ ] 定期安全报告

G. 物理安全
[ ] AP 安装在安全位置
[ ] 以太网端口安全
[ ] 信号覆盖控制
[ ] 物理巡查制度

H. 策略安全
[ ] 无线安全策略文档
[ ] 设备使用规范
[ ] 访客管理流程
[ ] 应急响应预案
[ ] 定期安全培训
```
