# 蓝牙安全防护

### 4.1 设备配对加固

```
蓝牙设备配对安全加固：

配对模式选择优先级：
1. Out of Band (OOB) — 最安全
2. Numeric Comparison (SC) — 推荐
3. Passkey Entry (SC) — 推荐
4. Just Works — 避免（无 MITM 保护）

安全配对实施指南：

1. 使用 BLE Secure Connections
   ├── 强制使用 ECDH-P256 密钥交换
   ├── 提供前向保密
   ├── 抵抗被动窃听
   └── BLE 4.2+ 必须支持

2. 用户交互认证
   ├── Numeric Comparison: 显示并确认 6 位数字
   ├── Passkey Entry: 输入显示的 6 位数字
   ├── 禁用 Just Works（除非低风险场景）
   └── 必要时使用 OOB（如 NFC 辅助配对）

3. 密钥长度强制
   ├── 最小加密密钥长度: 7 字节（56位）
   ├── 推荐密钥长度: 16 字节（128位）
   ├── 检查并拒绝降级请求
   └── 修补 KNOB 漏洞

4. 配对环境控制
   ├── 仅在可信环境配对
   ├── 避免公共场所配对
   ├── 限制配对时间窗口
   └── 配对后立即验证

代码示例（嵌入式蓝牙设备）：

// C 代码: BLE Secure Connections 配对配置
#include <bluetooth/bluetooth.h>
#include <bluetooth/conn.h>

static struct bt_conn_auth_cb auth_cb = {
    .pairing_confirm = pairing_confirm_cb,
    .passkey_display = passkey_display_cb,
    .passkey_entry = NULL,  // 禁用 Passkey Entry
    .passkey_confirm = passkey_confirm_cb,
    .cancel = auth_cancel_cb,
};

void configure_ble_security(void) {
    // 注册认证回调
    bt_conn_auth_cb_register(&auth_cb);
    
    // 配置安全参数
    struct bt_conn_auth_param param = {
        .sec_level = BT_SECURITY_L3,  // 高安全级别
        .force_pairing = true,
        .key_size = 16,               // 128 位密钥
        .use_secure_connections = true, // 强制 SC
        .oob_data = NULL,             // 无 OOB
        .io_caps = BT_IO_DISPLAY_YESNO, // 显示+确认
    };
}

static void passkey_display_cb(struct bt_conn *conn, 
                                unsigned int passkey) {
    char addr[BT_ADDR_LE_STR_LEN];
    bt_addr_le_to_str(bt_conn_get_dst(conn), addr, sizeof(addr));
    printf("配对设备: %s\n", addr);
    printf("请确认配对码: %06u\n", passkey);
    
    // 在屏幕上显示 6 位数字
    display_pairing_code(passkey);
}

static void pairing_confirm_cb(struct bt_conn *conn) {
    // 用户确认配对请求
    // 不要自动确认，要求用户交互
    prompt_user_confirmation(conn);
}
```

### 4.3 蓝牙安全监控

```
蓝牙安全监控系统：

监控组件：
├── 蓝牙扫描传感器
├── 流量分析引擎

├── 告警管理平台
└── SIEM 集成

监控指标：
├── 新设备出现: 检测未知蓝牙设备
├── 配对活动: 监控配对请求
├── 连接模式: 分析连接频率和时间
├── 数据传输: 监控大数据传输
├── 信号异常: 检测异常信号强度
├── 服务枚举: 检测 SDP 扫描
├── 协议异常: 检测异常协议行为
└── 已知漏洞: 检测漏洞利用特征

开源监控方案：

# Bluetooth 监控脚本
#!/bin/bash
# 蓝牙设备监控器

LOG_FILE="/var/log/bluetooth_monitor.log"
KNOWN_DEVICES_FILE="/etc/bt/known_devices.txt"
ALERT_EMAIL="security@company.com"

# 已知设备列表
declare -A KNOWN_DEVICES
while read -r mac name; do
    KNOWN_DEVICES["$mac"]="$name"
done < "$KNOWN_DEVICES_FILE"

# 持续扫描
while true; do
    # 扫描经典蓝牙设备
    hcitool scan | while read -r line; do
        if [[ "$line" =~ ([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2} ]]; then
            mac=$(echo "$line" | awk '{print $1}')
            name=$(echo "$line" | awk '{print $2}')
            
            if [[ -z "${KNOWN_DEVICES[$mac]}" ]]; then
                echo "$(date): 未知蓝牙设备: $mac ($name)" >> "$LOG_FILE"
                echo "发现未知蓝牙设备: $name ($mac)" | \
                    mail -s "BT Alert: Unknown Device" "$ALERT_EMAIL"
            fi
        fi
    done
    
    # 扫描 BLE 设备
    hcitool lescan --duplicates | while read -r line; do
        if [[ "$line" =~ ([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2} ]]; then
            mac=$(echo "$line" | awk '{print $1}')
            if [[ -z "${KNOWN_DEVICES[$mac]}" ]]; then
                echo "$(date): 未知 BLE 设备: $mac" >> "$LOG_FILE"
            fi
        fi
    done
    
    sleep 60  # 每分钟扫描一次
done
```
