# 无线渗透测试方法论

### 2.1 五阶段方法论概述

基于业界最佳实践和无线安全的特殊性，我们将无线渗透测试划分为五个核心阶段。每个阶段都有明确的目标、交付物和质量控制点。

│                    无线渗透测试五阶段方法论                │

│  侦察阶段   │ 规划与准备  │   攻击阶段   │  后渗透阶段    │

│   sance     │  & Prep     │             │ Exploitation  │

### 2.2 第一阶段：侦察阶段（Reconnaissance）

侦察阶段是无线渗透测试的起点，目标是尽可能全面地了解目标环境的无线资产分布、信号特征和安全配置。

#### 2.2.1 被动侦察

被动侦察是在不主动发射无线信号的前提下，通过监听和分析周围的无线信号来获取信息。这种方式的优点是隐蔽性强，不会被目标检测到。

**被动侦察的主要内容：**

1. **信号探测与识别**
   - 使用监听模式（Monitor Mode）捕获周围的802.11帧
   - 识别所有可见的SSID（包括隐藏SSID）
   - 记录每个AP的BSSID、信道、信号强度、加密方式
   - 绘制信号覆盖范围热力图

2. **客户端设备发现**
   - 通过Probe Request帧发现连接过目标网络的客户端设备
   - 识别客户端设备的厂商（通过MAC地址OUI）
   - 分析客户端的行为模式（连接时间、漫游行为等）

3. **网络拓扑推断**
   - 通过AP的配置信息推断网络结构
   - 识别同一ESS下的多个BSS
   - 分析漫游域的划分

4. **隐藏网络识别**
   - 通过广播帧中的信息推断隐藏SSID的名称
   - 等待合法客户端连接时捕获SSID信息

**常用被动侦察工具：**
- `airodump-ng`：最常用的无线数据包捕获和分析工具
- `Kismet`：功能强大的无线网络检测和嗅探工具
- `Wireshark`：深入的数据包协议分析
- `wash`：WPS启用状态检测
- `bettercap`：集成的无线侦察和攻击框架

#### 2.2.2 主动扫描

主动扫描是通过主动发送探测请求等方式来获取更多的目标信息。主动扫描的信息获取效率更高，但可能被目标的WIDS/WIPS系统检测到。

**主动扫描的主要内容：**

1. **AP详细信息收集**
   - 发送Probe Request获取AP的详细能力信息
   - 检测支持的802.11标准（a/b/g/n/ac/ax）
   - 检测支持的加密方式和认证方式
   - 检测WPS功能的启用状态

2. **客户端关联测试**
   - 测试AP对未授权客户端的响应方式
   - 测试MAC地址过滤的有效性
   - 测试客户端隔离功能

3. **WPS漏洞检测**
   - 检测WPS PIN码的脆弱性
   - 测试WPS暴力破解的可能性
   - 检测是否存在WPS锁定机制

4. **Rogue AP检测**
   - 对比授权AP列表，发现未授权接入点
   - 检测Evil Twin攻击风险

**主动扫描注意事项：**
- 在测试前确认是否允许主动扫描
- 控制扫描频率，避免对目标网络造成干扰
- 记录所有主动发送的数据包，便于后续分析和报告

#### 2.2.3 信号测绘

信号测绘（Wireless Site Survey）是对目标区域的无线信号进行系统性测量和绘图的过程，是无线渗透测试中非常重要的环节。

**信号测绘的目标：**

1. **确定信号覆盖范围**
   - 测量目标AP在建筑物内外的信号强度分布
   - 识别信号泄露区域（停车场、街道、相邻建筑等）
   - 评估攻击者可以在多远的距离外发起攻击

2. **绘制热力图**
   - 使用专业工具绘制信号强度热力图
   - 标注高风险区域（信号强且容易接近的外部区域）
   - 识别信号盲区（可能成为安全监控的死角）

3. **信道干扰分析**
   - 分析周围无线环境的信道使用情况
   - 识别可能的干扰源
   - 评估信道拥挤程度

4. **物理安全评估**
   - 识别AP的物理位置
   - 评估AP的物理安全防护措施
   - 发现可能被利用的物理接入点

**信号测绘工具：**
- `AirMagnet Survey`：专业的无线勘测工具
- `Ekahau Site Survey`：企业级WiFi勘测软件
- `Kismet + GPS`：开源的无线信号测绘方案
- `WiFi Explorer`：macOS平台的WiFi分析工具

**侦察阶段交付物：**
- 无线网络资产清单（AP列表、客户端列表）
- 信号覆盖热力图
- 网络拓扑推断图
- 初步安全评估报告（加密方式、认证机制等）
- 侦察阶段Checklist确认表

**侦察阶段Checklist：**
- [ ] 所有2.4GHz频段AP已识别
- [ ] 所有5GHz频段AP已识别
- [ ] 所有SSID已记录（包括隐藏SSID）
- [ ] 每个AP的加密方式已确认
- [ ] 每个AP的认证方式已确认
- [ ] WPS启用状态已检测
- [ ] 客户端设备列表已建立
- [ ] 信号覆盖范围已测绘
- [ ] Rogue AP检测已完成
- [ ] 物理接入点位置已标注

### 2.3 第二阶段：规划与准备阶段

规划与准备阶段是在正式发起攻击前，基于侦察阶段获取的信息，制定详细的测试计划和准备必要的工具环境。

#### 2.3.1 目标确认

在规划阶段，需要与客户确认以下关键信息：

1. **测试目标优先级**
   - 核心业务网络 vs 访客网络
   - 关键系统 vs 普通系统
   - 高风险设备 vs 低风险设备

2. **测试深度要求**
   - 仅发现漏洞 vs 深度利用
   - 是否允许后渗透测试
   - 是否允许社会工程测试

3. **限制条件确认**
   - 禁止使用的攻击方法
   - 禁止测试的系统或设备
   - 业务影响容忍度

#### 2.3.2 工具准备

根据目标环境的特点，准备相应的测试工具和设备：

1. **无线网卡**
   - 确认网卡支持监听模式和数据包注入
   - 准备支持2.4GHz和5GHz双频的网卡
   - 准备高增益天线（根据测试距离需求）

2. **软件工具**
   - 安装和配置Kali Linux或其他渗透测试系统
   - 更新无线工具到最新版本
   - 准备字典文件（根据目标信息定制）

3. **专用硬件**
   - WiFi Pineapple（用于Evil Twin等攻击）
   - Ubertooth One（用于蓝牙测试）
   - HackRF One（用于SDR相关测试）
   - 可编程路由器（用于定制化攻击）

4. **辅助设备**
   - GPS接收器（用于信号测绘）
   - 高容量电池（用于长时间野外测试）
   - 定向天线（用于远距离测试）

#### 2.3.3 环境评估

1. **无线环境评估**
   - 评估目标区域的无线信号干扰情况
   - 确认测试不会对周边合法用户造成严重干扰
   - 评估最佳测试时间窗口

2. **物理环境评估**
   - 确认测试人员的物理活动范围
   - 评估物理安全风险（是否会被安保人员盘问）
   - 确认紧急撤离路线

3. **技术环境评估**
   - 评估目标网络的安全防护能力
   - 确认是否有WIDS/WIPS系统
   - 预估测试被检测到的概率

#### 2.3.4 风险评估

在正式攻击前，必须进行充分的风险评估：

1. **业务影响风险**
   - 评估各种攻击方法可能对业务造成的影响
   - 识别高风险攻击方法并制定缓解措施
   - 制定业务中断应急预案

2. **法律合规风险**
   - 确认所有测试活动在授权范围内
   - 评估信号溢出可能造成的法律风险
   - 确认保险覆盖范围

3. **技术风险**
   - 评估测试设备故障的可能性
   - 准备备用设备和方案
   - 评估目标系统意外损坏的风险

**规划阶段交付物：**
- 详细测试计划（含时间表）
- 工具清单与配置说明
- 风险评估报告
- 应急预案
- 测试授权书（最终版）

### 2.4 第三阶段：攻击阶段

攻击阶段是无线渗透测试的核心，通过实际利用已发现的漏洞来验证安全风险的真实存在性。

#### 2.4.1 身份认证攻击

身份认证攻击针对无线网络的身份验证机制，目标是绕过认证或获取合法用户的认证凭证。

1. **WEP破解**
   - 原理：WEP加密存在致命的设计缺陷，通过收集足够的IV（初始化向量）即可破解密钥
   - 方法：ARP注入加速IV收集、Chop-Chop攻击、Fragmentation攻击
   - 工具：`aircrack-ng`套件
   - 预期时间：在流量充足的情况下，几分钟到几十分钟

2. **WPA/WPA2 PSK破解**
   - 原理：捕获WPA四次握手（4-Way Handshake），然后通过字典攻击破解预共享密钥
   - 方法：
     - 被动等待客户端连接时捕获握手
     - 发送Deauthentication帧强制客户端重连
     - 使用PMKID攻击（无需客户端，直接从AP获取PMKID）
   - 工具：`aircrack-ng`、`hashcat`、`hcxtools`
   - 成功率取决于密码强度和字典质量

3. **WPA3攻击面**
   - Dragonblood攻击：针对WPA3的Dragonfly握手协议的攻击
   - 降级攻击：迫使支持WPA3的设备使用WPA2模式
   - 侧信道攻击：利用时间侧信道信息恢复密码

4. **企业级认证攻击（WPA/WPA2 Enterprise）**
   - Evil Twin + RADIUS中继：搭建伪造的AP，中继认证请求到真实RADIUS服务器
   - PEAP/MS-CHAPv2破解：获取挑战响应后破解NTLM哈希
   - EAP中继攻击：中继EAP认证会话
   - 证书伪造攻击：利用客户端不验证服务器证书的漏洞

5. **WPS攻击**
   - WPS PIN暴力破解：利用WPS PIN码的设计缺陷（前4位和后3位分别验证）
   - Pixie Dust攻击：针对特定芯片组的WPS漏洞，快速获取PIN码
   - 工具：`Reaver`、`Bully`、`OneShot`

#### 2.4.2 加密破解

除了针对认证机制的攻击外，还需要评估无线网络加密机制的安全性：

1. **加密降级攻击**
   - 迫使AP和客户端使用较弱的加密方式
   - 利用TKIP的已知漏洞（如Beck-Tews攻击）

2. **密钥重装攻击（KRACK）**
   - 针对WPA2/WPA3的密钥重装漏洞
   - 攻击者可以解密、伪造甚至注入数据包
   - 影响几乎所有WiFi设备

3. **流量分析与解密**
   - 在获取密钥后解密无线流量
   - 分析解密后的流量中的敏感信息
   - 识别明文传输的敏感数据

#### 2.4.3 会话劫持

会话劫持是在攻击者已经能够监听无线流量的基础上，进一步劫持用户的网络会话：

1. **Deauthentication攻击**
   - 发送伪造的解除认证帧，强制客户端断开连接
   - 用于捕获WPA握手、配合其他攻击

2. **Disassociation攻击**
   - 类似于Deauth攻击，但针对关联状态
   - 用于强制客户端重新关联

3. **Man-in-the-Middle（MITM）攻击**
   - Evil Twin + 真实AP组合
   - ARP欺骗
   - DNS欺骗
   - SSL/TLS降级攻击

#### 2.4.4 中间人攻击

中间人攻击是无线渗透测试中非常重要的攻击类型，利用无线信道的广播特性，攻击者可以轻易地插入自己到通信双方之间。

1. **Evil Twin攻击**
   - 搭建与目标AP同名（或相似名）的伪造AP
   - 诱导用户连接到伪造AP
   - 监听和篡改用户的网络流量
   - 窃取用户的认证凭证

2. **KARMA攻击**
   - 响应客户端的所有Probe Request
   - 诱导客户端自动连接到攻击者的AP
   - 利用设备自动连接已知网络的特性

3. **MANA攻击**
   - KARMA攻击的改进版
   - 更智能的SSID管理
   - 支持更复杂的攻击场景

4. **SSL Stripping**
   - 将HTTPS连接降级为HTTP连接
   - 窃取明文传输的敏感信息
   - 工具：`sslstrip`、`bettercap`

**攻击阶段交付物：**
- 漏洞验证报告
- 攻击路径说明
- 证据截图和数据包捕获文件
- 已利用漏洞清单
- 攻击阶段Checklist确认表

### 2.5 第四阶段：后渗透阶段

后渗透阶段是在成功突破无线网络边界后，进一步评估攻击者能够在内网中造成多大危害的阶段。

#### 2.5.1 内网横向移动

1. **网络发现**
   - 内网主机发现（ARP扫描、ICMP扫描）
   - 端口扫描和服务识别
   - 网络拓扑绘制

2. **漏洞利用**
   - 利用未打补丁的系统漏洞
   - 利用弱口令和默认凭证
   - 利用配置错误

3. **凭证窃取**
   - 网络嗅探获取明文凭证
   - 哈希窃取和传递（Pass-the-Hash）
   - 钓鱼获取用户凭证

#### 2.5.2 权限提升

1. **本地权限提升**
   - 利用操作系统内核漏洞
   - 利用服务配置错误
   - 利用计划任务和服务权限

2. **域权限提升**
   - Kerberoasting攻击
   - AS-REP Roasting攻击
   - 利用域控制器漏洞

#### 2.5.3 数据窃取

1. **敏感数据发现**
   - 文件服务器中的敏感文档
   - 数据库中的用户数据
   - 配置文件中的凭证信息

2. **数据外传**
   - 评估数据外传的难度
   - 测试数据防泄漏（DLP）系统的有效性

#### 2.5.4 持久化

1. **账户持久化**
   - 创建隐藏账户
   - 修改现有账户权限

2. **后门持久化**
   - 安装Webshell
   - 安装Rootkit
   - 修改启动项和服务

3. **无线持久化**
   - 在AP中植入后门
   - 安装Rogue AP
   - 修改无线控制器配置

**后渗透阶段注意事项：**
- 严格遵守授权范围，不得越权访问
- 最小化对业务系统的影响
- 详细记录所有操作，便于追溯和清理
- 及时告知客户重大发现

**后渗透阶段交付物：**
- 内网拓扑图
- 权限获取路径图
- 敏感数据访问记录
- 持久化方法验证报告
- 业务影响评估报告

### 2.6 第五阶段：报告与清理阶段

#### 2.6.1 证据整理

1. **证据收集**
   - 整理所有数据包捕获文件
   - 收集漏洞验证的截图
   - 汇总测试日志和记录

2. **证据分类**
   - 按漏洞严重程度分类
   - 按攻击阶段分类
   - 按资产重要性分类

3. **证据保全**
   - 计算文件哈希值
   - 制作证据副本
   - 建立证据链

#### 2.6.2 漏洞报告

详细的漏洞报告应包含：
- 漏洞名称和描述
- 漏洞严重程度评级
- CVSS评分
- 影响范围
- 漏洞验证过程
- 漏洞利用代码（如有）
- 修复建议

#### 2.6.3 安全建议

针对发现的每个漏洞，提供具体可行的修复建议：
- 紧急修复措施
- 长期加固方案
- 最佳实践建议

#### 2.6.4 痕迹清理

测试完成后，需要清理测试过程中留下的痕迹：

1. **系统痕迹清理**
   - 删除测试过程中创建的账户
   - 移除植入的后门和测试工具
   - 清理日志记录
   - 恢复被修改的系统配置

2. **网络痕迹清理**
   - 关闭测试用的AP和设备
   - 清理DHCP租赁记录
   - 恢复网络设备配置

3. **数据清理**
   - 安全删除测试中获取的敏感数据
   - 清理测试设备上的临时文件
   - 确认数据销毁的完整性

**清理验证：**
- 验证所有测试账户已删除
- 验证所有测试工具已移除
- 验证系统配置已恢复
- 客户确认系统正常运行
