# 不同场景的测试策略

不同的无线应用场景具有不同的安全特点和风险模型，需要采用针对性的测试策略。本章详细介绍企业WiFi、IoT设备、蓝牙、Zigbee等典型场景的测试方法和重点。

### 4.1 企业WiFi渗透测试策略

企业WiFi网络是无线渗透测试最常见的场景，通常涉及办公网络、访客网络和BYOD（自带设备）等多个维度。

#### 4.1.1 办公网络测试策略

办公网络是企业的核心无线网络，承载着员工的日常办公流量，安全等级要求最高。

**测试重点：**

1. **认证机制测试**
   - 验证企业级认证（802.1X/EAP）的安全性
   - 测试证书验证机制是否有效
   - 检测弱密码和默认凭证
   - 测试账户锁定机制

2. **加密强度测试**
   - 验证加密算法的安全性（是否仍在使用WEP、TKIP）
   - 测试WPA/WPA2/WPA3的配置是否正确
   - 检测是否存在加密降级的可能

3. **网络隔离测试**
   - 测试无线客户端之间是否隔离
   - 测试无线网络与有线网络的隔离措施
   - 测试不同VLAN之间的访问控制

4. **接入控制测试**
   - 测试MAC地址过滤的有效性
   - 测试NAC（网络访问控制）的旁路可能性
   - 测试未授权设备的检测和阻断能力

**测试方法：**
- Evil Twin + RADIUS中继攻击
- PEAP/MS-CHAPv2破解
- 证书信任验证
- 客户端指纹识别与伪装

#### 4.1.2 访客网络测试策略

访客网络通常用于为来访人员提供互联网接入，安全策略相对宽松，但也存在被利用的风险。

**测试重点：**

1. **隔离有效性测试**
   - 验证访客网络与内部网络的隔离
   - 测试访客能否访问内部资源
   - 测试访客之间的隔离

2. **认证绕过测试**
   - 测试访客认证机制的安全性
   - 测试是否可以绕过认证直接上网
   - 测试会话固定和会话劫持

3. **滥用风险测试**
   - 测试带宽限制是否有效
   - 测试是否可以通过访客网络发起攻击
   - 测试日志记录和审计能力

#### 4.1.3 BYOD测试策略

BYOD（Bring Your Own Device）环境下，员工使用个人设备接入企业网络，带来了独特的安全挑战。

**测试重点：**

1. **设备合规性测试**
   - 测试MDM（移动设备管理）的强制能力
   - 测试不合规设备是否可以接入
   - 测试设备越狱/Root后的接入限制

2. **数据泄露风险测试**
   - 测试敏感数据是否可以被导出
   - 测试剪贴板、文件共享等数据通道
   - 测试网络侧的数据防泄漏能力

3. **应用安全测试**
   - 测试企业移动应用的安全性
   - 测试应用间数据隔离
   - 测试恶意应用的影响范围

**企业WiFi测试Checklist：**
- [ ] 所有办公网络SSID的认证和加密已测试
- [ ] 访客网络隔离已验证
- [ ] BYOD接入控制已测试
- [ ] WIDS/WIPS检测能力已评估
- [ ] Rogue AP检测机制已验证
- [ ] 无线控制器安全配置已审计
- [ ] 无线管理通道安全性已测试
- [ ] 日志审计能力已评估

### 4.2 IoT无线设备测试策略

物联网设备的爆发式增长带来了新的安全挑战。IoT设备通常资源受限、更新困难，安全防护能力较弱。

#### 4.2.1 智能家居设备测试

**测试对象：**
- 智能音箱、智能电视
- 智能门锁、智能摄像头
- 智能灯具、智能插座
- 智能家电（冰箱、洗衣机等）
- 家庭网关和中枢设备

**测试重点：**

1. **设备发现与识别**
   - 扫描网络中的IoT设备
   - 识别设备类型和固件版本
   - 发现开放的服务和端口

2. **认证与授权测试**
   - 测试设备登录密码强度
   - 测试默认凭证
   - 测试API认证机制
   - 测试本地控制和云控制的权限划分

3. **通信安全测试**
   - 测试设备与云端的通信加密
   - 测试本地通信的安全性
   - 测试固件更新的签名验证
   - 测试敏感数据的传输保护

4. **固件安全测试**
   - 提取和分析固件
   - 查找硬编码的凭证和密钥
   - 测试固件更新机制的安全性
   - 识别已知的漏洞

5. **移动App测试**
   - 测试配套App的安全性
   - 测试App与设备的通信
   - 测试本地数据存储安全

#### 4.2.2 工业IoT测试策略

工业IoT（IIoT）设备通常用于工业控制系统，安全问题可能导致严重的物理后果。

**测试对象：**
- 工业无线传感器
- SCADA无线模块
- 工业网关
- 无线PLC
- 远程终端单元（RTU）

**测试重点：**

1. **协议安全测试**
   - Modbus TCP over WiFi
   - MQTT协议安全
   - CoAP协议安全
   - 工业专用无线协议

2. **设备安全测试**
   - 测试设备的认证机制
   - 测试固件安全性
   - 测试物理接口安全
   - 测试默认配置安全性

3. **网络隔离测试**
   - 验证工业网络与办公网络的隔离
   - 测试边界防护措施
   - 测试网络分段有效性

**注意事项：**
- 工业IoT测试需要格外谨慎，避免影响生产
- 优先采用被动侦察和非侵入式测试
- 必须获得明确的书面授权
- 制定详细的应急预案

#### 4.2.3 可穿戴设备测试策略

**测试对象：**
- 智能手表、智能手环
- 健康监测设备
- 智能眼镜
- 运动追踪器

**测试重点：**
- 蓝牙通信安全
- 数据同步安全
- 个人隐私数据保护
- 设备配对机制安全
- 丢失后的安全防护

### 4.3 蓝牙设备测试策略

蓝牙是另一种广泛使用的无线通信技术，包括经典蓝牙（BR/EDR）和低功耗蓝牙（BLE）两种主要类型。

#### 4.3.1 经典蓝牙设备测试

**测试重点：**

1. **设备发现与识别**
   - 扫描可见的蓝牙设备
   - 识别设备类型和版本
   - 检测隐藏设备

2. **配对安全测试**
   - 测试PIN码强度
   - 测试配对机制的安全性
   - 测试旧版配对协议的漏洞（如BlueBorne）

3. **服务枚举与测试**
   - 枚举设备支持的服务和Profile
   - 测试未经授权的服务访问
   - 测试OBEX文件传输

4. **已知漏洞测试**
   - BlueBorne漏洞测试
   - BlueBleeding漏洞测试
   - 其他已知蓝牙漏洞

**经典蓝牙测试工具：**
- `hciconfig`、`hcitool`：蓝牙配置和扫描工具
- `sdptool`：SDP服务枚举
- `obexftp`：OBEX文件传输测试
- `bluesnarfer`：蓝牙信息窃取工具
- `btscanner`：蓝牙设备扫描工具
- Ubertooth One：蓝牙嗅探硬件

#### 4.3.2 BLE设备测试

低功耗蓝牙（BLE）广泛应用于IoT设备、可穿戴设备、信标等场景。

**测试重点：**

1. **设备侦察**
   - 扫描BLE广播包
   - 识别设备名称、厂商、服务UUID
   - 分析广播数据中的敏感信息

2. **连接安全测试**
   - 测试配对机制安全性
   - 测试Just Works配对的风险
   - 测试Passkey配对强度
   - 测试Legacy Pairing vs LE Secure Connections

3. **GATT安全测试**
   - 枚举GATT服务和特征值
   - 测试特征值的读写权限
   - 测试未经认证的访问
   - 测试数据加密保护

4. **重放攻击测试**
   - 捕获和重放BLE通信
   - 测试认证令牌的重放防护
   - 测试固件更新的重放攻击

5. **中间人攻击测试**
   - 测试配对过程中的MITM防护
   - 测试主动和被动MITM攻击

**BLE测试工具：**
- `nRF Connect`：强大的BLE调试工具（移动端）
- `gatttool`：Linux下的GATT工具
- `bluepy`：Python BLE库
- `btlejack`：BLE嗅探和劫持工具
- Ubertooth One + `ubertooth-btle`：BLE数据包捕获

#### 4.3.3 蓝牙信标（Beacon）测试

**测试重点：**
- Beacon信号仿冒
- 基于Beacon的定位欺骗
- Beacon固件安全
- 相关App的安全测试

### 4.4 Zigbee/IoT协议测试策略

Zigbee是一种基于IEEE 802.15.4标准的低功耗无线通信协议，广泛应用于智能家居、工业控制等领域。

#### 4.4.1 Zigbee协议安全基础

Zigbee网络的关键概念：
- **协调器（Coordinator）**：网络的建立者和管理者
- **路由器（Router）**：转发数据，扩展网络范围
- **终端设备（End Device）**：传感器和执行器
- **PAN ID**：网络标识符
- **扩展PAN ID**：64位的唯一网络标识符
- **网络密钥（Network Key）**：网络层加密密钥
- **链路密钥（Link Key）**：设备间的成对密钥

#### 4.4.2 Zigbee测试方法

1. **网络侦察**
   - 扫描2.4GHz频段的Zigbee网络
   - 识别PAN ID、信道、设备类型
   - 分析网络拓扑
   - 工具：`zig-a-zig-ah`、Wireshark + CC2531

2. **加密测试**
   - 检测网络是否启用加密
   - 测试默认密钥（如`ZigBeeAlliance09`）
   - 测试密钥强度
   - 测试密钥分发机制的安全性

3. **设备加入测试**
   - 测试是否允许未授权设备加入
   - 测试加入流程的安全性
   - 测试Touchlink Commissioning的安全性

4. **重放攻击测试**
   - 捕获和重放Zigbee数据包
   - 测试重放防护机制
   - 测试命令帧的重放风险

5. **固件和应用层测试**
   - 分析设备固件
   - 测试应用层协议的安全性
   - 测试OTA更新机制

**Zigbee测试工具：**
- **硬件：**
  - CC2531 USB Dongle（最常用的Zigbee抓包工具）
  - CC2540/CC2652开发板
  - Atmel RZUSBstick
  - ApiMote v4beta
- **软件：**
  - `zig-a-zig-ah`（zzh）：基于CC2652的多功能Zigbee工具
  - `killerbee`：Zigbee渗透测试框架
  - Wireshark：Zigbee协议分析
  - `zbdump`/`zbreplay`：数据包捕获和重放

#### 4.4.3 其他IoT无线协议

1. **Z-Wave**
   - 主要用于智能家居
   - 工作在Sub-GHz频段（中国868MHz）
   - 测试工具：Z-Wave Stick、`open-zwave`

2. **Thread**
   - 基于802.15.4的IPv6 mesh网络
   - 与Zigbee有相似之处也有区别
   - 支持Border Router接入互联网

3. **LoRaWAN**
   - 低功耗广域网（LPWAN）技术
   - 长距离、低速率
   - 安全测试重点：设备认证、数据加密、入网流程

### 4.5 物理接入点测试策略

物理接入点安全测试关注AP本身的物理安全和配置安全，以及Rogue AP和Evil Twin的检测与防护。

#### 4.5.1 Rogue AP检测

Rogue AP（未授权接入点）是企业无线网络的重大安全隐患，员工可能私自接入无线路由器，绕过企业的安全防护。

**Rogue AP的危害：**
- 绕过企业防火墙和入侵检测系统
- 提供未授权的网络访问入口
- 可能配置不当，引入安全漏洞
- 可能被攻击者利用作为内网入口

**检测方法：**

1. **有线侧检测**
   - 在交换机上检测未授权的MAC地址
   - 使用NAC系统检测未授权设备
   - 监控网络中的STP BPDU异常

2. **无线侧检测**
   - 使用WIDS/WIPS系统扫描
   - 定期进行无线勘测
   - 对比授权AP列表

3. **混合检测**
   - 关联有线和无线检测结果
   - 确认Rogue AP的物理位置
   - 评估Rogue AP的安全风险

#### 4.5.2 Evil Twin攻击测试

Evil Twin（邪恶双胞胎）是一种常见的无线攻击手段，攻击者搭建与合法AP同名的伪造AP，诱导用户连接。

**测试目标：**
- 评估用户被诱导连接的风险
- 测试WIDS/WIPS的Evil Twin检测能力
- 测试企业安全意识培训的效果

**测试方法：**

1. **Evil Twin搭建**
   - 使用WiFi Pineapple或其他工具搭建伪造AP
   - 配置与目标AP相同的SSID
   - 设置更强的信号强度

2. **客户端诱捕**
   - 发送Deauth帧踢下合法客户端
   - 等待客户端自动连接到Evil Twin
   - 利用KARMA攻击响应Probe Request

3. **流量劫持**
   - DNS劫持
   - SSL Stripping
   - 凭证窃取

4. **检测验证**
   - 测试企业WIPS是否能检测到Evil Twin
   - 测试检测响应时间
   - 测试自动化阻断能力

#### 4.5.3 AP物理安全测试

**测试内容：**
- AP的物理安装位置是否安全
- 是否容易被物理接触和篡改
- 管理接口的物理安全
- 电源和网络接口的物理防护

### 4.6 无线社会工程测试策略

无线社会工程测试结合无线技术和社会工程学，评估人员因素带来的安全风险。

#### 4.6.1 基于WiFi的社会工程

1. **伪造热点钓鱼**
   - 搭建带有企业标识的免费WiFi
   - 配置Portal页面模拟企业登录
   - 窃取用户的企业账户凭证

2. **WiFi名称诱导**
   - 使用相似的SSID名称
   - 如"Company-Guest" vs "Company-Guest-WiFi"
   - 利用用户的疏忽和习惯

3. **WiFi + 社工组合攻击**
   - 先通过电话社工获取信息
   - 再利用WiFi攻击扩大战果

#### 4.6.2 蓝牙社会工程

1. **Bluejacking**
   - 向蓝牙设备发送匿名消息
   - 测试用户的安全意识
   - 评估攻击的传播效果

2. **Bluesnarfing**
   - 利用蓝牙漏洞窃取设备信息
   - 测试设备的安全配置
   - 评估数据泄露风险

#### 4.6.3 物理门禁无线社工

1. **RFID卡克隆**
   - 使用Proxmark等设备克隆门禁卡
   - 测试物理门禁的安全性
   - 评估卡片防伪能力

2. **NFC攻击**
   - 近距离NFC数据窃取
   - 测试NFC支付安全
   - 测试NFC门禁安全

**无线社工测试注意事项：**
- 必须获得明确的书面授权
- 制定详细的测试方案
- 控制测试范围，避免影响无关人员
- 保护被测试者的隐私
- 测试后进行安全意识培训
