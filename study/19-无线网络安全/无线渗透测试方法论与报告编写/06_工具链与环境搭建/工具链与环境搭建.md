# 工具链与环境搭建

工欲善其事，必先利其器。无线渗透测试对工具和硬件有较高的要求，选择合适的工具链和搭建良好的测试环境是成功开展测试的基础。

### 5.1 无线网卡选型与驱动配置

无线网卡是无线渗透测试最基础也是最关键的硬件设备。不是所有无线网卡都支持渗透测试所需的监听模式和数据包注入功能。

#### 5.1.1 网卡芯片组选择

选择无线网卡的核心是选择合适的芯片组。以下是几种常用的支持渗透测试的芯片组：

| 芯片组 | 厂商 | 2.4G | 5G | 监听模式 | 注入 | 备注 |
|--------|------|------|-----|---------|------|------|
| RTL8188CUS | Realtek | 是 | 否 | 是 | 是 | 廉价，兼容性好 |
| RTL8812AU | Realtek | 是 | 是 | 是 | 是 | 双频，推荐 |
| RTL8814AU | Realtek | 是 | 是 | 是 | 是 | 大功率，远距离 |
| Atheros AR9271 | Qualcomm | 是 | 否 | 是 | 是 | 经典芯片，稳定 |
| Atheros AR9280 | Qualcomm | 是 | 否 | 是 | 是 | PCIe接口 |
| Atheros AR9285 | Qualcomm | 是 | 否 | 是 | 是 | 常见于笔记本 |
| Ralink RT3070 | MediaTek | 是 | 否 | 是 | 是 | 廉价易得 |
| Ralink RT3572 | MediaTek | 是 | 是 | 是 | 是 | 双频选择 |
| MediaTek MT7612U | MediaTek | 是 | 是 | 是 | 是 | 较新的芯片 |
| Broadcom BCM4339 | Broadcom | 是 | 是 | 是 | 部分 | Nexus 5手机 |
| Espressif ESP32 | 乐鑫 | 是 | 否 | 是 | 是 | IoT开发板 |

**推荐网卡：**

1. **Alfa AWUS036ACH**
   - 芯片组：RTL8812AU
   - 频段：2.4GHz + 5GHz双频
   - 接口：USB 3.0
   - 天线：可拆卸SMA接口
   - 特点：功能全面，兼容性好，强烈推荐

2. **Alfa AWUS036NH**
   - 芯片组：Ralink RT3070
   - 频段：2.4GHz
   - 接口：USB 2.0
   - 特点：经典稳定，价格便宜

3. **Panda PAU09**
   - 芯片组：RT3572
   - 频段：2.4GHz + 5GHz双频
   - 特点：驱动支持好，适合新手

4. **TP-Link TL-WN722N v1**
   - 芯片组：Atheros AR9271
   - 频段：2.4GHz
   - 特点：经典渗透测试网卡（注意只有v1版本支持）

#### 5.1.2 驱动安装与配置

不同芯片组的网卡需要安装相应的驱动程序。

**RTL8812AU驱动安装（Kali Linux）：**

```bash
# 方法1：使用apt安装
sudo apt update
sudo apt install realtek-rtl88xxau-dkms

# 方法2：从源码编译
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
make
sudo make install

# 加载驱动
sudo modprobe 8812au
```

**Atheros芯片驱动：**
Atheros网卡通常使用开源的ath9k/ath9k_htc驱动，内核自带，无需额外安装。

```bash
# 确认驱动加载
lsmod | grep ath

# 启用监控模式
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
```

#### 5.1.3 监听模式配置

监听模式（Monitor Mode）是无线渗透测试的基础，允许网卡捕获所有经过的无线数据包。

**使用airmon-ng配置监听模式：**

```bash
# 查看无线网卡状态
sudo airmon-ng

# 检查并停止可能干扰的进程
sudo airmon-ng check kill

# 启用监听模式
sudo airmon-ng start wlan0

# 确认监听模式已启用
sudo iwconfig

# 停止监听模式
sudo airmon-ng stop wlan0mon

# 重启网络管理服务
sudo systemctl start NetworkManager
```

**手动配置监听模式：**

```bash
# 禁用网卡
sudo ip link set wlan0 down

# 设置为监听模式
sudo iw dev wlan0 set type monitor

# 启用网卡
sudo ip link set wlan0 up

# 设置信道
sudo iw dev wlan0 set channel 6
```

#### 5.1.4 数据包注入测试

数据包注入是很多无线攻击的基础，需要确认网卡支持注入功能。

```bash
# 使用aireplay-ng测试注入
sudo aireplay-ng --test wlan0mon

# 测试结果说明
# - 显示"Injection is working!"表示注入正常
# - 显示"Injection doesn't work"表示注入失败
```

### 5.2 Kali Linux无线工具集

Kali Linux是最流行的渗透测试发行版，内置了丰富的无线安全工具。

#### 5.2.1 Aircrack-ng套件

Aircrack-ng是最经典的WiFi安全测试工具套件，包含多个工具：

| 工具 | 功能 |
|------|------|
| `airmon-ng` | 管理网卡的监听模式 |
| `airodump-ng` | 捕获无线数据包，显示AP和客户端信息 |
| `aireplay-ng` | 数据包注入，用于各种攻击 |
| `aircrack-ng` | WEP/WPA密钥破解 |
| `airdecap-ng` | 解密捕获的无线数据包 |
| `airbase-ng` | 创建伪造的AP |
| `aireplay-ng` | 注入攻击工具 |
| `airdecloak-ng` | 移除WDS/WEP cloaking |
| `airolib-ng` | 预计算PMK数据库，加速WPA破解 |
| `besside-ng` | 自动化WPA握手捕获工具 |
| `tkiptun-ng` | TKIP流量注入 |
| `wesside-ng` | 自动化WEP破解工具 |

**常用操作示例：**

```bash
# 扫描周围的无线网络
sudo airodump-ng wlan0mon

# 捕获指定AP的数据包和WPA握手
sudo airodump-ng -c <channel> --bssid <BSSID> -w <output_file> wlan0mon

# 发送Deauth帧强制客户端断开连接
sudo aireplay-ng --deauth 0 -a <BSSID> -c <client_MAC> wlan0mon

# 破解WPA-PSK密码
sudo aircrack-ng -w <wordlist> <capture_file.cap>
```

#### 5.2.2 Wireshark

Wireshark是最强大的网络协议分析工具，支持详细的802.11协议解析。

**无线分析常用过滤表达式：**

```
# 显示管理帧
wlan.fc.type == 0

# 显示控制帧
wlan.fc.type == 1

# 显示数据帧
wlan.fc.type == 2

# 显示Beacon帧
wlan.fc.type_subtype == 0x08

# 显示Probe Request
wlan.fc.type_subtype == 0x04

# 显示Deauth帧
wlan.fc.type_subtype == 0x0c

# 显示WPA握手（EAPOL）
eapol

# 按BSSID过滤
wlan.bssid == AA:BB:CC:DD:EE:FF

# 按SSID过滤
wlan.ssid == "MyWiFi"
```

#### 5.2.3 Kismet

Kismet是一个功能强大的无线网络检测、嗅探和入侵检测系统。

**主要功能：**
- 支持802.11a/b/g/n/ac
- 支持GPS集成，绘制信号地图
- 支持多种数据源（本地网卡、远程捕获等）
- Web UI界面，便于远程访问
- 支持插件扩展

**基本使用：**

```bash
# 安装Kismet
sudo apt install kismet

# 启动Kismet
sudo kismet -c wlan0mon

# 访问Web UI
# 浏览器打开 http://localhost:2501
```

#### 5.2.4 bettercap

bettercap是一个强大的、模块化的、可扩展的中间人攻击框架，支持WiFi、蓝牙、BLE等多种无线攻击。

**主要功能：**
- WiFi扫描和攻击
- 蓝牙/BLE扫描和攻击
- HID攻击
- 网络嗅探和欺骗
- 集成的Web UI

**常用WiFi攻击命令：**

```bash
# 启动bettercap
sudo bettercap -iface wlan0

# 进入WiFi模块
wifi.recon on

# 扫描WiFi网络
wifi.show

# 选择目标AP
wifi.deauth <BSSID>

# 启动Evil Twin
set wifi.ap.ssid "TargetSSID"
set wifi.ap.bssid AA:BB:CC:DD:EE:FF
set wifi.ap.channel 6
wifi.ap on
```

### 5.3 专用硬件设备

除了普通的无线网卡外，一些专用硬件设备可以大大扩展无线渗透测试的能力。

#### 5.3.1 WiFi Pineapple

WiFi Pineapple是Hak5出品的专业无线审计设备，专为无线渗透测试设计。

**主要型号：**
- **WiFi Pineapple Mark VII**：最新款，双频，功能最全面
- **WiFi Pineapple Nano**：便携款，适合隐蔽测试
- **WiFi Pineapple Tetra**：功能齐全，适合实验室和现场测试

**主要功能：**
- Evil Twin攻击
- 客户端追踪
- 凭证窃取
- 流量劫持和篡改
- 模块化扩展（Pineapple Modules）
- Web管理界面

**常用模块：**
- **Module: Site Survey** - 无线勘测
- **Module: Recon** - 侦察扫描
- **Module: Deauth** - 解除认证攻击
- **Module: Captive Portal** - 认证门户钓鱼
- **Module: DNSMasq Spoof** - DNS欺骗
- **Module: TCPDump** - 数据包捕获
- **Module: Evil Portal** - 邪恶门户
- **Module: PineAP** - 高级客户端诱捕

#### 5.3.2 HackRF One

HackRF One是一款开源的软件定义无线电（SDR）平台，可以发送和接收从1MHz到6GHz的无线电信号。

**技术规格：**
- 频率范围：1MHz - 6GHz
- 采样率：最高20Msps
- 分辨率：8位
- 接口：USB 2.0
- 半双工（同一时间只能发送或接收）

**无线安全应用：**
- **Replay攻击**：捕获并重放无线信号
- **信号分析**：分析未知的无线协议
- ** jammer**：无线信号干扰（需注意法律风险）
- **GSM分析**：2G/3G/4G信号分析
- **GPS欺骗**：GPS信号模拟
- **RFID/NFC分析**：支持多种RFID频率

**常用软件：**
- GNU Radio / GNU Radio Companion
- SDR# (SDR Sharp)
- `hackrf_transfer`：命令行收发工具
- `gqrx`：SDR接收和分析软件
- `inspectrum`：信号分析工具
- `rfcat`：无线攻击工具

#### 5.3.3 Ubertooth One

Ubertooth One是一款开源的蓝牙嗅探和实验平台，专门用于蓝牙安全研究。

**技术规格：**
- 支持经典蓝牙和BLE
- 频率范围：2.4GHz ISM频段
- 实时数据包捕获
- 支持Kismet集成
- 开源硬件和软件

**主要功能：**
- BLE数据包捕获和分析
- 经典蓝牙嗅探
- 蓝牙设备发现
- 蓝牙信号强度测量
- 配合Wireshark进行协议分析

**常用命令：**

```bash
# 扫描BLE设备
ubertooth-scan

# 嗅探BLE连接（跟随模式）
ubertooth-btle -f

# 指定接入地址嗅探
ubertooth-btle -t <access_address>

# 输出到PCAP文件
ubertooth-btle -f -w output.pcap

# 经典蓝牙扫描
ubertooth-scan -b
```

#### 5.4.3 靶机环境配置

1. **企业级认证环境**
   ```bash
   # 安装FreeRADIUS
   sudo apt install freeradius freeradius-mysql freeradius-utils
   
   # 添加测试用户
   sudo nano /etc/freeradius/3.0/users
   # testuser Cleartext-Password := "testpass"
   
   # 配置客户端
   sudo nano /etc/freeradius/3.0/clients.conf
   # client 192.168.1.0/24 {
   #     secret = testing123
   #     shortname = local
   # }
   
   # 重启服务
   sudo systemctl restart freeradius
   ```

2. **AP配置**
   - 配置多个SSID，使用不同的加密方式
   - 配置一个WEP加密的SSID（用于练习WEP破解）
   - 配置一个WPA/WPA2 Personal的SSID
   - 配置一个WPA/WPA2 Enterprise的SSID
   - 配置一个启用WPS的SSID
   - 配置一个隐藏SSID

3. **易受攻击的配置**
   - 使用弱密码的WPA PSK
   - 启用WPS且有漏洞的AP
   - 配置错误的企业认证
   - 客户端隔离关闭
   - MAC过滤但可绕过

#### 5.4.4 流量捕获与分析环境

1. **集中式捕获**
   - 使用Kismet或AIRODUMP-NG捕获流量
   - 设置定期自动捕获
   - 保存到数据库便于分析

2. **分布式捕获**
   - 部署多个捕获节点
   - 覆盖不同区域和信道
   - 中央服务器汇总和分析

3. **自动化分析**
   - 编写脚本自动分析捕获的数据包
   - 自动识别新设备和异常行为
   - 生成安全报告

**实验室安全注意事项：**
- 实验室AP使用较低的发射功率，减少信号泄露
- 实验室与生产网络物理隔离
- 明确标识实验室设备，避免混淆
- 定期检查实验室设备状态
- 制定实验室使用规范
