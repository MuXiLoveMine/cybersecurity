# LLM 安全概述

### 1.1 LLM 安全的重要性

大语言模型（Large Language Model，LLM）正在深刻改变我们使用 AI 的方式。从 ChatGPT 到文心一言，从 Claude 到通义千问，LLM 已经被广泛应用于各种场景。然而，随着能力的增强，安全风险也日益凸显。

**为什么 LLM 安全特别重要？**

1. **广泛的应用场景**
   - 客服对话、内容生成、代码编写
   - 教育辅导、医疗咨询、法律问答
   - 企业办公、数据分析、自动化决策
   - 应用越广泛，安全影响越大

2. **强大的生成能力**
   - 可以生成高质量的文本、代码、图像描述
   - 也可以生成有害内容、虚假信息、恶意代码
   - 能力越强，被滥用的风险越大

3. **对话式交互**
   - 自然语言交互降低了使用门槛
   - 也降低了攻击门槛（不需要技术背景）
   - 普通用户也可能无意中触发安全问题

4. **新兴的攻击面**
   - 提示注入、越狱攻击是全新的攻击类型
   - 传统的安全防护方法不完全适用
   - 安全研究和防护技术仍在快速发展中

### 1.3 LLM 安全的独特挑战

| 挑战 | 说明 |
|------|------|
| 语言的复杂性 | 自然语言表达多样，同一种意思有无数种说法 |
| 上下文敏感性 | 攻击效果取决于对话上下文 |
| 能力涌现性 | 模型能力不可预测，新的攻击方式不断出现 |
| 攻防不对等 | 防御方需要防住所有攻击，攻击方只需找到一个漏洞 |
| 安全性与有用性的权衡 | 限制太严影响用户体验，限制太松存在安全风险 |
| 多模态扩展 | 图文多模态模型带来新的攻击面（图像注入等） |
