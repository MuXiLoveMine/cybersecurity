# 模型窃取（Model Stealing）

### 5.1 什么是模型窃取

**模型窃取（Model Stealing / Model Extraction）** 是指攻击者通过查询模型 API，重建一个与目标模型功能相似的替代模型，从而窃取模型的知识产权。

**攻击动机：**
- 节省训练成本（大模型训练成本极高）
- 获取商业机密（模型是核心资产）
- 为进一步攻击做准备（白盒攻击比黑盒攻击更容易）

### 5.2 模型窃取方法

#### 5.2.1 基于决策的窃取

攻击者只能获取模型的最终决策（分类标签）。

**方法**：
- 选择或生成一组输入数据
- 查询模型获取标签
- 用这些 (输入, 标签) 对训练替代模型

**挑战**：
- 信息有限，只能获取标签
- 需要更多的查询次数

#### 5.2.2 基于分数的窃取

攻击者可以获取模型输出的概率/置信度分数。

**方法**：
- 类似基于决策的窃取，但信息更多
- 可以用概率分布作为训练目标
- 收敛更快，需要的查询更少

#### 5.2.3 基于梯度的窃取

如果模型返回梯度信息（如某些 MLaaS 平台），窃取效率更高。

**方法**：
- 利用梯度信息直接拟合模型参数
- 查询效率极高

#### 5.2.4 主动学习窃取

**核心思想**：不随机选择查询数据，而是主动选择"最有价值"的数据点进行查询。

**常见策略**：
- 不确定性采样：选择模型最不确定的样本
- 多样性采样：选择分布广泛的样本
- 基于迁移的采样：利用先验知识选择样本

### 5.3 LLM 模型窃取

#### 5.3.1 LLM 窃取的挑战

- **输出空间巨大**：词汇表通常有几万到几十万 Token
- **序列生成**：输出是变长序列，不是单一标签
- **模型规模大**：参数太多，完全复制几乎不可能
- **成本考虑**：查询大模型 API 的费用可能很高

#### 5.3.2 LLM 窃取策略

1. **指令微调窃取**
   - 查询目标模型获取指令-回答对
   - 用这些数据微调一个开源小模型
   - 不需要完全复制参数，只需要模仿能力

2. **蒸馏窃取**
   - 用目标模型的输出概率分布训练学生模型
   - 即知识蒸馏

3. **能力对齐窃取**
   - 针对特定能力进行窃取（如代码生成、推理能力）
   - 不需要复制整个模型

### 5.4 模型窃取的防御

#### 5.4.1 技术防御

1. **输出扰动**
   - 在输出概率中添加噪声
   - 只返回 Top-K 结果，不返回完整概率分布

2. **API 限制**
   - 速率限制：限制单位时间的查询次数
   - 查询总量限制
   - 异常检测：识别可疑的查询模式

3. **水印（Watermarking）**
   - 在模型输出中嵌入水印
   - 如果被盗模型也输出相同的水印，可以证明窃取

4. **模型混淆**
   - 有意降低输出精度
   - 增加输出的不确定性

#### 5.4.2 法律防御

- 专利保护
- 著作权保护
- 商业秘密保护
- 用户协议（禁止逆向工程）
