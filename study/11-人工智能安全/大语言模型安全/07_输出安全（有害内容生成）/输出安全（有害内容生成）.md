# 输出安全（有害内容生成）

### 7.1 有害内容类型

#### 7.1.1 违法违规内容

| 类别 | 示例 |
|------|------|
| 暴力内容 | 教人打架、制造武器、恐怖主义 |
| 色情内容 | 生成色情文本、性描写 |
| 毒品内容 | 教人制作和使用毒品 |
| 非法活动 | 黑客攻击、诈骗、伪造证件 |
| 仇恨言论 | 种族歧视、性别歧视、宗教仇恨 |

#### 7.1.2 虚假信息

1. **事实幻觉（Factual Hallucination）**
   - 编造不存在的事实
   - 伪造引用来源
   - 一本正经地胡说八道

2. **误导性信息**
   - 真假参半的信息
   - 选择性呈现事实
   - 断章取义

3. **深度伪造文本**
   - 冒充他人写作
   - 伪造新闻报道
   - 生成虚假证据

#### 7.1.3 偏见与歧视

**常见偏见类型：**
- **性别偏见**：默认某些职业是男性/女性
- **种族偏见**：对某些种族的刻板印象
- **地域偏见**：对某些地区的偏见
- **年龄偏见**：对老年人/年轻人的歧视
- **职业偏见**：对某些职业的刻板印象

**案例**：某招聘 AI 对女性简历打分更低；某贷款 AI 对某些地区的用户审批率更低。

#### 7.1.4 心理健康相关风险

- **自残/自杀内容**：引导或鼓励自残、自杀
- **饮食失调**：鼓励不健康的减肥方式
- **其他心理危害**：引发焦虑、抑郁等

### 7.2 幻觉问题（Hallucination）

#### 7.2.1 什么是幻觉

**幻觉（Hallucination）** 是指大语言模型生成的内容听起来很合理，但实际上是虚假的、错误的或不存在的。

**幻觉的特点：**
- 模型"编造"信息，但表现得很自信
- 用户难以辨别真假
- 在需要事实准确性的场景中危害很大

#### 7.2.2 幻觉的类型

1. **事实性幻觉**
   - 编造不存在的事实
   - 示例：生成不存在的论文引用、编造历史事件

2. **忠实性幻觉**
   - 生成内容与输入不一致
   - 示例：总结文章时添加文章中没有的内容

3. **逻辑性幻觉**
   - 推理过程中出现逻辑错误
   - 数学计算错误、因果关系混乱

#### 7.2.3 幻觉产生的原因

1. **训练数据的问题**
   - 训练数据中本身就有错误信息
   - 训练数据不完整或过时

2. **模型机制的问题**
   - 语言模型是概率模型，目标是生成"合理"的文本，不一定是"正确"的文本
   - 模型不知道自己"不知道"什么
   - 知识截止日期限制

3. **解码策略的问题**
   - 贪心解码可能导致错误累积
   - 采样生成的随机性可能引入错误

#### 7.2.4 缓解幻觉的方法

1. **检索增强生成（RAG）**
   - 基于真实的知识库生成回答
   - 附上引用来源
   - 目前最有效的方法之一

2. **思维链（CoT）与自我验证**
   - 让模型逐步推理
   - 让模型自己检查答案的正确性

3. **事实核查**
   - 生成后自动核查事实
   - 对接搜索引擎或数据库验证

4. **提示工程**
   - 让模型在不确定时说"不知道"
   - 要求模型提供信息来源

5. **后训练对齐**
   - RLHF 中加入事实准确性奖励
   - 事实性微调
