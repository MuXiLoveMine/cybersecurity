# AI 供应链安全概述

### 1.1 AI 开发流程与攻击面

AI 模型的开发经历数据采集、数据预处理、模型训练、模型评估、模型部署等阶段，每个阶段都可能成为攻击目标。

```text
+----------------------------------------------------------+
|                    AI 开发流程                            |
+----------------------------------------------------------+
| 1. 数据采集（爬虫 / 公开数据集 / 用户数据 / 第三方采购）  |
| 2. 数据标注（自标注 / 外包标注 / 自动标注）               |
| 3. 数据预处理（清洗 / 增强 / 特征工程）                  |
| 4. 模型训练（从头训练 / 迁移学习 / 微调）                 |
| 5. 模型评估（测试集 / 线上 A/B 测试）                     |
| 6. 模型部署（API 服务 / 边缘部署 / 联邦部署）             |
| 7. 持续运维（在线学习 / 定期重训练）                     |
+----------------------------------------------------------+
```

**各阶段攻击面：**

| 阶段 | 攻击面 | 典型威胁 |
|------|--------|----------|
| 数据采集 | 数据源可信度 | 数据投毒、数据污染 |
| 数据标注 | 标注者可信度 | 标签翻转、恶意标注 |
| 模型训练 | 预训练模型/训练框架 | 后门注入、恶意代码 |
| 模型部署 | 推理服务 | 模型窃取、对抗攻击 |
| 持续运维 | 在线更新 | 在线投毒、模型漂移 |

### 1.2 数据层 / 模型层 / 框架层风险

**数据层风险：**
- 训练数据被篡改（标签翻转、特征操纵）
- 数据源被污染（爬虫抓取恶意数据）
- 标注过程被操控（外包标注团队恶意标注）

**模型层风险：**
- 预训练模型植入后门（Hugging Face / PyTorch Hub）
- 模型权重被篡改（微调过程中注入触发器）
- 模型文件携带恶意代码（Pickle 反序列化攻击）

**框架层风险：**
- 训练框架漏洞（PyTorch / TensorFlow CVE）
- 依赖库供应链攻击（恶意 PyPI 包）
- 推理框架风险（vLLM / TGI 漏洞）
