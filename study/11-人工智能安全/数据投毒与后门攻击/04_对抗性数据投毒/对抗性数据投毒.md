# 对抗性数据投毒

### 4.1 在线学习投毒

在线学习（Online Learning）模型持续从新数据中学习并更新参数，攻击者可以在数据流中注入投毒样本。

```text
在线学习流程:
1. 接收新样本 (x_t, y_t)
2. 模型更新: θ_{t+1} = θ_t - η ∇L(f(x_t; θ_t), y_t)
3. 投毒: 攻击者注入 (x_poison, y_poison)

攻击策略:
- 渐进式投毒: 每轮注入小幅扰动，累积效应
- 自适应投毒: 根据当前模型状态调整投毒策略
- 反馈驱动投毒: 利用模型输出反馈优化投毒样本
```

**关键挑战：**
- 投毒样本需要通过实时检测
- 单轮投毒影响有限，需要持续攻击
- 模型更新可能导致投毒效果衰减

### 4.2 联邦学习投毒

联邦学习中多个客户端分别训练本地模型并上传梯度/参数到中心服务器聚合。恶意客户端可以发送恶意更新来投毒全局模型。

```text
联邦学习流程:
1. 中心服务器分发全局模型 w_global
2. 各客户端在本地数据上训练: w_local = w_global - η∇L_local
3. 中心服务器聚合: w_global = Σ(n_k/n) * w_k
4. 恶意客户端上传: w_malicious = w_global + δ_attack
```

**联邦学习投毒类型：**

| 类型 | 说明 | 防御 |
|------|------|------|
| 数据投毒 | 恶意客户端本地数据含后门 | 数据验证 |
| 模型替换攻击 | 上传大幅偏离的梯度覆盖全局模型 | 范数裁剪 |
| 定向后门投毒 | 嵌入触发器到本地训练 | 异常检测 |
| 自由骑士攻击 | 不训练直接上传全局模型 | 贡献度评估 |

**常见防御：**
- **Krum 算法**：选择与其他更新距离最小的客户端聚合
- **中位数聚合**：取各客户端参数的中位数而非均值
- **范数裁剪**：限制每个客户端更新的范数大小
- **差分隐私**：在聚合梯度中注入噪声
