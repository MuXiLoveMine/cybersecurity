# 对抗样本攻击与防御

> 本文档详细介绍对抗样本攻击与防御技术，包括白盒攻击、黑盒攻击、物理世界攻击、防御方法、对抗训练以及检测与评估。

---

## 一、对抗样本概念与原理

### 1.1 什么是对抗样本

**对抗样本（Adversarial Example）** 是指在原始样本上添加精心设计的微小扰动，使得机器学习模型产生错误输出，而这些扰动对人类来说几乎不可察觉。

**核心特征：**
1. **微小扰动**：扰动幅度很小，人眼/人耳难以察觉
2. **针对性强**：能够导致模型产生特定的错误输出
3. **迁移性**：一个模型的对抗样本可能对其他模型也有效
4. **泛化性**：同一攻击方法适用于多种模型架构

**直观示例：**
```
原始图片（熊猫） + 微小扰动 = 对抗样本（看起来还是熊猫，但模型识别为长臂猿）

置信度: 57.7% 熊猫  →  99.3% 长臂猿
```

### 1.2 对抗样本的数学表示

**形式化定义：**

给定一个分类器模型 `f(x) = y`，其中：
- `x` 是原始输入样本
- `y` 是正确的分类标签

寻找一个对抗样本 `x'`，满足：
```
f(x') ≠ y （或 f(x') = y_target 针对目标攻击）
且 ||x' - x|| ≤ ε （扰动约束）
```

其中 `||·||` 是范数（通常是 L∞、L2 或 L0 范数），`ε` 是最大允许扰动幅度。

**范数约束类型：**

| 范数类型 | 公式 | 含义 | 特点 |
|---------|------|------|------|
| L0 范数 | ||δ||₀ = count(δᵢ ≠ 0) | 非零元素的个数 | 修改最少的像素 |
| L2 范数 | ||δ||₂ = √(Σδᵢ²) | 欧几里得距离 | 扰动的总能量限制 |
| L∞ 范数 | ||δ||∞ = max(|δᵢ|) | 最大绝对扰动 | 每个像素的变化不超过 ε |

**攻击类型分类：**

| 类型 | 目标 | 说明 |
|------|------|------|
| 非目标攻击（Untargeted） | 只要分类错误即可 | 最简单的攻击形式 |
| 目标攻击（Targeted） | 分类到指定类别 | 更难，需要更多优化 |

### 1.3 对抗样本存在的原因

#### 1.3.1 线性视角解释

**核心观点**：高维空间中的线性行为导致了对抗样本的存在。

在高维空间中，即使每个维度的扰动很小，累积起来也会产生显著影响：

```
w^T * x' = w^T * (x + δ) = w^T * x + w^T * δ

当维度 n 很大时，即使每个 δᵢ 很小，w^T * δ = Σwᵢδᵢ 也可能很大
```

对于 ReLU 激活函数的神经网络，在局部区域内近似线性，这解释了为什么对抗样本容易生成。

#### 1.3.2 流形视角解释

**核心观点**：模型的决策边界在数据流形之外的区域是脆弱的。

- 训练数据分布在一个低维流形（Manifold）上
- 模型在训练数据附近表现良好
- 但在流形之外的区域，决策边界可能非常"扭曲"
- 对抗样本就在流形附近但跨越了决策边界

#### 1.3.3 其他解释理论

1. **过拟合假说**：模型过拟合训练数据，缺乏泛化能力
2. **不充分正则化**：模型太容易被小扰动影响
3. **非线性特性**：深度网络的非线性导致了脆弱性
4. **梯度掩码**：某些防御只是隐藏了梯度，并未真正增强鲁棒性

## 二、白盒攻击（White-box Attacks）

**白盒攻击**：攻击者完全了解目标模型的内部结构，包括：
- 模型架构
- 权重参数
- 梯度信息
- 训练数据分布（可能）

白盒攻击是最强的攻击假设，攻击效果通常最好。

---

### 2.1 FGSM（Fast Gradient Sign Method）

#### 2.1.1 基本原理

**提出者**：Ian Goodfellow 等（2015）

**核心思想**：沿着损失函数梯度上升的方向，一步添加最大的扰动，使损失最大化。

**数学公式：**

```
x' = x + ε * sign(∇_x J(x, y_true))
```

其中：
- `x` 是原始输入
- `ε` 是扰动幅度（越大攻击性越强，但越容易被察觉）
- `sign(·)` 是符号函数（正数取 1，负数取 -1，零取 0）
- `∇_x J(x, y_true)` 是损失函数对输入的梯度
- `J(·)` 是损失函数（通常是交叉熵损失）

**直观理解：**
- 计算损失函数对每个像素的梯度
- 对梯度取符号（只关心方向，不关心大小）
- 乘以 ε，一步到位地添加扰动

#### 2.1.2 算法步骤

```
输入：原始样本 x，真实标签 y，模型 f，损失函数 J，扰动幅度 ε
输出：对抗样本 x'

1. 计算损失函数对输入的梯度：
   g = ∇_x J(f(x), y)

2. 生成对抗样本：
   x' = x + ε * sign(g)

3. 裁剪到合法范围（如图像的 [0, 1]）：
   x' = clip(x', 0, 1)

返回 x'
```

#### 2.1.3 特点与优缺点

**优点：**
- 计算速度极快（一次前向+反向传播）
- 实现简单
- 是很多其他攻击方法的基础

**缺点：**
- 攻击强度有限，可能无法达到 100% 攻击成功率
- 只考虑梯度方向，不考虑梯度大小
- 一步到位，不是最优扰动

**适用场景：**
- 快速生成大规模对抗样本
- 对抗训练（用于生成训练数据）
- 作为基线攻击方法

#### 2.1.4 目标攻击版本

目标攻击的 FGSM 变体，使模型分类到指定目标类别：

```
x' = x - ε * sign(∇_x J(x, y_target))
```

沿着梯度下降的方向（最小化目标类别的损失），使模型将样本分类为目标类别。

---

### 2.2 BIM / PGD（迭代方法）

#### 2.2.1 BIM（Basic Iterative Method）

**核心思想**：FGSM 的迭代版本，每次走一小步，迭代多次，效果更好。

**数学公式：**

```
x₀' = x
x_{t+1}' = clip_ε(x_t' + α * sign(∇_x J(x_t', y_true)))
```

其中：
- `α` 是每一步的步长（通常 α < ε）
- `clip_ε` 表示将扰动裁剪到 [-ε, ε] 范围内
- 迭代次数通常为 10-100 次

**与 FGSM 的关系：**
- 当迭代次数为 1 且 α = ε 时，BIM 退化为 FGSM
- BIM 通常比 FGSM 攻击效果好得多

#### 2.2.2 PGD（Projected Gradient Descent）

**核心思想**：BIM 的增强版本，加入了随机初始化，是最常用的强白盒攻击方法之一。

**改进点：**
1. **随机初始化**：在 ε-ball 内随机采样初始点，避免陷入局部最优
2. **迭代优化**：与 BIM 类似的迭代过程
3. **投影操作**：每步后投影回 ε-ball 内

**算法步骤：**

```
输入：原始样本 x，真实标签 y，模型 f，损失函数 J，扰动幅度 ε，步长 α，迭代次数 T
输出：对抗样本 x'

1. 随机初始化：
   x₀' = x + δ，其中 δ ~ Uniform(-ε, ε)
   x₀' = clip(x₀', 0, 1)

2. 迭代优化（重复 T 次）：
   对于 t = 0 到 T-1：
       g = ∇_x J(f(x_t'), y)
       x_{t+1}' = x_t' + α * sign(g)
       x_{t+1}' = clip(x_{t+1}', x - ε, x + ε)  // 投影到 ε-ball
       x_{t+1}' = clip(x_{t+1}', 0, 1)        // 裁剪到合法范围

3. 返回 x_T'
```

**目标攻击版本：**
```
x_{t+1}' = x_t' - α * sign(∇_x J(x_t', y_target))
```

#### 2.2.3 PGD 的重要性

- **强攻击基线**：被广泛用作评估模型鲁棒性的标准攻击方法
- **对抗训练**：PGD 对抗训练是最经典的对抗训练方法
- **一阶攻击的上限**：在只使用一阶梯度信息的攻击中，PGD 接近最优

**参数选择经验：**
- **ε**：根据任务确定，图像分类常用 8/255 ≈ 0.031
- **α**：通常取 ε/10 ~ ε/4
- **迭代次数 T**：通常 10-100 次，次数越多效果越好但计算越慢

### 2.3 DeepFool

#### 2.3.1 基本原理

**提出者**：Moosavi-Dezfooli 等（2016）

**核心思想**：通过迭代地将样本向最近的决策边界移动，找到最小的扰动。

**特点：**
- 生成的扰动更小（L2 范数最小化）
- 迭代次数通常较少（10 次左右即可收敛）
- 基于几何直觉：找到样本到决策边界的最短距离

#### 2.3.2 算法思想

对于二分类问题，决策边界是 `f(x) = 0`：
- 样本点 x 到决策边界的距离为 `|f(x)| / ||∇f(x)||₂`
- 最小扰动方向是梯度方向的反方向

对于多分类问题：
- 计算样本到每个类别的决策边界的距离
- 选择最近的边界移动
- 迭代直到分类改变

```
算法步骤（简化版）：
1. 对于当前样本 x，计算每个类别的输出 f_k(x) 和梯度 ∇f_k(x)
2. 计算到每个类别的决策边界的近似距离
3. 选择最近的类别 k*，计算需要的最小扰动
4. 更新 x = x + δ
5. 重复直到分类改变或达到最大迭代次数
```

#### 2.3.3 特点

**优点：**
- 生成的扰动通常比 FGSM/BIM 更小
- 收敛速度快
- 基于几何直观，解释性强

**缺点：**
- 计算比 FGSM 复杂
- 主要是 L2 范数下的攻击
- 可能陷入局部最优

---

### 2.4 C&W 攻击（Carlini & Wagner）

#### 2.4.1 基本原理

**提出者**：Nicholas Carlini 和 David Wagner（2017）

**核心思想**：将对抗样本生成问题转化为优化问题，使用更复杂的优化方法找到最小扰动。

**地位**：被认为是最强的白盒攻击之一，经常用来"破解"各种防御方法。

#### 2.4.2 优化公式

**目标函数（L2 范数版本）：**

```
最小化：||δ||₂² + c * f(x + δ)

约束：x + δ ∈ [0, 1]^n
```

其中 `f(·)` 是目标函数，定义为：

```
非目标攻击：
f(x') = max(max_{i≠y} Z(x')_i - Z(x')_y, -κ)

目标攻击：
f(x') = max(Z(x')_t - max_{i≠t} Z(x')_i, -κ)
```

- `Z(x')` 是模型的 logits 输出（softmax 之前的值）
- `y` 是真实标签，`t` 是目标标签
- `κ` 是置信度参数，控制对抗样本的置信度
- `c` 是平衡扰动大小和攻击成功的权重参数

#### 2.4.3 优化技巧

1. **变量替换**：
   - 将 `x'` 表示为 `(tanh(w) + 1) / 2`，确保输出在 [0, 1] 范围内
   - 这样优化 w 而不是 x'，避免约束优化

2. **Adam 优化器**：
   - 使用 Adam 而不是简单的梯度下降
   - 收敛更快，效果更好

3. **二分搜索 c**：
   - c 控制扰动大小和攻击成功的权衡
   - 用二分搜索找到合适的 c 值

#### 2.4.4 特点

**优点：**
- 攻击能力极强，是目前最强的攻击之一
- 可以生成非常小的扰动
- 支持 L0、L2、L∞ 多种范数
- 可以控制攻击的置信度

**缺点：**
- 计算量大，速度慢
- 实现复杂
- 需要调整多个超参数

**重要意义：**
- 很多声称"鲁棒"的防御方法都被 C&W 攻击攻破
- 是评估防御方法有效性的重要基准
- 推动了对抗防御研究的发展

### 2.5 其他白盒攻击方法

#### 2.5.1 JSMA（Jacobian-based Saliency Map Attack）

**特点：**
- 基于雅可比矩阵的显著性图攻击
- 主要针对 L0 范数（修改最少的特征）
- 常用于图像和文本分类

**原理：**
- 计算输出对输入的雅可比矩阵
- 构建显著性图，找出对输出影响最大的输入特征
- 迭代修改最重要的特征

#### 2.5.2 动量迭代攻击（Momentum Iterative FGSM）

**特点：**
- 在 BIM 的基础上加入动量
- 提高了对抗样本的迁移性
- 常用于黑盒迁移攻击

**核心改进：**
```
g_{t+1} = μ * g_t + ∇_x J(x_t', y) / ||∇_x J(x_t', y)||₁
x_{t+1}' = x_t' + ε * sign(g_{t+1})
```

其中 `μ` 是动量系数。

#### 2.5.3 AutoAttack

**特点：**
- 不是单一攻击，而是多种攻击的组合
- 自动调整参数
- 是目前评估鲁棒性的标准基准之一

**组成：**
- APGD-CE（自适应 PGD + 交叉熵损失）
- APGD-DLR（自适应 PGD + DLR 损失）
- FAB（快速自适应边界攻击）
- 方形攻击（Square Attack）

## 三、黑盒攻击（Black-box Attacks）

**黑盒攻击**：攻击者只能查询模型的输入输出，不知道模型的内部结构和参数。

更接近真实世界的攻击场景，因为大多数 AI 服务只提供 API 接口。

**黑盒攻击分类：**

| 类型 | 攻击者能获取的信息 | 难度 |
|------|-------------------|------|
| 分数黑盒（Score-based） | 各类别的置信度/概率 | 中等 |
| 决策黑盒（Decision-based） | 只有最终分类结果 | 困难 |
| 迁移攻击（Transfer-based） | 完全不查询目标模型 | 较易 |

---

### 3.1 基于迁移的攻击（Transfer-based Attacks）

#### 3.1.1 基本原理

**核心思想**：对抗样本具有迁移性（Transferability），即针对一个模型生成的对抗样本，对另一个不同架构甚至不同训练数据的模型也可能有效。

**攻击流程：**

```
1. 收集与目标模型相似领域的训练数据
2. 训练一个"替代模型"（Substitute Model）
3. 使用白盒攻击方法在替代模型上生成对抗样本
4. 将对抗样本用于攻击目标模型
```

#### 3.1.2 迁移性原理

**为什么对抗样本可以迁移？**

1. **相似的数据分布**：如果模型在相似的数据上训练，学到的特征也相似
2. **决策边界的相似性**：不同模型可能在某些区域具有相似的决策边界
3. **线性近似**：在局部区域，不同模型的行为可能都近似线性
4. **特征空间的相似性**：相似的任务会学到相似的特征表示

#### 3.1.3 提高迁移性的方法

1. **集成攻击**：同时对多个模型生成对抗样本，迁移性更好
2. **动量迭代**：如 MI-FGSM，加入动量可以提高迁移性
3. **输入多样性**：对输入进行随机变换后再生成对抗样本
4. **中间层攻击**：攻击中间层特征而不是最终输出

**集成攻击公式：**
```
g = ∑_i w_i * ∇_x J_i(x, y)
x' = x + ε * sign(g)
```

其中 `J_i` 是第 i 个模型的损失，`w_i` 是权重。

#### 3.1.4 实际案例

**案例**：攻击者想要攻击某公司的图像识别 API（只能获取分类结果）。

1. 收集该领域的公开数据集
2. 训练一个自己的 CNN 模型作为替代模型
3. 用 FGSM/PGD 在替代模型上生成对抗样本
4. 将这些对抗样本提交给目标 API
5. 约 60-80% 的对抗样本也能攻击成功

---

### 3.2 基于查询的攻击（Query-based Attacks）

#### 3.2.1 分数攻击（Score-based）

攻击者可以获取模型输出的各类别概率/置信度。

**代表性方法：**

1. **ZOO（Zeroth Order Optimization）**
   - 使用零阶优化方法估计梯度
   - 通过查询两个接近的点来估计梯度：`∂f/∂x_i ≈ (f(x + he_i) - f(x - he_i)) / (2h)`
   - 然后用估计的梯度进行类似 PGD 的攻击
   - 查询复杂度：O(n) 每步，n 是输入维度

2. **NES（Natural Evolution Strategies）**
   - 使用进化策略估计梯度
   - 采样多个随机方向，根据函数值加权估计梯度
   - 查询复杂度：O(k) 每步，k 是采样数（通常远小于 n）

#### 3.2.2 决策攻击（Decision-based）

攻击者只能获取模型的最终决策（分类结果），无法获取概率分数。这是最困难的黑盒攻击场景。

**代表性方法：**

**HopSkipJumpAttack（HSJA）**

**核心思想**：从决策边界附近的点出发，沿着边界移动，逐渐接近原始样本。

**算法步骤：**

```
1. 初始化：找到一个初始的对抗样本（可以是随机生成的）
2. 边界搜索：在原始样本和对抗样本之间，找到决策边界上的点
3. 边界移动：沿着决策边界移动，寻找更接近原始样本的对抗点
4. 迭代优化：重复边界搜索和移动
```

**特点：**
- 不需要梯度信息
- 只需要分类结果
- 查询效率较高
- 可以生成 L2 和 L∞ 约束下的对抗样本

**Boundary Attack**

- 类似 HSJA 的早期方法
- 从一个大扰动的对抗样本开始，逐渐减小扰动
- 每步随机采样方向，如果仍然是对抗样本就接受

### 3.3 文本领域的黑盒攻击

文本领域的对抗样本与图像领域有很大不同：
- 文本是离散的，不能直接添加连续扰动
- 替换一个词可能改变语义
- 需要保证语法正确性和语义连贯性

**常见方法：**

1. **同义词替换**
   - 将句子中的词替换为同义词
   - 保持语义不变但改变模型输出

2. **字符级扰动**
   - 插入/删除/替换字符
   - 类似于拼写错误
   - 例如："hello" → "he1lo"

3. **句子重写**
   - 用不同的方式表达相同的意思
   - 基于释义（Paraphrase）的攻击

## 四、物理世界对抗攻击

### 4.1 物理世界攻击概述

**定义**：在真实物理环境中，通过对物理对象进行修改，使得 AI 系统（如摄像头、传感器）采集的数据成为对抗样本。

**与数字世界攻击的区别：**

| 维度 | 数字世界攻击 | 物理世界攻击 |
|------|-------------|-------------|
| 扰动形式 | 像素级精确控制 | 物理对象修改（贴纸、涂料等） |
| 环境因素 | 完全可控 | 光照、角度、距离、遮挡等 |
| 扰动约束 | 像素值约束 | 物理可实现性约束 |
| 评估难度 | 简单（直接计算准确率） | 困难（需要真实实验） |
| 实际威胁 | 理论/实验层面 | 直接现实威胁 |

### 4.2 典型物理攻击场景

#### 4.2.1 交通标志攻击

**目标**：让自动驾驶汽车的交通标志识别系统错误识别交通标志。

**攻击方式：**
- 在停止标志上贴黑白贴纸 → 识别为限速标志
- 在限速标志上贴特定图案 → 识别为其他标志

**著名研究**：
- 2016 年，研究人员展示了贴纸可以欺骗交通标志识别
- 2017 年，进一步展示了在物理世界中从不同角度和距离都有效的攻击
- 2018 年，研究了更鲁棒的物理对抗扰动

**防御挑战：**
- 需要从各个角度、距离、光照条件下都正确识别
- 真实驾驶场景变化多端

#### 4.2.2 人脸识别攻击

**目标**：绕过人脸识别系统（认证或识别）。

**攻击方式：**

1. **对抗性眼镜/面具**
   - 佩戴带有特定图案的眼镜
   - 可以伪装成特定的人（目标攻击）
   - 或者不被识别为任何人（逃避攻击）

2. **对抗性贴纸**
   - 在脸上贴特定图案的贴纸
   - 破坏人脸识别系统的特征提取

3. **红外攻击**
   - 利用红外摄像头的特性
   - 投射红外图案干扰人脸识别

**案例**：2020 年，研究人员展示了通过佩戴 3D 打印的眼镜框，可以成功绕过多种人脸识别系统，伪装成其他人。

#### 4.2.3 自动驾驶攻击

**目标**：干扰自动驾驶汽车的感知和决策系统。

**攻击方式：**

1. **道路标记攻击**
   - 在路面上绘制特定图案
   - 干扰车道线检测，导致车辆偏离车道

2. **障碍物欺骗**
   - 投影虚假的障碍物
   - 导致车辆急刹车或绕行

3. **激光雷达欺骗**
   - 发射激光干扰激光雷达
   - 制造虚假障碍物或隐藏真实障碍物

#### 4.2.4 安防监控攻击

**目标**：绕过安防监控系统的检测和识别。

**攻击方式：**
- 穿着特定图案的衣服，躲避行人检测
- 对抗性补丁让人不被检测为"人"
- 干扰行为识别系统

---

### 4.3 物理攻击的技术挑战

#### 4.3.1 环境变化的鲁棒性

物理世界中，以下因素会影响攻击效果：
- **视角变化**：拍摄角度不同
- **距离变化**：目标物体远近不同
- **光照变化**：光线明暗、阴影
- **遮挡**：部分被遮挡
- **相机参数**：焦距、曝光、白平衡
- **运动模糊**：目标移动时

**解决方案：**
- 在训练/生成对抗扰动时，加入数据增强（模拟各种变换）
- 优化目标考虑多种视角和条件
- 使用期望变换（EOT，Expectation over Transformation）

**EOT 方法：**
```
目标：最小化 E_{t~T}[J(f(t(x')), y)]
其中 t(·) 是随机变换（旋转、缩放、光照变化等）
```

对各种变换的期望进行优化，使对抗样本在各种条件下都有效。

#### 4.3.2 物理可实现性

- 扰动必须是可以物理制作的
- 不能有无法打印的颜色
- 不能有超出物理限制的图案
- 需要考虑材质、反光等因素

## 五、对抗样本防御方法

### 5.1 防御方法分类

**按防御阶段分类：**

| 类别 | 方法 | 说明 |
|------|------|------|
| 输入预处理 | 图像去噪、压缩、变换 | 在输入模型前处理样本 |
| 模型修改 | 对抗训练、防御蒸馏、梯度掩码 | 修改模型本身提高鲁棒性 |
| 检测方法 | 对抗样本检测器 | 先检测再拒绝/处理 |
| 外部防御 | 多模型集成、随机化 | 附加的防御机制 |

**按防御思路分类：**
- **鲁棒化**：让模型本身对对抗样本不敏感
- **检测**：识别出对抗样本并拒绝
- **净化**：去除输入中的对抗扰动
- **混淆**：让攻击者难以找到有效的攻击方向

---

### 5.2 输入预处理防御

#### 5.2.1 图像压缩/去噪

**原理**：对抗扰动通常是高频噪声，通过压缩或去噪可以去除部分扰动。

**方法：**
- JPEG 压缩
- 高斯滤波
- 中值滤波
- 双边滤波
- 基于深度学习的去噪（如 DnCNN）

**优点：**
- 实现简单
- 不改变模型
- 计算效率高

**缺点：**
- 防御能力有限，强攻击（如 C&W）可以绕过
- 可能降低正常样本的分类准确率
- 只是"弱化"攻击而不是真正防御

#### 5.2.2 特征压缩（Feature Squeezing）

**原理**：通过减少输入特征的表达空间，降低对抗样本存在的可能性。

**方法：**
1. **比特深度压缩**：减少每个像素的颜色位数
   - 例如：从 8-bit 压缩到 4-bit
2. **空间平滑**：用不同大小的滤波器平滑图像

**检测思路：**
- 如果原始输入和压缩后的输入的预测结果差异很大，可能是对抗样本

#### 5.2.3 随机变换

**原理**：对输入进行随机变换，破坏对抗扰动的结构。

**方法：**
- 随机裁剪和缩放
- 随机旋转
- 随机添加噪声
- 随机色彩抖动

**优点：**
- 实现简单
- 可以与其他方法结合

**缺点：**
- 效果有限
- 可能影响正常样本的准确率

---

### 5.3 防御蒸馏（Defensive Distillation）

#### 5.3.1 基本原理

**提出者**：Papernot 等（2016）

**核心思想**：使用知识蒸馏（Knowledge Distillation）技术，让模型输出更"平滑"，从而减少梯度的可利用性。

**蒸馏过程：**

```
1. 训练教师模型（Teacher Model）：在原始数据上正常训练
2. 计算软标签（Soft Labels）：用教师模型预测训练数据的概率分布
3. 训练学生模型（Student Model）：用软标签训练，温度 T > 1
```

**温度参数 T 的作用：**
- 正常 softmax：`softmax(z_i) = exp(z_i) / Σexp(z_j)`
- 带温度的 softmax：`softmax(z_i/T) = exp(z_i/T) / Σexp(z_j/T)`
- T 越大，输出概率分布越平滑
- 平滑的输出意味着梯度更小，对抗扰动更难生成

#### 5.3.2 效果与局限

**初始效果：**
- 论文声称可以有效防御多种白盒攻击
- 防御效果显著

**后续发现：**
- Carlini 和 Wagner 用 C&W 攻击攻破了防御蒸馏
- 原因：防御蒸馏只是"隐藏"了梯度（梯度掩码），并没有真正增强鲁棒性
- 攻击者可以通过调整攻击方法绕过

**教训：**
- 很多防御方法只是梯度掩码（Gradient Masking）
- 评估防御方法需要用更强的攻击（如 C&W）测试
- "看起来安全"不等于"真正安全"

---

### 5.4 梯度掩码（Gradient Masking）

#### 5.4.1 什么是梯度掩码

**定义**：防御方法使得基于梯度的攻击失效，但模型并没有真正变得鲁棒。

**常见形式：**

1. **梯度消失**：模型输出太平滑，梯度几乎为零
   - 防御蒸馏就属于这类
   - 但攻击者可以用其他方法估计梯度

2. **梯度破碎（Gradient Shattering）**
   - 梯度是随机的、不可用的
   - 常见于使用随机化的防御
   - 但攻击者可以通过多次查询平均梯度

3. **输出离散化**
   - 只输出类别标签，不输出概率
   - 但黑盒攻击仍然可以进行

#### 5.4.2 为什么梯度掩码不可靠

- **黑盒攻击可以绕过**：不需要梯度的攻击方法（如决策攻击）
- **迁移攻击可以绕过**：在替代模型上生成对抗样本
- **更强的白盒攻击可以绕过**：如 C&W 攻击

**评估防御的黄金法则：**
> 如果一个防御方法只在白盒 FGSM/BIM 下测试有效，那它很可能只是梯度掩码。
> 必须用多种强攻击（C&W、PGD 的变体、黑盒攻击等）进行全面测试。

---

## 六、对抗训练（Adversarial Training）

### 6.1 对抗训练基础

#### 6.1.1 基本思想

**核心思想**：在训练过程中加入对抗样本，让模型学习对对抗样本也能正确分类。

这是目前最有效、最主流的对抗防御方法。

#### 6.1.2 标准对抗训练

**目标函数（Min-Max 优化）：**

```
min_θ E_{(x,y)~D} [max_{||δ||≤ε} L(f_θ(x + δ), y)]
```

解释：
- **内部最大化**：对于每个样本，找到最强的对抗扰动（使损失最大）
- **外部最小化**：优化模型参数，使对抗样本上的损失最小

#### 6.1.3 训练过程

```
对于每个训练批次 (x, y):
    1. 使用当前模型生成对抗样本：
       x_adv = PGD(x, y, θ, ε, α, T)
    
    2. 在对抗样本上计算损失：
       loss = L(f_θ(x_adv), y)
    
    3. 反向传播更新模型参数：
       θ = θ - η * ∇_θ loss
```

**关键点：**
- 每个训练步都需要生成对抗样本
- 通常使用 PGD 作为内部最大化的攻击方法
- 训练比普通训练慢得多（因为每步要多次迭代生成对抗样本）

### 6.2 PGD 对抗训练

#### 6.2.1 标准实现

**最经典的对抗训练方法**：Madry 等（2018）提出的 PGD 对抗训练。

**设置：**
- 攻击方法：PGD（10 步迭代）
- 范数约束：L∞
- ε = 8/255（对于图像）
- α = 2/255
- 数据集：CIFAR-10、ImageNet 等

**效果：**
- 显著提高模型的鲁棒性
- 在 PGD 攻击下准确率从 ~10% 提升到 ~40-50%
- 但干净样本的准确率会下降（鲁棒性与准确性的权衡）

#### 6.2.2 鲁棒性与准确性的权衡

**现象**：对抗训练后的模型：
- 对抗鲁棒性提高了
- 但干净样本的准确率降低了
- 这被称为"鲁棒性代价"（Robustness Cost）

**可能的原因：**
- 模型容量有限，无法同时兼顾干净样本和对抗样本
- 鲁棒特征和非鲁棒特征是不同的
- 对抗训练改变了模型学习的特征类型

**研究方向**：如何在保持干净准确率的同时提高鲁棒性。

### 6.3 对抗训练的改进方法

#### 6.3.1 TRADES

**全称**：Theoretically Principled Trade-off between Robustness and Accuracy

**核心思想**：将对抗训练的目标分解为干净样本损失和对抗正则项。

**目标函数：**
```
min_θ E_{x,y} [ L(f(x), y) + λ * max_{||δ||≤ε} L(f(x+δ), f(x)) ]
```

- 第一项：干净样本的分类损失（保证准确率）
- 第二项：对抗正则项（保证鲁棒性，使对抗样本的输出接近干净样本的输出）
- λ：平衡参数

**优势**：
- 更好地平衡了鲁棒性和准确性
- 有理论依据

#### 6.3.2 MART

**全称**：Misclassification Aware Adversarial Training

**核心思想**：对分类错误的样本给予更高的权重，重点关注难样本。

#### 6.3.3 其他改进

1. **加速对抗训练**
   - 减少内部迭代次数
   - 使用更快的攻击方法
   - 自由对抗训练（Free AT）

2. **数据增强结合**
   - 对抗训练 + 数据增强
   - AutoAugment + 对抗训练

3. **模型结构优化**
   - 研究更适合对抗训练的网络结构
   - 宽度 vs 深度对鲁棒性的影响

4. **自监督预训练 + 对抗微调**
   - 先用自监督学习预训练
   - 再用对抗训练微调

---

### 6.4 对抗训练的局限

1. **计算成本高**
   - 比普通训练慢几倍到几十倍
   - 需要更多 GPU 资源

2. **过度拟合特定攻击**
   - 用 PGD 训练的模型，对 PGD 防御好
   - 但对其他类型的攻击可能防御效果差
   - 例如：对 L2 攻击、空间变换攻击的鲁棒性提升有限

3. "**鲁棒过拟合**"
   - 训练过程中，训练集上的鲁棒准确率持续上升
   - 但测试集上的鲁棒准确率可能先升后降
   - 类似于过拟合，但发生在鲁棒准确率上

4. **对强攻击的防御仍然有限**
   - 即使经过对抗训练，面对最强的攻击，鲁棒准确率仍然不高
   - 在 ImageNet 上，最先进的对抗训练也只能达到 60% 左右的鲁棒准确率

---

## 七、检测与防御评估

### 7.1 对抗样本检测

#### 7.1.1 检测方法分类

| 方法类别 | 原理 | 代表方法 |
|---------|------|---------|
| 基于密度/统计 | 对抗样本在特征空间中分布不同 | 核密度估计、贝叶斯不确定性 |
| 基于不确定性 | 对抗样本使模型不确定 | MC Dropout、深度集成 |
| 基于重建 | 对抗样本难以被正确重建 | 自编码器、GAN 重建 |
| 检测器分类 | 训练一个二分类器检测对抗样本 | 对抗样本检测网络 |
| 输入变换比较 | 变换前后预测差异大则可能是对抗样本 | 特征压缩、随机变换 |

#### 7.1.2 基于不确定性的检测

**MC Dropout**
- 原理：在测试时也开启 Dropout，多次前向传播
- 对抗样本的预测方差通常更大（模型更不确定）
- 根据方差大小判断是否为对抗样本

**深度集成（Deep Ensembles）**
- 训练多个不同初始化的模型
- 对抗样本在不同模型上的预测一致性更低
- 根据预测一致性判断

#### 7.1.3 基于重建的检测

**自编码器检测**
```
输入样本 → 自编码器编码 → 自解码器解码 → 重建样本
                                   ↓
                           计算重建误差
                                   ↓
                    重建误差大 → 可能是对抗样本
```

**原理**：
- 正常样本在数据流形上，可以被很好地重建
- 对抗样本在流形外，重建误差大
- 重建后的样本如果分类正确，说明是对抗样本

#### 7.1.4 检测方法的局限

- **自适应攻击**：攻击者可以知道检测方法并调整攻击策略，绕过检测
- **假阳性问题**：可能将正常样本误判为对抗样本
- **检测准确率有限**：面对强攻击时检测率不高
- **不能从根本上解决问题**：检测只是"发现"而不是"修复"

---

### 7.2 防御评估方法

#### 7.2.1 评估指标

1. **干净准确率（Clean Accuracy）**
   - 模型在正常样本上的准确率
   - 衡量模型的基本性能

2. **鲁棒准确率（Robust Accuracy）**
   - 模型在对抗样本上的准确率
   - 衡量模型的抗攻击能力
   - 通常需要指定具体的攻击方法和参数

3. **攻击成功率（Attack Success Rate）**
   - 对抗样本成功导致分类错误的比例
   - 从攻击角度衡量

4. **平均扰动大小**
   - 成功攻击所需的平均扰动大小
   - 扰动越小说明模型越脆弱

#### 7.2.2 评估时的注意事项

1. **白盒 vs 黑盒**
   - 白盒鲁棒性和黑盒鲁棒性可能不同
   - 需要分别评估

2. **多种攻击方法**
   - 不能只在一种攻击下评估
   - 至少包括：FGSM、PGD、C&W、决策攻击等
   - 不同范数约束（L0、L2、L∞）

3. **自适应攻击（Adaptive Attack）**
   - 攻击者知道防御方法并进行调整
   - 这是最公平、最严格的评估方式
   - 很多防御在自适应攻击下失效

4. **可复现性**
   - 详细记录攻击参数
   - 提供代码和配置
   - 便于其他人复现和验证

#### 7.2.3 常见的评估陷阱

1. **只测试弱攻击**
   - 只测 FGSM，不测 PGD 和 C&W
   - 结果过于乐观

2. **不做自适应攻击评估**
   - 攻击者不知道防御方法的评估是不公平的
   - 实际中攻击者会研究和绕过防御

3. **混淆梯度掩码和真正的鲁棒性**
   - 防御蒸馏就是典型例子
   - 白盒攻击看似失效，但黑盒攻击可以绕过

4. **在训练数据上评估**
   - 模型可能记住了训练数据
   - 必须在测试集上评估

---

### 7.3 鲁棒基准（Robustness Benchmarks）

**常用数据集与基准：**

| 基准 | 数据集 | 模型 | 约束 |
|------|--------|------|------|
| MNIST | 手写数字 | 简单 CNN | L∞ ε=0.3 |
| CIFAR-10 | 小图像分类 | ResNet 等 | L∞ ε=8/255 |
