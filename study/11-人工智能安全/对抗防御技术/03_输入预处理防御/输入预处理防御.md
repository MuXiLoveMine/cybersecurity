# 输入预处理防御

### 3.1 输入偏转

**输入偏转（Input Randomization/Deflection）** 通过对输入添加随机变换来破坏对抗扰动。

```text
输入偏转方法

方法1: 随机裁剪
  原始图像 → 随机裁剪区域 → 调整大小 → 模型输入
  对抗扰动在裁剪后被破坏

方法2: 随机调整大小
  原始图像(224x224) → 随机缩放(200-250) → 调整回224 → 模型
  缩放改变了扰动的像素位置

方法3: 随机噪声注入
  原始图像 → 添加高斯噪声 → 模型
  噪声破坏了精心设计的对抗扰动

方法4: 随机填充
  原始图像 → 随机边缘填充 → 模型
  改变了输入的空间结构

理论分析:
  对抗扰动 δ 是精心设计的
  随机变换 T 使 δ → T(δ) 不再有效
  E_{T}[f(T(x+δ))] ≠ f(x+δ)
```

```python
class InputRandomizationDefense:
    """输入随机化防御"""

    def __init__(self, crop_size=224, resize_range=(200, 250),
                 noise_std=0.05):
        self.crop_size = crop_size
        self.resize_range = resize_range
        self.noise_std = noise_std

    def random_resize_pad(self, x):
        """随机调整大小并填充"""
        h, w = x.shape[-2:]
        # 随机选择新大小
        new_size = torch.randint(self.resize_range[0],
                                 self.resize_range[1] + 1, (1,)).item()
        # 调整大小
        x_resized = nn.functional.interpolate(
            x.unsqueeze(0), size=(new_size, new_size),
            mode='bilinear', align_corners=False
        ).squeeze(0)

        # 随机填充到原始大小
        pad_h = max(self.crop_size - new_size, 0)
        pad_w = max(self.crop_size - new_size, 0)
        if pad_h > 0 or pad_w > 0:
            pad_top = torch.randint(0, pad_h + 1, (1,)).item()
            pad_left = torch.randint(0, pad_w + 1, (1,)).item()
            x_padded = nn.functional.pad(
                x_resized,
                (pad_left, pad_w - pad_left, pad_top, pad_h - pad_top),
                value=0
            )
        else:
            # 随机裁剪
            top = torch.randint(0, new_size - self.crop_size + 1, (1,)).item()
            left = torch.randint(0, new_size - self.crop_size + 1, (1,)).item()
            x_padded = x_resized[:, top:top+self.crop_size,
                                  left:left+self.crop_size]

        return x_padded

    def add_gaussian_noise(self, x):
        """添加高斯噪声"""
        noise = torch.randn_like(x) * self.noise_std
        return torch.clamp(x + noise, 0, 1)

    def defend(self, x):
        """应用防御"""
        # 随机调整和填充
        x = self.random_resize_pad(x)
        # 添加噪声
        x = self.add_gaussian_noise(x)
        return x
```

### 3.2 离散化防御

**离散化防御** 通过将连续输入离散化为有限级别，破坏对抗扰动的连续性。

```text
离散化防御原理

对抗扰动: 连续的微小变化 (如 +0.001)
离散化: 将像素值量化到有限级别

量化过程:
  x离散 = round(x × L) / L
  其中L是量化级别数

例如:
  原始像素: 0.5234
  8级量化: round(0.5234 × 8) / 8 = round(4.187) / 8 = 4/8 = 0.5

效果:
  扰动 < 1/(2L) 的部分被量化消除
  L越大 → 保留的信息越多 → 防御效果越弱
  L越小 → 丢失的信息越多 → 干净精度下降

最优L需要平衡精度和鲁棒性
```

### 3.3 量化防御

```python
class QuantizationDefense:
    """量化防御"""

    def __init__(self, levels=8):
        """
        :param levels: 量化级别数
        """
        self.levels = levels

    def quantize(self, x):
        """量化输入"""
        x_clamped = torch.clamp(x, 0, 1)
        x_quantized = torch.round(x_clamped * (self.levels - 1)) / (self.levels - 1)
        return x_quantized

    def defend(self, x):
        """应用量化防御"""
        return self.quantize(x)
```
