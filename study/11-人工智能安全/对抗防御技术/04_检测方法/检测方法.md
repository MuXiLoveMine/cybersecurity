# 检测方法

### 4.1 特征压缩检测

**特征压缩（Feature Squeezing）** 由Xu等人提出，通过比较模型在原始输入和压缩输入上的输出差异来检测对抗样本。

```text
特征压缩检测原理

核心假设:
  对抗样本 → 压缩后 → 模型输出改变
  正常样本 → 压缩后 → 模型输出基本不变

检测流程:
  1. 输入 x
  2. 压缩 x → x_compressed (多种压缩方法)
  3. 分别计算 f(x) 和 f(x_compressed)
  4. 比较输出差异
  5. 差异 > 阈值 → 判定为对抗样本

压缩方法:
├── 位深度减少: 8bit → 1-7bit
├── 空间平滑: 中值滤波
├── 局部平滑: 非局部均值去噪
└── 颜色映射: 减少颜色数量
```

```python
class FeatureSqueezingDetector:
    """特征压缩检测器"""

    def __init__(self, model, bit_depth=5, threshold=0.1):
        self.model = model
        self.bit_depth = bit_depth
        self.threshold = threshold

    def squeeze(self, x):
        """压缩输入特征"""
        # 位深度减少
        max_val = 2 ** self.bit_depth - 1
        x_squeezed = torch.round(x * max_val) / max_val
        return x_squeezed

    def median_filter(self, x, kernel_size=3):
        """中值滤波"""
        # 简化的中值滤波
        import torch.nn.functional as F
        padding = kernel_size // 2
        x_filtered = F.avg_pool2d(
            x.unsqueeze(0), kernel_size, stride=1, padding=padding
        ).squeeze(0)
        return x_filtered

    def detect(self, x):
        """检测是否为对抗样本"""
        with torch.no_grad():
            # 原始输出
            orig_output = nn.functional.softmax(self.model(x.unsqueeze(0)), dim=1)

            # 压缩后输出
            x_squeezed = self.squeeze(x)
            squeezed_output = nn.functional.softmax(
                self.model(x_squeezed.unsqueeze(0)), dim=1
            )

            # 计算输出差异
            difference = (orig_output - squeezed_output).norm().item()

            # 判定
            is_adversarial = difference > self.threshold

        return {
            'is_adversarial': is_adversarial,
            'difference': difference,
            'threshold': self.threshold
        }
```

### 4.2 不确定性检测

**不确定性检测** 利用模型对对抗样本表现出的高不确定性来检测。

```text
不确定性检测原理

正常样本:
  模型输出: [0.95, 0.03, 0.02] → 低不确定性 → 高置信度

对抗样本:
  模型输出: [0.4, 0.35, 0.25] → 高不确定性 → 低置信度

不确定性度量:
├── 熵 (Entropy): H(p) = -Σ p_i log(p_i)
├── 互信息 (Mutual Information)
├── 预测方差 (Predictive Variance)
└── 软最大值温度

检测策略:
  熵 > 阈值 → 可能是对抗样本
  置信度 < 阈值 → 可能是对抗样本

MC Dropout方法:
  通过多次Dropout采样估计不确定性
  多次预测的方差大 → 不确定性高
```

### 4.3 统计检测方法

```text
统计检测方法

方法1: 密度估计检测
  ├── 训练正常样本的密度估计模型
  ├── 对抗样本在低密度区域
  └── 检测: P(x) < 阈值 → 对抗样本

方法2: 核范数检测
  ├── 对抗样本的核范数与正常样本不同
  └── 比较输入的核范数

方法3: 区域分类检测
  ├── 训练一个检测器网络
  ├── 输入: 原始图像
  └── 输出: 正常/对抗

方法4: 激活值分析
  ├── 分析中间层激活值分布
  ├── 对抗样本的激活模式异常
  └── 使用激活值的统计特征检测

局限性:
├── 检测可被绕过(攻击者针对检测器优化)
├── 误报率难以控制
├── 对新型攻击效果有限
└── 检测+拒绝 ≠ 防御(只是拒绝服务)
```
