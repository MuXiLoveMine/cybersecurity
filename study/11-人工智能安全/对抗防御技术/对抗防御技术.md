## 一、对抗防御概述

### 1.1 对抗攻击回顾

**对抗样本（Adversarial Examples）** 是指通过对输入数据添加人类难以察觉的微小扰动，使AI模型产生错误输出的特殊构造样本。

```text
对抗攻击基本原理

正常分类:
  输入图像(熊猫) → 模型 → 输出: 熊猫 (99% 置信度)

对抗攻击:
  输入图像(熊猫)        → 模型 → 输出: 熊猫 (99%)
  + 微小扰动(不可见)    → 模型 → 输出: 长臂猿 (99.3%)
  = 对抗样本(看似熊猫)

攻击类型:
├── 白盒攻击: 攻击者知道模型结构和参数
│   ├── FGSM (Fast Gradient Sign Method)
│   ├── PGD (Projected Gradient Descent)
│   ├── C&W Attack
│   └── DeepFool
├── 黑盒攻击: 攻击者不知道模型参数
│   ├── 迁移攻击 (Transfer Attack)
│   ├── 决策边界攻击 (Boundary Attack)
│   └── 询问攻击 (Query-based Attack)
└── 物理世界攻击
    ├── 打印对抗样本
    ├── 贴纸对抗样本
    └── 光照对抗样本
```

## 二、对抗训练

### 2.1 FGSM对抗训练

**FGSM对抗训练** 由Goodfellow等人提出，是最早的对抗训练方法。

**原理：** 在训练过程中，对每个训练样本使用FGSM生成对抗样本，然后将对抗样本加入训练集一起训练。

```text
FGSM对抗训练流程

标准训练:
  最小化: L(θ, x, y) = -log p(y|x; θ)

FGSM对抗训练:
  1. 计算损失关于输入的梯度: ∇_x L(θ, x, y)
  2. 生成对抗样本: x_adv = x + ε · sign(∇_x L(θ, x, y))
  3. 在对抗样本上计算损失: L(θ, x_adv, y)
  4. 最小化: L(θ, x_adv, y)

FGSM公式:
  x_adv = x + ε · sign(∇_x L(θ, x, y))

其中:
  ε: 扰动大小（通常8/255 ≈ 0.031）
  sign: 符号函数
  ∇_x: 损失关于输入x的梯度
```

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader

def fgsm_attack(image, epsilon, data_grad):
    """
    FGSM攻击
    :param image: 原始图像
    :param epsilon: 扰动大小
    :param data_grad: 损失关于输入的梯度
    :return: 对抗样本
    """
    # 获取梯度符号
    sign_data_grad = data_grad.sign()
    # 生成对抗样本
    perturbed_image = image + epsilon * sign_data_grad
    # 裁剪到合法范围
    perturbed_image = torch.clamp(perturbed_image, 0, 1)
    return perturbed_image


def fgsm_adversarial_train(model, train_loader, epochs, epsilon=8/255,
                           lr=0.001, device='cpu'):
    """
    FGSM对抗训练
    """
    model = model.to(device)
    optimizer = optim.Adam(model.parameters(), lr=lr)
    criterion = nn.CrossEntropyLoss()

    for epoch in range(epochs):
        model.train()
        total_loss = 0
        correct_clean = 0
        correct_adv = 0
        total = 0

        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)

            # 需要计算输入梯度
            data.requires_grad = True

            # 前向传播（干净样本）
            output = model(data)
            loss_clean = criterion(output, target)

            # 反向传播获取输入梯度
            model.zero_grad()
            loss_clean.backward()
            data_grad = data.grad.data

            # 生成FGSM对抗样本
            perturbed_data = fgsm_attack(data, epsilon, data_grad)

            # 在对抗样本上前向传播
            output_adv = model(perturbed_data)
            loss_adv = criterion(output_adv, target)

            # 总损失 = 干净损失 + 对抗损失
            loss = loss_clean + loss_adv

            # 优化
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

            # 统计
            total_loss += loss.item()
            pred_clean = output.max(1, keepdim=True)[1]
            pred_adv = output_adv.max(1, keepdim=True)[1]
            correct_clean += pred_clean.eq(target.view_as(pred_clean)).sum().item()
            correct_adv += pred_adv.eq(target.view_as(pred_adv)).sum().item()
            total += len(target)

        print(f"Epoch {epoch+1}/{epochs}: "
              f"Loss={total_loss/len(train_loader):.4f}, "
              f"Clean Acc={100.*correct_clean/total:.2f}%, "
              f"Adv Acc={100.*correct_adv/total:.2f}%")

    return model
```

### 2.2 PGD对抗训练

**PGD（Projected Gradient Descent）对抗训练** 是目前最强的经验性防御方法之一，由Madry等人提出。

```text
PGD对抗训练原理

PGD是FGSM的多步迭代版本:

PGD攻击:
  x_0 = x  (原始样本)
  x_{t+1} = x_t + α · sign(∇_{x_t} L(θ, x_t, y))
  x_{t+1} = clip(x_{t+1}, x - ε, x + ε)  # 投影到ε-ball
  x_{t+1} = clip(x_{t+1}, 0, 1)  # 裁剪到合法范围

参数:
  ε: 最大扰动大小 (如 8/255)
  α: 每步扰动步长 (如 2/255)
  步数: 迭代次数 (如 7-10步)

PGD对抗训练:
  min_θ E_{(x,y)~D} [max_{||δ||≤ε} L(θ, x+δ, y)]

  内层: max - 找到最强的PGD对抗样本
  外层: min - 优化模型参数使对抗损失最小

特点:
├── 训练时间长（每步需要多步PGD攻击）
├── 对多种攻击有较好防御效果
├── 干净精度有一定下降
├── 被认为是经验防御的"黄金标准"
└── 但无法防御自适应攻击
```

```python
def pgd_attack(model, x, y, epsilon, alpha, num_steps, device='cpu'):
    """
    PGD攻击
    :param model: 目标模型
    :param x: 原始输入
    :param y: 真实标签
    :param epsilon: 最大扰动
    :param alpha: 步长
    :param num_steps: 迭代步数
    :return: 对抗样本
    """
    x_adv = x.clone().detach()
    x_adv = x_adv + torch.empty_like(x_adv).uniform_(-epsilon, epsilon)
    x_adv = torch.clamp(x_adv, 0, 1)

    for _ in range(num_steps):
        x_adv.requires_grad_(True)
        output = model(x_adv)
        loss = nn.functional.cross_entropy(output, y)

        model.zero_grad()
        loss.backward()

        with torch.no_grad():
            # PGD步
            x_adv = x_adv + alpha * x_adv.grad.sign()
            # 投影到ε-ball
            x_adv = torch.max(torch.min(x_adv, x + epsilon), x - epsilon)
            # 裁剪到合法范围
            x_adv = torch.clamp(x_adv, 0, 1)

    return x_adv.detach()


def pgd_adversarial_train(model, train_loader, epochs,
                           epsilon=8/255, alpha=2/255,
                           pgd_steps=7, lr=0.001, device='cpu'):
    """
    PGD对抗训练
    """
    model = model.to(device)
    optimizer = optim.SGD(model.parameters(), lr=lr, momentum=0.9, weight_decay=2e-4)
    scheduler = optim.lr_scheduler.MultiStepLR(optimizer, [100, 150], gamma=0.1)
    criterion = nn.CrossEntropyLoss()

    for epoch in range(epochs):
        model.train()
        total_loss = 0
        correct = 0
        total = 0

        for data, target in train_loader:
            data, target = data.to(device), target.to(device)

            # 1. 生成PGD对抗样本（内层最大化）
            x_adv = pgd_attack(model, data, target, epsilon,
                               alpha, pgd_steps, device)

            # 2. 在对抗样本上训练（外层最小化）
            optimizer.zero_grad()
            output = model(x_adv)
            loss = criterion(output, target)
            loss.backward()
            optimizer.step()

            total_loss += loss.item()
            pred = output.max(1, keepdim=True)[1]
            correct += pred.eq(target.view_as(pred)).sum().item()
            total += len(target)

        scheduler.step()
        print(f"Epoch {epoch+1}/{epochs}: "
              f"Loss={total_loss/len(train_loader):.4f}, "
              f"Adv Acc={100.*correct/total:.2f}%")

    return model
```

### 2.3 YOPO对抗训练

**YOPO（You Only Propagate Once）** 是一种高效的对抗训练方法，通过减少反向传播次数加速训练。

```text
YOPO原理

标准PGD对抗训练:
  每个PGD步 → 1次前向 + 1次反向传播
  7步PGD → 14次前向+反向传播（计算量大）

YOPO优化:
  利用对偶网络理论，将梯度计算分解:
  - 先计算一次完整的反向传播
  - 后续PGD步只更新输入，不重新反向传播
  - 大幅减少计算量

YOPO流程:
  1. 前向传播 + 1次反向传播
  2. 对每层特征计算PGD扰动（多次，不需要重新反向传播）
  3. 取最终扰动
  4. 在对抗样本上训练

效率: 比标准PGD快5-10倍
代价: 防御效果可能略差于标准PGD
```

### 2.4 对抗训练局限性

```text
对抗训练的局限性

1. 计算开销大
   ├── PGD训练时间 = 标准训练 × (PGD步数+1)
   ├── 例如: 7步PGD → 训练时间约8倍
   └── 大模型(如ResNet-152)训练需要数天

2. 精度-鲁棒性权衡
   ├── 防御越强 → 干净精度下降
   ├── PGD训练(ε=8/255) → 干净精度可能下降5-10%
   └── 不存在"免费午餐"

3. 对自适应攻击脆弱
   ├── 对抗训练针对特定攻击
   ├── 自适应攻击(如C&W)可绕过
   └── 黑盒迁移攻击仍有效

4. 扰动大小限制
   ├── 训练时用ε=8/255
   ├── 攻击者用更大ε → 防御失效
   └── 无法防御无界扰动

5. 标签泄露问题
   ├── 对抗训练使用真实标签生成对抗样本
   ├── 标签信息可能通过对抗样本泄露
   └── 影响模型泛化

6. 分布外样本
   ├── 训练分布外的对抗样本防御差
   └── 新型攻击方式防御不足
```

## 三、输入预处理防御

### 3.1 输入偏转

**输入偏转（Input Randomization/Deflection）** 通过对输入添加随机变换来破坏对抗扰动。

```text
输入偏转方法

方法1: 随机裁剪
  原始图像 → 随机裁剪区域 → 调整大小 → 模型输入
  对抗扰动在裁剪后被破坏

方法2: 随机调整大小
  原始图像(224x224) → 随机缩放(200-250) → 调整回224 → 模型
  缩放改变了扰动的像素位置

方法3: 随机噪声注入
  原始图像 → 添加高斯噪声 → 模型
  噪声破坏了精心设计的对抗扰动

方法4: 随机填充
  原始图像 → 随机边缘填充 → 模型
  改变了输入的空间结构

理论分析:
  对抗扰动 δ 是精心设计的
  随机变换 T 使 δ → T(δ) 不再有效
  E_{T}[f(T(x+δ))] ≠ f(x+δ)
```

```python
class InputRandomizationDefense:
    """输入随机化防御"""

    def __init__(self, crop_size=224, resize_range=(200, 250),
                 noise_std=0.05):
        self.crop_size = crop_size
        self.resize_range = resize_range
        self.noise_std = noise_std

    def random_resize_pad(self, x):
        """随机调整大小并填充"""
        h, w = x.shape[-2:]
        # 随机选择新大小
        new_size = torch.randint(self.resize_range[0],
                                 self.resize_range[1] + 1, (1,)).item()
        # 调整大小
        x_resized = nn.functional.interpolate(
            x.unsqueeze(0), size=(new_size, new_size),
            mode='bilinear', align_corners=False
        ).squeeze(0)

        # 随机填充到原始大小
        pad_h = max(self.crop_size - new_size, 0)
        pad_w = max(self.crop_size - new_size, 0)
        if pad_h > 0 or pad_w > 0:
            pad_top = torch.randint(0, pad_h + 1, (1,)).item()
            pad_left = torch.randint(0, pad_w + 1, (1,)).item()
            x_padded = nn.functional.pad(
                x_resized,
                (pad_left, pad_w - pad_left, pad_top, pad_h - pad_top),
                value=0
            )
        else:
            # 随机裁剪
            top = torch.randint(0, new_size - self.crop_size + 1, (1,)).item()
            left = torch.randint(0, new_size - self.crop_size + 1, (1,)).item()
            x_padded = x_resized[:, top:top+self.crop_size,
                                  left:left+self.crop_size]

        return x_padded

    def add_gaussian_noise(self, x):
        """添加高斯噪声"""
        noise = torch.randn_like(x) * self.noise_std
        return torch.clamp(x + noise, 0, 1)

    def defend(self, x):
        """应用防御"""
        # 随机调整和填充
        x = self.random_resize_pad(x)
        # 添加噪声
        x = self.add_gaussian_noise(x)
        return x
```

### 3.2 离散化防御

**离散化防御** 通过将连续输入离散化为有限级别，破坏对抗扰动的连续性。

```text
离散化防御原理

对抗扰动: 连续的微小变化 (如 +0.001)
离散化: 将像素值量化到有限级别

量化过程:
  x离散 = round(x × L) / L
  其中L是量化级别数

例如:
  原始像素: 0.5234
  8级量化: round(0.5234 × 8) / 8 = round(4.187) / 8 = 4/8 = 0.5

效果:
  扰动 < 1/(2L) 的部分被量化消除
  L越大 → 保留的信息越多 → 防御效果越弱
  L越小 → 丢失的信息越多 → 干净精度下降

最优L需要平衡精度和鲁棒性
```

### 3.3 量化防御

```python
class QuantizationDefense:
    """量化防御"""

    def __init__(self, levels=8):
        """
        :param levels: 量化级别数
        """
        self.levels = levels

    def quantize(self, x):
        """量化输入"""
        x_clamped = torch.clamp(x, 0, 1)
        x_quantized = torch.round(x_clamped * (self.levels - 1)) / (self.levels - 1)
        return x_quantized

    def defend(self, x):
        """应用量化防御"""
        return self.quantize(x)
```

## 四、检测方法

### 4.1 特征压缩检测

**特征压缩（Feature Squeezing）** 由Xu等人提出，通过比较模型在原始输入和压缩输入上的输出差异来检测对抗样本。

```text
特征压缩检测原理

核心假设:
  对抗样本 → 压缩后 → 模型输出改变
  正常样本 → 压缩后 → 模型输出基本不变

检测流程:
  1. 输入 x
  2. 压缩 x → x_compressed (多种压缩方法)
  3. 分别计算 f(x) 和 f(x_compressed)
  4. 比较输出差异
  5. 差异 > 阈值 → 判定为对抗样本

压缩方法:
├── 位深度减少: 8bit → 1-7bit
├── 空间平滑: 中值滤波
├── 局部平滑: 非局部均值去噪
└── 颜色映射: 减少颜色数量
```

```python
class FeatureSqueezingDetector:
    """特征压缩检测器"""

    def __init__(self, model, bit_depth=5, threshold=0.1):
        self.model = model
        self.bit_depth = bit_depth
        self.threshold = threshold

    def squeeze(self, x):
        """压缩输入特征"""
        # 位深度减少
        max_val = 2 ** self.bit_depth - 1
        x_squeezed = torch.round(x * max_val) / max_val
        return x_squeezed

    def median_filter(self, x, kernel_size=3):
        """中值滤波"""
        # 简化的中值滤波
        import torch.nn.functional as F
        padding = kernel_size // 2
        x_filtered = F.avg_pool2d(
            x.unsqueeze(0), kernel_size, stride=1, padding=padding
        ).squeeze(0)
        return x_filtered

    def detect(self, x):
        """检测是否为对抗样本"""
        with torch.no_grad():
            # 原始输出
            orig_output = nn.functional.softmax(self.model(x.unsqueeze(0)), dim=1)

            # 压缩后输出
            x_squeezed = self.squeeze(x)
            squeezed_output = nn.functional.softmax(
                self.model(x_squeezed.unsqueeze(0)), dim=1
            )

            # 计算输出差异
            difference = (orig_output - squeezed_output).norm().item()

            # 判定
            is_adversarial = difference > self.threshold

        return {
            'is_adversarial': is_adversarial,
            'difference': difference,
            'threshold': self.threshold
        }
```

### 4.2 不确定性检测

**不确定性检测** 利用模型对对抗样本表现出的高不确定性来检测。

```text
不确定性检测原理

正常样本:
  模型输出: [0.95, 0.03, 0.02] → 低不确定性 → 高置信度

对抗样本:
  模型输出: [0.4, 0.35, 0.25] → 高不确定性 → 低置信度

不确定性度量:
├── 熵 (Entropy): H(p) = -Σ p_i log(p_i)
├── 互信息 (Mutual Information)
├── 预测方差 (Predictive Variance)
└── 软最大值温度

检测策略:
  熵 > 阈值 → 可能是对抗样本
  置信度 < 阈值 → 可能是对抗样本

MC Dropout方法:
  通过多次Dropout采样估计不确定性
  多次预测的方差大 → 不确定性高
```

### 4.3 统计检测方法

```text
统计检测方法

方法1: 密度估计检测
  ├── 训练正常样本的密度估计模型
  ├── 对抗样本在低密度区域
  └── 检测: P(x) < 阈值 → 对抗样本

方法2: 核范数检测
  ├── 对抗样本的核范数与正常样本不同
  └── 比较输入的核范数

方法3: 区域分类检测
  ├── 训练一个检测器网络
  ├── 输入: 原始图像
  └── 输出: 正常/对抗

方法4: 激活值分析
  ├── 分析中间层激活值分布
  ├── 对抗样本的激活模式异常
  └── 使用激活值的统计特征检测

局限性:
├── 检测可被绕过(攻击者针对检测器优化)
├── 误报率难以控制
├── 对新型攻击效果有限
└── 检测+拒绝 ≠ 防御(只是拒绝服务)
```

## 五、防御性蒸馏

### 5.1 蒸馏原理

**防御性蒸馏（Defensive Distillation）** 由Papernot等人提出，通过知识蒸馏减少模型对对抗扰动敏感度。

```text
防御性蒸馏流程

阶段1: 训练教师模型
  标准训练教师模型 T_teacher
  使用温度T（通常T=20-100）

  损失函数:
  L_teacher = -Σ y_i · log(softmax(z_i / T))

  其中z_i是logits，T是温度参数

阶段2: 训练学生模型
  学生模型架构与教师相同
  使用教师模型的软标签训练

  软标签: q_i = softmax(z_i^teacher / T)
  损失: L_student = -Σ q_i · log(softmax(z_i^student / T))

阶段3: 部署学生模型
  推理时温度设为1
  学生模型继承了教师的知识但更平滑

防御原理:
  温度T使softmax输出更平滑
  → 梯度更小
  → 对抗扰动效果减弱
  → 模型更鲁棒
```

### 5.2 温度参数

```python
class DefensiveDistillation:
    """防御性蒸馏"""

    def __init__(self, teacher_model, student_model, temperature=20):
        """
        :param teacher_model: 教师模型
        :param student_model: 学生模型
        :param temperature: 温度参数T
        """
        self.teacher = teacher_model
        self.student = student_model
        self.T = temperature

    def get_soft_labels(self, x):
        """获取教师模型的软标签"""
        with torch.no_grad():
            logits = self.teacher(x)
            soft_labels = nn.functional.softmax(logits / self.T, dim=1)
        return soft_labels

    def distillation_loss(self, student_logits, teacher_soft_labels):
        """蒸馏损失"""
        student_log_probs = nn.functional.log_softmax(
            student_logits / self.T, dim=1
        )
        loss = nn.functional.kl_div(
            student_log_probs, teacher_soft_labels,
            reduction='batchmean'
        ) * (self.T ** 2)  # 温度缩放
        return loss

    def train_student(self, train_loader, epochs, lr=0.001, device='cpu'):
        """训练学生模型"""
        self.student = self.student.to(device)
        self.teacher = self.teacher.to(device)
        self.teacher.eval()

        optimizer = optim.Adam(self.student.parameters(), lr=lr)

        for epoch in range(epochs):
            self.student.train()
            total_loss = 0
            correct = 0
            total = 0

            for data, target in train_loader:
                data, target = data.to(device), target.to(device)

                # 获取教师软标签
                soft_labels = self.get_soft_labels(data)

                # 学生前向传播
                student_logits = self.student(data)

                # 蒸馏损失
                loss = self.distillation_loss(student_logits, soft_labels)

                optimizer.zero_grad()
                loss.backward()
                optimizer.step()

                total_loss += loss.item()
                # 推理时温度=1
                pred = student_logits.max(1, keepdim=True)[1]
                correct += pred.eq(target.view_as(pred)).sum().item()
                total += len(target)

            print(f"Epoch {epoch+1}: Loss={total_loss/len(train_loader):.4f}, "
                  f"Acc={100.*correct/total:.2f}%")

        return self.student
```

### 5.3 蒸馏的局限

```text
防御性蒸馏的局限性

1. 梯度掩蔽而非真正防御
   ├── 蒸馏使梯度变小 → 攻击者难以找到梯度方向
   ├── 但对抗扰动仍然有效
   └── 自适应攻击(如使用不同温度)可绕过

2. 被C&W攻击攻破
   ├── Carlini & Wagner证明可绕过蒸馏
   ├── 通过修改目标函数可恢复梯度信息
   └── 蒸馏提供的是虚假安全感

3. 干净精度可能下降
   ├── 软标签传递信息有损失
   └── 学生模型可能不如直接训练

4. 计算开销
   ├── 需要训练两个模型
   └── 推理时无额外开销
```

## 六、梯度掩蔽

### 6.1 梯度掩蔽概念

```text
梯度掩蔽(Gradient Masking)概念

定义:
  通过使模型梯度不可用或误导性，阻碍基于梯度的攻击

常见形式:
├── 梯度消失: 使损失关于输入的梯度接近0
├── 梯度误导: 梯度方向不指向真实决策边界
├── 梯度不稳定: 微小输入变化导致梯度剧变
└── 梯度不可微: 模型包含不可微操作

实现方式:
├── 防御性蒸馏: 高温度使梯度平滑
├── 不可微预处理: 量化、裁剪等
├── 梯度正则化: 惩罚大梯度
└── 离散化: 使输入离散不可微
```

### 6.2 掩蔽的攻击绕过

```text
梯度掩蔽的绕过

掩蔽的问题:
  掩蔽使白盒攻击困难
  但不改变模型的决策边界
  攻击者可通过以下方式绕过:

1. 近似梯度
   ├── 使用有限差分近似梯度
   ├── f'(x) ≈ (f(x+h) - f(x-h)) / (2h)
   └── 适用于不可微预处理

2. 反向掩蔽
   ├── 攻击者自行调整温度参数
   ├── 使用更大温度计算梯度
   └── 获取更准确的梯度方向

3. 黑盒迁移
   ├── 在代理模型上生成对抗样本
   ├── 代理模型无掩蔽
   └── 对抗样本迁移到掩蔽模型

4. 基于决策的攻击
   ├── 不需要梯度
   ├── 通过查询模型输出来估计决策边界
   └── 如Boundary Attack

结论:
  梯度掩蔽提供的是虚假安全感
  不应作为独立的防御手段
  应结合其他防御技术
```

## 七、随机化平滑

### 7.1 随机化平滑原理

**随机化平滑（Randomized Smoothing）** 是目前唯一能提供**认证鲁棒性**的防御方法，由Cohen等人提出。

```text
随机化平滑原理

核心思想:
  对输入添加随机噪声 → 构造平滑分类器
  平滑分类器在L2球内有认证的鲁棒性

定义:
  原始分类器: f(x)
  平滑分类器: g(x) = argmax_c P(f(x+N(0, σ²)) = c)

  即: 对输入加高斯噪声后，取模型最可能的类别

认证保证:
  如果 P(f(x+N) = c) ≥ p_A
  且 扰动 ||δ|| ≤ R
  则 g(x+δ) = c (以高概率)

  认证半径 R = σ/2 · (Φ^{-1}(p_A) - Φ^{-1}(p_B))

  其中:
    σ: 噪声标准差
    p_A: 正确类别的概率下界
    p_B: 第二高类别的概率上界
    Φ^{-1}: 标准正态分布CDF的反函数

优点:
  ✓ 提供数学证明的鲁棒性保证
  ✓ 适用于任何分类器
  ✓ 不需要修改模型架构

缺点:
  ✗ 认证精度低于经验防御
  ✗ 只对L2扰动有效
  ✗ 噪声降低干净精度
  ✗ 推理需要多次采样
```

### 7.2 认证鲁棒性

```text
认证鲁棒性 vs 经验鲁棒性

经验鲁棒性 (Empirical Robustness):
  在特定攻击下表现良好
  但不保证对抗其他攻击
  例如: PGD对抗训练

认证鲁棒性 (Certified Robustness):
  有数学证明的鲁棒性保证
  对一定范围内的任何扰动都有效
  例如: 随机化平滑

认证半径计算:
  给定输入x，类别c:
  1. 采样n次: x_i = x + N(0, σ²)
  2. 统计正确分类次数: n_c
  3. 计算概率下界: p_A (使用二项分布置信区间)
  4. 计算第二概率上界: p_B = 1 - p_A
  5. 认证半径: R = σ/2 · (Φ^{-1}(p_A) - Φ^{-1}(p_B))

  如果 ||δ||_2 ≤ R → 保证 g(x+δ) = c

参数选择:
├── σ越大 → 认证半径越大，但干净精度越低
├── 采样次数n越多 → 置信度越高
└── 需要平衡精度和鲁棒性
```

```python
import numpy as np
from scipy.stats import norm

class RandomizedSmoothing:
    """随机化平滑分类器"""

    def __init__(self, base_classifier, sigma=0.25,
                 num_samples=1000, alpha=0.001):
        """
        :param base_classifier: 基础分类器
        :param sigma: 噪声标准差
        :param num_samples: 采样次数
        :param alpha: 错误概率
        """
        self.base_classifier = base_classifier
        self.sigma = sigma
        self.num_samples = num_samples
        self.alpha = alpha  # 置信水平 1-alpha

    def predict(self, x):
        """预测类别"""
        # 添加噪声采样
        x_noisy = x.unsqueeze(0) + torch.randn(
            self.num_samples, *x.shape
        ) * self.sigma

        # 基础分类器预测
        with torch.no_grad():
            outputs = self.base_classifier(x_noisy)
            predictions = outputs.argmax(dim=1)

        # 统计各类别出现次数
        bin_counts = torch.bincount(
            predictions, minlength=outputs.shape[1]
        )

        # 最可能的类别
        top_class = bin_counts.argmax().item()
        top_count = bin_counts[top_class].item()

        return top_class, bin_counts

    def certify(self, x, n_samples_certify=100000):
        """
        认证鲁棒性
        :param x: 输入
        :param n_samples_certify: 认证采样次数
        :return: (类别, 认证半径)
        """
        # 1. 预测最可能类别
        pred_class, counts = self.predict(x)

        # 2. 更多样本进行认证
        x_noisy = x.unsqueeze(0) + torch.randn(
            n_samples_certify, *x.shape
        ) * self.sigma

        with torch.no_grad():
            outputs = self.base_classifier(x_noisy)
            predictions = outputs.argmax(dim=1)

        # 3. 统计
        n_A = (predictions == pred_class).sum().item()
        n_total = n_samples_certify

        # 4. 计算概率下界 (使用Clopper-Pearson区间)
        p_A_lower = self._binomial_lower_bound(n_A, n_total, 1 - self.alpha)

        if p_A_lower < 0.5:
            # 认证失败
            return pred_class, 0.0

        # 5. 第二高概率上界
        p_B_upper = 1 - p_A_lower

        # 6. 计算认证半径
        radius = self.sigma / 2 * (
            norm.ppf(p_A_lower) - norm.ppf(p_B_upper)
        )

        return pred_class, radius

    @staticmethod
    def _binomial_lower_bound(successes, total, confidence=0.999):
        """二项分布的Clopper-Pearson下界"""
        from scipy.stats import beta
        if successes == 0:
            return 0.0
        alpha = 1 - confidence
        lower = beta.ppf(alpha / 2, successes, total - successes + 1)
        return lower


# 演示
def demo_randomized_smoothing():
    """随机化平滑演示"""
    import torch.nn as nn

    # 简单模型
    model = nn.Sequential(

        nn.ReLU(),

    )

    # 随机化平滑
    smoother = RandomizedSmoothing(model, sigma=0.25, num_samples=100)

    # 模拟输入

    # 预测

    print(f"预测类别: {pred_class}")
    print(f"各类别计数: {counts}")

    # 认证（减少采样数用于演示）
    # cert_class, radius = smoother.certify(x.squeeze(0), n_samples_certify=1000)
    # print(f"认证类别: {cert_class}, 认证半径: {radius:.4f}")

    print("\n不同噪声标准差的影响:")

        s = RandomizedSmoothing(model, sigma=sigma, num_samples=100)
        pred, counts = s.predict(x.squeeze(0))
```

## 八、集成防御

### 8.1 集成防御架构

**集成防御** 使用多个模型或防御方法的组合来提升鲁棒性。

```text
集成防御架构

方案1: 多模型投票
  输入 → [模型A, 模型B, 模型C] → 投票 → 最终结果
  攻击者需要同时攻击多个模型

方案2: 多防御组合
  输入 → 量化 → 随机化 → PGD训练模型 → 最终结果
  串联多种防御方法

方案3: 自适应路由
  输入 → 检测器 → 正常/对抗?
                    ├── 正常 → 标准模型
                    └── 可疑 → 鲁棒模型(更慢但更安全)

方案4: 随机模型选择
  输入 → 随机选择模型 → [A, B, C, D中随机] → 输出
  攻击者不知道使用哪个模型

方案5: 对抗训练集成
  多个模型对抗训练 → 互相增强
  使用不同的攻击方法训练不同模型
```

### 8.2 多样性增强

```text
集成防御的多样性要求

问题:
  如果集成中的模型太相似 → 同样的对抗样本可同时攻击
  → 集成防御无效

多样性来源:
├── 架构多样性: ResNet + VGG + ViT + MobileNet
├── 训练数据多样性: 不同数据子集训练
├── 训练方法多样性: 标准训练 + PGD训练 + TRADES
├── 输入处理多样性: 不同预处理方式
└── 随机化多样性: 不同随机种子

度量:
  非一致性 = 不同模型预测不同类别的比例
  非一致性越高 → 集成防御越强
  理想: 非对抗样本一致性高，对抗样本非一致性高
```

```python
class EnsembleDefense:
    """集成防御"""

    def __init__(self, models, defense_methods=None, mode='voting'):
        """
        :param models: 模型列表
        :param defense_methods: 每个模型的输入防御方法
        :param mode: 'voting' 或 'averaging'
        """
        self.models = models
        self.defense_methods = defense_methods or [None] * len(models)
        self.mode = mode

    def predict(self, x):
        """集成预测"""
        outputs = []

        for model, defense in zip(self.models, self.defense_methods):
            input_x = x
            if defense is not None:
                input_x = defense.defend(input_x)

            with torch.no_grad():
                output = nn.functional.softmax(model(input_x.unsqueeze(0)), dim=1)
            outputs.append(output)

        if self.mode == 'voting':
            # 多数投票
            predictions = [o.argmax(dim=1).item() for o in outputs]
            from collections import Counter
            vote_counts = Counter(predictions)
            final_pred = vote_counts.most_common(1)[0][0]
            confidence = vote_counts[final_pred] / len(self.models)

        elif self.mode == 'averaging':
            # 平均概率
            avg_output = torch.stack(outputs).mean(dim=0)
            final_pred = avg_output.argmax(dim=1).item()
            confidence = avg_output[0, final_pred].item()

        return {
            'prediction': final_pred,
            'confidence': confidence,
            'individual_predictions': [o.argmax(dim=1).item()
                                       for o in outputs],
            'disagreement': len(set(o.argmax(dim=1).item()
                                    for o in outputs)) > 1
        }
```

### 10.1 防御技术对比

| 防御方法 | 防御类型 | 认证保证 | 计算开销 | 干净精度 | 鲁棒精度 | 实用性 |
|---------|---------|---------|---------|---------|---------|-------|
| FGSM对抗训练 | 修改模型 | 无 | 中 | 高 | 低 | 中 |
| PGD对抗训练 | 修改模型 | 无 | 高 | 中 | 中 | 高 |
| 输入预处理 | 修改输入 | 无 | 低 | 高 | 低 | 中 |
| 特征压缩检测 | 检测 | 无 | 低 | 高 | N/A | 低 |
| 防御性蒸馏 | 辅助 | 无 | 中 | 中 | 低 | 低 |

### 10.2 最佳实践建议

```text
对抗防御最佳实践

1. 防御策略选择
   □ 安全关键场景: PGD对抗训练 + 随机化平滑
   □ 资源受限场景: 输入预处理 + 轻量检测
   □ 理论保证需求: 随机化平滑(认证防御)
   □ 实用优先: PGD对抗训练 + 集成

2. 多层防御
   □ 不是一个防御解决所有问题
   □ 组合: 对抗训练 + 输入处理 + 异常检测
   □ 避免依赖梯度掩蔽

3. 持续评估
   □ 定期用最新攻击测试
   □ 评估自适应攻击效果
   □ 使用AutoAttack等标准化评估工具
   □ 监控干净精度下降

4. 威胁建模
   □ 明确威胁模型(白盒/黑盒)
   □ 定义可接受的扰动范围
   □ 考虑物理世界约束
   □ 评估攻击者能力

5. 实用建议
   □ 没有银弹，每种防御都有局限
   □ 优先使用认证防御(当可行时)
   □ PGD对抗训练是经验防御的基线
   □ 集成防御可提升但非万能
   □ 检测方法应与防御结合使用
   □ 保持对最新研究的关注
```
