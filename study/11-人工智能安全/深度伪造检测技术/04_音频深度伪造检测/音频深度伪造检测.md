# 音频深度伪造检测

### 4.1 频谱分析检测

```text
音频频谱分析检测

原理:
  人类语音的频谱有特定的自然特征
  合成语音在频谱中可能留有声码器的痕迹

检测方法:

1. 频谱图分析
   ├── 计算短时傅里叶变换(STFT)
   ├── 分析频谱图特征
   ├── 合成语音: 高频可能缺失或异常
   └── 方法: CNN分类频谱图

2. 梅尔频率分析
   ├── 计算MFCC特征
   ├── 分析MFCC统计特征
   ├── 合成语音: MFCC分布异常
   └── 方法: 统计检验 + 机器学习

3. 基频分析
   ├── 人类语音基频(F0)有自然模式
   ├── 合成语音: F0轨迹可能不自然
   ├── 分析: F0轮廓 + 抖动
   └── 方法: F0统计特征分析

4. 非线性特征
   ├── 人类声带有非线性特性
   ├── 合成: 可能缺少非线性特征
   ├── 分析: 谐波结构 + 噪声
   └── 方法: 高阶统计量分析
```

```python
class AudioDeepfakeDetector:
    """音频深度伪造检测器"""

    def __init__(self, sample_rate=16000):
        self.sample_rate = sample_rate

    def detect(self, audio):
        """
        检测音频是否为深度伪造
        :param audio: 音频信号 (numpy array)
        :return: 检测结果
        """
        results = {
            'spectral': self._analyze_spectrum(audio),
            'mfcc': self._analyze_mfcc(audio),
            'pitch': self._analyze_pitch(audio)
        }

        scores = [r['score'] for r in results.values() if 'score' in r]
        avg_score = sum(scores) / len(scores) if scores else 0.5

        return {
            'is_fake': avg_score > 0.5,
            'confidence': avg_score,
            'details': results
        }

    def _analyze_spectrum(self, audio):
        """频谱分析"""
        # 计算STFT
        from scipy.signal import spectrogram
        f, t, Sxx = spectrogram(audio, fs=self.sample_rate,
                                nperseg=512, noverlap=256)

        # 分析高频能量
        high_freq_mask = f > 4000  # 4kHz以上
        high_freq_energy = np.mean(Sxx[high_freq_mask, :])

        # 高低频比
        low_freq_mask = f < 4000
        low_freq_energy = np.mean(Sxx[low_freq_mask, :])
        freq_ratio = high_freq_energy / (low_freq_energy + 1e-10)

        # 合成语音高频能量通常偏低
        score = max(0, min(1, 0.5 - freq_ratio))

        return {
            'score': score,
            'high_freq_ratio': freq_ratio,
            'details': '频谱高频能量分析'
        }

    def _analyze_mfcc(self, audio):
        """MFCC分析"""
        try:
            import librosa
            # 计算MFCC
            mfcc = librosa.feature.mfcc(
                y=audio.astype(np.float32),
                sr=self.sample_rate,
                n_mfcc=20
            )

            # 分析MFCC统计特征
            mfcc_mean = np.mean(mfcc, axis=1)
            mfcc_std = np.std(mfcc, axis=1)

            # 合成语音的MFCC方差可能偏小
            avg_std = np.mean(mfcc_std)
            score = max(0, min(1, 0.5 - avg_std * 0.01))

            return {
                'score': score,
                'mfcc_std': avg_std,
                'details': 'MFCC统计特征'
            }
        except ImportError:
            return {'score': 0.5, 'details': 'librosa未安装'}

    def _analyze_pitch(self, audio):
        """基频分析"""
        try:
            import librosa
            # 提取基频
            f0, voiced_flag, _ = librosa.pyin(
                audio.astype(np.float32),
                fmin=50, fmax=400,
                sr=self.sample_rate
            )

            # 分析基频模式
            voiced_f0 = f0[voiced_flag > 0]
            if len(voiced_f0) > 0:
                f0_mean = np.mean(voiced_f0)
                f0_std = np.std(voiced_f0)
                f0_jitter = np.mean(np.abs(np.diff(voiced_f0)))

                # 自然语音的基频抖动
                # 合成语音可能过于平滑
                jitter_score = max(0, min(1, 1 - f0_jitter / 10))

                return {
                    'score': jitter_score,
                    'f0_mean': f0_mean,
                    'f0_jitter': f0_jitter,
                    'details': '基频抖动分析'
                }
        except Exception:
            pass

        return {'score': 0.5, 'details': '基频分析失败'}
```

### 4.2 声码器伪影检测

```text
声码器伪影检测

声码器(Vocoder):
  将声学特征转换为音频波形的模型
  常见: WaveNet, HiFi-GAN, Parallel WaveGAN

声码器伪影:
├── 高频伪影: 声码器生成的高频可能不自然
├── 谐波伪影: 谐波结构可能不完整
├── 噪声伪影: 背景噪声模式异常
├── 相位伪影: 相位连续性可能被破坏
└── 时序伪影: 帧间连续性可能异常

检测策略:
├── 针对特定声码器训练检测器
├── 分析声码器特有的频域模式
├── 检测相位连续性
└── 多声码器联合检测
```
