# 多模态检测

### 5.1 音视频一致性检测

```text
音视频一致性检测

原理:
  真实视频中音频和视频是同步采集的
  深度伪造可能只篡改视频或音频，导致不一致

检测维度:

1. 唇形-音频同步
   ├── 真实: 唇形运动与语音内容同步
   ├── 伪造: 唇形可能不匹配音频
   └── 检测: 唇语识别 + 音频分析

2. 面部运动-音频能量
   ├── 真实: 说话时面部运动与音频能量相关
   ├── 伪造: 可能存在延迟或不相关
   └── 检测: 运动能量相关性分析

3. 环境声音-场景一致性
   ├── 真实: 音频环境声与视频场景一致
   ├── 伪造: 可能不匹配
   └── 检测: 场景识别 + 声音分类

4. 混响一致性
   ├── 真实: 音频混响与视频空间一致
   ├── 伪造: 可能不一致
   └── 检测: 混响特征分析
```

### 5.2 融合检测架构

```text
多模态融合检测架构

输入: 视频文件
  │
  ├── 视频帧 → 图像检测器 → 分数1
  │
  ├── 视频序列 → 时序检测器 → 分数2
  │
  ├── 音频 → 音频检测器 → 分数3
  │
  └── 音视频对齐 → 一致性检测 → 分数4
         │
         ▼
  融合决策模块 → 最终判断: 真实/伪造

融合策略:
├── 早期融合: 原始特征拼接
├── 中期融合: 中间特征融合
└── 晚期融合: 各检测器分数加权
```

```python
class MultimodalDetector:
    """多模态融合检测器"""

    def __init__(self):
        self.image_detector = FrequencyDomainDetector()
        self.temporal_detector = TemporalConsistencyDetector()
        self.audio_detector = AudioDeepfakeDetector()

        # 融合权重
        self.weights = {
            'image': 0.25,
            'temporal': 0.35,
            'audio': 0.25,
            'consistency': 0.15
        }

    def detect(self, video_frames, audio):
        """
        多模态检测
        :param video_frames: 视频帧序列
        :param audio: 音频信号
        :return: 综合检测结果
        """
        results = {}

        # 1. 图像检测（取关键帧）
        key_frame = video_frames[0] if len(video_frames) > 0 else None
        if key_frame is not None:
            results['image'] = self.image_detector.detect(key_frame)

        # 2. 时序检测
        results['temporal'] = self.temporal_detector.detect(video_frames)

        # 3. 音频检测
        if audio is not None:
            results['audio'] = self.audio_detector.detect(audio)

        # 4. 一致性检测
        results['consistency'] = self._check_av_consistency(
            video_frames, audio
        )

        # 加权融合
        total_score = 0
        total_weight = 0
        for key, result in results.items():
            score = result.get('confidence', 0.5)
            weight = self.weights.get(key, 0)
            total_score += score * weight
            total_weight += weight

        final_score = total_score / total_weight if total_weight > 0 else 0.5

        return {
            'is_fake': final_score > 0.5,
            'confidence': final_score,
            'individual_results': results,
            'fusion_weights': self.weights
        }

    def _check_av_consistency(self, frames, audio):
        """音视频一致性检查"""
        # 简化: 检查音视频长度一致性
        if audio is not None and len(frames) > 0:
            # 计算视频时长和音频时长
            video_duration = len(frames) / 30.0  # 假设30fps
            audio_duration = len(audio) / 16000.0  # 假设16kHz

            duration_diff = abs(video_duration - audio_duration)
            score = max(0, min(1, duration_diff / video_duration))

            return {
                'score': score,
                'duration_diff': duration_diff,
                'details': '音视频时长一致性'
            }

        return {'score': 0.5, 'details': '无法检查一致性'}
```
