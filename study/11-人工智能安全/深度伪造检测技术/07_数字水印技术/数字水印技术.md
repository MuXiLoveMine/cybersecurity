# 数字水印技术

### 6.1 内容真实性水印

```text
内容真实性水印

目的:
  在真实媒体中嵌入不可见水印
  用于验证内容是否被篡改

水印类型:
├── 鲁棒水印: 抗压缩/裁剪/滤波等处理
│   └── 用于版权保护和来源验证
├── 脆弱水印: 对任何修改敏感
│   └── 用于完整性验证
└── 半脆弱水印: 抗常规处理但对恶意篡改敏感
    └── 用于深度伪造检测

应用场景:
├── 新闻媒体: 嵌入来源水印 → 验证真实性
├── 司法取证: 嵌入采集水印 → 防篡改
├── 社交媒体: 平台水印 → 标识AI生成
└── 个人内容: 个人水印 → 版权保护

标准:
├── C2PA (Content Provenance & Authenticity)
│   ├── 内容来源和真实性标准
│   ├── 嵌入创建者信息和编辑历史
│   └── 支持图像/视频/音频
├── JPEG XS水印
└── 各平台自有水印方案
```

### 6.2 深度伪造水印

```text
深度伪造水印

策略1: 生成端水印
  深度伪造工具 → 生成内容时自动嵌入水印
  → 检测端提取水印 → 标识为AI生成
  问题: 恶意用户可能使用不开源工具绕过

策略2: 主动检测水印
  检测器在分析时嵌入不可见标记
  → 跟踪检测历史
  问题: 不影响内容真实性

策略3: 数字签名
  内容创建者 → 用私钥签名
  → 接收者用公钥验证
  → 签名验证失败 → 可能被篡改
  问题: 需要PKI基础设施

C2PA实施:
  创建者 → 签名内容 + 添加元数据 → C2PA清单
  编辑者 → 添加编辑操作到清单
  消费者 → 验证C2PA签名 → 确认来源和修改历史
```
