# AI 安全领域分类

### 3.1 AI 自身安全（AI Security）

**定义**：保护 AI 系统本身免受攻击、操纵和滥用，确保 AI 系统的机密性、完整性和可用性。

#### 3.1.1 模型安全

| 威胁类型 | 说明 | 典型攻击 |
|---------|------|---------|
| 对抗样本攻击 | 通过微小扰动使模型输出错误 | FGSM、PGD、C&W、提示注入 |
| 数据投毒攻击 | 污染训练数据影响模型行为 | 标签翻转、后门攻击、干净标签投毒 |
| 模型窃取攻击 | 通过查询重建模型功能 | 基于决策/分数/梯度的窃取 |
| 模型逆向攻击 | 从模型反推训练数据 | 全连接层逆向、生成模型辅助逆向 |
| 后门攻击 | 植入触发器触发恶意行为 | BadNets、Trojan Attack、语义后门 |

#### 3.1.2 数据安全

| 威胁类型 | 说明 | 典型场景 |
|---------|------|---------|
| 训练数据泄露 | 训练数据被非法获取 | 模型记忆敏感信息 |
| 成员推断 | 判断样本是否在训练集中 | 医疗数据、金融数据隐私 |
| 属性推断 | 推断训练数据的属性信息 | 推断数据集的性别比例等 |
| 数据投毒 | 恶意数据注入训练集 | 后门植入、模型操控 |

#### 3.1.3 系统安全

| 威胁类型 | 说明 | 典型场景 |
|---------|------|---------|
| API 安全 | 模型 API 接口被攻击 | 暴力破解、速率限制绕过 |
| 拒绝服务 | 耗尽计算资源使服务不可用 | 构造高计算量的输入 |
| 供应链攻击 | 模型/组件被植入恶意代码 | 预训练模型投毒、恶意插件 |
| 权限绕过 | 未授权访问模型或数据 | 水平/垂直权限绕过 |

### 3.2 AI 赋能安全（AI for Security）

**定义**：利用人工智能技术提升网络安全防护能力，包括威胁检测、异常发现、自动化响应等。

#### 3.2.1 威胁检测

**应用场景：**
1. **入侵检测系统（IDS/IPS）**
   - 使用 ML 检测异常网络流量
   - 识别零日攻击和未知威胁
   - 降低误报率

2. **恶意软件检测**
   - 基于行为的恶意软件识别
   - 未知恶意软件家族检测
   - 恶意代码变种识别

3. **钓鱼邮件检测**
   - 文本内容分析
   - 发件人行为分析
   - 链接和附件安全分析

4. **欺诈检测**
   - 交易异常检测
   - 用户行为画像
   - 实时风险评估

**案例：** 某银行使用基于深度学习的欺诈检测系统，将欺诈检测准确率从 85% 提升到 95%，误报率降低 60%。

#### 3.2.2 安全运营

**应用场景：**
1. **告警分析与降噪**
   - 自动关联分析海量告警
   - 识别真正的高风险告警
   - 降低安全分析师工作量

2. **安全事件响应**
   - 自动生成事件调查报告
   - 推荐响应措施
   - 自动化执行响应动作

3. **威胁狩猎**
   - 主动发现潜伏威胁
   - 异常行为模式识别
   - 威胁情报关联分析

4. **漏洞管理**
   - 自动化漏洞发现和验证
   - 漏洞优先级评估
   - 补丁管理优化

#### 3.2.3 内容安全

**应用场景：**
1. **不良内容检测**
   - 涉黄、涉暴、涉政内容识别
   - 多模态内容审核（文本、图像、视频）
   - 敏感信息过滤

2. **深度伪造检测**
   - AI 生成图像/视频识别
   - 声音克隆检测
   - 数字水印验证

3. **垃圾信息过滤**
   - 垃圾短信/邮件过滤
   - 恶意评论检测
   - 水军识别

### 3.3 AI 伦理与治理（AI Ethics & Governance）

**定义**：确保 AI 技术的发展和应用符合伦理规范和法律法规，促进 AI 健康可持续发展。

#### 3.3.1 AI 伦理核心问题

1. **公平性（Fairness）**
   - 避免算法偏见和歧视
   - 确保不同群体获得公平对待
   - 性别、种族、年龄等维度的公平

2. **透明度（Transparency）**
   - 算法决策过程可理解
   - 数据使用透明
   - 模型行为可解释

3. **可解释性（Explainability）**
   - 解释模型为什么做出某个决策
   - 可解释 AI（XAI）技术
   - 关键领域（医疗、金融、司法）的需求

4. **问责制（Accountability）**
   - 明确 AI 决策的责任主体
   - 建立追溯和审计机制
   - 错误决策的纠正机制

5. **隐私保护（Privacy）**
   - 个人数据保护
   - 数据最小化原则
   - 用户知情权和控制权

6. **人类控制权（Human Agency）**
   - 人类对 AI 系统的最终控制权
   - 关键决策需要人类参与
   - 避免 AI 自主做出重要决策

#### 3.3.2 AI 治理框架

**治理层级：**
1. **国际层面**：国际准则、标准制定
2. **国家层面**：法律法规、监管政策
3. **行业层面**：行业标准、自律规范
4. **企业层面**：内部治理、合规管理
5. **个人层面**：数字素养、权益保护

**治理工具：**
- 风险评估与管理
- 合规审计
- 伦理审查
- 安全认证
- 信息披露
- 公众参与
