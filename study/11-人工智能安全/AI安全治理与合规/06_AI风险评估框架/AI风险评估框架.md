├── 数据泄露风险

### 6.2 风险评估方法

```text
AI风险评估方法

定性评估:
├── 风险矩阵法: 概率 × 影响
├── DELPHI法: 专家共识
├── 情景分析: 假设场景评估
└── 检查表法: 风险清单核查

定量评估:
├── 概率模型: 统计风险概率
├── 影响建模: 量化风险影响
├── 蒙特卡洛模拟: 概率分布分析
└── 成本效益分析: 风险/收益权衡

AI特有评估:
├── 鲁棒性测试: 对抗攻击下的表现
├── 公平性审计: 不同群体表现差异
├── 隐私评估: 信息泄露风险
├── 可解释性评估: 决策透明度
├── 安全测试: 攻击面分析
└── 社会影响评估: 宏观影响分析

评估流程:
1. 确定评估范围
2. 识别风险源
3. 分析风险概率和影响
4. 评估现有控制措施
5. 确定残余风险
6. 制定风险处理计划
7. 持续监控和更新
```

### 6.3 风险缓解策略

```text
AI风险缓解策略矩阵

风险类型    │ 缓解策略                        │ 优先级
─────────┼──────────────────────────────┼──────
对抗攻击    │ 对抗训练+认证防御+检测           │ 高
数据投毒    │ 数据验证+异常检测+联邦学习       │ 高
模型窃取    │ 查询限制+水印+差分隐私          │ 中
算法偏见    │ 数据审计+公平性约束+后处理       │ 高
隐私泄露    │ 差分隐私+联邦学习+数据脱敏       │ 高
安全漏洞    │ 安全编码+渗透测试+监控          │ 高
合规风险    │ 合规评估+算法备案+定期审计      │ 高
社会风险    │ 影响评估+利益相关方参与+透明度  │ 中
```
