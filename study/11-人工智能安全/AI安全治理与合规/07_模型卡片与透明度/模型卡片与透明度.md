# 模型卡片与透明度

### 7.1 模型卡片规范

**模型卡片（Model Card）** 由Google提出，是AI模型的标准文档，类似于食品营养标签。

```text
模型卡片标准内容

1. 模型概述
   ├── 模型名称和版本
   ├── 模型类型（分类/生成/回归等）
   ├── 开发机构
   ├── 发布日期
   └── 许可证

2. 模型描述
   ├── 设计目标
   ├── 预期用途
   ├── 不适用场景
   ├── 架构描述
   └── 输入输出格式

3. 训练数据
   ├── 数据来源
   ├── 数据规模
   ├── 数据标注方法
   ├── 数据分布描述
   ├── 已知偏见
   └── 数据处理流程

4. 评估方法
   ├── 评估指标
   ├── 评估数据集
   ├── 评估协议
   └── 基线对比

5. 评估结果
   ├── 整体性能
   ├── 分组性能（按性别/年龄/种族等）
   ├── 公平性指标
   ├── 鲁棒性指标
   └── 局限性分析

6. 伦理和社会影响
   ├── 潜在影响
   ├── 风险评估
   ├── 缓解措施
   └── 申诉机制

7. 使用建议
   ├── 推荐使用场景
   ├── 不推荐场景
   ├── 部署注意事项
   └── 监控建议

8. 维护信息
   ├── 更新历史
   ├── 已知问题
   ├── 联系方式
   └── 反馈渠道
```

class ModelCard:
    """AI模型卡片"""

    def __init__(self, model_name, version, developer):
        self.model_name = model_name
        self.version = version
        self.developer = developer
        self.sections = {}

    def add_overview(self, model_type, description, license):
        """添加模型概述"""
        self.sections['overview'] = {
            'name': self.model_name,
            'version': self.version,
            'developer': self.developer,
            'type': model_type,
            'description': description,
            'license': license,
            'date': '2026-09-13'
        }

    def add_training_data(self, source, size, distribution, biases):
        """添加训练数据信息"""
        self.sections['training_data'] = {
            'source': source,
            'size': size,
            'distribution': distribution,
            'known_biases': biases,
            'annotation_method': '人工标注 + 自动标注验证'
        }

    def add_evaluation(self, metrics, results, fairness):
        """添加评估结果"""
        self.sections['evaluation'] = {
            'metrics': metrics,
            'results': results,
            'fairness_analysis': fairness
        }

    def add_intended_use(self, primary_uses, out_of_scope):
        """添加预期用途"""
