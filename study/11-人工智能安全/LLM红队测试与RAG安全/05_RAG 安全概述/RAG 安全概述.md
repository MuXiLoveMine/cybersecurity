# RAG 安全概述

### 5.1 RAG 架构

RAG（Retrieval-Augmented Generation）通过检索外部知识库增强 LLM 生成，减少幻觉并提供最新信息。

```text
用户提问
   |
   v
[1. 查询向量化] --Embedding-->
   |
   v
[2. 向量检索] --从知识库检索 Top-K 文档-->
   |
   v
[3. 提示构造] --将检索结果拼入提示-->
   |
   v
[4. LLM 生成] --基于检索内容回答-->
   |
   v
最终回答
```

### 5.2 RAG 安全挑战

| 挑战 | 说明 |
| --- | --- |
| 知识库投毒 | 知识库被注入恶意文档 |
| 检索劫持 | 攻击者操纵检索结果 |
| 注入检索 | 知识库文档中藏有提示注入 |
| 数据泄露 | 检索暴露不应公开的内容 |
| 访问控制缺失 | 用户检索到无权访问的文档 |
| 检索质量攻击 | 干扰检索导致错误回答 |
