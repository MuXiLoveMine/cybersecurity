# 安全最佳实践

### 11.1 模型层

1. 使用经过充分安全对齐的模型
2. 持续进行 RLHF / Constitutional AI 训练
3. 定期运行红队测试框架（PyRIT / Garak）
4. 跟踪安全评估基准表现
5. 多模型投票降低单一漏洞

### 11.2 应用层

1. 系统提示加固，明确安全边界
2. 输入过滤（规则 + 语义 + 长度限制）
3. 输出审查（有害 / 幻觉 / 隐私）
4. 用户输入与检索内容明确隔离
5. 工具调用审批与范围限制
6. 速率限制防止滥用

### 11.3 RAG 层

1. 知识库文档上传审批与扫描
2. 检索结果注入检测
3. 文档级访问控制（ACL）
4. 检索内容与用户输入隔离标记
5. 事实性校验（NLI 模型）
6. 检索内容完整性校验

### 11.4 运营层

1. 全链路日志审计
2. 安全指标监测与告警
3. 用户反馈快速响应机制
4. 定期红队演练
5. 模型更新回归测试
6. 应急响应预案

### 11.5 架构层

1. 零信任：不信任任何输入（用户 / 检索 / 插件）
2. 纵深防御：多层独立过滤
3. 最小权限：工具与数据最小访问范围
4. 可观测优先：全链路可见可审计
5. 快速回滚：发现问题时可快速回退
