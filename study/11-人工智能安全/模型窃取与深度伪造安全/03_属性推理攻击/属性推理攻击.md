# 属性推理攻击

### 3.1 攻击原理

**属性推理攻击（Property Inference Attack）** 推断训练数据的全局属性（元属性），而非单个样本的成员关系。

```text
攻击目标示例:
- 训练数据中男女比例是多少？
- 训练数据是否包含特定种族的样本？
- 训练数据的地理分布特征？
- 训练数据是否包含某年龄段的人群？
```

**攻击方法：** 与成员推理类似，但关注模型参数/输出中体现的群体级统计特征。攻击者训练影子模型（一些在具有特定属性的数据上训练，一些在不具有该属性的数据上训练），然后训练攻击模型区分这两类模型的参数。

### 3.2 防御方案

| 防御方法 | 说明 |
|---------|------|
| 差分隐私 | 对训练过程施加 DP 噪声，掩盖群体属性 |
| 数据均衡 | 确保训练数据在敏感属性上均衡分布 |
| 模型参数不公开 | 不发布模型权重，仅提供 API 接口 |
| 正则化 | 降低过拟合，减少参数中的属性信息 |
