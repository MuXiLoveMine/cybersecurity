# 成员推理攻击

### 2.1 攻击原理

**成员推理攻击（Membership Inference Attack, MIA）** 判断某个特定样本是否曾参与模型训练。这会泄露训练数据的隐私信息。

```text
场景示例:
- 某医院训练了疾病预测模型
- 攻击者查询模型对某患者数据的预测置信度
- 如果置信度异常高 → 推断该患者数据在训练集中 → 泄露了患病信息
```

**影子模型方法（Shadow Model Approach）：**

```text
步骤:
1. 攻击者训练多个"影子模型"
   - 影子模型 In: 在数据 D_in 上训练
   - 影子模型 Out: 不在数据 D_out 上训练
2. 对每个训练样本收集影子模型的输出概率
   - In 样本 → 影子模型给出高置信度
   - Out 样本 → 影子模型给出低置信度
3. 训练一个"攻击模型"（二分类器）
   输入: 目标模型的输出概率
   输出: 该样本是否在训练集中（In / Out）
4. 对目标模型使用攻击模型进行推理
```

```text
+--------+     D_in      +---------+
| 数据集 | ──────────→   | 影子模型 |
|        |               |  (In)   |
|        | ←──────────   +---------+
|        |  输出概率        |
|        |               +---------+
|        | ──────────→   | 影子模型 |
|        |  D_out         |  (Out)  |
+--------+               +---------+
     |
     | 标注: In=1, Out=0
     v
+----------+  目标模型输出  +----------+
| 攻击模型 | ←─────────── | 目标模型 |
| (二分类) |               | (黑盒)   |
+----------+               +----------+
     |
     v
  成员判定: 训练集 / 非训练集
```

### 2.2 防御方案

| 防御方法 | 原理 | 效果 |
|---------|------|------|
| 差分隐私训练 | DP-SGD 在梯度中加噪声 | 强隐私保证，但降低模型精度 |
| 知识蒸馏 | 用大模型蒸馏小模型，降低过拟合 | 间接降低 MIA 成功率 |
| 置信度扰动 | 对返回概率加噪声 | 降低攻击模型判别力 |
| 输出截断 | 只返回 Top-1 标签 | 减少信息泄露 |
| 正则化 | 使用 L2/dropout 降低过拟合 | 模型对训练集不再"过于自信" |

**为什么过拟合使 MIA 更容易成功：**
- 过拟合的模型对训练样本给出异常高的置信度
- 训练集和非训练集的置信度差异显著
- 攻击模型容易学到这种差异
