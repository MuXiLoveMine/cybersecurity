# 模型窃取攻击

### 1.1 模型提取攻击原理

**模型提取攻击（Model Extraction Attack）** 是指攻击者通过不断查询目标模型的 API，收集输入-输出对，然后训练一个"窃取模型"来近似复现目标模型的功能。

```text
攻击流程:
+----------+     查询 x_i     +----------+
|  攻击者  | ──────────────→  | 目标模型 |
|          | ←──────────────  |  (黑盒)  |
+----------+   返回 f(x_i)    +----------+
      |
      | 收集 (x_i, f(x_i)) 数据集
      v
+----------+
| 训练窃取  |
| 模型 g(x) |  →  g ≈ f，功能近似
+----------+
```

**攻击动机：**
- 免费使用付费 API（规避计费）
- 获取商业模型知识产权
- 作为中间步骤发起后续攻击（对抗样本迁移）

**攻击分类：**

| 类型 | 攻击者能力 | 说明 |
|------|-----------|------|
| 完全提取 | 获取概率向量 | 最强攻击，可完全复现 |
| 部分提取 | 获取 Top-k 预测 | 只复制部分功能 |
| 决策提取 | 仅获取分类标签 | 最弱场景，难度最大 |

### 1.2 基于查询的提取（知识蒸馏）

将目标模型视为"教师模型"，窃取模型为"学生模型"，通过知识蒸馏进行提取。

```text
步骤:
1. 生成查询数据集 X_query（随机采样 / 对抗生成 / 数据增强）
2. 查询目标模型: Y_soft = f_target(X_query)  获取软标签
3. 训练窃取模型: min_θ KL(Y_soft || g_θ(X_query))
4. 迭代优化：用窃取模型不确定的样本继续查询（主动学习）
```

**软标签 vs 硬标签：**

| 信息类型 | 获取内容 | 提取效果 |
|---------|---------|---------|
| 硬标签 | argmax(f(x)) | 较差，需要更多查询 |
| 软标签 | f(x) 完整概率分布 | 较好，含"暗知识" |
| 温度软标签 | f(x) / T | 最好，信息量最大 |

### 1.3 主动学习策略加速提取

**核心思想：** 不是随机查询，而是选择窃取模型最"不确定"的样本进行查询，以最小查询次数最大化信息增益。

```text
主动学习策略:
1. 不确定性采样: 选择 g(x) 熵最大的 x
2. 边界采样: 选择 g(x) 中 Top-2 概率最接近的 x
3. 对抗生成: 生成位于决策边界附近的 x
4. 多样性采样: 保证查询数据覆盖整个输入空间
```

### 1.4 防御方案

| 防御方法 | 原理 | 效果 |
|---------|------|------|
| 查询审计 | 监控异常查询模式（频率/分布） | 检测提取行为 |
| 水印 | 在模型中嵌入后门作为版权标记 | 事后取证 |
| 输出扰动 | 对返回的概率加噪声 | 降低提取精度 |
| 置信度截断 | 只返回 Top-k 而非完整概率 | 减少信息泄露 |
| 查询限制 | 限制单用户查询频率和总量 | 提高攻击成本 |
| 伪响应 | 检测到攻击时返回错误结果 | 主动欺骗 |

**水印防御示例思路：**
```text
1. 训练时选择一组"水印密钥"输入 K = {k_1, ..., k_m}
2. 为每个密钥指定目标标签: f(k_i) = y_i^target
3. 正常训练 + 水印损失: L = L_task + λ * L_watermark
4. 怀疑被窃取时: 用密钥查询窃取模型，若匹配则为盗版
```
