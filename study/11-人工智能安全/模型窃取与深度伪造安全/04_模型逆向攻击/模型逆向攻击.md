# 模型逆向攻击

### 4.1 攻击原理

**模型逆向攻击（Model Inversion）** 从模型的输出反推输入数据，重建训练样本的敏感信息。

```text
场景: 人脸识别模型
- 攻击者知道某人的身份标签 y
- 通过反复优化输入 x，使 f(x) = y
- 重建出该人的面部图像
```

#### 4.1.1 梯度泄露（Gradient Leakage）

在联邦学习中，客户端向服务器上传梯度。攻击者可以从梯度逆向重建客户端的训练数据。

```text
攻击流程:
1. 服务器收到客户端上传的梯度 g = ∇L(f(x; θ), y)
2. 攻击者初始化虚拟数据 (x', y')
3. 计算虚拟梯度 g' = ∇L(f(x'; θ), y')
4. 优化: min_{x', y'} ||g' - g||²
5. 当 g' ≈ g 时，x' 重建了真实训练数据 x
```

#### 4.1.2 Deep Leakage by Gradient (DLG)

DLG 是经典的梯度泄露攻击方法，同时优化输入和标签，使虚拟梯度匹配真实梯度。

```text
DLG 优化目标:
min_{x', y'} ||∇_θ L(f(x'; θ), y') - g||²

步骤:
1. 随机初始化 (x', y')
2. 前向传播计算损失 L(f(x'; θ), y')
3. 反向传播得到虚拟梯度 g'
4. 计算 ||g' - g||² 并对 (x', y') 求导
5. 梯度下降更新 (x', y')
6. 重复直到收敛
```

### 4.2 防御方案

| 防御方法 | 原理 | 说明 |
|---------|------|------|
| 梯度压缩 | 只上传部分梯度分量 | 减少信息泄露 |
| 梯度噪声 | 在梯度中注入噪声 | 扰乱重建优化 |
| 梯度量化 | 将梯度量化到低精度 | 降低重建质量 |
| 安全聚合 | 多个客户端梯度先加密聚合再上传 | 服务器看不到单端梯度 |
| 差分隐私 | DP-SGD 加噪梯度 | 有理论保证 |
