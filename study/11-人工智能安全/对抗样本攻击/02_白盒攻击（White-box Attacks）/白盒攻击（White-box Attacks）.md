# 白盒攻击（White-box Attacks）

**白盒攻击**：攻击者完全了解目标模型的内部结构，包括：
- 模型架构
- 权重参数
- 梯度信息
- 训练数据分布（可能）

白盒攻击是最强的攻击假设，攻击效果通常最好。

---

### 2.1 FGSM（Fast Gradient Sign Method）

#### 2.1.1 基本原理

**提出者**：Ian Goodfellow 等（2015）

**核心思想**：沿着损失函数梯度上升的方向，一步添加最大的扰动，使损失最大化。

**数学公式：**

```
x' = x + ε * sign(∇_x J(x, y_true))
```

其中：
- `x` 是原始输入
- `ε` 是扰动幅度（越大攻击性越强，但越容易被察觉）
- `sign(·)` 是符号函数（正数取 1，负数取 -1，零取 0）
- `∇_x J(x, y_true)` 是损失函数对输入的梯度
- `J(·)` 是损失函数（通常是交叉熵损失）

**直观理解：**
- 计算损失函数对每个像素的梯度
- 对梯度取符号（只关心方向，不关心大小）
- 乘以 ε，一步到位地添加扰动

#### 2.1.2 算法步骤

```
输入：原始样本 x，真实标签 y，模型 f，损失函数 J，扰动幅度 ε
输出：对抗样本 x'

1. 计算损失函数对输入的梯度：
   g = ∇_x J(f(x), y)

2. 生成对抗样本：
   x' = x + ε * sign(g)

3. 裁剪到合法范围（如图像的 [0, 1]）：
   x' = clip(x', 0, 1)

返回 x'
```

#### 2.1.3 特点与优缺点

**优点：**
- 计算速度极快（一次前向+反向传播）
- 实现简单
- 是很多其他攻击方法的基础

**缺点：**
- 攻击强度有限，可能无法达到 100% 攻击成功率
- 只考虑梯度方向，不考虑梯度大小
- 一步到位，不是最优扰动

**适用场景：**
- 快速生成大规模对抗样本
- 对抗训练（用于生成训练数据）
- 作为基线攻击方法

#### 2.1.4 目标攻击版本

目标攻击的 FGSM 变体，使模型分类到指定目标类别：

```
x' = x - ε * sign(∇_x J(x, y_target))
```

沿着梯度下降的方向（最小化目标类别的损失），使模型将样本分类为目标类别。

### 2.2 BIM / PGD（迭代方法）

#### 2.2.1 BIM（Basic Iterative Method）

**核心思想**：FGSM 的迭代版本，每次走一小步，迭代多次，效果更好。

**数学公式：**

```
x₀' = x
x_{t+1}' = clip_ε(x_t' + α * sign(∇_x J(x_t', y_true)))
```

其中：
- `α` 是每一步的步长（通常 α < ε）
- `clip_ε` 表示将扰动裁剪到 [-ε, ε] 范围内
- 迭代次数通常为 10-100 次

**与 FGSM 的关系：**
- 当迭代次数为 1 且 α = ε 时，BIM 退化为 FGSM
- BIM 通常比 FGSM 攻击效果好得多

#### 2.2.2 PGD（Projected Gradient Descent）

**核心思想**：BIM 的增强版本，加入了随机初始化，是最常用的强白盒攻击方法之一。

**改进点：**
1. **随机初始化**：在 ε-ball 内随机采样初始点，避免陷入局部最优
2. **迭代优化**：与 BIM 类似的迭代过程
3. **投影操作**：每步后投影回 ε-ball 内

**算法步骤：**

```
输入：原始样本 x，真实标签 y，模型 f，损失函数 J，扰动幅度 ε，步长 α，迭代次数 T
输出：对抗样本 x'

1. 随机初始化：
   x₀' = x + δ，其中 δ ~ Uniform(-ε, ε)
   x₀' = clip(x₀', 0, 1)

2. 迭代优化（重复 T 次）：
   对于 t = 0 到 T-1：
       g = ∇_x J(f(x_t'), y)
       x_{t+1}' = x_t' + α * sign(g)
       x_{t+1}' = clip(x_{t+1}', x - ε, x + ε)  // 投影到 ε-ball
       x_{t+1}' = clip(x_{t+1}', 0, 1)        // 裁剪到合法范围

3. 返回 x_T'
```

**目标攻击版本：**
```
x_{t+1}' = x_t' - α * sign(∇_x J(x_t', y_target))
```

#### 2.2.3 PGD 的重要性

- **强攻击基线**：被广泛用作评估模型鲁棒性的标准攻击方法
- **对抗训练**：PGD 对抗训练是最经典的对抗训练方法
- **一阶攻击的上限**：在只使用一阶梯度信息的攻击中，PGD 接近最优

**参数选择经验：**
- **ε**：根据任务确定，图像分类常用 8/255 ≈ 0.031
- **α**：通常取 ε/10 ~ ε/4
- **迭代次数 T**：通常 10-100 次，次数越多效果越好但计算越慢

### 2.3 DeepFool

#### 2.3.1 基本原理

**提出者**：Moosavi-Dezfooli 等（2016）

**核心思想**：通过迭代地将样本向最近的决策边界移动，找到最小的扰动。

**特点：**
- 生成的扰动更小（L2 范数最小化）
- 迭代次数通常较少（10 次左右即可收敛）
- 基于几何直觉：找到样本到决策边界的最短距离

#### 2.3.2 算法思想

对于二分类问题，决策边界是 `f(x) = 0`：
- 样本点 x 到决策边界的距离为 `|f(x)| / ||∇f(x)||₂`
- 最小扰动方向是梯度方向的反方向

对于多分类问题：
- 计算样本到每个类别的决策边界的距离
- 选择最近的边界移动
- 迭代直到分类改变

```
算法步骤（简化版）：
1. 对于当前样本 x，计算每个类别的输出 f_k(x) 和梯度 ∇f_k(x)
2. 计算到每个类别的决策边界的近似距离
3. 选择最近的类别 k*，计算需要的最小扰动
4. 更新 x = x + δ
5. 重复直到分类改变或达到最大迭代次数
```

#### 2.3.3 特点

**优点：**
- 生成的扰动通常比 FGSM/BIM 更小
- 收敛速度快
- 基于几何直观，解释性强

**缺点：**
- 计算比 FGSM 复杂
- 主要是 L2 范数下的攻击
- 可能陷入局部最优

### 2.4 C&W 攻击（Carlini & Wagner）

#### 2.4.1 基本原理

**提出者**：Nicholas Carlini 和 David Wagner（2017）

**核心思想**：将对抗样本生成问题转化为优化问题，使用更复杂的优化方法找到最小扰动。

**地位**：被认为是最强的白盒攻击之一，经常用来"破解"各种防御方法。

#### 2.4.2 优化公式

**目标函数（L2 范数版本）：**

```
最小化：||δ||₂² + c * f(x + δ)

约束：x + δ ∈ [0, 1]^n
```

其中 `f(·)` 是目标函数，定义为：

```
非目标攻击：
f(x') = max(max_{i≠y} Z(x')_i - Z(x')_y, -κ)

目标攻击：
f(x') = max(Z(x')_t - max_{i≠t} Z(x')_i, -κ)
```

- `Z(x')` 是模型的 logits 输出（softmax 之前的值）
- `y` 是真实标签，`t` 是目标标签
- `κ` 是置信度参数，控制对抗样本的置信度
- `c` 是平衡扰动大小和攻击成功的权重参数

#### 2.4.3 优化技巧

1. **变量替换**：
   - 将 `x'` 表示为 `(tanh(w) + 1) / 2`，确保输出在 [0, 1] 范围内
   - 这样优化 w 而不是 x'，避免约束优化

2. **Adam 优化器**：
   - 使用 Adam 而不是简单的梯度下降
   - 收敛更快，效果更好

3. **二分搜索 c**：
   - c 控制扰动大小和攻击成功的权衡
   - 用二分搜索找到合适的 c 值

#### 2.4.4 特点

**优点：**
- 攻击能力极强，是目前最强的攻击之一
- 可以生成非常小的扰动
- 支持 L0、L2、L∞ 多种范数
- 可以控制攻击的置信度

**缺点：**
- 计算量大，速度慢
- 实现复杂
- 需要调整多个超参数

**重要意义：**
- 很多声称"鲁棒"的防御方法都被 C&W 攻击攻破
- 是评估防御方法有效性的重要基准
- 推动了对抗防御研究的发展

### 2.5 其他白盒攻击方法

#### 2.5.1 JSMA（Jacobian-based Saliency Map Attack）

**特点：**
- 基于雅可比矩阵的显著性图攻击
- 主要针对 L0 范数（修改最少的特征）
- 常用于图像和文本分类

**原理：**
- 计算输出对输入的雅可比矩阵
- 构建显著性图，找出对输出影响最大的输入特征
- 迭代修改最重要的特征

#### 2.5.2 动量迭代攻击（Momentum Iterative FGSM）

**特点：**
- 在 BIM 的基础上加入动量
- 提高了对抗样本的迁移性
- 常用于黑盒迁移攻击

**核心改进：**
```
g_{t+1} = μ * g_t + ∇_x J(x_t', y) / ||∇_x J(x_t', y)||₁
x_{t+1}' = x_t' + ε * sign(g_{t+1})
```

其中 `μ` 是动量系数。

#### 2.5.3 AutoAttack

**特点：**
- 不是单一攻击，而是多种攻击的组合
- 自动调整参数
- 是目前评估鲁棒性的标准基准之一

**组成：**
- APGD-CE（自适应 PGD + 交叉熵损失）
- APGD-DLR（自适应 PGD + DLR 损失）
- FAB（快速自适应边界攻击）
- 方形攻击（Square Attack）
