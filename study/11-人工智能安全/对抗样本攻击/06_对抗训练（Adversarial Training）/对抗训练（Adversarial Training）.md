# 对抗训练（Adversarial Training）

### 6.1 对抗训练基础

#### 6.1.1 基本思想

**核心思想**：在训练过程中加入对抗样本，让模型学习对对抗样本也能正确分类。

这是目前最有效、最主流的对抗防御方法。

#### 6.1.2 标准对抗训练

**目标函数（Min-Max 优化）：**

```
min_θ E_{(x,y)~D} [max_{||δ||≤ε} L(f_θ(x + δ), y)]
```

解释：
- **内部最大化**：对于每个样本，找到最强的对抗扰动（使损失最大）
- **外部最小化**：优化模型参数，使对抗样本上的损失最小

#### 6.1.3 训练过程

```
对于每个训练批次 (x, y):
    1. 使用当前模型生成对抗样本：
       x_adv = PGD(x, y, θ, ε, α, T)
    
    2. 在对抗样本上计算损失：
       loss = L(f_θ(x_adv), y)
    
    3. 反向传播更新模型参数：
       θ = θ - η * ∇_θ loss
```

**关键点：**
- 每个训练步都需要生成对抗样本
- 通常使用 PGD 作为内部最大化的攻击方法
- 训练比普通训练慢得多（因为每步要多次迭代生成对抗样本）

### 6.2 PGD 对抗训练

#### 6.2.1 标准实现

**最经典的对抗训练方法**：Madry 等（2018）提出的 PGD 对抗训练。

**设置：**
- 攻击方法：PGD（10 步迭代）
- 范数约束：L∞
- ε = 8/255（对于图像）
- α = 2/255
- 数据集：CIFAR-10、ImageNet 等

**效果：**
- 显著提高模型的鲁棒性
- 在 PGD 攻击下准确率从 ~10% 提升到 ~40-50%
- 但干净样本的准确率会下降（鲁棒性与准确性的权衡）

#### 6.2.2 鲁棒性与准确性的权衡

**现象**：对抗训练后的模型：
- 对抗鲁棒性提高了
- 但干净样本的准确率降低了
- 这被称为"鲁棒性代价"（Robustness Cost）

**可能的原因：**
- 模型容量有限，无法同时兼顾干净样本和对抗样本
- 鲁棒特征和非鲁棒特征是不同的
- 对抗训练改变了模型学习的特征类型

**研究方向**：如何在保持干净准确率的同时提高鲁棒性。

### 6.3 对抗训练的改进方法

#### 6.3.1 TRADES

**全称**：Theoretically Principled Trade-off between Robustness and Accuracy

**核心思想**：将对抗训练的目标分解为干净样本损失和对抗正则项。

**目标函数：**
```
min_θ E_{x,y} [ L(f(x), y) + λ * max_{||δ||≤ε} L(f(x+δ), f(x)) ]
```

- 第一项：干净样本的分类损失（保证准确率）
- 第二项：对抗正则项（保证鲁棒性，使对抗样本的输出接近干净样本的输出）
- λ：平衡参数

**优势**：
- 更好地平衡了鲁棒性和准确性
- 有理论依据

#### 6.3.2 MART

**全称**：Misclassification Aware Adversarial Training

**核心思想**：对分类错误的样本给予更高的权重，重点关注难样本。

#### 6.3.3 其他改进

1. **加速对抗训练**
   - 减少内部迭代次数
   - 使用更快的攻击方法
   - 自由对抗训练（Free AT）

2. **数据增强结合**
   - 对抗训练 + 数据增强
   - AutoAugment + 对抗训练

3. **模型结构优化**
   - 研究更适合对抗训练的网络结构
   - 宽度 vs 深度对鲁棒性的影响

4. **自监督预训练 + 对抗微调**
   - 先用自监督学习预训练
   - 再用对抗训练微调

---

### 6.4 对抗训练的局限

1. **计算成本高**
   - 比普通训练慢几倍到几十倍
   - 需要更多 GPU 资源

2. **过度拟合特定攻击**
   - 用 PGD 训练的模型，对 PGD 防御好
   - 但对其他类型的攻击可能防御效果差
   - 例如：对 L2 攻击、空间变换攻击的鲁棒性提升有限

3. "**鲁棒过拟合**"
   - 训练过程中，训练集上的鲁棒准确率持续上升
   - 但测试集上的鲁棒准确率可能先升后降
   - 类似于过拟合，但发生在鲁棒准确率上

4. **对强攻击的防御仍然有限**
   - 即使经过对抗训练，面对最强的攻击，鲁棒准确率仍然不高
   - 在 ImageNet 上，最先进的对抗训练也只能达到 60% 左右的鲁棒准确率
