# 对抗样本概念与原理

### 1.1 什么是对抗样本

**对抗样本（Adversarial Example）** 是指在原始样本上添加精心设计的微小扰动，使得机器学习模型产生错误输出，而这些扰动对人类来说几乎不可察觉。

**核心特征：**
1. **微小扰动**：扰动幅度很小，人眼/人耳难以察觉
2. **针对性强**：能够导致模型产生特定的错误输出
3. **迁移性**：一个模型的对抗样本可能对其他模型也有效
4. **泛化性**：同一攻击方法适用于多种模型架构

**直观示例：**
```
原始图片（熊猫） + 微小扰动 = 对抗样本（看起来还是熊猫，但模型识别为长臂猿）

置信度: 57.7% 熊猫  →  99.3% 长臂猿
```

### 1.2 对抗样本的数学表示

**形式化定义：**

给定一个分类器模型 `f(x) = y`，其中：
- `x` 是原始输入样本
- `y` 是正确的分类标签

寻找一个对抗样本 `x'`，满足：
```
f(x') ≠ y （或 f(x') = y_target 针对目标攻击）
且 ||x' - x|| ≤ ε （扰动约束）
```

其中 `||·||` 是范数（通常是 L∞、L2 或 L0 范数），`ε` 是最大允许扰动幅度。

**范数约束类型：**

| 范数类型 | 公式 | 含义 | 特点 |
|---------|------|------|------|
| L0 范数 | ||δ||₀ = count(δᵢ ≠ 0) | 非零元素的个数 | 修改最少的像素 |
| L2 范数 | ||δ||₂ = √(Σδᵢ²) | 欧几里得距离 | 扰动的总能量限制 |
| L∞ 范数 | ||δ||∞ = max(|δᵢ|) | 最大绝对扰动 | 每个像素的变化不超过 ε |

**攻击类型分类：**

| 类型 | 目标 | 说明 |
|------|------|------|
| 非目标攻击（Untargeted） | 只要分类错误即可 | 最简单的攻击形式 |
| 目标攻击（Targeted） | 分类到指定类别 | 更难，需要更多优化 |

### 1.3 对抗样本存在的原因

#### 1.3.1 线性视角解释

**核心观点**：高维空间中的线性行为导致了对抗样本的存在。

在高维空间中，即使每个维度的扰动很小，累积起来也会产生显著影响：

```
w^T * x' = w^T * (x + δ) = w^T * x + w^T * δ

当维度 n 很大时，即使每个 δᵢ 很小，w^T * δ = Σwᵢδᵢ 也可能很大
```

对于 ReLU 激活函数的神经网络，在局部区域内近似线性，这解释了为什么对抗样本容易生成。

#### 1.3.2 流形视角解释

**核心观点**：模型的决策边界在数据流形之外的区域是脆弱的。

- 训练数据分布在一个低维流形（Manifold）上
- 模型在训练数据附近表现良好
- 但在流形之外的区域，决策边界可能非常"扭曲"
- 对抗样本就在流形附近但跨越了决策边界

#### 1.3.3 其他解释理论

1. **过拟合假说**：模型过拟合训练数据，缺乏泛化能力
2. **不充分正则化**：模型太容易被小扰动影响
3. **非线性特性**：深度网络的非线性导致了脆弱性
4. **梯度掩码**：某些防御只是隐藏了梯度，并未真正增强鲁棒性
