# 黑盒攻击（Black-box Attacks）

**黑盒攻击**：攻击者只能查询模型的输入输出，不知道模型的内部结构和参数。

更接近真实世界的攻击场景，因为大多数 AI 服务只提供 API 接口。

**黑盒攻击分类：**

| 类型 | 攻击者能获取的信息 | 难度 |
|------|-------------------|------|
| 分数黑盒（Score-based） | 各类别的置信度/概率 | 中等 |
| 决策黑盒（Decision-based） | 只有最终分类结果 | 困难 |
| 迁移攻击（Transfer-based） | 完全不查询目标模型 | 较易 |

---

### 3.1 基于迁移的攻击（Transfer-based Attacks）

#### 3.1.1 基本原理

**核心思想**：对抗样本具有迁移性（Transferability），即针对一个模型生成的对抗样本，对另一个不同架构甚至不同训练数据的模型也可能有效。

**攻击流程：**

```
1. 收集与目标模型相似领域的训练数据
2. 训练一个"替代模型"（Substitute Model）
3. 使用白盒攻击方法在替代模型上生成对抗样本
4. 将对抗样本用于攻击目标模型
```

#### 3.1.2 迁移性原理

**为什么对抗样本可以迁移？**

1. **相似的数据分布**：如果模型在相似的数据上训练，学到的特征也相似
2. **决策边界的相似性**：不同模型可能在某些区域具有相似的决策边界
3. **线性近似**：在局部区域，不同模型的行为可能都近似线性
4. **特征空间的相似性**：相似的任务会学到相似的特征表示

#### 3.1.3 提高迁移性的方法

1. **集成攻击**：同时对多个模型生成对抗样本，迁移性更好
2. **动量迭代**：如 MI-FGSM，加入动量可以提高迁移性
3. **输入多样性**：对输入进行随机变换后再生成对抗样本
4. **中间层攻击**：攻击中间层特征而不是最终输出

**集成攻击公式：**
```
g = ∑_i w_i * ∇_x J_i(x, y)
x' = x + ε * sign(g)
```

其中 `J_i` 是第 i 个模型的损失，`w_i` 是权重。

#### 3.1.4 实际案例

**案例**：攻击者想要攻击某公司的图像识别 API（只能获取分类结果）。

1. 收集该领域的公开数据集
2. 训练一个自己的 CNN 模型作为替代模型
3. 用 FGSM/PGD 在替代模型上生成对抗样本
4. 将这些对抗样本提交给目标 API
5. 约 60-80% 的对抗样本也能攻击成功

### 3.2 基于查询的攻击（Query-based Attacks）

#### 3.2.1 分数攻击（Score-based）

攻击者可以获取模型输出的各类别概率/置信度。

**代表性方法：**

1. **ZOO（Zeroth Order Optimization）**
   - 使用零阶优化方法估计梯度
   - 通过查询两个接近的点来估计梯度：`∂f/∂x_i ≈ (f(x + he_i) - f(x - he_i)) / (2h)`
   - 然后用估计的梯度进行类似 PGD 的攻击
   - 查询复杂度：O(n) 每步，n 是输入维度

2. **NES（Natural Evolution Strategies）**
   - 使用进化策略估计梯度
   - 采样多个随机方向，根据函数值加权估计梯度
   - 查询复杂度：O(k) 每步，k 是采样数（通常远小于 n）

#### 3.2.2 决策攻击（Decision-based）

攻击者只能获取模型的最终决策（分类结果），无法获取概率分数。这是最困难的黑盒攻击场景。

**代表性方法：**

**HopSkipJumpAttack（HSJA）**

**核心思想**：从决策边界附近的点出发，沿着边界移动，逐渐接近原始样本。

**算法步骤：**

```
1. 初始化：找到一个初始的对抗样本（可以是随机生成的）
2. 边界搜索：在原始样本和对抗样本之间，找到决策边界上的点
3. 边界移动：沿着决策边界移动，寻找更接近原始样本的对抗点
4. 迭代优化：重复边界搜索和移动
```

**特点：**
- 不需要梯度信息
- 只需要分类结果
- 查询效率较高
- 可以生成 L2 和 L∞ 约束下的对抗样本

**Boundary Attack**

- 类似 HSJA 的早期方法
- 从一个大扰动的对抗样本开始，逐渐减小扰动
- 每步随机采样方向，如果仍然是对抗样本就接受

### 3.3 文本领域的黑盒攻击

文本领域的对抗样本与图像领域有很大不同：
- 文本是离散的，不能直接添加连续扰动
- 替换一个词可能改变语义
- 需要保证语法正确性和语义连贯性

**常见方法：**

1. **同义词替换**
   - 将句子中的词替换为同义词
   - 保持语义不变但改变模型输出

2. **字符级扰动**
   - 插入/删除/替换字符
   - 类似于拼写错误
   - 例如："hello" → "he1lo"

3. **句子重写**
   - 用不同的方式表达相同的意思
   - 基于释义（Paraphrase）的攻击
