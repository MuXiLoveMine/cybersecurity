# 检测与防御评估

### 7.1 对抗样本检测

#### 7.1.1 检测方法分类

| 方法类别 | 原理 | 代表方法 |
|---------|------|---------|
| 基于密度/统计 | 对抗样本在特征空间中分布不同 | 核密度估计、贝叶斯不确定性 |
| 基于不确定性 | 对抗样本使模型不确定 | MC Dropout、深度集成 |
| 基于重建 | 对抗样本难以被正确重建 | 自编码器、GAN 重建 |
| 检测器分类 | 训练一个二分类器检测对抗样本 | 对抗样本检测网络 |
| 输入变换比较 | 变换前后预测差异大则可能是对抗样本 | 特征压缩、随机变换 |

#### 7.1.2 基于不确定性的检测

**MC Dropout**
- 原理：在测试时也开启 Dropout，多次前向传播
- 对抗样本的预测方差通常更大（模型更不确定）
- 根据方差大小判断是否为对抗样本

**深度集成（Deep Ensembles）**
- 训练多个不同初始化的模型
- 对抗样本在不同模型上的预测一致性更低
- 根据预测一致性判断

#### 7.1.3 基于重建的检测

**自编码器检测**
```
输入样本 → 自编码器编码 → 自解码器解码 → 重建样本
                                   ↓
                           计算重建误差
                                   ↓
                    重建误差大 → 可能是对抗样本
```

**原理**：
- 正常样本在数据流形上，可以被很好地重建
- 对抗样本在流形外，重建误差大
- 重建后的样本如果分类正确，说明是对抗样本

#### 7.1.4 检测方法的局限

- **自适应攻击**：攻击者可以知道检测方法并调整攻击策略，绕过检测
- **假阳性问题**：可能将正常样本误判为对抗样本
- **检测准确率有限**：面对强攻击时检测率不高
- **不能从根本上解决问题**：检测只是"发现"而不是"修复"

### 7.2 防御评估方法

#### 7.2.1 评估指标

1. **干净准确率（Clean Accuracy）**
   - 模型在正常样本上的准确率
   - 衡量模型的基本性能

2. **鲁棒准确率（Robust Accuracy）**
   - 模型在对抗样本上的准确率
   - 衡量模型的抗攻击能力
   - 通常需要指定具体的攻击方法和参数

3. **攻击成功率（Attack Success Rate）**
   - 对抗样本成功导致分类错误的比例
   - 从攻击角度衡量

4. **平均扰动大小**
   - 成功攻击所需的平均扰动大小
   - 扰动越小说明模型越脆弱

#### 7.2.2 评估时的注意事项

1. **白盒 vs 黑盒**
   - 白盒鲁棒性和黑盒鲁棒性可能不同
   - 需要分别评估

2. **多种攻击方法**
   - 不能只在一种攻击下评估
   - 至少包括：FGSM、PGD、C&W、决策攻击等
   - 不同范数约束（L0、L2、L∞）

3. **自适应攻击（Adaptive Attack）**
   - 攻击者知道防御方法并进行调整
   - 这是最公平、最严格的评估方式
   - 很多防御在自适应攻击下失效

4. **可复现性**
   - 详细记录攻击参数
   - 提供代码和配置
   - 便于其他人复现和验证

#### 7.2.3 常见的评估陷阱

1. **只测试弱攻击**
   - 只测 FGSM，不测 PGD 和 C&W
   - 结果过于乐观

2. **不做自适应攻击评估**
   - 攻击者不知道防御方法的评估是不公平的
   - 实际中攻击者会研究和绕过防御

3. **混淆梯度掩码和真正的鲁棒性**
   - 防御蒸馏就是典型例子
   - 白盒攻击看似失效，但黑盒攻击可以绕过

4. **在训练数据上评估**
   - 模型可能记住了训练数据
   - 必须在测试集上评估

### 7.3 鲁棒基准（Robustness Benchmarks）

**常用数据集与基准：**

| 基准 | 数据集 | 模型 | 约束 |
|------|--------|------|------|
| MNIST | 手写数字 | 简单 CNN | L∞ ε=0.3 |
| CIFAR-10 | 小图像分类 | ResNet 等 | L∞ ε=8/255 |
| CIFAR-100 | 细粒度分类 | ResNet 等 | L∞ ε=8/255 |
| ImageNet | 大规模图像 | ResNet 等 | L∞ ε=4/255 |

**著名的鲁棒性竞赛/排行榜：**
- RobustBench（https://robustbench.github.io/）
- 每年的 NeurIPS 对抗竞赛
