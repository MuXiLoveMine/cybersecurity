# 后量子密钥交换

### 10.1 量子计算对密钥交换的威胁

```
Shor算法威胁:
  - 可以在多项式时间内求解离散对数
  - DH/ECDH完全不安全
  - RSA也不安全
  
Grover算法威胁:
  - 对称密钥安全减半
  - AES-256 → 128位安全（仍安全）
  
后量子密钥交换方向:
  1. 格基密码（Lattice-based）
  2. 编码密码（Code-based）
  3. 多变量密码（Multivariate）
  4. 哈希密码（Hash-based）
  5. 等同密码（Isogeny-based）
```

### 10.2 格基密钥交换

**CRYSTALS-Kyber** 是NIST后量子标准化的密钥封装机制（KEM）。

```
Kyber特点:
  类型: 格基密码（Module-LWE）
  密钥尺寸: ~800字节（公钥）
  密文尺寸: ~700字节
  安全等级: 128位（Kyber-512）/ 192位（Kyber-768）
  
Kyber流程:
  1. Alice生成密钥对(pk, sk)
  2. Alice发送pk给Bob
  3. Bob加密随机密钥: (c, K) = Encaps(pk)
  4. Bob发送c给Alice
  5. Alice解密: K = Decaps(sk, c)
  6. 双方共享密钥K
```

### 10.3 混合密钥交换

```
混合密钥交换（传统+后量子）:

  1. 执行ECDH密钥交换 → 共享密钥K1
  2. 执行后量子密钥交换 → 共享密钥K2
  3. 组合: K = KDF(K1 || K2)
  
  优势:
    - 如果量子计算未成熟: ECDH提供安全
    - 如果后量子算法有缺陷: ECDH提供安全
    - 两者都安全时: 双重保障
  
  TLS中的实现:
    TLS 1.3混合密钥交换:
      key_share包含ECDH公钥 + 后量子公钥
```

```python
"""
混合密钥交换概念实现
"""
from cryptography.hazmat.primitives.asymmetric import x25519
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
import os

class HybridKeyExchange:
    """混合密钥交换（ECDH + 后量子概念）"""
    
    @staticmethod
    def key_exchange() -> dict:
        """
        混合密钥交换
        
        ECDH（X25519） + 模拟后量子
        """
        # === ECDH部分 ===
        alice_ecdh_priv = x25519.X25519PrivateKey.generate()
        alice_ecdh_pub = alice_ecdh_priv.public_key()
        
        bob_ecdh_priv = x25519.X25519PrivateKey.generate()
        bob_ecdh_pub = bob_ecdh_priv.public_key()
        
        ecdh_shared_alice = alice_ecdh_priv.exchange(bob_ecdh_pub)
        ecdh_shared_bob = bob_ecdh_priv.exchange(alice_ecdh_pub)
        
        assert ecdh_shared_alice == ecdh_shared_bob
        
        # === 后量子部分（模拟） ===
        # 实际使用如Kyber等后量子算法
        # 这里用随机数模拟
        pq_shared_alice = os.urandom(32)
        pq_shared_bob = pq_shared_alice  # 模拟双方得到相同密钥
        
        # === 组合密钥 ===
        combined_alice = ecdh_shared_alice + pq_shared_alice
        combined_bob = ecdh_shared_bob + pq_shared_bob
        
        final_key_alice = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'hybrid-key-exchange'
        ).derive(combined_alice)
        
        final_key_bob = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'hybrid-key-exchange'
        ).derive(combined_bob)
        
        return {
            'alice_key': final_key_alice,
            'bob_key': final_key_bob,
            'match': final_key_alice == final_key_bob,
            'ecdh_key_size': len(ecdh_shared_alice),
            'pq_key_size': len(pq_shared_alice),
        }


# 演示
result = HybridKeyExchange.key_exchange()
print("=" * 60)
print("混合密钥交换演示")
print("=" * 60)
print(f"ECDH密钥大小: {result['ecdh_key_size']} bytes")
print(f"后量子密钥大小: {result['pq_key_size']} bytes")
print(f"密钥匹配: {result['match']}")
print(f"最终密钥: {result['alice_key'].hex()[:24]}...")
```
