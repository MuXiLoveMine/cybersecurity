# 量子密钥分发（QKD）

### 9.1 QKD概述

**量子密钥分发（Quantum Key Distribution）** 利用量子力学原理实现信息论安全的密钥交换。

```
QKD核心原理:
  1. 量子不可克隆定理: 无法完美复制未知量子态
  2. 测量塌缩: 测量会改变量子态
  3. 量子纠缠: 纠缠态的非局域关联性

安全模型:
  计算安全: DH/ECDH依赖数学难题
  信息论安全: QKD不依赖计算假设
```

### 9.2 BB84协议

**BB84协议** 是最著名的QKD协议，由Bennett和Brassard于1984年提出。

```
BB84协议流程:

  1. 量子传输:
     Alice随机选择比特(0/1)和基(+或×)
     发送对应偏振的光子给Bob
     
     |基|比特|光子偏振|
     |---|---|---------|
     | + | 0 | →       |
     | + | 1 | ↑       |
     | × | 0 | ↗       |
     | × | 1 | ↖       |
  
  2. 测量:
     Bob随机选择基(+或×)测量每个光子
     如果基选对了 → 结果正确
     如果基选错了 → 结果随机
  
  3. 基比对:
     Alice和Bob通过公开信道比对基的选择
     保留基相同的比特，丢弃基不同的比特
     
  4. 误码率检测:
     比对部分比特，检查误码率
     如果误码率过高 → 可能被窃听 → 丢弃
      
  5. 隐私放大:
     对剩余比特进行后处理
     提取出最终的安全密钥

  窃听检测:
    Eve如果窃听 → 必须测量光子 → 改变量子态
    → Bob测量错误率升高 → 被发现
```

### 9.3 QKD实际应用

```
QKD应用场景:
  1. 金融专线: 银行间安全通信
  2. 政府通信: 机密信息传输
  3. 军事通信: 高安全等级通信
  4. 数据中心互联: 数据中心间加密

QKD网络:
  量子密钥网络（QKN）:
    - 北京-上海量子干线
    - 武汉量子通信网
    - 合肥量子通信网
  
  QKD设备:
    - 光纤QKD: 基于光纤传输
    - 自由空间QKD: 基于卫星传输
    - 量子随机数生成器（QRNG）
```
