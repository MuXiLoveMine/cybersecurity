# 组密钥交换协议

### 8.1 组密钥交换概述

**组密钥交换（Group Key Exchange）** 允许多个参与方协商出一个共享的组密钥。

```
组密钥交换场景:
  - 视频会议加密
  - 群聊消息加密
  - 多方安全计算
  - 传感器网络
```

### 8.2 Burmester-Desmedt协议

**Burmester-Desmedt（BD）协议** 是经典的组密钥交换协议。

```
BD协议（n个参与方P1, P2, ..., Pn）:

  轮1: 每个Pi选择随机ri，广播zi = g^ri
  
  轮2: 每个Pi计算并广播Xi:
    Xi = (z(i+1) / z(i-1))^ri mod p
    
  密钥计算:
    Ki = z(i-1)^(n*ri) * Xi^(n-1) * X(i+1)^(n-2) * ... * X(i-2)
    
    所有Ki相等: K = g^(r1*r2 + r2*r3 + ... + rn*r1) mod p
```

### 8.3 树形组密钥管理

```
树形密钥管理（Logical Key Hierarchy）:

  使用树结构管理组成员关系
  
       [根密钥K]
       /        \
    [K1]        [K2]
    /  \        /  \
  [k1] [k2]  [k3] [k4]
   P1   P2    P3   P4
  
  当P3离开时:
    1. K3和K2需要更新
    2. 新K3用K4加密发给P4
    3. 新K2用新K3加密发给P4
    4. 新K2用K1加密发给P1,P2
    
  优势:
    - 成员变更效率高 O(log n)
    - 前向安全（离开成员无法解密新消息）
    - 后向安全（新成员无法解密旧消息）
```
