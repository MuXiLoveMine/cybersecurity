## 一、密钥交换概述

### 1.1 什么是密钥交换

**密钥交换（Key Exchange）** 是指两个或多个参与方通过公开信道协商出共享密钥的过程，即使攻击者监听了全部通信内容，也无法获得协商出的密钥。

```
密钥交换的基本场景：

  Alice                        Bob
    │                           │
    │ ←── 公开信道（被监听）───→ │
    │                           │
    │     交换公开参数            │
    │ ←──────────────────────→ │
    │                           │
    │ ←── 秘密计算 ──→          │
    │     各自计算共享密钥         │
    │                           │
    │     共享密钥K（相同）        │
    │     K = ??? = ???          │
    
  攻击者Eve可以监听所有通信
  但无法计算出共享密钥K
```

### 1.2 密钥交换的分类

```

│                  密钥交换协议分类                          │
├──────────────┬───────────────────────────────────────────┤

├──────────────┼───────────────────────────────────────────┤
```

| 前向安全性（PFS） | 即使长期密钥泄露，过去的会话密钥仍然安全 |

## 二、Diffie-Hellman密钥交换

### 2.1 DH密钥交换原理

**Diffie-Hellman（DH）密钥交换** 是世界上第一个公钥密码协议，由Whitfield Diffie和Martin Hellman于1976年提出。

**数学基础：离散对数问题（DLP）**

```
DH密钥交换原理:

  公开参数:
    p: 大素数
    g: 模p的本原根（生成元）
    
  Alice:
    1. 选择随机私钥 a ∈ [1, p-1]
    2. 计算公钥 A = g^a mod p
    3. 发送 A 给 Bob
    
  Bob:
    1. 选择随机私钥 b ∈ [1, p-1]
    2. 计算公钥 B = g^b mod p
    3. 发送 B 给 Alice
    
  共享密钥计算:
    Alice: K = B^a mod p = (g^b)^a mod p = g^(ab) mod p
    Bob:   K = A^b mod p = (g^a)^b mod p = g^(ab) mod p
    
  两者计算结果相同: K = g^(ab) mod p

攻击者Eve可以看到: p, g, A, B
  要计算K，需要知道a或b
  即从g^a mod p求a（离散对数问题）
  这是数学上公认的困难问题
```

### 2.2 DH的安全参数

| 参数 | 最小推荐值 | 说明 |
|------|----------|------|
| p（模数） | 2048位 | 等效112位安全 |
| p（模数） | 3072位 | 等效128位安全 |
| g（生成元） | 2 | 最常用的生成元 |
| 私钥长度 | ≥224位 | 随机数 |

**安全素数选择：**
```
安全素数: p = 2q + 1，其中q也是素数

选择安全素数的原因：
  1. 防止小子群攻击
  2. 确保离散对数的困难性
  
验证方法:
  1. p是素数
  2. q = (p-1)/2是素数
  3. g生成大子群
```

### 2.3 DH实现

```python
import os
import random

class DiffieHellman:
    """Diffie-Hellman密钥交换"""
    
    # RFC 3526推荐的参数（MODP Group 14, 2048位）
    P = int(
        "FFFFFFFFFFFFFFFFC90FDAA22168C234C4C6628B80DC1CD1"
        "29024E088A67CC74020BBEA63B139B22514A08798E3404DD"
        "EF9519B3CD3A431B302B0A6DF25F14374FE1356D6D51C245"
        "E485B576625E7EC6F44C42E9A637ED6B0BFF5CB6F406B7ED"
        "EE386BFB5A899FA5AE9F24117C4B1FE649286651ECE45B3D"
        "C2007CB8A163BF0598DA48361C55D39A69163FA8FD24CF5F"
        "83655D23DCA3AD961C62F356208552BB9ED529077096966D"
        "670C354E4ABCED0BC976BE5FC8A9C4E9A4E5B7A1E5B7A1E5"
        "B7A1E5B7A1E5B7A1E5B7A1E5B7A1E5B7A1E5B7A1E5B7A1"
        "E5B7A1E5B7A1E5B7A1E5B7A1", 16
    )
    
    G = 2
    
    def __init__(self):
        self.private_key = None
        self.public_key = None
        self.shared_key = None
    
    @staticmethod
    def _generate_random(bits: int) -> int:
        """生成密码学安全随机数"""
        return int.from_bytes(os.urandom(bits // 8), 'big')
    
    def generate_keypair(self, bits: int = 256):
        """生成密钥对"""
        # 选择随机私钥
        self.private_key = self._generate_random(bits)
        # 确保私钥在有效范围内
        self.private_key %= (self.P - 1)
        if self.private_key < 2:
            self.private_key = 2
        
        # 计算公钥 A = g^a mod p
        self.public_key = pow(self.G, self.private_key, self.P)
        
        return self.public_key
    
    def compute_shared_key(self, other_public_key: int) -> bytes:
        """计算共享密钥"""
        # 验证对方公钥
        if other_public_key < 2 or other_public_key >= self.P:
            raise ValueError("无效的公钥")
        
        # 计算共享密钥 K = B^a mod p
        shared = pow(other_public_key, self.private_key, self.P)
        
        # 转换为字节
        shared_bytes = shared.to_bytes(
            (shared.bit_length() + 7) // 8, 'big'
        )
        
        # 密钥派生（使用哈希）
        import hashlib
        self.shared_key = hashlib.sha256(shared_bytes).digest()
        
        return self.shared_key
    
    def get_public_key(self) -> int:
        """获取公钥"""
        return self.public_key
    
    def get_shared_key(self) -> bytes:
        """获取共享密钥"""
        return self.shared_key


# 使用示例
print("=" * 60)
print("Diffie-Hellman密钥交换演示")
print("=" * 60)

# Alice
alice = DiffieHellman()
alice.generate_keypair()
print(f"Alice公钥: {hex(alice.get_public_key())[:40]}...")

# Bob
bob = DiffieHellman()
bob.generate_keypair()
print(f"Bob公钥: {hex(bob.get_public_key())[:40]}...")

# 交换公钥并计算共享密钥
alice_shared = alice.compute_shared_key(bob.get_public_key())
bob_shared = bob.compute_shared_key(alice.get_public_key())

print(f"\nAlice共享密钥: {alice_shared.hex()[:32]}...")
print(f"Bob共享密钥:   {bob_shared.hex()[:32]}...")
print(f"密钥匹配: {alice_shared == bob_shared}")

# 使用共享密钥加密通信
from cryptography.hazmat.primitives.ciphers import (
    Cipher, algorithms, modes
)
from cryptography.hazmat.primitives import padding

key = alice_shared[:16]  # 使用前16字节作为AES密钥
iv = os.urandom(16)

# Alice加密消息
cipher = Cipher(algorithms.AES(key), modes.CBC(iv))
encryptor = cipher.encryptor()
padder = padding.PKCS7(128).padder()
plaintext = b"Hello from Alice via DH key exchange!"
padded = padder.update(plaintext) + padder.finalize()
ciphertext = encryptor.update(padded) + encryptor.finalize()

print(f"\n加密消息: {ciphertext.hex()[:48]}...")

# Bob解密消息
cipher = Cipher(algorithms.AES(key), modes.CBC(iv))
decryptor = cipher.decryptor()
unpadder = padding.PKCS7(128).unpadder()
decrypted_padded = decryptor.update(ciphertext) + decryptor.finalize()
decrypted = unpadder.update(decrypted_padded) + unpadder.finalize()

print(f"解密消息: {decrypted.decode()}")
```

### 2.4 DH的安全问题

#### 2.4.1 中间人攻击

```
无认证的DH密钥交换容易受到中间人攻击:

  Alice ←→ Mallory ←→ Bob
  
  1. Alice发送A给"Bob"（实际发给Mallory）
  2. Mallory截获A，生成自己的M1，发送M1给Bob
  3. Bob发送B给"Alice"（实际发给Mallory）
  4. Mallory截获B，生成自己的M2，发送M2给Alice
  
  结果:
    Alice和Mallory共享密钥K1
    Mallory和Bob共享密钥K2
    Alice和Bob之间没有真正的共享密钥
    
  Mallory可以:
    - 解密Alice的消息，重新加密发给Bob
    - 解密Bob的消息，重新加密发给Alice
    - 双方都以为在直接通信

防护:
  1. 使用数字签名认证交换消息（STS协议）
  2. 使用证书验证对方身份
  3. 使用预共享密钥认证
  4. 使用带认证的密钥交换协议（如TLS）
```

#### 2.4.2 小子群攻击

```
小子群攻击:

  如果p-1有小因子，攻击者可以利用小子群
    
  防护:
  1. 使用安全素数 p = 2q + 1
  2. 验证公钥的阶足够大
  3. 使用RFC 7919推荐的参数组
  4. 验证 1 < A < p-1
```

### 2.5 有限域DH vs 椭圆曲线DH

| 特性 | 有限域DH (FFDH) | 椭圆曲线DH (ECDH) |
|------|----------------|-------------------|
| 数学基础 | 离散对数 | 椭圆曲线离散对数 |
| 密钥长度 | 2048位 | 256位 |
| 安全强度 | 112位 | 128位 |
| 计算效率 | 较慢 | 更快 |
| 带宽消耗 | 大 | 小 |
| 标准化 | RFC 3526等 | RFC 7748等 |

## 三、ECDH椭圆曲线密钥交换

### 3.1 ECDH原理

**ECDH（Elliptic Curve Diffie-Hellman）** 是DH密钥交换在椭圆曲线上的实现。

```
ECDH密钥交换原理:

  公开参数:
    椭圆曲线: y² = x³ + ax + b (mod p)
    基点G: 曲线上的一个点
    阶n: G的阶
    
  Alice:
    1. 选择随机私钥 dA ∈ [1, n-1]
    2. 计算公钥 QA = dA * G（标量乘法）
    3. 发送 QA 给 Bob
    
  Bob:
    1. 选择随机私钥 dB ∈ [1, n-1]
    2. 计算公钥 QB = dB * G
    3. 发送 QB 给 Alice
    
  共享密钥计算:
    Alice: S = dA * QB = dA * dB * G
    Bob:   S = dB * QA = dB * dA * G
    
    两者结果相同: S = (dA * dB) * G
    
  共享密钥 = Hash(Sx)  （S的x坐标的哈希）
```

### 3.2 ECDH实现

```python
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
import os

class ECDHKeyExchange:
    """ECDH椭圆曲线密钥交换"""
    
    # 支持的曲线
    CURVES = {
        'P-256': ec.SECP256R1(),
        'P-384': ec.SECP384R1(),
        'P-521': ec.SECP521R1(),
        'Curve25519': None,  # 特殊处理
    }
    
    def __init__(self, curve_name: str = 'P-256'):
        self.curve_name = curve_name
        self.curve = self.CURVES.get(curve_name)
        
        if self.curve is None and curve_name != 'Curve25519':
            raise ValueError(f"不支持的曲线: {curve_name}")
        
        self.private_key = None
        self.public_key = None
    
    def generate_keypair(self):
        """生成密钥对"""
        if self.curve_name == 'Curve25519':
            from cryptography.hazmat.primitives.asymmetric.x25519 import (
                X25519PrivateKey
            )
            self.private_key = X25519PrivateKey.generate()
        else:
            self.private_key = ec.generate_private_key(self.curve)
        
        self.public_key = self.private_key.public_key()
        return self.public_key
    
    def compute_shared_key(self, other_public_key, 
                          key_length: int = 32) -> bytes:
        """
        计算共享密钥
        
        Args:
            other_public_key: 对方公钥
            key_length: 派生密钥长度
            
        Returns:
            共享密钥
        """
        if self.curve_name == 'Curve25519':
            from cryptography.hazmat.primitives.asymmetric.x25519 import (
                X25519PublicKey
            )
            shared = self.private_key.exchange(other_public_key)
        else:
            shared = self.private_key.exchange(
                ec.ECDH(), other_public_key
            )
        
        # 使用HKDF派生密钥
        derived_key = HKDF(
            algorithm=hashes.SHA256(),
            length=key_length,
            salt=None,
            info=b'ecdh-shared-key'
        ).derive(shared)
        
        return derived_key
    
    def export_public_key(self) -> bytes:
        """导出公钥（原始格式）"""
        from cryptography.hazmat.primitives.serialization import (
            Encoding, PublicFormat
        )
        return self.public_key.public_bytes(
            Encoding.Raw,
            PublicFormat.Raw
        )
    
    @staticmethod
    def import_public_key(key_bytes: bytes, 
                          curve_name: str = 'P-256'):
        """导入公钥"""
        if curve_name == 'Curve25519':
            from cryptography.hazmat.primitives.asymmetric.x25519 import (
                X25519PublicKey
            )
            return X25519PublicKey.from_public_bytes(key_bytes)
        else:
            curve = ECDHKeyExchange.CURVES.get(curve_name)
            return ec.EllipticCurvePublicKey.from_encoded_point(
                curve, key_bytes
            )


# 使用示例
print("=" * 60)
print("ECDH密钥交换演示")
print("=" * 60)

# Alice (P-256)
alice = ECDHKeyExchange('P-256')
alice.generate_keypair()
alice_pub_bytes = alice.export_public_key()
print(f"Alice公钥长度: {len(alice_pub_bytes)} bytes")

# Bob (P-256)
bob = ECDHKeyExchange('P-256')
bob.generate_keypair()
bob_pub_bytes = bob.export_public_key()
print(f"Bob公钥长度: {len(bob_pub_bytes)} bytes")

# 交换公钥
alice_shared = alice.compute_shared_key(
    ECDHKeyExchange.import_public_key(bob_pub_bytes, 'P-256')
)
bob_shared = bob.compute_shared_key(
    ECDHKeyExchange.import_public_key(alice_pub_bytes, 'P-256')
)

print(f"\nAlice共享密钥: {alice_shared.hex()[:32]}...")
print(f"Bob共享密钥:   {bob_shared.hex()[:32]}...")
print(f"密钥匹配: {alice_shared == bob_shared}")

# Curve25519演示
print("\n" + "=" * 60)
print("X25519 (Curve25519) 密钥交换")
print("=" * 60)

alice_x = ECDHKeyExchange('Curve25519')
alice_x.generate_keypair()
alice_x_pub = alice_x.export_public_key()
print(f"Alice公钥长度: {len(alice_x_pub)} bytes")

bob_x = ECDHKeyExchange('Curve25519')
bob_x.generate_keypair()
bob_x_pub = bob_x.export_public_key()
print(f"Bob公钥长度: {len(bob_x_pub)} bytes")

    ECDHKeyExchange.import_public_key(bob_x_pub, 'Curve25519')

print(f"密钥匹配: {alice_x_shared == bob_x_shared}")
```

### 3.3 Curve25519与X25519

**Curve25519** 是Daniel J. Bernstein设计的椭圆曲线，**X25519**是基于Curve25519的Diffie-Hellman协议。

```
Curve25519特点:
  方程: y² = x³ + 486662x² + x (mod p)
  模数: p = 2^255 - 19
  基点: x = 9
  阶: 2^252 + 2774231777373657118437490379410580678430126887995

X25519优势:
  1. 高性能: 速度快
  2. 小密钥: 32字节公钥
  3. 安全性: 抗侧信道攻击
  4. 简单性: 实现简单，不易出错
  5. 标准化: RFC 7748
```

```python
"""
X25519原始实现（概念）
"""
import os

def curve25519_clamp_scalar(scalar: bytes) -> bytes:
    """Clamping标量（Curve25519特殊处理）"""
    s = bytearray(scalar)
    s[0] &= 248    # 清除低3位
    s[31] &= 127   # 清除最高位
    s[31] |= 64    # 设置次高位
    return bytes(s)

def x25519_keygen() -> tuple:
    """
    X25519密钥生成
    
    返回: (私钥, 公钥)
    """
    # 生成随机私钥
    private = os.urandom(32)
    private = curve25519_clamp_scalar(private)
    
    # 基点x坐标
    basepoint = bytes([9]) + bytes(31)
    
    # 计算公钥（标量乘法）
    # 实际使用cryptography库的X25519

        X25519PrivateKey, X25519PublicKey
    )
    key = X25519PrivateKey.from_private_bytes(private)

    pub_bytes = public.public_bytes(
        __import__('cryptography').hazmat.primitives.serialization.Encoding.Raw,
        __import__('cryptography').hazmat.primitives.serialization.PublicFormat.Raw
    )
    
    return private, pub_bytes

def x25519_dh(private_key: bytes, other_public: bytes) -> bytes:
    """X25519密钥交换"""
    from cryptography.hazmat.primitives.asymmetric.x25519 import (
        X25519PrivateKey, X25519PublicKey

    from cryptography.hazmat.primitives.serialization import (
        Encoding, PublicFormat
    )
    
    priv = X25519PrivateKey.from_private_bytes(private_key)
    pub = X25519PublicKey.from_public_bytes(other_public)
    
    shared = priv.exchange(pub)
    return shared
```

## 四、认证密钥交换（AKE）

### 4.1 为什么需要认证密钥交换

```
普通DH密钥交换的问题:
  - 无法确认对方身份
  - 容易受到中间人攻击
  
认证密钥交换（Authenticated Key Exchange, AKE）:
  - 在密钥交换的同时验证对方身份
  - 防止中间人攻击
  
认证方式:
  1. 数字签名（证书）
  2. 预共享密钥（PSK）
  3. 口令（密码）
```

### 4.2 STS协议（站到站）

**STS（Station-to-Station）协议** 是带数字签名认证的DH密钥交换。

```
STS协议流程:

  公开参数: p, g
  Alice: 私钥dA, 公钥QA, 证书CertA
  Bob:   私钥dB, 公钥QB, 证书CertB
  
  1. Alice → Bob:
     ┌──────────────────────────────┐
     │ A = g^a mod p                │
     │ CertA                        │
     └──────────────────────────────┘
  
  2. Bob → Alice:
     ┌──────────────────────────────┐
     │ B = g^b mod p                │
     │ CertB                        │
     │ SigB(A, B)                   │ ← Bob对(A,B)签名
     │ E_K(SigB(A, B))              │ ← 用共享密钥加密
     └──────────────────────────────┘
     Bob计算: K = A^b mod p
  
  3. Alice → Bob:
     ┌──────────────────────────────┐
     │ E_K(SigA(A, B))              │ ← Alice对(A,B)签名
     └──────────────────────────────┘
     Alice计算: K = B^a mod p
  
  验证:
    - Alice验证Bob的签名和证书
    - Bob验证Alice的签名和证书
    - 双方确认共享密钥K
```

### 4.3 MQV协议

**MQV（Menezes-Qu-Vanstone）协议** 是一种高效的认证密钥交换协议。

```
MQV协议流程:

  公开参数: 椭圆曲线参数, 基点G, 阶n
  Alice: 静态私钥dA, 静态公钥QA = dA*G
  Bob:   静态私钥dB, 静态公钥QB = dB*G
  
  1. Alice生成临时密钥对: rA, RA = rA*G
     Alice → Bob: RA
  
  2. Bob生成临时密钥对: rB, RB = rB*G
     Bob → Alice: RB
  
  3. 双方计算共享密钥:
  
     Alice计算:
       x̄A = RA的x坐标的左⌈log2(n)/2⌉位
       SA = dA + x̄A * rA (mod n)
       x̄B = RB的x坐标的左⌈log2(n)/2⌉位
       点S = h * SA * (QB + x̄B * RB)
       密钥K = KDF(Sx)
  
     Bob计算:
       x̄B = RB的x坐标
       SB = dB + x̄B * rB (mod n)
       x̄A = RA的x坐标
       点S = h * SB * (QA + x̄A * RA)
       密钥K = KDF(Sx)
  
  MQV优势:
    - 不需要数字签名
    - 计算效率高
    - 提供隐式认证
```

### 4.4 HMQV协议

**HMQV（Hashed MQV）** 是MQV的改进版本，解决了MQV的一些安全缺陷。

```
HMQV改进:
  1. 使用哈希函数替代简单截取
  2. 提供形式化安全证明
  3. 抗未知密钥共享攻击
  4. 在CK模型下可证明安全

  改进计算:
    eA = H(RA || ID_A || RB || ID_B) (mod n)  ← 哈希替代截取
    SA = dA + eA * rA (mod n)
    类似计算Bob侧
```

### 4.5 SIGMA协议

**SIGMA（SIGn-and-MAC-based Authenticated）** 是TLS使用的密钥交换框架。

```
SIGMA协议核心思想:
  1. 先进行DH密钥交换
  2. 用共享密钥派生MAC密钥
  3. 用私钥对DH公开值签名
  4. 用MAC密钥认证签名
  
  流程:
    Alice → Bob: g^x
    Bob → Alice: g^y, SigB(g^y, g^x), MAC_K(ID_B, SigB)
    Alice → Bob: SigA(g^x, g^y), MAC_K(ID_A, SigA)
    
  特点:
    - 签名保证身份不可伪造
    - MAC保证身份不被篡改
    - 密钥确认
    - TLS 1.2和1.3的基础
```

## 五、TLS密钥交换机制

### 5.1 TLS 1.2密钥交换

TLS 1.2支持多种密钥交换算法：

```
TLS 1.2密钥交换套件:

  RSA密钥交换:
    Client → Server: 用服务器RSA公钥加密预主密钥
    特点: 不提供前向安全性
    
  DHE密钥交换:
    Client ←→ Server: DH密钥交换 + 数字签名认证
    特点: 提供前向安全性
    
  ECDHE密钥交换:
    Client ←→ Server: ECDH密钥交换 + 数字签名认证
    特点: 前向安全性 + 高性能
    
  PSK密钥交换:
    基于预共享密钥的交换
    特点: 快速，但需要预共享密钥
    
  常见套件:
    TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256
    TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384
    TLS_DHE_RSA_WITH_AES_256_CBC_SHA256
```

**TLS 1.2 ECDHE-RSA握手流程：**
```
  Client                              Server
    │                                    │
    │──── ClientHello ─────────────────→│
    │     (支持的套件,曲线等)              │
    │                                    │
    │←── ServerHello ──────────────────│
    │     (选定的套件)                    │
    │←── Certificate ──────────────────│
    │     (服务器RSA证书)                 │
    │←── ServerKeyExchange ────────────│
    │     (ECDH参数+签名)                │
    │←── ServerHelloDone ──────────────│
    │                                    │
    │──── ClientKeyExchange ──────────→│
    │     (客户端ECDH公钥)               │
    │──── ChangeCipherSpec ───────────→│
    │──── Finished ────────────────────→│
    │                                    │
    │←── ChangeCipherSpec ────────────│
    │←── Finished ────────────────────│
    │                                    │
    │←──── 加密应用数据 ──────────────→│
```

### 5.2 TLS 1.3密钥交换

TLS 1.3对密钥交换进行了重大简化：

```
TLS 1.3特点:
  1. 只保留ECDHE/PSK密钥交换
  2. 移除了RSA密钥交换
  3. 所有密钥交换都提供前向安全性
  4. 支持早期数据（0-RTT）
  5. 减少了握手轮次

TLS 1.3握手流程（1-RTT）:
  Client                              Server
    │                                    │
    │──── ClientHello ─────────────────→│
    │     (key_share: 客户端ECDH公钥)    │
    │     (supported_groups)             │
    │                                    │
    │←── ServerHello ──────────────────│
    │     (key_share: 服务器ECDH公钥)    │
    │←── {EncryptedExtensions} ─────────│
    │←── {Certificate} ────────────────│
    │←── {CertificateVerify} ──────────│
    │←── {Finished} ───────────────────│
    │                                    │
    │──── {Finished} ─────────────────→│
    │                                    │
    │←──── {应用数据} ────────────────→│

  优势:
    - 密钥交换在第一个消息中就开始
    - 减少握手延迟
    - 全程前向安全
```

### 5.3 TLS密钥派生

```python
"""
TLS 1.3密钥派生过程
"""
from cryptography.hazmat.primitives import hashes, hmac
from cryptography.hazmat.primitives.kdf.hkdf import HKDF, HKDFExpand

class TLS13KeySchedule:
    """TLS 1.3密钥调度"""
    
    @staticmethod
    def hkdf_expand_label(secret: bytes, label: str, 
                          context: bytes, length: int) -> bytes:
        """TLS 1.3 HKDF-Expand-Label"""
        full_label = f"tls13 {label}".encode()
        
        # 构造HkdfLabel
        import struct
        hkdf_label = (
            struct.pack("!H", length) +  # Length
            bytes([len(full_label)]) + full_label +  # Label
            bytes([len(context)]) + context  # Context
        )
        
        return HKDFExpand(
            algorithm=hashes.SHA256(),
            length=length,
            info=hkdf_label
        ).derive(secret)
    
    @staticmethod
    def derive_handshake_keys(shared_secret: bytes, 
                              hello_messages: bytes) -> dict:
        """推导握手密钥"""
        # 早期秘密
        zero = b'\x00' * 32
        early_secret = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=None,
            info=b'\x00' * 32
        ).derive(zero)
        
        # 推导秘密
        derived_secret = TLS13KeySchedule.hkdf_expand_label(
            early_secret, "derived", b'', 32
        )
        
        # 握手秘密
        handshake_secret = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=derived_secret,
            info=shared_secret
        ).derive(b'\x00' * 32)
        
        # 客户端握手流量秘密
        client_hs_secret = TLS13KeySchedule.hkdf_expand_label(
            handshake_secret, "c hs traffic", hello_messages, 32
        )
        
        # 服务器握手流量秘密
        server_hs_secret = TLS13KeySchedule.hkdf_expand_label(
            handshake_secret, "s hs traffic", hello_messages, 32
        )
        
        # 推导密钥和IV
        client_key = TLS13KeySchedule.hkdf_expand_label(
            client_hs_secret, "key", b'', 16
        )
        server_key = TLS13KeySchedule.hkdf_expand_label(
            server_hs_secret, "key", b'', 16
        )
        client_iv = TLS13KeySchedule.hkdf_expand_label(
            client_hs_secret, "iv", b'', 12
        )
        server_iv = TLS13KeySchedule.hkdf_expand_label(
            server_hs_secret, "iv", b'', 12
        )
        
        return {
            'client_key': client_key,
            'server_key': server_key,
            'client_iv': client_iv,
            'server_iv': server_iv,
            'client_secret': client_hs_secret,
            'server_secret': server_hs_secret,
        }


# 演示
shared = os.urandom(32)  # ECDH共享密钥
transcript = b"ClientHello + ServerHello"

keys = TLS13KeySchedule.derive_handshake_keys(shared, transcript)
print("TLS 1.3 密钥派生结果:")
for k, v in keys.items():
    print(f"  {k}: {v.hex()[:24]}...")
```

## 六、Signal协议密钥交换

### 6.1 Signal协议概述

**Signal协议** 是WhatsApp、Signal等端到端加密通信应用使用的协议。它解决了即时通信中的密钥交换和消息加密问题。

**Signal协议的核心组件：**
1. **X3DH（Extended Triple Diffie-Hellman）**：初始密钥交换
2. **Double Ratchet**：前向安全消息协议
3. **XEdDSA**：签名算法

### 6.2 X3DH密钥交换

**X3DH** 是一种异步密钥交换协议，允许在接收方离线时发送加密消息。

```
X3DH参与者:
  Alice（发送方）: 
    身份密钥 IK_A
    临时密钥 EK_A
  
  Bob（接收方）:
    身份密钥 IK_B
    已签名预共享密钥 SPK_B
    一次性预共享密钥 OPK_B（可选）

X3DH流程:

  1. Alice获取Bob的预发布密钥:
     ┌──────────────────────────────────┐
     │ Bob发布到服务器:                  │
     │   - IK_B (身份公钥)              │
     │   - SPK_B (签名预共享公钥)        │
     │   - SigB(IK_B, SPK_B) (签名)    │
     │   - OPK_B (一次性预共享公钥)      │
     └──────────────────────────────────┘
  
  2. Alice验证Bob的签名
     验证 SigB 是否用 IK_B 签名了 SPK_B
  
  3. Alice生成临时密钥对 EK_A
  
  4. Alice计算共享密钥:
     DH1 = DH(IK_A, SPK_B)     身份×签名预共享
     DH2 = DH(EK_A, IK_B)     临时×身份
     DH3 = DH(EK_A, SPK_B)     临时×签名预共享
     DH4 = DH(EK_A, OPK_B)    临时×一次性预共享（可选）
     
     SK = KDF(DH1 || DH2 || DH3 || DH4)
  
  5. Alice发送初始消息:
     ┌──────────────────────────────────┐
     │ IK_A                             │
     │ EK_A                             │
     │ 用IK_A对(EK_A, IK_B)的签名       │
     │ 密文(用SK加密)                   │
     └──────────────────────────────────┘
  
  6. Bob收到消息后:
     验证Alice的签名
     计算相同的共享密钥SK
     删除一次性预共享密钥OPK_B
```

```python
"""
X3DH密钥交换概念实现
"""
from cryptography.hazmat.primitives.asymmetric import x25519
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
import os

class X3DHKeyExchange:
    """X3DH异步密钥交换"""
    
    @staticmethod
    def generate_keypair():
        """生成X25519密钥对"""
        private = x25519.X25519PrivateKey.generate()
        public = private.public_key()
        return private, public
    
    @staticmethod
    def dh(private_key, public_key) -> bytes:
        """DH计算"""
        return private_key.exchange(public_key)
    
    @staticmethod
    def kdf(shared_secret: bytes, info: bytes = b'') -> bytes:
        """密钥派生"""
        return HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'X3DH' + info
        ).derive(shared_secret)
    
    @staticmethod
    def concat_dh(*dh_values: bytes) -> bytes:
        """连接多个DH值"""
        result = b''
        for v in dh_values:
            result += v
        return result


class Bob:
    """接收方（Bob）"""
    
    def __init__(self):
        # 身份密钥对
        self.ik_priv, self.ik_pub = X3DHKeyExchange.generate_keypair()
        # 签名预共享密钥对
        self.spk_priv, self.spk_pub = X3DHKeyExchange.generate_keypair()
        # 一次性预共享密钥对
        self.opk_priv, self.opk_pub = X3DHKeyExchange.generate_keypair()
    
    def publish_keys(self) -> dict:
        """发布预共享密钥"""
        return {
            'ik_pub': self.ik_pub,
            'spk_pub': self.spk_pub,
            'opk_pub': self.opk_pub,
        }
    
    def compute_shared_key(self, alice_ik_pub, alice_ek_pub) -> bytes:
        """计算共享密钥"""
        # DH1 = DH(IK_B, SPK_B对应的... 实际是 DH(IK_B, EK_A)的方向)
        # 在实际X3DH中:
        # DH1 = DH(IK_A, SPK_B) → Bob用SPK私钥
        dh1 = X3DHKeyExchange.dh(self.spk_priv, alice_ik_pub)
        # DH2 = DH(EK_A, IK_B) → Bob用IK私钥
        dh2 = X3DHKeyExchange.dh(self.ik_priv, alice_ek_pub)
        # DH3 = DH(EK_A, SPK_B) → Bob用SPK私钥
        dh3 = X3DHKeyExchange.dh(self.spk_priv, alice_ek_pub)
        # DH4 = DH(EK_A, OPK_B) → Bob用OPK私钥
        dh4 = X3DHKeyExchange.dh(self.opk_priv, alice_ek_pub)
        
        combined = X3DHKeyExchange.concat_dh(dh1, dh2, dh3, dh4)
        sk = X3DHKeyExchange.kdf(combined)
        
        # 删除一次性预共享密钥
        self.opk_priv = None
        
        return sk


class Alice:
    """发送方（Alice）"""
    
    def __init__(self):
        # 身份密钥对
        self.ik_priv, self.ik_pub = X3DHKeyExchange.generate_keypair()
        # 临时密钥对
        self.ek_priv, self.ek_pub = X3DHKeyExchange.generate_keypair()
    
    def compute_shared_key(self, bob_keys: dict) -> bytes:
        """计算共享密钥"""
        # DH1 = DH(IK_A, SPK_B)
        dh1 = X3DHKeyExchange.dh(self.ik_priv, bob_keys['spk_pub'])
        # DH2 = DH(EK_A, IK_B)
        dh2 = X3DHKeyExchange.dh(self.ek_priv, bob_keys['ik_pub'])
        # DH3 = DH(EK_A, SPK_B)
        dh3 = X3DHKeyExchange.dh(self.ek_priv, bob_keys['spk_pub'])
        # DH4 = DH(EK_A, OPK_B)
        dh4 = X3DHKeyExchange.dh(self.ek_priv, bob_keys['opk_pub'])
        
        combined = X3DHKeyExchange.concat_dh(dh1, dh2, dh3, dh4)
        sk = X3DHKeyExchange.kdf(combined)
        
        return sk


# 使用示例
print("=" * 60)
print("X3DH异步密钥交换演示")
print("=" * 60)

# Bob预先发布密钥
bob = Bob()
bob_published = bob.publish_keys()
print("Bob发布密钥到服务器")

# Alice获取Bob的密钥并计算共享密钥
alice = Alice()
alice_sk = alice.compute_shared_key(bob_published)
print(f"Alice共享密钥: {alice_sk.hex()[:24]}...")

# Alice发送初始消息给Bob
# 包含: alice.ik_pub, alice.ek_pub

# Bob收到消息后计算共享密钥
bob_sk = bob.compute_shared_key(alice.ik_pub, alice.ek_pub)
print(f"Bob共享密钥:   {bob_sk.hex()[:24]}...")

print(f"密钥匹配: {alice_sk == bob_sk}")
```

### 6.3 Double Ratchet算法

**Double Ratchet算法** 在初始密钥交换后，为每条消息提供前向安全性和后向安全性。

```
Double Ratchet的两个"棘轮":

  1. DH棘轮（对称密钥棘轮）:
     - 每次发送消息时生成新的DH密钥对
     - 用新的DH共享密钥更新链密钥
     - 提供前向安全性
     
  2. KDF链棘轮:
     - 从链密钥派生消息密钥
     - 每条消息使用不同的密钥
     - 消息密钥不能反推链密钥

消息流程:
  Alice → Bob: 消息1（密钥K1）
  Alice → Bob: 消息2（密钥K2）← KDF链更新
  Bob → Alice: 消息3（密钥K3）← DH棘轮更新
  Alice → Bob: 消息4（密钥K4）← DH棘轮更新

安全特性:
  - 前向安全: 密钥泄露不影响过去的消息
  - 后向安全: 密钥泄露后，新消息安全（通过DH更新）
  - 乱序处理: 消息可以乱序到达
  - 消息丢失: 可以跳过消息密钥
```

```python
"""
Double Ratchet简化实现
"""
from cryptography.hazmat.primitives.asymmetric import x25519
from cryptography.hazmat.primitives import hashes, hmac
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
import os
import struct

class SymmetricRatchet:
    """对称KDF棘轮"""
    
    def __init__(self, chain_key: bytes):
        self.chain_key = chain_key
    
    def next(self) -> tuple:
        """推进棘轮，返回(消息密钥, 新链密钥)"""
        # 消息密钥
        message_key = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'message_key'
        ).derive(self.chain_key)
        
        # 新链密钥
        self.chain_key = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'chain_key'
        ).derive(self.chain_key)
        
        return message_key, self.chain_key


class DHRatchet:
    """DH棘轮"""
    
    def __init__(self):
        self.dh_priv = x25519.X25519PrivateKey.generate()
        self.dh_pub = self.dh_priv.public_key()
    
    def step(self, other_pub) -> bytes:
        """DH棘轮步进"""
        shared = self.dh_priv.exchange(other_pub)
        # 生成新的DH密钥对
        self.dh_priv = x25519.X25519PrivateKey.generate()
        self.dh_pub = self.dh_priv.public_key()
        return shared


class DoubleRatchet:
    """Double Ratchet算法"""
    
    def __init__(self, shared_secret: bytes, 
                 remote_pub=None, is_alice=True):
        self.root_key = shared_secret
        self.send_chain = None
        self.recv_chain = None
        self.dh_ratchet = DHRatchet()
        self.remote_dh_pub = remote_pub
        self.is_alice = is_alice
    
    def _kdf_root(self, dh_output: bytes) -> tuple:
        """从根密钥和DH输出推导新密钥"""
        combined = self.root_key + dh_output
        
        new_root = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'root_key'
        ).derive(combined)
        
        chain_key = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'chain_key'
        ).derive(combined)
        
        self.root_key = new_root
        return chain_key
    
    def encrypt(self, plaintext: bytes) -> dict:
        """加密消息"""
        if self.send_chain is None:
            # 首次发送，初始化发送链
            if self.remote_dh_pub:
                dh_out = self.dh_ratchet.dh_priv.exchange(
                    self.remote_dh_pub
                )
                chain_key = self._kdf_root(dh_out)
            else:
                chain_key = self.root_key
            
            self.send_chain = SymmetricRatchet(chain_key)
        
        # 推进对称棘轮
        message_key, _ = self.send_chain.next()
        
        # 加密（简化版，实际使用AEAD）
        from cryptography.hazmat.primitives.ciphers.aead import AESGCM
        nonce = os.urandom(12)
        aesgcm = AESGCM(message_key)
        ciphertext = aesgcm.encrypt(nonce, plaintext, None)
        
        return {
            'ciphertext': ciphertext,
            'nonce': nonce,
            'dh_pub': self.dh_ratchet.dh_pub,
        }
    
    def decrypt(self, message: dict) -> bytes:
        """解密消息"""
        remote_dh_pub = message['dh_pub']
        
        # DH棘轮更新
        if self.remote_dh_pub != remote_dh_pub:
            dh_out = self.dh_ratchet.dh_priv.exchange(remote_dh_pub)
            chain_key = self._kdf_root(dh_out)
            self.recv_chain = SymmetricRatchet(chain_key)
            self.remote_dh_pub = remote_dh_pub
        
        # 推进对称棘轮
        message_key, _ = self.recv_chain.next()
        
        # 解密
        from cryptography.hazmat.primitives.ciphers.aead import AESGCM
        aesgcm = AESGCM(message_key)
        plaintext = aesgcm.decrypt(
            message['nonce'], message['ciphertext'], None
        )
        
        return plaintext
```

## 七、国密SM2密钥交换

### 7.1 SM2密钥交换协议

**SM2密钥交换协议** （GB/T 32918.3）是基于椭圆曲线的认证密钥交换协议，类似于MQV协议。

```
SM2密钥交换流程:

  前置条件:
    Alice: 静态私钥dA, 静态公钥PA = dA*G
    Bob:   静态私钥dB, 静态公钥PB = dB*G
    ZA, ZB: 用户标识哈希值
  
  1. Alice生成临时密钥对: rA, RA = rA*G
     Alice → Bob: RA
  
  2. Bob生成临时密钥对: rB, RB = rB*G
     Bob计算:
       x̄B = 2^(⌈⌈log2(n)⌉/2⌉-1) + (RBx & (2^(⌈⌈log2(n)⌉/2⌉-1) - 1))
       tB = (dB + x̄B * rB) mod n
       点U = [h * tB](PA + [x̄A] * RA)
       KB = KDF(Ux || Uy || ZA || ZB, klen)
     Bob → Alice: RB, 验证信息
  
  3. Alice计算:
       x̄A = 2^(⌈⌈log2(n)⌉/2⌉-1) + (RAx & (2^(⌈⌈log2(n)⌉/2⌉-1) - 1))
       tA = (dA + x̄A * rA) mod n
       点V = [h * tA](PB + [x̄B] * RB)
       KA = KDF(Vx || Vy || ZA || ZB, klen)
  
  如果 U == V，则 KA == KB，密钥交换成功
  
  其中:
    x̄ = 取x坐标的高⌈log2(n)/2⌉位，再设置最高位
    h = 余因子
    KDF = SM3-based密钥派生函数
```

### 7.2 SM2密钥交换实现

```python
"""
SM2密钥交换实现
使用gmssl库
"""

try:
    from gmssl import sm2, func, sm3
    HAS_GMSSL = True
except ImportError:
    HAS_GMSSL = False


class SM2KeyExchange:
    """SM2密钥交换协议"""
    
    DEFAULT_USER_ID = "1234567812345678"
    
    def __init__(self, user_id: str = None):
        if not HAS_GMSSL:
            raise ImportError("需要gmssl库: pip install gmssl")
        
        self.user_id = user_id or self.DEFAULT_USER_ID
        
        # 生成静态密钥对
        self.static_priv = func.random_hex(64)
        crypt = sm2.CryptSM2(
            pubkey='', privkey=self.static_priv
        )
        pub = crypt._kg(
            int(self.static_priv, 16), crypt.pointG
        )
        self.static_pub = '%064x%064x' % pub
    
    def generate_ephemeral_key(self) -> tuple:
        """生成临时密钥对"""
        ephemeral_priv = func.random_hex(64)
        crypt = sm2.CryptSM2(
            pubkey='', privkey=ephemeral_priv
        )
        pub = crypt._kg(
            int(ephemeral_priv, 16), crypt.pointG
        )
        ephemeral_pub = '%064x%064x' % pub
        
        return ephemeral_priv, ephemeral_pub
    
    def compute_shared_key(self, remote_static_pub: str,
                           remote_ephemeral_pub: str,
                           self_ephemeral_priv: str,
                           key_length: int = 32) -> bytes:
        """
        计算共享密钥（概念实现）
        
        实际实现需要完整的SM2密钥交换协议
        """
        # 注意: 这是概念性实现
        # 完整实现需要:
        # 1. 计算ZA, ZB
        # 2. 计算x̄A, x̄B
        # 3. 计算tA或tB
        # 4. 计算点U/V
        # 5. KDF派生密钥
        
        # 这里仅展示概念
        combined = (
            self_ephemeral_priv +
            remote_static_pub +
            remote_ephemeral_pub
        )
        
        # 使用SM3作为KDF基础
        kdf_input = combined.encode('utf-8')
        
        # KDF
        ct = 1
        result = b''
        while len(result) < key_length:
            block = sm3.sm3_hash(
                kdf_input + ct.to_bytes(4, 'big')
            )
            result += bytes.fromhex(block)
            ct += 1
        
        return result[:key_length]
```

## 八、组密钥交换协议

### 8.1 组密钥交换概述

**组密钥交换（Group Key Exchange）** 允许多个参与方协商出一个共享的组密钥。

```
组密钥交换场景:
  - 视频会议加密
  - 群聊消息加密
  - 多方安全计算
  - 传感器网络
```

### 8.2 Burmester-Desmedt协议

**Burmester-Desmedt（BD）协议** 是经典的组密钥交换协议。

```
BD协议（n个参与方P1, P2, ..., Pn）:

  轮1: 每个Pi选择随机ri，广播zi = g^ri
  
  轮2: 每个Pi计算并广播Xi:
    Xi = (z(i+1) / z(i-1))^ri mod p
    
  密钥计算:
    Ki = z(i-1)^(n*ri) * Xi^(n-1) * X(i+1)^(n-2) * ... * X(i-2)
    
    所有Ki相等: K = g^(r1*r2 + r2*r3 + ... + rn*r1) mod p
```

### 8.3 树形组密钥管理

```
树形密钥管理（Logical Key Hierarchy）:

  使用树结构管理组成员关系
  
       [根密钥K]
       /        \
    [K1]        [K2]
    /  \        /  \
  [k1] [k2]  [k3] [k4]
   P1   P2    P3   P4
  
  当P3离开时:
    1. K3和K2需要更新
    2. 新K3用K4加密发给P4
    3. 新K2用新K3加密发给P4
    4. 新K2用K1加密发给P1,P2
    
  优势:
    - 成员变更效率高 O(log n)
    - 前向安全（离开成员无法解密新消息）
    - 后向安全（新成员无法解密旧消息）
```

## 九、量子密钥分发（QKD）

### 9.1 QKD概述

**量子密钥分发（Quantum Key Distribution）** 利用量子力学原理实现信息论安全的密钥交换。

```
QKD核心原理:
  1. 量子不可克隆定理: 无法完美复制未知量子态
  2. 测量塌缩: 测量会改变量子态
  3. 量子纠缠: 纠缠态的非局域关联性

安全模型:
  计算安全: DH/ECDH依赖数学难题
  信息论安全: QKD不依赖计算假设
```

### 9.2 BB84协议

**BB84协议** 是最著名的QKD协议，由Bennett和Brassard于1984年提出。

```
BB84协议流程:

  1. 量子传输:
     Alice随机选择比特(0/1)和基(+或×)
     发送对应偏振的光子给Bob
     
     |基|比特|光子偏振|
     |---|---|---------|
     | + | 0 | →       |
     | + | 1 | ↑       |
     | × | 0 | ↗       |
     | × | 1 | ↖       |
  
  2. 测量:
     Bob随机选择基(+或×)测量每个光子
     如果基选对了 → 结果正确
     如果基选错了 → 结果随机
  
  3. 基比对:
     Alice和Bob通过公开信道比对基的选择
     保留基相同的比特，丢弃基不同的比特
     
  4. 误码率检测:
     比对部分比特，检查误码率
     如果误码率过高 → 可能被窃听 → 丢弃
      
  5. 隐私放大:
     对剩余比特进行后处理
     提取出最终的安全密钥

  窃听检测:
    Eve如果窃听 → 必须测量光子 → 改变量子态
    → Bob测量错误率升高 → 被发现
```

### 9.3 QKD实际应用

```
QKD应用场景:
  1. 金融专线: 银行间安全通信
  2. 政府通信: 机密信息传输
  3. 军事通信: 高安全等级通信
  4. 数据中心互联: 数据中心间加密

QKD网络:
  量子密钥网络（QKN）:
    - 北京-上海量子干线
    - 武汉量子通信网
    - 合肥量子通信网
  
  QKD设备:
    - 光纤QKD: 基于光纤传输
    - 自由空间QKD: 基于卫星传输
    - 量子随机数生成器（QRNG）
```

## 十、后量子密钥交换

### 10.1 量子计算对密钥交换的威胁

```
Shor算法威胁:
  - 可以在多项式时间内求解离散对数
  - DH/ECDH完全不安全
  - RSA也不安全
  
Grover算法威胁:
  - 对称密钥安全减半
  - AES-256 → 128位安全（仍安全）
  
后量子密钥交换方向:
  1. 格基密码（Lattice-based）
  2. 编码密码（Code-based）
  3. 多变量密码（Multivariate）
  4. 哈希密码（Hash-based）
  5. 等同密码（Isogeny-based）
```

### 10.2 格基密钥交换

**CRYSTALS-Kyber** 是NIST后量子标准化的密钥封装机制（KEM）。

```
Kyber特点:
  类型: 格基密码（Module-LWE）
  密钥尺寸: ~800字节（公钥）
  密文尺寸: ~700字节
  安全等级: 128位（Kyber-512）/ 192位（Kyber-768）
  
Kyber流程:
  1. Alice生成密钥对(pk, sk)
  2. Alice发送pk给Bob
  3. Bob加密随机密钥: (c, K) = Encaps(pk)
  4. Bob发送c给Alice
  5. Alice解密: K = Decaps(sk, c)
  6. 双方共享密钥K
```

### 10.3 混合密钥交换

```
混合密钥交换（传统+后量子）:

  1. 执行ECDH密钥交换 → 共享密钥K1
  2. 执行后量子密钥交换 → 共享密钥K2
  3. 组合: K = KDF(K1 || K2)
  
  优势:
    - 如果量子计算未成熟: ECDH提供安全
    - 如果后量子算法有缺陷: ECDH提供安全
    - 两者都安全时: 双重保障
  
  TLS中的实现:
    TLS 1.3混合密钥交换:
      key_share包含ECDH公钥 + 后量子公钥
```

```python
"""
混合密钥交换概念实现
"""
from cryptography.hazmat.primitives.asymmetric import x25519
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
import os

class HybridKeyExchange:
    """混合密钥交换（ECDH + 后量子概念）"""
    
    @staticmethod
    def key_exchange() -> dict:
        """
        混合密钥交换
        
        ECDH（X25519） + 模拟后量子
        """
        # === ECDH部分 ===
        alice_ecdh_priv = x25519.X25519PrivateKey.generate()
        alice_ecdh_pub = alice_ecdh_priv.public_key()
        
        bob_ecdh_priv = x25519.X25519PrivateKey.generate()
        bob_ecdh_pub = bob_ecdh_priv.public_key()
        
        ecdh_shared_alice = alice_ecdh_priv.exchange(bob_ecdh_pub)
        ecdh_shared_bob = bob_ecdh_priv.exchange(alice_ecdh_pub)
        
        assert ecdh_shared_alice == ecdh_shared_bob
        
        # === 后量子部分（模拟） ===
        # 实际使用如Kyber等后量子算法
        # 这里用随机数模拟
        pq_shared_alice = os.urandom(32)
        pq_shared_bob = pq_shared_alice  # 模拟双方得到相同密钥
        
        # === 组合密钥 ===
        combined_alice = ecdh_shared_alice + pq_shared_alice
        combined_bob = ecdh_shared_bob + pq_shared_bob
        
        final_key_alice = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'hybrid-key-exchange'
        ).derive(combined_alice)
        
        final_key_bob = HKDF(
            algorithm=hashes.SHA256(),
            length=32,
            salt=b'',
            info=b'hybrid-key-exchange'
        ).derive(combined_bob)
        
        return {
            'alice_key': final_key_alice,
            'bob_key': final_key_bob,
            'match': final_key_alice == final_key_bob,
            'ecdh_key_size': len(ecdh_shared_alice),
            'pq_key_size': len(pq_shared_alice),
        }


# 演示
result = HybridKeyExchange.key_exchange()
print("=" * 60)
print("混合密钥交换演示")
print("=" * 60)
print(f"ECDH密钥大小: {result['ecdh_key_size']} bytes")
print(f"后量子密钥大小: {result['pq_key_size']} bytes")
print(f"密钥匹配: {result['match']}")
print(f"最终密钥: {result['alice_key'].hex()[:24]}...")
```

## 十一、密钥交换安全分析

### 11.1 常见攻击类型

#### 11.1.1 中间人攻击

```
防护方案:
  1. 数字签名认证（STS/SIGMA）
  2. 证书验证（TLS）
  3. 预共享密钥
  4. 密钥指纹验证（Signal的safety number）
```

#### 11.1.2 重放攻击

```
防护方案:
  1. Nonce（随机数）
  2. 时间戳
  3. 序列号
  4. 消息认证码
```

#### 11.1.3 前向安全性分析

```
前向安全性（Forward Secrecy）:
  即使长期密钥泄露，过去会话密钥仍然安全
  
  有前向安全性:
    - DHE/ECDHE（临时DH）
    - Signal Double Ratchet
    
  无前向安全性:
    - RSA密钥交换（TLS 1.2部分套件）
    - 静态DH
    
  实现:
    - 每次会话使用不同的临时密钥
    - 临时密钥使用后立即销毁
    - 会话密钥不能从长期密钥推导
```

#### 11.1.4 Logjam攻击

```
Logjam攻击（2015年）:
  针对DH密钥交换的攻击
  
  攻击原理:
    1. 利用512位弱DH参数
    2. 预计算离散对数
    3. 在协商时降级到弱参数
    4. 破解弱DH密钥
    
  防护:
    1. 使用至少2048位DH参数
    2. 使用ECDHE替代DHE
    3. 禁止弱参数套件
    4. 使用RFC 7919推荐的参数组
```

### 11.2 安全模型

```
密钥交换安全模型:

  1. CK模型（Canetti-Krawczyk）:
     - 会话密钥安全
     - 前向安全性
     - 抗已知密钥攻击
     
  2. BR模型（Bellare-Rogaway）:
     - 会话密钥不可区分性
     - 伙伴关系
     
  3. eCK模型（enhanced CK）:
     - 最强的安全模型
     - 允许私钥泄露
     - 临时私钥泄露
     - 前向安全性
```

## 十二、密钥交换实践应用

### 12.1 SSH密钥交换

```
SSH支持的密钥交换算法:

  curve25519-sha256      X25519 + SHA-256（推荐）
  ecdh-sha2-nistp256     ECDH P-256 + SHA-256
  diffie-hellman-group14-sha256  DH-2048 + SHA-256
  diffie-hellman-group16-sha512  DH-4096 + SHA-512
  diffie-hellman-group-exchange-sha256  自定义DH参数

SSH密钥交换流程:
  1. 版本交换
  2. 算法协商（KEXINIT）
  3. DH/ECDH密钥交换
  4. 服务器签名认证
  5. 派生加密密钥
  6. 加密通信开始
```

```bash
# SSH配置推荐
# /etc/ssh/sshd_config

# 使用X25519密钥交换
KexAlgorithms curve25519-sha256,curve25519-sha256@libssh.org

# 使用Ed25519主机密钥
HostKey /etc/ssh/ssh_host_ed25519_key

# 禁用弱算法
Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com
MACs hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com
```

### 12.2 IPsec IKE密钥交换

```
IKE（Internet Key Exchange）:
  IPsec VPN的密钥交换协议

IKEv1:
  - 两阶段协商
  - 主模式/野蛮模式
  - 快模式（Quick Mode）

IKEv2:
  - 简化的协商流程
  - 更少的消息交换
  - 更好的扩展性
  - 支持EAP认证
  - MOBIKE（移动性支持）

IKEv2密钥交换:
  1. IKE_SA_INIT:
     交换DH公开值、Nonce、算法提议
  
  2. IKE_AUTH:
     身份认证、SA协商、子SA创建
  
  3. CREATE_CHILD_SA:
     子SA创建、重协商
  
  密钥交换算法:
    IKEv2使用DH/ECDH进行密钥交换
    支持group14 (2048), group19 (P-256), group20 (P-384)
    支持curve25519
```

### 12.3 WireGuard密钥交换

```
WireGuard:
  现代VPN协议，使用Noise协议框架

  特点:
    1. 使用Curve25519进行密钥交换
    2. ChaCha20-Poly1305加密
    3. BLAKE2s哈希
    4. HKDF密钥派生
    
  与IKE的区别:
    - 更简单（约4000行代码 vs IKE的数十万行）
    - 更快（更少的握手消息）
    - 更安静（不回应未认证的数据包）
    - 前向安全
    
  Noise协议:
    使用Noise_IK模式
    I = Initiator（发起方）
    K = Known（已知公钥）
    
    静态公钥预先配置
    临时密钥提供前向安全
```

### 12.4 国密VPN密钥交换

```
国密IPsec VPN (GM/T 0022):

  IKE阶段使用SM2签名认证:
    - SM2签名替代RSA/ECDSA签名
    - SM3替代SHA-256
    - SM2 DH替代DH/ECDH
    
  ESP阶段:
    - SM4-CBC加密
    - SM3-HMAC完整性
    
  国密VPN套件:
    ESP套件: SM4-CBC + SM3-HMAC
    IKE套件: SM2-SM3-SM2DH
```

## 十三、总结与最佳实践

### 13.1 密钥交换算法选择

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| Web TLS | X25519 (TLS 1.3) | 高性能，前向安全 |
| SSH | curve25519-sha256 | 安全高效 |
| VPN (IPsec) | ECDH P-256/P-384 | 标准兼容 |
| VPN (WireGuard) | Noise + X25519 | 简单高效 |
| 即时通信 | X3DH + Double Ratchet | 异步，前向安全 |
| 物联网 | ECDH P-256/curve25519 | 资源效率 |
| 国密合规 | SM2密钥交换 | 法规要求 |
| 高安全 | QKD | 信息论安全 |
| 后量子 | Kyber + X25519 | 抗量子攻击 |

### 13.2 最佳实践

1. **始终使用认证密钥交换**：不使用匿名DH
2. **优先选择ECDH**：比DHE更高效
3. **优先选择X25519**：性能最好，安全性高
4. **确保前向安全性**：使用临时密钥
5. **使用密钥派生函数**：不要直接使用DH输出
6. **验证对方身份**：证书/签名/预共享密钥
7. **使用安全随机数**：私钥必须密码学安全随机
8. **定期更新密钥**：避免长期使用同一密钥
9. **记录审计日志**：记录密钥交换事件
10. **支持后量子准备**：规划后量子密钥交换

### 13.3 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 使用匿名DH | 中间人攻击 | 使用认证DH |
| 使用静态DH | 无前向安全性 | 使用临时DH |
| DH参数太小 | 被破解 | 至少2048位 |
| 私钥非安全随机 | 密钥可预测 | 使用CSPRNG |
| 不使用KDF | 密钥强度不够 | 使用HKDF |
| 不验证证书 | 中间人攻击 | 完整证书验证 |
| 重用临时密钥 | 前向安全性丧失 | 每次新密钥 |

> **总结：** 密钥交换协议是安全通信的基石。从最初的Diffie-Hellman到现代的X25519和Signal协议，密钥交换技术不断发展以应对新的安全挑战。理解各种密钥交换协议的原理、安全特性和适用场景，对于设计安全通信系统至关重要。随着量子计算的发展，后量子密钥交换将成为未来的主流。在实践中，选择合适的算法、确保前向安全性、使用认证机制、遵循最佳实践，才能构建真正安全的密钥交换系统。
