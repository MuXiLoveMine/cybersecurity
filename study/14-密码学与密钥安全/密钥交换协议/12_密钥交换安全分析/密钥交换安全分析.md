# 密钥交换安全分析

### 11.1 常见攻击类型

#### 11.1.1 中间人攻击

```
防护方案:
  1. 数字签名认证（STS/SIGMA）
  2. 证书验证（TLS）
  3. 预共享密钥
  4. 密钥指纹验证（Signal的safety number）
```

#### 11.1.2 重放攻击

```
防护方案:
  1. Nonce（随机数）
  2. 时间戳
  3. 序列号
  4. 消息认证码
```

#### 11.1.3 前向安全性分析

```
前向安全性（Forward Secrecy）:
  即使长期密钥泄露，过去会话密钥仍然安全
  
  有前向安全性:
    - DHE/ECDHE（临时DH）
    - Signal Double Ratchet
    
  无前向安全性:
    - RSA密钥交换（TLS 1.2部分套件）
    - 静态DH
    
  实现:
    - 每次会话使用不同的临时密钥
    - 临时密钥使用后立即销毁
    - 会话密钥不能从长期密钥推导
```

#### 11.1.4 Logjam攻击

```
Logjam攻击（2015年）:
  针对DH密钥交换的攻击
  
  攻击原理:
    1. 利用512位弱DH参数
    2. 预计算离散对数
    3. 在协商时降级到弱参数
    4. 破解弱DH密钥
    
  防护:
    1. 使用至少2048位DH参数
    2. 使用ECDHE替代DHE
    3. 禁止弱参数套件
    4. 使用RFC 7919推荐的参数组
```

### 11.2 安全模型

```
密钥交换安全模型:

  1. CK模型（Canetti-Krawczyk）:
     - 会话密钥安全
     - 前向安全性
     - 抗已知密钥攻击
     
  2. BR模型（Bellare-Rogaway）:
     - 会话密钥不可区分性
     - 伙伴关系
     
  3. eCK模型（enhanced CK）:
     - 最强的安全模型
     - 允许私钥泄露
     - 临时私钥泄露
     - 前向安全性
```
