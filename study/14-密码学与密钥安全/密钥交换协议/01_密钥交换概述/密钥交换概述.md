# 密钥交换概述

### 1.1 什么是密钥交换

**密钥交换（Key Exchange）** 是指两个或多个参与方通过公开信道协商出共享密钥的过程，即使攻击者监听了全部通信内容，也无法获得协商出的密钥。

```
密钥交换的基本场景：

  Alice                        Bob
    │                           │
    │ ←── 公开信道（被监听）───→ │
    │                           │
    │     交换公开参数            │
    │ ←──────────────────────→ │
    │                           │
    │ ←── 秘密计算 ──→          │
    │     各自计算共享密钥         │
    │                           │
    │     共享密钥K（相同）        │
    │     K = ??? = ???          │
    
  攻击者Eve可以监听所有通信
  但无法计算出共享密钥K
```

### 1.2 密钥交换的分类

```
┌──────────────────────────────────────────────────────────┐
│                  密钥交换协议分类                          │
├──────────────┬───────────────────────────────────────────┤
│  按认证方式   │  匿名密钥交换（无认证）                     │
│              │  认证密钥交换（有认证）                      │
├──────────────┼───────────────────────────────────────────┤
│  按数学基础   │  离散对数（DH）                            │
│              │  椭圆曲线（ECDH）                          │
│              │  格基（后量子）                             │
│              │  编码基（后量子）                           │
│              │  量子力学（QKD）                           │
├──────────────┼───────────────────────────────────────────┤
│  按参与方数   │  两方密钥交换                              │
│              │  组密钥交换（多方）                         │
├──────────────┼───────────────────────────────────────────┤
│  按交互轮数   │  1轮（单消息）                             │
│              │  2轮（双消息）                             │
│              │  3轮及以上                                 │
│              │  0轮（非交互式）                           │
├──────────────┼───────────────────────────────────────────┤
│  按安全模型   │  计算安全（依赖数学难题）                   │
│              │  信息论安全（无条件安全）                   │
└──────────────┴───────────────────────────────────────────┘
```

### 1.3 密钥交换的安全属性

| 安全属性 | 说明 |
|----------|------|
| 机密性 | 攻击者无法从交换消息中推导出共享密钥 |
| 前向安全性（PFS） | 即使长期密钥泄露，过去的会话密钥仍然安全 |
| 身份认证 | 确认通信对方的真实身份 |
| 密钥确认 | 双方确认持有相同的共享密钥 |
| 抗中间人攻击 | 防止攻击者插入密钥交换过程 |
| 抗重放攻击 | 防止攻击者重放旧的交换消息 |
| 已知密钥安全 | 每次交换产生独立的密钥 |

### 1.4 密钥交换发展历史

| 年份 | 事件 | 意义 |
|------|------|------|
| 1976 | Diffie-Hellman密钥交换发表 | 公钥密码学诞生 |
| 1985 | ElGamal密钥交换提出 | 基于离散对数 |
| 1985 | 椭圆曲线密码学提出 | ECDH的理论基础 |
| 1991 | STS（站到站）协议提出 | 认证DH |
| 1994 | MQV协议提出 | 高效认证密钥交换 |
| 1995 | HMQV协议提出 | 改进MQV安全性 |
| 1999 | NAXOS协议提出 | 强前向安全性 |
| 2003 | SIGMA框架提出 | 信号基认证交换 |
| 2008 | Signal协议开始开发 | 端到端加密通信 |
| 2013 | X3DH协议发表 | 异步密钥交换 |
| 2018 | TLS 1.3标准化 | 前向安全密钥交换 |
| 2024 | 后量子密钥交换标准化 | 抗量子计算 |
