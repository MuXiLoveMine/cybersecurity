# 密钥交换实践应用

### 12.1 SSH密钥交换

```
SSH支持的密钥交换算法:

  curve25519-sha256      X25519 + SHA-256（推荐）
  ecdh-sha2-nistp256     ECDH P-256 + SHA-256
  diffie-hellman-group14-sha256  DH-2048 + SHA-256
  diffie-hellman-group16-sha512  DH-4096 + SHA-512
  diffie-hellman-group-exchange-sha256  自定义DH参数

SSH密钥交换流程:
  1. 版本交换
  2. 算法协商（KEXINIT）
  3. DH/ECDH密钥交换
  4. 服务器签名认证
  5. 派生加密密钥
  6. 加密通信开始
```

```bash
# SSH配置推荐
# /etc/ssh/sshd_config

# 使用X25519密钥交换
KexAlgorithms curve25519-sha256,curve25519-sha256@libssh.org

# 使用Ed25519主机密钥
HostKey /etc/ssh/ssh_host_ed25519_key

# 禁用弱算法
Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com
MACs hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com
```

### 12.2 IPsec IKE密钥交换

```
IKE（Internet Key Exchange）:
  IPsec VPN的密钥交换协议

IKEv1:
  - 两阶段协商
  - 主模式/野蛮模式
  - 快模式（Quick Mode）

IKEv2:
  - 简化的协商流程
  - 更少的消息交换
  - 更好的扩展性
  - 支持EAP认证
  - MOBIKE（移动性支持）

IKEv2密钥交换:
  1. IKE_SA_INIT:
     交换DH公开值、Nonce、算法提议
  
  2. IKE_AUTH:
     身份认证、SA协商、子SA创建
  
  3. CREATE_CHILD_SA:
     子SA创建、重协商
  
  密钥交换算法:
    IKEv2使用DH/ECDH进行密钥交换
    支持group14 (2048), group19 (P-256), group20 (P-384)
    支持curve25519
```

### 12.3 WireGuard密钥交换

```
WireGuard:
  现代VPN协议，使用Noise协议框架

  特点:
    1. 使用Curve25519进行密钥交换
    2. ChaCha20-Poly1305加密
    3. BLAKE2s哈希
    4. HKDF密钥派生
    
  与IKE的区别:
    - 更简单（约4000行代码 vs IKE的数十万行）
    - 更快（更少的握手消息）
    - 更安静（不回应未认证的数据包）
    - 前向安全
    
  Noise协议:
    使用Noise_IK模式
    I = Initiator（发起方）
    K = Known（已知公钥）
    
    静态公钥预先配置
    临时密钥提供前向安全
```

### 12.4 国密VPN密钥交换

```
国密IPsec VPN (GM/T 0022):

  IKE阶段使用SM2签名认证:
    - SM2签名替代RSA/ECDSA签名
    - SM3替代SHA-256
    - SM2 DH替代DH/ECDH
    
  ESP阶段:
    - SM4-CBC加密
    - SM3-HMAC完整性
    
  国密VPN套件:
    ESP套件: SM4-CBC + SM3-HMAC
    IKE套件: SM2-SM3-SM2DH
```
