# SHA-3 算法

### 4.1 SHA-3 概述

**SHA-3** 是 NIST 于 2015 年发布的最新哈希标准，基于 Keccak 算法。

**为什么需要 SHA-3？**
- MD5 和 SHA-1 相继被破解
- SHA-2 与 SHA-1 结构相似，担心类似攻击
- 需要一个设计完全不同的哈希算法作为备份

**Keccak 算法：**
- 设计者：Guido Bertoni、Joan Daemen、Michaël Peeters、Gilles Van Assche
- 2008 年参加 NIST SHA-3 竞赛
- 2012 年获胜
- 2015 年正式成为 SHA-3 标准

### 4.2 海绵结构（Sponge Construction）

SHA-3 使用**海绵结构**，而不是 Merkle-Damgård 结构。

```
                消息块 M₁    M₂    M₃    ...
                 │      │      │      │
                 ▼      ▼      ▼      ▼
初始状态 ────▶ 吸 收 ──▶ 吸 收 ──▶ 吸 收 ──▶ ... ──▶ 挤 压 ──▶ 输出
                (Absorbing)                       (Squeezing)
```

**海绵结构的两个阶段：**

1. **吸收阶段（Absorbing）**
   - 将消息分块，逐块与状态异或
   - 每次异或后调用置换函数 f
   - 直到所有消息块处理完毕

2. **挤压阶段（Squeezing）**
   - 从状态中输出部分数据
   - 每次输出后调用置换函数 f
   - 可以输出任意长度的数据

**状态结构：**
- 状态大小 = 速率（rate） + 容量（capacity）
- 速率 r：每次吸收/挤压的数据量
- 容量 c：安全参数，越大越安全
- SHA-3-256：r = 1088 位，c = 512 位，总状态 1600 位

### 4.3 Keccak-f 置换

SHA-3 的核心是 Keccak-f[1600] 置换函数。

**状态表示：**
- 1600 位状态表示为 5×5×64 的三维数组
- 5×5 个 lane，每个 lane 64 位

**5 个步骤（每轮）：**

```
1. θ（Theta）：列奇偶性混合
   计算每列的奇偶性，与相邻列混合

2. ρ（Rho）：车道旋转
   每个 lane 按不同偏移量循环左移

3. π（Pi）：车道置换
   重新排列 lane 的位置

4. χ（Chi）：非线性层
   b[x,y] = a[x,y] ⊕ (¬a[x+1,y] ∧ a[x+2,y])
   这是唯一的非线性步骤

5. ι（Iota）：轮常数
   与一个轮常数异或
```

**轮数：**
- Keccak-f[1600]：24 轮
- 字长 64 位，轮数 = 12 + 2×log₂(64) = 12 + 12 = 24

### 4.4 SHA-3 变体

| 算法 | 输出长度 | 速率 r | 容量 c | 安全强度 |
|------|---------|--------|--------|---------|
| SHA3-224 | 224 位 | 1152 位 | 448 位 | 112 位 |
| SHA3-256 | 256 位 | 1088 位 | 512 位 | 128 位 |
| SHA3-384 | 384 位 | 832 位 | 768 位 | 192 位 |
| SHA3-512 | 512 位 | 576 位 | 1024 位 | 256 位 |

### 4.5 SHA-3 的优势

1. **设计不同**：与 SHA-2/M D5 完全不同的结构，避免了类似攻击
2. **抗长度扩展攻击**：海绵结构天然抵抗长度扩展攻击
3. **灵活性**：可以输出任意长度，还可以作为 XOF（可扩展输出函数）
4. **硬件实现友好**：适合硬件实现，面积小，速度快
5. **安全性高**：目前没有有效的攻击方法

### 4.6 SHAKE（SHA-3 Extendable-Output Functions）

SHAKE 是 SHA-3 的可扩展输出函数变体，可以输出任意长度的哈希值。

- **SHAKE128**：128 位安全强度，输出任意长度
- **SHAKE256**：256 位安全强度，输出任意长度

**用途：**
- 伪随机数生成
- 密钥派生
- 流密码
- 需要任意长度输出的场景
