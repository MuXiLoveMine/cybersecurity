# SHA-1 与 SHA-2 系列

### 3.1 SHA 家族概述

**SHA（Secure Hash Algorithm）** 是由美国国家安全局（NSA）设计、NIST 发布的一系列哈希算法标准。

| 算法 | 输出长度 | 块大小 | 轮数 | 发布年份 | 状态 |
|------|---------|--------|------|---------|------|
| SHA-0 | 160 位 | 512 位 | 80 | 1993 | 已撤回 |
| SHA-1 | 160 位 | 512 位 | 80 | 1995 | 已破解 |
| SHA-224 | 224 位 | 512 位 | 64 | 2001 | 安全 |
| SHA-256 | 256 位 | 512 位 | 64 | 2001 | 安全 |
| SHA-384 | 384 位 | 1024 位 | 80 | 2001 | 安全 |
| SHA-512 | 512 位 | 1024 位 | 80 | 2001 | 安全 |
| SHA-512/224 | 224 位 | 1024 位 | 80 | 2012 | 安全 |
| SHA-512/256 | 256 位 | 1024 位 | 80 | 2012 | 安全 |

### 3.2 SHA-1 算法

#### SHA-1 结构

SHA-1 也使用 Merkle-Damgård 结构，与 MD5 类似。

**初始值：**
```
H₀ = 0x67452301
H₁ = 0xEFCDAB89
H₂ = 0x98BADCFE
H₃ = 0x10325476
H₄ = 0xC3D2E1F0
```

**消息扩展：**
每个 512 位消息块（16 个 32 位字）扩展为 80 个 32 位字：
```
对于 t = 0 到 15：
  W[t] = 消息的第 t 个字

对于 t = 16 到 79：
  W[t] = (W[t-3] ⊕ W[t-8] ⊕ W[t-14] ⊕ W[t-16]) <<< 1
```

**80 轮操作（4 轮，每轮 20 步）：**
```
初始化：
  a = H₀, b = H₁, c = H₂, d = H₃, e = H₄

对于 t = 0 到 79：
  TEMP = (a <<< 5) + f_t(b, c, d) + e + K_t + W[t]
  e = d
  d = c
  c = b <<< 30
  b = a
  a = TEMP

最后：
  H₀ = H₀ + a
  H₁ = H₁ + b
  H₂ = H₂ + c
  H₃ = H₃ + d
  H₄ = H₄ + e
```

**轮函数 f_t 和常量 K_t：**

| 轮次 | t 范围 | f_t(b, c, d) | K_t |
|------|--------|-------------|-----|
| 第 1 轮 | 0-19 | Ch(b,c,d) = (b ∧ c) ∨ (¬b ∧ d) | 0x5A827999 |
| 第 2 轮 | 20-39 | Parity(b,c,d) = b ⊕ c ⊕ d | 0x6ED9EBA1 |
| 第 3 轮 | 40-59 | Maj(b,c,d) = (b ∧ c) ∨ (b ∧ d) ∨ (c ∧ d) | 0x8F1BBCDC |
| 第 4 轮 | 60-79 | Parity(b,c,d) = b ⊕ c ⊕ d | 0xCA62C1D6 |

#### SHA-1 的破解

**时间线：**
- 2005 年：王小云团队宣布 SHA-1 理论碰撞攻击，复杂度 2^69
- 2006 年：改进到 2^63
- 2017 年：Google 和 CWI 公布了首个 SHA-1 碰撞（SHAttered 攻击）
- 2020 年：选择前缀碰撞攻击成本降低到约 5 万美元

**SHAttered 攻击（2017）：**
- Google 生成了两个内容不同但 SHA-1 相同的 PDF 文件
- 计算量约为 2^63.1 次 SHA-1 运算
- 使用了约 6500 年的 CPU 时间和 110 年的 GPU 时间
- 成本估计约为 10 万美元（按云计算价格）

**SHA-1 现状：**
- 理论上已破解，实际碰撞也已实现
- 不应该用于数字签名、证书等安全场景
- 可以用于非安全场景和向后兼容
- 迁移到 SHA-2 或 SHA-3

### 3.3 SHA-2 系列

SHA-2 是 SHA-1 的后继者，包括 SHA-224、SHA-256、SHA-384、SHA-512 等。

#### SHA-256 算法

**初始值（前 8 个素数的平方根的小数部分）：**
```
H₀ = 0x6a09e667
H₁ = 0xbb67ae85
H₂ = 0x3c6ef372
H₃ = 0xa54ff53a
H₄ = 0x510e527f
H₅ = 0x9b05688c
H₆ = 0x1f83d9ab
H₇ = 0x5be0cd19
```

**常量表 K（前 64 个素数的立方根的小数部分）：**
```
K[0..63] = [
  0x428a2f98, 0x71374491, 0xb5c0fbcf, 0xe9b5dba5,
  0x3956c25b, 0x59f111f1, 0x923f82a4, 0xab1c5ed5,
  ... 共 64 个
]
```

**消息扩展：**
每个 512 位消息块（16 个 32 位字）扩展为 64 个 32 位字：
```
对于 t = 0 到 15：
  W[t] = 消息的第 t 个字

对于 t = 16 到 63：
  s0 = (W[t-15] >>> 7) ⊕ (W[t-15] >>> 18) ⊕ (W[t-15] >> 3)
  s1 = (W[t-2] >>> 17) ⊕ (W[t-2] >>> 19) ⊕ (W[t-2] >> 10)
  W[t] = W[t-16] + s0 + W[t-7] + s1
```

**64 轮操作：**
```
初始化：
  a = H₀, b = H₁, c = H₂, d = H₃
  e = H₄, f = H₅, g = H₆, h = H₇

对于 t = 0 到 63：
  S1 = (e >>> 6) ⊕ (e >>> 11) ⊕ (e >>> 25)
  ch = (e ∧ f) ⊕ (¬e ∧ g)
  temp1 = h + S1 + ch + K[t] + W[t]
  
  S0 = (a >>> 2) ⊕ (a >>> 13) ⊕ (a >>> 22)
  maj = (a ∧ b) ⊕ (a ∧ c) ⊕ (b ∧ c)
  temp2 = S0 + maj
  
  h = g
  g = f
  f = e
  e = d + temp1
  d = c
  c = b
  b = a
  a = temp1 + temp2

最后：
  H₀ = H₀ + a
  H₁ = H₁ + b
  ...
  H₇ = H₇ + h
```

#### SHA-512 算法

SHA-512 与 SHA-256 结构类似，但：
- 使用 64 位字（而不是 32 位）
- 块大小 1024 位（而不是 512 位）
- 80 轮（而不是 64 轮）
- 初始值和常量不同
- 输出 512 位

**SHA-224 和 SHA-384：**
- SHA-224 = SHA-256 的变体，不同初始值，截断输出到 224 位
- SHA-384 = SHA-512 的变体，不同初始值，截断输出到 384 位

#### SHA-2 的安全性

- **SHA-256**：目前安全，碰撞攻击复杂度 2^128
- **SHA-512**：更安全，碰撞攻击复杂度 2^256
- 没有发现有效的碰撞攻击
- 但是 SHA-2 仍使用 Merkle-Damgård 结构，存在长度扩展攻击
- 64 位系统上 SHA-512 通常比 SHA-256 更快
