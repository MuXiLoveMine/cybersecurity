# 哈希函数性质与应用

### 1.1 什么是哈希函数

**哈希函数（Hash Function）**，又称散列函数、消息摘要函数，是将任意长度的输入映射为固定长度输出的函数。

```
任意长度输入 ────哈希函数────▶ 固定长度输出
    M                        H(M)
```

**输出的名称：**
- 哈希值（Hash Value）
- 消息摘要（Message Digest）
- 散列值
- 指纹（Fingerprint）

### 1.2 密码学哈希函数的性质

**性质 1：确定性（Deterministic）**
- 相同的输入总是产生相同的输出
- H(M₁) = H(M₂) 当且仅当 M₁ = M₂（在实际应用中）

**性质 2：快速计算（Efficiency）**
- 对于任意输入 M，计算 H(M) 是高效的
- 通常是线性时间 O(n)

**性质 3：单向性（One-way / Pre-image Resistance）**
- 给定哈希值 h，计算上不可能找到 M 使得 H(M) = h
- 即不可逆，无法从哈希值反推原文

**性质 4：抗第二原像性（Second Pre-image Resistance）**
- 给定输入 M₁，计算上不可能找到 M₂ ≠ M₁ 使得 H(M₁) = H(M₂)
- 即很难找到与特定输入碰撞的另一个输入

**性质 5：抗碰撞性（Collision Resistance）**
- 计算上不可能找到任意两个不同的输入 M₁ ≠ M₂ 使得 H(M₁) = H(M₂)
- 即很难找到任意一对碰撞

**性质 6：雪崩效应（Avalanche Effect）**
- 输入的微小变化（如一位改变）会导致输出的巨大变化
- 理想情况下，改变一位输入会导致约一半的输出位翻转

**性质强度对比：**
```
抗碰撞性 > 抗第二原像性 > 单向性

如果抗碰撞，则必然抗第二原像
如果抗第二原像，则不一定抗碰撞
```

### 1.3 生日悖论与碰撞攻击复杂度

**生日悖论：**
在 23 个人中，有两个人生日相同的概率超过 50%。

**推广到哈希函数：**
对于 n 位哈希函数（有 2^n 种可能输出）：
- 找到碰撞的期望尝试次数约为 2^(n/2)
- 这就是**生日攻击（Birthday Attack）**

**推导：**
```
k 个随机输入中至少有一对碰撞的概率约为：
P ≈ 1 - e^(-k² / 2^(n+1))

当 P ≈ 0.5 时：
k ≈ 2^(n/2)
```

**示例：**
- 128 位哈希（MD5）：碰撞攻击复杂度约为 2^64
- 160 位哈希（SHA-1）：碰撞攻击复杂度约为 2^80
- 256 位哈希（SHA-256）：碰撞攻击复杂度约为 2^128
- 512 位哈希（SHA-512）：碰撞攻击复杂度约为 2^256

### 1.4 哈希函数的应用

| 应用场景 | 说明 |
|----------|------|
| 数据完整性校验 | 下载文件后验证是否被篡改 |
| 密码存储 | 存储密码的哈希值而非明文 |
| 数字签名 | 先哈希消息再签名 |
| 消息认证码 | HMAC |
| 区块链 | 区块哈希、Merkle 树 |
| 数据去重 | 通过哈希值判断数据是否重复 |
| 索引与查找 | 哈希表 |
| 伪随机数生成 | 基于哈希的 PRNG |
| 密钥派生 | KDF 中使用哈希 |
