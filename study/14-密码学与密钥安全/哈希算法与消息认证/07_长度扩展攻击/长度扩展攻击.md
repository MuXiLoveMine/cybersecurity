# 长度扩展攻击

### 7.1 什么是长度扩展攻击

**长度扩展攻击（Length Extension Attack）** 是针对 Merkle-Damgård 结构哈希函数的一种攻击方式。

**攻击场景：**
- 攻击者知道消息 M 的哈希值 H = H(secret || M)
- 攻击者知道 M 的内容和长度
- 攻击者不知道 secret
- 攻击者想要计算 H(secret || M || padding || M')，而不需要知道 secret

**原理：**
Merkle-Damgård 结构的哈希函数，内部状态就是输出的哈希值。
所以知道了哈希值，就知道了内部状态，可以继续处理更多数据。

```
H(secret || M) = 内部状态 S（即哈希输出）

继续处理：
S' = 压缩函数(S, 填充块)
H(secret || M || padding || M') = 继续处理 M' 后的结果
```

### 7.2 攻击步骤详解

**已知：**
- 密钥 secret（未知）
- 已知消息 M（已知）
- 哈希值 H = H(secret || M)（已知）
- secret 的长度（可以猜测或通过其他方式获取）

**攻击目标：**
- 构造消息 M' = M || padding || append_data
- 计算 H' = H(secret || M')，而不需要知道 secret

**步骤：**

```
步骤 1：确定 secret 的长度 L
  可以通过尝试或其他方式获取

步骤 2：计算内部填充
  原始消息结构：
  secret (L字节) + M (已知) + padding + length_field
  
  我们需要构造出与原始填充相同的 padding

步骤 3：设置新的初始状态
  将已知的哈希值 H 作为压缩函数的初始状态
  （因为 H 就是处理完 secret||M||padding 后的状态）

步骤 4：追加新数据
  用新初始状态继续处理 append_data
  得到新的哈希值 H'

步骤 5：结果
  H' = H(secret || M || padding || append_data)
  对应的消息是：M || padding || append_data
  （注意：消息中包含了原始的填充）
```

### 7.3 攻击示例

**场景：**
一个网站使用 H(secret_key || data) 来认证请求。

```
用户请求：
  data = "user=alice&action=view"
  hash = H(secret_key || data)
  
服务器验证：
  计算 H(secret_key || data)
  与请求中的 hash 比较
```

**攻击者想要：**
将请求改为 "user=alice&action=view&role=admin"，但不知道 secret_key。

**长度扩展攻击：**
```
1. 攻击者知道 data 和 hash
2. 攻击者猜测 secret_key 的长度（比如 16 字节）
3. 攻击者计算原始填充 padding
   原始消息总长 = 16 + len(data)
   按照哈希函数的填充规则计算 padding
4. 攻击者将 hash 作为初始状态，继续处理 "&role=admin"
5. 得到新的 hash'
6. 攻击者发送：
   data' = data + padding + "&role=admin"
   hash'
7. 服务器计算 H(secret_key || data')
   = H(secret_key || data || padding || "&role=admin")
   = hash'
   验证通过！
```

### 7.4 受影响的算法

所有基于 Merkle-Damgård 结构的哈希函数都受到影响：
- MD5
- SHA-1
- SHA-2 系列（SHA-256、SHA-512 等）

**不受影响的算法：**
- SHA-3（海绵结构）
- BLAKE2
- HMAC（HMAC 的双层哈希结构抵抗长度扩展攻击）

### 7.5 防护措施

1. **使用 HMAC 而不是 H(key || message)**
   - HMAC 天然抵抗长度扩展攻击
   - 因为有外层哈希

2. **使用 SHA-3**
   - 海绵结构不支持长度扩展

3. **使用 H(message || key) 也不好**
   - 虽然能抵抗长度扩展，但有其他安全问题
   - 不推荐

4. **使用带密钥的哈希结构**
   - 如 SipHash、Poly1305 等专门的 MAC 算法
