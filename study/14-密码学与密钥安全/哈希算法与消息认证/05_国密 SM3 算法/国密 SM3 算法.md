# 国密 SM3 算法

### 5.1 SM3 概述

**SM3** 是中国国家密码管理局发布的密码哈希算法标准。

- **标准号**：GM/T 0004-2012
- **发布时间**：2012 年
- **输出长度**：256 位
- **块大小**：512 位
- **结构**：Merkle-Damgård 结构
- **设计者**：王小云团队

### 5.2 SM3 整体结构

SM3 的结构与 SHA-256 类似，但有自己的初始值、常量和轮函数。

```
输入消息
    │
    ▼
填充（与 SHA-256 类似，但长度字段是大端序）
    │
    ▼
Merkle-Damgård 迭代结构
    │
    ▼
输出 256 位哈希值
```

### 5.3 初始值和常量

**初始值（256 位 = 8 个 32 位字）：**
```
A = 0x7380166f
B = 0x4914b2b9
C = 0x172442d7
D = 0xda8a0600
E = 0xa96f30bc
F = 0x163138aa
G = 0xe38dee4d
H = 0xb0fb0e4e
```

### 5.4 消息扩展

每个 512 位消息块扩展为 68 个 32 位字 W[0..67] 和 64 个 32 位字 W'[0..63]。

```
对于 t = 0 到 15：
  W[t] = 消息的第 t 个字（大端序）

对于 t = 16 到 67：
  W[t] = P1(W[t-16] ⊕ W[t-9] ⊕ (W[t-3] <<< 15)) 
         ⊕ (W[t-13] <<< 7) 
         ⊕ W[t-6]

其中 P1(X) = X ⊕ (X <<< 15) ⊕ (X <<< 23)

对于 t = 0 到 63：
  W'[t] = W[t] ⊕ W[t+4]
```

### 5.5 压缩函数

SM3 有 64 轮操作，分为前 16 轮和后 48 轮，使用不同的布尔函数和常量。

```
初始化：
  a = A, b = B, c = C, d = D
  e = E, f = F, g = G, h = H

对于 t = 0 到 63：
  SS1 = ((a <<< 12) + e + (T_t <<< t)) <<< 7
  SS2 = SS1 ⊕ (a <<< 12)
  TT1 = FF_t(a, b, c) + d + SS2 + W'[t]
  TT2 = GG_t(e, f, g) + h + SS1 + W[t]
  d = c
  c = b <<< 9
  b = a
  a = TT1
  h = g
  g = f <<< 19
  f = e
  e = P0(TT2)

其中 P0(X) = X ⊕ (X <<< 9) ⊕ (X <<< 17)
```

**布尔函数 FF 和 GG：**

```
前 16 轮（t = 0 ~ 15）：
  FF_t(X, Y, Z) = X ⊕ Y ⊕ Z
  GG_t(X, Y, Z) = X ⊕ Y ⊕ Z

后 48 轮（t = 16 ~ 63）：
  FF_t(X, Y, Z) = (X ∧ Y) ∨ (X ∧ Z) ∨ (Y ∧ Z)
  GG_t(X, Y, Z) = (X ∧ Y) ∨ (¬X ∧ Z)
```

**常量 T：**
```
前 16 轮：T_t = 0x79cc4519
后 48 轮：T_t = 0x7a879d8a
```

**最后：**
```
A = A ⊕ a
B = B ⊕ b
C = C ⊕ c
D = D ⊕ d
E = E ⊕ e
F = F ⊕ f
G = G ⊕ g
H = H ⊕ h
```

> 注意：SM3 是异或更新链接变量，而 SHA-256 是模加更新。

### 5.6 SM3 的安全性

- **输出长度**：256 位
- **碰撞攻击复杂度**：约 2^128（生日攻击下限）
- **目前安全**：没有发现有效的碰撞攻击
- **与 SHA-256 安全性相当**

**已有的分析结果：**
- 简化轮数的攻击（如减少到 20 多轮）有一些结果
- 对完整 64 轮 SM3 没有有效的攻击
- 王小云团队作为设计者，对安全性有充分评估
