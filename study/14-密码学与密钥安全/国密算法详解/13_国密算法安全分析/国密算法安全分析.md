# 国密算法安全分析

### 12.1 SM2安全分析

```
SM2安全性:
  
  数学基础: 椭圆曲线离散对数问题（ECDLP）
  曲线选择: 随机生成，无后门嫌疑
  安全强度: 256位密钥等效128位安全
  抗量子: 不抗量子计算（与ECDSA相同）
  
  与NIST P-256的安全对比:
    - 都基于素数域椭圆曲线
    - SM2的a值不同（-2 vs -3）
    - 都通过随机性检验
    - NIST曲线有Dual_EC_DRBG后门嫌疑
    - SM2无已知后门
```

### 12.2 SM3安全分析

```
SM3安全性:
  
  结构: Merkle-Damgard结构（与SHA-256类似）
  摘要长度: 256位
  安全强度: 128位（抗碰撞）
  
  已知分析:
    - 差分分析: 不优于暴力攻击
    - 线性分析: 不优于暴力攻击
    - 逆碰撞: 无已知实用攻击
    - 长度扩展攻击: Merkle-Damgard结构固有
    
  与SHA-256对比:
    - 相同结构
    - 不同初始值和常量
    - 相同安全等级
```

### 12.3 SM4安全分析

```
SM4安全性:
  
  结构: 非平衡Feistel网络
  分组/密钥: 128/128位
  轮数: 32轮
  安全强度: 128位
  
  与AES对比:
    - 不同结构（Feistel vs SPN）
    - 相同密钥长度
    - 相同安全等级
    - SM4轮数更多（32 vs 10/12/14）
    
  已知分析:
    - 差分分析: 18轮以下可攻击
    - 线性分析: 22轮以下可攻击
    - 32轮设计有足够安全裕量
    
  侧信道:
    - 需要恒定时间实现
    - 查表实现有Cache时序泄露风险
```

### 12.4 ZUC安全分析

```
ZUC安全性:
  
  已知分析:
    - 最初版本（v1）存在相关密钥攻击
    - v2版本修复了安全问题
    - 3GPP标准化版本（v3）通过安全审查
    
  与Snow 3G对比:
    - 都是3GPP标准序列密码
    - 结构不同
    - 相同安全等级
```
