# SM9标识密码算法

### 5.1 SM9算法概述

**SM9** 是中国标识密码算法标准（GB/T 32918.7-2016），它是一种基于身份的密码（IBC）算法，使用用户的身份标识（如邮箱、身份证号）作为公钥。

**SM9的核心优势：**
- 不需要数字证书
- 不需要PKI体系
- 公钥就是用户标识
- 密钥由密钥生成中心（KGC）生成

### 5.2 SM9与传统PKI对比

| 特性 | 传统PKI（SM2） | 标识密码（SM9） |
|------|---------------|----------------|
| 公钥 | 随机生成 | 用户标识 |
| 证书 | 需要 | 不需要 |
| 密钥生成 | 用户自行 | KGC集中生成 |
| 密钥托管 | 不支持 | 支持 |
| 系统复杂度 | 高 | 低 |
| 密钥管理 | 复杂 | 简单 |
| 信任模型 | 信任CA | 信任KGC |

### 5.3 SM9算法结构

```
SM9系统参数：

  双线性映射: e: G1 × G2 → GT
  G1: 第一椭圆曲线群
  G2: 第二椭圆曲线群
  GT: 有限域上的乘法群
  
  主密钥对:
    主私钥 s ∈ [1, N-1]
    主公钥 P_pub = s * P2  （P2是G2的生成元）
  
  用户密钥对:
    公钥: ID（用户标识，如"alice@example.com"）
    私钥: d_ID = s * H1(ID)  （由KGC计算）

SM9签名:
  签名: 使用私钥d_ID签名消息
  验证: 使用公钥ID验证签名
  
SM9加密:
  加密: 使用公钥ID加密消息
  解密: 使用私钥d_ID解密密文
  
SM9密钥交换:
  双方使用各自的ID和私钥协商共享密钥
```

### 5.4 SM9应用场景

```
SM9适用场景：

  1. 企业内部通信
     - 员工用工号/邮箱作为公钥
     - 不需要部署CA和证书
  
  2. 电子邮件加密
     - 用收件人邮箱地址作为公钥
     - 发件人不需要获取收件人证书
  
  3. 物联网设备认证
     - 用设备序列号作为公钥
     - 简化设备证书管理
  
  4. 电子政务
     - 用身份证号作为公钥
     - 方便公民身份认证
```
