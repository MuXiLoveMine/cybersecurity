### 8.3 国密TLCP协议

**TLCP（Transport Layer Cryptographic Protocol）** 是国密SSL协议标准（GM/T 386-2020），使用国密算法替代国际算法。

```
TLCP与TLS对比:

  TLS 1.2:
    密钥交换: ECDHE
    认证: RSA/ECDSA
    加密: AES
    哈希: SHA-256
    
  TLCP:
    密钥交换: ECDHE-SM2
    认证: SM2
    加密: SM4
    哈希: SM3
    
  特点:
    - 使用SM2双证书（签名证书+加密证书）
    - 兼容TLS 1.2握手流程
    - 支持SM4-GCM/SM4-CBC
```

**TLCP双证书机制：**
```
TLCP使用双证书:
  签名证书: 用于数字签名（签名密钥对）
    └── 私钥由服务器自己保管
    
  加密证书: 用于密钥加密（加密密钥对）
    └── 私钥由CA托管，可恢复

握手流程:
  ClientHello → Server
  Server → ClientHello + 签名证书 + 加密证书 + ServerKeyExchange
  Client → 验证证书 + 生成预主密钥 → 用加密证书公钥加密发送
  双方计算主密钥 → 加密通信
```
