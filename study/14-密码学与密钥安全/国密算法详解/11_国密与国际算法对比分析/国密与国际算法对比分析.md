# 国密与国际算法对比分析

### 11.1 算法对比

| 类别 | 国密算法 | 国际算法 | 安全强度 | 性能 |
|------|---------|---------|---------|------|
| 非对称签名 | SM2 | ECDSA-P256 | 相当 | 相当 |
| 非对称加密 | SM2 | RSA/ECIES | 相当 | SM2更优 |
| 对称加密 | SM4 | AES-128 | 相当 | 相当 |
| 杂凑 | SM3 | SHA-256 | 相当 | 相当 |
| 序列密码 | ZUC | Snow 3G | 相当 | 相当 |
| 标识密码 | SM9 | 无直接对应 | 独有 | 较慢 |

### 11.2 性能对比

```python
"""
国密算法性能测试
"""
import time

def benchmark():
    """性能基准测试"""
    
    # SM3 vs SHA-256
    import hashlib
    
    data = b"x" * 1024 * 1024  # 1MB
    
    # SHA-256
    start = time.time()
    for _ in range(100):
        hashlib.sha256(data).digest()
    sha256_time = time.time() - start
    
    # SM3
    try:
        from gmssl import sm3
        start = time.time()
        for _ in range(100):
            sm3.sm3_hash(data)
        sm3_time = time.time() - start
        
        print(f"哈希1MB × 100次:")
        print(f"  SHA-256: {sha256_time:.3f}s")
        print(f"  SM3:     {sm3_time:.3f}s")
        print(f"  比率:    {sm3_time/sha256_time:.2f}x")
    except ImportError:
        print("需要gmssl库进行性能测试")
    
    # SM4 vs AES
    try:
        from gmssl import sm4
        from cryptography.hazmat.primitives.ciphers import (
            Cipher, algorithms, modes
        )
        
        key = b'0123456789abcdef'
        iv = b'\x00' * 16
        data = b"x" * 1024 * 1024  # 1MB
        
        # AES-128-CBC
        cipher = Cipher(algorithms.AES(key), modes.CBC(iv))
        enc = cipher.encryptor()
        start = time.time()
        for _ in range(100):
            enc = Cipher(algorithms.AES(key), modes.CBC(iv)).encryptor()
            enc.update(data) + enc.finalize()
        aes_time = time.time() - start
        
        # SM4-CBC
        sm4_crypt = sm4.CryptSM4()
        sm4_crypt.set_key(key, sm4.SM4_ENCRYPT)
        start = time.time()
        for _ in range(100):
            sm4_crypt.set_key(key, sm4.SM4_ENCRYPT)
            sm4_crypt.crypt_cbc(iv, data)
        sm4_time = time.time() - start
        
        print(f"\n加密1MB × 100次:")
        print(f"  AES-128-CBC: {aes_time:.3f}s")
        print(f"  SM4-CBC:     {sm4_time:.3f}s")
        print(f"  比率:        {sm4_time/aes_time:.2f}x")
    except ImportError:
        print("需要gmssl和cryptography库进行性能测试")

# benchmark()
```

### 11.3 互操作性

```
国密与国际算法的互操作:

  1. TLS互操作:
     - TLCP不兼容TLS 1.2/1.3
     - 需要支持双协议栈的SSL库
     - 一些浏览器支持国密TLS插件
     
  2. 证书互操作:
     - SM2证书使用不同的OID
     - 需要支持国密OID的证书验证库
     
  3. 混合模式:
     - 同一系统可同时支持国密和国际算法
     - 根据对端能力选择算法套件
     
  4. 转换:
     - 不存在算法间的直接转换
     - 需要重新签名/加密
```
