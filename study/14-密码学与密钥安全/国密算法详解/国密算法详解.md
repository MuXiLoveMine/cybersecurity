## 一、国密算法概述

### 1.1 什么是国密算法

**国密算法**，即中国商用密码算法，是由国家密码管理局发布的一系列密码算法标准。这些算法旨在为中国境内的信息安全应用提供自主可控的密码技术支撑。

**国密算法体系：**

```
┌───────────────────────────────────────────────────────────┐
│                    国密算法体系                              │
├─────────────┬─────────────────────────────────────────────┤
│  非对称密码   │  SM2（椭圆曲线） SM9（标识密码）               │
├─────────────┼─────────────────────────────────────────────┤
│  对称密码     │  SM4（分组） SM7（分组） ZUC（序列）           │
├─────────────┼─────────────────────────────────────────────┤
│  杂凑算法     │  SM3（杂凑）                                  │
├─────────────┼─────────────────────────────────────────────┤
│  密码协议     │  IPsec VPN、TLS/SSL、SSL VPN等              │
├─────────────┼─────────────────────────────────────────────┤
│  密码应用     │  电子证书、电子签章、电子公文等                │
└─────────────┴─────────────────────────────────────────────┘
```

## 二、SM2椭圆曲线公钥密码算法

### 2.1 SM2算法概述

**SM2** 是基于椭圆曲线的公钥密码算法标准（GB/T 32918），包含数字签名、密钥交换和公钥加密三个部分。

**SM2标准系列：**

| 标准号 | 名称 | 内容 |
|--------|------|------|
| GB/T 32918.1 | 总则 | 曲线参数、算法基础 |
| GB/T 32918.2 | 数字签名 | SM2签名算法 |
| GB/T 32918.3 | 密钥交换 | SM2密钥交换协议 |
| GB/T 32918.4 | 公钥加密 | SM2公钥加密算法 |
| GB/T 32918.5 | 参数定义 | 推荐曲线参数 |
| GB/T 32918.7 | SM9算法 | 标识密码算法 |

### 2.2 SM2椭圆曲线参数

```
SM2使用256位素数域上的椭圆曲线：
  方程: y² = x³ + ax + b (mod p)

推荐曲线参数（SM2-P-256）：
  p = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF 
      FFFFFFFF 00000000 FFFFFFFF FFFFFFFF
      
  a = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF 
      FFFFFFFF 00000000 FFFFFFFF FFFFFFFC
      
  b = 28E9FA9E 9D9F5E34 4D5A9E4B CF659098 
      E0369503 E0B68A65 C39E2E0C 9EDE51E6

  基点G:
    Gx = 32C4AE2C 1F198119 5F990446 6C5A9EC3 
         7D9E2A3D E0F4A7D3 89C8B71C 225BE9DD
         
    Gy = 9E6E9E3A 6E5C5D51 5B6B6C6C 9E6E2E4F 
         2D5C5E51 5E5E5E51 7C8C8C8C 5E5E5E5E

  阶n:
    n = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF 
        7203DF6B 21C6052B 53BBF409 39D54123

  余因子h: 1
```

**SM2与NIST P-256曲线对比：**

| 参数 | SM2 | NIST P-256 |
|------|------|-----------|
| 域类型 | 素数域 | 素数域 |
| 模数p | 256位 | 256位 |
| a | -2 (mod p) | -3 |
| 随机曲线 | 是（b随机生成） | 是 |
| 等效安全 | 128位 | 128位 |

### 2.3 SM2数字签名

#### 2.3.1 签名算法

```
SM2数字签名算法

输入：
  消息M、用户ID、私钥d、公钥P = dG

预处理（计算Z值）：
  1. ENTL = 用户ID的位长度（2字节）
  2. Z = SM3(ENTL || ID || a || b || Gx || Gy || Px || Py)

签名过程：
  1. e = SM3(Z || M)，取e的左前n位作为整数
  
  2. 生成随机数k ∈ [1, n-1]
  
  3. (x1, y1) = k * G
  
  4. r = (e + x1) mod n
     如果r == 0 或 r+k == n，返回步骤2
  
  5. s = ((1 + d)⁻¹ * (k - r * d)) mod n
     如果s == 0，返回步骤2
  
  6. 签名 = (r, s)
```

#### 2.3.2 验证算法

```
SM2签名验证算法

输入：
  消息M、签名(r,s)、用户ID、公钥P

验证过程：
  1. 检查 r ∈ [1, n-1]
  2. 检查 s ∈ [1, n-1]
  
  3. 计算Z值（同签名预处理）
  
  4. e = SM3(Z || M)
  
  5. t = (r + s) mod n
     如果t == 0，验证失败
  
  6. (x2, y2) = s*G + t*P
  
  7. R = (e + x2) mod n
  
  8. 如果 R == r，验证成功；否则验证失败
```

### 2.4 SM2公钥加密

SM2公钥加密使用了密钥派生函数KDF和消息认证码MAC的组合方案。

```
SM2公钥加密算法

加密过程：
  输入：明文M、公钥P
  
  1. 生成随机数k ∈ [1, n-1]
  
  2. C1 = k*G  （椭圆曲线点，公钥部分）
  
  3. S = k*P  （共享密钥点）
     如果S是无穷远点，返回步骤1
  
  4. 派生密钥: K = KDF(Sx || Sy, klen)
     klen = 明文长度 + SM3输出长度
  
  5. C2 = M XOR K[0:klen]  （密文）
  
  6. C3 = SM3(Sx || M || Sy)  （消息认证码）
  
  7. 密文 = C1 || C2 || C3

解密过程：
  输入：密文C1||C2||C3、私钥d
  
  1. 从C1恢复点(x1,y1)
  
  2. S = d * C1  （共享密钥点）
  
  3. 派生密钥: K = KDF(Sx || Sy, klen)
  
  4. M' = C2 XOR K[0:klen]  （解密明文）
  
  5. 验证: SM3(Sx || M' || Sy) == C3
     如果不等，解密失败
  
  6. 返回M'
```

### 2.5 SM2密钥交换

```
SM2密钥交换协议

前置条件：
  服务器A: 私钥dA, 公钥PA = dA*G
  客户端B: 私钥dB, 公钥PB = dB*G
  
交换过程：

  A → B: RA = rA*G (A的临时公钥)
  B → A: RB = rB*G (B的临时公钥)

  A计算:
    x = 椭圆曲线点RA的x坐标
    x̄ = 2^(⌈log2(n)⌉-1) + (x & (2^(⌈log2(n)⌉-1) - 1))
    tA = (dA + x̄ * rA) mod n
    
    点V = [h * tA] * (PB + [x̄B] * RB)
    
    密钥: KA = KDF(Vx || Vy || ZA || ZB, klen)

  B计算:
    x = 椭圆曲线点RB的x坐标
    x̄ = 2^(⌈log2(n)⌉-1) + (x & (2^(⌈log2(n)⌉-1) - 1))
    tB = (dB + x̄ * rB) mod n
    
    点U = [h * tB] * (PA + [x̄A] * RA)
    
    密钥: KB = KDF(Ux || Uy || ZA || ZB, klen)

  如果 V == U，则 KA == KB，密钥交换成功
```

### 2.6 SM2密钥派生函数KDF

```
KDF（Key Derivation Function）:

输入: Z（密钥材料比特串）、klen（派生密钥长度）
输出: K（派生密钥，长度klen）

过程:
  ct = 0x00000001
  counter = 1
  
  对于i从1到⌈klen/v⌉:
    Hai = SM3(Z || ct)
    ct = ct + 1
  
  K = Hai || Ha2 || ... || Ha⌈klen/v⌉
  K = K的前klen位
  
  返回K
```

class SM2Cipher:
    """SM2公钥加密/解密"""
    
    def __init__(self, pubkey: str = None, privkey: str = None):
        """
        Args:
            pubkey: 十六进制公钥字符串（04 || X || Y）
            privkey: 十六进制私钥字符串
        """
        if not HAS_GMSSL:
            raise ImportError("需要gmssl库: pip install gmssl")
        
        if privkey and not pubkey:
            # 从私钥推导公钥
            crypt = sm2.CryptSM2(pubkey='', privkey=privkey)
            pub = crypt._kg(int(privkey, 16), crypt.pointG)
            pubkey = '%064x%064x' % pub
        
        self.pubkey = pubkey
        self.privkey = privkey
        self.sm2_crypt = sm2.CryptSM2(
            pubkey=pubkey or '',
            privkey=privkey or ''
        )
    
    @staticmethod
    def generate_keypair() -> tuple:
        """生成SM2密钥对"""
        privkey = func.random_hex(64)  # 256位
        crypt = sm2.CryptSM2(pubkey='', privkey=privkey)
        pub = crypt._kg(int(privkey, 16), crypt.pointG)
        pubkey = '%064x%064x' % pub
        return privkey, pubkey
    
    def encrypt(self, plaintext: bytes) -> bytes:
        """SM2加密"""
        if isinstance(plaintext, str):
            plaintext = plaintext.encode('utf-8')
        return self.sm2_crypt.encrypt(plaintext)
    
    def decrypt(self, ciphertext: bytes) -> bytes:
        """SM2解密"""
        return self.sm2_crypt.decrypt(ciphertext)


class SM2Signature:
    """SM2数字签名"""
    
    DEFAULT_USER_ID = "1234567812345678"
    
    def __init__(self, pubkey: str, privkey: str):
        self.pubkey = pubkey
        self.privkey = privkey
        self.sm2_crypt = sm2.CryptSM2(
            pubkey=pubkey,
            privkey=privkey
        )
    
    def sign(self, data: bytes, user_id: str = None) -> bytes:
        """签名"""
        if user_id is None:
            user_id = self.DEFAULT_USER_ID
        
        if isinstance(data, str):
            data = data.encode('utf-8')
        
        sig = self.sm2_crypt.sign(data, user_id.encode('utf-8'))
        return sig
    
    def verify(self, data: bytes, signature: bytes,
               user_id: str = None) -> bool:
        """验证签名"""
        if user_id is None:
            user_id = self.DEFAULT_USER_ID
        
        if isinstance(data, str):
            data = data.encode('utf-8')
        
        return self.sm2_crypt.verify(
            signature, data, user_id.encode('utf-8')

## 三、SM3密码杂凑算法

### 3.1 SM3算法概述

**SM3** 是中国密码杂凑算法标准（GB/T 32905-2016），用于生成256位的消息摘要。

**SM3特点：**

| 特性 | 说明 |
|------|------|
| 摘要长度 | 256位（32字节） |
| 分组长度 | 512位（64字节） |
| 迭代结构 | Merkle-Damgard结构 |
| 字长度 | 32位 |
| 迭代轮数 | 64轮 |
| 等效安全 | 128位 |
| 性能 | 与SHA-256相当 |

### 3.2 SM3算法原理

#### 3.2.1 常量与初始值

```
初始值IV（8个32位字）:
  IV = 7380166F 4914B2B9 172442D7 DA8A0600 
      A96F30BC 163138AA E38DEE4D B0FB0E4E

常量:
  Tj: 
    T0~T15  = 79CC4519
    T16~T63 = 7A879D8A
```

#### 3.2.2 布尔函数

```
布尔函数FFj和GGj:

FFj(X, Y, Z):
  j ∈ [0, 15]:  FF = X XOR Y XOR Z
  j ∈ [16, 63]: FF = (X AND Y) OR (X AND Z) OR (Y AND Z)

GGj(X, Y, Z):
  j ∈ [0, 15]:  GG = X XOR Y XOR Z
  j ∈ [16, 63]: GG = (X AND Y) OR (NOT X AND Z)
```

#### 3.2.3 置换函数

```
P0(X) = X XOR (X <<< 9) XOR (X <<< 17)
P1(X) = X XOR (X <<< 15) XOR (X <<< 23)

注: <<< 表示循环左移
```

#### 3.2.4 消息扩展

```
消息扩展过程：

输入: 512位消息块 Bi (16个32位字 W0~W15)

扩展为132个字:
  W0~W15:   直接使用消息字
  
  Wj (16 ≤ j ≤ 67):
    Wj = P1(W(j-16) XOR W(j-9) XOR (W(j-3) <<< 15)) 
         XOR (W(j-13) <<< 7) XOR W(j-6)
  
  W'j (0 ≤ j ≤ 63):
    W'j = Wj XOR W(j+4)
```

#### 3.2.5 压缩函数

```
压缩函数CF:

输入: Vi-1 (256位中间哈希值), Bi (512位消息块)
输出: Vi (256位新的哈希值)

过程:
  1. 消息扩展: 将Bi扩展为W0~W67和W'0~W'63
  
  2. 初始化工作变量:
     A=V(i-1)[0], B=V(i-1)[1], ..., H=V(i-1)[7]
  
  3. 迭代压缩（64轮）:
     对于j = 0 到 63:
       SS1 = ((A <<< 12) + E + (Tj <<< j)) <<< 7
       SS2 = SS1 XOR (A <<< 12)
       TT1 = FFj(A, B, C) + D + SS2 + W'j
       TT2 = GGj(E, F, G) + H + SS1 + Wj
       D = C
       C = B <<< 9
       B = A
       A = TT1
       H = G
       G = F <<< 19
       F = E
       E = P0(TT2)
  
  4. 更新哈希值:
     V(i)[0] = V(i-1)[0] XOR A
     V(i)[1] = V(i-1)[1] XOR B
     ...
     V(i)[7] = V(i-1)[7] XOR H
```

#### 3.2.6 整体流程

```
SM3哈希流程:

  1. 消息填充:
     消息M → M || 1 || 000...0 || 64位长度
     填充使总长度 ≡ 0 (mod 512)
  
  2. 分组:
     将填充后的消息分为L个512位分组 B0, B1, ..., B(L-1)
  
  3. 迭代:
     V0 = IV
     对于i = 0 到 L-1:
       V(i+1) = CF(Vi, Bi)
  
  4. 输出:
     哈希值 = V(L) (256位)
```

### 3.3 SM3实现

```python
"""
SM3哈希算法Python实现
"""

class SM3:
    """SM3密码杂凑算法"""
    
    # 初始值
    IV = [
        0x7380166F, 0x4914B2B9, 0x172442D7, 0xDA8A0600,
        0xA96F30BC, 0x163138AA, 0xE38DEE4D, 0xB0FB0E4E
    ]
    
    # 常量
    T1 = 0x79CC4519  # 0~15轮
    T2 = 0x7A879D8A  # 16~63轮
    
    def __init__(self):
        self._buffer = b''
        self._length = 0
        self._v = list(self.IV)
    
    @staticmethod
    def _rotl(x: int, n: int) -> int:
        """循环左移"""
        n = n % 32
        return ((x << n) | (x >> (32 - n))) & 0xFFFFFFFF
    
    @staticmethod
    def _ff(j: int, x: int, y: int, z: int) -> int:
        """布尔函数FF"""
        if j < 16:
            return x ^ y ^ z
        else:
            return (x & y) | (x & z) | (y & z)
    
    @staticmethod
    def _gg(j: int, x: int, y: int, z: int) -> int:
        """布尔函数GG"""
        if j < 16:
            return x ^ y ^ z
        else:
            return (x & y) | ((~x & 0xFFFFFFFF) & z)
    
    @staticmethod
    def _p0(x: int) -> int:
        """置换函数P0"""
        return x ^ SM3._rotl(x, 9) ^ SM3._rotl(x, 17)
    
    @staticmethod
    def _p1(x: int) -> int:
        """置换函数P1"""
        return x ^ SM3._rotl(x, 15) ^ SM3._rotl(x, 23)
    
    def _message_expansion(self, block: bytes) -> tuple:
        """消息扩展"""
        W = []
        W_prime = []
        
        # W0~W15
        for i in range(16):
            W.append(int.from_bytes(
                block[i*4:(i+1)*4], 'big'
            ))
        
        # W16~W67
        for j in range(16, 68):
            w = self._p1(
                W[j-16] ^ W[j-9] ^ self._rotl(W[j-3], 15)
            ) ^ self._rotl(W[j-13], 7) ^ W[j-6]
            W.append(w)
        
        # W'0~W'63
        for j in range(64):
            W_prime.append(W[j] ^ W[j+4])
        
        return W, W_prime
    
    def _compress(self, v: list, block: bytes) -> list:
        """压缩函数"""
        W, W_prime = self._message_expansion(block)
        
        A, B, C, D, E, F, G, H = v
        
        for j in range(64):
            T = self.T1 if j < 16 else self.T2
            
            SS1 = self._rotl(
                (self._rotl(A, 12) + E + self._rotl(T, j % 32)) & 0xFFFFFFFF,
                7
            )
            SS2 = SS1 ^ self._rotl(A, 12)
            
            TT1 = (self._ff(j, A, B, C) + D + SS2 + W_prime[j]) & 0xFFFFFFFF
            TT2 = (self._gg(j, E, F, G) + H + SS1 + W[j]) & 0xFFFFFFFF
            
            D = C
            C = self._rotl(B, 9)
            B = A
            A = TT1
            H = G
            G = self._rotl(F, 19)
            F = E
            E = self._p0(TT2)
        
        return [
            v[0] ^ A, v[1] ^ B, v[2] ^ C, v[3] ^ D,
            v[4] ^ E, v[5] ^ F, v[6] ^ G, v[7] ^ H
        ]
    
    def update(self, data: bytes):
        """更新哈希状态"""
        self._buffer += data
        self._length += len(data)
        
        while len(self._buffer) >= 64:
            block = self._buffer[:64]
            self._buffer = self._buffer[64:]
            self._v = self._compress(self._v, block)
    
    def digest(self) -> bytes:
        """计算最终哈希值"""
        # 填充
        msg_len = self._length
        padding = b'\x80'
        padding += b'\x00' * ((56 - (msg_len + 1) % 64) % 64)
        padding += (msg_len * 8).to_bytes(8, 'big')
        
        self.update(padding)
        
        # 输出
        result = b''
        for v in self._v:
            result += v.to_bytes(4, 'big')
        
        return result
    
    def hexdigest(self) -> str:
        """计算最终哈希值（十六进制）"""
        return self.digest().hex()
    
    @staticmethod
    def hash(data: bytes) -> str:
        """一次性计算哈希"""
        h = SM3()
        h.update(data)
        return h.hexdigest()

"""
SM3-HMAC实现
"""
import hmac

class SM3HMAC:
    """基于SM3的HMAC"""
    
    BLOCK_SIZE = 64  # SM3分组大小
    
    @staticmethod
    def hmac(key: bytes, message: bytes) -> bytes:
        """计算HMAC-SM3"""
        # 密钥处理
        if len(key) > SM3HMAC.BLOCK_SIZE:
            key = bytes.fromhex(SM3.hash(key))
        
        if len(key) < SM3HMAC.BLOCK_SIZE:
            key = key + b'\x00' * (SM3HMAC.BLOCK_SIZE - len(key))
        
        # 内外层填充
        ipad = bytes(b ^ 0x36 for b in key)
        opad = bytes(b ^ 0x5c for b in key)
        
        # HMAC = SM3(opad || SM3(ipad || message))
        inner = bytes.fromhex(SM3.hash(ipad + message))
        outer = bytes.fromhex(SM3.hash(opad + inner))
        
        return outer
    
    @staticmethod
    def hmac_hex(key: bytes, message: bytes) -> str:
        """计算HMAC-SM3（十六进制）"""
        return SM3HMAC.hmac(key, message).hex()

## 四、SM4分组密码算法

### 4.1 SM4算法概述

**SM4** 是中国分组密码算法标准（GB/T 32907-2016），用于无线局域网产品等的数据加密保护。

**SM4特点：**

| 特性 | 说明 |
|------|------|
| 分组长度 | 128位（16字节） |
| 密钥长度 | 128位（16字节） |
| 迭代轮数 | 32轮 |
| 结构 | Feistel变体（非平衡Feistel） |
| S盒 | 8位输入/输出 |
| 等效安全 | 128位 |
| 设计理念 | 与AES设计不同 |

### 4.2 SM4算法原理

#### 4.2.1 基本运算

```
SM4基本运算:
  ⊕: 32位异或
  <<<i: 32位循环左移i位
  
S盒: 8位输入→8位输出的查找表
  SBOX = [
    0xd6,0x90,0xe9,0xfe,0xcc,0xe1,0x3d,0xb7,0x16,0xb6,0x14,0xc2,0x28,0xfb,0x2c,0x05,
    0x2b,0x67,0x9a,0x76,0x2a,0xbe,0x04,0xc3,0xaa,0x44,0x13,0x26,0x49,0x86,0x06,0x99,
    0x9c,0x66,0x42,0x25,0xf0,0x91,0x33,0x88,0xf9,0x32,0xa9,0xf1,0xd0,0xe7,0xe6,0x80,
    0xe6,0xfc,0xaa,0xa9,0xe1,0x0e,0x19,0x21,0x12,0xc9,0xe6,0x92,0xe5,0xdd,0x8c,0x88,
    ...（完整S盒见标准）
  ]
```

#### 4.2.2 密钥扩展

```
SM4密钥扩展:

系统参数:
  FK = [0xA3B1BAC6, 0x56AA3350, 0x677D9197, 0xB27022DC]

固定参数CK:
  CKi = (ck(4i), ck(4i+1), ck(4i+2), ck(4i+3))
  其中ck(i) = (4i+7) mod 7 或查表

轮密钥生成:
  输入: 128位密钥 K = (K0, K1, K2, K3)
  
  1. (K0, K1, K2, K3) = (K0⊕FK0, K1⊕FK1, K2⊕FK2, K3⊕FK3)
  
  2. 对于i = 0 到 31:
     rki = Ki ⊕ T'(Ki+1 ⊕ Ki+2 ⊕ Ki+3 ⊕ CKi)
     Ki+4 = rki
  
  其中T'变换:
    T'(B) = B' = (b0,b1,b2,b3)' = (S(b0), S(b1), S(b2), S(b3))
    然后 B' = B' ⊕ (B' <<< 13) ⊕ (B' <<< 23)
```

#### 4.2.3 加密流程

```
SM4加密流程:

输入: 128位明文 X = (X0, X1, X2, X3)
     32位轮密钥 rk0~rk31

32轮迭代:
  对于i = 0 到 31:
    Xi+4 = Xi ⊕ T(Xi+1 ⊕ Xi+2 ⊕ Xi+3 ⊕ rki)
    
    其中T变换:
      T(A) = L(τ(A))
      τ(A) = (S(a0), S(a1), S(a2), S(a3))  # S盒替换
      L(B) = B ⊕ (B <<< 2) ⊕ (B <<< 10) ⊕ (B <<< 18) ⊕ (B <<< 24)

输出: 密文 = (X35, X34, X33, X32)  # 注意顺序反转

解密:
  与加密流程相同，但轮密钥使用逆序 rk31, rk30, ..., rk0
```

        0x70777e85, 0x8c939aa1, 0xa8afb6bd, 0xc4cbd2d9,

    @staticmethod
    def _rotl(x: int, n: int) -> int:
        """32位循环左移"""
        n = n % 32
        return ((x << n) | (x >> (32 - n))) & 0xFFFFFFFF
    
    @staticmethod
    def _tau(a: int) -> int:
        """S盒替换（32位→32位）"""
        b0 = (a >> 24) & 0xFF
        b1 = (a >> 16) & 0xFF
        b2 = (a >> 8) & 0xFF
        b3 = a & 0xFF
        return (SM4.SBOX[b0] << 24) | (SM4.SBOX[b1] << 16) | \
               (SM4.SBOX[b2] << 8) | SM4.SBOX[b3]
    
    @staticmethod
    def _t(a: int) -> int:
        """T变换（加密用）"""
        b = SM4._tau(a)
        return b ^ SM4._rotl(b, 2) ^ SM4._rotl(b, 10) ^ \
               SM4._rotl(b, 18) ^ SM4._rotl(b, 24)
    
    @staticmethod
    def _t_prime(a: int) -> int:
        """T'变换（密钥扩展用）"""
        b = SM4._tau(a)
        return b ^ SM4._rotl(b, 13) ^ SM4._rotl(b, 23)
    
    @staticmethod
    def _key_expansion(key: bytes) -> list:
        """密钥扩展"""
        K = [int.from_bytes(key[i*4:(i+1)*4], 'big') for i in range(4)]
        
        # 与FK异或
        for i in range(4):
            K[i] ^= SM4.FK[i]
        
        rk = []
        for i in range(32):
            tmp = K[1] ^ K[2] ^ K[3] ^ SM4.CK[i]
            tmp = SM4._t_prime(tmp)
            rki = K[0] ^ tmp
            rk.append(rki)
            
            K[0] = K[1]
            K[1] = K[2]
            K[2] = K[3]
            K[3] = rki
        
        return rk
    
    @staticmethod
    def _crypt_block(block: bytes, rk: list, decrypt: bool = False) -> bytes:
        """加密/解密一个分组"""
        X = [int.from_bytes(block[i*4:(i+1)*4], 'big') for i in range(4)]
        
        keys = rk if not decrypt else rk[::-1]
        
        for i in range(32):
            tmp = X[1] ^ X[2] ^ X[3] ^ keys[i]
            tmp = SM4._t(tmp)
            new_x = X[0] ^ tmp
            X[0] = X[1]
            X[1] = X[2]
            X[2] = X[3]
            X[3] = new_x
        
        # 输出反转
        result = X[3]
        result = (result << 32) | X[2]
        result = (result << 32) | X[1]
        result = (result << 32) | X[0]
        
        return result.to_bytes(16, 'big')
    
    @staticmethod
    def encrypt_block(plaintext: bytes, key: bytes) -> bytes:
        """加密单个分组"""
        assert len(plaintext) == 16
        assert len(key) == 16
        rk = SM4._key_expansion(key)
        return SM4._crypt_block(plaintext, rk, decrypt=False)
    
    @staticmethod
    def decrypt_block(ciphertext: bytes, key: bytes) -> bytes:
        """解密单个分组"""
        assert len(ciphertext) == 16
        assert len(key) == 16
        rk = SM4._key_expansion(key)
        return SM4._crypt_block(ciphertext, rk, decrypt=True)
    
    @staticmethod
    def encrypt_ecb(plaintext: bytes, key: bytes) -> bytes:
        """ECB模式加密"""
        # PKCS7填充
        pad_len = 16 - (len(plaintext) % 16)
        plaintext += bytes([pad_len] * pad_len)
        
        rk = SM4._key_expansion(key)
        ciphertext = b''
        for i in range(0, len(plaintext), 16):
            block = plaintext[i:i+16]
            ciphertext += SM4._crypt_block(block, rk, decrypt=False)
        
        return ciphertext
    
    @staticmethod
    def decrypt_ecb(ciphertext: bytes, key: bytes) -> bytes:
        """ECB模式解密"""
        rk = SM4._key_expansion(key)
        plaintext = b''
        for i in range(0, len(ciphertext), 16):
            block = ciphertext[i:i+16]
            plaintext += SM4._crypt_block(block, rk, decrypt=True)
        
        # 去除PKCS7填充
        pad_len = plaintext[-1]
        if 1 <= pad_len <= 16:
            plaintext = plaintext[:-pad_len]
        
        return plaintext
    
    @staticmethod
    def encrypt_cbc(plaintext: bytes, key: bytes, iv: bytes) -> bytes:
        """CBC模式加密"""
        # PKCS7填充
        pad_len = 16 - (len(plaintext) % 16)
        plaintext += bytes([pad_len] * pad_len)
        
        rk = SM4._key_expansion(key)
        prev = iv
        ciphertext = b''
        
        for i in range(0, len(plaintext), 16):
            block = plaintext[i:i+16]
            # 与前一密文块异或
            xored = bytes(a ^ b for a, b in zip(block, prev))
            encrypted = SM4._crypt_block(xored, rk, decrypt=False)
            ciphertext += encrypted
            prev = encrypted
        
        return ciphertext
    
    @staticmethod
    def decrypt_cbc(ciphertext: bytes, key: bytes, iv: bytes) -> bytes:
        """CBC模式解密"""
        rk = SM4._key_expansion(key)
        prev = iv
        plaintext = b''
        
        for i in range(0, len(ciphertext), 16):
            block = ciphertext[i:i+16]
            decrypted = SM4._crypt_block(block, rk, decrypt=True)
            # 与前一密文块异或
            xored = bytes(a ^ b for a, b in zip(decrypted, prev))
            plaintext += xored
            prev = block
        
        # 去除PKCS7填充
        pad_len = plaintext[-1]
        if 1 <= pad_len <= 16:
            plaintext = plaintext[:-pad_len]
        
        return plaintext
    
    @staticmethod
    def encrypt_ctr(plaintext: bytes, key: bytes, nonce: bytes) -> bytes:
        """CTR模式加密"""
        rk = SM4._key_expansion(key)
        counter = int.from_bytes(nonce, 'big')
        ciphertext = b''
        
        for i in range(0, len(plaintext), 16):
            block = plaintext[i:i+16]
            # 生成密钥流
            ctr_block = counter.to_bytes(16, 'big')
            keystream = SM4._crypt_block(ctr_block, rk, decrypt=False)
            # 异或
            encrypted = bytes(a ^ b for a, b in zip(block, keystream[:len(block)]))
            ciphertext += encrypted
            counter += 1
        
        return ciphertext
    
    @staticmethod
    def decrypt_ctr(ciphertext: bytes, key: bytes, nonce: bytes) -> bytes:
        """CTR模式解密（与加密相同）"""
        return SM4.encrypt_ctr(ciphertext, key, nonce)

## 五、SM9标识密码算法

### 5.1 SM9算法概述

**SM9** 是中国标识密码算法标准（GB/T 32918.7-2016），它是一种基于身份的密码（IBC）算法，使用用户的身份标识（如邮箱、身份证号）作为公钥。

**SM9的核心优势：**
- 不需要数字证书
- 不需要PKI体系
- 公钥就是用户标识
- 密钥由密钥生成中心（KGC）生成

### 5.2 SM9与传统PKI对比

| 特性 | 传统PKI（SM2） | 标识密码（SM9） |
|------|---------------|----------------|
| 公钥 | 随机生成 | 用户标识 |
| 证书 | 需要 | 不需要 |
| 密钥生成 | 用户自行 | KGC集中生成 |
| 密钥托管 | 不支持 | 支持 |
| 系统复杂度 | 高 | 低 |
| 密钥管理 | 复杂 | 简单 |
| 信任模型 | 信任CA | 信任KGC |

### 5.3 SM9算法结构

```
SM9系统参数：

  双线性映射: e: G1 × G2 → GT
  G1: 第一椭圆曲线群
  G2: 第二椭圆曲线群
  GT: 有限域上的乘法群
  
  主密钥对:
    主私钥 s ∈ [1, N-1]
    主公钥 P_pub = s * P2  （P2是G2的生成元）
  
  用户密钥对:
    公钥: ID（用户标识，如"alice@example.com"）
    私钥: d_ID = s * H1(ID)  （由KGC计算）

SM9签名:
  签名: 使用私钥d_ID签名消息
  验证: 使用公钥ID验证签名
  
SM9加密:
  加密: 使用公钥ID加密消息
  解密: 使用私钥d_ID解密密文
  
SM9密钥交换:
  双方使用各自的ID和私钥协商共享密钥
```

### 5.4 SM9应用场景

```
SM9适用场景：

  1. 企业内部通信
     - 员工用工号/邮箱作为公钥
     - 不需要部署CA和证书

## 七、祖冲之密码算法（ZUC）

### 7.1 ZUC算法概述

**祖冲之算法（ZUC）** 是中国自主设计的序列密码算法，已作为4G LTE国际标准（3GPP TS 35.221）。

**ZUC特点：**

| 特性 | 说明 |
|------|------|
| 类型 | 序列密码 |
| 密钥长度 | 128位 |
| 初始向量 | 128位 |
| 输出 | 32位/时钟 |
| 结构 | LFSR + 非线性滤波 |
| 应用 | 4G/5G通信加密 |

### 7.2 ZUC算法结构

```
ZUC算法由三部分组成：

  1. 线性反馈移位寄存器（LFSR）
     - 16个31位寄存器单元
     - 基于GF(2^31-1)上的本原多项式
     
  2. 比特重组（BR）
     - 从LFSR状态中提取比特
     - 组合成4个32位字
     
  3. 非线性函数F
     - 使用两个S盒
     - 包含模加运算
     - 输出32位密钥流

ZUC加密流程:
  初始: 128位密钥K + 128位IV
  → LFSR初始化
  → 比特重组
  → F函数
  → 丢弃前32位输出
  → 生成密钥流Z0, Z1, Z2, ...
  
  密文 = 明文 XOR 密钥流
```

### 7.3 ZUC在通信中的应用

```
3GPP机密性和完整性算法：

  128-EEA3 (加密): 基于ZUC的机密性算法
    - 用于4G LTE用户数据和信令加密
    
  128-EIA3 (完整性): 基于ZUC的完整性算法
    - 用于4G LTE信令完整性保护
    
5G中的国密算法:
  5G也可以使用基于ZUC的算法
  作为NEA/NIA算法族的补充
```

### 8.3 国密TLCP协议

**TLCP（Transport Layer Cryptographic Protocol）** 是国密SSL协议标准（GM/T 386-2020），使用国密算法替代国际算法。

```
TLCP与TLS对比:

  TLS 1.2:
    密钥交换: ECDHE
    认证: RSA/ECDSA
    加密: AES
    哈希: SHA-256
    
  TLCP:
    密钥交换: ECDHE-SM2
    认证: SM2
    加密: SM4
    哈希: SM3
    
  特点:
    - 使用SM2双证书（签名证书+加密证书）
    - 兼容TLS 1.2握手流程
    - 支持SM4-GCM/SM4-CBC
```

**TLCP双证书机制：**
```
TLCP使用双证书:
  签名证书: 用于数字签名（签名密钥对）
    └── 私钥由服务器自己保管
    
  加密证书: 用于密钥加密（加密密钥对）
    └── 私钥由CA托管，可恢复

握手流程:
  ClientHello → Server
  Server → ClientHello + 签名证书 + 加密证书 + ServerKeyExchange
  Client → 验证证书 + 生成预主密钥 → 用加密证书公钥加密发送
  双方计算主密钥 → 加密通信
```

def benchmark():
    """性能基准测试"""
    
    # SM3 vs SHA-256
    import hashlib
    
    data = b"x" * 1024 * 1024  # 1MB
    
    # SHA-256
    start = time.time()
    for _ in range(100):
        hashlib.sha256(data).digest()
    sha256_time = time.time() - start
    
    # SM3

        start = time.time()

## 十二、国密算法安全分析

### 12.1 SM2安全分析

```
SM2安全性:
  
  数学基础: 椭圆曲线离散对数问题（ECDLP）
  曲线选择: 随机生成，无后门嫌疑
  安全强度: 256位密钥等效128位安全
  抗量子: 不抗量子计算（与ECDSA相同）
  
  与NIST P-256的安全对比:
    - 都基于素数域椭圆曲线
    - SM2的a值不同（-2 vs -3）
    - 都通过随机性检验
    - NIST曲线有Dual_EC_DRBG后门嫌疑
    - SM2无已知后门
```

### 12.2 SM3安全分析

```
SM3安全性:
  
  结构: Merkle-Damgard结构（与SHA-256类似）
  摘要长度: 256位
  安全强度: 128位（抗碰撞）
  
  已知分析:
    - 差分分析: 不优于暴力攻击
    - 线性分析: 不优于暴力攻击
    - 逆碰撞: 无已知实用攻击
    - 长度扩展攻击: Merkle-Damgard结构固有
    
  与SHA-256对比:
    - 相同结构
    - 不同初始值和常量
    - 相同安全等级
```

### 12.3 SM4安全分析

```
SM4安全性:
  
  结构: 非平衡Feistel网络
  分组/密钥: 128/128位
  轮数: 32轮
  安全强度: 128位
  
  与AES对比:
    - 不同结构（Feistel vs SPN）
    - 相同密钥长度
    - 相同安全等级
    - SM4轮数更多（32 vs 10/12/14）
    
  已知分析:
    - 差分分析: 18轮以下可攻击
    - 线性分析: 22轮以下可攻击
    - 32轮设计有足够安全裕量
    
  侧信道:
    - 需要恒定时间实现
    - 查表实现有Cache时序泄露风险
```

### 12.4 ZUC安全分析

```
ZUC安全性:
  
  已知分析:
    - 最初版本（v1）存在相关密钥攻击
    - v2版本修复了安全问题
    - 3GPP标准化版本（v3）通过安全审查
    
  与Snow 3G对比:
    - 都是3GPP标准序列密码
    - 结构不同
    - 相同安全等级
```

> **总结：** 国密算法是中国信息安全自主可控的重要技术基础。SM2、SM3、SM4、SM9和ZUC构成了完整的国密算法体系，覆盖了非对称密码、对称密码、杂凑算法和序列密码等各个领域。这些算法在安全性和性能上与国际算法相当，且已进入国际标准化体系。随着《密码法》的实施和等保2.0的推进，国密算法在中国的应用将越来越广泛。对于网络安全从业者来说，掌握国密算法的原理、实现和应用，是从事国内安全工作的必备技能。
