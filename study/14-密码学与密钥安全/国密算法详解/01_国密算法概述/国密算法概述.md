# 国密算法概述

### 1.1 什么是国密算法

**国密算法**，即中国商用密码算法，是由国家密码管理局发布的一系列密码算法标准。这些算法旨在为中国境内的信息安全应用提供自主可控的密码技术支撑。

**国密算法体系：**

```
┌───────────────────────────────────────────────────────────┐
│                    国密算法体系                              │
├─────────────┬─────────────────────────────────────────────┤
│  非对称密码   │  SM2（椭圆曲线） SM9（标识密码）               │
├─────────────┼─────────────────────────────────────────────┤
│  对称密码     │  SM4（分组） SM7（分组） ZUC（序列）           │
├─────────────┼─────────────────────────────────────────────┤
│  杂凑算法     │  SM3（杂凑）                                  │
├─────────────┼─────────────────────────────────────────────┤
│  密码协议     │  IPsec VPN、TLS/SSL、SSL VPN等              │
├─────────────┼─────────────────────────────────────────────┤
│  密码应用     │  电子证书、电子签章、电子公文等                │
└─────────────┴─────────────────────────────────────────────┘
```

### 1.2 国密算法发展历程

| 年份 | 事件 | 意义 |
|------|------|------|
| 2006 | SM4算法发布 | 第一个国密分组密码算法 |
| 2007 | SM2算法发布（征求意见稿） | 国密椭圆曲线算法诞生 |
| 2010 | SM2算法正式标准发布 | GB/T 32918系列标准 |
| 2010 | SM3算法正式标准发布 | GB/T 32905标准 |
| 2012 | ZUC算法成为4G LTE标准 | 国际化首突破 |
| 2016 | SM4算法标准更新 | GB/T 32907-2016 |
| 2016 | SM9算法标准发布 | GB/T 32918.7-2016 |
| 2017 | SM2/SM3/SM4进入ISO/IEC标准 | 国际标准化里程碑 |
| 2019 | SM9进入ISO/IEC标准 | 标识密码国际化 |
| 2020 | 《密码法》正式施行 | 密码管理法制化 |
| 2021 | SM4进入TLS 1.3标准草案 | 国密进入Web安全 |
| 2023 | 多项国密算法持续完善 | 生态日益成熟 |

### 1.3 国密算法的法律地位

**《中华人民共和国密码法》（2020年1月1日施行）：**

```
密码分类管理：
  核心密码: 保护国家机密级以上信息
  普通密码: 保护国家秘密级信息
  商用密码: 保护不属于国家秘密的信息
  
商用密码管理：
  - 鼓励商用密码技术的研究和应用
  - 商用密码产品依法纳入市场准入管理
  - 关键信息基础设施使用商用密码进行保护
  - 推动商用密码检测认证体系建设
```

### 1.4 国密算法应用领域

| 应用领域 | 使用算法 | 说明 |
|----------|---------|------|
| 电子政务 | SM2/SM3/SM4 | 公文加密、电子签章 |
| 金融支付 | SM2/SM3/SM4 | 银行卡、移动支付 |
| 通信安全 | ZUC/SM4 | 4G/5G通信加密 |
| 证书认证 | SM2/SM3 | 国密CA证书 |
| VPN网络 | SM2/SM3/SM4 | 国密IPsec/SSL VPN |
| 物联网 | SM2/SM3/SM4 | 设备认证、数据加密 |
| 区块链 | SM2/SM3 | 联盟链签名验证 |
| 智能电网 | SM2/SM4 | 电力系统安全 |
