# 祖冲之密码算法（ZUC）

### 7.1 ZUC算法概述

**祖冲之算法（ZUC）** 是中国自主设计的序列密码算法，已作为4G LTE国际标准（3GPP TS 35.221）。

**ZUC特点：**

| 特性 | 说明 |
|------|------|
| 类型 | 序列密码 |
| 密钥长度 | 128位 |
| 初始向量 | 128位 |
| 输出 | 32位/时钟 |
| 结构 | LFSR + 非线性滤波 |
| 应用 | 4G/5G通信加密 |

### 7.2 ZUC算法结构

```
ZUC算法由三部分组成：

  1. 线性反馈移位寄存器（LFSR）
     - 16个31位寄存器单元
     - 基于GF(2^31-1)上的本原多项式
     
  2. 比特重组（BR）
     - 从LFSR状态中提取比特
     - 组合成4个32位字
     
  3. 非线性函数F
     - 使用两个S盒
     - 包含模加运算
     - 输出32位密钥流

ZUC加密流程:
  初始: 128位密钥K + 128位IV
  → LFSR初始化
  → 比特重组
  → F函数
  → 丢弃前32位输出
  → 生成密钥流Z0, Z1, Z2, ...
  
  密文 = 明文 XOR 密钥流
```

### 7.3 ZUC在通信中的应用

```
3GPP机密性和完整性算法：

  128-EEA3 (加密): 基于ZUC的机密性算法
    - 用于4G LTE用户数据和信令加密
    
  128-EIA3 (完整性): 基于ZUC的完整性算法
    - 用于4G LTE信令完整性保护
    
5G中的国密算法:
  5G也可以使用基于ZUC的算法
  作为NEA/NIA算法族的补充
```
