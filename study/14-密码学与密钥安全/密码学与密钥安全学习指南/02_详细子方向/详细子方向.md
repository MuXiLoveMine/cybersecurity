# 详细子方向

### 2.1 密码学基础

#### 2.1.1 密码学概述
**密码学概念**
- 密码学（Cryptography）：研究信息加密和解密的科学
- 密码分析（Cryptanalysis）：研究破解密码的科学
- 密码学 = 密码编码学 + 密码分析学

**密码学目标**
- 保密性（Confidentiality）：信息不被未授权者获取
- 完整性（Integrity）：信息不被篡改
- 认证性（Authentication）：身份和消息的认证
- 不可否认性（Non-repudiation）：不能否认已发生的操作

#### 2.1.2 密码学发展历程
**古典密码学**
- 替换密码：凯撒密码、维吉尼亚密码
- 置换密码：栅栏密码、列置换
- 特点：简单、易破解

**近代密码学**
- 机械密码：恩尼格玛机
- 一次一密
- 特点：机械化、复杂度提高

**现代密码学**
- 对称加密：DES、AES
- 非对称加密：RSA、ECC
- 哈希函数：MD5、SHA
- 数字签名
- 公钥基础设施
- 特点：数学基础、计算机实现

#### 2.1.3 数学基础
**必备数学知识**
- 数论：素数、模运算、欧拉定理、费马小定理
- 代数：群、环、域
- 概率论：概率统计
- 信息论：熵、信息量
- 计算复杂性：NP 问题

### 2.3 对称加密

#### 2.3.1 对称加密概述
**对称加密概念**
- 加密和解密使用相同的密钥
- 也叫私钥加密、秘密密钥加密
- 速度快，适合大数据量
- 密钥分发困难

**对称加密分类**
- 分组密码（Block Cipher）：按块加密，如 DES、AES
- 流密码（Stream Cipher）：按字节/位加密，如 RC4、ChaCha20

#### 2.3.2 分组密码
**分组密码原理**
- 将明文分成固定长度的块
- 每块单独加密
- 常见块大小：64 位、128 位

**常见分组密码算法**
- DES：数据加密标准，56 位密钥，已不安全
- 3DES：三重 DES，112/168 位密钥，逐渐淘汰
- AES：高级加密标准，128/192/256 位密钥，当前标准
- SM4：国密算法，128 位密钥
- Blowfish、Twofish、Serpent 等

**分组密码工作模式**
- ECB：电子密码本，不安全，不推荐
- CBC：密码分组链接，常用
- CFB：密码反馈
- OFB：输出反馈
- CTR：计数器模式，常用
- GCM：伽罗瓦/计数器模式，认证加密，推荐

#### 2.3.3 流密码
**流密码原理**
- 生成密钥流
- 与明文异或
- 速度快
- 适合实时通信

**常见流密码算法**
- RC4：已不安全
- ChaCha20：现代流密码，安全高效
- Salsa20：ChaCha20 前身
- A5/1、A5/2：GSM 加密，已破解

#### 2.3.4 对称加密攻击
**常见攻击方式**
- 暴力破解
- 字典攻击
- 已知明文攻击
- 选择明文攻击
- 选择密文攻击
- 差分密码分析
- 线性密码分析
- 侧信道攻击

### 2.4 非对称加密

#### 2.4.1 非对称加密概述
**非对称加密概念**
- 加密和解密使用不同的密钥
- 公钥（Public Key）：公开，用于加密
- 私钥（Private Key）：保密，用于解密
- 也叫公钥加密

**非对称加密特点**
- 解决密钥分发问题
- 速度慢，不适合大数据量
- 可用于数字签名
- 基于数学难题

#### 2.4.2 RSA 算法
**RSA 原理**
- 基于大整数分解难题
- 密钥生成：选两个大素数 p、q，计算 n = p*q
- 公钥：(e, n)
- 私钥：(d, n)
- 加密：c = m^e mod n
- 解密：m = c^d mod n

**RSA 安全**
- 密钥长度：2048 位起步，推荐 4096 位
- 攻击：大整数分解、侧信道攻击
- 填充方式：PKCS#1 v1.5、OAEP

#### 2.4.3 椭圆曲线密码（ECC）
**ECC 原理**
- 基于椭圆曲线离散对数难题
- 密钥更短，安全性更高
- 256 位 ECC ≈ 3072 位 RSA

**常见 ECC 算法**
- ECDSA：椭圆曲线数字签名算法
- ECDH：椭圆曲线密钥交换
- Ed25519：Edwards 曲线签名
- Curve25519：Diffie-Hellman 曲线

**ECC 优势**
- 密钥短
- 速度快
- 功耗低
- 适合移动设备和物联网

#### 2.4.4 其他非对称算法
**其他算法**
- DSA：数字签名算法
- ElGamal：加密和签名
- 背包密码：已破解
- 格密码：抗量子

### 2.5 哈希函数

#### 2.5.1 哈希函数概述
**哈希函数概念**
- 将任意长度的输入映射为固定长度的输出
- 也叫散列函数、消息摘要
- 单向函数，不可逆

**哈希函数性质**
- 单向性：无法从哈希值反推原文
- 抗碰撞性：很难找到两个不同的输入有相同的哈希值
- 雪崩效应：输入微小变化，输出巨大变化
- 确定性：相同输入总是产生相同输出

#### 2.5.2 常见哈希算法
**MD5**
- 128 位输出
- 已被破解，不推荐使用
- 碰撞攻击可行

**SHA-1**
- 160 位输出
- 已被破解，不推荐使用
- 碰撞攻击可行

**SHA-2 系列**
- SHA-224、SHA-256、SHA-384、SHA-512
- 当前安全标准
- 推荐使用

**SHA-3 系列**
- 最新标准
- 基于 Keccak 算法
- 设计不同，更安全

**国密哈希**
- SM3：国密哈希算法
- 256 位输出
- 中国标准

#### 2.5.3 哈希攻击
**常见攻击**
- 暴力破解
- 字典攻击
- 彩虹表
- 碰撞攻击
- 长度扩展攻击
- 前缀碰撞攻击

**防护措施**
- 使用强哈希算法
- 加盐（Salt）
- 慢哈希（bcrypt、scrypt、Argon2）
- 密钥哈希（HMAC）

### 2.6 消息认证码

#### 2.6.1 MAC 概述
**MAC 概念**
- Message Authentication Code
- 消息认证码
- 用于验证消息的完整性和真实性
- 需要密钥

**MAC 性质**
- 需要密钥
- 验证完整性
- 验证真实性
- 不可否认性？不，双方共享密钥

#### 2.6.2 HMAC
**HMAC 概念**
- Hash-based MAC
- 基于哈希函数的消息认证码
- 使用哈希函数 + 密钥

**HMAC 原理**
- HMAC(K, m) = H((K ⊕ opad) || H((K ⊕ ipad) || m))
- 内层哈希 + 外层哈希
- 使用两个填充：ipad 和 opad

**常见 HMAC**
- HMAC-MD5（不推荐）
- HMAC-SHA1（不推荐）
- HMAC-SHA256（推荐）
- HMAC-SHA512（推荐）

### 2.7 数字签名

#### 2.7.1 数字签名概述
**数字签名概念**
- 用私钥签名，用公钥验证
- 类似于手写签名
- 提供认证性、完整性、不可否认性

**数字签名性质**
- 不可伪造：只有私钥持有者能签名
- 不可否认：签名后不能否认
- 不可篡改：签名后消息不能改
- 可验证：任何人都可以用公钥验证

#### 2.7.2 常见签名算法
**RSA 签名**
- 基于 RSA 算法
- 常用填充：PKCS#1 v1.5、PSS
- 密钥长度：2048+ 位

**DSA 签名**
- Digital Signature Algorithm
- 基于离散对数
- 只能签名，不能加密

**ECDSA 签名**
- 椭圆曲线数字签名算法
- 基于 ECC
- 密钥更短，速度更快

**Ed25519**
- Edwards 曲线签名
- 现代签名算法
- 安全高效

**国密签名**
- SM2：国密椭圆曲线签名算法
- 中国标准

### 2.8 密钥交换协议

#### 2.8.1 Diffie-Hellman 密钥交换
**DH 原理**
- 双方在不安全信道上协商出共享密钥
- 基于离散对数难题
- 不传输密钥，只交换公开值

**DH 流程**
1. 双方约定公共参数（p, g）
2. 各自生成私钥（a, b）
3. 各自计算公钥（A = g^a mod p, B = g^b mod p）
4. 交换公钥
5. 各自计算共享密钥（s = B^a mod p = A^b mod p）

**DH 问题**
- 不提供身份认证
- 容易遭受中间人攻击
- 需要结合身份认证

#### 2.8.2 ECDH
**ECDH 概念**
- Elliptic Curve Diffie-Hellman
- 椭圆曲线版本的 DH
- 密钥更短，效率更高

#### 2.8.3 其他密钥交换
**其他协议**
- RSA 密钥交换
- PSK（预共享密钥）
- 握手协议（如 TLS 握手）

#### 2.9.5 密钥分层
**密钥分层架构**
- 主密钥（Master Key）：最高级，保护其他密钥
- 密钥加密密钥（KEK）：加密数据密钥

**分层优势**

### 2.10 PKI 公钥基础设施

#### 2.10.1 PKI 概述
**PKI 概念**
- Public Key Infrastructure
- 公钥基础设施
- 管理公钥和数字证书的体系

**PKI 组成**
- CA（证书颁发机构）：颁发证书
- RA（注册机构）：审核注册
- 证书库：存储证书
- 终端实体：用户/设备
- 证书撤销列表（CRL）
- OCSP（在线证书状态协议）

#### 2.10.2 数字证书
**数字证书概念**
- 证明公钥归属的电子文档
- 由 CA 签发
- 包含公钥、身份信息、CA 签名等

**X.509 证书**
- 标准证书格式
- 版本
- 序列号
- 签名算法
- 颁发者
- 有效期
- 主体
- 公钥
- 扩展
- 签名

#### 2.10.3 CA 体系
**CA 层级**
- 根 CA：最顶层，自签名
- 中间 CA：由根 CA 签发
- 终端实体证书：由中间 CA 签发

**信任链**
- 从根 CA 到终端证书的链条
- 逐级验证
- 信任根 CA 就信任整个链条

#### 2.10.4 证书生命周期
**证书生命周期**
1. 证书申请
2. 身份验证
3. 证书颁发
4. 证书使用
5. 证书更新
6. 证书撤销
7. 证书过期

#### 2.10.5 证书撤销
**撤销原因**
- 私钥泄露
- 身份变更
- 关系终止
- 安全事件

**撤销机制**
- CRL（证书撤销列表）
- OCSP（在线证书状态协议）
- OCSP Stapling

### 2.11 TLS/SSL 协议

#### 2.11.1 TLS 概述
**TLS 概念**
- Transport Layer Security
- 传输层安全协议
- 前身是 SSL（Secure Sockets Layer）
- 提供加密、认证、完整性保护

**TLS 历史**
- SSL 1.0、2.0、3.0（已不安全）
- TLS 1.0、1.1（已淘汰）
- TLS 1.2（当前主流）
- TLS 1.3（最新，推荐）

#### 2.11.2 TLS 握手
**TLS 握手过程**
1. Client Hello：客户端支持的密码套件、随机数
2. Server Hello：选择的密码套件、随机数
3. 证书：服务器证书
4. 密钥交换：协商共享密钥
5. 完成：双方验证握手完成

**密钥交换算法**
- RSA 密钥交换
- DHE（Diffie-Hellman 临时）
- ECDHE（椭圆曲线 DH 临时）
- PSK（预共享密钥）

#### 2.11.3 TLS 安全
**常见攻击**
- BEAST
- CRIME
- POODLE
- Heartbleed
- Logjam
- FREAK
- Lucky 13
- 降级攻击

**安全最佳实践**
- 使用 TLS 1.2+，推荐 1.3
- 禁用弱密码套件
- 使用强证书
- 启用 HSTS
- 证书钉扎
- 前向保密

### 2.14 密码分析

- 发现密码算法的弱点

#### 2.14.2 对称密码分析
**分析方法**

- 时序攻击
- 功耗分析（SPA、DPA）

- 故障注入攻击
