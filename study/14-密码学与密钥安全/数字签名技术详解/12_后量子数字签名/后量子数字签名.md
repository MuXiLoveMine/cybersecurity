# 后量子数字签名

### 12.1 量子计算对签名的威胁

```
量子计算威胁：
  Shor算法:  可以在多项式时间内分解大整数和求解离散对数
             → RSA、DSA、ECDSA全部不安全
  Grover算法: 将对称密钥安全强度减半
             → 需要更长的哈希输出

影响评估：
  RSA-2048   → 量子下等效80位安全（不安全）
  ECDSA-256  → 量子下等效128/2≈不安全
  Ed25519    → 量子下等效128/2≈不安全
  SHA-256    → 量子下等效128位（基本安全）
  AES-256    → 量子下等效128位（基本安全）
```

### 12.2 NIST后量子签名标准

NIST后量子密码标准化竞赛选出的签名算法：

| 算法 | 类型 | 签名大小 | 公钥大小 | 私钥大小 | 安全等级 |
|------|------|---------|---------|---------|---------|
| ML-DSA (CRYSTALS-Dilithium) | 格基 | 3309B | 1312B | 2560B | Level 2 |
| SLH-DSA (SPHINCS+) | 哈希基 | 7856B | 64B | 64B | Level 2 |
| Falcon | 格基+NTRU | 666B | 897B | 1280B | Level 1 |

### 12.3 混合签名方案

```
混合签名方案：
  传统签名 + 后量子签名 → 混合签名
  
  优势：
  1. 即使量子计算成熟，传统签名仍提供安全
  2. 即使后量子算法有缺陷，传统签名仍提供安全
  3. 平滑过渡到后量子时代

  实现方式：
  1. 串行签名：先传统签名，再后量子签名
  2. 并行签名：两种签名独立产生
  3. 嵌套签名：一种签名嵌入另一种
```

```python
"""
混合签名方案概念实现
"""
from cryptography.hazmat.primitives.asymmetric import ec, ed25519
from cryptography.hazmat.primitives import hashes
import json
import base64

class HybridSigner:
    """混合签名（ECDSA + Ed25519）"""
    
    def __init__(self):
        # 传统算法密钥
        self.ecdsa_key = ec.generate_private_key(ec.SECP256R1())
        # 新一代算法密钥
        self.ed25519_key = ed25519.Ed25519PrivateKey.generate()
    
    def sign(self, message: bytes) -> dict:
        """双重签名"""
        # ECDSA签名
        ecdsa_sig = self.ecdsa_key.sign(
            message,
            ec.ECDSA(hashes.SHA256())
        )
        
        # Ed25519签名
        ed25519_sig = self.ed25519_key.sign(message)
        
        return {
            'message': message.hex(),
            'ecdsa_signature': base64.b64encode(ecdsa_sig).decode(),
            'ed25519_signature': base64.b64encode(ed25519_sig).decode(),
            'algorithms': ['ECDSA-P256-SHA256', 'Ed25519']
        }
    
    def verify(self, message: bytes, sig_data: dict) -> bool:
        """双重验证"""
        # 验证ECDSA
        try:
            self.ecdsa_key.public_key().verify(
                base64.b64decode(sig_data['ecdsa_signature']),
                message,
                ec.ECDSA(hashes.SHA256())
            )
            ecdsa_valid = True
        except Exception:
            ecdsa_valid = False
        
        # 验证Ed25519
        try:
            self.ed25519_key.public_key().verify(
                base64.b64decode(sig_data['ed25519_signature']),
                message
            )
            ed25519_valid = True
        except Exception:
            ed25519_valid = False
        
        # 两种签名都通过才算有效
        return ecdsa_valid and ed25519_valid


# 使用示例
hybrid = HybridSigner()
message = b"Important document"

sig = hybrid.sign(message)
print(f"ECDSA签名长度: {len(base64.b64decode(sig['ecdsa_signature']))} bytes")
print(f"Ed25519签名长度: {len(base64.b64decode(sig['ed25519_signature']))} bytes")

valid = hybrid.verify(message, sig)
print(f"混合签名验证: {valid}")
```
