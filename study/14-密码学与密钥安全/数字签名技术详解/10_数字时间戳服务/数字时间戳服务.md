# 数字时间戳服务

### 9.1 时间戳概述

**数字时间戳（Digital Timestamp）** 服务为电子文档提供可信的时间证明，证明某个文档在特定时间点已经存在。

```
时间戳的作用：
  1. 证明文档在某个时间点之前已经存在
  2. 为数字签名提供时间证明（防止签名后私钥泄露的回溯攻击）
  3. 满足法律对时间证据的要求
  4. 在专利申请、版权保护中的应用
```

### 9.2 RFC 3161时间戳协议

```
时间戳请求/响应流程：

  客户端                        TSA（时间戳机构）
    │                              │
    │── TimeStampReq ────────────→│
    │   (文档哈希)                  │
    │                              │ 获取当前时间
    │                              │ 用TSA私钥签名
    │←── TimeStampResp ───────────│
    │   (时间戳令牌)                │
    
TimeStampReq结构：
  version: 1
  messageImprint: 消息哈希（算法+值）
  reqPolicy: 请求的策略（可选）
  nonce: 随机数（防重放）
  certReq: 是否请求证书

TimeStampResp结构：
  status: 状态码
  statusString: 状态描述
  timeStampToken: 时间戳令牌（CMS格式）
```

"""
RFC 3161时间戳客户端
"""
import http.client
import hashlib

from cryptography.hazmat.primitives import hashes, serialization
from cryptography.x509 import load_der_x509_certificate
import asn1

class TimestampClient:
    """数字时间戳客户端"""
    
    TSA_URLS = {
        'digiCert': 'http://timestamp.digicert.com',
        'globalsign': 'http://timestamp.globalsign.com',
        'sectigo': 'http://timestamp.sectigo.com',
    }
    
    @staticmethod
    def create_request(data: bytes, 
                       hash_algorithm: str = 'sha256') -> bytes:
        """
        创建时间戳请求
        
        Args:
            data: 要加时间戳的数据
            hash_algorithm: 哈希算法
            
        Returns:
            DER编码的时间戳请求
        """
        # 计算哈希
        if hash_algorithm == 'sha256':
            h = hashlib.sha256(data).digest()
            oid = bytes.fromhex('0609608648016503040201')  # SHA-256 OID
        elif hash_algorithm == 'sha384':
            h = hashlib.sha384(data).digest()
            oid = bytes.fromhex('0609608648016503040202')
        else:
            raise ValueError(f"不支持的哈希算法: {hash_algorithm}")
        
        # 构建ASN.1请求（简化版）
        # 实际应使用pyasn1等库构建完整的ASN.1结构
        # 这里展示概念
        nonce = hashlib.sha256(data + str(hash(data)).encode()).digest()
        
        # 使用pyasn1构建请求
        # pip install pyasn1
        try:
            from pyasn1.type import univ, namedtype, tag
            from pyasn1.codec.der import encoder
            
            class MessageImprint(univ.Sequence):
                componentType = namedtype.NamedTypes(
                    namedtype.NamedType('hashAlgorithm', univ.Any()),
                    namedtype.NamedType('hashedMessage', univ.OctetString())
                )
            
            class TimeStampReq(univ.Sequence):
                componentType = namedtype.NamedTypes(
                    namedtype.NamedType('version', univ.Integer()),
                    namedtype.NamedType('messageImprint', MessageImprint()),
                    namedtype.NamedType('nonce', univ.Integer()),
                    namedtype.NamedType('certReq', univ.Boolean())
                )
            
            req = TimeStampReq()
            req['version'] = 1
            req['messageImprint']['hashAlgorithm'] = oid
            req['messageImprint']['hashedMessage'] = h
            req['nonce'] = int.from_bytes(nonce[:8], 'big')
            req['certReq'] = True
            
            return encoder.encode(req)
        except ImportError:
            print("需要pyasn1库: pip install pyasn1")
            return None
    
    @staticmethod
    def get_timestamp(data: bytes, tsa_url: str = None) -> bytes:
        """
        获取时间戳
        
        Args:
            data: 要加时间戳的数据
            tsa_url: TSA服务URL
            
        Returns:
            时间戳令牌（DER编码）
        """
        if tsa_url is None:
            tsa_url = TimestampClient.TSA_URLS['digiCert']
        
        # 创建请求
        request = TimestampClient.create_request(data)
        if request is None:
            return None
        
        # 发送HTTP请求
        parsed = urlparse(tsa_url)
        if parsed.scheme == 'http':
            conn = http.client.HTTPConnection(parsed.netloc)
        else:
            conn = http.client.HTTPSConnection(parsed.netloc)
        
        conn.request(
            "POST",
            parsed.path or "/",
            body=request,
            headers={
                "Content-Type": "application/timestamp-query",
                "Accept": "application/timestamp-reply"
            }
        )
        
        response = conn.getresponse()
        token = response.read()
        conn.close()
        
        return token

### 9.3 长期签名验证（LTV）

长期签名的验证需要考虑证书过期和算法过时的问题：

```
长期签名验证时间线：

  签名时 → 证书有效期内 → 证书过期后 → 长期保存

  签名时：
    1. 验证签名
    2. 验证证书链
    3. 验证证书状态（OCSP/CRL）
    
  证书有效期内：
    4. 添加时间戳（证明签名时间）
    5. 保存验证材料（证书链+OCSP/CRL）
    
  证书过期后：
    6. 添加归档时间戳（用新算法）
    7. 重新保存验证材料
    8. 循环步骤6-7以保持长期有效
```
