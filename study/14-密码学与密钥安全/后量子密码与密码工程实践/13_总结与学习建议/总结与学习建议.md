# 总结与学习建议

### 核心要点总结

```
后量子密码核心：
  1. Shor算法威胁RSA/ECC，Grover算法削弱对称加密
  2. NIST已发布ML-KEM/ML-DSA/SLH-DSA标准
  3. 迁移策略：混合部署 → 过渡 → 完全后量子
  4. 密钥尺寸增大是主要代价

密码工程核心：
  1. 理论安全 ≠ 实现安全
  2. 常量时间实现是基础要求
  3. 填充Oracle攻击是经典陷阱
  4. 随机数安全是密码学根基
  5. 侧信道攻击从理论到实践
  6. 不自行实现密码算法和协议

国密合规核心：
  1. SM2/SM3/SM4对应国际算法
  2. GM/T系列标准指导工程实现
  3. GmSSL/Tongsuo提供实现工具
  4. 金融和关基行业强制要求
```

### 学习建议

```
入门路径：
  1. 理解量子计算基础概念（Shor、Grover算法）
  2. 阅读NIST PQC标准（FIPS 203/204/205）
  3. 使用liboqs库体验后量子算法
  4. 学习经典密码工程漏洞（Heartbleed、Padding Oracle）
  5. 实践libsodium/OpenSSL安全编程
  6. 了解GM/T标准和GmSSL使用
  7. 关注IETF后量子TLS（hybrid ECDHE-Kyber）

进阶方向：
  - 格密码数学基础（LWE/Module-LWE）
  - 密码协议形式化验证（Tamarin、ProVerif）
  - 侧信道攻击实践（DPA、cache timing）
  - 后量子算法工程实现优化
  - 国密+后量子融合方案研究
  - 密码模块安全评估（FIPS 140-3 / GM/T 0028）

实践项目建议：
  1. 搭建TLS + 后量子混合密钥交换
  2. 实现Padding Oracle攻击PoC
  3. 编写常量时间密码比较函数
  4. 部署GmSSL国密TLS服务
  5. 实现SM2签名验证（使用GmSSL）
  6. 对比PQC算法性能基准测试
```

---

> 本文涵盖了后量子密码（量子威胁、NIST标准、迁移策略）和密码工程实践（实现安全、密码库选择、合规测试、国密算法）两大领域。后量子密码是面向未来的准备，密码工程是当下的基本功。安全学习者应同时关注"未来威胁"和"当下漏洞"——既要为量子计算时代做准备，也要确保今天的密码实现经得起攻击。建议在理解理论的基础上，动手实践后量子算法库和国密算法库，将知识转化为实战能力。
