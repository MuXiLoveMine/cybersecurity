# 密码工程安全清单

### 12.1 开发阶段安全清单

```
密码工程开发安全清单：

[ ] 算法选择
    [ ] 使用标准算法（AES、RSA、ECC、SM2/3/4）
    [ ] 不使用已破算法（RC4、DES、MD5）
    [ ] 密钥长度满足安全要求（AES-256、RSA-3072+）
    [ ] 考虑后量子兼容性（混合方案）

[ ] 协议设计
    [ ] 使用标准协议（TLS 1.3、Signal协议）
    [ ] 不自行设计密码协议
    [ ] 前向保密（PFS）使用临时密钥
    [ ] 使用AEAD模式（GCM、ChaCha20-Poly1305）

[ ] 密钥管理
    [ ] 密钥使用CSPRNG生成
    [ ] 密钥存储加密（HSM/KMS）
    [ ] 密钥轮换机制
    [ ] 密钥销毁安全覆盖

[ ] 实现
    [ ] 使用经过审计的密码库
    [ ] 常量时间比较（hmac.compare_digest）
    [ ] 不泄露错误细节（统一错误信息）
    [ ] IV/Nonce不重复使用
    [ ] 随机数使用os.urandom/secrets

[ ] 测试
    [ ] 已知答案测试（KAT）
    [ ] 边界条件测试
    [ ] 模糊测试（fuzzing）
    [ ] 侧信道分析测试
    [ ] 互操作性测试

[ ] 部署
    [ ] 密码库版本及时更新
    [ ] 禁用弱密码套件
    [ ] HSTS启用
    [ ] 证书自动轮换
    [ ] 监控密码使用异常
```

### 12.2 运维阶段安全清单

```
密码工程运维安全清单：

[ ] 漏洞管理
    [ ] 订阅CVE通知（OpenSSL等）
    [ ] 密码库补丁及时更新
    [ ] 定期安全扫描

[ ] 证书管理
    [ ] 证书有效期监控（自动告警）
    [ ] 证书吊销列表（CRL/OCSP）更新
    [ ] CA私钥安全存储

[ ] 密钥审计
    [ ] 密钥使用日志
    [ ] 异常密钥访问检测
    [ ] 定期密钥轮换验证

[ ] 合规检查
    [ ] 年度密码合规审计
    [ ] 密码模块安全等级验证
    [ ] 算法使用合规性检查

[ ] 应急准备
    [ ] 密钥泄露应急流程
    [ ] 证书快速替换方案
    [ ] 算法迁移预案（如SHA-1→SHA-256）
    [ ] 后量子迁移路线图
```
