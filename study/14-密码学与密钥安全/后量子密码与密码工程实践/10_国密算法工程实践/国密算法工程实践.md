# 国密算法工程实践

### 10.1 SM2/SM3/SM4 工程实现要点

```
国密算法概要：

SM2（椭圆曲线公钥密码）：
  └── 基于256位素域椭圆曲线
  └── 包含：数字签名、密钥交换、公钥加密
  └── 曲线参数：y² = x³ + ax + b (a, b固定)
  └── 基点G阶n：256位素数

SM3（密码杂凑算法）：
  └── 输出256位哈希值
  └── Merkle-Damgard结构
  └── 消息分组512位，64轮压缩函数
  └── 安全性类比SHA-256

SM4（分组密码算法）：
  └── 128位分组，128位密钥
  └── 32轮Feistel型结构（非标准Feistel）
  └── S盒、线性变换L、轮函数F
  └── 安全性类比AES-128
```

**SM2 签名验证实现要点：**

```python
# SM2签名验证（使用GmSSL/cryptography国密扩展）
# 注意：实际工程中推荐使用GmSSL等成熟库

"""
SM2签名算法（GB/T 32918.2）：

签名生成：
  1. 生成随机数 k ∈ [1, n-1]
  2. 计算椭圆曲线点 (x1, y1) = [k]G
  3. 计算 r = (e + x1) mod n  （e = SM3(Z || M)）
  4. 若 r=0 或 r+k=n 则重新选择k
  5. 计算 s = ((1 + dA)^-1 * (k - r * dA)) mod n
  6. 签名 = (r, s)

签名验证：
  1. 检查 r, s ∈ [1, n-1]
  2. 计算 e = SM3(Z || M)
  3. 计算 t = (r + s) mod n
  4. 计算 (x1, y1) = [s]G + [t]PA
  5. 计算 R = (e + x1) mod n
  6. 验证 R == r

关键工程要点：
  - Z为用户ID信息（默认"1234567812345678"的SM3）
  - 随机数k必须每次不同且不可预测
  - 验证时需检查r和s的范围
  - 侧信道防护：常量时间标量乘法
"""
```

### 10.2 GmSSL 库使用

```
GmSSL（OpenSSL国密扩展）：

项目地址：https://github.com/guanzhi/GmSSL

特性：
  ├── SM2密钥对生成、签名、验证
  ├── SM2加密解密
  ├── SM3哈希计算
  ├── SM4 ECB/CBC/CTR/GCM模式
  ├── 国密TLS（支持SM2+SM3+SM4密码套件）
  ├── 国密X.509证书
  └── 兼容OpenSSL API风格

命令行示例：
  # SM3哈希
  gmssl sm3 -in data.txt
  
  # SM4加密
  gmssl sm4 -in plaintext.txt -out ciphertext.bin -K <hex_key> -iv <hex_iv>
  
  # SM2密钥生成
  gmssl ecparam -genkey -name sm2p256v1 -out sm2key.pem
  
  # SM2签名
  gmssl sm2sign -in data.txt -inkey sm2key.pem -out signature.bin
  
  # SM2验证
  gmssl sm2verify -in data.txt -sig signature.bin -pubkey sm2pub.pem
```

```python
# Python调用GmSSL（通过subprocess或绑定）
import subprocess

class GmSSLWrapper:
    """GmSSL命令行封装"""
    
    def __init__(self, gmssl_path='gmssl'):
        self.gmssl_path = gmssl_path
    
    def sm3_hash(self, data):
        """计算SM3哈希"""
        result = subprocess.run(
            [self.gmssl_path, 'sm3'],
            input=data,
            capture_output=True
        )
        return result.stdout.strip()
    
    def sm4_encrypt(self, plaintext, key, iv, mode='CBC'):
        """SM4加密"""
        hex_key = key.hex()
        hex_iv = iv.hex()
        result = subprocess.run(
            [self.gmssl_path, 'sm4', '-e',
             '-K', hex_key, '-iv', hex_iv,
             '-in', '/dev/stdin', '-out', '/dev/stdout'],
            input=plaintext,
            capture_output=True
        )
        return result.stdout
    
    def sm2_sign(self, data, key_file):
        """SM2签名"""
        result = subprocess.run(
            [self.gmssl_path, 'sm2sign',
             '-inkey', key_file],
            input=data,
            capture_output=True
        )
        return result.stdout
```

### 10.3 GmJS 库使用

```javascript
// GmJS - JavaScript国密库
// 用于浏览器端或Node.js端的国密算法实现

const sm2 = require('gm-js').sm2;
const sm3 = require('gm-js').sm3;
const sm4 = require('gm-js').sm4;

// SM3哈希
const hash = sm3.digest('Hello, 国密!');
console.log('SM3:', hash.toString('hex'));

// SM2密钥对生成
const keypair = sm2.generateKeyPair();
console.log('公钥:', keypair.publicKey);
console.log('私钥:', keypair.privateKey);

// SM2签名
const message = '重要数据';
const signature = sm2.sign(message, keypair.privateKey);

// SM2验证
const isValid = sm2.verify(message, signature, keypair.publicKey);
console.log('签名验证:', isValid);

// SM4加密
const key = Buffer.from('0123456789abcdeffedcba9876543210', 'hex');
const iv = Buffer.from('0123456789abcdeffedcba9876543210', 'hex');
const plaintext = Buffer.from('Hello SM4!');
const ciphertext = sm4.encrypt(plaintext, key, iv, 'CBC');

// SM4解密
const decrypted = sm4.decrypt(ciphertext, key, iv, 'CBC');
console.log('解密:', decrypted.toString());
```
