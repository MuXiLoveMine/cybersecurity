# 密码库安全选择

### 7.1 主流密码库对比

| 特性 | OpenSSL | GnuTLS | libsodium | BoringSSL |
|------|---------|--------|-----------|-----------|
| 维护方 | OpenSSL项目 | GnuTLS社区 | Frank Denis等 | Google |
| 代码规模 | 庞大（~50万行） | 中等（~20万行） | 小（~3万行） | 中等 |
| API设计 | 复杂，历史包袱 | 中等 | 简洁，现代 | 简洁 |
| 安全审计 | 广泛审计 | 有审计 | 有审计 | Google内部审计 |
| 内存安全 | C语言，需小心 | C语言 | C语言 | C语言 |
| 适用场景 | 通用TLS/密码 | TLS库为主 | 应用层密码 | Chromium/Android |
| FIPS认证 | 有（FIPS模块） | 有 | 无 | 无 |
| 国密支持 | 需GmSSL分支 | 有限 | 无 | 无 |

**选择建议：**

```
密码库选择决策树：

需要TLS通信？
  ├── 是 → OpenSSL / GnuTLS / BoringSSL
  │        ├── 需要FIPS → OpenSSL FIPS模块
  │        ├── Chromium/Android → BoringSSL
  │        └── 通用 → OpenSSL 3.x
  │
  └── 否（应用层密码）→ libsodium
       ├── 简单API，不易出错
       ├── 默认安全参数
       └── 适合非密码专家使用

需要国密算法？
  ├── GmSSL（OpenSSL国密分支）
  ├── GmJS（JavaScript国密库）
  └── Tongsuo（蚂蚁开源，兼容OpenSSL+国密）
```

### 7.2 libsodium 使用示例

```python
# libsodium Python绑定（PyNaCl）
from nacl import secret, utils, signing, box
from nacl.public import PrivateKey, PublicKey

# 1. 对称加密（XSalsa20-Poly1305）
def symmetric_encrypt():
    key = secret.SecretKey.generate()  # 256位密钥
    nonce = utils.random(secret.NONCE_SIZE)  # 24字节nonce
    
    box_obj = secret.SecretBox(key)
    message = b"Hello, Post-Quantum World!"
    encrypted = box_obj.encrypt(message, nonce)
    
    # 解密
    decrypted = box_obj.decrypt(encrypted)
    print(f"Decrypted: {decrypted}")
    
# 2. 非对称加密（Curve25519 + XSalsa20-Poly1305）
def asymmetric_encrypt():
    # 接收方生成密钥对
    recipient_private = PrivateKey.generate()
    recipient_public = recipient_private.public_key
    
    # 发送方加密
    sender_private = PrivateKey.generate()
    encrypted = box.SealedBox(recipient_public).encrypt(
        b"Secret message"
    )
    
    # 接收方解密
    decrypted = box.SealedBox(recipient_private).decrypt(encrypted)
    print(f"Decrypted: {decrypted}")

# 3. 数字签名（Ed25519）
def digital_sign():
    # 生成签名密钥对
    signing_key = signing.SigningKey.generate()
    verify_key = signing_key.verify_key
    
    # 签名
    message = b"Important document"
    signed = signing_key.sign(message)
    
    # 验证
    try:
        verified = verify_key.verify(signed)
        print(f"Verified: {verified.message}")
    except:
        print("Signature verification failed!")
```
