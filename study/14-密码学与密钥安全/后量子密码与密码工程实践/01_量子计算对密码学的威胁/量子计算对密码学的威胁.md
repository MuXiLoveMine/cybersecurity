# 量子计算对密码学的威胁

### 1.1 量子计算基本概念

量子计算利用量子力学的叠加和纠缠特性，在某些计算问题上实现指数级加速。

**量子计算与经典计算对比：**

| 特性 | 经典计算 | 量子计算 |
|------|----------|----------|
| 信息单元 | 比特（0或1） | 量子比特（叠加态0和1） |
| 并行性 | 有限并行 | 量子并行（2^n状态叠加） |
| 操作模型 | 布尔逻辑门 | 量子门（Hadamard、CNOT等） |
| 测量 | 不改变状态 | 测量导致波函数坍缩 |
| 关键算法 | 传统算法 | Shor、Grover、量子傅里叶变换 |
| 物理实现 | 硅芯片 | 超导量子、离子阱、光量子 |

**量子比特叠加态表示：**

```
经典比特：|0⟩ 或 |1⟩

量子比特：|ψ⟩ = α|0⟩ + β|1⟩
  其中 |α|² + |β|² = 1
  α、β 为复数振幅

n个量子比特可同时表示2^n个状态的叠加：
  |ψ⟩ = Σ ci |i⟩  （i从0到2^n-1）

量子并行性：
  对叠加态进行一次操作 → 同时作用于所有2^n个基态
  但测量后只得到一个结果 → 需要量子干涉提取有用信息
```

### 1.2 Shor 算法：对 RSA/ECC 的致命威胁

Shor 算法（1994年，Peter Shor）是量子计算中最具代表性的算法，可在多项式时间内分解大整数和求解离散对数。

**Shor 算法原理概述：**

```
问题：分解大整数 N = p × q

经典方法：
  - 试除法：O(√N)
  - 数域筛法：O(exp((logN)^(1/3) × (loglogN)^(2/3)))
  - 分解2048位RSA需数百万年

Shor算法（量子）：
  - 时间复杂度：O((logN)³)
  - 分解2048位RSA（理论）：数小时

核心思路：
  1. 随机选 a < N，计算 gcd(a,N)，若>1则直接得到因子
  2. 找到 r = order(a) mod N（a^r ≡ 1 mod N）
  3. 若 r 为偶数，则 gcd(a^(r/2) ± 1, N) 可能给出因子
  4. 量子部分：用量子傅里叶变换（QFT）找周期 r

受威胁的密码体系：
  ├── RSA（大整数分解 → Shor）
  ├── DH/DHE（离散对数 → Shor）
  ├── ECDH/ECDSA（椭圆曲线离散对数 → Shor变体）
  ├── DSA（离散对数 → Shor）
  └── SM2（椭圆曲线离散对数 → Shor变体）
```

**威胁时间线评估：**

```
量子威胁时间线：

当前（2024-2026）：
  ├── 量子计算机：IBM(1121 qubits), Google(53-70 qubits纠错)
  ├── 无法威胁RSA-2048（需要~4096逻辑量子比特）
  └── "现在收集，未来解密"（Harvest Now, Decrypt Later）

近期（2027-2032）：
  ├── 纠错量子比特可能达到数千
  ├── RSA-1024可能被威胁
  └── 后量子迁移窗口期

中期（2033-2040）：
  ├── 可能出现足以威胁RSA-2048的量子计算机
  ├── 需要约20M物理量子比特（容错量子计算）
  └── 未迁移的系统面临实质风险

长期（2040+）：
  ├── 大规模容错量子计算机可能实现
  ├── 所有传统公钥密码失效
  └── 后量子密码成为必需
```

### 1.3 Grover 算法：对对称加密的影响

Grover 算法（1996年，Lov Grover）提供对无结构搜索问题的平方加速。

**Grover 算法原理：**

```
问题：在N个无序项中搜索特定项

经典方法：O(N)次查询
Grover算法：O(√N)次查询

对密码学的影响：
  对称密钥搜索（暴力破解）：
    经典：2^n 次操作（n=密钥位数）
    量子：2^(n/2) 次操作

  AES-128：经典2^128 → 量子2^64（安全性减半）
  AES-256：经典2^256 → 量子2^128（仍然安全）
  SHA-256：经典2^256 → 量子2^128（预像攻击仍安全）

缓解措施：
  AES-128 → 升级到 AES-256
  SHA-256 → 可继续使用（或SHA-384/512）
  ChaCha20 → 升级到 ChaCha20-256
```

**量子威胁总结：**

| 密码类型 | 代表算法 | 量子威胁 | 威胁程度 | 对策 |
|----------|----------|----------|----------|------|
| 公钥加密 | RSA、ECDH | Shor算法 | 致命（完全破解） | 迁移到PQC |
| 数字签名 | ECDSA、RSA-Sig | Shor算法 | 致命（完全破解） | 迁移到PQC签名 |
| 对称加密 | AES-128 | Grover算法 | 严重（安全性减半） | 升级到AES-256 |
| 哈希函数 | SHA-256 | Grover算法 | 中等（安全性减半） | 基本可接受 |
| 消息认证 | HMAC-SHA256 | Grover算法 | 中等 | 可接受 |
