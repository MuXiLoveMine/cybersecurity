# NIST 后量子密码标准化进程

### 2.1 PQC 竞赛历程

NIST 于 2016 年发起后量子密码标准化项目，经过多轮筛选最终确定标准算法。

```
NIST PQC 标准化时间线：

2016.12  NIST发布PQC征集公告
         目标：征求可抵抗量子计算机攻击的新公钥密码算法

2017.11  第一轮提交截止
         收到82个候选方案（69个有效）
         分类：KEM（加密）+ DSA（签名）

2018.12  第一轮评估结束
         筛选至26个进入第二轮

2020.07  第二轮评估结束
         筛选至7个进入第三轮 + 8个备选

2022.07  第三轮结束，公布初步选择
         KEM决赛：CRYSTALS-Kyber → ML-KEM
         签名决赛：CRYSTALS-Dilithium → ML-DSA
         签名备选：Falcon → FN-DSA（后续标准）
         签名备选：SPHINCS+ → SLH-DSA

2023.08  发布 FIPS 203草案（ML-KEM）
         发布 FIPS 204草案（ML-DSA）
         发布 FIPS 205草案（SLH-DSA）

2024.08  正式发布标准
         FIPS 203: ML-KEM（基于格的密钥封装）
         FIPS 204: ML-DSA（基于格的数字签名）
         FIPS 205: SLH-DSA（基于哈希的数字签名）

2025     FN-DSA（Falcon）标准草案（FIPS 206草案）
```

### 2.2 候选算法分类

后量子密码基于不同的数学难题，各有利弊：

```
PQC算法数学基础分类：

┌───────────────────────────────────────────────────────────┐
│                    后量子密码算法族                          │
├───────────────┬───────────────┬───────────────┬───────────┤
│   格密码       │   编码密码     │   多变量密码    │  哈希签名  │
│  (Lattice)   │  (Code-based) │ (Multivariate)│(Hash-based)│
├───────────────┼───────────────┼───────────────┼───────────┤
│ ML-KEM(Kyber)│ Classic       │ Rainbow       │ SLH-DSA    │
│ ML-DSA(Dili) │ McEliece      │  (已破)       │ (SPHINCS+) │
│ FN-DSA(Falc) │ BIKE          │ GeMSS         │            │
│ NTRU         │ HQC           │               │            │
│ Falcon       │               │               │            │
├───────────────┼───────────────┼───────────────┼───────────┤
│ 密钥尺寸小    │ 公钥大        │ 签名极小       │ 签名大     │
│ 性能好       │ 解码复杂      │ 验证快         │ 理论保守   │
│ 被选为标准   │ 未被选(备选)   │ Rainbow被破    │ 被选为标准 │
└───────────────┴───────────────┴───────────────┴───────────┘

还有：等周密码（SIKE已破）、对称密码扩展等
```
