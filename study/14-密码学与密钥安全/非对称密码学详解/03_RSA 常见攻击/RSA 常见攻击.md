# RSA 常见攻击

### 3.1 因数分解攻击

**原理：** 如果能分解 n = p × q，就能计算出私钥 d。

**分解算法：**

| 算法 | 时间复杂度 | 适用场景 |
|------|-----------|---------|
| 试除法 | O(√n) | 小数字 |
| Pollard's p-1 | 依赖 n 的结构 | p-1 只有小因子时 |
| Pollard's ρ | O(n^(1/4)) | 中等大小数字 |
| 二次筛法（QS） | L_n[1/2, 1] | 100-300 位数字 |
| 数域筛法（NFS） | L_n[1/3, 1.923] | 大数字（最快的通用算法） |

**RSA 因数分解里程碑：**

| 年份 | 密钥长度 | 方法 |
|------|---------|------|
| 1991 | 330 位（100 位十进制） | 二次筛法 |
| 1996 | 430 位（130 位十进制） | 数域筛法 |
| 1999 | 512 位（155 位十进制） | 数域筛法 |
| 2009 | 768 位（232 位十进制） | 数域筛法 |
| 至今 | 1024 位 | 理论上可行但成本极高 |

**结论：**
- 512 位 RSA 完全不安全（几天内可分解）
- 768 位 RSA 已被公开分解
- 1024 位 RSA 应该淘汰（国家水平可能已能分解）
- 2048 位 RSA 目前安全，但应准备迁移
- 4096 位 RSA 长期安全

### 3.2 共模攻击（Common Modulus Attack）

**场景：** 多个用户使用同一个模数 n，但不同的公钥指数 e。

**攻击原理：**
```
假设：
- 两个用户共享模数 n
- 公钥分别为 (e1, n) 和 (e2, n)
- gcd(e1, e2) = 1

同一消息 m 用两个公钥加密：
c1 = m^e1 mod n
c2 = m^e2 mod n

攻击者知道 c1、c2、e1、e2、n

用扩展欧几里得算法找到 a、b 满足：
a × e1 + b × e2 = 1

则：
m = (c1^a) × (c2^b) mod n
  = m^(a×e1 + b×e2) mod n
  = m^1 mod n
  = m
```

**教训：**
- 每个用户必须有独立的 n
- 不能共享 RSA 模数

### 3.3 低加密指数攻击

#### （1）广播攻击（Hastad's Broadcast Attack）

**场景：** 相同消息用相同的小 e（如 e=3）加密给多个接收者。

**攻击原理：**
```
如果 e=3，且同一消息 m 加密给 3 个不同的接收者：
c1 = m^3 mod n1
c2 = m^3 mod n2
c3 = m^3 mod n3

用中国剩余定理（CRT）可以找到：
C = m^3 mod (n1 × n2 × n3)

因为 m < n1, n2, n3，所以 m^3 < n1×n2×n3
因此 C = m^3（没有取模）
直接开三次方即可得到 m
```

**防护：** 使用 OAEP 填充（随机化密文）

#### （2）Coppersmith 攻击

当 e 很小（如 e=3），且明文的高位或低位已知时，可以快速求出明文。

**防护：**
- 使用较大的 e（推荐 65537）
- 使用 OAEP 填充

### 3.4 低解密指数攻击（Wiener's Attack）

**场景：** 私钥指数 d 很小（为了加速解密）

**攻击原理：**
如果 d < n^0.25，可以用连分数展开从公钥 (e, n) 恢复出 d。

**案例：**
- 一些嵌入式设备为了加速，选择了小的 d
- 导致私钥可以被快速恢复

**防护：**
- 不要使用小的 d
- 标准做法是选择 e=65537，d 由 e 计算得出
- 如果需要加速解密，使用 CRT 而不是减小 d

### 3.5 选择密文攻击（CCA）

**Bleichenbacher 攻击（针对 PKCS#1 v1.5）：**

攻击者向服务器发送大量修改过的密文，根据服务器返回的错误信息（填充正确/错误），逐步推导出明文。

**条件：**
- 使用 RSA PKCS#1 v1.5 加密
- 服务器会泄露填充是否正确
- 攻击者可以多次询问

**影响：**
- 可以解密任意密文
- 影响 SSL/TLS 中的 RSA 密钥交换

**防护：**
- 使用 OAEP 填充
- 不泄露填充错误信息
- 统一错误响应

### 3.6 侧信道攻击

RSA 实现也容易受到侧信道攻击：

- **时序攻击**：利用模幂运算的时间差异
- **简单功耗分析（SPA）**：通过功耗波形区分平方和乘操作
- **差分功耗分析（DPA）**：统计分析功耗数据

**防护：**
- 恒定时间实现
- 随机化盲化技术（Blinding）
- 指数随机化
