# ECDH 椭圆曲线密钥交换

### 7.1 ECDH 原理

**ECDH（Elliptic Curve Diffie-Hellman）** 是椭圆曲线版本的 DH 密钥交换。

```
公开参数：
  椭圆曲线（含 p, a, b, G, n, h）

Alice                        Bob
  │                            │
  │  生成私钥 a（随机数）       │  生成私钥 b（随机数）
  │  计算公钥 A = a × G        │  计算公钥 B = b × G
  │                            │
  ├──────── 发送 A ───────────→│
  │                            │
  │←─────── 发送 B ────────────┤
  │                            │
  │  计算共享点：               │  计算共享点：
  │  S = a × B                 │  S = b × A
  │    = a × (b × G)           │    = b × (a × G)
  │    = (ab) × G              │    = (ab) × G
  │                            │
  │         相同的共享点 S       │
  │  共享密钥 = x 坐标（或 KDF） │  共享密钥 = x 坐标（或 KDF）
```

### 7.2 ECDH 的优势

| 特性 | DH (有限域) | ECDH (椭圆曲线) |
|------|------------|----------------|
| 密钥长度 | 2048-4096 位 | 256-384 位 |
| 计算量 | 大 | 小 |
| 速度 | 慢 | 快 |
| 带宽 | 大（公钥大） | 小（公钥小） |
| 安全强度 | 2048 位 ≈ 112 位 | 256 位 ≈ 128 位 |

**ECDH 的应用：**
- TLS 1.2/1.3（ECDHE 密钥交换）
- SSH
- 无线通信
- 物联网设备

### 7.3 ECDH 安全注意事项

1. **曲线选择**：使用标准的、经过安全评估的曲线
2. **点验证**：接收到对方公钥后，验证点是否在曲线上
3. **小群攻击**：确保点的阶是大素数 n
4. **侧信道防护**：实现需要抗侧信道攻击
5. **身份认证**：ECDH 本身也不提供身份认证，需要结合签名
