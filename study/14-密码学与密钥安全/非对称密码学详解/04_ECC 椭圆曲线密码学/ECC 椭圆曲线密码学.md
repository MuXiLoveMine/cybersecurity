# ECC 椭圆曲线密码学

### 4.1 ECC 概述

**ECC（Elliptic Curve Cryptography）** 是基于椭圆曲线离散对数难题的公钥密码学。

- **提出者**：Neal Koblitz 和 Victor Miller（1985 年独立提出）
- **基于难题**：椭圆曲线离散对数问题（ECDLP）
- **优势**：相同安全强度下，密钥更短、速度更快、功耗更低

**安全强度对比：**

| 对称密钥长度 | RSA 密钥长度 | ECC 密钥长度 |
|-------------|-------------|-------------|
| 80 位 | 1024 位 | 160 位 |
| 112 位 | 2048 位 | 224 位 |
| 128 位 | 3072 位 | 256 位 |
| 192 位 | 7680 位 | 384 位 |
| 256 位 | 15360 位 | 512 位 |

> 256 位 ECC 的安全强度 ≈ 3072 位 RSA

### 4.2 椭圆曲线数学基础

#### （1）椭圆曲线方程

椭圆曲线的 Weierstrass 方程：
```
y² = x³ + ax + b
```

其中 a、b 是系数，满足 4a³ + 27b² ≠ 0（确保曲线没有奇点）。

**图形（实数域上）：**
```
      │
      │    ╭───╮
      │    │   │
      │   ╭╯   ╰╮
──────┼───┴─────┴──────
      │
      │        ╭
      │         ╲
      │          ╲
```

#### （2）群运算（点加）

椭圆曲线上的点构成一个交换群，定义了加法运算。

**几何解释：**

1. **两点相加 P + Q：**
   - 过 P 和 Q 画一条直线
   - 直线与曲线交于第三点 R
   - P + Q = -R（关于 x 轴对称的点）

2. **倍点运算 2P：**
   - 过 P 点画切线
   - 切线与曲线交于另一点 R
   - 2P = -R

3. **单位元（无穷远点 O）：**
   - P + O = P
   - P + (-P) = O

**代数计算：**

```
设 P = (x₁, y₁), Q = (x₂, y₂)

如果 P = Q（倍点）：
  λ = (3x₁² + a) / (2y₁)

如果 P ≠ Q（点加）：
  λ = (y₂ - y₁) / (x₂ - x₁)

P + Q = (x₃, y₃)，其中：
  x₃ = λ² - x₁ - x₂
  y₃ = λ(x₁ - x₃) - y₁
```

#### （3）有限域上的椭圆曲线

密码学中使用的是**有限域 GF(p) 上的椭圆曲线**（所有运算模 p）。

**曲线参数（域参数）：**
- p：大素数（有限域的阶）
- a, b：椭圆曲线系数（y² = x³ + ax + b mod p）
- G：基点（生成元）
- n：G 的阶（n × G = O，n 是素数）
- h：余因子（h = #E(Fp) / n，通常 h=1）

#### （4）椭圆曲线离散对数问题（ECDLP）

```
已知 P 和 Q = k × P，求 k
```

其中 k 是整数，Q 是 P 的 k 倍点。

这个问题被认为是困难的，没有已知的多项式时间算法（经典计算机上）。

### 4.3 ECC 加密（ECIES）

ECC 本身不直接用于加密，而是通过 ECIES（Elliptic Curve Integrated Encryption Scheme）方案。

```
发送方（Alice）想给接收方（Bob）发送消息：

1. Bob 的公钥：Q_B = d_B × G（d_B 是私钥）

2. Alice 生成随机数 k
   计算 R = k × G
   计算 S = k × Q_B

3. 从 S 派生出对称密钥 K
   K = KDF(S)  （密钥派生函数）

4. 用 K 加密消息（对称加密）
   C = E(K, M)

5. 发送 (R, C)

Bob 解密：
1. 计算 S = d_B × R  （d_B × R = d_B × k × G = k × d_B × G = k × Q_B）
2. 派生出相同的 K = KDF(S)
3. 解密 M = D(K, C)
```

### 4.4 ECDSA 椭圆曲线数字签名算法

**ECDSA（Elliptic Curve Digital Signature Algorithm）** 是基于 ECC 的数字签名标准。

**签名过程：**
```
私钥：d（随机整数，1 < d < n）
公钥：Q = d × G

对消息 m 签名：
1. 计算 e = H(m)  （哈希消息）
2. 生成随机数 k（1 < k < n）
3. 计算点 (x₁, y₁) = k × G
4. 计算 r = x₁ mod n
   如果 r = 0，返回步骤 2
5. 计算 s = k⁻¹ × (e + d × r) mod n
   如果 s = 0，返回步骤 2

签名：(r, s)
```

**验证过程：**
```
公钥 Q，消息 m，签名 (r, s)

1. 验证 r、s 在 [1, n-1] 范围内
2. 计算 e = H(m)
3. 计算 w = s⁻¹ mod n
4. 计算 u₁ = e × w mod n
5. 计算 u₂ = r × w mod n
6. 计算点 (x₁, y₁) = u₁ × G + u₂ × Q
7. 验证 v = x₁ mod n == r

如果相等，签名有效
```

**ECDSA 注意事项：**
- 随机数 k 必须是密码学安全的
- k 泄露会导致私钥泄露
- k 重复使用也会导致私钥泄露

**案例：PS3 破解**
- Sony PS3 使用 ECDSA 签名验证游戏
- 但 Sony 在所有签名中使用了相同的 k
- 攻击者通过两个签名即可恢复私钥
- 导致 PS3 被破解

### 4.5 常见椭圆曲线

| 曲线名称 | 位长 | 来源 | 说明 |
|----------|------|------|------|
| secp256k1 | 256 | SECG | 比特币使用 |
| secp256r1 (P-256) | 256 | NIST | 广泛使用 |
| secp384r1 (P-384) | 384 | NIST | 高安全级别 |
| Curve25519 | 255 | DJB | ECDH 专用，高效安全 |
| Ed25519 | 255 | DJB | EdDSA 签名，高效安全 |
| SM2 | 256 | 国密 | 中国标准 |

### 4.6 Curve25519 / Ed25519

**Curve25519** 是 Daniel J. Bernstein 设计的椭圆曲线，专门用于 ECDH 密钥交换。

**特点：**
- 255 位素数域（p = 2^255 - 19）
- 蒙哥马利曲线形式
- 设计避免了很多安全陷阱
- 恒定时间实现容易
- 性能优异

**Ed25519** 是基于 Edwards 曲线的签名算法，与 Curve25519 数学上等价。

**特点：**
- 快速签名和验证
- 小签名（64 字节）、小公钥（32 字节）
- 防碰撞（不需要随机数 k，避免了 ECDSA 的 k 重用问题）
- 已广泛应用于 SSH、TLS 1.3、区块链等
