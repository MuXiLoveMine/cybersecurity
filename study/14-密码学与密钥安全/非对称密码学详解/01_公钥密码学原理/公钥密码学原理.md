# 公钥密码学原理

### 1.1 基本概念

**非对称加密（Asymmetric Encryption）**，又称公钥加密（Public Key Cryptography），使用一对密钥：公钥和私钥。

```
┌─────────────┐                    ┌─────────────┐
│   公钥 PK   │  ←── 公开分发 ──→  │   公钥 PK   │
│ (Public Key)│                    │ (Public Key)│
└─────────────┘                    └─────────────┘
         │                                  │
         │ 加密                              │ 验证签名
         ▼                                  ▼
      密文                                签名
         │                                  │
         │ 解密                              │ 签名
         ▼                                  ▼
┌─────────────┐                    ┌─────────────┐
│   私钥 SK   │                    │   私钥 SK   │
│ (Private Key)│                    │ (Private Key)│
└─────────────┘                    └─────────────┘
```

**核心特性：**
- **双向性**：公钥加密 → 私钥解密（加密）
- **单向性**：私钥签名 → 公钥验证（签名）
- **不可推导**：从公钥无法计算出私钥（计算上不可行）

### 1.2 数学基础：陷门单向函数

公钥密码学的核心是**陷门单向函数（Trapdoor One-way Function）**：

```
单向函数：
  f(x) = y    容易计算（正向）
  f⁻¹(y) = x  很难计算（反向）

陷门单向函数：
  f(x) = y    容易计算
  f⁻¹(y) = x  很难计算（除非知道陷门信息）
  有了陷门（私钥），反向计算变得容易
```

**常见的数学难题（陷门基础）：**

| 数学难题 | 代表算法 | 描述 |
|----------|---------|------|
| 大整数分解 | RSA | 分解两个大素数的乘积很难 |
| 离散对数 | DH、DSA、ElGamal | 有限域上求离散对数很难 |
| 椭圆曲线离散对数 | ECC、ECDH、ECDSA | 椭圆曲线上求离散对数很难 |
| 格上最短向量 | 格密码 | 格中找最短非零向量很难 |

### 1.3 对称 vs 非对称对比

| 特性 | 对称加密 | 非对称加密 |
|------|---------|-----------|
| 密钥 | 一个密钥（加密解密相同） | 一对密钥（公钥/私钥） |
| 密钥分发 | 困难 | 容易（公钥公开） |
| 速度 | 快（适合大数据） | 慢（不适合大数据） |
| 典型算法 | AES、DES、SM4 | RSA、ECC、SM2 |
| 密钥长度 | 128-256 位 | 2048-4096 位（RSA） |
| 数字签名 | 不能 | 可以 |
| 不可否认性 | 不提供 | 提供 |

**混合加密（Hybrid Encryption）：**
实际应用中通常结合使用：
1. 用非对称加密交换对称密钥（密钥交换）
2. 用对称加密加密实际数据（数据加密）

```
发送方：
  1. 生成随机对称密钥 K
  2. 用接收方公钥加密 K → Ck = E(PK_recv, K)
  3. 用 K 加密数据 → Cd = E(K, data)
  4. 发送 (Ck, Cd)

接收方：
  1. 用私钥解密 Ck → K = D(SK_recv, Ck)
  2. 用 K 解密 Cd → data = D(K, Cd)
```
