# 实际案例

### 案例 1：索尼 PS3 ECDSA 破解

**背景：**
- Sony PlayStation 3 使用 ECDSA 签名验证游戏和系统更新
- 只有签名正确的软件才能运行

**漏洞：**
- Sony 在生成签名时使用了固定的随机数 k
- 根据 ECDSA 原理，如果知道两个使用相同 k 的签名：
  ```
  s1 = k⁻¹ × (e1 + d × r) mod n
  s2 = k⁻¹ × (e2 + d × r) mod n
  
  两式相减：s1 - s2 = k⁻¹ × (e1 - e2) mod n
  可求出：k = (e1 - e2) × (s1 - s2)⁻¹ mod n
  
  然后求出私钥：d = (s1 × k - e1) × r⁻¹ mod n
  ```

**结果：**
- 攻击者获取了 Sony 的签名私钥
- 可以运行任何自制软件
- PS3 安全体系被攻破

**教训：**
- ECDSA 中的随机数 k 必须是密码学安全的
- 不能重复使用 k
- 推荐使用 EdDSA（确定性签名，不需要随机数）

### 案例 2：Heartbleed 与私钥泄露

**背景：**
- OpenSSL Heartbleed 漏洞（CVE-2014-0160）
- 可以读取服务器内存中的 64KB 数据

**影响：**
- 可能泄露服务器的 RSA 私钥
- 私钥一旦泄露，整个 PKI 信任链就崩了
- 攻击者可以解密所有之前的 TLS 会话（如果没有前向保密）
- 攻击者可以伪造服务器证书

**应对：**
- 立即升级 OpenSSL
- 吊销受影响的证书
- 重新颁发证书
- 启用前向保密（ECDHE）

### 案例 3：ROCA 漏洞（Return of Coppersmith's Attack）

**背景：**
- 2017 年发现的 RSA 密钥生成漏洞
- 影响 Infineon 公司的 TPM 芯片和智能卡
- 涉及大量设备（YubiKey、银行卡、护照等）

**原理：**
- 芯片生成的 RSA 素数有特殊结构
- 可以使用 Coppersmith 方法快速分解
- 1024 位密钥几天内可分解，2048 位密钥几个月

**影响：**
- 数百万设备的 RSA 密钥不安全
- 需要更换硬件或更新固件

**教训：**
- 密钥生成的随机性和安全性至关重要
- 硬件实现也可能有漏洞
- 定期更换密钥是好的实践
