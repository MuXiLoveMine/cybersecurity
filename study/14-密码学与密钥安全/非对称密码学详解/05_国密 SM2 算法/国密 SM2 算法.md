# 国密 SM2 算法

### 5.1 SM2 概述

**SM2** 是中国国家密码管理局发布的椭圆曲线公钥密码标准。

- **标准号**：GM/T 0003-2012
- **发布时间**：2012 年
- **基于难题**：椭圆曲线离散对数问题（ECDLP）
- **曲线类型**：256 位素数域椭圆曲线
- **用途**：加密、解密、数字签名、密钥交换

### 5.2 SM2 曲线参数

SM2 使用一条 256 位的推荐曲线：

```
素数 p = 0xFFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF00000000FFFFFFFFFFFFFFFF
系数 a = 0xFFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF00000000FFFFFFFFFFFFFFFC
系数 b = 0x28E9FA9E9D9F5E344D5A9E4BCF6509A7F39789F515AB8F92DDBCBD414D940E93
基点 G 的 x 坐标 = 0x32C4AE2C1F1981195F9904466A39C9948FE30BBFF2660BE1715A4589334C74C7
基点 G 的 y 坐标 = 0xBC3736A2F4F6779C59BDCEE36B692153D0A9877CC62A474002DF32E52139F0A0
基点阶 n = 0xFFFFFFFEFFFFFFFFFFFFFFFFFFFFFFFF7203DF6B21C6052B53BBF40939D54123
余因子 h = 1
```

### 5.3 SM2 数字签名

SM2 签名算法与 ECDSA 类似，但有一些差异。

**签名前的预处理：**
SM2 签名需要先计算 Z 值（用户标识 + 曲线参数 + 公钥的哈希）：
```
Z_A = H(ENTL_A || ID_A || a || b || x_G || y_G || x_A || y_A)

其中：
- ENTL_A：用户 ID 的长度（位）
- ID_A：用户标识
- a, b：曲线系数
- x_G, y_G：基点坐标
- x_A, y_A：公钥坐标
```

**签名过程：**
```
私钥：d_A（1 < d_A < n-1）
公钥：P_A = d_A × G

对消息 M 签名：
1. 计算 Z_A
2. 计算 M' = Z_A || M
3. 计算 e = H(M')  （SM3 哈希）
4. 生成随机数 k（1 ≤ k ≤ n-1）
5. 计算点 (x₁, y₁) = k × G
6. 计算 r = (e + x₁) mod n
   如果 r = 0 或 r + k = n，返回步骤 4
7. 计算 s = ((1 + d_A)⁻¹ × (k - r × d_A)) mod n
   如果 s = 0，返回步骤 4

签名：(r, s)
```

**验证过程：**
```
公钥 P_A，消息 M，签名 (r, s)

1. 验证 r ∈ [1, n-1]，s ∈ [1, n-1]
2. 计算 Z_A
3. 计算 M' = Z_A || M
4. 计算 e = H(M')
5. 计算 t = (r + s) mod n
   如果 t = 0，验证失败
6. 计算点 (x₁, y₁) = s × G + t × P_A
7. 验证 R = (e + x₁) mod n == r

如果相等，签名有效
```

### 5.4 SM2 加密解密

SM2 使用 ECIES 类似的方案进行加密。

**加密过程：**
```
接收方公钥：P_B = d_B × G

对消息 M 加密：
1. 生成随机数 k（1 ≤ k ≤ n-1）
2. 计算点 C₁ = k × G
3. 计算点 S = h × P_B（如果 h=1，就是 P_B）
   如果 S 是无穷远点，错误
4. 计算点 (x₂, y₂) = k × P_B
5. 计算 t = KDF(x₂ || y₂, klen)  （密钥派生函数）
   如果 t 全为 0，返回步骤 1
6. 计算 C₂ = M ⊕ t
7. 计算 C₃ = Hash(x₂ || M || y₂)

密文：C = C₁ || C₃ || C₂  （注意顺序）
```

**解密过程：**
```
私钥 d_B，密文 C = C₁ || C₃ || C₂

1. 验证 C₁ 是否在曲线上
2. 计算 S = h × C₁
   如果 S 是无穷远点，错误
3. 计算点 (x₂, y₂) = d_B × C₁
4. 计算 t = KDF(x₂ || y₂, klen)
   如果 t 全为 0，解密失败
5. 计算 M' = C₂ ⊕ t
6. 计算 u = Hash(x₂ || M' || y₂)
   验证 u == C₃，如果不等，解密失败

明文：M'
```

### 5.5 SM2 密钥交换

SM2 也定义了密钥交换协议，与 ECDH 类似但增加了身份验证。

```
双方：A（发起方）和 B（响应方）
各自有密钥对：(d_A, P_A) 和 (d_B, P_B)

过程：
1. A 生成随机数 r_A，计算 R_A = r_A × G，发送给 B
2. B 生成随机数 r_B，计算 R_B = r_B × G，发送给 A
3. A 计算共享点 V = (x_V, y_V) = 2^w × (d_A + r_A × x₁) × (P_B + x₂ × R_B)
   其中 x₁ 是 R_A 的 x 坐标，x₂ 是 R_B 的 x 坐标
4. B 计算共享点 V = (x_V, y_V) = 2^w × (d_B + r_B × x₂) × (P_A + x₁ × R_A)
5. 双方得到相同的 V
6. 用 KDF 从 V 派生出会话密钥
```

### 5.6 SM2 与 ECDSA 对比

| 特性 | SM2 | ECDSA |
|------|-----|-------|
| 曲线 | 256 位国密推荐曲线 | secp256k1、P-256 等 |
| 签名公式 | 不同 | 不同 |
| 用户标识 | 包含 Z_A（用户ID） | 不包含 |
| 哈希函数 | SM3 | SHA-2 等 |
| 标准 | 中国国密 | 国际标准 |
| 安全性 | 256 位安全强度 | 取决于曲线 |
