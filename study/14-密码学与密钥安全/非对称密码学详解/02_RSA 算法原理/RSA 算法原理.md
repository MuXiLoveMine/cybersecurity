# RSA 算法原理

### 2.1 RSA 概述

**RSA** 是由 Ron Rivest、Adi Shamir、Leonard Adleman 于 1977 年提出的公钥加密算法。

- **基于难题**：大整数分解难题
- **用途**：加密、解密、数字签名、密钥交换
- **密钥长度**：1024（已不安全）、2048（最低）、3072（推荐）、4096（高安全）

### 2.2 数学基础

#### （1）素数与互质

- **素数（Prime）**：大于 1 的自然数，除了 1 和自身外没有其他因数
- **互质（Coprime）**：两个数的最大公约数是 1，即 gcd(a, b) = 1

#### （2）欧拉函数 φ(n)

欧拉函数 φ(n) 表示小于等于 n 且与 n 互质的正整数的个数。

**性质：**
- 如果 p 是素数，则 φ(p) = p - 1
- 如果 n = p × q，且 p、q 都是素数，则 φ(n) = (p-1)(q-1)

**示例：**
- φ(7) = 6（1, 2, 3, 4, 5, 6）
- φ(15) = φ(3×5) = 2×4 = 8（1, 2, 4, 7, 8, 11, 13, 14）

#### （3）欧拉定理

如果 a 和 n 互质，则：
```
a^φ(n) ≡ 1 (mod n)
```

**推论（费马小定理）：**
如果 p 是素数，且 a 不是 p 的倍数，则：
```
a^(p-1) ≡ 1 (mod p)
```

#### （4）模逆元

如果 a × b ≡ 1 (mod n)，则称 b 是 a 在模 n 下的逆元，记为 a⁻¹ mod n。

**存在条件：** 当且仅当 a 和 n 互质时，a 的逆元存在。

**计算方法：** 扩展欧几里得算法

### 2.3 RSA 密钥生成

```
步骤 1：选择两个大素数 p 和 q
  p ≠ q，都是大素数（推荐 1024 位以上）

步骤 2：计算 n = p × q
  n 称为模数（Modulus）
  n 的二进制长度就是密钥长度

步骤 3：计算 φ(n) = (p-1) × (q-1)
  欧拉函数值

步骤 4：选择整数 e，满足 1 < e < φ(n)，且 gcd(e, φ(n)) = 1
  e 称为公钥指数（Public Exponent）
  常用值：e = 65537 (0x10001)

步骤 5：计算 d ≡ e⁻¹ (mod φ(n))
  d 称为私钥指数（Private Exponent）
  即 e × d ≡ 1 (mod φ(n))

公钥：(e, n)
私钥：(d, n)
```

**示例（小数字演示）：**
```
p = 61, q = 53
n = 61 × 53 = 3233
φ(n) = 60 × 52 = 3120
选择 e = 17（gcd(17, 3120) = 1）
计算 d = 2753（17 × 2753 = 46801 ≡ 1 mod 3120）

公钥：(e=17, n=3233)
私钥：(d=2753, n=3233)
```

### 2.4 RSA 加密解密

**加密：**
```
C = P^e mod n

其中：
- P 是明文（必须小于 n）
- C 是密文
- (e, n) 是公钥
```

**解密：**
```
P = C^d mod n

其中：
- C 是密文
- P 是明文
- (d, n) 是私钥
```

**正确性证明（为什么解密能得到明文？）：**
```
需要证明：(P^e mod n)^d mod n = P

即证明：P^(ed) ≡ P (mod n)

因为 e × d ≡ 1 (mod φ(n))
所以 e × d = k × φ(n) + 1，k 是某个整数

根据欧拉定理：P^φ(n) ≡ 1 (mod n)  （假设 P 与 n 互质）

所以 P^(ed) = P^(k×φ(n) + 1) = (P^φ(n))^k × P^1 ≡ 1^k × P ≡ P (mod n)

证毕。
```

**加密示例（接上面小例子）：**
```
明文 P = 65（小于 3233）
公钥 (e=17, n=3233)

加密：
C = 65^17 mod 3233 = 2790

解密：
P = 2790^2753 mod 3233 = 65 ✓
```

### 2.5 RSA 数字签名

RSA 也可以用于数字签名，原理是"用私钥加密，用公钥验证"。

**签名：**
```
S = M^d mod n

其中：
- M 是消息（通常是消息的哈希值）
- S 是签名
- (d, n) 是私钥
```

**验证：**
```
验证 M' = S^e mod n
如果 M' == M，则签名有效
```

**为什么能证明身份？**
- 只有持有私钥的人才能生成有效的签名
- 任何人都可以用公钥验证签名
- 签名不能被伪造（没有私钥无法生成）

**注意：**
- 实际中不会直接对消息签名，而是对消息的哈希值签名
- 需要使用填充方案（PKCS#1 v1.5 或 PSS）

### 2.6 RSA 填充方案

直接使用 RSA 加密有很多问题，需要填充（Padding）方案。

#### PKCS#1 v1.5 填充（加密）

```
加密填充格式（以 2048 位 RSA 为例，256 字节）：
┌────┬────────────────────────────────────┬────┬──────────┐
│0x00│ 0x02 │  随机非零字节 (至少8字节)    │0x00│ 明文消息 │
└────┴────────────────────────────────────┴────┴──────────┘
 1字节 1字节        可变长度                  1字节   可变长度
```

**特点：**
- 结构简单
- 广泛使用
- 存在 Bleichenbacher 攻击（自适应选择密文攻击）

#### OAEP 填充（最优非对称加密填充）

```
OAEP (Optimal Asymmetric Encryption Padding)

结构：
┌──────────────────────────────────────────────────┐
│                  消息 M                           │
│  用随机数 r 和哈希函数进行变换                      │
│  确保安全性证明                                    │
└──────────────────────────────────────────────────┘
```

**特点：**
- 可证明安全（在随机预言机模型下）
- 推荐使用
- 比 PKCS#1 v1.5 更安全

#### PSS 填充（签名）

```
PSS (Probabilistic Signature Scheme)

特点：
- 概率性签名（每次签名结果不同）
- 可证明安全
- 推荐用于 RSA 签名
```

### 2.7 RSA 实现优化

#### （1）快速幂运算（模幂）

RSA 加密解密需要计算大指数的模幂，直接计算太慢，使用**快速幂算法**（平方-乘算法）。

```
计算 a^b mod n：

result = 1
base = a
while b > 0:
    if b % 2 == 1:
        result = (result * base) % n
    base = (base * base) % n
    b = b // 2
return result
```

时间复杂度：O(log b) 次乘法

#### （2）中国剩余定理（CRT）加速解密

私钥运算可以用中国剩余定理加速，速度提高约 4 倍。

```
已知 p、q（私钥保存了 p 和 q）：
计算 C^d mod p 和 C^d mod q
然后用 CRT 合并结果

因为 p 和 q 比 n 小一半，运算量小很多
```
