### 6.2 证书申请流程

```
证书申请流程（CSR方式）：

  1. 申请者生成密钥对
     ├── 私钥保存在安全位置
     └── 公钥用于创建CSR

  2. 创建CSR（证书签名请求）
     ├── 主题信息（CN, O, C等）
     ├── 公钥
     └── 申请者私钥签名

  3. 提交CSR给CA
     └── 通过RA进行身份验证

  4. CA审核
     ├── 验证域名所有权
     ├── 验证组织信息（OV/EV）
     └── 审批申请

  5. CA签发证书
     ├── 用CA私钥签名
     ├── 添加扩展字段
     └── 返回证书给申请者
```

**CSR生成：**

```bash
# 使用OpenSSL生成CSR
# 1. 生成私钥
openssl genrsa -out server.key 2048

# 2. 生成CSR
openssl req -new -key server.key -out server.csr -sha256

# 按提示输入信息：
# Country Name (2 letter code): CN
# State or Province Name: Beijing
# Locality Name: Beijing
# Organization Name: Example Inc
# Common Name: www.example.com
# Email Address: admin@example.com

# 3. 查看CSR内容
openssl req -in server.csr -text -noout

# 4. 带SAN的CSR（需要配置文件）
cat > san.cnf << 'EOF'
[req]
distinguished_name = req_distinguished_name
req_extensions = v3_req
prompt = no

[req_distinguished_name]
C = CN
O = Example Inc
CN = www.example.com

[v3_req]
keyUsage = keyEncipherment, dataEncipherment
extendedKeyUsage = serverAuth
subjectAltName = @alt_names

[alt_names]
DNS.1 = www.example.com
DNS.2 = example.com
DNS.3 = api.example.com
IP.1 = 192.168.1.1
EOF

openssl req -new -key server.key -out server.csr -config san.cnf -sha256
```

```python
# 使用Python生成CSR
from cryptography import x509
from cryptography.x509.oid import NameOID
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives.serialization import Encoding, PrivateFormat, NoEncryption

def generate_csr(common_name, organization, country, san_domains, key_size=2048):
    """
    生成CSR（证书签名请求）
    
    Args:
        common_name: 通用名称
        organization: 组织名
        country: 国家代码
        san_domains: SAN域名列表
        key_size: 密钥大小
        
    Returns:
        (CSR PEM, 私钥 PEM)
    """
    # 生成密钥对
    private_key = rsa.generate_private_key(
        public_exponent=65537,
        key_size=key_size
    )
    
    # 构建CSR
    csr = x509.CertificateSigningRequestBuilder().subject_name(
        x509.Name([
            x509.NameAttribute(NameOID.COUNTRY_NAME, country),
            x509.NameAttribute(NameOID.ORGANIZATION_NAME, organization),
            x509.NameAttribute(NameOID.COMMON_NAME, common_name),
        ])
    ).add_extension(
        x509.SubjectAlternativeName([
            x509.DNSName(d) for d in san_domains
        ]),
        critical=False
    ).sign(private_key, hashes.SHA256())
    
    csr_pem = csr.public_bytes(Encoding.PEM)
    key_pem = private_key.private_bytes(
        Encoding.PEM,
        PrivateFormat.TraditionalOpenSSL,
        NoEncryption()
    )
    
    return csr_pem, key_pem


# 使用示例
csr_pem, key_pem = generate_csr(
    common_name="www.example.com",
    organization="Example Inc",
    country="CN",
    san_domains=["www.example.com", "example.com", "api.example.com"]
)

with open("server.csr", "wb") as f:
    f.write(csr_pem)
with open("server.key", "wb") as f:
    f.write(key_pem)

print("CSR生成完成")
print(f"CSR内容预览:\n{csr_pem.decode()[:500]}...")
```

### 6.3 证书续期

```python
class CertificateRenewalManager:
    """证书续期管理器"""
    
    RENEWAL_THRESHOLDS = {
        'critical': 7,    # 7天内到期 - 紧急
        'warning': 30,    # 30天内到期 - 警告
        'notice': 60,     # 60天内到期 - 通知
    }
    
    @staticmethod
    def check_renewal_needed(cert_pem: bytes) -> dict:
        """
        检查证书是否需要续期
        
        Returns:
            {
                'needs_renewal': bool,
                'days_remaining': int,
                'status': 'ok'/'notice'/'warning'/'critical'/'expired',
                'not_after': datetime
            }
        """
        cert = x509.load_pem_x509_certificate(cert_pem)
        
        now = datetime.datetime.utcnow()
        expiry = cert.not_valid_after
        days_remaining = (expiry - now).days
        
        if days_remaining < 0:
            status = 'expired'
            needs_renewal = True
        elif days_remaining <= CertificateRenewalManager.RENEWAL_THRESHOLDS['critical']:
            status = 'critical'
            needs_renewal = True
        elif days_remaining <= CertificateRenewalManager.RENEWAL_THRESHOLDS['warning']:
            status = 'warning'
            needs_renewal = True
        elif days_remaining <= CertificateRenewalManager.RENEWAL_THRESHOLDS['notice']:
            status = 'notice'
            needs_renewal = True
        else:
            status = 'ok'
            needs_renewal = False
        
        return {
            'needs_renewal': needs_renewal,
            'days_remaining': days_remaining,
            'status': status,
            'not_after': expiry,
            'subject': cert.subject.rfc4514_string()
        }
    
    @staticmethod
    def batch_check(certificates: dict) -> list:
        """
        批量检查证书续期状态
        
        Args:
            certificates: {name: cert_pem}
            
        Returns:
            排序后的检查结果列表
        """
        results = []
        for name, cert_pem in certificates.items():
            result = CertificateRenewalManager.check_renewal_needed(cert_pem)
            result['name'] = name
            results.append(result)
        
        # 按剩余天数排序（最紧急的在前）
        results.sort(key=lambda x: x['days_remaining'])
        
        return results
```

### 6.4 证书撤销

**证书撤销原因代码（RFC 5280）：**

| 代码 | 原因 | 说明 |
|------|------|------|
| 0 | unspecified | 未指定 |
| 1 | keyCompromise | 密钥泄露 |
| 2 | cACompromise | CA被攻破 |
| 3 | affiliationChanged | 附属关系变更 |
| 4 | superseded | 证书被替代 |
| 5 | cessationOfOperation | 停止运营 |
| 6 | certificateHold | 证书暂停 |
| 8 | removeFromCRL | 从CRL中移除 |
| 9 | privilegeWithdrawn | 权限撤回 |
| 10 | aACompromise | AA被攻破 |

**撤销流程：**
```
1. 证书持有者向CA提交撤销请求
2. CA验证撤销请求的合法性
3. CA将证书加入CRL
4. CA更新OCSP响应
5. 依赖方通过CRL/OCSP获知证书已撤销
```
