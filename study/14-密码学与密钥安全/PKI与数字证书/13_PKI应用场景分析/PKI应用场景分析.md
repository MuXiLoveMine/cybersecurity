# PKI应用场景分析

### 13.1 HTTPS/TLS

PKI最广泛的应用场景，保护Web通信安全。

```
HTTPS证书验证流程：
  1. 浏览器连接服务器（TCP三次握手）
  2. TLS握手（服务器发送证书）
  3. 浏览器验证证书链
  4. 浏览器检查域名匹配
  5. 浏览器检查证书状态（OCSP/CRL）
  6. 密钥交换（生成会话密钥）
  7. 加密通信
```

### 13.2 代码签名

```
代码签名证书类型：
  ├── 标准代码签名（OV）
  ├── 扩展验证代码签名（EV）
  └── 内核驱动签名（WHQL/交叉签名）

签名流程：
  1. 计算文件哈希
  2. 用私钥签名哈希
  3. 将签名和证书嵌入文件
  4. 可选：添加时间戳
  
验证流程：
  1. 提取签名和证书
  2. 验证证书链
  3. 验证签名
  4. 验证时间戳
  5. 比对文件哈希
```

### 13.3 邮件安全（S/MIME）

```
S/MIME证书用途：
  ├── 加密邮件内容
  ├── 数字签名邮件
  └── 验证发件人身份

S/MIME操作：
  签名：用发件人私钥签名邮件
  加密：用收件人公钥加密邮件
  验证：用发件人公钥验证签名
  解密：用收件人私钥解密邮件
```

### 13.4 VPN认证

```
VPN中的证书用途：
  ├── 服务器身份认证
  ├── 客户端身份认证
  └── 双向TLS认证（mTLS）

IPSec VPN证书：
  - IKE协商中使用证书进行身份认证
  - 支持RSA和ECDSA签名

OpenVPN证书：
  - TLS双向认证
  - 服务器证书 + 客户端证书
  - 证书撤销列表控制访问
```

### 13.5 物联网设备认证

```
物联网PKI特点：
  ├── 大规模证书管理（百万级设备）
  ├── 设备证书自动注册（SCEP/EST）
  ├── 证书自动轮换
  ├── 轻量级证书格式
  └── 硬件安全存储（TPM/SE）

典型架构：
  设备 → 制造时注入证书 → 连接时mTLS认证 → OTA时证书更新
```
