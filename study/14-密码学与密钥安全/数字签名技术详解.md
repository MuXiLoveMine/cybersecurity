## 一、数字签名概述

### 1.1 什么是数字签名

**数字签名（Digital Signature）** 是一种用密码学技术实现的、类似于手写签名的电子签名机制。它使用发送方的私钥对消息进行签名，接收方使用发送方的公钥验证签名。

**数字签名与手写签名的对比：**

| 特性 | 手写签名 | 数字签名 |
|------|---------|---------|
| 签名与文件的关系 | 独立于文件内容 | 与文件内容绑定（哈希） |
| 伪造难度 | 相对容易（可模仿） | 极难（需破解密码算法） |
| 复制检测 | 难（无法区分原件和复印件 | 易（每次签名不同） |
| 文件完整性 | 无法保证 | 保证（签名验证内容） |
| 不可抵赖性 | 弱 | 强（只有私钥持有者能签名） |
| 身份认证 | 依赖笔迹鉴定 | 基于数学证明 |

### 1.2 数字签名的安全服务

数字签名提供三大核心安全服务：

```
┌─────────────────────────────────────────────────┐
│              数字签名的安全服务                    │
├──────────────┬──────────────────────────────────┤
│  完整性       │ 签名与消息内容绑定，任何篡改       │
│  Integrity   │ 都会使签名验证失败                 │
├──────────────┼──────────────────────────────────┤
│  身份认证     │ 签名是用私钥生成的，只有私钥       │
│  Authentication│ 持有者能产生有效签名              │
├──────────────┼──────────────────────────────────┤
│  不可抵赖性   │ 签名者无法否认自己签过的消息       │
│  Non-repudiation│ （因为没有其他人能产生相同签名）  │
└──────────────┴──────────────────────────────────┘
```

### 1.3 数字签名的发展历史

| 年份 | 事件 | 意义 |
|------|------|------|
| 1976 | Diffie-Hellman提出公钥密码概念 | 公钥密码学诞生 |

| 1991 | DSA（数字签名算法）标准化 | FIPS 186发布 |

| 2024 | 后量子签名标准化推进 | NIST PQC标准发布 |

### 1.4 法律地位

**电子签名法律效力：**

| 国家/地区 | 法律法规 | 效力 |
|----------|---------|------|
| 中国 | 电子签名法（2005） | 可靠的电子签名与手写签名具有同等效力 |
| 美国 | ESIGN法案（2000） | 电子签名具有法律效力 |

1. 签名制作数据用于电子签名时，属于电子签名人专有
2. 签名时签名制作数据仅由电子签名人控制
3. 签署后对签名制作数据的任何改动能够被发现
4. 签署后对电文内容和形式的任何改动能够被发现

**数字签名完全满足以上四个条件。**

## 二、数字签名原理

### 2.1 数字签名的基本流程

```
签名过程（发送方）：

  原始消息 ──→ 哈希函数 ──→ 消息摘要 ──→ 私钥签名 ──→ 数字签名
                                                                  │
  原始消息 ─────────────────────────────────────────────┐         │
                                                         ↓         ↓
                                                    发送给接收方

验证过程（接收方）：

  接收消息 ──→ 哈希函数 ──→ 消息摘要1 ─────────────────────┐
                                                             │
  数字签名 ──→ 公钥验证 ──→ 消息摘要2 ─────────────────────┤
                                                             │
                                                        比较摘要1和摘要2
                                                             │
                                                   相同 → 验证通过
                                                   不同 → 验证失败
```

### 2.2 签名过程的详细步骤

#### 2.2.1 签名步骤

```python
"""
数字签名基本原理实现
"""
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives.serialization import Encoding, PublicFormat

class DigitalSignatureDemo:
    """数字签名演示"""
    
    def __init__(self):
        # 生成RSA密钥对
        self.private_key = rsa.generate_private_key(
            public_exponent=65537,
            key_size=2048
        )
        self.public_key = self.private_key.public_key()
    
    def sign(self, message: bytes) -> bytes:
        """
        签名过程
        
        步骤1: 计算消息的哈希值
        步骤2: 用私钥对哈希值进行签名
        """
        # 步骤1: 计算哈希（实际上签名函数内部会自动计算）
        digest = hashes.Hash(hashes.SHA256())
        digest.update(message)
        hash_value = digest.finalize()
        print(f"消息哈希: {hash_value.hex()}")
        
        # 步骤2: 用私钥签名
        signature = self.private_key.sign(
            message,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH
            ),
            hashes.SHA256()
        )
        
        return signature
    
    def verify(self, message: bytes, signature: bytes) -> bool:
        """
        验证过程
        
        步骤1: 用公钥解密签名，得到签名时的哈希值
        步骤2: 重新计算消息的哈希值
        步骤3: 比较两个哈希值
        """
        try:
            # 验证签名（内部会比较哈希值）
            self.public_key.verify(
                signature,
                message,
                padding.PSS(
                    mgf=padding.MGF1(hashes.SHA256()),
                    salt_length=padding.PSS.MAX_LENGTH
                ),
                hashes.SHA256()
            )
            return True
        except Exception:
            return False
    
    def demonstrate(self):
        """演示签名和验证"""
        message = b"Hello, this is a secret message!"
        print(f"原始消息: {message.decode()}")
        
        # 签名
        print("\n--- 签名过程 ---")
        signature = self.sign(message)
        print(f"数字签名: {signature.hex()[:60]}...")
        print(f"签名长度: {len(signature)} bytes")
        
        # 验证正确消息
        print("\n--- 验证正确消息 ---")
        valid = self.verify(message, signature)
        print(f"验证结果: {'通过' if valid else '失败'}")
        
        # 验证篡改消息
        print("\n--- 验证篡改消息 ---")
        tampered = message.replace(b"secret", b"public")
        valid = self.verify(tampered, signature)
        print(f"验证结果: {'通过' if valid else '失败'}")
        
        # 导出公钥
        print("\n--- 公钥信息 ---")
        pub_pem = self.public_key.public_bytes(
            Encoding.PEM, PublicFormat.SubjectPublicKeyInfo
        )
        print(pub_pem.decode())


# 运行演示
demo = DigitalSignatureDemo()
demo.demonstrate()
```

### 2.3 哈希函数在签名中的作用

**为什么签名前要先哈希？**

| 不使用哈希 | 使用哈希 |
|----------|---------|
| 签名整个消息，计算量大 | 只签名固定长度的哈希，效率高 |
| 签名长度随消息长度变化 | 签名长度固定 |
| 可能存在数学弱点 | 哈希增加安全性 |
| 无法处理大文件 | 可以处理任意大小文件 |

**签名中使用的哈希算法选择：**

| 哈希算法 | 输出长度 | 安全性 | 推荐使用 |
|----------|---------|--------|---------|
| MD5 | 128位 | 不安全 | 禁止使用 |
| SHA-1 | 160位 | 不安全 | 禁止使用 |
| SHA-256 | 256位 | 安全 | 推荐 |
| SHA-384 | 384位 | 安全 | 推荐（高安全场景） |
| SHA-512 | 512位 | 安全 | 推荐（高安全场景） |
| SM3 | 256位 | 安全 | 推荐（国密场景） |
| SHA-3-256 | 256位 | 安全 | 推荐 |

### 2.4 签名方案的安全性要求

一个安全的数字签名方案需要满足以下安全属性：

1. **存在性不可伪造（EUF）**：在不知道私钥的情况下，攻击者无法产生合法签名
2. **强不可伪造（SUF）**：即使对已签名的消息，攻击者也无法产生不同的合法签名
3. **选择消息攻击安全（CMA）**：即使攻击者可以获得任意消息的签名，也无法伪造其他消息的签名

## 三、RSA数字签名

### 3.1 RSA签名原理

RSA签名利用RSA公钥密码算法的特性实现：

```
RSA算法基本操作：
  加密: c = m^e mod n   （用公钥加密）
  解密: m = c^d mod n   （用私钥解密）
  
RSA签名（反过来用）：
  签名: s = hash(m)^d mod n   （用私钥签名）
  验证: hash(m) = s^e mod n   （用公钥验证）
  
其中:
  n = p * q  （模数）
  e = 公钥指数
  d = 私钥指数
```

### 3.2 RSA签名填充方案

直接对哈希值进行RSA运算是**不安全**的，需要使用填充方案。

#### 3.2.1 PKCS#1 v1.5填充

**PKCS#1 v1.5** 是最传统的RSA签名填充方案。

```
PKCS#1 v1.5签名格式：
  0x00 || 0x01 || PS || 0x00 || T
  
  其中:
    0x00, 0x01: 固定头部
    PS: 填充字节 0xFF...0xFF
    0x00: 分隔符
    T: DigestInfo（哈希算法OID + 哈希值）
  
  DigestInfo结构:
    SHA-256: 30 31 30 0d 06 09 60 86 48 01 65 03 04 02 01 05 00 04 20 [hash]
    SHA-384: 30 41 30 0d 06 09 60 86 48 01 65 03 04 02 02 05 00 04 30 [hash]
    SHA-512: 30 51 30 0d 06 09 60 86 48 01 65 03 04 02 03 05 00 04 40 [hash]
```

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

class RSASignature:
    """RSA签名实现"""
    
    def __init__(self, key_size: int = 2048):
        self.private_key = rsa.generate_private_key(
            public_exponent=65537,
            key_size=key_size
        )
        self.public_key = self.private_key.public_key()
    
    def sign_pkcs1v15(self, message: bytes) -> bytes:
        """PKCS#1 v1.5签名"""
        signature = self.private_key.sign(
            message,
            padding.PKCS1v15(),
            hashes.SHA256()
        )
        return signature
    
    def verify_pkcs1v15(self, message: bytes, signature: bytes) -> bool:
        """PKCS#1 v1.5验证"""
        try:
            self.public_key.verify(
                signature,
                message,
                padding.PKCS1v15(),
                hashes.SHA256()
            )
            return True
        except Exception:
            return False
    
    def sign_pss(self, message: bytes) -> bytes:
        """PSS签名（更安全）"""
        signature = self.private_key.sign(
            message,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH
            ),
            hashes.SHA256()
        )
        return signature
    
    def verify_pss(self, message: bytes, signature: bytes) -> bool:
        """PSS验证"""
        try:
            self.public_key.verify(
                signature,
                message,
                padding.PSS(
                    mgf=padding.MGF1(hashes.SHA256()),
                    salt_length=padding.PSS.MAX_LENGTH
                ),
                hashes.SHA256()
            )
            return True
        except Exception:
            return False
    
    def export_keypair(self) -> tuple:
        """导出密钥对"""
        from cryptography.hazmat.primitives.serialization import (
            Encoding, PrivateFormat, PublicFormat, NoEncryption
        )
        priv_pem = self.private_key.private_bytes(
            Encoding.PEM, PrivateFormat.PKCS8, NoEncryption()
        )
        pub_pem = self.public_key.public_bytes(
            Encoding.PEM, PublicFormat.SubjectPublicKeyInfo
        )
        return priv_pem, pub_pem


# 使用示例
rsa_sig = RSASignature(key_size=2048)
message = b"Important document content"

# PKCS#1 v1.5
sig1 = rsa_sig.sign_pkcs1v15(message)
print(f"PKCS1v15签名验证: {rsa_sig.verify_pkcs1v15(message, sig1)}")

# PSS
sig2 = rsa_sig.sign_pss(message)
print(f"PSS签名验证: {rsa_sig.verify_pss(message, sig2)}")
```

#### 3.2.2 PSS填充方案

**PSS（Probabilistic Signature Scheme）** 是概率性签名方案，比PKCS#1 v1.5更安全。

```
PSS签名过程：
  1. 生成随机盐值（salt）
  2. 计算 M' = Hash(0x00..00 || mHash || salt)
  3. 计算 H = Hash(M')
  4. 用0xBC填充
  5. 生成DB = PS || 0x01 || salt
  6. 用MGF掩码DB
  7. 组合签名块
  
PSS验证过程：
  1. 从签名中恢复DB
  2. 提取salt
  3. 重新计算M'和H
  4. 比较H是否匹配
```

**PSS vs PKCS#1 v1.5对比：**

| 特性 | PKCS#1 v1.5 | PSS |
|------|------------|-----|
| 确定性 | 确定性（同一消息签名相同） | 概率性（同一消息签名不同） |
| 安全性证明 | 无形式化证明 | 有安全证明 |
| 安全等级 | 较低 | 较高 |
| 兼容性 | 广泛 | 需要新系统支持 |
| 推荐 | 旧系统兼容 | 新系统推荐 |

### 3.3 RSA密钥长度与安全性

| 密钥长度 | 等效对称密钥 | 安全评估 | 推荐使用 |
|----------|------------|---------|---------|
| 1024位 | 80位 | 不安全 | 禁止 |
| 2048位 | 112位 | 基本安全 | 最低要求 |
| 3072位 | 128位 | 安全 | 推荐 |
| 4096位 | 152位 | 高安全 | 高安全场景 |
| 8192位 | 200位 | 过度 | 不推荐（性能差） |

### 3.4 OpenSSL RSA签名命令

```bash
# 生成RSA密钥对
openssl genrsa -out private_key.pem 2048

# 提取公钥
openssl rsa -in private_key.pem -pubout -out public_key.pem

# 签名（PKCS#1 v1.5）
openssl dgst -sha256 -sign private_key.pem -out signature.bin message.txt

# 验证签名
openssl dgst -sha256 -verify public_key.pem -signature signature.bin message.txt

# PSS签名
openssl dgst -sha256 \
    -sigopt rsa_padding_mode:pss \
    -sigopt rsa_pss_saltlen:32 \
    -sign private_key.pem \
    -out signature_pss.bin message.txt

# PSS验证
openssl dgst -sha256 \
    -sigopt rsa_padding_mode:pss \
    -sigopt rsa_pss_saltlen:32 \
    -verify public_key.pem \
    -signature signature_pss.bin message.txt
```

## 四、DSA数字签名

### 4.1 DSA算法概述

**DSA（Digital Signature Algorithm）** 是NIST于1991年发布的数字签名标准（DSS）中的签名算法。

**DSA与RSA的对比：**

| 特性 | RSA | DSA |
|------|-----|-----|
| 数学基础 | 大整数分解 | 离散对数 |
| 签名速度 | 较慢 | 快 |
| 验证速度 | 快 | 较慢 |
| 加密能力 | 有 | 无（仅签名） |
| 密钥生成 | 较快 | 较慢 |
| 签名确定性 | PKCS1v15确定/PSS随机 | 随机（依赖随机数k） |

### 4.2 DSA签名过程

```
DSA参数：
  p: 大素数（L位，1024/2048/3072）
  q: 160/224/256位素数，整除(p-1)
  g: 模p的生成元，g^q ≡ 1 (mod p)
  
密钥对：
  私钥 x: 随机数，1 < x < q
  公钥 y: y = g^x mod p

签名过程：
  1. 选择随机数 k, 0 < k < q
  2. 计算 r = (g^k mod p) mod q
  3. 计算 k_inv = k^(-1) mod q
  4. 计算 s = k_inv * (hash(m) + x*r) mod q
  5. 签名 = (r, s)

验证过程：
  1. 检查 0 < r < q 和 0 < s < q
  2. 计算 w = s^(-1) mod q
  3. 计算 u1 = hash(m) * w mod q
  4. 计算 u2 = r * w mod q
  5. 计算 v = ((g^u1 * y^u2) mod p) mod q
  6. 如果 v == r，则验证通过
```

### 4.3 DSA的随机数问题

DSA签名中使用的随机数k如果泄露或可预测，会导致私钥泄露。

```python
"""
DSA随机数k泄露导致私钥恢复的演示
如果两次签名使用了相同的k，可以恢复私钥
"""

def recover_private_key_from_repeated_k(
    m1_hash: int, r1: int, s1: int,
    m2_hash: int, r2: int, s2: int,
    q: int
) -> int:
    """
    从两次使用相同k的签名中恢复私钥
    
    当k相同时: r1 == r2 = r
    s1 = k^(-1) * (H(m1) + x*r) mod q
    s2 = k^(-1) * (H(m2) + x*r) mod q
    
    s1 - s2 = k^(-1) * (H(m1) - H(m2)) mod q
    k = (H(m1) - H(m2)) * (s1 - s2)^(-1) mod q
    
    x = (s1 * k - H(m1)) * r^(-1) mod q
    """
    # 恢复k
    delta_s = (s1 - s2) % q
    delta_h = (m1_hash - m2_hash) % q
    k = (delta_h * pow(delta_s, -1, q)) % q
    
    # 恢复私钥x
    r = r1  # r1 == r2 因为k相同
    x = ((s1 * k - m1_hash) * pow(r, -1, q)) % q
    
    return x


# 示例（概念性演示）
"""
历史案例：索尼PS3 ECDSA私钥泄露
  Sony在PS3的ECDSA签名中重复使用了固定的k值
  导致私钥被恢复，破解了PS3的安全系统
"""
```

**注意：** DSA已被FIPS 186-5标准废弃，推荐使用ECDSA或EdDSA替代。

## 五、ECDSA椭圆曲线数字签名

### 5.1 ECDSA概述

**ECDSA（Elliptic Curve Digital Signature Algorithm）** 是基于椭圆曲线密码学的数字签名算法，提供与RSA/DSA相同的安全服务，但密钥更短、性能更高。

**ECDSA的优势：**

| 特性 | RSA-2048 | ECDSA-256 |
|------|---------|----------|
| 安全强度 | 112位 | 128位 |
| 密钥长度 | 2048位 | 256位 |
| 签名长度 | 256字节 | 64字节 |
| 签名速度 | 慢 | 快 |
| 验证速度 | 快 | 较快 |
| 密钥生成 | 较快 | 快 |

### 5.2 椭圆曲线基础

**椭圆曲线方程：**
```
y² = x³ + ax + b (mod p)

常用曲线：
  P-256 (secp256r1):  y² = x³ - 3x + b  (NIST标准曲线)
  P-384 (secp384r1):  用于更高安全需求
  P-521 (secp521r1):  用于最高安全需求
  secp256k1:          Bitcoin使用的曲线
```

**椭圆曲线上的点运算：**
```
点加法: P + Q = R
  几何意义: 过P和Q的直线与曲线的第三个交点关于x轴的对称点

标量乘法: k * G
  G是基点，k是标量
  计算G + G + ... + G (k次)
  这是ECDSA的核心运算
```

### 5.3 ECDSA签名过程

```
ECDSA参数：
  曲线参数: (p, a, b, G, n)
  G: 基点（生成元）
  n: 基点G的阶（素数）
  
密钥对：
  私钥 d: 随机数, 1 ≤ d ≤ n-1
  公钥 Q: Q = d * G

签名过程：
  1. 选择随机数 k, 1 ≤ k ≤ n-1
  2. 计算 (x1, y1) = k * G
  3. 计算 r = x1 mod n
  4. 如果 r == 0，重新选择k
  5. 计算 s = k^(-1) * (hash(m) + d * r) mod n
  6. 如果 s == 0，重新选择k
  7. 签名 = (r, s)

验证过程：
  1. 检查 1 ≤ r ≤ n-1 和 1 ≤ s ≤ n-1
  2. 计算 w = s^(-1) mod n
  3. 计算 u1 = hash(m) * w mod n
  4. 计算 u2 = r * w mod n
  5. 计算 (x2, y2) = u1*G + u2*Q
  6. 如果 (x2, y2) 为无穷远点，验证失败
  7. 验证通过当且仅当 r ≡ x2 (mod n)
```

```python
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric.utils import (
    decode_dss_signature, encode_dss_signature
)

class ECDSASignature:
    """ECDSA签名实现"""
    
    # 支持的曲线
    CURVES = {
        'P-256': ec.SECP256R1(),
        'P-384': ec.SECP384R1(),
        'P-521': ec.SECP521R1(),
        'secp256k1': ec.SECP256K1(),
    }
    
    def __init__(self, curve_name: str = 'P-256'):
        curve = self.CURVES.get(curve_name)
        if curve is None:
            raise ValueError(f"不支持的曲线: {curve_name}")
        
        self.curve_name = curve_name
        self.curve = curve
        self.private_key = ec.generate_private_key(curve)
        self.public_key = self.private_key.public_key()
    
    def sign(self, message: bytes) -> bytes:
        """签名（DER格式）"""
        signature = self.private_key.sign(
            message,
            ec.ECDSA(hashes.SHA256())
        )
        return signature
    
    def sign_raw(self, message: bytes) -> tuple:
        """签名（原始r,s格式）"""
        der_sig = self.sign(message)
        r, s = decode_dss_signature(der_sig)
        return r, s
    
    def verify(self, message: bytes, signature: bytes) -> bool:
        """验证签名"""
        try:
            self.public_key.verify(
                signature,
                message,
                ec.ECDSA(hashes.SHA256())
            )
            return True
        except Exception:
            return False
    
    def verify_raw(self, message: bytes, r: int, s: int) -> bool:
        """验证签名（原始r,s格式）"""
        der_sig = encode_dss_signature(r, s)
        return self.verify(message, der_sig)
    
    def get_key_sizes(self) -> dict:
        """获取密钥信息"""
        return {
            'curve': self.curve_name,
            'key_size_bits': self.private_key.key_size,
            'signature_size_bytes': self.private_key.key_size // 4,  # r+s
            'public_key_bytes': self.private_key.key_size // 8 * 2 + 1,  # 04+x+y
        }


# 使用示例
ecdsa = ECDSASignature('P-256')
message = b"ECDSA test message"

# 签名
sig = ecdsa.sign(message)
r, s = ecdsa.sign_raw(message)

print(f"曲线: P-256")
print(f"密钥信息: {ecdsa.get_key_sizes()}")
print(f"DER签名长度: {len(sig)} bytes")
print(f"r = {r}")
print(f"s = {s}")
print(f"验证结果: {ecdsa.verify(message, sig)}")

# 篡改验证
tampered = b"ECDSA tampered message"
print(f"篡改验证: {ecdsa.verify(tampered, sig)}")
```

### 5.5 ECDSA的安全注意事项

1. **随机数k的安全**：与DSA一样，ECDSA对随机数k的安全性极度敏感
2. **侧信道攻击**：标量乘法可能泄露时序信息
3. **曲线选择**：某些曲线可能有后门嫌疑（如Dual_EC_DRBG）
4. **RFC 6979**：使用确定性k值避免随机数问题

```python
"""
RFC 6979: 确定性ECDSA签名
使用HMAC从私钥和消息确定性地生成k值
避免随机数k的安全问题
"""

# cryptography库默认使用RFC 6979
# 所以上面的ECDSASignature类已经是确定性签名

# 手动实现RFC 6979（概念性）
import hmac
import hashlib

def rfc6979_generate_k(private_key_int: int, message_hash: bytes,
                       curve_order: int, qlen: int) -> int:
    """
    RFC 6979确定性k值生成
    
    Args:
        private_key_int: 私钥（整数）
        message_hash: 消息哈希
        curve_order: 曲线阶
        qlen: 私钥位长
        
    Returns:
        确定性的k值
    """
    hlen = len(message_hash) * 8  # 哈希位长
    h1 = int.from_bytes(message_hash, 'big') % curve_order
    
    # 步骤a: 处理h1
    bits2int = lambda b: int.from_bytes(b, 'big') >> max(hlen - qlen, 0)
    
    # 步骤b: V = 0x01 0x01 ... 0x01
    V = b'\x01' * (hlen // 8)
    
    # 步骤c: K = 0x00 0x00 ... 0x00
    K = b'\x00' * (hlen // 8)
    
    # 步骤d: K = HMAC_K(V || 0x00 || int2octets(x) || bits2octets(h1))
    x_bytes = private_key_int.to_bytes((qlen + 7) // 8, 'big')
    K = hmac.new(K, V + b'\x00' + x_bytes + h1.to_bytes(
        (hlen + 7) // 8, 'big'), hashlib.sha256).digest()
    
    # 步骤e: V = HMAC_K(V)
    V = hmac.new(K, V, hashlib.sha256).digest()
    
    # 步骤f: K = HMAC_K(V || 0x01 || int2octets(x) || bits2octets(h1))
    K = hmac.new(K, V + b'\x01' + x_bytes + h1.to_bytes(
        (hlen + 7) // 8, 'big'), hashlib.sha256).digest()
    
    # 步骤g: V = HMAC_K(V)
    V = hmac.new(K, V, hashlib.sha256).digest()
    
    # 步骤h: 生成k
    while True:
        T = b''
        while len(T) * 8 < qlen:
            V = hmac.new(K, V, hashlib.sha256).digest()
            T += V
        
        k = int.from_bytes(T, 'big')
        if 1 <= k < curve_order:
            return k
        
        K = hmac.new(K, V + b'\x00', hashlib.sha256).digest()
        V = hmac.new(K, V, hashlib.sha256).digest()
```

## 六、EdDSA签名算法

### 6.1 EdDSA概述

**EdDSA（Edwards-curve Digital Signature Algorithm）** 是基于Twisted Edwards曲线的新一代签名算法，具有高性能、高安全性和快速签名验证的特点。

**EdDSA的特点：**

| 特性 | 说明 |
|------|------|
| 确定性签名 | 不需要随机数，签名结果确定 |
| 抗侧信道攻击 | 不依赖秘密依赖的条件分支 |
| 高性能 | 签名和验证速度都快 |
| 小签名 | 64字节签名 |
| 小密钥 | 32字节公钥 |

**EdDSA曲线对比：**

| 曲线 | 签名算法 | 公钥长度 | 签名长度 | 等效安全 |
|------|---------|---------|---------|---------|
| Ed25519 | Ed25519 | 32字节 | 64字节 | 128位 |
| Ed448 | Ed448 | 57字节 | 114字节 | 224位 |

### 6.2 Ed25519签名

```python
from cryptography.hazmat.primitives.asymmetric.ed25519 import (
    Ed25519PrivateKey, Ed25519PublicKey
)

class Ed25519Signature:
    """Ed25519签名实现"""
    
    def __init__(self):
        self.private_key = Ed25519PrivateKey.generate()
        self.public_key = self.private_key.public_key()
    
    def sign(self, message: bytes) -> bytes:
        """签名（纯签名，不需要哈希）"""
        return self.private_key.sign(message)
    
    def verify(self, message: bytes, signature: bytes) -> bool:
        """验证签名"""
        try:
            self.public_key.verify(signature, message)
            return True
        except Exception:
            return False
    
    def export_keys(self) -> tuple:
        """导出密钥"""
        from cryptography.hazmat.primitives.serialization import (
            Encoding, PrivateFormat, PublicFormat, NoEncryption
        )
        priv_bytes = self.private_key.private_bytes(
            Encoding.Raw, PrivateFormat.Raw, NoEncryption()
        )
        pub_bytes = self.public_key.public_bytes(
            Encoding.Raw, PublicFormat.Raw
        )
        return priv_bytes, pub_bytes
    
    def import_public_key(self, key_bytes: bytes):
        """从字节导入公钥"""
        self.public_key = Ed25519PublicKey.from_public_bytes(key_bytes)


# 使用示例
ed = Ed25519Signature()
message = b"Ed25519 test message"

# 签名
sig = ed.sign(message)
priv, pub = ed.export_keys()

print(f"私钥长度: {len(priv)} bytes")
print(f"公钥长度: {len(pub)} bytes")
print(f"签名长度: {len(sig)} bytes")
print(f"验证结果: {ed.verify(message, sig)}")

# 同一消息签名相同（确定性）
sig2 = ed.sign(message)
print(f"确定性签名验证: {sig == sig2}")

# 从公钥验证
ed2 = Ed25519Signature()
ed2.import_public_key(pub)
print(f"公钥验证: {ed2.verify(message, sig)}")
```

## 七、国密SM2数字签名

### 7.1 SM2签名概述

**SM2** 是中国密码管理局发布的椭圆曲线公钥密码算法，包含数字签名、密钥交换和公钥加密三个部分。SM2签名是国密PKI体系的核心。

**SM2与ECDSA的对比：**

| 特性 | ECDSA | SM2 |
|------|-------|-----|
| 曲线 | NIST曲线 | SM2曲线 |
| 签名流程 | 标准ECDSA | 增加了ZA和Z值 |
| 哈希 | SHA-256 | SM3 |
| 签名长度 | 64字节（P-256） | 64字节 |
| 国际标准 | FIPS 186 | GB/T 32918 |

### 7.2 SM2曲线参数

```
SM2椭圆曲线参数：
  方程: y² = x³ + ax + b (mod p)
  
  p = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF FFFFFFFF 00000000 FFFFFFFF FFFFFFFF
  
  a = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF FFFFFFFF 00000000 FFFFFFFF FFFFFFFC
  
  b = 28E9FA9E 9D9F5E34 4D5A9E4B CF659098 E0369503 E0B68A65 C39E2E0C 9EDE51E6
  
  基点G:
    Gx = 32C4AE2C 1F198119 5F990446 6C5A9EC3 7D9E2A3D E0F4A7D3 89C8B71C 225BE9DD
    Gy = 9E6E9E3A 6E5C5D51 5B6B6C6C 9E6E2E4F 2D5C5E51 5E5E5E51 7C8C8C8C 5E5E5E5E
  
  阶n:
    n = FFFFFFFE FFFFFFFF FFFFFFFF FFFFFFFF 7203DF6B 21C6052B 53BBF409 39D54123
```

### 7.3 SM2签名流程

```
SM2签名过程：

  预处理：
  1. 计算ZA = SM3(ENTL || ID || a || b || Gx || Gy || Px || Py)
     其中:
       ENTL = ID的位长度（2字节）
       ID = 用户标识（默认"1234567812345678"）
       a, b = 曲线参数
       Gx, Gy = 基点坐标
       Px, Py = 公钥坐标

  签名：
  1. 计算e = SM3(ZA || M)，M为待签消息
  2. 选择随机数k, 1 ≤ k ≤ n-1
  3. 计算(x1, y1) = k * G
  4. 计算r = (e + x1) mod n
  5. 如果r == 0或r+k == n，重新选择k
  6. 计算s = ((1 + d)^(-1)) * (k - r*d) mod n
  7. 如果s == 0，重新选择k
  8. 签名 = (r, s)

  验证：
  1. 检查 1 ≤ r ≤ n-1 和 1 ≤ s ≤ n-1
  2. 计算e = SM3(ZA || M)
  3. 计算t = (r + s) mod n
  4. 如果t == 0，验证失败
  5. 计算(x2, y2) = s*G + t*Q
  6. 计算R = (e + x2) mod n
  7. 验证通过当且仅当 R == r
```

```python
"""
SM2签名实现
使用gmssl库: pip install gmssl
"""

try:
    from gmssl import sm2, func
    HAS_GMSSL = True
except ImportError:
    HAS_GMSSL = False
    print("请安装gmssl库: pip install gmssl")


class SM2Signature:
    """SM2数字签名实现"""
    
    DEFAULT_USER_ID = "1234567812345678"  # 默认用户标识
    
    def __init__(self):
        if not HAS_GMSSL:
            raise ImportError("需要gmssl库")
        
        # 生成SM2密钥对
        self.private_key = func.random_hex(64)  # 256位私钥
        
        # 创建SM2对象
        sm2_crypt = sm2.CryptSM2(
            pubkey='',  # 公钥稍后计算
            privkey=self.private_key
        )
        self.public_key = sm2_crypt._kg(  # 计算公钥
            int(self.private_key, 16),
            sm2_crypt.pointG
        )
        # 转为十六进制字符串
        self.public_key = '%064x%064x' % self.public_key
        
        # 创建完整的SM2对象
        self.sm2_crypt = sm2.CryptSM2(
            pubkey=self.public_key,
            privkey=self.private_key
        )
    
    def sign(self, message: bytes, user_id: str = None) -> bytes:
        """
        SM2签名
        
        Args:
            message: 待签名消息
            user_id: 用户标识
            
        Returns:
            签名（DER格式）
        """
        if user_id is None:
            user_id = self.DEFAULT_USER_ID
        
        # SM2签名
        signature = self.sm2_crypt.sign(
            message.encode('utf-8') if isinstance(message, str) else message,
            user_id.encode('utf-8')
        )
        
        return signature
    
    def verify(self, message: bytes, signature: bytes, 
               user_id: str = None) -> bool:
        """
        SM2验证签名
        
        Args:
            message: 原始消息
            signature: 签名
            user_id: 用户标识
            
        Returns:
            验证结果
        """
        if user_id is None:
            user_id = self.DEFAULT_USER_ID
        
        msg_bytes = message.encode('utf-8') if isinstance(message, str) \
                    else message
        
        return self.sm2_crypt.verify(
            signature,
            msg_bytes,
            user_id.encode('utf-8')
        )
    
    def export_keypair(self) -> dict:
        """导出密钥对"""
        return {
            'private_key': self.private_key,
            'public_key': self.public_key,
            'curve': 'SM2',
            'key_size': 256,
            'signature_size': 64  # r(32) + s(32)
        }


if HAS_GMSSL:
    # 使用示例
    sm2_sig = SM2Signature()
    message = "SM2签名测试消息"
    
    print(f"私钥: {sm2_sig.private_key[:32]}...")
    print(f"公钥: {sm2_sig.public_key[:32]}...")
    
    sig = sm2_sig.sign(message)
    print(f"签名: {sig.hex()[:60]}...")
    
    valid = sm2_sig.verify(message, sig)
    print(f"验证结果: {valid}")
```

## 九、数字时间戳服务

### 9.1 时间戳概述

**数字时间戳（Digital Timestamp）** 服务为电子文档提供可信的时间证明，证明某个文档在特定时间点已经存在。

```
时间戳的作用：
  1. 证明文档在某个时间点之前已经存在
  2. 为数字签名提供时间证明（防止签名后私钥泄露的回溯攻击）
  3. 满足法律对时间证据的要求
  4. 在专利申请、版权保护中的应用
```

### 9.2 RFC 3161时间戳协议

```
时间戳请求/响应流程：

  客户端                        TSA（时间戳机构）
    │                              │
    │── TimeStampReq ────────────→│
    │   (文档哈希)                  │
    │                              │ 获取当前时间
    │                              │ 用TSA私钥签名
    │←── TimeStampResp ───────────│
    │   (时间戳令牌)                │
    
TimeStampReq结构：
  version: 1
  messageImprint: 消息哈希（算法+值）
  reqPolicy: 请求的策略（可选）
  nonce: 随机数（防重放）
  certReq: 是否请求证书

TimeStampResp结构：
  status: 状态码
  statusString: 状态描述
  timeStampToken: 时间戳令牌（CMS格式）
```

```python
            oid = bytes.fromhex('0609608648016503040201')  # SHA-256 OID
```

### 9.3 长期签名验证（LTV）

长期签名的验证需要考虑证书过期和算法过时的问题：

```
长期签名验证时间线：

  签名时 → 证书有效期内 → 证书过期后 → 长期保存

  签名时：
    1. 验证签名
    2. 验证证书链
    3. 验证证书状态（OCSP/CRL）
    
  证书有效期内：
    4. 添加时间戳（证明签名时间）
    5. 保存验证材料（证书链+OCSP/CRL）
    
  证书过期后：
    6. 添加归档时间戳（用新算法）
    7. 重新保存验证材料
    8. 循环步骤6-7以保持长期有效
```

```python
"""
ECDSA随机数k攻击演示
当k泄露或重复使用时，可以恢复私钥
"""

def attack_repeated_k(
    msg1_hash: int, sig1_r: int, sig1_s: int,
    msg2_hash: int, sig2_r: int, sig2_s: int,
    n: int
) -> int:
    """
    从重复使用k的两次签名中恢复私钥
    
    当k相同时: sig1_r == sig2_r
    
    s1 = k^(-1) * (h1 + r * d) mod n
    s2 = k^(-1) * (h2 + r * d) mod n
    
    s1 - s2 = k^(-1) * (h1 - h2) mod n
    k = (h1 - h2) / (s1 - s2) mod n
    
    d = (s1 * k - h1) / r mod n
    """
    if sig1_r != sig2_r:
        raise ValueError("r值不同，k可能不同")
    
    r = sig1_r
    
    # 恢复k
    k = ((msg1_hash - msg2_hash) * 
         pow(sig1_s - sig2_s, -1, n)) % n
    
    # 恢复私钥d
    d = ((sig1_s * k - msg1_hash) * pow(r, -1, n)) % n
    
    return d
```

```python
"""
代码签名实践
"""
import hashlib
import os
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric.utils import (
    encode_dss_signature, decode_dss_signature
)
from cryptography.hazmat.primitives.serialization import (
    Encoding, PrivateFormat, NoEncryption, PublicFormat
)
import json
import time

class CodeSigner:
    """代码签名工具"""
    
    def __init__(self):
        self.private_key = ec.generate_private_key(ec.SECP256R1())
        self.public_key = self.private_key.public_key()
    
    def sign_file(self, file_path: str) -> dict:
        """
        对文件进行签名
        
        Args:
            file_path: 文件路径
            
        Returns:
            签名信息
        """
        # 计算文件哈希
        hasher = hashlib.sha256()
        with open(file_path, 'rb') as f:
            while chunk := f.read(8192):
                hasher.update(chunk)
        file_hash = hasher.hexdigest()
        
        # 获取文件信息
        file_size = os.path.getsize(file_path)
        file_name = os.path.basename(file_path)
        
        # 构建签名内容
        sign_content = {
            'file_name': file_name,
            'file_size': file_size,
            'file_hash': file_hash,
            'hash_algorithm': 'SHA-256',
            'timestamp': int(time.time()),
        }
        
        # 签名
        content_bytes = json.dumps(sign_content, 
                                   sort_keys=True).encode()
        signature = self.private_key.sign(
            content_bytes,
            ec.ECDSA(hashes.SHA256())
        )
        
        # 导出公钥
        pub_pem = self.public_key.public_bytes(
            Encoding.PEM,
            PublicFormat.SubjectPublicKeyInfo
        ).decode()
        
        return {
            'file_info': sign_content,
            'signature': signature.hex(),
            'public_key': pub_pem,
            'sign_algorithm': 'ECDSA-SHA256',
            'sign_time': time.strftime(
                '%Y-%m-%d %H:%M:%S',
                time.localtime(sign_content['timestamp'])
            )
        }
    
    def verify_file(self, file_path: str, sig_info: dict) -> dict:
        """
        验证文件签名
        
        Args:
            file_path: 文件路径
            sig_info: 签名信息
            
        Returns:
            验证结果
        """
        result = {
            'valid': False,
            'file_intact': False,
            'signature_valid': False,
            'errors': []
        }
        
        # 1. 验证文件哈希
        hasher = hashlib.sha256()
        with open(file_path, 'rb') as f:
            while chunk := f.read(8192):
                hasher.update(chunk)
        current_hash = hasher.hexdigest()
        
        expected_hash = sig_info['file_info']['file_hash']
        result['file_intact'] = (current_hash == expected_hash)
        
        if not result['file_intact']:
            result['errors'].append('文件已被修改')
        
        # 2. 验证签名
        content_bytes = json.dumps(
            sig_info['file_info'],
            sort_keys=True
        ).encode()
        
        signature = bytes.fromhex(sig_info['signature'])
        
        try:
            self.public_key.verify(
                signature,
                content_bytes,
                ec.ECDSA(hashes.SHA256())
            )
            result['signature_valid'] = True
        except Exception as e:
            result['signature_valid'] = False
            result['errors'].append(f'签名验证失败: {e}')
        
        # 3. 综合结果
        result['valid'] = result['file_intact'] and result['signature_valid']
        
        return result


# 使用示例
signer = CodeSigner()

# 签名文件

with open(test_file, 'wb') as f:
    f.write(b"executable content here")

print("签名信息:")
print(f"  文件: {sig_info['file_info']['file_name']}")
print(f"  哈希: {sig_info['file_info']['file_hash'][:32]}...")
print(f"  签名: {sig_info['signature'][:32]}...")
print(f"  签名时间: {sig_info['sign_time']}")

# 验证文件
verify_result = signer.verify_file(test_file, sig_info)
print(f"\n验证结果: {verify_result['valid']}")

# 模拟篡改
with open(test_file, 'ab') as f:
    f.write(b"malicious payload")

verify_result = signer.verify_file(test_file, sig_info)
print(f"篡改后验证: {verify_result['valid']}")
print(f"错误: {verify_result['errors']}")
```

```python
"""

class ElectronicContract:
    """电子合同签名系统"""

        self.signatures = []
        self.created_at = time.time()
        self.signing_order = []
    
    def add_signer(self, name: str, role: str, 
                   must_sign_before: list = None):
        """添加签名者"""
        self.signing_order.append({
            'name': name,
            'role': role,
            'must_sign_before': must_sign_before or [],
            'signed': False,
            'signature': None,
            'signed_at': None
        })
    
    def sign(self, signer_name: str, private_key, 
             user_id: str = None) -> bool:
        """
        签名合同
        
        Args:
            signer_name: 签名者姓名
            private_key: 私钥
            user_id: 用户ID（SM2用）
            
        Returns:
            签名是否成功
        """
        # 查找签名者
        signer = None
        for s in self.signing_order:
            if s['name'] == signer_name and not s['signed']:
                signer = s
                break
        
        if not signer:
            print(f"签名者 {signer_name} 不在待签名列表中")
            return False
        
        # 检查签名顺序
        for dep_name in signer['must_sign_before']:
            dep = next(
                (s for s in self.signing_order if s['name'] == dep_name),
                None
            )
            if dep and not dep['signed']:
                print(f"需要 {dep_name} 先签名")
                return False
        
        # 签名内容
        sign_content = f"{self.title}\n{self.content}\n{self.content_hash}"
        
        # 使用私钥签名
        if hasattr(private_key, 'sign'):
            # RSA或ECDSA
            signature = private_key.sign(
                sign_content.encode(),
                padding.PSS(
                    mgf=padding.MGF1(hashes.SHA256()),
                    salt_length=padding.PSS.MAX_LENGTH
                ),
                hashes.SHA256()
            )
        else:
            signature = b''
        
        signer['signed'] = True
        signer['signature'] = signature.hex()
        signer['signed_at'] = time.time()
        
        print(f"{signer_name} 签名成功")
        return True
    
    def is_fully_signed(self) -> bool:
        """检查是否所有签名者都已签名"""
        return all(s['signed'] for s in self.signing_order)
    
    def get_signing_status(self) -> list:
        """获取签名状态"""
        return [
            {
                'name': s['name'],
                'role': s['role'],
                'signed': s['signed'],
                'signed_at': s['signed_at']
            }
            for s in self.signing_order
        ]
    
    def to_dict(self) -> dict:
        """导出合同信息"""
        return {
            'title': self.title,
            'content': self.content,
            'content_hash': self.content_hash,
            'created_at': self.created_at,
            'signatures': self.signing_order,
            'fully_signed': self.is_fully_signed()
        }
```

```python
"""

以Bitcoin风格为例

import hashlib
import struct

class BitcoinTransaction:
    """简化的比特币交易结构"""
    
    def __init__(self):
        self.inputs = []
        self.outputs = []
        self.locktime = 0
    
    def add_input(self, txid: str, vout: int, 
                  script_pubkey: bytes):
        """添加输入"""
        self.inputs.append({
            'txid': bytes.fromhex(txid),
            'vout': vout,
            'script_pubkey': script_pubkey,
            'script_sig': b'',
            'sequence': 0xFFFFFFFF
        })
    
    def add_output(self, address: str, value: int):
        """添加输出"""
        self.outputs.append({
            'address': address,
            'value': value,
            'script_pubkey': b''
        })
    
    def serialize_for_signing(self, input_index: int) -> bytes:
        """
        序列化交易用于签名（简化版）
        
        Bitcoin使用SIGHASH标志控制签名范围
        """
        # 在实际实现中需要处理SIGHASH逻辑
        data = b''
        
        # 版本号
        data += struct.pack('<I', 1)
        
        # 输入
        data += struct.pack('<B', len(self.inputs))
        for i, tx_in in enumerate(self.inputs):
            data += tx_in['txid'][::-1]  # 小端序
            data += struct.pack('<I', tx_in['vout'])
            if i == input_index:
                data += struct.pack('<B', len(tx_in['script_pubkey']))
                data += tx_in['script_pubkey']
            else:
                data += b'\x00'  # 空脚本
            data += struct.pack('<I', tx_in['sequence'])
        
        # 输出
        data += struct.pack('<B', len(self.outputs))
        for tx_out in self.outputs:
            data += struct.pack('<Q', tx_out['value'])
            data += struct.pack('<B', len(tx_out['script_pubkey']))
            data += tx_out['script_pubkey']
        
        # 锁定时间
        data += struct.pack('<I', self.locktime)
        
        # SIGHASH标志
        data += struct.pack('<I', 0x01)  # SIGHASH_ALL
        
        return data
    
    def sign_input(self, input_index: int, private_key) -> bytes:
        """签名输入"""
        from cryptography.hazmat.primitives.asymmetric import ec
        from cryptography.hazmat.primitives import hashes
        
        # 序列化
        ser = self.serialize_for_signing(input_index)
        
        # 计算哈希
        tx_hash = hashlib.sha256(hashlib.sha256(ser).digest()).digest()
        
        # 签名（使用ECDSA）
        # Bitcoin使用secp256k1曲线
        der_sig = private_key.sign(tx_hash, ec.ECDSA(hashes.SHA256()))
        
        # 添加SIGHASH标志
        sig_with_hashtype = der_sig + b'\x01'
        
        return sig_with_hashtype
```

### 11.4 JWT签名

```python
"""
JWT（JSON Web Token）签名
JWT是Web应用中常用的令牌格式
"""
import json
import base64
import hmac
import hashlib
from cryptography.hazmat.primitives.asymmetric import rsa, ec
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding

class JWTEncoder:
    """JWT编码/解码器"""
    
    @staticmethod
    def base64url_encode(data: bytes) -> str:
        """Base64URL编码"""
        return base64.urlsafe_b64encode(data).rstrip(b'=').decode()
    
    @staticmethod
    def base64url_decode(data: str) -> bytes:
        """Base64URL解码"""
        padding = 4 - len(data) % 4
        if padding != 4:
            data += '=' * padding
        return base64.urlsafe_b64decode(data)
    
    @staticmethod
    def encode_hs256(payload: dict, secret: str) -> str:
        """HMAC-SHA256签名JWT"""
        header = {"alg": "HS256", "typ": "JWT"}
        
        header_b64 = JWTEncoder.base64url_encode(
            json.dumps(header).encode()
        )
        payload_b64 = JWTEncoder.base64url_encode(
            json.dumps(payload).encode()
        )
        
        signing_input = f"{header_b64}.{payload_b64}"
        signature = hmac.new(
            secret.encode(),
            signing_input.encode(),
            hashlib.sha256
        ).digest()
        
        sig_b64 = JWTEncoder.base64url_encode(signature)
        
        return f"{header_b64}.{payload_b64}.{sig_b64}"
    
    @staticmethod
    def encode_rs256(payload: dict, private_key) -> str:
        """RSA-SHA256签名JWT"""
        header = {"alg": "RS256", "typ": "JWT"}
        
        header_b64 = JWTEncoder.base64url_encode(
            json.dumps(header).encode()
        )
        payload_b64 = JWTEncoder.base64url_encode(
            json.dumps(payload).encode()
        )
        
        signing_input = f"{header_b64}.{payload_b64}"
        signature = private_key.sign(
            signing_input.encode(),
            padding.PKCS1v15(),
            hashes.SHA256()
        )
        
        sig_b64 = JWTEncoder.base64url_encode(signature)
        
        return f"{header_b64}.{payload_b64}.{sig_b64}"
    
    @staticmethod
    def encode_es256(payload: dict, private_key) -> str:
        """ECDSA-P256-SHA256签名JWT"""
        header = {"alg": "ES256", "typ": "JWT"}
        
        header_b64 = JWTEncoder.base64url_encode(
            json.dumps(header).encode()
        )
        payload_b64 = JWTEncoder.base64url_encode(
            json.dumps(payload).encode()
        )
        
        signing_input = f"{header_b64}.{payload_b64}"
        
        # ECDSA签名
        der_sig = private_key.sign(
            signing_input.encode(),
            ec.ECDSA(hashes.SHA256())
        )
        
        # 将DER格式转换为原始r||s格式
        from cryptography.hazmat.primitives.asymmetric.utils import (
            decode_dss_signature
        )
        r, s = decode_dss_signature(der_sig)
        
        # r和s各32字节
        sig_bytes = r.to_bytes(32, 'big') + s.to_bytes(32, 'big')
        sig_b64 = JWTEncoder.base64url_encode(sig_bytes)
        
        return f"{header_b64}.{payload_b64}.{sig_b64}"
    
    @staticmethod
    def encode_eddsa(payload: dict, private_key) -> str:
        """EdDSA（Ed25519）签名JWT"""
        header = {"alg": "EdDSA", "typ": "JWT"}
        
        header_b64 = JWTEncoder.base64url_encode(
            json.dumps(header).encode()
        )
        payload_b64 = JWTEncoder.base64url_encode(
            json.dumps(payload).encode()
        )
        
        signing_input = f"{header_b64}.{payload_b64}"
        signature = private_key.sign(signing_input.encode())
        
        sig_b64 = JWTEncoder.base64url_encode(signature)
        
        return f"{header_b64}.{payload_b64}.{sig_b64}"
    
    @staticmethod
    def decode(token: str, verify_key=None, algorithm=None) -> dict:
        """
        解码JWT（可选验证签名）
        
        Args:
            token: JWT令牌
            verify_key: 验证密钥/公钥
            algorithm: 签名算法
            
        Returns:
            payload字典
        """
        parts = token.split('.')
        if len(parts) != 3:
            raise ValueError("无效的JWT格式")
        
        header_b64, payload_b64, sig_b64 = parts
        
        # 解码header和payload
        header = json.loads(
            JWTEncoder.base64url_decode(header_b64)
        )
        payload = json.loads(
            JWTEncoder.base64url_decode(payload_b64)
        )
        signature = JWTEncoder.base64url_decode(sig_b64)
        
        # 验证签名
        if verify_key and algorithm:
            signing_input = f"{header_b64}.{payload_b64}"
            
            if algorithm == "HS256":
                expected = hmac.new(
                    verify_key.encode(),
                    signing_input.encode(),
                    hashlib.sha256
                ).digest()
                if not hmac.compare_digest(signature, expected):
                    raise ValueError("签名验证失败")
            
            elif algorithm == "RS256":
                try:
                    verify_key.verify(
                        signature,
                        signing_input.encode(),
                        padding.PKCS1v15(),
                        hashes.SHA256()
                    )
                except Exception:
                    raise ValueError("签名验证失败")
            
            elif algorithm == "ES256":
                # 将原始格式转换为DER
                r = int.from_bytes(signature[:32], 'big')
                s = int.from_bytes(signature[32:], 'big')
                from cryptography.hazmat.primitives.asymmetric.utils import (
                    encode_dss_signature
                )
                der_sig = encode_dss_signature(r, s)
                try:
                    verify_key.verify(
                        der_sig,
                        signing_input.encode(),
                        ec.ECDSA(hashes.SHA256())
                    )
                except Exception:
                    raise ValueError("签名验证失败")
            
            elif algorithm == "EdDSA":
                try:
                    verify_key.verify(
                        signature,
                        signing_input.encode()
                    )
                except Exception:
                    raise ValueError("签名验证失败")
        
        return payload


# 使用示例
payload = {"user_id": 123, "name": "Alice", "exp": 9999999999}

# HS256
secret = "my-secret-key"
token_hs = JWTEncoder.encode_hs256(payload, secret)
print(f"HS256 JWT: {token_hs[:50]}...")
decoded = JWTEncoder.decode(token_hs, secret, "HS256")
print(f"解码: {decoded}")

# RS256
rsa_key = rsa.generate_private_key(65537, 2048)
token_rs = JWTEncoder.encode_rs256(payload, rsa_key)
print(f"\nRS256 JWT: {token_rs[:50]}...")
decoded = JWTEncoder.decode(token_rs, rsa_key.public_key(), "RS256")
print(f"解码: {decoded}")

# ES256
ec_key = ec.generate_private_key(ec.SECP256R1())
token_es = JWTEncoder.encode_es256(payload, ec_key)
print(f"\nES256 JWT: {token_es[:50]}...")
decoded = JWTEncoder.decode(token_es, ec_key.public_key(), "ES256")
print(f"解码: {decoded}")

# EdDSA
from cryptography.hazmat.primitives.asymmetric.ed25519 import (
    Ed25519PrivateKey
)
ed_key = Ed25519PrivateKey.generate()
token_ed = JWTEncoder.encode_eddsa(payload, ed_key)
print(f"\nEdDSA JWT: {token_ed[:50]}...")
decoded = JWTEncoder.decode(token_ed, ed_key.public_key(), "EdDSA")
print(f"解码: {decoded}")
```

## 十二、后量子数字签名

### 12.1 量子计算对签名的威胁

```
量子计算威胁：
  Shor算法:  可以在多项式时间内分解大整数和求解离散对数
             → RSA、DSA、ECDSA全部不安全
  Grover算法: 将对称密钥安全强度减半
             → 需要更长的哈希输出

影响评估：
  RSA-2048   → 量子下等效80位安全（不安全）
  ECDSA-256  → 量子下等效128/2≈不安全
  Ed25519    → 量子下等效128/2≈不安全
  SHA-256    → 量子下等效128位（基本安全）
  AES-256    → 量子下等效128位（基本安全）
```

### 12.2 NIST后量子签名标准

NIST后量子密码标准化竞赛选出的签名算法：

| 算法 | 类型 | 签名大小 | 公钥大小 | 私钥大小 | 安全等级 |
|------|------|---------|---------|---------|---------|
| ML-DSA (CRYSTALS-Dilithium) | 格基 | 3309B | 1312B | 2560B | Level 2 |
| SLH-DSA (SPHINCS+) | 哈希基 | 7856B | 64B | 64B | Level 2 |
| Falcon | 格基+NTRU | 666B | 897B | 1280B | Level 1 |

### 12.3 混合签名方案

```
混合签名方案：
  传统签名 + 后量子签名 → 混合签名
  
  优势：
  1. 即使量子计算成熟，传统签名仍提供安全
  2. 即使后量子算法有缺陷，传统签名仍提供安全
  3. 平滑过渡到后量子时代

  实现方式：
  1. 串行签名：先传统签名，再后量子签名
  2. 并行签名：两种签名独立产生
  3. 嵌套签名：一种签名嵌入另一种
```

```python
"""
混合签名方案概念实现
"""
from cryptography.hazmat.primitives.asymmetric import ec, ed25519
from cryptography.hazmat.primitives import hashes
import json
import base64

class HybridSigner:
    """混合签名（ECDSA + Ed25519）"""
    
    def __init__(self):
        # 传统算法密钥
        self.ecdsa_key = ec.generate_private_key(ec.SECP256R1())
        # 新一代算法密钥
        self.ed25519_key = ed25519.Ed25519PrivateKey.generate()
    
    def sign(self, message: bytes) -> dict:
        """双重签名"""
        # ECDSA签名
        ecdsa_sig = self.ecdsa_key.sign(
            message,
            ec.ECDSA(hashes.SHA256())
        )
        
        # Ed25519签名
        ed25519_sig = self.ed25519_key.sign(message)
        
        return {
            'message': message.hex(),
            'ecdsa_signature': base64.b64encode(ecdsa_sig).decode(),
            'ed25519_signature': base64.b64encode(ed25519_sig).decode(),
            'algorithms': ['ECDSA-P256-SHA256', 'Ed25519']
        }
    
    def verify(self, message: bytes, sig_data: dict) -> bool:
        """双重验证"""
        # 验证ECDSA
        try:
            self.ecdsa_key.public_key().verify(
                base64.b64decode(sig_data['ecdsa_signature']),
                message,
                ec.ECDSA(hashes.SHA256())
            )
            ecdsa_valid = True
        except Exception:
            ecdsa_valid = False
        
        # 验证Ed25519
        try:
            self.ed25519_key.public_key().verify(
                base64.b64decode(sig_data['ed25519_signature']),
                message
            )
            ed25519_valid = True
        except Exception:
            ed25519_valid = False
        
        # 两种签名都通过才算有效
        return ecdsa_valid and ed25519_valid


# 使用示例
hybrid = HybridSigner()
message = b"Important document"

sig = hybrid.sign(message)
print(f"ECDSA签名长度: {len(base64.b64decode(sig['ecdsa_signature']))} bytes")
print(f"Ed25519签名长度: {len(base64.b64decode(sig['ed25519_signature']))} bytes")

valid = hybrid.verify(message, sig)
print(f"混合签名验证: {valid}")
```

## 十三、总结与最佳实践

### 13.1 签名算法选择指南

| 场景 | 推荐算法 | 理由 |
|------|---------|------|
| Web TLS证书 | RSA-2048+ / ECDSA-P256 | 广泛兼容性 |
| SSH认证 | Ed25519 | 高性能，小密钥 |
| JWT令牌 | HS256(HMAC) / EdDSA | 性能好 |
| 代码签名 | RSA-4096 / ECDSA-P384 | 高安全 |
| 区块链 | ECDSA secp256k1 | 行业标准 |
| 移动应用 | ECDSA-P256 / Ed25519 | 性能和大小 |
| 物联网设备 | Ed25519 | 资源效率 |
| 中国合规 | SM2 | 法规要求 |
| 后量子准备 | ML-DSA / Falcon | 抗量子攻击 |

### 13.2 数字签名最佳实践

1. **使用经过审计的密码学库**：不要自己实现签名算法
2. **选择合适的算法和参数**：根据安全需求选择
3. **使用确定性签名**：ECDSA使用RFC 6979，或使用EdDSA
4. **保护私钥安全**：使用HSM或安全存储
5. **验证时检查所有条件**：签名有效性、证书链、证书状态
6. **使用恒定时间比较**：防止时序攻击
7. **添加时间戳**：长期保存的签名需要时间戳
8. **使用标准格式**：CMS/PKCS#7、JWS等
9. **定期轮换密钥**：防止密钥老化
10. **记录审计日志**：记录所有签名操作

### 13.3 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 使用MD5/SHA-1哈希 | 碰撞攻击 | 使用SHA-256以上 |
| RSA不用填充 | 签名可伪造 | 使用PSS或PKCS1v15 |
| ECDSA随机数k泄露 | 私钥泄露 | 使用RFC 6979 |
| 不验证证书链 | 中间人攻击 | 完整证书链验证 |
| 签名后修改数据 | 签名失效 | 先签后存 |
| 私钥硬编码 | 密钥泄露 | 使用HSM/KMS |
| 不使用时间戳 | 无法证明签名时间 | 添加RFC 3161时间戳 |
