# 后量子密码学简介

### 6.1 量子计算威胁

**Shor 算法**：可在多项式时间内分解大整数和求离散对数

```
Shor 算法对现有密码的影响：
- RSA：完全破解（基于大整数分解）
- ECC：完全破解（基于离散对数）
- DH/DSA：完全破解
- AES：安全强度减半（Grover）
- SHA：安全强度减半
```

**Grover 算法**：O(√N) 搜索

```
影响：对称密码安全强度减半
对策：AES-256 → 128位安全（仍足够）
      SHA-256 → 128位安全（仍足够）
```

### 6.2 后量子密码学分类

```
后量子密码四大方向：
┌──────────────┬──────────────────────────────────────┐
│ 格基密码       │ 基于格上困难问题（SVP/CVP/LWE）      │
│ (Lattice)     │ 效率较高，通用性最强                  │
├──────────────┼──────────────────────────────────────┤
│ 编码基密码     │ 基于纠错码理论                        │
│ (Code-based)  │ 公钥大，历史最久（McEliece 1978）     │
├──────────────┼──────────────────────────────────────┤
│ 多变量密码     │ 基于多变量二次方程组求解困难          │
│ (Multivariate)│ 签名效率高，公钥大                    │
├──────────────┼──────────────────────────────────────┤
│ 哈希基密码     │ 基于哈希函数                          │
│ (Hash-based)  │ 安全性只依赖哈希函数，最可靠           │
└──────────────┴──────────────────────────────────────┘
```

### 6.3 NIST 后量子标准化进展

```
NIST PQC 标准化时间线：

2016.02  征集提案
2017.11  提交截止（收到69个方案）
2019.01  第一轮淘汰（26个进入第二轮）
2020.07  第二轮淘汰（15个进入第三轮）
2022.07  公布最终入选方案
2024.08  发布正式标准

入选标准：
┌────────────────┬──────────────┬──────────┐
│ 算法            │ 类型          │ 用途      │
├────────────────┼──────────────┼──────────┤
│ ML-KEM (Kyber) │ 格基          │ 密钥封装 │
│ ML-DSA (Dilithium)│ 格基       │ 数字签名 │
│ SLH-DSA (SPHINCS+)│ 哈希基     │ 数字签名 │
│ FN-DSA (Falcon)│ 格基(NTRU)   │ 数字签名 │
└────────────────┴──────────────┴──────────┘
```

**ML-KEM (Kyber) 原理：**

```python
# Kyber 核心基于 MLWE（Module Learning With Errors）
"""
问题：给定 A（随机矩阵）, t = A*s + e，求 s
其中 s, e 是小噪声向量

KEM 流程：
1. KeyGen: 
   - 采样秘密 s, 噪声 e
   - 计算 t = A*s + e
   - 公钥 = (A, t)，私钥 = s

2. Encapsulate:
   - 采样消息 m, 噪声 r, e1, e2
   - 计算 u = A^T*r + e1
   - 计算 v = t^T*r + e2 + m*ceil(q/2)
   - 密文 = (u, v)
   - 共享密钥 K = Hash(m)

3. Decapsulate:
   - 计算 m' = v - s^T*u
   - m' 接近 m（噪声影响）
   - 共享密钥 K = Hash(m')
"""
```
