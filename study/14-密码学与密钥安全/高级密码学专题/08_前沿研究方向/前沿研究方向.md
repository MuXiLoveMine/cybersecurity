```
└──────────────────┴──────────────────────────────────────┘
```

**可验证随机函数（VRF）：**

```python
# VRF 概念：可验证的随机数生成
"""
VRF = (KeyGen, Prove, Verify)
1. KeyGen → (pk, sk)
2. Prove(sk, input) → (output, proof)
   output = Hash(sk, input)  ← 伪随机
   proof ← 证明 output 正确
3. Verify(pk, input, output, proof) → True/False

应用：Algorand PoS、Chainlink VRF
"""
```

### 8.3 密码学与物联网

**轻量级密码学：**

```
IoT 设备约束：
- 计算能力弱（8/16/32位 MCU）
- 内存小（KB 级 RAM）
- 功耗受限（电池供电）
- 通信带宽窄

轻量级算法：
┌────────────────┬──────────────────────────────────┐
│ 算法            │ 特点                              │
├────────────────┼──────────────────────────────────┤
│ PRESENT         │ 轻量级分组密码（64/80位密钥）     │
│ CLEFIA          │ Sony 设计的轻量分组密码           │
│ ASCON           │ NIST 轻量级密码标准（2023）       │
│ ChaCha20        │ 流密码，ARM 上极快                │
│ Ed25519         │ 轻量级签名                        │
└────────────────┴──────────────────────────────────┘

ASCON（NIST LWC 标准）：
- 认证加密：ASCON-128 / ASCON-128a
- 哈希函数：ASCON-HASH / ASCON-XOF
- 极低资源占用（约 2K 门电路）
- 适合 IoT 嵌入式设备
```

### 8.4 密码学与云计算

**密文计算与可搜索加密：**

```
可搜索对称加密（SSE）：
- 客户端加密文档后上传到云
- 客户端生成搜索令牌
- 服务器在密文上搜索，返回匹配文档
- 服务器不知道搜索内容和结果

可搜索加密分类：
┌──────────────┬──────────────────────────────────────┐
│ 类型          │ 特点                                 │
├──────────────┼──────────────────────────────────────┤
│ SSE          │ 对称加密，效率高，泄露搜索模式        │
│ IBE/ABE      │ 公钥方案，功能强，效率低              │
│ ORAM         │ 隐藏访问模式，开销大                  │
│ FHE + Search  │ 安全最强，效率极低                    │
└──────────────┴──────────────────────────────────────┘
```

**属性基加密（ABE）：**

```python
# ABE 概念
"""
属性基加密：解密能力由属性决定

CP-ABE（密文策略）：
- 密文与访问策略绑定
- 满足策略的属性集可解密
- 例：加密时指定 "(部门=研发 AND 级别≥3) OR 部门=高管"
- 只有满足条件的密钥持有者能解密

KP-ABE（密钥策略）：
- 密钥与访问策略绑定
- 满足密文属性的策略可解密

应用：
- 云存储访问控制
- 细粒度权限管理
- 医疗记录共享
"""
```

**代理重加密（Proxy Re-Encryption）：**

```
场景：Alice 想让 Bob 读取她加密存在云上的文件
- 不想让云知道文件内容
- 不想自己下载再发给 Bob

方案：代理重加密
1. Alice 生成重加密密钥 rk_A→B
2. 将 rk_A→B 发给云
3. 云用 rk_A→B 将密文从"Alice可解"转为"Bob可解"
4. 云不知道明文（只做密文转换）
5. Bob 用自己的私钥解密

应用：文件共享、邮件转发、数据委托
```
