# 同态加密

### 1.1 同态加密概念与分类

**同态加密（Homomorphic Encryption, HE）** 是一种允许在密文上直接进行计算的特殊加密方案，计算结果解密后与对明文进行相同计算的结果一致。

```
传统加密：                       同态加密：
明文 P ─加密─→ 密文 C            明文 P₁ ─加密─→ 密文 C₁
                                明文 P₂ ─加密─→ 密文 C₂
不能在密文上计算                  密文 C₃ = Eval(C₁, C₂, ⊕)
                                C₃ ─解密─→ P₁ ⊕ P₂
```

**数学定义：**
- 加密：C = Enc(m, pk)
- 同态加法：Dec(Enc(m₁) ⊕_H Enc(m₂)) = m₁ + m₂
- 同态乘法：Dec(Enc(m₁) ⊗_H Enc(m₂)) = m₁ × m₂

**分类：**

| 类型 | 支持运算 | 代表方案 |
|------|----------|----------|
| 半同态加密（HE） | 仅加法 或 仅乘法 | RSA（乘法）、Paillier（加法） |
| 些许同态加密（SHE） | 加法+有限次乘法 | BGN、BFV（有限层） |
| 全同态加密（FHE） | 加法+任意次乘法 | Gentry FHE、CKKS、TFHE |

```
同态加密发展历程：
2009  Gentry 提出第一个全同态加密方案（基于理想格）
      └─ 关键创新：自举（Bootstrapping）技术

2011  BGV 方案（级数分层，无需自举即可评估深度电路）

2012  LTV 方案、FV 方案

2013  GSW 方案（利用近似特征向量，实现无钥匙切换）

2014  CKKS 方案（支持近似计算，适合浮点运算）

2016  TFHE 方案（快速全同态，门电路级别评估）

2017  B/FV（改进）、CKKS 改进
```

### 1.2 经典同态加密算法

**RSA 同态（乘法同态）**

RSA 天然具有乘法同态性：

```
Enc(m) = m^e mod n
Enc(m₁) × Enc(m₂) = m₁^e × m₂^e = (m₁ × m₂)^e = Enc(m₁ × m₂) mod n
```

```python
from Crypto.PublicKey import RSA
from Crypto.Util.number import bytes_to_long, long_to_bytes

# RSA 乘法同态演示
key = RSA.generate(2048)
m1 = 7
m2 = 3

c1 = pow(m1, key.e, key.n)
c2 = pow(m2, key.e, key.n)

# 密文域乘法
c_product = (c1 * c2) % key.n

# 解密验证
m_product = pow(c_product, key.d, key.n)
print(f"{m1} × {m2} = {m_product}")  # 21
```

**Paillier 同态（加法同态）**

Paillier 密码系统支持密文域的加法运算和标量乘法：

```python
# Paillier 同态加密示意
# 公钥：n = p * q
# 加密：c = g^m * r^n mod n^2

# 密文加法（对应明文加法）：
# c₁ * c₂ = (g^m1 * r1^n) * (g^m2 * r2^n) = g^(m1+m2) * (r1*r2)^n = Enc(m1 + m2)

# 标量乘法（密文与明文相乘）：
# c^k = (g^m * r^n)^k = g^(km) * (r^k)^n = Enc(k * m)

# Python 实现使用 phe 库
# pip install phe
from phe import paillier

# 生成密钥
pub_key, priv_key = paillier.generate_paillier_keypair()

# 加密
m1 = 42
m2 = 17
c1 = pub_key.encrypt(m1)
c2 = pub_key.encrypt(m2)

# 同态加法
c_sum = c1 + c2
print(f"42 + 17 = {priv_key.decrypt(c_sum)}")  # 59

# 同态标量乘法
c_mul = c1 * 3
print(f"42 * 3 = {priv_key.decrypt(c_mul)}")  # 126

# 混合运算
c_expr = c1 * 2 + c2 * 3
print(f"42*2 + 17*3 = {priv_key.decrypt(c_expr)}")  # 135
```

**Gentry 全同态加密（FHE）**

Gentry 的核心创新是自举（Bootstrapping）：

```
问题：FHE 方案在每次同态运算后引入噪声
      ──────────────────────────────────────
      密文噪声 → 加法后噪声增长 → 乘法后噪声指数增长
      ──────────────────────────────────────
      噪声超过阈值后 → 解密失败

解决：自举（Bootstrapping）
      用加密的私钥来运行解密电路（在密文域）
      ──────────────────────────────────────
      1. 将私钥加密为密文
      2. 在密文域执行解密函数
      3. 得到"刷新"的新密文（噪声降低）
      ──────────────────────────────────────
      前提：方案能评估自身的解密电路
```

### 1.3 现代同态加密方案

**BFV 方案（B/FV）**
- 基于环上容错学习（RLWE）问题
- 支持整数运算
- 适合精确计算

```
BFV 参数：
- 多项式环 R = Z[x] / (x^n + 1)
- 大整数明文空间
- 支持SIMD：一个密文可打包多个值
- 典型参数：n=32768, 安全级别128位
```

**CKKS 方案**
- 支持近似计算（浮点数）
- 适合机器学习推理
- 内在精度损失可控

```python
# CKKS 方案 Python 示例（使用 Pyfhel 库）
# pip install Pyfhel
"""
from Pyfhel import Pyfhel, PyCtxt

HE = Pyfhel()
# 使用 CKKS 方案
HE.contextGen(scheme='CKKS')
HE.keyGen()

# 加密浮点向量
v1 = [1.1, 2.2, 3.3, 4.4]
v2 = [5.5, 6.6, 7.7, 8.8]

c1 = HE.encryptFrac(v1)
c2 = HE.encryptFrac(v2)

# 同态加法
c_add = c1 + c2
# 同态乘法
c_mul = c1 * c2

# 解密
result_add = HE.decryptFrac(c_add)
result_mul = HE.decryptFrac(c_mul)
print(f"加法结果: {result_add}")   # [6.6, 8.8, 11.0, 13.2]
print(f"乘法结果: {result_mul}")   # [6.05, 14.52, 25.41, 38.72]
"""
```

**TFHE 方案**
- 门电路级别评估
- 极快的自举
- 适合布尔电路

```
方案对比：
┌────────┬──────────┬──────────┬──────────┬──────────┐
│  方案   │ 运算类型  │ 精度     │ 速度     │ 适用场景  │
├────────┼──────────┼──────────┼──────────┼──────────┤
│  BFV   │ 精确整数  │ 精确     │ 中       │ 整数计算  │
│  CKKS  │ 近似浮点  │ 可控误差  │ 中       │ 机器学习  │
│  TFHE  │ 布尔运算  │ 精确     │ 快       │ 通用电路  │
│  BGV   │ 精确整数  │ 精确     │ 中慢     │ 深层电路  │
└────────┴──────────┴──────────┴──────────┴──────────┘
```

### 1.4 同态加密库使用

**Microsoft SEAL**

```python
# SEAL 库 Python 接口（seal-python / py-seal）
# pip install seal
"""
from seal import *

# 创建参数
parms = EncryptionParameters(scheme_type.BFV)
poly_modulus_degree = 4096
parms.set_poly_modulus_degree(poly_modulus_degree)
parms.set_coeff_modulus(CoeffModulus.BFVDefault(poly_modulus_degree))
parms.set_plain_modulus(PlainModulus.Batching(poly_modulus_degree, 20))

context = SEALContext(parms)

# 生成密钥
keygen = KeyGenerator(context)
public_key = keygen.public_key()
secret_key = keygen.secret_key()
relin_keys = keygen.relin_keys()  # 重线性化密钥

# 加密器
encryptor = Encryptor(context, public_key)
evaluator = Evaluator(context)
decryptor = Decryptor(context, secret_key)

# 加密
m1 = [1, 2, 3, 4]  # 打包多个值
p1 = Plaintext()
# ... 批编码
c1 = Ciphertext()
encryptor.encrypt(p1, c1)

# 同态运算
c_result = Ciphertext()
evaluator.add(c1, c2, c_result)       # 加法
evaluator.multiply(c1, c2, c_result)   # 乘法
evaluator.relinearize(c_result, relin_keys)  # 重线性化

# 解密
result = Plaintext()
decryptor.decrypt(c_result, result)
"""
```
