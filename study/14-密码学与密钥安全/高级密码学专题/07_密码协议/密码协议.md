### 7.1 密钥交换协议

**Diffie-Hellman 密钥交换**

```
公共参数：大素数 p，生成元 g

Alice                          Bob
──────                         ──────
选随机 a                       选随机 b
A = g^a mod p                  B = g^b mod p
                               ↓
      ──── 发送 A ────→
      ←─── 发送 B ────

计算共享密钥：                  计算共享密钥：
K = B^a mod p                  K = A^b mod p
  = (g^b)^a                     = (g^a)^b
  = g^(ab) mod p                = g^(ab) mod p  ✓
```

```python
from Crypto.Util.number import getPrime, GCD
import random

def dh_key_exchange():
    # 生成参数
    p = getPrime(2048)
    g = 2

    # Alice
    a = random.randrange(2, p)
    A = pow(g, a, p)

    # Bob
    b = random.randrange(2, p)
    B = pow(g, b, p)

    # 共享密钥
    K_alice = pow(B, a, p)
    K_bob = pow(A, b, p)

    assert K_alice == K_bob
    return K_alice

print(f"DH 共享密钥: {dh_key_exchange()}")
```

**DH 的变体与改进：**

| 变体 | 改进点 | 应用 |
|------|--------|------|
| ECDH | 椭圆曲线版，更短密钥 | TLS, Signal |
| ECDHE | 临时密钥（前向安全） | TLS 1.3 |
| X3DH | 异步密钥交换 | Signal |
| MQV | 隐式认证 | 标准协议 |
| HMQV | Hash MQV，可证明安全 | 理论方案 |

### 7.2 TLS 1.3 密码协议

TLS 1.3 采用了现代密码学设计理念：

```
TLS 1.3 握手流程（1-RTT）：
Client                    Server
  │                         │
  │── ClientHello ─────────→│
  │   (含密钥共享参数)       │
  │                         │── 生成共享密钥
  │                         │
  │←── ServerHello ─────────│
  │   (含密钥共享参数)       │
  │                         │
  │←── EncryptedExtensions ─│  ← 已加密
  │←── Certificate ─────────│
  │←── CertificateVerify ───│
  │←── Finished ────────────│
  │                         │
  │── Finished ────────────→│
  │                         │
  │←── Application Data ────│  ← 双向加密通信
  │── Application Data ────→│

改进点：
- 所有握手消息在握手后立即加密
- 移除 RSA 密钥交换（仅 DHE/ECDHE）
- 移除 CBC 模式（仅 AEAD）
- 移除 MD5/SHA-1（仅 SHA-256/384）
- 支持 0-RTT 恢复
```

### 7.3 Signal 协议

Signal 协议是端到端加密消息的标杆，结合了多种密码学技术：

```
Signal 协议组成：
├── X3DH（Extended Triple Diffie-Hellman）
│   └── 异步密钥协商，利用预密钥
├── Double Ratchet
│   ├── KDF Chain（密钥衍生链）
│   └── DH Ratchet（前向安全）
└── XEdDSA 签名
    └── 身份验证

安全属性：
- 前向安全（Forward Secrecy）：过去消息不可解密
- 后向安全（Post-Compromise Security）：被攻破后可恢复
- 不可否认性（可选）
```

### 7.4 安全多方计算协议选型

```
协议选型决策树：
是否需要恶意安全？
├── 是 → SPDZ / malicious Yao
└── 否 → 半诚实模型
         ├── 两方 → Yao GC
         ├── 多方少数 → GMW
         └── 多方多数 → BGW / Shamir

是否需要在线效率？
├── 高 → 预处理型（SPDZ）
└── 中 → 直接执行型

数据类型？
├── 布尔电路 → Yao/GMW
├── 算术电路 → BGW/SPDZ
└── 混合 → ABY 框架
```
