# 密钥管理概述

### 1.1 什么是密钥管理

**密钥管理（Key Management）** 是指对密钥的整个生命周期进行安全管理的过程和技术。

```
密钥生命周期：
  生成 → 分发 → 存储 → 使用 → 轮换 → 归档 → 销毁
```

**密钥管理的重要性：**
- 密码算法的安全依赖于密钥的保密
- 大多数安全事件不是因为算法被破解，而是密钥管理出了问题
- 密钥是密码系统中最敏感的资产

**格言：**
> "密码学的关键不在算法，而在密钥。"
> —— 密码学界共识

### 1.2 密钥管理的目标

| 目标 | 说明 |
|------|------|
| 保密性 | 密钥只能被授权方访问 |
| 完整性 | 密钥不能被未授权修改 |
| 可用性 | 授权方在需要时能获取密钥 |
| 可审计 | 密钥的使用可以追溯和审计 |
| 可恢复 | 密钥丢失或损坏时可以恢复 |
| 合规性 | 满足相关法规和标准要求 |

### 1.3 密钥管理原则

**原则 1：最小权限原则（Least Privilege）**
- 只给需要的人最少的密钥访问权限
- 不同系统、不同用途使用不同的密钥
- 定期审查和回收权限

**原则 2：职责分离原则（Separation of Duties）**
- 密钥管理的不同职责由不同人负责
- 例如：密钥生成、密钥审批、密钥使用由不同人操作
- 防止单人可以完成敏感操作

**原则 3：密钥分层原则（Key Hierarchy）**
- 用高级密钥保护低级密钥
- 减少顶级密钥的使用频率
- 降低密钥泄露的影响

**原则 4：定期轮换原则（Key Rotation）**
- 定期更换密钥
- 减少密钥泄露的时间窗口
- 符合合规要求

**原则 5：安全存储原则（Secure Storage）**
- 密钥不能明文存储
- 使用专用硬件或加密系统存储
- 访问控制严格

**原则 6：审计监控原则（Audit & Monitoring）**
- 记录所有密钥操作
- 监控密钥使用情况
- 异常行为及时告警

### 1.4 密钥管理标准和法规

| 标准/法规 | 发布机构 | 说明 |
|----------|---------|------|
| NIST SP 800-57 | NIST | 密钥管理指南（3部分） |
| NIST SP 800-130 | NIST | 密钥管理系统框架 |
| ISO/IEC 11770 | ISO/IEC | IT 安全技术-密钥管理 |
| PKCS #11 | RSA 实验室 | 加密设备接口标准 |
| FIPS 140-2/140-3 | NIST | 加密模块安全要求 |
| 等保 2.0 | 中国 | 网络安全等级保护 |
| 商用密码管理条例 | 中国 | 商用密码管理法规 |
| GDPR | 欧盟 | 数据保护条例（涉及加密密钥） |
| PCI DSS | PCI SSC | 支付卡行业数据安全标准 |
