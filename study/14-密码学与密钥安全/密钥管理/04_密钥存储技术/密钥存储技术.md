# 密钥存储技术

### 4.1 硬件安全模块（HSM）

**HSM（Hardware Security Module）** 是专门用于密钥管理和密码运算的硬件设备。

**HSM 的核心功能：**
- 安全生成密钥
- 安全存储密钥（密钥永不离开 HSM）
- 执行密码运算（加密、解密、签名等）
- 密钥管理（生成、轮换、销毁）
- 访问控制和审计

**HSM 的安全特性：**

| 特性 | 说明 |
|------|------|
| 物理防篡改 | 检测到物理攻击时自动销毁密钥 |
| 密钥不导出 | 私钥永不出 HSM，只在内部使用 |
| 安全认证 | FIPS 140-2/3 Level 3/4 认证 |
| 多因素认证 | 密码 + 智能卡 + 指纹等 |
| 审计日志 | 记录所有操作，不可篡改 |
| 高可用性 | 支持集群、冗余、热备 |

**HSM 的部署形式：**
- 独立设备（PCIe 卡、网络设备）
- 云服务（AWS CloudHSM、Azure Key Vault HSM）
- 智能卡、USB Key（简化版 HSM）

**HSM 的适用场景：**
- 金融机构（银行、支付）
- 政府和军队
- 大型企业的核心密钥管理
- CA 机构的根密钥保护
- 密码服务平台

**FIPS 140 安全等级：**

| 等级 | 说明 | 典型应用 |
|------|------|---------|
| Level 1 | 基本安全要求 | 普通加密软件 |
| Level 2 | 角色认证、物理防篡改证据 | 商业 HSM |
| Level 3 | 身份认证、防入侵 | 金融级 HSM |
| Level 4 | 最高级别，完全防篡改 | 军事、政府最高安全 |

### 4.2 密钥管理系统（KMS）

**KMS（Key Management Service）** 是专门用于管理密钥生命周期的系统。

**KMS 的核心功能：**
- 密钥生成
- 密钥存储（通常后端是 HSM）
- 密钥分发
- 密钥轮换
- 密钥版本管理
- 访问控制
- 审计日志
- 加密/解密 API

**云 KMS 服务：**

| 云厂商 | KMS 服务 | 特点 |
|--------|---------|------|
| AWS | AWS KMS | 集成 AWS 服务，支持 CloudHSM |
| Azure | Azure Key Vault | 密钥、证书、机密管理 |
| GCP | Cloud KMS | 集成 GCP 服务 |
| 阿里云 | 密钥管理服务 KMS | 国密支持 |
| 腾讯云 | 密钥管理系统 KMS | 国密支持 |

**KMS 的优势：**
- 集中管理密钥
- 自动化密钥轮换
- 细粒度访问控制
- 完整的审计日志
- 高可用、高可靠
- 按使用量付费

** envelope encryption（信封加密）：**
KMS 的典型使用模式：
```
1. 生成数据密钥 DEK（由 KMS 生成）
2. 用 DEK 加密数据（本地加密，速度快）
3. 用 KMS 主密钥加密 DEK（信封）
4. 存储：加密的数据 + 加密的 DEK
5. 解密时：先调用 KMS 解密 DEK，再用 DEK 解密数据
```

### 4.3 可信平台模块（TPM）

**TPM（Trusted Platform Module）** 是集成在计算机主板上的安全芯片。

**TPM 的功能：**
- 安全存储密钥（绑定到硬件）
- 平台完整性度量（Secure Boot）
- 磁盘加密密钥保护（BitLocker、LUKS）
- 硬件随机数生成
- 密码运算加速

**TPM 的特点：**
- 绑定到特定设备，密钥不能迁移
- 防物理篡改
- 成本低（集成在主板上）
- 适合设备级密钥保护

### 4.4 智能卡 / USB Key

**智能卡（Smart Card）**：
- 内含微处理器和安全芯片
- 可以存储密钥和执行密码运算
- 密钥永不离开卡片
- 需要 PIN 码认证

**USB Key / U 盾：**
- 智能卡 + USB 接口
- 常见于网银、数字证书
- 双因素认证（持有设备 + 知道 PIN）

**特点：**
- 便携
- 成本适中
- 适合用户级密钥存储
- 物理持有 = 身份认证

### 4.5 软件密钥存储

#### 操作系统密钥存储

| 系统 | 存储方式 | 说明 |
|------|---------|------|
| Windows | DPAPI、证书存储 | 基于用户密码加密 |
| macOS | Keychain | 钥匙串，支持 iCloud 同步 |
| Linux | gnome-keyring、KWallet | 桌面环境密钥管理 |

#### 应用级密钥存储

- **Java KeyStore（JKS）**：Java 的密钥库文件
- **PKCS#12**：跨平台的密钥/证书存储格式（.p12, .pfx）
- **SSH agent**：SSH 密钥代理

#### 软件存储的问题：
- 依赖操作系统的安全性
- 可能被恶意软件窃取
- 物理安全依赖设备安全
- 需要额外的保护措施（主密码等）
