# AES 算法详解

### 4.1 AES 概述

**AES（Advanced Encryption Standard）** 是美国国家标准与技术研究院（NIST）于 2001 年发布的高级加密标准，取代了 DES。

- **设计者**：比利时密码学家 Joan Daemen 和 Vincent Rijmen
- **原名**：Rijndael（发音类似 "Rhine Dahl"）
- **块大小**：128 位（16 字节）
- **密钥长度**：128 / 192 / 256 位
- **轮数**：10 / 12 / 14 轮（对应不同密钥长度）
- **结构**：SPN 网络（Substitution-Permutation Network）

**AES 选择过程：**
- 1997 年 NIST 公开征集
- 收到 15 个候选算法
- 经过 5 年的公开评估
- 2000 年选定 Rijndael 为 AES
- 2001 年正式发布为 FIPS 197

### 4.2 AES 整体结构

AES 采用 SPN（替换-置换网络）结构，不是 Feistel 结构。

```
输入 128 位明文（16 字节）
    │
    ▼
初始轮密钥加（AddRoundKey）
    │
    ▼
┌─────────────────────────────────┐
│  第 1 轮 ~ 第 N-1 轮（标准轮）  │
│  1. 字节替换（SubBytes）        │
│  2. 行移位（ShiftRows）         │
│  3. 列混合（MixColumns）        │
│  4. 轮密钥加（AddRoundKey）     │
└─────────────────────────────────┘
    │
  重复 N-1 轮（128位密钥: 9轮, 192位: 11轮, 256位: 13轮）
    │
    ▼
┌─────────────────────────────────┐
│  最后一轮（无列混合）            │
│  1. 字节替换（SubBytes）        │
│  2. 行移位（ShiftRows）         │
│  3. 轮密钥加（AddRoundKey）     │
└─────────────────────────────────┘
    │
    ▼
输出 128 位密文
```

**轮数对照表：**

| AES 版本 | 密钥长度 | 块大小 | 轮数 |
|----------|---------|--------|------|
| AES-128 | 128 位 | 128 位 | 10 |
| AES-192 | 192 位 | 128 位 | 12 |
| AES-256 | 256 位 | 128 位 | 14 |

### 4.3 状态矩阵（State）

AES 将 128 位数据表示为 4×4 的字节矩阵，称为状态（State）：

```
输入 16 字节：b₀ b₁ b₂ b₃ b₄ b₅ b₆ b₇ b₈ b₉ b₁₀ b₁₁ b₁₂ b₁₃ b₁₄ b₁₅

状态矩阵（按列填充）：
┌─────┬─────┬─────┬─────┐
│ s₀₀ │ s₀₁ │ s₀₂ │ s₀₃ │  ← 第 0 行
│ s₁₀ │ s₁₁ │ s₁₂ │ s₁₃ │  ← 第 1 行
│ s₂₀ │ s₂₁ │ s₂₂ │ s₂₃ │  ← 第 2 行
│ s₃₀ │ s₃₁ │ s₃₂ │ s₃₃ │  ← 第 3 行
└─────┴─────┴─────┴─────┘
 第0列  第1列  第2列  第3列

s₀₀ = b₀, s₁₀ = b₁, s₂₀ = b₂, s₃₀ = b₃
s₀₁ = b₄, s₁₁ = b₅, s₂₁ = b₆, s₃₁ = b₇
...
```

### 4.4 轮函数详解

#### （1）字节替换 SubBytes

SubBytes 是 AES 中唯一的非线性变换，使用 S 盒进行字节替换。

```
状态矩阵中的每个字节 s_ij
    │
    ▼
S 盒查表替换
    │
    ▼
输出新的字节 s'_ij
```

**S 盒构造方法：**

AES 的 S 盒基于有限域 GF(2^8) 上的乘法逆元构造：

1. 对输入字节 x（非零），计算其在 GF(2^8) 中的乘法逆元 x⁻¹
   - 零字节的逆元定义为零
2. 对逆元进行仿射变换：
   ```
   b'_i = b_i ⊕ b_{(i+4) mod 8} ⊕ b_{(i+5) mod 8} ⊕ b_{(i+6) mod 8} ⊕ b_{(i+7) mod 8} ⊕ c_i
   ```
   其中 c_i 是常量 0x63 的第 i 位

**S 盒表（16×16）：**

```
S 盒（十六进制）：
     00 01 02 03 04 05 06 07 08 09 0a 0b 0c 0d 0e 0f
00: 63 7c 77 7b f2 6b 6f c5 30 01 67 2b fe d7 ab 76
10: ca 82 c9 7d fa 59 47 f0 ad d4 a2 af 9c a4 72 c0
20: b7 fd 93 26 36 3f f7 cc 34 a5 e5 f1 71 d8 31 15
30: 04 c7 23 c3 18 96 05 9a 07 12 80 e2 eb 27 b2 75
40: 09 83 2c 1a 1b 6e 5a a0 52 3b d6 b3 29 e3 2f 84
50: 53 d1 00 ed 20 fc b1 5b 6a cb be 39 4a 4c 58 cf
60: d0 ef aa fb 43 4d 33 85 45 f9 02 7f 50 3c 9f a8
70: 51 a3 40 8f 92 9d 38 f5 bc b6 da 21 10 ff f3 d2
80: cd 0c 13 ec 5f 97 44 17 c4 a7 7e 3d 64 5d 19 73
90: 60 81 4f dc 22 2a 90 88 46 ee b8 14 de 5e 0b db
a0: e0 32 3a 0a 49 06 24 5c c2 d3 ac 62 91 95 e4 79
b0: e7 c8 37 6d 8d d5 4e a9 6c 56 f4 ea 65 7a ae 08
c0: ba 78 25 2e 1c a6 b4 c6 e8 dd 74 1f 4b bd 8b 8a
d0: 70 3e b5 66 48 03 f6 0e 61 35 57 b9 86 c1 1d 9e

```

**示例：**
- 输入 0x53 → 行 5，列 3 → S[5][3] = 0xed
- 输入 0x00 → 行 0，列 0 → S[0][0] = 0x63

**逆 S 盒（InvSubBytes）：**
解密时使用逆 S 盒，是 S 盒的逆变换。

#### （2）行移位 ShiftRows

行移位对状态矩阵的每一行进行循环左移，移位量不同。

```
┌─────┬─────┬─────┬─────┐
│ s₀₀ │ s₀₁ │ s₀₂ │ s₀₃ │  →  第 0 行：左移 0 字节（不变）
│ s₁₀ │ s₁₁ │ s₁₂ │ s₁₃ │  →  第 1 行：左移 1 字节
│ s₂₀ │ s₂₁ │ s₂₂ │ s₂₃ │  →  第 2 行：左移 2 字节
│ s₃₀ │ s₃₁ │ s₃₂ │ s₃₃ │  →  第 3 行：左移 3 字节
└─────┴─────┴─────┴─────┘

移位后：
┌─────┬─────┬─────┬─────┐
│ s₀₀ │ s₀₁ │ s₀₂ │ s₀₃ │  （不变）
│ s₁₁ │ s₁₂ │ s₁₃ │ s₁₀ │  （左移1）
│ s₂₂ │ s₂₃ │ s₂₀ │ s₂₁ │  （左移2）
│ s₃₃ │ s₃₀ │ s₃₁ │ s₃₂ │  （左移3）
└─────┴─────┴─────┴─────┘
```

**作用：**
- 提供扩散（Diffusion）
- 一列的字节分散到不同的列
- 与列混合配合，几轮后所有字节都相互关联

#### （3）列混合 MixColumns

列混合对状态矩阵的每一列进行线性变换，在 GF(2^8) 上进行矩阵乘法。

```
每一列乘以一个固定矩阵：

┌ s'₀ⱼ ┐   ┌ 2 3 1 1 ┐ ┌ s₀ⱼ ┐
│ s'₁ⱼ │ = │ 1 2 3 1 │ │ s₁ⱼ │
│ s'₂ⱼ │   │ 1 1 2 3 │ │ s₂ⱼ │
└ s'₃ⱼ ┘   └ 3 1 1 2 ┘ └ s₃ⱼ ┘

其中乘法是 GF(2^8) 上的乘法，加法是异或（XOR）
```

**GF(2^8) 上的乘法：**

AES 使用的不可约多项式是：
```
x⁸ + x⁴ + x³ + x + 1 （即 0x11b）
```

乘以 2（xtime 操作）：
```python
def xtime(b):
    if b & 0x80:  # 最高位为1
        return ((b << 1) ^ 0x1b) & 0xff
    else:
        return (b << 1) & 0xff
```

乘以 3：
```
3 × b = (2 × b) ⊕ b
```

**示例：**
```
列 = [0x87, 0x6e, 0x46, 0xa6]

s'₀ = (2×0x87) ⊕ (3×0x6e) ⊕ (1×0x46) ⊕ (1×0xa6)
    = 0x07  ⊕ 0xb2     ⊕ 0x46     ⊕ 0xa6
    = 0x47
```

**作用：**
- 提供扩散
- 每列的四个字节混合在一起
- 改变一个输入字节会影响四个输出字节

#### （4）轮密钥加 AddRoundKey

轮密钥加将状态矩阵与轮密钥逐字节异或。

```
s'_ij = s_ij ⊕ k_ij
```

其中 k_ij 是轮密钥矩阵的对应字节。

**作用：**
- 将密钥信息混入状态
- 没有密钥，解密不可能
- 每轮都需要不同的轮密钥（由密钥扩展生成）

### 4.5 AES 密钥扩展

密钥扩展（Key Expansion）将初始密钥扩展为多轮所需的轮密钥。

以 AES-128 为例：
- 初始密钥：128 位 = 16 字节 = 4 个 32 位字（W[0]~W[3]）
- 需要 11 轮密钥：11 × 16 字节 = 176 字节 = 44 个 32 位字（W[0]~W[43]）

**密钥扩展规则：**

```
对于 i = 4, 5, 6, ..., 43：

如果 i mod 4 ≠ 0:
    W[i] = W[i-4] ⊕ W[i-1]

如果 i mod 4 = 0:
    W[i] = W[i-4] ⊕ SubWord(RotWord(W[i-1])) ⊕ Rcon[i/4]
```

**其中：**

- **RotWord**：循环左移一个字节
  ```
  RotWord([b0, b1, b2, b3]) = [b1, b2, b3, b0]
  ```

- **SubWord**：对每个字节进行 S 盒替换
  ```
  SubWord([b0, b1, b2, b3]) = [S[b0], S[b1], S[b2], S[b3]]
  ```

- **Rcon**：轮常数（Round Constant）
  ```
  Rcon[i] = [RC[i], 0x00, 0x00, 0x00]
  
  RC[1] = 0x01
  RC[2] = 0x02
  RC[3] = 0x04
  RC[4] = 0x08
  RC[5] = 0x10
  RC[6] = 0x20
  RC[7] = 0x40
  RC[8] = 0x80
  RC[9] = 0x1b
  RC[10] = 0x36
  ```
  RC[i] 是 GF(2^8) 中 x^(i-1) 的值。

**轮密钥提取：**
```
第 0 轮密钥：W[0]  W[1]  W[2]  W[3]
第 1 轮密钥：W[4]  W[5]  W[6]  W[7]
...
第 10 轮密钥：W[40] W[41] W[42] W[43]
```

### 4.6 AES 解密

AES 解密是加密的逆过程，但不是简单的逆序（因为某些操作可交换）。

**解密轮函数：**
```
每轮：
1. 逆行移位（InvShiftRows）
2. 逆字节替换（InvSubBytes）
3. 轮密钥加（AddRoundKey）
4. 逆列混合（InvMixColumns）
```

**等效解密结构：**
可以通过数学变换将解密结构变为与加密结构相同的顺序（Equivalent Inverse Cipher），便于硬件实现。

### 4.7 AES 的安全性

**已公开的攻击：**

| 攻击方法 | 攻击版本 | 复杂度 | 说明 |
|----------|---------|--------|------|
| 暴力破解 | 所有 | 2^128 / 2^192 / 2^256 | 理论上不可行 |
| 差分密码分析 | 7 轮 AES-128 | 2^128 选择明文 | 比暴力快但仍不可行 |
| 线性密码分析 | 7 轮 | 2^128 已知明文 | 同上 |
| Square 攻击 | 6-7 轮 | 2^72 | 对完整 10 轮无效 |
| 侧信道攻击 | 实现相关 | 因实现而异 | 攻击实现而非算法 |

**AES 现状：**
- 目前 AES 仍然是安全的
- 没有针对完整 AES-128 的有效攻击
- AES-256 对于量子计算也有足够的安全性（Grover 算法只能将 2^256 降到 2^128）
- 广泛应用于 TLS、磁盘加密、无线通信等领域
