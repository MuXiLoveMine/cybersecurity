# 对称加密原理

### 1.1 基本概念

**对称加密（Symmetric Encryption）**，又称私钥加密、秘密密钥加密，是指加密和解密使用**相同密钥**的加密方式。

```
明文 P ──[密钥 K]──加密──▶ 密文 C
密文 C ──[密钥 K]──解密──▶ 明文 P
```

**数学表示：**
- 加密：C = E(K, P)
- 解密：P = D(K, C)
- 性质：D(K, E(K, P)) = P

### 1.2 核心特点

| 特点 | 说明 |
|------|------|
| 速度快 | 算法简单，适合大数据量加密 |
| 效率高 | 硬件/软件实现都很高效 |
| 密钥分发困难 | 双方需要安全通道交换密钥 |
| 密钥管理复杂 | n 个用户需要 n(n-1)/2 个密钥 |
| 不提供不可否认性 | 双方共享密钥，无法证明是谁发送的 |

### 1.3 对称加密分类

```
对称加密
├── 分组密码（Block Cipher）
│   ├── DES / 3DES
│   ├── AES
│   ├── SM4
│   └── Blowfish / Twofish
└── 流密码（Stream Cipher）
    ├── RC4
    ├── ChaCha20 / Salsa20
    └── A5/1、A5/2
```
