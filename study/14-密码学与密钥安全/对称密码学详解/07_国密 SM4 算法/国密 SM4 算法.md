# 国密 SM4 算法

### 7.1 SM4 概述

**SM4**（原名 SMS4）是中国国家密码管理局发布的分组密码标准，是中国商用密码算法之一。

- **标准号**：GM/T 0002-2012
- **发布时间**：2012 年
- **设计者**：中国密码学会
- **块大小**：128 位
- **密钥长度**：128 位
- **轮数**：32 轮
- **结构**：非平衡 Feistel 网络（32 位轮函数）

### 7.2 SM4 整体结构

SM4 采用 32 轮的非平衡 Feistel 结构（也叫广义 Feistel 结构）。

```
输入 128 位明文，分为 4 个 32 位字：X₀, X₁, X₂, X₃

对于 i = 0, 1, ..., 31：
    X_{i+4} = X_i ⊕ F(X_{i+1} ⊕ X_{i+2} ⊕ X_{i+3} ⊕ rk_i)

输出：C = (X₃₅, X₃₄, X₃₃, X₃₂)  ← 注意反序
```

**轮函数 F：**
```
F(X) = L(τ(X))

其中：
- τ 是 S 盒替换（4个并行S盒，每个S盒8位输入8位输出）
- L 是线性变换（32位 → 32位，循环移位 + 异或）
```

### 7.3 SM4 轮函数详解

#### （1）S 盒替换 τ

SM4 使用一个 8×8 的 S 盒（和 AES 的 S 盒不同）。

```
输入 32 位字 X = (x₀, x₁, x₂, x₃)，每个 8 位
输出 32 位字 Y = (Sbox[x₀], Sbox[x₁], Sbox[x₂], Sbox[x₃])
```

SM4 的 S 盒也是基于 GF(2^8) 上的逆元，使用的不可约多项式与 AES 相同（x⁸ + x⁷ + x⁶ + x⁵ + x⁴ + x² + 1），但仿射变换不同。

#### （2）线性变换 L

```
L(B) = B ⊕ (B <<< 2) ⊕ (B <<< 10) ⊕ (B <<< 18) ⊕ (B <<< 24)

其中 <<< n 表示循环左移 n 位
```

**作用：**
- 提供扩散
- 一位输入变化，经过 L 后影响多位输出

### 7.4 SM4 密钥扩展

SM4 的密钥扩展将 128 位密钥扩展为 32 个 32 位的轮密钥。

```
输入密钥：MK = (MK₀, MK₁, MK₂, MK₃)，每个 32 位

初始值：
K₀ = MK₀ ⊕ FK₀
K₁ = MK₁ ⊕ FK₁
K₂ = MK₂ ⊕ FK₂
K₃ = MK₃ ⊕ FK₃

其中 FK 是系统参数（固定常量）：
FK₀ = 0xA3B1BAC6
FK₁ = 0x56AA3350
FK₂ = 0x677D9197
FK₃ = 0xB27022DC

对于 i = 0, 1, ..., 31：
    rk_i = K_{i+4} = K_i ⊕ T'(K_{i+1} ⊕ K_{i+2} ⊕ K_{i+3} ⊕ CK_i)

其中 T' 与轮函数中的 T 类似，但线性变换 L' 不同：
L'(B) = B ⊕ (B <<< 13) ⊕ (B <<< 23)
```

**CK（常数 Key）：**
- 32 个 32 位常数
- 生成方法：CK_i,j = (4i + j) × 7 mod 256
- 用于确保每轮密钥不同

### 7.5 SM4 解密

由于 SM4 的结构特性，解密只需要将轮密钥逆序使用即可：

```
加密轮密钥：rk₀, rk₁, ..., rk₃₁
解密轮密钥：rk₃₁, rk₃₀, ..., rk₀
```

解密算法本身与加密算法相同。

### 7.6 SM4 的安全性

**已公开的分析：**

| 攻击方法 | 攻击轮数 | 复杂度 | 说明 |
|----------|---------|--------|------|
| 差分密码分析 | 22 轮 | 2^118 | 对完整 32 轮无效 |
| 线性密码分析 | 23 轮 | 2^117 | 同上 |
| 不可能差分 | 18 轮 | 2^123 | 同上 |
| 积分攻击 | 16 轮 | 2^112 | 同上 |

**结论：**
- SM4 目前是安全的
- 32 轮有足够的安全余量
- 与 AES-128 安全性相当
- 广泛应用于中国政府、金融、电信等领域

### 7.7 SM4 与 AES 对比

| 特性 | SM4 | AES-128 |
|------|-----|---------|
| 块大小 | 128 位 | 128 位 |
| 密钥长度 | 128 位 | 128/192/256 位 |
| 轮数 | 32 | 10 |
| 结构 | 非平衡 Feistel | SPN |
| S 盒 | 1 个 8×8 | 1 个 8×8 |
| 扩散层 | 线性变换 L | ShiftRows + MixColumns |
| 标准 | 中国国密 | 国际标准 |
| 应用范围 | 中国为主 | 全球 |
