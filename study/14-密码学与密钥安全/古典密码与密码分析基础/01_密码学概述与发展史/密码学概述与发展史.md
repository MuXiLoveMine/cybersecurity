# 密码学概述与发展史

### 1.1 密码学基本概念

**密码学（Cryptography）** 是研究信息加密与解密的科学，由密码编码学和密码分析学两个分支组成。

```
密码学（Cryptography）
├── 密码编码学（Cryptology）
│   └── 研究如何设计加密算法和协议
├── 密码分析学（Cryptanalysis）
│   └── 研究如何破解密码和分析弱点
└── 密码学 = 编码学 + 分析学
```

**核心术语：**

| 术语 | 英文 | 含义 |
|------|------|------|
| 明文 | Plaintext (P) | 原始的、未加密的信息 |
| 密文 | Ciphertext (C) | 加密后的、不可读的信息 |
| 密钥 | Key (K) | 控制加密解密过程的秘密参数 |
| 加密 | Encryption (E) | 将明文转换为密文的过程 |
| 解密 | Decryption (D) | 将密文恢复为明文的过程 |
| 算法 | Algorithm | 加密/解密使用的数学规则 |
| 协议 | Protocol | 使用密码学完成安全目标的交互规则 |

**数学表示：**
- 加密：C = E(K, P)
- 解密：P = D(K, C)
- 正确性：D(K, E(K, P)) = P

**密码学的四大目标：**

```
┌──────────────────────────────────────────────────┐
│              密码学安全目标                        │
├──────────┬───────────────────────────────────────┤
│ 保密性    │ 信息不被未授权者获取（加密）           │
│ 完整性    │ 信息不被篡改（MAC/签名）              │
│ 认证性    │ 验证身份和消息来源（签名/证书）        │
│ 不可否认性│ 操作方不能否认已发生的行为（数字签名） │
└──────────┴───────────────────────────────────────┘
```

### 1.2 密码学发展阶段

密码学的发展经历了四个主要阶段，每个阶段的技术特征和安全水平都有显著提升：

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  手工密码    │ →  │  机械密码    │ →  │  计算机密码  │ →  │  现代密码    │
│ (前1900-1920)│    │ (1920-1970) │    │ (1970-2000) │    │ (2000-至今) │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
  凯撒/维吉尼亚      Enigma              DES/RSA            AES/ECC/PQC
  纸笔操作           机械转子             电子计算机          量子抗性
```

**第一阶段：手工密码（古典密码）**
- 时间：远古至 20 世纪初
- 特征：通过手工或简单工具完成加密
- 代表：凯撒密码、维吉尼亚密码、栅栏密码
- 安全性：极低，可被频率分析等方法破解

**第二阶段：机械密码**
- 时间：20 世纪初至中叶
- 特征：利用机械装置实现复杂替换
- 代表：Enigma 转子机、Purple（紫色密码机）
- 安全性：较高，需要机械辅助破解（如 Turing Bombe）

**第三阶段：计算机密码（传统现代密码）**
- 时间：1970 年代至 2000 年
- 特征：基于计算机实现，有严格数学定义
- 代表：DES（1977）、RSA（1978）、AES（2001）
- 安全性：依赖密钥长度和算法设计

**第四阶段：现代密码学**
- 时间：2000 年至今
- 特征：密码学与其他技术深度融合
- 代表：全同态加密、零知识证明、后量子密码
- 安全性：可证明安全，抗量子计算

### 1.3 密码学分类

```
密码学
├── 对称密码（Symmetric）
│   ├── 分组密码：AES、DES、SM4
│   └── 流密码：ChaCha20、RC4（已淘汰）
├── 非对称密码（Asymmetric）
│   ├── RSA（大整数分解）
│   ├── ECC（椭圆曲线离散对数）
│   └── DH（密钥交换）
├── 哈希函数（Hash）
│   ├── MD5（已不安全）
│   ├── SHA-1（已不安全）
│   ├── SHA-2/SHA-3
│   └── SM3（国密）
├── 数字签名（Digital Signature）
│   ├── RSA签名
│   ├── ECDSA
│   ├── DSA
│   └── EdDSA
└── 密码协议（Protocol）
    ├── TLS/SSL
    ├── Kerberos
    └── Signal协议
```

### 1.4 密码分析学定义与攻击类型

**密码分析学（Cryptanalysis）** 是在不知道密钥的情况下，从密文恢复明文或推导密钥的科学。

**Kerckhoffs 原则**：密码系统的安全性应只依赖于密钥的保密，算法设计应当公开。这意味着攻击者知道算法的全部细节，只不知道密钥。

**五种经典攻击模型（攻击能力递增）：**

| 攻击类型 | 英文 | 攻击者拥有的信息 | 难度 |
|----------|------|------------------|------|
| 唯密文攻击 | Ciphertext-Only | 仅密文 | 最难 |
| 已知明文攻击 | Known-Plaintext | 密文 + 部分明文-密文对 | 较难 |
| 选择明文攻击 | Chosen-Plaintext | 可选择明文获取密文 | 中等 |
| 选择密文攻击 | Chosen-Ciphertext | 可选择密文获取明文 | 较易 |
| 自适应选择明文攻击 | Adaptive Chosen-Plaintext | 可根据前次结果选择新明文 | 最易 |

```
攻击能力：

唯密文 ──→ 已知明文 ──→ 选择明文 ──→ 选择密文 ──→ 自适应
  ▲                                                   ▲
  │                                                   │
 最难                                                最易
（攻击者能力最弱）                                  （攻击者能力最强）
```

**其他攻击类型：**
- **旁路攻击（Side-Channel Attack）**：通过测量加密设备的物理特征（功耗、电磁辐射、时间）推断密钥
- **代数攻击（Algebraic Attack）**：将密码表示为代数方程组并求解
- **量子攻击（Quantum Attack）**：利用量子计算机运行 Shor/Grover 算法
