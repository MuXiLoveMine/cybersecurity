# 密码分析学进阶

### 7.1 对称密码分析

现代分组密码的分析方法比古典密码分析复杂得多，主要利用密码内部结构的统计偏差。

**差分密码分析（Differential Cryptanalysis）**
- Biham 和 Shamir 于 1990 年提出
- 利用特定输入差分导致的输出差分分布偏差
- 攻击 DES 需要约 2^47 选择明文

```
原理：
输入差分 ΔP = P₁ ⊕ P₂
观察输出差分 ΔC = C₁ ⊕ C₂
某些 (ΔP, ΔC) 对的概率高于随机，利用这一偏差恢复轮密钥
```

**线性密码分析（Linear Cryptanalysis）**
- Matsui 于 1992 年提出
- 寻找输入位、密钥位和输出位之间的线性近似关系
- 攻击 DES 需要约 2^43 已知明文

```
原理：
寻找等式 P[i₁] ⊕ P[i₂] ⊕ ... ⊕ K[j₁] ⊕ ... ⊕ C[k₁] ⊕ ... = 0
使得该等式成立的概率 p 偏离 0.5 越多，攻击越有效
```

**积分密码分析（Integral Cryptanalysis）**
- 利用输入集合的性质（如所有可能值的集合）推导输出信息
- 适用于字导向密码（如 AES）

### 7.2 哈希函数分析

**生日攻击（Birthday Attack）**
- 基于生日悖论：23 人中有两人同月同日生的概率超过 50%
- 对 n 位哈希，找到碰撞只需约 2^(n/2) 次运算
- 这意味着 SHA-256 的实际安全强度为 128 位

```python
import hashlib
import os

def birthday_attack_demo(hash_func, output_bits):
    """演示生日攻击（仅用于短哈希）"""
    seen = {}
    attempts = 0
    max_attempts = 2 ** (output_bits // 2 + 2)
    while attempts < max_attempts:
        msg = os.urandom(16)
        h = hash_func(msg).digest()[:output_bits//8]
        if h in seen:
            print(f"碰撞找到！经过 {attempts} 次尝试")
            print(f"消息1: {seen[h].hex()}")
            print(f"消息2: {msg.hex()}")
            print(f"哈希: {h.hex()}")
            return
        seen[h] = msg
        attempts += 1
    print(f"未找到碰撞（{attempts} 次尝试）")

# 演示对短哈希的生日攻击
birthday_attack_demo(hashlib.md5, 24)  # 24位哈希，约需 2^12 = 4096 次
```

**原像攻击与第二原像攻击**
- 原像攻击：给定哈希值 H，找消息 M 使 hash(M) = H，难度约 2^n
- 第二原像攻击：给定消息 M₁，找 M₂ 使 hash(M₂) = hash(M₁)，难度约 2^n

### 7.3 侧信道攻击

侧信道攻击不攻击算法本身，而是利用实现中的物理泄露。

```
┌────────────────────────────────────────────────────┐
│              侧信道攻击分类                          │
├──────────┬─────────────────────────────────────────┤
│ 时间侧信道 │ 测量加密操作耗时推断密钥位               │
│ 功耗分析   │ SPA（简单功耗分析）/ DPA（差分功耗分析）  │
│ 电磁辐射   │ 测量芯片电磁辐射                         │
│ 缓存侧信道 │ 利用 CPU 缓存访问模式推断密钥             │
│ 故障注入   │ 故意制造错误导致异常输出                  │
│ 声学侧信道 │ 利用 CPU 高频噪声                       │
└──────────┴─────────────────────────────────────────┘
```

**时间侧信道示例：**

```python
# 不安全的实现（时间依赖密钥位）
def insecure_compare(secret, user_input):
    for i in range(len(secret)):
        if secret[i] != user_input[i]:
            return False  # 提前退出，泄露比较位置
    return True

# 安全的实现（恒定时间比较）
def secure_compare(secret, user_input):
    result = 0
    for i in range(len(secret)):
        result |= ord(secret[i]) ^ ord(user_input[i])
    return result == 0
```

**防御措施：**
- 恒定时间实现（Constant-time implementation）
- 掩码技术（Masking）：用随机数打乱中间值
- 隐藏技术（Hiding）：均衡功耗
- 盲化技术（Blinding）：随机化输入

### 7.4 量子计算对密码学的影响

**Shor 算法**：可在多项式时间内分解大整数和求离散对数
- 威胁 RSA、ECC、DH 等基于数论的公钥密码
- 需要足够大的量子计算机（约 4096 逻辑量子比特）

**Grover 算法**：可在 O(√N) 时间内搜索无序数据库
- 对称密码安全强度减半（AES-256 → 128 位安全）
- 哈希函数安全强度减半（SHA-256 → 128 位安全）

```
密码系统在量子计算下的安全性：
┌──────────────┬──────────────┬────────────────────┐
│ 算法          │ 经典安全强度  │ 量子安全强度        │
├──────────────┼──────────────┼────────────────────┤
│ RSA-2048     │ 2048 位      │ 被破解（Shor）      │
│ ECC-256      │ 256 位       │ 被破解（Shor）      │
│ AES-128      │ 128 位       │ 64 位（Grover）     │
│ AES-256      │ 256 位       │ 128 位（Grover）    │
│ SHA-256      │ 256 位       │ 128 位（Grover）    │
└──────────────┴──────────────┴────────────────────┘
```
