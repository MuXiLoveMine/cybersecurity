# 转子密码机

### 6.1 Enigma 密码机原理

Enigma 是二战时期纳粹德国使用的机械加密设备，其核心由三个旋转的转子（Rotor）、一个反射器（Reflector）和一个接线板（Plugboard）组成。

```
     键盘      接线板      转子1     转子2     转子3     反射器
      │          │          │          │          │          │
   按下A ──→ 置换P ──→ 置换R1 ──→ 置换R2 ──→ 置换R3 ──→ 置换U
                                                                   │
                                                              反射回去
      │          │          │          │          │          │
   灯亮  ←── 置换P⁻¹ ←── 置换R1⁻¹ ←── R2⁻¹ ←── R3⁻¹ ←────────┘
```

**各组件功能：**

| 组件 | 功能 | 增加的密钥空间 |
|------|------|----------------|
| 接线板 | 交换字母对（如 A↔B） | 约 10^15 |
| 转子（3个） | 每次按键旋转，改变映射 | 26^3 ≈ 17,576 |
| 转子选择 | 3个转子选3个并排列 | 60 |
| 反射器 | 使加密可逆（对称性） | 2 |

**总密钥空间** ≈ 10^23，在当时看似不可破解。

### 6.2 Enigma 加密流程

```
1. 操作员按下字母 A
2. 接线板将 A 转换为 B（如果 A-B 已连接）
3. 信号经过转子1：B → 可能变为 K
4. 经过转子2：K → 可能变为 M
5. 经过转子3：M → 可能变为 D
6. 反射器将 D 映射为 R
7. 反向经过转子3：R → 可能变为 N
8. 反向经过转子2：N → 可能变为 T
9. 反向经过转子1：T → 可能变为 G
10. 接线板将 G 转换为 L（如果 G-L 已连接）
11. 灯泡 L 亮起
12. 转子1转动一格，下次按键时映射关系改变
```

**关键弱点：**
- Enigma 永远不会将一个字母加密为自身（因为反射器的存在）
- 天气预报格式固定（已知明文片段）
- 接线板只交换字母，不改变频率分布

### 6.3 Turing Bombe 破解方法

Alan Turing 设计的 Bombe 机器利用已知明文攻击来破解 Enigma。

**破解原理：**
1. 利用已知明文（如天气预报中的固定用语）建立明文-密文对应
2. 排除不可能的转子配置（利用"字母不自加密"特性）
3. Bombe 机器同时测试大量配置，找到一致的设置
4. 人工验证最终结果

**历史意义：**
- Bombe 每天破解约 3000 条 Enigma 消息
- 将二战缩短约 2-4 年
- 开创了自动化密码分析的时代

### 6.4 对现代密码设计的启示

```
Enigma 的教训 → 现代密码学原则
┌──────────────────────┬───────────────────────────────┐
│ Enigma 弱点           │ 现代密码学对策                │
├──────────────────────┼───────────────────────────────┤
│ 字母不自映射          │ 加密应是伪随机映射             │
│ 依赖机械复杂度        │ 依赖数学困难问题               │
│ 格式化消息提供线索    │ 消息应随机填充                 │
│ 密钥管理不当           │ 严格的密钥管理协议             │
│ 算法保密（非Kerckhoffs）│ 算法公开，安全性仅依赖密钥     │
└──────────────────────┴───────────────────────────────┘
```
