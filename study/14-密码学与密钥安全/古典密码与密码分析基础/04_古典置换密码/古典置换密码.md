# 古典置换密码

置换密码不改变字母本身，只改变其位置。

### 4.1 栅栏密码

**原理**：将明文按行排列，按列读出密文。

```
深度（栏数）= 2
明文：WEAREDISCOVEREDFLEEATONCE

按两行排列：
W E A R E D I S C O V E R E D F L E E A T O N C E
E . A . E . I . C . E . E . E . E . A . O . C .

密文（按行读取）：WECRLTEERDSOEERFEAOC
```

```python
def rail_fence_encrypt(plaintext, rails):
    fence = [[] for _ in range(rails)]
    rail = 0
    direction = 1
    for c in plaintext:
        fence[rail].append(c)
        if rail == 0:
            direction = 1
        elif rail == rails - 1:
            direction = -1
        rail += direction
    return ''.join(''.join(r) for r in fence)

def rail_fence_decrypt(ciphertext, rails):
    # 计算每个 rail 的长度
    pattern = list(range(rails)) + list(range(rails-2, 0, -1))
    rail_lengths = [0] * rails
    for i in range(len(ciphertext)):
        rail_lengths[pattern[i % len(pattern)]] += 1
    # 分配字符到各 rail
    idx = 0
    fence = []
    for length in rail_lengths:
        fence.append(list(ciphertext[idx:idx+length]))
        idx += length
    # 按原始顺序读取
    result = []
    rail = 0
    direction = 1
    for i in range(len(ciphertext)):
        result.append(fence[rail].pop(0))
        if rail == 0:
            direction = 1
        elif rail == rails - 1:
            direction = -1
        rail += direction
    return ''.join(result)

# 示例
cipher = rail_fence_encrypt("WEAREDISCOVEREDFLEEATONCE", 2)
print(cipher)
```

**破解**：栅栏密码的栏数通常不大，暴力枚举即可。

### 4.2 列置换密码

**原理**：将明文按行填入矩阵，按密钥指定的列顺序读出密文。

```
密钥：4 3 1 2 5 6 7 （列读取顺序）
明文：attackpostponeduntiltwoam

矩阵（7列）：
列号：1 2 3 4 5 6 7
顺序：4 3 1 2 5 6 7
     A T T A C K P
     O S T P O N E
     D U N T I L T
     W O A M X Y Z

按密钥顺序读取列：
第3列(顺序1)：TTNA
第4列(顺序2)：APM
第1列(顺序3)：AODW
第2列(顺序4)：TSUO
...
密文：TTNAAPMAODWTSUO...
```

### 4.3 周期置换密码

**原理**：将明文分成长度为 m 的块，每个块内的字符按固定置换表重排。

```
置换表 π = (3, 1, 4, 2) 表示位置映射：1→3, 2→1, 3→4, 4→2

明文：HELP
块1(HELP)：H(1)E(2)L(3)P(4) → 按π重排 → E(2)P(4)H(1)L(3) → EPHE
```

**破解**：已知明文攻击或利用置换的不完整性进行统计推断。
