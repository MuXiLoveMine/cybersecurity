# 逆向工具介绍

### 2.1 JEB

#### 简介
JEB 是一款专业的 Android 逆向工程平台，支持 DEX 反编译、Smali 调试、Native 代码分析等功能。

#### 核心功能
- **DEX 反编译**：将 DEX 反编译为 Java 代码（质量较高）
- **Smali 调试**：支持动态调试 Smali 代码
- **交叉引用**：类、方法、字段的引用关系
- **重命名**：可以给混淆的类/方法/字段重命名
- **注释**：支持添加注释
- **Native 分析**：支持 SO 文件的反汇编分析
- **脚本支持**：支持 Python 脚本自动化分析

#### 使用技巧
1. **快捷键**：
   - `Tab`：在 Smali 和 Java 之间切换
   - `X`：查看交叉引用
   - `N`：重命名
   - `/`：添加注释
   - `Ctrl+F`：搜索

2. **分析流程**：
   - 导入 APK → 等待解析完成
   - 查看 AndroidManifest.xml 了解应用结构
   - 搜索关键词（如"login"、"password"、"encrypt"）
   - 定位关键类和方法
   - 结合交叉引用分析调用链

### 2.2 IDA Pro

#### 简介
IDA Pro 是业界最强大的反汇编工具，支持多种架构和文件格式，是 Native 层逆向的首选工具。

#### 核心功能
- **多架构支持**：ARM、ARM64、x86、x64 等
- **反编译（F5）**：将汇编代码转换为伪 C 代码
- **交叉引用**：函数、字符串、数据的引用关系
- **动态调试**：支持远程调试 Android Native 代码
- **脚本支持**：IDC / IDAPython
- **插件系统**：丰富的第三方插件

#### 常用快捷键
| 快捷键 | 功能 |
|--------|------|
| F5 | 反编译为伪 C 代码 |
| Space | 切换图形视图/文本视图 |
| X | 查看交叉引用 |
| N | 重命名 |
| ; | 添加注释 |
| G | 跳转到地址 |
| Ctrl+S | 查看段列表 |
| Shift+F12 | 查看字符串 |
| Alt+T | 搜索文本 |

#### ARM 汇编基础

**寄存器**：
- R0-R3：函数参数和返回值
- R4-R11：通用寄存器（需保存）
- R12 (IP)：内部过程调用寄存器
- R13 (SP)：栈指针
- R14 (LR)：链接寄存器（保存返回地址）
- R15 (PC)：程序计数器

**常见指令**：
```arm
MOV R0, R1          @ R0 = R1
ADD R0, R1, R2      @ R0 = R1 + R2
SUB R0, R1, R2      @ R0 = R1 - R2
MUL R0, R1, R2      @ R0 = R1 * R2
LDR R0, [R1]        @ R0 = 内存[R1]
STR R0, [R1]        @ 内存[R1] = R0
BL function         @ 调用函数（LR = 返回地址, PC = function）
BX LR               @ 函数返回
CMP R0, R1          @ 比较 R0 和 R1
BEQ label           @ 相等则跳转
BNE label           @ 不等则跳转
BGT label           @ 大于则跳转
BLT label           @ 小于则跳转
```

### 2.3 Frida

#### 简介
Frida 是一款动态插桩工具，可以在运行时注入代码到目标进程，实现 Hook、内存修改、函数调用等功能。

#### 核心功能
- **Java 层 Hook**：Hook Java 方法，修改参数和返回值
- **Native 层 Hook**：Hook Native 函数
- **内存操作**：读写内存、搜索内存
- **模块操作**：加载/查找 SO 模块
- **函数调用**：主动调用应用内的函数
- **脚本注入**：动态注入 JavaScript 脚本

#### 安装与使用

```bash
# 安装 Frida 工具（电脑端）
pip install frida-tools

# 手机端安装 frida-server
# 1. 下载对应架构的 frida-server
# 2. push 到手机
adb push frida-server /data/local/tmp/
adb shell chmod 755 /data/local/tmp/frida-server

# 运行 frida-server
adb shell su -c /data/local/tmp/frida-server &

# 列出运行中的进程
frida-ps -U

# 附加到进程并执行脚本
frida -U -f com.example.app -l script.js --no-pause
```
