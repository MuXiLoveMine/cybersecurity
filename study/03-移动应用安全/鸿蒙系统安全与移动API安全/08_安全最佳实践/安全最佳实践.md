# 安全最佳实践

### 8.1 鸿蒙应用安全清单

- [ ] 使用最新 API（Stage 模型，API 9+）
- [ ] 申请最小必要权限
- [ ] 敏感数据存储使用加密等级目录（el2）
- [ ] 网络通信使用 HTTPS，启用证书绑定
- [ ] 使用 TEE 密钥管理 API 存储密钥
- [ ] 正确签名应用（Debug 和 Release 分别签名）
- [ ] 代码混淆，不硬编码密钥
- [ ] 完整性校验，防篡改

### 8.2 移动 API 安全清单

- [ ] 强制 HTTPS，禁用 HTTP 回退
- [ ] 实现 OAuth 2.0 / JWT 认证
- [ ] 每个资源操作验证所有权（防 BOLA）
- [ ] 输入验证和参数白名单（防 Mass Assignment）
- [ ] 速率限制和防暴力破解
- [ ] 响应数据最小化，不返回多余字段
- [ ] 敏感字段脱敏
- [ ] 全量审计日志
- [ ] API 版本管理
- [ ] 定期安全测试（SAST/DAST）

> **学习建议**：鸿蒙安全是一个快速发展的领域，建议关注华为开发者官方文档和安全公告，结合实际设备进行逆向分析练习。移动 API 安全方面，建议深入研读 OWASP API Security Top 10，并在靶场环境中复现各种漏洞类型。
