# 移动后端安全

### 7.1 MBaaS 安全

MBaaS（Mobile Backend as a Service）为移动应用提供后端服务，常见安全风险：

| 风险 | 说明 | 防护 |
|------|------|------|
| API Key 泄露 | 客户端硬编码 API Key | 使用动态令牌，服务端校验 |
| 数据过度暴露 | API 返回过多字段 | 响应字段白名单 |
| 后台逻辑泄露 | 客户端承担服务端逻辑 | 敏感逻辑服务端实现 |
| 未授权 API 调用 | API 缺少认证 | 强制 Token 校验 |

### 7.2 云函数安全

Serverless 云函数在移动后端中广泛使用：

```javascript
// 云函数安全示例 - 微信云函数
const cloud = require('wx-server-sdk');
cloud.init();

exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext();
  
  // 安全检查1：验证调用者身份
  if (!wxContext.OPENID) {
    return { code: 401, message: '未授权访问' };
  }
  
  // 安全检查2：输入验证
  const { orderId } = event;
  if (!orderId || typeof orderId !== 'string') {
    return { code: 400, message: '参数错误' };
  }
  
  // 安全检查3：资源所有权验证
  const db = cloud.database();
  const order = await db.collection('orders').doc(orderId).get();
  
  if (order.data._openid !== wxContext.OPENID) {
    return { code: 403, message: '无权访问该订单' };
  }
  
  // 安全检查4：速率限制（使用 Redis 计数）
  // const count = await redis.incr(`rate:${wxContext.OPENID}`);
  // if (count > 100) return { code: 429, message: '请求过于频繁' };
  
  return { code: 200, data: order.data };
};
```

### 7.3 API 网关安全

API 网关是移动 API 安全的统一入口，核心安全能力：

```
移动应用 → API 网关 → 后端微服务
              │
              ├── 认证鉴权（JWT/OAuth2 验证）
              ├── 速率限制（令牌桶/滑动窗口）
              ├── 请求过滤（WAF 规则）
              ├── 响应过滤（数据脱敏）
              ├── 日志审计（全量请求记录）
              ├── API 版本管理
              └── 熔断降级
```

**API 网关安全配置示例（Kong）**：

```yaml
# Kong API 网关安全配置
services:
  - name: mobile-api
    url: http://backend-service:8080/api
    routes:
      - name: mobile-api-route
        paths: ['/api/v1']
        methods: ['GET', 'POST', 'PUT', 'DELETE']

plugins:
  # JWT 认证
  - name: jwt
    service: mobile-api
    config:
      secret_is_base64: true
      claims_to_verify: ['exp']
  
  # 速率限制
  - name: rate-limiting
    service: mobile-api
    config:
      minute: 60
      hour: 1000
      policy: redis
      redis:
        host: redis-host
        port: 6379
  
  # 请求大小限制
  - name: request-size-limiting
    service: mobile-api
    config:
      allowed_payload_size: 10  # MB
  
  # IP 黑白名单
  - name: ip-restriction
    service: mobile-api
    config:
      blacklist: ['1.2.3.4']
```
