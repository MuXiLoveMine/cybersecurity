# 跨平台工具

### 3.1 Mobile Security Framework (MobSF)

**MobSF** 是开源的移动应用安全自动化分析框架，支持静态和动态分析。

```bash
# 安装 MobSF
git clone https://github.com/MobSF/Mobile-Security-Framework-MobSF.git
cd Mobile-Security-Framework-MobSF
./setup.sh  # Linux/macOS
# 或使用 Docker
docker run -it -p 8000:8000 opensecurity/mobile-security-framework-mobsf

# 访问 Web 界面
# http://localhost:8000

# 命令行模式
# 静态分析
mobsfscan --json target.apk > report.json

# MobSF REST API 使用
# 上传 APK 进行静态分析
curl -X POST -F "file=@target.apk" \
  http://localhost:8000/api/v1/upload

# 获取分析报告
curl -X POST \
  -d "hash=<hash_from_upload>" \
  -d "scan_type=apk" \
  http://localhost:8000/api/v1/scansource
```

**MobSF 静态分析报告内容**：

| 分析项 | 说明 |
|--------|------|
| Manifest 分析 | 权限、组件暴露、调试标志 |
| 代码分析 | 硬编码密钥、不安全 API 调用 |
| 二进制分析 | SO 库安全特性（NX, PIE, RELRO） |
| Malware 分析 | 恶意行为特征检测 |
| API 分析 | URL、密钥、Token 等敏感信息 |
| 追踪器分析 | 第三方 SDK 追踪分析 |

### 3.2 Drozer — Android 组件测试

**Drozer** 是针对 Android 应用的组件级安全测试框架。

```bash
# 安装
pip install drozer

# 在设备上安装 drozer Agent
adb install drozer-agent.apk
# 启动 drozer Agent，设置端口
adb forward tcp:31415 tcp:31415

# 连接到设备
drozer console connect

# 常用命令
# === 信息收集 ===
dz> run app.package.info -a com.example.app      # 应用信息
dz> run app.package.manifest com.example.app     # Manifest 内容
dz> run scanner.provider.finduris -a com.example.app  # 查找内容提供者

# === Activity 测试 ===
dz> run app.activity.info -a com.example.app     # 列出 Activity
dz> run app.activity.start --component com.example.app .MainActivity  # 启动 Activity
dz> run scanner.activity.browsable -a com.example.app  # 测试深链接

# === Service 测试 ===
dz> run app.service.info -a com.example.app      # 列出 Service
dz> run app.service.start --component com.example.app .MyService  # 启动 Service

# === ContentProvider 测试 ===
dz> run app.provider.info -a com.example.app     # 列出 Provider
dz> run app.provider.query content://com.example.app/users  # 查询数据
dz> run scanner.provider.injection -a com.example.app  # SQL 注入测试
dz> run scanner.provider.traversal -a com.example.app  # 路径遍历测试

# === Broadcast 测试 ===
dz> run app.broadcast.info -a com.example.app    # 列出 Receiver
dz> run app.broadcast.send --component com.example.app .MyReceiver  # 发送广播

# === 自动化扫描 ===
dz> run scanner.misc.writable_files --package com.example.app  # 可写文件
dz> run scanner.misc.native --package com.example.app          # Native 库检查
dz> run scanner.misc.readable_files --package com.example.app  # 可读文件
```
