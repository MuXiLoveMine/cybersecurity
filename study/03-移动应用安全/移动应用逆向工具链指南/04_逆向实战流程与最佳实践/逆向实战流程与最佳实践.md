# 逆向实战流程与最佳实践

### 4.1 Android 逆向标准流程

```
┌──────────────────────────────────────────────────┐
│                Android 逆向分析流程                │
├──────────────────────────────────────────────────┤
│                                                  │
│  1. 信息收集                                      │
│     ├── APK 获取（应用市场/APKPure/分享APK）      │
│     ├── 基础信息（包名、版本、权限）               │
│     └── 网络行为分析                              │
│                                                  │
│  2. 静态分析                                      │
│     ├── jadx 反编译 -> 阅读代码                   │
│     ├── apktool 解包 -> 分析资源/Manifest          │
│     ├── MobSF 自动扫描 -> 漏洞概览                 │
│     ├── 搜索敏感信息（密钥/URL/Token）             │
│     └── 识别加密/加固方案                         │
│                                                  │
│  3. 脱壳（如有加固）                              │
│     ├── FRIDA-DEXDump 内存 dump                   │
│     ├── BlackDex 脱壳                             │
│     └── 重新反编译脱壳后的 DEX                    │
│                                                  │
│  4. 动态分析                                      │
│     ├── Frida Hook 加密函数                       │
│     ├── objection 自动化测试                      │
│     ├── Burp Suite 抓包分析 API                   │
│     ├── Drozer 组件测试                           │
│     └── Native 层分析（IDA/Ghidra + Frida）       │
│                                                  │
│  5. 漏洞验证                                      │
│     ├── 越权/绕过验证                             │
│     ├── 信息泄露验证                               │
│     ├── 注入测试                                  │
│     └── 深链接劫持测试                            │
│                                                  │
│  6. 报告编写                                      │
│     ├── 漏洞描述与影响                            │
│     ├── 复现步骤                                  │
│     └── 修复建议                                  │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 4.2 iOS 逆向标准流程

```
┌──────────────────────────────────────────────────┐
│                 iOS 逆向分析流程                   │
├──────────────────────────────────────────────────┤
│                                                  │
│  1. 应用获取与准备                                 │
│     ├── App Store 下载 IPA                        │

│                                                  │
│  2. 砸壳                                          │
│     ├── frida-ios-dump                           │
│     ├── Clutch                                    │
│     └── 验证砸壳结果（otool 检查加密标志）         │
│                                                  │
│  3. 静态分析                                      │
│     ├── class-dump 导出头文件                     │
│     ├── Hopper/IDA 分析关键方法                    │
│     ├── 搜索字符串（URL/密钥/Token）               │
│     └── 分析 plist 配置文件                       │
│                                                  │
│  4. 动态分析                                      │
│     ├── Frida Hook ObjC/Swift 方法                │
│     ├── 网络请求拦截（Hook NSURLSession）         │
│     ├── SSL Pinning 绕过                         │
│     ├── Keychain 数据提取                         │
│     └── 调试器附加（LLDB）                        │
│                                                  │
│  5. 漏洞验证                                      │
│     ├── 越权测试                                  │
│     ├── 本地数据泄露检查                          │
│     ├── URL Scheme 劫持                          │
│     └── 剪贴板数据泄露                            │
│                                                  │
│  6. 报告编写                                      │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 4.4 法律与道德注意事项

- 逆向分析仅限于安全研究目的，不得用于非法用途
- 对商业应用进行逆向前需确认相关法律法规和用户协议
- 测试应使用自己的应用或获得授权的目标
- 发现漏洞应遵循负责任披露原则
- 不得分发脱壳/破解后的应用
