### 10.2 接口安全加固

```python
# 接口安全加固实施指南

"""
1. 鉴权机制
   - 使用 JWT + 短期 Refresh Token 机制
   - Token 有效期不超过 2 小时
   - Refresh Token 有效期不超过 7 天
   - Token 包含用户身份和权限信息

2. 接口权限控制
   - 实现基于角色的访问控制（RBAC）
   - 每个接口明确所需权限
   - 服务端校验当前用户是否有权访问目标资源
   - 越权检查：不仅校验用户身份，还校验资源归属

3. 参数安全
   - 服务端不信任任何客户端参数
   - 价格/金额等敏感参数由服务端查询
   - 所有参数进行类型和范围校验
   - 使用参数化查询防止 SQL 注入

4. 防重放
   - 每个请求携带 nonce（随机数）+ timestamp
   - 服务端记录已使用的 nonce（5分钟有效期）
   - timestamp 与服务端时间差超过 5 分钟拒绝

5. 限流
   - 单 IP 每分钟请求不超过 60 次
   - 单用户每分钟请求不超过 100 次
   - 敏感接口（登录/支付）每分钟不超过 5 次
"""
```

### 10.3 通信安全加固

```
通信安全加固：
├── 传输加密
│   ├── 强制 HTTPS（TLS 1.2+）
│   ├── 启用 HSTS（Strict-Transport-Security）
│   ├── 使用前向加密（ECDHE 密钥交换）
│   └── 禁用弱密码套件
├── SSL Pinning（服务端配置）
│   ├── 客户端实现证书固定
│   ├── 使用公钥固定（SPKI）而非证书固定
│   └── 备用固定密钥以应对证书更新
├── 通信加密
│   ├── 敏感数据使用端到端加密
│   ├── 加密密钥由服务端动态下发
│   ├── 使用 AES-GCM 认证加密模式
│   └── 每次通信使用随机 IV
└── 完整性校验
    ├── 使用 HMAC 或 AEAD 认证
    ├── 签名覆盖所有关键参数
    └── 服务端验证签名后才处理请求
```

### 10.4 H5 安全加固

```html
<!-- H5 安全加固配置示例 -->

<!-- 1. CSP（内容安全策略） -->
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self';
               script-src 'self' 'nonce-{random}';
               style-src 'self' 'unsafe-inline';
               img-src 'self' data: https:;
               connect-src 'self' https://api.target.com;
               frame-ancestors 'self';
               report-uri /csp-report">

<!-- 2. X-Frame-Options -->
<meta http-equiv="X-Frame-Options" content="SAMEORIGIN">

<!-- 3. X-Content-Type-Options -->
<meta http-equiv="X-Content-Type-Options" content="nosniff">

<!-- 4. Referrer-Policy -->
<meta name="referrer" content="strict-origin-when-cross-origin">
```

// WebView 安全配置（Android）

WebSettings settings = webView.getSettings();

// 1. 禁用不必要的功能
settings.setJavaScriptEnabled(true);  // 按需开启
settings.setAllowFileAccess(false);    // 禁止文件访问
settings.setAllowFileAccessFromFileURLs(false);
settings.setAllowUniversalAccessFromFileURLs(false);
settings.setSavePassword(false);      // 禁止保存密码

// 2. 安全的 JS Bridge
// - 域名白名单验证
// - 方法权限分级
// - 参数严格校验

// 3. WebView 内容验证
webView.setWebViewClient(new WebViewClient() {
    @Override
    public boolean shouldOverrideUrlLoading(WebView view, WebResourceRequest request) {
        String url = request.getUrl().toString();
        // URL 白名单验证
        if (!isAllowedUrl(url)) {
            return true; // 拦截非白名单 URL
        }
        return false;
    }

    @Override
    public void onReceivedSslError(WebView view, SslErrorHandler handler, SslError error) {
        // 不忽略 SSL 错误
        handler.cancel();
    }
});
