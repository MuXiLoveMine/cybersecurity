# 小程序通信安全

### 5.1 HTTPS 抓包

小程序默认强制 HTTPS，但通过配置代理仍可进行中间人抓包分析。

**Burp Suite 抓包配置**：

```
1. 配置 Burp Suite 代理
   Proxy → Options → Add
   Proxy Host: 0.0.0.0
   Proxy Port: 8080

2. 安装 CA 证书到设备
   # Android 7+ 需将证书安装到系统级证书存储
   # 方法1：使用 Magisk 模块（MagiskTrustUserCerts）
   # 方法2：手动安装到系统证书目录

   # 导出 Burp 证书
   # 访问 http://burp 并下载 cacert.der

   # 转换为系统证书格式
   openssl x509 -inform DER -in cacert.der -out cacert.pem
   HASH=$(openssl x509 -inform PEM -subject_hash_old -in cacert.pem | head -1)
   cp cacert.pem /system/etc/security/cacerts/${HASH}.0
   chmod 644 /system/etc/security/cacerts/${HASH}.0

3. 配置设备代理
   设置 → WiFi → 长按网络 → 修改 → 高级 → 代理 → 手动
   主机: <电脑IP>
   端口: 8080

4. 在微信中打开小程序，Burp Suite 即可捕获请求
```

**mitmproxy 抓包（适合自动化场景）**：

```bash
# 安装
pip install mitmproxy

# 启动代理
mitmproxy -p 8080

# 或使用 mitmweb（Web 界面）
mitmweb -p 8080

# 编写插件自动分析小程序请求
# mini_app_analyzer.py
from mitmproxy import http
import json

class MiniAppAnalyzer:
    def __init__(self):
        self.api_endpoints = set()
        self.sensitive_data = []

    def request(self, flow: http.HTTPFlow):
        # 记录所有 API 端点
        self.api_endpoints.add(flow.request.url)

        # 检查请求中的敏感参数
        for key, value in flow.request.query.items():
            if any(k in key.lower() for k in ['token', 'secret', 'key', 'password']):
                self.sensitive_data.append({
                    'url': flow.request.url,
                    'param': key,
                    'value': value
                })

    def response(self, flow: http.HTTPFlow):
        # 检查响应中的敏感数据
        try:
            body = json.loads(flow.response.text)
            for key in body:
                if any(k in key.lower() for k in ['phone', 'idcard', 'password']):
                    self.sensitive_data.append({
                        'url': flow.request.url,
                        'field': key,
                        'value': str(body[key])[:50]
                    })
        except:
            pass

addons = [MiniAppAnalyzer()]
```

### 5.2 SSL Pinning 绕过

部分小程序或其宿主 App 实现了 SSL Certificate Pinning（证书固定），导致常规代理抓包失败。以下是绕过方法：

**方法一：Frida 脚本绕过（推荐）**

```bash
# 使用 frida-code-share 中现成的 SSL Pinning Bypass 脚本
# 适用于大多数 Android App

frida -U -f com.tencent.mm -l ssl_pinning_bypass.js --no-pause

# ssl_pinning_bypass.js 核心逻辑：
"""
// 绕过 OkHttp CertificatePinning
Java.perform(function() {
    var CertificatePinning = Java.use('okhttp3.CertificatePinner');
    CertificatePinning.check.overload('java.lang.String', 'java.util.List').implementation = function(hostname, peerCertificates) {
        console.log('[SSL Pinning Bypass] OkHttp: ' + hostname);
        // 不执行任何检查，直接返回
    };
});

// 绕过 TrustManager
Java.perform(function() {
    var X509TrustManager = Java.use('javax.net.ssl.X509TrustManager');
    var SSLContext = Java.use('javax.net.ssl.SSLContext');

    var TrustManager = Java.registerClass({
        name: 'com.bypass.TrustManager',
        implements: [X509TrustManager],
        methods: {
            checkClientTrusted: function(chain, authType) {},
            checkServerTrusted: function(chain, authType) {},
            getAcceptedIssuers: function() {
                return [];
            }
        }
    });

    var TrustManagers = [TrustManager.$new()];
    var sslContext = SSLContext.getInstance('TLS');
    sslContext.init(null, TrustManagers, null);
    SSLContext.setDefault(sslContext);
});

// 绕过 WebView CertificatePinning
Java.perform(function() {
    var WebView = Java.use('android.webkit.WebView');
    var WebViewClient = Java.use('android.webkit.WebViewClient');

    WebViewClient.onReceivedSslError.implementation = function(view, handler, error) {
        handler.proceed(); // 忽略 SSL 错误
    };
});
"""
```


### 5.3 中间人攻击测试

```bash
# 使用 mitmproxy 进行中间人攻击测试
# 场景：篡改小程序 API 响应，测试前端行为

# 脚本：篡改用户信息接口响应
# mitm_intercept.py
from mitmproxy import http
import json

def response(flow: http.HTTPFlow):
    # 拦截用户信息接口
    if '/v1/user/profile' in flow.request.url:
        # 修改响应中的用户信息
        body = json.loads(flow.response.text)
        body['data']['isVip'] = True         # 篡改 VIP 状态
        body['data']['balance'] = 999999     # 篡改余额
        body['data']['role'] = 'admin'       # 篡改角色
        flow.response.text = json.dumps(body)
        print(f'[MITM] Tampered response for {flow.request.url}')

# 启动
mitmproxy -p 8080 -s mitm_intercept.py

# 测试目的：
# 1. 前端是否信任篡改后的响应进行特权操作
# 2. 前端是否对关键数据做二次验证
# 3. 是否存在前端校验绕过（如支付金额前端校验）
```

### 5.4 通信加密分析

```javascript
// 某小程序的加密通信实现（反编译后）
const CryptoJS = require('crypto-js');

// 请求加密
function encryptRequest(data) {
    const key = CryptoJS.enc.Utf8.parse('1234567890abcdef'); // 硬编码 AES 密钥
    const iv = CryptoJS.enc.Utf8.parse('abcdef1234567890');  // 固定 IV
    const encrypted = CryptoJS.AES.encrypt(
        JSON.stringify(data),
        key,
        { iv: iv, mode: CryptoJS.mode.CBC, padding: CryptoJS.pad.Pkcs7 }
    );
    return encrypted.toString();
}

// 响应解密
function decryptResponse(encrypted) {
    const key = CryptoJS.enc.Utf8.parse('1234567890abcdef');
    const iv = CryptoJS.enc.Utf8.parse('abcdef1234567890');
    const decrypted = CryptoJS.AES.decrypt(
        encrypted,
        key,
        { iv: iv, mode: CryptoJS.mode.CBC, padding: CryptoJS.pad.Pkcs7 }
    );
    return JSON.parse(decrypted.toString(CryptoJS.enc.Utf8));
}

// 安全问题：
// 1. AES 密钥硬编码在前端（反编译即可获取）
// 2. IV 固定不变（相同明文产生相同密文，可进行已知明文攻击）
// 3. 无消息认证（无 HMAC/GCM），可被篡改
// 4. 密钥可从反编译源码中直接提取
```

**密钥提取后解密通信数据**：

```python
#!/usr/bin/env python3
"""小程序加密通信解密工具"""
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad
import base64
import json

class MiniAppCryptoDecryptor:
    def __init__(self, key, iv):
        self.key = key.encode('utf-8') if isinstance(key, str) else key
        self.iv = iv.encode('utf-8') if isinstance(iv, str) else iv

    def decrypt(self, encrypted_data):
        """解密 AES-CBC 加密数据"""
        try:
            cipher = AES.new(self.key, AES.MODE_CBC, self.iv)
            encrypted_bytes = base64.b64decode(encrypted_data)
            decrypted = unpad(cipher.decrypt(encrypted_bytes), AES.block_size)
            return json.loads(decrypted.decode('utf-8'))
        except Exception as e:
            print(f"解密失败: {e}")
            return None

    def encrypt(self, data):
        """加密数据（用于构造测试请求）"""
        cipher = AES.new(self.key, AES.MODE_CBC, self.iv)
        from Crypto.Util.Padding import pad
        plaintext = json.dumps(data).encode('utf-8')
        encrypted = cipher.encrypt(pad(plaintext, AES.block_size))
        return base64.b64encode(encrypted).decode('utf-8')

# 使用示例
decryptor = MiniAppCryptoDecryptor('1234567890abcdef', 'abcdef1234567890')
# 从抓包获取的加密请求体
encrypted_request = 'U2FsdGVkX1+...'
decrypted = decryptor.decrypt(encrypted_request)
print(json.dumps(decrypted, indent=2, ensure_ascii=False))
```
