# 附录：关键工具速查表

| 工具 | 安装命令 | 核心用途 |
|------|---------|---------|
| wxappUnpacker | `git clone https://github.com/xuedingmiaojun/wxappUnpacker` | 微信小程序反编译 |
| unveilr | `npm install -g unveilr` | 多平台小程序反编译 |
| Burp Suite | 官网下载 | HTTP/HTTPS 抓包与测试 |
| mitmproxy | `pip install mitmproxy` | 程序化抓包与自动化 |
| Frida | `pip install frida-tools` | 运行时 Hook 与分析 |
| objection | `pip install objection` | 移动安全测试框架 |
| jadx | 官网下载 | APK 反编译 |
| ffuf | 下载二进制 | API 接口模糊测试 |
| sqlmap | `pip install sqlmap` | SQL 注入自动化 |
| MobSF | `docker pull opensecurity/mobile-security-framework-mobsf` | 移动应用安全框架 |
