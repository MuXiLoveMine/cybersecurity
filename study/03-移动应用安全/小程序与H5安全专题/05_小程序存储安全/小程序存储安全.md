# 小程序存储安全

### 4.1 本地存储机制

小程序提供多种本地存储方式，每种方式都存在潜在的安全风险。

**wx.setStorageSync / wx.getStorageSync**

```javascript
// 小程序本地存储（类似 localStorage）
// 存储位置：/data/data/com.tencent.mm/MicroMsg/<hash>/<AppID>/

// 常见危险存储示例
wx.setStorageSync('userInfo', {
    phone: '13800138000',      // 手机号明文存储
    idCard: '110101199001011234', // 身份证明文存储
    token: 'eyJhbGciOiJIUzI1NiIs...', // JWT Token 明文
    password: 'admin123'       // 密码明文存储！
});

// 安全风险：
// 1. 数据以明文 JSON 存储在 SQLite 数据库中
// 2. Root 设备可直接读取
// 3. 备份导出可获取
// 4. 微信小程序存储未加密
```

**文件存储（wx.getFileSystemManager）**

```javascript
// 文件系统管理器
const fs = wx.getFileSystemManager();

// 存储到本地文件
fs.writeFileSync(
    `${wx.env.USER_DATA_PATH}/config.txt`,
    JSON.stringify({ secret: 'api_key_here' }),
    'utf8'
);

// 安全风险：
// 1. 文件以明文存储在 USER_DATA_PATH 下
// 2. Root 设备可直接读取文件
// 3. 与其他存储方式相比，文件存储通常无额外加密
```

**数据提取与分析**：

```python
#!/usr/bin/env python3
"""小程序本地存储数据提取脚本"""

import sqlite3
import json
import os

class MiniProgramStorageExtractor:
    def __init__(self, db_path):
        self.db_path = db_path

    def extract_all(self):
        """提取所有存储数据"""
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()

        # 获取所有表名
        cursor.execute("SELECT name FROM sqlite_master WHERE type='table'")
        tables = cursor.fetchall()

        results = {}
        for table in tables:
            table_name = table[0]
            cursor.execute(f"SELECT * FROM {table_name}")
            rows = cursor.fetchall()

            # 获取列名
            columns = [desc[0] for desc in cursor.description]

            results[table_name] = []
            for row in rows:
                row_data = dict(zip(columns, row))
                results[table_name].append(row_data)

                # 尝试解析 JSON 数据
                for col in columns:
                    val = row_data.get(col, '')
                    if isinstance(val, str) and (val.startswith('{') or val.startswith('[')):
                        try:
                            row_data[col] = json.loads(val)
                        except:
                            pass

        conn.close()
        return results

    def find_sensitive_data(self, data):
        """查找敏感数据"""
        sensitive_patterns = [
            'token', 'secret', 'key', 'password', 'passwd',
            'phone', 'mobile', 'idcard', 'id_card',
            'session', 'cookie', 'auth'
        ]

        findings = []
        for table, rows in data.items():
            for row in rows:
                for key, value in row.items():
                    if any(pattern in str(key).lower() for pattern in sensitive_patterns):
                        findings.append({
                            'table': table,
                            'field': key,
                            'value_preview': str(value)[:100]
                        })

        return findings
```

### 4.3 敏感信息泄露场景

```javascript
// 场景1：日志输出敏感信息
console.log('用户Token:', token);  // 在 Release 版仍可能输出到 logcat
console.log('支付参数:', payParams);

// 场景2：调试信息未清理
if (debugMode) {
    console.log('Debug Info:', JSON.stringify(config));
    // 反编译后可直接看到完整配置
}

// 场景3：注释中的敏感信息
// const APP_SECRET = 'xxx';  // 注释中仍有泄露
// 测试环境: http://test.target.com (注释但仍在源码中)
// 数据库: 192.168.1.100:3306 (内网信息)

// 场景4：图片/文件中嵌入敏感信息
// 证件照直接存储在 CDN/OSS 上，URL 可预测

    url: `https://cdn.target.com/idcards/${userId}.jpg`
    // 无鉴权即可访问他人证件照
```

### 4.4 存储安全检测

```bash
# 使用 Frida Hook 监控小程序存储操作
# 以下脚本 Hook wx.setStorageSync 并打印存储的数据

frida -U -f com.tencent.mm -l hook_storage.js --no-pause

# hook_storage.js
"""
Java.perform(function() {
    // Hook WebView 的 localStorage
    var WebView = Java.use('android.webkit.WebView');
    WebView.evaluateJavascript.overload('java.lang.String', 'android.webkit.ValueCallback').implementation = function(script, callback) {
        if (script.indexOf('localStorage') !== -1 || script.indexOf('setStorage') !== -1) {
            console.log('[Storage] ' + script);
        }
        return this.evaluateJavascript(script, callback);
    };

    // Hook SQLite 数据库
    var SQLite = Java.use('android.database.sqlite.SQLiteDatabase');
    SQLite.execSQL.overload('java.lang.String', 'java.lang.Object[]').implementation = function(sql, args) {
        if (sql.indexOf('INSERT') !== -1 || sql.indexOf('storage') !== -1) {
            console.log('[SQLite] SQL: ' + sql);
            console.log('[SQLite] Args: ' + JSON.stringify(args));
        }
        return this.execSQL(sql, args);
    };
});
"""
```
