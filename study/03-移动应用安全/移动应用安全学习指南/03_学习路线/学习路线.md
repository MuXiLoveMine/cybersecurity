# 学习路线

### 阶段 1：移动开发基础（1-2 个月）
**学习目标**：掌握 Android 开发基础，理解应用工作原理

**学习内容**
- Java 基础
- Kotlin 基础
- Android 开发基础
- 四大组件
- 布局与控件
- 数据存储
- 网络编程
- Android Studio 使用

**实践任务**
- 开发简单的 Android 应用
- 熟悉 Android Studio
- 理解 Android 应用结构
- 学习使用 adb 命令

### 阶段 2：移动安全基础（2-3 个月）
**学习目标**：掌握移动安全基础知识，了解常见漏洞

**学习内容**
- Android 安全机制
- 常见移动安全漏洞
- OWASP Mobile Top 10
- 移动渗透测试基础
- 静态分析基础
- 动态分析基础

**实践任务**
- 反编译简单 APK
- 分析 AndroidManifest.xml
- 使用 MobSF 扫描应用
- 打移动安全靶场
- 学习使用 Drozer

### 阶段 3：逆向分析（3-4 个月）
**学习目标**：掌握 Android 逆向分析技术

**学习内容**
- Smali 语法
- 静态分析（Apktool、JADX、JEB、IDA）
- 动态调试
- Frida Hook
- Xposed 框架
- 脱壳技术
- Native 逆向基础

**实践任务**
- 反编译各种 APK
- 分析简单的应用
- 编写 Frida 脚本
- 使用 Xposed 模块
- 练习脱壳
- 打逆向 CTF 题目

### 阶段 4：渗透测试与漏洞挖掘（2-3 个月）
**学习目标**：掌握移动应用渗透测试和漏洞挖掘

**学习内容**
- 移动渗透测试方法论
- 信息收集
- 静态测试
- 动态测试
- 业务逻辑测试
- 漏洞挖掘技巧
- 报告编写

**实践任务**
- 完成完整的移动应用渗透测试
- 挖掘通用漏洞
- 挖掘业务逻辑漏洞
- 写渗透测试报告
- 参与 CTF 移动方向

### 阶段 5：深入研究（持续）
**研究方向**
- 高级逆向
- VMP 还原
- 内核漏洞
- 系统安全
- 恶意代码分析
- 安全防护
- 安全研究
