# 常见面试题

### 基础概念
1. **Android 的安全机制有哪些？**
   - 沙箱机制：每个应用有独立的 UID，运行在独立的进程中
   - 权限机制：应用需要申请权限才能访问敏感功能
   - 签名机制：APK 必须签名才能安装
   - SELinux：强制访问控制
   - 地址空间随机化（ASLR）
   - 数据加密

2. **APK 的文件结构？**
   - AndroidManifest.xml：清单文件
   - classes.dex：Dalvik 字节码
   - resources.arsc：资源索引表
   - res/：资源文件
   - lib/：原生库
   - assets/：资产文件
   - META-INF/：签名信息

3. **四大组件是什么？有什么安全风险？**
   - Activity：界面组件，导出可能导致越权访问
   - Service：服务组件，导出可能导致越权调用
   - BroadcastReceiver：广播接收器，导出可能导致广播劫持
   - ContentProvider：内容提供者，导出可能导致数据泄露

4. **Frida 的原理是什么？**
   - Frida 是一个动态插桩工具
   - 原理是向目标进程注入 JS 引擎
   - 通过 JS 脚本可以 Hook 函数、修改内存、调用函数等
   - 支持 Android、iOS、Windows、Linux、macOS

### 漏洞原理
5. **常见的 Android 漏洞有哪些？**
   - 组件导出漏洞
   - 数据存储不安全
   - 通信不安全（HTTP 明文、证书验证问题）
   - 硬编码敏感信息
   - 权限提升
   - WebView 漏洞
   - Intent 注入
   - PendingIntent 误用

6. **Android 加固的方式有哪些？**
   - 代码混淆
   - 整体加固
   - VMP 虚拟化保护
   - 字符串加密
   - 资源加密
   - 防调试
   - 防 Hook
   - 签名校验
   - 完整性校验

7. **脱壳的方法有哪些？**
   - 内存 dump
   - 动态调试脱壳
   - Frida 脱壳
   - Xposed 脱壳
   - 系统级脱壳（FART、Youpk）
   - 定制 ROM 脱壳

8. **Hook 的方式有哪些？**
   - Java 层 Hook：Frida、Xposed、Substrate
   - Native 层 Hook：PLT Hook、Inline Hook
   - 常用框架：Frida、Xposed、Substrate、xHook、Dobby

### 实战相关
9. **如何进行移动应用渗透测试？**
   - 信息收集：应用信息、权限、组件、SDK
   - 静态分析：反编译、代码审计、资源分析
   - 动态分析：抓包、调试、Hook
   - 漏洞验证：验证发现的漏洞
   - 报告编写：整理漏洞和修复建议

10. **OWASP Mobile Top 10 有哪些？**
    - M1: 不当的平台使用
    - M2: 不安全的数据存储
    - M3: 不安全的通信
    - M4: 不安全的身份验证
    - M5: 不足的加密
    - M6: 不安全的授权
    - M7: 客户端代码质量
    - M8: 代码篡改
    - M9: 逆向工程
    - M10: 无关的功能
