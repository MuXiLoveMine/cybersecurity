# 沙箱分析环境搭建

### 5.1 Cuckoo 沙箱

Cuckoo Sandbox 是开源的自动化恶意软件分析系统，支持 Android APK 分析。

```bash
# Cuckoo 沙箱搭建（基于 Docker）

# 1. 克隆 Cuckoo
git clone https://github.com/cuckoosandbox/cuckoo.git
cd cuckoo

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 Android 分析模块
# 修改 cuckoo.conf
# [android]
# enabled = yes
# emulator = genymotion
# emulator_path = /opt/genymotion

# 4. 配置 Android 模拟器
# 安装 Genymotion
# 创建 Android 7.0+ 模拟器
# 安装 Cuckoo Agent APK
adb install agent.apk

# 5. 配置网络分析
# 使用 tcpdump 捕获网络流量
# 配置 inetsim 模拟网络服务

# 6. 启动分析
cuckoo --submit /path/to/malicious.apk

# 分析结果包含：
# - APK 信息（包名、权限、组件）
# - 静态分析结果（字符串、API 调用）
# - 动态行为日志（系统调用、网络通信）
# - 网络流量 PCAP
# - 截图和屏幕录像
# - 行为分析报告
```

### 5.2 MobSF 动态分析

```bash
# MobSF（Mobile Security Framework）部署
# 支持静态和动态分析的综合性工具

# Docker 部署
docker run -it --rm \
  -p 8000:8000 \
  -p 8001:8001 \
  -v /path/to/samples:/root/MobSF/uploads \
  -v /path/to/output:/root/MobSF/output \
  opensecurity/mobile-security-framework-mobsf

# 动态分析环境配置
# 1. 配置 Android 模拟器
# 在 MobSF Web 界面设置 -> Dynamic Analyzer
# 选择模拟器 ID

# 2. 上传 APK 进行分析
curl -X POST http://localhost:8000/api/v1/upload \
  -F "file=@malicious.apk"

# 3. 启动动态分析
curl -X POST http://localhost:8000/api/v1/dynamic_analyze \
  -F "hash=<apk_hash>" \
  -F "avd_name=<emulator_id>"

# 4. 获取分析报告
curl http://localhost:8000/api/v1/dynamic_report_json?hash=<apk_hash>

# MobSF 动态分析功能：
# - 自动安装和启动 APK
# - Frida 脚本注入
# - 网络流量捕获
# - API 调用追踪
# - DOM 解析（WebView）
# - 截图记录
# - 行为分析报告
```

### 5.3 网络模拟环境

```bash
# 使用 inetsim 模拟网络服务
# 使恶意代码在隔离环境中运行，分析其网络行为

# 安装 inetsim
apt-get install inetsim

# 配置 inetsim
# /etc/inetsim/inetsim.conf
"""
service_bind_address 0.0.0.0
service_max_clients 20

start_service dns
start_service http
start_service https
start_service smtp
start_service pop3
start_service imap
start_service ftp
start_service irc

http_default_index_dir /var/lib/inetsim/www/
http_default_404_file /var/lib/inetsim/www/404.html
"""

# 配置 DNS 模拟
# 使所有域名解析到模拟服务器
echo "0.0.0.0 *.*" >> /etc/hosts

# 启动 inetsim
inetsim --debug

# 使用 mitmproxy 做透明代理
mitmproxy --mode transparent -p 8080

# iptables 配置透明代理
iptables -t nat -A PREROUTING -i <interface> -p tcp --dport 80 -j REDIRECT --to-port 8080
iptables -t nat -A PREROUTING -i <interface> -p tcp --dport 443 -j REDIRECT --to-port 8080
```

### 5.4 AFWall 网络隔离

```bash
# AFWall+ 网络防火墙
# 控制恶意应用的网络访问，限制其连接范围

# 安装 AFWall+
# 需要 Root 权限
adb install afwall.apk

# 配置防火墙规则
# 1. 阻止目标应用的所有网络访问
# 2. 仅允许连接到 inetsim/mitmproxy 所在地址
# 3. 阻止 SIM 卡数据连接
# 4. 阻止 WiFi 和移动数据

# 命令行配置
adb shell "su -c 'iptables -A OUTPUT -m owner --uid-owner <app_uid> -j DROP'"
adb shell "su -c 'iptables -A OUTPUT -m owner --uid-owner <app_uid> -d <simulator_ip> -j ACCEPT'"
```
