### 10.2 MobSF 综合分析

```bash
# MobSF 完整使用流程

# 1. Docker 部署
docker run -it --rm -p 8000:8000 -p 8001:8001 \
  opensecurity/mobile-security-framework-mobsf:latest

# 2. 静态分析 API
# 上传 APK
RESPONSE=$(curl -s -X POST http://localhost:8000/api/v1/upload \
  -H "Authorization: Token <api_key>" \
  -F "file=@malicious.apk")
HASH=$(echo $RESPONSE | jq -r .hash)

# 触发静态分析
curl -s -X POST http://localhost:8000/api/v1/static_analyze \
  -H "Authorization: Token <api_key>" \
  -F "hash=$HASH"

# 获取静态分析报告
curl -s http://localhost:8000/api/v1/static_report_json?hash=$HASH \
  -H "Authorization: Token <api_key>" > report.json

# 3. 动态分析 API
# 配置模拟器
curl -s -X POST http://localhost:8000/api/v1/dynamic_analyze \
  -H "Authorization: Token <api_key>" \
  -F "hash=$HASH" \
  -F "avd_name=<emulator_id>"

# 获取动态分析报告
curl -s http://localhost:8000/api/v1/dynamic_report_json?hash=$HASH \
  -H "Authorization: Token <api_key>" > dynamic_report.json

# 4. 报告内容包含
# - 应用信息（包名、版本、签名）
# - 权限分析（危险权限识别）
# - 组件分析（导出组件风险）
# - 代码分析（API 调用、字符串、URL）
# - 恶意行为检测（基于行为模式）
# - 网络流量分析（C&C 通信检测）
# - Frida API 追踪日志
# - DOM 分析（WebView 内容）
# - 截图记录
```

### 10.3 VirusTotal 多引擎检测

```python
#!/usr/bin/env python3
"""
VirusTotal API 检测脚本
"""

import requests
import hashlib
import time

class VirusTotalChecker:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = 'https://www.virustotal.com/api/v3'

    def scan_file(self, file_path):
        """上传文件扫描"""
        with open(file_path, 'rb') as f:
            file_data = f.read()
        file_hash = hashlib.sha256(file_data).hexdigest()

        # 先查询是否已有报告
        existing = self.get_report(file_hash)
        if existing:
            return existing

        # 上传文件
        files = {'file': (file_path, open(file_path, 'rb'))}
        headers = {'x-apikey': self.api_key}
        response = requests.post(f'{self.base_url}/files', files=files, headers=headers)

        if response.status_code == 200:
            analysis_id = response.json()['data']['id']
            # 等待分析完成
            return self._wait_for_result(analysis_id)
        return None

    def get_report(self, file_hash):
        """获取已有报告"""
        headers = {'x-apikey': self.api_key}
        response = requests.get(
            f'{self.base_url}/files/{file_hash}',
            headers=headers
        )
        if response.status_code == 200:
            return self._parse_report(response.json())
        return None

    def _parse_report(self, data):
        """解析报告"""
        attributes = data['data']['attributes']
        stats = attributes.get('last_analysis_stats', {})
        results = attributes.get('last_analysis_results', {})

        # 提取检测引擎结果
        detections = []
        for engine, result in results.items():
            if result['category'] == 'malicious':
                detections.append({
                    'engine': engine,
                    'result': result['result']
                })

        return {
            'hash': data['data']['id'],
            'malicious_count': stats.get('malicious', 0),
            'total_engines': stats.get('harmless', 0) + stats.get('malicious', 0),
            'detections': detections,
            'classification': attributes.get('popular_threat_classification', {}),
            'tags': attributes.get('tags', [])
        }
```

### 10.4 Google Play Protect

```
Google Play Protect 防护体系：

1. 上传扫描
   ├── 安装前实时扫描
   ├── 基于云的机器学习检测
   ├── 与已知恶意特征库比对
   └── 行为分析引擎

2. 运行时保护
   ├── 监控应用行为
   ├── 检测 Overlay 攻击
   ├── 阻止非 Play Store 来源 APK 安装
   ├── 警告无障碍服务滥用
   └── 检测设备被 Root

3. Play Store 审核机制
   ├── 自动化静态分析
   ├── 动态行为分析
   ├── 人工审核
   ├── 开发者身份验证
   └── 用户举报处理

4. 限制与绕过
   ├── 限制：Play Protect 可被关闭
   ├── 限制：仅保护 Play Store 安装的应用
   ├── 绕过：第三方应用商店安装不受保护
   ├── 绕过：恶意应用通过 Frida 禁用 Play Protect
   └── 绕过：利用零日漏洞绕过检测
```
