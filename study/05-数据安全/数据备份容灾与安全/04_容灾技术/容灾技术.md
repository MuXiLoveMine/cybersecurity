# 容灾技术

### 4.1 容灾模式对比

| 模式 | 原理 | RTO | RPO | 成本 | 适用场景 |
|------|------|-----|-----|------|----------|
| 热备 | 主备同时运行，备机实时同步 | 秒级 | 秒级 | 高 | 关键业务系统 |
| 温备 | 备机就绪但不处理业务，定期同步 | 分钟级 | 小时级 | 中 | 重要业务系统 |
| 冷备 | 备机离线，需手动启动恢复 | 小时~天 | 天级 | 低 | 非关键系统 |
| 双活 | 双中心同时运行，互为备份 | 零 | 零 | 最高 | 核心业务系统 |

### 4.2 双活数据中心

```
双活数据中心架构:

              ┌─────────────────┐
              │   全局负载均衡    │
              │  (GSLB / DNS)   │
              └────────┬────────┘
                       │
           ┌───────────┴───────────┐
           │                       │
    ┌──────▼──────┐          ┌──────▼──────┐
    │  数据中心 A  │◄────────►│  数据中心 B  │
    │  (北京)     │  专线    │  (上海)     │
    │             │  DWDM    │             │
    │ ┌─────────┐ │  10G/    │ ┌─────────┐ │
    │ │ 应用集群  │ │ 100G    │ │ 应用集群  │ │
    │ ├─────────┤ │          │ ├─────────┤ │
    │ │ 数据库   │◄┼─────────┼►│ 数据库   │ │
    │ │ (主/备)   │ │ Data    │ │(备/主)   │ │
    │ └─────────┘ │ Guard    │ └─────────┘ │
    └─────────────┘          └─────────────┘

双活核心要求:
├── 网络层: 低延迟专线（<2ms RTT）
├── 存储层: 存储虚拟化/双活存储
├── 数据库层: 数据同步（Oracle Data Guard/MySQL Group Replication）
├── 应用层: 无状态设计/会话共享
└── 流量层: 全局DNS负载均衡 + 健康检查
```

### 4.3 两地三中心架构

```
两地三中心架构:

         ┌─────────────────────────────┐
         │      同城双活中心          │
         │  ┌─────────┐  ┌─────────┐  │
         │  │ 中心A    │  │ 中心B    │  │
         │  │ (生产)  │◄─►│ (同城备)│  │
         │  │         │同│         │  │
         │  │         │城│         │  │
         │  │         │专│         │  │
         │  │         │线│         │  │
         │  └─────────┘  └────┬────┘  │
         └────────────────────┼──────┘
                              │
                      异地专线 (≥1000km)
                              │
         ┌────────────────────┼──────┐
         │              ┌─────▼────┐│
         │              │  中心C   ││
         │              │ (异地灾) ││
         │              │  备中心  ││
         │              └─────────┘│
         └────────────────────────┘

设计要点:
├── 中心A: 主生产中心
├── 中心B: 同城备份（RPO≈0，RTO≈分钟级）
├── 中心C: 异地灾备（RPO<小时级，RTO<小时级）
├── A→B: 同步复制（数据零丢失）
├── A/B→C: 异步复制（允许少量数据丢失）
└── 故障切换: A故障切B，A+B同时故障切C
```
