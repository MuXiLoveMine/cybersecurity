# 备份安全威胁

### 2.1 勒索软件对备份的威胁

勒索软件是数据备份面临的最大威胁。现代勒索软件（如 LockBit、BlackCat、Akira）在加密生产数据前，会先尝试破坏或加密备份数据。

```
勒索软件攻击备份的典型路径:

攻击阶段1: 侦察
├── 发现备份系统（vssadmin list shadows）
├── 识别备份软件和存储位置
├── 探测网络共享和映射驱动器
└── 获取备份管理凭据

攻击阶段2: 备份破坏
├── 删除卷影副本 (vssadmin delete shadows /all /quiet)
├── 篡改备份软件配置
├── 加密备份存储目录
├── 停止备份服务 (net stop BackupExecAgent)
└── 删除备份历史记录

攻击阶段3: 生产数据加密
├── 加密业务数据库
├── 加密文件服务器
├── 加密应用数据
└── 留下勒索说明

攻击阶段4: 勒索谈判
├── 威胁公开敏感数据
├── 要求加密货币支付
└── 提供解密密钥（不可靠）
```

```powershell
# 攻击者常用的备份破坏命令（防御者需监控这些操作）

# 删除 Windows 卷影副本
vssadmin delete shadows /all /quiet
wmic shadowcopy delete

# 停止备份相关服务
net stop VSS
net stop swprv
net stop BackupExecAgentAccelerator
net stop BackupExecRPCService
net stop BackupExecAgentBrowser

# 禁用 Windows 备份
wbadmin delete catalog -quiet
bcdedit /set {default} recoveryenabled No

# 破坏 Veeam 备份（如已获取管理权限）
# 停止 Veeam 服务
net stop "Veeam Backup Service"
net stop "Veeam Backup Catalog Data Service"

# 删除备份文件
del /f /q "D:\Backups\*.vbk"
del /f /q "\\backup-server\share\*.vib"
```

### 2.2 备份篡改威胁

```
备份篡改风险场景:

场景1: 内部威胁
├── 恶意管理员修改备份数据
├── 篡改财务数据进行欺诈
└── 修改日志备份消除痕迹

场景2: 供应链攻击
├── 备份软件本身被植入后门
├── 备份存储设备固件被篡改
└── 备份传输通道被劫持

场景3: 权限滥用
├── 备份管理员账号被盗
├── 过度授权导致误操作或恶意操作
└── 共享备份凭据泄露

场景4: 数据投毒
├── 攻击者提前植入恶意数据
├── 等待数据进入备份后触发
└── 恢复时连带恢复恶意载荷
```

### 2.3 备份泄露威胁

```
备份泄露场景:

场景1: 备份存储未加密
├── 磁带/硬盘物理丢失
├── 备份文件未经加密上传云存储
└── 网络传输中备份数据被截获

场景2: 备份访问控制不足
├── 备份目录权限设置过宽
├── 备份管理界面弱密码
├── API 接口未做认证
└── 备份服务器暴露在公网

场景3: 云备份配置错误
├── S3 存储桶公开访问
├── 快照共享给了错误账号
└── 跨区域复制配置暴露
```
