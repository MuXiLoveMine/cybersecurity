# API 数据安全概述

### 4.1 API 数据流

```
API 数据流转全景:

数据存储层
├── 数据库（MySQL/PostgreSQL/MongoDB）
├── 缓存（Redis/Memcached）
├── 对象存储（OSS/S3）
└── 数据仓库

API 后端层
├── API 网关（认证/限流/路由）
├── 微服务（业务逻辑）
├── 数据访问层（ORM/查询）
└── 数据脱敏中间件

网络传输层
├── HTTPS/TLS 加密传输
├── 证书绑定（移动端）
└── API 签名验证

客户端层
├── Web 前端（浏览器）
├── 移动 App
├── 第三方接入方
└── 内部系统调用

数据暴露面风险:
├── API 返回过多数据字段（过度暴露）
├── 缺乏字段级权限控制
├── 分页不当导致全量数据遍历
├── 搜索/导出接口无限制
└── API 文档泄露数据结构
```
