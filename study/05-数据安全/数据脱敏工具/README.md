# 数据脱敏工具

数据脱敏工具是数据安全保护的重要组成部分，通过对敏感数据进行变形、替换、遮蔽等处理，在保持数据可用性的同时保护隐私信息。

## 章节结构

1. **数据脱敏工具概述** - 脱敏工具的分类、选型原则
2. **主流脱敏工具对比** - 商业/开源工具对比分析
3. **数据库脱敏方案** - 数据库动态/静态脱敏实现
4. **文件与日志脱敏** - 文件、日志数据的脱敏方法
5. **脱敏工具实战** - 各类工具的实战使用指南

## 核心内容

- 商业与开源脱敏工具对比
- 数据库动态脱敏（SQL Server/Oracle/MySQL）
- CSV/JSON文件批量脱敏
- Presidio PII识别与脱敏
- Faker假数据生成
- 脱敏效果验证

## 学习建议

1. 先理解脱敏技术原理（遮蔽、替换、泛化、哈希等）
2. 掌握至少一种开源脱敏工具的使用
3. 结合业务场景设计脱敏方案
4. 重视脱敏效果验证和安全性评估
