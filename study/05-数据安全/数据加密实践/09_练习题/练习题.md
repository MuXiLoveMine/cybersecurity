# 练习题

### 基础练习

1. 使用 Python 实现 AES-256-GCM 加密解密，加密一段文本并验证解密结果。
2. 生成 RSA 密钥对，实现对一个 128 位 AES 密钥的加密和解密（混合加密）。
3. 计算一个文件的 MD5、SHA-256、SHA-512 哈希值，并比较长度。
4. 使用 bcrypt 哈希一个密码，并验证正确和错误的密码。
5. 实现一个 HMAC 签名验证的 API 接口（模拟）。

### 进阶练习

1. 实现一个文件加密工具，支持加密/解密任意文件，加密后文件包含版本号、nonce、关联数据等元数据。
2. 设计一个数据库字段加密方案，支持密文等值查询（提示：使用确定性加密或索引）。
3. 实现一个简单的密钥管理系统，支持密钥生成、存储、轮换和销毁。
4. 研究国密算法，使用 SM2/SM3/SM4 实现一个完整的加密通信流程。

---

> 💡 **加密技术是数据安全的基石，但加密只是手段，正确的密钥管理和安全编码才是关键。永远不要自己发明加密算法，使用经过验证的标准方案！**
