# 练习题

### 基础练习

1. 使用 Python 实现 AES-256-GCM 加密解密，加密一段文本并验证解密结果。
2. 生成 RSA 密钥对，实现对一个 128 位 AES 密钥的加密和解密（混合加密）。
3. 计算一个文件的 MD5、SHA-256、SHA-512 哈希值，并比较长度。
4. 使用 bcrypt 哈希一个密码，并验证正确和错误的密码。
5. 实现一个 HMAC 签名验证的 API 接口（模拟）。

### 进阶练习

1. 实现一个文件加密工具，支持加密/解密任意文件，加密后文件包含版本号、nonce、关联数据等元数据。
2. 设计一个数据库字段加密方案，支持密文等值查询（提示：使用确定性加密或索引）。
3. 实现一个简单的密钥管理系统，支持密钥生成、存储、轮换和销毁。
4. 研究国密算法，使用 SM2/SM3/SM4 实现一个完整的加密通信流程。

### 一、OpenSSL 命令速查表

#### 1. 对称加密

```bash
# ========== AES 加密 ==========

# AES-256-CBC 加密文件
openssl enc -aes-256-cbc -salt -in plain.txt -out encrypted.enc
openssl enc -aes-256-cbc -salt -in plain.txt -out encrypted.enc -pass pass:yourpassword

# AES-256-CBC 解密文件
openssl enc -aes-256-cbc -d -in encrypted.enc -out decrypted.txt
openssl enc -aes-256-cbc -d -in encrypted.enc -out decrypted.txt -pass pass:yourpassword

# AES-256-GCM 加密（需要OpenSSL 1.1+）
openssl enc -aes-256-gcm -salt -in plain.txt -out encrypted.enc -K 00112233445566778899aabbccddeeff -iv 0102030405060708

# Base64 编码输出
openssl enc -aes-256-cbc -a -salt -in plain.txt -out encrypted.b64

# ========== 支持的对称加密算法 ==========
# 查看所有支持的加密算法
openssl enc -list

# 常用算法：
# -aes-128-cbc, -aes-192-cbc, -aes-256-cbc
# -aes-128-ecb, -aes-256-ecb
# -aes-128-gcm, -aes-256-gcm
# -des3 (三重DES)
# -bf (Blowfish)
# -rc4
# -camellia-256-cbc

# ========== 使用密钥文件 ==========

# 生成密钥文件
openssl rand -base64 32 > key.bin   # 256位密钥

# 使用密钥文件加密
openssl enc -aes-256-cbc -salt -in plain.txt -out encrypted.enc -pass file:./key.bin

# 使用密钥文件解密
openssl enc -aes-256-cbc -d -in encrypted.enc -out plain.txt -pass file:./key.bin

# ========== PBKDF2 迭代 ==========

# 使用PBKDF2增强密码派生（推荐）
openssl enc -aes-256-cbc -salt -pbkdf2 -iter 100000 -in plain.txt -out encrypted.enc
```

#### 2. 非对称加密

```bash
# ========== RSA 密钥生成 ==========

# 生成 RSA 私钥（2048位）
openssl genrsa -out private.key 2048

# 生成 RSA 私钥（4096位，更安全）
openssl genrsa -out private.key 4096

# 生成带密码保护的RSA私钥
openssl genrsa -aes256 -out private.key 2048

# 从私钥提取公钥
openssl rsa -in private.key -pubout -out public.key

# 查看私钥信息
openssl rsa -in private.key -text -noout

# 查看公钥信息
openssl rsa -pubin -in public.key -text -noout

# ========== RSA 加密/解密 ==========

# 使用公钥加密（只能加密小数据，如密钥）
openssl rsautl -encrypt -inkey public.key -pubin -in secret.txt -out secret.enc

# 使用私钥解密
openssl rsautl -decrypt -inkey private.key -in secret.enc -out secret_decrypted.txt

# 使用OAEP填充（更安全）
openssl rsautl -encrypt -inkey public.key -pubin -in secret.txt -out secret.enc -oaep
openssl rsautl -decrypt -inkey private.key -in secret.enc -out secret.txt -oaep

# ========== 混合加密示例 ==========

# 1. 生成随机对称密钥
openssl rand -base64 32 > aes_key.bin

# 2. 使用AES加密大文件
openssl enc -aes-256-cbc -salt -pbkdf2 -in large_file.iso -out large_file.enc -pass file:./aes_key.bin

# 3. 使用RSA公钥加密AES密钥
openssl rsautl -encrypt -inkey public.key -pubin -in aes_key.bin -out aes_key.enc -oaep

# 解密时：
# 1. 使用RSA私钥解密AES密钥
openssl rsautl -decrypt -inkey private.key -in aes_key.enc -out aes_key.bin -oaep

# 2. 使用AES密钥解密大文件
openssl enc -aes-256-cbc -d -in large_file.enc -out large_file.iso -pass file:./aes_key.bin

# ========== EC (椭圆曲线) 密钥 ==========

# 查看支持的椭圆曲线
openssl ecparam -list_curves

# 生成 EC 私钥（secp256r1 / prime256v1）
openssl ecparam -name prime256v1 -genkey -noout -out ec_private.key

# 从EC私钥提取公钥
openssl ec -in ec_private.key -pubout -out ec_public.key

# 生成 secp384r1 曲线密钥
openssl ecparam -name secp384r1 -genkey -noout -out ec384_private.key
```

#### 3. 哈希算法

```bash
# ========== 计算文件哈希 ==========

# MD5（不推荐，仅用于兼容性）
openssl md5 file.txt
md5sum file.txt

# SHA-1（不推荐，仅用于兼容性）
openssl sha1 file.txt
sha1sum file.txt

# SHA-256（推荐）
openssl sha256 file.txt
sha256sum file.txt

# SHA-512
openssl sha512 file.txt
sha512sum file.txt

# SHA-384
openssl sha384 file.txt

# ========== 验证文件完整性 ==========

# 生成哈希校验文件
sha256sum file1.txt file2.txt file3.txt > sha256sums.txt

# 校验哈希
sha256sum -c sha256sums.txt

# 仅显示失败的
sha256sum -c sha256sums.txt --quiet

# ========== 计算字符串哈希 ==========

echo -n "password" | openssl sha256
echo -n "password" | sha256sum

# ========== HMAC ==========

# HMAC-SHA256
echo -n "message" | openssl dgst -sha256 -hmac "secret_key"

# HMAC-MD5
echo -n "message" | openssl dgst -md5 -hmac "secret_key"

# 使用密钥文件
openssl dgst -sha256 -hmac "$(cat key.txt)" file.txt
```

#### 4. 数字签名与证书

```bash
# ========== 数字签名 ==========

# 使用私钥签名（先哈希再签名）
openssl dgst -sha256 -sign private.key -out signature.bin file.txt

# 验证签名
openssl dgst -sha256 -verify public.key -signature signature.bin file.txt

# ========== 自签名证书 ==========

# 生成自签名证书（一步完成）
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt -days 365 -nodes

# 交互式生成
openssl req -x509 -newkey rsa:4096 -keyout server.key -out server.crt -days 365 \
    -subj "/CN=example.com/O=MyOrg/C=CN"

# ========== CSR（证书签名请求）==========

# 生成私钥和CSR
openssl req -newkey rsa:2048 -keyout server.key -out server.csr -nodes

# 从现有私钥生成CSR
openssl req -new -key server.key -out server.csr

# 查看CSR内容
openssl req -in server.csr -text -noout

# ========== 查看证书 ==========

# 查看证书详细信息
openssl x509 -in server.crt -text -noout

# 查看证书序列号
openssl x509 -in server.crt -serial -noout

# 查看证书指纹
openssl x509 -in server.crt -fingerprint -sha256 -noout

# 查看证书有效期
openssl x509 -in server.crt -dates -noout

# 验证证书链
openssl verify -CAfile ca.crt server.crt

# ========== 证书转换 ==========

# PEM 转 DER
openssl x509 -in cert.pem -outform der -out cert.der

# DER 转 PEM
openssl x509 -in cert.der -inform der -out cert.pem

# PFX/P12 转 PEM（提取私钥和证书）
openssl pkcs12 -in cert.pfx -out cert.pem -nodes

# PEM 转 PFX/P12
openssl pkcs12 -export -out cert.pfx -inkey private.key -in server.crt -certfile ca.crt

# ========== SSL/TLS 测试 ==========

# 测试服务器SSL连接
openssl s_client -connect example.com:443

# 查看服务器证书
openssl s_client -connect example.com:443 -showcerts </dev/null

# 测试特定TLS版本
openssl s_client -connect example.com:443 -tls1_2
openssl s_client -connect example.com:443 -tls1_3

# 检查支持的密码套件
openssl s_client -connect example.com:443 -cipher 'ECDHE-RSA-AES256-GCM-SHA384'
```

### 二、GPG (GNU Privacy Guard) 命令速查表

#### 1. 密钥管理

```bash
# ========== 生成密钥对 ==========

# 交互式生成密钥
gpg --gen-key

# 完整交互式生成（更多选项）
gpg --full-generate-key

# 快速生成（非交互式）
gpg --batch --gen-key <<EOF
Key-Type: RSA
Key-Length: 4096
Subkey-Type: RSA
Subkey-Length: 4096
Name-Real: Zhang San
Name-Email: zhangsan@example.com
Passphrase: your_passphrase
Expire-Date: 0
%commit
EOF

# ========== 查看密钥 ==========

# 列出公钥
gpg --list-keys
gpg -k

# 列出私钥
gpg --list-secret-keys
gpg -K

# 查看密钥指纹
gpg --fingerprint
gpg --fingerprint user@example.com

# ========== 导出/导入密钥 ==========

# 导出公钥（ASCII格式）
gpg --armor --export user@example.com > public.key
gpg -a --export user@example.com > public.key

# 导出私钥（谨慎！）
gpg --armor --export-secret-keys user@example.com > private.key

# 导入公钥
gpg --import public.key
gpg --import someone_pub.key

# 导入私钥
gpg --import private.key

# ========== 密钥管理 ==========

# 编辑密钥（添加UID、修改过期时间等）
gpg --edit-key user@example.com
# 常用子命令：trust, expire, adduid, deluid, save

# 信任密钥
gpg --edit-key user@example.com
# > trust
# > 5 (最终信任)
# > save

# 删除公钥
gpg --delete-key user@example.com

# 删除私钥
gpg --delete-secret-key user@example.com

# 吊销密钥
gpg --gen-revoke user@example.com > revoke.asc
gpg --import revoke.asc
```

#### 2. 加密与解密

```bash
# ========== 公钥加密 ==========

# 使用接收者公钥加密文件
gpg --encrypt --recipient recipient@example.com file.txt
gpg -e -r recipient@example.com file.txt

# 加密并指定输出文件
gpg -e -r recipient@example.com -o file.gpg file.txt

# ASCII 装甲输出（.asc）
gpg -e -r recipient@example.com --armor file.txt
gpg -e -r recipient@example.com -a file.txt

# 多个接收者
gpg -e -r user1@example.com -r user2@example.com file.txt

# ========== 解密 ==========

# 解密文件
gpg --decrypt file.gpg
gpg -d file.gpg

# 解密并输出到文件
gpg -d file.gpg > decrypted.txt
gpg -o decrypted.txt -d file.gpg

# ========== 对称加密 ==========

# 使用密码加密（无需密钥对）
gpg --symmetric file.txt
gpg -c file.txt

# 指定加密算法
gpg -c --cipher-algo AES256 file.txt

# 解密对称加密的文件
gpg -d file.gpg
```

#### 3. 签名与验证

```bash
# ========== 数字签名 ==========

# 创建分离签名
gpg --detach-sign file.txt
gpg -b file.txt
# 生成 file.txt.sig

# 创建ASCII装甲分离签名
gpg -b -a file.txt
# 生成 file.txt.asc

# 创建内联签名（签名+数据在同一文件）
gpg --sign file.txt
gpg -s file.txt

#  clearsign 签名（明文签名）
gpg --clearsign file.txt
# 生成 file.txt.asc，内容可读，包含签名

# ========== 验证签名 ==========

# 验证分离签名
gpg --verify file.txt.sig file.txt

# 验证内联签名（同时提取原文件）
gpg --verify file.gpg
gpg -d file.gpg > original.txt

# 验证clearsign签名
gpg --verify file.txt.asc

# ========== 签名并加密 ==========

# 同时签名和加密
gpg -e -s -r recipient@example.com file.txt

# 解密并验证签名
gpg -d file.gpg
```

#### 4. GPG 实用技巧

```bash
# ========== 密钥服务器 ==========

# 上传公钥到密钥服务器
gpg --send-keys --keyserver keyserver.ubuntu.com KEY_ID

# 从密钥服务器搜索公钥
gpg --search-keys --keyserver keyserver.ubuntu.com "user@example.com"

# 从密钥服务器接收公钥
gpg --recv-keys --keyserver keyserver.ubuntu.com KEY_ID

# 刷新本地公钥（更新吊销状态等）
gpg --refresh-keys --keyserver keyserver.ubuntu.com

# ========== 常用密钥服务器列表 ==========
# keyserver.ubuntu.com
# keys.openpgp.org
# pgp.mit.edu
# pool.sks-keyservers.net

# ========== 批量操作 ==========

# 批量加密目录中的所有文件
for f in *.txt; do gpg -e -r user@example.com "$f"; done

# 批量解密
for f in *.gpg; do gpg -d "$f" > "${f%.gpg}"; done

# ========== 配置文件 ==========
# ~/.gnupg/gpg.conf - 主配置文件
# 常用配置：
# personal-digest-preferences SHA512 SHA384 SHA256
# personal-cipher-preferences AES256 AES192 AES
# cert-digest-algo SHA512
# default-preference-list SHA512 SHA384 SHA256 AES256 AES192 AES ZLIB BZIP2 ZIP Uncompressed
```

### 三、VeraCrypt 命令速查表

#### 1. 加密卷操作

```bash
# ========== 创建加密卷 ==========

# 交互式创建加密卷
veracrypt -t -c

# 非交互式创建（指定所有参数）
veracrypt -t -c ~/encrypted_volume.vc \
    --volume-type normal \
    --encryption AES \
    --hash SHA-512 \
    --filesystem NTFS \
    --size 1G \
    --password "your_password" \
    --random-source /dev/urandom

# 创建隐藏加密卷
veracrypt -t -c ~/hidden_volume.vc \
    --volume-type hidden \
    --encryption AES-Twofish-Serpent \
    --hash SHA-512 \
    --filesystem NTFS \
    --size 500M \
    --password "outer_password" \
    -p "inner_password"

# 支持的加密算法：
# AES, Serpent, Twofish
# AES-Twofish, AES-Twofish-Serpent
# Serpent-AES, Twofish-Serpent
# Camellia, Kuznyechik, Magma

# 支持的哈希算法：
# SHA-256, SHA-512, Whirlpool
# Streebog, BLAKE2s-256

# ========== 挂载加密卷 ==========

# 挂载卷到指定挂载点
veracrypt ~/encrypted_volume.vc /mnt/secure

# 以只读方式挂载
veracrypt -m ro ~/encrypted_volume.vc /mnt/secure

# 挂载隐藏卷
veracrypt --mount-options=hidden ~/hidden_volume.vc /mnt/secure

# 挂载时不使用文件系统（裸设备）
veracrypt --filesystem=none ~/encrypted_volume.vc /mnt/secure

# 使用密钥文件挂载
veracrypt -k keyfile.dat ~/encrypted_volume.vc /mnt/secure

# 挂载分区
veracrypt /dev/sdb1 /mnt/secure

# ========== 卸载加密卷 ==========

# 卸载指定卷
veracrypt -d /mnt/secure

# 卸载所有卷
veracrypt -d

# 强制卸载
veracrypt -d -f /mnt/secure

# ========== 查看卷信息 ==========

# 列出所有挂载的卷
veracrypt -l
veracrypt --list

# 查看卷属性
veracrypt --volume-properties /mnt/secure

# ========== 修改卷密码 ==========

# 修改密码
veracrypt -C ~/encrypted_volume.vc
veracrypt --change-password ~/encrypted_volume.vc

# 添加密钥文件
veracrypt --add-keyfile ~/encrypted_volume.vc -k new_keyfile.dat
```

#### 2. 加密系统分区

```bash
# ========== 系统加密 ==========

# 加密系统分区（交互式）
veracrypt -t -c /dev/sda1 --volume-type system

# 注意：系统加密通常使用GUI工具进行，命令行功能有限

# ========== 应急操作 ==========

# 紧急恢复：使用恢复磁盘启动后解密
veracrypt --rescue --mount /dev/sda1 /mnt/rescue

# 备份卷头（重要！）
veracrypt --backup-headers ~/encrypted_volume.vc
# 保存生成的 .vc_backup 文件到安全位置

# 恢复卷头
veracrypt --restore-headers ~/encrypted_volume.vc -b backup_file.vc_backup
```

#### 3. VeraCrypt 安全实践

```bash
# ========== 密钥文件生成 ==========

# 生成密钥文件
openssl rand -out keyfile.dat 64

# 使用多个密钥文件
veracrypt -k key1.dat -k key2.dat volume.vc /mnt/secure

# ========== PIM (Personal Iterations Multiplier) ==========

# 指定PIM值（值越大越安全，但挂载越慢）
veracrypt --pim 500 ~/encrypted_volume.vc /mnt/secure

# ========== 安全卸载 ==========

# 卸载并清除缓存中的密码
veracrypt -d
veracrypt --text -d   # 非交互模式

# 清除所有密码缓存
veracrypt -c ""  # 空密码参数清除缓存
```

### 四、其他加密工具速查

#### 1. 7-Zip 加密压缩

```bash
# ========== 加密压缩 ==========

# 使用密码压缩文件（AES-256加密）
7z a -p secret.7z file1.txt file2.txt

# 加密文件名（更安全）
7z a -p -mhe=on secret.7z file1.txt file2.txt

7z a -p"your_password" -mhe=on backup.7z /path/to/directory/

# ========== 解压 ==========

# 解压加密文件
7z x secret.7z
7z x -p"your_password" secret.7z

# 解压到指定目录
7z x secret.7z -o /path/to/extract/

# 测试压缩文件完整性
7z t secret.7z
```

#### 2. zip / unzip 加密

```bash
# 加密压缩（传统ZIP加密，安全性较低）
zip -e secret.zip file1.txt file2.txt
zip -P password secret.zip file1.txt file2.txt

# 解压
unzip secret.zip
unzip -P password secret.zip

# 注意：传统ZIP加密安全性弱，建议使用7z的AES-256
```

#### 3. gocryptfs (基于FUSE的文件加密)

```bash

fusermount -u ~/decrypted_view

# 只读挂载
gocryptfs -ro ~/encrypted_dir ~/decrypted_view

# 反向模式（明文目录 -> 加密视图）
```

### 五、加密工具对比与选型

| 工具 | 类型 | 加密算法 | 适用场景 | 优点 | 缺点 |
|------|------|---------|---------|------|------|
| **OpenSSL** | 命令行工具 | AES/DES/RSA等 | 文件加密、证书、SSL/TLS | 功能全面，跨平台 | 命令复杂，学习成本高 |
| **GPG** | 命令行工具 | RSA/AES/CAST等 | 邮件加密、文件签名 | 标准格式，广泛兼容 | 密钥管理较复杂 |
| **VeraCrypt** | GUI/CLI | AES/Serpent/Twofish | 磁盘/分区/文件加密 | 高强度加密，支持隐藏卷 | 大容器扩容不便 |
| **7-Zip** | 压缩工具 | AES-256 | 加密压缩包 | 简单易用，压缩+加密 | 仅适用于归档文件 |
| **gocryptfs** | FUSE文件系统 | AES-GCM | 目录级加密 | 透明加密，增量备份友好 | 需要FUSE支持 |
| **BitLocker** | Windows内置 | AES-128/256 | Windows系统分区加密 | 系统集成，性能好 | 仅限Windows |
| **FileVault** | macOS内置 | AES-128-XTS | macOS系统加密 | 系统集成，易用 | 仅限macOS |
| **LUKS** | Linux内置 | AES等 | Linux磁盘加密 | 系统级支持，开源 | 仅限Linux |
