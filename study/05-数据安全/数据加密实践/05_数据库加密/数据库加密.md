# 数据库加密

### 5.1 数据库加密方式对比

| 加密方式 | 说明 | 优点 | 缺点 |
|----------|------|------|------|
| **透明数据加密（TDE）** | 数据库层面自动加密解密，应用无感知 | 应用无需改造、实施简单 | 粒度粗、无法防内部DBA |
| **字段级加密** | 对敏感字段单独加密 | 粒度细、灵活 | 需要改造应用、影响查询 |
| **文件系统加密** | 操作系统或文件系统层面加密 | 透明、不影响应用 | 粒度粗、只防物理窃取 |
| **应用层加密** | 应用程序在写入前加密 | 最灵活、最安全 | 开发量大、维护复杂 |

### 5.2 透明数据加密（TDE）

**原理**：在数据写入磁盘时自动加密，读取时自动解密，对应用程序完全透明。

**MySQL TDE 配置示例**：

```sql
-- MySQL 8.0 支持透明数据加密
-- 1. 安装 keyring 插件
INSTALL PLUGIN keyring_file SONAME 'keyring_file.so';

-- 2. 启用加密
SET GLOBAL early-plugin-load=keyring_file.so;

-- 3. 创建加密表
CREATE TABLE user_sensitive (
    id INT PRIMARY KEY AUTO_INCREMENT,
    id_card VARCHAR(18) COMMENT '身份证号',
    bank_card VARCHAR(20) COMMENT '银行卡号',
    medical_record TEXT COMMENT '医疗记录'
) ENCRYPTION='Y' ENGINE=InnoDB;

-- 4. 查看加密表
SELECT TABLE_NAME, CREATE_OPTIONS 
FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_SCHEMA = 'test' AND CREATE_OPTIONS LIKE '%ENCRYPTION%';
```

**SQL Server TDE 配置示例**：

```sql
-- SQL Server TDE 配置步骤
-- 1. 创建主密钥
CREATE MASTER KEY ENCRYPTION BY PASSWORD = 'StrongPassword123!';

-- 2. 创建或获取受主密钥保护的证书
CREATE CERTIFICATE TDE_Cert WITH SUBJECT = 'TDE Certificate';

-- 3. 在用户数据库中创建数据库加密密钥
USE YourDatabase;
CREATE DATABASE ENCRYPTION KEY
WITH ALGORITHM = AES_256
ENCRYPTION BY SERVER CERTIFICATE TDE_Cert;

-- 4. 启用透明数据加密
ALTER DATABASE YourDatabase SET ENCRYPTION ON;

-- 5. 查看加密状态
SELECT db.name, db.is_encrypted, dm.encryption_state
FROM sys.databases db
LEFT JOIN sys.dm_database_encryption_keys dm
    ON db.database_id = dm.database_id;
```

### 5.3 字段级加密

**原理**：在应用层对敏感字段进行加密后存储，查询时解密。

**Python + MySQL 字段加密示例**：

```python
import pymysql
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os
import base64

class FieldEncryption:
    """
    数据库字段加密工具类
    使用 AES-256-GCM 加密敏感字段
    """
    
    def __init__(self, key: bytes):
        """
        初始化加密器
        参数:
            key: 256 位（32 字节）加密密钥
        """
        self.aesgcm = AESGCM(key)
    
    def encrypt_field(self, plaintext: str) -> str:
        """
        加密字段
        参数:
            plaintext: 明文字符串
        返回:
            Base64 编码的密文字符串（包含 nonce + ciphertext + tag）
        """
        if plaintext is None:
            return None
        
        nonce = os.urandom(12)
        ciphertext = self.aesgcm.encrypt(nonce, plaintext.encode("utf-8"), None)
        # 将 nonce 和密文拼接后 base64 编码，方便存储
        combined = nonce + ciphertext
        return base64.b64encode(combined).decode("ascii")
    
    def decrypt_field(self, encrypted: str) -> str:
        """
        解密字段
        参数:
            encrypted: Base64 编码的密文字符串
        返回:
            明文字符串
        """
        if encrypted is None:
            return None
        
        combined = base64.b64decode(encrypted)
        # 前 12 字节是 nonce，后面是密文+标签
        nonce = combined[:12]
        ciphertext = combined[12:]
        plaintext = self.aesgcm.decrypt(nonce, ciphertext, None)
        return plaintext.decode("utf-8")

# ========== 数据库操作示例 ==========

def insert_encrypted_user(encryption: FieldEncryption, username: str,

def query_decrypted_user(encryption: FieldEncryption, user_id: int):

    conn = pymysql.connect(

        database="test"

    cursor = conn.cursor()

    conn.close()
    
    if row:
        # 解密敏感字段
        result = {
            "id": row[0],
            "username": row[1],
            "id_card": encryption.decrypt_field(row[2]),
```

### 5.4 加密方案选择建议

| 场景 | 推荐方案 | 说明 |
|------|----------|------|
| 防物理窃取 | TDE + 文件系统加密 | 简单有效，应用无感知 |
| 防内部 DBA | 字段级加密 + 密钥分离 | DBA 看不到明文 |
| 高度敏感数据 | 应用层加密 + HSM 密钥管理 | 最安全，但开发成本高 |
| 合规要求 | TDE + 字段加密 + 审计 | 满足等保、数据安全法要求 |
