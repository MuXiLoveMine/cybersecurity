# 数据泄露检测与防护

### 7.1 数据泄露途径

| 途径 | 说明 | 典型场景 |
|------|------|----------|
| **外部攻击** | 黑客通过技术手段窃取数据 | SQL 注入拖库、木马窃取、漏洞利用 |
| **内部泄露** | 内部人员主动或被动泄露数据 | 员工倒卖数据、误操作、权限滥用 |
| **第三方泄露** | 合作伙伴/供应商导致数据泄露 | 供应链攻击、第三方系统漏洞 |
| **物理泄露** | 物理介质丢失或被盗 | 笔记本电脑丢失、硬盘被盗、纸质文件泄露 |
| **公开泄露** | 数据被公开在互联网上 | 暗网售卖、公开存储桶、社交平台泄露 |

### 7.2 数据泄露检测

#### 7.2.1 检测技术

**基于规则的检测**：
- 敏感数据关键字匹配
- 正则表达式匹配
- 数据格式校验（身份证号、银行卡号格式）
- 文件指纹匹配

**基于行为的检测**：
- 异常数据访问行为（大量数据下载）
- 异常登录行为（异地登录、非常规时间登录）
- 异常数据传输（大量外发数据）
- 用户行为基线对比

**基于内容的检测**：
- 精确数据匹配（EDM）
- 文档指纹（IDM）
- 机器学习分类
- 自然语言处理

#### 7.2.2 检测维度

**网络层面**：
- 网络流量监控
- 邮件内容检测
- Web 上传检测
- FTP/文件传输检测

**终端层面**：
- 文件操作监控
- USB 设备管控
- 打印监控
- 截屏监控
- 剪贴板监控

**存储层面**：
- 敏感数据发现
- 文件访问审计
- 异常访问检测
- 权限异常检测

### 7.3 数据泄露防护措施

**技术防护**：
1. 数据加密（存储加密、传输加密）
2. 访问控制（最小权限、身份认证）
3. 数据脱敏（静态脱敏、动态脱敏）
4. DLP 系统（终端、网络、存储 DLP）
5. 数据库安全（审计、防火墙、漏洞扫描）
6. 终端安全（防病毒、终端管控、EDR）

**管理防护**：
1. 数据分类分级
2. 安全管理制度
3. 人员安全培训
4. 第三方安全管理
5. 安全审计与检查
6. 应急响应预案
