# 终端 DLP

### 2.1 终端 DLP 概述

终端 DLP 是部署在用户终端（PC、笔记本、移动设备）上的数据防泄露系统，通过安装 Agent 监控和控制终端上的敏感数据操作。

**保护对象**：
- 终端上存储的敏感文件
- 终端上的敏感数据操作

### 2.2 终端 DLP 核心功能

#### 2.2.1 外设管控

**USB 存储设备控制**：
- 禁止使用 U 盘/移动硬盘
- 只读模式（只能读不能写）
- 只允许特定 U 盘（白名单）
- 拷贝文件审计和审批
- 文件内容检测（只拦截敏感文件）

**其他外设控制**：
- 光驱/刻录机控制
- 串口/并口控制
- 蓝牙设备控制
- 红外传输控制
- 打印控制
- 截屏控制
- 剪贴板控制

#### 2.2.2 文件操作监控

**监控范围**：
- 文件创建、修改、删除
- 文件复制、移动
- 文件重命名
- 文件访问（打开/读取）

**文件分类识别**：
- 按文件名/后缀识别
- 按文件内容识别（关键字、正则）
- 按文件指纹识别
- 按标签识别（文件打上敏感标签）

#### 2.2.3 应用程序控制

**网络应用控制**：
- 浏览器（HTTP/HTTPS 上传）
- 邮件客户端（Outlook、Foxmail）
- 即时通讯（微信、QQ、钉钉）
- 云盘客户端（百度网盘、Dropbox）
- FTP/SFTP 客户端
- 代码托管（Git、SVN）

**控制方式**：
- 完全禁止使用
- 允许使用但禁止传输敏感数据
- 允许使用但需要审批
- 允许使用但审计记录

#### 2.2.4 网络访问控制

**网络控制维度**：
- 按域名/URL 控制
- 按 IP 地址控制
- 按端口控制
- 按应用协议控制

**内容检测**：
- HTTP POST 内容检测
- 邮件内容检测
- 上传文件内容检测

**关键技术**：
- **文件系统过滤驱动**：拦截文件读写操作
- **网络过滤驱动**：拦截网络数据包
- **API Hook**：Hook 应用程序的 API 调用
- **内容解析引擎**：解析各种文件格式（Office、PDF、压缩包等）
- **OCR 识别**：识别图片中的文字内容

### 2.4 实际案例

**案例：某企业终端 DLP 部署**

**背景**：
- 某金融科技公司，员工 2000 人
- 大量客户数据和金融数据
- 曾发生员工通过 U 盘带走客户信息的事件

**实施方案**：

1. **第一阶段：摸底调查（2 周）**
   - 部署终端 DLP Agent（监控模式）
   - 统计外设使用情况
   - 统计文件外发情况
   - 识别敏感数据分布

2. **第二阶段：策略制定（2 周）**
   - 数据分类分级：公开、内部、秘密、机密
   - 外设策略：
     - 普通员工：禁止 USB 写入，打印审批
     - 研发人员：USB 只读，代码外发审批
     - 管理层：开放权限，全程审计
   - 网络策略：
     - 禁止上传到个人网盘
     - 外发邮件内容检测
     - 即时通讯文件检测

3. **第三阶段：逐步落地（4 周）**
   - 先从研发部门开始（最敏感）
   - 再推广到业务部门
   - 最后全员覆盖
   - 从监控模式逐步过渡到拦截模式

4. **第四阶段：持续优化（持续）**
   - 定期分析事件
   - 优化策略减少误报
   - 定期安全培训

**实施效果**：
- 敏感数据外发事件下降 90%
- USB 违规使用事件从每周 50+ 降至接近 0
- 通过等保三级和行业监管检查
- 建立了完善的数据防泄露体系
