# 常见数据泄露途径

### 5.1 数据泄露途径分类

```
                    数据泄露途径
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
      外部攻击       内部威胁       第三方泄露
          │             │             │
    ┌─────┴─────┐  ┌────┴────┐  ┌────┴────┐
    ▼           ▼  ▼         ▼  ▼         ▼
  黑客攻击   漏洞利用 恶意内鬼  疏忽失误  供应链  合作方
```

### 5.2 外部攻击导致的数据泄露

#### 5.2.1 常见攻击手段

| 攻击手段 | 说明 | 典型案例 |
|----------|------|----------|
| **SQL 注入** | 通过注入恶意 SQL 语句获取数据库数据 | 某电商平台用户数据泄露 |
| **漏洞利用** | 利用系统/应用漏洞获取数据 | Log4j 漏洞导致的数据泄露 |
| **钓鱼攻击** | 通过钓鱼邮件窃取账号密码，进而窃取数据 | 鱼叉式钓鱼获取员工邮箱权限 |
| **勒索病毒** | 加密数据并勒索，同时可能泄露数据 | 某医院遭勒索病毒攻击 |
| **APT 攻击** | 高级持续性威胁，长期潜伏窃取数据 | 某科技公司核心技术被窃 |
| **撞库攻击** | 使用泄露的密码批量尝试登录 | 大量平台用户账号被盗 |

#### 5.2.2 防护措施

- Web 应用防火墙（WAF）
- 数据库审计与防火墙
- 漏洞扫描与渗透测试
- 安全补丁管理
- 邮件安全网关
- 终端检测与响应（EDR）
- 网络入侵检测系统（IDS/IPS）

### 5.3 内部威胁导致的数据泄露

#### 5.3.1 内部威胁类型

**恶意内鬼（Malicious Insider）**：
- 主动窃取数据出售
- 离职前带走核心资料
- 报复性破坏数据
- 与外部勾结

**常见场景**：
- 销售人员离职带走客户名单
- 研发人员离职带走源代码
- 财务人员泄露财务数据
- 客服人员导出用户信息售卖

**疏忽失误（Careless Insider）**：
- 误发邮件（发错人）
- 丢失电脑/U 盘
- 错误配置导致数据公开
- 被骗泄露信息（社会工程学）

#### 5.3.2 内部威胁特点

- **隐蔽性强**：内部人员有合法权限，不易被发现
- **破坏性大**：内部人员了解系统和数据，窃取更精准
- **检测困难**：正常操作和恶意操作界限模糊
- **动机多样**：经济利益、报复、无意等

#### 5.3.3 防护措施

**技术层面**：
- 最小权限原则
- 数据脱敏（开发/测试环境）
- DLP 系统（终端+网络+存储）
- 操作审计与行为分析
- 数据水印（追溯泄露源头）
- 离职流程管控（权限及时回收）

**管理层面**：
- 背景调查（入职）
- 保密协议签署
- 安全意识培训
- 定期安全审计
- 离职面谈与交接
- 激励与关怀（减少恶意动机）

### 5.4 第三方数据泄露

#### 5.4.1 常见场景

- **供应商泄露**：IT 服务商、外包公司
- **合作方泄露**：业务合作伙伴、数据共享方
- **云服务商泄露**：云平台安全问题
- **供应链攻击**：通过第三方软件/硬件植入后门

#### 5.4.2 典型案例

> **案例：Facebook-Cambridge Analytica 数据泄露事件**
> - 背景：剑桥分析公司通过第三方应用获取了 8700 万 Facebook 用户数据
> - 途径：第三方应用开发者滥用数据访问权限
> - 影响：影响美国大选，Facebook 被罚款 50 亿美元
> - 教训：第三方数据访问权限管控的重要性

#### 5.4.3 防护措施

- 第三方安全评估（准入前）
- 数据安全协议（合同约束）
- 数据最小化（只提供必要的数据）
- 数据脱敏（共享前脱敏处理）
- 数据水印（追溯泄露源）
- 定期安全审计
- 权限管控（最小权限、定期回收）

### 5.5 物理途径泄露

- 电脑/笔记本丢失或被盗
- U 盘/移动硬盘丢失
- 纸质文件泄露
- 打印文件泄露
- 屏幕偷拍
- 废弃硬盘数据恢复

**防护措施**：
- 磁盘加密（BitLocker、LUKS）
- 文件加密
- 打印管控与审计
- 纸质文件销毁（碎纸机）
- 介质销毁流程
- 物理安全（门禁、监控）
