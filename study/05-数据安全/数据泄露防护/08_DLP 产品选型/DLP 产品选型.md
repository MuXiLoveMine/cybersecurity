# DLP 产品选型

### 8.1 主流 DLP 产品

| 产品类型 | 代表产品 | 特点 |
|----------|----------|------|
| **国内品牌** | 奇安信天擎 DLP | 终端 DLP 强势，本土化好 |

| | 亿赛通 DLP | 文档加密出身，全系列产品 |

| | 阿里云 DLP | 国内云厂商 |

### 8.2 选型考虑因素

| 维度 | 考虑要点 |
|------|----------|
| **功能覆盖** | 终端、网络、存储、云、邮件等覆盖是否全面 |
| **识别准确率** | 各种识别技术的准确性，误报率高低 |
| **性能影响** | 对终端性能、网络性能的影响程度 |
| **易用性** | 管理界面是否友好，策略配置是否方便 |
| **本土化** | 对国内应用（微信、钉钉等）的支持 |
| **合规支持** | 是否满足国内合规要求（等保、数据安全法） |
| **服务支持** | 厂商技术支持能力，响应速度 |
| **价格成本** | 采购成本、实施成本、运维成本 |
| **集成能力** | 与现有安全设备、IT 系统的集成能力 |

### 8.3 选型建议

1. **明确需求**：先搞清楚自己要保护什么、防什么，再选产品
2. **POC 测试**：实际部署测试，验证功能和性能
3. **参考同行**：了解同行业的使用情况
4. **关注服务**：DLP 不是买完就完事，运维服务很重要
5. **分阶段实施**：先做终端，再做网络，逐步完善
