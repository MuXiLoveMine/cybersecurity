# 遏制阶段

### 5.1 短期遏制

**立即遏制措施**

```
网络隔离:
  - 在防火墙封锁攻击源IP
  - 在交换机关闭攻击端口
  - 将受感染主机移到隔离VLAN
  - 禁用远程访问通道

账号控制:
  - 禁用被入侵的账号
  - 强制重置相关用户密码
  - 撤销活跃会话令牌
  - 禁用VPN/远程桌面访问

服务控制:
  - 停止可疑进程
  - 停止相关服务
  - 关闭受影响的端口
  - 暂停数据同步/外传
```

**遏制操作记录**

```
记录每项遏制操作的：
  - 操作时间（精确到秒）
  - 操作人员
  - 操作内容
  - 操作前后状态
  - 使用工具和命令
  - 操作结果
```

### 5.3 证据保全

**取证顺序（按易失性排序）**

```
1. 寄存器和缓存        (极快丢失)
2. 内存(RAM)          (断电即丢失)
3. 网络状态           (连接会超时)
4. 运行进程           (可被终止)
5. 临时文件           (可被覆盖)
6. 磁盘数据           (持久)
7. 远程日志           (持久)
8. 物理存储           (持久)
```

**内存取证**

```bash
# Windows
# 使用Magnet RAM Capture或winpmem
winpmem_mini_x64.exe output.mem

# 使用Magnet RAM Capture (GUI工具)
# 或使用NIST的WindowsSCOPE

# Linux
# 使用LiME (Linux Memory Extractor)
insmod lime.ko "path=/tmp/memory.lime format=lime"

# 使用AVML (Azure Virtual Machine Linux)
avml output.lime

# 内存分析 (Volatility 3)
vol -f memory.dmp windows.pslist
vol -f memory.dmp windows.netscan
vol -f memory.dmp windows.malfind
vol -f memory.dmp windows.cmdline
```

**磁盘取证**

```bash
# 使用写保护器防止数据被修改

# Linux使用dd或dc3dd
dc3dd if=/dev/sda of=disk_image.dd hash=sha256 log=acquisition.log
# dc3dd会同时计算哈希，确保完整性

# 使用dc3dd带校验
dc3dd if=/dev/sda of=disk_image.dd \
    hash=sha256 hash=md5 \
    log=acquisition.log \
    mlog=multi.log \
    ofs=0

# 验证镜像
sha256sum disk_image.dd
md5sum disk_image.dd

# 比对源盘和镜像哈希是否一致

# Windows使用FTK Imager
# 1. 启动FTK Imager
# 2. 选择"Create Disk Image"
# 3. 选择物理设备
# 4. 选择镜像格式（E01/DD/RAW）
# 5. 设置哈希算法（MD5+SHA256）
# 6. 采集并验证
```
