# 数据安全事件概述

### 1.1 事件定义与分类

数据安全事件是指由于人为原因、软硬件缺陷或故障、自然灾害等因素，导致信息系统中的数据遭到未经授权的获取、损坏或修改，对数据机密性、完整性或可用性造成影响的事件。

**事件分类**

| 类别 | 定义 | 典型场景 |
|------|------|----------|
| 数据泄露 | 数据被未经授权地获取或暴露 | 数据库拖库、API数据泄露 |
| 数据篡改 | 数据被未经授权地修改 | 篡改交易数据、网页挂马 |
| 数据损毁 | 数据被破坏或不可用 | 勒索软件加密、误删除 |
| 数据丢失 | 数据永久性消失 | 存储设备损坏、备份失败 |
| 未授权访问 | 数据被不应当访问的人访问 | 越权访问、权限滥用 |

### 1.2 事件分级标准

**特别重大事件（一级）**

- 影响范围：涉及1000万以上个人信息
- 数据类型：敏感个人信息（生物识别、医疗健康、金融账户）
- 社会影响：国家安全、社会秩序受到严重影响
- 业务影响：核心业务系统中断

**重大事件（二级）**

- 影响范围：涉及100万至1000万个人信息
- 数据类型：重要数据或敏感个人信息
- 社会影响：较大范围社会影响
- 业务影响：重要业务系统中断

**较大事件（三级）**

- 影响范围：涉及10万至100万个人信息
- 数据类型：一般个人信息
- 社会影响：一定范围社会影响
- 业务影响：部分业务系统中断

**一般事件（四级）**

- 影响范围：涉及10万以下个人信息
- 数据类型：非敏感数据
- 社会影响：影响有限
- 业务影响：个别系统短暂中断

### 1.3 常见数据安全事件类型

**数据泄露事件**

```
攻击链：
  1. 初始入侵 (漏洞利用/钓鱼/供应链攻击)
  2. 内网横向移动 (凭证窃取/漏洞利用)
  3. 数据库访问 (SQL注入/凭证复用)
  4. 数据外传 (加密通道/压缩打包/DNS隧道)
  5. 数据公开或出售
```

常见泄露途径：

| 途径 | 说明 | 案例 |
|------|------|------|
| SQL注入 | 数据库直接被拖 | 某电商网站5000万用户数据泄露 |
| API泄露 | 接口未鉴权或越权 | 某社交平台API暴露用户好友列表 |
| 云存储泄露 | S3 Bucket/Object公开 | 某公司S3存储桶公开暴露6亿用户数据 |
| 内部人员泄露 | 员工恶意或疏忽 | 某银行员工离职前导出客户数据 |
| 供应链攻击 | 第三方服务商被入侵 | 某SDK收集并泄露宿主APP用户数据 |
| 勒索泄露 | 勒索软件双重勒索 | 某企业被勒索后数据被公开 |

**数据篡改事件**

```
攻击类型：
  - 网页篡改：修改网站页面内容
  - 交易篡改：修改交易金额或记录
  - 配置篡改：修改系统或应用配置
  - 日志篡改：删除或修改安全日志
  - DNS劫持：修改DNS解析指向
```

**勒索软件事件**

```
勒索软件攻击链：
  1. 初始入侵 (钓鱼邮件/RDP暴力破解/漏洞利用)
  2. 权限提升 (漏洞利用/凭证窃取)
  3. 横向移动 (PsExec/WMI/RDP)
  4. 数据窃取 (双重勒索筹码)
  5. 数据加密 (全盘/数据库/文件服务器)
  6. 勒索通知 (加密货币赎金)
```
