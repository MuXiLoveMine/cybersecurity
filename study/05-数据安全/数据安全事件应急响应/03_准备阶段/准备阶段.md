### 3.2 应急响应团队

**IRT（Incident Response Team）角色定义**

```
事件指挥官 (Incident Commander)
  - 统一指挥和决策
  - 资源调配和优先级决定
  - 对外沟通的最终决策者

技术处置组
  - 安全分析师：日志分析、威胁狩猎
  - 系统管理员：系统隔离、恢复
  - 网络工程师：网络隔离、流量分析
  - 取证专家：证据采集、数字取证

法律合规组
  - 评估法律义务
  - 准备监管报告
  - 管理外部法律顾问

对外联络组
  - 对内/对外通报
  - 媒体应对
  - 用户通知
```

### 3.4 预案与演练

**事件响应预案模板**

```
场景：数据库泄露
触发条件：IDS告警/异常数据查询/数据外传检测

响应步骤：
  1. 识别确认
     - 确认告警真实性
     - 初步评估影响范围
     - 启动二级响应

  2. 紧急遏制
     - 隔离数据库服务器
     - 封锁攻击源IP
     - 禁用相关账号
     - 保留系统快照

  3. 取证分析
     - 采集内存镜像
     - 采集磁盘镜像
     - 提取数据库访问日志
     - 提取网络流量

  4. 影响评估
     - 确定泄露数据类型和数量
     - 识别受影响用户
     - 评估法律合规影响

  5. 根除与恢复
     - 修复漏洞
     - 清除后门
     - 重置所有凭证
     - 从备份恢复数据

  6. 通知报告
     - 监管机构报告（72小时内）
     - 用户通知
     - 内部总结报告
```
