# 数字取证方法

### 9.1 取证原则

```
1. 不改变原始证据
   - 使用写保护器
   - 操作副本而非原件
   - 记录所有操作

2. 证据完整性
   - 采集时计算哈希
   - 传输后验证哈希
   - 存储后定期验证

3. 证据链
   - 从采集到呈堂的完整记录
   - 每个环节有签名
   - 时间戳精确

4. 合法性
   - 取证授权明确
   - 遵循法律法规
   - 保护隐私权利
```

### 9.4 网络取证

```bash
# 全流量捕获
tcpdump -i eth0 -w full_traffic.pcap -G 3600 -W 24

# 过滤特定流量
tcpdump -i eth0 -w suspicious.pcap \
    'port 4444 or port 8080 or host 192.168.1.100'

# 使用Zeek(Bro)进行流量分析
zeek -r traffic.pcap local

# 分析HTTP流量
tshark -r traffic.pcap -Y http -T fields \
    -e http.request.uri -e http.host

# 分析DNS查询
tshark -r traffic.pcap -Y dns -T fields \
    -e dns.qry.name -e dns.resp.addr

# 检测数据外传
tshark -r traffic.pcap -Y 'tcp.dstport != 80 and tcp.dstport != 443' \
    -T fields -e ip.src -e ip.dst -e tcp.dstport -e frame.len
```

### 9.5 日志取证

```bash
# Windows日志导出
wevtutil epl Security C:\forensics\Security.evtx
wevtutil epl System C:\forensics\System.evtx
wevtutil epl Application C:\forensics\Application.evtx
wevtutil epl "Windows PowerShell" C:\forensics\PowerShell.evtx

# Linux日志
cp /var/log/auth.log /forensics/
cp /var/log/syslog /forensics/
cp /var/log/audit/audit.log /forensics/

# Web服务器日志
cp /var/log/nginx/access.log /forensics/
cp /var/log/nginx/error.log /forensics/
cp /var/log/apache2/access.log /forensics/

# 数据库日志
cp /var/log/mysql/mysql.log /forensics/
cp /var/log/postgresql/postgresql.log /forensics/

# 计算哈希
sha256sum /forensics/* > /forensics/hashes.txt
```
