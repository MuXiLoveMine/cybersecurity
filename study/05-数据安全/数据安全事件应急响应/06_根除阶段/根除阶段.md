# 根除阶段

### 6.1 威胁清除

**恶意软件清除**

```bash
# 1. 识别恶意进程
# Windows
wmic process list full | findstr "suspicious"
tasklist /svc

# Linux
ps auxf
lsof -i

# 2. 终止恶意进程
taskkill /PID <pid> /F      # Windows
kill -9 <pid>               # Linux

# 3. 删除恶意文件
del /f <path>               # Windows
rm -f <path>                 # Linux

# 4. 清除持久化机制
# Windows
# - 检查注册表启动项
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
reg query HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
# - 检查计划任务
schtasks /query /fo TABLE /v
# - 检查服务
sc query state= all

# Linux
# - 检查crontab
crontab -l
cat /etc/crontab
ls -la /etc/cron.d/
# - 检查systemd
systemctl list-unit-files --state=enabled
# - 检查rc.local
cat /etc/rc.local
# - 检查.bashrc/.profile
cat ~/.bashrc
cat ~/.profile
```

### 6.2 漏洞修复

```
修复优先级排序：

P0 - 紧急修复 (24小时内)
  - 被利用的远程代码执行漏洞
  - 被利用的认证绕过漏洞
  - 被利用的权限提升漏洞

P1 - 高优先级 (72小时内)
  - 未被利用但影响严重
  - 公开PoC的漏洞
  - 暴露在公面的服务漏洞

P2 - 中优先级 (1周内)
  - 内部服务漏洞
  - 需要认证才能利用的漏洞

P3 - 低优先级 (1月内)
  - 信息泄露
  - 非关键系统漏洞
```

### 6.3 加固措施

```
访问控制加固：
  - 重置所有可能泄露的凭证
  - 启用多因素认证(MFA)
  - 实施最小权限原则
  - 审查并清理用户权限
  - 加强特权账户管理

网络加固：
  - 更新防火墙规则
  - 实施网络分段
  - 部署IDS/IPS规则
  - 加强出口流量监控
  - 启用DNS过滤

监控加固：
  - 部署EDR
  - 增加日志覆盖范围
  - 配置新检测规则
  - 加强告警阈值
```
