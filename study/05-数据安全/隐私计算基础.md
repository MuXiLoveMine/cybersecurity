# 隐私计算基础

> 隐私计算（Privacy-Preserving Computation）是在保证数据隐私安全的前提下实现数据流通与协同计算的技术体系。本文档系统介绍隐私计算的核心技术原理、主流框架及实践示例。

---

## 1. 隐私计算概述

### 1.1 定义与背景

**隐私计算**（Privacy-Enhancing Computation, PEC）是指在数据处理、计算、发布过程中，保护原始数据不被泄露的前提下，仍能完成数据分析与机器学习任务的技术体系。

**核心驱动力：**

- 《数据安全法》《个人信息保护法》等法规对数据流通提出合规要求
- 数据孤岛问题严重：企业间无法共享原始数据，阻碍 AI 模型训练
- 传统"数据汇聚后计算"模式存在泄露风险

### 1.2 数据可用不可见理念

```
┌──────────────────────────────────────────┐
│           数据可用不可见 (DUCV)            │
├──────────────────────────────────────────┤
│  数据持有方：提供数据参与计算，不泄露原始数据  │
│  数据使用方：获得计算结果，无法看到原始数据    │
│  核心目标：数据要素流通 + 隐私安全兼顾        │
└──────────────────────────────────────────┘
```

### 1.3 隐私计算技术分类

| 技术路线 | 核心思想 | 代表技术 |
|----------|----------|----------|
| **密码学路线** | 通过密码学协议保证计算安全 | 多方安全计算(MPC)、同态加密(HE)、零知识证明(ZKP) |
| **硬件信任路线** | 依赖可信硬件隔离计算环境 | 可信执行环境(TEE) |
| **人工智能融合路线** | 在模型训练中保护隐私 | 联邦学习(FL)、差分隐私(DP) |

## 2. 多方安全计算（MPC）

### 2.1 百万富翁问题

**姚期智百万富翁问题**是 MPC 的经典示例：

> 两个百万富翁 Alice 和 Bob 想知道谁更富有，但都不想透露自己的真实财富金额。

**核心思想：** 多个参与方各自持有私密输入，在不泄露各自输入的前提下共同计算某个函数的输出。

### 2.2 秘密共享（Shamir's Secret Sharing）

Shamir 秘密共享基于多项式插值原理：

- 将秘密 S 分成 n 份，任意 k 份（k <= n）可重构 S，少于 k 份无法获取任何信息
- **数学原理：** 构造 k-1 次多项式 f(x) = S + a1*x + a2*x^2 + ... + a(k-1)*x^(k-1)，令 f(0) = S
- 分发给第 i 方的份额为 (i, f(i))，任意 k 个份额可通过拉格朗日插值恢复 S

```
示例（3-of-5 方案）：
秘密 S = 1234
构造多项式 f(x) = 1234 + 166x + 94x^2 （mod p）

f(1) = 1494  → 分给参与方1
f(2) = 1942  → 分给参与方2
f(3) = 2756  → 分给参与方3
f(4) = 4090  → 分给参与方4
f(5) = 5994  → 分给参与方5

任意3份即可通过拉格朗日插值恢复 S=1234
任意2份无法获得 S 的任何信息
```

### 2.3 混淆电路（Garbled Circuit）

混淆电路由 Yao 提出，核心步骤：

1. **电路生成：** 将计算函数转化为布尔电路（AND/OR/NOT 门）
2. **混淆：** 为每条线路随机分配两个密钥（对应 0 和 1），用密钥加密真值表
3. **传输：** 生成方将混淆电路发送给另一方
4. **求值：** 另一方通过不经意传输获取输入对应密钥，逐门解密求值

### 2.4 不经意传输（Oblivious Transfer）

不经意传输（OT）协议：发送方有两条消息 m0、m1，接收方选择其中一条 b（0 或 1），但发送方不知道接收方选了哪条，接收方也不知道另一条内容。

```
OT 协议交互：
  发送方 S              接收方 R
  持有 m0, m1           选择 b ∈ {0,1}
     ←── 公钥请求 ──←
  ── 加密后的 m0,m1 ──→
                        解密得到 m_b
  
  S 不知 R 选了哪条
  R 不知 m_(1-b) 的内容
```

### 2.5 应用场景

- **联合统计：** 多方共同计算均值、方差等统计指标而不泄露各自数据
- **联合建模：** 多方协作训练机器学习模型（如联合训练风控模型）
- **隐私集合求交（PSI）**：求多方的交集而不泄露交集外的数据

## 3. 联邦学习（FL）

### 3.1 联邦学习原理

联邦学习允许多个参与方在各自本地训练模型，仅交换模型参数（梯度），不交换原始数据。

**分类：**

| 类型 | 数据特征 | 示例 |
|------|----------|------|
| **横向联邦** | 各方数据特征相同，样本不同 | 不同地区银行的相同客户特征 |
| **纵向联邦** | 各方样本相同（如同一批用户），特征不同 | 银行+电商针对相同用户群 |
| **联邦迁移学习** | 样本和特征都不同 | 跨领域迁移学习 |

### 3.2 联邦平均算法（FedAvg）

```
FedAvg 算法流程：
1. 服务器初始化全局模型 w0
2. 第 t 轮迭代：
   a. 服务器将全局模型 wt 广播给参与方
   b. 各参与方 i 在本地数据上训练 E 个 epoch：
      wi(t+1) = wt - η * ∇L(wt; Di)    // 本地梯度下降
   c. 各参与方将更新后的模型 wi(t+1) 上传服务器
   d. 服务器聚合：w(t+1) = Σ (ni/n) * wi(t+1)  // 按数据量加权平均
3. 重复直到收敛
```

### 3.3 安全聚合（Secure Aggregation）

安全聚合确保服务器只能看到聚合后的梯度，无法看到单个参与方的梯度：

1. 各参与方对梯度添加掩码（pairwise masking）
2. 服务器只能恢复聚合后的梯度（掩码相互抵消）
3. 即使服务器与某个参与方合谋，也无法获取其他参与方的梯度

### 3.4 差分隐私在联邦学习中的应用

在联邦学习中引入差分隐私：

- **客户端级 DP**：在本地梯度上添加噪声后上传
- **中心级 DP**：服务器在聚合后的梯度上添加噪声

```
带噪声的梯度更新：
  w(t+1) = w(t) - η * (聚合梯度 + Noise)

  Noise ~ Laplace(Δf / ε)
  其中 Δf 为梯度敏感度，ε 为隐私预算
```

### 3.5 框架介绍

| 框架 | 来源 | 特点 |
|------|------|------|
| **TensorFlow Federated** | Google | 基于 TF 的联邦学习框架，适合研究 |
| **PySyft** | OpenMined | 开源隐私计算框架，支持 FL + MPC + HE |
| **FATE** | 微众银行 | 工业级联邦学习框架，支持横向/纵向 |
| **TF-Encrypted** | OpenMined | 基于 TF 的安全多方计算框架 |

## 4. 同态加密（HE）

### 4.1 半同态加密（Paillier 算法）

**Paillier 加密**支持加法同态：对密文执行乘法运算等价于对明文执行加法。

```
Paillier 同态性质：
  Enc(m1) * Enc(m2) = Enc(m1 + m2)     // 密文乘 = 明文加
  Enc(m)^k = Enc(k * m)                 // 密文幂 = 明文数乘

密钥生成：
  选取大素数 p, q，计算 n = p*q，g = n+1
  公钥: (n, g)
  私钥: λ = lcm(p-1, q-1)

加密：
  c = g^m * r^n mod n^2   （r 为随机数）

解密：
  m = L(c^λ mod n^2) * μ mod n
  其中 L(x) = (x-1)/n
```

### 4.2 全同态加密（Gentry 方案）

2009 年 Gentry 提出第一个全同态加密方案，支持任意深度电路的同态计算：

- **核心挑战：** 同态运算会导致密文噪声增长，噪声超过阈值后无法解密
- **Bootstrapping 技术：** 在噪声达到阈值前，对密文执行"刷新"操作（同态解密），重置噪声
- **性能：** 全同态计算开销极大，比明文计算慢数个数量级

**同态加密分类：**

| 类型 | 支持运算 | 代表方案 |
|------|----------|----------|
| 半同态 (PHE) | 仅加法 或 仅乘法 | Paillier, RSA |
| 些许同态 (SHE) | 有限次加法+乘法 | BGV, CKKS |
| 全同态 (FHE) | 任意深度加法+乘法 | Gentry, FHEW, TFHE |

### 4.3 应用场景与性能考量

- **隐私统计：** 多方密文求和/求均值（Paillier 加法同态）
- **安全预测：** 同态执行模型推理（CKKS 支持近似浮点运算）
- **性能：** FHE 计算速度比明文慢 10^3 ~ 10^6 倍，需权衡安全性与效率

### 4.4 开源库

| 库 | 支持方案 | 特点 |
|----|----------|------|
| **Microsoft SEAL** | BFV, CKKS | C++ 实现，工业级，文档完善 |
| **HElib** | BGV, CKKS | IBM 开源，学术性强 |
| **TFHE** | TFHE | 支持快速布尔电路同态运算 |
| **Paillier (Python)** | Paillier | Python 实现，适合学习 |

## 5. 零知识证明（ZKP）

### 5.0 基本概念

零知识证明：证明者（Prover）向验证者（Verifier）证明某个陈述为真，但不泄露任何额外信息。

**三个性质：**

- **完备性（Completeness）**：若陈述为真，诚实验证者一定接受
- **可靠性（Soundness）**：若陈述为假，作弊证明者几乎不可能欺骗成功
- **零知识性（Zero-Knowledge）**：验证者除了知道陈述为真外，不获得任何其他信息

### 5.1 Schnorr 协议

Schnorr 身份证明协议是经典的 ZKP 示例：

```
已知：生成元 g，公钥 y = g^x mod p，证明者知道私钥 x

1. 承诺（Commit）：证明者选随机数 r，发送 R = g^r mod p 给验证者
2. 挑战（Challenge）：验证者发送随机挑战 c
3. 响应（Response）：证明者计算 s = r + c*x mod q，发送 s
4. 验证（Verify）：验证者检查 g^s == R * y^c mod p

验证者确信证明者知道 x，但无法从交互中获得 x 的值
```

### 5.2 zk-SNARKs 与 zk-STARKs

| 特性 | zk-SNARKs | zk-STARKs |
|------|-----------|-----------|
| 全称 | 简洁非交互式零知识证明 | 可扩展透明知识证明 |
| 可信设置 | 需要（trusted setup） | 不需要（透明） |
| 抗量子 | 否（依赖椭圆曲线） | 是（依赖哈希函数） |
| 证明大小 | 非常小（~200B） | 较大（~100KB） |
| 验证速度 | 极快 | 较快 |

### 5.3 应用场景

- **区块链隐私交易**：Zcash 使用 zk-SNARKs 隐藏交易金额和地址
- **身份认证**：证明"我满18岁"而不透露具体年龄
- **合规证明**：证明交易所储备金充足而不暴露具体持仓
- **Layer 2 扩容**：zk-Rollup 用 ZKP 压缩链上交易

|------|------|

| **snarkjs** | JavaScript 实现的 zk-SNARK 工具链 |
| **libsnark** | C++ 的 zk-SNARK 库 |
| **Cairo** | StarkNet 的 ZK 友好编程语言 |

## 6. 差分隐私（DP）

### 6.1 差分隐私定义

**ε-差分隐私**：对于任意只差一条记录的数据集 D 和 D'，算法 M 满足：

```
Pr[M(D) ∈ S] <= e^ε * Pr[M(D') ∈ S]

其中：
  ε 为隐私预算（越小隐私保护越强）
  e^ε 为隐私损失倍率
  当 ε 越接近 0，两个数据集的输出分布越接近，隐私保护越强
```

**核心意义：** 攻击者无法确定某条记录是否在数据集中，因为有无该记录的输出分布几乎相同。

### 6.2 噪声机制

**拉普拉斯机制**（适用于数值查询）：

```
在查询结果 f(D) 上添加拉普拉斯噪声：
  M(D) = f(D) + Lap(Δf / ε)

其中 Δf 为查询的全局敏感度（添加/删除一条记录对结果的最大影响）
拉普拉斯分布：Lap(b) 的概率密度为 (1/2b) * exp(-|x|/b)
```

**高斯机制**（适用于连续查询和组合）：

```
M(D) = f(D) + N(0, σ^2)
其中 σ = Δf * sqrt(2*ln(1.25/δ)) / ε
(ε, δ)-差分隐私
```

**指数机制**（适用于非数值输出）：

```
根据效用函数 u(D, r) 选取输出 r 的概率正比于 exp(ε*u(D,r)/(2*Δu))
```

### 6.3 组合性

差分隐私的关键优势在于组合性：

- **串行组合**：k 个 ε-差分隐私机制的组合满足 k*ε-差分隐私
- **并行组合**：互不相交数据集上的查询满足 max(ε)-差分隐私
- **后处理**：对差分隐私输出再处理不降低隐私保证

```
隐私预算分配示例：
  总预算 ε = 1.0
  查询1分配 ε1 = 0.3
  查询2分配 ε2 = 0.4
  查询3分配 ε3 = 0.3
  总消耗 ε_total = 0.3 + 0.4 + 0.3 = 1.0 <= ε
```

### 6.4 应用

- **数据发布**：人口普查统计、健康数据发布
- **机器学习**：DP-SGD（差分隐私随机梯度下降）
- **联邦学习**：在梯度上传时添加差分隐私噪声（见第3节）

## 7. 可信执行环境（TEE）

### 7.1 Intel SGX

Intel Software Guard Extensions (SGX) 提供 CPU 级别的安全隔离：

- **Enclave**：受硬件保护的内存区域，OS 和 Hypervisor 均无法访问
- **远程证明**：验证 Enclave 运行在真实 SGX 环境中
- **密封**：Enclave 内的数据可加密存储，仅同一 Enclave 可解封

**安全模型：** 信任 Intel CPU 硬件，不信任 OS、云平台和管理员。

**已知攻击：** L1 Terminal Fault (L1TF)、Spectre/Meltdown 侧信道攻击。

### 7.2 ARM TrustZone

ARM TrustZone 将 CPU 分为安全世界（Secure World）和普通世界（Normal World）：

- 安全世界运行 TEE OS（如 OP-TEE）
- 普通世界运行 Rich OS（如 Linux/Android）
- 硬件隔离两世界的内存和外设访问

**应用：** 移动设备中的指纹识别、DRM 版权保护、密钥存储。

### 7.3 TEE vs MPC 对比

| 对比维度 | TEE | MPC |
|----------|-----|-----|
| 安全假设 | 信任硬件厂商 | 信任数学/密码学 |
| 性能 | 接近明文（性能损耗极小） | 计算开销大（10-1000x） |
| 侧信道风险 | 有（缓存/时序攻击） | 较低 |
| 部署难度 | 需特定硬件 | 纯软件实现 |
| 适用场景 | 高性能隐私计算 | 高安全要求场景 |

### 7.4 应用场景

- **隐私计算平台**：在 Enclave 中执行多方数据计算，如隐私求交、联邦学习
- **密钥管理**：HSM 硬件安全模块使用 TEE 保护密钥
- **数字版权**：DRM 内容解密在 TrustZone 中进行
- **安全支付**：移动支付在 TrustZone 中处理支付密钥

## 9. Python 隐私计算示例

### 9.1 简单秘密共享演示

```python
import random

def shamir_secret_share(secret, n, k, prime=None):
    """Shamir (k, n) 秘密共享方案"""
    # 选择大于 secret 的大素数
    if prime is None:
        prime = 2**521 - 1  # Mersenne prime

    # 生成 k-1 次随机多项式，常数项为 secret
    coefficients = [secret] + [
        random.randint(1, prime - 1) for _ in range(k - 1)
    ]

    # 计算各份额
    shares = []
    for i in range(1, n + 1):
        # 多项式求值: f(i) = sum(coeff[j] * i^j) mod prime
        val = 0
        for j, coeff in enumerate(coefficients):
            val = (val + coeff * pow(i, j, prime)) % prime
        shares.append((i, val))

    return shares, prime

def lagrange_interpolation(shares, prime):
    """拉格朗日插值恢复秘密"""
    secret = 0
    k = len(shares)

    for i in range(k):
        xi, yi = shares[i]
        # 拉格朗日基函数
        numerator = 1
        denominator = 1
        for j in range(k):
            if i == j:
                continue
            xj, _ = shares[j]
            numerator = (numerator * (-xj)) % prime
            denominator = (denominator * (xi - xj)) % prime

        # 模逆元
        inv_denominator = pow(denominator, -1, prime)
        lagrange_coeff = (numerator * inv_denominator) % prime

        secret = (secret + yi * lagrange_coeff) % prime

    return secret


if __name__ == '__main__':
    secret = 2024
    print(f"原始秘密: {secret}")

    # 3-of-5 方案
    shares, prime = shamir_secret_share(secret, n=5, k=3)

    print("\n5 份份额:")
    for idx, (x, y) in enumerate(shares):
        print(f"  份额{idx+1}: ({x}, {y})")

    # 用任意 3 份恢复
    selected = random.sample(shares, 3)
    recovered = lagrange_interpolation(selected, prime)
    print(f"\n用 3 份恢复秘密: {recovered}")

    # 用 2 份尝试恢复（应无法恢复）
    selected_2 = random.sample(shares, 2)
    recovered_2 = lagrange_interpolation(selected_2, prime)
    print(f"用 2 份尝试恢复: {recovered_2} (不等于原始秘密)")
```

### 9.2 差分隐私数据发布演示

```python
import numpy as np

def laplace_mechanism(true_value, sensitivity, epsilon):
    """拉普拉斯机制实现差分隐私"""
    # 噪声尺度 b = Δf / ε
    b = sensitivity / epsilon
    noise = np.random.laplace(0, b)
    return true_value + noise

def gaussian_mechanism(true_value, sensitivity, epsilon, delta):
    """高斯机制实现 (ε, δ)-差分隐私"""
    sigma = sensitivity * np.sqrt(2 * np.log(1.25 / delta)) / epsilon
    noise = np.random.normal(0, sigma)
    return true_value + noise

def demonstrate_dp():
    """差分隐私数据发布演示"""
    np.random.seed(42)

    # 模拟数据集：10000 人的年龄
    ages = np.random.randint(18, 80, size=10000)
    true_mean = np.mean(ages)
    true_count = len(ages)

    print("=" * 60)
    print("差分隐私数据发布演示")
    print("=" * 60)
    print(f"数据集大小: {true_count}")
    print(f"真实均值: {true_mean:.4f}")
    print(f"真实计数: {true_count}")
    print()

    # 均值查询的敏感度: Δf = (max - min) / n = (80 - 18) / 10000
    mean_sensitivity = (80 - 18) / true_count
    # 计数查询的敏感度: Δf = 1
    count_sensitivity = 1.0

    # 不同隐私预算对比
    epsilons = [0.1, 0.5, 1.0, 5.0]

    print(f"{'ε':>6} | {'DP均值':>12} | {'均值误差':>10} | {'DP计数':>10} | {'计数误差':>10}")
    print("-" * 60)

    for eps in epsilons:
        dp_mean = laplace_mechanism(true_mean, mean_sensitivity, eps)
        dp_count = laplace_mechanism(true_count, count_sensitivity, eps)
        mean_err = abs(dp_mean - true_mean)
        count_err = abs(dp_count - true_count)
        print(f"{eps:>6.1f} | {dp_mean:>12.4f} | {mean_err:>10.4f} | "
              f"{dp_count:>10.0f} | {count_err:>10.2f}")

    print()
    print("结论: ε 越小 -> 隐私保护越强 -> 噪声越大 -> 误差越大")
    print("      ε 越大 -> 隐私保护越弱 -> 噪声越小 -> 误差越小")
    print("=" * 60)
```

### 9.3 联邦学习概念演示

```python
import numpy as np

class FederatedClient:
    """联邦学习客户端"""

    def __init__(self, client_id, X, y):
        self.client_id = client_id
        self.X = X  # 本地特征数据
        self.y = y  # 本地标签
        self.weights = None

    def local_train(self, global_weights, epochs=5, lr=0.01):
        """本地训练：在本地数据上训练线性回归模型"""
        self.weights = global_weights.copy()
        n_samples = len(self.X)

        for epoch in range(epochs):
            # 前向传播: y_pred = X @ w
            y_pred = self.X @ self.weights
            # 梯度: grad = (2/n) * X^T @ (y_pred - y)
            error = y_pred - self.y
            gradient = (2 / n_samples) * (self.X.T @ error)
            # 梯度下降
            self.weights -= lr * gradient

        return self.weights

class FederatedServer:
    """联邦学习服务器"""

    def __init__(self, n_features):
        self.global_weights = np.zeros(n_features)

    def aggregate(self, client_weights, client_sizes):
        """FedAvg 聚合：按数据量加权平均"""
        total_size = sum(client_sizes)
        aggregated = np.zeros_like(self.global_weights)

        for weights, size in zip(client_weights, client_sizes):
            aggregated += (size / total_size) * weights

        self.global_weights = aggregated
        return self.global_weights

def simulate_federated_learning():
    """模拟联邦学习过程"""
    np.random.seed(42)
    n_features = 3
    true_weights = np.array([2.0, -1.5, 0.5])

    print("=" * 60)
    print("联邦学习概念演示 (FedAvg)")
    print("=" * 60)
    print(f"真实权重: {true_weights}")
    print()

    # 创建 3 个客户端，各自有不同数据
    clients = []
    for i in range(3):
        n = 50 * (i + 1)  # 不同客户端数据量不同
        X = np.random.randn(n, n_features)
        y = X @ true_weights + np.random.randn(n) * 0.1  # 添加噪声
        clients.append(FederatedClient(f"Client-{i+1}", X, y))

    server = FederatedServer(n_features)

    # 联邦训练轮次
    rounds = 20
    for rnd in range(rounds):
        # 各客户端本地训练
        client_weights = []
        client_sizes = []
        for client in clients:
            w = client.local_train(server.global_weights, epochs=5, lr=0.05)
            client_weights.append(w)
            client_sizes.append(len(client.X))

        # 服务器聚合
        server.aggregate(client_weights, client_sizes)

        if (rnd + 1) % 5 == 0:
            print(f"轮次 {rnd+1:>2} | 全局权重: "
                  f"[{server.global_weights[0]:>6.3f}, "
                  f"{server.global_weights[1]:>6.3f}, "
                  f"{server.global_weights[2]:>6.3f}]")

    print()
    print(f"最终全局权重: {server.global_weights}")
    print(f"真实权重:     {true_weights}")
    print(f"权重误差:     {np.abs(server.global_weights - true_weights)}")
    print()
    print("说明: 各客户端数据未离开本地，仅交换模型权重")
    print("      服务器仅能看到聚合后的全局权重，保护数据隐私")
    print("=" * 60)

if __name__ == '__main__':
    simulate_federated_learning()
```

## 总结

隐私计算是数据要素流通与隐私保护的关键技术桥梁。核心技术要点：

1. **MPC**：数学上最安全，但计算开销大，适合高安全要求场景
2. **联邦学习**：工程上最实用，已在金融风控、医疗等领域落地
3. **同态加密**：理论上最优雅（直接对密文计算），但性能瓶颈明显
4. **零知识证明**：在区块链领域应用广泛，验证效率高
5. **差分隐私**：轻量级隐私保护，可与 FL/HE/TEE 组合使用
6. **TEE**：性能最优但需信任硬件厂商，适合高性能场景

技术选型应综合考虑安全需求、性能要求、部署条件和合规要求，多数实际系统采用**混合方案**（如 FL + DP、FL + HE、TEE + FL）以平衡安全与效率。
