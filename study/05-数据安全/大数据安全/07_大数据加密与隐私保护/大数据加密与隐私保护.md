# 大数据加密与隐私保护

### 7.1 透明数据加密（TDE）

TDE 在存储层自动加解密，应用无感。HDFS 透明加密区、HBase Cell 加密、Kafka 消息加密都属于此类。

```bash
# HDFS透明加密区(见2.2节)
# 关键: KEK存在KMS, 数据用EDEK加密, 密钥与数据分离

# HBase Cell级加密
# hbase-site.xml
<property>
  <name>hbase.crypto.keyprovider</name>
  <value>org.apache.hadoop.hbase.io.crypto.KeyProviderForTesting</value>
</property>
<property>
  <name>hbase.crypto.masterkey.alg</name>
  <value>AES</value>
</property>
```

TDE 防护的是"存储介质失窃"（硬盘被偷、备份磁带丢失），不防"已认证用户访问"——用户有权限读就能解密。所以 TDE 必须配合权限控制。

### 7.2 列级加密与行级加密

**列级加密：** 在应用层对敏感列做加密后存储，查询时解密。

```sql
-- Hive列级加密示例(UDF)
INSERT INTO customers_encrypted
SELECT id, encrypt_aes(name, '${KEY}'), phone, encrypt_aes(idcard, '${KEY}')
FROM customers_raw;

-- 查询时解密
SELECT id, decrypt_aes(name_enc, '${KEY}') FROM customers_encrypted WHERE id=100;

-- 缺点: 加密列无法用索引/谓词下推优化, 性能差
-- 替代: 确定性加密(可等值查询但泄露频次)
```

**行级控制：** Ranger 行级过滤在 SQL 执行时自动加 WHERE 条件，不同用户看到不同行。

### 7.3 差分隐私在大数据中的应用

差分隐私（Differential Privacy）通过添加噪声，保证"加入或移除任一条记录，统计结果几乎不变"，从而保护个体隐私。

```
差分隐私原理:

原始统计: COUNT(*) = 1000
加噪后:   COUNT(*) + Laplace(0, 1/ε) = 1000 ± 噪声

ε(epsilon)越小隐私越强, 但结果越不准
特性: 即使攻击者知道其他999条记录, 也无法推断第1000条
```

应用场景：
- 数据统计发布（如发布用户画像聚合数据）
- 跨部门数据共享前的脱敏
- 机器学习训练数据保护（DP-SGD）

局限：差分隐私适合"聚合统计"，不适合"精确查询"——总不能给用户查自己订单还加噪声。大数据平台中通常用于对外发布的统计报表。

### 7.4 数据脱敏与匿名化

**静态脱敏：** 把生产数据复制到测试库时，对敏感字段做不可逆变换。

```python
# Python脱敏示例
import hashlib
import random

def mask_idcard(idcard):
    # 保留前6后4, 中间打码
    return idcard[:6] + "********" + idcard[-4:]

def hash_phone(phone, salt="s3cr3t"):
    return hashlib.sha256((phone + salt).encode()).hexdigest()[:16]

def generalize_age(age):
    # 泛化为区间
    return f"{age//10*10}-{age//10*10+9}"

# k-匿名: 保证每条记录至少与k-1条在准标识符上不可区分
# 实现方式: 泛化(如年龄→区间, 邮编→前3位) + 抑制(删除标识列)
```

**动态脱敏：** 在查询时实时掩码，原始数据不动。Ranger 的 Masking 策略支持。

```
Ranger脱敏策略类型:
  MASK: 全部掩码 ****
  MASK_SHOW_LAST_4: 末4位可见 ****1234
  MASK_SHOW_FIRST_4: 首4位可见 1234****
  MASK_HASH: 哈希值
  MASK_DATE: 日期精度降到年
  MASK_NULL: 返回NULL
```

**匿名化标准：**
- k-匿名：每条记录至少与 k-1 条在准标识符上不可区分
- l-多样性：每个等价类中敏感属性至少有 l 个不同值
- t-贴近：敏感属性分布接近整体分布
