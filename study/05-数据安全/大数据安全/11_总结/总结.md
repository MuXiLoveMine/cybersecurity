# 总结

大数据安全是"分布式系统 + 海量敏感数据"双重挑战下的安全工程。掌握要点：

1. **认证是地基：** Kerberos 是 Hadoop 生态的认证基石，部署虽复杂但不可绕过。关键运维：KDC 高可用、keytab 严管、时钟同步。
2. **授权到列：** 原生 HDFS 权限粒度粗，Ranger 实现库/表/列级 + 行级过滤 + 动态脱敏，是合规审计的核心。
3. **加密分层：** 传输加密（SASL/SSL）防嗅探，存储加密（TDE）防介质失窃，应用层加密（列级）防越权，各防一面。
4. **审计贯通：** 各组件审计汇入统一平台，能按"谁、何时、访问了什么数据"还原完整链路，是事后追溯与合规证据的关键。
5. **行为监控补授权盲区：** 光有权限控制不够，必须监控"权限内的异常使用"——批量拉取、敏感字段高频查询、跨业务线访问。

持续学习路径：先理解 Kerberos 原理与排错 → 上手 Hadoop/Kafka 安全配置 → 部署 Ranger 统一授权 → 实施加密与脱敏 → 搭建统一审计与行为监控 → 在实战加固与事件响应中沉淀经验。大数据安全没有银弹，是认证、授权、加密、审计、监控五位一体的系统工程。
