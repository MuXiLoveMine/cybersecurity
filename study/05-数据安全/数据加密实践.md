## 一、对称加密实战

### 1.1 AES 算法概述

AES（Advanced Encryption Standard）是目前最广泛使用的对称加密算法，由美国国家标准与技术研究院（NIST）于 2001 年发布。

**AES 特点**：
- 密钥长度：128 位、192 位、256 位
- 分组长度：128 位（16 字节）
- 安全性高：目前尚无有效的破解方法
- 性能优秀：软硬件实现效率都很高

### 1.2 AES 工作模式对比

| 模式 | 全称 | 特点 | 安全性 | 推荐度 |
|------|------|------|--------|--------|
| ECB | 电子密码本 | 每个块独立加密，相同明文块产生相同密文块 | 低 | 不推荐 |
| CBC | 密码分组链接 | 每个明文块与前一个密文块异或后再加密，需要 IV | 中 | 谨慎使用 |
| CFB | 密码反馈 | 将前一个密文加密后与明文异或，可作为流密码 | 中 | 较少使用 |
| OFB | 输出反馈 | 类似 CFB，但反馈的是加密输出 | 中 | 较少使用 |
| CTR | 计数器 | 使用计数器生成密钥流，与明文异或，可并行 | 中高 | 推荐 |
| GCM | Galois/Counter | 提供加密 + 完整性认证，需要 nonce | 高 | **强烈推荐** |

#### 1.2.1 ECB 模式（不推荐）

**原理**：将明文分成固定大小的块，每个块独立加密。

```
明文块1 → AES加密 → 密文块1
明文块2 → AES加密 → 密文块2
明文块3 → AES加密 → 密文块3
```

**问题**：
- 相同的明文块产生相同的密文块
- 容易暴露数据模式
- 无法抵御重放攻击

**可视化示例**：
> 如果加密一张图片，ECB 模式加密后仍然能看出图片轮廓，因为相同颜色的块加密后颜色相同。

#### 1.2.2 CBC 模式

**原理**：每个明文块先与前一个密文块进行异或运算，然后再加密。第一个块需要初始化向量（IV）。

```
IV ⊕ 明文块1 → AES加密 → 密文块1
密文块1 ⊕ 明文块2 → AES加密 → 密文块2
密文块2 ⊕ 明文块3 → AES加密 → 密文块3
```

**特点**：
- 相同明文块会产生不同密文块
- 需要随机 IV（16 字节）
- 加密是串行的，无法并行
- 解密可以并行

**安全问题**：
- 存在填充提示攻击（Padding Oracle Attack）
- IV 必须不可预测

#### 1.2.3 GCM 模式（推荐）

**原理**：基于 CTR 模式 + Galois 消息认证码，同时提供保密性和完整性认证。

```
计数器 → AES加密 → 密钥流
密钥流 ⊕ 明文 → 密文
密文 → GHASH → 认证标签（Tag）
```

**特点**：
- 同时提供加密和认证（AEAD - 认证加密）
- 防止数据被篡改
- 需要 nonce（通常 12 字节），不能重复
- 加密解密都可并行，性能好
- 是目前最推荐的工作模式

#### 1.3.1 AES-ECB 模式示例

```python
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
from cryptography.hazmat.backends import default_backend
import os

# ========== AES-ECB 加密解密示例（仅作演示，不推荐使用） ==========

def aes_ecb_encrypt(key: bytes, plaintext: bytes) -> bytes:
    """
    AES-ECB 模式加密
    参数:
        key: 加密密钥，必须是 16/24/32 字节（对应 AES-128/192/256）
        plaintext: 明文数据，长度必须是 16 的倍数（需要填充）
    返回:
        密文数据
    """
    # 创建 AES 加密器，使用 ECB 模式
    cipher = Cipher(algorithms.AES(key), modes.ECB(), backend=default_backend())
    encryptor = cipher.encryptor()
    # 执行加密
    ciphertext = encryptor.update(plaintext) + encryptor.finalize()
    return ciphertext

def aes_ecb_decrypt(key: bytes, ciphertext: bytes) -> bytes:
    """
    AES-ECB 模式解密
    """
    cipher = Cipher(algorithms.AES(key), modes.ECB(), backend=default_backend())
    decryptor = cipher.decryptor()
    plaintext = decryptor.update(ciphertext) + decryptor.finalize()
    return plaintext

# ========== PKCS7 填充函数 ==========

def pkcs7_pad(data: bytes, block_size: int = 16) -> bytes:
    """
    PKCS7 填充
    将数据填充到 block_size 的整数倍
    填充规则：缺少 n 个字节，就填充 n 个值为 n 的字节
    """
    padding_len = block_size - (len(data) % block_size)
    padding = bytes([padding_len] * padding_len)
    return data + padding

def pkcs7_unpad(data: bytes, block_size: int = 16) -> bytes:
    """
    PKCS7 去填充
    """
    padding_len = data[-1]
    if padding_len < 1 or padding_len > block_size:
        raise ValueError("Invalid padding")
    # 验证填充是否正确
    if data[-padding_len:] != bytes([padding_len] * padding_len):
        raise ValueError("Invalid padding")
    return data[:-padding_len]

# ========== 使用示例 ==========
if __name__ == "__main__":
    # 生成 256 位（32 字节）随机密钥
    key = os.urandom(32)
    print(f"密钥（hex）: {key.hex()}")
    
    # 待加密数据
    plaintext = "这是一段需要加密的敏感数据：用户密码是123456".encode("utf-8")
    print(f"明文: {plaintext.decode('utf-8')}")
    
    # 填充
    padded_plaintext = pkcs7_pad(plaintext)
    print(f"填充后长度: {len(padded_plaintext)} 字节")
    
    # 加密
    ciphertext = aes_ecb_encrypt(key, padded_plaintext)
    print(f"密文（hex）: {ciphertext.hex()}")
    
    # 解密
    decrypted_padded = aes_ecb_decrypt(key, ciphertext)
    decrypted = pkcs7_unpad(decrypted_padded)
    print(f"解密结果: {decrypted.decode('utf-8')}")
```

**ECB 模式安全风险演示**：

```python
# 演示 ECB 模式的缺陷：相同明文块产生相同密文块
def demonstrate_ecb_weakness():
    """演示 ECB 模式的安全性缺陷"""
    key = os.urandom(32)
    
    # 构造包含重复块的明文
    # 32 字节 = 2 个 AES 块，两个块内容相同
    plaintext = b"A" * 16 + b"A" * 16  # 两个相同的 16 字节块
    
    ciphertext = aes_ecb_encrypt(key, plaintext)
    
    # 分割为两个 16 字节的密文块
    block1 = ciphertext[:16]
    block2 = ciphertext[16:]
    
    print(f"明文块1: {plaintext[:16]}")
    print(f"明文块2: {plaintext[16:]}")
    print(f"密文块1（hex）: {block1.hex()}")
    print(f"密文块2（hex）: {block2.hex()}")
    print(f"两个密文块是否相同: {block1 == block2}")
    print("风险：攻击者可以通过密文模式推断明文信息！")
```

#### 1.3.2 AES-CBC 模式示例

```python
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
from cryptography.hazmat.backends import default_backend
import os

def aes_cbc_encrypt(key: bytes, plaintext: bytes) -> tuple[bytes, bytes]:
    """
    AES-CBC 模式加密
    参数:
        key: 加密密钥，16/24/32 字节
        plaintext: 明文数据
    返回:
        (iv, ciphertext) 初始化向量和密文
    """
    # 生成随机 IV（初始化向量），16 字节
    iv = os.urandom(16)
    
    # PKCS7 填充
    padded = pkcs7_pad(plaintext)
    
    # 创建 CBC 模式加密器
    cipher = Cipher(algorithms.AES(key), modes.CBC(iv), backend=default_backend())
    encryptor = cipher.encryptor()
    ciphertext = encryptor.update(padded) + encryptor.finalize()
    
    return iv, ciphertext

def aes_cbc_decrypt(key: bytes, iv: bytes, ciphertext: bytes) -> bytes:
    """
    AES-CBC 模式解密
    参数:
        key: 解密密钥
        iv: 初始化向量
        ciphertext: 密文数据
    返回:
        明文数据
    """
    cipher = Cipher(algorithms.AES(key), modes.CBC(iv), backend=default_backend())
    decryptor = cipher.decryptor()
    padded_plaintext = decryptor.update(ciphertext) + decryptor.finalize()
    
    # 去填充
    plaintext = pkcs7_unpad(padded_plaintext)
    return plaintext

# ========== 使用示例 ==========
if __name__ == "__main__":
    key = os.urandom(32)  # AES-256
    plaintext = "用户敏感信息：张三，身份证号110101199001011234".encode("utf-8")
    
    # 加密
    iv, ciphertext = aes_cbc_encrypt(key, plaintext)
    print(f"IV（hex）: {iv.hex()}")
    print(f"密文（hex）: {ciphertext.hex()}")
    
    # 解密
    decrypted = aes_cbc_decrypt(key, iv, ciphertext)
    print(f"解密结果: {decrypted.decode('utf-8')}")
    
    # 演示：相同明文每次加密结果不同（因为 IV 随机）
    iv2, ciphertext2 = aes_cbc_encrypt(key, plaintext)
    print(f"\n第二次加密 IV（hex）: {iv2.hex()}")
    print(f"两次密文是否相同: {ciphertext == ciphertext2}")
    print("说明：CBC 模式下相同明文每次加密结果不同，更安全")
```

#### 1.3.3 AES-GCM 模式示例（推荐）

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os

def aes_gcm_encrypt(key: bytes, plaintext: bytes, associated_data: bytes = b"") -> tuple[bytes, bytes]:
    """
    AES-GCM 模式加密（认证加密）
    参数:
        key: 加密密钥，16/24/32 字节
        plaintext: 明文数据
        associated_data: 关联数据（仅参与认证，不加密，可选）
    返回:
        (nonce, ciphertext_with_tag) nonce 和带认证标签的密文
    """
    aesgcm = AESGCM(key)
    
    # 生成 nonce（Number used once），推荐 12 字节
    # 注意：同一个密钥下，nonce 绝对不能重复！
    nonce = os.urandom(12)
    
    # 加密，返回的是 密文 + 认证标签
    ciphertext = aesgcm.encrypt(nonce, plaintext, associated_data)
    
    return nonce, ciphertext

def aes_gcm_decrypt(key: bytes, nonce: bytes, ciphertext: bytes, associated_data: bytes = b"") -> bytes:
    """
    AES-GCM 模式解密
    参数:
        key: 解密密钥
        nonce: 加密时使用的 nonce
        ciphertext: 带认证标签的密文
        associated_data: 关联数据（必须与加密时一致）
    返回:
        明文数据
    异常:
        如果数据被篡改，抛出 InvalidTag 异常
    """
    aesgcm = AESGCM(key)
    try:
        plaintext = aesgcm.decrypt(nonce, ciphertext, associated_data)
        return plaintext
    except Exception as e:
        raise ValueError(f"解密失败，数据可能被篡改: {e}")

# ========== 使用示例 ==========
if __name__ == "__main__":
    # 生成密钥
    key = AESGCM.generate_key(bit_length=256)  # 生成 256 位密钥
    print(f"密钥（hex）: {key.hex()}")
    
    plaintext = "转账金额：10000元，收款人：张三".encode("utf-8")
    # 关联数据：不加密，但需要完整性保护的元数据
    associated_data = b"transaction_id=123456;timestamp=20240101"
    
    # 加密
    nonce, ciphertext = aes_gcm_encrypt(key, plaintext, associated_data)
    print(f"\nNonce（hex）: {nonce.hex()}")
    print(f"密文+标签（hex）: {ciphertext.hex()}")
    print(f"密文长度: {len(ciphertext)} 字节（明文 {len(plaintext)} 字节 + 16 字节标签）")
    
    # 正常解密
    decrypted = aes_gcm_decrypt(key, nonce, ciphertext, associated_data)
    print(f"\n正常解密结果: {decrypted.decode('utf-8')}")
    
    # 演示：篡改密文后解密失败
    print("\n=== 演示完整性保护 ===")
    tampered_ciphertext = ciphertext[:-1] + bytes([ciphertext[-1] ^ 0x01])  # 篡改最后一个字节
    try:
        aes_gcm_decrypt(key, nonce, tampered_ciphertext, associated_data)
        print("解密成功（不应该发生！）")
    except ValueError as e:
        print(f"篡改密文后解密失败: {e}")
        print("说明：GCM 模式能检测数据篡改，提供完整性保护")
    
    # 演示：关联数据不匹配也会解密失败
    print("\n=== 演示关联数据保护 ===")
    wrong_ad = b"transaction_id=999999;timestamp=20240101"
    try:
        aes_gcm_decrypt(key, nonce, ciphertext, wrong_ad)
        print("解密成功（不应该发生！）")
    except ValueError as e:
        print(f"关联数据不匹配解密失败: {e}")
        print("说明：关联数据也受到完整性保护")
```

### 1.4 三种模式对比总结

| 对比项 | ECB | CBC | GCM |
|--------|-----|-----|-----|
| 保密性 | 差（相同明文→相同密文） | 好 | 好 |
| 完整性 | 不提供 | 不提供 | **提供** |
| 认证功能 | 无 | 无 | **有** |
| IV/Nonce | 不需要 | 需要 IV | 需要 Nonce |
| 填充 | 需要 | 需要 | 不需要 |
| 加密并行 | 可以 | 不可以 | 可以 |
| 解密并行 | 可以 | 可以 | 可以 |
| 安全性 | 低 | 中 | 高 |
| 推荐场景 | 无（不推荐） | 兼容性场景 | **所有新系统** |

> **最佳实践**：新系统直接使用 AES-256-GCM 模式，它同时提供保密性、完整性和认证功能。

## 二、非对称加密实战

### 2.1 RSA 算法概述

RSA 是最经典的非对称加密算法，1977 年由 Ron Rivest、Adi Shamir、Leonard Adleman 提出。

**RSA 特点**：
- 基于大数分解难题
- 密钥对：公钥（公开）+ 私钥（保密）
- 公钥加密，私钥解密
- 私钥签名，公钥验签

**密钥长度建议**：
- 1024 位：已不安全，不推荐
- 2048 位：当前最低安全要求
- 3072 位：推荐，长期安全
- 4096 位：高安全需求

### 2.2 RSA 加密解密

```python
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.backends import default_backend
import os

# ========== RSA 密钥生成 ==========

def generate_rsa_keypair(key_size: int = 2048) -> tuple[rsa.RSAPrivateKey, rsa.RSAPublicKey]:
    """
    生成 RSA 密钥对
    参数:
        key_size: 密钥长度，推荐 2048 或 4096
    返回:
        (私钥, 公钥)
    """
    private_key = rsa.generate_private_key(
        public_exponent=65537,  # 公钥指数，固定使用 65537
        key_size=key_size,
        backend=default_backend()
    )
    public_key = private_key.public_key()
    return private_key, public_key

# ========== 密钥序列化（保存为文件） ==========

def save_private_key(private_key: rsa.RSAPrivateKey, filename: str, password: bytes = None):
    """
    将私钥保存为 PEM 格式文件
    参数:
        private_key: 私钥对象
        filename: 保存路径
        password: 私钥加密密码（可选，建议设置）
    """
    # 私钥加密选项
    if password:
        encryption_algorithm = serialization.BestAvailableEncryption(password)
    else:
        encryption_algorithm = serialization.NoEncryption()
    
    pem = private_key.private_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PrivateFormat.PKCS8,
        encryption_algorithm=encryption_algorithm
    )
    
    with open(filename, "wb") as f:
        f.write(pem)

def save_public_key(public_key: rsa.RSAPublicKey, filename: str):
    """
    将公钥保存为 PEM 格式文件
    """
    pem = public_key.public_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PublicFormat.SubjectPublicKeyInfo
    )
    
    with open(filename, "wb") as f:
        f.write(pem)

# ========== RSA 加密解密 ==========

def rsa_encrypt(public_key: rsa.RSAPublicKey, plaintext: bytes) -> bytes:
    """
    RSA 加密（使用 OAEP 填充，推荐）
    参数:
        public_key: 公钥
        plaintext: 明文数据，长度不能超过 (密钥长度/8 - 42) 字节
                   例如 2048 位密钥最多加密 245 - 42 = 203 字节
    返回:
        密文数据
    """
    ciphertext = public_key.encrypt(
        plaintext,
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None
        )
    )
    return ciphertext

def rsa_decrypt(private_key: rsa.RSAPrivateKey, ciphertext: bytes) -> bytes:
    """
    RSA 解密
    """
    plaintext = private_key.decrypt(
        ciphertext,
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None
        )
    )
    return plaintext

# ========== 使用示例 ==========
if __name__ == "__main__":
    print("=== RSA 密钥生成 ===")
    private_key, public_key = generate_rsa_keypair(2048)
    print("RSA 密钥对生成成功（2048 位）")
    
    # 保存密钥到文件
    save_private_key(private_key, "private_key.pem", password=b"my_secret_password")
    save_public_key(public_key, "public_key.pem")
    print("私钥已保存到 private_key.pem（加密保护）")
    print("公钥已保存到 public_key.pem")
    
    print("\n=== RSA 加密解密 ===")
    # 注意：RSA 加密数据长度有限制，适合加密短数据（如对称密钥）
    plaintext = "这是一段秘密消息".encode("utf-8")
    print(f"明文: {plaintext.decode('utf-8')}")
    print(f"明文长度: {len(plaintext)} 字节")
    
    # 加密（用公钥）
    ciphertext = rsa_encrypt(public_key, plaintext)
    print(f"密文长度: {len(ciphertext)} 字节（2048 位密钥 → 256 字节密文）")
    print(f"密文（hex）: {ciphertext.hex()[:64]}...")
    
    # 解密（用私钥）
    decrypted = rsa_decrypt(private_key, ciphertext)
    print(f"解密结果: {decrypted.decode('utf-8')}")
    
    print("\n=== RSA 不适合加密大量数据 ===")
    # 尝试加密过长的数据
    long_data = b"A" * 250  # 2048 位 RSA 最多加密约 245 字节（OAEP 填充）
    try:
        rsa_encrypt(public_key, long_data)
    except ValueError as e:
        print(f"加密 250 字节数据失败: {e}")
        print("说明：RSA 只适合加密小数据，大数据用对称加密，RSA 用于加密对称密钥")
```

### 2.3 RSA 数字签名

数字签名用于验证数据的完整性和来源真实性，防止抵赖。

```python
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.backends import default_backend
import os

def rsa_sign(private_key: rsa.RSAPrivateKey, data: bytes) -> bytes:
    """
    RSA 数字签名（使用 PSS 填充，推荐）
    参数:
        private_key: 签名私钥
        data: 待签名的数据
    返回:
        签名值
    """
    signature = private_key.sign(
        data,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH
        ),
        hashes.SHA256()
    )
    return signature

def rsa_verify(public_key: rsa.RSAPublicKey, data: bytes, signature: bytes) -> bool:
    """
    RSA 签名验证
    参数:
        public_key: 验签公钥
        data: 原始数据
        signature: 签名值
    返回:
        True 表示验证通过，False 表示验证失败
    """
    try:
        public_key.verify(
            signature,
            data,
            padding.PSS(
                mgf=padding.MGF1(hashes.SHA256()),
                salt_length=padding.PSS.MAX_LENGTH
            ),
            hashes.SHA256()
        )
        return True
    except Exception:
        return False

# ========== 使用示例 ==========
if __name__ == "__main__":
```

### 2.4 混合加密实战

实际应用中，RSA 不适合加密大量数据，通常使用混合加密机制：

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes, serialization
import os

def hybrid_encrypt(public_key: rsa.RSAPublicKey, plaintext: bytes) -> dict:
    """
    混合加密：RSA + AES-GCM
    流程：
    1. 生成随机 AES 密钥
    2. 用 AES 加密明文
    3. 用 RSA 加密 AES 密钥
    4. 返回加密的 AES 密钥 + AES 密文
    """
    # 1. 生成 256 位 AES 密钥
    aes_key = AESGCM.generate_key(bit_length=256)
    
    # 2. 使用 AES-GCM 加密明文
    aesgcm = AESGCM(aes_key)
    nonce = os.urandom(12)
    aes_ciphertext = aesgcm.encrypt(nonce, plaintext, None)
    
    # 3. 使用 RSA 加密 AES 密钥
    encrypted_aes_key = public_key.encrypt(
        aes_key,
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None
        )
    )
    
    return {
        "encrypted_key": encrypted_aes_key,  # RSA 加密的 AES 密钥
        "nonce": nonce,                       # AES-GCM nonce
        "ciphertext": aes_ciphertext          # AES-GCM 密文（含标签）
    }

def hybrid_decrypt(private_key: rsa.RSAPrivateKey, encrypted_data: dict) -> bytes:
    """
    混合解密
    流程：
    1. 用 RSA 解密得到 AES 密钥
    2. 用 AES 解密密文
    """
    # 1. RSA 解密得到 AES 密钥
    aes_key = private_key.decrypt(
        encrypted_data["encrypted_key"],
        padding.OAEP(
            mgf=padding.MGF1(algorithm=hashes.SHA256()),
            algorithm=hashes.SHA256(),
            label=None
        )
    )
    
    # 2. AES-GCM 解密
    aesgcm = AESGCM(aes_key)
    plaintext = aesgcm.decrypt(
        encrypted_data["nonce"],
        encrypted_data["ciphertext"],
        None
    )
    
    return plaintext

# ========== 使用示例 ==========
if __name__ == "__main__":
    print("=== 混合加密演示（RSA + AES-GCM）===")
    
    # 生成 RSA 密钥对
    private_key, public_key = generate_rsa_keypair(2048)
    
    # 大文件数据
    large_data = b"这是一段很长的敏感数据..." * 1000  # 约 30KB
    print(f"原始数据大小: {len(large_data)} 字节")
    
    # 加密
    encrypted = hybrid_encrypt(public_key, large_data)
    print(f"\n加密后各部分大小:")
    print(f"  - RSA 加密的 AES 密钥: {len(encrypted['encrypted_key'])} 字节")
    print(f"  - Nonce: {len(encrypted['nonce'])} 字节")
    print(f"  - AES 密文: {len(encrypted['ciphertext'])} 字节")
    print(f"  - 总大小: {len(encrypted['encrypted_key']) + len(encrypted['nonce']) + len(encrypted['ciphertext'])} 字节")
    
    # 解密
    decrypted = hybrid_decrypt(private_key, encrypted)
    print(f"\n解密结果: {'成功' if decrypted == large_data else '失败'}")
    
    print("\n混合加密的优势：")
    print("1. 利用 RSA 解决密钥分发问题（公钥公开）")
    print("2. 利用 AES 保证加密效率（适合大数据）")
    print("3. 兼顾安全性和性能")
```

## 三、哈希算法实战

### 3.1 常见哈希算法对比

| 算法 | 输出长度 | 碰撞阻力 | 速度 | 推荐场景 |
|------|----------|----------|------|----------|
| MD5 | 128 位 | 极低 | 快 | 非安全场景（如文件校验） |
| SHA-1 | 160 位 | 低 | 较快 | 已不推荐安全使用 |
| SHA-256 | 256 位 | 高 | 中 | 通用安全场景（推荐） |
| SHA-512 | 512 位 | 很高 | 中 | 高安全需求 |
| SM3 | 256 位 | 高 | 中 | 国密合规场景 |
| Bcrypt | 可变 | 高 | 慢（可调） | 密码哈希 |
| Argon2 | 可变 | 高 | 慢（可调） | 密码哈希（最佳） |

### 3.2 Python 实现哈希计算

```python
import hashlib
import os

# ========== 基础哈希函数 ==========

def md5_hash(data: bytes) -> str:
    """
    计算 MD5 哈希值
    注意：MD5 已不安全，不应用于安全场景
    """
    return hashlib.md5(data).hexdigest()

def sha1_hash(data: bytes) -> str:
    """
    计算 SHA-1 哈希值
    注意：SHA-1 已不安全，不应用于安全场景
    """
    return hashlib.sha1(data).hexdigest()

def sha256_hash(data: bytes) -> str:
    """
    计算 SHA-256 哈希值（推荐）
    """
    return hashlib.sha256(data).hexdigest()

def sha512_hash(data: bytes) -> str:
    """
    计算 SHA-512 哈希值
    """
    return hashlib.sha512(data).hexdigest()

# ========== 大文件哈希计算 ==========

def file_hash(filepath: str, algorithm: str = "sha256", chunk_size: int = 8192) -> str:
    """
    计算大文件的哈希值（分块读取，避免内存溢出）
    参数:
        filepath: 文件路径
        algorithm: 哈希算法名称（md5, sha1, sha256, sha512）
        chunk_size: 每次读取的块大小
    返回:
        哈希值（十六进制字符串）
    """
    hash_obj = hashlib.new(algorithm)
    
    with open(filepath, "rb") as f:
        while True:
            chunk = f.read(chunk_size)
            if not chunk:
                break
            hash_obj.update(chunk)
    
    return hash_obj.hexdigest()

# ========== 使用示例 ==========
if __name__ == "__main__":
    data = "Hello, 数据安全！".encode("utf-8")
    
    print("=== 常见哈希算法对比 ===")
    print(f"原始数据: {data.decode('utf-8')}")
    print()
    
    print(f"MD5:    {md5_hash(data)}  ({len(md5_hash(data))*4} 位)")
    print(f"SHA-1:  {sha1_hash(data)}  ({len(sha1_hash(data))*4} 位)")
    print(f"SHA-256: {sha256_hash(data)}  ({len(sha256_hash(data))*4} 位)")
    print(f"SHA-512: {sha512_hash(data)}  ({len(sha512_hash(data))*4} 位)")
    
    print("\n=== 雪崩效应演示 ===")
    data1 = "Hello, World"
    data2 = "Hello, World!"  # 只差一个字符
    
    hash1 = sha256_hash(data1.encode("utf-8"))
    hash2 = sha256_hash(data2.encode("utf-8"))
    
    print(f"字符串1: {data1}")
    print(f"字符串2: {data2}")
    print(f"SHA-256 1: {hash1}")
    print(f"SHA-256 2: {hash2}")
    
    # 计算差异位数
    diff = sum(1 for a, b in zip(hash1, hash2) if a != b)
    print(f"哈希值差异: {diff} 个字符不同（共 {len(hash1)} 个字符）")
    print("说明：输入微小变化会导致输出巨大变化，这就是雪崩效应")
```

### 3.3 HMAC 消息认证码

HMAC（Hash-based Message Authentication Code）是基于哈希的消息认证码，用于验证消息的完整性和真实性。

```python
import hmac
import hashlib
import os

def generate_hmac(key: bytes, message: bytes, algorithm: str = "sha256") -> str:
    """
    生成 HMAC
    参数:
        key: 密钥
        message: 消息数据
        algorithm: 哈希算法
    返回:
        HMAC 值（十六进制字符串）
    """
    h = hmac.new(key, message, algorithm)
    return h.hexdigest()

def verify_hmac(key: bytes, message: bytes, hmac_value: str, algorithm: str = "sha256") -> bool:
    """
    验证 HMAC
    使用 hmac.compare_digest 防止时序攻击
    """
    expected = generate_hmac(key, message, algorithm)
    return hmac.compare_digest(expected, hmac_value)

# ========== 使用示例 ==========
if __name__ == "__main__":
    print("=== HMAC 消息认证码演示 ===")
    
    # 共享密钥（双方事先约定）
    key = b"my_secret_key_12345"
    
    # 消息
    message = "转账 10000 元给张三".encode("utf-8")
    
    # 发送方生成 HMAC
    hmac_value = generate_hmac(key, message)
    print(f"消息: {message.decode('utf-8')}")
    print(f"HMAC-SHA256: {hmac_value}")
    
    # 接收方验证 HMAC
    is_valid = verify_hmac(key, message, hmac_value)
    print(f"验证结果: {'通过' if is_valid else '失败'}")
    
    # 演示：消息被篡改
    print("\n=== 演示防篡改 ===")
    tampered_message = "转账 100000 元给张三".encode("utf-8")
    is_valid_tampered = verify_hmac(key, tampered_message, hmac_value)
    print(f"篡改消息后验证结果: {'通过' if is_valid_tampered else '失败'}")
    print("说明：没有密钥的人无法生成正确的 HMAC，可防止篡改和伪造")
    
    print("\nHMAC vs 数字签名：")
    print("- HMAC：对称密钥，速度快，双方共享密钥")
    print("- 数字签名：非对称密钥，可验证身份，防止抵赖")
```

### 3.4 密码哈希（Bcrypt）

普通哈希不适合存储密码，因为可以用彩虹表破解。密码哈希需要使用专门的算法。

```python
import bcrypt

def hash_password(password: str) -> bytes:
    """
    使用 bcrypt 哈希密码
    特点：
    1. 自动加盐（salt）
    2. 可调节计算强度（cost factor）
    3. 计算慢，抗暴力破解
    """
    # gensalt() 生成随机盐
    # rounds 参数控制计算强度，默认 12，值越大越慢越安全
    salt = bcrypt.gensalt(rounds=12)
    hashed = bcrypt.hashpw(password.encode("utf-8"), salt)
    return hashed

def verify_password(password: str, hashed: bytes) -> bool:
    """
    验证密码
    """
    return bcrypt.checkpw(password.encode("utf-8"), hashed)

# ========== 使用示例 ==========
if __name__ == "__main__":
    print("=== 密码哈希演示（bcrypt）===")
    
    password = "my_password_123"
    
    # 哈希密码
    hashed = hash_password(password)
    print(f"原始密码: {password}")
    print(f"哈希结果: {hashed.decode('utf-8')}")
    print(f"哈希长度: {len(hashed)} 字节（包含算法、cost、salt、hash）")
    
    # 验证正确密码
    is_valid = verify_password(password, hashed)
    print(f"\n验证正确密码: {'成功' if is_valid else '失败'}")
    
    # 验证错误密码
    is_valid_wrong = verify_password("wrong_password", hashed)
    print(f"验证错误密码: {'成功' if is_valid_wrong else '失败'}")
    
    # 演示：每次哈希结果不同（因为盐不同）
    print("\n=== 自动加盐演示 ===")
    hashed2 = hash_password(password)
    print(f"第一次哈希: {hashed.decode('utf-8')}")
    print(f"第二次哈希: {hashed2.decode('utf-8')}")
    print(f"两次哈希是否相同: {hashed == hashed2}")
    print("说明：每次加盐不同，所以哈希结果不同，但都能验证同一个密码")
```

### 4.1 国密算法概述

国密算法是中国国家密码管理局发布的一系列密码算法标准。

| 算法 | 类型 | 说明 |
|------|------|------|
| SM1 | 对称加密 | 硬件实现，不公开算法 |
| SM2 | 非对称加密 | 基于椭圆曲线，类似 ECC |
| SM3 | 哈希算法 | 输出 256 位，类似 SHA-256 |
| SM4 | 对称加密 | 分组密码，类似 AES |
| SM9 | 标识密码 | 基于身份的密码体制 |
| ZUC | 序列密码 | 流密码算法 |

#### 4.2.1 SM2 非对称加密

```python
from gmssl import sm2, func
import os

# ========== SM2 密钥生成 ==========

def generate_sm2_keypair() -> tuple[str, str]:
    """
    生成 SM2 密钥对
    返回:
        (私钥 hex, 公钥 hex)
    """
    # 生成 256 位随机私钥
    private_key = func.random_hex(64)  # 64 个 hex 字符 = 256 位 = 32 字节
    
    # 通过私钥计算公钥
    sm2_crypt = sm2.CryptSM2(
        public_key="",
        private_key=private_key
    )
    public_key = sm2_crypt._kg(int(private_key, 16), sm2_crypt.ecc_table['g'])
    
    return private_key, public_key

# ========== SM2 加密解密 ==========

def sm2_encrypt(public_key: str, plaintext: bytes) -> str:
    """
    SM2 加密
    参数:
        public_key: 公钥（hex 字符串）
        plaintext: 明文数据
    返回:
        密文（hex 字符串）
    """
    sm2_crypt = sm2.CryptSM2(
        public_key=public_key,
        private_key=""
    )
    # SM2 加密需要随机数
    k = func.random_hex(64)
    ciphertext = sm2_crypt.encrypt(plaintext, k)
    return ciphertext

def sm2_decrypt(private_key: str, ciphertext: str) -> bytes:
    """
    SM2 解密
    参数:
        private_key: 私钥（hex 字符串）
        ciphertext: 密文（hex 字符串）
    返回:
        明文数据
    """
    sm2_crypt = sm2.CryptSM2(
        public_key="",
        private_key=private_key
    )
    plaintext = sm2_crypt.decrypt(ciphertext)
    return plaintext

# ========== 使用示例 ==========

    print(f"\n明文: {plaintext.decode('utf-8')}")

    print(f"密文（hex）: {ciphertext[:64]}...")
    
    # 解密
```

## 五、数据库加密

### 5.1 数据库加密方式对比

| 加密方式 | 说明 | 优点 | 缺点 |
|----------|------|------|------|
| **透明数据加密（TDE）** | 数据库层面自动加密解密，应用无感知 | 应用无需改造、实施简单 | 粒度粗、无法防内部DBA |
| **字段级加密** | 对敏感字段单独加密 | 粒度细、灵活 | 需要改造应用、影响查询 |
| **文件系统加密** | 操作系统或文件系统层面加密 | 透明、不影响应用 | 粒度粗、只防物理窃取 |
| **应用层加密** | 应用程序在写入前加密 | 最灵活、最安全 | 开发量大、维护复杂 |

### 5.2 透明数据加密（TDE）

**原理**：在数据写入磁盘时自动加密，读取时自动解密，对应用程序完全透明。

**MySQL TDE 配置示例**：


### 5.3 字段级加密

**原理**：在应用层对敏感字段进行加密后存储，查询时解密。

```python
import pymysql
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os
import base64

class FieldEncryption:
    """
    数据库字段加密工具类
    使用 AES-256-GCM 加密敏感字段
    """
    
    def __init__(self, key: bytes):
        """
        初始化加密器
        参数:
            key: 256 位（32 字节）加密密钥
        """
        self.aesgcm = AESGCM(key)
    
    def encrypt_field(self, plaintext: str) -> str:
        """
        加密字段
        参数:
            plaintext: 明文字符串
        返回:
            Base64 编码的密文字符串（包含 nonce + ciphertext + tag）
        """
        if plaintext is None:
            return None
        
        nonce = os.urandom(12)
        ciphertext = self.aesgcm.encrypt(nonce, plaintext.encode("utf-8"), None)
        # 将 nonce 和密文拼接后 base64 编码，方便存储
        combined = nonce + ciphertext
        return base64.b64encode(combined).decode("ascii")
    
    def decrypt_field(self, encrypted: str) -> str:
        """
        解密字段
        参数:
            encrypted: Base64 编码的密文字符串
        返回:
            明文字符串
        """
        if encrypted is None:
            return None
        
        combined = base64.b64decode(encrypted)
        # 前 12 字节是 nonce，后面是密文+标签
        nonce = combined[:12]
        ciphertext = combined[12:]
        plaintext = self.aesgcm.decrypt(nonce, ciphertext, None)
        return plaintext.decode("utf-8")
```

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os
import struct

class FileEncryptor:
    """
    文件加密工具类
    使用 AES-256-GCM 加密文件
    文件格式：
    [12字节 nonce][4字节关联数据长度][关联数据][密文+16字节tag]
    """
    
    def __init__(self, key: bytes):
        """
        初始化
        参数:
            key: 256 位（32 字节）加密密钥
        """
        if len(key) != 32:
            raise ValueError("密钥必须是 32 字节（256 位）")
        self.aesgcm = AESGCM(key)
    
    def encrypt_file(self, input_path: str, output_path: str, 
                     associated_data: bytes = b"") -> None:
        """
        加密文件
        参数:
            input_path: 输入文件路径（明文）
            output_path: 输出文件路径（密文）
            associated_data: 关联数据（如文件名、元数据）
        """
        # 生成随机 nonce
        nonce = os.urandom(12)
        
        # 读取明文文件
        with open(input_path, "rb") as f:
            plaintext = f.read()
        
        # 加密
        ciphertext = self.aesgcm.encrypt(nonce, plaintext, associated_data)
        
        # 写入加密文件
        # 格式：nonce(12) + ad_length(4) + associated_data + ciphertext
        with open(output_path, "wb") as f:
            f.write(nonce)                                      # 12 字节 nonce
            f.write(struct.pack("<I", len(associated_data)))    # 4 字节关联数据长度
            f.write(associated_data)                            # 关联数据
            f.write(ciphertext)                                 # 密文 + tag
    
    def decrypt_file(self, input_path: str, output_path: str) -> bytes:
        """
        解密文件
        参数:
            input_path: 输入文件路径（密文）
            output_path: 输出文件路径（明文）
        返回:
            关联数据
        """
        with open(input_path, "rb") as f:
            # 读取 nonce
            nonce = f.read(12)
            
            # 读取关联数据长度
            ad_length_data = f.read(4)
            ad_length = struct.unpack("<I", ad_length_data)[0]
            
            # 读取关联数据
            associated_data = f.read(ad_length)
            
            # 读取密文
            ciphertext = f.read()
        
        # 解密
        plaintext = self.aesgcm.decrypt(nonce, ciphertext, associated_data)
        
        # 写入明文文件
        with open(output_path, "wb") as f:
            f.write(plaintext)
        
        return associated_data

# ========== 大文件分块加密（内存友好） ==========

def encrypt_large_file(key: bytes, input_path: str, output_path: str, 
                       chunk_size: int = 1024 * 1024) -> None:
    """
    大文件分块加密（适合 GB 级文件，避免内存溢出）
    使用 CTR 模式（这里用 GCM 处理每个块）
    注意：生产环境建议使用专门的大文件加密方案
    """
    aesgcm = AESGCM(key)
    
    # 文件头：nonce + 总块数
    base_nonce = os.urandom(12)
    
    file_size = os.path.getsize(input_path)
    total_chunks = (file_size + chunk_size - 1) // chunk_size
    
    with open(input_path, "rb") as fin, open(output_path, "wb") as fout:
        # 写入文件头
        fout.write(base_nonce)
        fout.write(struct.pack("<Q", total_chunks))
        fout.write(struct.pack("<Q", file_size))
        fout.write(struct.pack("<I", chunk_size))
        
        chunk_index = 0
        while True:
            chunk = fin.read(chunk_size)
            if not chunk:
                break
            
            # 每个块使用不同的 nonce（基于 base_nonce + 块索引）
            # 注意：这是简化实现，实际应使用更严谨的方案
            chunk_nonce = base_nonce[:8] + struct.pack("<I", chunk_index)
            
            # 关联数据：块索引（用于验证块顺序）
            ad = struct.pack("<Q", chunk_index)
            
            # 加密块
            encrypted_chunk = aesgcm.encrypt(chunk_nonce, chunk, ad)
            
            # 写入块长度 + 加密块
            fout.write(struct.pack("<I", len(encrypted_chunk)))
            fout.write(encrypted_chunk)
            
            chunk_index += 1

# ========== 使用示例 ==========
if __name__ == "__main__":
    print("=== 文件加密演示 ===")
    
    # 生成密钥
    key = AESGCM.generate_key(bit_length=256)
    encryptor = FileEncryptor(key)
    
    # 创建测试文件
    test_content = "这是一份机密文档\n包含敏感数据...\n".encode("utf-8") * 100
    with open("test_document.txt", "wb") as f:
        f.write(test_content)
    print("测试文件已创建: test_document.txt")
    print(f"文件大小: {len(test_content)} 字节")
    
    # 加密文件
    metadata = b"filename=机密文档.txt;owner=张三;classification=confidential"
    encryptor.encrypt_file(
        input_path="test_document.txt",
        output_path="test_document.enc",
        associated_data=metadata
    )
    print(f"\n加密文件已生成: test_document.enc")
    print(f"加密后大小: {os.path.getsize('test_document.enc')} 字节")
    
    # 解密文件

    # 验证
```

### 7.1 密码安全存储

```python
import bcrypt
import secrets
import hashlib

class PasswordManager:
    """
    密码安全管理类
    最佳实践：使用 bcrypt/argon2 等专门的密码哈希算法
    """
    
    @staticmethod
    def hash_password(password: str) -> str:
        """
        哈希密码
        自动加盐，使用 bcrypt
        """
        # gensalt 的 rounds 参数控制计算强度
        # 默认 12，建议根据服务器性能调整到 12-15
        salt = bcrypt.gensalt(rounds=12)
        hashed = bcrypt.hashpw(password.encode("utf-8"), salt)
        return hashed.decode("utf-8")
    
    @staticmethod
    def verify_password(password: str, hashed_password: str) -> bool:
        """
        验证密码
        """
        try:
            return bcrypt.checkpw(
                password.encode("utf-8"),
                hashed_password.encode("utf-8")
            )
        except Exception:
            return False
    
    @staticmethod
    def generate_reset_token() -> tuple[str, str]:
        """
        生成密码重置令牌
        返回: (原始令牌, 令牌哈希)
        数据库只存储哈希值，防止数据库泄露导致令牌被滥用
        """
        # 生成 32 字节随机令牌
        token = secrets.token_hex(32)
        # 存储哈希值
        token_hash = hashlib.sha256(token.encode()).hexdigest()
        return token, token_hash

# ========== 错误示例 vs 正确示例 ==========

def password_storage_bad_example(password: str) -> str:
    """
    ❌ 错误示例：直接使用 MD5/SHA-256 不加盐
    风险：彩虹表攻击、暴力破解
    """
    return hashlib.md5(password.encode()).hexdigest()

def password_storage_good_example(password: str) -> str:
    """
    ✅ 正确示例：使用 bcrypt（自动加盐、计算慢）
    """
    return PasswordManager.hash_password(password)
```

### 7.2 API 接口签名验证

```python
import hmac
import hashlib
import time
import secrets

class ApiSignature:
    """
    API 接口签名验证
    防止：重放攻击、数据篡改、伪造请求
    """
    
    @staticmethod
    def generate_signature(api_key: str, api_secret: str, 
                           timestamp: str, method: str, 
                           path: str, body: str = "") -> str:
        """
        生成 API 请求签名
        
        签名算法：
        signature = HMAC-SHA256(api_secret, string_to_sign)
        
        string_to_sign 组成：
        method + "\n" +
        path + "\n" +
        timestamp + "\n" +
        body_hash
        """
        # 计算请求体哈希
        body_hash = hashlib.sha256(body.encode("utf-8")).hexdigest()
        
        # 构造待签名字符串
        string_to_sign = f"{method}\n{path}\n{timestamp}\n{body_hash}"
        
        # 计算 HMAC 签名
        signature = hmac.new(
            api_secret.encode("utf-8"),
            string_to_sign.encode("utf-8"),
            hashlib.sha256
        ).hexdigest()
        
        return signature
    
    @staticmethod
    def verify_signature(api_key: str, api_secret: str,
                         timestamp: str, method: str,
                         path: str, signature: str, 
                         body: str = "",
                         time_window: int = 300) -> bool:
        """
        验证 API 请求签名
        
        参数:
            time_window: 时间窗口（秒），防止重放攻击
        """
        # 1. 检查时间戳是否在有效窗口内
        try:
            request_time = int(timestamp)
        except ValueError:
            return False
        
        current_time = int(time.time())
        if abs(current_time - request_time) > time_window:
            return False  # 请求过期，可能是重放攻击
        
        # 2. 重新计算签名
        expected_signature = ApiSignature.generate_signature(
            api_key, api_secret, timestamp, method, path, body
        )
        
        # 3. 比较签名（使用恒定时间比较，防止时序攻击）
        return hmac.compare_digest(expected_signature, signature)

# ========== 使用示例 ==========
```

### 7.3 敏感数据内存保护

```python
import ctypes
import os

def secure_memzero(buffer: bytearray) -> None:
    """
    安全内存清零
    防止编译器优化掉清零操作
    
    用途：敏感数据使用完毕后，立即从内存中清除
    """
    if not buffer:
        return
    
    # 使用 ctypes 确保不会被优化掉
    buffer_len = len(buffer)
    ctypes.memset(
        ctypes.addressof(ctypes.c_char.from_buffer(buffer)),
        0,
        buffer_len
    )

class SecureString:
    """
    安全字符串类
    减少敏感数据在内存中的暴露时间
    
    注意：Python 层面无法完全保证内存安全，
    真正的高安全场景应使用 C 扩展或 HSM
    """
    
    def __init__(self, value: str):
        self._data = bytearray(value.encode("utf-8"))
        self._is_destroyed = False
    
    def get_value(self) -> str:
        """获取字符串值（使用后应尽快销毁）"""
        if self._is_destroyed:
            raise ValueError("SecureString 已被销毁")
        return self._data.decode("utf-8")
    
    def destroy(self) -> None:
        """销毁敏感数据，清零内存"""
        if not self._is_destroyed:
            secure_memzero(self._data)
            self._is_destroyed = True
    
    def __del__(self):
        """析构时自动销毁"""
        if hasattr(self, '_data') and not self._is_destroyed:
            self.destroy()

# 使用示例
def process_sensitive_data():
    """处理敏感数据的函数"""
    password = SecureString("my_secret_password")
    
    try:
        # 使用密码
        pwd = password.get_value()
        # ... 进行认证等操作 ...
        print(f"正在使用密码: {pwd[:3]}***")
    finally:
        # 确保使用完后销毁
        password.destroy()
```

| 哈希算法 | SHA-256、SHA-512、SM3 | MD5、SHA-1 |
| 密码哈希 | Argon2、Bcrypt、Scrypt | MD5、SHA-1、SHA-256（不加盐） |
| 消息认证 | HMAC-SHA256、GCM | 无认证的加密 |

### 8.2 密钥管理

1. **密钥生成**
   - 使用密码学安全的随机数生成器（CSPRNG）
   - Python 中使用 `os.urandom()` 或 `secrets` 模块
   - 不要使用 `random` 模块生成密钥

2. **密钥存储**
   - 不要硬编码密钥到代码中
   - 使用专业的密钥管理系统（KMS）
   - 硬件安全模块（HSM）存储根密钥
   - 密钥分级管理：根密钥 → 工作密钥 → 数据密钥

3. **密钥轮换**
   - 定期更换密钥（如每 90 天）
   - 密钥泄露后立即更换
   - 保留历史密钥用于解密旧数据

4. **密钥销毁**
   - 密钥不再使用时安全销毁
   - 确保使用该密钥加密的数据已解密或重新加密

### 8.3 常见错误

| 错误做法 | 风险 | 正确做法 |
|----------|------|----------|
| 使用 ECB 模式 | 明文模式泄露 | 使用 GCM/CBC 模式 |
| 硬编码密钥 | 密钥泄露 | 使用 KMS/环境变量 |
| MD5 存密码 | 彩虹表破解 | 使用 bcrypt/argon2 |
| 不加盐哈希 | 彩虹表攻击 | 加盐哈希（每个用户独立盐） |
| 自己实现加密 | 算法漏洞 | 使用标准库和成熟方案 |
| 随机数用 random | 可预测 | 使用 secrets/os.urandom |
| 缺少完整性校验 | 数据篡改 | 使用 GCM/HMAC |

### 8.4 实战案例

**案例：某电商平台数据加密改造**

**背景**：
- 平台有 5000 万用户，存储了大量用户敏感信息
- 之前数据库使用明文存储，存在数据泄露风险
- 需要满足等保三级和《个人信息保护法》要求

**改造方案**：

1. **密码存储**
   - 原方案：MD5 哈希
   - 新方案：bcrypt（rounds=12）
   - 迁移：用户登录时逐步升级哈希

2. **敏感字段加密**
   - 身份证号、银行卡号、手机号使用 AES-256-GCM 字段级加密
   - 密钥存储在 KMS 中，应用通过 API 获取
   - 建立密钥轮换机制（每 90 天轮换）

3. **数据库加密**
   - 启用 MySQL TDE 透明数据加密
   - 备份数据加密存储
   - 数据库访问审计

4. **传输加密**
   - 全站 HTTPS（TLS 1.3）
   - 内部服务间 mTLS
   - API 接口签名认证

**改造效果**：
- 通过等保三级测评
- 满足《个人信息保护法》合规要求
- 即使数据库被拖库，敏感数据也无法解密
- 建立了完善的密钥管理体系
