# 数据库安全审计与扫描

### 7.1 数据库漏洞扫描工具

| 工具 | 特点 |
|------|------|
| **Nessus** | 通用漏洞扫描，含数据库插件检查弱口令/配置 |
| **DBScan** | 专业数据库扫描，支持多种数据库类型 |
| **sqlmap 检测模式** | 专注 SQL 注入检测与利用 |
| **GreenSQL/DBHawk** | 数据库安全评估与管理 |

```bash
# sqlmap 检测模式（仅检测不利用）
sqlmap -u "http://target.com/page?id=1" --batch --level 3 --risk 1
# 列出数据库
sqlmap -u "http://target.com/page?id=1" --dbs --batch
# 检查是否 DBA
sqlmap -u "http://target.com/page?id=1" --is-dba --batch
```

### 7.2 数据库审计系统

数据库审计系统（DAS）核心功能：

- **全量 SQL 审计**：记录所有 SQL 操作，包含来源 IP、执行账号、执行时间
- **实时告警**：检测 SQL 注入、批量导出、越权访问
- **合规报表**：满足等保/PCI-DSS 审计要求
- **旁路部署**：通过镜像流量或 Agent 采集，不影响业务

### 7.3 敏感数据发现

```sql
-- 通过数据字典发现敏感字段
SELECT TABLE_NAME, COLUMN_NAME, DATA_TYPE
FROM INFORMATION_SCHEMA.COLUMNS
WHERE COLUMN_NAME LIKE '%password%'
   OR COLUMN_NAME LIKE '%idcard%'
   OR COLUMN_NAME LIKE '%phone%'
   OR COLUMN_NAME LIKE '%email%';

-- 使用正则匹配验证字段内容
SELECT id, phone,
  CASE WHEN phone REGEXP '^1[3-9][0-9]{9}$' THEN 'valid_phone' ELSE 'invalid' END
FROM users LIMIT 100;
```
