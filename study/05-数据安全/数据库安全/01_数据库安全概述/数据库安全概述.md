# 数据库安全概述

### 1.1 数据库安全三大维度

数据库安全围绕 **CIA 三要素** 展开：

| 维度 | 含义 | 安全目标 |
|------|------|----------|
| **机密性 (Confidentiality)** | 防止未授权访问敏感数据 | 加密存储、访问控制、脱敏 |
| **完整性 (Integrity)** | 防止数据被篡改或非法修改 | 校验和、审计日志、权限最小化 |
| **可用性 (Availability)** | 确保合法用户能及时访问数据 | 高可用架构、容灾备份、防 DDoS |

### 1.2 常见数据库安全威胁

- **SQL 注入**：通过构造恶意 SQL 语句窃取或篡改数据
- **弱口令/默认口令**：如 MySQL 的 root 空密码、MongoDB 的无认证
- **权限提升**：利用数据库漏洞从普通用户提升为 DBA
- **未授权访问**：数据库端口暴露在公网，无认证即可连接
- **数据泄露**：备份文件被盗、dump 导出未加密
- **勒索软件**：加密数据库文件并勒索赎金

### 1.3 数据库安全法规要求

| 法规 | 关键要求 |
|------|----------|
| **等保 2.0** | 数据库需进行身份鉴别、访问控制、安全审计、数据完整性/保密性保护 |
| **GDPR** | 个人数据处理需合法依据，数据主体有权访问/删除/可携其数据 |
| 《数据安全法》 | 实行数据分类分级保护，重要数据需重点保护，开展数据安全风险评估 |
