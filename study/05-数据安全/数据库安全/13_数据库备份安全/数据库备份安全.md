# 数据库备份安全

### 13.1 备份加密与验证

```bash
# MySQL备份加密
# 方法1: 使用mysqldump + openssl加密
mysqldump -u root -p --all-databases | \
    openssl enc -aes-256-cbc -salt -pbkdf2 \
    -pass pass:StrongEncryptionPassword \
    -out backup_$(date +%Y%m%d).sql.enc

# 解密恢复
openssl enc -d -aes-256-cbc -pbkdf2 \
    -pass pass:StrongEncryptionPassword \
    -in backup_20260915.sql.enc | \
    mysql -u root -p

# 方法2: 使用xtrabackup +加密
xtrabackup --backup --target-dir=/backup/full \
    --encrypt=AES-256 \
    --encrypt-key-file=/etc/mysql/backup_key

# PostgreSQL备份加密
pg_dump -U postgres -Fc dbname | \
    openssl enc -aes-256-cbc -salt -pbkdf2 \
    -pass pass:StrongPassword \
    -out pg_backup_$(date +%Y%m%d).dump.enc

# SQL Server备份加密
BACKUP DATABASE TargetDB
TO DISK = '/backup/target.bak'
WITH ENCRYPTION(ALGORITHM = AES_256, SERVER CERTIFICATE = BackupCert);

# 备份完整性验证
sha256sum backup_20260915.sql.enc > backup_checksum.txt
# 恢复时验证
sha256sum -c backup_checksum.txt
```

### 13.2 备份策略与RPO

```text
备份策略对比:

| 备份类型 | 频率 | RPO | 存储成本 | 恢复速度 | 适用场景 |
|----------|------|-----|----------|----------|----------|
| 全量备份 | 每周 | 7天 | 高 | 快 | 基础备份 |
| 增量备份 | 每天 | 1天 | 低 | 慢 | 日常备份 |
| 差异备份 | 每天 | 1天 | 中 | 中 | 折中方案 |
| 事务日志 | 每5分钟 | 5分钟 | 低 | 最慢 | 高可用要求 |
| 快照备份 | 每小时 | 1小时 | 中 | 最快 | 虚拟化环境 |

3-2-1备份原则:
  - 3份备份副本
  - 2种不同介质
  - 1份异地存储

安全要求:
  - 所有备份必须加密
  - 备份介质访问控制
  - 定期恢复演练
  - 备份完整性校验
  - 备份保留策略(保留90天)
```
