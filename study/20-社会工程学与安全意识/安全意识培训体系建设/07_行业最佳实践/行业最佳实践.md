# 行业最佳实践

### 7.1 SANS Security Awareness

```
SANS安全意识成熟度模型：

┌──────────────────────────────────────────────────────┐
│           SANS Security Awareness Maturity Model      │
├──────────┬───────────────────────────────────────────┤
│  级别     │              特征                          │
├──────────┼───────────────────────────────────────────┤
│  Level 1 │  初始阶段                                  │
│  初始    │  - 合规驱动的年度培训                       │
│          │  - 无定制化内容                             │
│          │  - 无持续教育                               │
│          │  - 无度量指标                               │
│          │  - 无专人负责                               │
├──────────┼───────────────────────────────────────────┤
│  Level 2 │  合规导向                                  │
│  合规    │  - 满足合规要求的培训                       │
│          │  - 基础钓鱼模拟                             │
│          │  - 基本完成率跟踪                           │
│          │  - 兼职人员管理                             │
│          │  - 标准化培训内容                           │
├──────────┼───────────────────────────────────────────┤
│  Level 3 │  行为导向                                  │
│  行为    │  - 分层/分岗位培训                          │
│          │  - 定期钓鱼模拟                             │
│          │  - 行为度量（点击率、报告率）                │
│          │  - 专职人员负责                             │
│          │  - 持续教育内容                             │
│          │  - 基础安全文化推广                         │
├──────────┼───────────────────────────────────────────┤
│  Level 4 │  文化导向                                  │
│  文化    │  - 安全融入工作流程                         │
│          │  - 安全冠军计划                             │
│          │  - 个性化培训                               │
│          │  - 全面度量体系                             │
│          │  - 管理层深度参与                           │
│          │  - 正向激励文化                             │
│          │  - 部门间安全竞争                           │
├──────────┼───────────────────────────────────────────┤
│  Level 5 │  持续改进                                  │
│  成熟    │  - 基于数据的持续优化                       │
│          │  - 威胁情报驱动的内容更新                   │
│          │  - 安全成为企业DNA                          │
│          │  - 员工主动报告和改进                       │
│          │  - 行业标杆                                 │
│          │  - 创新培训方式                             │
└──────────┴───────────────────────────────────────────┘

SANS关键建议:
1. 基于风险设计培训内容（而非仅合规驱动）
2. 持续性教育优于一次性培训
3. 度量行为改变而非仅培训完成
4. 正向激励优于惩罚
5. 安全文化需要自上而下推动
6. 个性化培训优于"一刀切"
```

### 7.2 NIST SP 800-50

```
NIST SP 800-50 "Building an Information Technology Security Awareness 
and Training Program" 关键要素：

1. 需求评估
   ├── 识别组织的安全意识需求
   ├── 评估当前安全意识水平
   ├── 识别高风险群体
   └── 确定合规要求

2. 培训计划设计
   ├── 制定培训目标和范围
   ├── 确定目标受众和分层
   ├── 选择培训方法
   ├── 开发培训内容
   └── 制定评估方法

3. 培训实施
   ├── 管理层支持获取
   ├── 资源分配
   ├── 日程安排
   ├── 交付培训
   └── 参与度管理

4. 培训后评估
   ├── 即时评估（测试/调查）
   ├── 短期评估（行为观察）
   ├── 长期评估（事件减少）
   └── 持续改进

NIST角色/职责矩阵:
├── CIO/CISO: 策略制定、资源分配
├── 安全意识经理: 计划设计、执行、评估
├── 部门管理者: 支持参与、资源保障
├── HR: 培训集成、入职培训
├── IT: 工具支持、技术配合
└── 全体员工: 积极参与、实践应用
```

### 7.3 ISO 27001 人为安全控制

```
ISO 27001:2022 附录A 人为安全控制（A.6）：

A.6.1 安全意识培训
├── 确保所有员工了解安全责任
├── 按岗位提供适当培训
├── 定期更新培训内容
└── 记录培训活动

A.6.2 身份验证
├── 正式入职流程中的安全验证
├── 背景调查（根据风险等级）
├── 保密协议
└── 条款和条件包含安全责任

A.6.3 信息传递事件管理
├── 建立报告渠道
├── 快速响应机制
├── 事件分类和处理
└── 经验教训分享

A.6.4 恶意代码防护
├── 用户对恶意软件的意识
├── 报告可疑活动
└── 遵守安全程序

A.6.5 安全远程工作
├── 远程工作安全培训
├── VPN使用培训
├── 物理安全意识
└── 设备安全使用

A.6.6 安全决策
├── 信息分类和处理的意识
├── 数据处理最佳实践
└── 非披露信息处理
```

### 7.4 其他框架与标准

```
其他安全意识相关框架：

1. NIST NICE Framework
   - 定义网络安全工作角色和能力
   - 包含安全意识教育相关能力
   - 用于职业发展路径设计

2. ENISA Awareness Raising
   - 欧盟网络与信息安全局指南
   - 面向不同受众的安全意识材料
   - 包含评估方法论

3. PCI DSS Requirement 12.6
   - 支付卡行业数据安全标准
   - 要求对处理卡数据的员工进行安全意识培训
   - 至少每年1次

4. CIS Controls
   - Control 14: Security Awareness and Skills Training
   - 建立和维护安全意识计划
   - 针对钓鱼和社会工程的专项培训

5. MITRE ATT&CK
   - Initial Access战术中包含钓鱼相关技术
   - 可用于指导培训内容与真实威胁对齐
   - 帮助理解攻击者的TTP
```
