# 培训方式

### 3.1 线上课程

```
线上课程设计标准：

课程结构:
├── 学习目标（1分钟）
├── 案例引入（2-3分钟）
├── 核心内容讲解（10-15分钟）
├── 互动练习（5分钟）
├── 知识检测测试（5分钟）
├── 要点总结（2分钟）
└── 资源链接（推荐阅读）

技术要求:
├── 支持PC和移动端
├── 支持中文字幕
├── 学习进度跟踪
├── 完成证书生成
├── LMS集成（SCORM/xAPI）
└── 数据导出（完成率、测试成绩）

课程开发工具:
├── Articulate Storyline 360（专业课件开发）
├── Adobe Captivate（交互式课件）
├── Camtasia（屏幕录制+编辑）
├── Canva（视觉设计）
└── 自研平台（基于Web技术）

内容更新频率:
├── 基础课程: 每年更新1次
├── 钓鱼趋势: 每季度更新
├── 新威胁专题: 随时发布
└── 合规要求: 法规变更后30天内更新
```

### 3.2 面对面工作坊

```
安全工作坊设计模板：

工作坊名称: 钓鱼攻击体验工作坊
时长: 90分钟
人数: 15-20人
形式: 互动+实操

┌──────────────────────────────────────────────┐
│              工作坊流程                        │
├──────────────────────────────────────────────┤
│                                              │
│  环节1: 开场与破冰（10分钟）                   │
│  ├── 安全意识现状调查（互动投票）              │
│  ├── 分享一个近期安全事件                     │
│  └── 设定工作坊目标                           │
│                                              │
│  环节2: 钓鱼攻击体验（20分钟）                 │
│  ├── 展示真实钓鱼邮件案例                     │
│  ├── 小组讨论：这些邮件有什么可疑之处？        │
│  ├── 揭示钓鱼邮件的欺骗手法                   │
│  └── 与真实攻击对比                           │
│                                              │
│  环节3: 钓鱼识别技能实操（30分钟）             │
│  ├── 发给每人5封"可疑邮件"                    │
│  ├── 独立分析每封邮件                         │
│  ├── 小组讨论分析结果                         │
│  ├── 讲师点评和讲解                           │
│  └── 总结"钓鱼识别清单"                      │
│                                              │
│  环节4: 正确响应演练（15分钟）                 │
│  ├── 演示报告流程                             │
│  ├── 实际操作报告工具                         │
│  ├── 角色扮演：接到钓鱼电话如何应对           │
│  └── Q&A                                    │
│                                              │
│  环节5: 总结与行动承诺（15分钟）               │
│  ├── 要点回顾                                 │
│  ├── 个人安全行动计划                         │
│  └── 反馈问卷                                 │
│                                              │
└──────────────────────────────────────────────┘
```

### 3.3 钓鱼模拟

```
钓鱼模拟培训设计：

模拟类型:

1. 基线模拟（Baseline）
   - 目的: 评估当前安全意识水平
   - 时机: 培训项目启动前
   - 场景: 通用钓鱼场景（密码过期）
   - 后续: 根据结果设计培训内容

2. 教育性模拟（Educational）
   - 目的: 在实际场景中学习
   - 时机: 培训后2-4周
   - 场景: 与培训内容相关的场景
   - 后续: 点击者自动进入补救培训

3. 持续性模拟（Continuous）
   - 目的: 保持警惕性
   - 时机: 每月1次微模拟
   - 场景: 不同场景轮换
   - 后续: 点击者进入微培训

4. 专项模拟（Targeted）
   - 目的: 针对特定威胁演练
   - 时机: 出现新威胁时
   - 场景: 模拟最新真实攻击
   - 后续: 全员通知+培训更新

模拟后处理:

点击者处理流程:
├── 立即显示教育页面（不惩罚）
├── 自动注册1分钟微培训
├── 记录但不公开个人数据
├── 累计3次以上点击 → 专项培训
└── 管理者收到部门汇总数据（非个人数据）

报告者处理:
├── 即时反馈感谢
├── 月度抽奖奖励
├── 部门报告率排名
└── 公开表扬（征得同意后）
```
