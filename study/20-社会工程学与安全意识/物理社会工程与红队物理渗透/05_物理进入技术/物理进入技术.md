# 物理进入技术

### 4.1 尾随（Tailgating）技巧

尾随，又称"跟屁虫"攻击，是指在合法持卡人刷卡开门后，攻击者紧跟其后进入门禁区域的攻击方法。这是最简单也最有效的物理进入技术之一，利用的是人们的礼貌习惯和嫌麻烦的心理。

#### 4.1.1 尾随的时机选择

**最佳时机：**

- **早高峰上班时间**：人员密集，大家都赶时间，不太会注意身后的人
- **午餐时间**：进出人员多，且员工状态相对放松
- **下班时间**：人们急于离开，注意力不集中
- **会议结束后**：大批人员同时移动，容易混入
- **安保人员换班时**：交接期间安保可能出现空档

**时机选择的要点：**

- 选择人流量适中的时机——人太少容易被注意，人太多可能反而有人警惕
- 确保前面的人是合法进入的员工而不是另一个尾随者
- 注意观察安保人员的注意力方向，选择其分心的时刻

#### 4.1.2 不同场景的尾随方法

**办公楼正门尾随：**

1. 在门禁附近"自然"地等待，假装在看手机或整理东西
2. 观察即将进入的人员，选择看起来面善、随和的目标
3. 当目标刷卡开门时，快步走向门口
4. 在门即将关闭前到达，用手扶住门或直接进入
5. 进入后保持正常步速，不要急于加速离开

**旋转门尾随：**

1. 等待目标进入旋转门的一个格子
2. 在旋转门还没转完一圈时，快速进入下一个格子
3. 保持与目标相近的推进速度
4. 出来后自然地分开

**停车场尾随：**

1. 驾车在停车场入口附近等待
2. 当前面的车辆刷卡或识别车牌抬杆后
3. 紧跟其后驶入，利用抬杆的延迟时间通过
4. 注意保持安全距离，避免追尾

#### 4.1.3 如何自然地融入人流

**外观准备：**

- 穿着与目标公司员工风格相近的服装
- 佩戴工牌（可以是假的，也可以是其他公司的）
- 携带合适的随身物品（笔记本包、咖啡杯等）
- 保持自信的神态和步伐

**行为要点：**

- 不要东张西望，表现得对环境很熟悉
- 可以边走边看手机，表现出忙碌的样子
- 与人群保持相同的步速和方向
- 避免与他人有过多的眼神接触
- 如果有人看你，可以微微点头示意

#### 4.1.4 被质疑时的应对话术

尾随并非每次都能成功，有时会被前面的人或安保人员质疑。提前准备好应对话术非常重要。

**被前面的员工质疑时：**

- "啊不好意思，我卡忘带了，就在这层上班，谢谢啊！"（边说边快步离开）
- "真巧，我也刚到，谢谢啦！"（自然地微笑，把对方的质疑转化为巧合）
- "我是XX部门新来的，卡还在办，麻烦了！"（新员工身份容易获得谅解）

**被安保人员质疑时：**

- "你好，我是XX公司的，来谈合作的，约了XX部门的王经理"（准备好具体的人名和部门）
- "不好意思，我是楼上XX公司的，刚才出去取了个快递"（假装是内部员工）
- "啊我访客登记过了，你看这是我的访客条"（准备好伪造的访客凭证）

**应对原则：**

1. **保持冷静**：不要表现出慌乱，语速平稳
2. **自信自然**：表现得你就应该出现在这里
3. **简短回应**：不要说太多话，言多必失
4. **顺势离开**：回答完后继续往前走，不要停留
5. **准备撤退**：如果对方坚持查验，及时撤退，不要硬闯

### 4.2 假冒身份（Impersonation）

假冒身份是指伪装成具有合法进入权限的角色，从而获得进入权限的攻击方法。这需要更充分的准备，但成功率也更高。

#### 4.2.1 常见伪装角色

**快递员/外卖员：**

- 最常见也最容易成功的伪装
- 快递员几乎可以到达任何办公楼的前台区域
- 很多公司允许快递员进入办公区送件
- 道具简单，容易获取

**维修工/技术人员：**

- 空调维修、水电维修、网络维修、办公设备维修等
- 可以合理地携带工具箱
- 可以进入设备间、机房等敏感区域
- 需要一定的专业知识作为支撑

**清洁工：**

- 清洁人员通常有较大的活动范围
- 工作时间可能在非工作时段
- 不容易引起注意
- 可以合理地进出各个房间

**IT支持人员：**

- 可以合理地接触电脑和网络设备
- 员工通常会配合IT人员的工作
- 可以借机安装恶意软件或硬件
- 需要一定的IT专业知识

**其他角色：**

- 面试者：可以进入前台和会议室区域
- 客户/合作伙伴：可以进入接待区和会议室
- 政府检查人员：消防、卫生、安监等检查人员身份有较高权威性
- 搬家公司：可以合理地搬运大件物品进出

#### 4.2.2 道具准备

**制服：**

- 尽量选择与目标场所常见的制服相似的款式
- 快递员制服可以网购获得
- 维修工制服选择常见的蓝色或灰色工装即可
- 制服上的标识可以自己制作或修改

**工牌：**

- 工牌是身份的直观证明
- 可以制作仿真工牌，包含照片、姓名、部门等信息
- 即使是假工牌，大多数人也不会仔细查看
- 工牌挂绳选择常见的款式和颜色

**工具箱：**

- 维修工角色的标配
- 里面放一些真实的工具（螺丝刀、万用表、钳子等）
- 可以同时隐藏渗透测试工具
- 工具箱本身就具有"通行证"效应

**其他道具：**

- 快递员：快递包裹、快递袋、扫码枪（可以用旧手机代替）
- 外卖员：外卖袋、餐盒
- IT人员：笔记本电脑、网线、测试仪器
- 清洁工：清洁工具、拖把、抹布

#### 4.2.3 角色话术设计

每个角色都需要设计对应的话术，包括：

**身份背景：**

- 姓名（可以使用假名）
- 所属公司
- 工号
- 来这里的原因

**常见问答准备：**

- "你找哪位？" → 准备好具体的联系人姓名
- "你有预约吗？" → "有的，约的X点"或"是你们XX部门的人打电话叫我们来的"
- "你带证件了吗？" → 出示工牌或工作证
- "你们负责人是谁？" → 准备好一个上级的名字和电话

**话术技巧：**

- 使用专业术语增加可信度
- 表现出忙碌和效率感
- 适当抱怨工作量大，增加真实感
- 对于不知道的问题，用"这个我得问一下我们工程师"等方式转移

### 4.3 借口进入（Pretexting）

借口进入是指通过编造一个合理的理由，说服对方允许自己进入的攻击方法。与假冒身份不同，借口进入的核心是"理由"而非"身份"。

#### 4.3.1 常见进入借口与场景

**"找人"借口：**

- "我找XX部门的张经理，约好了的"
- "我是来面试的，请问XX公司在这层吗？"
- "我是XX公司的，来送合同/发票/文件"

**"紧急情况"借口：**

- "我手机落里面了，能不能让我进去拿一下，很快就出来"
- "我钱包/钥匙忘在工位上了，我回去取一下"
- "里面有人找我有急事"

**"公务"借口：**

- "消防检查的，我们来看看消防设施"
- "我们是电信的，来检查线路"
- "物业的，例行巡检"

**"送货/服务"借口：**

- "送水的"
- "送花的"
- "收快递的"
- "外卖"

#### 4.3.2 借口可信度提升技巧

1. **细节增加真实感**：越具体的借口越可信，包括人名、部门、时间、事由等细节
2. **利用权威效应**：提到高管或重要部门的名字，可以降低被质疑的概率
3. **制造紧迫感**：表现出事情很紧急，对方可能来不及仔细核实
4. **情绪控制**：保持平静自信，不要表现出焦虑或紧张
5. **利用同情心**：适当表现出为难或需要帮助的样子，引发对方的同理心
6. **先入为主**：主动开口说明来意，不给对方思考的时间
7. **社会认同**：提到"XX让我来的"、"XX已经同意了"等

### 4.4 翻找垃圾（Dumpster Diving）

翻找垃圾，又称"垃圾箱潜水"，是指通过翻找目标组织的垃圾桶，获取有价值信息的攻击方法。虽然听起来不太雅观，但这是一种非常有效的情报收集手段。

#### 4.4.1 垃圾堆信息价值

企业垃圾桶中可能包含的有价值信息：

- **文档类**：废弃的合同、财务报表、内部备忘录、会议纪要等
- **便签类**：写有密码、账号、服务器地址的便签纸
- **名片类**：员工名片，可用于社会工程攻击
- **快递单**：包含员工姓名、电话、部门等信息
- **废弃设备**：旧硬盘、U盘、手机等，可能包含敏感数据
- **门禁卡**：有时员工会把损坏或过期的门禁卡扔掉
- **包装类**：产品包装上的序列号、配置信息等
- **日程表**：会议安排、出差计划等

#### 4.4.2 翻找技巧与注意事项

**时间选择：**

- 垃圾收集日的前一天晚上或凌晨
- 下班以后，人少的时候
- 避免在白天进行，容易引起注意

**地点选择：**

- 目标建筑的垃圾桶集中区域
- 地下车库的垃圾房
- 大楼后侧的垃圾箱
- 注意观察垃圾清运的时间和路线

**装备准备：**

- 手套（乳胶手套或劳保手套）
- 手电筒或头灯
- 垃圾袋（用于分类装找到的物品）
- 镊子或夹子（用于夹取物品）
- 口罩或面罩（卫生考虑）
- 深色衣物（便于隐蔽）

**操作要点：**

1. 先观察周围环境，确认安全
2. 快速翻找，重点寻找文件袋、信封、包装盒等
3. 找到有价值的物品后迅速装入垃圾袋
4. 翻找后尽量恢复垃圾桶的原样
5. 不要留下任何痕迹
6. 控制时间，不要在一个地方停留过久

**法律风险提示：**

翻找垃圾在不同司法管辖区有不同的法律认定。在某些地区，垃圾被视为"抛弃物"，翻找不构成违法；但在另一些地区，可能涉及侵犯隐私或侵入他人财产。在进行任何此类活动前，必须确认已获得合法授权并了解当地法律规定。

#### 4.4.3 常见有价值信息类型

**账号凭证类：**
- 写在便签上的系统密码
- 初始密码通知函
- 密码重置邮件打印件

**组织结构类：**
- 组织架构图
- 员工通讯录
- 部门分布图

**系统信息类：**
- 网络拓扑图打印件
- 服务器配置清单
- IP地址分配表

**商业信息类：**
- 客户名单
- 报价单
- 产品 roadmap

**个人信息类：**
- 员工身份证复印件（应妥善处理）
- 银行卡号
- 个人联系方式
