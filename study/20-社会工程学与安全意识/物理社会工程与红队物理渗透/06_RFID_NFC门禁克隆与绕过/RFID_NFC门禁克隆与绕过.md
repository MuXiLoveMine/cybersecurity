# RFID/NFC门禁克隆与绕过

### 5.1 RFID门禁系统原理

RFID（Radio Frequency Identification，射频识别）是一种非接触式的自动识别技术，通过射频信号自动识别目标对象并获取相关数据。

**RFID系统基本组成：**

- **读卡器（Reader）**：发送射频信号并读取标签返回的数据
- **标签（Tag/卡）**：接收射频信号并返回存储的数据
- **控制器**：处理读卡器读取的数据，判断是否授权
- **门锁/闸机**：执行开门/放行动作

**工作原理：**

1. 读卡器不断向外发送射频信号
2. 当RFID卡进入读卡器的感应范围时，卡内的线圈产生感应电流
3. 卡片利用感应电流供电，将存储的数据通过射频信号发送给读卡器
4. 读卡器读取卡号或数据后，传输给控制器进行验证
5. 验证通过则控制门锁打开

**RFID频率分类：**

- **低频（LF）125kHz**：读取距离短（约10cm），常见ID卡
- **高频（HF）13.56MHz**：读取距离中等（约10-50cm），常见IC卡、NFC
- **超高频（UHF）860-960MHz**：读取距离远（可达数米），常用于物流和停车场

门禁系统最常用的是低频（125kHz）和高频（13.56MHz）。

### 5.2 常见RFID卡类型

#### 5.2.1 EM4100卡

- 低频卡（125kHz）
- 只读型，出厂时写入唯一卡号
- 64位数据格式，其中40位为卡号
- 价格便宜，广泛用于门禁、考勤
- 安全性极低，极易复制

#### 5.2.2 Mifare Classic 1K

- 高频卡（13.56MHz）
- 8192位（1KB）存储空间，分为16个扇区
- 每个扇区有独立的密钥A和密钥B
- 支持读写操作
- 广泛用于门禁、公交卡、储值卡等
- 存在已知的安全漏洞（嵌套攻击、硬攻击等）

#### 5.2.3 Mifare Ultralight

- 高频卡（13.56MHz）
- 64字节存储空间
- 一次编程（OTP）区域
- 主要用于一次性票卡、NFC标签等
- 安全性较低，可被克隆

#### 5.2.4 Mifare DESFire

- 高频卡（13.56MHz）
- 内置硬件加密引擎
- 支持DES、3DES、AES加密
- 安全性较高，难以破解
- 常用于安全性要求较高的场合

#### 5.2.5 CPU卡

- 内置微处理器和操作系统
- 支持对称加密和非对称加密
- 安全性最高
- 常用于金融、身份认证等高安全领域

### 5.3 RFID克隆工具

#### 5.3.1 Proxmark3

Proxmark3是目前最强大的RFID研究工具，支持多种频率和协议的RFID卡的读取、分析、克隆和攻击。

**主要功能：**

- 支持125kHz低频和13.56MHz高频
- 读取和模拟各种RFID卡
- 破解Mifare Classic卡的密钥
- 嗅探读卡器和卡片之间的通信
- 编写自定义脚本进行高级攻击

**版本：**

- Proxmark3 Easy：入门版，功能完整，价格较低
- Proxmark3 RDV4：高级版，性能更强，配件更多
- 各种国产克隆版

#### 5.3.2 Chameleon Mini

Chameleon Mini是一款小巧的RFID模拟和克隆设备，可以模拟多种类型的RFID卡。

**主要功能：**

- 支持多种RFID卡模拟
- 可存储多张卡的数据
- 支持通过按钮切换模拟的卡片
- 体积小，便于携带和现场使用

#### 5.3.3 ACR122U

ACR122U是一款常见的NFC读写器，基于PN532芯片，主要用于13.56MHz高频卡。

**主要功能：**

- 读取Mifare系列卡片
- 写入数据到空白卡
- 配合软件进行密钥破解
- 价格便宜，容易获得

**常用软件：**

- mfoc（Mifare Classic Offline Cracker）：嵌套攻击工具
- mfcuk（Mifare Classic DarkSide Unique Attack）：硬攻击工具
- libnfc：NFC开发库

#### 5.3.4 其他工具

- **PM3-RDV4.0**：Proxmark3的高端版本
- **iCopy 3/5/8**：国产复制机，操作简单，适合现场快速复制
- **RFID读写模块**：如MFRC522、PN532等，可用于DIY设备

### 5.4 Mifare Classic卡破解

Mifare Classic卡是目前门禁系统中使用最广泛的IC卡，但其存在多个已知的安全漏洞。

#### 5.4.1 嵌套攻击（Nested Attack）

嵌套攻击利用了Mifare Classic卡的认证机制漏洞。如果知道一个扇区的密钥，就可以利用这个扇区作为"跳板"，快速破解其他扇区的密钥。

**攻击原理：**

1. 首先获取任意一个扇区的密钥（很多卡的默认密钥是FFFFFFFFFFFF）
2. 利用已知密钥认证该扇区
3. 在认证状态下，向另一个扇区发起认证
4. 利用认证过程中的PRNG漏洞，通过少量尝试即可破解新扇区的密钥
5. 重复此过程，直到破解所有扇区

**工具：**
- mfoc（Mifare Classic Offline Cracker）

#### 5.4.2 硬攻击（Hardnested Attack / DarkSide Attack）

硬攻击适用于不知道任何密钥的情况。利用Mifare Classic卡的随机数生成器漏洞，通过精心构造的认证请求，获取密钥的部分信息，最终推导出完整密钥。

**攻击原理：**

1. 向卡片发送认证请求
2. 利用卡片返回的错误响应中的信息泄露
3. 通过统计学分析缩小密钥的可能范围
4. 最终通过暴力破解获得完整密钥

**工具：**
- mfcuk（Mifare Classic DarkSide Unique Key Attack）
- hardnested工具（比mfcuk更快）

**破解时间：**
- 传统硬攻击：数分钟到数小时
- 优化的硬攻击：几十秒到几分钟

#### 5.4.3 已知密钥破解

如果目标卡使用的是默认密钥或常见密钥，可以直接尝试：

**常见默认密钥：**
- FFFFFFFFFFFF（最常见）
- A0A1A2A3A4A5
- B0B1B2B3B4B5
- 000000000000
- 111111111111
- 123456789ABC

### 5.5 卡数据读取与写入

#### 5.5.1 读取卡数据

使用Proxmark3读取Mifare Classic卡的典型流程：

```
# 连接设备
pm3 > hw version

# 搜索卡片
pm3 > hf search

# 尝试使用默认密钥读取
pm3 > hf mf chk *1 ? t

# 读取所有扇区（需要密钥）
pm3 > hf mf dump
```

使用mfoc读取卡片：

```bash
mfoc -O card_data.dmp
```

#### 5.5.2 写入卡数据

将数据写入空白卡或可擦写卡：

```
# 使用Proxmark3写入
pm3 > hf mf restore

# 使用其他工具写入
```

**可用于克隆的卡：**
- UID卡：卡号可修改，支持完全克隆
- CUID卡：卡号可修改，支持完全克隆（比UID卡更稳定）
- FUID卡：卡号可修改一次，修改后锁定
- UFUID卡：增强版UID卡

**注意**：普通Mifare Classic卡的UID是只读的，无法修改，因此不能用于完整克隆。克隆卡必须使用UID可修改的特殊卡。

### 5.6 嗅探与中继攻击

#### 5.6.1 嗅探攻击

嗅探攻击是指监听读卡器和合法卡片之间的通信，获取卡号或认证数据。

**使用Proxmark3进行嗅探：**

```
# 高频嗅探
pm3 > hf sniff
```

嗅探可以获取通信数据，用于分析协议或进行离线破解。

#### 5.6.2 中继攻击（Relay Attack）

中继攻击是指通过两个设备，将读卡器的信号"中继"给远处的合法卡片，再将卡片的响应"中继"回读卡器，从而在没有卡片的情况下通过认证。

**攻击原理：**

1. 攻击者A携带设备靠近读卡器
2. 攻击者B携带设备靠近合法持卡人（可能在很远的地方）
3. 两个设备之间通过无线方式传输数据
4. 读卡器发出的查询被A接收，通过无线传给B
5. B将信号发送给合法卡片，卡片响应
6. 响应数据通过B传回A，A再发送给读卡器
7. 读卡器认为面前有一张合法卡片，开门

中继攻击的危害极大，因为它不需要复制卡片，只需要持卡人在附近即可。对于高频卡，攻击距离可以达到数米甚至更远。

### 5.7 实战：从读卡到克隆完整流程

以下是一个典型的Mifare Classic门禁卡克隆流程（仅用于授权测试）：

**步骤1：获取目标卡**
- 可以通过短暂接触（如借用、偷看等方式）获取卡片的读取机会
- 或者通过嗅探方式获取通信数据

**步骤2：识别卡类型**
```
pm3 > hf search
```
确认是Mifare Classic 1K/4K卡。

**步骤3：检查是否使用默认密钥**
```
pm3 > hf mf chk *1 ? t
```
如果发现默认密钥，可以直接读取数据。

**步骤4：破解未知密钥**
```
# 如果没有已知密钥，使用硬攻击
pm3 > hf mf hardnested

# 或使用mfoc
mfoc -O card.dmp
```

**步骤5：导出卡数据**
```
pm3 > hf mf dump
```
保存为dump文件。

**步骤6：准备克隆卡**
- 使用CUID或UID可擦写卡作为克隆目标

**步骤7：写入数据**
```
pm3 > hf mf restore
```

**步骤8：验证克隆卡**
```
pm3 > hf mf chk *1 ? t
```
确认克隆成功。

### 5.8 门禁绕过技巧

#### 5.8.1 跟人进入

详见4.1节尾随技巧。这是最简单也最有效的门禁绕过方法。

#### 5.8.2 故障注入

某些门禁控制器在特定的电气干扰下可能出现故障，导致门锁打开。例如：

- 强电磁脉冲干扰
- 电源浪涌
- 数据线干扰

但这种方法可能损坏设备，且效果不稳定，一般不推荐使用。

#### 5.8.3 物理旁路

- 从门禁控制箱入手，如果控制箱可以打开，可能可以直接短接控制线开门
- 某些磁力锁可以通过强外力（如吸盘）拉开
- 某些门锁的磁感应开关可以用磁铁欺骗

#### 5.8.4 利用紧急出口

很多建筑的紧急出口只能从内部打开，但如果能通过其他方式到达紧急出口的内侧（如从窗户、天台等），就可以从内部打开紧急出口，建立一条进出通道。
