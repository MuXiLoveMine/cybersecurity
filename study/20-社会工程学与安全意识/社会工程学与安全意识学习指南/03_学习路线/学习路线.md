# 学习路线

### 阶段一：理论基础（1-2个月）

**学习目标**：建立社会工程学和心理学理论基础

**学习内容**：
- 阅读《欺骗的艺术》（凯文·米特尼克）
- 学习Cialdini六大影响力原则
- 了解社会工程学攻击的一般方法论
- 学习基本心理学知识（认知偏差、决策心理）

**实践任务**：
- 分析3个真实社会工程攻击案例
- 总结攻击者使用的心理操纵手法
- 撰写学习笔记

**推荐资源**：
- 书籍：《欺骗的艺术》《影响力》《社会工程：安全体系中的人性漏洞》
- 播客：Social Engineer Podcast
- 网站：social-engineer.org

### 阶段二：技术基础（2-3个月）

**学习目标**：掌握社会工程攻击相关的技术基础

**学习内容**：
- 邮件协议基础（SMTP/POP3/IMAP）与邮件安全（SPF/DKIM/DMARC）
- OSINT信息收集技术与方法论
- Web基础（HTML/JavaScript）与钓鱼网站原理
- 网络基础（DNS/HTTP）与域名系统
- 基本Linux命令行操作

**实践任务**：
- 使用OSINT工具对自己进行信息收集，评估个人数字足迹
- 搭建GoPhish钓鱼模拟平台
- 分析10封真实钓鱼邮件的邮件头

**推荐资源**：
- 工具：Maltego、theHarvester、GoPhish、SET
- 平台：TryHackMe社会工程学模块、HackTheBox OSINT挑战

### 阶段三：攻击技术实践（2-3个月）

**学习目标**：掌握各类社会工程攻击技术

**学习内容**：
- 钓鱼攻击技术（邮件钓鱼、鱼叉钓鱼、vishing、smishing）
- 钓鱼网站克隆与定制
- SET工具使用
- 物理社会工程基础
- 水坑攻击原理

**实践任务**：
- 在授权环境下完成一次完整的鱼叉钓鱼模拟
- 使用SET克隆钓鱼网站
- 编写不同场景的钓鱼邮件模板
- 记录和分析模拟攻击结果

**推荐资源**：
- 平台：GoPhish实战、SET实操
- 认证：SEPP（Social Engineering Professional Certification）

### 阶段四：防护与检测（2-3个月）

**学习目标**：掌握社会工程攻击的防护和检测技术

**学习内容**：
- 邮件安全网关配置与策略
- 钓鱼检测技术（邮件头分析、URL分析、沙箱检测）
- 安全意识培训体系设计
- 安全文化建设方法论
- 事件响应流程

**实践任务**：
- 设计完整的企业安全意识培训方案
- 配置邮件安全策略（SPF/DKIM/DMARC）
- 制定钓鱼事件响应预案
- 设计安全意识KPI

**推荐资源**：
- 框架：SANS Security Awareness、NIST SP 800-50
- 标准：ISO 27001人为安全控制

### 阶段五：高级实战与认证（持续）

**学习目标**：成为社会工程学领域专家

**学习内容**：
- 红队社会工程攻击
- 高级OSINT技术
- 安全意识项目度量与优化
- 行业最佳实践与前沿趋势

**实践任务**：
- 参与红队演练中的社会工程攻击环节
- 设计和执行长期安全意识项目
- 撰写社会工程攻击评估报告
- 参与行业会议和社区

**推荐认证**：
- OSINT Framework认证
- SANS SEC460: Social Engineering for Security Professionals
- OSCP（含社会工程元素）
