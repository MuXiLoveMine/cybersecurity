# 详细子方向

### 2.1 社会工程学基础

#### 2.1.1 心理学原理

社会工程学的根基在于对人类心理学的深刻理解。攻击者利用以下心理特征：

- **好奇心**：人类天生对新奇事物感兴趣，攻击者利用"标题党"诱导点击
- **恐惧感**：紧急威胁（如"账户即将关闭"）导致理性判断下降
- **贪婪**：利益诱惑（如"恭喜中奖"）降低警惕性
- **信任**：对权威、品牌、熟人的天然信任
- **从众心理**：看到"其他人都在做"时更容易跟从
- **惰性**：倾向走捷径，忽略安全步骤
- **感恩/互惠**：接受帮助后倾向回报

#### 2.1.2 影响力原则

罗伯特·西奥迪尼（Robert Cialdini）提出的六大影响力原则是社会工程学的理论基础：

| 原则 | 核心理念 | 社会工程学应用 |
|------|---------|---------------|
| 互惠（Reciprocity） | 人们倾向回报他人给予的东西 | 攻击者先提供帮助/礼物，再提出请求 |
| 承诺与一致（Commitment & Consistency） | 人们希望行为与自己先前的承诺一致 | 先让目标做出小承诺，再逐步升级要求 |
| 社会认同（Social Proof） | 人们会参考他人的行为来指导自己的行为 | "其他用户已验证"、"大家都在用" |
| 喜好（Liking） | 人们更容易被自己喜欢的人说服 | 建立亲和力、假冒熟人身份 |
| 权威（Authority） | 人们倾向于服从权威人物 | 冒充高管、IT部门、执法机构 |
| 稀缺（Scarcity） | 稀缺的东西更有价值 | "限时优惠"、"仅剩3个名额" |

### 2.2 攻击方法论

社会工程学攻击通常遵循以下方法论：

#### 2.2.1 信息收集（Information Gathering）

```
┌─────────────────────────────────────────────┐
│              信息收集阶段                     │
├─────────────────────────────────────────────┤
│  1. 目标组织公开信息收集                      │
│     - 公司官网、新闻稿、年度报告              │
│     - 招聘信息（技术栈、组织架构）             │
│     - SEC/工商注册信息                       │
│  2. 员工信息收集                             │
│     - LinkedIn / 脉脉 / GitHub               │
│     - 社交媒体（微博、微信、Twitter）         │
│     - 学术论文、会议演讲                     │
│  3. 技术信息收集                             │
│     - DNS记录、WHOIS信息                    │
│     - 子域名枚举                            │
│     - 邮件服务器配置（SPF/DKIM/DMARC）       │
│  4. 物理信息收集                             │
│     - Google Earth / 卫星图像               │
│     - 门禁系统类型                           │
│     - 员工出入时间规律                       │
└─────────────────────────────────────────────┘
```

#### 2.2.2 建立信任（Building Trust）

- 制造紧迫感但不过分，保持合理性
- 使用目标行业术语展示专业性
- 引用真实事件/项目增加可信度
- 渐进式接触，避免一次性索取过多

#### 2.2.3 利用（Exploitation）

- 发送钓鱼邮件/短信
- 拨打钓鱼电话
- 物理渗透
- 水坑攻击部署

#### 2.2.4 撤离（Exit/Maintaining Access）

- 清理痕迹，避免引起警觉
- 建立持久化访问
- 评估攻击效果
- 编写攻击报告

### 2.3 钓鱼攻击

#### 2.3.1 邮件钓鱼（Email Phishing）

邮件钓鱼是最经典的社会工程攻击形式：

- **发件人欺骗**：利用SMTP协议无身份验证的特性伪造发件人
- **显示名欺骗**：将发件人显示名设为知名品牌/高管姓名
- **域名仿冒**：使用相似域名（如 `paypa1.com` 替代 `paypal.com`）
- **子域名滥用**：使用合法服务的子域名（如 `company.sharepoint.com.evil.com`）
- **恶意附件**：含宏的Office文档、HTA文件、ISO镜像
- **恶意链接**：指向钓鱼网站或漏洞利用页面

#### 2.3.2 鱼叉钓鱼（Spear Phishing）

鱼叉钓鱼是针对特定目标的定制化钓鱼攻击：

- **目标画像**：通过OSINT收集目标个人信息、工作职责、社交关系
- **场景定制**：根据目标岗位设计合理的邮件场景（如针对财务人员的"发票"邮件）
- **时机选择**：选择目标繁忙/松懈的时机发送
- **多渠道配合**：邮件+电话+社交媒体协同攻击

#### 2.3.3 话音钓鱼（Vishing）

- 冒充IT支持/银行客服/政府机构
- 利用来电显示伪造技术
- 制造紧急情况迫使目标配合
- 常见场景：技术支持诈骗、税务诈骗、社保诈骗

#### 2.3.4 短信钓鱼（Smishing）

- 冒充快递通知、银行通知
- 伪造短信号码
- 利用URL缩短服务隐藏真实链接
- 常见场景：假冒快递取件、银行验证、中奖通知

### 2.4 物理社会工程

#### 2.4.1 尾随（Tailgating）

攻击者在合法用户通过门禁时紧跟进入，常见手法：
- 手持重物请求帮忙开门
- 假装忘带门禁卡
- 推车/搬运大件物品时自然跟随

#### 2.4.2 假冒身份（Impersonation）

- 冒充IT维修人员/快递员/审计人员
- 伪造工牌/工作服
- 提前准备道具增强可信度

#### 2.4.3 翻找垃圾（Dumpster Diving）

- 从废弃文件中获取敏感信息
- 寻找网络拓扑图、密码便签、系统文档
- 从废弃设备中恢复数据

### 2.5 Pretexting（借口编造）

Pretexting是编造一个合理的场景/借口来获取信息：

- **场景设计**：设计一个目标容易相信的故事场景
- **角色扮演**：攻击者扮演可信角色（审计员、供应商、客户）
- **信息编织**：利用已收集的真实信息增强可信度
- **目标锁定**：选择最容易受影响的部门/个人

**典型案例**：攻击者冒充IT供应商，声称需要对系统进行紧急维护，要求员工提供VPN凭证。

### 2.6 水坑攻击（Watering Hole Attack）

水坑攻击针对特定群体经常访问的网站：

1. **识别目标群体常访问的网站**：行业论坛、专业网站
2. **入侵目标网站**：利用网站漏洞植入恶意代码
3. **等待目标访问**：目标访问被感染网站时被植入恶意软件
4. **持久化与数据回传**：建立C2通道，窃取数据

### 2.7 社工工具集

#### 2.7.1 SET（Social Engineering Toolkit）

SET是最著名的社会工程学攻击框架，功能包括：
- 钓鱼攻击向量（邮件发送、钓鱼网站克隆）
- 网站攻击向量（Java Applet攻击、Metasploit浏览器漏洞利用）
- 传染性媒体攻击（恶意USB/CD生成）
- 短信/电话伪造

#### 2.7.2 BeEF（Browser Exploitation Framework）

BeEF专注于浏览器端的社会工程攻击：
- 钩子注入（通过XSS或水坑攻击植入）
- 浏览器指纹收集
- 内网端口扫描
- 社会工程模块（假更新提示、假登录页面）

#### 2.7.3 GoPhish

GoPhish是开源的钓鱼模拟平台：
- 邮件模板管理
- 着陆页管理
- 发送配置
- 详细的跟踪报告（打开率、点击率、提交率）
- API支持自动化

### 2.8 安全意识培训体系

安全意识培训是防范社会工程攻击的核心防线：

- **全员基础培训**：面向所有员工的基础安全意识教育
- **岗位定制培训**：针对不同岗位的专项培训
- **新员工培训**：入职安全意识培训
- **持续培训**：定期更新和强化
- **钓鱼模拟**：通过模拟演练检验培训效果

### 2.9 安全文化建设

- **安全冠军计划（Security Champions）**：在各团队中选拔安全代言人
- **安全事件分享**：透明分享安全事件和教训
- **奖励机制**：奖励安全行为和报告
- **管理层支持**：高层示范安全行为
- **安全融入日常**：将安全融入工作流程而非额外负担
