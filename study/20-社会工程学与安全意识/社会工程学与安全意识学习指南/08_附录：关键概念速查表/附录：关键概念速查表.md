# 附录：关键概念速查表

| 概念 | 简要说明 |
|------|---------|
| Phishing | 钓鱼攻击，通过伪装获取敏感信息 |
| Spear Phishing | 鱼叉钓鱼，针对特定目标的定制化钓鱼 |
| Whaling | 捕鲸攻击，针对高管的鱼叉钓鱼 |
| Vishing | 话音钓鱼，通过电话实施社会工程 |
| Smishing | 短信钓鱼，通过短信实施社会工程 |
| BEC | 商业邮件妥协，冒充高管/供应商骗取资金 |
| Pretexting | 借口编造，编造场景获取信息 |
| Tailgating | 尾随，物理社会工程手法 |
| Watering Hole | 水坑攻击，感染目标常访问的网站 |
| OSINT | 开源情报，从公开来源收集信息 |
| Baiting | 诱饵攻击，利用好奇心/贪婪引诱 |
| Quid Pro Quo | 利益交换，提供服务换取信息 |
| SPF | 发件人策略框架，邮件身份验证 |
| DKIM | 域名密钥识别邮件，邮件签名验证 |
| DMARC | 基于域名的邮件认证报告一致性 |
| MFA Bypass | 多因素认证绕过（如通过钓鱼） |
| EvilProxy | 中间人钓鱼代理，绕过MFA |
| Security Champion | 安全冠军，团队内安全代言人 |
