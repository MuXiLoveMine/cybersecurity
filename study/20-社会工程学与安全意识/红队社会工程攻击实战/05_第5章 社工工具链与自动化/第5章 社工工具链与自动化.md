# 第5章 社工工具链与自动化

### 5.1 钓鱼平台搭建

专业的红队社工需要专业的工具平台。手动发送钓鱼邮件、手动统计结果的方式，既低效又容易出错。使用专业的钓鱼平台可以实现钓鱼攻击的全流程自动化管理。

#### 5.1.1 Gophish平台详解

Gophish是目前最流行的开源钓鱼平台，功能强大、界面友好、易于部署。

**（1）Gophish主要功能**
- 钓鱼邮件模板管理
- 目标用户管理（支持分组）
- 钓鱼页面克隆与定制
- 钓鱼活动调度与执行
- 实时数据统计与可视化
- 多用户支持
- REST API支持

**（2）Gophish部署**

Gophish是跨平台的，部署非常简单：

```bash
# 下载Gophish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip

# 解压
unzip gophish-v0.12.1-linux-64bit.zip

# 修改配置
vim config.json

# 运行
chmod +x gophish
./gophish
```

**配置文件说明：**
```json
{
  "admin_server": {
    "listen_url": "0.0.0.0:3333",
    "use_tls": true,
    "cert_path": "gophish_admin.crt",
    "key_path": "gophish_admin.key"
  },
  "phish_server": {
    "listen_url": "0.0.0.0:8080",
    "use_tls": false,
    "cert_path": "example.crt",
    "key_path": "example.key"
  },
  "db_name": "sqlite3",
  "db_path": "gophish.db",
  "migrations_prefix": "db/db_",
  "contact_address": "",
  "logging": {
    "filename": "",
    "level": ""
  }
}
```

**（3）Gophish核心概念**

- **Users & Groups（用户与组）**：管理目标用户信息，支持CSV批量导入
- **Email Templates（邮件模板）**：创建和管理钓鱼邮件模板，支持变量替换
- **Landing Pages（着陆页）**：创建钓鱼页面，支持网站克隆
- **Sending Profiles（发送配置）**：配置邮件发送服务器
- **Campaigns（钓鱼活动）**：一次完整的钓鱼活动，将以上元素组合起来

**（4）Gophish高级技巧**

- **邮件模板变量**：使用`{{.FirstName}}`、`{{.LastName}}`、`{{.Email}}`等变量实现个性化邮件
- **URL跟踪**：Gophish会自动在钓鱼链接中加入唯一标识符，用于追踪每个目标的行为
- **重定向设置**：目标提交凭证后，可以重定向到真实网站，减少被发现的概率
- **数据导出**：支持将钓鱼结果导出为CSV，用于进一步分析

#### 5.1.2 King Phisher平台

King Phisher是另一个功能强大的钓鱼平台，相比Gophish，它提供了更多高级功能。

**King Phisher的特点：**
- 更丰富的统计数据和可视化
- 支持SSH隧道发送邮件
- 内置多个邮件模板和钓鱼页面模板
- 支持SPF/DKIM配置检查
- 支持凭据harvesting的多步骤表单
- 插件系统，可扩展功能

**适用场景：**
- 大型企业的复杂钓鱼演练
- 需要详细统计和报告的场景
- 需要高度定制化的场景

#### 5.1.3 钓鱼平台搭建的最佳实践

**（1）服务器选择**
- 选择信誉良好的VPS提供商
- IP地址不能在黑名单中
- 最好选择目标所在地区的服务器，减少延迟和异常

**（2）域名配置**
- 注册与目标相似的域名
- 配置SPF、DKIM、DMARC记录，提高邮件送达率
- 申请SSL证书，钓鱼页面使用HTTPS

**（3）邮件发送优化**
- 不要一次性发送大量邮件，要分批发送
- 控制发送频率，避免被邮件服务器判定为垃圾邮件
- 测试邮件在不同邮件服务商（Gmail、Outlook、企业邮箱等）中的到达情况

**（4）安全加固**
- 管理后台使用强密码
- 限制管理后台的访问IP
- 定期更新Gophish版本
- 钓鱼活动结束后及时清理数据

### 5.2 社工库与信息聚合

社工库（Social Engineering Database）是社工攻击的重要"弹药库"——收集和整理目标的各种信息，为社工攻击提供数据支撑。

#### 5.2.1 社工库的信息类型

**（1）个人身份信息**
- 姓名、身份证号、手机号
- 邮箱地址、家庭住址
- 出生日期、教育背景

**（2）账号密码信息**
- 各种网站的账号和密码（来自历史数据泄露）
- 密码习惯分析（目标常用的密码模式）

**（3）社交关系信息**
- 家庭成员、朋友、同事
- 社交账号和社交网络

**（4）行为偏好信息**
- 兴趣爱好、消费习惯
- 常用网站和App

#### 5.2.2 信息聚合方法

**（1）公开数据源查询**
- Have I Been Pwned：查询邮箱是否在已知的数据泄露中
- DeHashed：泄露数据搜索引擎
- WeLeakInfo：综合信息查询平台
- 各种社工库网站（注意合法性）

**（2）搜索引擎挖掘**
- 用Google/Bing搜索目标的邮箱、手机号、用户名
- 使用filetype:语法搜索包含目标信息的文档
- 在代码托管平台搜索目标的邮箱或用户名

**（3）社交媒体收集**
- 从LinkedIn、微博、知乎等平台收集信息
- 使用自动化工具批量收集

#### 5.2.3 信息聚合工具

**Maltego**
- 可视化的情报关联分析工具
- 可以将各种碎片化的信息关联起来，形成关系图谱
- 支持多种数据源和转换插件

**SpiderFoot**
- 自动化OSINT收集工具
- 支持200多种数据源
- 可以自动关联和分析收集到的信息

**theHarvester**
- 收集邮箱、子域名、人名等信息
- 支持多种搜索引擎和数据源

**Recon-ng**
- 全功能的Web侦察框架
- 模块化设计，功能强大
- 可以理解为"社工界的Metasploit"

### 5.3 自动化钓鱼邮件生成

随着AI技术的发展，自动化钓鱼邮件生成成为可能。利用大语言模型，可以快速生成高度定制化的钓鱼邮件。

#### 5.3.1 AI辅助钓鱼邮件生成

**（1）基于目标画像的个性化生成**
将目标画像信息输入AI模型，生成针对该目标的个性化钓鱼邮件。

输入信息包括：
- 目标的姓名、职位、部门
- 目标的兴趣爱好、工作内容
- 目标的沟通风格和语言习惯

**（2）多场景模板生成**
利用AI快速生成多种场景的钓鱼邮件模板：
- IT通知类
- HR通知类
- 财务通知类
- 业务合作类
- 紧急事件类

**（3）风格模仿**
分析目标的历史邮件风格，让AI模仿该风格生成邮件，提高可信度。

#### 5.3.2 批量个性化钓鱼

对于大规模的钓鱼演练，需要给不同的目标发送不同内容的钓鱼邮件。自动化工具可以实现：

- 根据目标信息自动选择最合适的攻击场景
- 自动填充个性化内容
- 自动调整语言风格
- 批量生成和发送

#### 5.3.3 A/B测试优化

高级的钓鱼平台可以对不同版本的钓鱼邮件进行A/B测试，找出效果最好的版本。

测试维度：
- 不同的邮件标题
- 不同的正文内容
- 不同的诱饵类型
- 不同的发送时间
