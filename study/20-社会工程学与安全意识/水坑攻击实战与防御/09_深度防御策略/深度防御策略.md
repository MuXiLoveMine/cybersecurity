# 深度防御策略

### 9.1 内容安全策略(CSP)配置

```
内容安全策略(CSP)防御水坑攻击:

CSP通过限制可执行的脚本来源,防止注入的恶意代码执行:

  HTTP头配置:
  Content-Security-Policy:
    default-src 'self';
    script-src 'self' 'nonce-{random}' https://cdn.trusted-cdn.com;
    object-src 'none';
    base-uri 'self';
    report-uri /csp-report;

  效果:
  1. 只允许同源脚本执行
  2. 只允许指定CDN的脚本
  3. 使用nonce防止内联脚本
  4. 禁止<object>/<embed>
  5. 防止base-uri劫持
  6. 报告违规行为

  严格CSP(推荐):
  Content-Security-Policy:
    script-src 'self' 'nonce-{random}' 'strict-dynamic';
    object-src 'none';
    base-uri 'none';
    require-trusted-types-for 'script';

  strict-dynamic:
  - 允许nonce标记的脚本加载子脚本
  - 不需要枚举所有可信域名
  - 防止注入的非nonce脚本执行
  - 即使网站被入侵,注入代码也无法执行

  Trusted Types:
  - 最新的DOM XSS防护
  - 只允许通过策略创建的DOM操作
  - 防止innerHTML等危险API被滥用
  - 需要修改代码适配
```

### 9.2 浏览器隔离实施方案

```
浏览器隔离(Browser Isolation)深度方案:

方案1: 远程浏览器隔离(RBI)
  架构:
    用户终端 <==像素流==> [云端浏览器] <==HTTP==> [目标网站]

  工作原理:
  1. 用户请求访问网站
  2. 云端容器启动浏览器实例
  3. 浏览器在云端加载网站
  4. 网站渲染为像素流
  5. 像素流传输到用户终端
  6. 终端显示网页(非真实HTML)

  安全效果:
  | 恶意代码在云端执行
  | 不接触用户终端
  | 会话结束后容器销毁
  | 即使网站被入侵也无害

  实施方案:
  | Menlo Security - 商业方案
  | Cloudflare Browser Isolation
  | Cisco Secure Browser
  | 自建: Docker + noVNC + Firefox

方案2: 本地容器隔离
  架构:
    [宿主机] --> [Docker容器] --> [浏览器]
                         |
                         v
                    [目标网站]

  工作原理:
  1. 用户点击链接
  2. 在Docker容器中启动浏览器
  3. 所有网页活动在容器内
  4. 会话结束后容器重置
  5. 恶意代码被困在容器中

  优势:
  | 不需要网络传输像素流
  | 用户体验更好(低延迟)
  | 可以本地部署
  | 成本较低

  劣势:
  | 容器逃逸风险
  | 需要本地资源
  | 管理复杂度

方案3: 虚拟机隔离
  架构:
    [用户终端] --> [VM浏览器] --> [目标网站]
  
  每次浏览会话:
  | 启动VM快照
  | 在VM中浏览
  | 结束后恢复快照
  | 恶意代码被清除

  优势:
  | 隔离最强(完整OS级)
  | 无容器逃逸风险
  | 成熟技术

  劣势:
  | 资源消耗大
  | 启动慢
  | 用户体验差
```

### 9.3 自动化补丁管理系统

```python
# 企业补丁管理系统
class PatchManagementSystem:
    """水坑攻击防御: 自动化补丁管理"""

    PATCH_PRIORITY = {
        'P0': {'description': '零日漏洞/在野利用', 'deadline_hours': 24},
        'P1': {'description': '严重漏洞/公开PoC', 'deadline_hours': 72},
        'P2': {'description': '高危漏洞', 'deadline_hours': 168},
        'P3': {'description': '中低危漏洞', 'deadline_hours': 720},
    }

    CRITICAL_TARGETS = [
        # 浏览器
        {'app': 'Chrome', 'vendor': 'Google', 'auto_update': True},
        {'app': 'Edge', 'vendor': 'Microsoft', 'auto_update': True},
        {'app': 'Firefox', 'vendor': 'Mozilla', 'auto_update': True},

        # 浏览器插件(高危)
        {'app': 'Flash', 'vendor': 'Adobe', 'action': 'uninstall'},
        {'app': 'Java', 'vendor': 'Oracle', 'auto_update': True},
        {'app': 'PDF Reader', 'vendor': 'Adobe', 'auto_update': True},

        # 操作系统
        {'app': 'Windows', 'vendor': 'Microsoft', 'patch_day': 'Tuesday'},
        {'app': 'macOS', 'vendor': 'Apple', 'auto_update': True},
        {'app': 'Linux', 'vendor': 'Various', 'pkg_manager': 'apt/yum'},

        # 运行时
        {'app': '.NET Framework', 'vendor': 'Microsoft'},
        {'app': 'Python', 'vendor': 'Python.org'},
    ]

    def assess_vulnerability(self, cve_id):
        """评估漏洞优先级"""
        # 查询CVE数据库
        cve_info = self._query_cve(cve_id)

        # 确定优先级
        if cve_info.get('in_the_wild'):
            priority = 'P0'
        elif cve_info.get('exploit_public'):
            priority = 'P1'
        elif cve_info.get('cvss_score', 0) >= 7.0:
            priority = 'P2'
        else:
            priority = 'P3'

        # 检查是否影响关键目标
        affected_apps = cve_info.get('affected_products', [])
        is_critical = any(
            any(target['app'].lower() in app.lower()
                for target in self.CRITICAL_TARGETS)
            for app in affected_apps
        )

        if is_critical:
            priority = self._escalate_priority(priority)

        return {
            'cve': cve_id,
            'priority': priority,
            'deadline_hours': self.PATCH_PRIORITY[priority]['deadline_hours'],
            'description': self.PATCH_PRIORITY[priority]['description'],
            'cvss': cve_info.get('cvss_score'),
            'affected': affected_apps,
            'in_the_wild': cve_info.get('in_the_wild', False),
            'exploit_public': cve_info.get('exploit_public', False),
        }

    def deploy_patch(self, patch_info, target_hosts):
        """部署补丁"""
        results = []
        for host in target_hosts:
            try:
                # 测试环境先部署
                if host.environment == 'production':
                    self._deploy_to_test_first(patch_info)

                # 部署补丁
                result = self._install_patch(host, patch_info)
                results.append({
                    'host': host.name,
                    'status': 'success' if result else 'failed',
                    'patch': patch_info['id'],
                })

                # 验证补丁
                if result:
                    verified = self._verify_patch(host, patch_info)
                    if not verified:
                        results[-1]['status'] = 'verification_failed'
                        self._rollback_patch(host, patch_info)

            except Exception as e:
                results.append({
                    'host': host.name,
                    'status': 'error',
                    'error': str(e),
                })

        return results

    def generate_compliance_report(self):
        """生成补丁合规报告"""
        report = "补丁合规报告\n"
        report += f"{'='*60}\n"

        for target in self.CRITICAL_TARGETS:
            app = target['app']
            deployed = self._get_deployment_stats(app)
            total = self._get_total_hosts(app)

            coverage = (deployed / total * 100) if total > 0 else 0

            status = 'PASS' if coverage >= 95 else 'FAIL'

            report += f"\n{app} ({target['vendor']}):\n"
            report += f"  部署: {deployed}/{total} ({coverage:.1f}%) [{status}]\n"

            if coverage < 95:
                missing = total - deployed
                report += f"  未打补丁: {missing}台\n"
                report += f"  建议: 立即部署补丁\n"

        return report
```
