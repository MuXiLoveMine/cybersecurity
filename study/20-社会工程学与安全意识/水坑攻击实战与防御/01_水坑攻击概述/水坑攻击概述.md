# 水坑攻击概述

### 1.1 什么是水坑攻击

水坑攻击（Watering Hole Attack）是一种定向社会工程学攻击。攻击者不直接攻击目标，而是感染目标群体经常访问的合法网站，在目标访问时实施攻击。

```
水坑攻击类比:

  自然界:
    狩猎者不在草原上追逐猎物
    而是在水坑(动物必经饮水处)下毒/设伏
    等待猎物自己来

  网络空间:
    攻击者不直接发送钓鱼邮件
    而是入侵目标员工经常访问的网站
    在网站上植入恶意代码
    等待目标员工访问时触发攻击
```

### 1.2 攻击特征

| 特征 | 说明 |
|------|------|
| 定向性 | 针对特定组织/行业/群体 |
| 间接性 | 不直接接触目标 |
| 隐蔽性 | 利用合法网站降低警惕 |
| 等待性 | 被动等待目标访问 |
| 高成功率 | 目标对信任站点警惕低 |
| 低成本 | 不需要大规模钓鱼 |

### 1.3 与其他攻击的关系

```
水坑攻击 vs 鱼叉钓鱼:

  鱼叉钓鱼:
    攻击者 -> 钓鱼邮件 -> 目标
    主动发送，需要邮件地址
    可被邮件网关检测

  水坑攻击:
    攻击者 -> 入侵网站 <- 目标主动访问
    被动等待，不需要邮箱
    更难检测(网站是合法的)

水坑攻击 vs 供应链攻击:

  供应链攻击:
    攻击者 -> 入侵供应商 -> 感染下游
    通过软件/硬件供应链传播
    影响面广

  水坑攻击:
    攻击者 -> 入侵网站 -> 感染访问者
    通过网站传播
    影响面可控(定向)
```
