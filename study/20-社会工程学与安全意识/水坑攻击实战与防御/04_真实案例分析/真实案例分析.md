# 真实案例分析

### 3.1 AOA攻击

```
AOA (Angler Exploit Kit) 水坑攻击:

目标: 金融行业员工
感染网站: 多个金融新闻和分析网站

攻击链:
  1. 攻击者入侵金融新闻网站
  2. 注入恶意JavaScript(loader)
  3. 受害者(金融员工)访问新闻网站
  4. loader检测到Flash漏洞可用
  5. 投递Flash exploit
  6. 下载并执行 banking trojan
  7. 窃取银行凭据

技术细节:
  - 使用Angler Exploit Kit
  - 利用CVE-2015-0311 (Flash)
  - 条件注入(只对目标IP段)
  - 快速轮换域名(避免封锁)
```

### 3.2 极光行动

```
Operation Aurora (2009-2010):

目标: Google, Adobe, Intel等20+家科技公司
感染方式: 通过即时通讯发送恶意链接

攻击链:
  1. 攻击者获取目标员工IM联系人信息
  2. 通过信任的IM账户发送链接
  3. 链接指向被入侵的网站(水坑)
  4. 网站利用IE零日漏洞(CVE-2010-0249)
  5. 在目标机器上执行代码
  6. 建立C2通道
  7. 横向移动到内部网络
  8. 访问源代码服务器

影响:
  - Google源代码被窃取
  - Gmail账户被监控
  - 多家科技公司受影响
  - Google退出中国大陆
```

### 3.3 IE零日漏洞事件

```
2015 IE零日水坑攻击:

目标: 美国国防和军事相关人员
感染网站: 美国退伍军人事务部相关网站

攻击链:
  1. 攻击者入侵军事/退伍军人相关网站
  2. 注入恶意iframe
  3. 受害者访问网站
  4. iframe加载漏洞利用页面
  5. IE漏洞(CVE-2015-2417)触发
  6. 执行shellcode
  7. 安装PlugX RAT

技术特征:
  - 定向攻击(只对军事相关IP)
  - 使用零日漏洞(补丁未发布)
  - 使用PlugX(中国APT常用工具)
  - 高度隐蔽(条件触发)
```
