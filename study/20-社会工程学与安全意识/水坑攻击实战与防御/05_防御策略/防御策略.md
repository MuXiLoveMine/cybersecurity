# 防御策略

### 5.1 URL过滤

```
URL过滤策略:

  1. 类别过滤
     | 允许: 工作/教育/新闻
     | 禁止: 赌博/色色/未知

  2. 信誉过滤
     | 新注册域名(7天内)阻止
     | 低信誉域名阻止
     | 动态DNS阻止

  3. 内容过滤
     | 检测恶意JavaScript
     | 阻止已知exploit域名
     | 沙箱分析URL

  实施:
     | 代理服务器(Squid/Bluecoat)
     | DNS过滤(Cisco Umbrella)
     | 安全Web网关(SWG)
```

### 5.2 补丁管理

```
补丁管理体系:

  补丁优先级:
    P0(24小时): 零日漏洞/在野利用
    P1(72小时): 严重漏洞/公开PoC
    P2(1周): 高危漏洞
    P3(1月): 中低危漏洞

  关键补丁目标:
    - 浏览器(Chrome/Edge/Firefox)
    - 浏览器插件(Flash[已废弃]/Java/PDF Reader)
    - 操作系统
    - 办公软件
    - 运行时环境

  自动化补丁管理:
    - WSUS (Windows)
    - SCCM (Windows企业)
    - Ansible (Linux)
    - 补丁测试流程
    - 回滚机制
```

### 5.3 浏览器隔离

```
浏览器隔离(Browser Isolation):

  1. 远程浏览器隔离(RBI)
     | 浏览器在云端/服务器运行
     | 用户只看到像素流
     | 恶意代码不接触终端
     | 示例: Menlo Security/Browser in Cloud

  2. 本地容器隔离
     | 浏览器在容器中运行
     | 每次会话后重置
     | 恶意代码困在容器中

  3. 虚拟机隔离
     | 浏览器在VM中运行
     | 与主机隔离
     | 快照恢复

  隔离效果:
     | 网页代码执行在隔离环境
     | 恶意软件无法到达终端
     | 即使用户访问被入侵网站
     | 攻击也被隔离
```

**安全意识要点**

```
员工安全意识培训内容:

  1. 水坑攻击原理
     - 理解合法网站可能被入侵
     - 不因网站"知名"就放松警惕

  2. 安全浏览习惯
     - 及时更新浏览器
     - 禁用不必要的插件
     - 使用安全DNS
     - 注意浏览器安全警告

  3. 异常识别
     - 浏览器突然弹出下载
     - 网页行为异常
     - 浏览器进程异常
     - 系统性能突然下降

  4. 报告机制
     - 发现异常立即报告
     - 不要自行处理
     - 记录异常现象和时间

  5. 分离工作和个人浏览
     - 工作机器只做工作
     - 个人浏览在隔离环境
     - 不在工作机器访问非工作网站
```
