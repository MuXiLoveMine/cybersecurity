# 附录

### A. BeEF常用快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+A | 全选所有Hooked浏览器 |
| Delete | 删除选中的浏览器 |
| F5 | 刷新管理界面 |
| Esc | 关闭当前弹窗 |

### B. BeEF默认端口清单

| 端口 | 协议 | 用途 |
|------|------|------|
| 3000 | TCP | HTTP管理界面和Hook服务 |
| 6789 | TCP | HTTPS管理界面和Hook服务 |
| 61985 | TCP | WebSocket通信（HTTP） |
| 61986 | TCP | WebSocket通信（HTTPS） |
| 55552 | TCP | Metasploit RPC服务（可选） |

### C. 浏览器缩写对照表

BeEF模块配置中常用的浏览器缩写：

| 缩写 | 浏览器 |
|------|--------|
| FF | Firefox |
| C | Chrome |
| S | Safari |
| IE | Internet Explorer |
| E | Edge |
| O | Opera |
| ALL | 所有浏览器 |
