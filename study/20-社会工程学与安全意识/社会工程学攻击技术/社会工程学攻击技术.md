## 1. 社会工程学心理学基础

### 1.1 Cialdini六大影响力原则详解

社会工程学的核心在于对人类心理的深刻理解。心理学家罗伯特·西奥迪尼（Robert Cialdini）在其著作《影响力》中提出的六大说服原则，是社会工程学攻击的理论基石。

#### 1.1.1 互惠原则（Reciprocity）

**原理**：人类社会中存在强烈的"投桃报李"倾向。当别人给予我们东西时，我们感到有义务回报。

**心理学机制**：
- 进化心理学认为互惠是人类社会合作的基础
- 接受恩惠会产生心理负债感
- 这种负债感会驱动回报行为，即使回报价值远大于接受的恩惠

**社会工程学应用**：

```
攻击场景：攻击者冒充IT支持人员

步骤1（给予）："您好，我是IT部的张伟。注意到您的VPN连接经常掉线，
              我可以帮您修复这个问题。"
步骤2（建立信任）：提供一些真实的IT建议，展示专业能力
步骤3（索取）："为了远程修复，我需要您的VPN用户名和密码进行诊断。"
```

在上述场景中，攻击者先提供"帮助"（即使只是口头建议），触发了互惠心理，使目标更愿意配合后续的信息请求。

#### 1.1.2 承诺与一致原则（Commitment & Consistency）

**原理**：人们一旦做出某种选择或表态，就会面临保持一致性的心理压力。

**心理学机制**：
- 一致性是社会认同的基础，反复无常会损害社会形象
- 一旦公开承诺，改变立场会产生认知失调
- 小承诺会逐步升级为大承诺（"登门槛"技术）

**社会工程学应用**：

```
攻击场景：渐进式信息获取

步骤1（小承诺）："您好，请问您是市场部的李经理吗？" → 目标确认
步骤2（确认信息）："我看到您负责第三季度的品牌推广项目？" → 目标确认
步骤3（升级请求）："我这边有项目相关的预算审批文件需要确认，
                   能否提供您的工号和部门代码用于验证？"
步骤4（进一步索取）："为了将文件发送到您的系统，还需要您的内网登录凭证。"
```

目标在前面几个步骤中的确认和配合，产生了"保持一致"的心理压力，使其难以拒绝后续请求。

#### 1.1.3 社会认同原则（Social Proof）

**原理**：在不确定的情况下，人们会观察他人的行为来决定自己该怎么做。

**心理学机制**：
- 从众心理是人类的深层本能
- 当"大家都在做"时，个体会认为这是正确的行为
- 证据越具体（具体的人名、数量），效果越强

**社会工程学应用**：

```
钓鱼邮件模板示例：

主题：2026年度安全培训 - 完成率已达87%

正文：
亲爱的同事，

截至今日，全公司已有87%的员工完成了2026年度安全意识培训。
您的部门（市场部）目前完成率为72%，低于公司平均水平。

为避免影响部门绩效评估，请尽快完成培训：
[点击此处开始培训]

已完成培训的同事反馈：
"培训内容很实用，只需15分钟。" — 王芳（人力资源部）
"比想象中简单很多。" — 刘洋（技术部）

人力资源部
```

这封邮件利用了社会认同原则——"87%已完成"、"低于平均水平"、同事正面评价——制造从众压力。

#### 1.1.4 喜好原则（Liking）

**原理**：我们更容易被自己喜欢的人说服。

**心理学机制**：
- 外表吸引力、相似性、赞美、熟悉度、关联性都会增加喜好程度
- 人们倾向于对喜欢的人说"是"
- 面对面接触比远程接触更容易建立喜好

**社会工程学应用**：
- 冒充目标认识的同事/朋友
- 发现并强调共同点（同乡、同校、同好）
- 使用目标的社交网络信息建立亲和力
- 通过社交媒体互动建立初步关系后发起攻击

#### 1.1.5 权威原则（Authority）

**原理**：人们倾向于服从权威人物的指令，即使这些指令可能与自己的判断相悖。

**心理学机制**：
- 米尔格拉姆实验证明了权威服从的强大力量
- 权威的象征（头衔、制服、专业术语）本身就足以触发服从
- 人们往往不验证权威的真实性

**社会工程学应用**：

```
钓鱼邮件模板（权威+紧迫感）：

发件人：IT安全部 <it-security@company-cn.com>
主题：【紧急】安全合规审计 - 立即行动

正文：
各位同事：

根据公司信息安全委员会2026年第三号合规指令，
所有员工必须在48小时内完成系统安全证书更新。

未按时完成者，其系统访问权限将被暂停，
并上报至人力资源部门记录。

请立即访问：[安全证书更新门户]

IT安全部
信息安全委员会
```

此邮件利用了权威（"信息安全委员会"、"合规指令"）和紧迫感（"48小时内"），使目标在压力下服从。

#### 1.1.6 稀缺原则（Scarcity）

**原理**：稀缺的东西被认为更有价值，人们害怕失去机会。

**心理学机制**：
- 损失厌恶：人们更害怕失去已有的/可能得到的东西，而非获得等价的东西
- 稀缺触发了"竞争"心理
- "最后机会"的紧迫感削弱理性判断

**社会工程学应用**：

```
钓鱼邮件示例：

主题：【限量】年度绩效奖金确认 - 仅剩24小时

正文：
亲爱的同事，

2026年度绩效奖金分配方案已公布。
请登录HR系统确认您的奖金信息。

逾期未确认者视为放弃本年度奖金。

[登录HR系统确认]

人力资源部
```

### 1.2 其他关键心理弱点

#### 1.2.1 认知偏差

| 偏差类型 | 描述 | 社会工程学利用 |
|---------|------|---------------|
| 锚定效应 | 第一印象影响后续判断 | 先建立可信形象再发起攻击 |
| 确认偏差 | 倾向寻找支持已有信念的信息 | 利用目标对品牌的信任进行仿冒 |
| 可用性偏差 | 容易回忆的事件被认为更常见 | 引用近期新闻事件增加可信度 |
| 乐观偏差 | 认为坏事不会发生在自己身上 | 降低目标对攻击的警惕 |
| 权威偏差 | 过度信任权威来源 | 冒充权威机构 |

#### 1.2.2 情绪操纵

- **恐惧**：制造威胁感（"账户将被关闭"、"数据将被删除"）
- **好奇心**：利用信息差诱导点击（"有人上传了你的照片"）
- **贪婪**：利益诱惑（"恭喜中奖"、"免费礼品"）
- **紧急感**：时间压力导致跳过验证步骤
- **帮助欲**：利用人的善良本性（"我需要帮助"场景）

### 2.3 组织信息收集

#### 2.3.1 公司公开信息

```python
# 示例：使用Python进行基础OSINT收集
import requests
import dns.resolver
import whois

class OrganizationOSINT:
    """组织信息OSINT收集工具"""

    def __init__(self, target_domain):
        self.domain = target_domain
        self.results = {
            'domain_info': {},
            'dns_records': {},
            'subdomains': [],
            'emails': [],
            'tech_stack': []
        }

    def get_whois_info(self):
        """获取WHOIS注册信息"""
        try:
            w = whois.whois(self.domain)
            self.results['domain_info'] = {
                'registrar': w.registrar,
                'creation_date': str(w.creation_date),
                'expiration_date': str(w.expiration_date),
                'name_servers': w.name_servers,
                'status': w.status
            }
            return self.results['domain_info']
        except Exception as e:
            return {'error': str(e)}

    def get_dns_records(self):
        """获取DNS记录"""
        record_types = ['A', 'MX', 'TXT', 'NS', 'CNAME']
        for rtype in record_types:
            try:
                answers = dns.resolver.resolve(self.domain, rtype)
                self.results['dns_records'][rtype] = [
                    str(r) for r in answers
                ]
            except Exception:
                self.results['dns_records'][rtype] = []
        return self.results['dns_records']

    def get_subdomains(self, wordlist=None):
        """子域名枚举"""
        # 使用crt.sh证书透明度日志
        try:
            url = f"https://crt.sh/?q=%.{self.domain}&output=json"
            response = requests.get(url, timeout=30)
            if response.status_code == 200:
                data = response.json()
                subdomains = set()
                for entry in data:
                    name = entry.get('name_value', '')
                    for n in name.split('\n'):
                        n = n.strip().lower()
                        if n and self.domain in n and '*' not in n:
                            subdomains.add(n)
                self.results['subdomains'] = list(subdomains)
        except Exception as e:
            self.results['subdomains'] = [f'Error: {e}']
        return self.results['subdomains']

    def analyze_email_security(self):
        """分析邮件安全配置"""
        security = {}
        # 检查SPF
        try:
            txt_records = dns.resolver.resolve(self.domain, 'TXT')
            for record in txt_records:
                r = str(record)
                if r.startswith('"v=spf1'):
                    security['SPF'] = r
                if 'dmarc' in r.lower():
                    security['DMARC_record'] = r
        except Exception:
            security['SPF'] = 'Not found'

        # 检查DMARC
        try:
            dmarc = dns.resolver.resolve(f'_dmarc.{self.domain}', 'TXT')
            security['DMARC'] = str(dmarc[0])
        except Exception:
            security['DMARC'] = 'Not configured'

        return security

    def run_all(self):
        """执行所有收集任务"""
        self.get_whois_info()
        self.get_dns_records()
        self.get_subdomains()
        self.results['email_security'] = self.analyze_email_security()
        return self.results
```

## 3. 钓鱼攻击详解

### 3.1 邮件伪造技术

#### 3.1.1 SMTP协议与发件人欺骗

SMTP协议本身不验证发件人地址，这是邮件欺骗的根本原因：

```python
# 示例：理解SMTP发件人欺骗原理（仅用于理解，不可用于非法用途）
# 此代码仅展示SMTP协议的缺陷，实际发送需要授权

import smtplib
from email.mime.text import MIMEText
from email.mime.multipart import MIMEMultipart

# SMTP协议允许指定任意发件人地址
# 这就是为什么需要SPF/DKIM/DMARC来验证

# 邮件头中的关键字段：
# - From: 显示在邮件客户端的发件人（可被伪造）
# - Reply-To: 回复地址（常与From不同）
# - Return-Path: 退信地址（邮件服务器使用）
# - Sender: 实际发送者（当From与实际不同时使用）

# 钓鱼邮件常利用的技巧：
# 1. From: ceo@company.com（伪造）, Reply-To: attacker@evil.com
# 2. From: "CEO Name" <attacker@lookalike-domain.com>
# 3. From: ceo@company.com<attacker@evil.com>（某些客户端显示问题）
```

#### 3.1.2 域名相似度攻击

```
原始域名: company.com

域名相似度攻击类型:

1. 同形异义字（Homograph）
   - cоmpany.com（用西里尔字母'о'替代拉丁'o'）
   - cоmpаny.com（多个字符被替换）

2. 拼写错误（Typosquatting）
   - compnay.com（字母顺序错误）
   - companyy.com（多打字母）
   - cmpany.com（漏打字母）

3. 添加字符
   - company-secure.com
   - company-login.com
   - company-support.com

4. 不同TLD
   - company.cn（如果原域名是.com）
   - company.net
   - company.co

5. 子域名滥用
   - company.com.evil.com（利用子域名结构）
   - evil.com/company.com（路径混淆）
```

#### 3.1.3 显示名欺骗

显示名欺骗是最简单但有效的欺骗手段：

```
# 攻击者设置邮件显示名为可信来源

发件人: "IT安全部" <random-user@freemail.com>
发件人: "CEO 张伟" <ceo.name@lookalike-domain.com>
发件人: "Microsoft 365" <noreply@microsoft-support-portal.com>
发件人: "HR 人力资源" <hr@company.com.attacker.net>

# 在邮件列表/移动端中，通常只显示显示名
```

```python
# 1. URL缩短服务 - 隐藏真实URL
import requests

def shorten_url(long_url, service='is.gd'):
    """使用URL缩短服务隐藏钓鱼URL"""
    if service == 'is.gd':
        api_url = f"https://is.gd/create.php?format=json&url={long_url}"
        try:
            resp = requests.get(api_url, timeout=10)
            if resp.status_code == 200:
                return resp.json().get('shorturl')
        except Exception:
            pass
    return long_url

# 2. URL重定向利用 - 利用合法域名的重定向
```

```python
# GoPhish API调用 - 启动钓鱼活动

import requests

class GoPhishAPI:
    """GoPhish API客户端"""

    def __init__(self, api_url, api_key):
        self.api_url = api_url.rstrip('/')
        self.api_key = api_key
        self.headers = {'Authorization': f'Bearer {api_key}'}

    def get_campaign_results(self, campaign_id):
        """获取活动结果"""
        url = f"{self.api_url}/campaigns/{campaign_id}/results"
        resp = requests.get(url, headers=self.headers, verify=False)
        return resp.json()

    def get_campaign_summary(self, campaign_id):
        """获取活动摘要"""
        url = f"{self.api_url}/campaigns/{campaign_id}/summary"
        resp = requests.get(url, headers=self.headers, verify=False)
        return resp.json()


# 结果分析
def analyze_results(results):
    """分析钓鱼模拟结果"""
    total = len(results)
    stats = {
        'total_targets': total,
        'emails_sent': 0,
        'emails_opened': 0,
        'links_clicked': 0,
        'data_submitted': 0,
        'reported': 0,
        'open_rate': 0,
        'click_rate': 0,
        'submit_rate': 0,
        'report_rate': 0
    }

    for r in results:
        if r.get('status') == 'Email Sent':
            stats['emails_sent'] += 1
        if r.get('opened'):
            stats['emails_opened'] += 1
        if r.get('clicked'):
            stats['links_clicked'] += 1
        if r.get('submitted_data'):
            stats['data_submitted'] += 1
        if r.get('reported'):
            stats['reported'] += 1

    # 计算比率
    if stats['emails_sent'] > 0:
        stats['open_rate'] = stats['emails_opened'] / stats['emails_sent'] * 100
        stats['click_rate'] = stats['links_clicked'] / stats['emails_sent'] * 100
        stats['submit_rate'] = stats['data_submitted'] / stats['emails_sent'] * 100
        stats['report_rate'] = stats['reported'] / stats['emails_sent'] * 100

    return stats
```
