# 语音钓鱼与短信钓鱼

### 4.1 语音钓鱼（Vishing）

#### 4.1.1 Vishing攻击流程

```
┌───────────────────────────────────────────┐
│              Vishing攻击流程                │
├───────────────────────────────────────────┤
│                                           │
│  1. 目标选择与信息收集                      │
│     - 确定攻击目标                          │
│     - 收集目标的电话号码                    │
│     - 收集目标相关信息用于建立可信度          │
│                                           │
│  2. 身份准备                                │
│     - 选择冒充身份（IT支持/银行/政府）       │
│     - 准备话术和应对预案                    │
│     - 设置来电显示伪造（如需要）              │
│                                           │
│  3. 建立信任                                │
│     - 专业问候和自我介绍                    │
│     - 提供可验证的信息（工号、部门）          │
│     - 引用真实事件增加可信度                │
│                                           │
│  4. 信息获取                                │
│     - 说明"问题"并制造紧迫感                │
│     - 请求密码/MFA验证码/敏感信息            │
│     - 渐进式获取，避免一次性索要过多          │
│                                           │
│  5. 撤离                                    │
│     - 确认获取到所需信息                    │
│     - 礼貌结束通话                          │
│     - 清理通话痕迹                          │
│                                           │
└───────────────────────────────────────────┘
```

#### 4.1.2 Vishing话术模板

**场景：冒充IT技术支持**

```
攻击者：您好，请问是李明先生吗？
目标：是的，请问您是？
攻击者：李先生您好，我是公司IT运维中心的张伟，工号IT-2847。
        我们的监控系统显示您的办公电脑存在异常网络连接，
        可能感染了恶意软件，需要紧急处理。
目标：啊？严重吗？
攻击者：目前还在可控范围内，但需要尽快处理。
        请问您现在能打开电脑吗？
目标：可以的，我现在就在电脑前。
攻击者：好的，为了远程排查，我需要先验证您的身份。
        请问您的域账户用户名是什么？
目标：liming.zhao
攻击者：好的，为了远程连接到您的电脑进行排查，
        我还需要您提供一下当前的登录密码。
        这是IT安全规程要求的身份验证步骤。
目标：好的，密码是...
攻击者：收到。另外，您的手机上应该会收到一个6位数的验证码，
        那是远程连接的授权码，请告诉我。
目标：好的，验证码是384621。
攻击者：收到，感谢配合。排查大约需要30分钟，
        期间请不要使用电脑。如有问题请致电400-xxxx-xxxx。
```

### 4.2 短信钓鱼（Smishing）

#### 4.2.1 Smishing策略

```
常见Smishing场景：

1. 快递通知类
   "【顺丰速运】您的包裹SF1234567890因地址不详无法派送，
    请点击 http://sf-express-update.evil.com 更新配送信息。"

2. 银行通知类
   "【招商银行】您的信用卡尾号8888于09月11日14:23消费¥9,800。
    如非本人操作，请立即点击 http://cmb-verify.evil.com 取消。"

3. 政务通知类
   "【国家税务总局】您的2026年度个税汇算清缴有¥3,562退税待领取，
    请于24小时内点击 http://tax-refund-cn.evil.com 完成领取。"

4. 社交验证类
   "【微信安全】您的微信账号在其他设备登录，
    点击 http://weixin-secure.evil.com 验证身份，否则将被冻结。"
```

#### 4.2.2 Smishing技术细节

```python
# Smishing URL处理技术示例

# 1. URL缩短服务 - 隐藏真实URL
import requests

def shorten_url(long_url, service='is.gd'):
    """使用URL缩短服务隐藏钓鱼URL"""
    if service == 'is.gd':
        api_url = f"https://is.gd/create.php?format=json&url={long_url}"
        try:
            resp = requests.get(api_url, timeout=10)
            if resp.status_code == 200:
                return resp.json().get('shorturl')
        except Exception:
            pass
    return long_url

# 2. URL重定向利用 - 利用合法域名的重定向
#    例如: https://legitimate-site.com/redirect?url=http://evil.com
#    在短信中显示合法域名，实际跳转到钓鱼网站

# 3. Unicode URL混淆
#    使用Unicode字符使URL看起来像合法域名
#    pаypal.com（'а'是西里尔字母）

# 4. 移动端特定考虑
#    - 短信中URL预览功能有限
#    - 移动浏览器地址栏较窄，URL显示不全
#    - 移动端用户警惕性通常低于桌面端
```
