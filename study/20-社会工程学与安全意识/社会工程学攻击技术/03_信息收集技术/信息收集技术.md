# 信息收集技术

### 2.1 OSINT概述

OSINT（Open-Source Intelligence，开源情报）是从公开来源收集和分析信息的过程。在社会工程学中，OSINT是攻击的前置步骤，决定了攻击的精准度和成功率。

### 2.3 组织信息收集

#### 2.3.1 公司公开信息

```python
# 示例：使用Python进行基础OSINT收集
import requests
import dns.resolver
import whois

class OrganizationOSINT:
    """组织信息OSINT收集工具"""

    def __init__(self, target_domain):
        self.domain = target_domain
        self.results = {
            'domain_info': {},
            'dns_records': {},
            'subdomains': [],
            'emails': [],
            'tech_stack': []
        }

    def get_whois_info(self):
        """获取WHOIS注册信息"""
        try:
            w = whois.whois(self.domain)
            self.results['domain_info'] = {
                'registrar': w.registrar,
                'creation_date': str(w.creation_date),
                'expiration_date': str(w.expiration_date),
                'name_servers': w.name_servers,
                'status': w.status
            }
            return self.results['domain_info']
        except Exception as e:
            return {'error': str(e)}

    def get_dns_records(self):
        """获取DNS记录"""
        record_types = ['A', 'MX', 'TXT', 'NS', 'CNAME']
        for rtype in record_types:
            try:
                answers = dns.resolver.resolve(self.domain, rtype)
                self.results['dns_records'][rtype] = [
                    str(r) for r in answers
                ]
            except Exception:
                self.results['dns_records'][rtype] = []
        return self.results['dns_records']

    def get_subdomains(self, wordlist=None):
        """子域名枚举"""
        # 使用crt.sh证书透明度日志
        try:
            url = f"https://crt.sh/?q=%.{self.domain}&output=json"
            response = requests.get(url, timeout=30)
            if response.status_code == 200:
                data = response.json()
                subdomains = set()
                for entry in data:
                    name = entry.get('name_value', '')
                    for n in name.split('\n'):
                        n = n.strip().lower()
                        if n and self.domain in n and '*' not in n:
                            subdomains.add(n)
                self.results['subdomains'] = list(subdomains)
        except Exception as e:
            self.results['subdomains'] = [f'Error: {e}']
        return self.results['subdomains']

    def analyze_email_security(self):
        """分析邮件安全配置"""
        security = {}
        # 检查SPF
        try:
            txt_records = dns.resolver.resolve(self.domain, 'TXT')
            for record in txt_records:
                r = str(record)
                if r.startswith('"v=spf1'):
                    security['SPF'] = r
                if 'dmarc' in r.lower():
                    security['DMARC_record'] = r
        except Exception:
            security['SPF'] = 'Not found'

        # 检查DMARC
        try:
            dmarc = dns.resolver.resolve(f'_dmarc.{self.domain}', 'TXT')
            security['DMARC'] = str(dmarc[0])
        except Exception:
            security['DMARC'] = 'Not configured'

        return security

    def run_all(self):
        """执行所有收集任务"""
        self.get_whois_info()
        self.get_dns_records()
        self.get_subdomains()
        self.results['email_security'] = self.analyze_email_security()
        return self.results
```

#### 2.3.2 招聘信息分析

招聘信息是了解目标组织技术栈和组织架构的宝库：

- **技术岗位JD**：透露使用的技术栈（如"熟悉AWS、Kubernetes"→ 云原生环境）
- **安全岗位JD**：透露安全工具和架构（如"有Splunk经验"→ SIEM使用Splunk）
- **部门信息**：了解组织结构和团队规模
- **办公地点**：物理位置信息

### 2.4 社交媒体情报

#### 2.4.1 LinkedIn信息搜集

LinkedIn是社会工程攻击中最有价值的信息源之一：

```
收集要点：
├── 员工名单（姓名、职位、部门）
├── 组织架构（汇报关系、团队结构）
├── 技术栈信息（从技能标签和项目描述获取）
├── 入职/离职时间（判断新人 - 更易攻击的目标）
├── 联系方式（邮箱格式推断：firstname.lastname@company.com）
└── 活动信息（参加会议、培训 - 可用作pretexting素材）
```

#### 2.4.2 社交媒体信息

| 平台 | 可收集信息 | 搜索技巧 |
|------|-----------|---------|
| LinkedIn | 职位、技能、同事关系 | site:linkedin.com/company/{company} |
| GitHub | 代码、邮箱、技术栈 | 搜索组织仓库、提交记录 |

| Instagram | 地理位置、生活习惯 | 搜索公司标签 |

### 2.5 Google Dorks

Google Dorks是利用高级搜索语法发现敏感信息的技术：

```
常用Google Dork语法：

# 搜索暴露的文件
site:example.com filetype:pdf "confidential"
site:example.com filetype:xls "password"
site:example.com filetype:doc "internal"

# 搜索目录列表
site:example.com intitle:"index of" "parent directory"

# 搜索登录页面
site:example.com inurl:admin OR inurl:login

# 搜索错误信息（信息泄露）
site:example.com "SQL syntax error"
site:example.com "Warning: mysql_connect()"

# 搜索配置文件
site:example.com filetype:env "DB_PASSWORD"
site:example.com filetype:xml "password"

# 搜索Git仓库
site:example.com "/.git/"

# 搜索暴露的API文档
site:example.com inurl:api filetype:json
```
