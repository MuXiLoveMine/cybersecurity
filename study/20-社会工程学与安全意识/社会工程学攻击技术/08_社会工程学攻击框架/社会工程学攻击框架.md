# 社会工程学攻击框架

### 7.1 SET（Social Engineering Toolkit）

#### 7.1.1 SET安装

```bash
# Kali Linux中已预装
# 手动安装（Ubuntu/Debian）
git clone https://github.com/trustedsec/social-engineer-toolkit.git
cd social-engineer-toolkit
pip3 install -r requirements.txt
python3 setup.py install

# 启动SET
sudo setoolkit
```

### 7.2 BeEF（Browser Exploitation Framework）

#### 7.2.1 BeEF基本使用

```bash
# 安装BeEF
git clone https://github.com/beefproject/beef.git
cd beef
bundle install
./beef

# BeEF启动后默认在 http://127.0.0.1:3000
# 默认凭据: beef / beef

# 钩子（Hook）URL: http://<your-ip>:3000/hook.js
# 将此JS注入到目标网页中，当目标访问时被"钩住"
```
