# 水坑攻击

### 6.1 水坑攻击原理

水坑攻击（Watering Hole Attack）是一种间接攻击策略。攻击者不直接攻击目标，而是感染目标群体经常访问的合法网站，等待目标访问时被感染。

```
水坑攻击流程：

┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  1. 侦察     │────▶│  2. 入侵网站  │────▶│ 3. 植入代码  │
│  确定目标    │     │  利用网站漏洞 │     │  注入恶意JS  │
│  常访问网站  │     │  获取控制权   │     │  或重定向    │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                                 │
                                                 ▼
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  5. 数据窃取 │◀────│  4. 等待目标  │◀────│  目标访问    │
│  建立C2通道  │     │  访问被感染   │     │  被感染网站  │
│  持久化      │     │  网站        │     │             │
└─────────────┘     └──────────────┘     └─────────────┘
```

#### 6.2.2 水坑攻击案例

**著名案例：AAHM水坑攻击**

2021年，一个针对中国高校和科研院所的水坑攻击被发现。攻击者入侵了多个学术论坛和教育平台，植入恶意JavaScript代码。当目标高校的教职工和学生访问这些网站时，恶意代码利用浏览器漏洞植入木马程序，窃取科研数据和敏感信息。

**关键特征**：
- 目标群体明确（高校科研人员）
- 选择了目标群体高频访问的学术论坛
- 利用了当时最新的浏览器0day漏洞
- 攻击持续时间长，隐蔽性强
