### 二、OSINT 信息收集常用命令

#### 2.1 theHarvester - 邮箱/子域名收集
```bash
# 基本使用
theHarvester -d example.com -b all

# 指定数据源
theHarvester -d example.com -b google,bing,linkedin
theHarvester -d example.com -b hunter,securityTrails
theHarvester -d example.com -b all -l 500   # 限制结果数量

# 结果保存
theHarvester -d example.com -b all -f output.html  # HTML格式
theHarvester -d example.com -b all -f output.xml   # XML格式

# 可用数据源：
# baidu, bing, bingapi, censys, crtsh, dnsdumpster,
# duckduckgo, google, google-cse, hackerTarget,
# hunter, intelx, linkedin, netcraft, otx,
# securityTrails, shodan, spyse, threatcrowd,
# trello, twitter, vhost, virustotal, yahoo
```

#### 2.2 Maltego - 可视化情报分析
```
Maltego 常用实体（Entity）：
├── Person              - 人物
├── Company             - 公司
├── Email Address       - 邮箱地址
├── Phone Number        - 电话号码
├── Domain              - 域名
├── DNS Name            - DNS名称
├── IP Address          - IP地址
├── URL                 - 网址
├── Phrase              - 关键词
├── Location            - 位置
├── Image               - 图片
└── Document            - 文档

常用变换（Transform）：
├── To Email Addresses [using Search Engine]
├── To Domains [using Search Engine]
├── To DNS Name [to IP]
├── To IP [DNS resolve]
├── To Website [Quick lookup]
├── To Social Networks [name]
├── To Locations [address]
└── To Documents [by search engine]

工作流程：
1. 创建根节点（公司名/域名/人名）
2. 运行变换扩展信息
3. 手动筛选和关联
4. 添加笔记和证据
5. 生成关系图谱报告
```

#### 2.3 Sherlock - 全网用户名搜索
```bash
# 安装
git clone https://github.com/sherlock-project/sherlock.git
cd sherlock
pip install -r requirements.txt

# 基本使用
python3 sherlock username
python3 sherlock user1 user2 user3     # 多用户同时搜索

# 输出选项
python3 sherlock username --output results/   # 输出到目录
python3 sherlock username --csv               # CSV格式输出
python3 sherlock username --json              # JSON格式输出

# 搜索选项
python3 sherlock username --site twitter      # 只搜索指定网站
python3 sherlock username --print-found       # 只显示找到的
python3 sherlock username --no-color          # 无颜色输出
python3 sherlock username -t 5               # 超时时间（秒）
python3 sherlock username --proxy socks5://127.0.0.1:1080  # 代理
```

#### 2.4 h8mail - 邮箱密码泄露查询
```bash
# 安装
pip install h8mail

# 基本使用
h8mail -t target@example.com

# 批量查询
h8mail -t target1@example.com,target2@example.com
h8mail -t emails.txt               # 从文件读取

# 使用API查询
h8mail -t target@example.com \
  --config config.ini
# config.ini 配置：
# [h8mail_config]
# hibp_api = xxxxxxxxxxxx
# hunter_io = xxxxxxxxxxxx
# leakz_pub = xxxxxxxxxxxx

# 本地查询（使用泄露数据库）
h8mail -t target@example.com \
  -lb breach1.txt breach2.txt
# 数据库格式：email:password 或 email:hash

# 高级选项
h8mail -t target@example.com \
  --power-cw                        # 针对企业域名批量查询
h8mail -t example.com \
  --domain                          # 搜索整个域名的泄露
```

### 三、社工攻击技术分类与方法

#### 3.1 基于权威的攻击
```
利用人们对权威的服从心理

常见场景：
├── 冒充IT部门/系统管理员
│   ├── "我是IT部门的，需要远程协助您修复电脑问题"
│   ├── "安全部门检测到您的账户异常，请配合验证"
│   └── "系统升级，需要您提供验证码完成升级"
├── 冒充公司高管/老板
│   ├── "我是王总，现在在外面开会，急需转账"
│   ├── "我是董事长，马上把财务报表发给我"
│   └── "这是我的私人邮箱，公司邮箱出问题了"
├── 冒充政府/监管机构
│   ├── "税务局通知，请查收税务稽查通知"
│   ├── "社保局通知，您的社保账户异常"
│   └── "公安局通知，您涉嫌洗钱，请配合调查"
├── 冒充客户/合作伙伴
│   ├── "我是XX公司的采购，想下订单"
│   ├── "合同需要修改，请重新签署这份"
│   └── "我们的付款信息变更了，请更新"
└── 冒充技术支持
    ├── "您的电脑中了病毒，我来帮您清理"
    ├── "Windows检测到您的系统有问题"
    └── "您的订单有问题，我帮您处理退款"

识别要点：
├── 是否主动联系你
├── 是否制造紧迫感
├── 是否要求保密
├── 是否要求通过非正常渠道沟通
└── 是否涉及金钱或敏感信息
```

#### 3.2 基于紧迫感的攻击
```
利用人们在压力下做出错误判断的倾向

常见场景：
├── 账户安全类
│   ├── "您的账户将在24小时后被锁定"
│   ├── "检测到异地登录，请立即验证"
│   └── "密码即将过期，请尽快修改"
├── 订单/交易类
│   ├── "您的订单即将发货，请确认地址"
│   ├── "付款失败，请立即重新支付"
│   └── "限时优惠，最后3小时"
├── 法律/合规类
│   ├── "您有一份法院传票，请及时领取"
│   ├── "税务稽查通知，请配合调查"
│   └── "您的包裹涉嫌违禁品，请配合调查"
└── 紧急事件类
    ├── "您的家人出事了，急需医药费"
    ├── "我被绑架了，快打赎金"
    └── "紧急：公司被攻击了，快提供管理员密码"

防御要点：
├── 暂停一下，不要立即行动
├── 通过官方渠道核实
├── 不要点击邮件中的链接
├── 不要拨打邮件中的电话
└── 咨询同事或上级
```

#### 3.3 基于好感/相似性的攻击
```
利用人们对喜欢的人或相似的人更容易信任的心理

常见场景：
├── 老乡/校友攻击
│   ├── "我也是XX大学毕业的，学长你好"
│   ├── "听口音你是XX地方的吧，我也是"
│   └── "咱们是老乡，帮个忙呗"
├── 共同兴趣/爱好
│   ├── "你也喜欢跑步啊，我也是"
│   ├── "上次马拉松我好像见过你"
│   └── "我也用XX品牌的产品，确实不错"
├── 赞美和奉承
│   ├── "久仰大名，您在业内非常有名"
│   ├── "早就想认识您了"
│   └── "您的文章我看过，写得太好了"
└── 外表/形象塑造
    ├── 专业形象（西装、工牌）
    ├── 亲和力（微笑、眼神交流）
    └── 共同朋友/社交圈

防御要点：
├── 保持警惕，不要因为好感就放松
├── 核实对方身份
├── 按流程办事，不搞特殊
└── 公私分明
```

#### 3.4 基于互惠的攻击
```
利用人们有恩报恩的心理倾向

常见场景：
├── 小恩小惠
│   ├── "我帮你搞定了这个问题，你帮我个小忙呗"
│   ├── "这是一点小意思，请收下"
│   └── "我请你吃饭，顺便跟你说个事"
├── 主动提供帮助
│   ├── "看你挺忙的，我帮你吧"
│   ├── "这个问题我遇到过，我教你"
│   └── "我有内部消息，告诉你"
├── 让步策略
│   ├── "本来要10万，看你爽快给8万吧"
│   ├── "我退一步，你也让一步"
│   └── "大的不行，小的总可以吧"
└── 人情绑架
    ├── "上次我可是帮过你的"
    ├── "咱们这关系，你还不放心吗"
    └── "就当还我个人情"

防御要点：
├── 警惕无缘无故的好处
├── 公事公办，不欠人情
├── 按制度和流程办事
└── 该拒绝就拒绝
```

### 五、社工攻击检测与响应

#### 5.1 检测指标
```
可疑行为指标：
├── 邮件类
│   ├── 发件人地址异常（拼写错误、相似域名）
│   ├── 邮件头异常（SPF/DKIM/DMARC失败）
│   ├── 紧急/威胁性语言
│   ├── 可疑链接或附件
│   ├── 请求敏感信息
│   └── 不寻常的发送时间
├── 电话类
│   ├── 来电号码异常（未知/境外/隐藏号码）
│   ├── 口音或语言不自然
│   ├── 询问敏感信息
│   ├── 拒绝提供联系方式
│   ├── 催促或威胁
│   └── 背景噪音异常
├── 现场类
│   ├── 身份信息模糊
│   ├── 对公司情况不熟悉
│   ├── 行为紧张或异常
│   ├── 试图绕过安检
│   ├── 出现在不该出现的区域
│   └── 随身携带可疑物品
└── 网络类
    ├── 异常登录时间/地点
    ├── 多次登录失败
    ├── 异常数据访问
    ├── 可疑的内部查询
    └── 权限变更请求
```

#### 5.2 响应流程
```
社工攻击事件响应流程：
1. 识别与报告
   ├── 员工发现可疑情况
   ├── 通过安全渠道报告
   └── 安全团队初步确认

2. 遏制与隔离
   ├── 隔离受影响系统/账户
   ├── 重置泄露的凭证
   ├── 阻断攻击通信渠道
   └── 保留现场证据

3. 调查与分析
   ├── 收集攻击证据（邮件/录音/日志）
   ├── 分析攻击手法和目的
   ├── 评估受影响范围
   ├── 追踪攻击来源（如可能）
   └── 判断是否为定向攻击

4. 修复与恢复
   ├── 修复被利用的漏洞
   ├── 加固薄弱环节
   ├── 恢复正常业务
   └── 监控后续活动

5. 总结与改进
   ├── 编写事件报告
   ├── 更新安全策略
   ├── 加强员工培训
   └── 改进检测能力
```
