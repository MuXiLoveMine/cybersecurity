### 6.2 URL重写与实时检查

```
URL重写（URL Rewriting）工作流程：

1. 入站邮件处理
   邮件安全网关扫描邮件中的所有URL

2. URL重写
   原始URL: http://suspicious-link.com/login
   重写URL: https://url-protection.gateway.com/v1/
           ?url=aHR0cDovL3N1c3BpY2lvdXMtbGluay5jb20vbG9naW4=
            &signature=xxxxx

3. 用户点击重写URL
   → 请求到达邮件网关

4. 实时检查
   网关在用户点击时实时检查原始URL：
   - 查询威胁情报数据库
   - 检查URL信誉
   - 必要时在沙箱中打开页面
   - 检查页面内容

5. 安全决策
   - 安全：重定向到原始URL
   - 可疑：显示警告页面
   - 恶意：阻止访问并通知IT

优势：
- 点击时检查比收到时检查更准确
- 可以撤销之前认为安全的URL
- 提供点击日志和审计追踪
```

### 6.3 附件沙箱配置

```
附件沙箱策略配置示例：

规则1：可执行文件
├── 拦截所有.exe/.scr/.bat/.cmd/.ps1/.vbs文件
├── 即使在压缩包内也拦截
└── 不投递，通知发件人和收件人

规则2：Office文档
├── 含宏的文档 → 沙箱检测
├── 沙箱检测恶意 → 阻断
├── 沙箱检测可疑 → 隔离+通知管理员
├── 沙箱检测正常 → 投递但添加警告标签
└── 策略：可配置为移除宏后投递

规则3：PDF文件
├── 含JavaScript的PDF → 沙箱检测
├── 含嵌入对象的PDF → 沙箱检测
├── 正常PDF → 投递
└── 加密PDF（无法扫描）→ 隔离+通知收件人

规则4：压缩文件
├── 最大层数：3层
├── 最大大小：50MB
├── 密码保护的压缩包 → 隔离+通知收件人
└── 包含可执行文件 → 按规则1处理

规则5：URL和链接
├── 所有URL进行实时重写
├── 新注册域名URL → 警告
├── IP地址URL → 警告
├── 已知恶意URL → 阻断
└── URL缩短服务 → 展开后检查
```
