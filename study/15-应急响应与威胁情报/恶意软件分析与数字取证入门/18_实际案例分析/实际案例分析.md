# 实际案例分析

### 9.1 勒索软件分析案例

```
WannaCry勒索软件分析案例：

1. 初始发现
   - 2017年5月12日大规模爆发
   - 利用EternalBlue (MS17-010)蠕虫式传播
   - 150个国家、30万台计算机受影响

2. 静态分析发现
   - PE32可执行文件
   - 使用UPX加壳
   - 包含比特币地址
   - 包含Tor隐藏服务地址
   - 加密算法: AES-128-CBC + RSA-2048

3. 动态分析发现
   - 释放以下文件:
     * @WanaDecryptor@.exe (勒索界面)
     * @WanaDecryptor@.bmp (桌面壁纸)
     * taskdl.exe (数据删除)
     * taskse.exe (勒索提示)
     * msg/ (多语言勒索信息)
   
   - 执行操作:
     * 创建互斥体 Global\\MsWin_Zones_Cache.0
     * 修改注册表启动项
     * 使用Windows Crypto API加密文件
     * 加密170+种文件扩展名
     * 删除卷影副本(vssadmin)

4. Kill-switch发现
   - 查询域名 iuqerfsodp9ifjaposdfjhgosurijfaewrwergwea.com
   - 若域名可解析则停止传播
   - 安全研究员注册该域名遏制了传播

5. IOC提取
   - 哈希: SHA256 (多个变种)
   - 互斥体: Global\\MsWin_Zones_Cache.0
   - 文件: @WanaDecryptor@.exe
   - 域名: iuqerfsodp9ifjaposdfjhgosurijfaewrwergwea.com
   - 比特币地址: 3 hardcoded addresses
```

### 9.2 APT攻击取证案例

```
APT28 (Fancy Bear) 取证案例：

1. 初始入侵
   - 鱼叉式钓鱼邮件
   - 附件: .docx文件包含CVE-2017-0199漏洞
   - 触发远程下载HTA文件

2. 持久化机制
   - 注册表Run键
   - 计划任务
   - WMI事件订阅
   - 启动文件夹LNK

3. 执行链
   - Winword.exe -> cmd.exe
   - cmd.exe -> powershell.exe
   - powershell.exe下载Sofacy后门
   - Sofacy注入explorer.exe

4. C2通信
   - HTTP/HTTPS通道
   - 伪装Google流量
   - 使用Twitter头像图片隐写C2配置

5. 横向移动
   - Pass-the-Hash
   - WMI远程执行
   - SMB共享传播

6. 数据外传
   - 压缩打包
   - 分段上传到云存储
   - 使用合法云服务外传

7. 取证发现
   - Prefetch记录
   - 事件日志 4688 (进程创建)
   - PowerShell脚本块日志 4104
   - 注册表时间戳
   - 网络流量日志
```

### 9.3 无文件恶意软件分析

```
PowerShell无文件攻击分析：

1. 初始投递
   - 邮件附件: .lnk快捷方式
   - 快捷方式目标: powershell.exe -enc [Base64]
   
2. 内存执行链
   Stage 1: PowerShell解码执行
   Stage 2: 下载脚本块注入内存
   Stage 3: 反射加载.NET程序集
   Stage 4: 注入合法进程

3. 取证挑战
   - 无文件落盘
   - 进程注入后原始代码消失
   - PowerShell日志可能未启用

4. 取证方法
   - 内存取证 (Volatility malfind)
   - PowerShell脚本块日志 (Event ID 4104)
   - AMSI日志
   - 网络流量分析
   - CLR审计日志

5. 关键证据
   - 进程内存中的.NET程序集
   - PowerShell命令历史
   - AMSI捕获的脚本内容
   - 网络PCAP中的下载行为
```
