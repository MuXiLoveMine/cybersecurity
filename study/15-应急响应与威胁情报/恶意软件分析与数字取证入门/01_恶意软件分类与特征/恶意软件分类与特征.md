# 恶意软件分类与特征

### 1.1 恶意软件基本分类

恶意软件（Malware）是根据其行为和传播方式进行分类的。以下是主要类型：

| 类型 | 中文名 | 描述 | 典型示例 |
|------|--------|------|----------|
| Virus | 病毒 | 需要宿主文件，通过感染其他文件传播 | CIH、ILOVEYOU |
| Worm | 蠕虫 | 自我传播，无需宿主文件，利用网络漏洞 | Conficker、Stuxnet |
| Trojan | 木马 | 伪装成合法软件，包含隐藏恶意功能 | Emotet、TrickBot |
| Ransomware | 勒索软件 | 加密用户文件并要求赎金 | WannaCry、LockBit |
| Spyware | 间谍软件 | 隐秘收集用户信息并外传 | Pegasus、FinFisher |
| Adware | 广告软件 | 强制展示广告，收集用户行为 | Fireball |
| Rootkit | Rootkit | 深度隐藏自身及恶意活动 | NTRootkit、ZeroAccess |
| Botnet | 僵尸网络 | 将受控主机组成网络用于攻击 | Mirai、Andromeda |
| Backdoor | 后门 | 提供远程隐蔽访问通道 | njRAT、DarkComet |
| Downloader | 下载器 | 下载并安装其他恶意软件 | BumbleBee |
| Loader | 加载器 | 在内存中加载恶意载荷 | Cobalt Strike Beacon |
| Cryptominer | 挖矿木马 | 劫持CPU/GPU资源进行加密货币挖矿 | XMRig、Coinhive |
| Wiper | 擦除器 | 破坏性删除数据 | Shamoon、NotPetya |
| Fileless Malware | 无文件恶意软件 | 仅在内存中运行，不落盘 | Powelike、Kovter |

### 1.2 恶意软件命名规范

业界普遍采用 CARO（恶意软件研究组织计算机防病毒研究组织）命名规范：

```
[类型]:[平台]/[家族].[变体][!附加信息]
```

示例解析：

```
W32:Win32/WannaCry.A!dam
```

- `W32` - 平台标识（32位Windows）
- `Win32` - 详细平台
- `WannaCry` - 恶意软件家族名
- `A` - 变体标识
- `dam` - 附加信息（damaged/损坏的文件）

### 1.4 恶意软件传播途径

```
传播途径分析：

1. 电子邮件
   - 钓鱼邮件 (Phishing)
   - 鱼叉式钓鱼 (Spear Phishing)
   - 鲸鱼攻击 (Whaling - 针对高管)
   - 邮件附件 (Office宏、PDF漏洞、ZIP)
   - 恶意链接

2. 漏洞利用
   - 服务端漏洞 (SMB、RDP、Web)
   - 客户端漏洞 (浏览器、Office)
   - 零日漏洞 (0-day)
   - N-day漏洞利用
   - Exploit Kit (RIG、Sundown)

3. 可移动媒体
   - USB自动运行
   - 快捷方式漏洞
   - 文件感染
   - 社会工程

4. 供应链攻击
   - 软件更新机制
   - 开源库投毒
   - 开发工具链攻击
   - MSP服务商入侵

5. 社会工程
   - 假冒软件
   - 虚假广告
   - 伪装破解工具
   - 虚假技术支持

6. 网络传播
   - 蠕虫自我复制
   - 暴力破解 (SMB、RDP、SSH)
   - Pass-the-Hash
   - 共享文件夹感染
```
