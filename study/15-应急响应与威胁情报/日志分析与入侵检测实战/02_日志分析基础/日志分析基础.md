# 日志分析基础

### 1.1 日志类型与来源

| 日志类型 | 来源 | 格式 | 内容 |
|----------|------|------|------|
| Windows安全日志 | Event Log (.evtx) | XML | 登录/权限/审计 |
| Windows系统日志 | Event Log | XML | 系统事件/错误 |
| Windows PowerShell | Event Log | XML | 脚本执行 |
| Linux auth.log | syslog | 文本 | 认证/授权 |
| Linux syslog | syslog | 文本 | 系统事件 |
| Linux audit | auditd | 文本 | 系统调用审计 |
| Apache访问日志 | access.log | CLF/JSON | HTTP请求 |
| Nginx访问日志 | access.log | 自定义 | HTTP请求 |
| 数据库日志 | DB引擎 | 文本/二进制 | 查询/连接 |
| 防火墙日志 | 防火墙 | syslog | 允许/拒绝 |
| IDS/IPS日志 | IDS/IPS | CEF/LEEF | 告警/事件 |
| EDR日志 | EDR代理 | JSON | 端点遥测 |

### 1.2 日志分析方法论

```
日志分析层次:

  Level 1 - 单条日志分析
    - 理解单条日志含义
    - 识别异常字段

  Level 2 - 关联分析
    - 时间关联(时间线)
    - 实体关联(用户/IP/主机)
    - 因果关联(登录->文件操作->进程)

  Level 3 - 统计分析
    - 频率统计
    - 异常检测
    - 趋势分析

  Level 4 - 行为分析
    - 基线对比
    - 用户行为分析(UEBA)
    - 机器学习检测
```
