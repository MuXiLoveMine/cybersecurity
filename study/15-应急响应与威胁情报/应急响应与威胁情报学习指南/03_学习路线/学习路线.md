# 学习路线

### 阶段 1：应急响应基础（1-2 个月）
**学习目标**：掌握应急响应基础知识和流程

**学习内容**
- 应急响应概念与流程
- 日志分析基础
- Windows 日志
- Linux 日志
- 常见攻击检测
- 应急响应工具

**实践任务**
- 学习应急响应流程
- 分析 Windows 日志
- 分析 Linux 日志
- 分析 Web 日志
- 使用日志分析工具
- 做简单的应急响应练习

### 阶段 2：入侵检测与分析（2-3 个月）
**学习目标**：掌握入侵检测和事件分析技术

**学习内容**
- 入侵检测系统
- 告警分析与处理
- 常见攻击检测
- 内网攻击检测
- 恶意代码基础
- SIEM 基础

**实践任务**
- 部署 IDS/IPS
- 配置检测规则
- 分析告警
- 做事件分析练习
- 部署 SIEM
- 分析安全事件

### 阶段 3：恶意代码与取证（3-4 个月）
**学习目标**：掌握恶意代码分析和数字取证技术

**学习内容**
- 恶意代码分析
- 静态分析
- 动态分析
- 沙箱使用
- 数字取证基础
- 内存取证
- 网络取证
- 取证报告编写

**实践任务**
- 分析恶意样本
- 使用分析工具
- 使用沙箱
- 做内存取证练习
- 做网络取证练习
- 写取证报告

### 阶段 4：威胁情报与威胁狩猎（2-3 个月）
**学习目标**：掌握威胁情报和威胁狩猎技术

**学习内容**
- 威胁情报基础
- 威胁情报源
- 威胁情报平台
- 威胁情报应用
- 威胁狩猎方法
- MITRE ATT&CK
- APT 分析
- 蜜罐技术

**实践任务**
- 使用威胁情报平台
- 分析威胁情报
- 做威胁狩猎练习
- 研究 APT 组织
- 部署蜜罐
- 用 ATT&CK 分析攻击

### 阶段 5：安全运营与高级技术（持续）
**学习目标**：掌握安全运营和高级应急响应技术

**学习内容**
- SOC 运营
- SOAR 自动化
- 高级事件响应
- 勒索软件响应
- APT 事件响应
- 应急响应管理
- 安全运营管理

**实践任务**
- 运营 SOC
- 使用 SOAR
- 处理复杂事件
- 做应急演练
- 制定应急预案
- 持续改进
