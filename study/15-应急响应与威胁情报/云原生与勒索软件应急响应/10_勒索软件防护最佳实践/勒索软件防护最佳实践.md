# 勒索软件防护最佳实践

### 9.1 备份策略（3-2-1-1规则）

```
3 - 保留3份副本（1份生产 + 2份备份）
2 - 使用2种不同介质（磁盘 + 磁带/云）
1 - 1份离线备份（物理隔离）
1 - 1份不可变备份（Immutable Backup）
```

```bash
# 不可变备份配置示例（AWS S3 Object Lock）
aws s3api create-bucket \
  --bucket immutable-backup \
  --object-lock-enabled-for-bucket

aws s3api put-object-lock-configuration \
  --bucket immutable-backup \
  --object-lock-configuration '{
    "ObjectLockEnabled": "Enabled",
    "Rule": {
      "DefaultRetention": {
        "Mode": "COMPLIANCE",
        "Days": 90
      }
    }
  }'

# 上传备份时启用对象锁定
aws s3api put-object \
  --bucket immutable-backup \
  --key daily-backup-$(date +%Y%m%d).tar.gz \
  --body backup.tar.gz \
  --object-lock-mode COMPLIANCE \
  --object-lock-retain-until-date $(date -d '+90 days' -u +%Y-%m-%dT%H:%M:%SZ)
```

### 9.2 网络分段与微隔离

```yaml
# Kubernetes网络策略 - 默认拒绝
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny-all
  namespace: production
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  - Egress
  ingress: []
  egress: []
---
# 允许特定Pod间的通信
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-web-to-db
  namespace: production
spec:
  podSelector:
    matchLabels:
      app: database
  policyTypes:
  - Ingress
  ingress:
  - from:
    - podSelector:
        matchLabels:
          app: web-server
    ports:
    - protocol: TCP
      port: 5432
```

### 9.3 终端防护加固

```powershell
# Windows防护加固
# 1. 启用勒索软件防护（受控文件夹访问）
Set-MpPreference -EnableControlledFolderAccess Enabled

# 添加受保护文件夹
Add-MpPreference -ControlledFolderAccessProtectedFolders "C:\CriticalData"

# 添加允许的应用
Add-MpPreference -ControlledFolderAccessAllowedApplications "C:\App\legitimate.exe"

# 2. 启用攻击面减少(ASR)规则
Set-MpPreference -AttackSurfaceReductionRules_Ids @(
  "BE9BA2D9-53EA-4CDC-84E2-CT9D9441D2B7"  # 阻止可执行邮件附件
  "D4F940AB-401B-4EFC-ADBC-67D88E8C80B4"  # 阻止所有Office应用程序创建子进程
  "75668C1F-73B5-4CF0-B5A4-BC7N9A8C8E2C"  # 阻止凭据提取
  "C1DB55AB-CF9E-4A87-BF8C-8C9DC9D4C3E1"  # 阻止PSExec的子进程
) -AttackSurfaceReductionRules_Actions Enabled

# 3. 启用网络保护
Set-MpPreference -EnableNetworkProtection Enabled

# 4. 禁用SMBv1
Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol
Set-SmbServerConfiguration -EnableSMB1Protocol $false

# 5. 启用Windows Defender防火墙日志
Set-NetFirewallProfile -Profile Domain -LogFileName "%SystemRoot%\System32\LogFiles\Firewall\pfirewall.log" -LogMaxSizeKB 16384 -LogBlocked True -LogAllowed False
```

### 9.4 监控与告警

```yaml
# Falco规则 - 勒索软件行为检测
- rule: Ransomware File Encryption Activity
  desc: Detect mass file encryption activity
  condition: >
    open_write and
    (fd.name endswith .locked or
     fd.name endswith .encrypted or
     fd.name endswith .crypted or
     fd.name endswith .lockbit or
     fd.name endswith .conti or
     fd.name endswith .akira) and
    not proc.name in (known_encryptors)
  output: >
    Ransomware activity detected!
    (user=%user.name proc=%proc.name pid=%proc.pid
    container_id=%container.id file=%fd.name)
  priority: CRITICAL
  tags: [ransomware, encryption, mitre_impact]

- rule: Mass File Modification
  desc: Detect mass file modification in short time
  condition: >
    open_write and
    evt.type in (open,openat,openat2) and
    fd.type=file and
    (k8s.ns.name or container.name)
  output: >
    Mass file modification (user=%user.name proc=%proc.name
    file=%fd.name container=%container.name ns=%k8s.ns.name)
  priority: WARNING
  tags: [ransomware, mass_modification]

- rule: Shadow Copy Deletion
  desc: Detect VSS shadow copy deletion (ransomware precursor)
  condition: >
    spawned_process and proc.name in (vssadmin, wmic, wbadmin, powershell)
    and
    (proc.args contains "delete" and proc.args contains "shadow")
  output: >
    Shadow copy deletion detected!
    (user=%user.name proc=%proc.name args=%proc.args)
  priority: CRITICAL
  tags: [ransomware, vss_deletion, mitre_impact]

- rule: Backup Software Termination
  desc: Detect backup software termination
  condition: >
    spawned_process and proc.name in (kill, pkill, killall)
    and
    (proc.args contains "backup" or
     proc.args contains "veeam" or
     proc.args contains "commvault" or
     proc.args contains "acronis")
  output: >
    Backup software termination detected!
    (user=%user.name proc=%proc.name target=%proc.args)
  priority: CRITICAL
  tags: [ransomware, backup_termination]
```

### 9.5 安全基线检查清单

| 检查项 | 检查内容 | 风险等级 |
|--------|----------|----------|
| RDP访问 | 是否限制来源IP | 高 |
| SMB配置 | 是否禁用SMBv1 | 高 |
| 备份策略 | 是否有离线/不可变备份 | 严重 |
| 终端防护 | 是否部署EDR | 高 |

| 权限管理 | 是否实施最小权限原则 | 中 |
| 网络分段 | 关键系统是否网络隔离 | 高 |
| 日志监控 | 是否监控异常文件操作 | 高 |
| 员工培训 | 是否定期安全意识培训 | 中 |
