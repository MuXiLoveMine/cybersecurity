# 云环境应急响应概述

### 1.1 云环境与传统环境差异

云环境的弹性和共享特性从根本上改变了应急响应的工作方式。以下从多个维度对比两者差异。

| 维度 | 传统环境 | 云环境 |
|------|----------|--------|
| 基础设施 | 物理服务器、固定网络 | 虚拟机、容器、Serverless，弹性伸缩 |
| 资源控制 | 完全自主控制 | 云厂商与租户共享控制（共享责任模型） |
| 取证方式 | 磁盘镜像、内存dump | 云存储快照、云API日志、容器镜像导出 |
| 网络边界 | 物理防火墙、VLAN | 安全组、VPC、微隔离、网络策略 |
| 日志来源 | 本地系统日志 | 云监控、CloudTrail、VPC Flow Log、审计日志 |
| 弹性恢复 | 备份恢复较慢 | 基础设施即代码快速重建 |
| 多租户影响 | 通常无 | 侧向攻击可能影响同租户工作负载 |
| 工具链 | 本地脚本 + 商用工具 | 云CLI + 云SDK + 容器工具链 |

**关键差异解析：**

1. **基础设施瞬态性**：容器和Serverless实例生命周期可能只有秒级，传统"到现场取证"模式失效
2. **控制平面攻击面**：云API（如AWS IAM、Kubernetes API Server）成为主要攻击目标
3. **身份即边界**：云环境中身份凭据（AK/SK、ServiceAccount Token）是核心防线
4. **不可变基础设施**：工作负载不可变意味着证据可能随实例销毁而消失

### 1.2 云环境责任边界（共享责任模型）

**共享责任模型**是云安全的基石，明确云厂商和租户各自负责的安全范围。

```
┌─────────────────────────────────────────────┐
│                 SaaS                         │
│  云厂商负责: 应用、数据、OS、基础设施         │
│  租户负责: 数据访问控制、身份管理              │
├─────────────────────────────────────────────┤
│                 PaaS                         │
│  云厂商负责: OS、基础设施、运行时              │
│  租户负责: 应用代码、数据、访问控制            │
├─────────────────────────────────────────────┤
│                 IaaS                         │
│  云厂商负责: 基础设施(物理、虚拟化)            │
│  租户负责: OS、应用、数据、网络配置            │
├─────────────────────────────────────────────┤
│              本地部署                         │
│  租户负责: 全部                                │
└─────────────────────────────────────────────┘
```

**应急响应中的责任划分示例：**

| 安全事件类型 | IaaS | PaaS | SaaS |
|-------------|------|------|------|
| 虚拟机入侵 | 租户负责 | 云厂商负责OS层 | 云厂商负责 |
| 应用漏洞利用 | 租户负责 | 租户负责应用层 | 云厂商负责 |
| 数据泄露 | 租户负责 | 租户负责 | 共同负责 |
| 云平台漏洞 | 云厂商负责 | 云厂商负责 | 云厂商负责 |
| IAM凭据泄露 | 租户负责 | 租户负责 | 租户负责 |

### 1.3 云环境应急响应工具链

```bash
# AWS CLI - 云资源操作
aws sts get-caller-identity                    # 确认当前身份
aws cloudtrail lookup-events --start-time ...  # 查询审计事件
aws ec2 describe-instances                     # 查询EC2实例
aws s3api list-buckets                          # 查询S3桶

# kubectl - Kubernetes操作
kubectl get pods --all-namespaces              # 查询所有Pod
kubectl get events --all-namespaces           # 查询集群事件
kubectl logs <pod> -n <namespace>              # 查看Pod日志
kubectl describe pod <pod> -n <namespace>      # Pod详细信息

# Docker - 容器操作
docker ps -a                                   # 查看所有容器
docker inspect <container_id>                  # 容器详情
docker save <image> -o image.tar              # 导出镜像
docker logs <container_id>                     # 容器日志

# crictl - 容器运行时工具(替代docker)
crictl ps                                      # 查看运行容器
crictl inspect <container_id>                  # 容器详情
crictl logs <container_id>                     # 容器日志

# Falco - 容器运行时安全监控
falco --list                                   # 列出规则
falco -r rules/                                 # 加载自定义规则
```
