# 勒索软件应急响应流程

### 8.1 流程总览

勒索软件应急响应遵循PICERL模型，但需要特别强调**隔离**的优先性。

```
发现勒索 → [隔离] → [识别] → [抑制] → [根除] → [恢复] → [总结]
    ↑          ↑         ↑        ↑        ↑        ↑        ↑
  告警/报告  网络隔离   家族识别  阻止扩散  清理恶意  备份恢复  攻击链还原
  用户报告   主机隔离   范围确认  清除持久化  修复路径  系统重建  防御改进
  监控告警   备份隔离   IOC提取             漏洞修复            经验教训
```

### 8.2 阶段1: 隔离

**隔离是勒索软件响应最关键的第一步。** 必须在分析之前完成隔离，防止勒索软件继续扩散和加密。

**1. 网络隔离**

```bash
# Windows主机网络隔离
# 方法1: 禁用网络适配器
netsh interface set interface "以太网" disable
netsh interface set interface "Wi-Fi" disable

# 方法2: 修改防火墙规则阻止所有出入站流量
# 注意：保留管理通道（如特定管理端口）
netsh advfirewall set allprofiles firewall policy blockinbound,blockoutbound
# 仅允许从管理网段访问
netsh advfirewall firewall add rule name="Emergency-Admin" dir=in action=allow protocol=TCP localport=3389 remoteip=10.0.0.0/24

# Linux主机网络隔离
# 方法1: 禁用网卡
ip link set eth0 down
ip link set ens33 down

# 方法2: iptables阻止所有流量（保留SSH管理）
iptables -P INPUT DROP
iptables -P OUTPUT DROP
iptables -P FORWARD DROP
# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT
# 允许管理网段SSH
iptables -A INPUT -s 10.0.0.0/24 -p tcp --dport 22 -j ACCEPT
iptables -A OUTPUT -d 10.0.0.0/24 -p tcp --sport 22 -j ACCEPT

# Kubernetes环境隔离
# 将受感染节点标记为不可调度
kubectl cordon <node-name>
# 驱逐节点上的Pod（谨慎操作）
kubectl drain <node-name> --ignore-daemonsets --delete-emptydir-data
# 如果需要完全隔离节点网络
# 在网络策略中添加拒绝规则
kubectl apply -f - <<EOF
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: quarantine-isolated-node
  namespace: default
spec:
  podSelector: {}
  policyTypes:
  - Ingress
  - Egress
  ingress: []
  egress: []
EOF
```

**2. 主机隔离**

```bash
# Windows: 断开SMB共享
net share /delete /y
# 停止Server服务（阻止文件共享）
net stop lanmanserver /y
# 停止远程注册表
net stop remoteregistry /y

# 断开所有网络共享会话
net session /delete /y
# 断开映射驱动器
net use * /delete /y

# Linux: 断开NFS/CIFS挂载
umount -a -t nfs,nfs4,cifs
# 停止SMB服务
systemctl stop smbd
systemctl stop nmbd
```

**3. 备份隔离（最关键）**

```
备份隔离优先级：
1. 立即断开备份存储与网络的连接（物理拔线或网络隔离）
2. 将云备份切换为只读模式
3. 锁定备份服务器账户
4. 检查备份是否被感染或加密
5. 保护备份恢复密钥
```

```bash
# AWS: 立即锁定S3备份桶
aws s3api put-bucket-versioning \
  --bucket my-backup-bucket \
  --versioning-configuration Status=Suspended

# 设置对象锁定(Object Lock)
aws s3api put-object-lock-configuration \
  --bucket my-backup-bucket \
  --object-lock-configuration '{
    "ObjectLockEnabled": "Enabled",
    "Rule": {
      "DefaultRetention": {
        "Mode": "COMPLIANCE",
        "Days": 365
      }
    }
  }'

# 修改桶策略拒绝所有写入
aws s3api put-bucket-policy \
  --bucket my-backup-bucket \
  --policy '{
    "Version": "2012-10-17",
    "Statement": [{
      "Sid": "DenyAllWrites",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::my-backup-bucket/*"
    }]
  }'

# 本地备份: 立即卸载备份存储
umount /backup
# 或设置只读
mount -o remount,ro /backup
```

### 8.3 阶段2: 识别

**1. 勒索家族识别**

```python
#!/usr/bin/env python3
"""勒索软件家族识别工具"""
import hashlib
import re
import json
import os

class RansomwareIdentifier:
    # 勒索软件特征库
    SIGNATURES = {
        'LockBit': {
            'extensions': ['.lockbit', '.lockbit3'],
            'ransom_notes': ['Restore_My_Files.txt'],
            'content_patterns': [
                r'LockBit\s+3\.0',
                r'lockbit[0-9a-z]*\.',
            ],
            'mutex': ['Global\\LockBit_Mutex'],
            'registry': [r'HKCU\\Software\\LockBit'],
        },
        'BlackCat': {
            'extensions': ['.alphv', '.blackcat'],
            'ransom_notes': ['recover.txt', 'HOW_TO_RECOVER_FILES.txt'],
            'content_patterns': [
                r'BlackCat\s+ALPHV',
                r'alphv',
            ],
        },
        'Conti': {
            'extensions': ['.conti'],
            'ransom_notes': ['readme.txt', 'FILES ENCRYPTED.txt'],
            'content_patterns': [
                r'Conti\s+ransomware',
                r'conti\.top',
            ],
        },
        'REvil': {
            'extensions': ['.revil', '.sodinokibi'],
            'ransom_notes': ['readme.txt'],
            'content_patterns': [
                r'REvil',
                r'Sodinokibi',
            ],
        },
        'Akira': {
            'extensions': ['.akira'],
            'ransom_notes': ['akira_readme.txt'],
            'content_patterns': [
                r'Akira\s+ransomware',
                r'akira',
            ],
        },
        'Hive': {
            'extensions': ['.hive'],
            'ransom_notes': ['HOW_TO_DECRYPT.txt'],
            'content_patterns': [
                r'Hive\s+ransomware',
            ],
        },
        'Cl0p': {
            'extensions': ['.Clop'],
            'ransom_notes': ['HOW_TO_DECRYPT.txt', 'CL0P_README.txt'],
            'content_patterns': [
                r'Cl0p',
                r'clop',
            ],
        },
    }

    def __init__(self):
        self.results = {}

    def identify_by_extension(self, file_path):
        """通过文件扩展名识别"""
        _, ext = os.path.splitext(file_path)
        ext_lower = ext.lower()
        matches = []
        for family, sig in self.SIGNATURES.items():
            if ext_lower in [e.lower() for e in sig['extensions']]:
                matches.append(family)
        return matches

    def identify_by_ransom_note(self, note_path):
        """通过勒索说明文件识别"""
        with open(note_path, 'r', errors='ignore') as f:
            content = f.read()
        
        matches = []
        for family, sig in self.SIGNATURES.items():
            for pattern in sig['content_patterns']:
                if re.search(pattern, content, re.IGNORECASE):
                    matches.append(family)
                    break
        return list(set(matches))

    def identify_by_note_name(self, note_filename):
        """通过勒索说明文件名识别"""
        matches = []
        for family, sig in self.SIGNATURES.items():
            if note_filename in sig['ransom_notes']:
                matches.append(family)
        return matches

    def identify_by_file_hash(self, file_path, hash_db=None):
        """通过文件哈希识别"""
        with open(file_path, 'rb') as f:
            file_hash = hashlib.sha256(f.read()).hexdigest()
        
        if hash_db and file_hash in hash_db:
            return hash_db[file_hash]
        return None

    def full_identification(self, sample_dir):
        """综合识别"""
        results = {
            'identified_families': set(),
            'evidence': []
        }

        for root, dirs, files in os.walk(sample_dir):
            for filename in files:
                filepath = os.path.join(root, filename)
                
                # 检查扩展名
                ext_matches = self.identify_by_extension(filepath)
                if ext_matches:
                    results['identified_families'].update(ext_matches)
                    results['evidence'].append({
                        'file': filepath,
                        'method': 'extension',
                        'families': ext_matches
                    })
                
                # 检查勒索说明文件
                note_name_matches = self.identify_by_note_name(filename)
                if note_name_matches:
                    results['identified_families'].update(note_name_matches)
                    results['evidence'].append({
                        'file': filepath,
                        'method': 'note_name',
                        'families': note_name_matches
                    })
                    
                    # 检查勒索说明内容
                    content_matches = self.identify_by_ransom_note(filepath)
                    if content_matches:
                        results['identified_families'].update(content_matches)
                        results['evidence'].append({
                            'file': filepath,
                            'method': 'note_content',
                            'families': content_matches
                        })

        results['identified_families'] = list(results['identified_families'])
        return results

# 使用
identifier = RansomwareIdentifier()
results = identifier.full_identification("/forensics/ransomware_sample")
print(json.dumps(results, indent=2, ensure_ascii=False))
```

**2. 加密范围确认**

```bash
#!/bin/bash
# 扫描加密文件范围
echo "=== 加密文件扫描报告 ==="

# 查找所有加密文件（按常见扩展名）
echo "--- 已加密文件统计 ---"
find / -type f \( -name "*.locked" -o -name "*.encrypted" -o -name "*.crypted" \
  -o -name "*.lockbit" -o -name "*.conti" -o -name "*.revil" \
  -o -name "*.akira" -o -name "*.hive" -o -name "*.alphv" \
  -o -name "*.blackcat" -o -name "*.clop" -o -name "*.ransom" \) 2>/dev/null | \
  while read f; do
    echo "$(stat -c '%s %Y' "$f" 2>/dev/null) $f"
  done | sort -k2 -n

# 按目录统计加密文件
echo ""
echo "--- 按目录统计 ---"
find / -type f \( -name "*.locked" -o -name "*.encrypted" -o -name "*.crypted" \) 2>/dev/null | \
  sed 's|/[^/]*$||' | sort | uniq -c | sort -rn | head -20

# 查找勒索说明文件
echo ""
echo "--- 勒索说明文件 ---"
find / -type f \( -name "README.txt" -o -name "HOW_TO_DECRYPT.txt" \
  -o -name "readme.txt" -o -name "RESTORE_FILES.txt" \
  -o -name "recover.txt" -o -name "CL0P_README.txt" \) 2>/dev/null

# 检查最近修改的文件（加密时间线）
echo ""
echo "--- 最近24小时修改的文件 ---"
find / -type f -mtime -1 -not -path "/proc/*" -not -path "/sys/*" 2>/dev/null | head -50
```

### 8.4 阶段3: 抑制

```bash
# 1. 阻止扩散
# 立即禁用受感染账户
# Windows
net user <username> /active:no
# Linux
usermod -L <username>
passwd -l <username>

# 禁用受感染的ServiceAccount (Kubernetes)
kubectl delete serviceaccount <suspicious-sa> -n <namespace>

# 轮换所有可能泄露的凭据
# SSH密钥
for user in $(awk -F: '$3>=1000 {print $1}' /etc/passwd); do
  echo "需要轮换 $user 的SSH密钥"
done

# 2. 清除持久化
# Windows持久化检查
# 检查计划任务
schtasks /query /fo LIST /v | findstr /i "TaskName\|Task To Run\|Author"
# 检查启动项
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
# 检查服务
sc query type= service state= all | findstr "SERVICE_NAME"

# Linux持久化检查
# 检查计划任务
crontab -l
ls -la /etc/cron.*
cat /etc/crontab
# 检查systemd服务
systemctl list-unit-files --type=service --state=enabled
# 检查启动脚本
cat /etc/rc.local
ls -la /etc/init.d/
# 检查SSH authorized_keys
for user_home in /home/* /root; do
  if [ -f "$user_home/.ssh/authorized_keys" ]; then
    echo "=== $user_home ==="
    cat "$user_home/.ssh/authorized_keys"
  fi
done

# 3. 终止恶意进程
# Windows
tasklist | findstr /i "ransom\|crypt\|encrypt\|lock"
taskkill /F /PID <pid>

# Linux
ps aux | grep -iE "ransom|crypt|encrypt|lock|wget|curl"
kill -9 <pid>

# 检查异常网络连接
# Windows
netstat -ano | findstr "ESTABLISHED"
# Linux
ss -tunap | grep ESTAB
```

### 8.5 阶段4: 根除

```bash
# 1. 清除恶意代码
# 查找并删除恶意可执行文件
find / -type f -executable -newer /var/log/syslog -not -path "/proc/*" -not -path "/sys/*" 2>/dev/null

# Windows: 检查最近创建的EXE/DLL
# PowerShell
Get-ChildItem -Path C:\ -Recurse -Include *.exe,*.dll,*.bat,*.ps1 |
  Where-Object { $_.CreationTime -gt (Get-Date).AddDays(-1) } |
  Select-Object FullName, CreationTime, Length

# 2. 修复入侵路径
# 修补已知漏洞
# Windows更新
wuauclt /detectnow /updatenow
# Linux更新
apt-get update && apt-get upgrade -y

# 禁用不必要的服务
systemctl disable telnet
systemctl disable rsh
systemctl disable rlogin

# 加固RDP
```

### 8.6 阶段5: 恢复

```bash
# 恢复决策树
# 1. 是否有可用备份？
#    → 是: 从备份恢复
#    → 否: 是否有解密工具？(检查 https://www.nomoreransom.org)
#         → 是: 使用解密工具
#         → 否: 评估是否需要支付赎金(最后手段)

# 2. 从备份恢复
# 验证备份完整性
sha256sum /backup/image.tar
# 恢复系统镜像
dd if=/backup/system.img of=/dev/sda bs=4M status=progress

# 数据恢复
# 从增量备份恢复
rsync -av --progress /backup/incremental/ /restored_data/

# 云环境恢复
# 从快照恢复EC2
aws ec2 create-volume --snapshot-id snap-xxx --availability-zone us-east-1a
# 从AMI恢复
aws ec2 run-instances --image-id ami-xxx --instance-type t3.large

# Kubernetes恢复
# 从备份恢复etcd
ETCDCTL_API=3 etcdctl snapshot restore /backup/etcd-snapshot.db \
  --data-dir=/var/lib/etcd
# 重新部署应用
kubectl apply -f /backup/deployments/

# 3. 恢复后验证
# 文件完整性检查
find /restored_data -type f -name "*.md5" -exec md5sum -c {} \;
# 系统安全扫描
clamscan -r /restored_data/
# 服务功能测试
systemctl status nginx
curl -I http://localhost/
```
