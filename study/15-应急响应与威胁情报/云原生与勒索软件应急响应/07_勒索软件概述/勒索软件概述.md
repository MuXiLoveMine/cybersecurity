# 勒索软件概述

### 7.1 勒索软件演变

勒索软件经历了从简单到复杂、从个人到组织的演变过程。

| 阶段 | 时间 | 特征 | 代表家族 |
|------|------|------|----------|
| 早期 | 1989-2009 | 简单加密，要求邮寄赎金 | AIDS Trojan |
| 爆发期 | 2010-2015 | 使用非对称加密，在线支付 | CryptoLocker, CryptoWall |
| RaaS期 | 2016-2019 | 勒索即服务，大规模传播 | Locky, Cerber, GandCrab |
| 双重勒索 | 2020-2022 | 加密+数据泄露威胁 | Maze, Conti, REvil |
| 三重勒索 | 2022-2023 | 加密+泄露+DDoS攻击 | BlackCat, LockBit |
| 供应链 | 2023-至今 | 供应链攻击大规模扩散 | Cl0p, Akira, Rhysida |

### 7.2 常见勒索家族

| 家族 | 加密算法 | 传播方式 | 特征 |
|------|----------|----------|------|
| LockBit 3.0 | AES+RSA | 钓鱼/RDP漏洞 | RaaS模式，加密极快 |
| BlackCat/ALPHV | AES+RSA | 凭据窃取/漏洞 | Rust编写，跨平台 |
| Conti | AES+RSA | 钓鱼/TrickBot | Ryuk的继承者 |
| REvil/Sodinokibi | AES+RSA | 钓鱼/漏洞利用 | RaaS模式 |
| Cl0p | AES+RSA | 供应链攻击 | MOVEit漏洞利用 |
| Akira | AES+RSA | VPN漏洞/凭据 | Cisco ASA漏洞 |
| Rhysida | AES | 钓鱼/漏洞 | 主要攻击教育和医疗 |
| Babuk | AES+RSA | 钓鱼/漏洞 | 源码泄露后被多方使用 |
| Hive | AES+RSA | 钓鱼/RDP | FBI介入破解 |

### 7.3 勒索软件加密机制

```
┌──────────────────────────────────────────────────────────────┐
│                    勒索软件加密流程                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 生成密钥                                                  │
│     攻击者C2服务器生成RSA密钥对(公钥+私钥)                     │
│     生成AES对称密钥用于文件加密                                │
│                                                              │
│  2. 文件发现                                                  │
│     遍历磁盘/网络共享/云存储                                   │
│     筛选高价值文件类型(.docx, .xlsx, .pdf, .db等)             │
│     排除系统文件(保证系统可运行以支付赎金)                     │
│                                                              │
│  3. 文件加密                                                  │
│     原文件 -> AES加密 -> 生成加密文件(.locked/.enc等)          │
│     AES密钥 -> RSA公钥加密 -> 写入加密文件头部                  │
│     删除原文件(安全擦除)                                       │
│                                                              │
│  4. 勒索部署                                                  │
│     生成勒索说明文件(README.txt/HOW_TO_DECRYPT.txt)            │
│     修改桌面壁纸                                               │
│     显示勒索信息                                               │
│                                                              │
│  5. 数据窃取(双重勒索)                                        │
│     加密前先窃取数据                                           │
│     上传到攻击者服务器                                          │
│     威胁公开泄露以施加压力                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**常见加密文件扩展名：**

```
.locked  .encrypted  .crypted  .enc  .crypto  .lockbit
.readme  .blocked   .ransom   . encoded .decrypt
.conti   .revil     .hive     .akira   .rhysida
.babuk  .blackcat   .alpha    .cl0p    .data
```
