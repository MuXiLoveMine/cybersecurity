# 威胁情报概述

### 1.1 威胁情报定义

**威胁情报**是关于现有或潜在威胁的经过加工和分析的信息，可用于决策，帮助组织更好地防御和应对安全威胁。

**简单来说**：威胁情报 = 数据 + 上下文 + 分析 + 可操作的建议

**核心要素：**
- **数据**：原始的威胁信息（IP、域名、文件哈希等）
- **上下文**：背景信息（谁、为什么、怎么做等）
- **分析**：对数据的加工和解读
- **可操作性**：能够指导行动和决策

**与原始数据的区别：**

| 类型 | 说明 | 例子 |
|------|------|------|
| **数据** | 原始事实 | IP 地址 1.2.3.4 |
| **信息** | 有上下文的数据 | IP 1.2.3.4 是恶意 IP |
| **情报** | 经过分析、可指导行动 | IP 1.2.3.4 属于 APT28 组织，用于 C2 通信，建议立即封禁并排查内网是否有主机连接该 IP |

### 1.2 威胁情报的价值

威胁情报的价值体现在以下几个方面：

#### 1.2.1 提升检测能力
- 基于 IOC 匹配检测已知威胁
- 基于 TTP 识别未知威胁
- 缩短检测时间（MTTD）
- 提高检测准确率

#### 1.2.2 加速响应速度
- 提供威胁上下文信息
- 指导响应措施
- 缩短响应时间（MTTR）
- 提高响应效率

#### 1.2.3 支持安全决策
- 帮助了解威胁态势
- 支持风险评估
- 指导安全投入
- 辅助战略决策

#### 1.2.4 主动防御
- 威胁狩猎（主动寻找威胁）
- 预测攻击趋势
- 提前部署防护
- 防范未然

#### 1.2.5 态势感知
- 了解整体威胁环境
- 跟踪攻击者活动
- 感知攻击趋势变化
- 预警重大威胁

### 1.3 威胁情报的分类

#### 1.3.1 按情报来源分类

| 类型 | 英文 | 说明 | 例子 |
|------|------|------|------|
| **开源情报** | OSINT (Open Source Intelligence) | 从公开渠道获取的情报 | 安全博客、社交媒体、公开报告、暗网信息 |
| **商业情报** | Commercial Intelligence | 从商业供应商购买的情报 | 商业威胁情报平台、安全厂商报告 |
| **政府情报** | Government Intelligence | 政府机构提供的情报 | 国家级 CERT、执法部门、情报机构 |
| **行业情报** | Industry Intelligence | 行业内共享的情报 | 行业 ISAC、行业协会、同业共享 |
| **内部情报** | Internal Intelligence | 组织内部产生的情报 | 自身安全事件、日志分析、红蓝对抗 |
| **信号情报** | SIGINT (Signals Intelligence) | 从信号/流量中获取的情报 | 网络流量分析、通信监听 |
| **人力情报** | HUMINT (Human Intelligence) | 从人员获取的情报 | 内部人员、线人、社交工程 |

#### 1.3.2 按情报内容分类

| 类型 | 说明 | 例子 |
|------|------|------|
| **IOC（指标）** | 技术指标，用于检测和匹配 | IP 地址、域名、URL、文件哈希、注册表项 |
| **TTP（战术/技术/程序）** | 攻击者的行为模式和方法 | 攻击手法、工具使用、操作流程 |
| **攻击者画像** | 关于攻击者的信息 | 攻击者身份、动机、能力、目标 |
| **威胁态势** | 整体威胁环境的信息 | 攻击趋势、威胁热点、重大威胁事件 |

### 1.4 威胁情报的误区

#### 误区1：威胁情报就是 IOC
- **错误认识**：威胁情报就是 IP、域名、哈希这些 IOC
- **正确理解**：IOC 只是威胁情报的一部分，TTP、攻击者画像等也是重要的情报类型
- **IOC 的局限性**：IOC 容易过时，攻击者可以快速更换 IP 和域名

#### 误区2：威胁情报越多越好
- **错误认识**：收集的情报越多越好
- **正确理解**：情报的质量比数量更重要，需要关注相关性和准确性
- **问题**：情报过载会导致重要信息被淹没，增加分析成本

#### 误区3：威胁情报能解决所有问题
- **错误认识**：有了威胁情报就能防御所有攻击
- **正确理解**：威胁情报是安全体系的一部分，需要与其他安全措施配合使用
- **现实**：威胁情报不能替代基础安全防护，也不能防御未知威胁

#### 误区4：威胁情报只适合大企业
- **错误认识**：只有大企业才需要威胁情报
- **正确理解**：各种规模的组织都可以从威胁情报中受益
- **建议**：根据自身需求和能力，选择合适的情报来源和应用方式
