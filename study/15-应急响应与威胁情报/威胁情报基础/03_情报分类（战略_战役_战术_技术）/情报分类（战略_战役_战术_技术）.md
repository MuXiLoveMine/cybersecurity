# 情报分类（战略/战役/战术/技术）

### 3.1 概述

威胁情报可以根据其用途和抽象程度分为四个层次：战略情报、战役情报、战术情报和技术情报。

```
        战略情报（Strategic）
           /            \
          /              \
    战役情报（Operational）  战术情报（Tactical）
          \              /
           \            /
        技术情报（Technical）
```

### 3.2 战略情报（Strategic Intelligence）

**定义**：面向高层决策者的宏观情报，用于战略决策和长期规划。

**特点：**
- 宏观、抽象、长期
- 关注整体威胁态势
- 面向高管和决策者
- 指导安全战略和资源分配

**主要内容：**
- 全球/区域威胁态势
- 攻击趋势和发展方向
- 重大威胁事件分析
- 威胁行为体的战略意图
- 行业威胁对比分析
- 安全风险评估

**产品形式：**
- 月度/季度/年度威胁态势报告
- 战略风险评估
- 安全趋势预测
- 高管简报

**案例：年度威胁态势报告**

> **报告主题**：2024 年网络安全威胁态势报告
>
> **目标受众**：CISO、CIO、CEO 等高管
>
> **主要内容：**
> 1. 2024 年威胁态势总览
> 2. 主要威胁类型变化趋势（勒索软件、APT、数据泄露等）
> 3. 重点威胁组织分析
> 4. 行业威胁对比（金融、能源、医疗、政府等）
> 5. 攻击技术发展趋势
> 6. 2025 年威胁预测
> 7. 战略建议和安全投入方向
>
> **价值**：帮助高管了解整体威胁环境，制定安全战略，分配安全预算

### 3.3 战役情报（Operational Intelligence）

**定义**：面向安全运营和管理的情报，用于规划和组织安全运营活动。

**特点：**
- 中观、计划性
- 关注具体的威胁活动
- 面向安全管理人员
- 指导安全运营和项目规划

**主要内容：**
- 具体威胁组织的活动分析
- 攻击活动的时间、目标、手法
- 威胁活动的趋势和变化
- 行业相关的威胁活动
- 漏洞利用趋势
- 恶意软件家族分析

**产品形式：**
- 威胁活动简报
- 攻击者画像
- 恶意软件分析报告
- 漏洞威胁分析

**案例：某 APT 组织活动分析报告**

> **报告主题**：APT28 组织 2024 年上半年活动分析
>
> **目标受众**：安全经理、威胁狩猎团队、应急响应团队
>
> **主要内容：**
> 1. APT28 组织概述（背景、动机、能力）
> 2. 2024 年上半年活动概览
> 3. 主要攻击活动详细分析
>    - 针对政府机构的钓鱼攻击活动
>    - 针对国防工业的供应链攻击
>    - 针对智库的水坑攻击
> 4. 使用的工具和 TTP
> 5. IOC 列表
> 6. 攻击趋势和预测
> 7. 防护建议
>
> **价值**：帮助安全团队了解具体威胁，规划威胁狩猎和防护措施

### 3.4 战术情报（Tactical Intelligence）

**定义**：面向一线安全人员的情报，用于具体的检测、响应和防御操作。

**特点：**
- 具体、可操作
- 关注攻击的具体手法
- 面向 SOC 分析师、应急响应人员
- 直接指导日常安全操作

**主要内容：**
- 攻击 TTP（战术、技术、程序）
- 检测规则和方法
- 响应建议和步骤
- 攻击指标和特征
- 漏洞利用细节

**产品形式：**
- IOC 列表
- 检测规则（Sigma、Snort 等）
- 攻击技术分析
- 应急响应指南
- 威胁狩猎剧本

**案例：钓鱼邮件检测指南**

> **指南主题**：最新钓鱼邮件攻击手法和检测方法
>
> **目标受众**：SOC 分析师、安全运营人员
>
> **主要内容：**
> 1. 当前钓鱼邮件的主要手法
>    - 主题和内容伪装
>    - 附件类型（Office 宏、ISO、LNK 等）
>    - 钓鱼链接特征
> 2. 检测方法
>    - 邮件头分析要点
>    - 可疑附件特征
>    - 可疑链接特征
>    - 检测规则示例（Sigma 规则）
> 3. 处置建议
>    - 收到可疑邮件怎么办
>    - 已点击链接/打开附件的处置
>    - 上报流程
>
> **价值**：直接指导一线人员检测和处置钓鱼邮件

### 3.5 技术情报（Technical Intelligence）

**定义**：最底层的技术指标情报，用于自动化检测和匹配。

**特点：**
- 具体、技术性强
- 机器可读
- 面向安全设备和系统
- 用于自动化检测

**主要内容（即 IOC）：**
- IP 地址
- 域名
- URL
- 文件哈希（MD5、SHA1、SHA256）
- 证书指纹
- 注册表键值
- 文件名和路径
- 进程特征
- 网络特征

**产品形式：**
- IOC 数据文件（CSV、JSON、STIX 等）
- API 接口
- 检测规则

**案例：IOC 数据文件示例**

```json
{
  "indicators": [
    {
      "type": "ipv4",

    {
      "type": "domain",
      "value": "malicious-example.com",
      "malware": "Emotet",
      "first_seen": "2024-01-02",
      "confidence": "high"
    },
    {
      "type": "sha256",

      "malware": "Emotet",

    }

```

### 3.6 四层情报的关系

| 层次 | 受众 | 时间范围 | 抽象程度 | 更新频率 |
|------|------|----------|----------|----------|
| **战略** | 高管 | 月/季/年 | 高 | 低（月/季） |
| **战役** | 安全经理 | 周/月 | 中 | 中（周/月） |
| **战术** | 一线人员 | 天/周 | 低 | 高（天/周） |
| **技术** | 安全设备 | 小时/天 | 最低 | 最高（实时） |

**相互关系：**
- 高层情报指导低层情报的方向
- 低层情报是高层情报的基础
- 各层情报相互支撑，缺一不可
- 组织需要各层次的情报来满足不同需求

### 3.7 情报成熟度模型

组织的威胁情报能力可以分为不同的成熟度等级：

**等级 1：初始级**
- 没有正式的威胁情报工作
- 偶尔使用免费的威胁情报
- 被动接收信息

**等级 2：可重复级**
- 有基本的威胁情报收集
- 使用商业或开源 IOC
- 简单的情报应用（如黑名单）

**等级 3：已定义级**
- 有正式的威胁情报团队
- 完整的情报生命周期流程
- 多种情报来源和产品
- 情报与安全运营集成

**等级 4：已管理级**
- 成熟的威胁情报体系
- 高质量的情报分析
- 情报驱动安全运营
- 量化的效果评估

**等级 5：优化级**
- 持续优化的情报能力
- 自动化和智能化程度高
- 主动预测和防御
- 情报共享和协作
