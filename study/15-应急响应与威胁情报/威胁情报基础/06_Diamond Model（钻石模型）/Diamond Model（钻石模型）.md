# Diamond Model（钻石模型）

### 6.1 钻石模型概述

**钻石模型（Diamond Model of Intrusion Analysis）** 是由美国国土安全部等机构提出的入侵分析模型，用于系统地分析入侵事件。

**模型名称来源**：模型的四个核心要素排列成钻石形状。

**核心思想**：每一个入侵事件都包含四个核心要素，通过分析这四个要素及其关系来理解入侵事件。

### 6.2 四个核心要素

钻石模型的四个核心要素：

```
           对手（Adversary）
              /       \
             /         \
    能力（Capability）  基础设施（Infrastructure）
             \         /
              \       /
           受害者（Victim）
```

#### 要素 1：对手（Adversary）
**定义**：实施入侵的攻击者/组织。

**包含内容：**
- 攻击者身份（已知/未知）
- 攻击组织
- 攻击动机
- 攻击目标
- 资源和能力

**分析要点：**
- 攻击者是谁？
- 攻击者的动机是什么？
- 攻击者的能力如何？
- 攻击者针对什么目标？

#### 要素 2：能力（Capability）
**定义**：攻击者使用的工具、技术和能力。

**包含内容：**
- 恶意软件
- 漏洞利用工具
- 攻击技术和手法
- 工具集
- TTP

**分析要点：**
- 攻击者使用了什么工具？
- 使用了什么攻击技术？
- 工具的来源（自研/购买/开源）？
- 技术的复杂度如何？

#### 要素 3：基础设施（Infrastructure）
**定义**：攻击者用于实施攻击的物理或逻辑资源。

**包含内容：**
- IP 地址
- 域名
- 服务器
- 代理/跳板
- 证书
- 邮件账号
- 社交媒体账号

**分析要点：**
- 攻击者使用了什么基础设施？
- 基础设施位于哪里？
- 基础设施是攻击者自己的还是攻陷的？
- 基础设施的规模和复杂度？

#### 要素 4：受害者（Victim）
**定义**：攻击的目标，被攻击的组织或个人。

**包含内容：**
- 受害者身份
- 受害者的行业和领域
- 被攻击的系统和数据
- 遭受的损失
- 受害者的价值

**分析要点：**
- 受害者是谁？
- 攻击者针对受害者的什么资产？
- 受害者为什么被攻击？
- 受害者遭受了什么损失？

### 6.3 要素之间的关系

四个要素之间存在六种关系：

| 关系 | 说明 |
|------|------|
| 对手 → 能力 | 对手拥有和使用某种能力 |
| 对手 → 基础设施 | 对手拥有或控制某种基础设施 |
| 对手 → 受害者 | 对手针对受害者 |
| 能力 → 基础设施 | 能力通过基础设施部署 |
| 基础设施 → 受害者 | 基础设施用于攻击受害者 |
| 能力 → 受害者 | 能力作用于受害者 |

### 6.4 钻石模型的应用

#### 6.4.1 入侵事件分析
- 系统地梳理入侵事件的各个方面
- 确保不遗漏重要信息
- 全面理解攻击事件

#### 6.4.2 事件关联
- 通过共享的要素关联不同事件
- 发现同一攻击者的不同活动
- 建立攻击者画像

#### 6.4.3 威胁评估
- 评估攻击者的能力和威胁程度
- 评估自身面临的风险
- 指导防御策略

#### 6.4.4 预测和预警
- 基于攻击者的模式预测下一个目标
- 提前部署防护措施
- 发布预警

### 6.5 钻石模型的分析步骤

1. **识别受害者**
   - 什么被攻击了？
   - 造成了什么影响？

2. **识别能力**
   - 使用了什么攻击工具和技术？
   - 如何实施的攻击？

3. **识别基础设施**
   - 攻击来自哪里？
   - 使用了什么 IP/域名/服务器？

4. **识别对手**
   - 谁发起的攻击？
   - 攻击动机是什么？

5. **分析关系**
   - 各要素之间的关系是什么？
   - 能关联到其他已知事件吗？

6. **得出结论**
   - 攻击的全貌是什么？
   - 应该如何应对？

### 6.6 三大模型对比

| 模型 | 特点 | 优势 | 适用场景 |
|------|------|------|----------|
| **Cyber Kill Chain** | 线性的七阶段攻击模型 | 简单易懂，适合理解攻击过程 | 防御体系设计、安全意识培训 |
| **ATT&CK** | 矩阵式的战术-技术模型 | 详细全面，基于真实数据 | 检测开发、威胁情报、红蓝对抗 |
| **Diamond Model** | 四要素的钻石模型 | 系统性强，适合事件分析 | 入侵分析、事件关联、威胁评估 |

**建议**：三个模型不是互斥的，可以结合使用，从不同角度理解和分析攻击。
