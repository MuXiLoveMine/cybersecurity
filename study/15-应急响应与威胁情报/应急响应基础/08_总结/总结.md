# 总结

应急响应基础是应急响应工作的基石，掌握好这些基础知识对于有效应对安全事件至关重要。

**核心要点回顾：**

1. **应急响应概述**：理解应急响应的定义、目标和七大原则（预防为主、快速响应、最小影响、证据保全、统一指挥、分级响应、持续改进）

2. **组织架构**：建立完善的应急响应团队，明确各角色职责，确保指挥顺畅、协作高效

3. **PDCERF 模型**：掌握应急响应六阶段生命周期——准备、检测、遏制、根除、恢复、跟踪，每个阶段都有明确的目标和工作内容

4. **事件分级**：根据事件严重程度分为四级（特别重大、重大、较大、一般），采取相应级别的响应措施，合理分配资源

5. **应急预案**：建立完善的应急预案体系，定期演练，持续改进，确保预案的实用性和有效性

6. **工具清单**：准备好应急响应所需的各类工具，熟练掌握使用方法，做到"工欲善其事，必先利其器"

7. **常见错误**：了解应急响应各阶段的常见错误，引以为戒，避免重蹈覆辙

> "安全是一场没有终点的马拉松，应急响应是其中最重要的冲刺能力。只有平时充分准备，才能在危机来临时从容应对。"

### 一、Windows 应急响应常用命令速查表

#### 1. 系统信息收集

```cmd
:: 系统基本信息
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"System Type" /C:"Original Install Date"

:: 主机名和用户名
hostname
whoami
whoami /priv   :: 查看当前用户权限
whoami /groups :: 查看用户组

:: 环境变量
set
echo %USERPROFILE%
echo %TEMP%

:: 系统运行时间
net statistics workstation
systeminfo | find "System Boot Time"

:: 补丁信息
wmic qfe get Caption,Description,HotFixID,InstalledOn /format:table
```

#### 2. 进程排查

```cmd
:: 列出所有进程（详细信息）
tasklist /v
tasklist /svc   :: 查看进程对应的服务
tasklist /m     :: 查看进程加载的DLL

:: 按内存/CPU排序
tasklist /v /fi "STATUS eq running" | sort /+65 /R

:: 查看进程树
wmic process get Name,ProcessId,ParentProcessId,CommandLine /format:list

:: 终止可疑进程
taskkill /F /PID <pid>
taskkill /F /IM <processname>.exe /T   :: 终止进程及其子进程
```

#### 3. 网络连接排查

```cmd
:: 查看所有网络连接
netstat -ano
netstat -anob  :: 显示关联进程（需管理员权限）

:: 查看监听端口
netstat -ano | findstr LISTENING

:: 查看已建立的连接
netstat -ano | findstr ESTABLISHED

:: 查看路由表
route print

:: 查看ARP缓存
arp -a

:: DNS缓存
ipconfig /displaydns
ipconfig /flushdns

:: 查看网络适配器信息
ipconfig /all
```

#### 4. 用户与权限排查

```cmd
:: 列出所有本地用户
net user
wmic useraccount get Name,SID,Status,AccountType /format:table

:: 查看管理员组成员
net localgroup administrators

:: 查看远程桌面用户组
net localgroup "Remote Desktop Users"

:: 查看最近登录的用户
net user <username> | findstr /B /C:"Last logon"

:: 检查隐藏账户（注册表方式）
reg query "HKLM\SAM\SAM\Domains\Account\Users\Names"
```

#### 5. 启动项与持久化排查

```cmd
:: 查看启动项（注册表）
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce"

:: 查看服务
net start
sc query type= service state= all
wmic service get Name,DisplayName,State,StartMode,PathName /format:table

:: 查看计划任务
schtasks /query /fo LIST /v
schtasks /query /fo TABLE /nh

:: 查看驱动程序
driverquery /v
wmic sysdriver get Name,DisplayName,State,StartMode,PathName /format:table
```

#### 6. 日志查看

```cmd
:: 查看安全日志（最近登录事件）
wevtutil qe Security /q:"*[System/EventID=4624]" /c:10 /f:text /rd:true

:: 查看登录失败事件
wevtutil qe Security /q:"*[System/EventID=4625]" /c:10 /f:text /rd:true

:: 查看进程创建事件
wevtutil qe Security /q:"*[System/EventID=4688]" /c:20 /f:text /rd:true

:: 查看服务安装事件
wevtutil qe System /q:"*[System/EventID=7045]" /c:10 /f:text /rd:true

:: 导出日志为EVTX
wevtutil epl Security C:\temp\security.evtx
wevtutil epl System C:\temp\system.evtx
wevtutil epl Application C:\temp\application.evtx
```

#### 2. Linux 证据收集清单与顺序

```bash
#!/bin/bash
# ========== 易失性证据优先 ==========
EVIDENCE_DIR="/evidence/$(hostname)_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$EVIDENCE_DIR"

# 1. 网络连接状态
netstat -tulnp > "$EVIDENCE_DIR/netstat_tulnp.txt"
netstat -anp > "$EVIDENCE_DIR/netstat_anp.txt"
ss -anp > "$EVIDENCE_DIR/ss_anp.txt"
ip addr > "$EVIDENCE_DIR/ip_addr.txt"
ip route > "$EVIDENCE_DIR/ip_route.txt"
arp -a > "$EVIDENCE_DIR/arp.txt"
cat /etc/resolv.conf > "$EVIDENCE_DIR/resolv_conf.txt"
cat /etc/hosts > "$EVIDENCE_DIR/hosts.txt"

# 2. 进程信息
ps aux > "$EVIDENCE_DIR/ps_aux.txt"
ps auxf > "$EVIDENCE_DIR/ps_auxf.txt"
ps -efH > "$EVIDENCE_DIR/ps_efH.txt"
top -bn1 > "$EVIDENCE_DIR/top.txt"

# 3. 进程详细信息（逐个PID）
for pid in $(ls /proc | grep -E '^[0-9]+$' | sort -n); do
    if [ -d "/proc/$pid" ]; then
        echo "=== PID: $pid ===" >> "$EVIDENCE_DIR/proc_detail.txt"
        cat /proc/$pid/cmdline | tr '\0' ' ' >> "$EVIDENCE_DIR/proc_detail.txt"
        echo "" >> "$EVIDENCE_DIR/proc_detail.txt"
        ls -la /proc/$pid/exe >> "$EVIDENCE_DIR/proc_detail.txt" 2>/dev/null
        ls -la /proc/$pid/cwd >> "$EVIDENCE_DIR/proc_detail.txt" 2>/dev/null
        ls -la /proc/$pid/fd/ >> "$EVIDENCE_DIR/proc_detail.txt" 2>/dev/null
        echo "" >> "$EVIDENCE_DIR/proc_detail.txt"
    fi
done

# 4. 内存镜像（使用LiME）
# insmod lime.ko "path=/evidence/memory.lime format=lime"

# 5. 用户信息
cat /etc/passwd > "$EVIDENCE_DIR/passwd.txt"
cat /etc/shadow > "$EVIDENCE_DIR/shadow.txt"
cat /etc/group > "$EVIDENCE_DIR/group.txt"
cat /etc/sudoers > "$EVIDENCE_DIR/sudoers.txt" 2>/dev/null
last > "$EVIDENCE_DIR/last.txt"
lastlog > "$EVIDENCE_DIR/lastlog.txt"
who > "$EVIDENCE_DIR/who.txt"
w > "$EVIDENCE_DIR/w_command.txt"

# 6. 计划任务
crontab -l > "$EVIDENCE_DIR/crontab_root.txt" 2>/dev/null
for user in $(cut -d: -f1 /etc/passwd); do
    crontab -u "$user" -l >> "$EVIDENCE_DIR/crontab_all.txt" 2>/dev/null
done
ls -laR /etc/cron* > "$EVIDENCE_DIR/cron_dirs.txt"

# 7. 服务信息
systemctl list-unit-files > "$EVIDENCE_DIR/systemd_units.txt" 2>/dev/null
systemctl list-units --state=running > "$EVIDENCE_DIR/systemd_running.txt" 2>/dev/null
chkconfig --list > "$EVIDENCE_DIR/chkconfig.txt" 2>/dev/null

# 8. 日志收集
cp /var/log/messages "$EVIDENCE_DIR/" 2>/dev/null
cp /var/log/syslog "$EVIDENCE_DIR/" 2>/dev/null
cp /var/log/secure "$EVIDENCE_DIR/" 2>/dev/null
cp /var/log/auth.log "$EVIDENCE_DIR/" 2>/dev/null
cp /var/log/wtmp "$EVIDENCE_DIR/" 2>/dev/null
cp /var/log/btmp "$EVIDENCE_DIR/" 2>/dev/null
cp -r /var/log/nginx/ "$EVIDENCE_DIR/nginx_logs/" 2>/dev/null
cp -r /var/log/apache2/ "$EVIDENCE_DIR/apache_logs/" 2>/dev/null
cp -r /var/log/httpd/ "$EVIDENCE_DIR/httpd_logs/" 2>/dev/null

# 9. 可疑文件收集
# 收集 /tmp 目录文件列表
ls -laR /tmp > "$EVIDENCE_DIR/tmp_files.txt"
ls -laR /var/tmp > "$EVIDENCE_DIR/var_tmp_files.txt"
ls -laR /dev/shm > "$EVIDENCE_DIR/dev_shm_files.txt"

# 10. bash历史
cat ~/.bash_history > "$EVIDENCE_DIR/bash_history_root.txt" 2>/dev/null
for user in $(cut -d: -f1 /etc/passwd); do
    home=$(getent passwd "$user" | cut -d: -f6)
    if [ -f "$home/.bash_history" ]; then
        cp "$home/.bash_history" "$EVIDENCE_DIR/bash_history_${user}.txt" 2>/dev/null
    fi
done

# 11. 内核模块
lsmod > "$EVIDENCE_DIR/lsmod.txt"
modinfo <module_name> > "$EVIDENCE_DIR/modinfo.txt"  # 可疑模块详细信息

echo "证据收集完成，保存目录: $EVIDENCE_DIR"
```

#### 3. 证据链保管原则

```
取证基本原则（LOCARD原则）：
1. 不改变原始证据 - 所有操作在镜像或副本上进行
2. 记录所有操作 - 详细的审计日志
3. 计算哈希值 - MD5/SHA-256 校验证据完整性
4. 专人保管 - 明确证据链传递记录
5. 最小操作原则 - 只做必要的取证操作

哈希校验示例：
  Windows: certutil -hashfile evidence.raw SHA256
  Linux:   sha256sum evidence.raw > evidence.sha256
```
