# 应急响应组织架构

### 2.1 应急响应团队类型

#### 2.1.1 CSIRT（计算机安全事件响应团队）
CSIRT（Computer Security Incident Response Team）是专门负责处理计算机安全事件的团队。

**CSIRT 的类型：**
- **内部 CSIRT**：企业内部建立的应急响应团队
- **国家 CSIRT**：国家级的应急响应机构（如 CNCERT/CC）
- **行业 CSIRT**：行业组织建立的应急响应团队
- **厂商 CSIRT**：安全厂商提供的应急响应服务
- **协作 CSIRT**：多个组织联合建立的应急响应团队

#### 2.1.2 SOC（安全运营中心）
SOC（Security Operations Center）是集中进行安全监控、分析和响应的组织。

**SOC 与 CSIRT 的关系：**
- SOC 侧重日常安全监控和运营
- CSIRT 侧重安全事件的应急响应
- 大型组织中 SOC 和 CSIRT 并存
- 小型组织中 SOC 承担 CSIRT 职能

#### 2.1.3 CERT（计算机应急响应小组）
CERT（Computer Emergency Response Team）是最早的应急响应组织形式，由卡内基梅隆大学于1988年建立。

**著名 CERT 组织：**
- CERT/CC（美国）- 最早的 CERT 组织
- CNCERT/CC（中国）- 国家互联网应急中心
- JPCERT/CC（日本）
- KISA（韩国）

### 2.2 应急响应团队角色与职责

一个完整的应急响应团队通常包含以下角色：

#### 2.2.1 应急响应负责人（Incident Commander）
**职责：**
- 全面负责应急响应工作
- 决策重大事项
- 协调内外部资源
- 向上级和管理层汇报
- 决定事件升级和降级

**要求：**
- 丰富的应急响应经验
- 良好的组织协调能力
- 快速决策能力
- 抗压能力强

#### 2.2.2 安全分析师（Security Analyst）
**职责：**
- 监控安全告警
- 分析安全事件
- 判断事件性质和严重程度
- 提出响应建议
- 编写分析报告

**分级：**
- **L1 分析师**：一线监控，处理简单告警
- **L2 分析师**：事件分析，处理复杂事件
- **L3 分析师**：深度分析，威胁狩猎

#### 2.2.3 取证分析师（Forensic Analyst）
**职责：**
- 收集和保全数字证据
- 进行磁盘取证、内存取证
- 分析攻击痕迹
- 还原攻击过程
- 出具取证报告

**要求：**
- 熟悉取证工具和方法
- 了解法律程序和要求
- 严谨细致的工作态度

#### 2.2.4 威胁情报分析师（Threat Intelligence Analyst）
**职责：**
- 收集和分析威胁情报
- 提供威胁上下文信息
- 进行 IOC 匹配
- 分析攻击者和攻击手法
- 输出威胁情报报告

#### 2.2.5 系统管理员（System Administrator）
**职责：**
- 提供系统技术支持
- 执行系统层面的响应措施
- 协助取证和分析
- 系统恢复和加固

#### 2.2.6 网络管理员（Network Administrator）
**职责：**
- 提供网络技术支持
- 执行网络层面的响应措施
- 协助网络流量分析
- 网络恢复和加固

#### 2.2.7 业务部门代表
**职责：**
- 评估业务影响
- 协调业务恢复
- 提供业务系统信息
- 配合应急响应工作

#### 2.2.8 法务与合规
**职责：**
- 提供法律意见
- 评估法律风险
- 处理监管报告要求
- 配合执法部门调查

#### 2.2.9 公关与沟通
**职责：**
- 处理媒体关系
- 管理对外信息发布
- 协调客户沟通
- 维护企业声誉

### 2.3 组织架构示例

**大型企业应急响应组织架构：**

```
                    应急响应领导小组
                           |
                    应急响应指挥中心
                           |
         +-----------------+-----------------+
         |                 |                 |
    技术响应组        协调保障组        对外沟通组
         |                 |                 |
  +------+------+    +-----+-----+    +------+------+
  |      |      |    |     |     |    |      |      |
分析组 取证组 恢复组 法务 行政 后勤  公关  客户  监管
```

**小型企业应急响应组织架构：**

```
                    安全负责人
                           |
         +-----------------+-----------------+
         |                 |                 |
     安全分析师         系统管理员         网络管理员
      (兼取证)          (兼恢复)           (兼监控)
```

### 2.4 外部资源协作

应急响应团队还需要与外部资源协作：

- **安全厂商**：提供技术支持和专业服务
- **监管部门**：按规定上报事件，接受指导
- **执法机关**：配合调查网络犯罪
- **行业组织**：共享威胁情报和最佳实践
- **保险公司**：处理网络安全保险理赔
