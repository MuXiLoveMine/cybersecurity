# 应急响应工具清单

### 6.1 工具分类

应急响应工具可以按用途分为以下几类：

1. **日志分析工具**
2. **进程分析工具**
3. **网络分析工具**
4. **取证工具**
5. **恶意代码分析工具**
6. **系统信息收集工具**
7. **威胁情报工具**
8. **报告编写工具**

### 6.2 Windows 应急响应工具

#### 6.2.1 Sysinternals 工具集
Sysinternals 是微软官方的 Windows 工具集，是应急响应的必备工具。

| 工具 | 用途 | 说明 |
|------|------|------|
| **Process Explorer** | 进程管理 | 查看进程详细信息、加载的DLL、句柄等 |
| **Process Monitor** | 进程监控 | 实时监控进程的文件、注册表、网络操作 |
| **Autoruns** | 启动项管理 | 查看所有自启动项，发现持久化机制 |
| **TCPView** | 网络连接查看 | 查看所有网络连接和监听端口 |
| **PsTools** | 远程管理工具集 | 包括 PsExec、PsList、PsService 等 |
| **Sigcheck** | 签名验证 | 验证文件数字签名，检测可疑文件 |
| **Strings** | 字符串提取 | 提取文件中的字符串 |
| **Handle** | 句柄查看 | 查看进程打开的句柄 |

### 6.4 综合应急响应工具包

#### 6.4.1 Windows 应急响应工具包
- **Sysinternals Suite**：微软官方工具集

- **RootkitRevealer**：Rootkit 检测

- **ComboFix**：恶意软件清除

#### 6.4.2 Linux 应急响应工具包
- **chkrootkit**：Rootkit 检测
- **rkhunter**：Rootkit 检测

#### 6.4.3 在线工具
- **VirusTotal**：多引擎病毒扫描
- **微步在线**：威胁情报查询
- **Hybrid Analysis**：在线沙箱分析
- **Any.Run**：交互式在线沙箱
- **URLScan**：URL 扫描

### 6.5 应急响应工具包准备建议

1. **准备 U 盘工具包**
   - 将常用工具拷贝到 U 盘
   - U 盘只读，防止被恶意软件感染
   - 定期更新工具版本

2. **准备 Live CD/USB**
   - 制作应急启动 U 盘
   - 包含完整的取证和分析工具
   - 可从光盘/U 盘启动，不修改硬盘数据

3. **工具使用培训**
   - 应急响应人员应熟练使用常用工具
   - 定期组织工具使用培训
   - 建立工具使用文档

4. **工具验证**
   - 确保工具来自可信来源
   - 验证工具完整性（哈希校验）
   - 定期更新工具版本
