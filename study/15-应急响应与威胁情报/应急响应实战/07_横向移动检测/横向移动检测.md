# 横向移动检测

### 7.1 横向移动概述

横向移动（Lateral Movement）是指攻击者在获得初始访问权限后，在网络内部从一台机器移动到另一台机器的过程。

**横向移动的目的：**
- 扩大控制范围
- 寻找有价值的数据
- 获取更高权限
- 访问关键系统
- 持久化访问

**常见横向移动技术：**

| 技术 | 说明 | 对应 ATT&CK |
|------|------|-------------|
| Pass-the-Hash (PtH) | 传递哈希，使用 NTLM 哈希登录 | T1550.002 |
| Pass-the-Ticket (PtT) | 传递票据，使用 Kerberos 票据登录 | T1550.003 |
| WMI 远程执行 | 通过 WMI 在远程机器执行命令 | T1047 |
| PsExec | 通过服务在远程机器执行命令 | T1569.002 |
| SMB 远程文件传输 | 通过 SMB 协议传输文件 | T1021.002 |
| RDP 远程桌面 | 通过 RDP 登录远程机器 | T1021.001 |
| WinRM | 通过 WinRM 远程管理 | T1021.006 |
| SSH | 通过 SSH 登录远程机器 | T1021.004 |
| DCOM | 通过 DCOM 远程执行 | T1021.003 |
| 远程注册表 | 远程访问注册表 | T1021.003 |

### 7.2 横向移动检测方法

#### 7.2.1 登录日志分析

**Windows 登录类型：**

| 登录类型 | 代码 | 说明 | 横向移动特征 |
|----------|------|------|-------------|
| 交互式登录 | 2 | 本地登录 | 本地使用 |
| 网络登录 | 3 | 网络访问（SMB、WMI等） | 常见横向移动 |
| 批处理登录 | 4 | 计划任务 | 计划任务执行 |
| 服务登录 | 5 | 服务启动 | PsExec 等 |
| 网络明文登录 | 8 | 网络明文登录 | 某些协议 |
| 新凭证登录 | 9 | runas 等 | 凭据替换 |
| 远程交互登录 | 10 | RDP 终端服务 | RDP 登录 |
| 缓存交互登录 | 11 | 缓存登录 | 离线登录 |

**检测方法：**

```bash
# 查找网络登录（登录类型3），可能是横向移动
# 事件 ID 4624，登录类型 3
wevtutil qe Security /q:"*[System[EventID=4624 and EventData/Data[@Name='LogonType']='3']]" /f:text

# 查找远程交互登录（登录类型10），即 RDP 登录
wevtutil qe Security /q:"*[System[EventID=4624 and EventData/Data[@Name='LogonType']='10']]" /f:text

# 查找服务登录（登录类型5），可能是 PsExec
wevtutil qe Security /q:"*[System[EventID=4624 and EventData/Data[@Name='LogonType']='5']]" /f:text
```

**异常特征：**
- 异常时间的登录（如凌晨）
- 异常来源 IP 的登录
- 使用管理员账户在非管理员机器上登录
- 短时间内大量登录成功/失败
- 登录来源是已被入侵的机器

#### 7.2.2 网络连接分析

**检测方法：**

1. **SMB 连接检测**
   ```bash
   # 查看 445 端口的连接
   netstat -ano | findstr ":445"
   ss -tulnp | grep 445
   
   # 大量 445 端口连接可能是横向移动或内网扫描
   ```

2. **RDP 连接检测**
   ```bash
   # 查看 3389 端口的连接
   netstat -ano | findstr ":3389"
   
   # 异常时间、异常来源的 RDP 连接需要关注
   ```

3. **WMI/WinRM 连接检测**
   ```bash
   # WMI 使用 135 端口和动态端口
   # WinRM 使用 5985/5986 端口
   netstat -ano | findstr ":5985"
   netstat -ano | findstr ":5986"
   ```

4. **异常连接模式**
   - 一台机器突然连接到很多其他机器
   - 非管理机器连接到服务器
   - 异常时间的大量连接
   - 使用异常端口的连接

#### 7.2.3 进程和命令检测

**常见横向移动工具和命令：**

```cmd
:: PsExec 执行
psexec \\remote-pc cmd.exe
psexec \\remote-pc -s cmd.exe

:: WMI 执行
wmic /node:remote-pc process call create "cmd.exe /c whoami"

:: WinRM 执行
winrs -r:remote-pc cmd.exe

:: 远程计划任务
schtasks /create /s remote-pc /tn "test" /tr "cmd.exe" /sc once /st 12:00

:: 远程服务
sc \\remote-pc create service binPath= "cmd.exe"
sc \\remote-pc start service
```

**检测方法：**
- 监控进程创建事件（4688）
- 查找可疑的命令行参数
- 查找 psexec、wmic、winrs 等工具的执行
- 监控服务安装事件（4697/7045）
- 监控计划任务创建事件（4698）

#### 7.2.4 凭证窃取检测

横向移动通常需要凭证，攻击者会先窃取凭证再进行横向移动。

**常见凭证窃取技术：**
- Mimikatz（从内存中提取明文密码、哈希、票据）
- Procdump + Mimikatz（导出 lsass 内存再分析）
- 凭据管理器中的凭证
- 浏览器保存的密码
- SAM 文件中的 NTLM 哈希
- NTDS.dit（域控制器上的所有域用户哈希）

**检测方法：**
- 监控 lsass.exe 的异常访问
- 监控 Procdump 等工具的使用
- 监控 SAM 和 NTDS.dit 的访问
- 检测 Mimikatz 特征（加载 mimikatz 驱动等）

### 7.3 横向移动检测指标

**关键检测指标：**

1. **认证相关**
   - 登录失败次数异常增加
   - 登录成功次数异常增加
   - 异常登录时间
   - 异常登录来源
   - 使用管理员账户的异常登录

2. **网络相关**
   - SMB 连接异常增加
   - RDP 连接异常增加
   - 横向端口扫描
   - 异常的内网连接模式

3. **进程相关**
   - PsExec/WMI/WinRM 等工具的使用
   - 系统工具的异常调用
   - 可疑的命令行参数
   - 服务和计划任务的异常创建

4. **行为相关**
   - 一台机器访问多台机器
   - 非管理员机器访问服务器
   - 非工作时间的活动
   - 异常的文件共享访问

### 7.4 横向移动防护建议

1. **网络分段**
   - 将网络分为不同的安全区域
   - 限制区域间的访问
   - 关键区域单独保护

2. **最小权限原则**
   - 用户权限最小化
   - 管理员账号单独管理
   - 禁止普通用户拥有本地管理员权限
   - 使用专门的管理账号进行管理操作

3. **凭证保护**
   - 启用 LSA 保护（RunAsPPL）
   - 禁用 WDigest（防止明文密码）
   - 使用受保护的用户组
   - 定期更换管理员密码
   - 多因素认证

4. **监控与检测**
   - 部署 EDR 系统
   - 集中日志管理（SIEM）
   - 建立异常行为检测
   - 监控管理员账号使用

5. **补丁和加固**
   - 及时安装系统补丁
   - 禁用不必要的服务
   - 关闭不必要的端口
   - 加强系统安全配置
