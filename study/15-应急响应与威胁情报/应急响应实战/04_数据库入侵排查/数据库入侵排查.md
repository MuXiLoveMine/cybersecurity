# 数据库入侵排查

### 4.1 数据库入侵概述

数据库入侵是指攻击者获取数据库访问权限，窃取、篡改或删除数据的行为。

**常见数据库入侵方式：**
- SQL 注入（通过 Web 应用）
- 弱口令/暴力破解
- 未授权访问（数据库暴露在公网）
- 漏洞利用（数据库漏洞）
- 权限提升
- 内部人员滥用

**常见目标数据库：**
- MySQL / MariaDB
- Oracle
- SQL Server
- PostgreSQL
- MongoDB（NoSQL）
- Redis（缓存数据库）

### 4.2 MySQL 入侵排查

#### 4.2.1 排查用户和权限

```sql
-- 查看所有用户
SELECT user, host, password FROM mysql.user;

-- 查看用户权限
SHOW GRANTS FOR '用户名'@'主机';

-- 查看有 SUPER 权限的用户
SELECT user, host FROM mysql.user WHERE Super_priv='Y';

-- 查看有 FILE 权限的用户（可读写文件）
SELECT user, host FROM mysql.user WHERE File_priv='Y';

-- 查看有 GRANT 权限的用户
SELECT user, host FROM mysql.user WHERE Grant_priv='Y';
```

#### 4.2.2 排查当前连接和操作

```sql
-- 查看当前连接
SHOW PROCESSLIST;
SHOW FULL PROCESSLIST;

-- 查看正在执行的查询
SELECT * FROM information_schema.PROCESSLIST WHERE COMMAND != 'Sleep';

-- 查看慢查询
SHOW VARIABLES LIKE 'slow_query_log';
-- 慢查询日志位置
SHOW VARIABLES LIKE 'slow_query_log_file';
```

#### 4.2.3 排查数据库日志

```bash
# 查看错误日志
tail -f /var/log/mysqld.log
tail -f /var/log/mysql/error.log

# 查看通用查询日志（需开启）
SHOW VARIABLES LIKE 'general_log';
SHOW VARIABLES LIKE 'general_log_file';

# 查看二进制日志（用于数据恢复和操作审计）
SHOW VARIABLES LIKE 'log_bin';
SHOW BINARY LOGS;
mysqlbinlog /var/lib/mysql/binlog.000001
```

#### 4.2.4 排查数据篡改和泄露

```sql
-- 查看数据库大小
SELECT table_schema, ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS 'Size (MB)' 
FROM information_schema.TABLES 
GROUP BY table_schema;

-- 查看表的修改时间
SELECT table_name, create_time, update_time 
FROM information_schema.tables 
WHERE table_schema = '数据库名' 
ORDER BY update_time DESC;

-- 查看最近修改的表（通过 update_time 大致判断）
SELECT table_schema, table_name, update_time 
FROM information_schema.tables 
WHERE update_time > '2024-01-01 00:00:00' 
ORDER BY update_time DESC;
```

#### 4.2.5 排查 UDF 提权和后门

```sql
-- 查看自定义函数（UDF）
SELECT * FROM mysql.func;

-- 查看存储过程
SHOW PROCEDURE STATUS;
SHOW FUNCTION STATUS;

-- 查看触发器
SHOW TRIGGERS;
SELECT * FROM information_schema.TRIGGERS;

-- 查看事件调度器
SHOW EVENTS;
SELECT * FROM mysql.event;
```

### 4.3 SQL Server 入侵排查

#### 4.3.1 排查登录和用户

```sql
-- 查看所有登录名
SELECT name, type_desc, is_disabled FROM sys.server_principals WHERE type IN ('S', 'U', 'G');

-- 查看 sysadmin 角色成员
SELECT name FROM syslogins WHERE sysadmin = 1;

-- 查看数据库用户
SELECT name, type_desc FROM sys.database_principals;

-- 查看当前连接
SELECT * FROM sys.dm_exec_sessions;
SELECT * FROM sys.dm_exec_connections;
```

#### 4.3.2 排查日志

```sql
-- 查看错误日志
EXEC sp_readerrorlog;
EXEC sp_readerrorlog 0, 1;

-- 查看登录审计（需开启）
-- SQL Server Audit
SELECT * FROM sys.dm_server_audit_status;
```

#### 4.3.3 排查 xp_cmdshell 等危险存储过程

```sql
-- 查看 xp_cmdshell 是否启用
SELECT name, value_in_use FROM sys.configurations WHERE name = 'xp_cmdshell';

-- 查看 OLE 自动化过程
SELECT name, value_in_use FROM sys.configurations WHERE name = 'Ole Automation Procedures';

-- 查看 Ad Hoc Distributed Queries
SELECT name, value_in_use FROM sys.configurations WHERE name = 'Ad Hoc Distributed Queries';
```

### 4.4 Oracle 入侵排查

#### 4.4.1 排查用户和权限

```sql
-- 查看所有用户
SELECT username, account_status, created FROM dba_users;

-- 查看 DBA 权限用户
SELECT grantee FROM dba_role_privs WHERE granted_role = 'DBA';

-- 查看当前会话
SELECT * FROM v$session;
SELECT * FROM v$process;
```

#### 4.4.2 排查日志

```sql
-- 查看告警日志
-- 位置：$ORACLE_BASE/diag/rdbms/dbname/instancename/trace/alert_instancename.log

-- 查看审计日志（需开启）
SELECT * FROM dba_audit_trail;
SELECT * FROM dba_common_audit_trail;
```

### 4.5 Redis 入侵排查

Redis 因配置不当导致的入侵非常常见。

#### 4.5.1 常见入侵方式

- 未设置密码或弱密码
- 暴露在公网
- 利用 Redis 写 SSH 公钥提权
- 利用 Redis 写 Webshell
- 利用 Redis 写计划任务反弹 shell

#### 4.5.2 排查方法

```bash
# 连接 Redis
redis-cli -h 主机 -p 端口 -a 密码

# 查看配置
CONFIG GET *
CONFIG GET requirepass  # 查看密码
CONFIG GET bind        # 查看绑定地址
CONFIG GET dir         # 查看数据目录
CONFIG GET dbfilename  # 查看数据库文件名

# 查看所有键
KEYS *
DBSIZE

# 查看慢查询
SLOWLOG GET 10
```

#### 4.5.3 排查入侵痕迹

```bash
# 检查是否有 SSH 公钥被写入
cat /root/.ssh/authorized_keys

# 检查是否有计划任务被写入
crontab -l
cat /var/spool/cron/root

# 检查 Web 目录是否有新增文件
ls -la /var/www/html/
```

### 4.6 MongoDB 入侵排查

#### 4.6.1 常见入侵方式

- 未开启认证
- 暴露在公网
- 弱密码
- 漏洞利用

#### 4.6.2 排查方法

```bash
# 连接 MongoDB
mongo 主机:端口/数据库 -u 用户名 -p 密码

# 查看用户
use admin
db.system.users.find()

# 查看当前操作
db.currentOp()

# 查看数据库和集合
show dbs
show collections
```

### 4.7 数据库入侵响应步骤

1. **遏制**
   - 限制数据库访问（防火墙、修改 bind 地址）
   - 修改数据库管理员密码
   - 禁用可疑用户
   - 断开可疑连接（KILL）

2. **保护证据**
   - 备份数据库日志
   - 导出当前用户和权限配置
   - 保存慢查询日志
   - 保存二进制日志（MySQL）

3. **分析**
   - 分析入侵路径（SQL 注入？弱密码？漏洞？）
   - 分析泄露/篡改的数据
   - 分析攻击者的操作记录
   - 评估影响范围

4. **根除**
   - 删除可疑用户和权限
   - 删除恶意存储过程/UDF/触发器
   - 修补漏洞
   - 加固配置

5. **恢复**
   - 从备份恢复被篡改的数据
   - 验证数据完整性
   - 逐步恢复访问

6. **总结**
   - 编写事件报告
   - 加固数据库安全
   - 加强审计和监控
