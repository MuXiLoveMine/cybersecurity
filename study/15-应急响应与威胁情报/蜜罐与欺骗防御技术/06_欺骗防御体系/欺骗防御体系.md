### 6.1 主动欺骗技术

现代欺骗防御超越传统蜜罐，形成多层主动欺骗体系：

```
┌──────────────────────────────────────┐
│          欺骗防御管理层                │
│  策略引擎 + 自动化投放 + 告警分析     │
├──────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐    │
│  │网络欺骗│ │端点欺骗│ │数据欺骗│    │
│  │虚假子网│ │虚假服务│ │诱饵文件│    │

├──────────────────────────────────────┤
│          企业网络环境                  │
└──────────────────────────────────────┘
```

### 6.2 Canary文件与令牌

**Canary文件（诱饵文件）：**
- 在文件服务器、共享目录、用户桌面投放虚假的诱饵文件
- 文件名具有诱惑性（如"员工薪资表.xlsx"、"数据库配置.ini"、"客户名单.docx"）
- 文件被打开、复制、修改时触发告警
- 文件内嵌追踪令牌（Canarytoken）

**Canarytoken类型：**

| 令牌类型 | 触发方式 | 部署位置 | 检测场景 |
|----------|----------|----------|----------|
| Web Bug token | 文件被打开并联网 | 文档中 | 数据窃取检测 |
| DNS token | DNS查询触发 | 任意文件 | 内网渗透检测 |
| AWS API Key token | API Key被使用 | 配置文件中 | 云凭据窃取 |
| SQL token | SQL查询执行 | 数据库中 | 数据外泄检测 |
| Slack token | API调用 | 配置文件 | 凭据盗用检测 |
| Microsoft Word token | 宏执行 | Office文档 | 文档钓鱼 |
| PDF token | 链接点击 | PDF文件 | 文档分发追踪 |

**Canarytoken部署示例（Thinkst Canary）：**

```python
# 生成DNS Canarytoken
import canarytokens
token = canarytokens.generate(
    type='dns',
    domain='canarytokens.com',
    memo='财务共享目录诱饵-2024Q1'
)
# 生成结果：xxx.canarytokens.com
# 将此域名嵌入诱饵文件中
```

### 6.3 假数据与假凭证

**假凭证投放策略：**

- 在配置文件中放置假的数据库连接字符串
- 在代码仓库中放置假的API Key
- 在密码管理器中放置假的特权账号
- 在SSH known_hosts中添加虚假主机条目

**设计原则：**
1. 假凭证看起来必须真实（符合命名规范和格式）
2. 假凭证不能与任何真实系统关联（确保误用时可追溯）
3. 假凭证的使用必须在监控系统中设置唯一告警规则
4. 定期轮换假凭证（保持新鲜度）

### 6.4 内网横向移动诱捕

**内网欺骗诱饵部署方案：**

```
办公网VLAN:
  - 虚假文件服务器（SMB共享含Canary文件）
  - 虚假域控（LDAP响应虚假用户列表）
  - 虚假管理员工作站

核心网VLAN:
  - 虚假数据库（SQL蜜罐）
  - 虚假内部API网关
  - 虚假跳板机

云环境:
  - 虚假S3存储桶（含诱饵数据）
  - 虚假IAM角色和策略
  - 虚假Lambda函数端点
```

**ATT&CK映射的欺骗诱饵：**

| ATT&CK技术 | 欺骗诱饵 | 触发告警 |
|------------|----------|----------|
| T1555 Credentials from Password Stores | 假凭据文件 | 凭据被读取 |
| T1087 Account Discovery | 虚假AD用户 | LDAP查询虚假用户 |
| T1046 Network Service Scanning | 虚假开放端口 | 虚假服务被扫描 |
| T1021 Remote Services | 虚假SSH服务 | SSH登录到蜜罐 |
| T1083 File and Directory Discovery | Canary文件 | 文件被枚举 |
| T1077 Windows Admin Shares | 虚假SMB共享 | 共享被访问 |
| T1212 Exploitation for Credential Access | 虚假数据库 | SQL注入尝试 |
| T1048 Exfiltration Over Alternative Protocol | 虚假FTP服务 | 数据外传到蜜罐 |

### 6.5 ATT&CK对抗技术中的欺骗

欺骗防御在整个ATT&CK Kill Chain中的部署：

```
Initial Access → 虚假VPN入口、虚假外部服务
    ↓
Execution → 虚假脚本/虚假计划任务
    ↓
Persistence → 虚假注册表项、虚假服务
    ↓
Privilege Escalation → 虚假特权账户
    ↓
Defense Evasion → 虚假安全工具
    ↓
Credential Access → 虚假凭据存储
    ↓
Discovery → 虚假目录/用户/服务
    ↓
Lateral Movement → 虚假主机/虚假共享
    ↓
Collection → Canary文件/虚假数据库
    ↓
Exfiltration → 虚假外传通道
    ↓
Impact → 虚假备份/虚假关键系统
```
