# DeFi安全监控

### 6.1 链上监控

**Forta网络：**
```
Forta监控架构：
  检测代理(Detection Bots) → 实时监控链上交易
      ↓
  告警生成 → 推送到Forta网络
      ↓
  订阅者 → 接收告警 → 响应

  检测场景：
  - 大额闪电贷交易
  - 异常清算交易
  - 治理提案异常投票
  - 桥大额跨链交易
  - 合约权限变更
  - 代币异常增发
```

**CertiK Skynet：**
- 实时安全评分
- 社交媒体情绪监控
- 链上行为异常告警
- 项目方风险评估

### 6.2 异常交易检测

```
异常交易检测指标：

  1. 金额异常：单笔交易超过协议TVL的5%
  2. 频率异常：短时间内大量交互
  3. 价格异常：预言机价格偏离超过阈值
  4. 流向异常：资金流向非预期地址
  5. 组合异常：闪电贷+清算+跨链组合
  6. 合约交互异常：调用非白名单合约
  7. 治理异常：大额代币转移+投票组合
```

### 6.3 预言机监控

- **价格偏差监控**：Chainlink与DEX价格偏差超过阈值告警
- **预言机延迟监控**：预言机更新延迟超过阈值告警
- **多源一致性**：多个预言机价格不一致告警
- **预言机合约变更**：预言机地址/合约升级监控
