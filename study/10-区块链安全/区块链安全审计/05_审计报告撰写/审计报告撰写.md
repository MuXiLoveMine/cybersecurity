# 审计报告撰写

### 5.1 审计报告结构

一份标准的智能合约审计报告通常包含以下部分：

```
1. 执行摘要（Executive Summary）
   ├─ 项目概述
   ├─ 审计范围
   ├─ 审计时间
   ├─ 整体评价
   └─ 漏洞统计

2. 审计方法（Audit Methodology）
   ├─ 静态分析
   ├─ 动态分析
   ├─ 人工审查
   ├─ 工具列表
   └─ 测试环境

3. 审计发现（Findings）
   ├─ 高危漏洞（Critical）
   ├─ 中危漏洞（High）
   ├─ 低危漏洞（Medium）
   ├─ 信息提示（Low）
   └─ 代码优化建议（Informational）

4. 详细漏洞分析
   └─ 每个漏洞包含：
      ├─ 漏洞标题
      ├─ 风险等级
      ├─ 影响范围
      ├─ 漏洞描述
      ├─ 漏洞代码
      ├─ 利用方式 / PoC
      ├─ 修复建议
      └─ 修复状态

5. 附录
   ├─ 合约文件列表
   ├─ 参考资料
   └─ 审计团队介绍
```
