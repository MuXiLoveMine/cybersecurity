| **SWC-105** | Unprotected Ether Withdrawal | 未保护的 ETH 提取 |
| **SWC-106** | Unprotected SELFDESTRUCT | 未保护的自毁 |
| **SWC-107** | Reentrancy | 重入攻击 |
| **SWC-108** | State Variable Default Visibility | 状态变量默认可见性 |
| **SWC-109** | Uninitialized Storage Pointer | 未初始化的存储指针 |
| **SWC-110** | Assert Violation | 断言违反 |
| **SWC-111** | Use of Deprecated Solidity Functions | 使用已弃用函数 |
| **SWC-112** | Delegatecall to Untrusted | 向不可信合约委托调用 |
| **SWC-113** | DoS with Failed Call | 调用失败导致拒绝服务 |
| **SWC-114** | Transaction Order Dependence | 交易顺序依赖 |
| **SWC-115** | Authorization through tx.origin | 通过 tx.origin 授权 |
| **SWC-116** | Block values as a proxy for time | 区块值作为时间代理 |

| **SWC-119** | Shadowing State Variables | 状态变量遮蔽 |
| **SWC-120** | Weak Sources of Randomness | 弱随机源 |
| **SWC-121** | Missing Protection against Signature Replay | 缺少签名重放保护 |
| **SWC-122** | Lack of Proper Signature Verification | 缺乏正确的签名验证 |

| **SWC-134** | Message call with hardcoded gas amount | 硬编码 gas 数量的消息调用 |
| **SWC-135** | Code With No Effects | 无效果的代码 |
| **SWC-136** | Unencrypted Private Data | 未加密的私有数据 |

### 4.3 漏洞模式识别指南

#### 4.3.1 快速识别重入攻击

**搜索关键词：** `.call{value:`、`send(`、`transfer(`、`.value(`

**检查要点：**
1. 外部调用前是否更新了状态？
2. 是否使用了 nonReentrant 修饰符？
3. 是否遵循 Checks-Effects-Interactions 模式？

#### 4.3.2 快速识别权限问题

**搜索关键词：** `onlyOwner`、`require(msg.sender`、`tx.origin`、`function mint`、`function burn`

**检查要点：**
1. 敏感函数是否有权限修饰符？
2. 是否使用了 tx.origin 做验证？
3. 初始化函数是否只能调用一次？

#### 4.3.3 快速识别溢出问题

**搜索关键词：** `+`、`-`、`*`、`/`、`SafeMath`、`unchecked`

**检查要点：**
1. Solidity 版本是否低于 0.8？
2. 是否使用了 SafeMath？
3. 循环中是否有 i++ 的边界检查？

#### 4.3.4 快速识别预言机问题

**搜索关键词：** `price`、`oracle`、`getReserves`、`spot`、`twap`

**检查要点：**
1. 价格来源是现货还是 TWAP？
2. 是否可以被闪电贷操纵？
3. 是否有多重价格源？
