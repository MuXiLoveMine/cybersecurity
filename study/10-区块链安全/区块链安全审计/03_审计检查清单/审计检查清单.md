# 审计检查清单

### 3.1 通用安全检查清单

#### 3.1.1 权限控制

| 检查项 | 说明 | 风险等级 |
|--------|------|---------|
| 敏感函数是否有权限修饰符 | mint、burn、withdraw 等函数是否有 onlyOwner 等 | 高危 |
| 权限检查是否正确 | 是否使用 msg.sender 而非 tx.origin | 高危 |
| 权限是否最小化 | 是否每个角色只有必要的权限 | 中危 |
| 权限转移是否安全 | 所有权转移是否有安全确认 | 中危 |
| 初始化函数是否受保护 | initialize 函数是否只能调用一次 | 高危 |
| 构造函数是否正确 | 是否有拼写错误（旧版本） | 高危 |

#### 3.1.2 数学运算

| 检查项 | 说明 | 风险等级 |
|--------|------|---------|
| 是否有溢出风险 | 0.8 以下版本是否使用 SafeMath | 高危 |
| 除法精度问题 | 除法是否先乘后除避免精度损失 | 中危 |
| 舍入方向是否正确 | 舍入是否对用户有利而非对合约有利 | 中危 |
| 零除保护 | 除数是否可能为零 | 高危 |
| 数组越界 | 数组访问是否有边界检查 | 高危 |

#### 3.1.3 外部调用

| 检查项 | 说明 | 风险等级 |
|--------|------|---------|
| 是否检查返回值 | call/send 的返回值是否检查 | 高危 |
| 重入风险 | 外部调用前是否已更新状态 | 高危 |
| 调用顺序 | 是否遵循 Checks-Effects-Interactions | 高危 |
| Gas 限制 | 是否控制外部调用的 Gas 量 | 中危 |
| 可信合约 | 外部调用的合约是否可信 | 中危 |
| delegatecall 安全 | delegatecall 的目标合约是否可信 | 高危 |

#### 3.1.4 状态管理

| 检查项 | 说明 | 风险等级 |
|--------|------|---------|
| 状态更新顺序 | 是否先更新状态后外部调用 | 高危 |
| 状态变量可见性 | 敏感变量是否设为 private | 低危 |
| 初始化顺序 | 继承合约的初始化顺序是否正确 | 中危 |
| 存储布局 | 代理合约的存储布局是否一致 | 高危 |

### 3.2 业务逻辑检查清单

#### 3.2.1 代币合约（ERC20）

| 检查项 | 说明 |
|--------|------|
| 精度计算 | decimals 是否正确处理 |
| 总量控制 | totalSupply 是否与实际铸造量一致 |
| 转账逻辑 | transfer/transferFrom 是否符合标准 |
| 授权逻辑 | approve 是否有竞争问题 |
| 铸币权限 | mint 函数是否有正确的权限控制 |
| 销毁逻辑 | burn 函数是否正确减少总量 |
| 黑白名单 | 黑白名单机制是否正确实现 |

#### 3.2.2 借贷协议

| 检查项 | 说明 |
|--------|------|
| 价格预言机 | 价格来源是否安全，是否可被操纵 |
| 抵押率计算 | LTV 计算是否正确 |
| 清算逻辑 | 清算触发条件和奖励是否正确 |
| 利率模型 | 利率计算是否正确 |
| 流动性风险 | 是否可能发生挤兑 |
| 闪电贷风险 | 是否能抵御闪电贷攻击 |

#### 3.2.3 DEX/AMM

| 检查项 | 说明 |
|--------|------|
| 定价公式 | xy=k 等定价公式是否正确实现 |
| 滑点保护 | 是否有最小输出量检查 |
| 手续费计算 | 手续费收取和分配是否正确 |
| LP 代币 | 流动性凭证的铸造和销毁是否正确 |
| 无常损失 | 是否有相关机制缓解 |
| 前置交易 | 是否有防抢跑机制 |

### 3.3 合约升级检查清单

| 检查项 | 说明 | 风险等级 |
|--------|------|---------|
| 初始化函数 | initialize 是否只能调用一次 | 高危 |
| 存储布局 | 升级前后存储布局是否一致 | 高危 |
| 升级权限 | 升级权限是否有适当控制 | 中危 |
| 时间锁 | 升级是否有时间锁延迟 | 中危 |
| 实现合约 | 实现合约本身是否安全 | 高危 |
| 代理兼容性 | 新实现是否与旧存储兼容 | 高危 |

### 3.4 经济模型检查清单

| 检查项 | 说明 |
|--------|------|
| 通胀模型 | 代币发行是否可控 |
| 奖励计算 | 奖励分配是否正确 |
| 锁仓机制 | 锁仓和释放是否正确 |
| 治理机制 | 投票和提案是否安全 |
| 经济攻击面 | 是否存在经济攻击向量 |
| 极端场景 | 极端情况下系统是否稳定 |
