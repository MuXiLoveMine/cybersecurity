# 逻辑漏洞

### 7.1 漏洞原理

逻辑漏洞是指合约的业务逻辑设计存在缺陷，导致攻击者可以利用正常的操作流程获取不当利益。这类漏洞往往最隐蔽，也最容易造成重大损失。

**常见类型：**
1. 价格预言机操纵
2. 闪电贷攻击
3. 治理攻击
4. 权限绕过
5. 业务逻辑错误

```solidity
}
```

### 7.3 闪电贷攻击

**原理：** 闪电贷允许在同一笔交易中无抵押借贷，利用交易的原子性（要么全部成功，要么全部回滚）。

**攻击模式：**
```
1. 从闪电贷池借出大量资金
2. 利用资金操纵价格/进行攻击
3. 归还闪电贷本金 + 利息
4. 剩余利润归攻击者所有
```

**典型案例：bZx 攻击（2020）**
- 利用闪电贷借出资金
- 在不同交易所之间操纵价格
- 进行错误的清算获利

### 7.4 治理攻击

**漏洞原理：** 攻击者通过大量获取治理代币，控制投票来执行恶意提案。

**攻击方式：**
1. 借大量治理代币（闪电贷）
2. 提交恶意提案并投票
3. 执行提案窃取资金
4. 归还代币

**防御：**
- 投票锁定（投票需要锁仓一段时间）
- 延迟执行（提案通过后延迟执行）
- 时间锁（Timelock）
