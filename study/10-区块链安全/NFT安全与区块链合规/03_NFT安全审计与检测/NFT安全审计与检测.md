# NFT安全审计与检测

### 3.1 NFT合约审计要点

NFT合约审计应系统检查以下方面：

**标准合规性**：
- 是否正确实现ERC-721/ERC-1155接口。
- 是否正确触发Transfer、Approval等事件。
- safeTransferFrom是否正确校验目标合约接口。

**铸币安全**：
- mint函数权限控制是否正确。
- tokenId生成方式是否安全（防碰撞、防预测）。
- 铸币数量限制是否有效。
- 铸币支付逻辑是否安全（重入保护）。

**转移安全**：
- transfer函数权限控制（仅所有者或授权者可调用）。
- 黑名单/冻结功能（如需要合规）。
- 批量转移的Gas限制。

**元数据安全**：
- tokenURI返回的URI是否可被恶意修改。
- 元数据存储方式是否去中心化。
- URI拼接逻辑是否安全（防路径遍历）。

**版税逻辑**：
- 版税计算是否正确（EIP-2981实现）。
- 版税接收地址是否可被篡改。
- 版税上限是否合理。

**升级安全**（如使用代理模式）：
- 升级权限是否合理（多签/DAO）。
- 升级时间锁是否充足。
- 存储槽是否正确（EIP-1967）。

### 3.2 NFT真实性验证方法

验证NFT是否为"正版"的方法：

1. **合约地址验证**：通过官方渠道获取合约地址，与链上实际对比。不依赖名称或外观。
2. **区块浏览器验证**：在Etherscan等浏览器上查看合约源码是否已验证，对比官方发布版本。
3. **IPFS CID验证**：如果元数据存储在IPFS，验证CID是否与官方公布的一致。
4. **创建者验证**：查看NFT的创建者地址是否为项目官方地址。
5. **交易历史分析**：正版NFT的发行历史应与项目方公布的铸币时间、数量一致。
6. **市场认证标识**：OpenSea等平台对官方系列有蓝色认证标识（但认证也可能被仿冒）。
7. **社区工具验证**：使用GoPlus Security、Token Sniffer等工具自动检测。

### 3.3 链上洗售交易检测

系统化的洗售交易检测方法：

**指标检测**：
- **自交易比率**：买卖双方为同一地址或资金直接回流。
- **交易频率**：短时间内同一NFT高频转手。
- **价格异常**：交易价格显著偏离市场均价。
- **资金关联性**：交易双方地址有直接转账历史。

**地址聚类**：
- 通过资金流向将多个地址聚类为同一实体。
- 同一实体的地址间交易即为可疑洗售。
- 使用图分析算法识别资金环路。

**机器学习检测**：
- 基于历史洗售交易样本训练分类模型。
- 特征包括：交易频率、金额分布、时间模式、地址关联图。
- 实时检测新交易的洗售概率。

**工具**：
- Chainalysis的NFT Wash Trading检测。
- NFT Scrape的洗售分析工具。
- 自定义Dune Analytics查询脚本。

### 3.4 NFT安全工具

- **GoPlus Security**：NFT安全检测API，检测恶意合约、洗售交易等。
- **Token Sniffer**：自动分析代币和NFT合约安全性。
- **Etherscan Token Checker**：查看合约验证状态和代币安全标签。
- **Dune Analytics**：SQL查询链上数据，自定义安全分析仪表盘。
- **NFT Scrape**：NFT市场数据抓取和分析。
- **Icy Tools**：NFT交易数据分析和异常检测。
- **BitsCrunch**：NFT数据分析和真实性验证。
