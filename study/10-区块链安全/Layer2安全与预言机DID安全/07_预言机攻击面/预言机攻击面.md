# 预言机攻击面

### 7.1 数据篡改攻击

攻击者通过操纵预言机数据源来影响链上价格：

```
数据篡改攻击向量：

1. 直接攻击数据源
   ├── 攻击交易所 API → 注入虚假价格
   ├── 攻击预言机节点 → 篡改上报数据
   └── 难度：高（需攻击中心化服务）

2. 操纵 DEX 池子价格
   ├── 大额交易改变 AMM 池子汇率
   ├── 闪电贷放大交易规模
   └── 难度：中（取决于流动性深度）

3. 利用预言机延迟
   ├── 预言机更新有延迟
   ├── 利用延迟窗口执行套利
   └── 难度：中（需精确时序）

4. 时间戳操纵
   ├── 矿工/验证者操纵区块时间戳
   ├── 影响时间依赖的预言机逻辑
   └── 难度：低-中（取决于实现）
```

### 7.2 闪电贷操纵预言机

闪电贷（Flash Loan）允许无抵押借入大量资金在同一区块内归还，攻击者可利用闪电贷操纵 DEX 价格，从而操纵链上预言机：

```
闪电贷操纵攻击流程：

步骤 1: 闪电贷借入大额资产
  ┌──────────────────────────────────────────────────┐
  │ 从 Aave 闪电贷借入 100,000 ETH (无抵押)           │
  │ 还款要求: 同一区块内归还 100,000 ETH + 0.09% 手续费│
  └──────────────────────────────────────────────────┘

步骤 2: 操纵 DEX 价格
  ┌──────────────────────────────────────────────────┐
  │ 用 100,000 ETH 在 Uniswap 兑换 XYZ 代币           │
  │ → Uniswap ETH/XYZ 池子被严重偏移                   │
  │ → XYZ 价格被推高 10 倍（从 $1 → $10）             │
  └──────────────────────────────────────────────────┘

步骤 3: 利用被操纵的价格
  ┌──────────────────────────────────────────────────┐
  │ 借贷协议使用 Uniswap 即时价格作为预言机           │
  │ → 协议认为 XYZ 价值 $10                            │
  │ → 攻击者用被推高的 XYZ 作为抵押借出更多 ETH        │
  │ → 借入 500,000 美元的 ETH                          │
  └──────────────────────────────────────────────────┘

步骤 4: 价格回落
  ┌──────────────────────────────────────────────────┐
  │ 攻击者将步骤2买入的 XYZ 在其他 DEX 卖出            │
  │ → Uniswap 价格回落（或套利者恢复）                 │
  │ → 但攻击者已借出的 ETH 不受影响                    │
  └──────────────────────────────────────────────────┘

步骤 5: 归还闪电贷 + 获利
  ┌──────────────────────────────────────────────────┐
  │ 归还 100,000 ETH + 手续费                         │
  │ 净获利: 500,000 - 100,000 手续费 = 约 $499,000     │
  │ 协议损失: 500,000 美元的坏账                       │
  └──────────────────────────────────────────────────┘
```

### 7.3 操纵市场攻击

```
市场操纵攻击（非闪电贷）：

  场景: 预言机使用多个 CEX 的现货价格

  攻击方式:
  1. 攻击者在低流动性交易所大量买入代币
  2. 该交易所价格被推高
  3. 预言机聚合多个交易所价格
  4. 如果低流动性交易所权重过高 → 聚合价格被影响
  5. 攻击者利用偏移的聚合价格获利

  关键条件:
  - 预言机的价格聚合算法对异常值不敏感
  - 低流动性交易所有较高权重
  - 预言机更新频率较低（延迟利用）
```
