# 自私挖矿

### 3.1 攻击原理

自私挖矿（Selfish Mining）是指矿工挖到新块后不立即广播，而是继续秘密挖矿，等到合适的时机再公布，从而获得超出其算力比例的收益。

**提出者：** Ittay Eyal 和 Emin Gün Sirer（2013 年）

### 3.2 攻击过程

```
正常挖矿：
  矿工挖到区块 → 立即广播 → 全网接受 → 获得区块奖励
  
自私挖矿：
  矿工挖到区块 → 保密，继续在上面挖矿
  → 如果其他矿工也挖到了区块，选择性公布
  → 利用自己的秘密链优势获得更多奖励
```

**详细步骤：**

```
状态 1：自私矿工挖到区块 1（秘密）
  公开链高度 = N
  秘密链高度 = N+1
  自私矿工领先 1 个区块

状态 2：诚实矿工挖到区块 N+1（公开）
  公开链高度 = N+1
  秘密链高度 = N+1
  两条链一样长
  → 自私矿工公布自己的区块 1，形成分叉
  → 部分矿工在自私矿工的链上挖矿

状态 3：如果自私矿工又挖到一个区块
  秘密链高度 = N+2
  → 公布全部秘密链（2 个区块）
  → 诚实矿工的区块作废
  → 自私矿工获得 2 个区块的奖励
  → 算力占比 < 收益占比
```

### 3.3 攻击效果

- 当自私矿工的算力大于 25% 时，攻击就可能盈利
- 算力越大，收益越高
- 攻击会降低整个网络的安全性（浪费诚实算力）

### 3.4 防御措施

1. **统一的区块传播协议**：确保区块快速传播
2. **惩罚机制**：对可疑的自私挖矿行为进行惩罚
3. **改进共识算法**：如 GHOST 协议等
