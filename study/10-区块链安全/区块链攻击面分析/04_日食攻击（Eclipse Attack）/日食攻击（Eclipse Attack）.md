# 日食攻击（Eclipse Attack）

### 4.1 攻击原理

日食攻击（Eclipse Attack）是一种网络层攻击，攻击者通过控制目标节点的所有对等连接，将目标节点与网络的其余部分隔离开来，向其提供虚假的区块链视图。

**名称由来：** 像日食一样，将目标节点「遮蔽」，使其看不到真实的网络。

```
正常网络：
  目标节点 ←→ 节点 A ←→ 节点 B ←→ 节点 C ←→ ...

日食攻击后：
  攻击者控制的节点群 ←→ 目标节点 ←→ 攻击者控制的节点群
                        （目标节点完全被攻击者节点包围）
                        （目标节点看不到真实的网络）
```

### 4.2 攻击方式

攻击者通过以下方式垄断目标节点的连接：

1. **建立大量连接**：攻击者创建多个节点，与目标节点建立连接
2. **驱逐合法节点**：利用 P2P 协议的特性，挤掉目标节点的合法对等节点
3. **地址污染**：向目标节点提供虚假的节点地址
4. **BGP 劫持**：通过网络层攻击控制目标节点的网络流量

### 4.3 攻击后果

| 后果 | 说明 |
|------|------|
| **交易屏蔽** | 目标节点的交易永远不会被打包 |
| **假链欺骗** | 向目标节点提供假的区块链数据 |
| **算力浪费** | 目标节点在假链上挖矿，算力被浪费 |
| **双花辅助** | 配合双花攻击，让商家看到假的确认 |

### 4.4 防御措施

1. **增加对等节点数量**：连接更多节点，降低被完全隔离的概率
2. **随机选择节点**：从多个来源获取节点地址
3. **节点多样性**：连接不同地区、不同网络的节点
4. **监控异常**：监测对等节点的行为是否异常
5. **多源数据验证**：从多个渠道验证区块信息
