# 交易所安全

### 6.1 交易所类型

#### 6.1.1 中心化交易所（CEX）

**代表：** Binance、Coinbase、OKX、Kraken

**特点：**
- 用户资产由交易所托管
- 交易速度快，深度好
- 支持法币交易
- 监管合规（部分）
- KYC/AML 要求

**风险点：**
- 单点故障风险
- 交易所被盗
- 交易所跑路
- 内部人员作案
- 监管风险

#### 6.1.2 去中心化交易所（DEX）

**代表：** Uniswap、SushiSwap、dYdX、Curve

**特点：**
- 用户资产由自己控制
- 无需 KYC
- 链上交易，透明可查
- 非托管式

**风险点：**
- 智能合约漏洞
- 闪电贷攻击
- 价格操纵
- 无常损失
- 滑点问题

### 6.2 中心化交易所安全架构

#### 6.2.1 冷热钱包分离

```
┌─────────────────────────────────────────────────┐
│                   热钱包（Hot Wallet）            │
│  - 联网，用于日常提现                              │
│  - 只存少量资金（如总资金的 5%）                   │
│  - 多签管理                                       │
│  - 实时监控                                       │
└────────────────────┬────────────────────────────┘
                     │ 定期补充
                     ↓
┌─────────────────────────────────────────────────┐
│                   冷钱包（Cold Wallet）           │
│  - 离线存储，不联网                                │
│  - 存储大部分资金（如总资金的 95%）                 │
│  - 多重签名                                       │
│  - 物理隔离（硬件钱包、纸钱包）                     │
└─────────────────────────────────────────────────┘
```

#### 6.2.2 多重签名（Multi-Sig）

**2/3 多签示例：**
```
密钥 A（CEO 持有）
密钥 B（CTO 持有）
密钥 C（COO 持有）

任意 2 个签名即可转账
→ 单个密钥泄露不会导致资金被盗
→ 单个密钥丢失不会导致资金无法取出
```

#### 6.2.3 安全风控体系

| 风控层级 | 措施 |
|---------|------|
| **账户安全** | 2FA、短信验证、邮箱验证、设备绑定 |
| **提现安全** | 提现白名单、提现延迟、人工审核（大额） |
| **资产安全** | 冷热钱包分离、多重签名、储备金证明 |
| **系统安全** | 防火墙、入侵检测、DDoS 防护 |
| **运营安全** | 权限分级、操作审计、定期安全审计 |
| **数据安全** | 加密存储、备份、灾备 |

### 6.3 交易所常见攻击方式

| 攻击类型 | 描述 | 防御措施 |
|---------|------|---------|
| **钓鱼攻击** | 伪造交易所网站骗取账号密码 | 2FA、域名验证、反钓鱼码 |
| **API 密钥泄露** | 用户 API 密钥被盗 | IP 白名单、权限限制、提现白名单 |
| **社工攻击** | 冒充客服骗取信息 | 官方渠道验证、信息保密教育 |
| **内部作案** | 员工盗取用户资产 | 权限分离、多签、审计 |
| **系统入侵** | 黑客入侵交易所系统 | 安全审计、渗透测试、监控 |
| **DDoS 攻击** | 分布式拒绝服务 | CDN、流量清洗 |

### 6.4 著名交易所被盗事件

| 事件 | 时间 | 损失 | 原因 |
|------|------|------|------|
| **Mt. Gox** | 2014 | 85 万 BTC | 管理混乱 + 技术漏洞 |
| **Coincheck** | 2018 | 5.3 亿美元 | 热钱包私钥被盗 |
| **Binance** | 2019 | 7000 BTC | 钓鱼 + 系统漏洞 |
| **KuCoin** | 2020 | 2.8 亿美元 | 私钥泄露 |
| **FTX** | 2022 | 百亿美元 | 挪用用户资金（内鬼） |
