# % 攻击

### 1.1 攻击原理

51% 攻击（多数攻击）是指攻击者控制了区块链网络中超过 50% 的算力（PoW）或权益（PoS），从而能够篡改区块链的交易历史。

**PoW 链的 51% 攻击：**
```
正常情况：
  全网算力 = 100%
  攻击者算力 < 50%
  → 攻击者无法比诚实链更快地生成区块

攻击情况：
  攻击者算力 > 50%
  → 攻击者可以秘密挖矿，生成一条更长的链
  → 攻击者发布更长的链，网络接受它作为主链
  → 攻击者可以回滚攻击期间的交易
```

### 1.2 攻击条件

| 区块链类型 | 攻击成本构成 | 攻击难度 |
|-----------|-------------|---------|
| **Bitcoin** | 购买/租赁 ASIC 矿机 + 电费 | 极高（需数十亿美元） |
| **Ethereum（PoS）** | 购买并质押 320 万+ ETH | 极高（需数百亿美元） |
| **小算力 PoW 链** | 租赁算力（NiceHash 等平台） | 较低（几千到几十万美元） |
| **DPoS 链** | 控制超级节点 | 中等 |

### 1.3 攻击能力

攻击者控制 51% 算力后可以：

| 能力 | 说明 |
|------|------|
| **双花攻击** | 回滚自己的支付交易，重复使用同一笔资金 |
| **阻止交易确认** | 选择性地排除某些交易，不让它们上链 |
| **阻止出块** | 不让其他矿工挖出的区块被接受 |
| **自私挖矿** | 隐瞒自己挖出的区块，获取更多收益 |

**攻击者不能做的事：**
- 不能凭空创造新币（除非改变协议规则，需要硬分叉）
- 不能偷走别人的私钥
- 不能修改未被攻击覆盖的历史区块（攻击前的交易无法篡改）
- 不能控制整个网络的所有节点

### 1.4 攻击过程详解（双花场景）

```
步骤 1：攻击者准备
  - 控制 51% 以上的算力
  - 在交易所存入一定数量的加密货币

步骤 2：攻击者发起两笔交易
  交易 A（公开链）：在交易所卖出，换成法币提现
  交易 B（秘密链）：把币转回自己的地址（双花）

步骤 3：攻击者秘密挖矿
  - 攻击者从交易 B 之前的区块开始秘密挖矿
  - 由于算力优势，攻击者的链增长更快

  公开链：  ... ← 区块 N ← 交易 A ← 区块 N+1 ← 区块 N+2
  秘密链：  ... ← 区块 N ← 交易 B ← 区块 N+1' ← 区块 N+2' ← 区块 N+3'

步骤 4：攻击者发布秘密链
  - 当秘密链比公开链更长时，攻击者发布
  - 网络协议接受最长链作为有效链
  - 交易 A 被回滚，交易 B 生效

步骤 5：攻击完成
  - 攻击者拿到了交易所的法币
  - 同时加密货币又回到了自己的地址
```

### 1.5 防御措施

1. **增加确认数**：等待更多区块确认，增加攻击者需要回滚的区块数
2. **提高攻击成本**：全网算力/权益越大，攻击成本越高
3. **算法抗 ASIC**：使用抗 ASIC 的挖矿算法，降低算力集中风险
4. **检查点机制**：定期设置检查点，检查点之前的区块不可回滚
5. **最终性机制**：PoS 链的最终性确认（如以太坊的 epoch 最终性）

### 1.6 真实案例

- **Bitcoin Gold 51% 攻击（2018）**：损失约 1800 万美元
- **Ethereum Classic 51% 攻击（2020）**：损失约 560 万美元
- **Vertcoin 多次遭受 51% 攻击**：小算力 PoW 链的通病
