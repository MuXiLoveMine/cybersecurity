# %攻击真实案例分析

### 7.1 Ethereum Classic 51%攻击(2019)

```
Ethereum Classic (ETC) 51%攻击事件

时间: 2019年1月
攻击者: 未知(疑似使用NiceHash租用算力)
损失: 约110万美元(双层花费)

攻击时间线:
  T0: 攻击者在交易所存入大量ETC
  T1: 交易所确认存款(等待12个确认)
  T2: 攻击者私下开始挖矿替代链
      | 替代链包含将ETC转回自己地址的交易
  T3: 攻击者租用算力追赶主链
  T4: 替代链长度超过主链
  T5: 攻击者发布替代链
      | 主链被重组
      | 交易所存款交易被回滚
  T6: 攻击者在替代链上已持有ETC
      | 在另一交易所提现

技术分析:
  ETC网络算力: 约8 TH/s
  攻击所需算力: >4 TH/s
  NiceHash可租用算力: 约30 TH/s
  攻击成本: 约每小时$5,000-$10,000
  攻击时长: 数小时
  重组深度: 约3000+区块

关键教训:
  1. 小币种51%攻击成本极低
  2. 交易所确认数不足(12确认对ETC不够)
  3. 算力租用平台降低了攻击门槛
  4. 算力与主链相同算法的币种共享安全风险
```

### 7.2 Bitcoin Gold 51%攻击(2018)

```
Bitcoin Gold (BTG) 51%攻击事件

时间: 2018年5月
攻击者: 未知
损失: 约1860万美元
手法: 双花攻击针对交易所

攻击细节:
  1. 攻击者在多个交易所开设账户
  2. 购买大量BTG
  3. 充值到交易所
  4. 交易所确认后，攻击者提现其他币种
  5. 攻击者用51%算力重组链
  6. 充值交易被回滚
  7. BTG在攻击者钱包中未减少

攻击成本估算:
  BTG网络算力: 约3-5 MSol/s
  攻击所需算力: 1.5-2.5 MSol/s
  租用成本: 约$1,000-$5,000/小时
  攻击收益: $18,600,000
  ROI: 极高

后续影响:
  - 多家交易所下架BTG
  - BTG价格暴跌
  - 社区讨论改为PoS或合并挖矿
  - 提高了交易所的确认数要求
```
