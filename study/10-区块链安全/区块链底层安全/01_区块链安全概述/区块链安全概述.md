# 区块链安全概述

### 1.1 区块链信任模型

传统系统依赖中心化信任，区块链通过密码学和共识机制实现去信任化：

```
传统信任模型:
  用户 --> 中心化机构 --> 数据库
  信任点: 中心化机构

区块链信任模型:
  用户 --> P2P网络 --> 分布式账本
         |          |
         v          v
    密码学验证   共识机制
  信任点: 数学(密码学) + 经济激励(共识)
```

### 1.2 安全属性

| 安全属性 | 实现机制 | 威胁 |
|----------|----------|------|
| 不可篡改 | 哈希链 + 共识 | 51%攻击、长程攻击 |
| 去中心化 | P2P网络 | 女巫攻击、日蚀攻击 |
| 匿名性 | 地址+签名 | 交易追踪、侧信道 |
| 可用性 | 分布式节点 | DDoS、网络分区 |
| 一致性 | 共识协议 | 分叉、双花 |
