# P2P网络攻击

### 4.1 女巫攻击

**攻击原理**

攻击者在P2P网络中创建大量虚假节点身份，控制网络通信：

```
正常网络:
  节点A <--> 节点B <--> 节点C
  每个节点是真实的

女巫攻击:
  节点A <--> [Sybil1, Sybil2, Sybil3, ...] <--> 节点B
  攻击者创建大量假节点
  - 影响路由
  - 影响投票
  - 实施审查
```

**区块链中的影响**

```
1. 交易审查
   - 女巫节点拒绝转发特定交易
   - 阻断合法交易传播

2. 区块传播延迟
   - 延迟区块传播
   - 增加分叉概率

3. 路由控制
   - 控制节点间通信路径
   - 配合日蚀攻击

4. 投票影响(在DPoS等)
   - 影响出块者选举
   - 影响治理投票
```

**防御措施**

```
1. 身份成本
   - PoW: 创建节点需要算力(挖矿成本)
   - PoS: 创建验证者需要质押
   - 许可链: 需要准入认证

2. 信任计算
   - 基于声誉的信任模型
   - 随机选择连接节点

3. 网络层防护
   - 限制单IP连接数
   - 随机化节点选择
   - 使用多样化网络层
```

### 4.2 日蚀攻击

**攻击原理**

日蚀攻击（Eclipse Attack）将目标节点与网络的连接完全隔离，使其只能与攻击者节点通信：

```
正常状态:
  受害者 <--> 网络中多个节点
  受害者获得全网信息

日蚀攻击后:
  受害者 <--> 攻击者控制的节点(看似多个)
  受害者只能获得攻击者提供的信息

  攻击效果:
  - 0确认双花: 受害者看到虚假交易
  - 区块延迟: 受害者获取区块延迟
  - 算力浪费: 矿工在旧链上挖矿
```

**攻击步骤**

```
1. 信息收集
   - 获取目标节点的出站连接IP
   - 分析目标节点的连接模式

2. 节点占位
   - 攻击者在目标节点地址池中填入攻击者IP
   - 等待目标节点重启或连接超时

3. 隔离
   - 目标节点重启后连接到攻击者节点
   - 攻击者节点拒绝其他节点连接
   - 目标完全被隔离

4. 利用
   - 向受害者提供虚假信息
   - 实施双花或延迟攻击
```

**防御措施**

```
1. 随机化连接
   - 随机选择出站连接节点
   - 不信任单一路径

2. 地址表多样性
   - 维护多样化的地址表
   - 不全部替换为新地址

3. 连接验证
   - 验证节点提供的区块是否与已知一致
   - 检测信息不一致

4. 锚定连接
   - 保持与已知可信节点的连接
   - 定期验证连接有效性

5. 感知延迟
   - 检测异常的网络延迟
   - 怀疑被隔离的情况
```

### 4.3 DDoS攻击

```
区块链DDoS攻击类型:

1. 交易泛洪
   - 大量低价值交易占用内存池
   - 提高交易费用
   - 延迟合法交易确认

2. 区块泛洪
   - 发送大量无效区块
   - 占用节点验证资源

3. 连接耗尽
   - 占满节点连接槽位
   - 阻止合法连接

4. 计算密集攻击
   - 发送复杂智能合约调用
   - 消耗节点计算资源

防御措施:
  - 交易费用市场机制
  - 内存池大小限制
  - 连接数限制
  - 请求频率限制
  - 验证难度调整
```

### 4.4 网络分区攻击

```
网络分区攻击:

  正常网络:
    A <---> B <---> C <---> D
    所有节点同步

  分区后:
    A <---> B     C <---> D
    两个分区独立运行

  危害:
  - 双花: 不同分区确认不同交易
  - 分叉: 合并时产生重组
  - 拒绝服务: 部分节点无法正常交易

  防御:
  - 监控网络分区
  - 检测分区合并
  - 延长确认时间
  - 分区检测和自动暂停
```
