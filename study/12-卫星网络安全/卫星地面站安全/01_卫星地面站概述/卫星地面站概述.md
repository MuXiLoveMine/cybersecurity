# 卫星地面站概述

### 1.1 地面站定义与作用

卫星地面站（Ground Station, GS）是地面与卫星之间进行通信、控制、数据传输的核心设施。它是整个卫星系统中唯一与公共网络直接连接的环节，因此成为安全防护的重点：

```
卫星系统三大组成部分:

┌─────────────────────────────────────────┐
│            空间段 (Space Segment)       │
│  ┌───┐ ┌───┐ ┌───┐                     │
│  │SAT1│ │SAT2│ │SAT3│  卫星星座         │
│  └─┬─┘ └─┬─┘ └─┬─┘                     │
└────┼─────┼─────┼────────────────────────┘
     │     │     │  上下行链路
┌────┼─────┼─────┼────────────────────────┐
│    │     │     │    地面段 (Ground)      │
│  ┌─┴─────┴─────┴─┐                       │
│  │   地面站网络   │  ← 唯一与公共网络连接  │
│  │ ┌───────────┐ │                       │
│  │ │ 天线系统   │ │                       │
│  │ │ 基带处理   │ │                       │
│  │ │ 运行管理   │ │                       │
│  │ │ 数据处理   │ │                       │
│  │ └───────────┘ │                       │
│  └───────┬───────┘                       │
└──────────┼──────────────────────────────┘
           │
┌──────────┼──────────────────────────────┐
│          │     用户段 (User Segment)     │
│    ┌─────┴─────┐                          │
│    │  用户终端   │  卫星电话/电视/数据      │
│    └───────────┘                          │
└──────────────────────────────────────────┘
```

### 1.2 地面站类型

| 类型 | 功能 | 安全等级 | 典型设施 |
|------|------|---------|---------|
| TT&C站 | 遥测、跟踪、指令 | 最高 | 测控中心 |
| 关口站 | 网络控制、关口管理 | 高 | 通信卫星地面站 |
| 测控站 | 卫星测轨、姿态控制 | 最高 | 深空测控网 |
| 数据接收站 | 遥感数据接收 | 中高 | 遥感卫星数据站 |
| 用户站 | 终端用户通信 | 中 | VSAT终端 |
| 监测站 | 频谱监测、信号质量 | 中 | 频谱监测站 |

### 1.3 地面站安全的重要性

```
地面站安全为什么至关重要:

1. 唯一地面接口
   - 所有卫星指令通过地面站发送
   - 控制地面站 = 控制卫星
   - 影响整个卫星星座

2. 高价值目标
   - 设备价值: 数千万至数十亿
   - 数据价值: 军事/气象/通信数据
   - 战略价值: 国家基础设施

3. 攻击面广泛
   - 网络接口: 与公共网络连接
   - 射频接口: 开放的天空
   - 物理接口: 地面设施可达
   - 供应链: 设备来自多个供应商

4. 历史教训
   - 1999年: 银行黑客控制卫星
   - 2007年: 解放军激光致盲卫星
   - 2018年: 海事卫星被干扰
   - 2022年: GPS欺骗攻击频发
```
