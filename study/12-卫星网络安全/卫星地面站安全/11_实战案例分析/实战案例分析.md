# 实战案例分析

### 11.1 Viasat KA-SAT攻击事件(2022)

```
事件背景:
- 时间: 2022年2月24日(俄乌冲突开始时)
- 目标: Viasat KA-SAT卫星网络
- 影响: 数千个乌克兰终端离线
- 攻击者: 美国/欧盟attributed to Russia

攻击链分析:
1. 攻击者入侵Viasat地面站网络
2. 通过VPN获取地面站管理网络访问权
3. 利用管理协议向终端下发恶意指令
4. 指令覆盖了终端的闪存(擦除固件)
5. 数千个终端永久变砖

技术分析:
- 攻击目标: KA-SAT终端的Tftpd32服务
- 利用的协议: SNMP/管理协议
- 破坏指令:擦除终端闪存
- 影响范围: UA地区约数千终端

经验教训:
1. 地面站网络安全是关键
2. 管理通道必须加密认证
3. 终端需要防擦除保护
4. 需要固件恢复机制
5. 供应链安全(管理权限)重要
```

### 11.2 GPS欺骗攻击

```
GPS欺骗攻击案例:

攻击方式:
1. 攻击者发射伪造GPS信号
2. 信号比真实GPS信号更强
3. 接收机锁定到伪造信号
4. 报告错误的位置/时间

影响:
- 船舶偏航: 多艘船只报告错误位置
- 无人机失控: 无人机被诱骗至指定区域
- 通信中断: 卫星天线指向错误方向
- 时间同步: 网络时间错误导致故障

防护:
1. 信号强度监测
2. 多星座接收(GPS+Galileo+BeiDou)
3. 天线抗欺骗设计
4. 交叉验证(INS/惯导)
5. 异常位置检测
```
