# 载荷安全分类与防护

### 3.1 通信载荷安全

```
通信载荷安全:

通信卫星载荷组成:
┌─────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────┐           │
│  │ 接收天线  │  │ 发射天线  │           │
│  └─────┬────┘  └────▲─────┘           │
│        │            │                   │
│  ┌─────┴────┐  ┌───┴──────┐           │
│  │ 接收机   │  │ 发射机    │           │
│  │ (RX)    │  │ (TX)     │           │
│  └─────┬────┘  └───▲──────┘           │
│        │           │                    │
│  ┌─────┴───────────┴──────┐            │
│  │    信号处理/路由/交换    │            │
│  │  ┌──────────────────┐  │            │
│  │  │ 转发器/通道化器  │  │            │
│  │  └──────────────────┘  │            │
│  └────────────────────────┘            │
└─────────────────────────────────────────┘

安全威胁:
1. 转发器劫持: 攻击者通过上行信道劫持转发器
2. 信号劫持: 转发器被重配置转发恶意信号
3. 功率操控: 调整发射功率影响覆盖区
4. 波束操控: 改变波束指向覆盖非授权区域
5. 信道干扰: 通过载荷信道互相干扰

防护措施:
• 上行链路加密认证
• 转发器配置锁定
• 波束指向授权
• 功率限制
• 频谱监测
```

### 3.2 遥感载荷安全

```
遥感载荷安全:

遥感卫星载荷:
├── 光学相机 (高分辨率成像)
├── 红外传感器 (热成像)
├── 合成孔径雷达 (SAR)
├── 高光谱成像仪
├── 多光谱扫描仪
└── 数据传输系统(DTX)

安全威胁:
1. 图像数据截获: 下行数据被截获
2. 成像指令篡改: 拍摄非授权目标
3. 数据注入: 注入伪造遥感数据
4. 相机参数篡改: 调整参数降低图像质量
5. 数据传输劫持: 数据被转发到非授权地面站

防护措施:
• 遥感数据加密下行
• 成像目标授权列表
• 数据签名认证
• 传输频率跳变
• 图像水印
```

### 3.3 导航载荷安全

```
导航载荷安全(GNSS):

导航卫星载荷:
├── 原子钟 (铷/铯/氢)
├── 导航信号生成器
├── L频段发射天线
├── 星间链路(ISL)
└── 激光反射器

安全威胁:
1. 原子钟操控: 时钟频率被篡改
2. 导航信号欺骗: 发射伪造导航信号
3. 星间链路劫持: 星座通信被篡改
4. 电文篡改: 导航电文被修改

防护措施:
• 原子钟状态监控
• 导航信号加密(PNT服务)
• 星间链路认证加密
• 电文完整性校验
• 地面监控站交叉验证
```
