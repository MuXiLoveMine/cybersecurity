### 7.2 密钥管理生命周期

```
星载密钥管理生命周期:

1. 密钥生成 (地面)
   ┌─────────────────────────────────┐
   │  • 在安全设施(HSM)中生成          │
   │  • 使用真随机数                   │
   │  • 生成主密钥、会话密钥、指令密钥 │
   │  • 双人控制 (2-of-3 Shamir共享)  │
   └─────────────────────────────────┘

2. 密钥注入 (发射前)
   ┌─────────────────────────────────┐
   │  • 在洁净间通过专用接口注入       │
   │  • 注入过程双人监控               │
   │  • 注入后接口物理断开             │
   │  • 密钥注入验证                   │
   └─────────────────────────────────┘

3. 密钥在轨使用
   ┌─────────────────────────────────┐
   │  • 加解密操作在安全模块内进行     │
   │  • 密钥永不出安全模块             │
   │  • 密钥使用计数与审计             │
   │  • 异常时密钥自动销毁             │
   └─────────────────────────────────┘

4. 密钥更新 (在轨)
   ┌─────────────────────────────────┐
   │  • 通过加密上行指令更新密钥        │
   │  • 使用旧密钥加密新密钥            │
   │  • 更新后验证新密钥有效性          │
   │  • 旧密钥安全擦除                 │
   └─────────────────────────────────┘

5. 密钥销毁 (退役)
   ┌─────────────────────────────────┐
   │  • 退役指令触发密钥销毁           │
   │  • 多次覆写+物理破坏              │
   │  • 防止退役卫星被逆向分析          │
   └─────────────────────────────────┘
```
