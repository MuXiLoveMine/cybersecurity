# 卫星抗辐射与容错安全

### 9.1 辐射对安全的影响

```
空间辐射对安全的影响:

1. 单粒子翻转(SEU)
   - 高能粒子导致存储位翻转
   - 0变1或1变0
   - 可能导致程序逻辑错误
   - 可能导致安全控制绕过

2. 单粒子锁定(SEL)
   - 高能粒子导致CMOS锁定
   - 大电流可能烧毁芯片
   - 需要断电恢复

3. 总剂量效应(TID)
   - 长期辐射累积
   - 晶体管性能退化
   - 阈值电压漂移
   - 最终器件失效

4. 单粒子功能中断(SEFI)
   - 复杂器件(如FPGA)功能紊乱
   - 需要重新配置或复位

安全影响:
- SEU可能翻转安全标志位
- SEU可能导致密钥泄露
- SEU可能导致权限提升
- TID可能导致安全功能失效
```
