# 卫星平台子系统安全

### 2.1 电源系统安全

```
电源系统安全:

卫星电源系统:
├── 太阳能帆板 (主电源)
├── 蓄电池组 (储能)
├── 电源控制与分配 (PCDU)
└── 配电网络

安全威胁:
1. 充放电控制被篡改 → 电池损坏/爆炸
2. 配电被关闭 → 卫星断电
3. 帆板指向被篡改 → 发电不足
4. 过压/过流 → 设备损坏

防护措施:
• 电源指令需要高级别授权
• 硬件限压/限流保护
• 冗余电源路径
• 电池管理系统独立运行
• 电源状态实时遥测
```

### 2.2 姿态控制系统(ADCS)安全

```python
# 姿态控制系统安全分析
class ADCSSecurity:
    """姿态控制(ADCS)安全"""

    # ADCS关键组件
    COMPONENTS = {
        'star_tracker': '星敏感器 - 姿态测量',
        'sun_sensor': '太阳敏感器 - 太阳方位',
        'magnetometer': '磁强计 - 地磁场测量',
        'gyroscope': '陀螺仪 - 角速度测量',
        'reaction_wheel': '反作用飞轮 - 姿态执行',
        'magnetorquer': '磁力矩器 - 磁力卸载',
        'thruster': '推进器 - 轨道/姿态控制',
    }

    # 安全威胁
    THREATS = {
        'sensor_spoofing': {
            'description': '传感器数据欺骗',
            'impact': '卫星姿态误判 → 错误控制',
            'severity': 'CRITICAL',
            'mitigations': [
                '传感器数据交叉验证',
                '异常值检测与过滤',
                '多传感器冗余',
                '数据签名验证',
            ],
        },
        'command_injection': {
            'description': '姿态控制指令注入',
            'impact': '卫星姿态被恶意控制',
            'severity': 'CRITICAL',
            'mitigations': [
                '指令加密签名',
                '双因子授权',
                '安全范围限制',
                '异常指令告警',
            ],
        },
        'wheel_over-speed': {
            'description': '反作用飞轮超速',
            'impact': '飞轮损坏 → 失去姿态控制',
            'severity': 'HIGH',
            'mitigations': [
                '硬件超速保护',
                '软件速度限制',
                '自动卸载逻辑',
            ],
        },
        'thruster_misfire': {
            'description': '推进器误点火',
            'impact': '燃料泄漏 → 卫星失效',
            'severity': 'CRITICAL',
            'mitigations': [
                '推进指令多重验证',
                '安全使能信号',
                '点火时间限制',
                '燃料量监控',
            ],
        },
    }

    def validate_attitude_command(self, command: dict) -> bool:
        """验证姿态控制指令"""
        # 1. 检查指令签名
        if not self._verify_signature(command):
            return False

        # 2. 检查指令在安全范围内
        target_quaternion = command.get('target_quaternion')
        if not self._is_safe_quaternion(target_quaternion):
            return False

        # 3. 检查角速度限制
        max_rate = command.get('max_angular_rate', 0)
        if max_rate > self.MAX_SAFE_RATE:
            return False

        # 4. 检查执行时间窗口
        if not self._is_in_safe_window(command):
            return False

        return True
```

### 2.3 热控系统安全

```
热控系统安全:

卫星热控系统功能:
- 维持各组件在温度范围内
- 散热(电子设备发热)
- 保温(阴影面防寒)

安全威胁:
1. 加热器异常 → 设备过热损坏
2. 散热器方向错误 → 温度失控
3. 温度传感器欺骗 → 错误热控决策
4. 热控指令被篡改 → 温度异常

防护措施:
• 温度阈值硬件保护
• 多点温度冗余测量
• 异常温升告警
• 热控指令授权
• 紧急断电机制
```

### 2.4 推进系统安全

```
推进系统安全(最高安全等级):

卫星推进系统:
├── 化学推进 (肼/电推进)
├── 电推进 (霍尔/离子推进器)
├── 推进剂储罐
├── 阀门/管路
└── 推力器

安全威胁等级: CRITICAL
- 推进剂泄漏 → 卫星失效
- 误点火 → 轨道偏离
- 阀门故障 → 推进剂耗尽
- 推力异常 → 姿态失控

安全要求:
1. 推进指令需要最高级别授权(3级)
2. 多重安全使能信号(物理+软件)
3. 推进剂储量实时监控
4. 推进时间限制(防止燃料耗尽)
5. 推进后轨道验证
6. 紧急切断阀
7. 推进前姿态确认
```
