# 卫星平台与载荷概述

### 1.1 卫星系统组成

卫星由两大主要部分构成：平台（Platform/Bus）和载荷（Payload）。平台提供卫星运行的基础保障功能，载荷执行卫星的核心任务：

### 1.2 安全挑战的独特性

| 特征 | 地面系统 | 卫星系统 |
|------|---------|---------|
| 物理可达性 | 可现场维修 | 不可维修（在轨） |
| 计算资源 | 充足 | 严重受限 |
| 通信带宽 | 高带宽 | 极低带宽 |
| 更新方式 | 随时更新 | 有限机会窗口 |
| 运行寿命 | 3-10年 | 10-15年+ |
| 环境条件 | 温控机房 | 辐射/温差/振动 |
| 攻击面 | 网络/物理 | 网络/射频/物理/辐射 |
| 安全更新 | 频繁 | 极少(风险大) |
| 容错要求 | 中等 | 极高(无法维修) |
