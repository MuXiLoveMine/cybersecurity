# 星载计算机安全

### 4.1 星载计算机架构

```
星载计算机(OBC)架构:

┌─────────────────────────────────────────┐
│           星载计算机(OBC)              │
├─────────────────────────────────────────┤
│  ┌──────────┐    ┌──────────┐         │
│  │ CPU      │    │ 冗余CPU  │         │
│  │ (RAD750  │    │ (备份)   │         │
│  │  /LEON3) │    │          │         │
│  └────┬─────┘    └────┬─────┘         │
│       │               │                │
│  ┌────┴───────────────┴─────┐         │
│  │      内存(EDAC保护)        │         │
│  │  SRAM + Flash + EEPROM    │         │
│  └─────────────┬─────────────┘         │
│                │                        │
│  ┌─────────────┴─────────────┐         │
│  │       总线接口              │         │
│  │  ┌────┐ ┌────┐ ┌────┐     │         │
│  │  │CAN │ │1553│ │Space│    │         │
│  │  │    │ │B   │ │Wire│    │         │
│  │  └────┘ └────┘ └────┘     │         │
│  └───────────────────────────┘         │
│  ┌───────────────────────────┐         │
│  │       I/O接口              │         │
│  │  GPIO/UART/SPI/I2C        │         │
│  └───────────────────────────┘         │
│  ┌───────────────────────────┐         │
│  │       看门狗定时器          │         │
│  └───────────────────────────┘         │
└─────────────────────────────────────────┘

关键安全特性:
1. 抗辐射CPU (RAD750, LEON3, AT697)
2. EDAC内存纠错
3. 看门狗定时器(硬件复位)
4. 冗余备份
5. 安全启动
6. 总线隔离
```

### 4.2 星载计算机安全要求

```python
# 星载计算机安全配置
class OnboardComputerSecurity:
    """星载计算机安全配置"""

    SECURITY_CONFIG = {
        'boot_chain': {
            'rom_verify': True,        # Boot ROM验证
            'bootloader_sign': True,    # 引导加载器签名
            'kernel_sign': True,        # 内核签名
            'application_sign': True,   # 应用签名
            'anti_rollback': True,     # 防回滚
        },
        'memory_protection': {
            'edac': 'Hamming/Reed-Solomon',  # 纠错码
            'mpu': True,               # 内存保护单元
            'stack_guard': True,       # 栈保护
            'code_flash_lock': True,   # 代码Flash锁定
        },
        'communication': {
            'uplink_crypto': 'AES-256-GCM',
            'downlink_crypto': 'AES-256-CBC',
            'command_auth': 'ECDSA-P256',
            'anti_replay': '序列号窗口',
        },
        'fault_tolerance': {
            'triple_redundancy': True,  # 三模冗余
            'majority_voting': True,    # 多数表决
            'watchdog': True,            # 看门狗
            'cold_spare': True,         # 冷备份
        },
        'access_control': {
            'command_levels': 5,
            'dual_auth': True,          # 双人授权
            'session_timeout': 300,     # 5分钟超时
            'max_retries': 3,           # 最大重试
        },
    }
```
