# 案例分析

### 11.1 Galaxy 15失控事件

```
案例: Galaxy 15卫星失控(2010)

事件背景:
- 卫星: AMC/Galaxy 15 (Orbital Sciences建造)
- 时间: 2010年4月
- 问题: 卫星停止响应指令但继续发射信号

故障分析:
1. 太阳活动引起的SEU
2. 星载计算机处理器寄存器翻转
3. 指令处理模块异常
4. 卫星停止响应但转发器仍在工作

安全影响:
- 卫星漂移可能干扰其他卫星
- 无法通过指令关闭转发器
- 整个轨道位置面临风险

恢复过程:
1. 地面持续尝试通信
2. 利用太阳食(卫星进入阴影)导致重启
3. 电池耗尽后卫星复位
4. 恢复后重新建立控制

教训:
1. SEU可能导致安全功能失效
2. 需要硬件看门狗强制复位
3. 需要故障安全模式(断电复位)
4. 星载软件需要异常自恢复能力
```

### 11.2 美国GPS地面控制系统入侵

```
案例: GPS地面控制系统安全(2008年)

事件背景:
- 检测到GPS地面控制系统的异常活动
- 涉及GPS指令系统的网络入侵

安全分析:
1. 攻击者尝试通过地面网络访问GPS控制段
2. 目标是修改GPS卫星的导航电文
3. 如果成功, 可影响全球GPS服务

防护措施:
1. 地面系统网络隔离
2. 指令系统多重认证
3. 导航电文完整性校验
4. 地面监控站交叉验证

教训:
1. 地面控制段是卫星安全的薄弱环节
2. 需要严格的网络分段
3. 卫星指令需要端到端安全
4. 持续安全监控至关重要
```
