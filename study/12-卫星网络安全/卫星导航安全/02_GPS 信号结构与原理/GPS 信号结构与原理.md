# GPS 信号结构与原理

### 2.1 导航定位基本原理

#### 2.1.1 三边测量法

GPS 定位基于三边测量原理：通过测量到至少 4 颗卫星的距离（伪距），计算出接收机的三维位置（x, y, z）和时间偏差（b）。

**数学模型：**
```
对于第 i 颗卫星：
√[(xi - x)² + (yi - y)² + (zi - z)²] + c*b = ρi
```
其中：
- (xi, yi, zi)：第 i 颗卫星的位置（已知，来自星历）
- (x, y, z)：接收机位置（未知）
- b：接收机时钟与 GPS 时间的偏差（未知）
- ρi：伪距测量值（已知）
- c：光速

**未知数：** x, y, z, b（共 4 个）
**需要卫星数：** 至少 4 颗

```
        卫星1        卫星2        卫星3        卫星4
           ○           ○           ○           ○
            \         /           /           /
             \       /           /           /
              \     /           /           /
               \   /           /           /
                \ /           /           /
                 ○ 接收机位置（4个球面交点）
                / \
               /   \
              /     \
```

#### 2.1.2 伪距测量原理

伪距 = 真实距离 + 时钟偏差引起的距离误差 + 其他误差

**测量方法：**
1. 卫星在已知时刻发射测距码（C/A 码或 P 码）
2. 接收机内部复制相同的测距码
3. 接收机调整复制码的相位，直到与接收到的信号相关峰值最大
4. 相位差对应的时间差乘以光速，得到伪距

### 2.2 GPS 信号结构

#### 2.2.1 GPS L1 信号组成

GPS L1 载波频率为 1575.42 MHz，其上调制了多种信号：

```
L1 载波 (1575.42 MHz)
├── C/A 码信号
│   ├── C/A 码（1.023 MHz，Gold 码）
│   └── 导航电文（50 bps）
├── P(Y) 码信号
│   ├── P 码（10.23 MHz，加密后为 Y 码）
│   └── 导航电文（50 bps）
└── M 码信号（军用，分 M_E 和 M_P）
```

#### 2.2.2 C/A 码（粗捕获码）

**基本参数：**
- 码率：1.023 MHz
- 码长：1023 个码片（chip）
- 周期：1 ms（1023 / 1.023e6 = 1 ms）
- 调制方式：BPSK
- 每颗卫星使用不同的 Gold 码（PRN 编号 1-32）

**特点：**
- 公开的，所有人都可以使用
- 码长短，容易捕获
- 抗干扰能力相对较弱
- 精度较低（约 10 米级）

#### 2.2.3 P(Y) 码（精密码）

**基本参数：**
- 码率：10.23 MHz
- 码长：极长（约 38 星期）
- 调制方式：BPSK
- 加密：P 码加密后变为 Y 码

**特点：**
- 军用，需要密钥才能使用
- 码率高，抗干扰能力强（比 C/A 码高约 10 dB）
- 码长长，难以捕获和欺骗
- 精度高（约 1 米级）

#### 2.2.4 导航电文

导航电文（Navigation Message）是调制在测距码上的数据，包含：

| 内容 | 说明 |
|-----|------|
| 星历数据（Ephemeris） | 卫星精确轨道参数，用于计算卫星位置 |
| 历书数据（Almanac） | 所有卫星粗略轨道，用于快速捕获 |
| 时钟校正参数 | 卫星时钟偏差校正 |
| 电离层校正参数 | 电离层延迟校正模型 |
| 卫星健康状态 | 卫星是否正常工作 |
| 时间信息 | GPS 时间、UTC 偏移 |

**电文结构：**
- 速率：50 bps
- 主帧：30 秒（25 页，每页 30 秒）
- 子帧：每帧 5 个子帧，每个子帧 6 秒（300 bit）
- 字：每个子帧 10 个字，每个字 30 bit（含 6 bit 校验）

**安全意义：**
- 星历数据是定位的基础，如果被篡改，定位结果就会错误
- 民用 GPS 导航电文没有认证，容易被伪造
- 欺骗攻击需要伪造导航电文

### 2.3 GPS 接收机工作流程

```
天线接收 → 射频前端 → 下变频 → A/D 转换 → 数字信号处理
                                                   │
                    ┌──────────────────────────────┘
                    ▼
            ┌───────────────┐
            │  信号捕获      │  搜索可见卫星，粗略同步
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  信号跟踪      │  精确跟踪载波和码相位
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  解调导航电文  │  获取星历、时间等数据
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  伪距测量      │  测量到各卫星的伪距
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  定位解算      │  计算位置、速度、时间
            └───────────────┘
```
