# GPS 欺骗攻击（Spoofing）

### 3.1 欺骗攻击概述

#### 3.1.1 什么是欺骗攻击

GPS 欺骗攻击（GPS Spoofing）是指攻击者发射伪造的 GPS 信号，使接收机计算出错误的位置和时间。

**与干扰攻击的区别：**

| 对比项 | 干扰攻击（Jamming） | 欺骗攻击（Spoofing） |
|-------|-------------------|---------------------|
| 目的 | 使接收机无法工作 | 使接收机得到错误结果 |
| 原理 | 大功率信号淹没 | 伪造信号误导 |
| 功率需求 | 高（需超过信号） | 低（与真实信号相当） |
| 可检测性 | 容易（信号明显异常） | 困难（信号看起来正常） |
| 技术难度 | 低 | 高 |
| 危害程度 | 高（功能失效） | 极高（被误导可能更危险） |

**一个经典比喻：**
- 干扰 = 让你听不见
- 欺骗 = 让你听错了（而且你还以为是对的）

#### 3.1.2 欺骗攻击的危害

| 领域 | 危害 |
|-----|------|
| 航空 | 飞机偏航、误入禁飞区、降落错误 |
| 航海 | 船舶偏航、触礁、驶入危险区域 |
| 金融 | 时间同步错误，导致交易异常 |
| 电力 | 电网同步异常，可能导致停电 |
| 通信 | 基站同步异常，通信中断 |
| 军事 | 武器制导错误、部队迷失方向 |
| 无人机 | 无人机被劫持、失控 |
| 自动驾驶 | 车辆定位错误，导致事故 |

### 3.2 欺骗攻击分类

#### 3.2.1 生成式欺骗（Generative Spoofing）

**原理：**
攻击者完全生成虚假的 GPS 信号，包括伪造的测距码和导航电文。

**特点：**
- 可以完全控制接收机的位置和时间
- 需要生成多颗卫星的假信号
- 技术难度高
- 需要精确了解 GPS 信号结构

**所需条件：**
- 真实的 GPS 星历数据（可以从公开渠道获取）
- 信号生成设备（SDR + 放大器 + 天线）
- 精确的时间同步
- 目标位置信息

#### 3.2.2 转发式欺骗（Replay/Forward Spoofing）

**原理：**
攻击者接收真实的 GPS 信号，经过延迟/放大/调整后转发给目标接收机。

**特点：**
- 技术难度相对较低
- 信号结构与真实信号完全一致
- 欺骗效果是让接收机"以为"自己在别的位置
- 延迟时间决定了伪距偏移量

**实现方式：**
1. 在一个位置接收 GPS 信号
2. 将信号放大（可能加上延迟）
3. 发射到目标区域
4. 目标接收机被误导到信号接收点的位置

#### 3.2.3 中间式欺骗（Meaconing / Interference Spoofing）

**原理：**
结合干扰和欺骗，先用干扰压制真实信号，再发射欺骗信号。

**攻击步骤：**
1. 发射大功率干扰信号，使目标接收机失锁
2. 降低干扰功率，同时发射欺骗信号
3. 目标接收机重新捕获到欺骗信号
4. 接收机被欺骗

**特点：**
- 成功率高（先打断再植入）
- 容易被检测到（有干扰过程）
- 是最常见的实用欺骗方式

### 3.3 欺骗攻击原理详解

#### 3.3.1 欺骗攻击的基本条件

要成功实施 GPS 欺骗攻击，需要满足以下条件：

1. **功率条件**：欺骗信号功率略高于真实信号（通常高 1-5 dB）
2. **同步条件**：欺骗信号的码相位和载波频率与真实信号接近
3. **数据条件**：欺骗信号包含合理的导航电文（星历等）
4. **一致性条件**：多颗假卫星信号之间相互一致（伪距要能解算出合理位置）

#### 3.3.2 欺骗攻击过程（以中间式欺骗为例）

```
阶段 1：干扰压制
    干扰功率 ████████████
    信号功率 ██░░░░░░░░░░
    结果：接收机失锁

阶段 2：欺骗信号注入
    干扰功率 ████░░░░░░░░
    欺骗信号 ██████░░░░░░
    信号功率 ██░░░░░░░░░░
    结果：接收机开始捕获欺骗信号

阶段 3：欺骗成功
    干扰功率 ░░░░░░░░░░░░
    欺骗信号 ██████░░░░░░
    信号功率 ██░░░░░░░░░░
    结果：接收机跟踪欺骗信号，计算出错误位置
```

#### 3.3.3 位置欺骗的数学原理

设接收机真实位置为 (x₀, y₀, z₀)，攻击者想让接收机认为自己在位置 (x', y', z')。

**真实伪距：**
```
ρi⁰ = √[(xi - x₀)² + (yi - y₀)² + (zi - z₀)²] + c*b
```

**欺骗伪距需要满足：**
```
ρi' = √[(xi - x')² + (yi - y')² + (zi - z')²] + c*b'
```

攻击者需要调整每颗卫星的欺骗信号延迟，使伪距等于 ρi'。

**关键：** 所有卫星的伪距偏移必须一致，能够解算出同一个 (x', y', z', b')。

### 3.4 欺骗攻击的实施

#### 3.4.1 硬件需求

**入门级（实验/演示）：**
- HackRF One / BladeRF 等 SDR 设备
- GPS 天线
- 放大器（可选）
- 电脑

**专业级：**
- 高性能 SDR（USRP 等）
- 多通道同步（多颗卫星同时生成）
- 高功率放大器
- 高增益定向天线
- 原子钟（高精度时间同步）

#### 3.4.2 软件工具

**GPS 信号生成：**
- gps-sdr-sim（开源 GPS 信号生成器）
- GNSS-SDR（软件定义 GNSS 接收机，也可以生成信号）
- MATLAB/Simulink 自定义

**使用 gps-sdr-sim 生成 GPS 欺骗信号的基本步骤：**
1. 下载广播星历数据（从 IGS 等网站）
2. 指定目标位置和时间
3. 运行 gps-sdr-sim 生成 IQ 数据文件
4. 使用 SDR 发射生成的信号

#### 3.4.3 攻击位置选择

- 靠近目标接收机（路径损耗小，所需功率低）
- 避开真实 GPS 信号的方向（减少真实信号干扰）
- 开阔地带（信号传播好）

### 3.5 针对不同目标的欺骗攻击

#### 3.5.1 无人机 GPS 欺骗

**攻击场景：**
- 劫持无人机到指定位置
- 使无人机坠落（伪造过低的高度）
- 使无人机偏航

**案例（公开报道）：**
- 2011 年伊朗"俘获"美国 RQ-170 无人机（据称使用 GPS 欺骗）
- 多次报道的无人机被 GPS 欺骗劫持事件
- 反无人机系统中有使用 GPS 欺骗技术的

**技术要点：**
- 无人机 GPS 天线通常朝下（接收地面方向信号）
- 从地面发射欺骗信号更容易成功
- 无人机自动驾驶对 GPS 依赖度高

#### 3.5.2 船舶 GPS 欺骗

**攻击场景：**
- 使船舶偏航
- 使船舶进入特定区域
- 掩盖船舶真实位置

**案例（公开报道）：**
- 黑海地区多次 GPS 欺骗事件
- 港口附近船舶 GPS 位置异常

#### 3.5.3 时间欺骗

除了位置欺骗，GPS 欺骗还可以进行时间欺骗：

**危害：**
- 金融交易时间戳错误
- 电力系统同步异常
- 通信基站同步故障
- 加密认证失效（依赖时间的认证协议）

**案例：**
- 2019 年 GPS 时间异常事件（非攻击，是系统故障，但说明了 GPS 时间的重要性）
- 各种利用 GPS 进行时间同步的系统都面临时间欺骗风险
