# 卫星通信安全

> 卫星通信安全是卫星网络安全的核心内容之一。由于卫星通信的广播特性和长距离传输特点，通信链路面临窃听、干扰、欺骗等多种安全威胁。本章系统介绍卫星通信安全的关键技术和防护方法。

---

## 一、信号干扰

### 1.1 干扰攻击概述

信号干扰（Jamming）是最常见的卫星通信攻击方式，通过发射无线信号干扰正常通信。

#### 1.1.1 干扰原理

**基本原理：**
干扰机在目标信号的工作频率上发射一定功率的干扰信号，使接收机输入端的干扰功率超过信号功率或达到足以影响正常解调的程度，从而导致通信质量下降或完全中断。

**干信比（J/S, Jam-to-Signal Ratio）：**
```
J/S (dB) = Pj + Gj - (Ps + Gs) - Lp 差
```
- Pj: 干扰机发射功率
- Gj: 干扰天线增益（在接收天线方向）
- Ps: 信号发射功率
- Gs: 信号天线增益
- Lp 差: 路径损耗差异

**干扰效果与 J/S 的关系：**
| 干信比（dB） | 干扰效果 |
|-------------|---------|
| 0-5 dB | 轻微误码，通信质量下降 |
| 5-10 dB | 明显误码，部分业务中断 |
| 10-20 dB | 严重干扰，通信困难 |
| >20 dB | 完全压制，通信中断 |

#### 1.1.2 干扰分类

**按干扰带宽分类：**

| 类型 | 特点 | 适用场景 |
|-----|------|---------|
| 宽带噪声干扰 | 干扰带宽大于信号带宽 | 压制多个信道 |
| 窄带干扰/单频干扰 | 干扰带宽小于等于信号带宽 | 针对特定信道 |
| 部分频带干扰 | 在部分频段上施加干扰 | 对付跳频系统 |
| 脉冲干扰 | 周期性脉冲信号 | 对付某些调制方式 |

**按干扰信号形式分类：**

| 类型 | 说明 | 技术难度 |
|-----|------|---------|
| 噪声干扰 | 类似白噪声的干扰信号 | 低 |
| 单频干扰 | 单一频率的正弦波 | 很低 |
| 调制干扰 | 带有调制的干扰信号 | 中 |
| 转发式干扰 | 接收并转发对方信号 | 中-高 |
| 灵巧干扰 | 针对特定协议/调制的干扰 | 高 |

**按干扰目标分类：**
- 上行干扰：干扰地面站到卫星的链路
- 下行干扰：干扰卫星到地面的链路
- 星间干扰：干扰卫星之间的链路

### 1.2 典型干扰技术

#### 1.2.1 压制式干扰

**定义：** 通过大功率信号直接淹没目标信号，使接收机无法检测到有用信号。

**特点：**
- 原理简单，容易实现
- 需要较大的干扰功率
- 干扰效果明显
- 容易被检测和定位

**实现方式：**
1. 宽带噪声干扰：发射宽带噪声信号
2. 多音干扰：多个单频信号组合
3. 扫频干扰：在目标频段内快速扫频

**案例：GPS 压制式干扰器**
- 小型 GPS 干扰器（俗称 GPS 屏蔽器）价格仅几百元
- 功率从几瓦到几十瓦不等
- 干扰范围从几十米到几公里
- 广泛（非法）用于车辆防跟踪、考场防作弊等
- 对民航、海事等公共安全构成严重威胁

#### 1.2.2 欺骗式干扰

**定义：** 发射与目标信号特征相似的假信号，使接收机接收到错误信息。

**与压制式干扰的区别：**
- 压制式：让你"听不到"（信噪比不够）
- 欺骗式：让你"听错了"（接收错误信息）

**特点：**
- 需要的功率较小（与真实信号相当即可）
- 隐蔽性强，难以察觉
- 技术难度高，需要了解信号结构
- 危害更大（误导比不可用更危险）

**详见本章"调制解调安全"和"卫星导航安全"章节。**

#### 1.2.3 灵巧干扰（Smart Jamming）

**定义：** 针对特定通信协议或调制方式设计的干扰，以最小的干扰功率达到最大的干扰效果。

**典型方式：**
- 针对帧同步字的干扰
- 针对控制信道的干扰
- 针对 ACK 报文的干扰
- 协议级别的干扰

**优势：**
- 干扰效率高
- 功率需求小
- 隐蔽性更好
- 针对性强

### 1.3 干扰攻击的实施

#### 1.3.1 干扰机组成

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  信号源/振荡器 │───►│  功率放大器   │───►│  发射天线    │
└─────────────┘    └─────────────┘    └─────────────┘
       ▲
       │
┌──────┴──────┐
│  控制单元    │  (频率、功率、调制方式控制)
└─────────────┘
```

**关键参数：**
- 工作频率范围
- 输出功率
- 天线增益
- 调制方式
- 供电方式

#### 1.3.2 干扰位置选择

**上行干扰：**
- 位置：靠近目标卫星地面站（或在其附近）
- 难度：较高，需要知道地面站位置
- 功率：相对较小（路径损耗小）

**下行干扰：**
- 位置：在目标接收区域附近
- 难度：较低，只需在覆盖范围内
- 功率：取决于目标接收机的位置

### 1.4 干扰检测与定位

#### 1.4.1 干扰检测方法

| 方法 | 原理 | 特点 |
|-----|------|------|
| 功率检测 | 监测接收功率是否异常升高 | 简单，但误报率高 |
| 信噪比检测 | 监测 SNR 是否下降 | 较准确 |
| 误码率检测 | 监测 BER 是否异常 | 直接反映通信质量 |
| 频谱分析 | 分析频谱特征 | 可以识别干扰类型 |
| 信号特征比对 | 比对预期信号特征 | 可以检测欺骗 |

#### 1.4.2 干扰源定位

**常用方法：**
- 到达方向（DOA）估计
- 到达时间差（TDOA）定位
- 到达频率差（FDOA）定位
- 功率测量定位

**法律与法规：**
- 故意干扰卫星通信是违法行为
- 各国无线电管理部门有干扰查处职责
- 国际电信联盟（ITU）有相关规定

## 二、窃听与信号截获

### 2.1 卫星通信窃听原理

#### 2.1.1 广播特性与窃听

卫星通信的下行链路具有天然的广播特性——卫星发射的信号覆盖一个很大的区域，区域内任何人都可以接收到信号。

```
                    ★ 卫星
                   / │ \
                  /  │  \
                 /   │   \
                /    │    \
               ▼     ▼     ▼
           合法用户  窃听者  合法用户
```

**窃听的可行性因素：**
- 信号覆盖范围：GEO 卫星覆盖几大洲，LEO 覆盖区域相对小
- 信号强度：信号越强越容易接收
- 频率：低频段更容易接收
- 加密：加密信号即使被截获也难以解密

#### 2.1.2 窃听的类型

| 类型 | 目标 | 技术难度 | 法律风险 |
|-----|------|---------|---------|
| 信号检测 | 检测信号是否存在 | 低 | 低（被动接收） |
| 信号分析 | 分析信号参数（频率、调制等） | 中 | 低 |
| 数据截获 | 截获原始数据/比特流 | 中-高 | 中 |
| 解密破译 | 破解加密获取明文 | 高 | 高 |
| 通信分析 | 分析通信模式、流量特征 | 中 | 低-中 |

### 2.2 信号截获技术

#### 2.2.1 接收设备

**基本设备组成：**
- 接收天线（高增益定向天线）
- 低噪声放大器（LNA）
- 下变频器
- 解调器
- 数据记录设备

**常用设备：**
| 设备 | 用途 | 价格范围 |
|-----|------|---------|
| 卫星电视接收天线 | 接收 Ku/C 波段卫星信号 | 几百-几千元 |
| SDR 设备（HackRF/USRP） | 通用信号接收与分析 | 几百-几万元 |
| 专业卫星接收机 | 特定制式卫星信号接收 | 几万-几十万元 |
| 大型抛物面天线 | 深空/低信噪比信号接收 | 几十万元以上 |

#### 2.2.2 信号参数获取

需要获取的信号参数：
- 载波频率
- 符号率/比特率
- 调制方式（BPSK、QPSK、8PSK、QAM 等）
- 编码方式（卷积码、Turbo 码、LDPC 等）
- 帧结构
- 加扰方式

**获取方法：**
- 公开资料查询
- 信号频谱分析
- 调制识别算法
- 盲解调技术

### 2.3 加密信号的破译威胁

#### 2.3.1 常见加密强度评估

| 加密算法 | 密钥长度 | 破译难度 | 备注 |
|---------|---------|---------|------|
| DES | 56 bit | 低 | 已被破解，不推荐使用 |
| 3DES | 112/168 bit | 中 | 安全性下降 |
| AES-128 | 128 bit | 极高 | 当前主流 |
| AES-256 | 256 bit | 极高 | 高安全需求 |
| 国密 SM4 | 128 bit | 极高 | 中国商用密码 |

#### 2.3.2 实际破译案例（公开报道）

**卫星电视加密系统破解：**
- 多种卫星电视 CAS 系统被破解
- 破解方式：智能卡攻击、漏洞利用、CW 共享
- 经济利益驱动，形成黑色产业链
- 运营商通过定期更换加密系统应对

**弱加密系统的风险：**
- 老旧卫星系统可能使用弱加密算法
- 部分系统使用自定义加密算法，安全性未经充分验证
- 密钥管理不当可能导致密钥泄露

### 2.4 通信流量分析

即使通信内容被加密，攻击者仍然可以通过流量分析获取有价值的情报：

**可获取的信息：**
- 通信双方的位置和身份
- 通信时间和频率
- 通信数据量
- 通信模式（定期/突发）
- 网络拓扑结构

**军事意义：**
- 通过卫星通信流量分析部队部署和调动
- 识别指挥节点
- 推断行动计划

## 三、调制解调安全

### 3.1 常用调制方式

卫星通信中常用的调制方式及其安全特性：

| 调制方式 | 频谱效率 | 抗干扰能力 | 典型应用 |
|---------|---------|-----------|---------|
| BPSK | 1 bit/s/Hz | 强 | 测控、低速率通信 |
| QPSK | 2 bit/s/Hz | 较强 | 通信、广播 |
| 8PSK | 3 bit/s/Hz | 中 | 高速通信 |
| 16QAM | 4 bit/s/Hz | 较弱 | 高速数据 |
| 32APSK | ~5 bit/s/Hz | 中 | DVB-S2 |
| OQPSK | 2 bit/s/Hz | 较强 | 部分测控 |

### 3.2 调制识别

调制识别是信号分析和干扰/欺骗攻击的前提。

#### 3.2.1 识别方法

**基于特征的方法：**
- 瞬时特征：瞬时幅度、瞬时相位、瞬时频率
- 统计特征：高阶累积量、谱特征
- 变换域特征：小波变换、时频分析

**基于深度学习的方法：**
- CNN（卷积神经网络）
- 循环神经网络
- 迁移学习

#### 3.2.2 常用识别步骤

```
信号接收 → 预处理 → 特征提取 → 分类识别 → 结果输出
```

**常见工具和库：**
- MATLAB Communications Toolbox
- Python + scikit-learn / TensorFlow
- GNU Radio + 自定义模块

### 3.3 调制层安全威胁

#### 3.3.1 调制参数欺骗

通过伪造调制参数误导接收方：
- 伪造调制方式
- 伪造符号率
- 伪造编码参数

#### 3.3.2 部分符号干扰

选择性地干扰某些符号：
- 干扰帧头/同步字
- 干扰控制信息
- 干扰关键数据

#### 3.3.3 调制域隐蔽通信

利用调制参数传递隐蔽信息（隐写术）：
- 最低有效位调制
- 相位调制中的隐蔽信道
- 利用信号特征的细微变化

### 3.4 安全调制技术

#### 3.4.1 混沌调制

利用混沌信号的特性实现安全通信：
- 混沌键控（CSK）
- 差分混沌键控（DCSK）
- 混沌扩频

**安全优势：**
- 信号类似噪声，难以检测
- 不掌握混沌参数难以解调
- 天然的抗截获特性

#### 3.4.2 自适应调制

动态改变调制参数增加攻击难度：
- 跳调制（Modulation Hopping）
- 自适应编码调制（ACM）
- 调制参数随机化

## 四、加密与密钥管理

### 4.1 卫星通信加密体系

#### 4.1.1 加密分层

```
┌─────────────────────────────────────────────┐
│              应用层加密                       │
│  端到端加密、业务数据加密、文件加密             │
├─────────────────────────────────────────────┤
│              链路层加密                       │
│  帧加密、链路加密、TC/TM 安全协议             │
├─────────────────────────────────────────────┤
│              物理层加密                       │
│  扩频、跳频、混沌通信、信号加扰                │
└─────────────────────────────────────────────┘
```

#### 4.1.2 主要加密协议和标准

**CCSDS 安全协议：**
- SCPS-SP（Space Communications Protocol Specification - Security Protocol）
- 提供数据机密性、完整性、认证服务
- 支持多种加密算法

**卫星通信加密标准：**
- 军用加密标准（各国不同）
- 商用卫星通信加密方案
- DVB-CSA（通用加扰算法）

### 4.2 链路加密

#### 4.2.1 上行链路加密

**加密对象：**
- 遥控指令（TC, Telecommand）
- 上传数据
- 软件更新

**安全要求：**
- 机密性：防止指令内容泄露
- 完整性：防止指令被篡改
- 认证：确认指令来源合法
- 抗重放：防止旧指令被重放

**实现机制：**
- 指令加密（对称加密算法）
- 消息认证码（MAC）
- 序列号和时间戳
- 数字签名（高安全等级）

#### 4.2.2 下行链路加密

**加密对象：**
- 遥测数据（TM, Telemetry）
- 载荷数据
- 遥感图像

**安全要求：**
- 机密性：防止数据被窃听
- 完整性：防止数据被篡改
- 可选认证：数据源认证

#### 4.2.3 星间链路加密

**特殊挑战：**
- 卫星数量多，密钥管理复杂
- 链路动态建立，需要快速密钥协商
- 星上计算资源有限
- 卫星可能被俘获或被控制

**技术方案：**
- 预共享密钥（静态配置，简单但不灵活）
- 密钥分发中心（需要可信第三方）
- 公钥基础设施（PKI，计算量大）
- 量子密钥分发（QKD，前沿方向）

### 4.3 密钥管理

#### 4.3.1 密钥管理生命周期

```
密钥生成 → 密钥分发 → 密钥存储 → 密钥使用 → 密钥更新 → 密钥销毁
```

#### 4.3.2 密钥分发方式

| 方式 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| 地面预装 | 安全可靠 | 不灵活，无法更新 | 初始密钥 |
| 地面站加密上注 | 可以更新 | 依赖上行链路安全 | 常规更新 |
| 星间密钥协商 | 灵活 | 协议复杂 | 星间链路 |
| 物理手段配送 | 安全性高 | 周期长、成本高 | 高安全需求 |

#### 4.3.3 密钥层级结构

典型的卫星系统密钥采用分层管理：

```
                    根密钥 (Root Key)
                        │
                    密钥加密密钥 (KEK)
                   /       │        \
              链路密钥    业务密钥    认证密钥
             /    \      /    \
          上行密钥 下行密钥 ...
```

**各级密钥说明：**
- **根密钥**：最高级密钥，用于保护下层密钥
- **密钥加密密钥（KEK）**：用于加密传输业务密钥
- **链路密钥**：用于加密通信链路数据
- **业务密钥**：用于加密具体业务数据
- **会话密钥**：单次通信使用的临时密钥

### 4.4 典型加密算法在卫星通信中的应用

#### 4.4.1 对称加密算法

| 算法 | 密钥长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| AES | 128/192/256 bit | 数据加密 | 当前主流 |
| SM4 | 128 bit | 数据加密 | 国密算法 |
| 3DES | 112/168 bit | 旧系统 | 逐步淘汰 |

#### 4.4.2 非对称加密算法

| 算法 | 密钥长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| RSA | 2048/4096 bit | 密钥分发、签名 | 计算量大 |
| ECC | 256 bit+ | 密钥协商、签名 | 效率高，适合星上 |
| SM2 | 256 bit | 密钥协商、签名 | 国密算法 |

#### 4.4.3 哈希算法

| 算法 | 输出长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| SHA-256 | 256 bit | 完整性校验 | 当前主流 |
| SHA-3 | 可变 | 完整性校验 | 新一代 |
| SM3 | 256 bit | 完整性校验 | 国密算法 |

## 五、卫星链路加密

### 5.1 CCSDS 安全协议详解

#### 5.1.1 SCPS-SP 协议

SCPS-SP（Space Communications Protocol Specification - Security Protocol）是 CCSDS 制定的空间通信安全协议。

**提供的安全服务：**
- 连接机密性
- 无连接机密性
- 连接完整性（带恢复）
- 无连接完整性
- 数据源认证
- 抗重放保护
- 访问控制

**协议格式：**
```
┌──────────────┬──────────────┬────────────────┬──────────┐
│  SP 头部      │  用户数据     │  填充（可选）    │  ICV     │

└──────────────┴──────────────┴────────────────┴──────────┘
```

#### 5.1.2 TC 安全操作

遥控指令（TC）的安全操作包括：

| 安全操作 | 说明 | 位置 |
|---------|------|------|

| 加密 | 保护指令内容机密性 | 数据域加密 |
| 序列号 | 防止重放攻击 | 帧头中增加序号 |
| 时间戳 | 防止重放 | 指令数据中包含时间 |

**TC 安全帧结构：**
```
┌──────────┬──────────┬──────────────────────┬──────────┐
│  帧头     │  安全头   │  加密的指令数据域      │  认证域   │
└──────────┴──────────┴──────────────────────┴──────────┘
```

### 6.2 扩频通信

#### 6.2.1 直接序列扩频（DSSS）

**原理：**
用一个速率远高于信息速率的伪随机码（PN 码）对载波进行调制，使信号带宽远大于信息带宽。

**扩频增益：**
```
Gp (dB) = 10 * log10(扩频后带宽 / 扩频前带宽)
```

**抗干扰原理：**
- 解扩处理后，有用信号被恢复为窄带
- 干扰信号被扩频处理，功率谱密度降低
- 通过窄带滤波滤除大部分干扰功率

**典型应用：**
- GPS 信号（C/A 码、P 码）
- 军事卫星通信
- CDMA 通信

#### 6.2.2 跳频扩频（FHSS）

**原理：**
载波频率按照预定的跳频图案在较宽的频带内跳变。

**抗干扰原理：**
- 干扰机难以同时干扰所有跳频点
- 跳频速率越快，抗干扰能力越强
- 配合纠错编码可以更好地抗部分频带干扰

**分类：**
- 慢跳频：每跳传输多个符号
- 快跳频：每个符号多次跳频

#### 6.2.3 扩频与卫星安全

**GPS 扩频信号的安全意义：**
- GPS C/A 码是公开的，扩频只提供一定的抗干扰能力
- GPS P(Y) 码是加密的，提供更高的抗干扰和认证能力
- 扩频信号可以隐藏在噪声底以下，降低被检测的概率

### 6.3 自适应调零天线

#### 6.3.1 原理

利用阵列天线和自适应算法，在干扰信号方向形成零点（方向图零点），从而抑制干扰信号。

**核心算法：**
- LMS（最小均方）算法
- RLS（递归最小二乘）算法
- SMI（采样矩阵求逆）算法
- 功率反演算法

#### 6.3.2 性能指标

- 调零深度：干扰方向的增益衰减程度（通常 20-40 dB）
- 调零数目：同时抑制的干扰源数量
- 收敛速度：适应干扰变化的速度
- 阵列增益：对有用信号的增益

### 6.4 其他抗干扰技术

#### 6.4.1 波束成形

通过阵列天线将发射/接收波束集中在特定方向，提高目标方向的信号增益，降低其他方向的干扰。

**应用场景：**
- 多波束卫星天线
- 相控阵用户终端
- 卫星互联网相控阵天线

#### 6.4.2 前向纠错编码（FEC）

通过增加冗余信息，使接收端能够纠正一定数量的误码，从而在信噪比较低（存在干扰）的情况下仍能正常通信。

**常用编码：**
- 卷积码
- Turbo 码
- LDPC 码
- Polar 码

**编码增益：**
通常可以获得几 dB 到十几 dB 的编码增益，等效于提高了抗干扰能力。

#### 6.4.3 干扰检测与规避

检测到干扰后，主动采取措施规避干扰：
- 频率切换（换频）
- 功率调整（提高发射功率）
- 调制方式调整（降低阶数）
- 路由切换（换一条链路/卫星）

### 7.4 SDR 在卫星信号分析中的应用

## 八、实际案例分析

### 8.1 案例一：卫星电视信号盗收

**背景：**
卫星电视广播使用条件接收系统（CAS）对节目进行加扰，用户需要合法的智能卡才能收看。但盗版产业链一直存在。

**技术手段：**
1. **智能卡破解**
   - 通过物理手段或侧信道攻击破解智能卡
   - 复制合法智能卡
   - 写入盗版卡

2. **CW 共享（Card Sharing）**
   - 一张正版卡通过网络共享控制字（CW）
   - 多个用户通过网络获取 CW 解扰
   - 形成大规模盗版网络

3. **插件破解**
   - 利用接收机软件漏洞
   - 安装第三方插件直接解扰

**运营商应对：**
- 定期更换加密系统
- 反制 CW 共享（动态 CW、增加认证）
- 法律手段打击盗版
- 推行正版化优惠

### 8.2 案例二：军事卫星通信抗干扰实战

**背景：**
在现代军事冲突中，卫星通信是指挥控制的重要手段，也是电子战的重点目标。

**典型抗干扰措施：**
1. **扩频通信**：军用卫星通信普遍使用扩频技术
2. **多频段工作**：同时使用多个频段，干扰一个换另一个
3. **波束成形**：定向天线，降低被干扰概率
4. **跳频**：快速跳频躲避干扰
5. **自适应功率控制**：根据干扰情况调整功率

**实战案例（公开报道）：**
- 海湾战争中，美军卫星通信经受了电子战考验
- 近年冲突中，各方都有使用卫星通信干扰的报道

### 8.3 案例三：遥感卫星数据安全

**背景：**
高分辨率遥感卫星图像具有重要的军事和经济价值，需要保护数据安全。

**安全措施：**
1. **下行数据加密**：卫星下行的图像数据经过加密
2. **地面站访问控制**：严格控制数据接收和处理权限
3. **数据分级管理**：按分辨率和敏感度分级
4. **分发授权管理**：用户需授权才能获取特定数据

**安全事件：**
- 有报道称某些国家通过接收其他国家遥感卫星下行信号获取情报
- 商用遥感卫星数据的扩散引发安全担忧

## 九、本章小结

1. **信号干扰**：从压制式到欺骗式，从窄带到宽带，干扰攻击是最常见的卫星通信威胁
2. **窃听威胁**：卫星广播特性使得窃听天然可行，加密是主要防护手段
3. **调制解调安全**：调制识别是攻击的前提，安全调制技术可以增加攻击难度
4. **加密与密钥管理**：多层加密体系是卫星通信安全的基础，密钥管理是关键挑战
5. **链路加密**：上行、下行、星间链路各有不同的加密需求和方案
6. **抗干扰技术**：扩频、跳频、调零天线、FEC 等多层抗干扰措施
7. **信号分析与侦察**：SDR 和数字信号处理技术降低了信号分析的门槛
