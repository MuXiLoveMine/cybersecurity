# 卫星链路加密

### 5.1 CCSDS 安全协议详解

#### 5.1.1 SCPS-SP 协议

SCPS-SP（Space Communications Protocol Specification - Security Protocol）是 CCSDS 制定的空间通信安全协议。

**提供的安全服务：**
- 连接机密性
- 无连接机密性
- 连接完整性（带恢复）
- 无连接完整性
- 数据源认证
- 抗重放保护
- 访问控制

**协议格式：**
```
┌──────────────┬──────────────┬────────────────┬──────────┐
│  SP 头部      │  用户数据     │  填充（可选）    │  ICV     │
│ (Security    │  (加密/认证)  │                │ (完整性  │
│  Parameters) │              │                │  校验值) │
└──────────────┴──────────────┴────────────────┴──────────┘
```

#### 5.1.2 TC 安全操作

遥控指令（TC）的安全操作包括：

| 安全操作 | 说明 | 位置 |
|---------|------|------|
| 认证 | 验证指令来源和完整性 | 帧尾增加认证域 |
| 加密 | 保护指令内容机密性 | 数据域加密 |
| 序列号 | 防止重放攻击 | 帧头中增加序号 |
| 时间戳 | 防止重放 | 指令数据中包含时间 |

**TC 安全帧结构：**
```
┌──────────┬──────────┬──────────────────────┬──────────┐
│  帧头     │  安全头   │  加密的指令数据域      │  认证域   │
└──────────┴──────────┴──────────────────────┴──────────┘
```

### 5.2 卫星互联网链路加密

#### 5.2.1 加密架构

卫星互联网的加密通常采用多层加密策略：

```
用户数据 ──► 用户层加密（TLS/IPsec） ──► 接入层加密 ──► 星间链路加密
```

#### 5.2.2 关键加密点

**用户终端到卫星：**
- 接入认证
- 数据加密
- 类似蜂窝网络的加密机制

**星间链路：**
- 高速加密
- 快速密钥协商
- 前向保密

**卫星到地面关口站：**
- 回程链路加密
- 高带宽加密

### 5.3 量子密钥分发（QKD）在卫星通信中的应用

#### 5.3.1 量子密钥分发原理

利用量子力学的基本原理（量子不可克隆定理、测不准原理）实现安全的密钥分发。

**优势：**
- 理论上绝对安全
- 可以检测窃听
- 应对量子计算威胁

#### 5.3.2 卫星 QKD 进展

**墨子号量子科学实验卫星（中国）：**
- 2016 年发射
- 实现了星地量子密钥分发
- 实现了千公里级量子纠缠分发
- 验证了卫星量子通信的可行性

**未来展望：**
- 量子通信星座
- 全球量子保密通信网络
- 与经典通信融合
