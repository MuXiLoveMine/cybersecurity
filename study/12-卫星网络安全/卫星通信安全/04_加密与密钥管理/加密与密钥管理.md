# 加密与密钥管理

### 4.1 卫星通信加密体系

#### 4.1.1 加密分层

```
┌─────────────────────────────────────────────┐
│              应用层加密                       │
│  端到端加密、业务数据加密、文件加密             │
├─────────────────────────────────────────────┤
│              链路层加密                       │
│  帧加密、链路加密、TC/TM 安全协议             │
├─────────────────────────────────────────────┤
│              物理层加密                       │
│  扩频、跳频、混沌通信、信号加扰                │
└─────────────────────────────────────────────┘
```

#### 4.1.2 主要加密协议和标准

**CCSDS 安全协议：**
- SCPS-SP（Space Communications Protocol Specification - Security Protocol）
- 提供数据机密性、完整性、认证服务
- 支持多种加密算法

**卫星通信加密标准：**
- 军用加密标准（各国不同）
- 商用卫星通信加密方案
- DVB-CSA（通用加扰算法）

### 4.2 链路加密

#### 4.2.1 上行链路加密

**加密对象：**
- 遥控指令（TC, Telecommand）
- 上传数据
- 软件更新

**安全要求：**
- 机密性：防止指令内容泄露
- 完整性：防止指令被篡改
- 认证：确认指令来源合法
- 抗重放：防止旧指令被重放

**实现机制：**
- 指令加密（对称加密算法）
- 消息认证码（MAC）
- 序列号和时间戳
- 数字签名（高安全等级）

#### 4.2.2 下行链路加密

**加密对象：**
- 遥测数据（TM, Telemetry）
- 载荷数据
- 遥感图像

**安全要求：**
- 机密性：防止数据被窃听
- 完整性：防止数据被篡改
- 可选认证：数据源认证

#### 4.2.3 星间链路加密

**特殊挑战：**
- 卫星数量多，密钥管理复杂
- 链路动态建立，需要快速密钥协商
- 星上计算资源有限
- 卫星可能被俘获或被控制

**技术方案：**
- 预共享密钥（静态配置，简单但不灵活）
- 密钥分发中心（需要可信第三方）
- 公钥基础设施（PKI，计算量大）
- 量子密钥分发（QKD，前沿方向）

### 4.3 密钥管理

#### 4.3.1 密钥管理生命周期

```
密钥生成 → 密钥分发 → 密钥存储 → 密钥使用 → 密钥更新 → 密钥销毁
```

#### 4.3.2 密钥分发方式

| 方式 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| 地面预装 | 安全可靠 | 不灵活，无法更新 | 初始密钥 |
| 地面站加密上注 | 可以更新 | 依赖上行链路安全 | 常规更新 |
| 星间密钥协商 | 灵活 | 协议复杂 | 星间链路 |
| 物理手段配送 | 安全性高 | 周期长、成本高 | 高安全需求 |

#### 4.3.3 密钥层级结构

典型的卫星系统密钥采用分层管理：

```
                    根密钥 (Root Key)
                        │
                    密钥加密密钥 (KEK)
                   /       │        \
              链路密钥    业务密钥    认证密钥
             /    \      /    \
          上行密钥 下行密钥 ...
```

**各级密钥说明：**
- **根密钥**：最高级密钥，用于保护下层密钥
- **密钥加密密钥（KEK）**：用于加密传输业务密钥
- **链路密钥**：用于加密通信链路数据
- **业务密钥**：用于加密具体业务数据
- **会话密钥**：单次通信使用的临时密钥

### 4.4 典型加密算法在卫星通信中的应用

#### 4.4.1 对称加密算法

| 算法 | 密钥长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| AES | 128/192/256 bit | 数据加密 | 当前主流 |
| SM4 | 128 bit | 数据加密 | 国密算法 |
| 3DES | 112/168 bit | 旧系统 | 逐步淘汰 |

#### 4.4.2 非对称加密算法

| 算法 | 密钥长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| RSA | 2048/4096 bit | 密钥分发、签名 | 计算量大 |
| ECC | 256 bit+ | 密钥协商、签名 | 效率高，适合星上 |
| SM2 | 256 bit | 密钥协商、签名 | 国密算法 |

#### 4.4.3 哈希算法

| 算法 | 输出长度 | 典型用途 | 备注 |
|-----|---------|---------|------|
| SHA-256 | 256 bit | 完整性校验 | 当前主流 |
| SHA-3 | 可变 | 完整性校验 | 新一代 |
| SM3 | 256 bit | 完整性校验 | 国密算法 |
