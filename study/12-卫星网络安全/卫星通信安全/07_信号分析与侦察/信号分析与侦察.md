# 信号分析与侦察

### 7.1 卫星信号侦察概述

信号侦察是指通过接收和分析卫星信号，获取信号参数、通信内容、系统特征等情报信息的技术。

#### 7.1.1 侦察目的

| 目的 | 说明 |
|-----|------|
| 信号检测 | 发现和识别卫星信号的存在 |
| 参数测量 | 测量信号的频率、带宽、功率等参数 |
| 调制识别 | 识别信号的调制方式和编码方式 |
| 信息截获 | 解调解码获取通信内容 |
| 系统分析 | 分析卫星系统的工作模式和能力 |
| 目标定位 | 定位辐射源位置 |

#### 7.1.2 侦察系统组成

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 接收天线 │──►│ 接收机  │──►│ 数字采集│──►│ 信号处理│──►│ 分析显示│
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
```

### 7.2 常用信号分析方法

#### 7.2.1 频谱分析

**工具：** 频谱分析仪、FFT 分析

**分析内容：**
- 载波频率
- 信号带宽
- 功率谱密度
- 邻道功率
- 信号类型初步判断

#### 7.2.2 时域分析

**分析内容：**
- 信号包络
- 脉冲特性
- 突发特性
- 时隙结构

#### 7.2.3 调制分析

**分析方法：**
- 星座图分析
- 眼图分析
- 调制特征提取
- 调制模式识别

#### 7.2.4 协议分析

在解调和解码后，对数据链路层和网络层协议进行分析：
- 帧结构分析
- 协议类型识别
- 地址信息提取
- 控制信息分析

### 7.3 电子对抗中的信号分析

#### 7.3.1 电子支援（ES）

电子支援措施（ESM）是电子战的重要组成部分，包括：
- 威胁信号搜索
- 信号识别
- 参数测量
- 辐射源定位

#### 7.3.2 信号分析在安全防护中的应用

**防御性应用：**
- 干扰检测与识别
- 异常信号监测
- 频谱态势感知
- 威胁预警

**进攻性应用：**
- 干扰参数优化
- 欺骗信号生成
- 协议漏洞利用

### 7.4 SDR 在卫星信号分析中的应用

#### 7.4.1 SDR 简介

软件定义无线电（Software Defined Radio, SDR）是用软件实现无线电通信功能的技术。

**优势：**
- 灵活：通过软件升级支持新的调制方式和协议
- 可重配置：同一硬件可以做不同用途
- 低成本：相比专用设备
- 适合研究和实验

#### 7.4.2 常用 SDR 设备

| 设备 | 频率范围 | 采样率 | 价格 | 备注 |
|-----|---------|--------|------|------|
| RTL-SDR | 24-1766 MHz | 最高 3.2 MS/s | ~200 元 | 入门级，仅接收 |
| HackRF One | 1 MHz - 6 GHz | 最高 20 MS/s | ~2000 元 | 半双工收发 |
| BladeRF 2.0 | 47 MHz - 6 GHz | 最高 61.44 MS/s | ~3000 元 | 全双工 |
| USRP B210 | 70 MHz - 6 GHz | 最高 56 MS/s | ~15000 元 | 专业级 |
| LimeSDR | 100 kHz - 3.8 GHz | 最高 61.44 MS/s | ~2000 元 | 开源 |

#### 7.4.3 GNU Radio

GNU Radio 是最流行的 SDR 软件开发框架：
- 提供丰富的信号处理模块
- 图形化开发环境（GRC）
- 支持 Python 和 C++
- 大量开源项目可用

**卫星相关应用：**
- 卫星信号接收与解调
- 卫星遥测解码
- 业余卫星通信
- GPS 信号生成与接收（研究用）
