# 信号干扰

### 1.1 干扰攻击概述

信号干扰（Jamming）是最常见的卫星通信攻击方式，通过发射无线信号干扰正常通信。

#### 1.1.1 干扰原理

**基本原理：**
干扰机在目标信号的工作频率上发射一定功率的干扰信号，使接收机输入端的干扰功率超过信号功率或达到足以影响正常解调的程度，从而导致通信质量下降或完全中断。

**干信比（J/S, Jam-to-Signal Ratio）：**
```
J/S (dB) = Pj + Gj - (Ps + Gs) - Lp 差
```
- Pj: 干扰机发射功率
- Gj: 干扰天线增益（在接收天线方向）
- Ps: 信号发射功率
- Gs: 信号天线增益
- Lp 差: 路径损耗差异

**干扰效果与 J/S 的关系：**
| 干信比（dB） | 干扰效果 |
|-------------|---------|
| 0-5 dB | 轻微误码，通信质量下降 |
| 5-10 dB | 明显误码，部分业务中断 |
| 10-20 dB | 严重干扰，通信困难 |
| >20 dB | 完全压制，通信中断 |

#### 1.1.2 干扰分类

**按干扰带宽分类：**

| 类型 | 特点 | 适用场景 |
|-----|------|---------|
| 宽带噪声干扰 | 干扰带宽大于信号带宽 | 压制多个信道 |
| 窄带干扰/单频干扰 | 干扰带宽小于等于信号带宽 | 针对特定信道 |
| 部分频带干扰 | 在部分频段上施加干扰 | 对付跳频系统 |
| 脉冲干扰 | 周期性脉冲信号 | 对付某些调制方式 |

**按干扰信号形式分类：**

| 类型 | 说明 | 技术难度 |
|-----|------|---------|
| 噪声干扰 | 类似白噪声的干扰信号 | 低 |
| 单频干扰 | 单一频率的正弦波 | 很低 |
| 调制干扰 | 带有调制的干扰信号 | 中 |
| 转发式干扰 | 接收并转发对方信号 | 中-高 |
| 灵巧干扰 | 针对特定协议/调制的干扰 | 高 |

**按干扰目标分类：**
- 上行干扰：干扰地面站到卫星的链路
- 下行干扰：干扰卫星到地面的链路
- 星间干扰：干扰卫星之间的链路

### 1.2 典型干扰技术

#### 1.2.1 压制式干扰

**定义：** 通过大功率信号直接淹没目标信号，使接收机无法检测到有用信号。

**特点：**
- 原理简单，容易实现
- 需要较大的干扰功率
- 干扰效果明显
- 容易被检测和定位

**实现方式：**
1. 宽带噪声干扰：发射宽带噪声信号
2. 多音干扰：多个单频信号组合
3. 扫频干扰：在目标频段内快速扫频

**案例：GPS 压制式干扰器**
- 小型 GPS 干扰器（俗称 GPS 屏蔽器）价格仅几百元
- 功率从几瓦到几十瓦不等
- 干扰范围从几十米到几公里
- 广泛（非法）用于车辆防跟踪、考场防作弊等
- 对民航、海事等公共安全构成严重威胁

#### 1.2.2 欺骗式干扰

**定义：** 发射与目标信号特征相似的假信号，使接收机接收到错误信息。

**与压制式干扰的区别：**
- 压制式：让你"听不到"（信噪比不够）
- 欺骗式：让你"听错了"（接收错误信息）

**特点：**
- 需要的功率较小（与真实信号相当即可）
- 隐蔽性强，难以察觉
- 技术难度高，需要了解信号结构
- 危害更大（误导比不可用更危险）

**详见本章"调制解调安全"和"卫星导航安全"章节。**

#### 1.2.3 灵巧干扰（Smart Jamming）

**定义：** 针对特定通信协议或调制方式设计的干扰，以最小的干扰功率达到最大的干扰效果。

**典型方式：**
- 针对帧同步字的干扰
- 针对控制信道的干扰
- 针对 ACK 报文的干扰
- 协议级别的干扰

**优势：**
- 干扰效率高
- 功率需求小
- 隐蔽性更好
- 针对性强

### 1.3 干扰攻击的实施

#### 1.3.1 干扰机组成

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  信号源/振荡器 │───►│  功率放大器   │───►│  发射天线    │
└─────────────┘    └─────────────┘    └─────────────┘
       ▲
       │
┌──────┴──────┐
│  控制单元    │  (频率、功率、调制方式控制)
└─────────────┘
```

**关键参数：**
- 工作频率范围
- 输出功率
- 天线增益
- 调制方式
- 供电方式

#### 1.3.2 干扰位置选择

**上行干扰：**
- 位置：靠近目标卫星地面站（或在其附近）
- 难度：较高，需要知道地面站位置
- 功率：相对较小（路径损耗小）

**下行干扰：**
- 位置：在目标接收区域附近
- 难度：较低，只需在覆盖范围内
- 功率：取决于目标接收机的位置

### 1.4 干扰检测与定位

#### 1.4.1 干扰检测方法

| 方法 | 原理 | 特点 |
|-----|------|------|
| 功率检测 | 监测接收功率是否异常升高 | 简单，但误报率高 |
| 信噪比检测 | 监测 SNR 是否下降 | 较准确 |
| 误码率检测 | 监测 BER 是否异常 | 直接反映通信质量 |
| 频谱分析 | 分析频谱特征 | 可以识别干扰类型 |
| 信号特征比对 | 比对预期信号特征 | 可以检测欺骗 |

#### 1.4.2 干扰源定位

**常用方法：**
- 到达方向（DOA）估计
- 到达时间差（TDOA）定位
- 到达频率差（FDOA）定位
- 功率测量定位

**法律与法规：**
- 故意干扰卫星通信是违法行为
- 各国无线电管理部门有干扰查处职责
- 国际电信联盟（ITU）有相关规定
