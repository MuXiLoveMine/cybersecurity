# 窃听与信号截获

### 2.1 卫星通信窃听原理

#### 2.1.1 广播特性与窃听

卫星通信的下行链路具有天然的广播特性——卫星发射的信号覆盖一个很大的区域，区域内任何人都可以接收到信号。

```
                    ★ 卫星
                   / │ \
                  /  │  \
                 /   │   \
                /    │    \
               ▼     ▼     ▼
           合法用户  窃听者  合法用户
```

**窃听的可行性因素：**
- 信号覆盖范围：GEO 卫星覆盖几大洲，LEO 覆盖区域相对小
- 信号强度：信号越强越容易接收
- 频率：低频段更容易接收
- 加密：加密信号即使被截获也难以解密

#### 2.1.2 窃听的类型

| 类型 | 目标 | 技术难度 | 法律风险 |
|-----|------|---------|---------|
| 信号检测 | 检测信号是否存在 | 低 | 低（被动接收） |
| 信号分析 | 分析信号参数（频率、调制等） | 中 | 低 |
| 数据截获 | 截获原始数据/比特流 | 中-高 | 中 |
| 解密破译 | 破解加密获取明文 | 高 | 高 |
| 通信分析 | 分析通信模式、流量特征 | 中 | 低-中 |

### 2.2 信号截获技术

#### 2.2.1 接收设备

**基本设备组成：**
- 接收天线（高增益定向天线）
- 低噪声放大器（LNA）
- 下变频器
- 解调器
- 数据记录设备

**常用设备：**
| 设备 | 用途 | 价格范围 |
|-----|------|---------|
| 卫星电视接收天线 | 接收 Ku/C 波段卫星信号 | 几百-几千元 |
| SDR 设备（HackRF/USRP） | 通用信号接收与分析 | 几百-几万元 |
| 专业卫星接收机 | 特定制式卫星信号接收 | 几万-几十万元 |
| 大型抛物面天线 | 深空/低信噪比信号接收 | 几十万元以上 |

#### 2.2.2 信号参数获取

需要获取的信号参数：
- 载波频率
- 符号率/比特率
- 调制方式（BPSK、QPSK、8PSK、QAM 等）
- 编码方式（卷积码、Turbo 码、LDPC 等）
- 帧结构
- 加扰方式

**获取方法：**
- 公开资料查询
- 信号频谱分析
- 调制识别算法
- 盲解调技术

### 2.3 加密信号的破译威胁

#### 2.3.1 常见加密强度评估

| 加密算法 | 密钥长度 | 破译难度 | 备注 |
|---------|---------|---------|------|
| DES | 56 bit | 低 | 已被破解，不推荐使用 |
| 3DES | 112/168 bit | 中 | 安全性下降 |
| AES-128 | 128 bit | 极高 | 当前主流 |
| AES-256 | 256 bit | 极高 | 高安全需求 |
| 国密 SM4 | 128 bit | 极高 | 中国商用密码 |

#### 2.3.2 实际破译案例（公开报道）

**卫星电视加密系统破解：**
- 多种卫星电视 CAS 系统被破解
- 破解方式：智能卡攻击、漏洞利用、CW 共享
- 经济利益驱动，形成黑色产业链
- 运营商通过定期更换加密系统应对

**弱加密系统的风险：**
- 老旧卫星系统可能使用弱加密算法
- 部分系统使用自定义加密算法，安全性未经充分验证
- 密钥管理不当可能导致密钥泄露

### 2.4 通信流量分析

即使通信内容被加密，攻击者仍然可以通过流量分析获取有价值的情报：

**可获取的信息：**
- 通信双方的位置和身份
- 通信时间和频率
- 通信数据量
- 通信模式（定期/突发）
- 网络拓扑结构

**军事意义：**
- 通过卫星通信流量分析部队部署和调动
- 识别指挥节点
- 推断行动计划
