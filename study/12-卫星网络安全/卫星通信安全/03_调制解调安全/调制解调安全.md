# 调制解调安全

### 3.1 常用调制方式

卫星通信中常用的调制方式及其安全特性：

| 调制方式 | 频谱效率 | 抗干扰能力 | 典型应用 |
|---------|---------|-----------|---------|
| BPSK | 1 bit/s/Hz | 强 | 测控、低速率通信 |
| QPSK | 2 bit/s/Hz | 较强 | 通信、广播 |
| 8PSK | 3 bit/s/Hz | 中 | 高速通信 |
| 16QAM | 4 bit/s/Hz | 较弱 | 高速数据 |
| 32APSK | ~5 bit/s/Hz | 中 | DVB-S2 |
| OQPSK | 2 bit/s/Hz | 较强 | 部分测控 |

### 3.2 调制识别

调制识别是信号分析和干扰/欺骗攻击的前提。

#### 3.2.1 识别方法

**基于特征的方法：**
- 瞬时特征：瞬时幅度、瞬时相位、瞬时频率
- 统计特征：高阶累积量、谱特征
- 变换域特征：小波变换、时频分析

**基于深度学习的方法：**
- CNN（卷积神经网络）
- 循环神经网络
- 迁移学习

#### 3.2.2 常用识别步骤

```
信号接收 → 预处理 → 特征提取 → 分类识别 → 结果输出
```

**常见工具和库：**
- MATLAB Communications Toolbox
- Python + scikit-learn / TensorFlow
- GNU Radio + 自定义模块

### 3.3 调制层安全威胁

#### 3.3.1 调制参数欺骗

通过伪造调制参数误导接收方：
- 伪造调制方式
- 伪造符号率
- 伪造编码参数

#### 3.3.2 部分符号干扰

选择性地干扰某些符号：
- 干扰帧头/同步字
- 干扰控制信息
- 干扰关键数据

#### 3.3.3 调制域隐蔽通信

利用调制参数传递隐蔽信息（隐写术）：
- 最低有效位调制
- 相位调制中的隐蔽信道
- 利用信号特征的细微变化

### 3.4 安全调制技术

#### 3.4.1 混沌调制

利用混沌信号的特性实现安全通信：
- 混沌键控（CSK）
- 差分混沌键控（DCSK）
- 混沌扩频

**安全优势：**
- 信号类似噪声，难以检测
- 不掌握混沌参数难以解调
- 天然的抗截获特性

#### 3.4.2 自适应调制

动态改变调制参数增加攻击难度：
- 跳调制（Modulation Hopping）
- 自适应编码调制（ACM）
- 调制参数随机化
