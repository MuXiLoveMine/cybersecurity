# 卫星通信概述

### 1.1 卫星轨道类型

卫星按照轨道高度可以分为以下几大类，不同轨道类型决定了卫星的应用场景和安全特性。

#### 1.1.1 GEO（地球静止轨道）

**基本参数：**
- 轨道高度：约 35,786 公里
- 轨道周期：约 23 小时 56 分 4 秒（与地球自转同步）
- 轨道倾角：0°（赤道上空）
- 覆盖范围：单颗卫星约覆盖地球表面 42%

**特点：**
- 相对地面静止，地面天线无需跟踪
- 覆盖范围广，三颗卫星可实现全球覆盖（除两极）
- 传播延迟大：单向约 250-280ms
- 路径损耗大，需要较大的发射功率
- 轨道资源有限，国际电信联盟（ITU）统一分配

**安全考量：**
- 轨道位置固定，容易被定位和瞄准
- 单颗卫星价值高，一旦受损影响大
- 信号覆盖范围广，容易被窃听
- 反卫星武器的重点目标

**典型应用：**
- 通信卫星（如中国卫通、Intelsat）
- 气象卫星（如风云二号、GOES）
- 广播卫星（电视直播）
- 军事通信卫星

#### 1.1.2 MEO（中地球轨道）

**基本参数：**
- 轨道高度：约 2,000 - 35,786 公里
- 轨道周期：约 2 - 24 小时
- 典型高度：导航卫星约 20,000 公里左右

**特点：**
- 覆盖范围适中，需要多颗卫星组成星座
- 延迟较低（相对于 GEO）
- 轨道周期适中，卫星相对地面移动

**安全考量：**
- 星座分布广，单颗受损影响相对有限
- 信号到达地面功率低，容易受到干扰
- 导航信号公开透明，存在欺骗风险

**典型应用：**
- GPS（美国）：约 20,180 公里，6 轨道面，24+ 颗卫星
- 北斗 MEO 卫星：约 21,500 公里
- GLONASS（俄罗斯）：约 19,130 公里
- Galileo（欧盟）：约 23,222 公里

#### 1.1.3 LEO（低地球轨道）

**基本参数：**
- 轨道高度：约 160 - 2,000 公里
- 轨道周期：约 90 - 120 分钟
- 速度：约 7.8 km/s

**特点：**
- 延迟低：单向约 20-50ms
- 路径损耗小
- 单颗覆盖范围小，需要大规模星座
- 卫星高速运动，需要频繁切换
- 发射成本相对较低

**安全考量：**
- 星座规模大，分布式架构，抗毁性强
- 卫星数量多，单颗损失影响小
- 星间链路复杂，安全管理难度大
- 快速切换带来认证和密钥管理挑战
- 太空碎片威胁更大

**典型应用：**
- 卫星互联网：Starlink、OneWeb、星网、鸿雁
- 遥感卫星：高分系列、Landsat
- 通信星座：铱星（Iridium）、Globalstar
- 空间站：国际空间站（ISS）、天宫空间站

#### 1.1.4 其他轨道类型

| 轨道类型 | 英文缩写 | 高度/特点 | 典型应用 |
|---------|---------|-----------|---------|
| 太阳同步轨道 | SSO | 约 600-800km，轨道面与太阳同步 | 遥感卫星、气象卫星 |
| 地球同步转移轨道 | GTO | 椭圆轨道，近地点约 200km，远地点约 36000km | GEO 卫星转移 |
| 极轨道 | PO | 经过南北极，倾角约 90° | 遥感、侦察卫星 |
| 大椭圆轨道 | HEO | 远地点高、近地点低 | 通信（高纬度覆盖） |
| 中地球轨道 | MEO | 2000-35786km | 导航卫星 |
| 超同步轨道 | - | 高于 GEO | 部分军事卫星 |

### 1.2 卫星系统组成

一个完整的卫星系统由空间段、地面段和用户段三大部分组成。

```
┌─────────────────────────────────────────────────────────────┐
│                        用户段 (User Segment)                  │
│  卫星手机  卫星电视  GPS终端  卫星互联网终端  遥感数据用户     │
└──────────────────────────┬──────────────────────────────────┘
                           │ 上行/下行链路
┌──────────────────────────▼──────────────────────────────────┐
│                        空间段 (Space Segment)                 │
│   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐     │
│   │ 卫星1│   │ 卫星2│   │ 卫星3│   │ 卫星4│   │ 卫星5│ ... │
│   └──┬───┘   └──┬───┘   └──┬───┘   └──┬───┘   └──┬───┘     │
│      └──────────┴────星间链路────┴──────────┴──────────┘    │
└──────────────────────────┬──────────────────────────────────┘
                           │ 测控/通信链路
┌──────────────────────────▼──────────────────────────────────┐
│                        地面段 (Ground Segment)                │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │ 测控站  │  │ 关口站  │  │ 数据接收│  │ 控制中心│  ...    │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘         │
└─────────────────────────────────────────────────────────────┘
```

#### 1.2.1 空间段（Space Segment）

**组成部分：**
- 卫星平台（卫星本体）
- 有效载荷（通信载荷、导航载荷、遥感载荷等）
- 卫星星座（多颗卫星组成的网络）

**卫星平台子系统：**
| 子系统 | 功能 | 安全相关 |
|-------|------|---------|
| 结构系统 | 卫星骨架和外壳 | 抗辐射、抗碎片 |
| 热控系统 | 温度控制 | 过热保护、异常检测 |
| 电源系统 | 太阳能电池、蓄电池 | 电源安全、防过载 |
| 姿态控制系统 | 卫星姿态稳定和控制 | 防失控、姿态安全 |
| 轨道控制系统 | 轨道维持和变轨 | 防轨道偏离、防撞 |
| 测控通信系统 | 与地面通信 | 链路加密、认证 |
| 星载计算机 | 星上数据处理 | 软件安全、防篡改 |

**有效载荷：**
- **通信载荷**：转发器、天线、功率放大器
- **导航载荷**：原子钟、导航信号发生器、发射天线
- **遥感载荷**：光学相机、合成孔径雷达（SAR）、光谱仪
- **科学载荷**：各种科学探测仪器

#### 1.2.2 地面段（Ground Segment）

**主要组成：**

| 地面设施 | 功能 | 安全等级 |
|---------|------|---------|
| 卫星控制中心（SCC） | 卫星运行控制、任务规划 | 最高 |
| 测控站（TT&C） | 卫星跟踪、遥测、遥控 | 高 |
| 关口站/网关站 | 卫星互联网网关、数据交换 | 高 |
| 数据接收站 | 遥感/气象数据接收 | 中-高 |
| 导航监测站 | 导航信号监测、星历计算 | 中 |
| 运行管理中心 | 网络管理、用户管理 | 高 |

**关键设备：**
- 大口径天线（测控、通信）
- 发射机/接收机（高功率）
- 基带处理设备
- 服务器和网络设备
- 电源系统（含 UPS）
- 空调和冷却系统

#### 1.2.3 用户段（User Segment）

**用户终端类型：**
- 卫星电视接收天线（"锅"）
- 卫星电话终端
- GPS/北斗接收机
- 卫星互联网终端（Starlink 天线等）
- 车载/船载/机载卫星通信终端
- 卫星物联网终端

**安全特点：**
- 数量庞大，分布广泛
- 安全能力参差不齐
- 容易成为攻击切入点
- 物理安全难以保证
