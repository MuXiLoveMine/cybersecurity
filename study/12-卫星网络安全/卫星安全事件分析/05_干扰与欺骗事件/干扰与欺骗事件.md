# 干扰与欺骗事件

### 4.1 Terra卫星干扰事件(2013)

```
事件: Terra地球观测卫星受到干扰

时间: 2013年6月和10月
目标: NASA Terra卫星(X频段下行)
发现者: 美国科学促进会(AAAS)

事件经过:
1. 2013年6月: Terra卫星下行信号受到干扰
   - 数据传输中断
   - 干扰持续数小时
   - 干扰源不明

2. 2013年10月: 再次受到干扰
   - 与6月干扰模式相似
   - 干扰源仍未确定

技术分析:
- 干扰频段: X频段(8-12GHz)
- 干扰类型: 压制性干扰
- 干扰区域: 某特定地面站覆盖区
- 干扰源: 推测为军事雷达或电子战设备

影响:
- 遥感数据传输中断
- 科学观测数据丢失
- 可能影响气候监测

调查结果:
- 美国认为干扰源在中东某国
- 可能是无意干扰(雷达频段接近)
- 也可能是有意干扰

教训:
1. 下行链路同样容易受干扰
2. 需要频谱监测能力
3. 需要干扰源定位能力
4. 需要备用通信链路
5. 频率协调至关重要
```

```
事件: 全球GPS欺骗攻击频发

时间: 2016年至今(持续中)
影响范围: 全球

典型事件汇总:

事件1: 黑海GPS欺骗(2017年6月)
┌─────────────────────────────────────────┐
│  • 至少20艘船只报告GPS位置错误             │
│  • 船只GPS显示在内陆(实际在海面)           │
│  • 涉及范围: 黑海约400平方海里             │
│  • 疑似军事GPS干扰/欺骗                     │
│  • 可能用于保护重要设施                    │
└─────────────────────────────────────────┘

事件2: 中东GPS欺骗(2018-2019年)
┌─────────────────────────────────────────┐
│  • 叙利亚/以色列地区GPS欺骗               │
│  • 影响民航和军事导航                      │
│  • 可能用于反无人机/防空                   │
│  • 影响范围广泛                            │
└─────────────────────────────────────────┘

事件3: UT Austin无人机劫持(2012年)
┌─────────────────────────────────────────┐
│  • 德州大学研究团队演示                    │
│  • 使用SDR发射伪造GPS信号                  │
│  • 成功劫持无人机航向                      │
│  • 证明民用GPS极易被欺骗                    │
└─────────────────────────────────────────┘

事件4: 地中海GPS欺骗(2020年)
┌─────────────────────────────────────────┐
│  • 利比亚沿海地区GPS欺骗                   │
│  • 影响航运安全                            │
│  • 可能与军事冲突相关                      │
└─────────────────────────────────────────┘

事件5: 中东GPS大规模欺骗(2023年)
┌─────────────────────────────────────────┐
│  • 以色列/黎巴嫩/叙利亚区域               │
│  • 大规模GPS欺骗影响民航                   │
│  • 多家航空公司调整航线                    │
│  • 可能用于防御目的                        │
└─────────────────────────────────────────┘

技术分析:
- 攻击原理: 发射比真实GPS信号更强的伪造信号
- 攻击成本: 数百至数千美元(SDR+功放)
- 攻击难度: 低(开源工具可用)
- 影响范围: 覆盖区域内的所有GPS接收机

防护措施:
1. Galileo OS-NMA(导航电文认证)
2. GPS M-Code(军用加密信号)
3. 多星座交叉验证
4. 惯性导航系统交叉检查
5. 天线抗欺骗设计(多天线/调零)
6. 信号强度异常检测
7. 位置合理性检查
```

### 4.3 卫星电视信号盗版

```
事件: 卫星电视信号盗版(持续存在)

背景:
- DVB-S/S2卫星电视使用条件接收(CA)系统加密
- 控制字(CW)用于加扰业务数据
- 授权智能卡用于解密CW

盗版方式:

1. 智能卡克隆
   - 逆向工程合法智能卡
   - 提取加密密钥
   - 制作盗版卡

2. CW共享(Control Word Sharing)
   - 一个合法用户获取CW
   - 通过互联网共享CW给多人
   - 多人同时观看付费内容

3. 卡共享服务器(Card Sharing)
   - 建设大规模CW分发网络
   - 用户付费订阅盗版服务
   - 服务器集群分发CW

4. DVB-CSA破解
   - 早期DVB-CSA算法密钥长度不足
   - 使用FPGA/ASIC暴力破解
   - 实时获取CW

对抗措施:
1. DVB-CSA v2(更强算法)
2. 智能卡硬件安全(Tamper-resistant)
3. CW变更频率提高(每2秒)
4. 智能卡配对(绑定接收机)
5. ECM/EMM反盗版措施
6. 在线智能卡吊销
7. 法律打击盗版服务
```
