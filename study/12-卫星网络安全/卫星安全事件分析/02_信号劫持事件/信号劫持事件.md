# 信号劫持事件

### 2.1 Captain Midnight事件(1986)

```
事件: HBO卫星信号劫持

时间: 1986年4月27日
地点: 美国佛罗里达州
攻击者: John MacDougall(化名Captain Midnight)
目标: HBO Galaxy 1卫星(下行链路)

事件经过:
1. MacDougall是卫星通信工程师
2. 拥有合法的卫星上行发射设备(Ocala地球站)
3. 在HBO节目时段, 切断了HBO的上行信号
4. 使用更强功率发射了自己的信号
5. 卫星转发了MacDougall的信号
6. 画面显示: "Captain Midnight"
   "$12.95 monthly, no descrambling"
   "Good Evening HBO"
7. 信号持续约4.5分钟
8. 随后HBO恢复信号

动机: 抗议HBO加密收费政策

技术分析:
- 攻击类型: 上行链路信号劫持
- 攻击方式: 功率压制+频率覆盖
- 弱点: 上行链路无认证机制
- 成功率: 只需足够功率即可

影响:
- HBO信号中断4.5分钟
- 数百万观众受影响
- 美国国会通过卫星通信安全法规
- FCC加强卫星上行链路监管

教训:
1. 上行链路缺乏认证和加密
2. 合法设备可被滥用
3. 需要上行信号认证机制
4. 需要功率异常监测
```

### 2.2 银行黑客控制卫星事件(1999)

```
事件: 伦敦银行黑客声称控制卫星

时间: 1999年
攻击者: 不明黑客组织(声称)
目标: 英国军事通信卫星

事件经过:
1. 黑客声称通过互联网入侵了卫星地面站
2. 威胁将卫星转向太阳以损坏传感器
3. 要求赎金
4. 英国国防部介入调查
5. 事件真实性存在争议

技术分析(如果属实):
- 攻击路径: 互联网 → 地面站网络 → 卫星控制系统
- 攻击方式: 网络入侵 → 指令系统 → 发送恶意指令
- 弱点: 地面站与公共网络连接
- 影响: 可能操控卫星姿态

教训:
1. 地面站网络安全至关重要
2. 卫星控制系统不应与公共网络直连
3. 指令系统需要多重认证
4. 需要网络分段隔离
```
