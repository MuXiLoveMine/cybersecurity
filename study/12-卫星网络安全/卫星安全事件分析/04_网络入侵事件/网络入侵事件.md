```
事件: Viasat KA-SAT卫星网络攻击

时间: 2022年2月24日(俄乌冲突爆发日)

目标: Viasat KA-SAT宽带卫星网络
影响: 数千个乌克兰/欧洲终端离线

攻击链详细分析:

阶段2: 侦察与横向移动
┌─────────────────────────────────────────┐
│  在地面站网络内横向移动                   │
│  • 识别终端管理服务器                     │
│  • 获取终端SNMP管理凭证                   │
│  • 识别终端固件更新机制                   │
│  • 确定终端擦除指令格式                   │
└─────────────────────────────────────────┘

阶段3: 攻击执行 (2022年2月24日)
┌─────────────────────────────────────────┐
│  通过管理通道向终端下发擦除指令            │
│  • 使用wipemode命令擦除终端flash           │
│  • 擦除了终端固件和配置                    │
│  • 数千个终端永久变砖(需返厂维修)          │
└─────────────────────────────────────────┘

阶段4: 影响评估
┌─────────────────────────────────────────┐
│  • 乌克兰数千终端离线                     │
│  • 部分欧洲用户受影响                     │
│  • 乌克兰军事通信受影响                    │
│  • 风力发电场远程通信中断                  │
│  • 总计约3万+终端受影响                    │
└─────────────────────────────────────────┘

技术分析:
- 攻击向量: 地面站网络入侵
- 利用的协议: SNMP/管理协议
- 破坏方式: 终端固件擦除
- 攻击特征: 精准、定向、破坏性

防御缺失分析:
1. 地面站网络安全不足
2. 管理通道缺乏加密认证
3. 终端缺乏防擦除保护
4. 缺乏固件恢复机制
5. 管理凭证管理不当

经验教训:
1. 地面站是卫星系统安全的关键薄弱点
2. 管理通道必须独立加密认证
3. 终端需要物理级防篡改
4. 需要固件恢复/回滚机制
5. 需要实时异常行为检测
6. 网络分段至关重要
```

```
事件: NSA ANT Catalog曝光
```
