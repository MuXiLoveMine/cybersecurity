# 太空对抗事件

### 5.1 中国FY-1C反卫星试验(2007)

```
事件: 中国反卫星导弹(ASAT)试验

时间: 2007年1月11日
地点: 中国四川西昌
目标: FY-1C气象卫星(已报废)
武器: SC-19反卫星导弹

事件经过:
1. FY-1C卫星在轨(870km高度)
2. SC-19导弹从地面发射
3. 导弹直接撞击卫星
4. 卫星被完全摧毁
5. 产生大量空间碎片

技术分析:
- 攻击方式: 动能撞击(直接碰撞)
- 拦截高度: 870km(LEO)
- 拦截速度: 约8km/s相对速度
- 精度: 直接碰撞(极高)

影响:
- 创造了约3000个可追踪碎片
- 约32000个不可追踪碎片
- 碎片轨道寿命: 数百年(870km)
- 威胁ISS和其他LEO卫星
- 引发国际社会强烈关注

太空安全意义:
1. 证明了中国具备反卫星能力
2. 动能ASAT是有效的太空对抗手段
3. 空间碎片是长期安全威胁
4. 太空军备竞赛加速

防护思考:
1. 卫星缺乏对动能武器的防护
2. 需要轨道机动规避能力
3. 需要空间态势感知
4. 需要国际太空行为准则
```

### 5.2 美国USA-193卫星击毁(2008)

```
事件: 美国击毁失控卫星

时间: 2008年2月21日
目标: USA-193间谍卫星(NRO)
武器: SM-3导弹(从宙斯盾舰发射)

事件经过:
1. USA-193卫星2006年发射后故障
2. 卫星无法控制, 轨道衰减
3. 含有有毒燃料(联氨)
4. 美国决定击毁卫星
5. SM-3导弹在247km高度拦截
6. 卫星被击碎

官方理由: 防止有毒燃料伤害地面人员
分析推测: 防止机密技术泄露

技术分析:
- 拦截高度: 247km(低LEO)
- 碎片寿命: 数天-数周(快速衰减)
- 与中国ASAT的区别:
  • 高度更低(碎片衰减快)
  • 目的是安全而非威慑
  • 但同样展示了反卫星能力

教训:
1. 反卫星技术大国均掌握
2. 低轨ASAT碎片问题较小
3. 但展示能力仍有政治意义
4. 卫星故障可能成为安全问题
```

### 5.3 俄罗斯反卫星试验(2021)

```
事件: 俄罗斯DA-ASAT试验

时间: 2021年11月15日
目标: Kosmos 1408卫星(已报废)
武器: DA-ASAT(Nudol)反卫星导弹

事件经过:
1. 俄罗斯发射DA-ASAT导弹
2. 拦截了Kosmos 1408卫星
3. 在约480km高度摧毁卫星
4. 产生约1500个可追踪碎片
5. ISS crew紧急避难

影响:
- 碎片威胁ISS(约400km高度)
- 碎片威胁其他LEO卫星
- 国际空间站人员紧急避难
- 美国强烈谴责

太空安全分析:
1. 碎片在480km, 寿命数十年
2. 对LEO卫星构成长期威胁
3. 加剧太空军备竞赛
4. 太空碎片日益严重

教训:
1. 反卫星试验制造长期太空碎片
2. 卫星和空间站面临碎片威胁
3. 需要国际规则约束太空行为
4. 太空交通管理日益重要
```
