# 链路层安全

### 3.1 链路加密体系

#### 3.1.1 加密分层结构

```
用户数据 ──► 应用层加密（端到端）
            ──► 链路层加密（单跳）
            ──► 物理层加密（波形级）
```

**各层加密特点对比：**

| 加密层 | 加密对象 | 优点 | 缺点 |
|-------|---------|------|------|
| 物理层 | 波形/符号 | 安全性最高，完全隐藏信号特征 | 实现复杂，互通性差 |
| 链路层 | 帧/数据链路 | 对上层透明，易于部署 | 仅保护单条链路 |
| 网络层 | IP 数据包 | 端到端保护，灵活 | 需要网络层支持 |
| 应用层 | 应用数据 | 端到端，应用可控 | 每个应用单独实现 |

#### 3.1.2 上行链路安全

**上行链路的特殊性：**
- 上行链路是控制卫星的通道
- 一旦被控制，后果极其严重
- 安全要求最高

**安全机制：**

| 安全机制 | 说明 | 实现方式 |
|---------|------|---------|
| 机密性保护 | 防止指令内容泄露 | 对称加密（AES 等） |
| 完整性保护 | 防止指令被篡改 | 消息认证码（MAC）、数字签名 |
| 身份认证 | 确认指令来源合法 | 证书认证、预共享密钥 |
| 抗重放保护 | 防止旧指令被重放 | 时间戳、序列号、随机数挑战 |
| 访问控制 | 限制谁可以发送什么指令 | 权限管理、指令分级 |

**遥控指令安全流程：**
```
指令生成 → 指令加密 → 添加认证码 → 添加序列号 → 发送
                                           ↓
接收 → 序列号验证 → 认证验证 → 解密 → 执行检查 → 执行
```

#### 3.1.3 下行链路安全

**下行链路的特点：**
- 广播特性，容易被窃听
- 数据量大，加密性能要求高
- 不同数据密级不同

**安全机制：**
- 数据加密（机密数据）
- 数据认证（完整性保护）
- 分级加密（不同密级不同密钥）
- 密钥定期更新

#### 3.1.4 星间链路安全

**星间链路的特殊挑战：**
- 链路动态建立/断开
- 卫星数量多，密钥管理复杂
- 星上计算资源有限
- 可能存在恶意节点

**关键技术：**
- 快速认证协议
- 高效密钥协商
- 分布式密钥管理
- 路由安全
- 节点信任评估

**激光星间链路的安全优势：**
- 方向性极强（光束极窄），难以窃听
- 难以被干扰（需要精确对准）
- 天然的物理层安全特性

### 3.2 链路认证协议

#### 3.2.1 CCSDS SCPS-SP

SCPS-SP 是 CCSDS 标准的空间通信安全协议，提供：
- 数据机密性
- 数据完整性
- 数据源认证
- 抗重放保护
- 访问控制

#### 3.2.2 卫星通信认证方案

| 方案 | 特点 | 适用场景 |
|-----|------|---------|
| 预共享密钥（PSK） | 简单高效，不灵活 | 小型系统、固定配置 |
| 公钥基础设施（PKI） | 灵活，可扩展 | 大型系统、多用户 |
| 基于身份的加密（IBE） | 无需证书，密钥分发简单 | 新兴方向 |
| 轻量级认证协议 | 资源占用少 | 星上处理、物联网 |

### 3.3 抗干扰链路技术

#### 3.3.1 综合抗干扰体系

```
抗干扰能力 = 处理增益 + 编码增益 + 天线增益 + 功率裕量
```

**各部分贡献（典型值）：**
- 扩频处理增益：20-40 dB
- 纠错编码增益：2-8 dB
- 调零天线增益：20-40 dB
- 功率控制裕量：5-10 dB

#### 3.3.2 抗干扰等级

| 等级 | 抗干扰能力 | 适用对象 |
|-----|-----------|---------|
| A 级 | >60 dB | 战略级军用 |
| B 级 | 40-60 dB | 战役级军用 |
| C 级 | 20-40 dB | 战术级军用/重要民用 |
| D 级 | <20 dB | 普通民用/商业 |
