# 应用层安全

### 5.1 身份认证与访问控制

#### 5.1.1 用户身份认证

**认证方式：**

| 认证方式 | 安全强度 | 适用场景 |
|---------|---------|---------|
| 用户名/密码 | 低 | 普通用户 |
| 数字证书 | 高 | 重要用户、设备认证 |
| 多因素认证（MFA） | 很高 | 管理员、关键操作 |
| 硬件令牌 | 高 | 高安全需求 |
| 生物识别 | 中-高 | 特定场景 |

#### 5.1.2 卫星终端认证

**卫星终端入网认证：**
- 终端身份认证（确认终端合法）
- 位置验证（防止非法地区使用）
- 设备指纹（防止终端克隆）
- SIM/USIM 卡（类移动通信方式）

**认证协议：**
- 挑战-应答协议
- 证书认证协议
- 轻量级认证协议（适合资源受限终端）

#### 5.1.3 访问控制模型

**基于角色的访问控制（RBAC）：**
- 用户 → 角色 → 权限
- 适合地面站和管理系统
- 权限管理清晰

**基于属性的访问控制（ABAC）：**
- 根据用户、资源、环境属性动态决策
- 适合动态变化的场景
- 灵活性高

**强制访问控制（MAC）：**
- 系统强制实施安全策略
- 用户无法改变权限
- 用于高安全等级系统（军用）

### 5.2 数据安全

#### 5.2.1 数据分类分级

按照数据敏感度分类：

| 级别 | 名称 | 说明 | 泄露后果 |
|-----|------|------|---------|
| 1 | 公开数据 | 可对外公开的数据 | 无 |
| 2 | 内部数据 | 系统内部使用 | 轻微影响 |
| 3 | 敏感数据 | 商业秘密/工作秘密 | 较大影响 |
| 4 | 机密数据 | 国家机密/核心商业机密 | 严重影响 |
| 5 | 绝密数据 | 最高级别机密 | 灾难性影响 |

#### 5.2.2 数据全生命周期安全

```
数据生成 → 数据传输 → 数据存储 → 数据处理 → 数据销毁
    ↓         ↓         ↓         ↓         ↓
  分类分级   传输加密   存储加密   访问控制   安全销毁
  来源认证   完整性     备份恢复   脱敏处理   介质消磁
           抗抵赖     审计日志   审计日志   物理销毁
```

#### 5.2.3 卫星数据安全特殊要求

- **遥感数据**：高分辨率数据涉及国家安全，需要分级管控
- **测控数据**：卫星控制指令和遥测数据，安全要求极高
- **导航数据**：导航电文的完整性和真实性至关重要
- **通信数据**：用户通信数据的隐私保护

### 5.3 应用安全防护

#### 5.3.1 Web 应用安全

卫星地面站和管理系统通常有 Web 管理界面，需要防护：
- SQL 注入
- XSS 跨站脚本
- CSRF 跨站请求伪造
- 文件上传漏洞
- 命令注入
- 越权访问

#### 5.3.2 星载软件安全

**星载软件的特殊性：**
- 运行环境特殊（辐射、资源受限）
- 更新困难且有风险
- 可靠性要求极高
- 安全漏洞影响严重

**安全措施：**
- 软件安全开发生命周期（SDL）
- 代码审计和安全测试
- 软件加固（内存保护、堆栈保护）
- 安全启动（Secure Boot）
- 安全更新机制（签名验证）
- 错误检测和容错
