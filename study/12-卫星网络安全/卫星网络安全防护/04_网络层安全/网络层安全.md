# 网络层安全

### 4.1 卫星网络安全威胁

#### 4.1.1 网络层攻击类型

| 攻击类型 | 说明 | 危害程度 |
|---------|------|---------|
| DDoS 攻击 | 分布式拒绝服务攻击，消耗网络资源 | 高 |
| 路由攻击 | 篡改路由信息，劫持或中断流量 | 高 |
| DNS 攻击 | DNS 欺骗、DNS 缓存投毒 | 中-高 |
| 中间人攻击 | 拦截并篡改通信内容 | 高 |
| 端口扫描 | 探测网络结构和服务 | 低（侦察阶段） |
| 漏洞利用 | 利用系统漏洞入侵 | 高 |
| 僵尸网络 | 控制大量终端发动攻击 | 高 |

#### 4.1.2 卫星互联网的特殊安全挑战

1. **动态拓扑**：卫星高速运动，网络拓扑快速变化，传统安全机制难以适应
2. **星上处理受限**：星上计算和存储资源有限，无法部署复杂安全设备
3. **长时延**：GEO 卫星单向延迟约 250ms，影响安全协议性能
4. **高误码率**：无线链路误码率高，加密和认证协议需要适应
5. **海量终端**：卫星互联网用户终端数量巨大，管理难度高
6. **跨境跨域**：卫星覆盖全球，涉及多个国家和司法管辖区

### 4.2 网络层防护技术

#### 4.2.1 防火墙与访问控制

**地面站网络防火墙部署：**
```
互联网 ──► 边界防火墙 ──► DMZ区 ──► 内部防火墙 ──► 内部网络
                                                    ├─ 办公网
                                                    ├─ 业务网
                                                    └─ 控制网（物理隔离）
```

**安全区域划分：**
- **互联网区**：对外服务，安全等级最低
- **DMZ 区**：对外服务器，有防护
- **办公区**：内部办公，中等安全
- **业务区**：卫星业务系统，高安全
- **控制区**：卫星控制系统，最高安全（物理隔离）

#### 4.2.2 入侵检测系统（IDS/IPS）

**部署位置：**
- 网络边界
- 关键网段
- 重要服务器
- 地面站与卫星链路

**检测技术：**
- 特征匹配（已知攻击）
- 异常检测（偏离正常行为）
- 协议分析
- 威胁情报

**卫星网络 IDS 的特殊性：**
- 需要适应卫星链路的长时延和高误码
- 需要识别针对卫星协议的攻击
- 需要考虑空间段的异常行为

#### 4.2.3 DDoS 防护

**卫星网络 DDoS 攻击的特点：**
- 可以从全球范围发起
- 卫星链路带宽相对有限，更容易打满
- 攻击源难以追踪和定位

**防护措施：**
- 流量清洗（地面站部署）
- 接入认证（防止未授权终端接入）
- 速率限制
- Anycast 和分布式部署
- 卫星链路冗余和切换

#### 4.2.4 路由安全

**卫星网络路由安全挑战：**
- 动态拓扑，路由变化频繁
- 星间链路路由安全
- 卫星节点可能被控制

**防护措施：**
- 路由认证（验证路由信息来源）
- 安全路由协议（如 SDN 集中控制）
- 路由异常检测
- 多路径冗余

### 4.3 软件定义卫星网络（SDSN）安全

#### 4.3.1 SDN 在卫星网络中的应用

SDN（软件定义网络）将控制平面和数据平面分离，适合管理动态变化的卫星网络。

**优势：**
- 集中管理，灵活调度
- 快速适应拓扑变化
- 便于安全策略部署
- 网络可编程

**安全挑战：**
- 控制器成为新的攻击目标
- 控制器被控制后果严重
- 南向接口安全
- 集中式架构的单点故障风险

#### 4.3.2 SDN 安全增强

- 控制器冗余和备份
- 控制器安全加固
- 南向接口认证和加密
- 流规则验证
- 网络态势感知
