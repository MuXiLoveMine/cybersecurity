# 星间链路安全

### 7.1 ISL安全特性

```
星间链路(ISL)安全:

ISL相对于地空链路的安全优势:
1. 方向性强: 点对点通信, 难以截获
2. 距离近: 星间距离远小于地空距离
3. 频率高: 通常使用Ka/V波段或激光
4. 波束窄: 信号不易被截获

ISL安全威胁:
1. 第三方截获
   - 需要特殊设备(高频接收机)
   - 需要在轨道附近部署
   - 技术门槛高

2. 信号注入
   - 需要知道ISL频率和调制
   - 需要高功率发射
   - 需要在轨道附近

3. 中继攻击
   - 接收ISL信号并转发修改后版本
   - 利用传播延迟

4. 路由攻击
   - 篡改星座路由信息
   - 影响数据传输路径

ISL安全防护:
• 端到端加密(每条ISL独立密钥)
• 设备认证(通信双方身份验证)
• 路由表完整性验证
• 异常流量检测
• 波束跟踪异常检测
```

### 7.2 激光ISL安全

```
激光星间链路安全:

优势:
1. 极高方向性: 波束宽度<0.01度
2. 极高频段: 200-400THz
3. 高带宽: Gbps级
4. 低截获: 除非在波束路径上
5. 抗干扰: 难以干扰

安全威胁:
1. 波束遮挡: 在两星之间放置遮挡物
2. 致盲攻击: 发射高功率激光致盲接收器
3. 波束窃听: 在波束路径上放置接收器

防护措施:
• 波束功率控制
• 接收器保护(光限幅器)
• 多波束冗余
• 波束跟踪异常检测
```
