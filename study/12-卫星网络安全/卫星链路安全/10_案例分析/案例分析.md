# 案例分析

### 10.1 Captain Midnight事件(1986)

```
事件: HBO信号劫持 (1986年4月27日)

背景:
- HBO(Home Box Office)使用卫星加密其电视信号
- John MacDougall(化名Captain Midnight)使用卫星上行设备
- 劫持了HBO的卫星信号

攻击过程:
1. MacDougall是卫星通信工程师
2. 拥有合法的上行发射设备
3. 在HBO节目时段, 用更强信号覆盖了HBO上行信号
4. 卫星转发了MacDougall的信号(文本消息)
5. 信号持续了约4.5分钟

影响:
- HBO信号中断
- 数百万观众受到影响
- 促使美国国会通过卫星通信安全法规

教训:
1. 上行链路缺乏认证机制
2. 任何人有足够功率的发射设备即可劫持
3. 需要上行信号认证
4. 需要功率监测
```

### 10.2 GPS欺骗事件

```
事件: 多起GPS欺骗攻击 (2016-2023)

背景:
- GPS下行信号未加密未认证
- 任何人都可以发射伪造GPS信号
- 攻击成本低(数百美元的SDR设备)

典型攻击:

1. 船舶GPS欺骗(2017年)
   - 黑海区域多艘船只报告位置错误
   - 船舶GPS显示在 inland位置
   - 实际在海面上

2. 无人机GPS欺骗(2012年)
   - UT Austin研究团队演示
   - 使用SDR发射伪造GPS信号
   - 成功劫持无人机航向

3. 金融系统GPS时间欺骗(2019年)
   - CEPT系统依赖GPS授时
   - GPS时间欺骗导致交易时间戳错误
   - 影响金融交易

防护:
1. GPS信号认证(OS-NMA, NMA)
2. 多星座交叉验证(GPS+Galileo+BeiDou)
3. 惯性导航交叉验证
4. 信号强度异常检测
5. 天线抗欺骗设计
```

### 10.3 DVB-S密钥泄露

```
事件: DVB-CSA密钥破解

背景:
- DVB-CSA(Common Scrambling Algorithm)用于卫星电视加密
- 控制字(CW)为48/64位
- 设计于1990年代

破解过程:
1. 2002年: DVB-CSA算法被逆向分析
2. 控制字空间不足, 可被暴力破解
3. 使用FPGA/ASIC加速破解
4. 实时破解CW(秒级)

影响:
- 卫星电视内容可被非法解密
- 盗版智能卡泛滥
- 推动DVB-CSA v2和更强加密

教训:
1. 加密算法需要足够密钥长度
2. 密码学算法会随时间失效
3. 需要可更新的加密方案
4. 密钥管理比算法本身更重要
```
