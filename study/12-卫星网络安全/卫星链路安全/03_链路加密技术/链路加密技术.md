# 链路加密技术

### 3.1 链路加密层次

```
卫星链路加密层次:

┌─────────────────────────────────────────┐
│           应用层加密 (End-to-End)        │
│  ┌─────────────────────────────────┐   │
│  │ 用户数据加密 (如TLS/自定义)      │   │
│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤
│           网络层加密                   │
│  ┌─────────────────────────────────┐   │
│  │ IPsec / 自定义网络层加密          │   │
│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤
│           链路层加密 (Link-Layer)      │
│  ┌─────────────────────────────────┐   │
│  │ DVB-CISSA/CISSB / 自定义链路加密 │   │
│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤
│           物理层安全                   │
│  ┌─────────────────────────────────┐   │
│  │ 扩频/跳频/波束成形               │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘

各层功能:
• 物理层: 抗干扰、低截获概率
• 链路层: 链路级数据加密、认证
• 网络层: 端到端网络加密
• 应用层: 业务数据加密
```

### 3.2 DVB加密标准

```
DVB条件接收(CA)系统:

DVB-CSA (Common Scrambling Algorithm):
- 用于DVB-S/S2卫星电视加密
- 使用64位控制字(CW)
- 分为DVB-CSA v1和v2

DVB-CISSA (Common IPTV Scrambling):
- 用于IP化DVB传输
- AES-128-CBC加密

DVB-CISSB:
- 改进版本
- AES-128-CBC + AES-128-CMAC

加密流程:
1. 业务数据 → 分组
2. 控制字(CW)生成 → 每10秒更换
3. 使用CW加密业务数据
4. 使用授权密钥(SK)加密CW
5. 加密后的CW通过ECM传输
6. 授权信息通过EMM传输

ECM (Entitlement Control Message):
- 包含加密的控制字
- 频繁发送(每2-10秒)
- 只有授权用户能解密

EMM (Entitlement Management Message):
- 包含授权信息
- 不频繁发送
- 更新用户的订阅权限
```
