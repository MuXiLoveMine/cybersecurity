# 上下行链路安全

### 2.1 上行链路安全威胁

```
上行链路安全威胁:

威胁1: 未授权指令注入 (最严重)
┌──────────┐         ┌──────┐
│ 攻击者    │──指令──→│ 卫星  │
│ 发射设备  │  信号   │      │
└──────────┘         └──────┘
- 攻击者发射与地面站相同频率/调制
- 如果没有加密认证, 卫星会执行未授权指令
- 历史案例: 1986年HBO信号劫持(Captain Midnight)

威胁2: 指令重放
┌──────────┐   捕获    ┌──────┐
│ 攻击者    │←──信号──│地面站│
│          │          │      │
│          │──重放──→│ 卫星  │
└──────────┘   信号   └──────┘
- 攻击者截获合法指令, 稍后重放
- 如果没有防重放机制, 卫星会执行

威胁3: 上行干扰
┌──────────┐   干扰    ┌──────┐
│ 攻击者    │──信号──→│ 卫星  │
│          │          │      │
└──────────┘          └──────┘
- 压制性干扰: 使卫星无法接收合法指令
- 欺骗性干扰: 使卫星接收错误信息

威胁4: 上行信号分析
┌──────────┐   截获    ┌──────┐
│ 攻击者    │←──信号──│地面站│
│          │          │      │
└──────────┘          └──────┘
- 被动截获上行信号
- 分析调制方式、编码特征
- 推断通信内容和卫星功能
```

### 2.2 下行链路安全威胁

```
下行链路安全威胁:

威胁1: 遥测数据截获
┌──────┐          ┌──────────┐
│ 卫星  │──信号──→│ 攻击者    │
│      │          │ 接收设备  │
└──────┘          └──────────┘
- 任何人都可以接收卫星下行信号
- 如果未加密, 遥测数据暴露卫星状态
- 可分析卫星轨道、姿态、健康状况

威胁2: 数据窃取
┌──────┐          ┌──────────┐
│ 卫星  │──数据──→│ 攻击者    │
│      │          │          │
└──────┘          └──────────┘
- 通信卫星: 窃取通信内容
- 遥感卫星: 窃取遥感图像
- 导航卫星: 分析导航电文

威胁3: 信号分析
┌──────┐          ┌──────────┐
│ 卫星  │──信号──→│ 攻击者    │
│      │          │ 分析设备  │
└──────┘          └──────────┘
- 分析调制方式
- 分析信号参数
- 推断载荷能力

威胁4: 伪造下行信号
┌──────────┐  伪造   ┌──────────┐
│ 攻击者    │──信号──→│ 地面站    │
│          │        │          │
└──────────┘        └──────────┘
- 向地面站发送伪造的卫星信号
- 如果未认证, 地面站可能接受假数据
```
