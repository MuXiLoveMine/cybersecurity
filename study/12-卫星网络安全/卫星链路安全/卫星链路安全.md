## 1. 卫星链路概述

### 1.1 卫星链路组成

卫星链路是卫星与地面之间、卫星与卫星之间的通信通道。它是卫星系统中最开放的接口，也是安全防护的重中之重：

```
卫星链路类型:

1. 上行链路 (Uplink): 地面 → 卫星
   地面站 ──→ 卫星
   用途: 指令上传、数据注入、测距信号

2. 下行链路 (Downlink): 卫星 → 地面
   卫星 ──→ 地面站
   用途: 遥测下行、数据传输、定位信号

3. 前向链路 (Forward): 网关 → 卫星 → 用户
   网关站 ──→ 卫星 ──→ 用户终端
   用途: 广播、数据分发

4. 返向链路 (Return): 用户 → 卫星 → 网关
   用户终端 ──→ 卫星 ──→ 网关站
   用途: 数据采集、用户请求

5. 星间链路 (ISL): 卫星 ↔ 卫星
   SAT1 ←──→ SAT2
   用途: 星座组网、数据中继

链路安全关键性:
- 上行链路: 任何人都能发射信号 → 指令注入风险
- 下行链路: 任何人都能接收信号 → 数据截获风险
- 星间链路: 需要特殊设备截获 → 相对安全但仍需防护
```

### 1.2 链路频段与安全特性

| 频段 | 频率范围 | 主要用途 | 安全特性 |
|------|---------|---------|---------|
| UHF | 300-1000MHz | 军事通信 | 易被干扰, 设备易获取 |
| L | 1-2GHz | 导航/移动通信 | 中等安全性 |
| S | 2-4GHz | 遥测遥控/移动通信 | 中等安全性 |
| C | 4-8GHz | 固定业务 | 较好安全性 |
| X | 8-12GHz | 军事通信 | 较高安全性 |
| Ku | 12-18GHz | 固定/广播 | 较高安全性 |
| Ka | 18-40GHz | 宽带通信 | 高安全性, 雨衰大 |
| V | 40-75GHz | 宽带/星间 | 高安全性 |
| 光学 | 200-400THz | 星间激光 | 极高安全性(方向性强) |

## 2. 上下行链路安全

### 2.1 上行链路安全威胁

```
上行链路安全威胁:

威胁1: 未授权指令注入 (最严重)
┌──────────┐         ┌──────┐
│ 攻击者    │──指令──→│ 卫星  │
│ 发射设备  │  信号   │      │
└──────────┘         └──────┘
- 攻击者发射与地面站相同频率/调制
- 如果没有加密认证, 卫星会执行未授权指令
- 历史案例: 1986年HBO信号劫持(Captain Midnight)

威胁2: 指令重放
┌──────────┐   捕获    ┌──────┐
│ 攻击者    │←──信号──│地面站│
│          │          │      │
│          │──重放──→│ 卫星  │
└──────────┘   信号   └──────┘
- 攻击者截获合法指令, 稍后重放
- 如果没有防重放机制, 卫星会执行

威胁3: 上行干扰
┌──────────┐   干扰    ┌──────┐
│ 攻击者    │──信号──→│ 卫星  │
│          │          │      │
└──────────┘          └──────┘
- 压制性干扰: 使卫星无法接收合法指令
- 欺骗性干扰: 使卫星接收错误信息

威胁4: 上行信号分析
┌──────────┐   截获    ┌──────┐
│ 攻击者    │←──信号──│地面站│
│          │          │      │
└──────────┘          └──────┘
- 被动截获上行信号
- 分析调制方式、编码特征
- 推断通信内容和卫星功能
```

### 2.2 下行链路安全威胁

```
下行链路安全威胁:

威胁1: 遥测数据截获
┌──────┐          ┌──────────┐
│ 卫星  │──信号──→│ 攻击者    │
│      │          │ 接收设备  │
└──────┘          └──────────┘
- 任何人都可以接收卫星下行信号
- 如果未加密, 遥测数据暴露卫星状态
- 可分析卫星轨道、姿态、健康状况

威胁2: 数据窃取
┌──────┐          ┌──────────┐
│ 卫星  │──数据──→│ 攻击者    │
│      │          │          │
└──────┘          └──────────┘
- 通信卫星: 窃取通信内容
- 遥感卫星: 窃取遥感图像
- 导航卫星: 分析导航电文

威胁3: 信号分析
┌──────┐          ┌──────────┐
│ 卫星  │──信号──→│ 攻击者    │
│      │          │ 分析设备  │
└──────┘          └──────────┘
- 分析调制方式
- 分析信号参数
- 推断载荷能力

威胁4: 伪造下行信号
┌──────────┐  伪造   ┌──────────┐
│ 攻击者    │──信号──→│ 地面站    │
│          │        │          │
└──────────┘        └──────────┘
- 向地面站发送伪造的卫星信号
- 如果未认证, 地面站可能接受假数据
```

```
┌─────────────────────────────────────────┐

│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤
│           链路层加密 (Link-Layer)      │
│  ┌─────────────────────────────────┐   │
│  │ DVB-CISSA/CISSB / 自定义链路加密 │   │
│  └─────────────────────────────────┘   │
├─────────────────────────────────────────┤

│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘

各层功能:
• 物理层: 抗干扰、低截获概率
• 链路层: 链路级数据加密、认证
• 网络层: 端到端网络加密
• 应用层: 业务数据加密
```

### 3.2 DVB加密标准

```
DVB条件接收(CA)系统:

DVB-CSA (Common Scrambling Algorithm):
- 用于DVB-S/S2卫星电视加密
- 使用64位控制字(CW)
- 分为DVB-CSA v1和v2

DVB-CISSA (Common IPTV Scrambling):
- 用于IP化DVB传输
- AES-128-CBC加密

DVB-CISSB:
- 改进版本
- AES-128-CBC + AES-128-CMAC

加密流程:
1. 业务数据 → 分组
2. 控制字(CW)生成 → 每10秒更换
3. 使用CW加密业务数据
4. 使用授权密钥(SK)加密CW
5. 加密后的CW通过ECM传输
6. 授权信息通过EMM传输

ECM (Entitlement Control Message):
- 包含加密的控制字
- 频繁发送(每2-10秒)
- 只有授权用户能解密

EMM (Entitlement Management Message):
- 包含授权信息
- 不频繁发送
- 更新用户的订阅权限
```

## 4. 扩频与抗干扰

### 4.1 扩频技术

```
扩频通信技术:

1. 直接序列扩频 (DSSS)
   ┌──────────────────────────────────────┐
   │  原始数据: 1 0 1 1 0                │
   │      ↓                               │
   │  扩频码: 1010101 0101010 1010101...  │
   │      ↓                               │
   │  扩频后: (XOR) 宽带信号              │
   │      ↓                               │
   │  接收端: 使用相同扩频码解扩          │
   └──────────────────────────────────────┘
   优势:
   - 抗干扰: 干扰信号被解扩为窄带噪声
   - 低截获: 功率谱密度低, 难以检测
   - 抗多径: 扩频码的自相关性
   - 多址: 不同扩频码可共享频段

2. 跳频扩频 (FHSS)
   ┌──────────────────────────────────────┐
   │  频率: f1  f2  f3  f4  f5  f6  f7  │
   │  时间: t1  t2  t3  t4  t5  t6  t7  │
   │        ↓   ↓   ↓   ↓   ↓   ↓   ↓   │
   │  信号: [f3][f1][f7][f5][f2][f6][f4] │
   │  (伪随机跳频模式)                    │
   └──────────────────────────────────────┘
   优势:
   - 抗干扰: 只有当前频率可被干扰
   - 抗截获: 难以跟踪跳频模式
   - 频率分集: 利用多径效应

3. 混合扩频 (DSSS+FHSS)
   - 结合直接序列和跳频
   - 更强的抗干扰能力
   - 更低的截获概率

安全优势:
- 处理增益 = 10log(扩频因子)
- 例如: 扩频因子1000 → 30dB处理增益
- 意味着需要1000倍的干扰功率
```

### 4.2 自适应抗干扰

```python
# 自适应抗干扰系统
class AdaptiveAntiJamming:
    """自适应抗干扰系统"""

    def __init__(self):
        self.current_mode = 'normal'
        self.interference_level = 0
        self.freq_hop_pattern = None
        self.dsss_spreading_factor = 1
        self.power_control = 1.0  # 相对功率

    def monitor_interference(self) -> float:
        """监测干扰水平"""
        # 实时监测信噪比
        snr = self._measure_snr()
        
        # 计算干扰水平 (0-1)
        self.interference_level = max(0, 1 - (snr / self.target_snr))
        
        return self.interference_level

    def adapt_defense(self):
        """自适应调整防御策略"""
        interference = self.monitor_interference()

        if interference < 0.1:
            # 低干扰: 正常模式
            self.current_mode = 'normal'
            self.dsss_spreading_factor = 1
            self.power_control = 1.0
            logger.info("正常模式")

        elif interference < 0.3:
            # 中等干扰: 增加扩频
            self.current_mode = 'enhanced_dsss'
            self.dsss_spreading_factor = 16
            self.power_control = 1.5
            logger.info("增强扩频模式")

        elif interference < 0.6:
            # 高干扰: 跳频+扩频
            self.current_mode = 'fhss_dsss'
            self.dsss_spreading_factor = 64
            self.freq_hop_pattern = self._generate_hop_pattern()
            self.power_control = 2.0
            logger.warning("跳频+扩频模式")

        elif interference < 0.9:
            # 极高干扰: 最低速率+最大扩频
            self.current_mode = 'survival'
            self.dsss_spreading_factor = 1024
            self.power_control = 3.0  # 最大功率
            # 降低数据速率
            self.data_rate = self.base_rate / 100
            logger.critical("生存模式(最低速率)")

        else:
            # 无法通信: 进入静默
            self.current_mode = 'silent'
            logger.critical("进入静默模式")

    def _generate_hop_pattern(self) -> list:
        """生成跳频模式"""
        # 使用密钥生成的伪随机序列
        # 确保收发两端同步跳频
        import hashlib
        pattern = []
        for i in range(1000):
            seed = hashlib.sha256(
                f'{self.hop_key}:{i}'.encode()
            ).digest()
            freq_idx = int.from_bytes(seed[:2], 'big') % self.num_channels
            pattern.append(self.channels[freq_idx])
        return pattern
```

### 5.1 上行链路认证

```python
# 上行指令认证系统
class UplinkAuthentication:
    """上行链路指令认证"""

    def __init__(self, private_key, satellite_public_key):
        self.private_key = private_key  # 地面站私钥
        self.sat_pubkey = satellite_public_key  # 卫星预置公钥
        self.sequence_number = 0
        self.session_key = None

    def authenticate_command(self, command: bytes) -> bytes:
        """对上行指令进行认证"""
        # 1. 添加序列号(防重放)
        seq_bytes = struct.pack('>Q', self.sequence_number)
        
        # 2. 添加时间戳
        timestamp = struct.pack('>I', int(time.time()))
        
        # 3. 构造认证数据
        auth_data = seq_bytes + timestamp + command
        
        # 4. 签名
        signature = self._sign(auth_data)
        
        # 5. 加密(指令保密)
        encrypted_command = self._encrypt(command)
        
        # 6. 构造认证帧
        auth_frame = {
            'sequence': self.sequence_number,
            'timestamp': int(time.time()),
            'encrypted_command': encrypted_command,
            'signature': signature,
            'session_id': self.session_id,
        }
        
        self.sequence_number += 1
        return self._pack_frame(auth_frame)

    def _sign(self, data: bytes) -> bytes:
        """ECDSA-P256签名"""
        from cryptography.hazmat.primitives.asymmetric import ec
        from cryptography.hazmat.primitives import hashes
        return self.private_key.sign(data, ec.ECDSA(hashes.SHA256()))

    def _encrypt(self, data: bytes) -> bytes:
        """AES-256-GCM加密"""
        iv = os.urandom(12)
        cipher = AESGCM(self.session_key)
        ciphertext = cipher.encrypt(iv, data, None)
        return iv + ciphertext
```

## 6. 射频攻击与防御

### 6.1 射频攻击分类

```
射频攻击分类:

1. 压制性干扰 (Jamming)
   ├── 瞄准干扰: 针对特定频率
   │   - 需要知道目标频率
   │   - 功率需求相对较低
   │
   ├── 宽带干扰: 覆盖宽频带
   │   - 不需要知道精确频率
   │   - 功率需求高
   │
   ├── 扫频干扰: 快速扫描频带
   │   - 周期性干扰多个频率
   │   - 难以被定位
   │
   └── 脉冲干扰: 高功率脉冲
       - 瞬时高功率
       - 破坏AGC和同步

2. 欺骗性干扰 (Spoofing)
   ├── 信号欺骗: 发射伪造信号
   │   - 伪造卫星下行信号
   │   - 伪造导航信号
   │
   ├── 中继转发: 转发并延迟真实信号
   │   - 信号延迟导致测距错误
   │   - 影响导航定位
   │
   └── 重放攻击: 录制并重放信号
       - 需要录制合法信号
       - 简单但可能有效

3. 信号截获 (Interception)
   ├── 被动截获: 仅接收分析
   │   - 无需发射信号
   │   - 不可检测
   │
   └── 信号分析: 深度分析信号特征
       - 调制分析
       - 流量分析
       - 特征提取
```

### 6.2 干扰检测与定位

```python
# 射频干扰检测与定位
class RFInterferenceDetection:
    """射频干扰检测与定位"""

    def __init__(self):
        self.baseline_snr = 15.0  # dB
        self.spectrum_baseline = {}
        self.interference_log = []

    def detect_jamming(self, received_signal: dict) -> dict:
        """检测干扰"""
        result = {
            'jamming_detected': False,
            'jamming_type': 'none',
            'interference_level': 0,
            'affected_frequencies': [],
        }

        # 1. SNR分析
        current_snr = received_signal.get('snr', 0)
        snr_drop = self.baseline_snr - current_snr

        if snr_drop > 3:  # 3dB以上下降
            result['jamming_detected'] = True
            result['interference_level'] = snr_drop

        # 2. 频谱分析
        spectrum = received_signal.get('spectrum', {})
        for freq, power in spectrum.items():
            baseline_power = self.spectrum_baseline.get(freq, -100)
            if power > baseline_power + 6:  # 6dB以上异常
                result['affected_frequencies'].append(freq)
                result['jamming_detected'] = True

        # 3. 干扰类型判断
        if result['jamming_detected']:
            result['jamming_type'] = self._classify_jamming(
                spectrum, result['affected_frequencies']
            )

            # 记录
            self.interference_log.append({
                'time': datetime.now().isoformat(),
                'type': result['jamming_type'],
                'level': result['interference_level'],
                'freqs': result['affected_frequencies'],
            })

        return result

    def _classify_jamming(self, spectrum: dict,
                          affected_freqs: list) -> str:
        """分类干扰类型"""
        if len(affected_freqs) <= 2:
            return 'narrowband'  # 窄带干扰
        elif len(affected_freqs) > 10:
            return 'broadband'  # 宽带干扰
        else:
            return 'partial'  # 部分频带干扰

    def locate_interference_source(self, 
                                     multi_station_data: list) -> dict:
        """多站协同定位干扰源"""
        # 使用TDOA(到达时间差)定位
        # 或AOA(到达角度)定位
        result = {
            'method': 'TDOA',
            'estimated_position': {},
            'confidence': 0,
        }

        if len(multi_station_data) >= 3:
            # 三站TDOA定位
            result['estimated_position'] = self._tdoa_locate(
                multi_station_data
            )
            result['confidence'] = 0.8

        return result
```

```python
# 卫星链路安全协议设计
class SatelliteLinkSecurityProtocol:
    """卫星链路安全协议(SLSP)"""

    PROTOCOL_VERSION = '1.0'

    # 协议状态
    STATES = {
        'INIT': '初始状态',
        'KEY_EXCHANGE': '密钥交换',
        'AUTHENTICATED': '已认证',
        'ENCRYPTED': '加密通信',
        'REKEYING': '密钥更新中',
        'TERMINATED': '终止',
    }

    def __init__(self):
        self.state = 'INIT'
        self.session_keys = {}
        self.sequence_tx = 0
        self.sequence_rx = 0
        self.replay_window = 64

    def handshake(self, satellite_id: str) -> bool:
        """安全握手"""
        # 基于证书的双向认证
        # 简化的握手流程:

        # 1. 地面站发送Hello (含证书)
        ground_hello = {
            'version': self.PROTOCOL_VERSION,
            'ground_cert': self.ground_certificate,
            'nonce_ground': os.urandom(16),
            'supported_algos': ['AES-256-GCM', 'ECDSA-P256'],
        }

        # 2. 卫星验证地面站证书
        if not self._verify_ground_cert(ground_hello['ground_cert']):
            return False

        # 3. 卫星发送Hello (含证书)
        satellite_hello = {
            'version': self.PROTOCOL_VERSION,
            'sat_cert': self.satellite_certificate,
            'nonce_sat': os.urandom(16),
            'selected_algo': 'AES-256-GCM',
        }

        # 4. 地面站验证卫星证书
        if not self._verify_sat_cert(satellite_hello['sat_cert']):
            return False

        # 5. ECDH密钥交换
        shared_secret = self._ecdh_key_exchange(
            ground_hello['nonce_ground'],
            satellite_hello['nonce_sat']
        )

        # 6. 派生会话密钥
        self.session_keys = self._derive_keys(shared_secret)

        self.state = 'ENCRYPTED'
        return True

    def send_secure(self, data: bytes) -> bytes:
        """发送加密数据"""
        if self.state != 'ENCRYPTED':
            raise ValueError("未建立加密会话")

        # 构造安全帧
        frame = {
            'seq': self.sequence_tx,
            'timestamp': int(time.time()),
            'data': data,
        }

        # 加密
        frame_data = json.dumps(frame).encode()
        iv = os.urandom(12)

        cipher = AESGCM(self.session_keys['data_key'])
        ciphertext = cipher.encrypt(
            iv, frame_data,
            struct.pack('>QI', self.sequence_tx, int(time.time()))
        )

        secure_frame = struct.pack('>Q', self.sequence_tx) + iv + ciphertext
        self.sequence_tx += 1

        return secure_frame

    def recv_secure(self, frame: bytes) -> bytes:
        """接收并解密"""
        if self.state != 'ENCRYPTED':
            raise ValueError("未建立加密会话")

        # 解析帧
        seq = struct.unpack('>Q', frame[:8])[0]
        iv = frame[8:20]
        ciphertext = frame[20:]

        # 防重放检查
        if seq <= self.sequence_rx - self.replay_window:
            raise ValueError(f"重放攻击! seq={seq}")
        if seq <= self.sequence_rx and seq in self.received_seqs:
            raise ValueError(f"重复序列号! seq={seq}")

        # 解密
        try:
            cipher = AESGCM(self.session_keys['data_key'])
            plaintext = cipher.decrypt(
                iv, ciphertext,
                struct.pack('>QI', seq, int(time.time()))
            )
        except Exception:
            raise ValueError("解密失败")

        self.sequence_rx = max(self.sequence_rx, seq)
        self.received_seqs.add(seq)

        frame_data = json.loads(plaintext)
        return frame_data['data']
```

## 总结

卫星链路安全是整个卫星系统中最具挑战性的安全领域。由于卫星链路的开放性（上行链路任何人都能发射，下行链路任何人都能接收），安全防护必须从物理层到应用层构建完整的防护体系。

关键防护原则：
1. **上行认证** - 所有上行指令必须经过加密认证
2. **下行加密** - 所有下行数据必须加密保护
3. **扩频抗干扰** - 使用DSSS/FHSS增强抗干扰能力
4. **防重放** - 序列号+时间戳防止指令重放
5. **密钥管理** - 多层次密钥体系，定期更新
6. **实时监测** - 射频、加密、流量多维监测
7. **自适应防御** - 根据威胁等级动态调整防护策略
