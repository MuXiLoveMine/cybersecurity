# 卫星网络安全基础

> 卫星网络安全是研究卫星系统、卫星网络及其相关基础设施的安全防护的学科。本章从卫星通信概述出发，系统介绍卫星网络架构、通信链路、协议标准、安全威胁及著名安全事件。

---

## 一、卫星通信概述

### 1.1 卫星轨道类型

卫星按照轨道高度可以分为以下几大类，不同轨道类型决定了卫星的应用场景和安全特性。

#### 1.1.1 GEO（地球静止轨道）

**基本参数：**
- 轨道高度：约 35,786 公里
- 轨道周期：约 23 小时 56 分 4 秒（与地球自转同步）
- 轨道倾角：0°（赤道上空）
- 覆盖范围：单颗卫星约覆盖地球表面 42%

**特点：**
- 相对地面静止，地面天线无需跟踪
- 覆盖范围广，三颗卫星可实现全球覆盖（除两极）
- 传播延迟大：单向约 250-280ms
- 路径损耗大，需要较大的发射功率
- 轨道资源有限，国际电信联盟（ITU）统一分配

**安全考量：**
- 轨道位置固定，容易被定位和瞄准
- 单颗卫星价值高，一旦受损影响大
- 信号覆盖范围广，容易被窃听
- 反卫星武器的重点目标

**典型应用：**
- 通信卫星（如中国卫通、Intelsat）
- 气象卫星（如风云二号、GOES）
- 广播卫星（电视直播）
- 军事通信卫星

#### 1.1.2 MEO（中地球轨道）

**基本参数：**
- 轨道高度：约 2,000 - 35,786 公里
- 轨道周期：约 2 - 24 小时
- 典型高度：导航卫星约 20,000 公里左右

**特点：**
- 覆盖范围适中，需要多颗卫星组成星座
- 延迟较低（相对于 GEO）
- 轨道周期适中，卫星相对地面移动

**安全考量：**
- 星座分布广，单颗受损影响相对有限
- 信号到达地面功率低，容易受到干扰
- 导航信号公开透明，存在欺骗风险

**典型应用：**
- GPS（美国）：约 20,180 公里，6 轨道面，24+ 颗卫星
- 北斗 MEO 卫星：约 21,500 公里
- GLONASS（俄罗斯）：约 19,130 公里
- Galileo（欧盟）：约 23,222 公里

#### 1.1.3 LEO（低地球轨道）

**基本参数：**
- 轨道高度：约 160 - 2,000 公里
- 轨道周期：约 90 - 120 分钟
- 速度：约 7.8 km/s

**特点：**
- 延迟低：单向约 20-50ms
- 路径损耗小
- 单颗覆盖范围小，需要大规模星座
- 卫星高速运动，需要频繁切换
- 发射成本相对较低

**安全考量：**
- 星座规模大，分布式架构，抗毁性强
- 卫星数量多，单颗损失影响小
- 星间链路复杂，安全管理难度大
- 快速切换带来认证和密钥管理挑战
- 太空碎片威胁更大

**典型应用：**
- 卫星互联网：Starlink、OneWeb、星网、鸿雁
- 遥感卫星：高分系列、Landsat
- 通信星座：铱星（Iridium）、Globalstar
- 空间站：国际空间站（ISS）、天宫空间站

#### 1.1.4 其他轨道类型

| 轨道类型 | 英文缩写 | 高度/特点 | 典型应用 |
|---------|---------|-----------|---------|
| 太阳同步轨道 | SSO | 约 600-800km，轨道面与太阳同步 | 遥感卫星、气象卫星 |
| 地球同步转移轨道 | GTO | 椭圆轨道，近地点约 200km，远地点约 36000km | GEO 卫星转移 |
| 极轨道 | PO | 经过南北极，倾角约 90° | 遥感、侦察卫星 |
| 大椭圆轨道 | HEO | 远地点高、近地点低 | 通信（高纬度覆盖） |
| 中地球轨道 | MEO | 2000-35786km | 导航卫星 |
| 超同步轨道 | - | 高于 GEO | 部分军事卫星 |

### 1.2 卫星系统组成

一个完整的卫星系统由空间段、地面段和用户段三大部分组成。

```
┌─────────────────────────────────────────────────────────────┐
│                        用户段 (User Segment)                  │
│  卫星手机  卫星电视  GPS终端  卫星互联网终端  遥感数据用户     │
└──────────────────────────┬──────────────────────────────────┘
                           │ 上行/下行链路
┌──────────────────────────▼──────────────────────────────────┐
│                        空间段 (Space Segment)                 │
│   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐     │
│   │ 卫星1│   │ 卫星2│   │ 卫星3│   │ 卫星4│   │ 卫星5│ ... │
│   └──┬───┘   └──┬───┘   └──┬───┘   └──┬───┘   └──┬───┘     │
│      └──────────┴────星间链路────┴──────────┴──────────┘    │
└──────────────────────────┬──────────────────────────────────┘
                           │ 测控/通信链路
┌──────────────────────────▼──────────────────────────────────┐
│                        地面段 (Ground Segment)                │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │ 测控站  │  │ 关口站  │  │ 数据接收│  │ 控制中心│  ...    │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘         │
└─────────────────────────────────────────────────────────────┘
```

#### 1.2.1 空间段（Space Segment）

**组成部分：**
- 卫星平台（卫星本体）
- 有效载荷（通信载荷、导航载荷、遥感载荷等）
- 卫星星座（多颗卫星组成的网络）

**卫星平台子系统：**
| 子系统 | 功能 | 安全相关 |
|-------|------|---------|
| 结构系统 | 卫星骨架和外壳 | 抗辐射、抗碎片 |
| 热控系统 | 温度控制 | 过热保护、异常检测 |
| 电源系统 | 太阳能电池、蓄电池 | 电源安全、防过载 |
| 姿态控制系统 | 卫星姿态稳定和控制 | 防失控、姿态安全 |
| 轨道控制系统 | 轨道维持和变轨 | 防轨道偏离、防撞 |
| 测控通信系统 | 与地面通信 | 链路加密、认证 |
| 星载计算机 | 星上数据处理 | 软件安全、防篡改 |

**有效载荷：**
- **通信载荷**：转发器、天线、功率放大器
- **导航载荷**：原子钟、导航信号发生器、发射天线
- **遥感载荷**：光学相机、合成孔径雷达（SAR）、光谱仪
- **科学载荷**：各种科学探测仪器

#### 1.2.2 地面段（Ground Segment）

**主要组成：**

| 地面设施 | 功能 | 安全等级 |
|---------|------|---------|
| 卫星控制中心（SCC） | 卫星运行控制、任务规划 | 最高 |
| 测控站（TT&C） | 卫星跟踪、遥测、遥控 | 高 |
| 关口站/网关站 | 卫星互联网网关、数据交换 | 高 |
| 数据接收站 | 遥感/气象数据接收 | 中-高 |
| 导航监测站 | 导航信号监测、星历计算 | 中 |
| 运行管理中心 | 网络管理、用户管理 | 高 |

**关键设备：**
- 大口径天线（测控、通信）
- 发射机/接收机（高功率）
- 基带处理设备
- 服务器和网络设备
- 电源系统（含 UPS）
- 空调和冷却系统

#### 1.2.3 用户段（User Segment）

**用户终端类型：**
- 卫星电视接收天线（"锅"）
- 卫星电话终端
- GPS/北斗接收机
- 卫星互联网终端（Starlink 天线等）
- 车载/船载/机载卫星通信终端
- 卫星物联网终端

**安全特点：**
- 数量庞大，分布广泛
- 安全能力参差不齐
- 容易成为攻击切入点
- 物理安全难以保证

## 二、卫星网络架构

### 2.1 空间段网络

#### 2.1.1 单星系统

传统的 GEO 通信卫星多为单星或少量卫星组网，星间没有直接连接，所有通信都通过地面站中转。

**特点：**
- 结构简单
- 星上处理简单
- 依赖地面站
- 延迟较高（双跳）

**安全特点：**
- 攻击面相对较少
- 地面站是关键节点
- 链路数量有限，易于监控

#### 2.1.2 星座系统

现代 LEO 卫星互联网采用大规模星座，通过星间链路（ISL）实现卫星之间的直接通信。

**星座网络特点：**
- 分布式架构
- 动态拓扑（卫星高速运动）
- 星间路由
- 快速切换
- 冗余路径

**安全挑战：**
- 动态密钥管理困难
- 星间链路认证复杂
- 路由安全（恶意节点、路由欺骗）
- 快速切换时的安全上下文传递
- 分布式攻击检测

#### 2.1.3 典型星座架构

**Starlink 架构：**
- 数千颗 LEO 卫星，分布在多个轨道面
- 星间激光链路
- 地面关口站接入互联网
- 用户终端通过相控阵天线连接

**北斗系统架构：**
- GEO + IGSO + MEO 混合星座
- 区域增强系统
- 地面运控系统
- 各类用户终端

### 2.2 地面段网络

#### 2.2.1 地面站网络拓扑

```
                    ┌──────────────┐
                    │  卫星控制中心  │
                    └──────┬───────┘
                           │ 专线
              ┌────────────┼────────────┐
              │            │            │
        ┌─────▼─────┐ ┌───▼─────┐ ┌────▼─────┐
        │  测控站 A  │ │ 测控站 B │ │ 测控站 C │
        └─────┬─────┘ └───┬─────┘ └────┬─────┘
              │            │            │
              └────────────┼────────────┘
                           │
                    ┌──────▼──────┐
                    │   卫星星座    │
                    └─────────────┘
```

#### 2.2.2 地面站网络安全分区

按照等保 2.0 和相关标准，地面站网络通常划分为以下安全区域：

| 安全区域 | 包含系统 | 安全等级 | 隔离要求 |
|---------|---------|---------|---------|
| 控制区 | 卫星控制、指令生成 | 等保四级 | 物理隔离 |
| 测控区 | 测控设备、基带 | 等保三级 | 严格隔离 |
| 数据区 | 数据处理、存储 | 等保三级 | 逻辑隔离 |
| 办公区 | 办公网络 | 等保二级 | 严格隔离 |
| 外网区 | 互联网接入 | - | 防火墙隔离 |

### 2.3 用户段接入

#### 2.3.1 接入方式

| 接入方式 | 特点 | 典型应用 |
|---------|------|---------|
| 单向接收 | 只收不发 | 卫星电视、GPS、广播 |
| 双向通信 | 收发都有 | 卫星电话、卫星互联网 |
| 间歇连接 | 非实时连通 | 遥感数据回传、物联网 |

#### 2.3.2 用户认证模型

- 预共享密钥（PSK）
- 证书认证
- 用户名/密码
- SIM 卡认证（类移动通信）

## 三、卫星通信链路

### 3.1 链路类型

#### 3.1.1 上行链路（Uplink）

**定义：** 地面站 → 卫星的通信链路

**特点：**
- 地面发射功率大
- 上行频率通常高于下行
- 点对多点（多个地面站到一颗卫星）

**安全威胁：**
- 未授权上行（非法发送指令）
- 指令篡改
- 重放攻击
- 上行干扰
- 冒充地面站

**防护措施：**
- 指令加密
- 消息认证码（MAC）
- 时间戳和序列号
- 身份认证
- 访问控制
- 异常检测（上行信号监测）

#### 3.1.2 下行链路（Downlink）

**定义：** 卫星 → 地面的通信链路

**特点：**
- 广播特性（一个发射，多个接收）
- 卫星发射功率受限
- 容易被窃听

**安全威胁：**
- 信号窃听（被动攻击，难以发现）
- 数据泄露
- 下行干扰
- 信号欺骗（伪造下行信号）

**防护措施：**
- 数据加密
- 信号认证
- 抗干扰技术
- 防欺骗技术

#### 3.1.3 星间链路（Inter-Satellite Link, ISL）

**定义：** 卫星与卫星之间的通信链路

**技术方式：**
- 微波链路
- 激光链路（星间激光通信）

**特点：**
- 高速率（激光可达 Gbps 级）
- 距离远（几百到几千公里）
- 动态建立和断开
- 方向性强（激光）

**安全挑战：**
- 密钥分发困难
- 快速认证需求
- 动态路由安全
- 激光链路对准安全
- 星间窃听（激光相对安全）

### 3.2 通信频段

卫星通信使用的频段由国际电信联盟（ITU）统一分配和管理。

| 频段 | 频率范围 | 典型应用 | 波长 | 传播特性 |
|-----|---------|---------|------|---------|
| VHF | 30-300 MHz | 卫星测控、业余卫星 | 1-10m | 绕射能力强，带宽低 |
| UHF/L | 300MHz-2GHz | 导航、移动卫星 | 0.15-1m | 穿透能力较好 |
| S | 2-4 GHz | 气象、通信、测控 | 7.5-15cm | 适中 |
| C | 4-8 GHz | 通信、电视广播 | 3.75-7.5cm | 雨衰小，稳定 |
| X | 8-12 GHz | 军事、遥感 | 2.5-3.75cm | 带宽较高 |
| Ku | 12-18 GHz | 卫星电视、VSAT | 1.67-2.5cm | 雨衰较大 |
| Ka | 26-40 GHz | 高速通信、卫星互联网 | 0.75-1.15cm | 带宽高，雨衰大 |
| Q/V | 33-75 GHz | 未来高速通信 | 0.4-0.9cm | 极高带宽，雨衰很大 |

**安全相关特点：**
- 频率越高，带宽越大，但定向性越强，窃听难度相对较高
- 频率越低，绕射能力越强，覆盖范围越广，越容易被窃听
- 军事通信通常使用专用频段，并有加密和抗干扰设计

### 3.3 链路预算基础

链路预算是评估卫星通信链路性能的基本方法，也是分析干扰和窃听可行性的基础。

**基本公式：**
```
接收功率 (Pr) = 发射功率 (Pt) + 发射天线增益 (Gt) + 接收天线增益 (Gr) - 路径损耗 (Lp) - 其他损耗
```

**自由空间路径损耗：**
```
Lp = 20 * log10(4πd/λ)
```
其中 d 为距离，λ 为波长。

**安全意义：**
- 计算窃听所需的接收灵敏度
- 评估干扰所需的发射功率
- 分析不同距离下的信号强度
- 设计抗干扰链路余量

## 四、卫星通信协议与标准

### 4.1 CCSDS 标准

#### 4.1.1 CCSDS 概述

**空间数据系统咨询委员会（Consultative Committee for Space Data Systems, CCSDS）** 是一个由各航天机构组成的国际组织，负责制定空间数据系统标准。

**成立时间：** 1982 年
**成员：** NASA、ESA、CNSA、JAXA 等主要航天机构
**目标：** 实现空间数据系统的标准化和互操作

#### 4.1.2 CCSDS 协议栈

```
┌─────────────────────────────────────┐
│         应用层 (Application)         │  CCSDS 应用数据
├─────────────────────────────────────┤
│         网络层 (Network)             │  SCPS-NP (空间通信协议规范-网络层)
├─────────────────────────────────────┤
│         传输层 (Transport)           │  SCPS-TP (可靠传输)
├─────────────────────────────────────┤
│         数据链路层 (Data Link)       │  TM/TC/AOS 帧
├─────────────────────────────────────┤
│         物理层 (Physical)            │  射频、调制、编码
└─────────────────────────────────────┘
```

#### 4.1.3 CCSDS 主要协议

**遥测协议（TM, Telemetry）：**
- 卫星 → 地面 的下行数据
- 传送卫星状态和载荷数据
- 帧结构：主导头 + 数据域 + 帧尾
- 版本号、航天器 ID、虚拟信道 ID

**遥控协议（TC, Telecommand）：**
- 地面 → 卫星 的上行指令
- 控制卫星运行
- 有严格的认证和安全机制
- 指令类型：实时指令、块指令

**高级在轨系统（AOS, Advanced Orbit Systems）：**
- 高速数据传输
- 支持多种业务复用
- 用于遥感、通信卫星

**安全相关协议：**
- SCPS-SP（安全协议）：提供认证、加密、完整性保护
- 认证框架：基于证书的身份认证
- 密钥管理协议

#### 4.1.4 CCSDS 安全框架

| 安全服务 | 实现方式 | 说明 |
|---------|---------|------|
| 机密性 | 加密（AES 等） | 保护数据不被窃听 |
| 完整性 | MAC / 数字签名 | 检测数据篡改 |
| 认证 | 身份认证协议 | 验证通信双方身份 |
| 不可否认 | 数字签名 | 防止抵赖 |
| 访问控制 | 权限管理 | 控制对资源的访问 |

### 4.2 DVB-S/S2 标准

#### 4.2.1 DVB-S 概述

**数字视频广播-卫星（Digital Video Broadcasting - Satellite）** 是卫星电视广播的主流标准。

- **DVB-S**：第一代，1994 年发布
- **DVB-S2**：第二代，2005 年发布，效率提升约 30%
- **DVB-S2X**：DVB-S2 的扩展，更高效率

#### 4.2.2 DVB-S2 关键技术

| 技术 | 说明 | 安全相关 |
|-----|------|---------|
| 调制方式 | QPSK, 8PSK, 16APSK, 32APSK | 高阶调制抗干扰能力较弱 |
| 信道编码 | LDPC + BCH | 前向纠错，抗干扰 |
| 自适应编码调制 | ACM/VCM | 根据链路质量动态调整 |
| 多输入多输出 | MIMO（部分模式） | 提高容量和抗干扰 |
| 加扰 | 能量扩散加扰 | 不是加密，仅用于频谱整形 |

#### 4.2.3 DVB 条件接收系统（CAS）

**条件接收（Conditional Access）** 是卫星电视付费业务的安全机制：

- **加扰（Scrambling）：** 对音视频数据进行加扰处理
- **控制字（CW, Control Word）：** 加扰密钥，周期性更新
- **授权控制信息（ECM）：** 加密的控制字
- **授权管理信息（EMM）：** 用户授权信息
- **智能卡：** 解密 ECM 和 EMM，输出 CW

**安全威胁：**
- 智能卡破解（盗版卡）
- CW 共享网络
- 信号盗收
- 中间人攻击

### 4.3 其他重要标准

| 标准组织 | 相关标准 | 应用领域 |
|---------|---------|---------|
| ITU-R | 卫星频谱管理、固定卫星业务 | 频谱分配、国际协调 |
| 3GPP | NTN（非地面网络）、卫星 5G/6G | 卫星与地面通信融合 |
| IEEE | 卫星通信相关标准 | 技术规范 |
| IETF | IP over Satellite、TCP 性能增强 | 卫星互联网 |
| ISO | 信息安全管理体系 | 安全管理 |

## 五、卫星网络安全威胁与挑战

### 5.1 威胁模型

#### 5.1.1 按攻击层面分类

```
┌─────────────────────────────────────────┐
│           应用层威胁                     │
│  数据篡改、恶意软件、未授权访问           │
├─────────────────────────────────────────┤
│           网络层威胁                     │
│  DDoS、路由攻击、中间人、DNS 劫持        │
├─────────────────────────────────────────┤
│           链路层威胁                     │
│  协议攻击、帧注入、重放攻击              │
├─────────────────────────────────────────┤
│           物理层/信号层威胁              │
│  干扰、欺骗、窃听、信号截获              │
├─────────────────────────────────────────┤
│           物理/环境威胁                  │
│  反卫星武器、太空碎片、自然灾害           │
└─────────────────────────────────────────┘
```

#### 5.1.2 按攻击目的分类

| 攻击类型 | 目的 | 典型手段 |
|---------|------|---------|
| 拒绝服务 | 使系统无法正常工作 | 干扰攻击、DDoS、物理破坏 |
| 窃取信息 | 获取敏感信息 | 窃听、数据泄露、网络入侵 |
| 篡改控制 | 控制系统或数据 | 欺骗攻击、指令篡改、未授权控制 |
| 降级服务 | 降低服务质量 | 部分干扰、性能下降攻击 |
| 经济利益 | 获取经济收益 | 盗收卫星电视、盗用通信资源 |

### 5.2 关键安全挑战

#### 5.2.1 卫星系统固有脆弱性

1. **广播特性**：卫星信号天然具有广播性，下行信号任何人都可以接收，窃听门槛低
2. **长距离传输**：信号经过长距离传输，到达地面时功率极低，容易被干扰
3. **物理不可达**：卫星在太空，物理安全难以保障，出现问题难以现场修复
4. **资源受限**：星上计算、存储、功率资源有限，难以部署复杂的安全机制
5. **生命周期长**：卫星设计寿命 10-15 年，安全技术可能过时
6. **发射前不可更新**：卫星发射后固件更新困难且有风险

#### 5.2.2 供应链安全挑战

- 卫星组件供应链长，涉及全球众多供应商
- 商业现货（COTS）组件广泛使用，安全难以保证
- 芯片、操作系统、软件都可能存在后门
- 难以对所有组件进行全面安全检测

#### 5.2.3 卫星互联网新挑战

1. **规模庞大**：数万颗卫星，管理复杂度高
2. **动态拓扑**：卫星高速运动，网络拓扑快速变化
3. **星间链路**：新增的攻击面，密钥管理困难
4. **快速切换**：用户在卫星间频繁切换，认证挑战大
5. **终端数量大**：海量用户终端，安全管理难
6. **与地面网络融合**：攻击可以跨网络传播

### 5.3 威胁行为体分析

| 威胁行为体 | 能力等级 | 典型动机 | 典型攻击 |
|-----------|---------|---------|---------|
| 业余爱好者 | 低 | 好奇、学习 | 简单信号接收、低功率干扰 |
| 黑客组织 | 中 | 知名度、经济利益 | 地面站入侵、数据窃取 |
| 犯罪组织 | 中-高 | 经济利益 | 信号盗收、敲诈勒索 |
| 恐怖组织 | 中-高 | 破坏、恐吓 | 关键设施干扰、通信中断 |
| 国家级 | 极高 | 战略利益、情报 | 高级干扰、欺骗、网络攻击、反卫星 |
| 内部人员 | 中-高 | 报复、经济利益 | 未授权访问、数据泄露 |

## 六、著名卫星安全事件

### 6.1 导航安全事件

#### 6.1.1 2011 年伊朗捕获美国 RQ-170 无人机事件

**事件概述：**
2011 年 12 月，伊朗宣布"俘获"一架美国 RQ-170"哨兵"隐身无人机，无人机基本完好无损地降落在伊朗境内。

**技术分析（推测）：**
- 伊朗可能使用了 GPS 欺骗技术（GPS Spoofing）
- 通过发射伪造的 GPS 信号，使无人机误判自身位置
- 无人机根据错误的 GPS 信息飞向了错误的地点
- 据称使用了从俄罗斯引进的电子战设备

**安全意义：**
- 首次公开的重大 GPS 欺骗军事应用案例
- 暴露了 GPS 导航系统的脆弱性
- 推动了 GPS 抗欺骗技术的发展
- 促使各国加强导航安全研究

**争议：**
- 美方未明确承认是 GPS 欺骗导致
- 有分析认为可能是通信干扰+自动驾驶失效
- 也有观点认为是机械故障导致坠落

#### 6.1.2 2019 年 GPS 干扰事件（中东地区）

**事件概述：**
2019 年，地中海东部和中东地区出现大范围 GPS 信号异常，多个航班报告 GPS 信号丢失或不稳定。

**影响范围：**
- 以色列、黎巴嫩、塞浦路斯附近海域
- 影响民航、海事、通用航空
- 部分船舶导航系统受影响

**原因分析：**
- 据信是某国在军事行动中使用 GPS 干扰设备
- 干扰信号波及周边地区
- 军用 GPS 干扰设备功率大，影响范围广

**安全警示：**
- GPS 干扰的影响范围可能远超预期
- 民用基础设施对 GPS 依赖严重
- 需要发展多源导航和抗干扰技术

#### 6.1.3 黑海地区 GPS 干扰事件（多次）

**事件概述：**
近年来，黑海地区多次出现 GPS 干扰事件，影响船舶和飞机导航。

**特点：**
- 干扰源据称来自克里米亚地区
- 干扰功率大，影响范围广
- 与军事活动时间高度相关

**影响：**
- 船舶导航系统异常
- 航空导航受影响
- 渔船作业受干扰

### 6.2 通信安全事件

#### 6.2.1 "老虎机"卫星通信窃听事件（公开报道）

**背景：**
在一些冲突地区，卫星通信被广泛用于军事和民用通信。由于卫星通信的广播特性，信号可以被广泛接收。

**技术细节：**
- 使用卫星接收设备接收下行信号
- 对未加密或弱加密的通信进行解密
- 获取语音、数据、视频等通信内容
- 一些军用卫星通信使用了不当的加密配置

**教训：**
- 卫星通信默认是广播的，机密通信必须强加密
- 加密算法和密钥管理至关重要
- 老旧卫星系统的加密强度可能不足

#### 6.2.2 卫星电视干扰事件

**事件类型：**
- 政治性质的信号插播
- 宗教宣传信号干扰
- 商业竞争导致的干扰

**技术手段：**
- 上行干扰：在相同频率发射更强的信号
- 插播：劫持上行链路，替换节目内容

**法律性质：**
- 违反无线电管理法规
- 违反国际电信联盟规则
- 严重的可能构成犯罪

### 6.3 网络攻击事件

#### 6.3.1 2014-2015 年太空黑客事件（报道）

**事件概述：**
据公开报道，有黑客组织多次尝试入侵卫星地面站和卫星运营商网络。

**攻击方式：**
- 钓鱼邮件获取员工凭证
- 利用网络设备漏洞
- 社会工程学攻击
- 供应链攻击

**安全警示：**
- 地面站网络安全防护不足
- 人员安全意识需要提高
- 供应链安全是薄弱环节

#### 6.3.2 2022 年 Viasat 卫星通信被攻击事件

**事件概述：**
2022 年 2 月，美国卫星通信公司 Viasat 的 KA-SAT 网络遭到网络攻击，导致欧洲部分地区的卫星互联网服务中断。

**攻击细节：**
- 攻击目标是地面网络基础设施
- 通过利用 VPN 设备漏洞进入网络
- 向卫星终端发送恶意指令
- 导致大量终端调制解调器脱网
- 影响范围包括乌克兰及欧洲其他地区

**影响：**
- 数千用户卫星互联网中断
- 部分风能发电站远程监控受影响
- 军事和政府通信受影响

**安全意义：**
- 卫星通信网络是关键基础设施
- 地面段网络攻击可以产生大规模影响
- 卫星终端安全需要重视
- 国家级网络攻击的新战场

### 6.4 反卫星与太空安全事件

#### 6.4.1 2007 年中国反卫星试验

**事件概述：**
2007 年 1 月 11 日，中国进行了一次反卫星试验，使用动能杀伤飞行器摧毁了一颗报废的风云-1C 气象卫星。

**技术参数：**
- 靶星：风云-1C，轨道高度约 865 公里
- 拦截方式：动能撞击（直接上升式）
- 结果：卫星完全碎裂

**影响：**
- 产生了大量太空碎片（数千块可跟踪碎片）
- 对其他卫星和太空资产构成长期威胁
- 引发国际社会对太空军备竞赛的担忧
- 推动了太空碎片治理讨论

#### 6.4.2 2021 年俄罗斯反卫星试验

**事件概述：**
2021 年 11 月 15 日，俄罗斯进行了一次反卫星试验，摧毁了一颗报废的 Tselina-D 系列电子侦察卫星（Kosmos-1408）。

**影响：**
- 产生超过 1,500 块可跟踪碎片
- 国际空间站（ISS）航天员被迫进入避难舱
- 增加了低轨卫星碰撞风险

**国际反应：**
- 美国等国家强烈谴责
- 联合国讨论太空安全问题
- 呼吁禁止反卫星试验

#### 6.4.3 2019 年印度反卫星试验

**事件概述：**
2019 年 3 月 27 日，印度进行了首次反卫星试验（"沙克提任务"），成功击落一颗低轨卫星。

**参数：**
- 靶星高度：约 300 公里
- 拦截方式：动能撞击
- 印度称为"低高度"试验，碎片会很快再入大气层

### 6.5 卫星故障与异常事件

#### 6.5.2 卫星异常事件（公开案例）

**GPS 星座异常：**
- 2019 年 1 月，GPS 系统发生异常，导致部分用户设备时间计算错误
- 原因是 GPS 地面控制系统软件问题
- 影响了一些依赖 GPS 时间同步的系统

**铱星碰撞事件：**
- 2009 年 2 月，美国铱星 33 与俄罗斯报废卫星 Kosmos-2251 在西伯利亚上空相撞
- 两颗卫星完全损毁
- 产生大量太空碎片
- 这是首次完整卫星之间的碰撞事件

## 七、本章小结

1. **卫星系统基础**：卫星按轨道分为 GEO、MEO、LEO 等，不同轨道有不同的应用和安全特点
2. **三段架构**：卫星系统由空间段、地面段、用户段组成，各段有不同的安全挑战
3. **三类链路**：上行、下行、星间链路各有特点，安全威胁和防护措施各不相同
4. **协议标准**：CCSDS 是航天领域主流标准，DVB-S/S2 是卫星广播标准，都有相应的安全机制
5. **安全威胁**：从物理层到应用层，卫星系统面临全方位的安全威胁
6. **安全事件**：从 GPS 欺骗到反卫星试验，卫星安全事件层出不穷，安全形势严峻
