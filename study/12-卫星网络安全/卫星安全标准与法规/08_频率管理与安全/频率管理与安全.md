# 频率管理与安全

### 8.1 频率安全要求

```
卫星频率安全要求:

1. 频率协调
   - 国际频率协调(ITU)
   - 避免有害干扰
   - 优先权保护

2. 发射功率限制
   - EIRP限制
   - 功率谱密度限制
   - 偏轴辐射限制

3. 地球站安全
   - 选址要求
   - 干扰保护
   - 天线方向限制

4. 紧急频率保护
   - 安全通信频率
   - 紧急业务优先
   - 干扰零容忍

5. 频谱监测
   - 非法发射检测
   - 干扰源定位
   - 频谱合规检查
```

### 8.2 中国卫星频率管理

```
中国卫星频率管理体系:

法规依据:
• 《中华人民共和国无线电管理条例》
• 《卫星网络空间业务申报管理办法》
• 《卫星频率和轨道资源管理办法》

管理流程:
1. 频率规划 → 国家频率分配表
2. 频率申请 → 向工信部无线电管理局申请
3. 国际协调 → ITU频率协调
4. 频率许可 → 取得频率使用许可证
5. 频率使用 → 遵守使用条件
6. 频率监测 → 合规监督检查
7. 频率保护 → 干扰投诉和处理

安全要求:
• 不得干扰已授权系统
• 紧急频率严格保护
• 发射功率不得超过许可
• 不得改变授权参数
```
