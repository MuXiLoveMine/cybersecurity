```
┌─────────────────────────────────────────┐
│       ISO 27001控制域 → 卫星应用          │

│  A.5 信息安全政策                       │

│  A.6 组织信息安全                       │

│  → 卫星安全委员会                        │
│                                        │
│  A.7 人力资源安全                       │
│  → 卫星工程师安全审查                    │
│  → 涉密人员管理                         │
│                                        │
│  A.8 资产管理                           │
│  → 卫星资产分类                         │
│  → 遥感/通信数据分级                    │
│                                        │
│  A.9 访问控制                           │
│  → 地面站访问控制                       │
│  → 指令系统权限管理                     │
│                                        │
│  A.10 密码学                            │
│  → 链路加密体系                         │
│  → 密钥管理全生命周期                    │
│                                        │
│  A.11 物理与环境安全                     │
│  → 地面站物理安全                       │
│  → 发射场安全                           │
│                                        │
│  A.12 运营安全                          │
│  → 卫星运营安全程序                      │
│  → 在轨安全管理                         │
│                                        │
│  A.13 通信安全                          │
│  → 上下行链路安全                       │
│  → 星间链路安全                         │
│                                        │
│  A.14 系统获取/开发/维护                 │
│  → 卫星安全开发                         │
│  → 供应链安全                           │
│                                        │
│  A.15 供应商关系                        │
│  → 卫星供应商评估                       │

│                                        │

│                                        │

│  → 法规合规检查                         │
│  → 审计跟踪                             │
```

```
┌─────────────────────────────────────────────────┐
│              NIST CSF → 卫星安全                  │

│                                                  │
│  IDENTIFY (识别)                                 │

└─────────────────────────────────────────────────┘
```
