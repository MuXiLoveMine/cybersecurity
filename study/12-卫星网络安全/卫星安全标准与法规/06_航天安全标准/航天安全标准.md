# 航天安全标准

### 6.1 CCSDS标准

```
CCSDS (Consultative Committee for Space Data Systems):

CCSDS是国际航天数据系统标准化组织

安全相关CCSDS建议书:

┌───────────────────────────────────────────────┐
│                CCSDS安全标准                    │
├───────────────────────────────────────────────┤
│                                                │
│  1. CCSDS 355.0-B-2                           │
│     "CCSDS Space Data Link Security Protocol" │
│     空间数据链路安全协议                        │
│     - 链路层加密和认证                          │
│     - 适用于所有空间数据链路                    │
│                                                │
│  2. CCSDS 356.0-B-1                           │
│     "CCSDS Cryptographic Algorithms"          │
│     密码算法选择                                │
│     - AES-256                                  │
│     - SHA-256                                  │
│     - HMAC-SHA-256                             │
│                                                │
│  3. CCSDS 358.0-B-1                           │
│     "Authentication and Integrity             │
│      Mechanisms for Space Data Links"         │
│     空间数据链路认证和完整性机制                  │
│                                                │
│  4. CCSDS 916.1-B-1                           │
│     "Spacecraft Onboard Interface Services"   │
│     航天器在板接口服务安全                      │
│                                                │
└───────────────────────────────────────────────┘
```
