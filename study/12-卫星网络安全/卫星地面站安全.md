## 1. 卫星地面站概述

### 1.1 地面站定义与作用

卫星地面站（Ground Station, GS）是地面与卫星之间进行通信、控制、数据传输的核心设施。它是整个卫星系统中唯一与公共网络直接连接的环节，因此成为安全防护的重点：

```
卫星系统三大组成部分:

┌─────────────────────────────────────────┐
│            空间段 (Space Segment)       │
│  ┌───┐ ┌───┐ ┌───┐                     │
│  │SAT1│ │SAT2│ │SAT3│  卫星星座         │
│  └─┬─┘ └─┬─┘ └─┬─┘                     │
└────┼─────┼─────┼────────────────────────┘
     │     │     │  上下行链路
┌────┼─────┼─────┼────────────────────────┐
│    │     │     │    地面段 (Ground)      │
│  ┌─┴─────┴─────┴─┐                       │
│  │   地面站网络   │  ← 唯一与公共网络连接  │
│  │ ┌───────────┐ │                       │
│  │ │ 天线系统   │ │                       │
│  │ │ 基带处理   │ │                       │
│  │ │ 运行管理   │ │                       │
│  │ │ 数据处理   │ │                       │
│  │ └───────────┘ │                       │
│  └───────┬───────┘                       │
└──────────┼──────────────────────────────┘
           │
┌──────────┼──────────────────────────────┐
│          │     用户段 (User Segment)     │
│    ┌─────┴─────┐                          │
│    │  用户终端   │  卫星电话/电视/数据      │
│    └───────────┘                          │
└──────────────────────────────────────────┘
```

### 1.2 地面站类型

| 类型 | 功能 | 安全等级 | 典型设施 |
|------|------|---------|---------|
| TT&C站 | 遥测、跟踪、指令 | 最高 | 测控中心 |
| 关口站 | 网络控制、关口管理 | 高 | 通信卫星地面站 |
| 测控站 | 卫星测轨、姿态控制 | 最高 | 深空测控网 |
| 数据接收站 | 遥感数据接收 | 中高 | 遥感卫星数据站 |
| 用户站 | 终端用户通信 | 中 | VSAT终端 |
| 监测站 | 频谱监测、信号质量 | 中 | 频谱监测站 |

### 1.3 地面站安全的重要性

```
地面站安全为什么至关重要:

1. 唯一地面接口
   - 所有卫星指令通过地面站发送
   - 控制地面站 = 控制卫星
   - 影响整个卫星星座

2. 高价值目标
   - 设备价值: 数千万至数十亿
   - 数据价值: 军事/气象/通信数据
   - 战略价值: 国家基础设施

3. 攻击面广泛
   - 网络接口: 与公共网络连接
   - 射频接口: 开放的天空
   - 物理接口: 地面设施可达
   - 供应链: 设备来自多个供应商

4. 历史教训
   - 1999年: 银行黑客控制卫星
   - 2007年: 解放军激光致盲卫星
   - 2018年: 海事卫星被干扰
   - 2022年: GPS欺骗攻击频发
```

## 4. 天线与射频子系统安全

### 4.1 射频安全威胁

```
射频子系统的安全威胁:

1. 射频干扰 (RF Jamming)
   - 压制性干扰: 大功率信号压制正常信号
   - 欺骗性干扰: 发射伪造信号欺骗接收机
   - 扫频干扰: 在宽频带内快速切换干扰频率
   - 脉冲干扰: 发射高功率脉冲信号

2. 信号注入
   - 上行注入: 向卫星发送伪造指令信号
   - 下行截获: 截获卫星下行信号进行分析
   - 中继攻击: 转发并修改卫星信号

3. 信号截获
   - 被动截获: 不发射信号，仅接收分析
   - 信号分析: 分析调制方式、编码特征
   - 流量分析: 通过信号模式推断通信内容

4. 物理破坏
   - 天线损坏: 物理破坏天线系统
   - 馈源遮挡: 阻挡天线馈源
   - 线缆切断: 切断射频线缆
```

### 4.2 射频安全防护

```
射频安全防护措施:

1. 频率跳变
   - 使用跳频扩频(FHSS)技术
   - 随机跳变频率，避免干扰
   - 需要收发同步跳频

2. 波束成形
   - 使用自适应波束成形天线
   - 将零陷对准干扰源
   - 提高信号抗干扰能力

3. 信号加密
   - 上行链路: 指令加密+认证
   - 下行链路: 遥测数据加密
   - 使用强加密算法(AES-256)

4. 功率控制
   - 自动功率控制(APC)
   - 干扰检测自动调整
   - 冗余功率储备

5. 多站接收
   - 多地面站分集接收
   - 空间分集对抗干扰
   - 信号融合处理

6. 频谱监测
   - 实时频谱分析
   - 异常信号检测
   - 干扰源定位
```

## 5. 基带处理与数据链路安全

### 5.1 基带处理安全

```
基带处理链路安全:

卫星 ←→ 天线 ←→ LNA/HPA ←→ 变频器 ←→ 调制解调 ←→ 加密解密 ←→ 网络
                                                    ↑
                                              安全关键节点

基带安全要求:
1. 链路加密: 所有上下行数据必须加密
2. 认证机制: 确保数据来源可信
3. 完整性: 防止数据被篡改
4. 防重放: 防止指令重放
5. 密钥管理: 安全的密钥分发和更新
```

### 5.2 加密链路设计

```python
# 卫星链路加密设计
class SatelliteLinkCrypto:
    """卫星链路加密系统"""

    # 加密算法选择
    CRYPTO_CONFIG = {
        'uplink': {
            'encryption': 'AES-256-GCM',
            'authentication': 'HMAC-SHA256',
            'key_length': 256,
            'rekey_interval': 3600,  # 1小时
            'anti_replay': True,
        },
        'downlink': {
            'encryption': 'AES-256-CBC',
            'authentication': 'AES-CMAC',
            'key_length': 256,
            'rekey_interval': 3600,
            'anti_replay': True,
        },
        'command': {
            'encryption': 'AES-256-GCM',
            'authentication': 'ECDSA-P256',
            'key_length': 256,
            'rekey_interval': 1800,  # 30分钟(更频繁)
            'anti_replay': True,
            'multi_sign': True,  # 多重签名
        },
    }

    def __init__(self):
        self.session_keys = {}
        self.sequence_numbers = {}
        self.key_store = None  # HSM连接

    def encrypt_uplink(self, data: bytes, satellite_id: str) -> bytes:
        """加密上行数据"""
        key = self.session_keys.get(f'{satellite_id}_up')
        if not key:
            raise ValueError("无有效上行密钥")

        seq_num = self.sequence_numbers.get(satellite_id, 0)

        # 构造加密包
        # 格式: 序号(4B) + IV(12B) + 密文 + Tag(16B)
        iv = os.urandom(12)

        # GCM加密
        cipher = AESGCM(key)
        ciphertext = cipher.encrypt(iv, data, str(seq_num).encode())

        packet = struct.pack('>I', seq_num) + iv + ciphertext

        self.sequence_numbers[satellite_id] = seq_num + 1
        return packet

    def decrypt_downlink(self, data: bytes,
                         satellite_id: str) -> bytes:
        """解密下行数据"""
        key = self.session_keys.get(f'{satellite_id}_down')
        if not key:
            raise ValueError("无有效下行密钥")

        # 解析
        seq_num = struct.unpack('>I', data[:4])[0]
        iv = data[4:16]
        ciphertext = data[16:]

        # 重放检查
        last_seq = self.sequence_numbers.get(
            f'{satellite_id}_down_recv', 0
        )
        if seq_num <= last_seq:
            raise ValueError(f"重放攻击! seq={seq_num}, "
                           f"last={last_seq}")

        # GCM解密
        cipher = AESGCM(key)
        plaintext = cipher.decrypt(iv, ciphertext,
                                    str(seq_num).encode())

        self.sequence_numbers[f'{satellite_id}_down_recv'] = seq_num
        return plaintext

    def rekey(self, satellite_id: str):
        """密钥更新"""

# 卫星指令安全系统
class SatelliteCommandSecurity:
    """卫星指令安全控制"""

    # 指令安全等级
    COMMAND_LEVELS = {
        1: {'name': '常规遥测请求', 'auth': 'single', 'audit': True},
        2: {'name': '配置更新', 'auth': 'single', 'audit': True},
        3: {'name': '姿态控制', 'auth': 'dual', 'audit': True},
        4: {'name': '轨道机动', 'auth': 'dual+review', 'audit': True},
        5: {'name': '应急指令', 'auth': 'dual+override', 'audit': True},
        6: {'name': '自毁/退役', 'auth': 'triple+review', 'audit': True},
    }

    def __init__(self):
        self.command_queue = []
        self.pending_authorizations = {}
        self.executed_commands = []
        self.command_counter = 0

    def submit_command(self, command: dict,
                       operator_id: str) -> dict:
        """提交指令"""
        cmd_level = command.get('security_level', 1)
        auth_req = self.COMMAND_LEVELS[cmd_level]

        # 创建待授权指令
        pending_cmd = {
            'id': f'CMD-{self.command_counter:06d}',
            'command': command,
            'submitter': operator_id,
            'submit_time': datetime.now().isoformat(),
            'security_level': cmd_level,
            'auth_required': auth_req['auth'],
            'authorizations': [],
            'status': 'pending',
        }

        self.command_counter += 1
        self.pending_authorizations[pending_cmd['id']] = pending_cmd

        logger.info(f"指令提交: {pending_cmd['id']} "
                    f"(级别: {cmd_level}, "
                    f"操作员: {operator_id})")

        return pending_cmd

    def authorize_command(self, cmd_id: str,
                          authorizer_id: str) -> dict:
        """授权指令"""
        if cmd_id not in self.pending_authorizations:
            return {'error': '指令不存在'}

        cmd = self.pending_authorizations[cmd_id]

        # 检查授权者不是提交者
        if authorizer_id == cmd['submitter']:
            return {'error': '不能自授权'}

        # 记录授权
        cmd['authorizations'].append({
            'authorizer': authorizer_id,
            'time': datetime.now().isoformat(),
        })

        # 检查是否满足授权要求
        auth_type = cmd['auth_required']
        auth_count = len(cmd['authorizations'])

        if auth_type == 'single' and auth_count >= 1:
            return self._execute_command(cmd)
        elif auth_type == 'dual' and auth_count >= 2:
            return self._execute_command(cmd)
        elif auth_type == 'dual+review' and auth_count >= 2:
            # 需要额外审查
            return {'status': 'needs_review', 'command': cmd}
        elif auth_type == 'triple+review' and auth_count >= 3:
            return {'status': 'needs_review', 'command': cmd}

        return {
            'status': 'pending',
            'authorizations': auth_count,
            'required': auth_type,
        }

    def _execute_command(self, cmd: dict) -> dict:
        """执行指令"""
        # 加密签名
        signed_cmd = self._sign_command(cmd)

        # 防回滚检查
        if self._check_rollback(cmd):
            return {'error': '指令版本回滚被拒绝'}

        # 发送指令
        cmd['status'] = 'executed'
        cmd['execute_time'] = datetime.now().isoformat()
        self.executed_commands.append(cmd)

        logger.info(f"指令执行: {cmd['id']}")

        return {'status': 'executed', 'command_id': cmd['id']}

    def _sign_command(self, cmd: dict) -> bytes:
        """对指令进行数字签名"""
        # 使用ECDSA-P256签名
        # 实际实现使用HSM
        cmd_data = json.dumps(cmd['command'], sort_keys=True).encode()
        # signature = hsm.sign(cmd_data)
        return cmd_data  # 简化

    def _check_rollback(self, cmd: dict) -> bool:
        """检查防回滚"""
        # 检查指令序列号是否大于上次执行的
        return False
```

# 地面站安全监控平台
class GroundStationSOC:
    """地面站安全运营中心"""

    def __init__(self):
        self.alerts = []
        self.incidents = []
        self.metrics = {}

    def collect_logs(self):
        """收集所有安全日志"""
        log_sources = {
            'firewall': '/var/log/firewall.log',
            'ids': '/var/log/suricata.log',
            'auth': '/var/log/auth.log',
            'antenna': '/var/log/antenna_ctrl.log',
            'scada': '/var/log/scada.log',
            'crypto': '/var/log/crypto_audit.log',
            'physical': '/var/log/access_control.log',
        }

        for source, path in log_sources.items():
            # 收集并解析日志
            events = self._parse_log(path, source)
            self._analyze_events(events)

    def _analyze_events(self, events: list):
        """分析安全事件"""
        for event in events:
            # 基于规则的检测
            rule_match = self._check_rules(event)
            if rule_match:
                self._create_alert(rule_match, event)

            # 基于异常的检测
            anomaly = self._check_anomaly(event)
            if anomaly:
                self._create_alert(anomaly, event)

    def _check_rules(self, event: dict) -> Optional[dict]:
        """规则匹配"""
        rules = [
            {
                'name': '未授权网络访问',
                'condition': lambda e: (
                    e.get('action') == 'DENY' and
                    e.get('src_zone') == 'external' and
                    e.get('dst_zone') == 'operations'
                ),
                'severity': 'HIGH',
            },
            {
                'name': '异常指令提交',
                'condition': lambda e: (
                    e.get('source') == 'scada' and
                    e.get('event_type') == 'command_submit' and
                    e.get('operator') not in self._authorized_ops()
                ),
                'severity': 'CRITICAL',
            },
            {
                'name': '加密异常',
                'condition': lambda e: (
                    e.get('source') == 'crypto' and
                    e.get('event_type') == 'decryption_failure'
                ),
                'severity': 'HIGH',
            },
            {
                'name': '物理入侵',
                'condition': lambda e: (
                    e.get('source') == 'physical' and
                    e.get('event_type') == 'force_entry'
                ),
                'severity': 'CRITICAL',
            },
        ]

        for rule in rules:
            if rule['condition'](event):
                return rule
        return None

## 总结

卫星地面站是整个卫星系统中安全防护的核心节点。其安全不仅关系到卫星资产的安全，更关系到依赖卫星服务的关键基础设施的稳定运行。

地面站安全防护需要从网络、射频、物理、供应链等多个维度构建纵深防御体系。关键原则包括：网络分段与隔离、严格的身份认证与访问控制、端到端的加密与签名、实时安全监控与告警、以及完善的应急响应机制。

Viasat KA-SAT攻击事件等真实案例提醒我们，地面站安全不是理论问题而是现实威胁。建议结合本文中的架构分析和安全配置示例，在实际地面站环境中进行安全评估和加固。
