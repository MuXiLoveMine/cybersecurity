# 卫星导航安全（GNSS 安全）

> 全球导航卫星系统（GNSS）是现代社会的重要基础设施，广泛应用于交通、金融、电力、通信等关键领域。GNSS 安全直接关系到国家安全和社会稳定。本章系统介绍 GNSS 原理、安全威胁和防护技术。

---

## 一、GNSS 概述

### 1.1 全球四大导航系统

#### 1.1.1 GPS（全球定位系统，美国）

**基本信息：**
- 运营方：美国空军
- 全面运行时间：1995 年
- 星座：24+ 颗 MEO 卫星
- 轨道高度：约 20,180 公里
- 轨道周期：约 12 小时（恒星时）
- 轨道面：6 个轨道面，倾角 55°
- 覆盖范围：全球

**信号服务：**
- **C/A 码（粗捕获码）**：民用，公开，1.023 MHz 码率
- **P(Y) 码（精密码）**：军用，加密，10.23 MHz 码率
- **M 码**：新一代军用信号，抗干扰能力更强
- **L1C**：新一代民用信号
- **L2C**：第二民用信号
- **L5**：生命安全信号

**频段：**
- L1：1575.42 MHz（C/A 码、P 码、M 码、L1C）
- L2：1227.60 MHz（P 码、L2C、M 码）
- L5：1176.45 MHz（生命安全信号）

#### 1.1.2 北斗卫星导航系统（BDS，中国）

**基本信息：**
- 运营方：中国卫星导航系统管理办公室
- 全面服务时间：2020 年
- 星座：35 颗卫星（GEO + IGSO + MEO 混合星座）
- 特色：短报文通信、星基增强

**星座结构：**
- **GEO 卫星**：5 颗，地球静止轨道，位于东经 80°、110.5°、140°、160°等
- **IGSO 卫星**：3 颗，倾斜地球同步轨道，倾角 55°
- **MEO 卫星**：27 颗，中地球轨道，约 21,500 公里

**信号服务：**
- **B1I**：公开服务信号（1561.098 MHz）
- **B2I**：公开服务信号（1207.14 MHz）
- **B3I**：公开服务信号（1268.52 MHz）
- **B1C**：新一代公开信号（1575.42 MHz，与 GPS L1 同频）
- **B2a**：新一代公开信号（1176.45 MHz，与 GPS L5 同频）
- **B2b**：全球星基增强信号
- **授权服务信号**：军码，需要授权

**特色服务：**
- 短报文通信：全球短报文、区域短报文
- 国际搜救服务
- 精密单点定位（PPP）
- 星基增强（SBAS）

#### 1.1.3 GLONASS（格洛纳斯，俄罗斯）

**基本信息：**
- 运营方：俄罗斯航天集团
- 恢复运行：2011 年
- 星座：24+ 颗 MEO 卫星
- 轨道高度：约 19,130 公里
- 轨道周期：约 11 小时 16 分钟
- 轨道面：3 个轨道面，倾角 64.8°

**特点：**
- 采用 FDMA（频分多址），每颗卫星不同频率
- 高纬度地区性能较好
- 抗干扰能力较强

**信号：**
- L1OF：1602 + k×0.5625 MHz（民用）
- L1SF：军用加密信号
- L2OF / L2SF：第二频率

#### 1.1.4 Galileo（伽利略，欧盟）

**基本信息：**
- 运营方：欧盟空间局（ESA）和欧盟
- 初始服务：2016 年
- 星座：24+ 颗 MEO 卫星
- 轨道高度：约 23,222 公里
- 轨道周期：约 14 小时 5 分钟
- 轨道面：3 个轨道面，倾角 56°

**特点：**
- 完全民用的卫星导航系统
- 提供高精度服务
- 提供认证服务（OS-NMA，公开服务-导航消息认证）

**信号：**
- E1：1575.42 MHz（与 GPS L1 同频）
- E5a：1176.45 MHz（与 GPS L5 同频）
- E5b：1207.14 MHz
- E6：1278.75 MHz（高精度服务）

| 领域 | 典型应用 | 安全重要性 |
|-----|---------|-----------|

| 金融系统 | 时间同步、交易时间戳 | 高（经济安全） |
| 电力系统 | 电网时间同步、故障定位 | 极高（关键基础设施） |

| 消费电子 | 手机导航、共享单车、可穿戴 | 中 |

## 二、GPS 信号结构与原理

### 2.1 导航定位基本原理

#### 2.1.1 三边测量法

GPS 定位基于三边测量原理：通过测量到至少 4 颗卫星的距离（伪距），计算出接收机的三维位置（x, y, z）和时间偏差（b）。

**数学模型：**
```
对于第 i 颗卫星：
√[(xi - x)² + (yi - y)² + (zi - z)²] + c*b = ρi
```
其中：
- (xi, yi, zi)：第 i 颗卫星的位置（已知，来自星历）
- (x, y, z)：接收机位置（未知）
- b：接收机时钟与 GPS 时间的偏差（未知）
- ρi：伪距测量值（已知）
- c：光速

**未知数：** x, y, z, b（共 4 个）
**需要卫星数：** 至少 4 颗

```
        卫星1        卫星2        卫星3        卫星4
           ○           ○           ○           ○
            \         /           /           /
             \       /           /           /
              \     /           /           /
               \   /           /           /
                \ /           /           /
                 ○ 接收机位置（4个球面交点）
                / \
               /   \
              /     \
```

#### 2.1.2 伪距测量原理

伪距 = 真实距离 + 时钟偏差引起的距离误差 + 其他误差

**测量方法：**
1. 卫星在已知时刻发射测距码（C/A 码或 P 码）
2. 接收机内部复制相同的测距码
3. 接收机调整复制码的相位，直到与接收到的信号相关峰值最大
4. 相位差对应的时间差乘以光速，得到伪距

### 2.2 GPS 信号结构

#### 2.2.1 GPS L1 信号组成

GPS L1 载波频率为 1575.42 MHz，其上调制了多种信号：

```
L1 载波 (1575.42 MHz)
├── C/A 码信号
│   ├── C/A 码（1.023 MHz，Gold 码）
│   └── 导航电文（50 bps）
├── P(Y) 码信号
│   ├── P 码（10.23 MHz，加密后为 Y 码）
│   └── 导航电文（50 bps）
└── M 码信号（军用，分 M_E 和 M_P）
```

#### 2.2.2 C/A 码（粗捕获码）

**基本参数：**
- 码率：1.023 MHz
- 码长：1023 个码片（chip）
- 周期：1 ms（1023 / 1.023e6 = 1 ms）
- 调制方式：BPSK
- 每颗卫星使用不同的 Gold 码（PRN 编号 1-32）

**特点：**
- 公开的，所有人都可以使用
- 码长短，容易捕获
- 抗干扰能力相对较弱
- 精度较低（约 10 米级）

#### 2.2.3 P(Y) 码（精密码）

**基本参数：**
- 码率：10.23 MHz
- 码长：极长（约 38 星期）
- 调制方式：BPSK
- 加密：P 码加密后变为 Y 码

**特点：**
- 军用，需要密钥才能使用
- 码率高，抗干扰能力强（比 C/A 码高约 10 dB）
- 码长长，难以捕获和欺骗
- 精度高（约 1 米级）

#### 2.2.4 导航电文

导航电文（Navigation Message）是调制在测距码上的数据，包含：

| 内容 | 说明 |
|-----|------|
| 星历数据（Ephemeris） | 卫星精确轨道参数，用于计算卫星位置 |
| 历书数据（Almanac） | 所有卫星粗略轨道，用于快速捕获 |
| 时钟校正参数 | 卫星时钟偏差校正 |
| 电离层校正参数 | 电离层延迟校正模型 |
| 卫星健康状态 | 卫星是否正常工作 |
| 时间信息 | GPS 时间、UTC 偏移 |

**电文结构：**
- 速率：50 bps
- 主帧：30 秒（25 页，每页 30 秒）
- 子帧：每帧 5 个子帧，每个子帧 6 秒（300 bit）
- 字：每个子帧 10 个字，每个字 30 bit（含 6 bit 校验）

**安全意义：**
- 星历数据是定位的基础，如果被篡改，定位结果就会错误
- 民用 GPS 导航电文没有认证，容易被伪造
- 欺骗攻击需要伪造导航电文

### 2.3 GPS 接收机工作流程

```
天线接收 → 射频前端 → 下变频 → A/D 转换 → 数字信号处理
                                                   │
                    ┌──────────────────────────────┘
                    ▼
            ┌───────────────┐
            │  信号捕获      │  搜索可见卫星，粗略同步
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  信号跟踪      │  精确跟踪载波和码相位
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  解调导航电文  │  获取星历、时间等数据
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  伪距测量      │  测量到各卫星的伪距
            └───────┬───────┘
                    ▼
            ┌───────────────┐
            │  定位解算      │  计算位置、速度、时间
            └───────────────┘
```

## 三、GPS 欺骗攻击（Spoofing）

### 3.1 欺骗攻击概述

#### 3.1.1 什么是欺骗攻击

GPS 欺骗攻击（GPS Spoofing）是指攻击者发射伪造的 GPS 信号，使接收机计算出错误的位置和时间。

**与干扰攻击的区别：**

| 对比项 | 干扰攻击（Jamming） | 欺骗攻击（Spoofing） |
|-------|-------------------|---------------------|
| 目的 | 使接收机无法工作 | 使接收机得到错误结果 |
| 原理 | 大功率信号淹没 | 伪造信号误导 |
| 功率需求 | 高（需超过信号） | 低（与真实信号相当） |
| 可检测性 | 容易（信号明显异常） | 困难（信号看起来正常） |
| 技术难度 | 低 | 高 |
| 危害程度 | 高（功能失效） | 极高（被误导可能更危险） |

**一个经典比喻：**
- 干扰 = 让你听不见
- 欺骗 = 让你听错了（而且你还以为是对的）

#### 3.1.2 欺骗攻击的危害

| 领域 | 危害 |
|-----|------|
| 航空 | 飞机偏航、误入禁飞区、降落错误 |
| 航海 | 船舶偏航、触礁、驶入危险区域 |
| 金融 | 时间同步错误，导致交易异常 |
| 电力 | 电网同步异常，可能导致停电 |
| 通信 | 基站同步异常，通信中断 |
| 军事 | 武器制导错误、部队迷失方向 |
| 无人机 | 无人机被劫持、失控 |
| 自动驾驶 | 车辆定位错误，导致事故 |

### 3.2 欺骗攻击分类

#### 3.2.1 生成式欺骗（Generative Spoofing）

**原理：**
攻击者完全生成虚假的 GPS 信号，包括伪造的测距码和导航电文。

**特点：**
- 可以完全控制接收机的位置和时间
- 需要生成多颗卫星的假信号
- 技术难度高
- 需要精确了解 GPS 信号结构

**所需条件：**
- 真实的 GPS 星历数据（可以从公开渠道获取）
- 信号生成设备（SDR + 放大器 + 天线）
- 精确的时间同步
- 目标位置信息

#### 3.2.2 转发式欺骗（Replay/Forward Spoofing）

**原理：**
攻击者接收真实的 GPS 信号，经过延迟/放大/调整后转发给目标接收机。

**特点：**
- 技术难度相对较低
- 信号结构与真实信号完全一致
- 欺骗效果是让接收机"以为"自己在别的位置
- 延迟时间决定了伪距偏移量

**实现方式：**
1. 在一个位置接收 GPS 信号
2. 将信号放大（可能加上延迟）
3. 发射到目标区域
4. 目标接收机被误导到信号接收点的位置

#### 3.2.3 中间式欺骗（Meaconing / Interference Spoofing）

**原理：**
结合干扰和欺骗，先用干扰压制真实信号，再发射欺骗信号。

**攻击步骤：**
1. 发射大功率干扰信号，使目标接收机失锁
2. 降低干扰功率，同时发射欺骗信号
3. 目标接收机重新捕获到欺骗信号
4. 接收机被欺骗

**特点：**
- 成功率高（先打断再植入）
- 容易被检测到（有干扰过程）
- 是最常见的实用欺骗方式

### 3.3 欺骗攻击原理详解

#### 3.3.1 欺骗攻击的基本条件

要成功实施 GPS 欺骗攻击，需要满足以下条件：

1. **功率条件**：欺骗信号功率略高于真实信号（通常高 1-5 dB）
2. **同步条件**：欺骗信号的码相位和载波频率与真实信号接近
3. **数据条件**：欺骗信号包含合理的导航电文（星历等）
4. **一致性条件**：多颗假卫星信号之间相互一致（伪距要能解算出合理位置）

#### 3.3.2 欺骗攻击过程（以中间式欺骗为例）

```
阶段 1：干扰压制
    干扰功率 ████████████
    信号功率 ██░░░░░░░░░░
    结果：接收机失锁

阶段 2：欺骗信号注入
    干扰功率 ████░░░░░░░░
    欺骗信号 ██████░░░░░░
    信号功率 ██░░░░░░░░░░
    结果：接收机开始捕获欺骗信号

阶段 3：欺骗成功
    干扰功率 ░░░░░░░░░░░░
    欺骗信号 ██████░░░░░░
    信号功率 ██░░░░░░░░░░
    结果：接收机跟踪欺骗信号，计算出错误位置
```

#### 3.3.3 位置欺骗的数学原理

设接收机真实位置为 (x₀, y₀, z₀)，攻击者想让接收机认为自己在位置 (x', y', z')。

**真实伪距：**
```
ρi⁰ = √[(xi - x₀)² + (yi - y₀)² + (zi - z₀)²] + c*b
```

**欺骗伪距需要满足：**
```
ρi' = √[(xi - x')² + (yi - y')² + (zi - z')²] + c*b'
```

攻击者需要调整每颗卫星的欺骗信号延迟，使伪距等于 ρi'。

**关键：** 所有卫星的伪距偏移必须一致，能够解算出同一个 (x', y', z', b')。

### 3.4 欺骗攻击的实施

#### 3.4.1 硬件需求

**入门级（实验/演示）：**
- HackRF One / BladeRF 等 SDR 设备
- GPS 天线
- 放大器（可选）
- 电脑

**专业级：**
- 高性能 SDR（USRP 等）
- 多通道同步（多颗卫星同时生成）
- 高功率放大器
- 高增益定向天线
- 原子钟（高精度时间同步）

#### 3.4.2 软件工具

**GPS 信号生成：**
- gps-sdr-sim（开源 GPS 信号生成器）
- GNSS-SDR（软件定义 GNSS 接收机，也可以生成信号）
- MATLAB/Simulink 自定义

**使用 gps-sdr-sim 生成 GPS 欺骗信号的基本步骤：**
1. 下载广播星历数据（从 IGS 等网站）
2. 指定目标位置和时间
3. 运行 gps-sdr-sim 生成 IQ 数据文件
4. 使用 SDR 发射生成的信号

#### 3.4.3 攻击位置选择

- 靠近目标接收机（路径损耗小，所需功率低）
- 避开真实 GPS 信号的方向（减少真实信号干扰）
- 开阔地带（信号传播好）

### 3.5 针对不同目标的欺骗攻击

#### 3.5.1 无人机 GPS 欺骗

**攻击场景：**
- 劫持无人机到指定位置
- 使无人机坠落（伪造过低的高度）
- 使无人机偏航

**案例（公开报道）：**
- 2011 年伊朗"俘获"美国 RQ-170 无人机（据称使用 GPS 欺骗）
- 多次报道的无人机被 GPS 欺骗劫持事件
- 反无人机系统中有使用 GPS 欺骗技术的

**技术要点：**
- 无人机 GPS 天线通常朝下（接收地面方向信号）
- 从地面发射欺骗信号更容易成功
- 无人机自动驾驶对 GPS 依赖度高

#### 3.5.2 船舶 GPS 欺骗

**攻击场景：**
- 使船舶偏航
- 使船舶进入特定区域
- 掩盖船舶真实位置

**案例（公开报道）：**
- 黑海地区多次 GPS 欺骗事件
- 港口附近船舶 GPS 位置异常

#### 3.5.3 时间欺骗

除了位置欺骗，GPS 欺骗还可以进行时间欺骗：

**危害：**
- 金融交易时间戳错误
- 电力系统同步异常
- 通信基站同步故障
- 加密认证失效（依赖时间的认证协议）

**案例：**
- 2019 年 GPS 时间异常事件（非攻击，是系统故障，但说明了 GPS 时间的重要性）
- 各种利用 GPS 进行时间同步的系统都面临时间欺骗风险

## 四、GPS 干扰攻击（Jamming）

### 4.1 干扰攻击概述

GPS 干扰攻击是通过发射射频信号，使 GPS 接收机无法正常接收和处理 GPS 信号。

#### 4.1.1 GPS 信号的脆弱性

GPS 信号到达地面时的功率极低，这是其容易被干扰的根本原因：

- GPS L1 C/A 码到达地面的功率：约 -160 dBW（约 1e-16 W）
- 比热噪声还低约 20 dB（藏在噪声里）
- 依靠扩频增益才能从噪声中提取出来

**对比：**
- 一部手机的发射功率：约 1 W（30 dBm）
- GPS 信号到达地面：约 -130 dBm
- 差值：160 dB（相差 10^16 倍！）

这意味着一个小小的干扰器就能在很大范围内干扰 GPS 信号。

#### 4.1.2 干扰效果

| 干扰强度 | 效果 |
|---------|------|
| 轻微干扰 | 定位精度下降、失星（可用卫星数减少） |
| 中度干扰 | 完全无法定位、定位结果跳变 |
| 严重干扰 | 接收机完全失锁、无法捕获信号 |
| 极端干扰 | 接收机前端饱和损坏（极少） |

### 4.2 干扰器类型

#### 4.2.1 简易干扰器

**特点：**
- 电路简单，成本低
- 单频或扫频干扰
- 功率不大，但足以影响民用 GPS

**典型参数：**
- 频率：L1 频段（1575.42 MHz 附近）
- 功率：几十毫瓦到几瓦
- 干扰范围：几十米到几公里（视功率和环境）
- 价格：几百到几千元

**用途（非法）：**
- 车辆防跟踪
- 考场防作弊
- 个人隐私保护（但会干扰他人）

**法律风险：**
- 在大多数国家是违法的
- 可能危害公共安全（民航、海事等）
- 可能被定位和查处

#### 4.2.2 军用干扰系统

**特点：**
- 功率大，干扰范围广
- 多频段（L1、L2、L5 等）
- 智能化（自适应干扰）
- 通常集成在电子战系统中

**典型系统（公开资料）：**
- 车载 GPS 干扰系统
- 便携式 GPS 干扰机
- 机载电子战吊舱（含 GPS 干扰）
- 地基 GPS 干扰站

### 4.3 干扰方式

#### 4.3.1 窄带干扰

- 单频或窄带信号
- 瞄准 GPS 中心频率
- 结构简单，效率高
- 对扩频系统有一定效果（但不如宽带干扰）

#### 4.3.2 宽带噪声干扰

- 宽带噪声信号，覆盖 GPS 整个频段
- 对扩频系统干扰效果好
- 需要更大的干扰功率

#### 4.3.3 扫频干扰

- 干扰频率在一定范围内快速扫动
- 可以同时干扰多个频段
- 对跳频系统也有一定效果

#### 4.3.4 脉冲干扰

- 周期性脉冲信号
- 峰值功率高
- 对某些类型的接收机效果好

### 4.4 干扰范围估算

**简化估算公式：**
干扰范围取决于干扰功率、目标接收机的抗干扰能力、环境等因素。

对于自由空间传播，干扰距离 d 满足：
```
P_j + G_j - L_p(d) = P_s + G_s - L_p(sat) + J/S_required
```

其中 J/S_required 是达到干扰效果所需的干信比。

**大致范围参考：**
| 干扰功率 | 开阔地干扰距离 | 备注 |
|---------|--------------|------|
| 10 mW | ~100 m | 小型便携干扰器 |
| 1 W | ~1 km | 车载干扰器 |
| 10 W | ~3 km | 中型干扰系统 |
| 100 W | ~10 km | 大型干扰站 |
| 1 kW | ~30 km | 军用级干扰系统 |

注意：以上为粗略估算，实际距离受天线增益、环境、接收机灵敏度等多种因素影响。

## 五、GPS 重放攻击

### 5.1 重放攻击原理

GPS 重放攻击是指攻击者录制真实的 GPS 信号，然后在另一个时间或地点播放，使接收机被误导。

#### 5.1.1 与欺骗攻击的区别

| 对比项 | 重放攻击 | 欺骗攻击 |
|-------|---------|---------|
| 信号来源 | 录制的真实信号 | 人工生成的假信号 |
| 信号真实性 | 信号本身是真的 | 信号是伪造的 |
| 技术难度 | 较低 | 较高 |
| 灵活度 | 低（只能重放录制的内容） | 高（可以任意设定位置） |
| 导航电文 | 真实的（但可能过期） | 伪造的 |

#### 5.1.2 重放攻击的类型

| 类型 | 说明 | 危害 |
|-----|------|------|
| 位置重放 | 在 A 地录制，在 B 地播放 | 接收机以为自己在 A 地 |
| 时间重放 | 过去录制，现在播放 | 接收机时间被误导到过去 |
| 时移重放 | 录制后延迟一段时间播放 | 伪距偏移，位置偏移 |

### 5.2 重放攻击的实施

#### 5.2.1 设备需求

- 高保真 GPS 接收机/录制设备
- 高速数据采集存储设备
- SDR 发射设备
- 放大器和天线

#### 5.2.2 攻击步骤

```
录制阶段：
  真实 GPS 信号 → 接收 → 放大 → 数字化 → 存储 IQ 数据

重放阶段：
  读取 IQ 数据 → D/A 转换 → 上变频 → 放大 → 发射 → 目标接收机
```

### 5.3 重放攻击的局限性

1. **导航电文时效性**：GPS 星历每 2 小时更新一次，过期的星历可能被接收机拒绝
2. **时间戳问题**：重放信号中的时间信息与当前时间不符
3. **多普勒频移**：录制地点和播放地点不同，多普勒频移可能不一致
4. **多路径效应**：重放环境的多路径特征与真实环境不同

这些局限性也是检测重放攻击的依据。

## 六、GNSS 防护技术

### 6.1 防护技术分类

```
GNSS 防护技术
├── 抗干扰技术
│   ├── 天线域：调零天线、波束成形、阵列天线
│   ├── 信号域：扩频增益、高码率信号
│   ├── 接收机域：干扰检测与抑制、自适应滤波
│   └── 系统域：多系统融合、惯性辅助
├── 防欺骗技术
│   ├── 信号层：加密信号（P(Y)码、M码）、信号认证
│   ├── 接收机层：欺骗检测、一致性检验
│   ├── 系统层：多系统/多频融合、惯性辅助
│   └── 密码学层：导航电文认证（NMA）
├── 抗干扰防欺骗 (AJ+AS)
│   └── 军用高端接收机
└── 替代导航技术
    ├── 惯性导航（INS）
    ├── 天文导航
    ├── 地形匹配
    ├── 无线电导航（罗兰、北斗短报文等）
    ├── 视觉导航
    └── 多源融合导航
```

### 6.2 抗干扰技术

#### 6.2.1 调零天线

**原理：**
使用阵列天线和自适应算法，在干扰源方向形成方向图零点，抑制干扰信号。

**性能：**
- 调零深度：30-50 dB（对单干扰源）
- 可同时抑制多个干扰（取决于阵元数）
- 对有用信号影响小

**应用：**
- 军用 GPS 接收机
- 关键基础设施（电力、金融）
- 航空航天

#### 6.2.2 波束成形

**原理：**
通过阵列天线将接收/发射波束指向卫星方向，提高卫星方向的增益，降低其他方向的干扰。

**优势：**
- 提高信号增益（阵列增益）
- 抑制非卫星方向的干扰
- 可以同时跟踪多颗卫星（多波束）

#### 6.2.3 接收机抗干扰算法

| 算法 | 原理 | 效果 |
|-----|------|------|
| 时域滤波 | 滤除干扰频率成分 | 对窄带干扰有效 |
| 频域滤波 | FFT 后滤除干扰谱线 | 对单频/窄带干扰有效 |
- 自适应滤波 | 自适应调整滤波器系数 | 对多种干扰有效 |
| 空时自适应处理（STAP） | 联合空域和时域处理 | 抗干扰能力强 |
| 变换域干扰抑制 | 如小波变换 | 对非平稳干扰有效 |

### 6.3 防欺骗技术

#### 6.3.1 信号层防护

**加密军用信号：**
- GPS P(Y) 码、M 码
- 北斗军码
- Galileo PRS（公共管制服务）

**为什么加密信号能防欺骗：**
- 攻击者不知道加密码的结构
- 无法生成伪造的加密信号
- 只能进行转发式欺骗（难度更高）
- 配合军码的高码率，抗干扰能力也强

**导航电文认证（NMA）：**
- 对导航电文进行数字签名或消息认证
- 接收机可以验证导航电文的真实性
- 即使码是公开的，电文无法伪造
- Galileo OS-NMA 是首个公开服务的导航电文认证系统

#### 6.3.2 接收机层欺骗检测

**常用检测方法：**

| 方法 | 原理 | 适用场景 |
|-----|------|---------|
| 信号功率监测 | 欺骗信号功率通常偏高 | 简单场景 |
| 载波相位一致性 | 多频信号相位关系检验 | 多频接收机 |
| 伪距一致性 | 不同卫星伪距的几何一致性 | 通用 |
| 位置跳跃检测 | 位置突然变化超出运动极限 | 动态应用 |
| 时间一致性 | GPS 时间与本地时钟对比 | 有本地时钟的系统 |
| 空间滤波 | 用阵列天线区分信号方向 | 高端接收机 |
| 加密信号验证 | 对比公开码和加密码结果 | 军用接收机 |
| 运动模型检验 | 定位结果是否符合运动规律 | 有运动约束的系统 |

**IMU/GPS 组合导航防欺骗：**
- 惯性导航系统（INS）短期精度高，不依赖外部信号
- GPS 长期精度高，但易受干扰和欺骗
- 组合导航中，IMU 可以检测 GPS 结果是否异常
- 如果 GPS 结果与 IMU 推算偏差过大，可能遭受了欺骗

#### 6.3.3 系统层防护

**多系统融合：**
- 同时使用 GPS、北斗、GLONASS、Galileo
- 如果只有一个系统结果异常，可能是欺骗
- 多个系统同时被欺骗的难度大得多

**多频接收：**
- 同时接收 L1、L2、L5 等多个频率
- 欺骗者需要同时欺骗所有频率难度大
- 不同频率的电离层延迟有固定关系，可以检验

### 6.4 高端抗干扰防欺骗接收机

**军用级接收机特点：**
- 支持军用加密信号（M 码、军码）
- 调零天线 / 可控波束天线
- 多系统多频
- 高性能抗干扰算法
- 防欺骗检测
- 高可靠设计

**典型产品（公开资料）：**
- 军用 GPS 接收机（各型号）
- 抗干扰导航终端
- 组合导航系统（GPS + 惯导）

## 七、导航战（NAVWAR）

### 7.1 导航战概述

#### 7.1.1 定义

导航战（Navigation Warfare, NAVWAR）是指在军事对抗中，通过控制和利用导航信息，确保己方有效使用导航系统，同时阻止敌方使用导航系统的作战行动。

**导航战的三大要素：**
1. **导航战保护（NAVWAR Protection）**：保护己方使用导航的能力
2. **导航战阻止（NAVWAR Prevention）**：阻止敌方使用导航
3. **导航战利用（NAVWAR Exploitation）**：利用导航信息获取优势

#### 7.1.2 导航战的地位

- 导航战是电子战的重要组成部分
- 是太空战和信息战的交汇点
- 现代战争的关键能力之一
- 关系到精确制导武器的效能

### 7.2 导航战攻击手段

| 攻击手段 | 说明 | 效果 |
|---------|------|------|
| 压制式干扰 | 大功率干扰敌方导航接收 | 使敌方无法使用导航 |
| 欺骗式干扰 | 发射虚假导航信号 | 误导敌方位置和时间 |
| 反卫星武器 | 摧毁导航卫星 | 永久/半永久破坏导航能力 |
| 网络攻击 | 攻击地面控制系统 | 影响系统运行 |
| 空间电磁攻击 | 对卫星进行电磁攻击 | 使卫星暂时失效或损坏 |

### 7.3 导航战防御手段

| 防御手段 | 说明 |
|---------|------|
| 抗干扰接收机 | 调零天线、波束成形、抗干扰算法 |
| 加密军码 | 防止欺骗，提高抗干扰能力 |
| 多系统融合 | GPS + 北斗 + GLONASS + Galileo |
| 惯性导航辅助 | IMU + GNSS 组合导航 |
| 星基增强 | 提高精度和完好性 |
| 冗余设计 | 多星座、多频段、多传感器 |
| 导航战训练 | 提高操作人员在无 GPS 环境下的作战能力 |

### 7.4 导航战发展趋势

1. **从单系统对抗到体系对抗**：对抗不再局限于单一导航系统，而是多系统、多手段的综合对抗
2. **从压制干扰到智能欺骗**：欺骗比压制更隐蔽、更有效，是发展重点
3. **从信号层到系统层**：攻击向网络层、系统层延伸
4. **AI 赋能**：人工智能在干扰、欺骗、检测中广泛应用
5. **量子导航**：量子精密测量技术可能带来导航革命
6. **多源融合**：导航从单一 GNSS 向多源融合导航发展

## 八、安全事件案例分析

### 8.1 案例一：2011 年 RQ-170 无人机事件

**事件回顾：**
- 2011 年 12 月 4 日，伊朗宣布俘获一架美国 RQ-170"哨兵"隐身无人机
- 无人机基本完好，仅腹部有轻微损伤
- 美方最初否认，后确认一架无人机"失踪"

**伊朗声称的技术手段：**
- 使用 GPS 欺骗技术
- 干扰无人机的卫星通信链路
- 注入虚假的 GPS 信号
- 使无人机误认为自己在阿富汗基地的 GPS 坐标上空
- 无人机自动降落在了伊朗境内

**技术分析与争议：**
- RQ-170 作为高级隐身无人机，应该有军用 GPS（P(Y) 码甚至 M 码）
- 军用 GPS 欺骗难度远大于民用
- 可能的情况：
  1. 无人机同时有民用 GPS 作为备份，攻击者攻击了民用通道
  2. 通信干扰导致无人机切换到自动驾驶模式
  3. 无人机存在其他技术故障
  4. 伊朗确实掌握了高级 GPS 欺骗技术

**事件影响：**
- 首次大规模公开报道的 GPS 欺骗军事应用
- 引发全球对 GPS 安全的关注
- 推动各国加强导航安全投入
- 无人机安全设计受到重视

### 8.2 案例二：黑海地区 GPS 异常事件

**事件概述：**
2010 年代以来，黑海地区多次出现大规模 GPS 信号异常，影响船舶和航空导航。

**异常现象：**
- 船舶 GPS 位置显示错误（有的显示在几十公里外的机场）
- GPS 信号时有时无
- 多艘船只同时受到影响
- 时间与军事演习高度重合

**技术分析：**
- 大概率是 GPS 干扰或欺骗
- 干扰/欺骗源可能来自克里米亚地区
- 功率较大，影响范围广（几十到上百公里）
- 可能是军用电子战系统的测试或使用

**受影响系统：**
- 商船导航
- 渔船作业
- 通用航空
- 部分航空导航（有备份系统，影响有限）

**安全启示：**
- GPS 干扰/欺骗的影响范围可以很大
- 民用设施高度依赖 GPS，非常脆弱
- 关键基础设施需要有 GPS 备份方案
- 船舶需要配备多种导航手段

### 8.3 案例三：无人机 GPS 欺骗劫持事件

**背景：**
随着消费级无人机的普及，无人机的安全问题日益突出。GPS 欺骗被认为是反无人机的一种手段。

**已报道的事件：**
- 多起无人机闯入敏感区域事件
- 反无人机系统中有使用 GPS 欺骗技术的产品
- 研究人员多次演示对消费级无人机的 GPS 欺骗

**技术原理：**
1. 消费级无人机主要使用民用 GPS（C/A 码）
2. 无人机的飞行控制高度依赖 GPS
3. 从地面发射欺骗信号（无人机 GPS 天线朝下）
4. 使无人机"认为"自己偏离了航线
5. 无人机自动修正，飞向攻击者想要的位置

**防护措施：**
- 高端无人机使用多频多系统 GPS
- 增加惯性导航辅助
- GPS 欺骗检测算法
- 视觉导航辅助
- 其他导航手段备份

### 8.4 案例四：2019 年 GPS 时间异常事件

**事件概述：**
2019 年 1 月，GPS 系统发生一次时间异常事件。

**事件详情：**
- 由于 GPS 地面控制系统的软件问题
- 导致 GPS 广播的时间信息出现偏差
- 部分用户设备的时间计算错误
- 影响了一些依赖 GPS 时间同步的系统

**影响：**
- 部分通信基站同步异常
- 部分电力系统监测设备异常
- 金融交易系统时间戳偏差
- 持续时间不长，很快被修复

**安全意义：**
- 说明 GPS 时间同步的重要性
- 非攻击原因的故障也能造成很大影响
- 如果是故意的时间欺骗攻击，危害可能更大
- 关键系统需要多源时间同步备份

## 九、本章小结

1. **GNSS 系统**：GPS、北斗、GLONASS、Galileo 四大系统各有特点，多系统融合是趋势
2. **GPS 信号结构**：C/A 码公开、P(Y) 码加密，导航电文包含星历等关键信息
3. **欺骗攻击**：比干扰更隐蔽、更危险，有生成式、转发式、中间式等类型
4. **干扰攻击**：实现简单，效果直接，GPS 信号功率低是天然弱点
5. **重放攻击**：录制并重放真实信号，技术门槛较低
6. **防护技术**：调零天线、加密信号、多系统融合、惯性辅助、欺骗检测等
7. **导航战**：军事领域导航对抗的高级形式，是电子战的重要组成部分
