# API身份认证概述

### 1.1 API安全挑战

```text
API安全核心挑战

┌──────────────────────────────────────────────────────────┐
│                    API安全威胁                             │
├──────────────────────────────────────────────────────────┤
│ 认证威胁                                                  │
│ ├── 未授权访问: 无认证直接访问API                          │
│ ├── 凭据泄露: API Key/Token被窃取                        │
│ ├── 暴力破解: 针对认证端点的密码猜解                      │
│ └── 令牌重用: 令牌在不同上下文中重用                      │
│                                                          │
│ 授权威胁                                                  │
│ ├── 权限提升: 获取超出分配的权限                          │
│ ├── 水平越权: 访问同级用户数据                            │
│ ├── 垂直越权: 低权限访问高权限功能                        │
│ └── 功能滥用: 合法权限的非法使用                          │
│                                                          │
│ 传输威胁                                                  │
│ ├── 中间人攻击: 拦截/篡改API通信                          │
│ ├── 重放攻击: 重发有效请求                                │
│ └── 注入攻击: SQL/XSS/命令注入                           │
│                                                          │
│ 业务威胁                                                  │
│ ├── 速率滥用: 超量调用API                                 │
│ ├── 数据爬取: 批量获取数据                                │
│ └── 业务逻辑漏洞: 绕过业务约束                            │
└──────────────────────────────────────────────────────────┘
```

### 1.2 认证方式分类

| 认证方式 | 认证对象 | 安全等级 | 适用场景 |
|---------|---------|---------|---------|
| API Key | 应用/服务 | 低-中 | 服务间调用 |
| Basic Auth | 用户 | 低 | 简单认证 |
| Bearer Token/JWT | 用户/应用 | 中 | Web/移动应用 |
| OAuth 2.0 | 第三方应用 | 中-高 | 第三方授权 |
| mTLS | 服务/设备 | 高 | 服务间通信 |
| HMAC签名 | 请求 | 高 | API请求验证 |
