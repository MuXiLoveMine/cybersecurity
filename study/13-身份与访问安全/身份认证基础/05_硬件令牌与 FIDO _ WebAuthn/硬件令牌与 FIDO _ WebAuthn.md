# 硬件令牌与 FIDO / WebAuthn

### 5.1 硬件令牌概述

**硬件令牌**：一种物理设备，用于生成或存储认证凭证，提供强身份认证。

**硬件令牌类型**：

| 类型 | 原理 | 示例 |
|------|------|------|
| 时间型令牌 | 基于时间生成动态密码 | RSA SecurID |
| 事件型令牌 | 基于事件计数生成密码 | HOTP令牌 |
| 挑战-响应型 | 接收挑战码，计算响应 | 银行U盾 |
| 公钥型令牌 | 非对称加密，私钥不出设备 | YubiKey（U2F/FIDO2） |

### 5.2 U2F 通用第二因素

**U2F 简介**：
- Universal 2nd Factor
- 由 Google 和 Yubico 联合开发
- FIDO 联盟标准
- 基于公钥密码学

**U2F 工作原理**：

**注册流程**：
```
1. 用户访问网站，点击注册U2F设备
2. 网站生成挑战（challenge）
3. 用户插入U2F设备并按下按钮
4. 设备生成新的密钥对（私钥存在设备中，公钥发给网站）
5. 网站存储公钥和Key Handle
```

**认证流程**：
```
1. 用户登录，网站发送挑战 + Key Handle
2. 用户插入U2F设备并按下按钮
3. 设备用对应私钥签名挑战
4. 网站用公钥验证签名
5. 验证通过，登录成功
```

**U2F 的优势**：
- 防钓鱼：绑定域名，假网站无法验证通过
- 防中间人攻击
- 物理设备，无法远程窃取
- 使用简单，一键操作
- 一个设备可绑定多个网站

### 5.3 WebAuthn / FIDO2

**WebAuthn 简介**：
- Web Authentication API
- W3C 推荐标准（2019年）
- FIDO2 规范的核心组件
- 浏览器内置支持

**WebAuthn vs U2F**：

| 特性 | U2F | WebAuthn |
|------|-----|----------|
| 仅第二因素 | ✅ | ✅ |
| 无密码登录 | ❌ | ✅ |
| 平台认证器 | ❌ | ✅（Touch ID、Face ID、Windows Hello） |
| 跨平台认证器 | ✅ | ✅（YubiKey等） |
| 用户验证 | 可选 | 支持 |

**WebAuthn 核心概念**：

| 概念 | 说明 |
|------|------|
| 认证器（Authenticator） | 生成和存储密钥的设备 |
| 平台认证器 | 内置在设备中（Touch ID、Face ID） |
| 跨平台认证器 | 可移除的硬件设备（YubiKey） |
| 依赖方（Relying Party） | 使用WebAuthn的网站/应用 |
| 凭证（Credential） | 公钥密钥对 |
| 用户验证（User Verification） | 验证用户本人（指纹、PIN） |

**WebAuthn 认证流程**：
```
客户端（浏览器）                    服务器（Relying Party）
     |                                     |
     |-------- 请求认证挑战 ---------------->|
     |                                     | 生成挑战
     |<------- 返回挑战 + 凭证ID ----------|
     |
     | 调用 WebAuthn API
     | → 提示用户操作（按按钮/指纹）
     | → 认证器签名
     |
     |-------- 签名结果 ------------------->|
     |                                     | 验证签名
     |<------- 认证结果 -------------------|
```

**支持情况**：
- 浏览器：Chrome、Firefox、Safari、Edge 均已支持
- 平台：Windows Hello、Apple Touch ID/Face ID、Android指纹
- 硬件：YubiKey、Google Titan Key、Solo Key
