# 身份认证概述

### 1.1 认证、授权与审计（AAA）

身份安全的核心是 **AAA 框架**，三者构成了完整的访问控制闭环：

| 概念 | 英文 | 说明 | 核心问题 |
|------|------|------|----------|
| 认证 | Authentication | 验证用户身份的真实性 | 你是谁？ |
| 授权 | Authorization | 决定用户可访问的资源和操作 | 你能做什么？ |
| 审计 | Accounting | 记录用户的所有操作行为 | 你做了什么？ |

**三者关系**：
```
用户请求 → 【认证】验证身份 → 【授权】检查权限 → 【审计】记录操作 → 返回结果
```

**实际案例**：
- 员工登录公司系统（认证）→ 只能访问自己部门的文件（授权）→ 所有文件操作被记录（审计）
- 银行APP登录（认证）→ 只能查看自己的账户（授权）→ 每笔交易都有日志（审计）

### 1.2 身份认证的定义

身份认证是指**通过一定的手段确认用户身份真实性的过程**，确保当前请求者确实是其所声称的身份。

**认证的本质**：
- 证明你拥有某种**唯一且难以伪造**的东西
- 认证强度取决于伪造该东西的难度

**常见认证场景**：
- 系统登录（用户名+密码）
- 门禁刷卡
- 手机解锁（指纹/面容）
- 网银U盾
- 邮箱验证链接
