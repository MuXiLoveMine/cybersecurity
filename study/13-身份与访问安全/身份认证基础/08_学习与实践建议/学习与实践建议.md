# 学习与实践建议

### 动手实践

1. **密码哈希实验**：
   - 使用 Python 的 bcrypt、argon2-cffi 库进行密码哈希实验
   - 测试不同成本因子对计算时间的影响
   - 编写彩虹表原理演示代码

2. **TOTP 实现**：
   - 用 Python 从零实现 TOTP 算法
   - 与 Google Authenticator 对比验证
   - 测试时间偏移的影响

3. **WebAuthn 体验**：
   - 在支持 WebAuthn 的网站（如 GitHub）注册硬件密钥
   - 体验无密码登录流程
   - 分析 WebAuthn 的数据包

4. **搭建 SSO 系统**：
   - 使用 Keycloak 搭建本地 IdP
   - 配置 SAML 和 OIDC 应用
   - 测试单点登录流程

### 推荐工具

| 工具 | 用途 |
|------|------|
| John the Ripper | 密码哈希破解 |
| Hashcat | GPU密码破解 |
| Hydra | 网络认证暴力破解 |

| Google Authenticator | TOTP手机应用 |
