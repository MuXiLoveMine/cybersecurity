# 身份与访问安全学习指南

> 身份与访问安全聚焦身份认证、授权管理和访问控制，是网络安全的基础和核心，也是零信任架构的基石。

---

## 一、方向概述

身份与访问安全（Identity and Access Management，简称 IAM）是网络安全的基础和核心，负责管理"谁能访问什么"的问题。身份是安全的起点，访问控制是安全的核心。随着零信任架构的兴起，身份安全变得越来越重要。

**核心防护对象**：用户身份、设备身份、应用身份、服务身份、权限策略、访问控制、身份治理、特权账号

**关键威胁**：弱口令、凭证泄露、暴力破解、钓鱼攻击、身份盗用、权限提升、越权访问、横向移动、内部威胁、供应链攻击

**职业方向**：IAM 工程师、身份安全工程师、零信任架构师、特权访问管理工程师、身份治理专家、安全架构师

## 二、详细子方向

### 2.1 身份认证技术

#### 2.1.1 身份认证基础
**认证概念**
- 身份认证：验证你是谁
- 授权：验证你能做什么
- 审计：记录你做了什么

**认证三要素**
- 你知道的（Something you know）：密码、PIN
- 你拥有的（Something you have）：手机、令牌、U 盾
- 你本身（Something you are）：指纹、人脸、虹膜

**认证强度**
- 单因素认证（SFA）：只用一种因素
- 双因素认证（2FA）：使用两种因素
- 多因素认证（MFA）：使用多种因素

#### 2.1.2 密码认证
**密码安全**
- 密码强度
- 密码策略
- 密码存储（哈希加盐）
- 密码轮换
- 密码复用问题
- 密码管理器

**常见攻击**
- 暴力破解
- 字典攻击
- 彩虹表
- 社会工程学
- 钓鱼攻击
- 键盘记录
- 凭证填充（Credential Stuffing）

**防护措施**
- 强密码策略
- 密码哈希加盐
- 限制登录尝试
- 验证码
- 登录异常检测
- 密码管理器

#### 2.1.3 多因素认证（MFA）
**常见 MFA 方式**
- 短信验证码
- 邮件验证码
- 语音验证码
- TOTP（基于时间的一次性密码）：Google Authenticator、Authy
- HOTP（基于事件的一次性密码）
- 硬件令牌：RSA SecurID、U 盾
- 生物识别：指纹、人脸、虹膜
- 推送通知：手机 App 推送
- FIDO / U2F：硬件安全密钥

**MFA 绕过方法**
- 会话劫持
- Cookie 窃取
- MFA 疲劳攻击
- 社会工程学
- 中间人攻击
- 令牌窃取

#### 2.1.4 生物识别认证
**常见生物特征**
- 指纹识别
- 人脸识别
- 虹膜识别
- 声纹识别
- 步态识别
- 静脉识别

**安全风险**
- 生物特征泄露（无法更改）
- 欺骗攻击（假指纹、假人脸）
- 隐私问题
- 准确性问题
- 偏见问题

### 2.2 访问控制模型

#### 2.2.1 访问控制基础
**访问控制概念**
- 主体（Subject）：访问者
- 客体（Object）：被访问的资源
- 操作（Action）：读、写、执行等
- 策略（Policy）：访问规则

**访问控制三要素**
- 身份认证：你是谁
- 授权：你能做什么
- 审计：你做了什么

#### 2.2.2 自主访问控制（DAC）
**DAC 模型**
- Discretionary Access Control
- 资源所有者决定谁能访问
- 灵活性高
- 安全性较低

**特点**
- 所有者可以分配权限
- 权限可以传递
- 管理分散
- 适合小型系统

#### 2.2.3 强制访问控制（MAC）
**MAC 模型**
- Mandatory Access Control
- 系统强制控制访问
- 安全性高
- 灵活性低

**特点**
- 安全标签
- 系统统一管理
- 不可绕过
- 适合高安全需求系统
- 如 SELinux、军用系统

#### 2.2.4 基于角色的访问控制（RBAC）
**RBAC 模型**
- Role-Based Access Control
- 基于角色分配权限
- 最常用的模型
- 平衡安全和灵活

**核心概念**
- 用户（User）
- 角色（Role）
- 权限（Permission）
- 会话（Session）

**特点**
- 权限分配给角色
- 用户分配角色
- 角色继承
- 职责分离
- 易于管理

#### 2.2.5 基于属性的访问控制（ABAC）
**ABAC 模型**
- Attribute-Based Access Control
- 基于属性进行访问控制
- 灵活强大
- 零信任的基础

**属性类型**
- 用户属性：部门、职位、级别
- 资源属性：分类、密级、所有者
- 环境属性：时间、地点、设备
- 操作属性：读、写、删除

**特点**
- 动态决策
- 细粒度控制
- 策略灵活
- 适合复杂场景
- 零信任架构常用

#### 2.2.6 其他访问控制模型
**其他模型**
- 基于规则的访问控制（RBAC）
- 基于任务的访问控制（TBAC）
- 基于团队的访问控制（TMAC）
- 时空访问控制
- 基于风险的访问控制

### 2.3 身份治理与管理（IGA）

#### 2.3.1 IGA 概述
**IGA 概念**
- Identity Governance and Administration
- 身份治理与管理
- 管理身份的全生命周期
- 确保正确的人有正确的权限

**IGA 核心功能**
- 身份生命周期管理
- 访问请求与审批
- 权限认证（Access Certification）
- 职责分离（SoD）
- 权限分析
- 合规报告

#### 2.3.2 身份生命周期管理
**生命周期阶段**
- 创建：入职、新用户
- 变更：调岗、晋升
- 停用：离职、休假
- 删除：永久删除
- 审计：定期审查

**自动化**
- HR 系统集成
- 自动开通
- 自动变更
- 自动回收
- 工作流驱动

#### 2.3.3 权限认证与复核
**权限认证（Access Certification）**
- 定期审查权限
- 管理者确认
- 权限回收
- 合规要求

**最小权限原则**
- 只分配必要的权限
- 权限最小化
- 定期清理权限
- 及时回收权限

**职责分离（SoD）**
- Separation of Duties
- 关键职责分离
- 防止舞弊
- 如：申请人和审批人不能是同一人

### 2.4 特权访问管理（PAM）

#### 2.4.1 PAM 概述
**特权账号概念**
- 权限最大的账号
- 风险最高的账号
- 攻击者的主要目标
- 如：管理员、root、DBA

**常见特权账号**
- 系统管理员
- 数据库管理员
- 网络管理员
- 应用管理员
- 服务账号
- 应急账号
- 测试账号

#### 2.4.2 PAM 核心功能
**核心功能**
- 特权账号金库（Vault）
- 密码管理
- 会话管理
- 命令控制
- 操作审计
- 审批工作流
- 即时权限（JIT）

#### 2.4.3 特权账号金库
**金库（Vault）**
- 集中存储特权密码
- 加密存储
- 访问控制
- 密码轮换
- 审计日志

**密码管理**
- 自动密码轮换
- 强密码生成
- 密码历史
- 密码策略

#### 2.4.4 会话管理与审计
**会话管理**
- 会话录制
- 实时监控
- 会话中断
- 命令控制
- 命令白名单/黑名单

**操作审计**
- 操作日志
- 命令审计
- 视频回放
- 风险告警
- 合规报告

#### 2.4.5 即时权限（JIT）
**JIT 概念**
- Just-In-Time
- 即时申请，即时授权
- 用完即收
- 最小权限

**JIT 特点**
- 按需申请
- 审批流程
- 时间限制
- 自动回收
- 审计记录

### 2.5 单点登录（SSO）

#### 2.5.1 SSO 概述
**SSO 概念**
- Single Sign-On
- 单点登录
- 一次登录，多处访问
- 提升用户体验
- 减少密码疲劳

**SSO 优势**
- 用户体验好
- 减少密码数量
- 集中管理
- 统一认证
- 安全审计

#### 2.5.2 SSO 协议
**常见协议**
- SAML（Security Assertion Markup Language）
- OAuth 2.0
- OpenID Connect（OIDC）
- CAS（Central Authentication Service）
- LDAP
- Kerberos

#### 2.5.3 SAML
**SAML 概述**
- 基于 XML 的认证协议
- 企业级 SSO 标准
- 身份提供商（IdP）和服务提供商（SP）
- 浏览器重定向

**SAML 流程**
1. 用户访问 SP
2. SP 重定向到 IdP
3. 用户在 IdP 认证
4. IdP 生成 SAML 断言
5. SP 验证断言
6. 用户登录成功

#### 2.5.4 OAuth 2.0
**OAuth 2.0 概述**
- 授权框架
- 不是认证协议
- 第三方应用授权
- 令牌机制

**OAuth 角色**
- 资源所有者（用户）
- 客户端（第三方应用）
- 授权服务器
- 资源服务器

**OAuth 授权模式**
- 授权码模式（Authorization Code）
- 隐式模式（Implicit）
- 密码模式（Resource Owner Password Credentials）
- 客户端模式（Client Credentials）
- 设备码模式（Device Code）

#### 2.5.5 OpenID Connect（OIDC）
**OIDC 概述**
- 基于 OAuth 2.0 的身份层
- 提供认证信息
- ID Token（JWT 格式）
- 现代 Web 应用常用

**OIDC 核心概念**
- ID Token：身份令牌
- Access Token：访问令牌
- Refresh Token：刷新令牌
- UserInfo 端点：用户信息

### 2.6 零信任架构（ZTA）

#### 2.6.1 零信任概述
**零信任概念**
- Zero Trust
- 永不信任，始终验证
- 不以网络位置判断信任
- 每次访问都验证
- 最小权限原则

**零信任核心原则**
- 永不信任，始终验证
- 最小权限
- 假设 breach
- 持续验证
- 动态访问控制
- 全面审计

#### 2.6.2 零信任架构
**零信任三大支柱**
- 身份：身份是新的安全边界
- 设备：设备安全状态
- 应用：应用级访问控制

**零信任关键技术**
- 身份认证与授权
- 设备信任评估
- 微隔离
- 软件定义边界（SDP）
- 持续验证
- 动态访问控制
- 安全分析

#### 2.6.3 零信任实施
**实施步骤**
1. 资产梳理
2. 身份治理
3. 设备管理
4. 应用接入
5. 微隔离
6. 持续监控
7. 持续优化

**常见挑战**
- 遗留系统
- 用户体验
- 复杂度
- 成本
- 组织变革

### 2.7 身份联邦

#### 2.7.1 身份联邦概述
**身份联邦概念**
- 不同组织之间共享身份
- 跨组织认证
- 一次认证，多处访问
- 信任关系建立

**联邦身份模型**
- 一对多：一个 IdP，多个 SP
- 多对多：多个 IdP，多个 SP
- 联邦枢纽：中间枢纽

#### 2.7.2 常见联邦标准
**标准与协议**
- SAML
- OAuth 2.0 / OIDC
- WS-Federation
- SCIM（System for Cross-domain Identity Management）
- LDAP

#### 2.7.3 企业身份联邦
**企业场景**
- 企业内部：统一身份
- 企业间：B2B 联邦
- 企业与云：云服务联邦
- 供应链：供应链身份

### 2.8 API 身份安全

#### 2.8.1 API 认证方式
**常见认证方式**
- API Key
- Basic Auth
- Bearer Token（JWT）
- OAuth 2.0
- mTLS（双向 TLS）
- HMAC 签名
- API 签名

#### 2.8.2 JWT 安全
**JWT 概述**
- JSON Web Token
- 无状态认证
- 三部分：Header、Payload、Signature
- Base64 编码，不是加密

**JWT 安全风险**
- 算法混淆攻击
- 密钥泄露
- 令牌泄露
- 重放攻击
- 权限提升
- 无状态问题（无法撤销）

**JWT 安全最佳实践**
- 使用强密钥
- 设置过期时间
- 验证签名
- 验证算法
- 使用 HTTPS
- 令牌刷新机制
- 黑名单机制（可选）

#### 2.8.3 API 授权
**API 授权模型**
- 基于角色（RBAC）
- 基于属性（ABAC）
- 基于范围（Scope）
- 基于策略

#### 2.9.2 Active Directory
**AD 概述**
- 微软活动目录
- Windows 域环境
- 企业最常用
- 集成度高

**AD 安全风险**
- 域管理员权限过大
- 黄金票据攻击
- 白银票据攻击
- Pass-the-Hash
- Pass-the-Ticket
- Kerberoasting
- AS-REP Roasting

**AD 安全防护**
- 最小权限
- 特权账号管理
- 组策略安全
- 补丁管理
- 监控审计
- 分层架构（Tier Model）

#### 2.9.3 LDAP
**LDAP 概述**
- Lightweight Directory Access Protocol
- 轻量级目录访问协议
- 标准协议
- 跨平台

## 六、常见面试题

### 基础概念
1. **什么是身份认证？什么是授权？什么是审计？**
   - 身份认证：验证你是谁（Authentication）
   - 授权：验证你能做什么（Authorization）
   - 审计：记录你做了什么（Accounting）
   - 合称 AAA

2. **常见的访问控制模型有哪些？各有什么特点？**
   - DAC（自主访问控制）：所有者决定，灵活但安全性低
   - MAC（强制访问控制）：系统强制，安全但不灵活
   - RBAC（基于角色）：按角色分配，平衡安全和灵活，最常用
   - ABAC（基于属性）：基于属性动态决策，灵活强大，零信任常用

3. **什么是 SSO？常见的 SSO 协议有哪些？**
   - SSO 是单点登录，一次登录多处访问
   - 常见协议：SAML、OAuth 2.0、OpenID Connect、CAS、LDAP、Kerberos

4. **什么是零信任？零信任的核心原则是什么？**
   - 零信任是一种安全理念：永不信任，始终验证
   - 不以网络位置判断信任，每次访问都验证
   - 核心原则：永不信任始终验证、最小权限、假设 breach、持续验证、动态访问控制、全面审计

### 技术原理
5. **OAuth 2.0 和 OpenID Connect 的区别是什么？**
   - OAuth 2.0 是授权框架，解决的是"授权"问题（你能做什么）
   - OpenID Connect 是基于 OAuth 2.0 的身份层，解决的是"认证"问题（你是谁）
   - OIDC 在 OAuth 基础上增加了 ID Token，提供身份信息

6. **JWT 的安全风险有哪些？如何防护？**
   - 风险：算法混淆攻击、密钥泄露、令牌泄露、重放攻击、权限提升、无法撤销
   - 防护：使用强密钥、设置过期时间、验证签名和算法、使用 HTTPS、令牌刷新机制、黑名单机制

7. **什么是 PAM？为什么需要 PAM？**
   - PAM 是特权访问管理（Privileged Access Management）
   - 特权账号权限最大、风险最高，是攻击者的主要目标
   - PAM 集中管理特权账号，控制访问，审计操作，降低风险
   - 核心功能：密码金库、会话管理、命令控制、操作审计、即时权限

8. **什么是 IGA？核心功能有哪些？**
   - IGA 是身份治理与管理（Identity Governance and Administration）
   - 管理身份的全生命周期
   - 核心功能：身份生命周期管理、访问请求与审批、权限认证、职责分离、权限分析、合规报告

### 实战相关
9. **AD 域的常见攻击方法有哪些？如何防护？**
    - 攻击：Pass-the-Hash、Pass-the-Ticket、黄金票据、白银票据、Kerberoasting、AS-REP Roasting、DCSync
    - 防护：最小权限、特权账号管理、组策略安全、补丁管理、监控审计、分层架构（Tier Model）

10. **如何设计一个企业的身份安全体系？**
    - 统一身份：建立统一的身份管理平台
    - 统一认证：SSO 单点登录
    - 多因素认证：MFA 保护关键账号
    - 特权管理：PAM 管理特权账号
    - 身份治理：IGA 治理身份生命周期
    - 零信任：向零信任架构演进
    - 安全监控：身份安全监控与审计

11. **MFA 的类型有哪些？各有什么优缺点？**
    - 短信验证码：方便但不安全，SIM 劫持
    - TOTP（Google Authenticator）：安全，需要手机
    - 硬件令牌（U2F/FIDO）：最安全，成本高
    - 生物识别：方便，有隐私和欺骗风险
    - 推送通知：方便，有疲劳攻击风险

12. **零信任如何实施？实施步骤是什么？**
    - 资产梳理：梳理需要保护的资产
    - 身份治理：建立统一身份体系
    - 设备管理：设备信任评估
    - 应用接入：应用接入零信任
    - 微隔离：网络微隔离
    - 持续监控：持续监控和分析
    - 持续优化：持续改进和优化

## 七、学习建议

### 7.1 学习方法
1. **先基础后高级**：先学好身份认证和访问控制基础，再学零信任等高级概念。

2. **理论结合实践**：多动手搭建实验环境，如 AD、Keycloak、PAM 等。

3. **从企业场景出发**：身份安全主要是企业场景，多了解企业需求和痛点。

4. **关注架构设计**：身份安全很多是架构层面的问题，要培养架构思维。

5. **了解合规要求**：身份安全与合规紧密相关，要了解相关法规和标准。

### 7.2 学习重点
- **身份认证技术**：基础中的基础
- **访问控制模型**：核心理论
- **单点登录（SSO）**：常用技术
- **身份治理（IGA）**：管理层面
- **特权访问管理（PAM）**：高风险领域
- **零信任架构**：当前热门
- **目录服务（AD/LDAP）**：企业基础
- **API 身份安全**：云原生时代重要
- **身份攻防**：攻击与防御
- **安全运营**：持续运营

### 7.3 常见误区
- ❌ 认为身份安全就是登录：身份安全远不止登录
- ❌ 只学技术不学管理：身份安全技术和管理都很重要
- ❌ 忽视治理：身份治理是身份安全的重要部分
- ❌ 认为零信任就是产品：零信任是理念和架构，不是单一产品
- ❌ 急于求成：身份安全体系建设是长期过程
- ❌ 不考虑用户体验：身份安全要平衡安全和用户体验

- **初级**：IAM 工程师、身份安全工程师、系统管理员
- **中级**：高级 IAM 工程师、身份安全架构师、PAM 工程师、零信任工程师
- **高级**：身份安全专家、安全架构师、身份治理专家
- **专家**：首席安全架构师、零信任架构师、安全咨询专家
