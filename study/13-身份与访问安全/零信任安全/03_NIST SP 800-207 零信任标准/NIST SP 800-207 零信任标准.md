# NIST SP 800-207 零信任标准

### 3.1 标准概述

**NIST SP 800-207**：《Zero Trust Architecture》（零信任架构），由美国国家标准与技术研究院于2020年发布，是零信任领域最权威的标准文档。

**标准定位**：
- 不是产品规范，而是架构和概念框架
- 提供零信任的通用定义和原则
- 描述零信任架构的组成和部署方法
- 适用于各种规模的企业和组织

### 3.2 零信任的定义

NIST 对零信任的定义：

> **Zero Trust (ZT)**：一组 cybersecurity paradigms that move defenses from static, network-based perimeters to focus on users, assets, and resources.
>
> **零信任**：一组网络安全范式，将防御从静态的、基于网络的边界转移到关注用户、资产和资源上。

> **Zero Trust Architecture (ZTA)**：An enterprise’s cybersecurity architecture that utilizes Zero Trust concepts and encompasses component relationships, workflow planning, and access policies.
>
> **零信任架构**：一种企业网络安全架构，利用零信任概念，包含组件关系、工作流规划和访问策略。

### 3.3 零信任基本假设

NIST 列出了零信任的基本假设：

1. **假设1**：网络位置不代表信任
   - 企业拥有的网络不自动被信任
   - 内部和外部网络没有本质区别

2. **假设2**：所有资产和用户主体都需要身份
   - 每个设备、用户、服务都有身份
   - 身份是访问决策的基础

3. **假设3**：每个访问请求都经过授权
   - 没有自动的信任
   - 每次访问都需要评估

4. **假设4**：访问策略是动态的
   - 基于多个因素的评估
   - 随时间和行为变化而调整

5. **假设5**：企业监控和衡量资产和基础设施的完整性
   - 持续监控安全状态
   - 及时发现和响应异常

### 3.4 零信任部署方法

NIST 描述了三种零信任架构实施方法：

#### 方法一：使用增强身份治理

```
核心：以身份为中心
┌───────────┐
│  IAM/IdP  │ ← 策略决策的核心
└─────┬─────┘
      │
      ▼
  应用/资源
```

**特点**：
- 基于身份的访问控制
- 强认证和动态授权
- 适合已有成熟IAM体系的组织
- 实施相对简单

#### 方法二：使用微隔离

```
核心：网络微分段
┌─────────────────────┐
│  微隔离 / SDP        │
│  每个工作负载独立防护 │
└─────────────────────┘
```

**特点**：
- 工作负载级别的访问控制
- 限制横向移动
- 适合云环境和数据中心
- 需要软件定义网络支持

#### 方法三：使用统一组件和分析

```
核心：统一的策略和分析平台
┌─────────────────────┐
│  统一策略引擎        │
│  + 全面数据分析      │
└─────────────────────┘
```

**特点**：
- 集中的策略管理
- 多源数据融合分析
- 最全面但也最复杂
- 需要强大的分析能力

### 3.5 零信任部署的十大步骤

NIST 建议的零信任实施步骤：

1. **确定攻击面**：识别需要保护的资产和资源
2. **确定资产的访问流程**：梳理谁在什么情况下访问什么资源
3. **构建零信任架构**：设计整体架构和组件
4. **创建身份和访问管理系统**：建立统一身份体系
5. **为工作负载开发策略**：定义访问控制策略
6. **监控和日志记录**：建立全面的监控体系
7. **自动化和编排**：实现策略自动执行
8. **扩展范围**：逐步扩大零信任覆盖范围
9. **迭代优化**：持续改进和优化
10. **文化变革**：培养零信任安全文化
