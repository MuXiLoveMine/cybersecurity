# 学习与实践建议

### 动手实践

1. **搭建 AD 实验环境**：
   - 使用 VMware/VirtualBox 安装 Windows Server
   - 配置 Active Directory 域服务
   - 创建用户、组、OU，练习组策略
   - 加入客户端计算机到域

2. **AD 攻击实验**：
   - 使用 Mimikatz 练习 Pass-the-Hash
   - 使用 Rubeus 练习 Kerberoasting
   - 使用 BloodHound 分析 AD 攻击路径
   - （注意：仅在授权的实验环境中进行）

3. **部署开源 IAM**：
   - 部署 Keycloak 或 Casdoor
   - 配置用户、角色、权限
   - 配置 SAML/OIDC 应用集成
   - 体验 SSO 单点登录

4. **身份生命周期管理**：
   - 设计一个企业的身份生命周期流程
   - 编写自动化脚本模拟用户入职/离职流程
   - 设计权限认证流程

### 推荐工具

| 类别 | 工具 | 用途 |
|------|------|------|
| 目录服务 | Active Directory | 企业级目录服务 |
| 目录服务 | OpenLDAP | 开源目录服务 |
| IAM平台 | Keycloak | 开源IAM/SSO |
| IAM平台 | Casdoor | 开源IAM |
| AD攻击 | Mimikatz | 凭证窃取工具 |
| AD攻击 | BloodHound | AD攻击路径分析 |
| AD攻击 | Rubeus | Kerberos攻击工具 |
| AD攻击 | Impacket | 网络协议工具集 |
| PAM | JumpServer | 开源堡垒机 |
| PAM | HashiCorp Vault | 密钥管理 |

---

> 💡 **IAM 是企业安全的基础设施。从目录服务到身份联邦，从生命周期管理到身份治理，IAM 体系庞大而复杂。掌握 IAM 技术，不仅是安全工程师的核心技能，也是向安全架构师发展的必经之路。**
