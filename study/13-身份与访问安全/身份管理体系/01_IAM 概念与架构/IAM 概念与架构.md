# IAM 概念与架构

### 1.1 什么是 IAM

**IAM（Identity and Access Management）**：身份与访问管理，是一套用于管理数字身份、控制访问权限、确保合规审计的技术体系、流程和策略的组合。

**IAM 的核心目标**：
- 确保正确的人（身份）
- 在正确的时间（时机）
- 以正确的理由（业务需要）
- 访问正确的资源（权限）
- 并且所有操作可审计

**IAM 覆盖的范围**：
```
┌─────────────────────────────────────────────────┐
│                  IAM 体系                         │
├──────────┬──────────┬──────────┬────────────────┤
│  身份管理  │  认证管理  │  授权管理  │  审计与治理    │
│ (Identity)│(Authentication)│(Authorization)│(Governance)│
├──────────┼──────────┼──────────┼────────────────┤
│ 用户管理  │ 密码认证  │ RBAC     │ 权限审查       │
│ 目录服务  │ MFA     │ ABAC     │ 合规报告       │
│ 生命周期  │ SSO     │ 策略管理  │ 身份分析       │
│ 身份联邦  │ 生物识别  │ 特权管理  │ 风险评估       │
└──────────┴──────────┴──────────┴────────────────┘
```

### 1.2 IAM 的业务价值

| 价值维度 | 说明 |
|----------|------|
| **安全提升** | 统一身份管理，减少身份泄露和越权访问风险 |
| **合规保障** | 满足等保、GDPR、SOX等合规要求 |
| **效率提升** | 自动化身份生命周期管理，减少人工操作 |
| **用户体验** | SSO单点登录，减少密码记忆负担 |
| **成本降低** | 集中管理降低运维成本 |
| **业务赋能** | 快速支撑新业务上线，敏捷交付 |

### 1.3 IAM 架构模型

#### 传统 IAM 架构
```
┌─────────────────────────────────────────────┐
│                  管理控制台                   │
├──────────────┬──────────────┬───────────────┤
│  身份管理     │  认证服务     │  授权服务      │
│ (User Mgmt)  │  (AuthN)     │  (AuthZ)      │
├──────────────┴──────────────┴───────────────┤
│              目录服务 (LDAP/AD)              │
├─────────────────────────────────────────────┤
│              审计日志服务                    │
└─────────────────────────────────────────────┘
```

#### 现代云原生 IAM 架构
```
┌──────────────────────────────────────────────────────┐
│                   API 网关 / 策略引擎                  │
├──────────┬──────────┬──────────┬──────────┬──────────┤
│ 身份服务  │ 认证服务  │ 授权服务  │ 联邦服务  │ 治理服务  │
│ Identity │ AuthN    │ AuthZ    │ Fed      │ Gov      │
├──────────┴──────────┴──────────┴──────────┴──────────┤
│                   统一目录 / 用户存储                   │
├──────────────────────────────────────────────────────┤
│                   审计与分析平台                       │
└──────────────────────────────────────────────────────┘
```

### 1.4 IAM 核心组件

| 组件 | 功能 | 典型产品/技术 |
|------|------|--------------|
| 目录服务 | 存储身份信息 | Active Directory、OpenLDAP |
| 身份管理 | 用户生命周期管理 | IdM、IGA 平台 |
| 认证服务 | 身份验证 | SSO、MFA、密码服务 |
| 授权服务 | 访问控制决策 | RBAC、ABAC、策略引擎 |
| 联邦服务 | 跨组织身份共享 | SAML、OAuth、OIDC |
| 特权管理 | 特权账号管控 | PAM、堡垒机 |
| 审计治理 | 合规与审计 | IGA、SIEM、身份分析 |
