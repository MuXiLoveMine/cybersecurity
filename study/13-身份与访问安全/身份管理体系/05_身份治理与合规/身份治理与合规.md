# 身份治理与合规

### 5.1 什么是身份治理

**身份治理（Identity Governance）**：通过制定政策、流程和控制措施，确保身份和访问权限的分配、使用和审查符合企业安全策略和合规要求。

**身份治理的核心问题**：
- 谁拥有什么权限？
- 这些权限是否合理？
- 权限是否经过审批？
- 是否存在过度授权？
- 是否满足合规要求？

### 5.2 IGA 核心功能

**IGA（Identity Governance and Administration）**：身份治理与管理，是身份管理的高级阶段。

| 功能模块 | 说明 |
|----------|------|
| 身份生命周期管理 | 用户创建、变更、停用的自动化流程 |
| 访问请求与审批 | 用户自助申请权限，审批流 |
| 权限认证（Access Certification） | 定期审查权限的合理性 |
| 职责分离（SoD） | 检测和预防权限冲突 |
| 权限分析 | 分析权限分配，识别风险 |
| 合规报告 | 生成合规审计报告 |

### 5.3 权限认证（Access Certification）

**定义**：定期让管理者确认下属用户的权限是否仍然合理，回收不再需要的权限。

**认证流程**：
```
1. 发起认证 campaign
   ↓
2. 生成待审查项（每个用户的权限）
   ↓
3. 发送给评审人（通常是部门经理）
   ↓
4. 评审人逐项确认：
   - 保留：该权限仍然需要
   - 撤销：该权限不再需要
   - 转交：转交给其他评审人
   ↓
5. 自动执行撤销操作
   ↓
6. 生成认证报告
```

**认证类型**：

| 类型 | 说明 | 频率 |
|------|------|------|
| 用户认证 | 评审用户拥有的所有权限 | 季度/半年 |
| 角色认证 | 评审角色的成员是否合理 | 季度/半年 |
| 特权认证 | 重点审查特权账号 | 月度/季度 |
| 应用认证 | 评审应用的访问权限 | 半年/年度 |

### 5.4 合规与审计

#### 常见合规要求

| 法规/标准 | 相关要求 |
|-----------|----------|
| **等保2.0** | 身份鉴别、访问控制、安全审计 |
| **ISO 27001** | 访问控制（A.9）、权限管理 |
| **GDPR** | 数据主体权利、访问控制、审计 |
| **SOX** | 职责分离、访问控制、变更管理 |
| **PCI-DSS** | 唯一ID、最小权限、审计日志 |

#### 身份合规审计要点

1. **身份生命周期**：
   - 入职是否及时开通账号？
   - 离职是否及时回收权限？
   - 调岗是否调整权限？

2. **权限管理**：
   - 是否遵循最小权限原则？
   - 是否有职责分离冲突？
   - 特权账号是否受控？

3. **访问审计**：
   - 是否有完整的访问日志？
   - 日志是否安全存储？
   - 是否定期审查日志？

4. **认证强度**：
   - 关键系统是否启用MFA？
   - 密码策略是否合规？
   - 特权账号是否有特殊保护？
