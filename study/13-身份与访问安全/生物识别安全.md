## 一、生物识别概述

### 1.1 生物识别原理

**生物识别（Biometric Recognition）** 是利用人体固有的生理特征或行为特征进行身份识别的技术。

```text
生物识别基本原理

识别模式:
├── 验证 (Verification, 1:1): "我是我声称的人吗？"
│   ├── 输入: 声称身份 + 生物特征
│   └── 输出: 接受/拒绝

├── 辨识 (Identification, 1:N): "我是谁？"
│   ├── 输入: 生物特征
│   └── 输出: 身份/未知

└── 排查 (Watchlist, 1:M): "是否在监视名单中？"
    ├── 输入: 生物特征
    └── 输出: 在名单中/不在

生物识别流程:
┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐
│ 采集  │──►│ 增强  │──►│ 特征  │──►│ 比对  │
│Sensor │   │Enhance│   │Extract│   │ Match │
└──────┘   └──────┘   └──────┘   └──────┘
                                      │
                              ┌───────▼───────┐
                              │  决策 (Decision) │
                              └───────────────┘

注册流程 (Enrollment):
  采集 → 特征提取 → 模板生成 → 存储
  注意: 不存储原始生物特征，只存储模板
```

### 1.2 生物特征分类

```text
生物特征分类

生理特征 (Physiological):
├── 指纹 (Fingerprint): 最成熟，使用最广
├── 人脸 (Face): 非接触，接受度高
├── 虹膜 (Iris): 准确率最高
├── 视网膜 (Retina): 安全但侵入性强
├── 掌纹 (Palmprint): 大面积特征
├── 掌静脉 (Palm Vein): 活体性好
├── 指静脉 (Finger Vein): 活体性好
├── DNA: 最准确但慢
└── 耳形 (Ear Shape): 稳定性好

行为特征 (Behavioral):
├── 签名 (Signature): 动态签名
├── 声纹 (Voiceprint): 自然交互
├── 步态 (Gait): 远距离识别
├── 击键模式 (Keystroke): 连续认证
└── 心电图 (ECG): 活体性强

理想生物特征的标准:
├── 普遍性 (Universality): 每个人都有
├── 独特性 (Uniqueness): 人各不同
├── 持久性 (Permanence): 时间稳定
├── 可采集 (Collectability): 易于采集
├── 性能 (Performance): 准确快速
├── 可接受 (Acceptability): 用户接受
└── 防欺骗 (Circumvention): 难以伪造
```

### 1.3 评价指标

| 指标 | 说明 | 公式 |
|------|------|------|
| FAR | 误识率（假冒者被接受） | FA/N |
| FRR | 拒真率（真实者被拒绝） | FR/N |
| EER | 等错误率（FAR=FRR点） | - |
| TAR | 真识率（真实者被接受） | 1-FRR |
| FMR | 假匹配率 | 类似FAR |
| FNMR | 假不匹配率 | 类似FRR |
| GAR | 识别率 | 1-FRR |

```text
性能指标详解

FAR (False Acceptance Rate) - 误识率:
  非法用户被系统接受的概率
  例: FAR=0.01% → 10000次中1次错误接受
  安全要求: FAR越低越安全

FRR (False Rejection Rate) - 拒真率:
  合法用户被系统拒绝的概率
  例: FRR=5% → 20次中1次错误拒绝
  体验要求: FRR越低越好

EER (Equal Error Rate) - 等错误率:
  FAR = FRR 时的错误率
  总体性能指标: EER越低越好

ROC曲线 (Receiver Operating Characteristic):
  FAR vs TAR 曲线
  越靠近左上角越好

安全性与便利性的权衡:
  高安全场景: 降低FAR（但FRR升高）→ 安全但不便
  高便利场景: 降低FRR（但FAR升高）→ 便利但不安全
  平衡点: EER附近

典型性能:
├── 指纹: FAR=0.001%, FRR=2%
├── 人脸(3D): FAR=0.01%, FRR=0.1%
├── 虹膜: FAR=0.0001%, FRR=0.5%
├── 声纹: FAR=1%, FRR=5%
└── 多模态: FAR=0.00001%, FRR=0.1%
```

## 二、指纹识别安全

### 2.1 指纹特征提取

```text
指纹识别原理

指纹基本特征:
├── 全局特征 (Level 1):
│   ├── 弓型 (Arch)
│   ├── 箕型 (Loop)
│   ├── 斗型 (Whorl)
│   └── 用于粗分类
│
├── 局部特征 (Level 2):
│   ├── 端点 (Ridge Ending)
│   ├── 分叉点 (Bifurcation)
│   ├── 短纹 (Short Ridge)
│   ├── 点 (Dot)
│   └── 核心 (Minutiae) - 最重要
│
└── 微观特征 (Level 3):
    ├── 汗孔 (Pore)
    ├── 纹线宽度
    ├── 纹线边缘
    └── 用于高精度匹配

特征提取流程:
1. 图像采集 → 指纹图像
2. 图像增强 → 去噪、定向
3. 二值化 → 黑白指纹
4. 细化 → 单像素宽纹线
5. 端点提取 → 坐标+方向
6. 模板生成 → 端点集合
```

```python
import numpy as np

class FingerprintFeatureExtractor:
    """指纹特征提取（简化版）"""

    def __init__(self):
        self.minutiae_threshold = 3

    def extract_minutiae(self, fingerprint_image):
        """
        从指纹图像中提取端点
        :param fingerprint_image: 二值化指纹图像 (0/1)
        :return: 端点列表
        """
        # 二值化
        if fingerprint_image.max() > 1:
            binary = (fingerprint_image > 128).astype(np.uint8)
        else:
            binary = fingerprint_image.astype(np.uint8)

        # 细化（简化）
        thinned = self._thin(binary)

        # 端点检测
        minutiae = self._detect_minutiae(thinned)

        # 过滤边界点
        minutiae = self._filter_border_minutiae(minutiae, thinned.shape)

        return minutiae

    def _thin(self, binary):
        """细化操作（简化）"""
        # 实际使用Zhang-Suen或Guo-Hall算法
        return binary

    def _detect_minutiae(self, thinned):
        """检测端点和分叉点"""
        minutiae = []
        rows, cols = thinned.shape

        for i in range(1, rows - 1):
            for j in range(1, cols - 1):
                if thinned[i, j] == 1:  # 前景像素
                    # 计算交叉数(Crossing Number)
                    cn = self._crossing_number(thinned, i, j)

                    if cn == 1:
                        minutiae.append({
                            'type': 'ending',
                            'x': j, 'y': i,
                            'direction': self._compute_direction(thinned, i, j)
                        })
                    elif cn == 3:
                        minutiae.append({
                            'type': 'bifurcation',
                            'x': j, 'y': i,
                            'direction': self._compute_direction(thinned, i, j)
                        })

        return minutiae

    @staticmethod
    def _crossing_number(image, i, j):
        """计算交叉数"""
        # 8邻域顺时针
        neighbors = [
            image[i-1, j], image[i-1, j+1], image[i, j+1], image[i+1, j+1],
            image[i+1, j], image[i+1, j-1], image[i, j-1], image[i-1, j-1]
        ]

        cn = 0
        for k in range(8):
            cn += abs(int(neighbors[k]) - int(neighbors[(k+1) % 8]))

        return cn // 2

    @staticmethod
    def _compute_direction(image, i, j):
        """计算端点方向（简化）"""
        return 0.0

    @staticmethod
    def _filter_border_minutiae(minutiae, shape, margin=10):
        """过滤边界附近的端点"""
        return [m for m in minutiae
                if margin < m['x'] < shape[1] - margin
                and margin < m['y'] < shape[0] - margin]

    @staticmethod
    def match_templates(template1, template2, threshold=12):
        """
        比对两个指纹模板
        :param template1: 端点列表1
        :param template2: 端点列表2
        :param threshold: 匹配端点数阈值
        :return: 匹配分数
        """
        matched_count = 0

        for m1 in template1:
            for m2 in template2:
                # 距离匹配
                dist = np.sqrt((m1['x'] - m2['x'])**2 +
                               (m1['y'] - m2['y'])**2)
                if dist < 10:  # 距离阈值
                    # 方向匹配
                    angle_diff = abs(m1['direction'] - m2['direction'])
                    if angle_diff < 0.3:  # 角度阈值
                        matched_count += 1
                        break

        match_score = matched_count / max(len(template1), 1)
        is_match = matched_count >= threshold

        return {
            'matched': is_match,
            'score': match_score,
            'matched_count': matched_count
        }
```

### 2.2 AFIS系统

**AFIS (Automated Fingerprint Identification System)** 是自动指纹识别系统，用于大规模指纹比对。

```text
AFIS系统架构

┌──────────────────────────────────────────────────────┐
│                   AFIS系统                             │
├──────────────────────────────────────────────────────┤
│  采集层: 指纹扫描仪/活体采集                           │
│  处理层: 图像增强/特征提取                             │
│  比对层: 快速搜索/精确比对                             │
│  存储层: 指纹数据库(模板存储)                          │
│  管理层: 用户管理/审计日志                             │
└──────────────────────────────────────────────────────┘

比对模式:
├── 1:1验证: 比对两个模板
├── 1:N排查: 在数据库中搜索
└── 1:1:N: 验证+排查

性能要求:
├── 指纹库规模: 百万至亿级
├── 搜索速度: 10000模板/秒
├── 精确度: FAR < 0.001%
└── 活体检测: 防止假指纹
```

### 2.3 指纹攻击与防御

```text
指纹识别安全威胁

威胁1: 假指纹攻击
  ├── 攻击者制作假指纹（硅胶/3D打印）
  ├── 从照片/物体表面提取指纹
  └── 防御: 活体检测（温度/湿度/电容）

威胁2: 指纹数据泄露
  ├── 指纹模板从数据库泄露
  ├── 生物特征不可更换 → 永久泄露
  └── 防御: 模板加密存储 + 不可逆变换

威胁3: 中间人攻击
  ├── 截获指纹传输数据
  ├── 重放指纹模板
  └── 防御: 传输加密 + challenge-response

威胁4: 深度伪造
  ├── 利用AI生成指纹图像
  └── 防御: 多维度活体检测

威胁5: 数据库注入
  ├── 在数据库中注入攻击者指纹模板
  └── 防御: 数据库访问控制 + 审计
```

## 三、人脸识别安全

### 3.1 2D与3D人脸识别

```text
2D与3D人脸识别对比

2D人脸识别:
├── 技术: 基于平面图像
├── 特征: LBP/HOG/深度学习特征
├── 优势: 成本低，部署容易
├── 劣势: 易被照片/视频欺骗
└── 应用: 手机解锁(早期)，门禁

3D人脸识别:
├── 技术: 基于深度信息
├── 特征: 3D点云/深度图/结构光
├── 优势: 防照片攻击，更准确
├── 劣势: 成本高，需要3D传感器
└── 应用: Face ID，高安全门禁

红外人脸识别:
├── 技术: 基于红外图像
├── 特征: 红外波段特征
├── 优势: 不受光照影响，防照片
└── 应用: 暗光环境，高安全场景

多光谱识别:
├── 结合可见光+红外+3D
├── 最高安全性
└── 应用: 边境检查，金融认证

人脸识别流程:
1. 人脸检测: 检测图像中的人脸
2. 人脸对齐: 关键点定位和归一化
3. 特征提取: 生成人脸特征向量
4. 特征比对: 计算特征向量相似度
5. 决策: 基于阈值判断

人脸关键点 (Face Landmarks):
├── 5点: 双眼+鼻尖+嘴角两端
├── 68点: 标准关键点集
├── 106点: 高精度关键点
└── 240点: 超高精度

特征向量:
├── 2D: 128-512维向量
├── 3D: 3D点云特征
└── 比对: 余弦相似度/欧氏距离
```

### 3.2 活体检测技术

```text
人脸活体检测技术

1. 配合式活体检测 (Active Liveness)
   ├── 眨眼检测: 要求用户眨眼
   ├── 张嘴检测: 要求用户张嘴
   ├── 摇头检测: 要求用户摇头
   ├── 随机动作: 随机要求动作组合
   └── 读数字: 要求读出随机数字(音视频同步)

2. 静默式活体检测 (Passive Liveness)
   ├── 纹理分析: 照片/屏幕纹理检测
   ├── 光照分析: 反射/阴影一致性
   ├── 运动分析: 微表情/呼吸
   ├── 深度分析: 3D结构验证
   └── 红外分析: 红外特性验证

3. 3D结构活体检测
   ├── 结构光: 投射光栅图案
   ├── ToF: 飞时测距
   ├── 双目视觉: 立体匹配
   └── 特征: 真实人脸有3D结构，照片无

4. 多模态活体检测
   ├── 可见光 + 红外
   ├── 2D + 3D
   ├── 视频 + 音频
   └── 最强防御方案
```

```python
class FaceLivenessDetector:
    """人脸活体检测器"""

    def __init__(self):
        self.active_actions = ['blink', 'mouth_open', 'turn_head_left',
                               'turn_head_right', 'smile']
        self.passive_threshold = 0.5

    def active_liveness_check(self, video_frames, requested_action):
        """
        配合式活体检测
        :param video_frames: 视频帧序列
        :param requested_action: 要求的动作
        """
        # 提取面部关键点序列
        landmarks_sequence = self._extract_landmarks(video_frames)

        if requested_action == 'blink':
            return self._check_blink(landmarks_sequence)
        elif requested_action == 'mouth_open':
            return self._check_mouth_open(landmarks_sequence)
        elif requested_action == 'turn_head_left':
            return self._check_head_turn(landmarks_sequence, 'left')
        elif requested_action == 'turn_head_right':
            return self._check_head_turn(landmarks_sequence, 'right')
        elif requested_action == 'smile':
            return self._check_smile(landmarks_sequence)

        return {'passed': False, 'reason': '未知动作'}

    def passive_liveness_check(self, image):
        """
        静默式活体检测
        :param image: 单张图像
        """
        results = {
            'texture': self._check_texture(image),
            'color': self._check_color_distribution(image),
            'frequency': self._check_frequency(image),
            'reflection': self._check_light_reflection(image)
        }

        # 综合判断
        scores = [r['score'] for r in results.values() if 'score' in r]
        avg_score = sum(scores) / len(scores) if scores else 0.5

        return {
            'passed': avg_score > self.passive_threshold,
            'score': avg_score,
            'details': results
        }

    def _check_blink(self, landmarks_sequence):
        """检查眨眼"""
        # 计算眼睛纵横比(EAR)的变化
        ear_values = []
        for landmarks in landmarks_sequence:
            # 左眼EAR
            left_ear = self._eye_aspect_ratio(landmarks, 'left')
            right_ear = self._eye_aspect_ratio(landmarks, 'right')
            ear = (left_ear + right_ear) / 2
            ear_values.append(ear)

        # 检测EAR从高到低再到高的变化（眨眼）
        if len(ear_values) > 3:
            min_ear = min(ear_values)
            max_ear = max(ear_values)
            if max_ear - min_ear > 0.05:  # 眨眼阈值
                return {'passed': True, 'reason': '检测到眨眼'}
            else:
                return {'passed': False, 'reason': '未检测到眨眼'}

        return {'passed': False, 'reason': '帧数不足'}

    @staticmethod
    def _eye_aspect_ratio(landmarks, side='left'):
        """计算眼睛纵横比(EAR)"""
        # EAR = |p2-p6| + |p3-p5| / 2 / |p1-p4|
        # 简化返回
        return 0.3

    @staticmethod
    def _extract_landmarks(video_frames):
        """提取面部关键点序列"""
        # 实际使用dlib或MediaPipe
        return [{'eyes': 0.3, 'mouth': 0.1, 'head_pose': 0}
                for _ in range(len(video_frames))]

    @staticmethod
    def _check_mouth_open(landmarks_sequence):
        """检查张嘴"""
        return {'passed': True, 'reason': '检测到张嘴'}

    @staticmethod
    def _check_head_turn(landmarks_sequence, direction):
        """检查转头"""
        return {'passed': True, 'reason': f'检测到{direction}转头'}

    @staticmethod
    def _check_smile(landmarks_sequence):
        """检查微笑"""
```

## 八、多模态生物识别

### 8.1 融合策略

```text
多模态生物识别融合策略

1. 传感器级融合 (Sensor Level)
   ├── 多传感器数据融合
   ├── 例: 可见光 + 红外人脸
   └── 融合后进行特征提取

2. 特征级融合 (Feature Level)
   ├── 不同生物特征的特征向量拼接
   ├── 例: 人脸特征 + 声纹特征
   └── 可能需要降维

3. 分数级融合 (Score Level)
   ├── 各模态独立匹配
   ├── 融合匹配分数
   ├── 例: 人脸分数0.8 + 声纹分数0.7
   └── 最常用策略

4. 决策级融合 (Decision Level)
   ├── 各模态独立决策
   ├── 融合最终决策
   ├── 例: 人脸接受 + 声纹接受 → 最终接受
   └── 信息丢失最多

5. 混合融合
   ├── 结合多种融合策略
   └── 最灵活但复杂

分数级融合方法:
├── 简单平均: (score1 + score2) / 2
├── 加权平均: w1*score1 + w2*score2
├── 最大值: max(score1, score2)
├── 最小值: min(score1, score2)
├── 乘积: score1 * score2
├── 贝叶斯决策: 基于后验概率
├── SVM分类: 学习融合权重
└── 深度学习: 端到端学习

融合优势:
├── 提高准确率
├── 降低FAR和FRR
├── 提高鲁棒性
├── 增强安全性
└── 改善用户体验
```

### 8.2 多模态架构

```python
class MultimodalBiometricSystem:
    """多模态生物识别系统"""

    def __init__(self, face_threshold=0.6, voice_threshold=0.55,
                 fingerprint_threshold=0.5):
        self.face_threshold = face_threshold
        self.voice_threshold = voice_threshold
        self.fingerprint_threshold = fingerprint_threshold

        # 各模态权重
        self.weights = {
            'face': 0.4,
            'voice': 0.3,
            'fingerprint': 0.3
        }

    def authenticate(self, face_data, voice_data, fingerprint_data):
        """多模态认证"""
        # 各模态独立匹配
        face_result = self._match_face(face_data)
        voice_result = self._match_voice(voice_data)
        fp_result = self._match_fingerprint(fingerprint_data)

        # 分数级融合
        fusion_result = self._fuse_scores({
            'face': face_result,
            'voice': voice_result,
            'fingerprint': fp_result
        })

        return fusion_result

    def _fuse_scores(self, results):
        """分数级融合"""
        # 加权平均
        weighted_sum = 0
        total_weight = 0
        details = {}

        for modality, result in results.items():
            score = result.get('score', 0)
            weight = self.weights.get(modality, 0)
            weighted_sum += score * weight
            total_weight += weight
            details[modality] = {
                'score': score,
                'threshold': getattr(self, f'{modality}_threshold'),
                'weight': weight,
                'matched': result.get('matched', False)
            }

        fused_score = weighted_sum / total_weight if total_weight > 0 else 0

        # 决策规则: 至少2个模态通过 且 融合分数 > 0.6
        passed_count = sum(1 for r in results.values()
                           if r.get('matched', False))
        decision = passed_count >= 2 and fused_score > 0.6

        return {
            'authenticated': decision,
            'fused_score': fused_score,
            'passed_count': passed_count,
            'total_modalities': len(results),
            'details': details
        }

    def _match_face(self, face_data):
        """人脸匹配"""
        return {'matched': True, 'score': 0.75}

    def _match_voice(self, voice_data):
        """声纹匹配"""
        return {'matched': True, 'score': 0.65}

    def _match_fingerprint(self, fp_data):
        """指纹匹配"""
        return {'matched': False, 'score': 0.45}
```

## 九、FIDO2与WebAuthn

### 9.1 FIDO2架构

```text
FIDO2标准体系

FIDO2 = WebAuthn + CTAP

WebAuthn (Web Authentication):
├── W3C标准
├── 浏览器API
├── 网站与认证器之间的认证协议
└── 替代密码的Web认证

CTAP (Client to Authenticator Protocol):
├── FIDO Alliance标准
├── 客户端与认证器之间的通信协议
├── CTAP1: 基于U2F的USB/NFC协议
└── CTAP2: 支持平台认证器和更多功能

核心概念:
├── 认证器 (Authenticator): 存储密钥的设备
│   ├── 平台认证器: 内置于设备（如TouchID）
│   ├── 漫游认证器: 外部设备（如YubiKey）
│   └── 安全密钥: USB/NFC/BLE

├── 依赖方 (Relying Party, RP): 网站或应用
│   └── 依赖认证器进行用户认证

├── 凭据 (Credential):
│   ├── 公钥: 发送给RP存储
│   └── 私钥: 存储在认证器中，不可导出

└── 挑战 (Challenge):
    └── RP生成的随机数，防重放

FIDO2安全特性:
├── 非对称加密: 私钥不离开认证器
├── 域绑定: 密钥绑定到特定域名
├── 防钓鱼: 不同域名使用不同密钥
├── 用户验证: 生物识别/PIN
├── 设备绑定: 绑定到特定认证器
├── 多设备: 可注册多个认证器
└── 无密码: 替代传统密码
```

### 9.2 WebAuthn流程

```text
WebAuthn注册流程

1. RP生成挑战
   RP → 浏览器: PublicKeyCredentialCreationOptions
   包含:
   ├── challenge: 随机挑战值
   ├── rp: {name, id} (RP信息)
   ├── user: {id, name, displayName} (用户信息)
   ├── pubKeyCredParams: 支持的算法
   ├── authenticatorSelection: 认证器要求
   │   ├── userVerification: required/preferred/discouraged
   │   ├── authenticatorAttachment: platform/cross-platform
   │   └── requireResidentKey: 是否需要存储用户信息
   └── excludeCredentials: 排除已注册的凭据

2. 浏览器调用认证器
   浏览器 → 认证器: navigator.credentials.create(options)
   用户: 进行生物识别/PIN验证

3. 认证器生成密钥对
   认证器:
   ├── 生成非对称密钥对
   ├── 私钥安全存储(不可导出)
   ├── 生成凭据ID
   ├── 用RP的公钥签名attestation
   └── 返回: {credentialId, publicKey, attestation}

4. 浏览器返回结果
   浏览器 → RP: AuthenticatorAttestationResponse
   包含:
   ├── clientDataJSON: 客户端数据
   ├── attestationObject: 认证器签名数据
   └── 包含公钥和签名

5. RP验证并存储
   RP:
   ├── 验证challenge
   ├── 验证origin
   ├── 验证attestation签名
   ├── 存储公钥和凭据ID
   └── 注册完成

WebAuthn认证流程

1. RP生成挑战
   RP → 浏览器: PublicKeyCredentialRequestOptions
   包含:
   ├── challenge: 随机挑战值
   ├── rpId: RP标识
   ├── allowCredentials: 允许的凭据列表
   └── userVerification: 验证要求

2. 浏览器调用认证器
   浏览器 → 认证器: navigator.credentials.get(options)
   用户: 生物识别/PIN验证

3. 认证器签名
   认证器:
   ├── 用私钥签名(challenge + origin + counter)
   ├── 返回签名和计数器
   └── counter: 防克隆(每次递增)

4. RP验证
   RP:
   ├── 验证challenge
   ├── 验证origin
   ├── 验证签名(用存储的公钥)
   ├── 验证计数器(必须递增)
   └── 认证完成
```

```python
"""
WebAuthn服务端验证实现
"""
import base64
import json
import secrets
import hashlib

class WebAuthnServer:
    """WebAuthn服务端"""

    def __init__(self, rp_id, rp_name, origin):
        self.rp_id = rp_id  # 例: "example.com"
        self.rp_name = rp_name
        self.origin = origin  # 例: "https://example.com"
        self.registered_credentials = {}  # user_id → [credentials]

    def generate_registration_options(self, user_id, username,
                                        user_display_name):
        """生成注册选项"""
        challenge = secrets.token_bytes(32)

        options = {
            'challenge': base64.urlsafe_b64encode(challenge).decode(),
            'rp': {
                'name': self.rp_name,
                'id': self.rp_id
            },
            'user': {
                'id': base64.urlsafe_b64encode(user_id.encode()).decode(),
                'name': username,
                'displayName': user_display_name
            },
            'pubKeyCredParams': [
                {'type': 'public-key', 'alg': -7},   # ES256
                {'type': 'public-key', 'alg': -257},  # RS256
            ],
            'authenticatorSelection': {
                'authenticatorAttachment': 'platform',
                'userVerification': 'required',
                'requireResidentKey': False
            },
            'timeout': 60000,
            'excludeCredentials': []
        }

        return options, challenge

    def verify_registration(self, user_id, credential_response,
                             expected_challenge):
        """验证注册响应"""
        try:
            # 解析clientDataJSON
            client_data = json.loads(
                base64.urlsafe_b64decode(
                    credential_response['clientDataJSON']
                ).decode()
            )

            # 验证类型
            if client_data.get('type') != 'webauthn.create':
                return {'success': False, 'error': '错误的类型'}

            # 验证挑战
            received_challenge = base64.urlsafe_b64decode(
                client_data['challenge']
            )
            if received_challenge != expected_challenge:
                return {'success': False, 'error': '挑战不匹配'}

            # 验证来源
            if client_data.get('origin') != self.origin:
                return {'success': False, 'error': '来源不匹配'}

            # 解析attestationObject（简化）
            # 实际需要解析CBOR格式
            # 提取公钥和凭据ID

            # 存储凭据
            credential_id = credential_response.get('id', '')
            public_key = b'extracted_public_key'  # 实际从attestation提取

            if user_id not in self.registered_credentials:
                self.registered_credentials[user_id] = []

            self.registered_credentials[user_id].append({
                'credential_id': credential_id,
                'public_key': public_key,
                'counter': 0,
                'created_at': int(time.time())
            })

            return {
                'success': True,
                'credential_id': credential_id,
                'message': '注册成功'
            }

        except Exception as e:
            return {'success': False, 'error': str(e)}

    def generate_authentication_options(self, user_id):
        """生成认证选项"""
        challenge = secrets.token_bytes(32)

        # 获取用户已注册的凭据
        credentials = self.registered_credentials.get(user_id, [])
        allow_credentials = [
            {'type': 'public-key', 'id': c['credential_id']}
            for c in credentials
        ]

        options = {
            'challenge': base64.urlsafe_b64encode(challenge).decode(),
            'rpId': self.rp_id,
            'allowCredentials': allow_credentials,
            'userVerification': 'required',
            'timeout': 60000
        }

        return options, challenge

    def verify_authentication(self, user_id, assertion_response,
                                expected_challenge):
        """验证认证断言"""
        try:
            # 解析clientDataJSON
            client_data = json.loads(
                base64.urlsafe_b64decode(
                    assertion_response['clientDataJSON']
                ).decode()
            )

            # 验证类型
            if client_data.get('type') != 'webauthn.get':
                return {'success': False, 'error': '错误的类型'}

            # 验证挑战
            received_challenge = base64.urlsafe_b64decode(
                client_data['challenge']
            )
            if received_challenge != expected_challenge:
                return {'success': False, 'error': '挑战不匹配'}

            # 验证来源
            if client_data.get('origin') != self.origin:
                return {'success': False, 'error': '来源不匹配'}

            # 验证签名
            credential_id = assertion_response.get('id', '')
            authenticator_data = base64.urlsafe_b64decode(
                assertion_response['authenticatorData']
            )
            signature = base64.urlsafe_b64decode(
                assertion_response['signature']
            )

            # 查找凭据
            credentials = self.registered_credentials.get(user_id, [])
            credential = None
            for c in credentials:
                if c['credential_id'] == credential_id:
                    credential = c
                    break

            if not credential:
                return {'success': False, 'error': '凭据未找到'}

            # 验证签名（使用存储的公钥）
            # 实际需要用公钥验证签名
            # verify(credential['public_key'], signature, data)

            # 验证计数器（防克隆）
            # 从authenticatorData中提取计数器
            new_counter = int.from_bytes(authenticator_data[33:37], 'big')
            if new_counter <= credential['counter']:
                return {'success': False, 'error': '计数器异常(可能的克隆攻击)'}

            credential['counter'] = new_counter

            return {
                'success': True,
                'user_id': user_id,
                'message': '认证成功'
            }

        except Exception as e:
            return {'success': False, 'error': str(e)}
```
