# UEBA 检测场景

### 9.1 异常登录时间检测

```
场景描述：
  张三是某公司财务部员工，正常工作时间为周一至周五9:00-18:00
  周日02:30，张三的账号从内网IP发起VPN登录

检测逻辑：
  1. 提取张三历史登录时间分布
  2. 周末凌晨登录概率 = 0.002（近1年仅2次）
  3. 当前时间概率低于阈值0.01
  4. 生成异常告警：unusual_login_time

风险评估：
  ┌─────────────────────────────────────┐
  │ 用户：zhangsan                        │
  │ 时间：周日 02:30                       │
  │ IP：10.0.1.55（内网）                  │
  │ 异常类型：异常登录时间                   │
  │ 历史概率：0.2%                          │
  │ 风险评分：25                           │
  │ 建议：增加监控，检查是否为紧急加班        │
  └─────────────────────────────────────┘
```

### 9.2 异常地理位置检测

```
场景描述：
  李四是研发工程师，常驻上海办公室
  10:00 从上海IP(114.80.x.x)登录成功
  10:35 从深圳IP(120.79.x.x)登录成功
  间隔仅35分钟，上海到深圳距离约1200km

检测逻辑：
  1. 计算两次登录地理距离
  2. 计算所需速度：1200km / 0.58h ≈ 2069km/h
  3. 超过航空速度（900km/h）→ 不可能旅行
  4. 生成告警：impossible_travel

风险评估：
  ┌─────────────────────────────────────┐
  │ 用户：lisi                            │
  │ 第一次登录：10:00 上海 114.80.x.x      │
  │ 第二次登录：10:35 深圳 120.79.x.x      │
  │ 异常类型：不可能旅行                    │
  │ 距离：1200km，时间差：35分钟            │
  │ 推算速度：2069km/h（不可达）            │
  │ 风险评分：50                           │
  │ 建议：强制重新MFA验证，检查账号是否被盗  │
  └─────────────────────────────────────┘
```

### 9.3 异常数据访问检测

```
场景描述：
  王五是销售部员工，日常访问CRM系统和销售文档
  某日14:00开始，王五的账号连续访问了：
  - HR薪资目录（首次访问）
  - 财务报表目录（首次访问）
  - 技术源代码仓库（首次访问）
  - 总计下载3.5GB文件

检测逻辑：
  1. 文件访问目录全部为首次出现
  2. 访问目录跨部门（销售→HR/财务/技术）
  3. 数据量3.5GB远超日常基线（日均<50MB）
  4. 组合异常评分升高

风险评估：
  ┌─────────────────────────────────────┐
  │ 用户：wangwu（销售部）                 │
  │ 异常类型1：跨部门数据访问              │
  │   - 访问HR薪资目录（权限外）            │
  │   - 访问财务报表目录（权限外）           │
  │   - 访问技术源代码仓库（权限外）         │
  │ 异常类型2：异常数据量                   │
  │   - 下载3.5GB，基线日均<50MB           │
  │ 综合风险评分：80（critical）            │
  │ 建议：立即冻结账号，启动安全调查        │
  └─────────────────────────────────────┘
```

### 9.4 横向移动行为检测

```
场景描述：
  攻击者通过钓鱼获取了普通员工账号
  随后在1小时内：
  - 对30台内部服务器发起SMB连接
  - 尝试3台数据库服务器认证
  - 使用WinRM连接5台管理服务器
  - 在2台服务器上执行whoami/systeminfo

检测逻辑：
  1. 内部主机连接数突增（30台，基线<5台/天）
  2. 多种横向移动技术同时使用（SMB+WinRM+认证尝试）
  3. 执行侦察命令（whoami/systeminfo）
  4. 时间序列上行为呈递进式（扫描→认证→执行）

风险评估：
  ┌─────────────────────────────────────┐
  │ 用户：zhaoliu（被钓鱼的普通员工）       │
  │ 异常类型：横向移动                     │
  │   - SMB扫描30台服务器                  │
  │   - WinRM连接5台管理机                 │
  │   - 数据库认证尝试                     │
  │   - 侦察命令执行                       │
  │ 综合风险评分：90（critical）            │
  │ 建议：立即隔离终端，阻断网络，启动IR    │
  └─────────────────────────────────────┘
```
