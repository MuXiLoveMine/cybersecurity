## 一、身份联邦概述

### 1.1 联邦概念

**身份联邦（Identity Federation）** 是指多个独立的安全域（组织、系统）之间建立信任关系，使用户能够用自己所在域的身份访问其他域的资源，无需重新认证。

```text
身份联邦核心概念

传统认证（无联邦）:
  用户A → 组织A: 登录组织A的账号
  用户A → 组织B: 需要重新注册组织B的账号
  用户A → 组织C: 又需要组织C的账号
  问题: 多个账号密码，管理困难

联邦认证:
  用户A → 组织A: 登录组织A的账号（身份提供者）
  组织A → 组织B: 信任关系 → 允许用户A访问
  组织A → 组织C: 信任关系 → 允许用户A访问
  优势: 一次认证，多域访问

核心术语:
├── IdP (Identity Provider): 身份提供者，认证用户
├── SP (Service Provider): 服务提供者，提供资源
├── RP (Relying Party): 信任方，依赖IdP的认证
├── Trust Domain: 信任域，相互信任的区域
├── Federation: 联邦，多个信任域的集合
└── Metadata: 元数据，描述IdP/SP的配置信息

联邦的价值:
├── 用户体验: 一次登录，多处访问
├── 安全管理: 集中身份管理
├── 降低成本: 减少账号管理开销
├── 合规: 统一审计和访问控制
└── 协作: 跨组织协作更便捷
```

### 1.2 联邦模型分类

```text
联邦模型分类

模型1: 双边联邦 (Bilateral Federation)
  组织A ←→ 组织B
  直接建立信任关系
  适合: 两个组织之间的点对点联邦

模型2: 联邦联盟 (Federation Alliance)
  组织A ←→ 联邦中心 ←→ 组织B
                    ←→ 组织C
  通过联邦中心间接信任
  适合: 多组织联盟（如教育网联邦）

模型3: 中心联邦 (Hub-and-Spoke)
  IdP ←→ 联邦中心 ←→ SP1
                    ←→ SP2
                    ←→ SP3
  中央联邦枢纽
  适合: 企业与多个SaaS应用联邦

模型4: 联邦链 (Chained Federation)
  组织A → 组织B → 组织C
  信任通过链传递
  适合: 多级信任传递

模型5: 网状联邦 (Mesh Federation)
  每个组织与其他所有组织建立信任
  适合: 小规模紧密联盟
  问题: N个组织需要N*(N-1)/2个信任关系

模型6: 联邦信任框架 (Trust Framework)
  所有组织遵循统一的信任标准
  通过第三方审计验证信任
  适合: 大规模联邦（如eIDAS）
```

## 二、SAML联邦

### 2.1 SAML协议概述

**SAML (Security Assertion Markup Language)** 是基于XML的联邦认证标准，广泛用于企业身份联邦。

```text
SAML 2.0 核心概念

SAML断言 (Assertion):
  XML格式的认证和属性声明
  包含: 认证信息、属性信息、授权决策

SAML绑定 (Binding):
  断言的传输方式
  ├── HTTP-Redirect: URL重定向传递
  ├── HTTP-POST: HTTP POST传递
  ├── HTTP-Artifact: 间接引用传递
  └── SOAP: SOAP消息传递

SAML协议 (Protocol):
  请求-响应模式
  ├── AuthnRequest: 认证请求
  ├── Response: 认证响应(含断言)
  ├── LogoutRequest: 注销请求
  ├── LogoutResponse: 注销响应
  └── ArtifactResolve: Artifact解析

SAML配置文件 (Profile):
  特定使用场景的约束
  ├── Web Browser SSO: 浏览器单点登录
  ├── Single Logout: 单点注销
  ├── Name Identifier Management: 名称管理
  └── Attribute Query: 属性查询
```

### 2.2 SAML认证流程

```text
SAML SSO认证流程 (SP发起)

1. 用户访问SP
   用户 → SP: 访问受保护资源
   SP: 检查会话 → 无有效会话

2. SP生成AuthnRequest
   SP → 用户: 重定向到IdP (携带AuthnRequest)
   AuthnRequest包含:
   ├── SP的EntityID
   ├── AssertionConsumerService URL
   ├── 请求的NameIDFormat
   └── 请求的认证上下文

3. 用户在IdP认证
   用户 → IdP: 登录认证
   IdP: 验证凭据 → 生成SAML断言

4. IdP返回断言
   IdP → 用户: 重定向回SP (携带SAML Response)
   SAML Response包含:
   ├── 认证断言 (Authentication Statement)
   ├── 属性断言 (Attribute Statement)
   └── IdP签名

5. SP验证断言
   SP: 验证IdP签名 → 提取用户信息 → 建立会话

6. 用户访问资源
   SP → 用户: 返回受保护资源内容
```

```python
"""
SAML联邦实现示例
"""

import base64
import xml.etree.ElementTree as ET
from xml.etree.ElementTree import ParseError
from datetime import datetime, timedelta
import hashlib
import hmac

class SAMLFederation:
    """SAML联邦实现"""

    # SAML命名空间
    NS = {
        'saml': 'urn:oasis:names:tc:SAML:2.0:assertion',
        'samlp': 'urn:oasis:names:tc:SAML:2.0:protocol',
        'ds': 'http://www.w3.org/2000/09/xmldsig#'
    }

    def __init__(self, entity_id, role='sp'):
        """
        :param entity_id: 实体ID (如 https://sp.example.com)
        :param role: 'sp' 或 'idp'
        """
        self.entity_id = entity_id
        self.role = role
        self.trusted_partners = {}  # entity_id → metadata

    def generate_authn_request(self, idp_entity_id, acs_url=None):
        """生成SAML AuthnRequest（SP端）"""
        request_id = self._generate_id()
        issue_instant = datetime.utcnow().strftime('%Y-%m-%dT%H:%M:%SZ')

        if acs_url is None:
            acs_url = f"{self.entity_id}/saml/acs"

        authn_request = f"""<samlp:AuthnRequest 
    xmlns:samlp="urn:oasis:names:tc:SAML:2.0:protocol"
    ID="{request_id}"
    Version="2.0"
    IssueInstant="{issue_instant}"
    Destination="{idp_entity_id}/saml/sso"
    ProtocolBinding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST"
    AssertionConsumerServiceURL="{acs_url}">
    <saml:Issuer xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion">
        {self.entity_id}
    </saml:Issuer>
    <samlp:NameIDPolicy 
        AllowCreate="true"
        Format="urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress"/>
    <samlp:RequestedAuthnContext 
        Comparison="minimum">
        <saml:AuthnContextClassRef>
            urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport
        </saml:AuthnContextClassRef>
    </samlp:RequestedAuthnContext>
</samlp:AuthnRequest>"""

        return {
            'request_xml': authn_request,
            'request_id': request_id,
            'encoded': self._encode_for_redirect(authn_request)
        }

    def generate_saml_response(self, request_id, user_info, sp_entity_id,
                                 acs_url, signing_key=None):
        """生成SAML Response（IdP端）"""
        response_id = self._generate_id()
        assertion_id = self._generate_id()
        issue_instant = datetime.utcnow()
        not_on_or_after = issue_instant + timedelta(minutes=5)
        not_before = issue_instant - timedelta(minutes=1)
        session_not_on_or_after = issue_instant + timedelta(hours=8)

        fmt = '%Y-%m-%dT%H:%M:%SZ'
        issue_str = issue_instant.strftime(fmt)
        noa_str = not_on_or_after.strftime(fmt)
        nb_str = not_before.strftime(fmt)
        snoa_str = session_not_on_or_after.strftime(fmt)

        user_id = user_info.get('email', user_info.get('id', 'unknown'))
        attributes = user_info.get('attributes', {})

        attr_xml = ''
        for name, value in attributes.items():
            attr_xml += f"""<saml:Attribute Name="{name}" 
    NameFormat="urn:oasis:names:tc:SAML:2.0:attrname-format:basic">
    <saml:AttributeValue>{value}</saml:AttributeValue>
</saml:Attribute>"""

        saml_response = f"""<samlp:Response 
    xmlns:samlp="urn:oasis:names:tc:SAML:2.0:protocol"
    ID="{response_id}"
    Version="2.0"
    IssueInstant="{issue_str}"
    Destination="{acs_url}"
    InResponseTo="{request_id}">
    <saml:Issuer xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion">
        {self.entity_id}
    </saml:Issuer>
    <samlp:Status>
        <samlp:StatusCode Value="urn:oasis:names:tc:SAML:2.0:status:Success"/>
    </samlp:Status>
    <saml:Assertion 
        xmlns:saml="urn:oasis:names:tc:SAML:2.0:assertion"
        ID="{assertion_id}"
        Version="2.0"
        IssueInstant="{issue_str}">
        <saml:Issuer>{self.entity_id}</saml:Issuer>
        <saml:Subject>
            <saml:NameID Format="urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress">
                {user_id}
            </saml:NameID>
            <saml:SubjectConfirmation Method="urn:oasis:names:tc:SAML:2.0:cm:bearer">
                <saml:SubjectConfirmationData
                    NotOnOrAfter="{noa_str}"
                    Recipient="{acs_url}"
                    InResponseTo="{request_id}"/>
            </saml:SubjectConfirmation>
        </saml:Subject>
        <saml:Conditions
            NotBefore="{nb_str}"
            NotOnOrAfter="{noa_str}">
            <saml:AudienceRestriction>
                <saml:Audience>{sp_entity_id}</saml:Audience>
            </saml:AudienceRestriction>
        </saml:Conditions>
        <saml:AuthnStatement
            AuthnInstant="{issue_str}"
            SessionIndex="{assertion_id}"
            SessionNotOnOrAfter="{snoa_str}">
            <saml:AuthnContext>
                <saml:AuthnContextClassRef>
                    urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport
                </saml:AuthnContextClassRef>
            </saml:AuthnContext>
        </saml:AuthnStatement>
        <saml:AttributeStatement>
            {attr_xml}
        </saml:AttributeStatement>
    </saml:Assertion>
</samlp:Response>"""

        return {
            'response_xml': saml_response,
            'response_id': response_id,
            'assertion_id': assertion_id
        }

    def verify_saml_response(self, response_xml, trusted_idp_entity_id):
        """验证SAML Response（SP端）"""
        try:
            root = ET.fromstring(response_xml)

            # 验证Issuer
            issuer = root.find('.//{*}Issuer')
            if issuer is not None:
                if issuer.text != trusted_idp_entity_id:
                    return {'valid': False, 'reason': '不信任的IdP'}

            # 验证状态
            status = root.find('.//{*}StatusCode')
            if status is not None:
                if 'Success' not in status.get('Value', ''):
                    return {'valid': False, 'reason': 'IdP返回失败状态'}

            # 提取断言信息
            assertion = root.find('.//{*}Assertion')
            if assertion is None:
                return {'valid': False, 'reason': '无断言'}

            # 提取用户信息
            name_id = assertion.find('.//{*}NameID')
            user_id = name_id.text if name_id is not None else 'unknown'

            # 提取属性
            attributes = {}
            for attr in assertion.findall('.//{*}Attribute'):
                name = attr.get('Name')
                values = attr.findall('{*}AttributeValue')
                if values:
                    attributes[name] = values[0].text

            # 验证时间
            conditions = assertion.find('.//{*}Conditions')
            if conditions is not None:
                not_before = conditions.get('NotBefore')
                not_on_or_after = conditions.get('NotOnOrAfter')
                now = datetime.utcnow()
                if not_on_or_after:
                    noa = datetime.strptime(not_on_or_after, '%Y-%m-%dT%H:%M:%SZ')
                    if now > noa:
                        return {'valid': False, 'reason': '断言已过期'}

            return {
                'valid': True,
                'user_id': user_id,
                'attributes': attributes
            }

        except ParseError as e:
            return {'valid': False, 'reason': f'XML解析失败: {e}'}
        except Exception as e:
            return {'valid': False, 'reason': f'验证异常: {e}'}

    def add_trusted_partner(self, entity_id, metadata):
        """添加信任伙伴"""
        self.trusted_partners[entity_id] = metadata

    @staticmethod
    def _generate_id():
        import secrets
        return f"id_{secrets.token_hex(16)}"

    @staticmethod
    def _encode_for_redirect(xml):
        """Base64编码用于URL重定向"""
        return base64.b64encode(xml.encode('utf-8')).decode('utf-8')
```

### 2.3 SAML安全考量

```text
SAML安全风险与防御

风险1: XML签名包装 (XSW)
  ├── 攻击者修改SAML断言结构
  ├── 使签名验证覆盖错误部分
  ├── 防御: 严格验证签名覆盖范围
  └── 使用: Schema验证 + 签名位置检查

风险2: 重放攻击
  ├── 截获有效SAML断言并重放
  ├── 防御: 验证NotOnOrAfter + InResponseTo
  └── 记录已使用的断言ID

风险3: 中间人攻击
  ├── 拦截SAML消息
  ├── 防御: HTTPS传输 + 断言签名
  └── Destination验证

风险4: XXE注入
  ├── XML外部实体注入
  ├── 防御: 禁用外部实体解析
  └── 使用安全XML解析器

风险5: 令牌伪造
  ├── 伪造SAML断言
  ├── 防御: 验证IdP签名
  └── 验证证书信任链

风险6: 会话固定
  ├── 攻击者固定SP会话ID
  ├── 防御: 认证后生成新会话
  └── 会话绑定到用户身份

最佳实践:
├── 断言签名必须验证
├── 严格验证所有时间条件
├── 验证AudienceRestriction
├── 验证Recipient
├── 记录InResponseTo
├── 使用安全XML解析（禁XXE）
├── 断言有效期不超过5分钟
├── 使用HTTPS传输
└── 定期轮换签名证书
```

## 三、OAuth/OIDC联邦

### 3.1 OIDC联邦架构

```text
OIDC联邦架构 (OpenID Connect Federation)

OIDC联邦通过联邦信任链实现多组织信任:

┌──────────────────────────────────────────────────────┐
│              联邦权威 (Federation Authority)           │
│          (Trust Anchor / 根信任锚)                     │
│        签发联邦操作者证书                               │
└──────────────────────┬───────────────────────────────┘
                       │ 签发
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 中间CA       │ │ 中间CA       │ │ 中间CA       │
│ (Org A)     │ │ (Org B)     │ │ (Org C)     │
└──────┬───────┘ └──────┬───────┘ └──────┬───────┘
       │签发              │签发            │签发
       ▼                  ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ IdP/SP      │ │ IdP/SP      │ │ IdP/SP      │
│ (实体A)     │ │ (实体B)     │ │ (实体C)     │
└──────────────┘ └──────────────┘ └──────────────┘

信任链验证:
  实体A → 联邦权威 的信任链:
  联邦权威签名 → 中间CA签名 → 实体A
  验证: 验证签名链直至信任锚

OIDC联邦元数据:
  每个实体发布元数据声明:
  ├── OIDC配置端点
  ├── 支持的范围
  ├── 公钥(JWK Set)
  ├── 联邦角色
  └── 联邦信任链
```

```python
class OIDCFederation:
    """OIDC联邦实现"""

    def __init__(self, entity_id, role='OP'):
        """
        :param entity_id: 实体标识URL
        :param role: 'OP'(OpenID Provider) 或 'RP'(Relying Party)
        """
        self.entity_id = entity_id
        self.role = role
        self.federation_endpoints = {}
        self.trust_anchors = {}  # 信任锚
        self.trusted_entities = {}  # 已验证信任的实体

    def get_federation_metadata(self):
        """获取联邦元数据"""
        metadata = {
            'iss': self.entity_id,
            'sub': self.entity_id,
            'iat': int(time.time()),
            'exp': int(time.time()) + 3600,
            'jwks': {
                'keys': [
                    {'kty': 'RSA', 'kid': 'key-001',
                     'use': 'sig', 'n': '...', 'e': 'AQAB'}
                ]
            },
            'metadata': {
                self.role: {
                    'issuer': self.entity_id,
                    'authorization_endpoint': f'{self.entity_id}/auth',
                    'token_endpoint': f'{self.entity_id}/token',
                    'jwks_uri': f'{self.entity_id}/jwks',
                    'response_types_supported': ['code'],
                    'subject_types_supported': ['public'],
                    'id_token_signing_alg_values_supported': ['RS256'],
                    'scopes_supported': ['openid', 'profile', 'email']
                }
            }
        }

        if self.role == 'OP':
            metadata['metadata'][self.role].update({
                'userinfo_endpoint': f'{self.entity_id}/userinfo',
                'token_endpoint_auth_methods_supported': [
                    'client_secret_basic',
                    'client_secret_post',
                    'private_key_jwt'
                ]
            })

        return metadata

    def establish_trust(self, target_entity_id, trust_anchor_metadata):
        """建立信任关系"""
        # 1. 获取目标实体元数据
        target_metadata = self._fetch_entity_statement(target_entity_id)

        # 2. 验证信任链
        trust_chain = self._verify_trust_chain(
            target_entity_id, trust_anchor_metadata
        )

        if trust_chain['valid']:
            self.trusted_entities[target_entity_id] = {
                'metadata': target_metadata,
                'trust_chain': trust_chain,
                'trust_anchor': trust_anchor_metadata
            }
            return True
        return False

    def _fetch_entity_statement(self, entity_id):
        """获取实体声明"""
        # 实际通过HTTP获取
        return {
            'iss': entity_id,
            'sub': entity_id,
            'metadata': {}
        }

    def _verify_trust_chain(self, entity_id, trust_anchor):
        """验证信任链"""
        # 简化验证
        return {
            'valid': True,
            'chain': [entity_id, trust_anchor.get('entity_id', '')]
        }

    def generate_authorization_request(self, client_id, redirect_uri,
                                         scope='openid profile'):
        """生成授权请求"""
        import urllib.parse

        params = {
            'response_type': 'code',
            'client_id': client_id,
            'redirect_uri': redirect_uri,
            'scope': scope,
            'state': self._generate_state(),
            'nonce': self._generate_nonce()
        }

        auth_url = f"{self.entity_id}/auth?{urllib.parse.urlencode(params)}"
        return {
            'url': auth_url,
            'state': params['state'],
            'nonce': params['nonce']
        }

    @staticmethod
    def _generate_state():
        import secrets
        return secrets.token_urlsafe(32)

    @staticmethod
    def _generate_nonce():
        import secrets
        return secrets.token_urlsafe(32)
```

### 4.2 用户生命周期管理

```python
class SCIMUserManager:
    """SCIM用户生命周期管理"""

    SCIM_USER_SCHEMA = "urn:ietf:params:scim:schemas:core:2.0:User"
    SCIM_ENTERPRISE_SCHEMA = "urn:ietf:params:scim:schemas:extension:enterprise:2.0:User"

    def __init__(self, base_url, auth_token):
        self.base_url = base_url.rstrip('/')
        self.headers = {
            'Authorization': f'Bearer {auth_token}',
            'Content-Type': 'application/scim+json',
            'Accept': 'application/scim+json'
        }

    def create_user(self, user_data):
        """创建用户 (SCIM POST /Users)"""
        import requests

        scim_user = {
            'schemas': [self.SCIM_USER_SCHEMA],
            'userName': user_data['username'],
            'name': {
                'givenName': user_data.get('first_name', ''),
                'familyName': user_data.get('last_name', '')
            },
            'emails': [{
                'value': user_data['email'],
                'type': 'work',
                'primary': True
            }],
            'active': True,
            'password': user_data.get('temporary_password', ''),
            'displayName': f"{user_data.get('first_name', '')} {user_data.get('last_name', '')}".strip()
        }

        # 企业扩展属性
        if 'department' in user_data or 'title' in user_data:
            scim_user[self.SCIM_ENTERPRISE_SCHEMA] = {
                'department': user_data.get('department', ''),
                'title': user_data.get('title', '')
            }

        response = requests.post(
            f'{self.base_url}/Users',
            json=scim_user,
            headers=self.headers
        )

        if response.status_code == 201:
            return response.json()
        else:
            raise Exception(f"创建用户失败: {response.status_code} {response.text}")

    def get_user(self, user_id):
        """获取用户 (SCIM GET /Users/{id})"""
        import requests
        response = requests.get(
            f'{self.base_url}/Users/{user_id}',
            headers=self.headers
        )
        if response.status_code == 200:
            return response.json()
        return None

    def search_users(self, filter_expr=None, start_index=1, count=100):
        """搜索用户 (SCIM GET /Users?filter=...)"""
        import requests
        params = {
            'startIndex': start_index,
            'count': count
        }
        if filter_expr:
            params['filter'] = filter_expr

        response = requests.get(
            f'{self.base_url}/Users',
            params=params,
            headers=self.headers
        )
        if response.status_code == 200:
            return response.json()
        return None

    def update_user(self, user_id, updates):
        """更新用户 (SCIM PATCH /Users/{id})"""
        import requests

        operations = []
        for path, value in updates.items():
            operations.append({
                'op': 'replace',
                'path': path,
                'value': value
            })

        patch_request = {
            'schemas': ['urn:ietf:params:scim:api:messages:2.0:PatchOp'],
            'Operations': operations
        }

        response = requests.patch(
            f'{self.base_url}/Users/{user_id}',
            json=patch_request,
            headers=self.headers
        )
        return response.status_code == 200

    def deactivate_user(self, user_id):
        """停用用户"""
        return self.update_user(user_id, {'active': False})

    def delete_user(self, user_id):
        """删除用户 (SCIM DELETE /Users/{id})"""
        import requests
        response = requests.delete(
            f'{self.base_url}/Users/{user_id}',
            headers=self.headers
        )
        return response.status_code == 204

    def sync_user(self, user_data):
        """同步用户（创建或更新）"""
        # 先查找用户
        filter_expr = f'userName eq "{user_data["username"]}"'
        results = self.search_users(filter_expr)

        if results and results.get('totalResults', 0) > 0:
            # 用户已存在，更新
            user = results['Resources'][0]
            return self.update_user(user['id'], {
                'name.givenName': user_data.get('first_name', ''),
                'name.familyName': user_data.get('last_name', ''),
                'emails[type eq "work"].value': user_data.get('email', '')
            })
        else:
            # 用户不存在，创建
            return self.create_user(user_data)
```
