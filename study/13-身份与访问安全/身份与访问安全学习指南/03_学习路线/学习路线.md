# 学习路线

### 阶段 1：身份安全基础（1-2 个月）
**学习目标**：掌握身份与访问安全基础知识

**学习内容**
- 身份认证基础
- 访问控制模型
- 密码安全
- 多因素认证
- 目录服务基础
- 身份安全概述

**实践任务**
- 学习身份认证原理
- 了解访问控制模型
- 配置 AD 域环境
- 配置 LDAP
- 学习密码安全

### 阶段 2：身份管理技术（2-3 个月）
**学习目标**：掌握身份管理核心技术

**学习内容**
- 单点登录（SSO）
- SAML / OAuth / OIDC
- 身份治理（IGA）
- 特权访问管理（PAM）
- 身份联邦
- 目录服务深入

**实践任务**
- 搭建 SSO 系统
- 配置 OAuth/OIDC
- 部署 IGA 系统
- 部署 PAM 系统
- 配置身份联邦

### 阶段 3：零信任与高级技术（3-4 个月）
**学习目标**：掌握零信任和高级身份安全技术

**学习内容**
- 零信任架构
- 零信任关键技术
- 微隔离
- 软件定义边界（SDP）
- API 身份安全
- 身份安全攻防
- 持续验证与动态访问控制

**实践任务**
- 设计零信任架构
- 部署零信任组件
- 配置微隔离
- 测试 API 安全
- 做身份攻防练习

### 阶段 4：身份安全运营（2-3 个月）
**学习目标**：掌握身份安全运营和治理

**学习内容**
- 身份安全运营
- 身份安全监控
- 身份威胁检测
- 身份安全审计
- 合规与治理
- 身份安全项目实施

**实践任务**
- 设计身份安全方案
- 做身份安全评估
- 配置身份监控
- 制定身份治理策略
- 参与身份安全项目

### 阶段 5：深入研究（持续）
**研究方向**
- 零信任架构
- 身份治理
- 特权访问管理
- 身份威胁检测与响应
- AI 与身份安全
- 云原生身份安全
- 身份安全标准
