# 详细子方向

### 2.1 身份认证技术

#### 2.1.1 身份认证基础
**认证概念**
- 身份认证：验证你是谁
- 授权：验证你能做什么
- 审计：记录你做了什么

**认证三要素**
- 你知道的（Something you know）：密码、PIN
- 你拥有的（Something you have）：手机、令牌、U 盾
- 你本身（Something you are）：指纹、人脸、虹膜

**认证强度**
- 单因素认证（SFA）：只用一种因素
- 双因素认证（2FA）：使用两种因素
- 多因素认证（MFA）：使用多种因素

#### 2.1.2 密码认证
**密码安全**
- 密码强度
- 密码策略
- 密码存储（哈希加盐）
- 密码轮换
- 密码复用问题
- 密码管理器

**常见攻击**
- 暴力破解
- 字典攻击
- 彩虹表
- 社会工程学
- 钓鱼攻击
- 键盘记录
- 凭证填充（Credential Stuffing）

**防护措施**
- 强密码策略
- 密码哈希加盐
- 限制登录尝试
- 验证码
- 登录异常检测
- 密码管理器

#### 2.1.3 多因素认证（MFA）
**常见 MFA 方式**
- 短信验证码
- 邮件验证码
- 语音验证码
- TOTP（基于时间的一次性密码）：Google Authenticator、Authy
- HOTP（基于事件的一次性密码）
- 硬件令牌：RSA SecurID、U 盾
- 生物识别：指纹、人脸、虹膜
- 推送通知：手机 App 推送
- FIDO / U2F：硬件安全密钥

**MFA 绕过方法**
- 会话劫持
- Cookie 窃取
- MFA 疲劳攻击
- 社会工程学
- 中间人攻击
- 令牌窃取

#### 2.1.4 生物识别认证
**常见生物特征**
- 指纹识别
- 人脸识别
- 虹膜识别
- 声纹识别
- 步态识别
- 静脉识别

**安全风险**
- 生物特征泄露（无法更改）
- 欺骗攻击（假指纹、假人脸）
- 隐私问题
- 准确性问题
- 偏见问题

### 2.2 访问控制模型

#### 2.2.1 访问控制基础
**访问控制概念**
- 主体（Subject）：访问者
- 客体（Object）：被访问的资源
- 操作（Action）：读、写、执行等
- 策略（Policy）：访问规则

**访问控制三要素**
- 身份认证：你是谁
- 授权：你能做什么
- 审计：你做了什么

#### 2.2.2 自主访问控制（DAC）
**DAC 模型**
- Discretionary Access Control
- 资源所有者决定谁能访问
- 灵活性高
- 安全性较低

**特点**
- 所有者可以分配权限
- 权限可以传递
- 管理分散
- 适合小型系统

#### 2.2.3 强制访问控制（MAC）
**MAC 模型**
- Mandatory Access Control
- 系统强制控制访问
- 安全性高
- 灵活性低

**特点**
- 安全标签
- 系统统一管理
- 不可绕过
- 适合高安全需求系统
- 如 SELinux、军用系统

#### 2.2.4 基于角色的访问控制（RBAC）
**RBAC 模型**
- Role-Based Access Control
- 基于角色分配权限
- 最常用的模型
- 平衡安全和灵活

**核心概念**
- 用户（User）
- 角色（Role）
- 权限（Permission）
- 会话（Session）

**特点**
- 权限分配给角色
- 用户分配角色
- 角色继承
- 职责分离
- 易于管理

#### 2.2.5 基于属性的访问控制（ABAC）
**ABAC 模型**
- Attribute-Based Access Control
- 基于属性进行访问控制
- 灵活强大
- 零信任的基础

**属性类型**
- 用户属性：部门、职位、级别
- 资源属性：分类、密级、所有者
- 环境属性：时间、地点、设备
- 操作属性：读、写、删除

**特点**
- 动态决策
- 细粒度控制
- 策略灵活
- 适合复杂场景
- 零信任架构常用

#### 2.2.6 其他访问控制模型
**其他模型**
- 基于规则的访问控制（RBAC）
- 基于任务的访问控制（TBAC）
- 基于团队的访问控制（TMAC）
- 时空访问控制
- 基于风险的访问控制

### 2.3 身份治理与管理（IGA）

#### 2.3.1 IGA 概述
**IGA 概念**
- Identity Governance and Administration
- 身份治理与管理
- 管理身份的全生命周期
- 确保正确的人有正确的权限

**IGA 核心功能**
- 身份生命周期管理
- 访问请求与审批
- 权限认证（Access Certification）
- 职责分离（SoD）
- 权限分析
- 合规报告

#### 2.3.2 身份生命周期管理
**生命周期阶段**
- 创建：入职、新用户
- 变更：调岗、晋升
- 停用：离职、休假
- 删除：永久删除
- 审计：定期审查

**自动化**
- HR 系统集成
- 自动开通
- 自动变更
- 自动回收
- 工作流驱动

#### 2.3.3 权限认证与复核
**权限认证（Access Certification）**
- 定期审查权限
- 管理者确认
- 权限回收
- 合规要求

**最小权限原则**
- 只分配必要的权限
- 权限最小化
- 定期清理权限
- 及时回收权限

**职责分离（SoD）**
- Separation of Duties
- 关键职责分离
- 防止舞弊
- 如：申请人和审批人不能是同一人

### 2.4 特权访问管理（PAM）

#### 2.4.1 PAM 概述
**特权账号概念**
- 权限最大的账号
- 风险最高的账号
- 攻击者的主要目标
- 如：管理员、root、DBA

**常见特权账号**
- 系统管理员
- 数据库管理员
- 网络管理员
- 应用管理员
- 服务账号
- 应急账号
- 测试账号

#### 2.4.2 PAM 核心功能
**核心功能**
- 特权账号金库（Vault）
- 密码管理
- 会话管理
- 命令控制
- 操作审计
- 审批工作流
- 即时权限（JIT）

#### 2.4.3 特权账号金库
**金库（Vault）**
- 集中存储特权密码
- 加密存储
- 访问控制
- 密码轮换
- 审计日志

**密码管理**
- 自动密码轮换
- 强密码生成
- 密码历史
- 密码策略

#### 2.4.4 会话管理与审计
**会话管理**
- 会话录制
- 实时监控
- 会话中断
- 命令控制
- 命令白名单/黑名单

**操作审计**
- 操作日志
- 命令审计
- 视频回放
- 风险告警
- 合规报告

#### 2.4.5 即时权限（JIT）
**JIT 概念**
- Just-In-Time
- 即时申请，即时授权
- 用完即收
- 最小权限

**JIT 特点**
- 按需申请
- 审批流程
- 时间限制
- 自动回收
- 审计记录

### 2.5 单点登录（SSO）

#### 2.5.1 SSO 概述
**SSO 概念**
- Single Sign-On
- 单点登录
- 一次登录，多处访问
- 提升用户体验
- 减少密码疲劳

**SSO 优势**
- 用户体验好
- 减少密码数量
- 集中管理
- 统一认证
- 安全审计

#### 2.5.2 SSO 协议
**常见协议**
- SAML（Security Assertion Markup Language）
- OAuth 2.0
- OpenID Connect（OIDC）
- CAS（Central Authentication Service）
- LDAP
- Kerberos

#### 2.5.3 SAML
**SAML 概述**
- 基于 XML 的认证协议
- 企业级 SSO 标准
- 身份提供商（IdP）和服务提供商（SP）
- 浏览器重定向

**SAML 流程**
1. 用户访问 SP
2. SP 重定向到 IdP
3. 用户在 IdP 认证
4. IdP 生成 SAML 断言
5. SP 验证断言
6. 用户登录成功

#### 2.5.4 OAuth 2.0
**OAuth 2.0 概述**
- 授权框架
- 不是认证协议
- 第三方应用授权
- 令牌机制

**OAuth 角色**
- 资源所有者（用户）
- 客户端（第三方应用）
- 授权服务器
- 资源服务器

**OAuth 授权模式**
- 授权码模式（Authorization Code）
- 隐式模式（Implicit）
- 密码模式（Resource Owner Password Credentials）
- 客户端模式（Client Credentials）
- 设备码模式（Device Code）

#### 2.5.5 OpenID Connect（OIDC）
**OIDC 概述**
- 基于 OAuth 2.0 的身份层
- 提供认证信息
- ID Token（JWT 格式）
- 现代 Web 应用常用

**OIDC 核心概念**
- ID Token：身份令牌
- Access Token：访问令牌
- Refresh Token：刷新令牌
- UserInfo 端点：用户信息

### 2.6 零信任架构（ZTA）

#### 2.6.1 零信任概述
**零信任概念**
- Zero Trust
- 永不信任，始终验证
- 不以网络位置判断信任
- 每次访问都验证
- 最小权限原则

**零信任核心原则**
- 永不信任，始终验证
- 最小权限
- 假设 breach
- 持续验证
- 动态访问控制
- 全面审计

#### 2.6.2 零信任架构
**零信任三大支柱**
- 身份：身份是新的安全边界
- 设备：设备安全状态
- 应用：应用级访问控制

**零信任关键技术**
- 身份认证与授权
- 设备信任评估
- 微隔离
- 软件定义边界（SDP）
- 持续验证
- 动态访问控制
- 安全分析

#### 2.6.3 零信任实施
**实施步骤**
1. 资产梳理
2. 身份治理
3. 设备管理
4. 应用接入
5. 微隔离
6. 持续监控
7. 持续优化

**常见挑战**
- 遗留系统
- 用户体验
- 复杂度
- 成本
- 组织变革

### 2.8 API 身份安全

#### 2.8.1 API 认证方式
**常见认证方式**
- API Key
- Basic Auth
- Bearer Token（JWT）
- OAuth 2.0
- mTLS（双向 TLS）
- HMAC 签名
- API 签名

#### 2.8.2 JWT 安全
**JWT 概述**
- JSON Web Token
- 无状态认证
- 三部分：Header、Payload、Signature
- Base64 编码，不是加密

**JWT 安全风险**
- 算法混淆攻击
- 密钥泄露
- 令牌泄露
- 重放攻击
- 权限提升
- 无状态问题（无法撤销）

**JWT 安全最佳实践**
- 使用强密钥
- 设置过期时间
- 验证签名
- 验证算法
- 使用 HTTPS
- 令牌刷新机制
- 黑名单机制（可选）

#### 2.8.3 API 授权
**API 授权模型**
- 基于角色（RBAC）
- 基于属性（ABAC）
- 基于范围（Scope）
- 基于策略

### 2.9 目录服务

#### 2.9.1 目录服务概述
**目录服务概念**
- 存储用户、设备、应用等信息
- 统一管理
- LDAP 协议
- 如：Active Directory、OpenLDAP

#### 2.9.2 Active Directory
**AD 概述**
- 微软活动目录
- Windows 域环境
- 企业最常用
- 集成度高

**AD 安全风险**
- 域管理员权限过大
- 黄金票据攻击
- 白银票据攻击
- Pass-the-Hash
- Pass-the-Ticket
- Kerberoasting
- AS-REP Roasting

**AD 安全防护**
- 最小权限
- 特权账号管理
- 组策略安全
- 补丁管理
- 监控审计
- 分层架构（Tier Model）

#### 2.9.3 LDAP
**LDAP 概述**
- Lightweight Directory Access Protocol
- 轻量级目录访问协议
- 标准协议
- 跨平台
