# 零信任架构基础

### 7.1 零信任的核心理念

**零信任（Zero Trust）**：一种安全理念，核心是"永不信任，始终验证"（Never Trust, Always Verify），不基于网络位置自动授予信任，每次访问都需要验证。

**传统网络安全 vs 零信任**：

| 维度 | 传统边界安全 | 零信任 |
|------|-------------|--------|
| 信任基础 | 网络位置（内网=可信） | 身份和设备 |
| 假设 | 内部用户可信 | 所有人都不可信 |
| 防护重点 | 边界防护（防火墙） | 身份和数据 |
| 访问控制 | 粗粒度（网段级） | 细粒度（每次访问） |
| 验证方式 | 一次验证，长期有效 | 持续验证，动态评估 |

### 7.2 零信任的核心原则

1. **永不信任，始终验证**：无论来自内网还是外网，每次访问都要验证
2. **最小权限**：只授予完成任务所需的最少权限
3. **假设 breach**：假设已经被入侵，设计防御纵深
4. **持续验证**：不是一次性认证，而是持续评估信任度
5. **动态访问控制**：基于实时风险动态调整权限
6. **全面审计**：所有访问行为都记录和监控
7. **微隔离**：网络分段，限制横向移动

### 7.3 零信任与访问控制

零信任架构下的访问控制特点：

| 特点 | 说明 |
|------|------|
| 身份为中心 | 身份是新的安全边界 |
| 动态策略 | ABAC为主，基于多属性动态决策 |
| 持续评估 | 访问过程中持续评估风险 |
| 自适应 | 风险变化时自动调整权限 |
| 细粒度 | 应用级、API级的细粒度控制 |
| 上下文感知 | 考虑设备状态、环境、行为等上下文 |
