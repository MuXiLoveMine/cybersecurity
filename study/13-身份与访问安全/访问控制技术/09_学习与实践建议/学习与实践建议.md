# 学习与实践建议

### 动手实践

1. **RBAC 实现练习**：
   - 设计一个简单系统的角色权限体系
   - 用 Python/Java 实现 RBAC 权限检查
   - 实现角色继承和职责分离检测

2. **ABAC 策略练习**：
   - 设计一个基于属性的访问控制策略
   - 实现简单的策略评估引擎
   - 测试不同属性组合的访问决策

3. **Linux 权限实验**：
   - 练习 Linux 文件权限和 ACL 设置
   - 配置 SELinux/AppArmor
   - 实践最小权限原则

4. **PAM 体验**：
   - 部署 JumpServer 开源堡垒机
   - 配置特权账号管理
   - 体验会话审计和命令控制

### 推荐工具

| 工具 | 用途 |
|------|------|
| JumpServer | 开源堡垒机/PAM |
| Keycloak | 开源 IAM，支持RBAC |
| Casbin | 访问控制框架（支持RBAC/ABAC等） |
| Open Policy Agent (OPA) | 通用策略引擎 |
| HashiCorp Vault | 密钥和特权访问管理 |

---

> 💡 **访问控制是信息安全的核心机制。从DAC到MAC，从RBAC到ABAC，访问控制模型在不断演进。在零信任时代，动态、细粒度、持续的访问控制将成为标配。设计好访问控制体系，是保护企业资产的关键。**
