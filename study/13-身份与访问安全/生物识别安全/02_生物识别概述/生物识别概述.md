# 生物识别概述

### 1.1 生物识别原理

**生物识别（Biometric Recognition）** 是利用人体固有的生理特征或行为特征进行身份识别的技术。

```text
生物识别基本原理

识别模式:
├── 验证 (Verification, 1:1): "我是我声称的人吗？"
│   ├── 输入: 声称身份 + 生物特征
│   └── 输出: 接受/拒绝

├── 辨识 (Identification, 1:N): "我是谁？"
│   ├── 输入: 生物特征
│   └── 输出: 身份/未知

└── 排查 (Watchlist, 1:M): "是否在监视名单中？"
    ├── 输入: 生物特征
    └── 输出: 在名单中/不在

生物识别流程:
┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐
│ 采集  │──►│ 增强  │──►│ 特征  │──►│ 比对  │
│Sensor │   │Enhance│   │Extract│   │ Match │
└──────┘   └──────┘   └──────┘   └──────┘
                                      │
                              ┌───────▼───────┐
                              │  决策 (Decision) │
                              └───────────────┘

注册流程 (Enrollment):
  采集 → 特征提取 → 模板生成 → 存储
  注意: 不存储原始生物特征，只存储模板
```

### 1.2 生物特征分类

```text
生物特征分类

生理特征 (Physiological):
├── 指纹 (Fingerprint): 最成熟，使用最广
├── 人脸 (Face): 非接触，接受度高
├── 虹膜 (Iris): 准确率最高
├── 视网膜 (Retina): 安全但侵入性强
├── 掌纹 (Palmprint): 大面积特征
├── 掌静脉 (Palm Vein): 活体性好
├── 指静脉 (Finger Vein): 活体性好
├── DNA: 最准确但慢
└── 耳形 (Ear Shape): 稳定性好

行为特征 (Behavioral):
├── 签名 (Signature): 动态签名
├── 声纹 (Voiceprint): 自然交互
├── 步态 (Gait): 远距离识别
├── 击键模式 (Keystroke): 连续认证
└── 心电图 (ECG): 活体性强

理想生物特征的标准:
├── 普遍性 (Universality): 每个人都有
├── 独特性 (Uniqueness): 人各不同
├── 持久性 (Permanence): 时间稳定
├── 可采集 (Collectability): 易于采集
├── 性能 (Performance): 准确快速
├── 可接受 (Acceptability): 用户接受
└── 防欺骗 (Circumvention): 难以伪造
```

### 1.3 评价指标

| 指标 | 说明 | 公式 |
|------|------|------|
| FAR | 误识率（假冒者被接受） | FA/N |
| FRR | 拒真率（真实者被拒绝） | FR/N |
| EER | 等错误率（FAR=FRR点） | - |
| TAR | 真识率（真实者被接受） | 1-FRR |
| FMR | 假匹配率 | 类似FAR |
| FNMR | 假不匹配率 | 类似FRR |
| GAR | 识别率 | 1-FRR |

```text
性能指标详解

FAR (False Acceptance Rate) - 误识率:
  非法用户被系统接受的概率
  例: FAR=0.01% → 10000次中1次错误接受
  安全要求: FAR越低越安全

FRR (False Rejection Rate) - 拒真率:
  合法用户被系统拒绝的概率
  例: FRR=5% → 20次中1次错误拒绝
  体验要求: FRR越低越好

EER (Equal Error Rate) - 等错误率:
  FAR = FRR 时的错误率
  总体性能指标: EER越低越好

ROC曲线 (Receiver Operating Characteristic):
  FAR vs TAR 曲线
  越靠近左上角越好

安全性与便利性的权衡:
  高安全场景: 降低FAR（但FRR升高）→ 安全但不便
  高便利场景: 降低FRR（但FAR升高）→ 便利但不安全
  平衡点: EER附近

典型性能:
├── 指纹: FAR=0.001%, FRR=2%
├── 人脸(3D): FAR=0.01%, FRR=0.1%
├── 虹膜: FAR=0.0001%, FRR=0.5%
├── 声纹: FAR=1%, FRR=5%
└── 多模态: FAR=0.00001%, FRR=0.1%
```
