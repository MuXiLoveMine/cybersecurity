# 虹膜识别安全

### 4.1 虹膜特征

```text
虹膜识别原理

虹膜特征:
├── 位置: 瞳孔与巩膜之间的环状区域
├── 形成: 胎儿发育期随机形成，2岁后稳定
├── 独特性: 即使同卵双胞胎也不同
├── 稳定性: 一生不变
├── 非接触: 适合卫生要求高的场景
└── 准确性: 识别率最高的生物特征之一

虹膜纹理特征:
├── 斑点 (Freckles)
├── 细丝 (Filaments)
├── 收缩沟 (Furrows)
├── 环 (Rings)
├── 晶状体斑点 (Crypts)
└── 色素沉着 (Pigmentation)

虹膜编码:
  Daugman算法:
  1. 虹膜定位: 检测瞳孔和外边界
  2. 归一化: 转换为极坐标的固定大小
  3. 特征编码: Gabor滤波 → 2进制编码
  4. 匹配: Hamming距离比较

  编码长度: 通常2048位(256字节)
  匹配速度: 极快(Hamming距离计算)
  准确率: FAR < 0.0001%
```

### 4.2 虹膜识别流程

```text
虹膜识别流程

1. 图像采集
   ├── 近红外照明 (700-900nm)
   ├── 高分辨率相机
   ├── 用户配合（注视镜头）
   └── 距离: 10-30cm (部分支持远距离)

2. 虹膜定位
   ├── 检测瞳孔边界（内边界）
   ├── 检测虹膜外边界（外边界）
   ├── 检测上下眼睑（遮挡处理）
   └── 质量评估（清晰度/遮挡）

3. 归一化
   ├── 转换为极坐标
   ├── 橡胶圈模型(Rubber Sheet Model)
   ├── 固定大小(如64x512)
   └── 补偿瞳孔缩放

4. 特征编码
   ├── Gabor滤波器组
   ├── 量化为2进制
   ├── 掩码（遮挡区域）
   └── 生成2048位虹膜码

5. 匹配
   ├── Hamming距离计算
   ├── 掩码处理
   ├── 阈值判断(如HD < 0.35)
   └── 决策

虹膜识别优势:
  ✓ 准确率最高
  ✓ 稳定性最好
  ✓ 非接触
  ✓ 难以伪造
  ✓ 编码紧凑

虹膜识别劣势:
  ✗ 需要专用设备
  ✗ 成本较高
  ✗ 需要用户配合
  ✗ 对眼镜/隐形眼镜敏感
  ✗ 远距离识别困难
```
