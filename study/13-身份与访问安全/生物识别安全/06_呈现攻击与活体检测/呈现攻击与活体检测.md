# 呈现攻击与活体检测

### 6.1 呈现攻击类型

**呈现攻击（Presentation Attack, PA）** 是指攻击者使用伪造的生物特征欺骗生物识别系统。

```text
呈现攻击分类 (ISO/IEC 30107-1)

Level 0: 无攻击（正常使用）

Level 1: 简单照片/录音
├── 打印照片
├── 屏幕显示照片
├── 录音回放
└── 防御难度: 低

Level 2: 视频/3D面具
├── 视频回放
├── 3D打印面具
├── 硅胶指纹
├── 防御难度: 中

Level 3: 高级假体
├── 高精度3D面具
├── 人工虹膜
├── 电子指纹
├── 实时深度伪造
└── 防御难度: 高

Level 4: 植入/改造
├── 指纹移植
├── 整容手术
└── 防御难度: 极高

攻击类型详表:
┌──────────────┬─────────────┬─────────────┬──────────┐
│ 生物特征      │ 攻击方式    │ 攻击级别    │ 防御     │
├──────────────┼─────────────┼─────────────┼──────────┤
│ 指纹          │ 硅胶假指纹  │ Level 2    │ 活体检测 │
│              │ 残留指纹    │ Level 1    │ 活体检测 │
│              │ 电子指纹    │ Level 3    │ 多模态   │
├──────────────┼─────────────┼─────────────┼──────────┤
│ 人脸          │ 照片        │ Level 1    │ 3D/活体  │
│              │ 视频        │ Level 2    │ 随机指令 │
│              │ 3D面具      │ Level 3    │ 红外/多谱│
│              │ 深度伪造    │ Level 3-4  │ 多模态   │
├──────────────┼─────────────┼─────────────┼──────────┤
│ 虹膜          │ 隐形眼镜    │ Level 2    │ 深度验证 │
│              │ 人工虹膜    │ Level 3    │ 多光谱   │

```

### 6.2 活体检测技术

```text
活体检测技术全景

1. 硬件级活体检测
   ├── 电容式指纹传感器: 测量电容变化
   ├── 温度传感器: 人体温度范围
   ├── 湿度传感器: 皮肤湿度
   ├── 红外传感器: 红外反射特性
   ├── 超声波传感器: 皮肤层结构
   ├── ToF传感器: 3D深度信息
   └── 结构光: 3D表面重建

2. 软件级活体检测
   ├── 纹理分析: 照片/屏幕纹理
   ├── 频域分析: 频谱特征异常
   ├── 运动分析: 微表情/呼吸
   ├── 光照分析: 反射/阴影一致性
   ├── 深度估计: 从单图估计深度
   └── 基于学习的: CNN/RNN分类

3. 交互式活体检测
   ├── 随机动作指令: 眨眼/张嘴/摇头
   ├── 文本朗读: 随机数字/句子
   ├── 头部姿态: 特定方向转动
   └── 时间约束: 限时完成

4. 多模态活体检测
   ├── 可见光 + 红外
   ├── 2D + 3D
   ├── 视频 + 音频
   └── 多帧分析

PAD评估标准 (ISO/IEC 30107-3):
├── APCER (Attack Presentation Classification Error Rate)
│   └── 攻击样本被分类为真实的比例
├── BPCER (Bona Fide Presentation Classification Error Rate)
│   └── 真实样本被分类为攻击的比例
└── ACER (Average Classification Error Rate)
    └── (APCER + BPCER) / 2
```
