# 指纹识别安全

### 2.1 指纹特征提取

```text
指纹识别原理

指纹基本特征:
├── 全局特征 (Level 1):
│   ├── 弓型 (Arch)
│   ├── 箕型 (Loop)
│   ├── 斗型 (Whorl)
│   └── 用于粗分类
│
├── 局部特征 (Level 2):
│   ├── 端点 (Ridge Ending)
│   ├── 分叉点 (Bifurcation)
│   ├── 短纹 (Short Ridge)
│   ├── 点 (Dot)
│   └── 核心 (Minutiae) - 最重要
│
└── 微观特征 (Level 3):
    ├── 汗孔 (Pore)
    ├── 纹线宽度
    ├── 纹线边缘
    └── 用于高精度匹配

特征提取流程:
1. 图像采集 → 指纹图像
2. 图像增强 → 去噪、定向
3. 二值化 → 黑白指纹
4. 细化 → 单像素宽纹线
5. 端点提取 → 坐标+方向
6. 模板生成 → 端点集合
```

```python
import numpy as np

class FingerprintFeatureExtractor:
    """指纹特征提取（简化版）"""

    def __init__(self):
        self.minutiae_threshold = 3

    def extract_minutiae(self, fingerprint_image):
        """
        从指纹图像中提取端点
        :param fingerprint_image: 二值化指纹图像 (0/1)
        :return: 端点列表
        """
        # 二值化
        if fingerprint_image.max() > 1:
            binary = (fingerprint_image > 128).astype(np.uint8)
        else:
            binary = fingerprint_image.astype(np.uint8)

        # 细化（简化）
        thinned = self._thin(binary)

        # 端点检测
        minutiae = self._detect_minutiae(thinned)

        # 过滤边界点
        minutiae = self._filter_border_minutiae(minutiae, thinned.shape)

        return minutiae

    def _thin(self, binary):
        """细化操作（简化）"""
        # 实际使用Zhang-Suen或Guo-Hall算法
        return binary

    def _detect_minutiae(self, thinned):
        """检测端点和分叉点"""
        minutiae = []
        rows, cols = thinned.shape

        for i in range(1, rows - 1):
            for j in range(1, cols - 1):
                if thinned[i, j] == 1:  # 前景像素
                    # 计算交叉数(Crossing Number)
                    cn = self._crossing_number(thinned, i, j)

                    if cn == 1:
                        minutiae.append({
                            'type': 'ending',
                            'x': j, 'y': i,
                            'direction': self._compute_direction(thinned, i, j)
                        })
                    elif cn == 3:
                        minutiae.append({
                            'type': 'bifurcation',
                            'x': j, 'y': i,
                            'direction': self._compute_direction(thinned, i, j)
                        })

        return minutiae

    @staticmethod
    def _crossing_number(image, i, j):
        """计算交叉数"""
        # 8邻域顺时针
        neighbors = [
            image[i-1, j], image[i-1, j+1], image[i, j+1], image[i+1, j+1],
            image[i+1, j], image[i+1, j-1], image[i, j-1], image[i-1, j-1]
        ]

        cn = 0
        for k in range(8):
            cn += abs(int(neighbors[k]) - int(neighbors[(k+1) % 8]))

        return cn // 2

    @staticmethod
    def _compute_direction(image, i, j):
        """计算端点方向（简化）"""
        return 0.0

    @staticmethod
    def _filter_border_minutiae(minutiae, shape, margin=10):
        """过滤边界附近的端点"""
        return [m for m in minutiae
                if margin < m['x'] < shape[1] - margin
                and margin < m['y'] < shape[0] - margin]

    @staticmethod
    def match_templates(template1, template2, threshold=12):
        """
        比对两个指纹模板
        :param template1: 端点列表1
        :param template2: 端点列表2
        :param threshold: 匹配端点数阈值
        :return: 匹配分数
        """
        matched_count = 0

        for m1 in template1:
            for m2 in template2:
                # 距离匹配
                dist = np.sqrt((m1['x'] - m2['x'])**2 +
                               (m1['y'] - m2['y'])**2)
                if dist < 10:  # 距离阈值
                    # 方向匹配
                    angle_diff = abs(m1['direction'] - m2['direction'])
                    if angle_diff < 0.3:  # 角度阈值
                        matched_count += 1
                        break

        match_score = matched_count / max(len(template1), 1)
        is_match = matched_count >= threshold

        return {
            'matched': is_match,
            'score': match_score,
            'matched_count': matched_count
        }
```

### 2.2 AFIS系统

**AFIS (Automated Fingerprint Identification System)** 是自动指纹识别系统，用于大规模指纹比对。

```text
AFIS系统架构

┌──────────────────────────────────────────────────────┐
│                   AFIS系统                             │
├──────────────────────────────────────────────────────┤
│  采集层: 指纹扫描仪/活体采集                           │
│  处理层: 图像增强/特征提取                             │
│  比对层: 快速搜索/精确比对                             │
│  存储层: 指纹数据库(模板存储)                          │
│  管理层: 用户管理/审计日志                             │
└──────────────────────────────────────────────────────┘

比对模式:
├── 1:1验证: 比对两个模板
├── 1:N排查: 在数据库中搜索
└── 1:1:N: 验证+排查

性能要求:
├── 指纹库规模: 百万至亿级
├── 搜索速度: 10000模板/秒
├── 精确度: FAR < 0.001%
└── 活体检测: 防止假指纹
```

### 2.3 指纹攻击与防御

```text
指纹识别安全威胁

威胁1: 假指纹攻击
  ├── 攻击者制作假指纹（硅胶/3D打印）
  ├── 从照片/物体表面提取指纹
  └── 防御: 活体检测（温度/湿度/电容）

威胁2: 指纹数据泄露
  ├── 指纹模板从数据库泄露
  ├── 生物特征不可更换 → 永久泄露
  └── 防御: 模板加密存储 + 不可逆变换

威胁3: 中间人攻击
  ├── 截获指纹传输数据
  ├── 重放指纹模板
  └── 防御: 传输加密 + challenge-response

威胁4: 深度伪造
  ├── 利用AI生成指纹图像
  └── 防御: 多维度活体检测

威胁5: 数据库注入
  ├── 在数据库中注入攻击者指纹模板
  └── 防御: 数据库访问控制 + 审计
```
