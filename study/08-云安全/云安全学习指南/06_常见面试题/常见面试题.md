# 常见面试题

### 基础概念
1. **什么是云计算？云服务模式有哪些？**
   - 云计算是通过网络提供计算资源的模式
   - IaaS（基础设施即服务）：虚拟机、存储、网络
   - PaaS（平台即服务）：数据库、中间件、开发平台
   - SaaS（软件即服务）：应用程序、邮箱、CRM

2. **什么是责任共担模型？**
   - 云厂商负责云基础设施的安全
   - 客户负责自己在云上的数据和应用的安全
   - IaaS 模式下客户责任最大，SaaS 模式下客户责任最小
   - 不同服务模式责任划分不同

3. **云安全的主要风险有哪些？**
   - 配置错误：最常见的风险
   - 身份与访问管理问题：权限过大、密钥泄露
   - 数据泄露：存储配置错误、未加密
   - 账户劫持：凭证泄露、钓鱼
   - 不安全的接口：API 漏洞
   - 共享技术漏洞：虚拟化漏洞
   - 内部威胁：恶意内部人员

4. **什么是云原生？云原生安全包括什么？**
   - 云原生是基于微服务、容器、DevOps、持续交付的软件开发方式
   - 云原生安全包括：容器安全、K8s 安全、微服务安全、API 安全、DevSecOps、安全左移

### 技术原理
5. **容器和虚拟机的区别？容器安全风险有哪些？**
   - 区别：容器共享内核，轻量级，启动快；虚拟机有独立内核，重量级，启动慢
   - 安全风险：容器逃逸、镜像漏洞、敏感信息泄露、权限提升、资源滥用、横向移动

6. **Kubernetes 的安全风险有哪些？**
   - 身份与权限：RBAC 配置错误、权限过大、Service Account 滥用
   - 工作负载：特权容器、容器逃逸、镜像漏洞
   - 网络：网络隔离不足、服务暴露、横向移动
   - 集群：API Server 安全、etcd 安全、控制平面安全

7. **什么是 DevSecOps？安全左移是什么意思？**
   - DevSecOps 是将安全融入 DevOps 流程，在开发运维全过程中考虑安全
   - 安全左移是指将安全工作从后期提前到早期，在设计、开发阶段就考虑安全
   - 好处：更早发现问题、修复成本更低、安全效率更高

8. **常见的云配置错误有哪些？**
   - 身份与访问：权限过大、未启用 MFA、密钥泄露、角色信任过宽
   - 存储：存储桶公开访问、策略配置错误、未加密
   - 网络：安全组端口过度开放、公网暴露过多、网络隔离不足
   - 数据库：公网暴露、弱口令、未加密

### 实战相关
9. **如何进行云安全配置审计？**
   - 使用自动化工具：Scout Suite、Prowler、CloudSploit 等
   - 检查身份与访问管理配置
   - 检查网络安全配置
   - 检查存储安全配置
   - 检查数据库安全配置
   - 检查日志与监控配置
   - 对照安全基线和最佳实践
   - 输出审计报告和整改建议

10. **云渗透测试需要注意什么？**
    - 遵守云厂商的渗透测试规则
    - 提前报备，获得授权
    - 控制测试范围和影响
    - 禁止测试云基础设施
    - 保护客户数据
    - 及时报告发现的漏洞
    - 遵守法律法规

11. **什么是元数据服务攻击？**
    - 云平台提供元数据服务，供实例获取自身信息
    - 如果应用存在 SSRF 漏洞，可以访问元数据服务
    - 可以获取临时凭证、实例信息等敏感数据
    - 防护：限制元数据服务访问、启用 IMDSv2、最小权限角色

12. **云安全最佳实践有哪些？**
    - 身份安全：最小权限、启用 MFA、定期轮换密钥、使用角色
    - 网络安全：最小化公网暴露、严格安全组、网络分段
    - 数据安全：加密存储和传输、备份、访问控制
    - 配置安全：安全基线、配置审计、自动化检查
    - 监控检测：日志收集、威胁检测、安全告警
    - 应急响应：应急预案、事件响应、灾难恢复
