# 学习路线

### 阶段 1：云计算基础（1-2 个月）
**学习目标**：掌握云计算基础知识和主流云平台使用

**学习内容**
- 云计算概念与架构
- 云服务模式与部署模式
- 责任共担模型
- 主流云平台使用（选一个深入）
- 云服务器、存储、网络基础
- 云数据库基础

**实践任务**
- 注册云平台账号（免费试用）
- 创建云服务器
- 配置 VPC 和安全组
- 使用对象存储
- 创建云数据库
- 学习云平台基本操作

### 阶段 2：云安全基础（2-3 个月）
**学习目标**：掌握云安全基础知识和配置安全

**学习内容**
- 云安全责任共担模型
- 身份与访问管理（IAM）
- 云网络安全
- 云存储安全
- 云服务器安全
- 云数据库安全
- 常见配置错误
- 云安全最佳实践

**实践任务**
- 配置 IAM 策略
- 配置安全组
- 配置存储桶安全
- 加固云服务器
- 做配置安全审计
- 学习云安全产品

### 阶段 3：容器与 K8s 安全（3-4 个月）
**学习目标**：掌握容器和 Kubernetes 安全技术

**学习内容**
- Docker 安全
- 容器安全风险
- 镜像安全
- 容器运行时安全
- Kubernetes 架构
- K8s 安全风险
- K8s 安全配置
- K8s 安全工具

**实践任务**
- 学习 Docker 安全配置
- 使用镜像扫描工具
- 搭建 K8s 集群
- 配置 K8s RBAC
- 配置 Network Policy
- 使用 K8s 安全工具
- 做 K8s 安全审计

### 阶段 4：云原生安全与攻防（2-3 个月）
**学习目标**：掌握云原生安全和云攻防技术

**学习内容**
- DevSecOps
- 安全左移
- IaC 安全
- 微服务安全
- API 安全
- 云渗透测试
- 云攻击技术
- 云防御技术
- 云安全运营

**实践任务**
- 搭建 DevSecOps 流水线
- 使用 IaC 安全扫描工具
- 做云渗透测试练习
- 学习云攻击技术
- 配置云安全监控
- 做云安全应急响应练习

### 阶段 5：深入研究（持续）
**研究方向**
- 云原生安全
- 容器安全
- K8s 安全
- 云攻防技术
- 云安全运营
- 云合规
- 云安全产品
