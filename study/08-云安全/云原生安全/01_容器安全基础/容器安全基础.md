# 容器安全基础

### 1.1 容器与虚拟机的区别

| 特性 | 容器（Container） | 虚拟机（VM） |
|------|-------------------|--------------|
| 虚拟化层级 | 操作系统级虚拟化 | 硬件级虚拟化 |
| 内核共享 | 共享宿主机内核 | 每个 VM 有独立内核 |
| 隔离级别 | 进程级隔离（较弱） | 系统级隔离（较强） |
| 资源占用 | 轻量（MB 级） | 重量（GB 级） |
| 启动速度 | 秒级 | 分钟级 |
| 性能损耗 | 极小 | 较大 |
| 安全边界 | cgroup + namespace | Hypervisor |

**容器安全的核心挑战**：
- 共享内核带来的逃逸风险
- 镜像供应链安全
- 容器间隔离与横向移动
- 运行时安全监控
- 密钥与敏感信息管理

### 1.2 容器安全风险矩阵

| 风险类别 | 具体风险 | 严重程度 | 常见场景 |
|----------|----------|----------|----------|
| 镜像安全 | 基础镜像漏洞 | 高危 | 使用过时的基础镜像 |
| 镜像安全 | 恶意镜像 | 高危 | 从不可信来源拉取镜像 |
| 镜像安全 | 敏感信息泄露 | 高危 | Dockerfile 中硬编码密钥 |
| 运行时安全 | 容器逃逸 | 高危 | 特权容器 + 内核漏洞 |
| 运行时安全 | 权限提升 | 高危 | root 用户运行容器 |
| 运行时安全 | 资源滥用 | 中危 | 未设置资源限制 |
| 配置安全 | 特权容器 | 高危 | --privileged 参数 |
| 配置安全 | 挂载敏感目录 | 高危 | 挂载 /var/run/docker.sock |
| 网络安全 | 容器间未隔离 | 中危 | 默认网络模式 |
| 网络安全 | 端口暴露过多 | 中危 | -P 参数暴露所有端口 |
