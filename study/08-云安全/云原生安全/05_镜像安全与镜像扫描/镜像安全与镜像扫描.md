# 镜像安全与镜像扫描

### 5.1 镜像安全风险

#### 5.1.1 镜像安全威胁

| 威胁类型 | 说明 | 示例 |
|----------|------|------|
| 漏洞镜像 | 基础镜像或应用包含已知漏洞 | Log4j、OpenSSL 漏洞 |
| 恶意镜像 | 镜像中植入恶意代码 | 挖矿木马、后门 |
| 敏感信息泄露 | 镜像中包含密钥、密码等 | Dockerfile 中的 ENV 密码 |
| 镜像篡改 | 镜像在传输或存储中被篡改 | 中间人攻击替换镜像 |
| 供应链攻击 | 基础镜像或依赖被投毒 | npm 包投毒、Docker Hub 恶意镜像 |
| 配置不当 | 镜像配置存在安全缺陷 | root 用户运行、开放过多端口 |

### 5.2 镜像安全防护措施

#### 5.2.1 镜像构建安全

1. **使用可信的基础镜像**：
   - 优先使用官方镜像
   - 验证镜像签名
   - 固定镜像版本（digest 而非 tag）

2. **最小化镜像**：
   - 使用 distroless 镜像
   - 使用 alpine/slim 变体
   - 多阶段构建
   - 删除不必要的工具和文件

3. **敏感信息保护**：
   - 使用 BuildKit 的 secret 挂载
   - 使用 multi-stage build 清除中间层敏感信息
   - 配置 .dockerignore 排除敏感文件

4. **非 root 用户**：
   - Dockerfile 中使用 USER 指令
   - 指定具体的 UID/GID

#### 5.2.2 多阶段构建示例

```dockerfile
# 构建阶段
FROM golang:1.21-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -a -installsuffix cgo -o app .

# 最终阶段（使用最小镜像）
FROM gcr.io/distroless/static:nonroot

WORKDIR /app
# 只复制编译后的二进制文件
COPY --from=builder /app/app .

# 使用非 root 用户
USER nonroot:nonroot

EXPOSE 8080

CMD ["./app"]
```

### 5.3 镜像签名与验证

#### 5.3.1 Cosign 工具

Cosign 是 Sigstore 项目的一部分，用于容器镜像的签名和验证。

**使用示例**：
```bash
# 生成密钥对
cosign generate-key-pair

# 签名镜像
cosign sign --key cosign.key myregistry/myimage:tag

# 验证镜像签名
cosign verify --key cosign.pub myregistry/myimage:tag

# 在 Kubernetes 中通过准入控制器验证
# 使用 policy-controller 或 Kyverno
```

### 5.4 镜像扫描实践

#### 5.4.1 Trivy 详细使用

```bash
# 扫描镜像漏洞
trivy image nginx:1.24

# 指定严重级别
trivy image --severity CRITICAL,HIGH nginx:1.24

# 输出详细报告
trivy image --format json --output report.json nginx:1.24

# 扫描镜像中的敏感信息
trivy image --scanners secret nginx:1.24

# 扫描镜像配置（Dockerfile 问题）
trivy image --scanners config nginx:1.24

# 扫描全部类型（漏洞+密钥+配置）
trivy image --scanners vuln,secret,config nginx:1.24

# 忽略已修复的漏洞
trivy image --ignore-unfixed nginx:1.24
```
