# Serverless 安全概述

### 1.1 什么是 Serverless

Serverless（无服务器）是一种云原生计算模型，开发者只需编写函数代码，云厂商负责底层服务器、扩缩容、调度。典型形式为 FaaS（Function as a Service）：
- AWS Lambda
- 阿里云函数计算（FC）
- Azure Functions
- 腾讯云 SCF

特点：
- 事件驱动：由 HTTP、对象存储、消息队列等事件触发
- 按调用计费
- 无需管理服务器
- 自动弹性伸缩
- 短时执行（通常 15 分钟内）

### 1.2 FaaS 安全模型与责任边界变化

传统云主机安全中，云厂商负责底层物理设施，客户负责操作系统以上。而 FaaS 模型下，责任边界进一步上移：

| 安全责任 | 传统云主机 | FaaS Serverless |
| --- | --- | --- |
| 物理设施 | 云厂商 | 云厂商 |
| 虚拟化层 | 云厂商 | 云厂商 |
| 操作系统 | 客户 | 云厂商 |
| 运行时（Node/Python） | 客户 | 云厂商 |
| 应用代码与依赖 | 客户 | 客户 |
| 函数权限与触发器配置 | 不适用 | 客户 |
| 事件源配置 | 不适用 | 客户 |

可见，客户的安全责任集中在：
- 函数代码本身
- 函数依赖库
- 函数执行角色权限
- 触发器与事件源映射
- 环境变量与密钥管理

### 1.3 Serverless 攻击面模型

Serverless 引入了与传统应用不同的攻击面：

```text
+---------------------------------------------------+
|                  Serverless 攻击面                  |
+---------------------------------------------------+
| 1. 事件源注入（HTTP / 消息 / 对象存储事件）         |
| 2. 函数权限过度（IAM 角色权限过大）                  |
| 3. 第三方依赖漏洞（npm / pip 包）                    |
| 4. 拒绝钱包攻击（资源消耗攻击导致计费）              |
| 5. 敏感信息泄露（环境变量 / 日志）                    |
| 6. 函数执行链滥用（跨函数横向移动）                   |
| 7. 持久化攻击（事件触发器劫持）                      |
+---------------------------------------------------+
```
