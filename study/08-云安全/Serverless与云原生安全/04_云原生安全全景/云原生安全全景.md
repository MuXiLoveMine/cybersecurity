# 云原生安全全景

云原生（Cloud Native）以容器、微服务、声明式 API 为核心。其安全覆盖从代码到运行时全生命周期：

```text
代码 -> 构建 -> 部署 -> 运行
 |        |        |        |
SCA     镜像扫描   IaC扫描   运行时
SAST    SBOM     策略校验   Falco
密钥扫描  签名     准入控制   Tetragon
```

### 4.1 容器安全

容器安全核心要点：
- 镜像漏洞扫描
- 最小化基础镜像（如 distroless / alpine）
- 非 root 用户运行
- 只读文件系统
- 限制资源（CPU / 内存）
- 禁用特权模式

**安全 Pod 配置示例**

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: secure-app
spec:
  securityContext:
    runAsNonRoot: true
    runAsUser: 1000
    fsGroup: 2000
  containers:
  - name: app
    image: myapp:1.0
    securityContext:
      allowPrivilegeEscalation: false
      readOnlyRootFilesystem: true
      runAsNonRoot: true
      capabilities:
        drop:
          - ALL
    resources:
      limits:
        cpu: "500m"
        memory: "256Mi"
      requests:
        cpu: "100m"
        memory: "128Mi"
    volumeMounts:
    - name: tmp
      mountPath: /tmp
  volumes:
  - name: tmp
    emptyDir: {}
```

### 4.2 镜像扫描与签名

#### 镜像漏洞扫描（Trivy）

```bash
# 扫描镜像漏洞
trivy image myapp:1.0

# 在 CI 中阻断高危漏洞
trivy image --exit-code 1 --severity HIGH,CRITICAL myapp:1.0
```

#### 镜像签名（Cosign）

```bash
# 生成密钥对
cosign generate-key-pair

# 对镜像签名
cosign sign --key cosign.key myregistry/myapp:1.0

# 验证签名（部署前校验）
cosign verify --key cosign.pub myregistry/myapp:1.0
```

#### Kyverno 准入策略：只允许已签名镜像

```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-signed-images
spec:
  validationFailureAction: Enforce
  rules:
  - name: check-signature
    match:
      resources:
        kinds:
        - Pod
    verifyImages:
    - imageReferences:
        - "*"
      attestors:
      - entries:
        - keys:
            publicKeys: |
              -----BEGIN PUBLIC KEY-----
              <cosign 公钥内容>
              -----END PUBLIC KEY-----
```
