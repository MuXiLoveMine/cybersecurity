# 安全最佳实践

### 10.1 Serverless 最佳实践

1. 每个函数最小权限，独立 IAM 角色
2. 所有输入视为不可信，严格校验
3. CI 集成依赖扫描与 SAST
4. 环境变量不存敏感信息，用密钥管理服务
5. API 网关启用认证、限速、WAF
6. 设置函数并发上限与超时
7. 日志统一聚合，异常告警

### 10.2 容器与 Kubernetes 最佳实践

1. 使用最小化基础镜像（distroless）
2. 镜像漏洞扫描 + 签名验证
3. 非 root 运行，只读根文件系统
4. 禁用特权模式与危险 capabilities
5. Pod Security Standard 设为 restricted
6. RBAC 最小权限
7. NetworkPolicy 默认拒绝
8. etcd 加密存储
9. 定期升级集群版本

### 10.3 Service Mesh 最佳实践

1. 全网格 mTLS STRICT 模式
2. 授权策略默认拒绝
3. JWT 校验在网格层
4. 审计所有授权决策
5. 证书自动轮转

### 10.4 运行时安全最佳实践

1. 部署 Falco / Tetragon 全集群监控
2. 关键规则：shell 执行、敏感文件访问、网络外联
3. 高危行为实时阻断
4. 告警接入 SIEM
5. 定期演练容器逃逸响应

### 10.5 供应链最佳实践

1. 全流程生成 SBOM
2. 镜像签名 + 准入校验
3. IaC 模板扫描（Checkov / tfsec）
4. OPA 策略准入控制
5. 依赖定期更新与漏洞监控
6. 私有镜像仓库 + 镜像代理缓存

### 10.6 GitOps 最佳实践

1. Git 仓库强制签名提交
2. PR 评审 + 自动扫描
3. ArgoCD / Flux 最小 RBAC
4. 生产环境同步需审批
5. 监控配置漂移
6. 回滚机制演练
