# 云计算概述

### 1.1 云计算定义

云计算（Cloud Computing）是一种通过网络按需提供可弹性扩展的计算资源的服务模式。用户无需购买和维护物理硬件，而是通过互联网访问计算、存储、数据库、网络等资源，按使用量付费。

**云计算的五大核心特征**（NIST 定义）：

| 特征 | 说明 |
|------|------|
| 按需自助服务 | 用户可自动按需获取计算能力，无需与服务提供商人工交互 |
| 广泛的网络接入 | 通过网络访问，支持各种客户端（手机、平板、笔记本） |
| 资源池化 | 提供商的计算资源池化，以多租户模式服务多个用户 |
| 快速弹性 | 可快速弹性地提供和释放资源，按需增减 |
| 可计量的服务 | 按使用量计费，资源使用可监控、控制和报告 |

### 1.2 云服务模式（IaaS / PaaS / SaaS）

#### 1.2.1 IaaS（基础设施即服务）

**定义**：提供虚拟化的计算基础设施，包括虚拟机、存储、网络等基础资源。

**典型服务**：
- 云服务器（AWS EC2、阿里云 ECS、Azure VM）
- 对象存储（AWS S3、阿里云 OSS、Azure Blob）
- 虚拟网络（AWS VPC、阿里云 VPC、Azure VNet）
- 块存储、文件存储

**用户责任**：
- 操作系统安装与维护
- 中间件、运行时配置
- 应用程序部署
- 数据安全
- 身份认证与访问控制
- 网络安全配置（安全组等）

**适用场景**：
- 需要完全控制基础设施的企业
- 有特殊操作系统/软件需求
- 传统应用迁移上云

**案例**：某创业公司使用 AWS EC2 部署 Web 应用，自行管理 Linux 系统、Nginx、应用代码和数据库。

---

#### 1.2.2 PaaS（平台即服务）

**定义**：提供应用开发、运行和管理的平台环境，用户无需管理底层基础设施。

**典型服务**：
- 云数据库（AWS RDS、阿里云 RDS、Azure SQL）
- 容器服务（AWS ECS/EKS、阿里云 ACK、Azure AKS）
- 无服务器计算（AWS Lambda、阿里云函数计算、Azure Functions）
- 消息队列、缓存服务
- 开发平台（Heroku、Google App Engine）

**用户责任**：
- 应用程序开发与部署
- 数据安全
- 身份认证与访问控制
- 应用层安全配置

**适用场景**：
- 快速应用开发与部署
- 微服务架构
- 无需关心底层运维

**案例**：某电商平台使用阿里云 RDS（MySQL）作为数据库，云厂商负责数据库安装、补丁、备份、高可用，客户只负责表结构设计、数据操作和访问控制。

---

#### 1.2.3 SaaS（软件即服务）

**定义**：通过互联网提供完整的软件应用，用户直接使用，无需管理任何基础设施。

**典型服务**：
- 企业邮箱（腾讯企业邮、Gmail）
- CRM 系统（Salesforce、纷享销客）
- 协作工具（飞书、钉钉、Slack）
- 在线办公（Office 365、Google Workspace）
- ERP、HR 系统

**用户责任**：
- 数据输入与管理
- 用户账号管理
- 基本的配置安全
- 数据导出与备份

**适用场景**：
- 通用办公软件
- 标准化业务应用
- 快速上线、降低成本

**案例**：某公司使用 Salesforce CRM 管理客户关系，Salesforce 负责所有基础设施、平台、应用的安全，客户只负责账号配置、数据录入和权限管理。

---

#### 1.2.4 三种模式对比

| 对比项 | IaaS | PaaS | SaaS |
|--------|------|------|------|
| 用户管理 | 操作系统及以上 | 应用及数据 | 数据和配置 |
| 厂商管理 | 物理设施、虚拟化 | 基础设施、平台 | 全部基础设施和应用 |
| 灵活性 | 最高 | 中等 | 最低 |
| 运维成本 | 最高 | 中等 | 最低 |
| 用户技术要求 | 高 | 中 | 低 |
| 安全责任（客户） | 最大 | 中等 | 最小 |
| 典型代表 | AWS EC2 | AWS RDS | Salesforce |

### 1.3 云部署模式

#### 1.3.1 公有云（Public Cloud）
- 由第三方云服务提供商运营，向公众开放
- 多租户共享资源
- 成本低、弹性好、无需维护
- 代表：阿里云、AWS、Azure

#### 1.3.2 私有云（Private Cloud）
- 为单个组织单独构建
- 可部署在企业内部或由第三方托管
- 安全性高、可控性强
- 成本高、弹性相对较弱
- 代表：VMware、OpenStack

#### 1.3.3 混合云（Hybrid Cloud）
- 公有云 + 私有云的组合
- 敏感数据放私有云，非敏感业务放公有云
- 兼顾安全与灵活性
- 挑战：数据同步、统一管理、网络连接

#### 1.3.4 多云（Multi-Cloud）
- 同时使用多个公有云服务商
- 避免厂商锁定
- 可选择各厂商优势服务
- 挑战：管理复杂度、安全策略统一
