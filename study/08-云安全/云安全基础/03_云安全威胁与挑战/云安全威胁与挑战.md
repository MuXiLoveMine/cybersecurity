# 云安全威胁与挑战

### 3.1 云安全顶级威胁（CSA Top Threats）

根据云安全联盟（CSA）发布的《云计算顶级威胁报告》，主要威胁包括：

#### 3.1.1 数据泄露（Data Breaches）
**威胁描述**：敏感数据被未授权访问、窃取或泄露。

**常见原因**：
- 存储桶配置错误（公开访问）
- 弱口令或凭证泄露
- API 安全漏洞
- 内部人员恶意泄露
- 供应链攻击

**实际案例**：
2019 年，Capital One 数据泄露事件中，攻击者利用 AWS WAF 配置错误，通过 SSRF 漏洞访问元数据服务获取角色凭证，进而访问 S3 存储桶，泄露超过 1 亿客户的个人信息。

#### 3.1.2 配置错误、变更管理不足
**威胁描述**：云资源配置错误导致安全漏洞。

**常见错误类型**：
- 存储桶公开访问
- 安全组端口全开放（0.0.0.0/0）
- IAM 权限过大
- 数据库公网暴露
- 未启用加密
- 未启用日志审计

**统计数据**：
- 据 Gartner 预测，到 2025 年，99% 的云安全失败将由客户自身配置错误导致
- 错误配置是云数据泄露的首要原因

#### 3.1.3 身份与访问管理薄弱
**威胁描述**：身份认证和访问控制存在缺陷，导致未授权访问。

**常见问题**：
- 权限过大（过度授权）
- 长期密钥未轮换
- 未启用多因素认证（MFA）
- 角色信任策略过宽
- 废弃账号未清理
- 根账号日常使用

#### 3.1.4 不安全的接口与 API
**威胁描述**：云服务 API 设计或实现存在安全漏洞。

**常见问题**：
- API 未授权访问
- 弱认证机制
- 缺乏速率限制
- 敏感信息明文传输
- API 密钥泄露

#### 3.1.5 账户劫持
**威胁描述**：攻击者窃取用户凭证，控制云账户。

**攻击方式**：
- 钓鱼攻击获取凭证
- 凭证泄露（代码仓库、日志文件）
- 社会工程学攻击
- 暴力破解弱口令

#### 3.1.6 内部威胁
**威胁描述**：企业内部人员恶意或误操作导致安全事件。

**类型**：
- 恶意内部人员：窃取数据、破坏系统
- 疏忽大意：误删数据、配置错误
- 第三方人员：供应商、合作伙伴

#### 3.1.7 共享技术漏洞
**威胁描述**：云基础设施共享导致的安全风险。

**风险点**：
- 虚拟化漏洞（如 VMware 逃逸）
- 容器逃逸
- 多租户隔离缺陷
- 宿主机漏洞影响客户虚拟机

### 3.2 云安全的独特挑战

| 挑战 | 说明 | 传统环境 vs 云环境 |
|------|------|-------------------|
| 边界模糊 | 云环境没有明确的物理边界，网络边界动态变化 | 传统：固定物理边界 → 云：软件定义边界 |
| 资产动态性 | 云资源弹性伸缩，IP、实例随时变化 | 传统：固定资产 → 云：动态资产 |
| 多租户共享 | 多用户共享基础设施，隔离依赖软件 | 传统：物理隔离 → 云：逻辑隔离 |
| 责任共担 | 安全责任由厂商和客户共同承担 | 传统：全部自己负责 → 云：分工负责 |
| API 驱动 | 一切操作通过 API 完成，API 安全至关重要 | 传统：物理/控制台操作 → 云：API 驱动 |
| 可见性不足 | 对底层基础设施缺乏可见性 | 传统：完全可见 → 云：黑盒底层 |
| 合规复杂性 | 不同地区、行业合规要求不同 | 传统：自主合规 → 云：共同合规 |
