# 主流云平台安全对比

### 5.1 三大云平台概览

| 对比项 | AWS（亚马逊云） | Azure（微软云） | 阿里云 |
|--------|-----------------|-----------------|--------|
| 全球市场份额 | 第一（约 32%） | 第二（约 22%） | 第三，国内第一 |
| 起步时间 | 2006 年 | 2010 年 | 2009 年 |
| 服务数量 | 最多（200+） | 多（100+） | 多（100+） |
| 数据中心 | 全球最多 | 全球分布广 | 国内最多，海外扩展中 |
| 主要客户 | 互联网、创业公司 | 企业客户、微软生态 | 国内企业、电商、金融 |

### 5.2 核心安全服务对比

#### 5.2.1 身份与访问管理

| 功能 | AWS | Azure | 阿里云 |
|------|-----|-------|--------|
| 身份管理服务 | IAM | Azure AD | RAM |
| 多因素认证 | AWS MFA | Azure MFA | MFA |
| 角色 | IAM Role | 托管标识 | RAM 角色 |
| 策略语言 | JSON | JSON | JSON |
| 身份联合 | IAM Identity Center | Azure AD Connect | RAM SSO |
| 访问密钥 | Access Key | 服务主体密钥 | AccessKey |

**AWS IAM 特点**：
- 策略粒度极细，支持资源级权限
- 支持条件策略（时间、IP、来源等）
- 支持权限边界（Permissions Boundary）

**Azure AD 特点**：
- 与企业 AD 深度集成
- 强大的 B2B/B2C 功能
- 条件访问（Conditional Access）功能强大

**阿里云 RAM 特点**：
- 符合国内使用习惯
- 支持操作审计深度集成
- 与阿里云各产品深度整合

#### 5.2.2 存储服务安全

| 功能 | AWS S3 | Azure Blob | 阿里云 OSS |
|------|--------|------------|------------|
| 默认访问权限 | 私有 | 私有 | 私有 |
| 桶策略 | Bucket Policy | 容器访问策略 | Bucket Policy |
| ACL | 支持 | 支持 | 支持 |
| 服务端加密 | SSE-S3/SSE-KMS/SSE-C | 服务端加密 | SSE-KMS/SSE-OSS |
| 版本控制 | 支持 | 支持 | 支持 |
| 访问日志 | S3 Access Logs | 存储分析日志 | 访问日志 |
| 生命周期管理 | 支持 | 支持 | 支持 |
| 静态网站托管 | 支持 | 支持 | 支持 |

#### 5.2.3 网络安全

| 功能 | AWS | Azure | 阿里云 |
|------|-----|-------|--------|
| 虚拟网络 | VPC | VNet | VPC |
| 虚拟机防火墙 | 安全组（Security Group） | NSG | 安全组 |
| 子网级防火墙 | NACL | NSG（子网级） | 网络 ACL |
| Web 防火墙 | AWS WAF | Azure WAF | 阿里云 WAF |
| DDoS 防护 | AWS Shield | Azure DDoS | DDoS 高防 |
| 负载均衡 | ELB/ALB/NLB | Azure Load Balancer | SLB/ALB/NLB |
| DNS 服务 | Route 53 | Azure DNS | 云解析 DNS |
| CDN | CloudFront | Azure CDN | CDN |

#### 5.2.4 日志与审计

| 功能 | AWS | Azure | 阿里云 |
|------|-----|-------|--------|
| API 调用审计 | CloudTrail | Azure Activity Log | 操作审计（ActionTrail） |
| 日志收集 | CloudWatch Logs | Azure Monitor Logs | 日志服务 SLS |
| 监控告警 | CloudWatch | Azure Monitor | 云监控 |
| 安全中心 | AWS Security Hub | Microsoft Defender for Cloud | 云安全中心 |
| 配置审计 | AWS Config | Azure Policy | 配置审计 |

### 5.3 安全责任共担对比

三家云厂商的责任共担模型基本一致，但在具体服务上有细微差别：

| 服务类型 | AWS | Azure | 阿里云 |
|----------|-----|-------|--------|
| IaaS（VM） | 客户负责 OS 及以上 | 客户负责 OS 及以上 | 客户负责 OS 及以上 |
| 托管数据库 | 客户负责数据和权限 | 客户负责数据和权限 | 客户负责数据和权限 |
| 无服务器 | 客户负责代码和数据 | 客户负责代码和数据 | 客户负责代码和数据 |
| SaaS 类服务 | 客户负责数据和配置 | 客户负责数据和配置 | 客户负责数据和配置 |
