# 云安全学习建议

### 7.1 学习路径

```
阶段一：云计算基础（1-2 个月）
    │
    ├─ 理解云计算概念、服务模式、部署模式
    ├─ 掌握一个云平台的基本操作
    └─ 理解责任共担模型

阶段二：云安全基础（2-3 个月）
    │
    ├─ IAM 身份与访问管理
    ├─ 云网络安全（VPC、安全组）
    ├─ 云存储安全
    ├─ 云数据库安全
    └─ 日志与审计

阶段三：云安全进阶（3-4 个月）
    │
    ├─ 容器与 Kubernetes 安全
    ├─ DevSecOps
    ├─ 云渗透测试
    └─ 云安全运营

阶段四：深入研究（持续）
    │
    ├─ 云安全架构设计
    ├─ 云原生安全
    ├─ 云合规与治理
    └─ 云攻防技术
```

### 7.2 推荐学习资源

**官方文档**：
- AWS Security Documentation: https://docs.aws.amazon.com/security/
- Azure Security Documentation: https://docs.microsoft.com/en-us/azure/security/
- 阿里云安全文档: https://help.aliyun.com/product/security.html

**标准组织**：
- Cloud Security Alliance (CSA): https://cloudsecurityalliance.org/
- NIST Cloud Computing: https://www.nist.gov/programs-projects/cloud-computing

**练习平台**：
- CloudGoat（AWS 漏洞靶场）
- 各云厂商免费试用服务
- TryHackMe / Hack The Box 云相关房间

---

> **小结**：云安全的核心是理解责任共担模型，掌握身份与访问管理、网络安全、数据安全三大支柱，并通过持续学习跟上云技术的快速发展。配置错误是当前云安全最大的风险，建立自动化的配置审计和合规检查机制至关重要。
