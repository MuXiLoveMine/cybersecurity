# 云安全标准

### 4.1 CSA CCM（云控制矩阵）

#### 4.1.1 概述
CSA（Cloud Security Alliance，云安全联盟）是全球领先的云安全组织，CCM（Cloud Controls Matrix，云控制矩阵）是其发布的云安全控制框架。

**最新版本**：CCM v4.0

#### 4.1.2 CCM 控制域

CCM 包含 17 个控制域，覆盖云安全的各个方面：

| 控制域 | 代码 | 说明 |
|--------|------|------|
| 审计与保证 | CCM-AAR | 审计日志、合规验证 |
| 应用安全 | CCM-APP | 应用开发安全、API 安全 |
| 密码学 | CCM-CEK | 加密、密钥管理 |
| 数据中心安全 | CCM-DCS | 物理安全、环境安全 |
| 数据安全与生命周期管理 | CCM-DSL | 数据分类、加密、销毁 |
| 治理、风险管理与合规 | CCM-GRC | 安全治理、风险管理 |
| 人力资源安全 | CCM-HRS | 人员背景调查、安全培训 |
| 身份与访问管理 | CCM-IAM | 身份认证、访问控制 |
| 基础设施与虚拟化安全 | CCM-IVS | 虚拟化安全、基础设施安全 |
| 互操作性与可移植性 | CCM-IPY | 数据和应用可移植性 |
| 运维安全 | CCM-OPS | 变更管理、漏洞管理 |
| 人员安全 | CCM-PES | 人员安全管理 |
| 物理安全 | CCM-PHY | 物理访问控制 |
| 风险管理 | CCM-RSK | 风险评估、风险处理 |
| 安全架构 | CCM-SEC | 安全架构设计 |
| 供应链管理、透明度与问责 | CCM-STA | 第三方管理、供应链安全 |
| 威胁与脆弱性管理 | CCM-TVM | 威胁检测、漏洞管理 |

#### 4.1.3 CCM 的价值
- 提供统一的云安全评估标准
- 帮助云厂商建立安全体系
- 帮助客户评估云服务商安全能力
- 可映射到多个合规标准（ISO 27001、SOC 2、PCI DSS 等）

### 4.2 等保 2.0 云计算安全扩展要求

#### 4.2.1 概述
《网络安全等级保护基本要求》（GB/T 22239-2019）简称"等保 2.0"，其中包含云计算安全扩展要求。

**适用范围**：
- 等级保护对象采用云计算技术构建时，除满足通用要求外，还应满足云计算安全扩展要求
- 适用于云服务商和云服务客户

#### 4.2.2 云计算安全扩展要求主要内容

**1. 安全物理环境**
- 机房位置选择：云服务商机房应满足相应等级要求
- 物理访问控制：云服务商数据中心物理安全
- 防盗窃和防破坏

**2. 安全通信网络**
- 网络架构：云平台网络架构安全
- 通信传输：数据传输加密
- 可信验证：网络设备可信验证

**3. 安全区域边界**
- 边界防护：云平台与外部边界防护
- 访问控制：不同租户之间的访问控制
- 入侵防范：边界入侵检测/防御
- 安全审计：边界访问审计

**4. 安全计算环境**
- 身份鉴别：云租户身份认证
- 访问控制：云资源访问控制
- 安全审计：云操作审计
- 入侵防范：云环境入侵检测
- 数据完整性：数据完整性保护
- 数据保密性：数据加密保护
- 数据备份恢复：数据备份与恢复
- 剩余信息保护：数据销毁
- 个人信息保护：个人信息安全

**5. 安全管理中心**
- 系统管理：云平台系统管理
- 审计管理：安全审计管理
- 安全管理：安全策略管理
- 集中管控：安全集中管控

#### 4.2.3 云服务商与客户责任
等保 2.0 明确了云计算环境下的责任划分：
- **云服务商**：负责云平台基础设施的安全，提供安全能力
- **云服务客户**：负责自身业务系统和数据的安全
- 客户租用的云资源应纳入自身等级保护对象范围

### 4.3 ISO 27001 与云安全

#### 4.3.1 ISO 27001 概述
ISO 27001 是国际公认的信息安全管理体系（ISMS）标准，规定了建立、实施、维护和持续改进信息安全管理体系的要求。

**标准编号**：ISO/IEC 27001:2022

#### 4.3.2 云安全相关 ISO 标准

| 标准 | 名称 | 说明 |
|------|------|------|
| ISO 27001 | 信息安全管理体系要求 | 基础标准，适用于所有组织 |
| ISO 27017 | 云服务信息安全控制实践指南 | 针对云服务的安全控制指南 |
| ISO 27018 | 公有云个人信息保护实践指南 | 针对公有云中个人数据保护 |
| ISO 27005 | 信息安全风险管理 | 风险管理方法 |

#### 4.3.3 ISO 27017 云安全控制要点
- 云服务中的职责划分
- 云服务客户资产的保护
- 云服务的删除和返还
- 虚拟环境安全
- 云服务提供商的管理
- 监控与测量

#### 4.3.4 ISO 27018 个人数据保护要点
- 云服务商作为个人数据处理者的责任
- 数据主体权利保障
- 数据泄露通知
- 数据跨境传输
- 第三方分包处理
