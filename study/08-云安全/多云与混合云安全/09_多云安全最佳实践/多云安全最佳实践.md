# 多云安全最佳实践

### 9.1 身份与访问

1. 建立统一企业 IdP（Azure AD / Okta），所有云联邦登录
2. 全员强制 MFA，特权账号使用硬件密钥（FIDO2）
3. 使用 SCIM 实现账号自动开通 / 回收，杜绝幽灵账号
4. 推行临时凭证（STS / 角色切换），禁用长期 AccessKey
5. 定期执行权限审计，识别过度权限并收敛（最小权限原则）
6. 特权操作采用 JIT（Just-In-Time）授权，用完即收

### 9.2 网络与数据

1. 跨云互联全部加密（专线 L3 加密 或 IPSec）
2. 实施网络微分段，限制跨云东西向流量
3. 使用各云私有端点访问云服务，避免公网暴露
4. 跨云数据传输使用各云 KMS 加密，或自带密钥（BYOK）
5. 建立统一密钥管理服务（KMS / Vault），避免密钥分散
6. 数据按敏感级别分类，高敏数据强制驻留指定区域

### 9.3 配置与合规

1. 使用 CSPM 工具持续监控跨云配置
2. 用策略即代码（OPA / Checkov）统一基线，避免手工配置
3. 建立配置漂移检测与自动修复流水线
4. 定期生成跨云合规报告，覆盖 CIS / 等保 / PCI
5. 基础设施变更必须经过代码评审 + IaC 扫描

### 9.4 监控与响应

1. 各云日志统一聚合到 SIEM
2. 建立跨云威胁检测规则库，覆盖常见异常模式
3. 使用 SOAR 自动响应高危事件
4. 定期开展跨云红蓝对抗演练
5. 建立 IR（事件响应）剧本，明确各云取证与隔离步骤

### 9.5 DevSecOps

1. IaC（Terraform / Pulumi）模板必须通过安全扫描
2. 容器镜像在 CI 中扫描漏洞与敏感信息
3. 部署前校验策略合规性（OPA admission controller）
4. 运行时持续监控工作负载行为
5. 建立 SBOM 资产清单，覆盖跨云所有组件

### 9.6 架构原则

1. **零信任**：不因网络位置而信任，每次访问均验证身份与权限
2. **纵深防御**：身份 / 网络 / 数据 / 工作负载多层独立防护
3. **可观测优先**：先看见才能防护，跨云可见性是基础
4. **自动化优先**：手工操作必然出错，策略与修复均自动化
5. **最小暴露面**：默认拒绝，按需开放，临时授权
