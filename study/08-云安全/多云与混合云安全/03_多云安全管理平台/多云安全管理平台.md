# 多云安全管理平台

### 3.1 云安全态势管理（CSPM）

CSPM（Cloud Security Posture Management）通过 API 连接各云厂商，持续发现云资源、评估配置是否符合安全基线与合规框架（如 CIS Benchmark、等保2.0、PCI DSS）。

核心能力：
- 资源自动发现与盘点
- 配置基线扫描与漂移检测
- 合规报告生成
- 自动修复（Remediation）

### 3.2 云工作负载保护平台（CWPP）

CWPP（Cloud Workload Protection Platform）关注云主机、容器、Serverless 函数等工作负载的运行时安全：
- 漏洞扫描
- 主机入侵检测（HIDS）
- 容器运行时保护
- 文件完整性监控

### 3.3 云原生应用保护平台（CNAPP）

CNAPP（Cloud Native Application Protection Platform）是 CSPM + CWPP + CI/CD 安全的组合体，强调从代码到运行时的全生命周期保护：
- 基础设施即代码（IaC）扫描
- 容器镜像扫描
- 运行时云资源配置检测
- 工作负载运行时保护
- 权限分析（CIEM，云基础设施权限管理）

### 3.4 三者关系示意

```text
+---------------------------------------------------+
|                      CNAPP                        |
|  (代码 -> 构建 -> 部署 -> 运行 全链路安全)          |
|                                                   |
|  +-------------------+   +---------------------+  |
|  |       CSPM        |   |        CWPP         |  |
|  | 云资源配置合规     |   | 工作负载运行时保护   |  |
|  | + CIEM 权限分析   |   | + 容器/主机/函数保护 |  |
|  +-------------------+   +---------------------+  |
+---------------------------------------------------+
```
