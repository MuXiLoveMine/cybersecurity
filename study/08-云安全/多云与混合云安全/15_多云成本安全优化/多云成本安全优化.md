# 多云成本安全优化

### 15.1 成本与安全的平衡

```text
安全控制项的成本影响:

| 安全控制 | 成本影响 | 优化建议 |
|----------|----------|----------|
| GuardDuty | 按事件量收费 | 仅对关键区域启用 |
| CloudTrail | S3存储+分析 | 使用生命周期策略降存储 |
| VPC Flow Logs | 日志量巨大 | 采样+过滤 |
| KMS密钥 | 按密钥数+API调用 | 合并密钥,减少密钥数 |
| WAF | 按规则数+请求量 | 精简规则集 |
| Shield Advanced | 固定月费 | 仅保护关键业务 |

成本优化原则:
  - 按风险分级投入,高优先级资产优先
  - 使用托管服务减少运维成本
  - 日志分层存储,热数据->冷数据->归档
  - 自动化减少人工操作成本
  - 利用各云免费额度
```

### 15.2 成本监控自动化

```bash
# AWS Cost Explorer - 按安全服务过滤
aws ce get-cost-and-usage \
    --time-period Start=2026-09-01,End=2026-09-15 \
    --granularity DAILY \
    --metrics "UnblendedCost" \
    --group-by Type=DIMENSION,Key=SERVICE \
    --filter '{"Dimensions":{"Key":"SERVICE","Values":["AmazonGuardDuty","AWSKeyManagementService","AWSCloudTrail"]}}'

# Azure Cost Management
az costmanagement query \
    --type "Usage" \
    --timeframe "Custom" \
    --time-period from="2026-09-01T00:00:00Z" to="2026-09-15T23:59:59Z" \
    --dimension "ServiceName"

# 设置预算告警
aws budgets create-budget \
    --account-id 123456789012 \
    --budget '{"BudgetName":"SecurityBudget","BudgetLimit":{"Amount":10000,"Unit":"USD"},"TimeUnit":"MONTHLY","TimePeriod":{"Start":"2026-09-01","End":"2027-09-01"}}' \
    --notifications-with-subscribers file://notifications.json
```
