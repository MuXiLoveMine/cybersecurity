# 混合云安全架构

### 4.1 云 + 本地数据中心安全连接

混合云的核心是公有云与本地数据中心的网络与数据互通。常见连接方式：

| 方式 | 特点 | 安全要点 |
| --- | --- | --- |
| 专线 / 专用连接 | 私有物理链路，低延迟高可靠 | L3 加密、BGP 认证、路由过滤 |
| IPSec VPN | 基于公网加密隧道 | 强算法（AES-256-GCM）、PFS、DPD |
| SD-WAN | 软件定义广域网，多链路智能调度 | 零信任接入、分段加密 |
| 私有端点 | 云服务通过私有网络访问 | PrivateLink / PrivateZone |

#### IPSec VPN 配置示例（AWS 到本地）

```json
// AWS Customer Gateway 配置
{
  "CustomerGateway": {
    "BgpAsn": 65000,
    "IpAddress": "203.0.113.10",
    "Type": "ipsec.1"
  },
  "VPNConnection": {
    "Type": "ipsec.1",
    "StaticRoutes": ["10.0.0.0/16"],
    "Options": {
      "IkeVersions": ["ikev2"],
      "Phase1EncryptionAlgorithms": ["AES-256-GCM"],
      "Phase1IntegrityAlgorithms": ["SHA-256"],
      "Phase1DHGroupNumbers": [20],
      "Phase2EncryptionAlgorithms": ["AES-256-GCM"],
      "Phase2IntegrityAlgorithms": ["SHA-256"],
      "Phase2DHGroupNumbers": [20],
      "ReplayDetection": true,
      "DeadPeerDetection": true
    }
  }
}
```

### 4.2 SD-WAN 安全

SD-WAN 将多个广域网链路（专线、宽带、LTE）虚拟化，通过控制平面集中调度。安全要点：
- **零信任接入**：每个站点间流量基于身份而非网络位置授权
- **分段加密**：每段链路端到端加密
- **应用感知防火墙**：基于应用类型做安全策略
- **安全互联网访问（SIA）**：分支流量回转到云安全网关

### 4.3 混合云安全分层模型

```text
+---------------------------------------------+
|        身份层：统一 SSO + MFA + 权限联邦      |
+---------------------------------------------+
|        访问层：零信任网关 / SASE              |
+---------------------------------------------+
|        网络层：SD-WAN + 加密隧道 + 微分段     |
+---------------------------------------------+
|        数据层：统一 KMS / BYOK / 数据分类      |
+---------------------------------------------+
|        工作负载层：CWPP / 容器 / 主机保护     |
+---------------------------------------------+
|        可观测层：跨云 SIEM / SOAR             |
+---------------------------------------------+
```
