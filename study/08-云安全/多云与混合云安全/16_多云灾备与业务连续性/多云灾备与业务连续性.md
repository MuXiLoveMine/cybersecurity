# 多云灾备与业务连续性

### 16.1 多云灾备架构

```text
多云灾备模式:

模式1: 主动-被动 (Active-Passive)
  - 主云: AWS (全量运行)
  - 备云: Azure (最小运行,准备切换)
  - RTO: 15-30分钟
  - RPO: 5-15分钟

模式2: 主动-主动 (Active-Active)
  - 云1: AWS (50%流量)
  - 云2: Azure (50%流量)
  - RTO: 接近0
  - RPO: 接近0
  - 成本最高

模式3: 按需启动 (Pilot Light)
  - 主云: AWS (全量运行)
  - 备云: Azure (核心服务最小运行)
  - RTO: 30-60分钟
  - 成本最低

模式4: 多区域同云 (Same Cloud Multi-Region)
  - 同一云厂商多区域部署
  - 简化管理,但无法防云厂商级故障
```

### 16.2 多云数据同步

```bash
# 跨云数据库同步
# AWS RDS -> Azure Database for PostgreSQL
# 使用DMS(Database Migration Service)
aws dms create-endpoint \
    --endpoint-identifier source-rds \
    --endpoint-type source \
    --engine-name postgres \
    --server-name rds.example.com \
    --port 5432 \
    --database-name prod \
    --username admin \
    --password secret

aws dms create-endpoint \
    --endpoint-identifier target-azure \
    --endpoint-type target \
    --engine-name postgres \
    --server-name azure.postgres.database.azure.com \
    --port 5432 \
    --database-name prod \
    --username admin \
    --password secret

aws dms create-replication-task \
    --replication-task-identifier cross-cloud-sync \
    --source-endpoint-arn arn:aws:dms:...:source-rds \
    --target-endpoint-arn arn:aws:dms:...:target-azure \
    --migration-type full-load-and-cdc

# 跨云对象存储同步
# 使用rclone同步S3和Azure Blob
rclone sync s3:my-bucket azure:my-container \
    --transfers 16 \
    --checkers 8 \
    --backup-dir backup/$(date +%Y%m%d) \
    --log-level INFO

# 跨云文件系统同步
# 使用rsync over SSH
rsync -avz --delete \
    -e "ssh -i /path/to/key" \
    /local/data/ \
    remote@azure-vm:/data/
```

### 16.3 多云故障切换自动化

```python
#!/usr/bin/env python3
"""多云故障切换自动化工具"""

import boto3
import requests
import time
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class MultiCloudFailover:
    def __init__(self):
        self.route53 = boto3.client('route53')
        self.health_check_interval = 30
        self.failure_threshold = 3

    def check_endpoint_health(self, url):
        """检查端点健康状态"""
        try:
            response = requests.get(url, timeout=10)
            return response.status_code == 200
        except Exception as e:
            logger.warning(f"健康检查失败: {url}, 错误: {e}")
            return False

    def failover_dns(self, hosted_zone_id, record_name, target_value):
        """切换DNS到备用云"""
        try:
            self.route53.change_resource_record_sets(
                HostedZoneId=hosted_zone_id,
                ChangeBatch={
                    'Changes': [{
                        'Action': 'UPSERT',
                        'ResourceRecordSet': {
                            'Name': record_name,
                            'Type': 'A',
                            'TTL': 60,
                            'ResourceRecords': [{'Value': target_value}]
                        }
                    }]
                }
            )
            logger.info(f"DNS已切换: {record_name} -> {target_value}")
        except Exception as e:
            logger.error(f"DNS切换失败: {e}")

    def monitor_and_failover(self, primary_url, secondary_ip, zone_id, record_name):
        """监控并自动切换"""
        failure_count = 0
        while True:
            if self.check_endpoint_health(primary_url):
                failure_count = 0
                logger.info(f"主端点正常: {primary_url}")
            else:
                failure_count += 1
                logger.warning(f"主端点异常 ({failure_count}/{self.failure_threshold})")
                if failure_count >= self.failure_threshold:
                    logger.critical("触发故障切换!")
                    self.failover_dns(zone_id, record_name, secondary_ip)
                    break
            time.sleep(self.health_check_interval)

# 使用示例
if __name__ == "__main__":
    failover = MultiCloudFailover()
    failover.monitor_and_failover(
        primary_url="https://app.example.com/health",
        secondary_ip="20.1.2.3",
        zone_id="Z1234567890",
        record_name="app.example.com"
    )
```
