# 多云密钥管理

### 12.1 密钥管理架构

```text
多云密钥管理架构:

Level 1: 中央密钥管理系统 (On-Premise HSM)
  ├── AWS KMS (BYOK - 自带密钥)
  ├── Azure Key Vault (BYOK)
  ├── 阿里云KMS (BYOK)
  └── 腾讯云KMS (BYOK)

Level 2: 各云KMS服务
  ├── 数据加密密钥 (DEK)
  ├── 密钥加密密钥 (KEK)
  └── 信封加密

Level 3: 应用层加密
  ├── 应用级密钥
  └── 字段级加密

安全原则:
  - 密钥与数据分离存储
  - 不同云使用不同KEK
  - 密钥轮换周期: 90天
  - HSM根密钥不可导出
```

### 12.2 BYOK与HYOK配置

```bash
# AWS KMS BYOK配置
# 1. 在本地HSM生成密钥
openssl rand -out plaintext_key_material.bin 32

# 2. 使用AWS KMS Public Key加密密钥材料
aws kms get-public-key --key-id mrk-1234567890 > public_key.json

# 3. 导入密钥材料
aws kms import-key-material \
    --key-id mrk-1234567890 \
    --encrypted-blob-key-material fileb://encrypted_key_material.bin \
    --wrapping-key-algorithm RSAES_OAEP_SHA_256 \
    --expiration-model KEY_MATERIAL_EXPIRES

# Azure Key Vault BYOK
# 使用Azure CLI导入HSM保护密钥
az keyvault key import \
    --name myKey \
    --vault-name myVault \
    --byok-file key.byo \
    --byok-kty RSA-HSM

# HYOK (Hold Your Own Key) - 密钥完全保留在本地
# 使用Thales CipherTrust Manager
# 应用直接通过API调用本地HSM
# 云端只存储加密后的数据
```

#!/usr/bin/env python3
"""多云密钥轮换自动化工具"""

import boto3
from azure.keyvault.keys import KeyClient
from azure.identity import DefaultAzureCredential
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

class MultiCloudKeyRotation:
    def __init__(self):
        self.aws_kms = boto3.client('kms', region_name='us-east-1')
        self.azure_credential = DefaultAzureCredential()
        self.azure_key_client = KeyClient(
            vault_url="https://myvault.vault.azure.net/",
            credential=self.azure_credential
        )

    def rotate_aws_key(self, key_id):
        """轮换AWS KMS密钥"""
        try:
            response = self.aws_kms.rotate_key_on_demand(
                keyId=key_id
            )
            logger.info(f"AWS密钥轮换成功: {key_id}")
            return response
        except Exception as e:
            logger.error(f"AWS密钥轮换失败: {key_id}, 错误: {e}")
            return None

    def rotate_azure_key(self, key_name):
        """轮换Azure Key Vault密钥"""
        try:
            rotated_key = self.azure_key_client.rotate_key(key_name)
            logger.info(f"Azure密钥轮换成功: {key_name}, 新版本: {rotated_key.properties.version}")
            return rotated_key
        except Exception as e:
            logger.error(f"Azure密钥轮换失败: {key_name}, 错误: {e}")
            return None

# 使用示例
if __name__ == "__main__":
    rotator = MultiCloudKeyRotation()

    rotator.rotate_azure_key("dataEncryptionKey")
