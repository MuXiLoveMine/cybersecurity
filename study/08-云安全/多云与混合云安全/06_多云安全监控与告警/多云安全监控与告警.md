# 多云安全监控与告警

### 6.1 跨云日志聚合

各云日志需集中到统一 SIEM：

| 云厂商 | 审计日志 | 资源日志 | 投递方式 |
| --- | --- | --- | --- |
| AWS | CloudTrail | CloudWatch Logs | Kinesis / Firehose |
| 阿里云 | ActionTrail | SLS 日志服务 | SLS 投递 |
| Azure | Activity Log | Diagnostic Settings | Event Hub / Log Analytics |
| 腾讯云 | CloudAudit | CLS 日志服务 | CLS 投递 |

#### 日志统一格式化示例（Python）

```python
import json

# 各云日志统一为通用事件格式
def normalize_aws_cloudtrail(event):
    return {
        "cloud": "aws",
        "event_time": event.get("eventTime"),
        "source_ip": event.get("sourceIPAddress"),
        "identity": event.get("userIdentity", {}).get("arn"),
        "action": f"{event.get('eventSource')}:{event.get('eventName')}",
        "resource": event.get("resources", [{}])[0].get("ARN"),
        "raw": event,
    }

def normalize_aliyun_actiontrail(event):
    return {
        "cloud": "aliyun",
        "event_time": event.get("eventTime"),
        "source_ip": event.get("sourceIpAddress"),
        "identity": event.get("userIdentity", {}).get("principalId"),
        "action": f"{event.get('serviceName')}:{event.get('eventName')}",
        "resource": event.get("resourceName"),
        "raw": event,
    }

# 统一投递到 SIEM
def forward_to_siem(normalized_event):
    print(json.dumps(normalized_event, ensure_ascii=False))
```

### 6.2 统一安全运营（SOC）

跨云 SIEM 的关键检测场景：
- 跨云异常 API 调用（如从未见过的 IP 执行 DeleteBucket）
- 权限提升行为（如新增 IAM 管理员）
- 跨云数据外泄（如批量下载对象存储后外传）
- 配置高危变更（如关闭加密、开放安全组 0.0.0.0/0）

#### SOAR 自动响应示例

```python
# 检测到异常登录后的自动响应编排
def handle_anomalous_login(alert):
    user = alert["user"]
    source_ip = alert["source_ip"]

    # 1. 跨云禁用该用户
    for cloud in ["aws", "aliyun", "azure"]:
        disable_user(cloud, user)

    # 2. 撤销该用户活跃会话 / 临时凭证
    revoke_active_sessions(user)

    # 3. 将源 IP 加入跨云黑名单
    add_to_blocklist(source_ip)

    # 4. 通知安全运营人员
    send_alert(f"已自动响应异常登录: {user} from {source_ip}")
```

### 6.3 跨云安全指标看板

建议监控的关键指标：
- 跨云未授权访问尝试次数
- 高危配置项数量与修复时长
- 特权账号数量与使用频率
- 跨云数据传输量异常
- 合规检查不通过项数
