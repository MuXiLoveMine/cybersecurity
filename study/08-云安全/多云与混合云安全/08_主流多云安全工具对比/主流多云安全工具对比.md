# 主流多云安全工具对比

| 维度 | Wiz | Palo Alto Prisma Cloud | Lacework | 奇安信 |
| --- | --- | --- | --- | --- |
| 定位 | CNAPP，图谱驱动 | CNAPP + 网络安全 | CNAPP，数据驱动 | 国产云安全平台 |
| 支持云厂商 | AWS / Azure / GCP / 阿里云等 | 主流公有云 + 私有云 | AWS / Azure / GCP | 阿里云 / 腾讯云 / 华为云 / 私有云 |
| CSPM | 强，攻击路径分析突出 | 强，策略库丰富 | 强，异常检测 | 支持，等保合规 |
| CWPP | 通过 agentless 实现 | 强，主机 + 容器 | 强，行为基线 | 主机入侵检测 |
| CIEM | 权限图分析 | 支持 | 支持 | 支持 |
| 供应链/IaC | 支持 Terraform 扫描 | 支持 | 有限 | 支持 |
| 合规报告 | 国际框架 | 国际 + 部分国内 | 国际框架 | 等保 / 国密合规 |
| 国内本地化 | 一般 | 一般 | 一般 | 强 |
| 适用场景 | 大型企业多云 | 综合云安全 | AWS 重度用户 | 国资 / 合规要求高 |

### 选型建议

- **重图谱分析与攻击路径**：优先 Wiz
- **需要主机 + 网络 + 云一体化**：考虑 Prisma Cloud
- **以 AWS 为主、关注行为异常**：考虑 Lacework
- **国内合规与数据主权要求强**：考虑奇安信等国产方案
