### 1.3 云数据库安全威胁全景

```
威胁分类：

1. 网络层威胁
   ├── 公网暴露
   ├── 安全组配置过宽
   ├── VPN/直连配置不当
   └── DNS劫持

   ├── 弱密码
   ├── 凭证泄露
```

## 二、公网暴露风险

### 2.1 暴露场景

**直接公网暴露**

```
# MongoDB默认暴露案例
# 默认监听0.0.0.0:27017
# 无认证或弱认证
# 攻击者使用Shodan扫描:
shodan search "product:MongoDB" --fields ip_str,port

# Elasticsearch暴露案例
# 默认无认证
# 攻击者使用Shodan扫描:
shodan search "product:Elasticsearch" --fields ip_str,port

# Redis暴露案例
# 默认无密码
# 攻击者直接连接:
redis-cli -h target_ip
```

**安全组配置过宽**

```
# 危险的安全组规则
# 允许所有IP访问数据库端口

# AWS RDS安全组
# 入站规则: 0.0.0.0/0 -> TCP 3306  [危险！]

# Azure NSG
# 入站规则: * -> 1433  [危险！]

# GCP防火墙
# 入站规则: 0.0.0.0/0 -> TCP 5432  [危险！]
```

### 2.2 攻击手法

```bash
# Shodan搜索暴露的数据库
shodan search "port:3306 country:CN"
shodan search "product:MySQL"
shodan search "product:PostgreSQL"
shodan search "product:MongoDB"
shodan search "product:Elasticsearch"
shodan search "product:Redis"

# Censys搜索
censys search "services.port: 3306"
censys search "services.port: 27017"

# 暴力破解
hydra -L users.txt -P passwords.txt mysql://target
patator mysql_login host=target user=admin password=FILE0 0=passwords.txt

# 未授权访问检测
# MongoDB
mongo --host target --port 27017
# 如果无认证直接进入，则存在未授权访问

# Elasticsearch
curl http://target:9200/_cat/indices
# 如果直接返回索引列表，则存在未授权访问

# Redis
redis-cli -h target
# 如果直接连接成功，则存在未授权访问
```

### 2.3 检测与防御

```bash
# AWS检测暴露的RDS实例
aws rds describe-db-instances --query 'DBInstances[?PubliclyAccessible==`true`]'
aws rds describe-db-security-groups --query 'DBSecurityGroups[].EC2SecurityGroups[]'

# 检查安全组规则
aws ec2 describe-security-groups --query 'SecurityGroups[?IpPermissions[].IpRanges[?CidrIp==`0.0.0.0/0`]]'

# Azure检测暴露的SQL数据库
az sql server list --query "[].{name:name, fwl:firewallRules}"

# GCP检测暴露的SQL实例
gcloud sql instances list --format="table(name,ipAddresses)"

# 修复措施
# AWS: 将RDS实例设为不可公开访问
aws rds modify-db-instance --db-instance-identifier mydb --no-publicly-accessible

# 限制安全组
aws ec2 authorize-security-group-ingress --group-id sg-xxx \
    --ip-protocol tcp --port 3306 --cidr 10.0.0.0/8
```

## 三、弱密码与认证安全

### 3.1 弱密码风险

```
常见弱密码：
  - admin / admin
  - root / root
  - admin / password123
  - sa / sa
  - 默认密码未修改
  - 密码与用户名相同
  - 密码在字典中
```

### 3.2 认证加固

**密码策略**

```
# 密码复杂度要求
- 最小长度: 16字符
- 包含大小写字母、数字、特殊字符
- 不包含用户名或数据库名
- 不使用常见密码
- 定期轮换(90天)
- 密码历史记录(不重复最近5个)

# AWS RDS密码策略
aws rds modify-db-instance --db-instance-identifier mydb \
    --master-user-password "Str0ng!Passw0rd#2026" \
    --apply-immediately
```

**IAM数据库认证**

```bash
# AWS RDS IAM数据库认证
# 生成IAM令牌
aws rds generate-db-auth-token \
    --hostname mydb.abc123.us-east-1.rds.amazonaws.com \
    --port 3306 \
    --username admin \
    --region us-east-1

# MySQL IAM认证
mysql --host=mydb.abc123.rds.amazonaws.com \
    --user=admin \
    --enable-cleartext-plugin \
    --password="$(aws rds generate-db-auth-token ...)"

# Azure AD认证
az sql server ad-admin create --server myserver \
    --display-name "DBAdmin" --object-id <object-id>
```

## 四、存储加密

### 4.1 TDE透明数据加密

```
TDE (Transparent Data Encryption) 工作原理：

  应用 --> 数据库引擎 --> [TDE加密] --> 存储层
                              |
                              v
                          加密密钥
                              |
                              v
                          KMS/密钥管理服务
```

**AWS RDS TDE配置**

```bash
# 启用加密（创建时）
aws rds create-db-instance \
    --db-instance-identifier mydb \
    --db-instance-class db.r5.large \
    --engine mysql \
    --master-username admin \
    --master-user-password StrongPass! \
    --storage-encrypted \
    --kms-key-id arn:aws:kms:us-east-1:123:key/abc-123

# 对现有实例启用加密（需要创建新实例）
# 因为加密只能在创建时启用
```

### 4.2 CMK客户管理密钥

```bash
# AWS KMS创建客户管理密钥
aws kms create-key \
    --description "Database encryption key" \
    --key-usage ENCRYPT_DECRYPT \
    --key-spec SYMMETRIC_DEFAULT

# 设置密钥策略
aws kms put-key-policy \
    --key-id <key-id> \
    --policy-name default \
    --policy '{
        "Version": "2012-10-17",
        "Statement": [
            {
                "Effect": "Allow",
                "Principal": {"AWS": "arn:aws:iam::123:root"},
                "Action": "kms:*",
                "Resource": "*"
            },
            {
                "Effect": "Allow",
                "Principal": {"Service": "rds.amazonaws.com"},
                "Action": ["kms:Encrypt","kms:Decrypt","kms:ReEncrypt*","kms:GenerateDataKey*"],
                "Resource": "*"
            }
        ]
    }'

# 启用密钥轮换
aws kms enable-key-rotation --key-id <key-id>
```

### 4.3 传输加密

```
# AWS RDS强制SSL
# 参数组设置
aws rds modify-db-parameter-group \
    --db-parameter-group-name my-pg \
    --parameters "ParameterName=require_secure_transport,ApplyMethod=immediate,ParameterValue=1"

# MySQL SSL配置
# 下载RDS证书
wget https://s3.amazonaws.com/rds-downloads/rds-ca-2019-us-east-1.pem

# 使用SSL连接
mysql --host=mydb.rds.amazonaws.com \
    --ssl-ca=rds-ca-2019.pem \
    --ssl-mode=VERIFY_IDENTITY
```

## 五、云上SQL注入

### 5.1 注入风险场景

```python
# 危险代码示例 - 直接拼接SQL
def get_user(user_id):
    # 不安全：直接拼接用户输入
    sql = f"SELECT * FROM users WHERE id = {user_id}"
    cursor.execute(sql)
    return cursor.fetchone()

# 攻击者输入: 1 OR 1=1
# 实际执行: SELECT * FROM users WHERE id = 1 OR 1=1
# 返回所有用户数据

# NoSQL注入
def search_users(keyword):
    # 不安全：直接传递用户输入作为查询条件
    db.users.find({"$where": f"this.name == '{keyword}'"})

# 攻击者输入: '; while(1){}; '
# 导致DoS
```

### 5.2 防御措施

```python
# 安全代码 - 参数化查询
def get_user_safe(user_id):
    # 安全：使用参数化查询
    sql = "SELECT * FROM users WHERE id = %s"
    cursor.execute(sql, (user_id,))
    return cursor.fetchone()

# ORM安全使用
def get_user_orm(user_id):
    # 安全：ORM自动参数化
    return User.query.filter_by(id=user_id).first()

# 输入验证
import re

def validate_input(input_str, max_length=100):
    """验证用户输入"""
    if not input_str or len(input_str) > max_length:
        raise ValueError("Invalid input length")
    # 白名单字符检查
    if not re.match(r'^[a-zA-Z0-9_\-]+$', input_str):
        raise ValueError("Invalid characters")
    return input_str
```

## 六、备份安全

```
备份安全要求：

1. 备份加密
   - 所有备份必须加密存储
   - 使用独立密钥加密备份

2. 备份访问控制
   - 限制备份访问权限
   - 备份不应对公网可访问
   - 使用IAM策略控制

3. 备份完整性
   - 定期验证备份可恢复
   - 检查备份哈希完整性
   - 异地备份

4. 备份保留
   - 定期备份策略（每日/每周/每月）
   - 保留期限符合合规要求
   - 过期备份自动删除
```

```bash
# AWS RDS备份
# 自动备份
aws rds modify-db-instance \
    --db-instance-identifier mydb \
    --backup-retention-period 30

# 手动快照
aws rds create-db-snapshot \
    --db-instance-identifier mydb \
    --db-snapshot-identifier mydb-snapshot-20260913

# 加密快照
aws rds copy-db-snapshot \
    --source-db-snapshot-identifier arn:aws:rds:...:snapshot:mydb-snapshot \
    --target-db-snapshot-identifier mydb-encrypted-snapshot \
    --kms-key-id <kms-key-id>

# 限制快照访问
# 不要将快照共享给其他账户或设为公开
aws rds modify-db-snapshot-attribute \
    --db-snapshot-identifier mydb-snapshot \
    --attribute-name restore \
    --values-to-remove public
```

## 七、数据库防火墙

数据库防火墙（WAF for Database）在应用和数据库之间提供额外安全层：

```
应用 --> [数据库防火墙] --> 数据库
              |
              v
         规则引擎
         - SQL注入检测
         - 虚拟补丁
         - 访问控制
         - 异常检测
         - 审计日志
```

```
数据库防火墙功能：

1. SQL注入防护
   - 基于特征的注入检测
   - 基于行为的异常查询检测
   - 自动阻断恶意查询

2. 虚拟补丁
   - 在防火墙层屏蔽已知漏洞
   - 无需修改数据库即可防护
   - 为未打补丁的数据库提供保护

3. 访问控制
   - 基于IP/用户/应用的访问策略
   - 时间窗口限制
   - 查询频率限制

4. 数据脱敏
   - 查询结果实时脱敏
   - 基于角色的脱敏策略
   - 动态数据掩码

5. 审计与合规
   - 全量SQL审计日志
   - 合规报告生成
   - 异常告警
```

## 八、审计日志

```bash
# AWS RDS审计日志
# 启用审计日志
aws rds modify-db-parameter-group \
    --db-parameter-group-name my-pg \
    --parameters "ParameterName=server_audit_events,ApplyMethod=immediate,ParameterValue=CONNECT,QUERY,TABLE"

# 导出日志到CloudWatch
aws rds modify-db-instance \
    --db-instance-identifier mydb \
    --cloudwatch-logs-export-configuration '{"EnableLogTypes":["audit","error","general"]}'

# 查看审计日志
aws logs filter-log-events \
    --log-group-name /aws/rds/instance/mydb/audit \
    --filter-pattern "DELETE"

# Azure SQL审计
az sql db audit-policy update \
    --resource-group myGroup \
    --server myServer \
    --database myDB \
    --state Enabled \
    --storage-account mystorageaccount
```

**审计日志分析**

```python
# 审计日志分析脚本示例
import re
from collections import Counter

def analyze_audit_logs(log_file):
    """分析数据库审计日志"""
    patterns = {
        "drop_table": r"DROP\s+TABLE",
        "delete_data": r"DELETE\s+FROM\s+\w+\s+WHERE\s+1=1",
        "grant_all": r"GRANT\s+ALL\s+PRIVILEGES",
        "create_user": r"CREATE\s+USER",
        "sql_injection": r"(?:UNION\s+SELECT|OR\s+1=1|--|/\*|\*/)",
        "bulk_select": r"SELECT\s+\*\s+FROM",
        "after_hours": None,  # 需要时间检查
    }

    alerts = []
    with open(log_file, "r") as f:
        for line_num, line in enumerate(f, 1):
            for name, pattern in patterns.items():
                if pattern and re.search(pattern, line, re.IGNORECASE):
                    alerts.append({
                        "line": line_num,
                        "type": name,
                        "content": line.strip()[:200],
                    })

    # 统计
    type_counts = Counter(a["type"] for a in alerts)
    print(f"审计日志分析结果:")
    for alert_type, count in type_counts.items():
        print(f"  {alert_type}: {count}")

    return alerts
```

## 九、网络隔离

```
数据库网络隔离最佳实践：

1. 私有子网部署
   - 数据库实例部署在私有子网
   - 不分配公网IP
   - 仅通过NAT/VPN/直连访问

2. 安全组最小化
   - 仅允许应用服务器IP访问
   - 限制端口范围
   - 禁止0.0.0.0/0规则

3. 网络分段
   - 不同环境(dev/test/prod)网络隔离
   - 数据库子网独立
   - 跨网段访问需通过防火墙

4. 私有链接
   - 使用PrivateLink/Private Endpoint
   - 避免经过公网的数据访问
```

```bash
# AWS VPC私有子网部署RDS
# 1. 创建私有子网组
aws rds create-db-subnet-group \
    --db-subnet-group-name private-subnet-group \
    --db-subnet-group-description "Private subnet group" \
    --subnet-ids subnet-aaa subnet-bbb

# 2. 创建RDS实例在私有子网
aws rds create-db-instance \
    --db-instance-identifier mydb \
    --db-instance-class db.r5.large \
    --engine mysql \
    --vpc-security-group-ids sg-private \
    --db-subnet-group-name private-subnet-group \
    --no-publicly-accessible

# 3. 创建安全组只允许应用服务器
aws ec2 create-security-group \
    --group-name db-access \
    --description "Database access from app servers" \
    --vpc-id vpc-xxx

aws ec2 authorize-security-group-ingress \
    --group-id sg-db-access \
    --ip-protocol tcp \
    --port 3306 \
    --source-security-group-id sg-app-servers

# 4. 使用Private Endpoint
aws rds create-db-instance-read-endpoint \
    --db-instance-identifier mydb \
    --read-endpoint-identifier my-private-endpoint
```

## 十一、AWS RDS安全深度配置

### 11.1 RDS安全参数组详解

```bash
# 创建自定义参数组
aws rds create-db-parameter-group \
    --db-parameter-group-name secure-mysql-pg \

    --description "Secure MySQL 8.0 parameter group"

aws rds modify-db-parameter-group \
    --db-parameter-group-name secure-mysql-pg \
```

### 11.4 RDS安全自动化检测脚本

```python
import boto3
import json
from datetime import datetime

class RDSSecurityAuditor:
    """AWS RDS安全审计自动化"""

    def __init__(self, region='us-east-1'):
        self.rds = boto3.client('rds', region_name=region)
        self.ec2 = boto3.client('ec2', region_name=region)
        self.findings = []

    def audit_all(self):
        """执行完整安全审计"""
        instances = self.rds.describe_db_instances()
        for inst in instances['DBInstances']:
            self._check_public_access(inst)
            self._check_encryption(inst)
            self._check_backups(inst)
            self._check_multi_az(inst)
            self._check_security_groups(inst)
            self._check_enhanced_monitoring(inst)
            self._check_deletion_protection(inst)
            self._check_auto_minor_upgrade(inst)
            self._check_parameter_groups(inst)
        return self.findings

    def _check_public_access(self, inst):
        if inst.get('PubliclyAccessible', False):
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'CRITICAL',
                'issue': 'RDS实例可公网访问',
                'remediation': '设置 --no-publicly-accessible'
            })

    def _check_encryption(self, inst):
        if not inst.get('StorageEncrypted', False):
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'HIGH',
                'issue': '存储未加密',
                'remediation': '创建加密快照并恢复到新实例'
            })

    def _check_backups(self, inst):
        retention = inst.get('BackupRetentionPeriod', 0)
        if retention < 7:
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'MEDIUM',
                'issue': f'备份保留期仅{retention}天，建议至少7天',
                'remediation': '设置 --backup-retention-period 30'
            })

    def _check_multi_az(self, inst):
        if not inst.get('MultiAZ', False):
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'MEDIUM',
                'issue': '未启用多可用区部署',
                'remediation': '启用Multi-AZ以提供高可用性'
            })

    def _check_security_groups(self, inst):
        for sg in inst.get('VpcSecurityGroups', []):
            sg_detail = self.ec2.describe_security_groups(
                GroupIds=[sg['VpcSecurityGroupId']]
            )
            for group in sg_detail['SecurityGroups']:
                for rule in group.get('IpPermissions', []):
                    for ip_range in rule.get('IpRanges', []):
                        if ip_range.get('CidrIp') == '0.0.0.0/0':
                            self.findings.append({
                                'instance': inst['DBInstanceIdentifier'],
                                'severity': 'CRITICAL',
                                'issue': f'安全组{group["GroupName"]}允许0.0.0.0/0访问端口{rule.get("FromPort")}',
                                'remediation': '限制安全组仅允许应用服务器IP'
                            })

    def _check_enhanced_monitoring(self, inst):
        if inst.get('MonitoringInterval', 0) == 0:
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'LOW',
                'issue': '增强监控未启用',
                'remediation': '设置 --monitoring-interval 1'
            })

    def _check_deletion_protection(self, inst):
        if not inst.get('DeletionProtection', False):
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'MEDIUM',
                'issue': '删除保护未启用',
                'remediation': '设置 --deletion-protection'
            })

    def _check_auto_minor_upgrade(self, inst):
        if not inst.get('AutoMinorVersionUpgrade', False):
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'MEDIUM',
                'issue': '自动小版本升级未启用',
                'remediation': '设置 --auto-minor-version-upgrade'
            })

    def _check_parameter_groups(self, inst):
        pg_name = inst.get('DBParameterGroups', [{}])[0].get('DBParameterGroupName', '')
        if pg_name == 'default.mysql8.0':
            self.findings.append({
                'instance': inst['DBInstanceIdentifier'],
                'severity': 'LOW',
                'issue': '使用默认参数组，未自定义安全参数',
                'remediation': '创建自定义参数组并应用安全配置'
            })

    def generate_report(self):
        """生成安全报告"""
        report = f"RDS安全审计报告 - {datetime.now().strftime('%Y-%m-%d %H:%M')}\n"
        report += f"发现总数: {len(self.findings)}\n"
        report += "=" * 60 + "\n"
        severity_count = {}
        for f in self.findings:
            sev = f['severity']
            severity_count[sev] = severity_count.get(sev, 0) + 1
        for sev in ['CRITICAL', 'HIGH', 'MEDIUM', 'LOW']:
            count = severity_count.get(sev, 0)
            report += f"{sev}: {count}\n"
        report += "=" * 60 + "\n"
        for f in self.findings:
            report += f"\n[{f['severity']}] {f['instance']}\n"
            report += f"  问题: {f['issue']}\n"
            report += f"  修复: {f['remediation']}\n"
        return report

# 使用示例
auditor = RDSSecurityAuditor('us-east-1')
auditor.audit_all()
print(auditor.generate_report())
```

```python
# Redis未授权访问检测脚本
import redis
import socket

def check_redis_security(host, port=6379):
    """检测Redis安全配置"""
    findings = []

    # 1. 检查未授权访问
    try:
        r = redis.Redis(host=host, port=port, socket_timeout=5)
        info = r.info()
        findings.append({
            'severity': 'CRITICAL',
            'issue': 'Redis无需认证即可访问',
            'detail': f"Redis版本: {info.get('redis_version')}"
        })
    except redis.exceptions.AuthenticationError:
        findings.append({
            'severity': 'INFO',
            'issue': 'Redis已启用认证(良好)'
        })
    except redis.exceptions.ConnectionError:
        findings.append({
            'severity': 'INFO',
            'issue': '无法连接Redis(端口关闭或防火墙)'
        })
        return findings

    # 2. 检查危险命令是否可用
    dangerous_commands = ['CONFIG', 'FLUSHDB', 'FLUSHALL', 'KEYS', 'DEBUG']
    for cmd in dangerous_commands:
        try:
            r.execute_command(cmd)
        except redis.exceptions.ResponseError as e:
            if "unknown command" in str(e).lower():
                findings.append({
                    'severity': 'GOOD',
                    'issue': f'{cmd}命令已禁用(良好)'
                })
        except:
            findings.append({
                'severity': 'HIGH',
                'issue': f'{cmd}命令可用(危险)'
            })

    # 3. 检查绑定地址
    if 'redis_version' in info:
        try:
            config_get = r.config_get('bind')
            bind = config_get.get('bind', '')
            if '0.0.0.0' in bind or not bind:
                findings.append({
                    'severity': 'CRITICAL',
                    'issue': 'Redis绑定0.0.0.0(公网可访问)'
                })
        except:
            pass

    # 4. 检查是否启用TLS
    try:
        tls_info = r.config_get('tls-port')
        if tls_info.get('tls-port', '0') == '0':
            findings.append({
                'severity': 'MEDIUM',
                'issue': 'Redis未启用TLS加密'
            })
    except:
        pass

    return findings

# 批量检测
targets = ['10.0.1.10', '10.0.1.11', '10.0.2.20']
for target in targets:
    print(f"\n检测目标: {target}")
    results = check_redis_security(target, 6379)
    for r in results:
        print(f"  [{r['severity']}] {r['issue']}")
```

```python
        elif self.db_type == 'postgres':
            self.conn = psycopg2.connect(
                host=self.host, port=self.port,
                user=self.user, password=self.password,
                dbname=self.dbname
            )

    def check_mysql_baseline(self):
        cursor = self.conn.cursor()

        checks = [
            ("默认数据库", "SELECT user FROM mysql.user WHERE user IN ('root','admin') AND authentication_string=''", "不应存在无密码root/admin账户"),
            ("匿名用户", "SELECT user FROM mysql.user WHERE user=''", "不应存在匿名用户"),
            ("远程root", "SELECT host FROM mysql.user WHERE user='root' AND host NOT IN ('localhost','127.0.0.1')", "root不应允许远程登录"),
            ("空密码", "SELECT user,host FROM mysql.user WHERE authentication_string=''", "不应有空密码账户"),
            ("SSL连接", "SHOW VARIABLES LIKE 'require_secure_transport'", "应强制SSL连接"),
            ("日志功能", "SHOW VARIABLES LIKE 'general_log'", "应启用查询日志"),
            ("错误日志", "SHOW VARIABLES LIKE 'log_error'", "应配置错误日志"),
            ("审计日志", "SHOW VARIABLES LIKE 'server_audit_logging'", "应启用审计日志"),
            ("最大连接数", "SHOW VARIABLES LIKE 'max_connections'", "应限制最大连接数"),
            ("密码策略", "SHOW VARIABLES LIKE 'validate_password_length'", "应启用密码复杂度策略"),
        ]

        for name, query, recommendation in checks:
            try:
                cursor.execute(query)
                result = cursor.fetchall()
                self._evaluate(name, result, recommendation)
            except Exception as e:
                self.results.append({
                    'check': name,
                    'status': 'ERROR',
                    'detail': str(e),
                    'recommendation': recommendation
                })

        cursor.close()

    def _evaluate(self, name, result, recommendation):
        if name in ("默认数据库", "匿名用户", "远程root", "空密码"):
            if result:
                self.results.append({
                    'check': name,
                    'status': 'FAIL',
                    'detail': f'发现: {result}',
                    'recommendation': recommendation
                })
            else:
                self.results.append({
                    'check': name,
                    'status': 'PASS',
                    'detail': '合规',
                    'recommendation': recommendation
                })
        elif name == "SSL连接":
            val = result[0][1] if result else ''
            status = 'PASS' if val == 'ON' else 'FAIL'
            self.results.append({
                'check': name,
                'status': status,
                'detail': f'当前值: {val}',
                'recommendation': recommendation
            })
        else:
            self.results.append({
                'check': name,
                'status': 'INFO',
                'detail': f'值: {result}',
                'recommendation': recommendation
            })

    def generate_report(self):
        report = f"\n{'='*60}\n"
        report += f"数据库安全基线检查报告\n"
        report += f"数据库类型: {self.db_type}\n"
        report += f"主机: {self.host}:{self.port}\n"
        report += f"检查时间: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n"
        report += f"{'='*60}\n\n"

        pass_count = sum(1 for r in self.results if r['status'] == 'PASS')
        fail_count = sum(1 for r in self.results if r['status'] == 'FAIL')
        info_count = sum(1 for r in self.results if r['status'] == 'INFO')
        error_count = sum(1 for r in self.results if r['status'] == 'ERROR')

        report += f"通过: {pass_count}  失败: {fail_count}  "
        report += f"信息: {info_count}  错误: {error_count}\n\n"

        for r in self.results:
            status_symbol = {'PASS': '[PASS]', 'FAIL': '[FAIL]', 'INFO': '[INFO]', 'ERROR': '[ERR ]'}
            report += f"{status_symbol.get(r['status'], '[????]')} {r['check']}\n"
            report += f"       详情: {r['detail']}\n"
            report += f"       建议: {r['recommendation']}\n\n"

        return report

    def close(self):
        if self.conn:
            self.conn.close()

# 使用示例
checker = DatabaseSecurityBaseline('mysql', '10.0.1.10', 3306, 'audit_user', 'password', 'myapp')
checker.connect()
checker.check_mysql_baseline()
print(checker.generate_report())
checker.close()
```

## 十六、云数据库安全事件响应

### 16.1 数据库泄露事件响应流程

```
数据库安全事件响应流程:

  Phase 1: 发现与确认(0-1小时)
    ├── 告警触发(异常查询/大流量导出/权限变更)
    ├── 初步评估影响范围
    ├── 确认是否真实事件
    └── 启动应急响应预案

  Phase 2: 遏制(1-4小时)
    ├── 立即撤销泄露凭证
    ├── 隔离受影响数据库实例
    ├── 封禁恶意IP
    ├── 保留证据(日志/快照)
    └── 评估是否需要断网

  Phase 3: 根因分析(4-24小时)
    ├── 分析审计日志定位攻击路径
    ├── 确定数据泄露范围
    ├── 识别被利用的漏洞
    ├── 分析攻击者活动轨迹
    └── 评估数据泄露影响

  Phase 4: 恢复(24-72小时)
    ├── 修复被利用漏洞
    ├── 从干净备份恢复数据
    ├── 更新所有凭证和密钥
    ├── 部署额外防护措施
    └── 逐步恢复服务

  Phase 5: 事后总结(72小时+)
    ├── 编写事件报告
    ├── 分析流程改进点
    ├── 更新安全策略
    ├── 合规报告(如需要)
    └── 安全加固实施
```

### 16.2 数据库取证脚本

```python
import boto3
import json
from datetime import datetime, timedelta

class DatabaseForensics:
    """数据库安全事件取证工具"""

    def __init__(self, region='us-east-1'):
        self.rds = boto3.client('rds', region_name=region)
        self.cloudtrail = boto3.client('cloudtrail', region_name=region)
        self.logs = boto3.client('logs', region_name=region)
        self.ec2 = boto3.client('ec2', region_name=region)

    def collect_evidence(self, db_instance_id, time_range_hours=24):
        """收集数据库安全事件证据"""
        end_time = datetime.now()
        start_time = end_time - timedelta(hours=time_range_hours)

        evidence = {
            'instance_id': db_instance_id,
            'time_range': f"{start_time} to {end_time}",
            'instance_info': self._get_instance_info(db_instance_id),
            'recent_modifications': self._get_recent_modifications(db_instance_id, start_time, end_time),
            'security_group_changes': self._get_sg_changes(start_time, end_time),
            'snapshot_activity': self._get_snapshot_activity(db_instance_id, start_time, end_time),
            'audit_logs': self._get_audit_logs(db_instance_id, start_time, end_time),
            'cloudtrail_events': self._get_cloudtrail_events(db_instance_id, start_time, end_time),
        }
        return evidence

    def _get_instance_info(self, instance_id):
        resp = self.rds.describe_db_instances(
            DBInstanceIdentifier=instance_id
        )
        inst = resp['DBInstances'][0]
        return {
            'engine': inst.get('Engine'),
            'version': inst.get('EngineVersion'),
            'encrypted': inst.get('StorageEncrypted'),
            'publicly_accessible': inst.get('PubliclyAccessible'),
            'multi_az': inst.get('MultiAZ'),
            'security_groups': [sg['VpcSecurityGroupId']
                               for sg in inst.get('VpcSecurityGroups', [])],
            'subnet_group': inst.get('DBSubnetGroup', {}).get('DBSubnetGroupName'),
        }

    def _get_recent_modifications(self, instance_id, start, end):
        events = []
        for event in self.rds.describe_events(
            SourceType='db-instance',
            SourceIdentifier=instance_id,
            StartTime=start,
            EndTime=end
        ).get('Events', []):
            events.append({
                'date': event['Date'].isoformat(),
                'message': event['Message'],
                'type': event.get('SourceName', '')
            })
        return events

    def _get_sg_changes(self, start, end):
        """检查安全组变更"""
        changes = []
        try:
            events = self.cloudtrail.lookup_events(
                LookupAttributes=[{
                    'AttributeKey': 'EventName',
                    'AttributeValue': 'AuthorizeSecurityGroupIngress'
                }],
                StartTime=start,
                EndTime=end
            )
            for event in events.get('Events', []):
                changes.append({
                    'event_name': event['EventName'],
                    'user': event.get('Username'),
                    'time': event['EventTime'].isoformat(),
                    'source_ip': event.get('SourceIpAddress'),
                })
        except Exception as e:
            changes.append({'error': str(e)})
        return changes

    def _get_snapshot_activity(self, instance_id, start, end):
        """快照活动"""
        snapshots = []
        resp = self.rds.describe_db_snapshots(
            DBInstanceIdentifier=instance_id
        )
        for snap in resp.get('DBSnapshots', []):
            snap_time = snap.get('SnapshotCreateTime')
            if snap_time and start <= snap_time.replace(tzinfo=None) <= end:
                snapshots.append({
                    'snapshot_id': snap['DBSnapshotIdentifier'],
                    'create_time': snap_time.isoformat(),
                    'encrypted': snap.get('Encrypted'),
                    'status': snap.get('Status'),
                })
        return snapshots

    def _get_audit_logs(self, instance_id, start, end):
        """获取审计日志中的高危操作"""
        high_risk_patterns = ['DROP', 'DELETE', 'TRUNCATE', 'GRANT', 'REVOKE',
                              'CREATE USER', 'ALTER USER', 'SET PASSWORD']
        findings = []
        try:
            log_group = f"/aws/rds/instance/{instance_id}/audit"
            events = self.logs.filter_log_events(
                logGroupName=log_group,
                startTime=int(start.timestamp() * 1000),
                endTime=int(end.timestamp() * 1000),
            )
            for event in events.get('events', []):
                msg = event.get('message', '')
                for pattern in high_risk_patterns:
                    if pattern.lower() in msg.lower():
                        findings.append({
                            'timestamp': datetime.fromtimestamp(
                                event['timestamp'] / 1000
                            ).isoformat(),
                            'pattern': pattern,
                            'message': msg[:500],
                        })
                        break
        except Exception as e:
            findings.append({'error': str(e)})
        return findings

    def _get_cloudtrail_events(self, instance_id, start, end):
        """CloudTrail RDS相关事件"""
        events = []
        rds_events = ['ModifyDBInstance', 'DeleteDBInstance',
                       'RestoreDBInstanceFromSnapshot', 'FailoverDBCluster']
        for event_name in rds_events:
            try:
                resp = self.cloudtrail.lookup_events(
                    LookupAttributes=[{
                        'AttributeKey': 'EventName',
                        'AttributeValue': event_name
                    }],
                    StartTime=start,
                    EndTime=end
                )
                for event in resp.get('Events', []):
                    if instance_id.lower() in json.dumps(
                        event.get('CloudTrailEvent', '')
                    ).lower():
                        events.append({
                            'event_name': event['EventName'],
                            'user': event.get('Username'),
                            'time': event['EventTime'].isoformat(),
                            'source_ip': event.get('SourceIpAddress'),
                        })
            except:
                pass
        return events

    def generate_forensics_report(self, evidence):
        """生成取证报告"""
        report = f"\n{'='*60}\n"
        report += f"数据库安全事件取证报告\n"
        report += f"实例: {evidence['instance_id']}\n"
        report += f"时间范围: {evidence['time_range']}\n"
        report += f"{'='*60}\n\n"

        report += "[实例信息]\n"
        info = evidence['instance_info']
        report += f"  引擎: {info.get('engine')} {info.get('version')}\n"
        report += f"  加密: {'是' if info.get('encrypted') else '否'}\n"
        report += f"  公网可访问: {'是' if info.get('publicly_accessible') else '否'}\n"
        report += f"  多AZ: {'是' if info.get('multi_az') else '否'}\n\n"

        report += f"[最近修改事件: {len(evidence['recent_modifications'])}条]\n"
        for mod in evidence['recent_modifications'][:10]:
            report += f"  {mod['date']}: {mod['message']}\n"

        report += f"\n[安全组变更: {len(evidence['security_group_changes'])}条]\n"
        for sg in evidence['security_group_changes'][:10]:
            report += f"  {sg.get('time','')}: {sg.get('event_name','')} by {sg.get('user','')}\n"

        report += f"\n[快照活动: {len(evidence['snapshot_activity'])}条]\n"
        for snap in evidence['snapshot_activity']:
            report += f"  {snap['snapshot_id']} ({snap['create_time']}) - {snap['status']}\n"

        report += f"\n[审计日志高危操作: {len(evidence['audit_logs'])}条]\n"
        for log in evidence['audit_logs'][:20]:
            if 'error' not in log:
                report += f"  [{log['pattern']}] {log['timestamp']}: {log['message'][:100]}\n"

        report += f"\n[CloudTrail事件: {len(evidence['cloudtrail_events'])}条]\n"
        for ct in evidence['cloudtrail_events'][:10]:
            report += f"  {ct['time']}: {ct['event_name']} by {ct['user']} from {ct['source_ip']}\n"

        return report

# 使用示例
forensics = DatabaseForensics('us-east-1')
evidence = forensics.collect_evidence('mydb-prod', time_range_hours=48)
print(forensics.generate_forensics_report(evidence))
```
