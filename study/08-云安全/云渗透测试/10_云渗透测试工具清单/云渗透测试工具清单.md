### 10.4 Pacu 使用简介

Pacu 是一个模块化的 AWS 渗透测试框架，类似 Metasploit。

```bash
# 安装
git clone https://github.com/RhinoSecurityLabs/pacu.git
cd pacu
pip install -r requirements.txt

# 运行
python3 pacu.py

# 常用命令
# 设置凭证
set_keys

# 信息收集模块
run iam__enum_users
run iam__enum_roles
run s3__enum
run ec2__enum

# 权限提升模块
run iam__privesc_scan

# 持久化模块
run iam__create_backdoor_user
```

---

> **小结**：云渗透测试的核心是利用配置错误和权限管理缺陷，从信息收集到凭证获取，再到权限提升和数据窃取，形成完整的攻击链。防御方需要建立持续的安全审计和监控机制，及时发现和修复配置错误，遵循最小权限原则，防止云环境被入侵。
