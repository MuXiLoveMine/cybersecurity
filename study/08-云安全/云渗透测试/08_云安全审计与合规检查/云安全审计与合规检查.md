# 云安全审计与合规检查

### 8.1 安全审计内容

#### 8.1.1 身份与访问管理审计

| 检查项 | 检查方法 | 风险等级 |
|--------|----------|----------|
| 根账号 MFA | 控制台/API 检查 | 高危 |
| IAM 用户 MFA | 列出所有用户，检查 MFA 状态 | 高危 |
| 访问密钥年龄 | 检查密钥创建时间，超过 90 天需轮换 | 中危 |
| 未使用的用户/密钥 | 检查最后使用时间 | 中危 |
| 权限过大的策略 | 检查包含 "*" 的策略 | 高危 |
| 角色信任策略 | 检查是否信任未知账户 | 高危 |
| 密码策略 | 检查密码复杂度要求 | 中危 |

#### 8.1.2 网络安全审计

| 检查项 | 检查方法 | 风险等级 |
|--------|----------|----------|
| 安全组 0.0.0.0/0 开放端口 | 检查所有安全组入站规则 | 高危 |
| 数据库公网暴露 | 检查数据库实例是否有公网 IP | 高危 |
| 高危端口公网开放 | 22、3389、3306、6379 等 | 高危 |
| NACL 配置 | 检查网络 ACL 规则 | 中危 |
| VPC 流日志 | 检查是否启用 | 中危 |

#### 8.1.3 存储安全审计

| 检查项 | 检查方法 | 风险等级 |
|--------|----------|----------|
| 存储桶公开访问 | 检查所有存储桶权限 | 高危 |
| 存储桶策略过宽 | 检查策略中的 Principal 和 Action | 高危 |
| 服务端加密 | 检查是否启用加密 | 中危 |
| 版本控制 | 检查是否启用 | 中危 |
| 访问日志 | 检查是否启用 | 中危 |

#### 8.1.4 日志与审计配置

| 检查项 | 检查方法 | 风险等级 |
|--------|----------|----------|
| CloudTrail/操作审计 | 是否启用全区域跟踪 | 高危 |
| 日志文件完整性验证 | 是否启用日志验证 | 中危 |
| 日志存储加密 | 日志存储桶是否加密 | 中危 |
| 关键告警 | 是否配置关键事件告警 | 中危 |
| 日志保存时间 | 是否满足合规要求 | 低危 |

### 8.2 云安全审计工具

#### 8.2.1 开源审计工具

| 工具 | 支持平台 | 说明 |
|------|----------|------|
| Prowler | AWS | AWS 安全审计和合规检查 |
| Scout Suite | 多云（AWS/Azure/GCP） | 多云安全审计工具 |
| CloudSploit | 多云 | 云安全状态监控 |
| Steampipe | 多云 | SQL 查询云资源 |
| Trivy | 多云 | 漏洞和配置扫描 |

#### 8.2.2 Prowler 使用示例

Prowler 是 AWS 最流行的安全审计工具，基于 CIS AWS Foundations Benchmark。

```bash
# 安装
pip install prowler

# 运行所有检查
prowler aws

# 运行特定分组的检查
prowler aws --group iam
prowler aws --group s3
prowler aws --group network

# 输出 HTML 报告
prowler aws -M html

# 输出 JSON 报告
prowler aws -M json

# 只检查高风险项
prowler aws --severity critical high
```

#### 8.2.3 Scout Suite 使用示例

```bash
# 安装
pip install scoutsuite

# 审计 AWS
scout aws

# 审计阿里云（部分支持）
# Scout Suite 主要支持 AWS/Azure/GCP

# 生成 HTML 报告
# 默认输出到 scout-report/ 目录
```

### 8.3 合规检查

#### 8.3.1 CIS 基准

CIS（Center for Internet Security）发布了各云平台的安全基准：
- CIS AWS Foundations Benchmark
- CIS Microsoft Azure Foundations Benchmark
- CIS Alibaba Cloud Foundations Benchmark

#### 8.3.2 等保 2.0 检查要点

| 层面 | 检查要点 |
|------|----------|
| 物理安全 | 数据中心位置、物理访问控制 |
| 网络安全 | 网络架构、访问控制、边界防护 |
| 主机安全 | 身份鉴别、访问控制、入侵防范 |
| 应用安全 | 身份认证、访问控制、通信完整性 |
| 数据安全 | 数据完整性、保密性、备份恢复 |
| 安全管理 | 安全制度、人员管理、应急响应 |
