# 横向移动

### 6.1 云环境横向移动特点

传统内网横向移动 vs 云环境横向移动：

| 传统内网 | 云环境 |
|----------|--------|
| 同网段扫描 | 跨服务、跨区域、跨账户 |
| SMB/RDP/SSH 登录 | API 调用、角色扮演 |
| Pass-the-Hash | Access Key 复用 |
| 域控提权 | IAM/RAM 提权 |
| 内网代理 | VPC 对等连接、VPN |

### 6.2 横向移动路径

#### 6.2.1 跨服务移动

```
获取 S3 读取权限
    │
    ├─ S3 中有数据库备份 → 获取数据库凭证
    │    │
    │    ▼
    │  访问 RDS 数据库 → 获取更多数据
    │
    ├─ S3 中有源代码 → 分析漏洞
    │    │
    │    ▼
    │  利用应用漏洞 → 获取 EC2 权限
    │
    └─ S3 中有凭证 → 直接使用新凭证
         │
         ▼
      以新身份访问更多资源
```

#### 6.2.2 跨区域移动

```
在 us-east-1 区域获取凭证
    │
    ▼
尝试在其他区域使用相同凭证
    │
    ├─ eu-west-1 → 发现更多资源
    ├─ ap-southeast-1 → 发现更多资源
    └─ ...
```

**注意**：IAM 是全局服务，凭证在所有区域通用。但资源是区域级的，需要逐个区域枚举。

#### 6.2.3 跨账户移动

**通过角色信任**：
```
当前账户 A 中的身份
    │
    ▼
发现 A 账户中的角色信任 B 账户
    │
    ▼
（但通常是反过来：B 账户的角色信任 A 账户的身份）
    │
    ▼
如果账户 A 的身份可以扮演账户 B 的角色
→ 获得账户 B 的访问权限
```

**通过凭证复用**：
- 代码仓库中可能包含多个账户的凭证
- 不同环境（dev/staging/prod）可能使用不同账户
- 从一个账户的数据中找到另一个账户的凭证

### 6.3 VPC 内网渗透

如果获得了 VPC 内一台机器的权限，可以进行内网渗透：

```
获得 EC2 实例访问权限（SSM/SSH）
    │
    ▼
内网信息收集
    │
    ├─ 查看实例元数据 → 获取角色凭证
    ├─ 查看 VPC 网络配置 → 了解网络拓扑
    ├─ 扫描内网 → 发现其他实例
    ├─ 查看安全组 → 了解访问规则
    └─ 查看 DNS 记录 → 发现内部服务
    │
    ▼
横向移动到其他实例
    │
    ├─ 利用 SSH 密钥复用
    ├─ 利用弱口令
    ├─ 利用应用漏洞
    └─ 利用服务间信任
```

**内网信息收集命令**：
```bash
# 查看本机网络配置
ifconfig / ip addr

# 查看路由表
route -n / ip route

# 查看 DNS 配置
cat /etc/resolv.conf

# 扫描内网存活主机
nmap -sn 10.0.0.0/24

# 查看安全组（需要元数据或 API 权限）
TOKEN=$(curl -X PUT http://169.254.169.254/latest/api/token \
    -H "X-aws-ec2-metadata-token-ttl-seconds: 21600")
curl -H "X-aws-ec2-metadata-token: $TOKEN" \
    http://169.254.169.254/latest/meta-data/security-groups
```
