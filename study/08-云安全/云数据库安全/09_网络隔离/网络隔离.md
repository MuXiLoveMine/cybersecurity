# 网络隔离

```
数据库网络隔离最佳实践：

1. 私有子网部署
   - 数据库实例部署在私有子网
   - 不分配公网IP
   - 仅通过NAT/VPN/直连访问

2. 安全组最小化
   - 仅允许应用服务器IP访问
   - 限制端口范围
   - 禁止0.0.0.0/0规则

3. 网络分段
   - 不同环境(dev/test/prod)网络隔离
   - 数据库子网独立
   - 跨网段访问需通过防火墙

4. 私有链接
   - 使用PrivateLink/Private Endpoint
   - 避免经过公网的数据访问
```

```bash
# AWS VPC私有子网部署RDS
# 1. 创建私有子网组
aws rds create-db-subnet-group \
    --db-subnet-group-name private-subnet-group \
    --db-subnet-group-description "Private subnet group" \
    --subnet-ids subnet-aaa subnet-bbb

# 2. 创建RDS实例在私有子网
aws rds create-db-instance \
    --db-instance-identifier mydb \
    --db-instance-class db.r5.large \
    --engine mysql \
    --vpc-security-group-ids sg-private \
    --db-subnet-group-name private-subnet-group \
    --no-publicly-accessible

# 3. 创建安全组只允许应用服务器
aws ec2 create-security-group \
    --group-name db-access \
    --description "Database access from app servers" \
    --vpc-id vpc-xxx

aws ec2 authorize-security-group-ingress \
    --group-id sg-db-access \
    --ip-protocol tcp \
    --port 3306 \
    --source-security-group-id sg-app-servers

# 4. 使用Private Endpoint
aws rds create-db-instance-read-endpoint \
    --db-instance-identifier mydb \
    --read-endpoint-identifier my-private-endpoint
```
