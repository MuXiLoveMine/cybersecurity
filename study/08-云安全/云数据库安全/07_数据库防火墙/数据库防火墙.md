# 数据库防火墙

数据库防火墙（WAF for Database）在应用和数据库之间提供额外安全层：

```
应用 --> [数据库防火墙] --> 数据库
              |
              v
         规则引擎
         - SQL注入检测
         - 虚拟补丁
         - 访问控制
         - 异常检测
         - 审计日志
```

```
数据库防火墙功能：

1. SQL注入防护
   - 基于特征的注入检测
   - 基于行为的异常查询检测
   - 自动阻断恶意查询

2. 虚拟补丁
   - 在防火墙层屏蔽已知漏洞
   - 无需修改数据库即可防护
   - 为未打补丁的数据库提供保护

3. 访问控制
   - 基于IP/用户/应用的访问策略
   - 时间窗口限制
   - 查询频率限制

4. 数据脱敏
   - 查询结果实时脱敏
   - 基于角色的脱敏策略
   - 动态数据掩码

5. 审计与合规
   - 全量SQL审计日志
   - 合规报告生成
   - 异常告警
```
