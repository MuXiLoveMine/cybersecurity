# 云数据库安全概述

### 1.1 云数据库类型

| 类型 | AWS | Azure | GCP | 阿里云 |
|------|-----|-------|-----|--------|
| 关系型 | RDS, Aurora | SQL Database | Cloud SQL | RDS, PolarDB |
| 文档型 | DocumentDB | CosmosDB | Firestore | MongoDB |
| 键值型 | DynamoDB | Table Storage | Bigtable | Table Store |
| 图数据库 | Neptune | CosmosDB(Gremlin) | - | Graph Database |
| 时序 | Timestream | - | Bigtable | TSDB |
| 内存 | ElastiCache | Cache for Redis | Memorystore | Redis |

### 1.2 共享责任模型

```
+------------------------------------------+
|           云服务商负责                     |
|  - 物理安全                               |
|  - 基础设施安全                           |
|  - 数据库引擎补丁                         |
|  - 底层存储加密                           |
|  - 网络基础设施                           |
+------------------------------------------+
                    |
+------------------------------------------+
|           客户负责                       |
|  - 数据库访问控制                         |
|  - 网络安全组/防火墙配置                   |
|  - 数据加密密钥管理                       |
|  - 审计日志配置                           |
|  - 备份策略                               |
|  - 应用层安全(SQL注入防护)                 |
|  - 密码/凭证管理                          |
|  - 合规配置                               |
+------------------------------------------+
```

### 1.3 云数据库安全威胁全景

```
威胁分类：

1. 网络层威胁
   ├── 公网暴露
   ├── 安全组配置过宽
   ├── VPN/直连配置不当
   └── DNS劫持

2. 认证层威胁
   ├── 弱密码
   ├── 凭证泄露
   ├── 过度授权
   ├── 缺少MFA
   └── 密码策略薄弱

3. 数据层威胁
   ├── 存储未加密
   ├── 传输未加密
   ├── 备份未加密
   ├── 快照权限过宽
   └── 临时文件泄露

4. 应用层威胁
   ├── SQL注入
   ├── NoSQL注入
   ├── 越权访问
   └── API密钥泄露

5. 运维层威胁
   ├── 缺少审计日志
   ├── 补丁管理缺失
   ├── 配置漂移
   └── 备份策略不当
```
