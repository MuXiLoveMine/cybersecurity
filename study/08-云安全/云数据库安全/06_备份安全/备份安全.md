# 备份安全

```
备份安全要求：

1. 备份加密
   - 所有备份必须加密存储
   - 使用独立密钥加密备份

2. 备份访问控制
   - 限制备份访问权限
   - 备份不应对公网可访问
   - 使用IAM策略控制

3. 备份完整性
   - 定期验证备份可恢复
   - 检查备份哈希完整性
   - 异地备份

4. 备份保留
   - 定期备份策略（每日/每周/每月）
   - 保留期限符合合规要求
   - 过期备份自动删除
```

```bash
# AWS RDS备份
# 自动备份
aws rds modify-db-instance \
    --db-instance-identifier mydb \
    --backup-retention-period 30

# 手动快照
aws rds create-db-snapshot \
    --db-instance-identifier mydb \
    --db-snapshot-identifier mydb-snapshot-20260913

# 加密快照
aws rds copy-db-snapshot \
    --source-db-snapshot-identifier arn:aws:rds:...:snapshot:mydb-snapshot \
    --target-db-snapshot-identifier mydb-encrypted-snapshot \
    --kms-key-id <kms-key-id>

# 限制快照访问
# 不要将快照共享给其他账户或设为公开
aws rds modify-db-snapshot-attribute \
    --db-snapshot-identifier mydb-snapshot \
    --attribute-name restore \
    --values-to-remove public
```
