# 弱密码与认证安全

### 3.1 弱密码风险

```
常见弱密码：
  - admin / admin
  - root / root
  - admin / password123
  - sa / sa
  - 默认密码未修改
  - 密码与用户名相同
  - 密码在字典中
```

### 3.2 认证加固

**密码策略**

```
# 密码复杂度要求
- 最小长度: 16字符
- 包含大小写字母、数字、特殊字符
- 不包含用户名或数据库名
- 不使用常见密码
- 定期轮换(90天)
- 密码历史记录(不重复最近5个)

# AWS RDS密码策略
aws rds modify-db-instance --db-instance-identifier mydb \
    --master-user-password "Str0ng!Passw0rd#2026" \
    --apply-immediately
```

**IAM数据库认证**

```bash
# AWS RDS IAM数据库认证
# 生成IAM令牌
aws rds generate-db-auth-token \
    --hostname mydb.abc123.us-east-1.rds.amazonaws.com \
    --port 3306 \
    --username admin \
    --region us-east-1

# MySQL IAM认证
mysql --host=mydb.abc123.rds.amazonaws.com \
    --user=admin \
    --enable-cleartext-plugin \
    --password="$(aws rds generate-db-auth-token ...)"

# Azure AD认证
az sql server ad-admin create --server myserver \
    --display-name "DBAdmin" --object-id <object-id>
```
