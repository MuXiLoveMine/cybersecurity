# 网络安全

### 4.1 VPC 安全架构

#### 4.1.1 网络分段设计

**三层架构模式**：
```
┌─────────────────────────────────────────────────────┐
│                    公有子网层                        │
│  (对外服务：负载均衡、堡垒机、NAT 网关)            │
├─────────────────────────────────────────────────────┤
│                    应用子网层                        │
│  (内部服务：Web 服务器、应用服务器)                │
├─────────────────────────────────────────────────────┤
│                    数据子网层                        │
│  (数据服务：数据库、缓存、消息队列)                │
└─────────────────────────────────────────────────────┘
```

**安全控制**：
- 公有子网 → 互联网：通过 Internet Gateway
- 应用子网 → 互联网：通过 NAT 网关（出站）
- 数据子网：不允许直接访问互联网
- 各层之间通过安全组控制访问

#### 4.1.2 网络访问路径

**入站访问**：
```
用户 → 负载均衡（公有子网） → Web 服务器（应用子网） → 数据库（数据子网）
```

**出站访问**：
```
应用服务器 → NAT 网关（公有子网） → 互联网
```

**管理访问**：
```
管理员 → 堡垒机（公有子网） → 应用服务器（应用子网）
```

### 4.2 安全组 vs NACL 深度对比

| 特性 | 安全组（Security Group） | 网络 ACL（NACL） |
|------|--------------------------|------------------|
| 操作级别 | 实例级别 | 子网级别 |
| 状态类型 | 有状态 | 无状态 |
| 支持的规则 | 仅 Allow | Allow + Deny |
| 规则顺序 | 不按顺序，全部评估 | 按编号顺序，匹配即停止 |
| 默认行为 | 入站拒绝，出站允许 | 全部允许 |
| 应用范围 | 关联的实例 | 子网内所有实例 |
| 配置复杂度 | 简单 | 较复杂 |
| 使用场景 | 实例级精细控制 | 子网级粗粒度控制 |

### 4.3 负载均衡安全

#### 4.3.1 负载均衡安全配置

| 配置项 | 安全要求 |
|--------|----------|
| 监听器协议 | 使用 HTTPS，禁用 HTTP 或配置重定向 |
| SSL/TLS 证书 | 使用强加密套件，禁用弱加密 |
| 安全组 | 限制后端服务只能被负载均衡访问 |
| 访问控制 | 配置黑白名单（按需） |
| WAF 集成 | 开启 WAF 防护 |
| DDoS 防护 | 开启 DDoS 防护 |
| 健康检查 | 配置合理的健康检查 |

#### 4.3.2 HTTPS 配置最佳实践
- 使用 TLS 1.2 及以上版本
- 禁用 SSLv3、TLS 1.0、TLS 1.1
- 使用强加密套件（如 ECDHE-RSA-AES256-GCM-SHA384）
- 证书有效期管理，自动续期
- 启用 HTTP Strict Transport Security (HSTS)
