```

└─────────────────────────────────────────────────────────────┘
```

### 6.2 关键审计日志类型

| 日志类型 | AWS | 阿里云 | 用途 |
|----------|-----|--------|------|
| API 操作日志 | CloudTrail | 操作审计 | 记录所有云资源操作 |
| 访问日志 | S3 Access Logs / ELB Access Logs | OSS 访问日志 / SLB 访问日志 | 记录请求访问明细 |
| 流日志 | VPC Flow Logs | 流日志 | 记录网络流量 |
| 数据库日志 | RDS Logs / CloudWatch | RDS 审计日志 / SLS | 记录数据库操作 |
| 系统日志 | CloudWatch Logs | 日志服务 SLS | 操作系统和应用日志 |

### 6.3 审计最佳实践

1. **开启全量审计**：所有 API 操作、关键服务访问日志全部开启
2. **集中化管理**：日志集中存储到独立的安全账户
3. **防篡改保护**：日志存储启用版本控制和对象锁定
4. **定期审计**：定期分析日志，发现异常行为
5. **实时告警**：配置关键事件的实时告警
6. **长期保存**：根据合规要求保存足够长时间（等保要求 6 个月以上）
