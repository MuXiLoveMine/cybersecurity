# 数据安全

### 5.1 存储加密

#### 5.1.1 加密类型

| 加密类型 | 说明 | 场景 |
|----------|------|------|
| 服务端加密（SSE） | 数据写入磁盘时由服务端加密 | 存储加密，对用户透明 |
| 客户端加密（CSE） | 数据上传前由客户端加密 | 极高安全要求，密钥自己掌控 |
| 传输加密 | SSL/TLS 加密传输过程 | 防止数据在传输中被窃取 |

#### 5.1.2 S3/OSS 服务端加密选项

| 选项 | 密钥管理 | 适用场景 |
|------|----------|----------|
| SSE-S3 / SSE-OSS | 云厂商管理密钥 | 简单加密需求 |
| SSE-KMS | KMS 管理密钥，可审计 | 需要密钥使用审计 |
| SSE-C / BYOK | 客户自己提供密钥 | 完全掌控密钥 |

### 5.2 数据库安全

#### 5.2.1 云数据库安全配置清单

| 配置项 | 安全要求 |
|--------|----------|
| 网络隔离 | 部署在私有子网，不分配公网 IP |
| 访问控制 | 白名单限制访问来源 |
| 强密码 | 设置强密码策略，定期更换 |
| 最小权限 | 数据库账号只授予必要权限 |
| 存储加密 | 启用 TDE（透明数据加密） |
| 传输加密 | 启用 SSL 连接 |
| 审计日志 | 开启数据库审计 |
| 备份 | 定期备份，测试恢复 |
| 补丁 | 及时应用数据库补丁 |

#### 5.2.2 常见数据库安全问题

**问题 1：数据库公网暴露**
- **风险**：直接面临互联网攻击，暴力破解、漏洞利用
- **修复**：将数据库迁移到私有子网，通过内网访问

**问题 2：弱口令/默认口令**
- **风险**：易被暴力破解
- **修复**：设置强密码（12 位以上，包含大小写、数字、特殊字符）

**问题 3：未启用 SSL**
- **风险**：数据传输过程中可能被窃听
- **修复**：启用 SSL/TLS 加密连接

### 5.3 密钥管理（KMS）

#### 5.3.1 KMS 核心功能
- 密钥创建与管理
- 密钥轮换
- 密钥使用审计
- 数据加密/解密 API
- 与云服务深度集成

#### 5.3.2 密钥管理最佳实践
1. **密钥分类**：按数据类型和业务使用不同密钥
2. **定期轮换**：启用自动密钥轮换（建议每年至少一次）
3. **权限控制**：严格控制谁可以使用和管理密钥
4. **密钥审计**：监控密钥使用情况
5. **多区域备份**：关键密钥多区域备份
