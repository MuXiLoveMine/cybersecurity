### 3.3 SOC 2

```
SOC 2五大信任服务原则:

1. 安全性 (Security)
   - 系统和数据的逻辑和物理保护

2. 可用性 (Availability)
   - 系统和数据的可访问性

3. 处理完整性 (Processing Integrity)
   - 数据处理的完整性和准确性

4. 保密性 (Confidentiality)
   - 机密数据的保护

5. 隐私性 (Privacy)
   - 个人信息的收集、使用和披露

SOC 2 Type I: 控制设计有效性（某一时点）
SOC 2 Type II: 控制运行有效性（一段时间）
```

### 3.4 PCI DSS

```
PCI DSS v4.0要求:

1. 安装并维护网络安全
   - 安装并维护防火墙
   - 自定义密码不使用默认值

2. 保护存储的持卡人数据
   - 最小化存储
   - 对传输中的数据进行加密

3. 维护漏洞管理计划
   - 保护所有系统和网络免受恶意软件侵害
   - 开发和维护安全系统和软件

4. 实施强访问控制
   - 限制对持卡人数据的访问
   - 识别用户和系统访问
   - 限制对系统组件的物理访问

5. 定期监控和测试网络
   - 记录和监控所有访问
   - 定期测试安全系统

6. 维护信息安全策略
   - 为所有人员维护安全策略
```

### 3.5 GDPR

```
GDPR核心要求:

1. 合法性基础
   - 同意
   - 合同必要性
   - 法律义务
   - 重要利益
   - 公共任务
   - 合法利益

2. 数据主体权利
   - 知情权
   - 访问权
   - 更正权
   - 删除权(被遗忘权)
   - 限制处理权
   - 数据可携带权
   - 反对权
   - 自动决策反对权

3. 数据保护
   - 设计与默认隐私
   - 加密和假名化
   - 数据泄露通知(72小时)
   - DPIA(数据保护影响评估)

4. 问责制
   - 数据保护官(DPO)指定
   - 处理记录
   - 数据处理协议
   - 跨境数据传输机制
```
