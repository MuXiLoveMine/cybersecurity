# 云安全最佳实践

```
云安全最佳实践清单：

1. 身份与访问
   - 启用MFA
   - 使用IAM角色而非用户密钥
   - 定期审查权限
   - 实施条件访问
   - 使用SSO/SAML/OIDC

2. 网络安全
   - 默认拒绝原则
   - 网络分段
   - 流量日志和监控
   - 专用连接(VPN/Direct Connect)
   - WAF/DDoS防护

3. 数据安全
   - 全量加密(存储+传输)
   - 客户管理密钥(CMK)
   - 密钥轮换
   - 数据分类分级
   - DLP数据防泄漏

4. 日志与监控
   - 全量审计日志
   - 集中日志管理(SIEM)
   - 异常检测
   - 安全事件告警
   - 日志不可篡改

5. 合规与治理
   - 安全基线
   - CSPM持续扫描
   - 合规报告
   - 配置漂移检测
   - 自动化修复

6. 运营安全
   - DevSecOps集成
   - IaC安全扫描
   - 容器/镜像扫描
   - 补丁管理
   - 变更管理

7. 事件响应
   - 云SOC运营
   - 自动化响应
   - 取证准备
   - 恢复预案
   - 经验总结

8. 供应链安全
   - 第三方组件管理
   - 开源安全扫描
   - SBOM物料清单
   - 供应商安全评估
```
