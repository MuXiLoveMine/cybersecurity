### 2.2 云原生威胁检测

```
云原生威胁检测用例：

1. 异常API调用
   - 非常规时间的API调用
   - 异常频率的API请求
   - 来自异常IP的API调用
   - 权限提升API序列

2. 资源异常操作
   - 大量创建EC2实例(加密货币挖矿)
   - 异常的S3存储桶访问
   - 安全组修改(开放端口)
   - IAM策略变更

3. 数据外传检测
   - 大量数据从S3下载
   - 异常的数据传输量
   - 到异常目标的数据传输
   - 加密通道数据传输

4. 横向移动检测
   - EC2实例间异常连接
   - 跨账户访问
   - 角色链滥用
   - Lambda函数异常调用
```

**AWS GuardDuty检测示例**

```bash
# 启用GuardDuty
```

### 2.3 自动化响应

```python
# AWS Lambda自动化响应示例
# 当检测到恶意EC2实例时自动隔离

import json
import boto3

def lambda_handler(event, context):
    """GuardDuty发现事件的自动响应"""
    finding = json.loads(event['detail']['finding'])
    finding_type = finding['type']

    ec2 = boto3.client('ec2')
    instance_id = finding.get('resource', {}).get('instanceDetails', {}).get('instanceId')

    if not instance_id:
        return {"status": "no_instance_id"}

    # 根据发现类型执行不同响应
    if finding_type.startswith('UnauthorizedAccess') or \
       finding_type.startswith('Impact'):
        # 隔离实例：替换安全组为隔离安全组
        try:
            ec2.modify_instance_attribute(
                InstanceId=instance_id,
                Groups=['sg-isolated']  # 隔离安全组
            )
            print(f"实例 {instance_id} 已隔离")

            # 发送通知
            sns = boto3.client('sns')
            sns.publish(
                TopicArn='arn:aws:sns:us-east-1:123:security-alerts',
                Subject=f'安全事件: {finding_type}',
                Message=f'实例 {instance_id} 因 {finding_type} 已自动隔离'
            )

        except Exception as e:
            print(f"隔离失败: {e}")
            return {"status": "error", "message": str(e)}

    elif finding_type.startswith('Exfiltration'):
        # 阻断出口流量
        # 修改安全组拒绝所有出站
        pass

    return {"status": "success"}
```

### 3.3 SOC 2

```
SOC 2五大信任服务原则:

1. 安全性 (Security)
   - 系统和数据的逻辑和物理保护

2. 可用性 (Availability)
   - 系统和数据的可访问性

3. 处理完整性 (Processing Integrity)
   - 数据处理的完整性和准确性

4. 保密性 (Confidentiality)
   - 机密数据的保护

5. 隐私性 (Privacy)
   - 个人信息的收集、使用和披露

SOC 2 Type I: 控制设计有效性（某一时点）
SOC 2 Type II: 控制运行有效性（一段时间）
```

## 四、CSPM云安全态势管理

### 4.1 CSPM概念

CSPM (Cloud Security Posture Management) 是持续监控、评估和修复云基础设施安全配置的工具。

```
CSPM工作流程：

  持续扫描 --> 评估风险 --> 优先级排序 --> 自动修复 --> 报告合规
     |             |             |             |           |
     v             v             v             v           v
  配置发现     风险评分     修复建议     自动行动    合规报告
  API查询     基于上下文   按严重度     Lambda/    等保/ISO/
  配置比对    和业务影响   排列优先级    函数执行    SOC2/PCI
```

### 4.2 CSPM核心功能

```
1. 配置审计
   - 自动发现云资源
   - 检查配置合规性
   - 与安全基线对比
   - 持续监控配置漂移

2. 合规报告
   - 映射合规框架
   - 生成合规报告
   - 跟踪合规状态
   - 提供修复建议

3. 风险评估
   - 识别暴露的资源
   - 评估权限过宽
   - 检测加密缺失
   - 评估网络暴露

4. 自动修复
   - 自动修复配置
   - 执行安全策略
   - 阻止不合规变更
   - 通知安全团队

5. 可视化
   - 云资源拓扑图
   - 安全态势仪表盘
   - 风险热图
   - 趋势分析
```

**Cloud Custodian策略示例**

```yaml
# 确保所有S3存储桶启用加密
policies:
  - name: s3-encryption-check
    resource: aws.s3
    filters:
      - type: bucket-encryption
        state: False
    actions:
      - type: set-bucket-encryption
        crypto: AES256

  # 检测公共EC2实例
  - name: ec2-public-instance-alert
    resource: aws.ec2
    filters:
      - type: instance-attribute
        key: SourceDestCheck
        value: false
    actions:
      - type: mark-for-op
        op: stop
        days: 1

  # 确保安全组不开放22端口到公网
  - name: ssh-open-to-world
    resource: aws.security-group
    filters:
      - type: ingress
        IpProtocol: tcp
        FromPort: 22
        Cidr: 0.0.0.0/0
    actions:
      - type: remove-permissions
        ip-protocol: tcp
        from-port: 22
```

## 五、多云安全治理

### 5.1 多云挑战

```
多云环境安全挑战：

1. 可见性碎片化
   - 不同云平台管理控制台
   - 不同的API和工具集
   - 难以获得统一视图

2. 配置不一致
   - 各云厂商默认配置不同
   - 安全控制实现方式不同
   - 容易出现配置漏洞

3. 身份管理复杂
   - 各云独立的IAM体系
   - 跨云权限难以统一管理
   - 身份联邦配置复杂

4. 合规碎片化
   - 各云厂商合规认证不同
   - 审计日志格式不统一
   - 合规报告难以统一

5. 成本与效率
   - 多套工具采购成本高
   - 运维团队技能要求高
   - 自动化难以统一
```

### 5.3 云安全基线

```

身份与访问管理:
  [ ] MFA已为所有用户启用
  [ ] 无root/admin直接使用
  [ ] 最小权限原则
  [ ] 定期清理未使用账号
```

## 十、云安全合规自动化

### 10.1 策略即代码

```python
#!/usr/bin/env python3
"""云安全合规自动化检查工具"""

import boto3
import json
import logging
from datetime import datetime
from typing import List, Dict

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class CloudComplianceChecker:
    """云安全合规自动化检查"""

    def __init__(self, region='us-east-1'):
        self.ec2 = boto3.client('ec2', region_name=region)
        self.s3 = boto3.client('s3', region_name=region)
        self.iam = boto3.client('iam', region_name=region)
        self.kms = boto3.client('kms', region_name=region)
        self.rds = boto3.client('rds', region_name=region)
        self.config = boto3.client('config', region_name=region)
        self.ct = boto3.client('cloudtrail', region_name=region)
        self.guardduty = boto3.client('guardduty', region_name=region)

    def check_s3_security(self):
        """检查S3存储桶安全配置"""
        findings = []
        buckets = self.s3.list_buckets()
        for bucket in buckets['Buckets']:
            name = bucket['Name']
            # 检查公开访问
            try:
                acl = self.s3.get_bucket_acl(Bucket=name)
                for grant in acl['Grants']:
                    if grant['Permission'] in ['READ', 'WRITE']:
                        uri = grant.get('Grantee', {}).get('URI', '')
                        if 'AllUsers' in uri:
                            findings.append({
                                'severity': 'CRITICAL',
                                'resource': name,
                                'issue': 'S3存储桶公开访问',
                                'remediation': '启用阻止公开访问设置'
                            })
            except Exception as e:
                logger.warning(f"检查S3 ACL失败 {name}: {e}")

            # 检查加密
            try:
                self.s3.get_bucket_encryption(Bucket=name)
            except:
                findings.append({
                    'severity': 'HIGH',
                    'resource': name,
                    'issue': 'S3存储桶未启用加密',
                    'remediation': '启用SSE-KMS加密'
                })

            # 检查版本控制
            try:
                versioning = self.s3.get_bucket_versioning(Bucket=name)
                if versioning.get('Status') != 'Enabled':
                    findings.append({
                        'severity': 'MEDIUM',
                        'resource': name,
                        'issue': 'S3存储桶未启用版本控制',
                        'remediation': '启用版本控制保护数据'
                    })
            except Exception:
                pass

        return findings

    def check_iam_security(self):
        """检查IAM安全配置"""
        findings = []
        # 检查密码策略
        try:
            policy = self.iam.get_account_password_policy()
            p = policy['PasswordPolicy']
            if p.get('MinimumPasswordLength', 0) < 14:
                findings.append({
                    'severity': 'MEDIUM',
                    'issue': '密码最小长度不足14位',
                    'remediation': '设置最小密码长度为14'
                })
            if not p.get('RequireSymbols', False):
                findings.append({
                    'severity': 'LOW',
                    'issue': '密码策略未要求特殊字符',
                    'remediation': '启用密码复杂度要求'
                })
        except:
            findings.append({
                'severity': 'HIGH',
                'issue': '未设置IAM密码策略',
                'remediation': '配置账户密码策略'
            })

        # 检查MFA
        users = self.iam.list_users()
        for user in users['Users']:
            username = user['UserName']
            mfa = self.iam.list_mfa_devices(UserName=username)
            if not mfa['MFADevices']:
                findings.append({
                    'severity': 'HIGH',
                    'resource': username,
                    'issue': 'IAM用户未启用MFA',
                    'remediation': '为所有用户启用MFA'
                })

        # 检查访问密钥年龄
        for user in users['Users']:
            keys = self.iam.list_access_keys(UserName=user['UserName'])
            for key in keys['AccessKeyMetadata']:
                age = (datetime.now(key['CreateDate'].tzinfo) - key['CreateDate']).days
                if age > 90:
                    findings.append({
                        'severity': 'MEDIUM',
                        'resource': f"{user['UserName']}/{key['AccessKeyId']}",
                        'issue': f'访问密钥已使用{age}天(超过90天)',
                        'remediation': '轮换访问密钥'
                    })

        return findings

    def check_security_groups(self):
        """检查安全组配置"""
        findings = []
        groups = self.ec2.describe_security_groups()
        for sg in groups['SecurityGroups']:
            sg_name = sg['GroupName']
            for rule in sg.get('IpPermissions', []):
                for ip_range in rule.get('IpRanges', []):
                    if ip_range['CidrIp'] == '0.0.0.0/0':
                        port = rule.get('FromPort', 'All')
                        if port in [22, 3389, 3306, 5432, 6379, 27017] or port == 'All':
                            findings.append({
                                'severity': 'CRITICAL',
                                'resource': f"{sg_name} ({sg['GroupId']})",
                                'issue': f'安全组开放端口{port}到0.0.0.0/0',
                                'remediation': '限制管理端口访问源IP'
                            })
        return findings

    def check_rds_security(self):
        """检查RDS安全配置"""
        findings = []
        instances = self.rds.describe_db_instances()
        for instance in instances['DBInstances']:
            db_id = instance['DBInstanceIdentifier']
            # 检查公开访问
            if instance.get('PubliclyAccessible', False):
                findings.append({
                    'severity': 'HIGH',
                    'resource': db_id,
                    'issue': 'RDS实例可公开访问',
                    'remediation': '设置PubliclyAccessible为false'
                })
            # 检查加密
            if not instance.get('StorageEncrypted', False):
                findings.append({
                    'severity': 'HIGH',
                    'resource': db_id,
                    'issue': 'RDS存储未加密',
                    'remediation': '启用存储加密'
                })
            # 检查备份
            if instance.get('BackupRetentionPeriod', 0) < 7:
                findings.append({
                    'severity': 'MEDIUM',
                    'resource': db_id,
                    'issue': f'备份保留期仅{instance.get("BackupRetentionPeriod", 0)}天',
                    'remediation': '设置备份保留至少7天'
                })
            # 检查多AZ
            if not instance.get('MultiAZ', False):
                findings.append({
                    'severity': 'LOW',
                    'resource': db_id,
                    'issue': 'RDS未启用多可用区',
                    'remediation': '启用MultiAZ提高可用性'
                })
        return findings

    def generate_report(self):
        """生成合规报告"""
        all_findings = []
        all_findings.extend(self.check_s3_security())
        all_findings.extend(self.check_iam_security())
        all_findings.extend(self.check_security_groups())
        all_findings.extend(self.check_rds_security())

        # 统计
        summary = {
            'total': len(all_findings),
            'critical': len([f for f in all_findings if f['severity'] == 'CRITICAL']),
            'high': len([f for f in all_findings if f['severity'] == 'HIGH']),
            'medium': len([f for f in all_findings if f['severity'] == 'MEDIUM']),
            'low': len([f for f in all_findings if f['severity'] == 'LOW']),
        }

        return {
            'timestamp': datetime.now().isoformat(),
            'summary': summary,
            'findings': all_findings
        }


if __name__ == '__main__':
    checker = CloudComplianceChecker()
    report = checker.generate_report()
    print(f"\n{'='*60}")
    print("云安全合规检查报告")
    print(f"{'='*60}")
```

```python
#!/usr/bin/env python3
"""云安全自动响应剧本"""

import json
import logging

logger = logging.getLogger(__name__)

class SecurityPlaybook:
    """安全自动响应剧本"""

    def handle_iam_anomaly(self, event):
        """处理IAM异常事件"""
        finding_type = event.get('findingType', '')
        entity = event.get('entity', '')

        actions = []
        if 'UnauthorizedAccess' in finding_type:
            # 1. 禁用访问密钥
            actions.append({
                'action': 'disable_access_key',
                'target': entity,
                'reason': '检测到未授权访问'
            })
            # 2. 隔离相关实例
            actions.append({
                'action': 'isolate_instance',
                'target': event.get('instanceId'),
                'reason': '可能被入侵'
            })
            # 3. 通知安全团队
            actions.append({
                'action': 'notify_team',
                'channel': '#security-alerts',
                'message': f'检测到IAM异常: {finding_type}, 实体: {entity}'
            })
        elif 'CredentialExfiltration' in finding_type:
            # 1. 立即禁用所有密钥
            actions.append({
                'action': 'disable_all_keys',
                'target': entity,
                'reason': '凭据泄露检测'
            })
            # 2. 强制密码重置
            actions.append({
                'action': 'force_password_reset',
                'target': entity,
                'reason': '安全事件'
            })

        return actions

    def handle_s3_public_access(self, event):
        """处理S3公开访问事件"""
        bucket = event.get('bucketName', '')

        actions = [
            # 1. 阻止公开访问
            {'action': 'block_public_access', 'target': bucket},
            # 2. 检查是否有敏感数据
            {'action': 'scan_bucket_contents', 'target': bucket},
            # 3. 记录访问日志
            {'action': 'enable_access_logging', 'target': bucket},
            # 4. 通知数据所有者
            {'action': 'notify_data_owner', 'target': bucket},
        ]
        return actions

    def handle_ec2_compromise(self, event):
        """处理EC2实例被入侵"""
        instance_id = event.get('instanceId', '')

        actions = [
            # 1. 隔离实例(更改安全组)
            {'action': 'isolate_instance', 'target': instance_id},
            # 2. 创建取证快照
            {'action': 'create_forensic_snapshot', 'target': instance_id},
            # 3. 收集实例元数据
            {'action': 'collect_metadata', 'target': instance_id},
            # 4. 分析CloudTrail日志
            {'action': 'analyze_cloudtrail', 'target': instance_id},
            # 5. 检查横向移动
            {'action': 'check_lateral_movement', 'target': instance_id},
            # 6. 通知IR团队
            {'action': 'notify_ir_team', 'target': instance_id},
        ]
        return actions
```
