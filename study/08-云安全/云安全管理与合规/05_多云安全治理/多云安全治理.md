# 多云安全治理

### 5.1 多云挑战

```
多云环境安全挑战：

1. 可见性碎片化
   - 不同云平台管理控制台
   - 不同的API和工具集
   - 难以获得统一视图

2. 配置不一致
   - 各云厂商默认配置不同
   - 安全控制实现方式不同
   - 容易出现配置漏洞

3. 身份管理复杂
   - 各云独立的IAM体系
   - 跨云权限难以统一管理
   - 身份联邦配置复杂

4. 合规碎片化
   - 各云厂商合规认证不同
   - 审计日志格式不统一
   - 合规报告难以统一

5. 成本与效率
   - 多套工具采购成本高
   - 运维团队技能要求高
   - 自动化难以统一
```

### 5.3 云安全基线

```
云安全基线检查项（跨云通用）：

身份与访问管理:
  [ ] MFA已为所有用户启用
  [ ] 无root/admin直接使用
  [ ] 最小权限原则
  [ ] 定期清理未使用账号
  [ ] 服务账号使用角色而非密钥
  [ ] 密钥/密码定期轮换

网络安全:
  [ ] 安全组/NSG最小化规则
  [ ] 无0.0.0.0/0开放管理端口
  [ ] 数据库不在公有子网
  [ ] VPC/虚拟网络流量日志已启用
  [ ] DDoS防护已启用

数据保护:
  [ ] 存储加密已启用
  [ ] 传输加密(TLS)已强制
  [ ] 密钥由客户管理(CMK)
  [ ] 备份已加密
  [ ] 敏感数据已分类分级

日志与监控:
  [ ] 审计日志已启用
  [ ] 日志发送到SIEM
  [ ] 异常检测已配置
  [ ] 安全事件告警已配置
  [ ] 日志保留>=1年

网络安全:
  [ ] 网络分段已实施
  [ ] WAF已部署
  [ ] DNS安全已配置
  [ ] 出口流量监控
  [ ] VPN/直连加密
```
