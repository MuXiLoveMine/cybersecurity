# 云原生安全

### 8.1 容器运行时安全

```text
云原生安全四层模型:

Layer 1: 代码安全
  ├── 源代码扫描(SAST)
  ├── 依赖检查(SCA)
  ├── 硬编码密钥检测
  └── 容器化文件安全(Dockerfile扫描)

Layer 2: 构建安全
  ├── 镜像漏洞扫描(Trivy/Clair)
  ├── 镜像签名验证(Cosign)
  ├── 基础镜像最小化
  └── 多阶段构建

Layer 3: 部署安全
  ├── 准入控制器(OPA/Kyverno)
  ├── Pod安全策略
  ├── NetworkPolicy
  └── 安全上下文

Layer 4: 运行时安全
  ├── 容器运行时保护(Falco)
  ├── 工作负载行为监控
  ├── 异常进程检测
  └── 容器逃逸检测
```

### 8.2 Kubernetes安全加固

```yaml
# 1. Pod安全标准(Pod Security Standards)
# 通过准入控制器强制执行
apiVersion: v1
kind: Namespace
metadata:
  name: production
  labels:
    pod-security.kubernetes.io/enforce: restricted
    pod-security.kubernetes.io/enforce-version: v1.25
    pod-security.kubernetes.io/audit: restricted
    pod-security.kubernetes.io/warn: restricted

---
# 2. 安全的Pod配置
apiVersion: v1
kind: Pod
metadata:
  name: secure-pod
spec:
  securityContext:
    runAsNonRoot: true
    runAsUser: 10001
    runAsGroup: 10001
    fsGroup: 10001
    seccompProfile:
      type: RuntimeDefault
    seLinuxOptions:
      level: "s0:c123,c456"
  containers:
    - name: app
      image: registry.example.com/app:v1.2.3@sha256:abc123...
      securityContext:
        allowPrivilegeEscalation: false
        privileged: false
        readOnlyRootFilesystem: true
        runAsNonRoot: true
        capabilities:
          drop:
            - ALL
          add:
            - NET_BIND_SERVICE
      resources:
        limits:
          cpu: "2"
          memory: "2Gi"
        requests:
          cpu: "500m"
          memory: "512Mi"
      volumeMounts:
        - name: tmp
          mountPath: /tmp
        - name: cache
          mountPath: /cache
  volumes:
    - name: tmp
      emptyDir:
        medium: Memory
    - name: cache
      emptyDir: {}

---
# 3. RBAC最小权限
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  namespace: production
  name: app-reader
rules:
  - apiGroups: [""]
    resources: ["configmaps", "secrets"]
    verbs: ["get", "list", "watch"]
    resourceNames: ["app-config", "app-secrets"]

---
# 4. NetworkPolicy
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny-all
  namespace: production
spec:
  podSelector: {}
  policyTypes:
    - Ingress
    - Egress

---
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-app-to-db
  namespace: production
spec:
  podSelector:
    matchLabels:
      role: app
  policyTypes:
    - Egress
  egress:
    - to:
        - podSelector:
            matchLabels:
              role: db
      ports:
        - protocol: TCP
          port: 5432
```

### 8.3 容器运行时安全监控

```bash
# Falco - 容器运行时安全监控
# 安装
helm install falco falcosecurity/falco \
    --set falco.driver.kind=ebpf \
    --set falcosidekick.enabled=true \
    --set falcosidekick.config.elasticsearch.hostport=http://elasticsearch:9200

# 自定义Falco规则
# /etc/falco/falco_rules.local.yaml
cat > custom_rules.yaml << 'EOF'
- macro: container
  condition: (container.id != host)

- rule: Unexpected Process In Container
  desc: 检测容器中运行的非预期进程
  condition: container and proc.name not in (allowed_processes)
  output: >
    非预期进程 (container=%container.name
    proc=%proc.name pid=%proc.pid
    user=%user.name)
  priority: WARNING
  tags: [container, process]

- rule: Container Escape Attempt
  desc: 检测容器逃逸尝试
  condition: >
    container and
    (proc.name in (nsenter, mount, docker, kubectl)
    or proc.args contains "privileged"
    or proc.args contains "hostPath"
    or proc.args contains "hostNetwork")
  output: >
    容器逃逸尝试 (container=%container.name
    proc=%proc.name args=%proc.args)
  priority: CRITICAL
  tags: [container, escape]

- rule: Sensitive File Access
  desc: 检测容器访问敏感文件
  condition: >
    container and
    (fd.name startswith /etc/shadow
    or fd.name startswith /etc/passwd
    or fd.name startswith /root/.ssh
    or fd.name startswith /var/run/docker.sock
    or fd.name startswith /proc/1/root)
  output: >
    敏感文件访问 (container=%container.name
    file=%fd.name proc=%proc.name)
  priority: WARNING
  tags: [container, file]

- rule: Crypto Miner Detection
  desc: 检测加密货币挖矿进程
  condition: >
    container and
    (proc.name in (xmrig, ethminer, minerd, cpuminer)
    or proc.cmdline contains "stratum+tcp"
    or proc.cmdline contains "stratum+ssl"
    or proc.cmdline contains "monero"
    or proc.cmdline contains "pool.")
  output: >
    挖矿进程检测 (container=%container.name
    proc=%proc.name cmdline=%proc.cmdline)
  priority: CRITICAL
  tags: [container, malware]
EOF

# Kubernetes审计日志分析
# 获取审计日志
kubectl get events --all-namespaces --sort-by='.lastTimestamp'
# 检查异常API调用
kubectl logs -n kube-system -l component=kube-apiserver | grep "forbidden"

# 使用kube-bench进行CIS基准检查
kube-bench --benchmark cis-1.6
kube-bench run --targets=node
kube-bench run --targets=master
```
