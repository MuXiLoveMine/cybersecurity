> 📋 每个阶段结束后，用这份测试题检验自己的掌握程度
> ⭐ 评分标准：60分及格，80分良好，95分优秀
> 💡 做错的题目就是你需要补强的知识点

---

## 📊 评估说明

### 测试结构
每个阶段的测试包含两部分：
- **理论题**（50分）：选择题、判断题、简答题
- **实操题**（50分）：靶场实操、工具使用、漏洞利用

### 评分标准
| 分数 | 等级 | 说明 |
|------|------|------|
| 95-100 | 优秀 | 完全掌握，可以进入下一阶段 |
| 80-94 | 良好 | 基本掌握，少量知识点需要复习 |
| 60-79 | 及格 | 勉强掌握，建议重点复习薄弱环节 |
| 60以下 | 不及格 | 需要重新学习本阶段内容 |

### 评估流程
1. 先做理论题，闭卷，不查资料
2. 再做实操题，计时完成
3. 对照答案评分
4. 整理错题，针对性复习
5. 达到80分以上再进入下一阶段

## 一、理论题（50分）

### 选择题（每题2分，共20分）

1. OSI 七层模型中，路由器工作在哪一层？
   - A. 物理层
   - B. 数据链路层
   - C. 网络层
   - D. 传输层

2. TCP 三次握手的顺序是？

   - B. SYN → ACK → SYN+ACK
   - C. SYN+ACK → SYN → ACK
   - D. ACK → SYN → SYN+ACK

3. 以下哪个不是 TCP 协议的特点？
   - A. 面向连接
   - B. 可靠传输
   - C. 拥塞控制
   - D. 速度快

4. HTTP 状态码 404 表示什么？
   - A. 服务器内部错误
   - B. 请求的资源不存在
   - C. 权限不足
   - D. 重定向

5. Linux 中修改文件权限的命令是？
   - A. chown
   - B. chmod
   - C. chgrp
   - D. passwd

6. Linux 中查看当前目录下文件的命令是？
   - A. cd
   - B. pwd
   - C. ls
   - D. mkdir

7. Python 中以下哪个数据类型是不可变的？
   - A. 列表 list
   - B. 字典 dict
   - C. 元组 tuple
   - D. 集合 set

8. SQL 中用于查询数据的关键字是？
   - A. INSERT
   - B. UPDATE
   - C. SELECT
   - D. DELETE

9. 以下哪个不是 Burp Suite 的模块？
   - A. Proxy
   - B. Repeater
   - C. Intruder
   - D. Nmap

10. 以下哪个端口是 HTTPS 默认使用的？
    - A. 80
    - B. 443
    - C. 22
    - D. 3306

### 判断题（每题1分，共10分）

1. TCP 是无连接的协议，UDP 是面向连接的协议。（ ）
2. HTTP 是明文传输的，HTTPS 是加密传输的。（ ）
3. Linux 中 root 用户拥有最高权限。（ ）
4. Python 中的列表索引从 1 开始。（ ）
5. SQL 注入是因为用户输入被当作 SQL 代码执行。（ ）
6. DNS 协议使用 TCP 端口 53。（ ）
7. Cookie 存储在服务器端，Session 存储在客户端。（ ）
8. Nmap 只能用来扫描端口，不能用来识别服务版本。（ ）
9. 虚拟机中的操作不会影响物理机，所以可以随便搞。（ ）
10. 只要不被发现，攻击别人的网站是可以的。（ ）

### 简答题（每题4分，共20分）

1. 简述 TCP 三次握手的过程，为什么需要三次握手而不是两次？

2. 简述 HTTP 和 HTTPS 的区别，HTTPS 是如何保证安全的？

3. 简述 Linux 文件权限的 rwx 分别代表什么，数字 755 表示什么权限？

4. 什么是 SQL 注入？SQL 注入的主要类型有哪些？

5. 简述一次完整的 HTTP 请求过程，从输入 URL 到页面显示都发生了什么？

# 💡 学习建议

## 测试没通过怎么办？

1. **不要灰心**：测试的目的是找出薄弱环节，不是为了打击你
2. **分析错题**：把做错的题目整理出来，分析为什么错
3. **针对性复习**：哪个知识点不会，就重点复习哪个
4. **多动手练**：安全是实践性很强的学科，多动手才能掌握
5. **寻求帮助**：实在搞不懂的，可以去社区提问、找师傅

## 如何高效复习？

1. **错题本**：把做错的题和遇到的坑记下来，定期复习
2. **费曼学习法**：用自己的话把知识点讲出来，能讲清楚才是真懂了
3. **间隔重复**：第一天学的内容，第二天、第七天、第三十天各复习一次
4. **以战养学**：多打靶场、多做 CTF 题，在实战中巩固知识
5. **教别人**：最好的学习方式就是教别人

## 学习瓶颈期怎么办？

1. **调整节奏**：如果学累了，就休息几天，不要硬撑
2. **换个方向**：Web 学累了，可以看看逆向、移动安全
3. **打 CTF**：参加比赛可以激发学习动力
4. **写文章**：把学到的东西写成博客，加深理解
5. **找伙伴**：和志同道合的人一起学，互相鼓励
