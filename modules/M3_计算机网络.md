## 1. 模块定位与前置知识

### 模块定位
网络是安全的"高速公路"——所有攻击和防御都发生在网络上。不懂网络协议，你就看不懂流量，不知道攻击是怎么发生的、数据是怎么传输的、漏洞是怎么被利用的。

对于安全从业者，网络知识的要求不是"考试背题"，而是**能看懂流量、能分析协议、能理解攻击原理**。

### 前置知识
- 零基础可学，但建议先掌握 M2 的基本网络命令（ping / netstat / ifconfig 等）
- 与 M1（编程）并行，学到网络编程部分需要编程基础
- 需要 Wireshark 抓包实操环境

### 安全从业者网络能力分级

| 级别 | 能力描述 | 对应阶段 |
|------|---------|---------|
| **L1 入门** | 理解 OSI 七层、TCP/IP、HTTP，会用 Wireshark 抓包 | 阶段一中 |
| **L2 实用** | 掌握常见协议原理、能独立分析攻击流量、理解常见攻击的网络层原理 | 阶段一末 |
| **L3 熟练** | 能构造自定义数据包、理解隧道/代理/绕过原理、能做流量分析取证 | 阶段二末 |
| **L4 精通** | 协议级漏洞挖掘、高级流量隐匿、网络攻防对抗 | 阶段三及以后 |

### 5.2 Scapy 练习（重点！）

```python
from scapy.all import *

# 练习 1：构造并发送一个 ICMP Echo Request（ping）
packet = IP(dst="192.168.1.1") / ICMP()
response = sr1(packet, timeout=2, verbose=0)
if response:
    response.show()

# 练习 2：SYN 扫描 — 发送 SYN 包，根据响应判断端口状态
def syn_scan(target, port):
    pkt = IP(dst=target) / TCP(dport=port, flags="S")
    resp = sr1(pkt, timeout=1, verbose=0)
    if resp and resp.haslayer(TCP):
        if resp[TCP].flags == "SA":  # SYN-ACK
            return "Open"
        elif resp[TCP].flags == "RA":  # RST-ACK
            return "Closed"
    return "Filtered"

# 练习 3：ARP 扫描 — 发现局域网内存活主机
# 练习 4：DNS 查询请求构造
```

## 8. 实战项目

### 项目一：Wireshark 流量分析报告

**目标**：通过分析几个真实场景的抓包文件，输出专业的流量分析报告。

**任务清单**：
1. **基础流量分析**
   - 抓取一次完整的 Web 访问（HTTP + HTTPS）
   - 分析 TCP 三次握手、HTTP 请求响应、四次挥手
   - 统计：总数据包数、HTTP 请求数、各状态码数量
2. **DNS 流量分析**
   - 抓取 DNS 查询过程
   - 分析 DNS 报文结构、查询类型、响应码
3. **攻击流量识别**
   - 分析一个包含端口扫描的 pcap 文件
   - 识别扫描类型（全连接 / SYN / Xmas 等）
   - 找出扫描者 IP 和目标端口
4. **流量取证**
   - 从 pcap 中还原传输的文件（图片 / 文档等）
   - 从流量中提取 FTP / HTTP 明文密码
5. 输出一份《Wireshark 流量分析报告》，包含截图和分析结论

**预计耗时**：20 小时

## 9. 常见误区

### ❌ 误区 1：死记硬背 OSI 七层，不理解实际应用
**现象**：能背出七层名字和每层设备，但不知道 TCP 握手发生在哪一层、HTTP 请求怎么封装。
**纠正**：用 Wireshark 抓包对照学习。每学一个协议，就抓一次包，看真实的数据包长什么样。理论 + 实操结合才能理解。

### ❌ 误区 2：子网划分学不会就放弃
**现象**：觉得子网划分太抽象，学不会就跳过了。
**纠正**：子网划分是网络工程师的基本功，也是安全从业者的必备技能。多画数轴、多做练习题、用在线工具验证，花一周时间专项练习，肯定能学会。

### ❌ 误区 3：只学 Web 相关协议，不关心底层
**现象**：只学 HTTP/HTTPS，TCP/UDP/ARP 一知半解。
**纠正**：Web 安全是应用层的，但很多攻击（SQL 注入、XSS）的理解深度取决于你对协议的理解深度。端口扫描、内网渗透、流量分析更是离不开底层协议。

### ❌ 误区 4：Wireshark 抓了包不知道看什么
**现象**：打开 Wireshark 抓了一堆包，面对满屏数据无从下手。
**纠正**：先明确分析目标，再用过滤器过滤。例如：要分析 HTTP 就过滤 `http`，要找某个 IP 的流量就过滤 `ip.addr == 1.2.3.4`。带着问题抓包，而不是瞎抓。

### ❌ 误区 5：觉得 Scapy 太难，反正有 Nmap 能用
**现象**：觉得 Scapy 语法复杂，反正 Nmap 已经够用了。
**纠正**：Nmap 是别人写好的工具，Scapy 让你理解工具背后的原理。懂原理才能在特殊场景定制工具，也才能理解各种绕过检测的技巧。

### ❌ 误区 6：忽视网络安全防御技术
**现象**：只学攻击技术，不学防火墙、IDS、VPN 等防御技术。
**纠正**：不知道防御机制怎么运作，就不知道怎么绕过。攻击和防御是硬币的两面，都要理解。
