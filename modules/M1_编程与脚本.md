## 1. 模块定位与前置知识

### 模块定位
编程与脚本能力是网络安全从业者的"基本功中的基本功"。不会编程的安全从业者只能使用别人的工具，遇到特殊场景就束手无策；而会编程的人可以快速自动化、定制工具、写 PoC/EXP、分析恶意代码，形成核心竞争力。

本模块的目标不是成为"程序员"，而是成为**能用编程解决安全问题的人**。

### 前置知识
- **零基础可学**：本模块从零开始，不需要任何编程基础
- 建议同时学习 M2（Linux/Windows），因为编程需要在操作系统环境中练习
- 建议第 2 个月起同步学 M3（计算机网络），编程中的网络编程需要网络知识

### 安全从业者编程能力分级

| 级别 | 能力描述 | 对应阶段 |
|------|---------|---------|
| **L1 入门** | 读懂脚本、修改参数、跑通现有工具 | 阶段一中期 |
| **L2 实用** | 独立编写自动化脚本、简单 PoC、数据处理工具 | 阶段一末 |
| **L3 熟练** | 编写完整工具链、漏洞 EXP、定制化扫描器 | 阶段二末 |
| **L4 精通** | 造轮子、开源项目、复杂漏洞利用框架 | 阶段三及以后 |

# 练习 1：写一个密码生成器，支持指定长度、是否包含特殊字符
import random
import string

def generate_password(length=12, use_special=True):
    chars = string.ascii_letters + string.digits
    if use_special:
        chars += string.punctuation
    return ''.join(random.choice(chars) for _ in range(length))

# 练习 2：写一个端口扫描器（TCP Connect 扫描）
import socket

def port_scan(target, port):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(1)
    result = s.connect_ex((target, port))
    s.close()
    return result == 0

# 练习 3：写一个目录爆破器雏形（单线程）
import requests

def dir_brute(url, wordlist_path):
    with open(wordlist_path, 'r') as f:
        for line in f:
            path = line.strip()
            resp = requests.get(f"{url}/{path}")
            if resp.status_code == 200:
                print(f"[+] Found: /{path}")

## 9. 常见误区

### ❌ 误区 1：只看视频不敲代码
**现象**：看了几十小时视频，觉得自己懂了，一写代码全是 Bug。
**纠正**：视频和代码时间比例至少 1:2，每学一个知识点立即动手写。编程是练出来的，不是看出来的。

### ❌ 误区 2：追求"全栈"，样样松
**现象**：Python 刚入门就去学 Go，Go 没搞明白又去学 Rust。
**纠正**：先把 Python 练到 L3 水平（能独立写完整工具），再学第二门语言。安全领域 Python 使用率超过 70%，先精通一门。

### ❌ 误区 3：跳过算法和数据结构
**现象**：觉得安全不需要算法，只会写脚本。
**纠正**：至少掌握基本的数据结构（数组、链表、栈、队列、哈希表、树）和常见算法（排序、查找、递归）。算法训练逻辑思维，写漏洞利用和逆向都需要。

### ❌ 误区 4：不做版本管理
**现象**：代码乱堆，改坏了没法回退。
**纠正**：从第一天开始用 Git，所有代码都放 GitHub 私有仓库，定期提交。

### ❌ 误区 5：不写注释和文档
**现象**：自己写的代码，一个月后看不懂了。
**纠正**：养成写注释的习惯，函数必须有 Docstring，复杂逻辑必须有行内注释。

### ❌ 误区 6：沉迷"黑客脚本"，基础不牢
**现象**：到处收集 EXP 脚本、后门代码，觉得很酷。
**纠正**：先把基础语法和编程思想学扎实，再去研究攻击代码。不然连脚本改参数都不会改。
