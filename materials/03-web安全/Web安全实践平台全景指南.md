## 一、实践平台概览

### 1.1 为什么需要实践平台

> 安全是一门实践性极强的学科——**看书看不会，听课听不会，只有动手练才会**。

| 为什么要实践 | 说明 |
|------------|------|
| **理论落地** | 看了 100 遍 SQL 注入原理，不如亲手打一遍印象深 |
| **培养手感** | 工具使用、漏洞利用都需要"手感"，练多了自然熟 |
| **发现盲区** | 自以为懂了，一做才发现有很多细节没理解 |
| **建立信心** | 成功打穿一个靶场的成就感，是继续学习的最好动力 |
| **积累经验** | 真实漏洞千变万化，实战经验只能靠练出来 |

### 1.2 平台类型总览

| 平台类型 | 特点 | 代表平台 | 适合阶段 | 学习目标 | 优势 | 劣势 |
|---------|------|---------|---------|---------|------|------|
| **在线实验室** | 浏览器直接用，引导式学习，有讲解 | PortSwigger Academy、TryHackMe | 入门 → 中级 | 系统学习各类漏洞 | 即开即用、有引导、质量高 | 部分高级内容收费 |
| **本地靶场** | Docker/虚拟机部署，完全可控 | DVWA、Juice Shop、Vulhub | 入门 → 高级 | 深入研究、复现漏洞 | 完全控制、可定制、离线可用 | 需要一定运维能力 |
| **CTF 平台** | 竞技式，题目制，有排名 | 攻防世界、CTFSHOW、BUUCTF | 中级 → 高级 | 技术提升、竞赛训练 | 题目多、有竞争感、社区活跃 | 有些题偏 CTF 技巧，离实战有距离 |
| **SRC 平台** | 真实目标，真实漏洞，有奖金 | 补天、漏洞盒子、各大厂 SRC | 高级 → 实战 | 真实漏洞挖掘、实战经验 | 最真实、有回报、简历加分 | 有门槛、需要遵守规则 |
| **综合靶场** | 体系化，多方向，有学习路径 | 好靶场等 | 入门 → 实战 | 系统成长，全面提升 | 有体系、本地化、国内友好 | 部分需付费 |

### 1.3 学习阶段与平台选择

```
  零基础
    │
    ▼
  入门阶段 ──→ 在线实验室（引导式）+ 简单本地靶场
    │         PortSwigger Academy / DVWA / TryHackMe
    │
    ▼
  进阶阶段 ──→ 在线实验室（高级）+ CTF 刷题 + 更多本地靶场
    │         PortSwigger Practitioner / CTFSHOW / Vulhub
    │
    ▼
  高级阶段 ──→ CTF 竞赛 + SRC 实战 + 综合靶场
    │         HackTheBox / 补天 / 好靶场高级靶场
    │
    ▼
  实战阶段 ──→ 真实项目 + SRC + 红队演练
              授权渗透测试 / 漏洞挖掘 / 红队评估
```

## 三、本地靶场（Docker 部署，完全可控）

本地靶场的优势是**完全可控、可以随意折腾、离线可用**——你可以随时暂停、快照、回滚、改代码来研究漏洞原理。

### 3.1 OWASP Juice Shop

| 项目 | 内容 |
|------|------|
| **全称** | OWASP Juice Shop |
| **定位** | 现代 Web 应用靶场，OWASP 官方项目 |
| **技术栈** | Node.js + Express + Angular + SQLite |
| **特点** | 现代化、设计好、漏洞全面、有挑战模式和评分系统 |
| **部署方式** | Docker（推荐）、源码部署、可执行文件 |
| **难度** | 入门 → 中级 |
| **漏洞数量** | 涵盖 OWASP Top 10 全部类别，100+ 个挑战 |
| **语言** | 英文（界面支持多语言） |
| **官网** | juice-shop.owasp.org |

#### 覆盖的漏洞类型

- SQL 注入
- XSS（反射型、存储型、DOM 型）
- CSRF
- 越权访问（水平/垂直）
- 文件上传
- XXE
- 不安全的反序列化
- 密码安全
- 业务逻辑漏洞
- API 安全
- ……等等

#### 为什么推荐 Juice Shop

- ✅ **官方出品**：OWASP 官方项目，质量有保证
- ✅ **现代化**：技术栈新，不像有些老靶场还在用 PHP 5
- ✅ **体验好**：界面好看，有进度系统和成就系统，像玩游戏
- ✅ **部署简单**：Docker 一行命令启动
- ✅ **社区活跃**：有大量教程和 Writeup

#### 快速部署（Docker）

```bash
docker pull bkimminich/juice-shop
docker run -d -p 3000:3000 bkimminich/juice-shop
# 然后浏览器访问 http://localhost:3000
```

#### 适用场景

- ✅ Web 安全入门
- ✅ OWASP Top 10 学习
- ✅ 安全培训和演示
- ✅ 自己研究漏洞原理

### 3.2 DVWA（Damn Vulnerable Web Application）

| 项目 | 内容 |
|------|------|
| **全称** | Damn Vulnerable Web Application |
| **定位** | 经典 PHP/MySQL 靶场，入门必备 |
| **技术栈** | PHP + MySQL |
| **特点** | 经典、简单、四种难度可调、入门友好 |
| **部署方式** | Docker、手动部署（XAMPP + DVWA） |
| **难度** | 入门级（有四个难度级别：Low/Medium/High/Impossible） |
| **官网** | dvwa.co.uk |

#### 四大难度级别

| 难度 | 说明 | 适合 |
|------|------|------|
| **Low** | 几乎没有防护，最容易利用 | 零基础，理解漏洞原理 |
| **Medium** | 有一些简单的防护，可以被绕过 | 入门后练习绕过技巧 |
| **High** | 防护更严格，需要更巧妙的利用 | 中级学习者 |
| **Impossible** | 安全的实现方式，用来对比学习 | 学习正确的写法 |

> DVWA 的设计非常棒——同一个漏洞，四个难度。你可以从 Low 开始理解原理，然后逐步挑战 Medium 和 High，最后看 Impossible 学习正确的防御方式。

#### 覆盖的漏洞模块

- 暴力破解（Brute Force）
- 命令注入（Command Injection）
- CSRF
- 文件包含（File Inclusion）
- 文件上传（File Upload）
- SQL 注入（SQL Injection）
- SQL 盲注（SQL Injection (Blind)）
- 弱会话 ID（Weak Session IDs）
- XSS（反射型、存储型、DOM 型）
- CSP 绕过
- JavaScript 攻击
- ……等十几个模块

#### 适用场景

- ✅ 绝对零基础的第一个靶场
- ✅ 理解最基础的 Web 漏洞
- ✅ 学习 PHP 相关的 Web 安全
- ✅ 安全入门教学

## 五、SRC 漏洞挖掘平台（真实实战）

SRC（Security Response Center，安全应急响应中心）是企业设立的漏洞接收平台——白帽子（安全研究者）可以在授权范围内提交漏洞，获得奖金和排名。

### 5.1 平台对比

|------|------|------|---------|------|

| **漏洞盒子** | 第三方众测平台 | 漏洞众测与安全服务 | 几十到几万不等 | 另一个主流平台 |
| **阿里先知 SRC** | 企业自建 SRC | 阿里集团安全应急响应中心 | 几百到几十万 | 大厂 SRC、奖金高、要求严 |
| **腾讯安全应急响应中心（TSRC）** | 企业自建 SRC | 腾讯安全应急响应中心 | 几百到几十万 | 大厂 SRC、影响力大 |
| **百度安全应急响应中心（BSRC）** | 企业自建 SRC | 百度安全应急响应中心 | 几百到几万 | 大厂 SRC |
| **各大互联网公司 SRC** | 企业自建 SRC | 字节/美团/京东/拼多多等 | 各有不同 | 几乎所有大厂都有自己的 SRC |

> **第三方平台 vs 企业自建 SRC**：
> - 第三方平台（补天/漏洞盒子）：厂商多、选择多、一个账号挖所有厂商
> - 企业自建 SRC：奖金可能更高、漏洞范围更明确、直接对接企业安全团队
> - 建议：两者都可以注册，根据兴趣和能力选择

### 5.3 SRC 入门建议

1. **先在靶场打基础**：不要上来就直接挖 SRC，先在靶场练到一定水平
2. **从简单漏洞开始**：信息泄露、弱口令、逻辑漏洞等相对容易发现
3. **仔细阅读规则**：每个平台、每个厂商都有自己的规则，一定要遵守
4. **写好漏洞报告**：清晰的描述、复现步骤、危害说明、修复建议——报告质量很重要
5. **不要触碰底线**：超出范围的测试、破坏性操作、数据泄露等绝对不要做
6. **坚持和积累**：刚开始可能很久都挖不到漏洞，坚持下去就会有收获

> **SRC 的意义**：
> - **实战经验**：真实目标、真实漏洞，和靶场完全不同
> - **经济回报**：挖到漏洞有奖金，做得好收入不错
> - **简历加分**：有 SRC 排名和漏洞记录，找工作很有优势
> - **行业认可**：在安全圈积累名气和人脉
>
> **但也要注意**：
> - SRC 不是"想挖就能挖到"，需要技术、耐心和运气
> - 一定要在规则范围内测试，越界可能承担法律责任
> - 安全是目的，奖金是副产品，不要本末倒置

### 9.4 常见问题解答

#### Q：平台太多了，我应该选哪个？

**A**：建议从 PortSwigger Academy 开始（免费、权威、系统），同时用 DVWA 或 Juice Shop 练手。等有基础了，再根据自己的方向选择更多平台。

> **重点不是选哪个平台，而是选一个坚持学下去。**
> 平台只是工具，你的努力和坚持才是关键。

#### Q：免费平台够用吗？需要付费吗？

**A**：入门阶段免费平台完全够用。PortSwigger Academy 全免费，质量还非常高。等你学到一定程度，觉得有需要了再考虑付费平台也不迟。

#### Q：只练靶场能找到工作吗？

**A**：靶场练习是基础，但只有靶场经验是不够的。还需要：
- 实际项目经验（实习、SRC、开源贡献）
- 系统的知识体系（不只是会做题）
- 沟通和表达能力
- 持续学习的能力

靶场能证明你的技术基础，但不能替代全部。

#### Q：CTF 和实战差别大吗？

**A**：有差别，但基础是相通的。
- CTF 题目是精心设计的，考点明确，答案唯一
- 真实环境更复杂，信息更多，需要自己找方向

但 CTF 能训练你的技术基础和解题思维——这些都是通用的。建议先用 CTF 打基础，再到实战中历练。
